# Malay surah-name meanings, Nakafa review record

No official Malaysian edition publishes the meanings of all 114 surah names, so Nakafa wrote the Malay values from the Arabic names and reviewed each one against the pinned Tanzil English meaning and the pinned LPMQ Indonesian meaning. Malaysian Malay spelling is used (Lembu, Jumaat, Mesyuarat), and proper-name headings stay as the name itself (Yunus, Hud, Taha).

These values are Nakafa's own work, published with the Aksara corpus under its licence. This file is the pinned record of the review; `packages/corpus/quran/names.ts` holds the same values for generation.
