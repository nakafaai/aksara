# Gegeben

Gegeben ist eine **Logarithmusungleichung** mit einer Basis kleiner als eins:

<BlockMath math="\log_{\frac{1}{2}}\left(x^2 - 3x\right) \ge -2" />

# Gesucht

Bestimme alle reellen Zahlen <InlineMath math="x" />, die diese Ungleichung erfüllen.

# Lösung

Eine Logarithmusungleichung mit Basis <InlineMath math="\frac{1}{2}" /> hat **zwei feste Kontrollstellen**, die beide bestehen müssen. Erstens muss das Argument im Logarithmus strikt positiv sein, damit der Ausdruck überhaupt existiert. Zweitens läuft ein Logarithmus mit Basis zwischen <InlineMath math="0" /> und <InlineMath math="1" /> bergab: größere Argumente liefern kleinere Werte, weshalb sich das Ungleichheitszeichen umdreht.

> Bei einem Logarithmus mit Basis kleiner als eins sicherst du zuerst den positiven Definitionsbereich und drehst beim Weglassen des Logarithmus das Ungleichheitszeichen um.

## Den Definitionsbereich festlegen

Der Logarithmus ist nur definiert, wenn **sein Argument strikt positiv ist**:

<BlockMath math="x^2 - 3x = x(x - 3) > 0 \quad \Longleftrightarrow \quad x < 0 \ \text{oder} \ x > 3" />

Alle Zahlen von <InlineMath math="0" /> bis <InlineMath math="3" /> einschließlich der Randpunkte <InlineMath math="0" /> und <InlineMath math="3" /> fallen sofort heraus.

## Ungleichheitszeichen wegen der kleinen Basis umdrehen

Schreibe die rechte Seite zur gleichen Basis um:

<BlockMath math="\left(\frac{1}{2}\right)^{-2} = 4 \quad \Longrightarrow \quad -2 = \log_{\frac{1}{2}} 4" />

Da der Logarithmus zur Basis <InlineMath math="\frac{1}{2}" /> **streng monoton fällt**, dreht sich das Zeichen beim Auflösen um:

<BlockMath math="\begin{aligned}
\log_{\frac{1}{2}}\left(x^2 - 3x\right) &\ge \log_{\frac{1}{2}} 4 \\
x^2 - 3x &\le 4 \\
(x - 4)(x + 1) &\le 0 \quad \Longleftrightarrow \quad -1 \le x \le 4
\end{aligned}" />

## Beide Bedingungen schneiden

Schneide nun das Intervall von <InlineMath math="-1" /> bis <InlineMath math="4" /> mit **dem Definitionsbereich außerhalb von null bis drei**:

<BlockMath math="-1 \le x < 0 \qquad \text{oder} \qquad 3 < x \le 4" />

## Falsche Antworten prüfen

Jede falsche Auswahl **scheitert an einer der beiden Kontrollstellen**:

| Auswahl | Warum falsch |
| --- | --- |
| <InlineMath math="-1 \le x \le 4" /> | Vergisst den Definitionsbereich, denn für <InlineMath math="x = 1" /> ist das Argument <InlineMath math="-2" />. |
| <InlineMath math="x \le -1" /> oder <InlineMath math="x \ge 4" /> | Dreht das Ungleichheitszeichen beim Weglassen von <InlineMath math="\log_{\frac{1}{2}}" /> nicht um. |
| <InlineMath math="x < 0" /> oder <InlineMath math="x > 3" /> | Gibt nur den Definitionsbereich an, ohne die Schranke <InlineMath math="-2" /> auszuwerten. |
| <InlineMath math="-1 < x < 0" /> oder <InlineMath math="3 < x < 4" /> | Schließt <InlineMath math="-1" /> und <InlineMath math="4" /> aus, obwohl <InlineMath math="\ge" /> Gleichheit zulässt. |
| <InlineMath math="-1 \le x \le 0" /> oder <InlineMath math="3 \le x \le 4" /> | Nimmt <InlineMath math="0" /> und <InlineMath math="3" /> mit auf, wo das Argument null und der Logarithmus undefiniert ist. |

# Antwort

Alle reellen Zahlen <InlineMath math="x" />, die die Ungleichung erfüllen, sind:

<BlockMath math="-1 \le x < 0 \qquad \text{oder} \qquad 3 < x \le 4" />
