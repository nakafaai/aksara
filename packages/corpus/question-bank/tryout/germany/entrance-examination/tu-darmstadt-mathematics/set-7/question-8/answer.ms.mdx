# Diberi

Diberikan **ketaksamaan logaritma** (*Ungleichung*) dengan asas pecahan kurang daripada satu:

<BlockMath math="\log_{\frac{1}{2}}\left(x^2 - 3x\right) \ge -2" />

# Ditanya

Tentukan semua nombor nyata <InlineMath math="x" /> yang memenuhi ketaksamaan ini.

# Penyelesaian

Ketaksamaan logaritma berasaskan <InlineMath math="\frac{1}{2}" /> mempunyai **dua pusat pemeriksaan** yang mesti lulus serentak. Pertama, argumen di dalam logaritma mesti positif supaya nilainya wujud. Kedua, asas antara <InlineMath math="0" /> dengan <InlineMath math="1" /> bergerak menurun: makin besar argumen, makin kecil nilai logaritma, maka tanda ketaksamaan mesti diterbalikkan.

> Bagi logaritma berasas kurang daripada satu, sentiasa semak domain positif dahulu dan terbalikkan tanda ketaksamaan apabila membuang logaritma.

## Menentukan domain positif

Logaritma hanya tertakrif apabila **argumennya positif ketat**:

<BlockMath math="x^2 - 3x = x(x - 3) > 0 \quad \Longleftrightarrow \quad x < 0 \ \text{atau} \ x > 3" />

Semua nombor dari <InlineMath math="0" /> hingga <InlineMath math="3" />, termasuk titik hujung <InlineMath math="0" /> dan <InlineMath math="3" />, disingkirkan terus.

## Menterbalikkan tanda ketaksamaan kerana asas pecahan

Tulis sebelah kanan dengan asas yang sama menggunakan hukum indeks negatif:

<BlockMath math="\left(\frac{1}{2}\right)^{-2} = 4 \quad \Longrightarrow \quad -2 = \log_{\frac{1}{2}} 4" />

Kerana fungsi logaritma berasas <InlineMath math="\frac{1}{2}" /> **menyusut tegas**, membuang logaritma membalikkan tanda:

<BlockMath math="\begin{aligned}
\log_{\frac{1}{2}}\left(x^2 - 3x\right) &\ge \log_{\frac{1}{2}} 4 \\
x^2 - 3x &\le 4 \\
(x - 4)(x + 1) &\le 0 \quad \Longleftrightarrow \quad -1 \le x \le 4
\end{aligned}" />

## Menyatukan persilangan dua syarat

Gabungkan selang dari <InlineMath math="-1" /> hingga <InlineMath math="4" /> dengan **syarat domain di luar sifar hingga tiga**:

<BlockMath math="-1 \le x < 0 \qquad \text{atau} \qquad 3 < x \le 4" />

## Menyemak pilihan salah

Perhatikan bagaimana setiap pengganggu **gagal pada salah satu pusat pemeriksaan**:

| Pilihan | Mengapa salah |
| --- | --- |
| <InlineMath math="-1 \le x \le 4" /> | Melupakan domain, kerana bagi <InlineMath math="x = 1" /> argumennya ialah <InlineMath math="-2" />. |
| <InlineMath math="x \le -1" /> atau <InlineMath math="x \ge 4" /> | Tidak menterbalikkan tanda ketaksamaan ketika membuang logaritma berasas <InlineMath math="\frac{1}{2}" />. |
| <InlineMath math="x < 0" /> atau <InlineMath math="x > 3" /> | Hanya menyatakan domain tanpa menyelesaikan had <InlineMath math="-2" />. |
| <InlineMath math="-1 < x < 0" /> atau <InlineMath math="3 < x < 4" /> | Membuang hujung <InlineMath math="-1" /> dan <InlineMath math="4" /> walaupun <InlineMath math="\ge" /> membenarkan kesamaan. |
| <InlineMath math="-1 \le x \le 0" /> atau <InlineMath math="3 \le x \le 4" /> | Memasukkan <InlineMath math="0" /> dan <InlineMath math="3" />, tempat argumen bernilai sifar dan logaritma tidak tertakrif. |

# Jawapan

Semua nombor nyata <InlineMath math="x" /> yang memenuhi ketaksamaan ini ialah:
