# Gegeben

In dieser Gleichung vierten Grades tritt der **wiederkehrende Block** <InlineMath math="x^2 - 2x" /> zweimal auf:

<BlockMath math="\left(x^2 - 2x\right)^2 - 2\left(x^2 - 2x\right) - 3 = 0" />

# Gesucht

Gesucht ist die Lösungsmenge <InlineMath math="\mathbb{L}" /> aller reellen Zahlen <InlineMath math="x" />, die diese Gleichung erfüllen.

# Lösung

Wer alles ausmultipliziert, landet bei einem langen Polynom vierten Grades. Dabei wirkt der gesamte Ausdruck <InlineMath math="x^2 - 2x" /> wie **ein geschlossenes Paket**, das zweimal vorkommt. Gib diesem Paket einfach einen eigenen Buchstaben <InlineMath math="u" />.

> Taucht ein Teilterm komplett mehrfach auf, fasse ihn per Substitution zusammen, damit eine Gleichung vierten Grades in einfache quadratische Gleichungen zerfällt.

## Den wiederholten Block ersetzen

Setze <InlineMath math="u = x^2 - 2x" />. Die lange Gleichung schrumpft sofort zu einer **einfachen quadratischen Gleichung in <InlineMath math="u" />**:

<BlockMath math="u^2 - 2u - 3 = 0 \quad \Longleftrightarrow \quad (u - 3)(u + 1) = 0" />

Damit ergeben sich die beiden Zielwerte <InlineMath math="u = 3" /> und <InlineMath math="u = -1" />.

## Prüfen welche Werte erreichbar sind

Verwirf negative Werte hier nicht reflexartig wie bei <InlineMath math="u = x^2" />. Quadratisches Ergänzen zeigt, dass **der kleinste mögliche Wert genau bei <InlineMath math="-1" /> liegt**:

<BlockMath math="x^2 - 2x = (x - 1)^2 - 1 \ge -1" />

Sowohl <InlineMath math="u = 3" /> als auch <InlineMath math="u = -1" /> werden erreicht.

## Rücksubstitution ausführen

Löse nun **beide quadratischen Gleichungen in <InlineMath math="x" />** getrennt:

<BlockMath math="\begin{aligned}
x^2 - 2x = 3 &\quad \Longleftrightarrow \quad (x - 3)(x + 1) = 0 \quad \Longleftrightarrow \quad x = 3 \ \text{oder} \ x = -1 \\
x^2 - 2x = -1 &\quad \Longleftrightarrow \quad (x - 1)^2 = 0 \quad \Longleftrightarrow \quad x = 1
\end{aligned}" />

Die Probe für <InlineMath math="x = 1" /> in der Ausgangsgleichung geht glatt auf:

<BlockMath math="(1 - 2)^2 - 2(1 - 2) - 3 = 1 + 2 - 3 = 0" />

Alle drei Werte lösen die Gleichung vollständig.

## Falsche Antworten prüfen

Jede falsche Auswahl **verliert einen Zweig oder dreht ein Vorzeichen um**:

| Auswahl | Warum falsch |
| --- | --- |
| <InlineMath math="\mathbb{L} = \{-1,\, 3\}" /> | Streicht <InlineMath math="u = -1" />, als dürfe <InlineMath math="u" /> nicht negativ sein, und verliert <InlineMath math="x = 1" />. |
| <InlineMath math="\mathbb{L} = \{1\}" /> | Löst nur den Scheitelzweig <InlineMath math="u = -1" /> und lässt <InlineMath math="u = 3" /> weg. |
| <InlineMath math="\mathbb{L} = \{-3,\, -1,\, 1\}" /> | Dreht das mittlere Vorzeichen um und rechnet mit <InlineMath math="x^2 + 2x" /> statt <InlineMath math="x^2 - 2x" />. |
| <InlineMath math="\mathbb{L} = \{1 - \sqrt{2},\, 1 + \sqrt{2}\}" /> | Faktorisiert die <InlineMath math="u" />-Gleichung falsch als <InlineMath math="(u + 3)(u - 1) = 0" />. |
| <InlineMath math="\mathbb{L} = \{1,\, 3\}" /> | Streicht die gültige negative Lösung <InlineMath math="x = -1" />. |

# Antwort

Die Lösungsmenge lautet **<InlineMath math="\mathbb{L} = \{-1,\, 1,\, 3\}" />**.
