# Given

Two **conjugate numbers** are given:

<BlockMath math="a = \sqrt{3} + 1 \qquad \text{and} \qquad b = \sqrt{3} - 1" />

We need to evaluate the negative-exponent expression (*Term*):

<BlockMath math="\frac{a^{-1} + b^{-1}}{a^{-2} - b^{-2}}" />

# Asked

What is the exact value of this expression?

# Solution

Plugging <InlineMath math="\sqrt{3} + 1" /> straight into negative powers turns a tidy puzzle into messy fractions. Think of it like unpacking nested boxes: **simplify the algebraic wrapper first** before touching the square roots.

> Always simplify the algebraic structure before substituting roots, because messy factors often cancel cleanly.

## Factoring the difference of squares

Set <InlineMath math="u = a^{-1}" /> and <InlineMath math="v = b^{-1}" /> so the pattern jumps out. The denominator is a difference of two squares, so **the sum factor cancels immediately**:

<BlockMath math="\frac{u + v}{u^2 - v^2} = \frac{u + v}{(u - v)(u + v)} = \frac{1}{u - v}" />

Now substitute <InlineMath math="u" /> and <InlineMath math="v" /> back in terms of <InlineMath math="a" /> and <InlineMath math="b" /> and combine the fractions:

<BlockMath math="\frac{1}{\frac{1}{a} - \frac{1}{b}} = \frac{1}{\frac{b - a}{ab}} = \frac{ab}{b - a}" />

## Computing the product and difference

Now you only need the **product and ordered difference** of the conjugate pair:

<BlockMath math="\begin{aligned}
ab &= (\sqrt{3} + 1)(\sqrt{3} - 1) = 3 - 1 = 2 \\
b - a &= (\sqrt{3} - 1) - (\sqrt{3} + 1) = -2
\end{aligned}" />

Since <InlineMath math="b" /> sits to the left of <InlineMath math="a" />, the denominator <InlineMath math="b - a" /> carries a minus sign. Substitute both values into the compact formula:

<BlockMath math="\frac{ab}{b - a} = \frac{2}{-2} = -1" />

Quick decimal check: <InlineMath math="a^{-1} \approx 0.366" /> and <InlineMath math="b^{-1} \approx 1.366" />. The numerator is about <InlineMath math="1.732" /> and the denominator is about <InlineMath math="0.134 - 1.866 = -1.732" />, giving exactly <InlineMath math="-1" />.

## Checking the distractors

Notice how each wrong option comes from **one slipped sign or dropped factor**:

| Option | Why it is wrong |
| --- | --- |
| <InlineMath math="1" /> | Reverses the difference into <InlineMath math="a - b" />, losing the minus sign. |
| <InlineMath math="-2" /> | Computes <InlineMath math="ab = 4" /> as if <InlineMath math="(\sqrt{3} + 1)(\sqrt{3} - 1) = 3 + 1" />. |
| <InlineMath math="-\frac{1}{2}" /> | Drops <InlineMath math="ab" /> from the numerator and evaluates only <InlineMath math="\frac{1}{b - a}" />. |
| <InlineMath math="2" /> | Evaluates only the product <InlineMath math="ab" /> without dividing by <InlineMath math="b - a" />. |
| <InlineMath math="\frac{1}{2}" /> | Takes only the reciprocal of the product, <InlineMath math="\frac{1}{ab}" />. |

# Answer

The exact value of the expression is **<InlineMath math="-1" />**.
