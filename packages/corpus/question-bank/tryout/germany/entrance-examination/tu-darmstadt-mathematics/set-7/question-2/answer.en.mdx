# Given

This fourth-degree equation contains the **repeated block** <InlineMath math="x^2 - 2x" /> twice:

<BlockMath math="\left(x^2 - 2x\right)^2 - 2\left(x^2 - 2x\right) - 3 = 0" />

# Asked

Find the solution set (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> of all real numbers <InlineMath math="x" /> satisfying this equation.

# Solution

Expanding everything would leave a clunky fourth-degree polynomial. Instead, notice that the entire expression <InlineMath math="x^2 - 2x" /> behaves like **one sealed package** used twice. Give that package a single letter <InlineMath math="u" />.

> When one expression repeats as a whole block, wrap it in a substitution variable so a quartic splits into ordinary quadratics.

## Replacing the repeated block

Let <InlineMath math="u = x^2 - 2x" />. The long equation collapses into a **simple quadratic in <InlineMath math="u" />**:

<BlockMath math="u^2 - 2u - 3 = 0 \quad \Longleftrightarrow \quad (u - 3)(u + 1) = 0" />

This gives two target values for <InlineMath math="u" />: <InlineMath math="u = 3" /> and <InlineMath math="u = -1" />.

## Checking which values are reachable

Do not automatically discard negative <InlineMath math="u" /> as you would for <InlineMath math="u = x^2" />. Completing the square shows **the minimum value of <InlineMath math="u" /> is <InlineMath math="-1" />**:

<BlockMath math="x^2 - 2x = (x - 1)^2 - 1 \ge -1" />

Both <InlineMath math="u = 3" /> and <InlineMath math="u = -1" /> are reachable.

## Solving back for the original variable

Solve **both quadratic equations in <InlineMath math="x" />** separately:

<BlockMath math="\begin{aligned}
x^2 - 2x = 3 &\quad \Longleftrightarrow \quad (x - 3)(x + 1) = 0 \quad \Longleftrightarrow \quad x = 3 \ \text{or} \ x = -1 \\
x^2 - 2x = -1 &\quad \Longleftrightarrow \quad (x - 1)^2 = 0 \quad \Longleftrightarrow \quad x = 1
\end{aligned}" />

Check <InlineMath math="x = 1" /> directly in the original equation:

<BlockMath math="(1 - 2)^2 - 2(1 - 2) - 3 = 1 + 2 - 3 = 0" />

All three values satisfy the original equation exactly.

## Checking the distractors

See how each wrong answer **drops one branch or flips a sign**:

| Option | Why it is wrong |
| --- | --- |
| <InlineMath math="\mathbb{L} = \{-1,\, 3\}" /> | Rejects <InlineMath math="u = -1" /> as if <InlineMath math="u" /> could not be negative, missing <InlineMath math="x = 1" />. |
| <InlineMath math="\mathbb{L} = \{1\}" /> | Solves only the vertex branch <InlineMath math="u = -1" /> and omits <InlineMath math="u = 3" />. |
| <InlineMath math="\mathbb{L} = \{-3,\, -1,\, 1\}" /> | Flips the middle sign and solves <InlineMath math="x^2 + 2x" /> instead of <InlineMath math="x^2 - 2x" />. |
| <InlineMath math="\mathbb{L} = \{1 - \sqrt{2},\, 1 + \sqrt{2}\}" /> | Mis-factors the <InlineMath math="u" /> quadratic as <InlineMath math="(u + 3)(u - 1) = 0" />. |
| <InlineMath math="\mathbb{L} = \{1,\, 3\}" /> | Drops the valid negative solution <InlineMath math="x = -1" />. |

# Answer

The solution set is **<InlineMath math="\mathbb{L} = \{-1,\, 1,\, 3\}" />**.
