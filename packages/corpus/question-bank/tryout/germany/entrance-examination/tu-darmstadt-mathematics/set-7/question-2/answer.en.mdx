# Replace the repeated expression

The expression <InlineMath math="x^2-2x" /> appears twice. Set <InlineMath math="u=x^2-2x" />. Then the equation becomes **quadratic in <InlineMath math="u" />**:

<BlockMath math="u^2-2u-3=0\quad\Longleftrightarrow\quad (u-3)(u+1)=0\quad\Longleftrightarrow\quad u=3\ \text{or}\ u=-1" />

# Which values <InlineMath math="u" /> can take

# Solve for <InlineMath math="x" /> for both values

Each value of <InlineMath math="u" /> gives **its own quadratic equation in <InlineMath math="x" />**:

<BlockMath math="\begin{aligned}
x^2-2x=3&\quad\Longleftrightarrow\quad (x-3)(x+1)=0\quad\Longleftrightarrow\quad x=3\ \text{or}\ x=-1 \\
x^2-2x=-1&\quad\Longleftrightarrow\quad (x-1)^2=0\quad\Longleftrightarrow\quad x=1
\end{aligned}" />

Check <InlineMath math="x=1" />: <InlineMath math="(1-2)^2-2\cdot(1-2)-3=1+2-3=0" />. The solution set is **<InlineMath math="\mathbb{L}=\{-1;\,1;\,3\}" />**.

# Why the other answers are wrong

- <InlineMath math="\{-1;\,3\}" /> discards <InlineMath math="u=-1" />, as if <InlineMath math="u" /> couldn't be negative. That way **the solution <InlineMath math="x=1" /> is lost**. By coincidence these two numbers also match the <InlineMath math="u" />-values.
- <InlineMath math="\{1\}" /> works out only the case <InlineMath math="u=-1" />.
- <InlineMath math="\{-3;\,-1;\,1\}" /> solves with <InlineMath math="x^2+2x" /> instead of <InlineMath math="x^2-2x" />, a sign slip.
- <InlineMath math="\{1-\sqrt2;\,1+\sqrt2\}" /> comes from the wrong values <InlineMath math="u=1" /> and <InlineMath math="u=-3" /> from <InlineMath math="(u+3)(u-1)" />. Then only <InlineMath math="x^2-2x=1" /> gives solutions.
- <InlineMath math="\{1;\,3\}" /> leaves out the negative number <InlineMath math="x=-1" />.
