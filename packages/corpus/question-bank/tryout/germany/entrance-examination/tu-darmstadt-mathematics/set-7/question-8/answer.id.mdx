# Diketahui

Diberikan **pertidaksamaan logaritma** (*Ungleichung*) dengan basis pecahan kurang dari satu:

<BlockMath math="\log_{\frac{1}{2}}\left(x^2 - 3x\right) \ge -2" />

# Ditanyakan

Tentukan semua bilangan real <InlineMath math="x" /> yang memenuhi pertidaksamaan ini.

# Penyelesaian

Pertidaksamaan logaritma dengan basis <InlineMath math="\frac{1}{2}" /> selalu punya **dua penjaga pintu** yang harus lolos bersamaan. Penjaga pertama memastikan isi logaritma bernilai positif agar nilainya benar-benar ada. Penjaga kedua mengingatkan bahwa basis antara <InlineMath math="0" /> dan <InlineMath math="1" /> berjalan terbalik: makin besar isinya, makin kecil logaritmanya, jadi tanda pertidaksamaan wajib berbalik arah.

> Pada logaritma berbasis kurang dari satu, selalu periksa daerah asal positif lebih dulu dan balikkan tanda pertidaksamaan saat melepas logaritma.

## Menentukan daerah asal positif

Logaritma hanya terdefinisi jika **numerusnya bernilai positif ketat**:

<BlockMath math="x^2 - 3x = x(x - 3) > 0 \quad \Longleftrightarrow \quad x < 0 \ \text{atau} \ x > 3" />

Semua bilangan dari <InlineMath math="0" /> sampai <InlineMath math="3" />, termasuk ujung <InlineMath math="0" /> dan <InlineMath math="3" />, langsung gugur sebagai penyelesaian.

## Membalik tanda pertidaksamaan karena basis pecahan

Ubah ruas kanan menjadi logaritma berbasis sama, karena pangkat negatif membalik pecahan:

<BlockMath math="\left(\frac{1}{2}\right)^{-2} = 4 \quad \Longrightarrow \quad -2 = \log_{\frac{1}{2}} 4" />

Sebab fungsi logaritma berbasis <InlineMath math="\frac{1}{2}" /> **turun tegas**, melepas logaritma membalik arah tanda:

<BlockMath math="\begin{aligned}
\log_{\frac{1}{2}}\left(x^2 - 3x\right) &\ge \log_{\frac{1}{2}} 4 \\
x^2 - 3x &\le 4 \\
(x - 4)(x + 1) &\le 0 \quad \Longleftrightarrow \quad -1 \le x \le 4
\end{aligned}" />

## Mengiriskan kedua syarat

Sekarang gabungkan selang batas dari <InlineMath math="-1" /> sampai <InlineMath math="4" /> dengan **syarat daerah asal di luar selang nol sampai tiga**:

<BlockMath math="-1 \le x < 0 \qquad \text{atau} \qquad 3 < x \le 4" />

## Mengecek pilihan salah

Perhatikan bagaimana setiap pengecoh **gagal di salah satu penjaga pintu**:

| Pilihan | Mengapa salah |
| --- | --- |
| <InlineMath math="-1 \le x \le 4" /> | Melupakan syarat daerah asal, misalnya untuk <InlineMath math="x = 1" /> numerusnya <InlineMath math="-2" />. |
| <InlineMath math="x \le -1" /> atau <InlineMath math="x \ge 4" /> | Tidak membalik tanda pertidaksamaan saat melepas logaritma berbasis <InlineMath math="\frac{1}{2}" />. |
| <InlineMath math="x < 0" /> atau <InlineMath math="x > 3" /> | Baru menuliskan syarat daerah asal tanpa menyelesaikan batas <InlineMath math="-2" />. |
| <InlineMath math="-1 < x < 0" /> atau <InlineMath math="3 < x < 4" /> | Membuang ujung <InlineMath math="-1" /> dan <InlineMath math="4" /> padahal tanda <InlineMath math="\ge" /> mengizinkan kesamaan. |
| <InlineMath math="-1 \le x \le 0" /> atau <InlineMath math="3 \le x \le 4" /> | Memasukkan <InlineMath math="0" /> dan <InlineMath math="3" />, tempat numerus bernilai nol dan logaritma tak terdefinisi. |
