# Gegeben

Die **quadratische Funktion** mit reellem Parameter <InlineMath math="a" /> wird auf dem abgeschlossenen Intervall <InlineMath math="0 \le x \le 3" /> betrachtet.

<BlockMath math="f(x) = x^2 - 2ax + 6" />

Ihr kleinster Funktionswert auf dem Intervall <InlineMath math="0 \le x \le 3" /> beträgt genau <InlineMath math="2" />.

# Gesucht

Der reelle Wert des Parameters <InlineMath math="a" />.

# Lösung

Stell dir ein parabelförmiges Tal vor, das hinter einem schmalen Fenster von <InlineMath math="x = 0" /> bis <InlineMath math="x = 3" /> nach links oder rechts gleitet. Der tiefste sichtbare Punkt im Fenster ist entweder **der Talboden selbst, falls er im Fenster liegt, oder einer der beiden Fensterränder, falls der Scheitel draußen liegt**.

> Das Minimum einer nach oben geöffneten Parabel auf einem abgeschlossenen Intervall liegt im Scheitelpunkt innerhalb des Intervalls oder am näheren Rand, und jeder Kandidat muss seine eigene Fallbedingung erfüllen.

Forme durch quadratische Ergänzung um und lies den Scheitel bei <InlineMath math="x = a" /> ab.

<BlockMath math="f(x) = (x - a)^2 + 6 - a^2" />

## Alle drei Lagen des Scheitelpunkts prüfen

Untersuch **alle drei Bereiche für <InlineMath math="a" />** relativ zum Intervall <InlineMath math="0 \le x \le 3" />.

<BlockMath math="\begin{aligned}
0 \le a \le 3 &: \quad \min = f(a) = 6 - a^2 = 2 \implies a = 2 \quad (a = -2 \text{ außerhalb dieses Falls}) \\
a > 3 &: \quad \min = f(3) = 15 - 6a = 2 \implies a = \frac{13}{6} \quad (\text{entfällt wegen } \tfrac{13}{6} < 3) \\
a < 0 &: \quad \min = f(0) = 6 \neq 2
\end{aligned}" />

Nur <InlineMath math="a = 2" /> passt zu seiner eigenen Fallbedingung. Vergleich im Graphen die richtige Parabel <InlineMath math="a = 2" /> mit der Randfalle <InlineMath math="\frac{13}{6}" />.

## Probe und falsche Antworten prüfen

Direkte Probe für <InlineMath math="a = 2" />: Die Funktion lautet **in Scheitelpunktform <InlineMath math="(x - 2)^2 + 2" />** und nimmt im Intervall bei <InlineMath math="x = 2" /> exakt den Kleinstwert <InlineMath math="2" /> an.

| Antwort | Warum sie falsch ist |
| :--- | :--- |
| <InlineMath math="a = -2" /> oder <InlineMath math="a = 2" /> | Nimmt beide Lösungen von <InlineMath math="6 - a^2 = 2" />, obwohl <InlineMath math="a = -2" /> außerhalb des Intervalls liegt. |
| <InlineMath math="a = \frac{13}{6}" /> | Prüft nur <InlineMath math="f(3) = 2" />, obwohl der Scheitel im Intervall auf <InlineMath math="\frac{47}{36} < 2" /> fällt. |
| <InlineMath math="a = 2" /> oder <InlineMath math="a = \frac{13}{6}" /> | Behält den Randkandidaten, obwohl <InlineMath math="\frac{13}{6}" /> die Bedingung <InlineMath math="a > 3" /> verletzt. |
| <InlineMath math="a = -2" /> | Legt den Scheitel außerhalb des Intervalls, sodass das Minimum dort <InlineMath math="f(0) = 6" /> ist. |
| <InlineMath math="a = 2\sqrt{2}" /> | Berechnet die Scheitelhöhe fälschlich als <InlineMath math="6 - \frac{a^2}{2}" /> statt <InlineMath math="6 - a^2" />. |

# Antwort

Der gesuchte Wert ist **<InlineMath math="a = 2" />**.
