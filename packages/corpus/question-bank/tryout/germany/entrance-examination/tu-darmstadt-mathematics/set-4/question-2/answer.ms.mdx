# Diberi

**Persamaan punca kuasa dua** (*Wurzelgleichung*) dalam set nombor nyata diberi seperti berikut.

<BlockMath math="\sqrt{3x + 1} - \sqrt{x - 1} = 2" />

# Ditanya

Tentukan set penyelesaian (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> dalam nombor nyata.

# Penyelesaian

Membahagi kedua-dua belah persamaan dengan sebutan yang boleh bernilai sifar ibarat mengunci pintu tanpa menyemak sama ada tetamu sah masih berada di luar. Kedua-dua punca tertakrif untuk <InlineMath math="x \ge 1" />, dan **pemfaktoran jauh lebih selamat daripada membahagi dengan punca** supaya <InlineMath math="x = 1" /> tidak hilang.

> Jangan sesekali bahagi persamaan dengan faktor yang boleh menjadi sifar, dan sentiasa semak semua calon dalam persamaan asal kerana pengkuasaduaan boleh menghasilkan punca palsu.

Pindahkan satu punca ke sebelah kanan sebelum mengkuasaduakan supaya hanya tinggal satu punca kuasa dua.

<BlockMath math="\begin{aligned}
\sqrt{3x + 1} &= 2 + \sqrt{x - 1} \\
3x + 1 &= 4 + 4\sqrt{x - 1} + x - 1 \\
2x - 2 &= 4\sqrt{x - 1} \\
x - 1 &= 2\sqrt{x - 1}
\end{aligned}" />

## Memfaktorkan tanpa kehilangan punca

Gantikan <InlineMath math="\sqrt{x - 1}" /> dengan <InlineMath math="u \ge 0" /> supaya <InlineMath math="x - 1" /> sama dengan <InlineMath math="u^2" /> dan **kedua-dua penyelesaian muncul dengan jelas**.

<BlockMath math="u^2 = 2u \iff u(u - 2) = 0 \iff u = 0 \text{ atau } u = 2" />

Nilai <InlineMath math="u = 0" /> memberi <InlineMath math="x = 1" />, manakala <InlineMath math="u = 2" /> memberi <InlineMath math="x - 1 = 4" /> iaitu <InlineMath math="x = 5" />. Semak kedua-dua nilai dalam persamaan asal.

<BlockMath math="\begin{aligned}
x = 1 &\implies \sqrt{4} - \sqrt{0} = 2 \\
x = 5 &\implies \sqrt{16} - \sqrt{4} = 4 - 2 = 2
\end{aligned}" />

## Menyemak pilihan salah

Perhatikan bagaimana setiap pilihan salah lahir daripada **perangkap algebra klasik bagi persamaan punca**.

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="\mathbb{L} = \{5\}" /> | Membahagi kedua-dua belah dengan <InlineMath math="\sqrt{x - 1}" /> sehingga punca <InlineMath math="x = 1" /> hilang. |
| <InlineMath math="\mathbb{L} = \{1\}" /> | Mengkuasaduakan sebutan demi sebutan dan melupakan sebutan tengah dua kali hasil darab. |
| <InlineMath math="\mathbb{L} = \{1,\, 3\}" /> | Terlupa mengkuasaduakan faktor <InlineMath math="2" /> di hadapan punca sehingga mengekalkan <InlineMath math="2" /> bukannya <InlineMath math="4" />. |
| <InlineMath math="\mathbb{L} = \{3 + 2\sqrt{3}\}" /> | Berpunca daripada kesilapan tanda semasa kembangan menjadi <InlineMath math="4x + 4" />. |
| <InlineMath math="\mathbb{L} = \{\}" /> | Terlepas pandang bahawa kedua-dua calon lulus semakan. |

# Jawapan

Set penyelesaian bagi persamaan ini ialah **<InlineMath math="\mathbb{L} = \{1,\, 5\}" />**.
