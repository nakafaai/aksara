# Diketahui

**Fungsi kuadrat** (*quadratische Funktion*) dengan parameter real <InlineMath math="a" /> diamati pada selang tertutup <InlineMath math="0 \le x \le 3" />.

<BlockMath math="f(x) = x^2 - 2ax + 6" />

Nilai terkecil (*kleinster Funktionswert*) fungsi ini pada selang <InlineMath math="0 \le x \le 3" /> tepat sama dengan <InlineMath math="2" />.

# Ditanyakan

Tentukan nilai parameter real <InlineMath math="a" />.

# Penyelesaian

Bayangkan sebuah lembah berbentuk parabola yang bergeser ke kiri atau kanan di balik jendela sempit dari <InlineMath math="x = 0" /> sampai <InlineMath math="x = 3" />. Titik terendah yang tampak dari jendela hanyalah salah satu dari dua tempat: **dasar lembah itu sendiri jika berada di dalam jendela, atau salah satu tepi jendela jika dasar lembah ada di luar**.

> Minimum fungsi kuadrat terbuka ke atas pada selang tertutup selalu berada di puncak jika puncak masuk selang, atau di ujung selang terdekat jika puncak di luar, dan setiap calon wajib dicocokkan ulang dengan syarat kasusnya.

Lengkapi kuadrat untuk membaca puncak parabola di <InlineMath math="x = a" />.

<BlockMath math="f(x) = (x - a)^2 + 6 - a^2" />

## Menguji ketiga letak puncak parabola

Periksa **tiga kemungkinan posisi <InlineMath math="a" />** terhadap selang <InlineMath math="0 \le x \le 3" />.

<BlockMath math="\begin{aligned}
0 \le a \le 3 &: \quad \min = f(a) = 6 - a^2 = 2 \implies a = 2 \quad (a = -2 \text{ di luar kasus}) \\
a > 3 &: \quad \min = f(3) = 15 - 6a = 2 \implies a = \frac{13}{6} \quad (\text{gugur karena } \tfrac{13}{6} < 3) \\
a < 0 &: \quad \min = f(0) = 6 \neq 2
\end{aligned}" />

Hanya <InlineMath math="a = 2" /> yang konsisten dengan syarat kasusnya sendiri. Bandingkan kurva <InlineMath math="a = 2" /> dengan jebakan ujung kanan <InlineMath math="\frac{13}{6}" /> pada grafik berikut.

## Menguji solusi dan pilihan salah

Cek langsung untuk <InlineMath math="a = 2" />: fungsi menjadi **bentuk kuadrat lengkap <InlineMath math="(x - 2)^2 + 2" />**, yang mencapai minimum tepat <InlineMath math="2" /> di <InlineMath math="x = 2" /> di dalam selang.

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="a = -2" /> atau <InlineMath math="a = 2" /> | Mengambil kedua akar <InlineMath math="6 - a^2 = 2" /> tanpa mengecek bahwa puncak <InlineMath math="a = -2" /> ada di luar selang. |
| <InlineMath math="a = \frac{13}{6}" /> | Hanya mengecek ujung kanan <InlineMath math="f(3) = 2" />, padahal puncaknya turun sampai <InlineMath math="\frac{47}{36} < 2" />. |
| <InlineMath math="a = 2" /> atau <InlineMath math="a = \frac{13}{6}" /> | Lupa menolak <InlineMath math="\frac{13}{6}" /> yang melanggar syarat kasus <InlineMath math="a > 3" />. |
| <InlineMath math="a = -2" /> | Puncaknya di luar selang sehingga minimum pada selang justru <InlineMath math="f(0) = 6" />. |
| <InlineMath math="a = 2\sqrt{2}" /> | Keliru menghitung tinggi puncak sebagai <InlineMath math="6 - \frac{a^2}{2}" />, bukan <InlineMath math="6 - a^2" />. |
