# Diberi

**Fungsi kuadratik** (*quadratische Funktion*) dengan parameter nyata <InlineMath math="a" /> diperhatikan pada selang tertutup <InlineMath math="0 \le x \le 3" />.

<BlockMath math="f(x) = x^2 - 2ax + 6" />

Nilai terkecil (*kleinster Funktionswert*) fungsi ini pada selang <InlineMath math="0 \le x \le 3" /> tepat sama dengan <InlineMath math="2" />.

# Ditanya

Tentukan nilai parameter nyata <InlineMath math="a" />.

# Penyelesaian

Bayangkan sebuah lembah berbentuk parabola yang bergerak ke kiri atau kanan di belakang tingkap sempit dari <InlineMath math="x = 0" /> hingga <InlineMath math="x = 3" />. Titik terendah yang kelihatan melalui tingkap hanya boleh berada di satu daripada dua tempat: **dasar lembah itu sendiri jika berada di dalam tingkap, atau salah satu pinggir tingkap jika dasar lembah berada di luar**.

> Minimum bagi parabola terbuka ke atas pada selang tertutup sentiasa terletak di puncak apabila puncak berada dalam selang, atau di hujung selang terdekat apabila puncak di luar, dan setiap calon mesti disemak semula dengan syarat kesnya.

Lengkapkan kuasa dua untuk membaca puncak parabola pada <InlineMath math="x = a" />.

<BlockMath math="f(x) = (x - a)^2 + 6 - a^2" />

## Menguji ketiga kedudukan puncak parabola

Semak **tiga kemungkinan kedudukan <InlineMath math="a" />** berbanding selang <InlineMath math="0 \le x \le 3" />.

<BlockMath math="\begin{aligned}
0 \le a \le 3 &: \quad \min = f(a) = 6 - a^2 = 2 \implies a = 2 \quad (a = -2 \text{ di luar kes}) \\
a > 3 &: \quad \min = f(3) = 15 - 6a = 2 \implies a = \frac{13}{6} \quad (\text{ditolak kerana } \tfrac{13}{6} < 3) \\
a < 0 &: \quad \min = f(0) = 6 \neq 2
\end{aligned}" />

Hanya <InlineMath math="a = 2" /> tekal dengan syarat kesnya sendiri. Bandingkan lengkung sah <InlineMath math="a = 2" /> dengan perangkap hujung kanan <InlineMath math="\frac{13}{6}" /> pada graf berikut.

## Menyemak jawapan dan pilihan salah

Semakan terus bagi <InlineMath math="a = 2" />: fungsi menjadi **bentuk penyempurnaan kuasa dua <InlineMath math="(x - 2)^2 + 2" />**, yang mencapai minimum tepat <InlineMath math="2" /> di <InlineMath math="x = 2" />.

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="a = -2" /> atau <InlineMath math="a = 2" /> | Mengambil kedua-dua punca <InlineMath math="6 - a^2 = 2" /> tanpa menyemak bahawa puncak <InlineMath math="a = -2" /> berada di luar selang. |
| <InlineMath math="a = \frac{13}{6}" /> | Hanya menyemak <InlineMath math="f(3) = 2" />, padahal puncaknya jatuh ke <InlineMath math="\frac{47}{36} < 2" />. |
| <InlineMath math="a = 2" /> atau <InlineMath math="a = \frac{13}{6}" /> | Terlupa menolak <InlineMath math="\frac{13}{6}" /> yang melanggar syarat <InlineMath math="a > 3" />. |
| <InlineMath math="a = -2" /> | Puncaknya di luar selang sehingga minimum sebenar ialah <InlineMath math="f(0) = 6" />. |
| <InlineMath math="a = 2\sqrt{2}" /> | Tersilap mengira tinggi puncak sebagai <InlineMath math="6 - \frac{a^2}{2}" />, bukannya <InlineMath math="6 - a^2" />. |

# Jawapan

Nilai parameter yang memenuhi syarat ialah **<InlineMath math="a = 2" />**.
