# Given

We are given a **radical equation** (*Wurzelgleichung*) over the real numbers.

<BlockMath math="\sqrt{3x + 1} - \sqrt{x - 1} = 2" />

# Asked

Find the real solution set (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> of this equation.

# Solution

Dividing both sides of an equation by an expression that can equal zero is like locking the door without checking whether a valid ticket holder is standing outside. Both roots require <InlineMath math="x \ge 1" />, and **factoring is far safer than dividing by a radical** so that <InlineMath math="x = 1" /> is never lost.

> Never divide an equation by a factor that can vanish, and always check every candidate back in the original radical equation because squaring can create extraneous roots.

Isolate one square root on each side before squaring so only a single radical remains.

<BlockMath math="\begin{aligned}
\sqrt{3x + 1} &= 2 + \sqrt{x - 1} \\
3x + 1 &= 4 + 4\sqrt{x - 1} + x - 1 \\
2x - 2 &= 4\sqrt{x - 1} \\
x - 1 &= 2\sqrt{x - 1}
\end{aligned}" />

## Factoring without losing a root

Replace <InlineMath math="\sqrt{x - 1}" /> with <InlineMath math="u \ge 0" /> so that <InlineMath math="x - 1" /> equals <InlineMath math="u^2" /> and **both solutions appear side by side**.

<BlockMath math="u^2 = 2u \iff u(u - 2) = 0 \iff u = 0 \text{ or } u = 2" />

Here <InlineMath math="u = 0" /> yields <InlineMath math="x = 1" />, while <InlineMath math="u = 2" /> gives <InlineMath math="x - 1 = 4" />, so <InlineMath math="x = 5" />. Check both values directly in the original equation.

<BlockMath math="\begin{aligned}
x = 1 &\implies \sqrt{4} - \sqrt{0} = 2 \\
x = 5 &\implies \sqrt{16} - \sqrt{4} = 4 - 2 = 2
\end{aligned}" />

Watch the graph of the left side dip slightly after <InlineMath math="x = 1" /> and climb back through height <InlineMath math="2" />.

## Checking wrong choices

Notice how each distractor comes from **a classic algebraic trap in radical equations**.

| Option | Why it is wrong |
| :--- | :--- |
| <InlineMath math="\mathbb{L} = \{5\}" /> | Divides both sides by <InlineMath math="\sqrt{x - 1}" />, erasing the valid solution <InlineMath math="x = 1" />. |
| <InlineMath math="\mathbb{L} = \{1\}" /> | Squares the left side term by term and forgets the cross-term of twice the product. |
| <InlineMath math="\mathbb{L} = \{1,\, 3\}" /> | Forgets to square the factor <InlineMath math="2" /> in front of the root, keeping <InlineMath math="2" /> instead of <InlineMath math="4" />. |
| <InlineMath math="\mathbb{L} = \{3 + 2\sqrt{3}\}" /> | Comes from a sign slip that turns the right side into <InlineMath math="4x + 4" />. |
| <InlineMath math="\mathbb{L} = \{\}" /> | Misses that both candidates verify cleanly in the original equation. |

# Answer

The solution set is **<InlineMath math="\mathbb{L} = \{1,\, 5\}" />**.
