# Given

A **quadratic function** (*quadratische Funktion*) with real parameter <InlineMath math="a" /> is restricted to the closed interval <InlineMath math="0 \le x \le 3" />.

<BlockMath math="f(x) = x^2 - 2ax + 6" />

Its smallest value (*kleinster Funktionswert*) on <InlineMath math="0 \le x \le 3" /> equals <InlineMath math="2" />.

# Asked

Find the real value of parameter <InlineMath math="a" />.

# Solution

Picture a U-shaped valley sliding left or right behind a narrow window spanning from <InlineMath math="x = 0" /> to <InlineMath math="x = 3" />. The lowest point visible through the window must be one of two places: **the bottom of the valley if it sits inside the window, or one of the window edges if the bottom lies outside**.

> The minimum of an upward-opening parabola on a closed interval lies either at its vertex when inside the interval or at the nearest endpoint when outside, and every candidate must satisfy its own case condition.

Complete the square to read the vertex directly at <InlineMath math="x = a" />.

<BlockMath math="f(x) = (x - a)^2 + 6 - a^2" />

## Testing all three vertex positions

Check **all three regions for <InlineMath math="a" />** relative to <InlineMath math="0 \le x \le 3" />.

<BlockMath math="\begin{aligned}
0 \le a \le 3 &: \quad \min = f(a) = 6 - a^2 = 2 \implies a = 2 \quad (a = -2 \text{ outside this case}) \\
a > 3 &: \quad \min = f(3) = 15 - 6a = 2 \implies a = \frac{13}{6} \quad (\text{fails since } \tfrac{13}{6} < 3) \\
a < 0 &: \quad \min = f(0) = 6 \neq 2
\end{aligned}" />

Only <InlineMath math="a = 2" /> stays consistent with its own case condition. Compare the valid curve <InlineMath math="a = 2" /> with the endpoint trap <InlineMath math="\frac{13}{6}" /> below.

The graph immediately exposes the second-case trap: for <InlineMath math="\frac{13}{6}" />, the point <InlineMath math="(3 \mid 2)" /> is not the lowest point because the vertex sits inside the window below height <InlineMath math="2" />.

## Verifying the answer and checking wrong choices

Direct check at <InlineMath math="a = 2" />: the function becomes **the completed square <InlineMath math="(x - 2)^2 + 2" />**, whose minimum on the interval is indeed <InlineMath math="2" /> at <InlineMath math="x = 2" />.

| Option | Why it is wrong |
| :--- | :--- |
| <InlineMath math="a = -2" /> or <InlineMath math="a = 2" /> | Keeps both roots of <InlineMath math="6 - a^2 = 2" /> without noticing that <InlineMath math="a = -2" /> sits outside the interval. |
| <InlineMath math="a = \frac{13}{6}" /> | Checks only <InlineMath math="f(3) = 2" />, missing that the vertex drops to <InlineMath math="\frac{47}{36} < 2" /> inside the interval. |
| <InlineMath math="a = 2" /> or <InlineMath math="a = \frac{13}{6}" /> | Fails to reject <InlineMath math="\frac{13}{6}" /> for violating its case rule <InlineMath math="a > 3" />. |
| <InlineMath math="a = -2" /> | Places the vertex outside the interval, where the actual minimum is <InlineMath math="f(0) = 6" />. |
| <InlineMath math="a = 2\sqrt{2}" /> | Miscomputes the vertex height as <InlineMath math="6 - \frac{a^2}{2}" /> instead of <InlineMath math="6 - a^2" />. |

# Answer

The required value is <InlineMath math="a = 2" />.
