# Where the minimum can be

The graph of <InlineMath math="f" /> is an upward parabola with its vertex at <InlineMath math="x=a" />, because <InlineMath math="f(x)=(x-a)^2+6-a^2" />. On the interval <InlineMath math="0\le x\le3" /> the smallest value is **either at the vertex or at an end of the interval**. Which case happens depends on where <InlineMath math="a" /> lies.

# The three cases

<BlockMath math="\begin{aligned}
0\le a\le3:&\quad \min=f(a)=6-a^2=2\ \Rightarrow\ a=2\ \ (a=-2\ \text{isn't in this case}) \\
a>3:&\quad \min=f(3)=15-6a=2\ \Rightarrow\ a=\tfrac{13}{6}\ \ (\text{but}\ \tfrac{13}{6}<3) \\
a<0:&\quad \min=f(0)=6\ne2
\end{aligned}" />

Only in the first case does the number you find **fit the assumption of the case**.

# Check

For <InlineMath math="a=2" />, <InlineMath math="f(x)=(x-2)^2+2" />. The vertex <InlineMath math="x=2" /> lies in the interval, so **the smallest value there is <InlineMath math="2" />**. So <InlineMath math="a=2" />.

# Why the other answers are wrong

- <InlineMath math="a=-2" /> or <InlineMath math="a=2" /> takes both solutions of <InlineMath math="6-a^2=2" />. For <InlineMath math="a=-2" /> the vertex is at <InlineMath math="x=-2" />, outside, and the smallest value on the interval is <InlineMath math="f(0)=6" />.
- <InlineMath math="a=\frac{13}{6}" /> checks only the right end. Since <InlineMath math="\frac{13}{6}" /> lies in the interval, the vertex value <InlineMath math="6-\frac{169}{36}=\frac{47}{36}" /> is **less than <InlineMath math="2" />**.
- <InlineMath math="a=2" /> or <InlineMath math="a=\frac{13}{6}" /> keeps the solution of the end case without checking the condition <InlineMath math="a>3" />.
- <InlineMath math="a=-2" /> alone is the value whose vertex isn't in the interval at all.
- <InlineMath math="a=2\sqrt2" /> comes from taking the vertex value as <InlineMath math="6-\frac{a^2}{2}" /> instead of <InlineMath math="6-a^2" />.
