# Diketahui

**Pertidaksamaan bentuk akar** (*Wurzelungleichung*) dalam bilangan real diberikan sebagai berikut.

<BlockMath math="\sqrt{x + 5} > x - 1" />

# Ditanyakan

Tentukan semua bilangan real <InlineMath math="x" /> yang memenuhi pertidaksamaan ini.

# Penyelesaian

Mengkuadratkan pertidaksamaan bisa menjebak saat salah satu ruas negatif: contohnya <InlineMath math="2 > -10" /> benar, tetapi begitu dikuadratkan menjadi <InlineMath math="4 > 100" /> yang salah! Karena akar tidak pernah negatif, kita wajib **memisahkan wilayah ruas kanan negatif sebagai zona menang otomatis** sebelum mengkuadratkan apa pun.

> Hanya kuadratkan pertidaksamaan jika kedua ruas sama-sama tak negatif, sedangkan pada wilayah tempat ruas kanan negatif, akar kuadrat yang terdefinisi otomatis menang tanpa perlu dikuadratkan.

Syarat daerah asal akar menuntut <InlineMath math="x + 5 \ge 0" />, artinya <InlineMath math="x \ge -5" />.

## Membagi kasus menurut tanda ruas kanan

Pada kasus pertama, ketika <InlineMath math="x" /> berada dari <InlineMath math="-5" /> sampai di bawah <InlineMath math="1" />, ruas kanan <InlineMath math="x - 1" /> bernilai negatif. Karena akar selalu tak negatif, **seluruh selang pertama otomatis memenuhi pertidaksamaan**.

Pada kasus kedua, untuk <InlineMath math="x \ge 1" />, kedua ruas tak negatif sehingga aman dikuadratkan.

<BlockMath math="\begin{aligned}
x + 5 &> (x - 1)^2 = x^2 - 2x + 1 \\
0 &> x^2 - 3x - 4 = (x - 4)(x + 1) \\
-1 &< x < 4
\end{aligned}" />

Diiriskan dengan syarat kasus kedua <InlineMath math="x \ge 1" />, tersisa selang <InlineMath math="1 \le x < 4" />. Gabungan kedua kasus menyambung tanpa celah dari <InlineMath math="-5" /> sampai di bawah <InlineMath math="4" />.

## Mengecek titik batas dan pilihan salah

Uji kedua ujungnya: di <InlineMath math="x = -5" /> berlaku <InlineMath math="0 > -6" /> (benar, jadi <InlineMath math="-5" /> ikut), sedangkan di <InlineMath math="x = 4" /> **kedua ruas sama-sama bernilai <InlineMath math="3" />** sehingga <InlineMath math="4" /> tidak ikut.

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="-1 < x < 4" /> | Langsung mengkuadratkan tanpa membagi kasus sehingga membuang selang dari <InlineMath math="-5" /> sampai <InlineMath math="-1" />. |
| <InlineMath math="1 \le x < 4" /> | Hanya menghitung kasus kedua dan melupakan zona ruas kanan negatif. |
| <InlineMath math="x < 4" /> | Lupa daerah asal <InlineMath math="x \ge -5" /> sehingga angka di bawah <InlineMath math="-5" /> ikut masuk. |
| <InlineMath math="-5 \le x \le 4" /> | Memasukkan <InlineMath math="x = 4" />, padahal pertidaksamaan bersifat tegas. |
| <InlineMath math="x > 4" /> | Membalik arah, karena di kanan <InlineMath math="4" /> garis justru berada di atas akar. |
