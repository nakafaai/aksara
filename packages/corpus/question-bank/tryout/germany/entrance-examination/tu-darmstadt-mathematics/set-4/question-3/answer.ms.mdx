# Diberi

**Ketaksamaan punca kuasa dua** (*Wurzelungleichung*) dalam set nombor nyata diberi seperti berikut.

<BlockMath math="\sqrt{x + 5} > x - 1" />

# Ditanya

Tentukan semua nombor nyata <InlineMath math="x" /> yang memenuhi ketaksamaan ini.

# Penyelesaian

Mengkuasaduakan ketaksamaan boleh memerangkap apabila sebelah kanan bernilai negatif: contohnya <InlineMath math="2 > -10" /> benar, tetapi selepas dikuasaduakan menjadi <InlineMath math="4 > 100" /> yang salah! Oleh sebab punca kuasa dua sentiasa bukan negatif, **asingkan kawasan sebelah kanan negatif sebagai zon menang automatik** sebelum mengkuasaduakan apa-apa.

> Hanya kuasaduakan ketaksamaan apabila kedua-dua belah bukan negatif, manakala apabila sebelah kanan negatif, punca yang tertakrif menang secara automatik tanpa perlu dikuasaduakan.

Syarat domain punca menuntut <InlineMath math="x + 5 \ge 0" />, iaitu <InlineMath math="x \ge -5" />.

## Membahagi kes mengikut tanda sebelah kanan

Bagi kes pertama, apabila <InlineMath math="x" /> berada dari <InlineMath math="-5" /> hingga bawah <InlineMath math="1" />, sebelah kanan <InlineMath math="x - 1" /> bernilai negatif. Oleh sebab punca bukan negatif, **keseluruhan selang pertama automatik memenuhi ketaksamaan**.

Bagi kes kedua, untuk <InlineMath math="x \ge 1" />, kedua-dua belah bukan negatif dan selamat dikuasaduakan.

<BlockMath math="\begin{aligned}
x + 5 &> (x - 1)^2 = x^2 - 2x + 1 \\
0 &> x^2 - 3x - 4 = (x - 4)(x + 1) \\
-1 &< x < 4
\end{aligned}" />

Disilangkan dengan syarat kes kedua <InlineMath math="x \ge 1" />, tinggal selang <InlineMath math="1 \le x < 4" />. Gabungan kedua-dua kes bersambung rapat dari <InlineMath math="-5" /> hingga bawah <InlineMath math="4" />.

## Menyemak hujung selang dan pilihan salah

Uji kedua-dua titik hujung: pada <InlineMath math="x = -5" /> diperoleh <InlineMath math="0 > -6" /> (benar, jadi <InlineMath math="-5" /> termasuk), manakala pada <InlineMath math="x = 4" /> **kedua-dua belah sama bernilai <InlineMath math="3" />**, maka <InlineMath math="4" /> dikecualikan.

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="-1 < x < 4" /> | Terus mengkuasaduakan tanpa membagi kes sehingga tercicir nilai dari <InlineMath math="-5" /> hingga <InlineMath math="-1" />. |
| <InlineMath math="1 \le x < 4" /> | Hanya mengambil kes kedua dan melupakan zon sebelah kanan negatif. |
| <InlineMath math="x < 4" /> | Terlupa domain <InlineMath math="x \ge -5" /> sehingga nilai tidak tertakrif termasuk. |
| <InlineMath math="-5 \le x \le 4" /> | Memasukkan <InlineMath math="x = 4" />, sedangkan ketaksamaan bersifat ketat. |
| <InlineMath math="x > 4" /> | Menterbalikkan arah kerana di kanan <InlineMath math="4" /> garis mengatasi punca. |

# Jawapan

Ketaksamaan ini dipenuhi oleh semua nombor nyata dalam selang berikut.
