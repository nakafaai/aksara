# Given

We are given a **radical inequality** (*Wurzelungleichung*) over the real numbers.

<BlockMath math="\sqrt{x + 5} > x - 1" />

# Asked

Find all real numbers <InlineMath math="x" /> that satisfy this inequality.

# Solution

Squaring an inequality can backfire whenever one side is negative: for instance, <InlineMath math="2 > -10" /> is true, yet squaring flips it to <InlineMath math="4 > 100" />, which is false! Because a square root is never negative, **claim the negative right-hand zone as an automatic win first** before squaring anything.

> Only square an inequality when both sides are non-negative, whereas wherever the right side is negative a defined square root wins automatically without squaring.

The square root requires <InlineMath math="x + 5 \ge 0" />, so the domain is <InlineMath math="x \ge -5" />.

## Splitting cases by the sign of the right side

In the first case, whenever <InlineMath math="x" /> runs from <InlineMath math="-5" /> up to just below <InlineMath math="1" />, the right side <InlineMath math="x - 1" /> is negative. Since the left side is non-negative, **that entire first stretch automatically solves the inequality**.

In the second case, for <InlineMath math="x \ge 1" />, both sides are non-negative and safe to square.

<BlockMath math="\begin{aligned}
x + 5 &> (x - 1)^2 = x^2 - 2x + 1 \\
0 &> x^2 - 3x - 4 = (x - 4)(x + 1) \\
-1 &< x < 4
\end{aligned}" />

Intersecting with <InlineMath math="x \ge 1" /> leaves <InlineMath math="1 \le x < 4" />. Joining both cases seamlessly covers everything from <InlineMath math="-5" /> up to <InlineMath math="4" />.

## Checking endpoints and wrong choices

Test both endpoints: at <InlineMath math="x = -5" /> we get <InlineMath math="0 > -6" /> (true, so <InlineMath math="-5" /> stays), whereas at <InlineMath math="x = 4" /> **both sides tie at <InlineMath math="3" />**, excluding <InlineMath math="4" />.

| Option | Why it is wrong |
| :--- | :--- |
| <InlineMath math="-1 < x < 4" /> | Squares immediately without case splitting, losing every value from <InlineMath math="-5" /> to <InlineMath math="-1" />. |
| <InlineMath math="1 \le x < 4" /> | Solves only the second case and forgets the negative right-side zone. |
| <InlineMath math="x < 4" /> | Forgets the domain <InlineMath math="x \ge -5" />, letting undefined values slip in. |
| <InlineMath math="-5 \le x \le 4" /> | Includes <InlineMath math="x = 4" />, even though the inequality is strict. |
| <InlineMath math="x > 4" /> | Flips the direction, since the line rises above the root to the right of <InlineMath math="4" />. |

# Answer

The inequality holds for all real numbers in the interval below.

<BlockMath math="-5 \le x < 4" />
