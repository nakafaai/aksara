# Diketahui

Diberikan **pertidaksamaan nilai mutlak** (*Ungleichung*) linear:

<BlockMath math="\lvert 2x - 3 \rvert \le x + 1" />

# Ditanyakan

Tentukan semua bilangan real <InlineMath math="x" /> yang memenuhi pertidaksamaan ini.

# Penyelesaian

Nilai mutlak <InlineMath math="\lvert 2x - 3 \rvert" /> bekerja seperti sakelar dua mode yang berganti tepat di titik nolnya <InlineMath math="\frac{3}{2}" />. Di kanan <InlineMath math="\frac{3}{2}" />, isinya positif sehingga tanda mutlak dibuka begitu saja. Di kiri <InlineMath math="\frac{3}{2}" />, isinya negatif sehingga seluruh isinya dibalik tandanya. Selesaikan **kedua mode itu lalu sambungkan hasilnya**.

> Pertidaksamaan nilai mutlak terpecah di titik pembuat nol isinya menjadi dua pertidaksamaan linear biasa, lalu kedua himpunan hasilnya digabungkan.

## Menyelesaikan kedua kasus di kiri dan kanan titik belok

Bentuk <InlineMath math="2x - 3" /> berganti tanda di <InlineMath math="\frac{3}{2}" />, sehingga muncul **dua cabang terpisah**:

<BlockMath math="\begin{aligned}
x \ge \frac{3}{2}: &\quad 2x - 3 \le x + 1 \quad \Longleftrightarrow \quad x \le 4 \quad \Longrightarrow \quad \frac{3}{2} \le x \le 4 \\
x < \frac{3}{2}: &\quad 3 - 2x \le x + 1 \quad \Longleftrightarrow \quad 2 \le 3x \quad \Longrightarrow \quad \frac{2}{3} \le x < \frac{3}{2}
\end{aligned}" />

Perhatikan bahwa kedua potongan selang itu **bersambung mulus tanpa celah** di titik <InlineMath math="\frac{3}{2}" />:

<BlockMath math="\frac{2}{3} \le x \le 4" />

## Mengecek pilihan salah

Perhatikan cabang mana yang **hilang atau tertukar** pada setiap pengecoh:

| Pilihan | Mengapa salah |
| --- | --- |
| <InlineMath math="\frac{3}{2} \le x \le 4" /> | Hanya menyertakan kasus pertama dan melupakan cabang kiri. |
| <InlineMath math="x \le 4" /> | Mengambil batas atas tanpa memasang batas bawah dari kasus kedua. |
| <InlineMath math="\frac{2}{3} \le x < \frac{3}{2}" /> | Hanya menyertakan kasus kedua dan melupakan cabang kanan. |
| <InlineMath math="-4 \le x \le -\frac{2}{3}" /> | Membalik tanda kedua ujung selang ke bilangan negatif. |
| <InlineMath math="\frac{2}{3} < x < 4" /> | Membuang kedua titik ujung padahal tanda <InlineMath math="\le" /> mengizinkan kesamaan. |
