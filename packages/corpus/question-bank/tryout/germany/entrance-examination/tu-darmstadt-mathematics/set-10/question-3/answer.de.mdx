# Gegeben

Gegeben ist eine lineare **Betragsungleichung**:

<BlockMath math="\lvert 2x - 3 \rvert \le x + 1" />

# Gesucht

Bestimme alle reellen Zahlen <InlineMath math="x" />, für die diese Ungleichung gilt.

# Lösung

Der Betrag <InlineMath math="\lvert 2x - 3 \rvert" /> wirkt wie ein Kippschalter, der genau bei seiner Nullstelle <InlineMath math="\frac{3}{2}" /> umschaltet. Rechts von <InlineMath math="\frac{3}{2}" /> ist der Ausdruck nicht negativ und die Betragsstriche fallen einfach weg. Links davon dreht sich sein Vorzeichen um. Löse **beide Fälle und füge sie zusammen**.

> Eine Betragsungleichung teilt sich an der Nullstelle ihres Inhalts in zwei einfache lineare Ungleichungen, deren Lösungsbereiche anschließend vereinigt werden.

## Beide Fälle rund um die Knickstelle lösen

Der Term <InlineMath math="2x - 3" /> wechselt bei <InlineMath math="\frac{3}{2}" /> sein Vorzeichen, sodass **zwei getrennte Fälle** entstehen:

<BlockMath math="\begin{aligned}
x \ge \frac{3}{2}: &\quad 2x - 3 \le x + 1 \quad \Longleftrightarrow \quad x \le 4 \quad \Longrightarrow \quad \frac{3}{2} \le x \le 4 \\
x < \frac{3}{2}: &\quad 3 - 2x \le x + 1 \quad \Longleftrightarrow \quad 2 \le 3x \quad \Longrightarrow \quad \frac{2}{3} \le x < \frac{3}{2}
\end{aligned}" />

Beide Teilstücke **schließen bei <InlineMath math="\frac{3}{2}" /> lückenlos aneinander**:

<BlockMath math="\frac{2}{3} \le x \le 4" />

## Falsche Antworten prüfen

Sieh nach, welcher Fall bei **jeder falschen Auswahl** fehlt oder umgedreht wurde:

| Auswahl | Warum falsch |
| --- | --- |
| <InlineMath math="\frac{3}{2} \le x \le 4" /> | Enthält nur den ersten Fall und vergisst den linken Zweig. |
| <InlineMath math="x \le 4" /> | Behält die obere Grenze, vergisst aber die untere aus dem zweiten Fall. |
| <InlineMath math="\frac{2}{3} \le x < \frac{3}{2}" /> | Enthält nur den zweiten Fall und vergisst den rechten Zweig. |
| <InlineMath math="-4 \le x \le -\frac{2}{3}" /> | Kehrt die Vorzeichen beider Grenzen ins Negative um. |
| <InlineMath math="\frac{2}{3} < x < 4" /> | Schließt die Randpunkte aus, obwohl <InlineMath math="\le" /> Gleichheit zulässt. |

# Antwort

Alle reellen Zahlen <InlineMath math="x" />, die die Ungleichung erfüllen, sind:

<BlockMath math="\frac{2}{3} \le x \le 4" />
