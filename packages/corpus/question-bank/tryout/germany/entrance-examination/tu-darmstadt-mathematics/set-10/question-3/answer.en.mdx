# Given

We are given a linear **absolute-value inequality** (*Ungleichung*):

<BlockMath math="\lvert 2x - 3 \rvert \le x + 1" />

# Asked

Determine all real numbers <InlineMath math="x" /> satisfying this inequality.

# Solution

The absolute value <InlineMath math="\lvert 2x - 3 \rvert" /> acts like a two-mode switch flipping right at its zero <InlineMath math="\frac{3}{2}" />. To the right of <InlineMath math="\frac{3}{2}" />, the expression is nonnegative and the bars simply drop. To the left, it is negative and its sign reverses. Solve **both modes and join the pieces together**.

> An absolute-value inequality splits at the zero of its inner expression into two ordinary linear inequalities whose solutions are then combined.

## Solving both cases around the turning point

The expression <InlineMath math="2x - 3" /> changes sign at <InlineMath math="\frac{3}{2}" />, giving **two separate cases**:

<BlockMath math="\begin{aligned}
x \ge \frac{3}{2}: &\quad 2x - 3 \le x + 1 \quad \Longleftrightarrow \quad x \le 4 \quad \Longrightarrow \quad \frac{3}{2} \le x \le 4 \\
x < \frac{3}{2}: &\quad 3 - 2x \le x + 1 \quad \Longleftrightarrow \quad 2 \le 3x \quad \Longrightarrow \quad \frac{2}{3} \le x < \frac{3}{2}
\end{aligned}" />

Notice how the two intervals **join seamlessly without any gap** at <InlineMath math="\frac{3}{2}" />:

<BlockMath math="\frac{2}{3} \le x \le 4" />

## Checking the distractors

See which branch is **dropped or flipped** in each wrong choice:

| Option | Why it is wrong |
| --- | --- |
| <InlineMath math="\frac{3}{2} \le x \le 4" /> | Keeps only the first case and omits the left branch. |
| <InlineMath math="x \le 4" /> | Keeps the upper bound but drops the lower bound from the second case. |
| <InlineMath math="\frac{2}{3} \le x < \frac{3}{2}" /> | Keeps only the second case and omits the right branch. |
| <InlineMath math="-4 \le x \le -\frac{2}{3}" /> | Negates both endpoints into the negative half. |
| <InlineMath math="\frac{2}{3} < x < 4" /> | Excludes both endpoints even though <InlineMath math="\le" /> allows equality. |

# Answer

All real numbers <InlineMath math="x" /> satisfying the inequality are:

<BlockMath math="\frac{2}{3} \le x \le 4" />
