# Diberi

Diberikan **ketaksamaan nilai mutlak** (*Ungleichung*) linear:

<BlockMath math="\lvert 2x - 3 \rvert \le x + 1" />

# Ditanya

Tentukan semua nombor nyata <InlineMath math="x" /> yang memenuhi ketaksamaan ini.

# Penyelesaian

Nilai mutlak <InlineMath math="\lvert 2x - 3 \rvert" /> bertindak seperti suis dua mod yang bertukar tepat pada titik sifarnya <InlineMath math="\frac{3}{2}" />. Di kanan <InlineMath math="\frac{3}{2}" />, kandungannya bukan negatif jadi tanda mutlak dibuka terus. Di kiri, kandungannya negatif jadi tandanya diterbalikkan. Selesaikan **kedua-dua mod lalu gabungkan hasilnya**.

> Ketaksamaan nilai mutlak terpecah pada titik sifar kandungannya menjadi dua ketaksamaan linear biasa, lalu hasil kedua-duanya disatukan.

## Menyelesaikan dua kes di kiri dan kanan titik belok

Ungkapan <InlineMath math="2x - 3" /> bertukar tanda pada <InlineMath math="\frac{3}{2}" />, melahirkan **dua cabang berasingan**:

<BlockMath math="\begin{aligned}
x \ge \frac{3}{2}: &\quad 2x - 3 \le x + 1 \quad \Longleftrightarrow \quad x \le 4 \quad \Longrightarrow \quad \frac{3}{2} \le x \le 4 \\
x < \frac{3}{2}: &\quad 3 - 2x \le x + 1 \quad \Longleftrightarrow \quad 2 \le 3x \quad \Longrightarrow \quad \frac{2}{3} \le x < \frac{3}{2}
\end{aligned}" />

Perhatikan kedua-dua selang **bersambung rapat tanpa jurang** di titik <InlineMath math="\frac{3}{2}" />:

<BlockMath math="\frac{2}{3} \le x \le 4" />

## Menyemak pilihan salah

Perhatikan cabang mana yang **hilang atau diterbalikkan** pada setiap pengganggu:

| Pilihan | Mengapa salah |
| --- | --- |
| <InlineMath math="\frac{3}{2} \le x \le 4" /> | Hanya mengambil kes pertama dan meninggalkan cabang kiri. |
| <InlineMath math="x \le 4" /> | Mengekalkan had atas tetapi melupakan had bawah dari kes kedua. |
| <InlineMath math="\frac{2}{3} \le x < \frac{3}{2}" /> | Hanya mengambil kes kedua dan meninggalkan cabang kanan. |
| <InlineMath math="-4 \le x \le -\frac{2}{3}" /> | Menukar tanda kedua-dua titik hujung menjadi negatif. |
| <InlineMath math="\frac{2}{3} < x < 4" /> | Membuang kedua-dua titik hujung walaupun <InlineMath math="\le" /> membenarkan kesamaan. |
