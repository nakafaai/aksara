# Gegeben

Gegeben ist eine **quadratische trigonometrische Gleichung** für Winkel <InlineMath math="x" /> in einem vollen Umlauf von <InlineMath math="0^\circ" /> bis knapp unter <InlineMath math="360^\circ" />:

<BlockMath math="2\sin^2 x - \sin x - 1 = 0" />

# Gesucht

Wie viele Lösungen besitzt die Gleichung in diesem Bereich?

# Lösung

Stell dir <InlineMath math="\sin x" /> als Höhe einer Gondel auf einem Riesenrad am Einheitskreis vor. Die Substitution <InlineMath math="s = \sin x" /> liefert eine gewöhnliche quadratische Gleichung mit zwei Zielhöhen. Bei einer vollen Umdrehung wird **fast jede Höhe zweimal durchlaufen** (aufwärts und abwärts), nur **der höchste und der tiefste Punkt werden genau einmal berührt**.

> Am Einheitskreis liefert jeder Sinuswert echt zwischen <InlineMath math="-1" /> und <InlineMath math="1" /> genau zwei Winkel, während die Extremwerte <InlineMath math="1" /> und <InlineMath math="-1" /> jeweils nur einen Winkel ergeben.

## Die quadratische Gleichung im Sinus faktorisieren

Setze <InlineMath math="s = \sin x" />. Die Gleichung **zerfällt sofort in zwei Faktoren**:

<BlockMath math="2s^2 - s - 1 = 0 \quad \Longleftrightarrow \quad (2s + 1)(s - 1) = 0 \quad \Longleftrightarrow \quad s = 1 \ \text{oder} \ s = -\frac{1}{2}" />

Beide Werte liegen im zulässigen Sinusbereich zwischen <InlineMath math="-1" /> und <InlineMath math="1" />.

## Alle Winkel am Einheitskreis abzählen

Bestimme alle Winkel einer vollen Umdrehung für **beide Zielhöhen**:

<BlockMath math="\begin{aligned}
\sin x = 1: &\quad x = 90^\circ \\
\sin x = -\frac{1}{2}: &\quad x = 210^\circ \ \text{oder} \ x = 330^\circ
\end{aligned}" />

Alle drei Punkte liegen im Schaubild direkt auf dem Einheitskreis.

## Falsche Antworten prüfen

Jede falsche Auswahl **verzählt sich bei der Anzahl der Winkel am Einheitskreis**:

| Auswahl | Warum falsch |
| --- | --- |
| <InlineMath math="4" /> | Nimmt auch für <InlineMath math="\sin x = 1" /> zwei Winkel an, obwohl das Maximum nur einmal erreicht wird. |
| <InlineMath math="2" /> | Zählt nur einen Winkel pro Sinuswert. |
| <InlineMath math="1" /> | Berücksichtigt nur <InlineMath math="\sin x = 1" /> und streicht den negativen Sinuswert. |
| <InlineMath math="5" /> | Zählt <InlineMath math="90^\circ" /> doppelt und nimmt <InlineMath math="360^\circ" /> außerhalb des Intervalls mit. |
| <InlineMath math="6" /> | Unterstellt drei Winkel je Sinuswert in einem einzigen Umlauf. |

# Antwort

Die Gleichung hat genau **<InlineMath math="3" />** Lösungen.
