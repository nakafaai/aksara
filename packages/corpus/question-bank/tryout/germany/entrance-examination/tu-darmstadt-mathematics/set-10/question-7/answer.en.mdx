# A quadratic equation in <InlineMath math="\sin x" />

Set <InlineMath math="s=\sin x" />. Then the equation is **quadratic in <InlineMath math="s" />**:

<BlockMath math="2s^2-s-1=0\quad\Longleftrightarrow\quad (2s+1)(s-1)=0\quad\Longleftrightarrow\quad s=1\ \text{or}\ s=-\tfrac12" />

Both values lie between <InlineMath math="-1" /> and <InlineMath math="1" />, so both are possible as sine values.

# Count the angles for each sine value

In the range <InlineMath math="0^\circ\le x<360^\circ" /> a sine value usually has two angles. **The value <InlineMath math="1" /> is an exception**, because it is the maximum: it is reached only at <InlineMath math="90^\circ" />.

<BlockMath math="\begin{aligned}
\sin x=1:&\quad x=90^\circ \\
\sin x=-\tfrac12:&\quad x=180^\circ+30^\circ=210^\circ\ \text{or}\ x=360^\circ-30^\circ=330^\circ
\end{aligned}" />

# The count

Together these are the angles <InlineMath math="90^\circ" />, <InlineMath math="210^\circ" /> and <InlineMath math="330^\circ" />. The equation has **exactly <InlineMath math="3" /> solutions**.

# Why the other answers are wrong

- <InlineMath math="4" /> gives <InlineMath math="\sin x=1" /> two angles too, although **the maximum is reached only once**.
- <InlineMath math="2" /> counts only one angle per sine value.
- <InlineMath math="1" /> counts only <InlineMath math="\sin x=1" /> and discards the negative value.
- <InlineMath math="5" /> also counts <InlineMath math="x=360^\circ" />, which is outside the range, and the doubled <InlineMath math="90^\circ" /> solution.
- <InlineMath math="6" /> assumes three angles for each value, as if the range went beyond one full turn.
