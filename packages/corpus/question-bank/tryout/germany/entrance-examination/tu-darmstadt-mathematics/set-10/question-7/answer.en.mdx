# Given

We are given a **quadratic trigonometric equation** for angles <InlineMath math="x" /> in one full turn from <InlineMath math="0^\circ" /> up to <InlineMath math="360^\circ" /> exclusive:

<BlockMath math="2\sin^2 x - \sin x - 1 = 0" />

# Asked

How many solutions (*Lösungen*) does this equation have in this interval?

# Solution

Think of <InlineMath math="\sin x" /> as the height of a passenger riding around a unit-circle Ferris wheel. Substituting <InlineMath math="s = \sin x" /> turns the equation into a plain quadratic that picks out two target heights. During one full rotation, **almost every height is passed twice** (once climbing, once descending), except **the very top and bottom, which are touched only once**.

> On the unit circle over one full turn, every sine value strictly between <InlineMath math="-1" /> and <InlineMath math="1" /> yields two angles, while the extremes <InlineMath math="1" /> and <InlineMath math="-1" /> yield only one.

## Factoring the quadratic in sine

Let <InlineMath math="s = \sin x" />. The quadratic **factors cleanly**:

<BlockMath math="2s^2 - s - 1 = 0 \quad \Longleftrightarrow \quad (2s + 1)(s - 1) = 0 \quad \Longleftrightarrow \quad s = 1 \ \text{or} \ s = -\frac{1}{2}" />

Both values lie inside the valid sine range from <InlineMath math="-1" /> to <InlineMath math="1" />.

## Counting the angles on the unit circle

List every angle in one full turn for **each target height**:

<BlockMath math="\begin{aligned}
\sin x = 1: &\quad x = 90^\circ \\
\sin x = -\frac{1}{2}: &\quad x = 210^\circ \ \text{or} \ x = 330^\circ
\end{aligned}" />

# Answer

The equation has exactly **<InlineMath math="3" />** solutions.
