# Gegeben

Eine Ameise sitzt auf einer Ecke eines Würfels mit der **Kantenlänge <InlineMath math="2\text{ cm}" />**.

Sie darf sich nur auf der **Würfeloberfläche** bewegen und will zur am weitesten entfernten gegenüberliegenden Ecke gelangen.

# Gesucht

Wie lang ist der kürzeste Weg der Ameise auf der Oberfläche?

# Lösung

Auf einem dreidimensionalen Körper täuscht der erste Eindruck oft vor, man müsse Kanten entlanglaufen oder eine Flächendiagonale mit einer Kante kombinieren. Der beste Trick lautet: **Klappe die Würfeloberfläche flach in ein Netz auf**. Sobald die beiden überquerten Seitenflächen eben nebeneinanderliegen, ist der kürzeste Weg immer **eine gerade Strecke** über die Faltkante hinweg.

> Der kürzeste Weg auf einer Körperoberfläche wird stets zur geraden Strecke, wenn man die durchlaufenen Seitenflächen flach in ein Netz aufklappt.

## Zwei benachbarte Würfelflächen flach ausbreiten

Bis zur gegenüberliegenden Ecke überquert die Ameise **zwei aneinandergrenzende Quadratflächen**. Aufgeklappt bilden diese beiden <InlineMath math="2\text{ cm}" />-Quadrate ein einziges Rechteck mit:

- Breite <InlineMath math="2\text{ cm}" />.
- Gesamtlänge <InlineMath math="2 + 2 = 4\text{ cm}" />.

Startecke <InlineMath math="A" /> und Zielecke <InlineMath math="B" /> sitzen genau in gegenüberliegenden Ecken dieses Rechtecks.

Die Gerade schneidet die gemeinsame Kante genau in ihrer Mitte, nicht in einer Ecke.

## Diagonale berechnen und Wege vergleichen

Wende den **Satz des Pythagoras** auf das <InlineMath math="4\text{ cm}" /> mal <InlineMath math="2\text{ cm}" /> große Rechteck an:

<BlockMath math="d = \sqrt{4^2 + 2^2} = \sqrt{16 + 4} = \sqrt{20} = 2\sqrt{5}\text{ cm}" />

Wegevergleich: über drei Kanten sind es <InlineMath math="6\text{ cm}" />, über eine Kante plus Flächendiagonale rund <InlineMath math="4{,}83\text{ cm}" />. Die Netzdiagonale misst nur rund <InlineMath math="4{,}47\text{ cm}" /> und ist klar am kürzesten.

## Falsche Antworten prüfen

Sieh nach, welchen Weg **jede falsche Auswahl misst**:

| Auswahl | Warum falsch |
| --- | --- |
| <InlineMath math="2\sqrt{3}\text{ cm}" /> | Ist die Raumdiagonale quer durch das Innere, doch die Ameise bleibt auf der Oberfläche. |
| <InlineMath math="6\text{ cm}" /> | Läuft drei volle Kanten entlang, deutlich länger als der gerade Weg im Netz. |
| <InlineMath math="4\text{ cm}" /> | Nur zwei Kanten, erreicht bloß die Gegenecke derselben Seitenfläche. |
| <InlineMath math="(2 + 2\sqrt{2})\text{ cm}" /> | Eine Kante plus eine Flächendiagonale (rund <InlineMath math="4{,}83\text{ cm}" />), länger als <InlineMath math="2\sqrt{5}\text{ cm}" />. |
| <InlineMath math="2\sqrt{2}\text{ cm}" /> | Nur eine Flächendiagonale, endet noch auf der Startfläche statt an der Gegenecke. |

# Antwort

Der kürzeste Weg auf der Würfeloberfläche ist **<InlineMath math="2\sqrt{5}\text{ cm}" />** lang.
