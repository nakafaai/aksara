# Diberi

Diberikan persamaan yang **menyamakan nilai mutlak dengan punca kuasa dua**:

<BlockMath math="\lvert x - 3 \rvert = \sqrt{x + 3}" />

# Ditanya

Tentukan set penyelesaian (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> bagi semua nombor nyata <InlineMath math="x" /> yang memenuhi persamaan ini.

# Penyelesaian

Biasanya menguasaduakan persamaan berpunca boleh melahirkan jawapan palsu apabila tanda negatif terhapus. Di sini keadaan jauh lebih kemas: **sebelah kiri ialah nilai mutlak dan sebelah kanan ialah punca kuasa dua**, jadi kedua-dua belah sentiasa sifar atau positif. Dalam domain punca, menguasaduakan terus tidak mencipta penyelesaian palsu.

> Apabila kedua-dua belah persamaan dijamin bukan negatif, pengkuasaduakan menghapuskan nilai mutlak dan tanda punca serentak tanpa mencipta punca palsu.

## Menyemak domain lalu menguasaduakan terus

Agar punca tertakrif, mesti berlaku <InlineMath math="x + 3 \ge 0" />, iaitu <InlineMath math="x \ge -3" />. Oleh sebab kedua-dua belah bukan negatif dan kuasa dua nilai mutlak sama dengan kuasa dua biasa, **kuasaduakan kedua-dua belah terus**:

<BlockMath math="\begin{aligned}
\lvert x - 3 \rvert^2 &= x + 3 \\
(x - 3)^2 &= x + 3 \\
x^2 - 7x + 6 &= 0 \\
(x - 1)(x - 6) &= 0
\end{aligned}" />

Kita mendapat dua calon, iaitu <InlineMath math="x = 1" /> dan <InlineMath math="x = 6" />.

## Menguji dua calon pada persamaan asal dan graf

Kedua-duanya memenuhi <InlineMath math="x \ge -3" />. Uji terus dalam persamaan asal untuk **memastikan tiada punca tertolak**:

<BlockMath math="\begin{aligned}
x = 1: &\quad \lvert 1 - 3 \rvert = 2, \qquad \sqrt{1 + 3} = 2 \\
x = 6: &\quad \lvert 6 - 3 \rvert = 3, \qquad \sqrt{6 + 3} = 3
\end{aligned}" />

Tanpa nilai mutlak, <InlineMath math="x = 1" /> akan gagal kerana <InlineMath math="1 - 3 = -2" />. Berkat nilai mutlak, kedua-dua titik persilangan adalah sah.

## Menyemak pilihan salah

Perhatikan bagaimana pengganggu lain **menolak <InlineMath math="x = 1" /> atau silap memfaktorkan**:

| Pilihan | Mengapa salah |
| --- | --- |
| <InlineMath math="\mathbb{L} = \{6\}" /> | Melayan <InlineMath math="\lvert x - 3 \rvert" /> seperti <InlineMath math="x - 3" /> lalu silap membuang <InlineMath math="x = 1" />. |
| <InlineMath math="\mathbb{L} = \{1\}" /> | Membuang penyelesaian sah <InlineMath math="x = 6" /> tanpa sebab. |
| <InlineMath math="\mathbb{L} = \{-1,\, 6\}" /> | Berpunca daripada silap tanda pemfaktoran <InlineMath math="(x + 1)(x - 6) = x^2 - 5x - 6" />. |
| <InlineMath math="\mathbb{L} = \{-6,\, -1\}" /> | Memfaktorkan <InlineMath math="x^2 + 7x + 6" /> bukannya <InlineMath math="x^2 - 7x + 6" />, dan <InlineMath math="-6" /> di luar domain. |
| <InlineMath math="\mathbb{L} = \{\}" /> | Mengabaikan bahawa kedua-dua calon lulus semakan. |

# Jawapan

Set penyelesaiannya ialah **<InlineMath math="\mathbb{L} = \{1,\, 6\}" />**.
