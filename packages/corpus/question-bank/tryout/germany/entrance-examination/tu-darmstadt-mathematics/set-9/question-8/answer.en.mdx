# Given

For a real number <InlineMath math="x" />, we are given an **exponential equation with two different bases**:

<BlockMath math="2^{x + 1} = 3^{x - 1}" />

# Asked

Which real number <InlineMath math="x" /> satisfies this equation?

# Solution

Bases <InlineMath math="2" /> and <InlineMath math="3" /> cannot be rewritten as powers of a common integer. The cleanest move is to **gather every <InlineMath math="x" />-power onto one side** and every plain constant onto the other. Once only one combined power remains, a single logarithm frees <InlineMath math="x" /> immediately.

> In an exponential equation with different bases, split off the exponent shifts, combine all variable powers on one side, and take the logarithm.

## Splitting the shifts and combining the powers

Pull out the constant factors from the shifted exponents on both sides, then **group all <InlineMath math="x" />-powers together**:

<BlockMath math="2^{x + 1} = 3^{x - 1} \quad \Longleftrightarrow \quad 2 \cdot 2^x = \frac{3^x}{3} \quad \Longleftrightarrow \quad 6 = \frac{3^x}{2^x} = \left(\frac{3}{2}\right)^x" />

## Taking the logarithm and checking the graph

Because <InlineMath math="\left(\frac{3}{2}\right)^x" /> rises strictly from zero to infinity, the equation has **one unique real solution**, the base-<InlineMath math="\frac{3}{2}" /> logarithm of <InlineMath math="6" />:

<BlockMath math="x = \log_{\frac{3}{2}} 6 = \frac{\lg 6}{\lg 1.5} \approx 4.42" />

## Checking the distractors

See how the wrong options **invert the base fraction or swap base and argument**:

| Option | Why it is wrong |

| <InlineMath math="x = \log_6 \frac{3}{2}" /> | Swaps the base <InlineMath math="\frac{3}{2}" /> with the argument <InlineMath math="6" />. |
| <InlineMath math="x = \log_{\frac{3}{2}} 3" /> | Drops the factor <InlineMath math="2" /> from <InlineMath math="2^{x + 1}" />, leaving <InlineMath math="3" /> instead of <InlineMath math="6" />. |
| <InlineMath math="x = -1" /> | Makes <InlineMath math="2^0 = 1" />, while the right side is <InlineMath math="3^{-2} = \frac{1}{9}" />. |
| No real number <InlineMath math="x" /> exists | Assumes different bases never meet, overlooking that the faster curve always overtakes. |

# Answer

The real number <InlineMath math="x" /> satisfying the equation is:

<BlockMath math="x = \log_{\frac{3}{2}} 6" />
