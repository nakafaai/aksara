# Given

We are given an equation setting **an absolute value equal to a square root**:

<BlockMath math="\lvert x - 3 \rvert = \sqrt{x + 3}" />

# Asked

Find the solution set (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> of all real numbers <InlineMath math="x" /> satisfying this equation.

# Solution

Usually, squaring a radical equation risks creating fake solutions when a minus sign gets erased. Here you get a free gift: **the left side is an absolute value and the right side is a principal square root**, so both sides are automatically nonnegative. Inside the root's domain, squaring both sides directly preserves every true solution without introducing fakes.

> When both sides of an equation are guaranteed nonnegative, squaring removes the absolute value and square root in one step without creating extraneous solutions.

## Checking the domain and squaring directly

For the square root to exist, we need <InlineMath math="x + 3 \ge 0" />, meaning <InlineMath math="x \ge -3" />. Because both sides are nonnegative and squaring drops the absolute value bars cleanly, **square both sides directly**:

<BlockMath math="\begin{aligned}
\lvert x - 3 \rvert^2 &= x + 3 \\
(x - 3)^2 &= x + 3 \\
x^2 - 7x + 6 &= 0 \\
(x - 1)(x - 6) &= 0
\end{aligned}" />

This yields two candidates: <InlineMath math="x = 1" /> and <InlineMath math="x = 6" />.

## Verifying both candidates in the equation and graph

Both lie well inside <InlineMath math="x \ge -3" />. Plug both into the original equation to **verify that neither gets rejected**:

<BlockMath math="\begin{aligned}
x = 1: &\quad \lvert 1 - 3 \rvert = 2, \qquad \sqrt{1 + 3} = 2 \\
x = 6: &\quad \lvert 6 - 3 \rvert = 3, \qquad \sqrt{6 + 3} = 3
\end{aligned}" />

Without the absolute value bars, <InlineMath math="x = 1" /> would fail because <InlineMath math="1 - 3 = -2" />. Because of the absolute value, both crossings are completely valid.

## Checking the distractors

Notice how the wrong options **discard <InlineMath math="x = 1" /> or mis-factor the quadratic**:

| Option | Why it is wrong |
| --- | --- |
| <InlineMath math="\mathbb{L} = \{6\}" /> | Treats <InlineMath math="\lvert x - 3 \rvert" /> like <InlineMath math="x - 3" /> and wrongly rejects <InlineMath math="x = 1" />. |
| <InlineMath math="\mathbb{L} = \{1\}" /> | Drops the valid solution <InlineMath math="x = 6" /> without reason. |
| <InlineMath math="\mathbb{L} = \{-1,\, 6\}" /> | Comes from a sign error factoring <InlineMath math="(x + 1)(x - 6) = x^2 - 5x - 6" />. |
| <InlineMath math="\mathbb{L} = \{-6,\, -1\}" /> | Factors <InlineMath math="x^2 + 7x + 6" /> instead of <InlineMath math="x^2 - 7x + 6" />, and <InlineMath math="-6" /> leaves the domain. |
| <InlineMath math="\mathbb{L} = \{\}" /> | Ignores that both candidates check out cleanly. |

# Answer

The solution set is **<InlineMath math="\mathbb{L} = \{1,\, 6\}" />**.
