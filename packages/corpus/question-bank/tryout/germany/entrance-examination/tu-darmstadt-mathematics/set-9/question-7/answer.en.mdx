# Given

The price of an item (*Preis einer Ware*) undergoes two consecutive percentage changes:

- First, the price is **increased by <InlineMath math="25\,\%" />**.
- Next, the new price is **reduced by <InlineMath math="s" />** so the final price ends up <InlineMath math="10\,\%" /> below the original price.

# Asked

By what percent was the **increased price** reduced?

# Solution

Back-to-back percentage changes never simply add, because **the reference base changes after the first step**. Picture a <InlineMath math="100\text{ €}" /> item: a <InlineMath math="25\,\%" /> markup lifts it to <InlineMath math="125\text{ €}" />. To drop it down to <InlineMath math="90\text{ €}" />, you cut <InlineMath math="35\text{ €}" />, and that <InlineMath math="35\text{ €}" /> cut is measured out of <InlineMath math="125\text{ €}" />, not out of <InlineMath math="100\text{ €}" />.

> Every percentage change acts on the current value right before that step, so chained percentages combine by multiplying factors.

## Setting up the multiplier equation

A <InlineMath math="25\,\%" /> increase multiplies the starting price by <InlineMath math="1.25" />, and finishing <InlineMath math="10\,\%" /> below the start means multiplying by <InlineMath math="0.9" />. For **a markdown fraction <InlineMath math="s" /> off the raised price**:

<BlockMath math="1.25(1 - s) = 0.9" />

## Solving for the percentage cut

Divide both sides by <InlineMath math="1.25" /> to get **the remaining fraction and then the markdown rate**:

<BlockMath math="1 - s = \frac{0.9}{1.25} = \frac{90}{125} = 0.72 \quad \Longrightarrow \quad s = 1 - 0.72 = 0.28 = 28\,\%" />

## Checking the distractors

See how each wrong option **adds percentages naively or confuses the reference base**:

| Option | Why it is wrong |
| --- | --- |
| by <InlineMath math="35\,\%" /> | Adds <InlineMath math="25 + 10" /> as if the cut were measured against <InlineMath math="100" /> instead of <InlineMath math="125" />. |
| by <InlineMath math="30\,\%" /> | Adds the <InlineMath math="20\,\%" /> undo cut and <InlineMath math="10\,\%" /> instead of multiplying factors. |
| by <InlineMath math="72\,\%" /> | Reports the remaining share <InlineMath math="0.72" /> instead of the reduction <InlineMath math="1 - 0.72" />. |
| by <InlineMath math="20\,\%" /> | Only returns the price to the start (<InlineMath math="1.25 \cdot 0.8 = 1" />), without the extra <InlineMath math="10\,\%" /> drop. |
| by <InlineMath math="25\,\%" /> | Simply mirrors the markup percent, leaving the price at <InlineMath math="93.75\text{ €}" />. |

# Answer

The increased price was reduced by **<InlineMath math="28\,\%" />**.
