# Diketahui

Diberikan persamaan yang **mempertemukan nilai mutlak dengan akar kuadrat**:

<BlockMath math="\lvert x - 3 \rvert = \sqrt{x + 3}" />

# Ditanyakan

Tentukan himpunan penyelesaian (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> berisi semua bilangan real <InlineMath math="x" /> yang memenuhi persamaan ini.

# Penyelesaian

Biasanya, mengkuadratkan persamaan akar bisa memunculkan jawaban palsu karena tanda minus ikut hilang. Di sini ada kabar baik: **ruas kiri berupa nilai mutlak dan ruas kanan berupa akar**, sehingga kedua ruas sudah pasti nol atau positif. Artinya di dalam daerah asal akar, mengkuadratkan langsung tidak mengubah himpunan penyelesaian sama sekali.

> Bila kedua ruas persamaan sudah pasti tak negatif, mengkuadratkan langsung membuang tanda mutlak sekaligus tanda akar tanpa menciptakan solusi palsu.

## Menentukan daerah asal lalu mengkuadratkan

Agar akar terdefinisi, wajib berlaku <InlineMath math="x + 3 \ge 0" />, yaitu <InlineMath math="x \ge -3" />. Karena kedua ruas tak negatif dan kuadrat nilai mutlak sama dengan kuadrat biasa, **kuadratkan langsung kedua ruas**:

<BlockMath math="\begin{aligned}
\lvert x - 3 \rvert^2 &= x + 3 \\
(x - 3)^2 &= x + 3 \\
x^2 - 7x + 6 &= 0 \\
(x - 1)(x - 6) &= 0
\end{aligned}" />

Kita memperoleh dua kandidat, yaitu <InlineMath math="x = 1" /> dan <InlineMath math="x = 6" />.

## Menguji kedua kandidat pada persamaan asli dan grafik

Keduanya berada di atas batas <InlineMath math="x \ge -3" />. Uji langsung ke persamaan asli untuk **memastikan tidak ada solusi yang gugur**:

<BlockMath math="\begin{aligned}
x = 1: &\quad \lvert 1 - 3 \rvert = 2, \qquad \sqrt{1 + 3} = 2 \\
x = 6: &\quad \lvert 6 - 3 \rvert = 3, \qquad \sqrt{6 + 3} = 3
\end{aligned}" />

Lihat grafik huruf V milik nilai mutlak dan kurva akar berikut: keduanya bertemu dua kali.

Andai tanda mutlak tidak ada, <InlineMath math="x = 1" /> akan gugur karena <InlineMath math="1 - 3 = -2" />. Justru berkat nilai mutlak, kedua titik temu sama-sama sah.

## Mengecek pilihan salah

Perhatikan bagaimana pengecoh lain **membuang <InlineMath math="x = 1" /> atau salah memfaktorkan**:

| Pilihan | Mengapa salah |
| --- | --- |
| <InlineMath math="\mathbb{L} = \{6\}" /> | Memperlakukan <InlineMath math="\lvert x - 3 \rvert" /> seperti <InlineMath math="x - 3" />, sehingga keliru membuang <InlineMath math="x = 1" />. |
| <InlineMath math="\mathbb{L} = \{1\}" /> | Membuang penyelesaian sah <InlineMath math="x = 6" /> tanpa alasan. |
| <InlineMath math="\mathbb{L} = \{-1,\, 6\}" /> | Salah tanda pemfaktoran dari <InlineMath math="(x + 1)(x - 6) = x^2 - 5x - 6" />. |
| <InlineMath math="\mathbb{L} = \{-6,\, -1\}" /> | Memfaktorkan <InlineMath math="x^2 + 7x + 6" /> alih-alih <InlineMath math="x^2 - 7x + 6" />, dan <InlineMath math="-6" /> di luar daerah asal. |
| <InlineMath math="\mathbb{L} = \{\}" /> | Mengabaikan bahwa kedua kandidat lolos uji di persamaan asli. |

# Jawaban

Himpunan penyelesaiannya adalah **<InlineMath math="\mathbb{L} = \{1,\, 6\}" />**.
