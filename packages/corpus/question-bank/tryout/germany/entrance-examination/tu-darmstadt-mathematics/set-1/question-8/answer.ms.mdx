# Diberi

Persamaan nilai mutlak dengan parameter nyata <InlineMath math="a" /> diberi seperti berikut.

<BlockMath math="\left|x^2 - 4x\right| = a" />

Soalan meminta tepat **tiga penyelesaian nyata yang berbeza** (*genau drei verschiedene reelle Lösungen*).

# Ditanya

Tentukan semua nilai nyata <InlineMath math="a" /> yang menjadikan persamaan ini mempunyai tepat tiga penyelesaian nyata berbeza.

# Penyelesaian

Bilangan penyelesaian bagi <InlineMath math="|x^2 - 4x| = a" /> sama dengan **bilangan titik persilangan lengkung <InlineMath math="y = |x^2 - 4x|" /> dengan garis mendatar <InlineMath math="y = a" />**. Tanpa tanda mutlak, parabola <InlineMath math="x^2 - 4x" /> turun ke lembah pada <InlineMath math="(2 \mid -4)" />.

Tanda mutlak memantulkan lembah di bawah paksi <InlineMath math="x" /> ke atas, membentuk **bukit dengan puncak tepat pada <InlineMath math="(2 \mid 4)" />**.

> Garis mendatar memotong graf nilai mutlak parabola pada tepat tiga titik hanya apabila garis itu menyentuh puncak bukit pantulannya.

Gerakkan ketinggian garis <InlineMath math="y = a" /> pada graf berikut untuk mengira perubahan bilangan titik persilangan daripada sifar hingga empat.

Apabila garis digerakkan naik dari bawah, bilangan persilangan melonjak dari <InlineMath math="0" /> kepada <InlineMath math="2" />, lalu <InlineMath math="4" />, lalu tepat **<InlineMath math="3" /> di puncak bukit <InlineMath math="a = 4" />**, sebelum turun semula kepada <InlineMath math="2" />.

## Mengira persilangan mengikut aras

Ringkaskan semua aras garis <InlineMath math="y = a" /> untuk mengesahkan bahawa **hanya puncak bukit memberi tiga persilangan**.

| Nilai <InlineMath math="a" /> | Bilangan persilangan |
| :--- | :--- |
| <InlineMath math="a < 0" /> | <InlineMath math="0" /> |
| <InlineMath math="a = 0" /> | <InlineMath math="2" /> |
| <InlineMath math="0 < a < 4" /> | <InlineMath math="4" /> |
| <InlineMath math="a = 4" /> | <InlineMath math="3" /> |
| <InlineMath math="a > 4" /> | <InlineMath math="2" /> |

## Semakan algebra dan pilihan salah

Pada <InlineMath math="a = 4" />, pecahkan persamaan kepada dua cabang untuk **mengesahkan tepat tiga punca berbeza**.

<BlockMath math="\begin{aligned}
-(x^2 - 4x) = 4 &\implies (x - 2)^2 = 0 \implies x = 2 \\
x^2 - 4x = 4 &\implies (x - 2)^2 = 8 \implies x = 2 \pm 2\sqrt{2}
\end{aligned}" />

Ketiga-tiga puncanya nyata dan saling berbeza.

- <InlineMath math="a = 0" /> hanya memberi dua punca, iaitu <InlineMath math="x = 0" /> dan <InlineMath math="x = 4" />.
- <InlineMath math="0 < a < 4" /> (termasuk <InlineMath math="a = 2" />) memotong bukit dua kali dan kedua-dua cabang luar dua kali, berjumlah empat punca.
- <InlineMath math="a > 4" /> melepasi puncak bukit lalu hanya memotong kedua-dua cabang luar (dua punca).
- <InlineMath math="a = -4" /> mustahil kerana nilai mutlak tidak pernah negatif.

# Jawapan

Persamaan ini mempunyai tepat tiga penyelesaian nyata berbeza hanya untuk **<InlineMath math="a = 4" />**.
