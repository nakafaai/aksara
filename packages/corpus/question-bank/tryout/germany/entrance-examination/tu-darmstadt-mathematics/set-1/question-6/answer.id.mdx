# Diketahui

Sudut lancip (*Winkel*) <InlineMath math="x" /> berada **di antara <InlineMath math="0^\circ" /> dan <InlineMath math="45^\circ" />** serta memenuhi persamaan trigonometri berikut.

<BlockMath math="\sin x + \cos x = \frac{17}{13}" />

# Ditanyakan

Tentukan nilai tepat dari <InlineMath math="\tan x" />.

# Penyelesaian

Pada lingkaran satuan, titik <InlineMath math="(\cos x \mid \sin x)" /> berjalan sepanjang busur kuadran pertama berjari-jari <InlineMath math="1" />. Garis dengan jumlah koordinat <InlineMath math="\frac{17}{13}" /> memotong busur itu di **dua titik yang simetris terhadap garis <InlineMath math="45^\circ" />**.

> Untuk setiap sudut lancip di bawah empat puluh lima derajat, tinggi titik pada lingkaran satuan selalu lebih kecil daripada jarak mendatarnya, sehingga sinus lebih kecil daripada kosinus.

Lihat pada busur kuadran pertama berikut bagaimana batas sudut di bawah <InlineMath math="45^\circ" /> langsung memilih titik hijau di bawah diagonal.

Titik hijau di bawah garis <InlineMath math="45^\circ" /> memiliki nilai kosinus <InlineMath math="\frac{12}{13}" /> dan nilai sinus <InlineMath math="\frac{5}{13}" />. Sekarang kita turunkan nilai ini secara aljabar.

## Mengkuadratkan kedua ruas

Kita belum tahu nilai sinus dan kosinus satu per satu. **Kuadratkan kedua ruas** agar identitas <InlineMath math="\sin^2 x + \cos^2 x = 1" /> muncul dan langsung memberi hasil kalinya.

<BlockMath math="\begin{aligned}
(\sin x + \cos x)^2 &= \frac{289}{169} \\
1 + 2\sin x \cos x &= \frac{289}{169} \\
\sin x \cos x &= \frac{60}{169}
\end{aligned}" />

## Menentukan nilai tangen

Dengan jumlah <InlineMath math="\frac{17}{13}" /> dan hasil kali <InlineMath math="\frac{60}{169}" />, kedua nilainya adalah akar persamaan kuadrat berikut.

<BlockMath math="\begin{aligned}
t^2 - \frac{17}{13}t + \frac{60}{169} &= 0 \\
169t^2 - 221t + 60 &= 0 \\
(13t - 5)(13t - 12) &= 0
\end{aligned}" />

Kedua nilainya adalah <InlineMath math="\frac{5}{13}" /> dan <InlineMath math="\frac{12}{13}" />. Karena sudut berada di bawah <InlineMath math="45^\circ" />, **nilai sinus lebih kecil daripada kosinus**, sehingga kita langsung mendapat tangennya.

<BlockMath math="\sin x = \frac{5}{13}, \quad \cos x = \frac{12}{13} \implies \tan x = \frac{\sin x}{\cos x} = \frac{5}{12}" />

Cek: jumlah <InlineMath math="\frac{5}{13}" /> dan <InlineMath math="\frac{12}{13}" /> tepat <InlineMath math="\frac{17}{13}" />, dan nilai <InlineMath math="\tan x < 1" /> cocok dengan sudut di bawah <InlineMath math="45^\circ" />.

## Mengapa pilihan lain salah

- <InlineMath math="\frac{12}{5}" /> **menukar sinus dengan kosinus** sehingga cocok untuk sudut di atas <InlineMath math="45^\circ" />.
- <InlineMath math="\frac{60}{169}" /> adalah hasil tengah <InlineMath math="\sin x \cos x" />, bukan nilai tangen.
- <InlineMath math="\frac{5}{12}" /> atau <InlineMath math="\frac{12}{5}" /> mengabaikan syarat sudut di bawah <InlineMath math="45^\circ" />.
- <InlineMath math="\frac{120}{169}" /> adalah nilai <InlineMath math="\sin 2x" />, bukan <InlineMath math="\tan x" />.
- Pernyataan tidak ada sudut muncul ketika suku tengah <InlineMath math="2\sin x \cos x" /> dilupakan saat mengkuadratkan.
