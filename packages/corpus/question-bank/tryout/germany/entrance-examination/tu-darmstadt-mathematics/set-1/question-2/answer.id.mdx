# Diketahui

**Pertidaksamaan pecahan** (*Ungleichung*) untuk semua bilangan real <InlineMath math="x \neq -2" /> diberikan sebagai berikut.

<BlockMath math="\frac{x\,(x - 3)^2}{x + 2} \le 0" />

Syarat <InlineMath math="x \neq -2" /> mengecualikan titik pembuat nol penyebut (*Definitionsbereich*).

# Ditanyakan

Tentukan semua bilangan real <InlineMath math="x \neq -2" /> yang memenuhi pertidaksamaan ini.

# Penyelesaian

Bayangkan tiga sakelar tanda yang bekerja bersamaan pada pecahan ini. Faktor <InlineMath math="x" /> dan <InlineMath math="x + 2" /> membalik tanda positif atau negatif, sedangkan faktor kuadrat <InlineMath math="(x - 3)^2" /> **tidak pernah negatif** dan hanya menyentuh nol di <InlineMath math="x = 3" />.

> Faktor berpangkat genap tidak pernah mengubah tanda pecahan, tetapi titik pembuat nolnya tetap ikut menjadi penyelesaian ketika tandanya kurang dari atau sama dengan nol.

## Titik nol dan tabel tanda

Pecahan bernilai nol saat pembilang nol dan penyebut tidak nol, yaitu di <InlineMath math="x = 0" /> dan <InlineMath math="x = 3" />. Karena tanda pertidaksamaannya <InlineMath math="\le" />, **kedua titik ini wajib ikut**.

Untuk <InlineMath math="x \neq 3" />, faktor <InlineMath math="(x - 3)^2 > 0" />, sehingga tanda pecahan sepenuhnya ditentukan oleh hasil bagi <InlineMath math="x" /> dengan <InlineMath math="x + 2" />.

| Selang | <InlineMath math="x" /> | <InlineMath math="x + 2" /> | Tanda pecahan |
| :--- | :--- | :--- | :--- |
| <InlineMath math="x < -2" /> | negatif | negatif | positif |
| <InlineMath math="-2 < x < 0" /> | negatif | positif | negatif |
| <InlineMath math="x > 0" /> | positif | positif | positif |

## Pengecekan nilai dan pilihan salah

Uji tiga titik wakil untuk **mengonfirmasi seluruh selang dan batasnya**.

<BlockMath math="\begin{aligned}
x = -1 &\implies \frac{(-1)(-4)^2}{1} = -16 \le 0 \\
x = 2 &\implies \frac{2(-1)^2}{4} = \frac{1}{2} > 0 \\
x = -3 &\implies \frac{(-3)(-6)^2}{-1} = 108 > 0
\end{aligned}" />

- Pilihan yang hanya mengambil selang terbuka <InlineMath math="-2" /> sampai <InlineMath math="0" /> melupakan titik terpencil <InlineMath math="x = 3" /> tempat pembilang bernilai nol.
- Pilihan dengan batas kiri tertutup di <InlineMath math="-2" /> ikut memasukkan <InlineMath math="x = -2" />, padahal penyebut menjadi nol.
- Pilihan <InlineMath math="x \le 0" /> atau <InlineMath math="x = 3" /> mengalikan kedua ruas dengan <InlineMath math="x + 2" /> tanpa memperhatikan tanda negatifnya saat <InlineMath math="x < -2" />.
- Pilihan yang mengganti titik <InlineMath math="x = 3" /> menjadi <InlineMath math="x \ge 3" /> mengira tanda berganti di <InlineMath math="x = 3" />, padahal faktor kuadrat tidak mengubah tanda.
- Pilihan <InlineMath math="x < -2" /> atau <InlineMath math="x \ge 0" /> membalik arah pertidaksamaan sehingga mengambil daerah non-negatif.
