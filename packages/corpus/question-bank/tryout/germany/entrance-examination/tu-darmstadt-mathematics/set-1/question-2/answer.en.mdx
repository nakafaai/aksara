# Given

We are given a **rational inequality** (*Ungleichung*) for all real numbers <InlineMath math="x \neq -2" />.

<BlockMath math="\frac{x\,(x - 3)^2}{x + 2} \le 0" />

The condition <InlineMath math="x \neq -2" /> excludes the zero of the denominator (*Definitionsbereich*).

# Asked

Find all real numbers <InlineMath math="x \neq -2" /> that satisfy this inequality.

# Solution

Think of the fraction as three sign switches working together. The linear factors <InlineMath math="x" /> and <InlineMath math="x + 2" /> flip signs when they cross zero, while the square <InlineMath math="(x - 3)^2" /> is **never negative** and only hits zero at <InlineMath math="x = 3" />.

> An even-power factor never flips the sign of a fraction, yet its zero still joins the solution whenever the inequality allows equality with zero.

## Zeros and sign table

The fraction equals zero when its numerator is zero and its denominator is not, namely at <InlineMath math="x = 0" /> and <InlineMath math="x = 3" />. Because the inequality is <InlineMath math="\le" />, **both points belong in the solution**.

For <InlineMath math="x \neq 3" />, the factor <InlineMath math="(x - 3)^2 > 0" />, so the sign of the fraction matches the ratio of <InlineMath math="x" /> to <InlineMath math="x + 2" />.

| Interval | <InlineMath math="x" /> | <InlineMath math="x + 2" /> | Fraction sign |
| :--- | :--- | :--- | :--- |
| <InlineMath math="x < -2" /> | negative | negative | positive |
| <InlineMath math="-2 < x < 0" /> | negative | positive | negative |
| <InlineMath math="x > 0" /> | positive | positive | positive |

## Test points and wrong choices

Check three sample points to **confirm every interval and boundary**.

<BlockMath math="\begin{aligned}
x = -1 &\implies \frac{(-1)(-4)^2}{1} = -16 \le 0 \\
x = 2 &\implies \frac{2(-1)^2}{4} = \frac{1}{2} > 0 \\
x = -3 &\implies \frac{(-3)(-6)^2}{-1} = 108 > 0
\end{aligned}" />

- Keeping only the interval from <InlineMath math="-2" /> up to <InlineMath math="0" /> forgets the isolated point <InlineMath math="x = 3" />, where the numerator is zero.
- Closing the left endpoint at <InlineMath math="-2" /> includes <InlineMath math="x = -2" />, which divides by zero.
- Choosing <InlineMath math="x \le 0" /> or <InlineMath math="x = 3" /> multiplies through by <InlineMath math="x + 2" /> as if it were always positive, ignoring that it is negative for <InlineMath math="x < -2" />.
- Replacing <InlineMath math="x = 3" /> with <InlineMath math="x \ge 3" /> assumes a sign flip at <InlineMath math="x = 3" />, even though a square never changes sign.
- Choosing <InlineMath math="x < -2" /> or <InlineMath math="x \ge 0" /> reverses the inequality and picks the non-negative region.

# Answer

All real numbers satisfying the inequality are given below.

<BlockMath math="-2 < x \le 0 \quad \text{or} \quad x = 3" />
