# Diketahui

Persamaan nilai mutlak dengan parameter real <InlineMath math="a" /> diberikan sebagai berikut.

<BlockMath math="\left|x^2 - 4x\right| = a" />

Soal meminta tepat **tiga penyelesaian real yang berbeda** (*genau drei verschiedene reelle Lösungen*).

# Ditanyakan

Tentukan semua nilai real <InlineMath math="a" /> yang membuat persamaan ini memiliki tepat tiga penyelesaian real berbeda.

# Penyelesaian

Banyak penyelesaian <InlineMath math="|x^2 - 4x| = a" /> sama dengan **banyak titik potong kurva <InlineMath math="y = |x^2 - 4x|" /> dengan garis mendatar <InlineMath math="y = a" />**. Tanpa tanda mutlak, parabola <InlineMath math="x^2 - 4x" /> turun hingga lembah di <InlineMath math="(2 \mid -4)" />.

Tanda mutlak melipat lembah di bawah sumbu <InlineMath math="x" /> ke atas seperti kertas yang dilipat, membentuk **bukit dengan puncak tepat di <InlineMath math="(2 \mid 4)" />**.

> Garis mendatar memotong grafik nilai mutlak parabola di tepat tiga titik hanya ketika garis itu menyentuh tepat puncak bukit pantulannya.

Ketika garis digeser naik dari bawah, jumlah titik potong melompat dari <InlineMath math="0" /> menjadi <InlineMath math="2" />, lalu <InlineMath math="4" />, lalu tepat **<InlineMath math="3" /> di puncak bukit <InlineMath math="a = 4" />**, dan turun kembali menjadi <InlineMath math="2" />.

## Menghitung titik potong per daerah

Ringkas seluruh kasus ketinggian garis <InlineMath math="y = a" /> untuk melihat bahwa **hanya puncak bukit yang memberi tiga titik potong**.

| Nilai <InlineMath math="a" /> | Jumlah titik potong |
| :--- | :--- |
| <InlineMath math="a < 0" /> | <InlineMath math="0" /> |
| <InlineMath math="a = 0" /> | <InlineMath math="2" /> |
| <InlineMath math="0 < a < 4" /> | <InlineMath math="4" /> |
| <InlineMath math="a = 4" /> | <InlineMath math="3" /> |
| <InlineMath math="a > 4" /> | <InlineMath math="2" /> |

## Verifikasi aljabar dan pilihan salah

Saat <InlineMath math="a = 4" />, pecah persamaan menjadi dua cabang untuk **memastikan tepat tiga akar berbeda**.

<BlockMath math="\begin{aligned}
-(x^2 - 4x) = 4 &\implies (x - 2)^2 = 0 \implies x = 2 \\
x^2 - 4x = 4 &\implies (x - 2)^2 = 8 \implies x = 2 \pm 2\sqrt{2}
\end{aligned}" />

Ketiga akarnya nyata dan saling berbeda.

- <InlineMath math="a = 0" /> hanya menghasilkan dua akar, yaitu <InlineMath math="x = 0" /> dan <InlineMath math="x = 4" />.
- <InlineMath math="0 < a < 4" /> (termasuk <InlineMath math="a = 2" />) memotong bukit dua kali dan kedua kaki luar dua kali, total empat akar.
- <InlineMath math="a > 4" /> berada di atas puncak bukit sehingga hanya memotong kedua kaki luar (dua akar).
- <InlineMath math="a = -4" /> mustahil karena nilai mutlak tidak pernah negatif.
