# Given

We are given a **nested absolute-value inequality** (*Ungleichung*) for real numbers <InlineMath math="x" />.

<BlockMath math="\left|\,|x - 2| - 3\,\right| < 1" />

# Asked

Find all real numbers <InlineMath math="x" /> that satisfy this inequality.

# Solution

Think of peeling an onion from the outermost layer inward. Set <InlineMath math="u = |x - 2|" />, which measures **the distance from <InlineMath math="x" /> to <InlineMath math="2" />**. The outer inequality demands that <InlineMath math="u" /> stay within distance <InlineMath math="1" /> of <InlineMath math="3" />.

> Peeling nested absolute values from the outside in turns the problem into a clean band of distances around the center of symmetry.

## Peeling both layers of absolute value

Unwrap the **outer absolute value first** using <InlineMath math="u = |x - 2|" />.

<BlockMath math="|u - 3| < 1 \iff -1 < u - 3 < 1 \iff 2 < |x - 2| < 4" />

Split this distance band into two simultaneous conditions: distance from <InlineMath math="2" /> must be less than <InlineMath math="4" /> and greater than <InlineMath math="2" />.

<BlockMath math="\begin{aligned}
|x - 2| < 4 &\iff -2 < x < 6 \\
|x - 2| > 2 &\iff x < 0 \quad \text{or} \quad x > 4
\end{aligned}" />

Their intersection yields two open intervals.

<BlockMath math="-2 < x < 0 \quad \text{or} \quad 4 < x < 6" />

## Test points and wrong choices

Check three sample points to **verify both endpoints and interior regions**.

<BlockMath math="\begin{aligned}
x = -1 &\implies ||{-3}| - 3| = 0 < 1 \quad \text{(valid)} \\
x = 2 &\implies ||0| - 3| = 3 \not< 1 \quad \text{(fails)} \\
x = 0 &\implies ||{-2}| - 3| = 1 \not< 1 \quad \text{(endpoint excluded)}
\end{aligned}" />

- <InlineMath math="4 < x < 6" /> keeps only the right side and forgets the mirror side left of <InlineMath math="2" />.
- The single span from <InlineMath math="-2" /> to <InlineMath math="6" /> drops the outer absolute value and ignores the central peak around <InlineMath math="2" />.
- <InlineMath math="0 < x < 4" /> flips the lower distance bound into distance less than <InlineMath math="2" />.
- <InlineMath math="x < 0" /> or <InlineMath math="x > 4" /> forgets the upper bound of distance less than <InlineMath math="4" />.
- Using <InlineMath math="\le" /> includes the endpoints, where the left-hand side equals <InlineMath math="1" /> rather than being strictly less than <InlineMath math="1" />.

# Answer

All real numbers satisfying this inequality are given below.

<BlockMath math="-2 < x < 0 \quad \text{or} \quad 4 < x < 6" />
