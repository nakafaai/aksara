# Given

The following **quadratic inequality** (*Ungleichung*) with a real parameter <InlineMath math="a" /> must hold for every real number <InlineMath math="x \ge 1" />.

<BlockMath math="x^2 + ax + 4 > 0" />

# Asked

Find all real values of <InlineMath math="a" /> for which this inequality holds for all <InlineMath math="x \ge 1" />.

# Solution

Imagine guarding only the half of the field to the right of <InlineMath math="x = 1" />. The parabola is free to dip below zero outside the field (<InlineMath math="x < 1" />). All that matters is that **its lowest point inside <InlineMath math="x \ge 1" /> stays strictly above zero**.

> To keep a quadratic strictly positive on a half-line, its minimum on that half-line must be positive, whether that minimum occurs at the boundary or at the vertex.

At <InlineMath math="a = 5" />, the vertex at <InlineMath math="x = -2.5" /> dips below zero, yet the entire section inside <InlineMath math="x \ge 1" /> climbs high above zero!

## Two positions for the vertex

The vertex sits at <InlineMath math="-\frac{a}{2}" />. Split into **two cases based on where the vertex lands** relative to <InlineMath math="x = 1" />.

First case: if the vertex lies left of or at the boundary (<InlineMath math="a \ge -2" />), the parabola rises throughout <InlineMath math="x \ge 1" />, putting its minimum at <InlineMath math="x = 1" />.

<BlockMath math="1 + a + 4 > 0 \implies a > -5" />

Every <InlineMath math="a \ge -2" /> already satisfies <InlineMath math="a > -5" />, so all <InlineMath math="a \ge -2" /> work.

Second case: if the vertex sits inside the region (<InlineMath math="a < -2" />), the minimum is the vertex height itself.

<BlockMath math="4 - \frac{a^2}{4} > 0 \iff a^2 < 16 \iff -4 < a < 4" />

Intersected with <InlineMath math="a < -2" />, this gives the interval between <InlineMath math="-4" /> and <InlineMath math="-2" />.

## Combining cases and checking wrong choices

Joining both cases gives **the single interval <InlineMath math="a > -4" />**. Check the boundary <InlineMath math="a = -4" />:

<BlockMath math="x^2 - 4x + 4 = (x - 2)^2 = 0 \quad \text{at } x = 2 \ge 1" />

Because it hits zero at <InlineMath math="x = 2" />, <InlineMath math="a = -4" /> is excluded.

- Restricting <InlineMath math="a" /> between <InlineMath math="-4" /> and <InlineMath math="4" /> checks the entire real line, even though negative roots at <InlineMath math="a = 10" /> never violate <InlineMath math="x \ge 1" />.
- <InlineMath math="a > -5" /> checks only <InlineMath math="x = 1" />, yet at <InlineMath math="a = -4.5" /> the vertex at <InlineMath math="x = 2.25" /> dips below zero.
- <InlineMath math="a \ge -4" /> wrongly includes <InlineMath math="a = -4" />, where the value touches zero at <InlineMath math="x = 2" />.
- <InlineMath math="a \ge -2" /> forgets the case where the vertex lies inside <InlineMath math="x \ge 1" />.
- <InlineMath math="a < 4" /> misplaces the vertex at <InlineMath math="\frac{a}{2}" /> with the wrong sign.

# Answer

The inequality holds for all <InlineMath math="x \ge 1" /> exactly when <InlineMath math="a > -4" />.
