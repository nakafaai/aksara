# Only part of the parabola counts

The left side is an upward parabola with its vertex at <InlineMath math="x=-\frac a2" />. The inequality only has to hold for <InlineMath math="x\ge1" />, so **what matters is the parabola's smallest value on that region**, not on the whole <InlineMath math="x" />-axis. Where the vertex sits decides where that smallest value is.

# Vertex left of the region

If <InlineMath math="-\frac a2\le1" />, that is <InlineMath math="a\ge-2" />, the parabola is already rising on <InlineMath math="x\ge1" />. **Its smallest value is at the end <InlineMath math="x=1" />**:

<BlockMath math="1+a+4>0\quad\Rightarrow\quad a>-5" />

Every <InlineMath math="a\ge-2" /> meets this, so this whole case works.

# Vertex inside the region

If <InlineMath math="a<-2" />, the vertex is at <InlineMath math="x=-\frac a2>1" />. **The smallest value is the value at the vertex**:

<BlockMath math="\begin{aligned}
\left(-\frac a2\right)^2+a\left(-\frac a2\right)+4&>0 \\
4-\frac{a^2}4&>0 \\
-4<a&<4
\end{aligned}" />

Together with <InlineMath math="a<-2" />, this case gives <InlineMath math="-4<a<-2" />.

# Putting both cases together

<InlineMath math="-4<a<-2" /> and <InlineMath math="a\ge-2" /> **join up into <InlineMath math="a>-4" />**.

Check at the edge: for <InlineMath math="a=-4" />, <InlineMath math="x^2-4x+4=(x-2)^2" /> is <InlineMath math="0" /> at <InlineMath math="x=2\ge1" />, so <InlineMath math="a=-4" /> is out.

So the inequality holds for all <InlineMath math="x\ge1" /> exactly when <InlineMath math="a>-4" />.

# Why the other options are wrong

- <InlineMath math="-4<a<4" /> **checks the whole <InlineMath math="x" />-axis** with the discriminant. For <InlineMath math="a=10" />, the parabola does cross the <InlineMath math="x" />-axis, but only at <InlineMath math="x<0" />.
- <InlineMath math="a>-5" /> only checks <InlineMath math="x=1" />. For <InlineMath math="a=-4.5" />, the value at the vertex <InlineMath math="x=2.25" /> is negative.
- <InlineMath math="a\ge-4" /> includes <InlineMath math="a=-4" />, where the left side is zero at <InlineMath math="x=2" />.
- <InlineMath math="a\ge-2" /> only uses the case with the vertex left of the region and drops <InlineMath math="-4<a<-2" />.
- <InlineMath math="a<4" /> puts the vertex at <InlineMath math="x=\frac a2" />, with the wrong sign, so every case comes out mirrored.
