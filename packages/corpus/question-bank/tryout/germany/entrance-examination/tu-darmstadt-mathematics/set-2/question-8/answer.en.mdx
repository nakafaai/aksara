# Given

We are given an **exponential equation** with a real parameter <InlineMath math="a" />.

<BlockMath math="9^x - 6 \cdot 3^x + a = 0" />

The problem asks for **exactly one real solution** (*genau eine reelle Lösung*) for <InlineMath math="x" />.

# Asked

Find all real values of <InlineMath math="a" /> for which this equation has exactly one real solution <InlineMath math="x" />.

# Solution

Substitute <InlineMath math="t = 3^x" /> so that <InlineMath math="9^x = t^2" /> and the equation turns into a quadratic in <InlineMath math="t" />. The crucial hidden rule is that **<InlineMath math="3^x" /> is always strictly positive**, so only roots with <InlineMath math="t > 0" /> produce a real <InlineMath math="x" />.

<BlockMath math="t^2 - 6t + a = 0" />

> Every positive root of the quadratic in t yields exactly one real value of x, whereas zero or negative roots drop out because a power of three can never be zero or negative.

At <InlineMath math="a = 9" />, the vertex kisses the axis at <InlineMath math="t = 3" />. Once <InlineMath math="a \le 0" />, the left root hits zero or turns negative, leaving only one positive root on the right.

## Analyzing every case of a

The roots sum to <InlineMath math="6" />, multiply to <InlineMath math="a" />, and have discriminant <InlineMath math="36 - 4a" />. **Check all five regimes of <InlineMath math="a" /> below**.

| Value of <InlineMath math="a" /> | Roots in <InlineMath math="t" /> | Solutions in <InlineMath math="x" /> |
| :--- | :--- | :--- |
| <InlineMath math="a > 9" /> | no real roots | <InlineMath math="0" /> |
| <InlineMath math="a = 9" /> | double root <InlineMath math="t = 3 > 0" /> | <InlineMath math="1" /> |
| <InlineMath math="0 < a < 9" /> | two distinct positive roots | <InlineMath math="2" /> |
| <InlineMath math="a = 0" /> | <InlineMath math="t = 0" /> rejected, <InlineMath math="t = 6" /> kept | <InlineMath math="1" /> |
| <InlineMath math="a < 0" /> | one positive root, one negative root | <InlineMath math="1" /> |

## Concrete checks and wrong choices

Test <InlineMath math="a = -7" /> and <InlineMath math="a = 0" /> to **confirm that both produce exactly one solution <InlineMath math="x" />**.

<BlockMath math="\begin{aligned}
a = -7 &\implies (t - 7)(t + 1) = 0 \implies t = 7 \implies x = \log_3 7 \\
a = 0 &\implies t(t - 6) = 0 \implies t = 6 \implies x = \log_3 6
\end{aligned}" />

- <InlineMath math="a = 9" /> alone considers only the double root and misses the one-positive-root cases.
- <InlineMath math="a < 0" /> or <InlineMath math="a = 9" /> forgets <InlineMath math="a = 0" />, where <InlineMath math="t = 6" /> still supplies one solution.
- <InlineMath math="a \le 0" /> forgets the double-root case <InlineMath math="a = 9" />.
- <InlineMath math="0 < a < 9" /> gives two distinct real solutions instead of one.
- <InlineMath math="a < 0" /> misses both boundary cases <InlineMath math="a = 0" /> and <InlineMath math="a = 9" />.

# Answer

The equation has exactly one real solution for **<InlineMath math="a \le 0" />** or **<InlineMath math="a = 9" />**.
