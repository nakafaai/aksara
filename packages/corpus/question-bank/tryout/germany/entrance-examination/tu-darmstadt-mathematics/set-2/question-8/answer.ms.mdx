# Diberi

**Persamaan indeks** dengan parameter nyata <InlineMath math="a" /> diberi seperti berikut.

<BlockMath math="9^x - 6 \cdot 3^x + a = 0" />

Soalan meminta tepat **satu penyelesaian nyata** (*genau eine reelle Lösung*) bagi <InlineMath math="x" />.

# Ditanya

Tentukan semua nilai nyata <InlineMath math="a" /> yang menjadikan persamaan ini mempunyai tepat satu penyelesaian nyata <InlineMath math="x" />.

# Penyelesaian

Gantikan <InlineMath math="t = 3^x" /> supaya <InlineMath math="9^x = t^2" /> dan persamaan bertukar menjadi persamaan kuadratik dalam <InlineMath math="t" />. Kuncinya terletak pada sifat indeks: **<InlineMath math="3^x" /> sentiasa positif**, jadi hanya punca <InlineMath math="t > 0" /> yang memberi nilai <InlineMath math="x" />.

<BlockMath math="t^2 - 6t + a = 0" />

> Setiap punca positif bagi persamaan kuadratik dalam t menghasilkan tepat satu nilai x, manakala punca sifar atau negatif terus ditolak kerana kuasa tiga tidak pernah sifar atau negatif.

Pada <InlineMath math="a = 9" />, puncak menyentuh paksi tepat di <InlineMath math="t = 3" />. Apabila <InlineMath math="a \le 0" />, punca kiri jatuh ke sifar atau negatif lalu hanya tinggal satu punca positif di kanan.

## Menganalisis setiap kes nilai a

Hasil tambah kedua-dua punca ialah <InlineMath math="6" />, hasil darabnya <InlineMath math="a" />, dan pembezalayannya <InlineMath math="36 - 4a" />. **Semak kelima-lima kawasan <InlineMath math="a" /> berikut**.

| Nilai <InlineMath math="a" /> | Punca <InlineMath math="t" /> | Bilangan <InlineMath math="x" /> |
| :--- | :--- | :--- |
| <InlineMath math="a > 9" /> | tiada punca nyata | <InlineMath math="0" /> |
| <InlineMath math="a = 9" /> | punca kembar <InlineMath math="t = 3 > 0" /> | <InlineMath math="1" /> |
| <InlineMath math="0 < a < 9" /> | dua punca berbeza, kedua-duanya positif | <InlineMath math="2" /> |
| <InlineMath math="a = 0" /> | <InlineMath math="t = 0" /> ditolak, tinggal <InlineMath math="t = 6" /> | <InlineMath math="1" /> |
| <InlineMath math="a < 0" /> | satu punca positif, satu punca negatif | <InlineMath math="1" /> |

## Semakan contoh dan pilihan salah

Uji <InlineMath math="a = -7" /> dan <InlineMath math="a = 0" /> untuk **mengesahkan kedua-duanya memberi tepat satu nilai <InlineMath math="x" />**.

<BlockMath math="\begin{aligned}
a = -7 &\implies (t - 7)(t + 1) = 0 \implies t = 7 \implies x = \log_3 7 \\
a = 0 &\implies t(t - 6) = 0 \implies t = 6 \implies x = \log_3 6
\end{aligned}" />

- <InlineMath math="a = 9" /> sahaja hanya memikirkan punca kembar dan tertinggal kes satu punca positif dengan satu punca bukan positif.
- <InlineMath math="a < 0" /> atau <InlineMath math="a = 9" /> tertinggal sempadan <InlineMath math="a = 0" />, sedangkan <InlineMath math="t = 6" /> tetap memberi satu nilai <InlineMath math="x" />.
- <InlineMath math="a \le 0" /> tertinggal punca kembar pada <InlineMath math="a = 9" />.
- <InlineMath math="0 < a < 9" /> memberi dua penyelesaian nyata berbeza.
- <InlineMath math="a < 0" /> tertinggal kedua-dua nilai sempadan <InlineMath math="a = 0" /> dan <InlineMath math="a = 9" />.

# Jawapan

Persamaan ini mempunyai tepat satu penyelesaian nyata untuk <InlineMath math="a \le 0" /> atau <InlineMath math="a = 9" />.
