# Diketahui

**Persamaan eksponensial** dengan parameter real <InlineMath math="a" /> diberikan sebagai berikut.

<BlockMath math="9^x - 6 \cdot 3^x + a = 0" />

Syarat soal meminta tepat **satu penyelesaian real** (*genau eine reelle Lösung*) untuk <InlineMath math="x" />.

# Ditanyakan

Tentukan semua nilai real <InlineMath math="a" /> yang membuat persamaan ini memiliki tepat satu penyelesaian real <InlineMath math="x" />.

# Penyelesaian

Ganti <InlineMath math="t = 3^x" /> sehingga <InlineMath math="9^x = t^2" /> dan persamaan berubah menjadi persamaan kuadrat dalam <InlineMath math="t" />. Kuncinya ada pada sifat pangkat: **<InlineMath math="3^x" /> selalu bernilai positif**, jadi hanya akar <InlineMath math="t > 0" /> yang bisa menghasilkan nilai <InlineMath math="x" />.

<BlockMath math="t^2 - 6t + a = 0" />

> Setiap akar positif dari persamaan kuadrat dalam t menghasilkan tepat satu nilai x, sedangkan akar nol atau negatif otomatis gugur karena pangkat tiga tidak pernah nol maupun negatif.

## Menganalisis seluruh kasus nilai a

Jumlah kedua akar adalah <InlineMath math="6" />, hasil kalinya <InlineMath math="a" />, dan diskriminannya <InlineMath math="36 - 4a" />. **Periksa kelima daerah <InlineMath math="a" /> berikut**.

| Nilai <InlineMath math="a" /> | Akar <InlineMath math="t" /> | Banyak <InlineMath math="x" /> |
| :--- | :--- | :--- |
| <InlineMath math="a > 9" /> | tidak ada akar real | <InlineMath math="0" /> |
| <InlineMath math="a = 9" /> | akar kembar <InlineMath math="t = 3 > 0" /> | <InlineMath math="1" /> |
| <InlineMath math="0 < a < 9" /> | dua akar berbeda, keduanya positif | <InlineMath math="2" /> |
| <InlineMath math="a = 0" /> | <InlineMath math="t = 0" /> gugur, tersisa <InlineMath math="t = 6" /> | <InlineMath math="1" /> |
| <InlineMath math="a < 0" /> | satu akar positif, satu akar negatif | <InlineMath math="1" /> |

## Cek contoh dan pilihan salah

Uji <InlineMath math="a = -7" /> dan <InlineMath math="a = 0" /> untuk **mengonfirmasi bahwa keduanya memberi tepat satu solusi <InlineMath math="x" />**.

<BlockMath math="\begin{aligned}
a = -7 &\implies (t - 7)(t + 1) = 0 \implies t = 7 \implies x = \log_3 7 \\
a = 0 &\implies t(t - 6) = 0 \implies t = 6 \implies x = \log_3 6
\end{aligned}" />

- <InlineMath math="a = 9" /> saja hanya memikirkan akar kembar dan melupakan kasus satu akar positif plus satu akar tak positif.
- <InlineMath math="a < 0" /> atau <InlineMath math="a = 9" /> melupakan batas <InlineMath math="a = 0" />, padahal <InlineMath math="t = 6" /> tetap memberi satu nilai <InlineMath math="x" />.
- <InlineMath math="a \le 0" /> melupakan akar kembar di <InlineMath math="a = 9" />.
- <InlineMath math="0 < a < 9" /> justru menghasilkan dua penyelesaian real berbeda.
- <InlineMath math="a < 0" /> kehilangan kedua nilai batas <InlineMath math="a = 0" /> dan <InlineMath math="a = 9" />.

# Jawaban
