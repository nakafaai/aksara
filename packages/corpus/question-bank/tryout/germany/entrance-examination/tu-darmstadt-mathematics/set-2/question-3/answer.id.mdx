# Diketahui

**Pertidaksamaan kuadrat** (*Ungleichung*) dengan parameter real <InlineMath math="a" /> berikut harus berlaku untuk semua bilangan real <InlineMath math="x \ge 1" />.

<BlockMath math="x^2 + ax + 4 > 0" />

# Ditanyakan

Tentukan semua nilai real <InlineMath math="a" /> yang membuat pertidaksamaan ini selalu benar pada seluruh daerah <InlineMath math="x \ge 1" />.

# Penyelesaian

Bayangkan kamu hanya mengawasi setengah lapangan di sebelah kanan garis <InlineMath math="x = 1" />. Parabola boleh turun di bawah nol di luar lapangan (<InlineMath math="x < 1" />), yang penting **titik terendah parabola di dalam daerah <InlineMath math="x \ge 1" /> harus tetap di atas nol**.

> Untuk menjamin fungsi kuadrat selalu positif pada selang setengah tak hingga, cukup pastikan nilai minimumnya di dalam selang itu positif, baik saat puncak berada di dalam maupun di luar selang.

Saat <InlineMath math="a = 5" />, puncak berada di <InlineMath math="x = -2{,}5" /> di bawah nol, tetapi seluruh bagian di daerah <InlineMath math="x \ge 1" /> sudah naik jauh di atas nol!

## Dua letak puncak parabola

Absis puncak parabola berada di <InlineMath math="-\frac{a}{2}" />. Kita bagi menjadi **dua kasus menurut letak puncaknya** terhadap garis <InlineMath math="x = 1" />.

Kasus pertama: jika puncak berada di kiri atau tepat pada batas (<InlineMath math="a \ge -2" />), parabola naik terus pada <InlineMath math="x \ge 1" /> sehingga nilai terkecil ada di <InlineMath math="x = 1" />.

<BlockMath math="1 + a + 4 > 0 \implies a > -5" />

Semua <InlineMath math="a \ge -2" /> otomatis memenuhi <InlineMath math="a > -5" />, jadi seluruh <InlineMath math="a \ge -2" /> sah.

Kasus kedua: jika puncak berada di dalam daerah (<InlineMath math="a < -2" />), nilai terkecil adalah nilai di puncak parabola.

<BlockMath math="4 - \frac{a^2}{4} > 0 \iff a^2 < 16 \iff -4 < a < 4" />

Diiriskan dengan <InlineMath math="a < -2" />, kasus kedua menghasilkan selang di antara <InlineMath math="-4" /> dan <InlineMath math="-2" />.

## Menggabungkan kasus dan mengecek pilihan salah

Gabungan kedua kasus menyambung mulus menjadi **selang tunggal <InlineMath math="a > -4" />**. Cek batas <InlineMath math="a = -4" />:

<BlockMath math="x^2 - 4x + 4 = (x - 2)^2 = 0 \quad \text{di } x = 2 \ge 1" />

Karena menyentuh nol di <InlineMath math="x = 2" />, nilai <InlineMath math="a = -4" /> tidak ikut.

- Selang di antara <InlineMath math="-4" /> dan <InlineMath math="4" /> memeriksa seluruh sumbu <InlineMath math="x" />, padahal untuk <InlineMath math="a = 10" /> akar negatif tidak melanggar <InlineMath math="x \ge 1" />.
- <InlineMath math="a > -5" /> hanya mengecek ujung <InlineMath math="x = 1" />, padahal untuk <InlineMath math="a = -4{,}5" /> puncak di <InlineMath math="x = 2{,}25" /> bernilai negatif.
- <InlineMath math="a \ge -4" /> memasukkan batas <InlineMath math="a = -4" /> yang menyentuh nol di <InlineMath math="x = 2" />.
- <InlineMath math="a \ge -2" /> melupakan kasus puncak di dalam daerah.
- <InlineMath math="a < 4" /> keliru menaruh puncak di <InlineMath math="\frac{a}{2}" /> dengan tanda terbalik.

# Jawaban

Pertidaksamaan ini berlaku untuk semua <InlineMath math="x \ge 1" /> tepat untuk <InlineMath math="a > -4" />.
