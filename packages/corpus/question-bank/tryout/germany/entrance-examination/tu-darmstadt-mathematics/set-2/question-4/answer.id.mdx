# Diketahui

**Pertidaksamaan nilai mutlak bersarang** (*Ungleichung*) untuk bilangan real <InlineMath math="x" /> diberikan sebagai berikut.

<BlockMath math="\left|\,|x - 2| - 3\,\right| < 1" />

# Ditanyakan

Tentukan semua bilangan real <InlineMath math="x" /> yang memenuhi pertidaksamaan ini.

# Penyelesaian

Bayangkan mengupas bawang dari lapisan terluar dulu, bukan membelahnya sembarangan. Anggap <InlineMath math="u = |x - 2|" /> adalah **jarak <InlineMath math="x" /> ke titik <InlineMath math="2" />**. Pertidaksamaan ini meminta jarak <InlineMath math="u" /> ke <InlineMath math="3" /> kurang dari <InlineMath math="1" />.

> Mengupas nilai mutlak bersarang dari luar ke dalam mengubah soal menjadi rentang jarak sederhana di sekitar pusat simetri.

## Mengupas dua lapis nilai mutlak

Kupas **nilai mutlak terluar terlebih dahulu** dengan mengganti <InlineMath math="u = |x - 2|" />.

<BlockMath math="|u - 3| < 1 \iff -1 < u - 3 < 1 \iff 2 < |x - 2| < 4" />

Pecah syarat jarak menjadi dua syarat yang berlaku serentak: jarak ke <InlineMath math="2" /> kurang dari <InlineMath math="4" /> sekaligus lebih dari <InlineMath math="2" />.

<BlockMath math="\begin{aligned}
|x - 2| < 4 &\iff -2 < x < 6 \\
|x - 2| > 2 &\iff x < 0 \quad \text{atau} \quad x > 4
\end{aligned}" />

Irisan keduanya menghasilkan dua selang terbuka terpisah.

<BlockMath math="-2 < x < 0 \quad \text{atau} \quad 4 < x < 6" />

## Pengecekan titik dan pilihan salah

Uji tiga titik wakil untuk **memastikan batas dan interiornya benar**.

<BlockMath math="\begin{aligned}
x = -1 &\implies ||{-3}| - 3| = 0 < 1 \quad \text{(sah)} \\
x = 2 &\implies ||0| - 3| = 3 \not< 1 \quad \text{(gugur)} \\
x = 0 &\implies ||{-2}| - 3| = 1 \not< 1 \quad \text{(ujung tidak ikut)}
\end{aligned}" />

- Pilihan <InlineMath math="4 < x < 6" /> hanya mengambil sisi kanan dan melupakan sisi kiri dari <InlineMath math="2" />.
- Pilihan selang penuh dari <InlineMath math="-2" /> sampai <InlineMath math="6" /> membuang nilai mutlak luar sehingga mengabaikan puncak di sekitar <InlineMath math="2" />.
- Pilihan <InlineMath math="0 < x < 4" /> membalik syarat jarak lebih dari <InlineMath math="2" /> menjadi kurang dari <InlineMath math="2" />.
- Pilihan <InlineMath math="x < 0" /> atau <InlineMath math="x > 4" /> melupakan batas atas jarak kurang dari <InlineMath math="4" />.
- Pilihan bertanda <InlineMath math="\le" /> ikut memasukkan titik ujung tempat nilai ruas kiri tepat sama dengan <InlineMath math="1" />.
