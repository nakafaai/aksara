# Gegeben

Gegeben ist die folgende **Exponentialgleichung** mit einem reellen Parameter <InlineMath math="a" />.

<BlockMath math="9^x - 6 \cdot 3^x + a = 0" />

Die Gleichung soll **genau eine reelle Lösung** <InlineMath math="x" /> besitzen.

# Gesucht

Alle reellen Werte von <InlineMath math="a" />, für die genau eine reelle Lösung <InlineMath math="x" /> existiert.

# Lösung

Setz <InlineMath math="t = 3^x" />, sodass <InlineMath math="9^x = t^2" /> und eine quadratische Gleichung in <InlineMath math="t" /> entsteht. Entscheidend ist die versteckte Bedingung: **<InlineMath math="3^x" /> ist stets strikt positiv**, also liefert nur eine Lösung mit <InlineMath math="t > 0" /> ein reelles <InlineMath math="x" />.

<BlockMath math="t^2 - 6t + a = 0" />

> Jede positive Lösung der quadratischen Gleichung in t ergibt genau ein reelles x, während null oder negative Lösungen wegfallen, weil eine Dreierpotenz nie null oder negativ wird.

## Alle Fälle für a untersuchen

Summe der Lösungen ist <InlineMath math="6" />, ihr Produkt <InlineMath math="a" /> und die Diskriminante <InlineMath math="36 - 4a" />. **Prüf alle fünf Bereiche von <InlineMath math="a" />**.

| Wert von <InlineMath math="a" /> | Lösungen für <InlineMath math="t" /> | Lösungen für <InlineMath math="x" /> |
| :--- | :--- | :--- |
| <InlineMath math="a > 9" /> | keine reelle Lösung | <InlineMath math="0" /> |
| <InlineMath math="a = 9" /> | doppelte Lösung <InlineMath math="t = 3 > 0" /> | <InlineMath math="1" /> |
| <InlineMath math="0 < a < 9" /> | zwei verschiedene positive Lösungen | <InlineMath math="2" /> |
| <InlineMath math="a = 0" /> | <InlineMath math="t = 0" /> entfällt, <InlineMath math="t = 6" /> bleibt | <InlineMath math="1" /> |
| <InlineMath math="a < 0" /> | eine positive, eine negative Lösung | <InlineMath math="1" /> |

## Zahlenprobe und falsche Antworten

Prüf <InlineMath math="a = -7" /> und <InlineMath math="a = 0" />, um **beide Fälle mit genau einer Lösung <InlineMath math="x" /> zu bestätigen**.

<BlockMath math="\begin{aligned}
a = -7 &\implies (t - 7)(t + 1) = 0 \implies t = 7 \implies x = \log_3 7 \\
a = 0 &\implies t(t - 6) = 0 \implies t = 6 \implies x = \log_3 6
\end{aligned}" />

- Nur <InlineMath math="a = 9" /> denkt allein an die doppelte Lösung und vergisst die Fälle mit genau einer positiven Lösung.
- <InlineMath math="a < 0" /> oder <InlineMath math="a = 9" /> übersieht <InlineMath math="a = 0" />, obwohl <InlineMath math="t = 6" /> weiterhin eine Lösung liefert.
- <InlineMath math="a \le 0" /> vergisst die doppelte Lösung bei <InlineMath math="a = 9" />.
- <InlineMath math="0 < a < 9" /> erzeugt zwei verschiedene reelle Lösungen.
- <InlineMath math="a < 0" /> verliert beide Randwerte <InlineMath math="a = 0" /> und <InlineMath math="a = 9" />.

# Antwort

Die Gleichung besitzt genau dann eine reelle Lösung, wenn **<InlineMath math="a \le 0" />** oder **<InlineMath math="a = 9" />** gilt.
