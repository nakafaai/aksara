# A parabola with its vertex on the line

A parabola that is only shifted has the form <InlineMath math="y=(x-h)^2+k" /> with vertex <InlineMath math="S(h\mid k)" />. The vertex is on <InlineMath math="y=2x" />, so <InlineMath math="k=2h" />:

<BlockMath math="y=(x-h)^2+2h" />

You don't know <InlineMath math="h" />. **Keep <InlineMath math="h" /> as a letter and see whether the result depends on it**.

# Where it meets the line

Set the parabola equal to the line <InlineMath math="y=2x" />. **The right side can be written as <InlineMath math="2(x-h)" />**, so only <InlineMath math="x-h" /> appears:

<BlockMath math="\begin{aligned}
(x-h)^2+2h&=2x \\
(x-h)^2&=2(x-h) \\
(x-h)(x-h-2)&=0
\end{aligned}" />

So <InlineMath math="x=h" />, the vertex <InlineMath math="S" />, or <InlineMath math="x=h+2" />, the point <InlineMath math="T(h+2\mid2h+4)" />.

# The length of ST

From <InlineMath math="S(h\mid2h)" /> to <InlineMath math="T(h+2\mid2h+4)" /> you go <InlineMath math="2" /> to the right and <InlineMath math="4" /> up:

<BlockMath math="ST=\sqrt{2^2+4^2}=\sqrt{20}=2\sqrt5" />

**The letter <InlineMath math="h" /> is gone completely**, so the length is the same for every shift. Check with <InlineMath math="h=0" />: <InlineMath math="y=x^2" /> meets <InlineMath math="y=2x" /> at <InlineMath math="(0\mid0)" /> and <InlineMath math="(2\mid4)" />, which are <InlineMath math="\sqrt{20}" /> apart.

So <InlineMath math="ST=2\sqrt5" />.

# Why the other options are wrong

- "Depends on the shift" **gives up before trying it with a letter**. Once you write it with <InlineMath math="h" />, the result is fixed.
- <InlineMath math="\sqrt5" /> takes a horizontal gap of <InlineMath math="1" /> instead of <InlineMath math="2" />.
- <InlineMath math="2" /> takes only the horizontal gap and forgets the climb along the line.
- <InlineMath math="4" /> takes only the vertical gap.
- <InlineMath math="2\sqrt2" /> assumes the climb equals the horizontal gap, but the line has slope <InlineMath math="2" />.
