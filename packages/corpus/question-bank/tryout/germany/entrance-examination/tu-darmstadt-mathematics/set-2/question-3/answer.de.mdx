# Gegeben

Die folgende **quadratische Ungleichung** mit reellem Parameter <InlineMath math="a" /> soll für alle reellen Zahlen <InlineMath math="x \ge 1" /> gelten.

<BlockMath math="x^2 + ax + 4 > 0" />

# Gesucht

Alle reellen Werte von <InlineMath math="a" />, für die diese Ungleichung im gesamten Bereich <InlineMath math="x \ge 1" /> erfüllt ist.

# Lösung

Stell dir vor, du beobachtest nur das halbe Feld rechts von <InlineMath math="x = 1" />. Links davon (<InlineMath math="x < 1" />) darf die Parabel ruhig unter null sinken. Entscheidend ist allein, dass **ihr tiefster Punkt im Bereich <InlineMath math="x \ge 1" /> strikt über null bleibt**.

> Damit eine quadratische Funktion auf einer Halbgeraden positiv bleibt, muss ihr Minimum auf dieser Halbgeraden positiv sein, egal ob es am Rand oder im Scheitelpunkt liegt.

Verschieb den Parameter <InlineMath math="a" /> im Graphen und beobachte, wann die Kurve im gesamten schraffierten Bereich <InlineMath math="x \ge 1" /> über der <InlineMath math="x" />-Achse liegt.

Bei <InlineMath math="a = 5" /> taucht der Scheitel bei <InlineMath math="x = -2{,}5" /> unter null, doch im gesamten Bereich <InlineMath math="x \ge 1" /> verläuft die Kurve deutlich über null.

## Zwei Lagen für den Scheitelpunkt

Der Scheitel liegt bei <InlineMath math="-\frac{a}{2}" />. Unterscheide **zwei Fälle nach der Lage des Scheitels** zur Grenze <InlineMath math="x = 1" />.

Erster Fall: Liegt der Scheitel links von oder auf der Grenze (<InlineMath math="a \ge -2" />), steigt die Parabel auf <InlineMath math="x \ge 1" /> streng, ihr Minimum liegt also bei <InlineMath math="x = 1" />.

<BlockMath math="1 + a + 4 > 0 \implies a > -5" />

Jedes <InlineMath math="a \ge -2" /> erfüllt <InlineMath math="a > -5" /> automatisch, dieser ganze Bereich gilt also.

Zweiter Fall: Liegt der Scheitel im Bereich (<InlineMath math="a < -2" />), ist der Scheitelwert selbst das Minimum.

<BlockMath math="4 - \frac{a^2}{4} > 0 \iff a^2 < 16 \iff -4 < a < 4" />

Zusammen mit <InlineMath math="a < -2" /> liefert dieser Fall den Bereich zwischen <InlineMath math="-4" /> und <InlineMath math="-2" />.

## Fälle vereinen und falsche Antworten prüfen

Beide Fälle schließen nahtlos zu **dem einzigen Bereich <InlineMath math="a > -4" />** zusammen. Grenzprobe für <InlineMath math="a = -4" />:

<BlockMath math="x^2 - 4x + 4 = (x - 2)^2 = 0 \quad \text{bei } x = 2 \ge 1" />

Da der Wert bei <InlineMath math="x = 2" /> null wird, gehört <InlineMath math="a = -4" /> nicht dazu.

- Der Bereich zwischen <InlineMath math="-4" /> und <InlineMath math="4" /> prüft die ganze <InlineMath math="x" />-Achse, obwohl negative Nullstellen für <InlineMath math="a = 10" /> im Bereich <InlineMath math="x \ge 1" /> nicht stören.
- <InlineMath math="a > -5" /> prüft nur <InlineMath math="x = 1" />, doch für <InlineMath math="a = -4{,}5" /> sinkt der Scheitel bei <InlineMath math="x = 2{,}25" /> unter null.
- <InlineMath math="a \ge -4" /> schließt <InlineMath math="a = -4" /> mit ein, wo bei <InlineMath math="x = 2" /> null erreicht wird.
- <InlineMath math="a \ge -2" /> vergisst den Fall mit Scheitel im Bereich <InlineMath math="x \ge 1" />.
- <InlineMath math="a < 4" /> setzt den Scheitel mit falschem Vorzeichen bei <InlineMath math="\frac{a}{2}" /> an.

# Antwort

Die Ungleichung gilt für alle **<InlineMath math="x \ge 1" />** genau dann, wenn **<InlineMath math="a > -4" />** ist.
