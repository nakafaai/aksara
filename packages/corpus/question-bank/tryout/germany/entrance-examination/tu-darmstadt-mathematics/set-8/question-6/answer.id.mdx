# Diketahui

Diberikan fungsi berparameter real <InlineMath math="a" />:

<BlockMath math="f(x) = (a - 1)x^2 + 2ax + a + 2" />

Kita ingin **nilai fungsi selalu positif ketat**, yaitu <InlineMath math="f(x) > 0" /> untuk setiap bilangan real <InlineMath math="x" />.

# Ditanyakan

Untuk nilai <InlineMath math="a" /> mana sajakah <InlineMath math="f(x) > 0" /> berlaku bagi semua <InlineMath math="x \in \mathbb{R}" />?

# Penyelesaian

Bayangkan kurva fungsi ini melayang di atas lantai datar (sumbu <InlineMath math="x" />). Supaya kurva tidak pernah menyentuh apalagi menembus ke bawah lantai, perlu **dua syarat sekaligus**: kurva harus parabola terbuka ke atas, dan dasar mangkuknya harus tetap melayang di atas nol tanpa menyentuh lantai.

> Sebuah fungsi kuadrat selalu positif ketat untuk semua bilangan real tepat saat koefisien kuadratnya positif dan diskriminannya negatif ketat.

## Memeriksa kasus linear khusus

Uji dulu kasus saat suku <InlineMath math="x^2" /> lenyap, yaitu <InlineMath math="a = 1" />. Fungsi berubah menjadi **garis miring** <InlineMath math="f(x) = 2x + 3" />. Garis miring selalu menembus sumbu <InlineMath math="x" /> (misalnya <InlineMath math="f(-2) = -1" />, bernilai negatif), jadi <InlineMath math="a = 1" /> gugur.

## Mengunci bukaan parabola dan diskriminan

Untuk <InlineMath math="a \ne 1" />, grafiknya adalah parabola. Agar seluruhnya melayang di atas sumbu <InlineMath math="x" />, kita wajibkan **terbuka ke atas dan tidak memiliki pembuat nol**:

<BlockMath math="\begin{aligned}
a - 1 > 0 &\quad \Longrightarrow \quad a > 1 \\
D = (2a)^2 - 4(a - 1)(a + 2) &= 4a^2 - 4(a^2 + a - 2) = -4a + 8 < 0 \quad \Longrightarrow \quad a > 2
\end{aligned}" />

Irisan dari <InlineMath math="a > 1" /> dan <InlineMath math="a > 2" /> adalah tepat <InlineMath math="a > 2" />.

## Mengecek pilihan salah

Perhatikan syarat mana yang dilanggar **setiap pilihan pengecoh**:

| Pilihan | Mengapa salah |
| --- | --- |
| <InlineMath math="a > 1" /> | Hanya memeriksa bukaan ke atas, padahal pada <InlineMath math="a = 1{,}5" />, <InlineMath math="D = 2 > 0" /> sehingga parabola menembus sumbu <InlineMath math="x" />. |
| <InlineMath math="a \ge 2" /> | Ikut memasukkan <InlineMath math="a = 2" />, tempat grafik menyentuh nol di <InlineMath math="x = -2" />. |
| <InlineMath math="1 < a < 2" /> | Membalik tanda diskriminan menjadi <InlineMath math="D > 0" />. |
| <InlineMath math="a = 1" /> atau <InlineMath math="a > 2" /> | Melupakan bahwa garis lurus <InlineMath math="2x + 3" /> pada <InlineMath math="a = 1" /> mencapai nilai negatif. |
| <InlineMath math="a < 2" /> | Salah arah pada syarat diskriminan sekaligus mengabaikan bukaan ke atas. |
