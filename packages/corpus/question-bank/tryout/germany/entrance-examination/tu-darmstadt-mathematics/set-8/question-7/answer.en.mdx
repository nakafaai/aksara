# What <InlineMath math="f^{-1}(12)" /> means

<InlineMath math="f^{-1}(12)" /> is the number <InlineMath math="x" /> in the range considered for which **<InlineMath math="f(x)=12" /> holds**. So you don't have to write down the inverse function, just solve an equation:

<BlockMath math="\begin{aligned}
x^2-6x+5&=12 \\
(x-3)^2-9+5&=12 \\
(x-3)^2&=16
\end{aligned}" />

So <InlineMath math="x-3=4" /> or <InlineMath math="x-3=-4" />, that is <InlineMath math="x=7" /> or <InlineMath math="x=-1" />.

# The range picks the solution

The function is only considered for <InlineMath math="x\ge3" />. Only there is it invertible, because **every function value occurs exactly once there**. Of the two solutions only <InlineMath math="x=7" /> lies in that range:

# Why the other answers are wrong

- <InlineMath math="-1" /> solves <InlineMath math="f(x)=12" /> on the **left branch**, which isn't in the range considered.
- <InlineMath math="7" /> or <InlineMath math="-1" /> overlooks that an inverse function assigns exactly one number to each value.
- <InlineMath math="77" /> is <InlineMath math="f(12)=144-72+5" />, the function value instead of the preimage.
- <InlineMath math="\frac1{77}" /> confuses <InlineMath math="f^{-1}" /> with the reciprocal <InlineMath math="\frac{1}{f(12)}" />.
- <InlineMath math="3+\sqrt{12}" /> forgets the numbers <InlineMath math="-9+5" /> when completing the square: from <InlineMath math="(x-3)^2=12" /> instead of <InlineMath math="(x-3)^2=16" />.
