# Given

The quadratic function <InlineMath math="f" /> is defined by:

<BlockMath math="f(x) = x^2 - 6x + 5" />

Its domain is restricted to **only the right branch <InlineMath math="x \ge 3" />**, on which it has an inverse function (*Umkehrfunktion*) <InlineMath math="f^{-1}" />.

# Asked

What is the value of <InlineMath math="f^{-1}(12)" />?

# Solution

An inverse function simply runs the machine in reverse: instead of plugging in <InlineMath math="12" />, you ask **which input <InlineMath math="x" /> produces the output <InlineMath math="12" />**. You do not even need the general formula for <InlineMath math="f^{-1}(y)" />. Just solve <InlineMath math="f(x) = 12" /> and keep the unique root inside the allowed domain <InlineMath math="x \ge 3" />.

> To evaluate an inverse function at a single number, solve the reverse equation and select the one root inside the restricted domain.

## Solving the reverse equation by completing the square

Set <InlineMath math="f(x) = 12" /> and **complete the square** to isolate <InlineMath math="x" /> cleanly:

<BlockMath math="\begin{aligned}
x^2 - 6x + 5 &= 12 \\
(x - 3)^2 - 9 + 5 &= 12 \\
(x - 3)^2 &= 16
\end{aligned}" />

Taking square roots gives <InlineMath math="x - 3 = 4" /> or <InlineMath math="x - 3 = -4" />, yielding two candidates: <InlineMath math="x = 7" /> and <InlineMath math="x = -1" />.

## Selecting the valid branch on the graph

This parabola has its vertex at <InlineMath math="(3 \mid -4)" />. Because the domain keeps **only <InlineMath math="x \ge 3" />**, the left branch is excluded and only <InlineMath math="x = 7" /> survives.

# Answer

The value of <InlineMath math="f^{-1}(12)" /> is **<InlineMath math="7" />**.
