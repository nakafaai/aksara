# Given

We are given an **exponential inequality** (*Ungleichung*) whose bases are both fractions below one:

<BlockMath math="\left(\frac{1}{3}\right)^{x^2 - 8} \le \left(\frac{1}{9}\right)^x" />

# Asked

Determine all real numbers <InlineMath math="x" /> that satisfy this inequality.

# Solution

If you keep cutting a cake into thirds over and over, more cuts (a larger exponent) leave a smaller piece. With base <InlineMath math="\frac{1}{3}" />, **a larger exponent produces a smaller value**. Once both sides share base <InlineMath math="\frac{1}{3}" />, dropping the base must **reverse the inequality sign**.

> When comparing powers with the same base between zero and one, the exponents always stand in the opposite inequality order from the powers themselves.

## Matching the base on both sides

Rewrite <InlineMath math="\frac{1}{9}" /> as the square of <InlineMath math="\frac{1}{3}" /> so both sides share **the same base <InlineMath math="\frac{1}{3}" />**:

<BlockMath math="\left(\frac{1}{9}\right)^x = \left(\left(\frac{1}{3}\right)^2\right)^x = \left(\frac{1}{3}\right)^{2x} \quad \Longrightarrow \quad \left(\frac{1}{3}\right)^{x^2 - 8} \le \left(\frac{1}{3}\right)^{2x}" />

## Reversing the inequality on the exponents

Since the exponential function with base <InlineMath math="\frac{1}{3}" /> is strictly decreasing, **<InlineMath math="\le" /> flips to <InlineMath math="\ge" />** when moving to the exponents:

<BlockMath math="\begin{aligned}
x^2 - 8 &\ge 2x \\
x^2 - 2x - 8 &\ge 0 \\
(x - 4)(x + 2) &\ge 0
\end{aligned}" />

## Reading the nonnegative intervals from the parabola

The upward-opening parabola <InlineMath math="x^2 - 2x - 8" /> crosses zero at <InlineMath math="-2" /> and <InlineMath math="4" />, so it stays **nonnegative on its two outer wings**.

Quick check at <InlineMath math="x = 0" />: the left side is <InlineMath math="3^8" /> and the right side is <InlineMath math="1" />. Since <InlineMath math="3^8 \le 1" /> is false, the middle interval is excluded, confirming the two outer wings.

## Checking the distractors

Notice how each wrong choice **forgets to flip the sign or mishandles the exponent**:

| Option | Why it is wrong |
| --- | --- |
| <InlineMath math="-2 \le x \le 4" /> | Fails to reverse the inequality sign, as if the base were greater than <InlineMath math="1" />. |
| <InlineMath math="x \le -4" /> or <InlineMath math="x \ge 2" /> | Rewrites <InlineMath math="\left(\frac{1}{9}\right)^x" /> wrongly as <InlineMath math="\left(\frac{1}{3}\right)^{-2x}" />. |
| <InlineMath math="-4 \le x \le 2" /> | Makes both mistakes at once: wrong exponent sign and unflipped inequality. |
| <InlineMath math="x \ge 4" /> | Drops the entire left branch <InlineMath math="x \le -2" />. |
| <InlineMath math="x \le -2\sqrt{2}" /> or <InlineMath math="x \ge 2\sqrt{2}" /> | Solves only <InlineMath math="x^2 - 8 \ge 0" /> while ignoring the right-hand <InlineMath math="2x" />. |

# Answer

All real numbers <InlineMath math="x" /> satisfying the inequality are:

<BlockMath math="x \le -2 \qquad \text{or} \qquad x \ge 4" />
