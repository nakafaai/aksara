# Given

We are given a family of functions with real parameter <InlineMath math="a" />:

<BlockMath math="f(x) = (a - 1)x^2 + 2ax + a + 2" />

We require **strict positivity everywhere**: <InlineMath math="f(x) > 0" /> for every real number <InlineMath math="x" />.

# Asked

For which values of <InlineMath math="a" /> does <InlineMath math="f(x) > 0" /> hold for all <InlineMath math="x \in \mathbb{R}" />?

# Solution

Picture the graph hovering above a flat floor (the <InlineMath math="x" />-axis). To stay strictly above the floor for every <InlineMath math="x" />, the graph must clear **two checks at once**: it must be an upward-opening parabola, and its lowest point must stay above zero without even grazing the floor.

> A quadratic is strictly positive for all real numbers exactly when its leading coefficient is positive and its discriminant is strictly negative.

## Checking the special linear case

First test the value where the <InlineMath math="x^2" /> term vanishes, <InlineMath math="a = 1" />. The function collapses to a **slanted line** <InlineMath math="f(x) = 2x + 3" />. Any slanted line crosses below zero (for example, <InlineMath math="f(-2) = -1" />, which is negative), so <InlineMath math="a = 1" /> fails.

## Locking in the opening direction and discriminant

For <InlineMath math="a \ne 1" />, the graph is a parabola. To float strictly above the <InlineMath math="x" />-axis, it must **open upward and have no real roots**:

<BlockMath math="\begin{aligned}
a - 1 > 0 &\quad \Longrightarrow \quad a > 1 \\
D = (2a)^2 - 4(a - 1)(a + 2) &= 4a^2 - 4(a^2 + a - 2) = -4a + 8 < 0 \quad \Longrightarrow \quad a > 2
\end{aligned}" />

Intersecting <InlineMath math="a > 1" /> and <InlineMath math="a > 2" /> gives exactly <InlineMath math="a > 2" />.

## Inspecting the boundary case on the graph

Compare <InlineMath math="a = 3" /> (safely floating) with **the boundary case <InlineMath math="a = 2" />**, which grazes the floor at <InlineMath math="(-2 \mid 0)" />.

At <InlineMath math="a = 2" />, <InlineMath math="f(-2) = 0" /> violates <InlineMath math="f(x) > 0" />, so the boundary <InlineMath math="2" /> must stay excluded.

## Checking the distractors

See which condition fails in **each wrong option**:

| Option | Why it is wrong |
| --- | --- |
| <InlineMath math="a > 1" /> | Checks only the upward opening, yet at <InlineMath math="a = 1.5" />, <InlineMath math="D = 2 > 0" /> so the parabola dips below the axis. |
| <InlineMath math="a \ge 2" /> | Includes <InlineMath math="a = 2" />, where the graph hits zero at <InlineMath math="x = -2" />. |
| <InlineMath math="1 < a < 2" /> | Flips the discriminant requirement to <InlineMath math="D > 0" />. |
| <InlineMath math="a = 1" /> or <InlineMath math="a > 2" /> | Misses that the line <InlineMath math="2x + 3" /> at <InlineMath math="a = 1" /> takes negative values. |
| <InlineMath math="a < 2" /> | Reverses the discriminant inequality and ignores the upward-opening condition. |

# Answer

The required condition is **<InlineMath math="a > 2" />**.
