# Given

We are given a **fractional equation** (*Bruchgleichung*) over the real numbers.

<BlockMath math="\frac{2x + 3}{x + 4} = \frac{20}{x^2 + 4x}" />

# Asked

Find the real solution set (*Lösungsmenge*) <InlineMath math="L" /> of this equation.

# Solution

Clearing denominators by multiplying both sides feels like opening a locked door with a master key, yet it can sneak in an uninvited guest. Before doing any algebra, **post a do-not-enter sign at every value that makes a denominator zero**.

> In a fractional equation, the domain always comes from the original equation, so any candidate root that zeroes an original denominator must be rejected even if it works after clearing fractions.

Factor the right denominator as <InlineMath math="x(x + 4)" />. Neither denominator may vanish, so <InlineMath math="x \neq 0" /> and <InlineMath math="x \neq -4" />.

## Clearing denominators and factoring

Multiply both sides by the common denominator <InlineMath math="x(x + 4)" /> to obtain **a clean quadratic equation**.

<BlockMath math="\begin{aligned}
x(2x + 3) &= 20 \\
2x^2 + 3x - 20 &= 0 \\
(2x - 5)(x + 4) &= 0
\end{aligned}" />

Factoring yields two candidates, <InlineMath math="\frac{5}{2}" /> and <InlineMath math="-4" />. Watch on the cleared quadratic graph how one root lands directly on a forbidden vertical line.

## Checking the solution and wrong choices

Substitute <InlineMath math="\frac{5}{2}" /> back into **both sides of the original equation** to confirm equality.

<BlockMath math="\text{Left: } \frac{2\left(\frac{5}{2}\right) + 3}{\frac{5}{2} + 4} = \frac{8}{\frac{13}{2}} = \frac{16}{13}, \qquad \text{Right: } \frac{20}{\frac{25}{4} + 10} = \frac{20}{\frac{65}{4}} = \frac{16}{13}" />

- <InlineMath math="L = \{-4\}" /> keeps the extraneous root that breaks the denominator and throws away the valid one.
- <InlineMath math="L = \{4\}" /> comes from swapping signs in the factorization and keeping only the positive number.
- <InlineMath math="L = \{-\tfrac{5}{2},\, 4\}" /> solves the flipped quadratic <InlineMath math="2x^2 - 3x - 20" /> after reversing the sign of the linear term.
- <InlineMath math="L = \{\tfrac{5}{2},\, -4\}" /> forgets the domain restriction and keeps the undefined value <InlineMath math="-4" />.
- <InlineMath math="L = \emptyset" /> wrongly discards <InlineMath math="\frac{5}{2}" /> even though no denominator vanishes there.

# Answer

The solution set is **<InlineMath math="L = \{\tfrac{5}{2}\}" />**.
