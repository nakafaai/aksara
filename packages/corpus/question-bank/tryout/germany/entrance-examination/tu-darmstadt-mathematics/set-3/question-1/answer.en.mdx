# Given

We are asked to simplify the following **nested-radical expression** (*verschachtelte Wurzeln*) without a calculator.

<BlockMath math="\frac{\sqrt{9 + 4\sqrt{5}} - \sqrt{9 - 4\sqrt{5}}}{\sqrt{6 - 2\sqrt{5}}}" />

# Asked

Compute the exact value of this radical fraction.

# Solution

A square root nested inside another root works like a set of nesting dolls: whenever the inside hides **a perfect square of the form <InlineMath math="(p \pm q)^2" />**, the outer roof peels straight off. The one golden rule is that a square root never outputs a negative number.

> When peeling a square root off a perfect square, always apply absolute value and choose the positive difference, because a principal square root can never be negative.

Rewrite all three radicands as perfect squares using the pattern <InlineMath math="p^2 + q^2 \pm 2pq" />.

<BlockMath math="\begin{aligned}
9 + 4\sqrt{5} &= 5 + 4 + 2 \cdot 2\sqrt{5} = \left(\sqrt{5} + 2\right)^2 \\
9 - 4\sqrt{5} &= 5 + 4 - 2 \cdot 2\sqrt{5} = \left(\sqrt{5} - 2\right)^2 \\
6 - 2\sqrt{5} &= 5 + 1 - 2\sqrt{5} = \left(\sqrt{5} - 1\right)^2
\end{aligned}" />

Because <InlineMath math="\sqrt{5}" /> exceeds <InlineMath math="2" />, we pick the positive branch for all three roots.

<BlockMath math="\sqrt{9 + 4\sqrt{5}} = \sqrt{5} + 2, \qquad \sqrt{9 - 4\sqrt{5}} = \sqrt{5} - 2, \qquad \sqrt{6 - 2\sqrt{5}} = \sqrt{5} - 1" />

## Simplifying the fraction and checking wrong choices

In the numerator, **the two <InlineMath math="\sqrt{5}" /> terms cancel cleanly**, and then we rationalize the denominator using a difference of squares.

<BlockMath math="\frac{(\sqrt{5} + 2) - (\sqrt{5} - 2)}{\sqrt{5} - 1} = \frac{4}{\sqrt{5} - 1} = \frac{4(\sqrt{5} + 1)}{(\sqrt{5} - 1)(\sqrt{5} + 1)} = \frac{4(\sqrt{5} + 1)}{5 - 1} = \sqrt{5} + 1" />

Decimal sanity check using <InlineMath math="\sqrt{5}" /> near <InlineMath math="2.236" />:

<BlockMath math="\frac{4.236 - 0.236}{1.236} = \frac{4}{1.236} \approx 3.236 \approx \sqrt{5} + 1" />

| Option | Why it is wrong |
| :--- | :--- |
| <InlineMath math="-\sqrt{5} - 1" /> | Takes the negative value <InlineMath math="1 - \sqrt{5}" /> for the denominator root. |
| <InlineMath math="\frac{5 + \sqrt{5}}{2}" /> | Writes <InlineMath math="\sqrt{9 - 4\sqrt{5}}" /> as <InlineMath math="2 - \sqrt{5}" />, turning the numerator into <InlineMath math="2\sqrt{5}" />. |
| <InlineMath math="-\frac{5 + \sqrt{5}}{2}" /> | Makes both sign mistakes at the same time. |
| <InlineMath math="\sqrt{5} - 1" /> | Mistakenly expands <InlineMath math="(\sqrt{5} - 1)^2" /> as <InlineMath math="5 - 1 = 4" /> and cancels directly. |
| <InlineMath math="\frac{2\sqrt{5} + 2}{3}" /> | Evaluates the conjugate product <InlineMath math="(\sqrt{5} - 1)(\sqrt{5} + 1)" /> as <InlineMath math="6" /> instead of <InlineMath math="4" />. |

# Answer

The exact value of the expression is <InlineMath math="\sqrt{5} + 1" />.
