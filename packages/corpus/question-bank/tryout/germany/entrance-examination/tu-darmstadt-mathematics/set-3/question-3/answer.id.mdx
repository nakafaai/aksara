# Diketahui

**Persamaan logaritma** (*Logarithmusgleichung*) berbasis dua dalam bilangan real diberikan sebagai berikut.

<BlockMath math="2\log_2 x - \log_2(x + 3) = 2" />

# Ditanyakan

Tentukan himpunan penyelesaian (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> dalam himpunan bilangan real.

# Penyelesaian

Menguadratkan sebuah bilangan menghapus tanda minusnya secara diam-diam. Begitu kita menaikkan angka <InlineMath math="2" /> menjadi pangkat pada <InlineMath math="\log_2(x^2)" />, pintu tiba-tiba terbuka bagi <InlineMath math="x" /> negatif, padahal **persamaan asli menuntut setiap argumen logaritma bernilai positif**.

> Daerah asal persamaan logaritma selalu dikunci dari bentuk awalnya sebelum aturan logaritma diterapkan, sehingga setiap akar yang melanggar syarat positif wajib dibuang.

Dari <InlineMath math="\log_2 x" /> dan <InlineMath math="\log_2(x + 3)" />, syarat serentak <InlineMath math="x > 0" /> dan <InlineMath math="x + 3 > 0" /> langsung menyusut menjadi <InlineMath math="x > 0" />.

## Menggabungkan logaritma dan mencari calon akar

Gunakan sifat pangkat dan selisih logaritma untuk menyatukan ruas kiri menjadi **satu logaritma tunggal**, lalu ubah ke bentuk pangkat dua.

<BlockMath math="\begin{aligned}
\log_2\left(\frac{x^2}{x + 3}\right) &= 2 \\
\frac{x^2}{x + 3} &= 2^2 = 4 \\
x^2 - 4x - 12 &= 0 \\
(x - 6)(x + 2) &= 0
\end{aligned}" />

Muncul dua calon, yaitu <InlineMath math="x = 6" /> dan <InlineMath math="x = -2" />. Lihat grafik berikut untuk melihat mengapa bentuk ubahan punya perpotongan hantu di sisi negatif.

## Menguji solusi dan pilihan salah

Masukkan <InlineMath math="x = 6" /> ke **persamaan logaritma asli** untuk memastikan hasilnya tepat dua.

<BlockMath math="2\log_2 6 - \log_2 9 = \log_2 36 - \log_2 9 = \log_2 4 = 2" />

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="\mathbb{L} = \{-2;\, 6\}" /> | Mempertahankan <InlineMath math="x = -2" />, padahal <InlineMath math="\log_2(-2)" /> tidak terdefinisi. |
| <InlineMath math="\mathbb{L} = \{-2\}" /> | Membuang akar yang sah dan justru menyimpan akar palsu. |
| <InlineMath math="\mathbb{L} = \{\}" /> | Membaca <InlineMath math="2\log_2 x" /> sebagai <InlineMath math="\log_2(2x)" /> lalu mendapat <InlineMath math="x = -6" /> yang gugur. |
| <InlineMath math="\mathbb{L} = \left\{\frac{1 + \sqrt{29}}{2}\right\}" /> | Mengubah selisih logaritma menjadi logaritma dari selisih <InlineMath math="x^2 - (x + 3)" />. |
| <InlineMath math="\mathbb{L} = \{1 + \sqrt{7}\}" /> | Menyamakan hasil logaritma dengan <InlineMath math="2" />, bukan <InlineMath math="2^2 = 4" />. |

# Jawaban

Himpunan penyelesaian persamaan ini adalah **<InlineMath math="\mathbb{L} = \{6\}" />**.
