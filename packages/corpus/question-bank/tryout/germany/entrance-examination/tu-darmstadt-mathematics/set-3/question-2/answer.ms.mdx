# Diberi

**Persamaan pecahan** (*Bruchgleichung*) dalam set nombor nyata diberi seperti berikut.

<BlockMath math="\frac{2x + 3}{x + 4} = \frac{20}{x^2 + 4x}" />

# Ditanya

Tentukan set penyelesaian (*Lösungsmenge*) <InlineMath math="L" /> bagi persamaan ini dalam nombor nyata.

# Penyelesaian

Mendarab kedua-dua belah persamaan pecahan dengan penyebut sepunya ibarat membuka pintu dengan kunci induk, tetapi berisiko membawa masuk tetamu palsu. Sebelum mula mengira, kita mesti **menandakan setiap nilai terlarang yang menjadikan penyebut sifar**.

> Bagi persamaan pecahan, domain sentiasa ditentukan oleh persamaan asal, maka sebarang calon punca yang menjadikan penyebut asal sifar mesti ditolak walaupun sah selepas pecahan dihapuskan.

Faktorkan penyebut kanan menjadi <InlineMath math="x(x + 4)" />. Penyebut tidak boleh sifar, jadi <InlineMath math="x \neq 0" /> dan <InlineMath math="x \neq -4" />.

## Menghapuskan penyebut dan memfaktorkan

Darabkan kedua-dua belah dengan penyebut sepunya <InlineMath math="x(x + 4)" /> untuk mendapat **persamaan kuadratik yang ringkas**.

<BlockMath math="\begin{aligned}
x(2x + 3) &= 20 \\
2x^2 + 3x - 20 &= 0 \\
(2x - 5)(x + 4) &= 0
\end{aligned}" />

Pemfaktoran menghasilkan dua calon, iaitu <InlineMath math="\frac{5}{2}" /> dan <InlineMath math="-4" />. Perhatikan pada graf polinomial berikut bagaimana satu punca jatuh tepat di atas garis terlarang.

## Menyemak penyelesaian dan pilihan salah

Gantikan <InlineMath math="\frac{5}{2}" /> ke dalam **kedua-dua belah persamaan asal** untuk mengesahkan kesamaannya.

<BlockMath math="\text{Kiri: } \frac{2\left(\frac{5}{2}\right) + 3}{\frac{5}{2} + 4} = \frac{8}{\frac{13}{2}} = \frac{16}{13}, \qquad \text{Kanan: } \frac{20}{\frac{25}{4} + 10} = \frac{20}{\frac{65}{4}} = \frac{16}{13}" />

- <InlineMath math="L = \{-4\}" /> mengekalkan punca palsu yang menjadikan penyebut sifar dan membuang punca sah.
- <InlineMath math="L = \{4\}" /> terhasil apabila tanda faktor tertukar lalu hanya nilai positif diambil.
- <InlineMath math="L = \{-\tfrac{5}{2},\, 4\}" /> berpunca daripada polinomial <InlineMath math="2x^2 - 3x - 20" /> akibat tanda sebutan linear tertukar.
- <InlineMath math="L = \{\tfrac{5}{2},\, -4\}" /> terlupa menyemak domain sehingga nilai terlarang <InlineMath math="-4" /> dikekalkan.
- <InlineMath math="L = \emptyset" /> turut membuang <InlineMath math="\frac{5}{2}" />, padahal tiada penyebut yang menjadi sifar di situ.

# Jawapan

Set penyelesaian bagi persamaan ini ialah **<InlineMath math="L = \{\tfrac{5}{2}\}" />**.
