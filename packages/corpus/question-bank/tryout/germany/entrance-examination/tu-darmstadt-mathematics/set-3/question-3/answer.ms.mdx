# Diberi

**Persamaan logaritma** (*Logarithmusgleichung*) asas dua dalam set nombor nyata diberi seperti berikut.

<BlockMath math="2\log_2 x - \log_2(x + 3) = 2" />

# Ditanya

Tentukan set penyelesaian (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> dalam nombor nyata.

# Penyelesaian

Mengkuasaduakan suatu nombor memadamkan tanda negatifnya secara senyap. Sebaik sahaja pekali <InlineMath math="2" /> dinaikkan menjadi indeks pada <InlineMath math="\log_2(x^2)" />, nilai negatif <InlineMath math="x" /> tiba-tiba lepas masuk walaupun **persamaan asal menuntut setiap argumen logaritma bernilai positif**.

> Domain bagi persamaan logaritma sentiasa ditetapkan daripada bentuk asal sebelum hukum logaritma digunakan, maka sebarang calon punca yang melanggar syarat positif mesti ditolak.

Daripada <InlineMath math="\log_2 x" /> dan <InlineMath math="\log_2(x + 3)" />, syarat serentak <InlineMath math="x > 0" /> dan <InlineMath math="x + 3 > 0" /> diringkaskan menjadi <InlineMath math="x > 0" />.

## Menggabungkan logaritma dan mencari calon punca

Gunakan hukum kuasa dan hasil bahagi logaritma untuk menyatukan sebelah kiri menjadi **satu logaritma tunggal**, lalu tukar kepada bentuk indeks.

<BlockMath math="\begin{aligned}
\log_2\left(\frac{x^2}{x + 3}\right) &= 2 \\
\frac{x^2}{x + 3} &= 2^2 = 4 \\
x^2 - 4x - 12 &= 0 \\
(x - 6)(x + 2) &= 0
\end{aligned}" />

Terhasil dua calon, iaitu <InlineMath math="x = 6" /> dan <InlineMath math="x = -2" />. Lihat graf berikut untuk memahami mengapa bentuk gubahan menghasilkan pintasan palsu di sebelah negatif.

## Menyemak penyelesaian dan pilihan salah

Gantikan <InlineMath math="x = 6" /> ke dalam **persamaan logaritma asal** untuk mengesahkan nilainya tepat dua.

<BlockMath math="2\log_2 6 - \log_2 9 = \log_2 36 - \log_2 9 = \log_2 4 = 2" />

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="\mathbb{L} = \{-2;\, 6\}" /> | Mengekalkan <InlineMath math="x = -2" />, sedangkan <InlineMath math="\log_2(-2)" /> tidak tertakrif. |
| <InlineMath math="\mathbb{L} = \{-2\}" /> | Membuang punca sah dan menyimpan punca palsu. |
| <InlineMath math="\mathbb{L} = \{\}" /> | Membaca <InlineMath math="2\log_2 x" /> sebagai <InlineMath math="\log_2(2x)" /> lalu mendapat <InlineMath math="x = -6" /> yang ditolak. |
| <InlineMath math="\mathbb{L} = \left\{\frac{1 + \sqrt{29}}{2}\right\}" /> | Menukar beza logaritma menjadi logaritma bagi beza <InlineMath math="x^2 - (x + 3)" />. |
| <InlineMath math="\mathbb{L} = \{1 + \sqrt{7}\}" /> | Menyamakan nisbah dengan <InlineMath math="2" />, bukannya <InlineMath math="2^2 = 4" />. |

# Jawapan

Set penyelesaian persamaan ini ialah **<InlineMath math="\mathbb{L} = \{6\}" />**.
