# Given

We are given a base-two **logarithmic equation** (*Logarithmusgleichung*) over the real numbers.

<BlockMath math="2\log_2 x - \log_2(x + 3) = 2" />

# Asked

Find the real solution set (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> of this equation.

# Solution

Squaring a number quietly erases its minus sign. The moment you lift the factor <InlineMath math="2" /> into the exponent to write <InlineMath math="\log_2(x^2)" />, negative values of <InlineMath math="x" /> sneak past the gate even though **the original equation requires every logarithm input to be positive**.

> Always lock in the domain from the original logarithmic equation before applying log laws, because squaring inside a logarithm widens the domain and can introduce fake roots.

From <InlineMath math="\log_2 x" /> and <InlineMath math="\log_2(x + 3)" />, requiring both <InlineMath math="x > 0" /> and <InlineMath math="x + 3 > 0" /> reduces to <InlineMath math="x > 0" />.

## Combining the logarithms and solving for candidates

Use the power and quotient laws to collapse the left side into **one single logarithm**, then convert to exponential form.

<BlockMath math="\begin{aligned}
\log_2\left(\frac{x^2}{x + 3}\right) &= 2 \\
\frac{x^2}{x + 3} &= 2^2 = 4 \\
x^2 - 4x - 12 &= 0 \\
(x - 6)(x + 2) &= 0
\end{aligned}" />

This produces two candidates, <InlineMath math="x = 6" /> and <InlineMath math="x = -2" />. Watch on the graph how the rewritten expression invents a phantom crossing on the negative side.

## Checking the solution and wrong choices

Substitute <InlineMath math="x = 6" /> into **the original logarithmic equation** to confirm that it equals two.

<BlockMath math="2\log_2 6 - \log_2 9 = \log_2 36 - \log_2 9 = \log_2 4 = 2" />

| Option | Why it is wrong |
| :--- | :--- |
| <InlineMath math="\mathbb{L} = \{-2;\, 6\}" /> | Keeps <InlineMath math="x = -2" />, where <InlineMath math="\log_2(-2)" /> does not exist. |
| <InlineMath math="\mathbb{L} = \{-2\}" /> | Throws away the valid root and keeps only the extraneous one. |
| <InlineMath math="\mathbb{L} = \{\}" /> | Misreads <InlineMath math="2\log_2 x" /> as <InlineMath math="\log_2(2x)" />, giving <InlineMath math="x = -6" /> which drops out. |
| <InlineMath math="\mathbb{L} = \left\{\frac{1 + \sqrt{29}}{2}\right\}" /> | Turns a difference of logs into the log of a difference <InlineMath math="x^2 - (x + 3)" />. |
| <InlineMath math="\mathbb{L} = \{1 + \sqrt{7}\}" /> | Sets the ratio equal to <InlineMath math="2" /> instead of <InlineMath math="2^2 = 4" />. |

# Answer

The solution set is **<InlineMath math="\mathbb{L} = \{6\}" />**.
