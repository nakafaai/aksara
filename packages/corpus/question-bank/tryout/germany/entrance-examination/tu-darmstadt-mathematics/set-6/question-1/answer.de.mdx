# Gegeben

Gegeben ist eine lineare Gleichung mit der Variablen <InlineMath math="x" /> und einem **reellen Parameter <InlineMath math="a" />**.

<BlockMath math="ax + 3 = 2x - a" />

Die Gleichung soll **keine reelle Lösung** für <InlineMath math="x" /> besitzen.

# Gesucht

Für welche Werte von <InlineMath math="a" /> hat die Gleichung keine reelle Lösung <InlineMath math="x" />?

# Lösung

Stell dir die Gleichung wie eine Waage vor, auf der <InlineMath math="x" /> eine geheimnisvolle Kiste ist. Damit sofort klar wird, wie viele Kisten links liegen, **sammelst du alle Terme mit <InlineMath math="x" /> links** und alle anderen Terme rechts.

<BlockMath math="\begin{aligned}
ax - 2x &= -a - 3 \\
(a - 2)\,x &= -(a + 3)
\end{aligned}" />

Jetzt entscheidet der **Koeffizient vor <InlineMath math="x" />**, also <InlineMath math="a - 2" />. Ist diese Zahl ungleich null, darfst du beide Seiten durch <InlineMath math="a - 2" /> teilen und bekommst genau eine Lösung für <InlineMath math="x" />.

<BlockMath math="x = -\frac{a + 3}{a - 2} \qquad (a \neq 2)" />

> Eine lineare Gleichung hat genau dann keine Lösung, wenn der **Koeffizient vor <InlineMath math="x" /> gleich null** ist, während die **Konstante auf der anderen Seite ungleich null** bleibt und einen Widerspruch erzeugt.

Kritisch wird es genau dann, wenn der **Teiler null wird**, also für <InlineMath math="a = 2" />. Setze <InlineMath math="a = 2" /> in die umgeformte Gleichung ein.

<BlockMath math="\begin{aligned}
(2 - 2)\,x &= -(2 + 3) \\
0 \cdot x &= -5 \\
0 &= -5
\end{aligned}" />

Egal welche Zahl du in <InlineMath math="x" /> einsetzt, null mal eine Zahl bleibt immer null und **wird niemals gleich <InlineMath math="-5" />**. Zur Probe setzt du <InlineMath math="a = 2" /> direkt in die Ausgangsgleichung ein.

<BlockMath math="\begin{aligned}
2x + 3 &= 2x - 2 \\
3 &= -2
\end{aligned}" />

Dieser Widerspruch bestätigt eindeutig, dass die Gleichung für <InlineMath math="a = 2" /> keine reelle Lösung hat.

Steht der Regler auf <InlineMath math="a = 2" />, wird die Anzeige <InlineMath math="a - 2" /> gleich null und beide Geraden bleiben überall um <InlineMath math="5" /> Einheiten getrennt. Verschiebst du <InlineMath math="a" /> auf einen anderen Wert wie <InlineMath math="a = -3" />, schneiden sie sich sofort in genau einem Punkt.

## Warum die anderen Antworten falsch sind

- Für <InlineMath math="a = -3" /> wird die rechte Seite null und es bleibt <InlineMath math="-5x = 0" />. Diese Gleichung hat die **gültige Lösung <InlineMath math="x = 0" />**.
- Der Wert <InlineMath math="a = -2" /> entsteht durch einen **Vorzeichenfehler** beim Herüberbringen von <InlineMath math="2x" />, wodurch fälschlich <InlineMath math="(a + 2)\,x" /> entsteht.
- Die Kombination <InlineMath math="a = 2" /> und <InlineMath math="a = -3" /> wirft zwei verschiedene Fälle zusammen. Nur <InlineMath math="a = 2" /> führt auf einen Widerspruch, während <InlineMath math="a = -3" /> durch <InlineMath math="x = 0" /> gelöst wird.
- Die Option „für keinen Wert“ übersieht, dass **eine Division durch null verboten** ist, sobald <InlineMath math="a - 2" /> verschwindet.
- Für jedes <InlineMath math="a \neq 2" /> besitzt die Gleichung genau eine reelle Lösung, also genau das Gegenteil des Gesuchten.

# Antwort

Die Gleichung hat genau für **<InlineMath math="a = 2" />** keine reelle Lösung.
