# Diberi

**Persamaan punca kuasa dua** (*Wurzelgleichung*) dalam set nombor nyata diberi seperti berikut.

<BlockMath math="\sqrt{x^2 - 6x + 9} + \sqrt{x^2 + 4x + 4} = 7" />

# Ditanya

Tentukan semua nombor nyata <InlineMath math="x" /> yang memenuhi persamaan ini.

# Penyelesaian

Setiap ungkapan di dalam punca ialah kuasa dua sempurna, dan kerana punca kuasa dua tidak pernah negatif, persamaan bertukar menjadi **hasil tambah dua jarak pada garis nombor** dari <InlineMath math="x" /> ke tiang <InlineMath math="3" /> dan tiang <InlineMath math="-2" />! Di mana-mana antara dua tiang itu, jumlah jarak kekal <InlineMath math="5" />. Untuk menaikkannya kepada <InlineMath math="7" />, melangkahlah tepat <InlineMath math="1" /> unit keluar ke kiri <InlineMath math="-2" /> atau ke kanan <InlineMath math="3" />!

> Punca kuasa dua bagi kuasa dua sempurna sentiasa menghasilkan nilai mutlak dan bukannya membuang tanda punca begitu sahaja, lalu membahagikan garis nombor kepada tiga kawasan.

Tulis semula kedua-dua punca kuasa dua sempurna sebagai nilai mutlak.

<BlockMath math="\sqrt{(x - 3)^2} + \sqrt{(x + 2)^2} = |x - 3| + |x + 2| = 7" />

## Menyelesaikan bagi tiga kawasan garis nombor

Tanda dalam nilai mutlak bertukar pada <InlineMath math="x = -2" /> dan <InlineMath math="x = 3" />, membahagikan garis nombor kepada **tiga kawasan berasingan**.

<BlockMath math="\begin{aligned}
x < -2 &: \quad (3 - x) + (-x - 2) = 1 - 2x = 7 \implies x = -3 \\
-2 \le x \le 3 &: \quad (3 - x) + (x + 2) = 5 \neq 7 \\
x > 3 &: \quad (x - 3) + (x + 2) = 2x - 1 = 7 \implies x = 4
\end{aligned}" />

## Menyemak penyelesaian dan pilihan salah

Gantikan kedua-dua nilai ke dalam persamaan asal untuk **mengesahkan kedua-duanya memberi <InlineMath math="7" />**.

<BlockMath math="\begin{aligned}
x = -3 &\implies \sqrt{36} + \sqrt{1} = 6 + 1 = 7 \\
x = 4 &\implies \sqrt{1} + \sqrt{36} = 1 + 6 = 7
\end{aligned}" />

| Pilihan | Mengapa salah |
| :--- | :--- |
| Hanya <InlineMath math="x = 4" /> | Membuang tanda nilai mutlak semasa membuka punca lalu kehilangan <InlineMath math="x = -3" />. |
| Hanya <InlineMath math="x = -3" /> | Hanya menyemak kawasan kiri dan melupakan kawasan kanan. |
| <InlineMath math="x = -4" /> atau <InlineMath math="x = 3" /> | Menukar tanda dalam kedua-dua nilai mutlak menjadi <InlineMath math="\lvert x + 3 \rvert + \lvert x - 2 \rvert = 7" />. |
| Semua <InlineMath math="x" /> dengan <InlineMath math="-2 \le x \le 3" /> | Itulah kawasan dasar rata dengan hasil tambah <InlineMath math="5" />, bukannya <InlineMath math="7" />. |
| Tiada nombor <InlineMath math="x" /> sedemikian | Hanya melihat kawasan tengah dan mengabaikan kedua-dua sisi luar. |

# Jawapan

Nombor nyata yang memenuhi persamaan ini ialah **<InlineMath math="x = -3" />** atau **<InlineMath math="x = 4" />**.
