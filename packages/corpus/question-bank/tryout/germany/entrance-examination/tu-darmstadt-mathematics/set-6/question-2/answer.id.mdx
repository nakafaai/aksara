# Diketahui

**Persamaan bentuk akar** (*Wurzelgleichung*) dalam bilangan real diberikan sebagai berikut.

<BlockMath math="\sqrt{x^2 - 6x + 9} + \sqrt{x^2 + 4x + 4} = 7" />

# Ditanyakan

Tentukan semua bilangan real <InlineMath math="x" /> yang memenuhi persamaan ini.

# Penyelesaian

Setiap bentuk di dalam akar adalah kuadrat sempurna sehingga berubah menjadi **jumlah dua jarak pada garis bilangan**, dari <InlineMath math="x" /> ke tiang <InlineMath math="3" /> dan <InlineMath math="-2" />! Di antara kedua tiang, total langkah selalu <InlineMath math="5" />. Agar naik menjadi <InlineMath math="7" />, melangkahlah <InlineMath math="1" /> satuan keluar ke kiri <InlineMath math="-2" /> atau kanan <InlineMath math="3" />!

> Akar kuadrat dari suatu kuadrat sempurna selalu menghasilkan nilai mutlak, bukan hilangnya tanda akar begitu saja, sehingga persamaan terbagi menjadi tiga wilayah menurut pembuat nol masing-masing nilai mutlak.

Ubah kedua akar kuadrat sempurna menjadi nilai mutlak.

<BlockMath math="\sqrt{(x - 3)^2} + \sqrt{(x + 2)^2} = |x - 3| + |x + 2| = 7" />

## Menelusuri tiga wilayah garis bilangan

Tanda di dalam nilai mutlak berubah di <InlineMath math="x = -2" /> dan <InlineMath math="x = 3" />, sehingga kita memeriksa **ketiga wilayah yang terpisah**.

<BlockMath math="\begin{aligned}
x < -2 &: \quad (3 - x) + (-x - 2) = 1 - 2x = 7 \implies x = -3 \\
-2 \le x \le 3 &: \quad (3 - x) + (x + 2) = 5 \neq 7 \\
x > 3 &: \quad (x - 3) + (x + 2) = 2x - 1 = 7 \implies x = 4
\end{aligned}" />

## Menguji solusi dan pilihan salah

Substitusi keduanya ke persamaan asli untuk **mengonfirmasi bahwa keduanya menghasilkan <InlineMath math="7" />**.

<BlockMath math="\begin{aligned}
x = -3 &\implies \sqrt{36} + \sqrt{1} = 6 + 1 = 7 \\
x = 4 &\implies \sqrt{1} + \sqrt{36} = 1 + 6 = 7
\end{aligned}" />

| Pilihan | Mengapa salah |
| :--- | :--- |
| Hanya <InlineMath math="x = 4" /> | Membuang tanda nilai mutlak saat melepas akar sehingga kehilangan <InlineMath math="x = -3" />. |
| Hanya <InlineMath math="x = -3" /> | Hanya menyelesaikan wilayah kiri dan melupakan wilayah kanan. |
| <InlineMath math="x = -4" /> atau <InlineMath math="x = 3" /> | Menukar tanda di dalam kedua nilai mutlak menjadi <InlineMath math="\lvert x + 3 \rvert + \lvert x - 2 \rvert = 7" />. |
| Semua <InlineMath math="x" /> dengan <InlineMath math="-2 \le x \le 3" /> | Itu wilayah dasar datar tempat jumlahnya selalu <InlineMath math="5" />, bukan <InlineMath math="7" />. |
| Tidak ada bilangan <InlineMath math="x" /> | Hanya melihat wilayah tengah yang tidak memotong <InlineMath math="7" /> dan melupakan kedua sayap luar. |

# Jawaban

Bilangan real yang memenuhi persamaan adalah **<InlineMath math="x = -3" />** atau **<InlineMath math="x = 4" />**.
