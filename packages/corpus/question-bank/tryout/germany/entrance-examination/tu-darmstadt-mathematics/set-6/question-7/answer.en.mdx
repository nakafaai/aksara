# Given

We are given an **exponential equation** (*Exponentialgleichung*) over the real numbers.

<BlockMath math="2^{2x + 1} - 9 \cdot 2^x + 4 = 0" />

# Asked

Find the real solution set (*Lösungsmenge*) <InlineMath math="\mathbb{L}" /> of this equation.

# Solution

First peel off the <InlineMath math="+1" /> in the exponent so every power is built out of the same block <InlineMath math="2^x" />! Setting <InlineMath math="t = 2^x" /> with <InlineMath math="t > 0" /> converts the exponential equation into a clean quadratic, and **the crucial final step is turning each positive <InlineMath math="t" /> back into <InlineMath math="x" />**.

> Substituting an exponential power turns the equation into a quadratic in a strictly positive variable, and every positive root must then be converted back into the original exponent.

Rewrite <InlineMath math="2^{2x + 1}" /> as <InlineMath math="2 \cdot (2^x)^2" /> and solve the quadratic in <InlineMath math="t" />.

<BlockMath math="\begin{aligned}
2t^2 - 9t + 4 &= 0 \\
(2t - 1)(t - 4) &= 0 \implies t = \frac{1}{2} \quad \text{or} \quad t = 4
\end{aligned}" />

## Converting back to variable x

Both <InlineMath math="t" /> values are positive, so neither drops out, and **a negative exponent <InlineMath math="x" /> is completely valid** because <InlineMath math="2^x" /> remains positive.

<BlockMath math="\begin{aligned}
2^x = 4 &\implies x = 2 \\
2^x = \frac{1}{2} = 2^{-1} &\implies x = -1
\end{aligned}" />

## Checking the solutions and wrong choices

Test <InlineMath math="x = -1" /> and <InlineMath math="x = 2" /> directly in **the original exponential equation**:

<BlockMath math="\begin{aligned}
x = -1 &\implies 2^{-1} - 9 \cdot \frac{1}{2} + 4 = \frac{1}{2} - \frac{9}{2} + 4 = 0 \\
x = 2 &\implies 2^5 - 9 \cdot 4 + 4 = 32 - 36 + 4 = 0
\end{aligned}" />

| Option | Why it is wrong |
| :--- | :--- |
| <InlineMath math="\mathbb{L} = \left\{\frac{1}{2},\, 4\right\}" /> | Stops at the <InlineMath math="t" /> values and forgets to solve back for <InlineMath math="x" />. |
| <InlineMath math="\mathbb{L} = \{2\}" /> | Rejects <InlineMath math="x = -1" />, even though negative exponents are allowed for <InlineMath math="2^x" />. |
| <InlineMath math="\mathbb{L} = \{1,\, 2\}" /> | Flips the sign of the exponent, confusing <InlineMath math="2^{-1}" /> with <InlineMath math="2^1" />. |
| <InlineMath math="\mathbb{L} = \{2 - \log_2 7\}" /> | Misreads <InlineMath math="2^{2x + 1}" /> as <InlineMath math="2t" /> instead of <InlineMath math="2t^2" />. |
| <InlineMath math="\mathbb{L} = \left\{\log_2\frac{9 \pm \sqrt{65}}{2}\right\}" /> | Drops the leading factor <InlineMath math="2" /> in front of <InlineMath math="t^2" />. |

# Answer

The solution set is <InlineMath math="\mathbb{L} = \{-1,\, 2\}" />.
