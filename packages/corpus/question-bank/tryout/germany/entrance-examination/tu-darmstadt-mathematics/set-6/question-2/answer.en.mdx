# Given

We are given a **radical equation** (*Wurzelgleichung*) over the real numbers.

<BlockMath math="\sqrt{x^2 - 6x + 9} + \sqrt{x^2 + 4x + 4} = 7" />

# Asked

Find all real numbers <InlineMath math="x" /> that satisfy this equation.

# Solution

Each radicand is a perfect square, and because square roots are never negative, the equation becomes **the sum of two distances on the number line** from <InlineMath math="x" /> to posts at <InlineMath math="3" /> and <InlineMath math="-2" />! Anywhere between the two posts, the total distance stays stuck at <InlineMath math="5" />. To push the total up to <InlineMath math="7" />, step exactly <InlineMath math="1" /> unit past either post, landing at <InlineMath math="-3" /> or <InlineMath math="4" />!

> Taking the square root of a perfect square always produces an absolute value rather than stripping the radical blindly, splitting the number line into three regions around the zeros of each absolute value.

Rewrite both perfect-square radicals using absolute values.

<BlockMath math="\sqrt{(x - 3)^2} + \sqrt{(x + 2)^2} = |x - 3| + |x + 2| = 7" />

## Solving across the three regions

The expressions inside the absolute values change sign at <InlineMath math="x = -2" /> and <InlineMath math="x = 3" />, splitting the line into **three clean regions**.

<BlockMath math="\begin{aligned}
x < -2 &: \quad (3 - x) + (-x - 2) = 1 - 2x = 7 \implies x = -3 \\
-2 \le x \le 3 &: \quad (3 - x) + (x + 2) = 5 \neq 7 \\
x > 3 &: \quad (x - 3) + (x + 2) = 2x - 1 = 7 \implies x = 4
\end{aligned}" />

Both roots lie inside their own case regions since <InlineMath math="-3 < -2" /> and <InlineMath math="4 > 3" />. Inspect the flat-bottomed distance graph below.

## Checking the solutions and wrong choices

Substitute both answers back into the original equation to **confirm that each equals <InlineMath math="7" />**.

<BlockMath math="\begin{aligned}
x = -3 &\implies \sqrt{36} + \sqrt{1} = 6 + 1 = 7 \\
x = 4 &\implies \sqrt{1} + \sqrt{36} = 1 + 6 = 7
\end{aligned}" />

| Option | Why it is wrong |
| :--- | :--- |
| Only <InlineMath math="x = 4" /> | Drops the absolute value signs when taking roots, losing <InlineMath math="x = -3" />. |
| Only <InlineMath math="x = -3" /> | Checks only the left region and forgets the right region. |
| <InlineMath math="x = -4" /> or <InlineMath math="x = 3" /> | Flips signs inside both absolute values to solve <InlineMath math="\lvert x + 3 \rvert + \lvert x - 2 \rvert = 7" />. |
| All <InlineMath math="x" /> with <InlineMath math="-2 \le x \le 3" /> | That is the flat floor where the sum equals <InlineMath math="5" />, not <InlineMath math="7" />. |
| No such real number <InlineMath math="x" /> | Checks only the middle plateau and overlooks both rising sides. |

# Answer

The equation holds for **<InlineMath math="x = -3" />** or **<InlineMath math="x = 4" />**.
