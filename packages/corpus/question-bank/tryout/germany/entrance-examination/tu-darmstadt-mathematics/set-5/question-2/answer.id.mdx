# Diketahui

Sebuah **petak kebun persegi panjang** (*rechteckiges Beet*) memiliki keliling (*Umfang*) tepat <InlineMath math="20\text{ m}" /> dengan salah satu sisinya sepanjang <InlineMath math="x\text{ m}" />. Luas petak (*Flächeninhalt*) harus paling sedikit (*mindestens*) <InlineMath math="21\text{ m}^2" />.

# Ditanyakan

Tentukan semua nilai real <InlineMath math="x" /> yang membuat luas petak paling sedikit <InlineMath math="21\text{ m}^2" />.

# Penyelesaian

Dengan pagar sepanjang <InlineMath math="20\text{ m}" />, dua sisi bersebelahan selalu berbagi setengah keliling, yaitu <InlineMath math="10\text{ m}" />. Jika kamu menarik petak terlalu panjang dan tipis (<InlineMath math="1\text{ m}" /> kali <InlineMath math="9\text{ m}" />), luasnya menyusut menjadi <InlineMath math="9\text{ m}^2" />, sedangkan **bentuk yang lebih dekat ke persegi menghasilkan luas lebih besar**.

> Pada persegi panjang berkeliling tetap, luas membentuk parabola terbuka ke bawah yang memuncak di bentuk persegi, sehingga syarat luas minimal selalu berupa selang tertutup di antara dua batas simetris.

Nyatakan sisi kedua sebagai <InlineMath math="10 - x" />, lalu susun pertidaksamaan kuadrat untuk luas.

<BlockMath math="\begin{aligned}
x(10 - x) &\ge 21 \\
10x - x^2 - 21 &\ge 0 \\
x^2 - 10x + 21 &\le 0 \\
(x - 3)(x - 7) &\le 0
\end{aligned}" />

## Membaca selang luas dan kurva parabola

Saat mengalikan kedua ruas dengan <InlineMath math="-1" />, arah tanda pertidaksamaan berbalik. Hasil kali <InlineMath math="(x - 3)(x - 7)" /> bernilai tak positif **tepat di antara <InlineMath math="3" /> dan <InlineMath math="7" /> termasuk kedua batasnya**.

## Menguji batas dan pilihan salah

Uji tiga nilai: pada <InlineMath math="x = 3" /> luasnya tepat <InlineMath math="3 \cdot 7 = 21\text{ m}^2" />, pada <InlineMath math="x = 5" /> naik menjadi **luas maksimum <InlineMath math="25\text{ m}^2" />**, sedangkan pada <InlineMath math="x = 2" /> turun ke <InlineMath math="16\text{ m}^2" />.

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="3 < x < 7" /> | Membuang kedua batas, padahal kata paling sedikit mengizinkan luas tepat <InlineMath math="21\text{ m}^2" />. |
| <InlineMath math="0 < x \le 3" /> atau <InlineMath math="7 \le x < 10" /> | Mengambil sisi luar yang luasnya justru paling besar <InlineMath math="21\text{ m}^2" />. |
| <InlineMath math="3 \le x < 10" /> | Lupa batas atas <InlineMath math="7" />, padahal pada <InlineMath math="x = 9" /> luasnya cuma <InlineMath math="9\text{ m}^2" />. |
| <InlineMath math="-7 \le x \le -3" /> | Salah tanda pemfaktoran menjadi <InlineMath math="(x + 3)(x + 7)" /> dan panjang sisi tidak mungkin negatif. |
| <InlineMath math="0 < x \le 7" /> | Lupa batas bawah <InlineMath math="3" />, padahal pada <InlineMath math="x = 1" /> luasnya cuma <InlineMath math="9\text{ m}^2" />. |
