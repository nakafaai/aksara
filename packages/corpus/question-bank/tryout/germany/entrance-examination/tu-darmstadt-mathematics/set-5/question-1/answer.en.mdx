# Given

We are given a **cubic polynomial** (*Polynom*) with a real parameter <InlineMath math="a" />.

<BlockMath math="p(x) = x^3 + ax^2 - 5x + 6" />

This polynomial is divisible without remainder (*ohne Rest teilbar*) by <InlineMath math="(x - 1)" />.

# Asked

Find all other real roots (*weitere Nullstellen*) of <InlineMath math="p" /> besides <InlineMath math="x = 1" />.

# Solution

Saying a polynomial is divisible by <InlineMath math="(x - 1)" /> works like a key turning a lock: **plugging in <InlineMath math="x = 1" /> must return zero**! That single substitution pins down <InlineMath math="a" /> immediately, and polynomial division then peels off <InlineMath math="(x - 1)" /> to leave an everyday quadratic.

> By the factor theorem, a polynomial is divisible by a linear factor exactly when that factor's root zeroes the polynomial, allowing division to reduce the remaining factor to a lower degree.

Apply the root condition <InlineMath math="p(1) = 0" /> to solve for <InlineMath math="a" />.

<BlockMath math="p(1) = 1 + a - 5 + 6 = a + 2 = 0 \implies a = -2" />

## Dividing the polynomial and factoring the quotient

Substitute <InlineMath math="a = -2" /> and divide by <InlineMath math="(x - 1)" /> to isolate **a clean quadratic factor**.

<BlockMath math="\begin{aligned}
p(x) &= x^3 - 2x^2 - 5x + 6 \\
&= (x - 1)\left(x^2 - x - 6\right) \\
&= (x - 1)(x - 3)(x + 2)
\end{aligned}" />

## Checking the factorization and wrong choices

Quick Vieta check on the three factors: the constant product gives **exactly <InlineMath math="+6" />**, and the root sum matches the <InlineMath math="-2x^2" /> term.

<BlockMath math="(-1)(-3)(2) = +6, \qquad 1 + 3 + (-2) = 2" />

| Option | Why it is wrong |
| :--- | :--- |
| <InlineMath math="x = 2" /> and <InlineMath math="x = -3" /> | Swaps both signs when factoring <InlineMath math="x^2 - x - 6" /> into <InlineMath math="(x + 3)(x - 2)" />. |
| <InlineMath math="x = \frac{11 \pm \sqrt{97}}{2}" /> | Uses <InlineMath math="p(-1) = 0" /> instead of <InlineMath math="p(1) = 0" />, producing <InlineMath math="a = -10" />. |
| No other real roots | Misdivides to get <InlineMath math="x^2 - x + 6" />, which has no real zeros. |
| <InlineMath math="x = -1" /> and <InlineMath math="x = 6" /> | Copies <InlineMath math="-5" /> and <InlineMath math="6" /> straight into a quadratic without dividing. |
| <InlineMath math="x = 2" /> and <InlineMath math="x = 3" /> | Uses the wrong quotient <InlineMath math="x^2 - 5x + 6" /> after flipping signs. |

# Answer

The other real roots of **<InlineMath math="p" />** are **<InlineMath math="x = -2" />** and **<InlineMath math="x = 3" />**.
