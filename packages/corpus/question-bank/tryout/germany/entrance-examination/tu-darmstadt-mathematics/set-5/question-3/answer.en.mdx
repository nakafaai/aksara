Measured from the hinge, the chain is <InlineMath math="1\text{ m}" /> along each leg and the floor is <InlineMath math="2.5\text{ m}" /> along each leg. The parallel segments are in the same ratio as these distances.

<BlockMath math="\frac{k}{1.5}=\frac{1}{2.5}\quad\Rightarrow\quad k=1.5\cdot0.4=0.6" />

So the gap grows by <InlineMath math="0.6\text{ m}" /> per metre of leg, and after <InlineMath math="1\text{ m}" /> it is exactly <InlineMath math="0.6\text{ m}" />.

So the chain is <InlineMath math="0.6\text{ m}" /> long.
