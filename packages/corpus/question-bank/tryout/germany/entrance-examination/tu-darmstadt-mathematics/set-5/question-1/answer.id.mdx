# Diketahui

**Polinomial kubik** (*Polynom*) dengan parameter real <InlineMath math="a" /> diberikan sebagai berikut.

<BlockMath math="p(x) = x^3 + ax^2 - 5x + 6" />

Polinomial ini habis dibagi (*ohne Rest teilbar*) oleh <InlineMath math="(x - 1)" />.

# Ditanyakan

Tentukan semua pembuat nol real lainnya (*weitere Nullstellen*) dari <InlineMath math="p" /> selain <InlineMath math="x = 1" />.

# Penyelesaian

Pernyataan bahwa polinomial habis dibagi <InlineMath math="(x - 1)" /> bekerja seperti kunci pas yang langsung membuka gembok: **memasukkan <InlineMath math="x = 1" /> pasti menghasilkan nol**! Satu substitusi ini langsung mengunci nilai <InlineMath math="a" />, lalu pembagian polinomial mengupas faktor <InlineMath math="(x - 1)" /> hingga tersisa kuadrat biasa.

> Berdasarkan teorema faktor, suatu polinomial habis dibagi faktor linear tepat ketika akar faktor itu menjadi pembuat nol polinomial, sehingga sisanya dapat diturunkan derajatnya lewat pembagian polinomial.

Terapkan syarat <InlineMath math="p(1) = 0" /> untuk menemukan <InlineMath math="a" />.

<BlockMath math="p(1) = 1 + a - 5 + 6 = a + 2 = 0 \implies a = -2" />

## Membagi polinomial dan memfaktorkan sisanya

Substitusi <InlineMath math="a = -2" /> lalu bagi polinomial oleh <InlineMath math="(x - 1)" /> untuk memperoleh **faktor kuadrat yang mudah difaktorkan**.

<BlockMath math="\begin{aligned}
p(x) &= x^3 - 2x^2 - 5x + 6 \\
&= (x - 1)\left(x^2 - x - 6\right) \\
&= (x - 1)(x - 3)(x + 2)
\end{aligned}" />

## Menguji hasil kali faktor dan pilihan salah

Cek balik dengan mengalikan ulang ketiga faktornya: suku konstanta memberi **tepat <InlineMath math="+6" />**, dan jumlah ketiga akar cocok dengan koefisien <InlineMath math="-2x^2" />.

<BlockMath math="(-1)(-3)(2) = +6, \qquad 1 + 3 + (-2) = 2" />

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="x = 2" /> dan <InlineMath math="x = -3" /> | Menukar kedua tanda saat memfaktorkan <InlineMath math="x^2 - x - 6" /> menjadi <InlineMath math="(x + 3)(x - 2)" />. |
| <InlineMath math="x = \frac{11 \pm \sqrt{97}}{2}" /> | Memakai <InlineMath math="p(-1) = 0" /> alih-alih <InlineMath math="p(1) = 0" /> sehingga mendapat <InlineMath math="a = -10" />. |
| Tidak ada pembuat nol lain | Salah hitung pembagian menjadi <InlineMath math="x^2 - x + 6" /> yang tidak punya akar real. |
| <InlineMath math="x = -1" /> dan <InlineMath math="x = 6" /> | Langsung menyalin koefisien <InlineMath math="-5" /> dan <InlineMath math="6" /> tanpa membagi polinomial. |
| <InlineMath math="x = 2" /> dan <InlineMath math="x = 3" /> | Memakai faktor keliru <InlineMath math="x^2 - 5x + 6" /> akibat tanda terbalik. |

# Jawaban

Pembuat nol real lainnya dari **<InlineMath math="p" />** adalah **<InlineMath math="x = -2" />** dan **<InlineMath math="x = 3" />**.
