# Gegeben

Ein **rechteckiges Beet** hat genau den Umfang <InlineMath math="20\text{ m}" />, und eine Seite misst <InlineMath math="x\text{ m}" />. Sein Flächeninhalt soll mindestens <InlineMath math="21\text{ m}^2" /> betragen.

# Gesucht

Alle reellen Werte von <InlineMath math="x" />, für die der Flächeninhalt mindestens <InlineMath math="21\text{ m}^2" /> beträgt.

# Lösung

Bei <InlineMath math="20\text{ m}" /> Zaun teilen sich zwei benachbarte Seiten immer den halben Umfang von <InlineMath math="10\text{ m}" />. Ziehst du das Beet sehr lang und schmal (<InlineMath math="1\text{ m}" /> mal <InlineMath math="9\text{ m}" />), schrumpft die Fläche auf <InlineMath math="9\text{ m}^2" />, während **quadratnähere Rechtecke deutlich mehr Fläche einschließen**.

> Bei festem Umfang beschreibt die Rechteckfläche eine nach unten geöffnete Parabel mit Maximum beim Quadrat, sodass eine Mindestfläche stets ein abgeschlossenes Intervall zwischen zwei symmetrischen Grenzen ergibt.

Schreib die zweite Seite als <InlineMath math="10 - x" /> und stelle die quadratische Ungleichung auf.

<BlockMath math="\begin{aligned}
x(10 - x) &\ge 21 \\
10x - x^2 - 21 &\ge 0 \\
x^2 - 10x + 21 &\le 0 \\
(x - 3)(x - 7) &\le 0
\end{aligned}" />

## Flächenbereich an der Parabel ablesen

Durch das Multiplizieren mit <InlineMath math="-1" /> dreht sich das Ungleichheitszeichen um. Das Produkt <InlineMath math="(x - 3)(x - 7)" /> ist kleiner oder gleich null **genau zwischen <InlineMath math="3" /> und <InlineMath math="7" /> einschließlich beider Grenzen**.

## Randprobe und falsche Antworten prüfen

Prüf drei Werte: Bei <InlineMath math="x = 3" /> beträgt die Fläche <InlineMath math="3 \cdot 7 = 21\text{ m}^2" />, bei <InlineMath math="x = 5" /> erreicht sie **das Maximum <InlineMath math="25\text{ m}^2" />**, und bei <InlineMath math="x = 2" /> sinkt sie auf <InlineMath math="16\text{ m}^2" />.

| Antwort | Warum sie falsch ist |
| :--- | :--- |
| <InlineMath math="3 < x < 7" /> | Schließt beide Ränder aus, obwohl mindestens exakt <InlineMath math="21\text{ m}^2" /> erlaubt. |
| <InlineMath math="0 < x \le 3" /> oder <InlineMath math="7 \le x < 10" /> | Wählt die Außenbereiche mit höchstens <InlineMath math="21\text{ m}^2" />, also die falsche Richtung. |
| <InlineMath math="3 \le x < 10" /> | Vergisst die obere Grenze <InlineMath math="7" />, doch für <InlineMath math="x = 9" /> gibt es nur <InlineMath math="9\text{ m}^2" />. |
| <InlineMath math="-7 \le x \le -3" /> | Entsteht aus falschen Vorzeichen <InlineMath math="(x + 3)(x + 7)" />, und Längen sind positiv. |
| <InlineMath math="0 < x \le 7" /> | Vergisst die untere Grenze <InlineMath math="3" />, doch für <InlineMath math="x = 1" /> gibt es nur <InlineMath math="9\text{ m}^2" />. |

# Antwort

Der Flächeninhalt ist mindestens <InlineMath math="21\text{ m}^2" /> für <InlineMath math="3 \le x \le 7" />.
