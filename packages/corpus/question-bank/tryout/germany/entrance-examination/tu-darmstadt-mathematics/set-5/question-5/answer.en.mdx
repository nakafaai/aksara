# Given

A **circle** (*Kreis*) lies in the first quadrant of a coordinate plane and is tangent to both the <InlineMath math="x" />-axis and the <InlineMath math="y" />-axis. In addition, the circle passes through the point <InlineMath math="P(1 \mid 8)" />.

# Asked

Find all possible values for the radius (*Radius*) <InlineMath math="r" /> of the circle.

# Solution

Picture inflating a balloon tucked snugly into the corner between a floor and a wall! Its center glides along <InlineMath math="M(r \mid r)" /> as it grows: its upper arc sweeps past <InlineMath math="P(1 \mid 8)" /> once while small, and then **its lower arc sweeps past <InlineMath math="P" /> a second time once large**!

> A first-quadrant circle tangent to both axes always centers at equal coordinates matching its radius, so passing through one point produces a quadratic with two valid circles.

Because the distance from <InlineMath math="M(r \mid r)" /> to <InlineMath math="P(1 \mid 8)" /> equals <InlineMath math="r" />, set up the squared distance equation.

<BlockMath math="\begin{aligned}
(1 - r)^2 + (8 - r)^2 &= r^2 \\
1 - 2r + r^2 + 64 - 16r + r^2 &= r^2 \\
r^2 - 18r + 65 &= 0 \\
(r - 5)(r - 13) &= 0
\end{aligned}" />

## Confirming both circles in the coordinate plane

Both roots <InlineMath math="r = 5" /> and <InlineMath math="r = 13" /> are positive with centers in the first quadrant, so **neither radius needs to be rejected**.

## Checking distances and wrong choices

Verify directly with **the distance from each center to <InlineMath math="P(1 \mid 8)" />**:

<BlockMath math="\begin{aligned}
(1 - 5)^2 + (8 - 5)^2 &= 16 + 9 = 25 = 5^2 \\
(1 - 13)^2 + (8 - 13)^2 &= 144 + 25 = 169 = 13^2
\end{aligned}" />

| Option | Why it is wrong |
| :--- | :--- |
| Only <InlineMath math="r = 5" /> | Drops the valid larger radius <InlineMath math="r = 13" />. |
| Only <InlineMath math="r = 13" /> | Drops the valid smaller radius <InlineMath math="r = 5" />. |
| Only <InlineMath math="r = \sqrt{65}" /> | Measures the distance from <InlineMath math="P" /> to the origin, which is not the circle's center. |
| Only <InlineMath math="r = 4.5" /> | Averages the coordinates <InlineMath math="1" /> and <InlineMath math="8" /> instead of using the circle equation. |
| Only <InlineMath math="r = 9" /> | Picks the midpoint of the two valid radii, which is the vertex of <InlineMath math="r^2 - 18r + 65" />. |

# Answer

The circle can have radius **<InlineMath math="r = 5" />** or **<InlineMath math="r = 13" />**.
