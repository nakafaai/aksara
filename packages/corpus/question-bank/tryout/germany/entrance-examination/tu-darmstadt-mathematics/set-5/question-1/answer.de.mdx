# Gegeben

Gegeben ist das folgende **kubische Polynom** mit einem reellen Parameter <InlineMath math="a" />.

<BlockMath math="p(x) = x^3 + ax^2 - 5x + 6" />

Dieses Polynom ist ohne Rest durch <InlineMath math="(x - 1)" /> teilbar.

# Gesucht

Alle weiteren reellen Nullstellen von <InlineMath math="p" /> außer <InlineMath math="x = 1" />.

# Lösung

Dass ein Polynom ohne Rest durch <InlineMath math="(x - 1)" /> teilbar ist, wirkt wie ein passender Schlüssel: **Setzt du <InlineMath math="x = 1" /> ein, muss null herauskommen**! Mit diesem einen Schritt steht <InlineMath math="a" /> sofort fest, und die Polynomdivision spaltet <InlineMath math="(x - 1)" /> zu einem einfachen quadratischen Rest ab.

> Ein Polynom ist genau dann ohne Rest durch einen Linearfaktor teilbar, wenn dessen Nullstelle das Polynom zu null macht, danach senkt eine Polynomdivision den Grad auf eine quadratische Gleichung.

Nutze die Nullstellenbedingung <InlineMath math="p(1) = 0" />, um <InlineMath math="a" /> zu bestimmen.

<BlockMath math="p(1) = 1 + a - 5 + 6 = a + 2 = 0 \implies a = -2" />

## Polynomdivision und Faktorisierung des Restpolynoms

Setz <InlineMath math="a = -2" /> ein und teile durch <InlineMath math="(x - 1)" />, um **einen leicht faktorisierbaren quadratischen Faktor** zu erhalten.

<BlockMath math="\begin{aligned}
p(x) &= x^3 - 2x^2 - 5x + 6 \\
&= (x - 1)\left(x^2 - x - 6\right) \\
&= (x - 1)(x - 3)(x + 2)
\end{aligned}" />

## Probe und falsche Antworten prüfen

Kurzprobe an den drei Faktoren: Das Produkt der Konstanten ergibt **genau <InlineMath math="+6" />**, und die Summe aller drei Nullstellen passt zum Glied <InlineMath math="-2x^2" />.

<BlockMath math="(-1)(-3)(2) = +6, \qquad 1 + 3 + (-2) = 2" />

| Antwort | Warum sie falsch ist |
| :--- | :--- |
| <InlineMath math="x = 2" /> und <InlineMath math="x = -3" /> | Vertauscht beide Vorzeichen beim Faktorisieren von <InlineMath math="x^2 - x - 6" /> zu <InlineMath math="(x + 3)(x - 2)" />. |
| <InlineMath math="x = \frac{11 \pm \sqrt{97}}{2}" /> | Nutzt <InlineMath math="p(-1) = 0" /> statt <InlineMath math="p(1) = 0" /> und erhält <InlineMath math="a = -10" />. |
| Keine weiteren reellen Nullstellen | Verrechnet sich bei der Division zu <InlineMath math="x^2 - x + 6" /> ohne reelle Nullstellen. |
| <InlineMath math="x = -1" /> und <InlineMath math="x = 6" /> | Übernimmt die Koeffizienten <InlineMath math="-5" /> und <InlineMath math="6" /> direkt ohne Polynomdivision. |
| <InlineMath math="x = 2" /> und <InlineMath math="x = 3" /> | Verwendet den falschen Restfaktor <InlineMath math="x^2 - 5x + 6" /> mit falschem Vorzeichen. |

# Antwort

Die weiteren Nullstellen von <InlineMath math="p" /> sind <InlineMath math="x = -2" /> und <InlineMath math="x = 3" />.
