# Diberi

**Polinomial kubik** (*Polynom*) dengan parameter nyata <InlineMath math="a" /> diberi seperti berikut.

<BlockMath math="p(x) = x^3 + ax^2 - 5x + 6" />

Polinomial ini boleh dibahagi tepat (*ohne Rest teilbar*) oleh <InlineMath math="(x - 1)" />.

# Ditanya

Tentukan semua punca nyata lain (*weitere Nullstellen*) bagi <InlineMath math="p" /> selain <InlineMath math="x = 1" />.

# Penyelesaian

Kenyataan bahawa polinomial boleh dibahagi tepat oleh <InlineMath math="(x - 1)" /> bertindak seperti anak kunci yang membuka mangga: **menggantikan <InlineMath math="x = 1" /> pasti memberi sifar**! Satu gantian ini terus menentukan nilai <InlineMath math="a" />, lalu pembahagian polinomial memisahkan <InlineMath math="(x - 1)" /> sehingga tinggal ungkapan kuadratik ringkas.

> Mengikut teorem faktor, suatu polinomial boleh dibahagi tepat oleh faktor linear apabila punca faktor itu menjadikan polinomial sifar, lalu pembahagian menurunkan darjah baki faktornya.

Gunakan syarat <InlineMath math="p(1) = 0" /> untuk mencari nilai <InlineMath math="a" />.

<BlockMath math="p(1) = 1 + a - 5 + 6 = a + 2 = 0 \implies a = -2" />

## Membahagi polinomial dan memfaktorkan hasil bahagi

Gantikan <InlineMath math="a = -2" /> kemudian bahagikan dengan <InlineMath math="(x - 1)" /> untuk memperoleh **faktor kuadratik yang mudah difaktorkan**.

<BlockMath math="\begin{aligned}
p(x) &= x^3 - 2x^2 - 5x + 6 \\
&= (x - 1)\left(x^2 - x - 6\right) \\
&= (x - 1)(x - 3)(x + 2)
\end{aligned}" />

## Menyemak pemfaktoran dan pilihan salah

Semakan pantas pada ketiga-tiga faktornya: hasil darab pemalar memberi **tepat <InlineMath math="+6" />**, dan hasil tambah ketiga-tiga punca sepadan dengan sebutan <InlineMath math="-2x^2" />.

<BlockMath math="(-1)(-3)(2) = +6, \qquad 1 + 3 + (-2) = 2" />

| Pilihan | Mengapa salah |
| :--- | :--- |
| <InlineMath math="x = 2" /> dan <InlineMath math="x = -3" /> | Menukar kedua-dua tanda apabila memfaktorkan <InlineMath math="x^2 - x - 6" /> menjadi <InlineMath math="(x + 3)(x - 2)" />. |
| <InlineMath math="x = \frac{11 \pm \sqrt{97}}{2}" /> | Menggunakan <InlineMath math="p(-1) = 0" /> bukannya <InlineMath math="p(1) = 0" /> sehingga mendapat <InlineMath math="a = -10" />. |
| Tiada punca nyata lain | Tersilap membahagi menjadi <InlineMath math="x^2 - x + 6" /> yang tiada punca nyata. |
| <InlineMath math="x = -1" /> dan <InlineMath math="x = 6" /> | Menyalin terus pekali <InlineMath math="-5" /> dan <InlineMath math="6" /> tanpa membahagi polinomial. |
| <InlineMath math="x = 2" /> dan <InlineMath math="x = 3" /> | Menggunakan hasil bahagi silap <InlineMath math="x^2 - 5x + 6" /> akibat tanda terbalik. |

# Jawapan

Punca nyata lain bagi **<InlineMath math="p" />** ialah **<InlineMath math="x = -2" />** dan **<InlineMath math="x = 3" />**.
