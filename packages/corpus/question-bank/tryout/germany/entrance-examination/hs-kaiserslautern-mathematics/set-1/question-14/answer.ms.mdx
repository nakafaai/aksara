# Diberi

**Kereta api barang** sepanjang <InlineMath math="300\text{ m}" /> mengambil <InlineMath math="50\text{ s}" /> dari kepala masuk hingga ekor keluar terowong dan berada sepenuhnya di dalam selama <InlineMath math="30\text{ s}" />. Tepat apabila ia masuk sepenuhnya, kereta api penumpang <InlineMath math="200\text{ m}" /> masuk dari arah bertentangan pada laju <InlineMath math="20\,\tfrac{\text{m}}{\text{s}}" />.

# Ditanya

Berapa saat kedua-dua kereta api berada sepenuhnya di dalam terowong secara serentak?

# Penyelesaian

> Beza masa melintas penuh dengan masa berada sepenuhnya di dalam memansuhkan panjang terowong dan memberi **masa tepat untuk menempuh dua kali panjang kereta api itu sendiri**.

## Dua masa dua anu

Bayangkan kereta api sebagai ular panjang yang menjalar melalui paip. Untuk keluar sepenuhnya, kepalanya bergerak sejauh panjang terowong ditambah panjang badannya. Untuk berada sepenuhnya di dalam, kepalanya hanya bergerak sejauh panjang terowong ditolak panjang badannya. **Jadi <InlineMath math="(L+300)/v = 50" /> dan <InlineMath math="(L-300)/v = 30" />**.

<BlockMath math="\begin{aligned}
L+300&=50v\\
L-300&=30v\\
600&=20v\ \Rightarrow\ v=30\,\tfrac{\text{m}}{\text{s}},\ L=1200\text{ m}
\end{aligned}" />

## Tetingkap masa setiap kereta api

Mulakan jam apabila kereta api barang berada sepenuhnya di dalam. **Ia kekal di dalam selama <InlineMath math="30\text{ s}" />, hingga <InlineMath math="t=30" />**. Kepala kereta api penumpang masuk pada <InlineMath math="t=0" />, tetapi ekornya hanya menyusul <InlineMath math="10\text{ s}" /> kemudian. Kereta itu berada sepenuhnya di dalam dari <InlineMath math="t=10" /> hingga kepalanya sampai ke hujung lain pada <InlineMath math="60\text{ s}" />.

Membandingkan kedua-dua palang selang masa menampakkan **pertindihan dari <InlineMath math="10\text{ s}" /> hingga <InlineMath math="30\text{ s}" />**, iaitu tepat <InlineMath math="20\text{ s}" />.

## Pertindihannya

Kedua-dua tetingkap terbuka dari <InlineMath math="t=10" /> hingga <InlineMath math="t=30" />. **Itu <InlineMath math="20" /> saat**. Kalau kereta api penumpang dikira berada di dalam sebaik kepalanya masuk, kamu dapat <InlineMath math="30\text{ s}" />.

# Jawapan

Kedua-dua kereta api berada sepenuhnya di dalam terowong secara serentak selama <InlineMath math="20\text{ s}" />.
