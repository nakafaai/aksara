# Dua masa, dua anu

Bayangkan kereta api sebagai ular panjang yang menjalar melalui paip. Untuk keluar sepenuhnya, kepalanya bergerak sejauh panjang terowong ditambah panjang badannya. Untuk berada sepenuhnya di dalam, kepalanya hanya bergerak sejauh panjang terowong ditolak panjang badannya. **Jadi <InlineMath math="\frac{L+300}{v}=50" /> dan <InlineMath math="\frac{L-300}{v}=30" />**.

<BlockMath math="\begin{aligned}
L+300&=50v\\
L-300&=30v\\
600&=20v\ \Rightarrow\ v=30\,\tfrac{\text{m}}{\text{s}},\ L=1200\text{ m}
\end{aligned}" />

# Tetingkap masa setiap kereta api

Mulakan jam apabila kereta api barang berada sepenuhnya di dalam. **Ia kekal di dalam selama <InlineMath math="30\text{ s}" />, hingga <InlineMath math="t=30" />**. Kepala kereta api penumpang masuk pada <InlineMath math="t=0" />, tetapi ekornya hanya menyusul <InlineMath math="\frac{200}{20}=10\text{ s}" /> kemudian. Kereta itu berada sepenuhnya di dalam dari <InlineMath math="t=10" /> hingga kepalanya sampai ke hujung lain pada <InlineMath math="\frac{1200}{20}=60\text{ s}" />.

# Pertindihannya

Kedua-dua tetingkap terbuka dari <InlineMath math="t=10" /> hingga <InlineMath math="t=30" />. **Itu <InlineMath math="20" /> saat**. Kalau kereta api penumpang dikira berada di dalam sebaik kepalanya masuk, kamu dapat <InlineMath math="30\text{ s}" />.
