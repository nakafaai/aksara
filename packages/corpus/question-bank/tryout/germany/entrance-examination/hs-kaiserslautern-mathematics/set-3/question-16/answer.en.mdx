# How low the rope lets it hang

Hold a necklace by both ends and slide a ring along it: the ring settles at the lowest spot the chain allows. **The pulley can hang at height <InlineMath math="y" /> only if <InlineMath math="20\text{ m}" /> of rope suffice to run from the first knot down to that height and back up to the second knot**. So for each height you need the shortest such rope.

# Mirroring finds the shortest rope

Mirror the second knot <InlineMath math="B(16\mid9)" /> across the horizontal line at height <InlineMath math="y" />. **From any point on that line the distance to <InlineMath math="B" /> equals the distance to the mirror image <InlineMath math="B'" />, so the shortest rope is the straight segment from <InlineMath math="A(0\mid12)" /> to <InlineMath math="B'" />**.

<BlockMath math="\begin{aligned}
B'&=(16\mid2y-9)\\
L_{\min}(y)^2&=16^2+\bigl(12-(2y-9)\bigr)^2=256+(21-2y)^2
\end{aligned}" />

The pulley can reach height <InlineMath math="y" /> as long as that length is at most <InlineMath math="20\text{ m}" />.

<BlockMath math="\begin{aligned}
256+(21-2y)^2&\le400\\
(21-2y)^2&\le144\\
21-2y&\le12,\qquad y\ge4.5
\end{aligned}" />

# Where it hangs, as a check

**At the lowest height the rope runs straight from <InlineMath math="A" /> to <InlineMath math="B'(16\mid0)" />, so both pieces make the same angle with the horizontal**.

<BlockMath math="\begin{aligned}
\cos\alpha&=\tfrac{16}{20}=0.8,\qquad\tan\alpha=0.75\\
x_1&=\tfrac{12-4.5}{0.75}=10,\qquad x_2=\tfrac{9-4.5}{0.75}=6
\end{aligned}" />

The two pieces measure <InlineMath math="12.5\text{ m}" /> and <InlineMath math="7.5\text{ m}" />, adding to <InlineMath math="20\text{ m}" />. **The pulley hangs <InlineMath math="4.5\text{ m}" /> above the ground**, not halfway between the trees but <InlineMath math="2\text{ m}" /> closer to the lower knot.
