# Diberi

**Roket dua peringkat** membawa muatan <InlineMath math="50\text{ kg}" /> dengan jisim kering peringkat pertama <InlineMath math="200\text{ kg}" /> (<InlineMath math="u_1=4\text{ km/s}" />), peringkat kedua <InlineMath math="50\text{ kg}" /> (<InlineMath math="u_2=2\text{ km/s}" />), dan jumlah bahan api <InlineMath math="600\text{ kg}" /> dibahagi sebagai <InlineMath math="T_1 + T_2 = 600" />. Jumlah peningkatan laju mesti <InlineMath math="2\ln(10)\text{ km/s}" /> dengan <InlineMath math="2\ln(2)\text{ km/s}" />.

# Ditanya

Berapa kilogram bahan api T1 yang diterima oleh peringkat pertama?

# Penyelesaian

> Oleh sebab laju ekzos peringkat pertama **dua kali ganda peringkat kedua**, menggabungkan kedua-dua logaritma mengkuasaduakan nisbah jisim peringkat pertama dan meringkaskan persamaan roket kepada satu persamaan kuadratik kemas dalam <InlineMath math="T_2" />.

## Menjejak jisim sebelum dan selepas pelepasan

Bayangkan pendaki yang meninggalkan botol kosong yang berat sebelum pendakian terakhir: peringkat kedua tidak lagi membawa badan kosong <InlineMath math="200\text{ kg}" /> peringkat pertama. **Katakan <InlineMath math="x=T_2" /> ialah bahan api peringkat kedua, jadi <InlineMath math="T_1=600-x" />, lalu tulis keempat-empat jisimnya dalam <InlineMath math="x" />**.

<BlockMath math="\begin{aligned}
m_{\text{mula},1}=50+50+200+600=900\text{ kg},\qquad m_{\text{akhir},1}=900-(600-x)=300+x\\
m_{\text{mula},2}=100+x,\qquad m_{\text{akhir},2}=50+50=100\text{ kg}
\end{aligned}" />

## Menyatukan logaritma menjadi persamaan kuadratik

**Bahagikan kedua-dua belah dengan <InlineMath math="2" /> dan gunakan <InlineMath math="2\ln A+\ln B=\ln(A^2 B)" /> supaya semua logaritma hilang serentak**.

<BlockMath math="\begin{aligned}
4\ln\!\left(\frac{900}{300+x}\right)+2\ln\!\left(\frac{100+x}{100}\right)=2\ln(10)\\
\left(\frac{900}{300+x}\right)^2\cdot\frac{100+x}{100}=10\ \Longleftrightarrow\ 810\,(100+x)=(300+x)^2\\
x^2-210x+9000=0\ \Longleftrightarrow\ (x-60)(x-150)=0
\end{aligned}" />

Dua pembahagian bahan api mencapai laju sasaran dengan tepat: <InlineMath math="x=60\text{ kg}" /> dan <InlineMath math="x=150\text{ kg}" />. Jika faktor <InlineMath math="2" /> terlupa dimasukkan sebagai kuasa dua, persamaannya terus tersasar.

Puncak lengkung tepat pada <InlineMath math="x=100\text{ kg}" />, jadi garis sasaran memotong lengkung sekali di kiri dan sekali di kanan garis sempadan.

## Menyemak syarat minimum peringkat kedua

**Peringkat kedua sahaja mesti menyumbang sekurang-kurangnya <InlineMath math="2\ln(2)\,\tfrac{\text{km}}{\text{s}}" />, jadi <InlineMath math="x=60\text{ kg}" /> gugur kerana <InlineMath math="1.6 < 2" />**.

<BlockMath math="\begin{aligned}
2\ln\!\left(\frac{100+x}{100}\right)\ge2\ln(2)\ \Longleftrightarrow\ \frac{100+x}{100}\ge2\ \Longleftrightarrow\ x\ge100\\
T_2=150\text{ kg}\ \Longrightarrow\ T_1=600-150=450\text{ kg}
\end{aligned}" />

Semakan ringkas: dengan <InlineMath math="T_1=450\text{ kg}" /> dan <InlineMath math="T_2=150\text{ kg}" />, nisbah peringkat satu ialah <InlineMath math="\tfrac{900}{450}=2" /> dan peringkat dua ialah <InlineMath math="\tfrac{250}{100}=2.5" />, memberi <InlineMath math="2\ln 10" />. Mengekalkan <InlineMath math="x=60\text{ kg}" /> memberi perangkap <InlineMath math="540\text{ kg}" />. **Peringkat pertama menerima <InlineMath math="450\text{ kg}" /> bahan api**.

# Jawapan

Peringkat pertama menerima **<InlineMath math="450\text{ kg}" />** bahan api.
