# Warum die anderen Antworten falsch sind

- <InlineMath math="25{,}0\%" /> vertauscht die Isotope. **Der Mittelwert <InlineMath math="63{,}5" /> liegt näher an <InlineMath math="63" />, also ist <InlineMath math="^{63}\text{Cu}" /> das häufige**.
