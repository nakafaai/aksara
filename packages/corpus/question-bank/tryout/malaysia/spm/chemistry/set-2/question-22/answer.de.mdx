# Oxidation ist eine Erhöhung der Oxidationszahl

Ein Eisen(II)-Ion wird oxidiert, wenn **seine Oxidationszahl über <InlineMath math="+2" /> steigt**, es also ein Elektron abgibt.

In <InlineMath math="2\text{FeCl}_2 + \text{Cl}_2 \rightarrow 2\text{FeCl}_3" /> geht Eisen von <InlineMath math="+2" /> in <InlineMath math="\text{FeCl}_2" /> auf <InlineMath math="+3" /> in <InlineMath math="\text{FeCl}_3" />. Jedes <InlineMath math="\text{Fe}^{2+}" /> gibt ein Elektron an Chlor ab: <InlineMath math="\text{Fe}^{2+} \rightarrow \text{Fe}^{3+} + e^-" />.

# Warum die anderen Antworten falsch sind

- In der Reaktion mit Salzsäure bleibt Eisen bei <InlineMath math="+2" />. Das ist eine Neutralisation, keine Redoxreaktion.
- Mit Kupfer(II)-sulfat wird Eisen oxidiert, aber **es startet als metallisches Eisen bei <InlineMath math="0" />, nicht als Eisen(II)**. Eisen(II) ist das Produkt.
- Mit Natronlauge bleibt Eisen in einer Fällung bei <InlineMath math="+3" />.
