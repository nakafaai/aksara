# The polymer's mass equals the ethene's, each chain is a thousand units, and the chains are a thousand times fewer than the units

No mass is lost, so the ethene is <InlineMath math="\tfrac{5.60}{28}=0.200\text{ mol}" />, <InlineMath math="4.80\text{ dm}^3" />. **Each repeating unit is one ethene, <InlineMath math="M_r=28" />**, so a chain holds <InlineMath math="28\,000\div28=1000" /> units. The chains are <InlineMath math="\tfrac{5.60}{28\,000}=2.00\times10^{-4}\text{ mol}" />, <InlineMath math="2.00\times10^{-4}\times6.02\times10^{23}=1.20\times10^{20}" />.

# Why the other options are wrong

- <InlineMath math="1.20\times10^{23}" /> counts the ethene units, but **a thousand units join into each chain**.
- <InlineMath math="2000" /> counts <InlineMath math="\text{CH}_2" /> groups, but the repeating unit is a whole ethene, <InlineMath math="M_r=28" />.
- <InlineMath math="9.60\text{ dm}^3" /> uses two ethene per unit, but each unit comes from one ethene molecule.
