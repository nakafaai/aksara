Dengan fraksi <InlineMath math="x" /> untuk <InlineMath math="^{25}\text{Mg}" />, <InlineMath math="24\times0{,}79+25x+26(0{,}21-x)=24{,}3" />, jadi <InlineMath math="x=0{,}120" />, <InlineMath math="12{,}0\%" />.
