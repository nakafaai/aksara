# Each molecule gives one silicon dioxide and four hydrogen chloride, and only a tenth of the acid goes into the burette

Silicon tetrachloride has <InlineMath math="M_r=170" />, so <InlineMath math="0.0100\text{ mol}" />, which gives <InlineMath math="0.0100\times60=0.600\text{ g}" /> of silicon dioxide and **four hydrogen chloride each**, <InlineMath math="0.0400\text{ mol}" />. **The portion is a tenth of the flask**, <InlineMath math="0.00400\text{ mol}" />, which needs <InlineMath math="0.00400\div0.0500=0.0800\text{ dm}^3" />, <InlineMath math="80.0\text{ cm}^3" />. Each molecule had four <InlineMath math="\text{Si–Cl}" /> bonds, one shared pair each, <InlineMath math="0.0400\times6.02\times10^{23}=2.41\times10^{22}" />.

# Why the other options are wrong

- <InlineMath math="20.0\text{ cm}^3" /> gives one hydrogen chloride per molecule, but **each molecule has four chlorine atoms**.
- <InlineMath math="6.02\times10^{21}" /> counts one shared pair per molecule, but each of the four chlorine atoms shares its own.
- <InlineMath math="800\text{ cm}^3" /> titrates all the acid, but only the <InlineMath math="25.0\text{ cm}^3" /> portion goes into the flask.
