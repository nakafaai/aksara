# Lebih banyak karbon untuk oksigen yang sama bermaksud lebih banyak jelaga

Jelaga ialah **karbon yang tidak terbakar**. Bahan api yang lebih kaya karbon memerlukan lebih banyak oksigen untuk terbakar dengan lengkap, jadi di udara terbuka lebih banyak karbonnya tidak terbakar.

- Heksana, <InlineMath math="\text{C}_6\text{H}_{14}" />: <InlineMath math="\dfrac{72}{86} \times 100\% = 83.7\%" /> karbon.
- Heksena, <InlineMath math="\text{C}_6\text{H}_{12}" />: <InlineMath math="\dfrac{72}{84} \times 100\% = 85.7\%" /> karbon.

Heksena mempunyai dua atom hidrogen kurang untuk enam karbon yang sama, jadi bahagian jisimnya yang berupa karbon lebih besar, dan nyalaannya lebih berjelaga.

# Kenapa pilihan lain salah

- Kedua-dua molekul mempunyai **tepat enam atom karbon**.
- Takat didih tidak menentukan sejauh mana bahan api terbakar dengan lengkap.
- Penyahwarnaan air bromin menunjukkan ikatan ganda dua, tetapi tidak menerangkan jelaga.
