# Kenapa pilihan lain salah

- <InlineMath math="13{,}6^\circ\text{C}" /> dan <InlineMath math="5{,}70\text{ kJ}" /> membiarkan asam yang menentukan, padahal hanya ada <InlineMath math="0{,}0500\text{ mol}" /> basa untuk membentuk air.
- <InlineMath math="13{,}6^\circ\text{C}" /> dengan <InlineMath math="2{,}85\text{ kJ}" /> hanya memanaskan <InlineMath math="50\text{ g}" />, padahal **kalor menyebar ke kedua larutan, <InlineMath math="100\text{ g}" />**.
