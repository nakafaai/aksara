# Polimer adisi menyimpan setiap atom monomernya

Pada polimerisasi adisi, **ikatan rangkap dua terbuka dan monomer bergabung tanpa kehilangan atom apa pun**. Massa rantai sama dengan massa satu monomer dikali jumlah monomernya.

/>

- Massa molekul relatif kloroetena, <InlineMath math="\text{C}_2\text{H}_3\text{Cl}" />: <InlineMath math="2(12) + 3(1) + 35{,}5 = 62{,}5" />.
- Rantai <InlineMath math="2000" /> monomer: <InlineMath math="2000 \times 62{,}5 = 125\,000" />.

# Kenapa pilihan lain salah

- <InlineMath math="62\,500" /> hanya menghitung <InlineMath math="1000" /> monomer, **seakan-akan tiap unit berulang berisi dua monomer**.
- <InlineMath math="250\,000" /> menggandakan rantai, menghitung <InlineMath math="4000" /> monomer.
- <InlineMath math="89\,000" /> melewatkan klorin dan hanya menghitung karbon dan hidrogen.
