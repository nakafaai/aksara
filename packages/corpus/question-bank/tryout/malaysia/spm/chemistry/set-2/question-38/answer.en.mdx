# Cross-links act like springs between the chains

In natural rubber, the long polymer chains **slide past each other** when stretched and stay in their new positions. Vulcanisation ties the chains together with sulfur.

Natural rubber is still <InlineMath math="2.4\text{ cm}" /> longer after the load is removed, while vulcanised rubber is back within <InlineMath math="0.1\text{ cm}" />. In vulcanised rubber, sulfur atoms form cross-links between neighbouring chains. The links stop the chains sliding and pull them back when the load goes, so the rubber is more elastic and stretches less.

# Why the other options are wrong

- Sulfur uses some double bonds to form cross-links, but **the rubber stays flexible, not rigid**.
- Vulcanisation joins chains together. It does not break them.
- Forming cross-links uses up double bonds, so vulcanised rubber has fewer, not more.
