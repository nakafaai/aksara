# Count ions, not formula units

The same number of ions means the same **moles of ions**. Find the moles of each compound, then multiply by the ions in one formula unit.

- Sodium chloride, <InlineMath math="M_r = 58.5" />: <InlineMath math="\dfrac{5.85}{58.5} = 0.1" /> mol, with <InlineMath math="2" /> ions each, so <InlineMath math="0.2" /> mol of ions.
- Calcium chloride, <InlineMath math="M_r = 111" />: <InlineMath math="\dfrac{7.4}{111} = 0.0667" /> mol, with <InlineMath math="3" /> ions each, <InlineMath math="\text{Ca}^{2+}" /> and two <InlineMath math="\text{Cl}^-" />, so <InlineMath math="0.0667 \times 3 = 0.2" /> mol of ions.

# Why the other options are wrong

- <InlineMath math="11.1\text{ g}" /> of calcium chloride has the same number of **formula units**, <InlineMath math="0.1" /> mol, but <InlineMath math="0.3" /> mol of ions.
- <InlineMath math="2.8\text{ g}" /> of potassium hydroxide, <InlineMath math="M_r = 56" />, is <InlineMath math="0.05" /> mol with two ions each, so <InlineMath math="0.1" /> mol of ions.
- <InlineMath math="2.0\text{ g}" /> of magnesium oxide, <InlineMath math="M_r = 40" />, is <InlineMath math="0.05" /> mol with two ions each, so <InlineMath math="0.1" /> mol of ions.
