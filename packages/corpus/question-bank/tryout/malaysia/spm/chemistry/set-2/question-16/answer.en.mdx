# Apply the temperature change and the concentration change, one after the other

The cross disappears when the same amount of sulfur has formed in the same volume. **Halving the concentration halves the rate, so it doubles the time**, and the temperature effect is read from the chart.

- Temperature: at <InlineMath math="45^\circ\text{C}" />, the full-strength solution takes <InlineMath math="26\text{ s}" />.
- Concentration: <InlineMath math="15\text{ cm}^3" /> made up to <InlineMath math="50\text{ cm}^3" /> is <InlineMath math="\dfrac{15}{50} = 0.30" /> of the original concentration, so the rate is <InlineMath math="0.30" /> times as fast and the time is <InlineMath math="\dfrac{1}{0.30}" /> times as long.
- Expected time: <InlineMath math="26 \times \dfrac{50}{15} = 87\text{ s}" />.

# Why the other options are wrong

- <InlineMath math="26\text{ s}" /> uses the temperature effect only and **forgets that the solution was diluted**.
- <InlineMath math="200\text{ s}" /> scales the <InlineMath math="30^\circ\text{C}" /> time, so it uses the dilution but forgets the higher temperature.
- <InlineMath math="8\text{ s}" /> multiplies by <InlineMath math="0.30" /> instead of dividing, as if dilution sped the reaction up.
