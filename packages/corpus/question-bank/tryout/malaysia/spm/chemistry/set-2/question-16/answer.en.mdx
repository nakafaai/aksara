# Apply the temperature change and the concentration change, one after the other

The cross disappears when the same amount of sulfur has formed in the same volume. **Halving the concentration halves the rate, so it doubles the time**, and the temperature effect is read from the chart.

- Expected time: <InlineMath math="20 \times 2 = 40\text{ s}" />.

# Why the other options are wrong

- <InlineMath math="20\text{ s}" /> uses the temperature effect only and **forgets that the solution was diluted**.
- <InlineMath math="120\text{ s}" /> doubles the <InlineMath math="30^\circ\text{C}" /> time, so it uses the dilution but forgets the higher temperature.
- <InlineMath math="10\text{ s}" /> halves the time instead of doubling it, as if dilution sped the reaction up.
