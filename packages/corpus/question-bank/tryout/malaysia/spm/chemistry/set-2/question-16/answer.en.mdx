# Only the carbonate fizzes

Magnesium oxide is a base, so it neutralises the acid quietly. **Every bubble in the syringe came from calcium carbonate**, one carbon dioxide per carbonate, so the sample held <InlineMath math="0.0200\text{ mol}" /> of it, <InlineMath math="2.00\text{ g}" /> out of <InlineMath math="2.40\text{ g}" />. The <InlineMath math="16.7\%" /> in one choice is the oxide's share.

# The oxide still spends acid

The flask started with <InlineMath math="0.100\text{ mol}" /> of acid. The carbonate took <InlineMath math="0.0400\text{ mol}" />, and the <InlineMath math="0.400\text{ g}" /> of oxide, <InlineMath math="0.0100\text{ mol}" />, took another <InlineMath math="0.0200\text{ mol}" />. **The oxide never shows up on the graph, but it still empties the acid**. Forget it and <InlineMath math="0.0600\text{ mol}" /> seems to remain, which reads as <InlineMath math="0.600\text{ mol dm}^{-3}" />.

There is still acid when the gas stops, so the curve went flat because the carbonate ran out, not the acid.
