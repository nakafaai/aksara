# Polimer penambahan menyimpan setiap atom monomernya

Dalam pempolimeran penambahan, **ikatan ganda dua terbuka dan monomer bergabung tanpa kehilangan sebarang atom**. Jisim rantai ialah jisim satu monomer didarab dengan bilangan monomer.

/>

- Jisim molekul relatif kloroetena, <InlineMath math="\text{C}_2\text{H}_3\text{Cl}" />: <InlineMath math="2(12) + 3(1) + 35.5 = 62.5" />.
- Rantai <InlineMath math="2000" /> monomer: <InlineMath math="2000 \times 62.5 = 125\,000" />.

# Kenapa pilihan lain salah

- <InlineMath math="62\,500" /> hanya mengira <InlineMath math="1000" /> monomer, **seolah-olah setiap unit berulang mengandungi dua monomer**.
- <InlineMath math="250\,000" /> menggandakan rantai, mengira <InlineMath math="4000" /> monomer.
- <InlineMath math="89\,000" /> mengabaikan klorin dan hanya mengira karbon dan hidrogen.
