# The fluorine runs out first

Calcium is <InlineMath math="0.0200\text{ mol}" /> and fluorine <InlineMath math="0.0150\text{ mol}" />, one to one. Read the chart at <InlineMath math="0.800\text{ g}" />: the curve is already flat, because **the gas decides how much salt forms**. That gives <InlineMath math="0.0150\text{ mol}" /> of calcium fluoride, <InlineMath math="M_r=78" />, and <InlineMath math="0.0050\text{ mol}" /> of calcium left. Letting all the calcium react gives <InlineMath math="1.56\text{ g}" /> and no metal left.

# Fluorine atoms travel into the acid

The sulfuric acid swaps each calcium fluoride for **two hydrogen fluoride**, one for each fluoride ion in the lattice. So the acid made is <InlineMath math="0.0300\text{ mol}" />, and each needs one hydroxide. Taking one hydrogen fluoride per calcium fluoride halves this to <InlineMath math="15.0\text{ cm}^3" />.

<BlockMath math="\begin{aligned}
n(\text{Ca})&=\tfrac{0.800}{40}=0.0200>n(\text{F}_2)=\tfrac{360}{24\,000}=0.0150\ \Rightarrow\ m(\text{CaF}_2)=0.0150\times78=1.17\text{ g}\\
m(\text{Ca})'&=0.0050\times40=0.200\text{ g},\quad V(\text{NaOH})=\tfrac{2\times0.0150}{1.00}=0.0300\text{ dm}^3=30.0\text{ cm}^3
\end{aligned}" />
