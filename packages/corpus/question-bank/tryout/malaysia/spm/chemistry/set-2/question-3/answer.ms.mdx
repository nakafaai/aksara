# Hidrogen mengehadkan penurunan

Oksida itu <InlineMath math="0.200\text{ mol}" /> tetapi hidrogen hanya <InlineMath math="0.150\text{ mol}" />, jadi **hanya <InlineMath math="0.150\text{ mol}" /> kuprum terbentuk** dan sebahagian oksida kekal hitam. # Ion argentum mengehadkan penyesaran

Sekarang kuprum ialah <InlineMath math="0.150\text{ mol}" /> dan ion argentum <InlineMath math="0.220\text{ mol}" />. Satu atom kuprum mengambil dua ion argentum, jadi kuprum itu memerlukan <InlineMath math="0.300\text{ mol}" /> dan **ion argentum habis dahulu**.
