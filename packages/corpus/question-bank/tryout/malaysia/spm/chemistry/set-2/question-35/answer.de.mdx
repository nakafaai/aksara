# Das Kupfer am Boden des Becherglases

Das abgeschiedene Kupfer entspricht dem verbrauchten Zink, <InlineMath math="0{,}0100\text{ mol}" /> oder <InlineMath math="0{,}640\text{ g}" />. **Zwei Elektronen pro Atom halbieren das Kupfer nicht**: Ein Zinkatom gibt beide Elektronen an ein Kupferion ab, das trotzdem ein einziges Kupferatom wird, und <InlineMath math="0{,}320\text{ g}" /> halbiert ohne Grund.
