# Titrasi menghitung basa yang terpakai, massa membaginya antara ester dan asam, keduanya memberi garam, tetapi hanya ester yang memberi etanol

Satu porsi punya <InlineMath math="0{,}00400\text{ mol}" /> basa sisa, jadi **seluruh campuran punya sepuluh kalinya**, <InlineMath math="0{,}0400\text{ mol}" />, dan <InlineMath math="0{,}100-0{,}0400=0{,}0600\text{ mol}" /> terpakai.
