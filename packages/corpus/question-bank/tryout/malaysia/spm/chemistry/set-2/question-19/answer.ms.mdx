# Atom karbon membezakan kedua-dua bahan api

Selepas penyejukan, air menjadi cecair, jadi alkali hanya bertemu karbon dioksida dan baki oksigen. Bagi gas pada keadaan yang sama, isi padu mengira molekul, dan **molekul metana membawa satu atom karbon manakala molekul propana membawa tiga**.

Sebanyak <InlineMath math="2.88\text{ dm}^3" /> karbon dioksida daripada <InlineMath math="1.20\text{ dm}^3" /> bahan api bermakna purata <InlineMath math="2.40" /> atom karbon bagi setiap molekul bahan api. Nilai itu berada pada <InlineMath math="70\%" /> daripada jarak antara satu dan tiga, jadi <InlineMath math="70\%" /> bahan api ialah propana, iaitu <InlineMath math="0.840\text{ dm}^3" />. Pilihan <InlineMath math="0.360\text{ dm}^3" /> ialah bahagian metana.

# Oksigen yang ditinggalkan nyalaan

Propana bahan api yang lebih rakus, **lima oksigen bagi setiap molekul berbanding dua bagi metana**. Bersama-sama, kedua-duanya membakar <InlineMath math="4.92\text{ dm}^3" /> dan meninggalkan <InlineMath math="1.08\text{ dm}^3" />. Menolak <InlineMath math="2.88\text{ dm}^3" /> daripada oksigen memberi <InlineMath math="3.12\text{ dm}^3" />, tetapi isi padu karbon dioksida tidak memberitahu terus berapa oksigen yang digunakan.

# Magnesium menyerap bakinya

Setiap molekul oksigen menukarkan dua atom magnesium kepada oksida, jadi **<InlineMath math="0.0450\text{ mol}" /> oksigen menghasilkan <InlineMath math="0.0900\text{ mol}" /> magnesium oksida**. Satu oksida bagi setiap molekul oksigen memberi separuh jisim, <InlineMath math="1.80\text{ g}" />, dan pilihan <InlineMath math="10.4\text{ g}" /> membawa kesilapan <InlineMath math="3.12\text{ dm}^3" /> ke langkah ini.

<BlockMath math="\begin{aligned}
1+2p&=\tfrac{2.88}{1.20}=2.40\ \Rightarrow\ p=0.700,\quad V(\text{C}_3\text{H}_8)=0.700\times1.20=0.840\text{ dm}^3\\
V(\text{O}_2)'&=6.00-(2\times0.360+5\times0.840)=1.08\text{ dm}^3\\
m(\text{MgO})&=2\times\tfrac{1.08}{24}\times40=3.60\text{ g}
\end{aligned}" />

Magnesium tidak pernah menyentuh bahan api, jadi pembakaran tadi hanya penting di sini melalui oksigen yang ditinggalkannya.
