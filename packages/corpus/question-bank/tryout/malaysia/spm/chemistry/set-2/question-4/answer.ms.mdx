# Formula empirik daripada pembakaran, jisim molar daripada wap

Data pembakaran memberi **nisbah atom**, dan isi padu wap memberi **bilangan unit itu dalam satu molekul**. Oksigen dalam P dicari melalui beza, kerana pembakaran juga menggunakan oksigen daripada udara.

- Karbon: <InlineMath math="0.44 \times \dfrac{12}{44} = 0.12\text{ g}" />. Hidrogen: <InlineMath math="0.18 \times \dfrac{2}{18} = 0.02\text{ g}" />. Oksigen: <InlineMath math="0.30 - 0.12 - 0.02 = 0.16\text{ g}" />.

- Mol: C <InlineMath math="0.01" />, H <InlineMath math="0.02" />, O <InlineMath math="0.01" />, jadi formula empirik ialah <InlineMath math="\text{CH}_2\text{O}" />, jisim <InlineMath math="30" />.
- Wap: <InlineMath math="\dfrac{0.120}{24} = 0.0050\text{ mol}" />, jadi <InlineMath math="M_r = \dfrac{0.30}{0.0050} = 60" />.
- <InlineMath math="\dfrac{60}{30} = 2" />, jadi formula molekul ialah <InlineMath math="\text{C}_2\text{H}_4\text{O}_2" />.

# Kenapa pilihan lain salah

- <InlineMath math="\text{CH}_2\text{O}" /> ialah formula empirik: ia **berhenti sebelum menggunakan isi padu wap**.
- <InlineMath math="\text{C}_2\text{H}_2\text{O}_2" /> mengira satu atom hidrogen bagi setiap molekul air, bukan dua.
- <InlineMath math="\text{C}_3\text{H}_6\text{O}_3" /> mengambil tiga unit empirik tanpa menyemak jisim molar: <InlineMath math="M_r" />nya ialah <InlineMath math="90" />, tetapi wap memberi <InlineMath math="60" />.
