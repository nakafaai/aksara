# Atom fluorin pindah ke asam

Asam sulfat menukar tiap kalsium fluorida menjadi **dua hidrogen fluorida**, satu untuk tiap ion fluorida di kisi. Jadi asam yang terbentuk <InlineMath math="0{,}0300\text{ mol}" />, dan tiap satu butuh satu hidroksida. Mengambil satu hidrogen fluorida per kalsium fluorida membagi dua hasilnya menjadi <InlineMath math="15{,}0\text{ cm}^3" />.

n(\text{Ca})&=\tfrac{0{,}800}{40}=0{,}0200>n(\text{F}_2)=\tfrac{360}{24\,000}=0{,}0150\ \Rightarrow\ m(\text{CaF}_2)=0{,}0150\times78=1{,}17\text{ g}\\
