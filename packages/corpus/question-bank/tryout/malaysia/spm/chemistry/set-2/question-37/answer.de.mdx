# Die Bindungen der Kette zählen, dann ihr Wasser abziehen

Jede Amidbindung entsteht, wenn eine Carboxygruppe der Säure auf eine Aminogruppe des Diamins trifft, und dabei wird ein Wassermolekül frei. **Eine gerade Kette aus <InlineMath math="1000" /> Monomeren hat eine Bindung weniger, als sie Monomere hat**, so wie eine Perlenkette eine Lücke weniger hat als Perlen.

Die Kette setzt also <InlineMath math="999" /> Wassermoleküle frei und hat eine relative Molekülmasse von <InlineMath math="113{.}018" />.

# Warum die anderen Antworten falsch sind

- <InlineMath math="1000" /> Wassermoleküle gibt eines pro Monomer. Die beiden Kettenenden behalten ihre Gruppen, also gibt es eine Bindung weniger.
- <InlineMath math="500" /> zählt ein Wassermolekül pro Monomerpaar. **Jede Bindung zwischen Nachbarn setzt Wasser frei, auch die zwischen einem Paar und dem nächsten**.
- <InlineMath math="131{.}000" /> zählt das Wasser richtig, zieht seine Masse aber nie von den Monomeren ab.
