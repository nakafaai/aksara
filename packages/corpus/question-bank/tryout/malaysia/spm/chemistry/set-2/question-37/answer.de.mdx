# Das Blatt nach dem Schwefel wiegen

Beim Vulkanisieren kommt der Schwefel zum Kautschuk dazu, also wiegt das fertige Blatt <InlineMath math="13{,}6+0{,}640=14{,}24\text{ g}" />. **Der Prozentsatz bezieht sich auf dieses schwerere Blatt**, das ergibt <InlineMath math="4{,}49\%" />. Bezogen auf die rohen <InlineMath math="13{,}6\text{ g}" /> kämen <InlineMath math="4{,}71\%" /> heraus, ein Anteil an einem Blatt, das es so nicht mehr gibt.

# Zwei Schwefelatome und zwei Einheiten pro Brücke

Der Schwefel liefert <InlineMath math="0{,}0200\text{ mol}" /> Atome, und **jede Brücke verbraucht zwei davon**, also entstehen <InlineMath math="0{,}0100\text{ mol}" /> Brücken, <InlineMath math="6{,}02\times10^{21}" /> Stück. Wer jedes Schwefelatom für eine eigene Brücke hält, zählt <InlineMath math="1{,}20\times10^{22}" />.

Jede Brücke hat zwei Enden, eines an jeder Kette, also tragen <InlineMath math="0{,}0200\text{ mol}" /> Isopreneinheiten eine Quervernetzung. Der Rohkautschuk hat <InlineMath math="13{,}6\div68=0{,}200\text{ mol}" /> Einheiten, und jede zehnte ist vernetzt. Bekommt jede Brücke nur eine Einheit, halbiert sich das auf <InlineMath math="5{,}00\%" />.
