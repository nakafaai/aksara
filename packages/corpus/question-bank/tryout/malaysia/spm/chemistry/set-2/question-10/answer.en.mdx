# The height stops rising when one reactant runs out

The precipitate keeps growing **while every new drop of lead(II) ions still finds iodide ions to react with**. Once the iodide is used up, more lead(II) nitrate adds nothing.

The height levels off from tube <InlineMath math="5" />, so <InlineMath math="5.0\text{ cm}^3" /> of lead(II) nitrate exactly uses up the iodide.

- Moles of <InlineMath math="\text{Pb}^{2+}" />: <InlineMath math="0.50 \times \dfrac{5.0}{1000} = 0.0025\text{ mol}" />.
- Moles of <InlineMath math="\text{I}^-" />: <InlineMath math="1.0 \times \dfrac{5.0}{1000} = 0.0050\text{ mol}" />.
- Ratio <InlineMath math="\text{Pb}^{2+} : \text{I}^-" /> is <InlineMath math="0.0025 : 0.0050 = 1 : 2" />.

So <InlineMath math="\text{Pb}^{2+} + 2\text{I}^- \rightarrow \text{PbI}_2" />, which also balances the charges.

# Why the other options are wrong

- A <InlineMath math="1 : 1" /> ratio would level off at tube <InlineMath math="10" />, and **PbI leaves a charge of <InlineMath math="+1" /> unbalanced**.
- A <InlineMath math="2 : 1" /> ratio would need tube <InlineMath math="20" />.
- A <InlineMath math="1 : 4" /> ratio would level off at tube <InlineMath math="2.5" />, and a charged complex ion is not a precipitate.
