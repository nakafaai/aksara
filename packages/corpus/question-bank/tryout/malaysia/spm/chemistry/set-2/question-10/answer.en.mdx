# Measuring the ammonium by what it leaves

Ammonium chloride cannot be titrated directly here, so the method gives it a known excess of alkali and **titrates the alkali that survives**. The acid used, <InlineMath math="0.00750\text{ mol}" />, equals the sodium hydroxide left, so the ammonium ions took <InlineMath math="0.0175\text{ mol}" />. Treating the titre as the ammonium itself gives <InlineMath math="26.4\%" />.

Each ammonium ion releases one ammonia molecule, <InlineMath math="0.0175\text{ mol}" /> or <InlineMath math="420\text{ cm}^3" />. Doubling that, as if two hydroxide ions freed each ammonia, gives <InlineMath math="840\text{ cm}^3" />.

# Both salts carry chloride

The ammonium chloride weighs <InlineMath math="0.936\text{ g}" />, so the sodium chloride is the remaining <InlineMath math="0.584\text{ g}" />, <InlineMath math="0.0100\text{ mol}" />. The silver nitrate does not care which cation came with the chloride, so it precipitates **all <InlineMath math="0.0275\text{ mol}" /> of chloride ions**. Counting only the ammonium salt's chloride gives <InlineMath math="2.51\text{ g}" />.
