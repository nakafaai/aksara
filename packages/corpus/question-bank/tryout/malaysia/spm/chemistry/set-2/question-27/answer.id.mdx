# Tiap tambahan unit karbon menambah kalor yang sama

Anggota deret homolog berselisih **satu unit <InlineMath math="\text{CH}_2" />**. Membakar unit tambahan itu melepas energi yang hampir sama setiap kali, jadi kalor pembakaran naik dengan langkah yang sama.

Langkahnya <InlineMath math="1560 - 890 = 670" />, <InlineMath math="2220 - 1560 = 660" />, dan <InlineMath math="2880 - 2220 = 660" />. Pentana punya satu atom karbon lebih banyak daripada butana:

# Kenapa pilihan lain salah

- <InlineMath math="3200\text{ kJ mol}^{-1}" /> hanya menambah sekitar setengah langkah, **seakan-akan deretnya mulai mendatar**.
- <InlineMath math="4200\text{ kJ mol}^{-1}" /> menambah dua langkah, yaitu ramalan untuk heksana.
- <InlineMath math="2950\text{ kJ mol}^{-1}" /> hampir tidak melewati butana, mengabaikan unit <InlineMath math="\text{CH}_2" /> tambahan.
