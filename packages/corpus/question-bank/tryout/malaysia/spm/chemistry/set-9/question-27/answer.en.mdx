# One bromine molecule adds across each double bond, so the bromine counts the alkene, and the product carries both bromine atoms

The bromine is <InlineMath math="0.0500\times0.200=0.0100\text{ mol}" />. **An alkene has one double bond, and each takes one bromine molecule**, so the alkene is <InlineMath math="0.0100\text{ mol}" /> and <InlineMath math="M_r=0.700\div0.0100=70" />. <InlineMath math="14n=70" /> gives <InlineMath math="n=5" />: <InlineMath math="\text{C}_5\text{H}_{10}" />. **Both bromine atoms join the molecule**, giving <InlineMath math="\text{C}_5\text{H}_{10}\text{Br}_2" />, <InlineMath math="M_r=230" />, <InlineMath math="0.0100\times230=2.30\text{ g}" />.

# Why the other options are wrong

- <InlineMath math="\text{C}_5\text{H}_{12}" /> is an alkane, which does not decolourise bromine. **The alkene is <InlineMath math="\text{C}_n\text{H}_{2n}" />**.
- <InlineMath math="\text{C}_{10}\text{H}_{20}" /> lets two alkene molecules share one bromine molecule, but each double bond takes a whole one.
- <InlineMath math="1.50\text{ g}" /> adds only one bromine atom, but addition puts one on each carbon of the double bond.
