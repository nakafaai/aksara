# Tiap atom menyumbang elektron valensinya, tiap dua elektron membentuk satu molekul hidrogen, dan magnesium memberi dua per atom

Aluminiumnya <InlineMath math="2{,}70\div27=0{,}100\text{ mol}" />. **Tiap atom menyumbang tiga elektron valensi**, jadi <InlineMath math="0{,}300\text{ mol}" />, <InlineMath math="1{,}81\times10^{23}" /> elektron. Dalam asam elektron ini mereduksi ion hidrogen, <InlineMath math="2\text{H}^++2e^-\rightarrow\text{H}_2" />, **dua elektron per molekul hidrogen**, jadi <InlineMath math="0{,}150\text{ mol}" />, <InlineMath math="3{,}60\text{ dm}^3" />. Magnesium memberi dua elektron, jadi satu hidrogen per atom: <InlineMath math="0{,}150\text{ mol}" /> magnesium, <InlineMath math="3{,}60\text{ g}" />.
