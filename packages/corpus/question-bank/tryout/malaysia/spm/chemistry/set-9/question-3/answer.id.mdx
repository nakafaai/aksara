# Timbang cairannya, hitung sebagai molekul diatomik, biarkan tiap mol mengisi volume molar, lalu hitung dua atom per molekul di balon

Satu sentimeter kubik bermassa <InlineMath math="0{,}807\text{ g}" />. **Nitrogen adalah <InlineMath math="\text{N}_2" />, <InlineMath math="M_r=28" />**, jadi itu <InlineMath math="0{,}0288\text{ mol}" />, yang mengembang menjadi <InlineMath math="0{,}0288\times24{.}000=692\text{ cm}^3" /> gas. Balon itu perlu <InlineMath math="5000\div692=7{,}23\text{ cm}^3" /> cairan. Balon memuat <InlineMath math="5{,}00\div24=0{,}208\text{ mol}" /> molekul, **dan tiap molekul punya dua atom**, <InlineMath math="0{,}417\times6{,}02\times10^{23}=2{,}51\times10^{23}" />.
