# Compare the two gases one to one, let the hydrogen chloride run out, and give each ammonium ion exactly one dative bond

The ammonia is <InlineMath math="1.70\div17=0.100\text{ mol}" /> and the hydrogen chloride <InlineMath math="1.80\div24=0.0750\text{ mol}" />. **They react one to one, so the hydrogen chloride runs out** and forms <InlineMath math="0.0750\text{ mol}" /> of ammonium chloride, <InlineMath math="0.0750\times53.5=4.01\text{ g}" />. The other <InlineMath math="0.0250\text{ mol}" /> of ammonia stays as gas, <InlineMath math="600\text{ cm}^3" />. **Each ammonium ion forms one dative bond**, so <InlineMath math="0.0750\times6.02\times10^{23}=4.52\times10^{22}" /> form.

# Why the other options are wrong

- <InlineMath math="5.35\text{ g}" /> lets all the ammonia react. **The hydrogen chloride runs out first**.
- <InlineMath math="1.81\times10^{23}" /> counts all four bonds in each ammonium ion, but only the new one is dative.
- No dative bonds ignores how the ammonium ion forms: the nitrogen's lone pair bonds to the hydrogen ion.
