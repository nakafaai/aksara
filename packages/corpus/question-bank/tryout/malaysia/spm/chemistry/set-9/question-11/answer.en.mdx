# Count the shared pairs in each molecule and double them for electrons, then let each lone pair make one dative bond

The ammonia is <InlineMath math="3.40\div17=0.200\text{ mol}" />. Each molecule has three nitrogen to hydrogen bonds, and **each covalent bond is one shared pair, two electrons**, so a molecule shares <InlineMath math="6" /> electrons and the sample <InlineMath math="1.20\times6.02\times10^{23}=7.22\times10^{23}" />. Each molecule has one lone pair, and **forming the ammonium ion turns it into exactly one dative bond**, so <InlineMath math="0.200\times6.02\times10^{23}=1.20\times10^{23}" /> dative bonds form.

# Why the other options are wrong

- <InlineMath math="3.61\times10^{23}" /> counts shared pairs, not electrons. **Each covalent bond shares two electrons**.
- No dative bonds ignores how the ammonium ion forms: the nitrogen's lone pair bonds to the hydrogen ion.
- <InlineMath math="4.82\times10^{23}" /> counts all four bonds in each ammonium ion, but only the new one is dative.
