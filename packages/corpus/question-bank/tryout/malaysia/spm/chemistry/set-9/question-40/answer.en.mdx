# Moles, not masses, decide which reactant runs out, and only the pure product counts towards the yield

Salicylic acid has <InlineMath math="M_r=138" />, so <InlineMath math="2.76\text{ g}" /> is <InlineMath math="0.0200\text{ mol}" />. Ethanoic anhydride has <InlineMath math="M_r=102" />, so <InlineMath math="3.06\text{ g}" /> is <InlineMath math="0.0300\text{ mol}" />. **They react one to one, so the salicylic acid runs out**, and the most aspirin possible is <InlineMath math="0.0200\text{ mol}" />, <InlineMath math="0.0200\times180=3.60\text{ g}" />. **The crude solid still holds impurities**, so the yield uses the pure <InlineMath math="2.70\text{ g}" />, <InlineMath math="2.70\div3.60=75.0\%" />. The pure aspirin fills <InlineMath math="2.70\div0.300=9" /> tablets.

# Why the other options are wrong

- Ethanoic anhydride and <InlineMath math="50.0\%" /> compare the moles the wrong way. **<InlineMath math="0.0300\text{ mol}" /> of anhydride is more than the <InlineMath math="0.0200\text{ mol}" /> of acid**, so it is in excess.
- <InlineMath math="80.0\%" /> uses the crude <InlineMath math="2.88\text{ g}" />, which still holds impurities.
- <InlineMath math="12" /> tablets uses the theoretical <InlineMath math="3.60\text{ g}" />, not the aspirin actually obtained.
