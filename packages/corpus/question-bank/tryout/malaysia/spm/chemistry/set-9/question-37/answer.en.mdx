# Count repeating units, give each one chlorine atom and so one hydrogen chloride, then trap each with one sodium hydroxide

Each repeating unit keeps the monomer's formula, <InlineMath math="\text{C}_2\text{H}_3\text{Cl}" />, <InlineMath math="M_r=62.5" />, so the waste is <InlineMath math="1000\div62.5=16.0\text{ mol}" /> of units. **Each unit holds one chlorine atom**, so <InlineMath math="16.0\text{ mol}" /> of hydrogen chloride forms, <InlineMath math="16.0\times24=384\text{ dm}^3" />. <InlineMath math="\text{NaOH}+\text{HCl}\rightarrow\text{NaCl}+\text{H}_2\text{O}" /> is one to one, so <InlineMath math="16.0\times40=640\text{ g}" /> of sodium hydroxide is needed.

# Why the other options are wrong

- <InlineMath math="192\text{ dm}^3" /> and <InlineMath math="320\text{ g}" /> give one hydrogen chloride per two units. **Every unit carries its own chlorine atom**.
- <InlineMath math="320\text{ g}" /> takes two hydrogen chloride per sodium hydroxide, but the neutralisation is one to one.
- <InlineMath math="768\text{ dm}^3" /> gives each unit two chlorine atoms, but chloroethene has one.
