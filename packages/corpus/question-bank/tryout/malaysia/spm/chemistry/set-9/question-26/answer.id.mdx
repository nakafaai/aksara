# Kenapa pilihan lain salah

- <InlineMath math="240\text{ cm}^3" /> memberi satu molekul hidrogen per elektron. **Tiap molekul hidrogen mengambil dua elektron**.
- <InlineMath math="0{,}0500\text{ mol dm}^{-3}" /> membuat satu natrium hipoklorit per natrium hidroksida, padahal persamaannya membuat satu per molekul klorin.
- <InlineMath math="0{,}0250\text{ mol dm}^{-3}" /> natrium hidroksida sisa memakainya satu banding satu dengan klorin, padahal tiap molekul klorin mengambil dua.
