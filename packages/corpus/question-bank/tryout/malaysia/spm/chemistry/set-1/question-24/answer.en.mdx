# Two opposite changes in mass

Zinc is more electropositive, so it displaces copper: <InlineMath math="\text{Zn}+\text{Cu}^{2+}\rightarrow\text{Zn}^{2+}+\text{Cu}" />. The plate **loses the zinc that dissolves** and at the same time **gains the copper that deposits**, in a <InlineMath math="1:1" /> mole ratio.

<BlockMath math="\begin{aligned}
n(\text{Cu}^{2+})&=0.10\times\frac{100}{1000}=0.010\text{ mol}\\
\text{zinc lost}&=0.010\times65=0.65\text{ g}\\
\text{copper gained}&=0.010\times64=0.64\text{ g}\\
\Delta m&=0.64-0.65=-0.010\text{ g}
\end{aligned}" />

The chart sets the two changes against each other. The loss bar is a little longer than the gain bar, so the net change is a small loss.

Each zinc atom that dissolves is replaced by one slightly lighter copper atom. So the mass of the plate decreases by <InlineMath math="0.010\text{ g}" />.

# Why the other options are wrong

- Increasing by <InlineMath math="0.64\text{ g}" /> counts only the copper deposited and **forgets the zinc that dissolves**.
- Decreasing by <InlineMath math="0.65\text{ g}" /> counts only the zinc that dissolves and forgets the copper that sticks.
- Increasing by <InlineMath math="0.010\text{ g}" /> flips the sign, but the atoms arriving are lighter than those leaving.
