# Compare only the fair data

A conclusion about concentration is valid only from runs in which **the other variables stay fixed**. The third run uses <InlineMath math="3.0\text{ cm}" /> of ribbon, so it also takes longer because there is more magnesium to dissolve. That result cannot be compared fairly.

The first two runs both use <InlineMath math="2.0\text{ cm}" /> of ribbon. The higher concentration gives the shorter time, <InlineMath math="20\text{ s}" /> against <InlineMath math="45\text{ s}" />, so the rate is higher. Notice too that the rate does not exactly double: <InlineMath math="\tfrac1{20}" /> against <InlineMath math="\tfrac1{45}" /> is <InlineMath math="2.25" /> times. So the valid conclusion is that the rate increases as concentration increases, based on the first two results only.

# Why the other options are wrong

- Direct proportion is not supported, because the rate rises <InlineMath math="2.25" /> times when the concentration doubles, and **the third result is not fair**.
- The big rise in time from <InlineMath math="1.0" /> to <InlineMath math="0.5\text{ mol dm}^{-3}" /> is partly due to the longer ribbon, so it cannot be used.
- Keeping the acid volume constant makes the comparison fair and does not prevent a conclusion.
