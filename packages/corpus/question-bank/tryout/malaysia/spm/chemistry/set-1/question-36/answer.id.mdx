# Hitung unit berulang, bukan rantai

Setiap unit berulang <InlineMath math="-\text{CH}_2-\text{CHCl}-" /> berasal dari satu monomer dan membawa **tepat satu atom klorin**. Jadi, banyaknya atom klorin sama dengan banyaknya unit berulang. Massa molekul rantai tidak dibutuhkan untuk itu, karena massa sampel langsung dibagi massa satu unit berulang.

<BlockMath math="\begin{aligned}
M_r(\text{C}_2\text{H}_3\text{Cl})&=2(12)+3(1)+35{,}5=62{,}5\\
n(\text{unit})&=\frac{15{,}625}{62{,}5}=0{,}25\text{ mol}\\
N(\text{Cl})&=0{,}25\times6{,}02\times10^{23}\approx1{,}51\times10^{23}
\end{aligned}" />

Cek: tiap rantai punya <InlineMath math="\tfrac{31{.}250}{62{,}5}=500" /> unit, dan sampel berisi <InlineMath math="\tfrac{15{,}625}{31{.}250}=5{,}0\times10^{-4}" /> mol rantai, sehingga <InlineMath math="500\times5{,}0\times10^{-4}=0{,}25" /> mol unit, hasilnya sama. Jadi, sampel mengandung sekitar <InlineMath math="1{,}51\times10^{23}" /> atom klorin.

# Mengapa pilihan lain salah

- <InlineMath math="3{,}01\times10^{20}" /> adalah banyaknya **rantai polimer**, padahal tiap rantai membawa <InlineMath math="500" /> atom klorin.
- <InlineMath math="3{,}01\times10^{23}" /> menganggap tiap unit berulang membawa dua atom klorin.
- <InlineMath math="3{,}36\times10^{23}" /> memakai massa etena, <InlineMath math="28" />, sebagai massa unit berulang.
