# Dari ion kembali ke atom

Ion <InlineMath math="\text{X}^{2+}" /> terbentuk saat atom X **melepas dua elektron**, jadi atom netral X punya <InlineMath math="18+2=20" /> elektron dan <InlineMath math="20" /> proton. Nomor nukleon adalah proton ditambah neutron, <InlineMath math="20+20=40" />, sehingga atomnya <InlineMath math="^{40}_{20}\text{X}" />.

Atom Y dengan susunan <InlineMath math="2{,}8.7" /> menerima satu elektron dan membentuk ion <InlineMath math="\text{Y}^-" />. Agar muatan senyawa netral, satu ion <InlineMath math="\text{X}^{2+}" /> butuh dua ion <InlineMath math="\text{Y}^-" />.

<BlockMath math="(+2)+2(-1)=0\ \Rightarrow\ \text{XY}_2" />

Jadi, atom X adalah <InlineMath math="^{40}_{20}\text{X}" /> dan senyawanya <InlineMath math="\text{XY}_2" />.
