# Kira unit berulang, bukan rantai

Setiap unit berulang <InlineMath math="-\text{CH}_2-\text{CHCl}-" /> berasal daripada satu monomer dan membawa **tepat satu atom klorin**. Jadi, bilangan atom klorin sama dengan bilangan unit berulang. Jisim molekul rantai tidak diperlukan untuk itu, kerana jisim sampel terus dibahagi dengan jisim satu unit berulang.

<BlockMath math="\begin{aligned}
M_r(\text{C}_2\text{H}_3\text{Cl})&=2(12)+3(1)+35.5=62.5\\
n(\text{unit})&=\frac{15.625}{62.5}=0.25\text{ mol}\\
N(\text{Cl})&=0.25\times6.02\times10^{23}\approx1.51\times10^{23}
\end{aligned}" />

Semak: setiap rantai mempunyai <InlineMath math="\tfrac{31{,}250}{62.5}=500" /> unit, dan sampel mengandungi <InlineMath math="\tfrac{15.625}{31{,}250}=5.0\times10^{-4}" /> mol rantai, jadi <InlineMath math="500\times5.0\times10^{-4}=0.25" /> mol unit, hasilnya sama. Maka, sampel itu mengandungi kira-kira <InlineMath math="1.51\times10^{23}" /> atom klorin.

# Kenapa pilihan lain salah

- <InlineMath math="3.01\times10^{20}" /> ialah bilangan **rantai polimer**, sedangkan setiap rantai membawa <InlineMath math="500" /> atom klorin.
- <InlineMath math="3.01\times10^{23}" /> menganggap setiap unit berulang membawa dua atom klorin.
- <InlineMath math="3.36\times10^{23}" /> menggunakan jisim etena, <InlineMath math="28" />, sebagai jisim unit berulang.
