# From the ion back to the atom

The ion <InlineMath math="\text{X}^{2+}" /> forms when atom X **loses two electrons**, so the neutral atom X has <InlineMath math="18+2=20" /> electrons and <InlineMath math="20" /> protons. The nucleon number is protons plus neutrons, <InlineMath math="20+20=40" />, so the atom is <InlineMath math="^{40}_{20}\text{X}" />.

Atom Y with the arrangement <InlineMath math="2.8.7" /> gains one electron and forms the ion <InlineMath math="\text{Y}^-" />. For the compound to be neutral, one <InlineMath math="\text{X}^{2+}" /> ion needs two <InlineMath math="\text{Y}^-" /> ions.

<BlockMath math="(+2)+2(-1)=0\ \Rightarrow\ \text{XY}_2" />

So atom X is <InlineMath math="^{40}_{20}\text{X}" /> and the compound is <InlineMath math="\text{XY}_2" />.

# Why the other options are wrong

- <InlineMath math="^{38}_{18}\text{X}" /> uses the ion's electron count as the proton count, but **the number of protons does not change** when an ion forms.
- <InlineMath math="\text{X}_2\text{Y}" /> inverts the ratio, giving charges of <InlineMath math="+4-1" />, which is not neutral.
- <InlineMath math="^{36}_{16}\text{X}" /> treats a <InlineMath math="2+" /> charge as gaining two electrons.
