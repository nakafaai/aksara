# Count repeating units, not chains

Each repeating unit <InlineMath math="-\text{CH}_2-\text{CHCl}-" /> comes from one monomer and carries **exactly one chlorine atom**. So the number of chlorine atoms equals the number of repeating units. The chain's molecular mass is not needed for that, because the sample mass divides straight into the mass of one repeating unit.

<BlockMath math="\begin{aligned}
M_r(\text{C}_2\text{H}_3\text{Cl})&=2(12)+3(1)+35.5=62.5\\
n(\text{units})&=\frac{15.625}{62.5}=0.25\text{ mol}\\
N(\text{Cl})&=0.25\times6.02\times10^{23}\approx1.51\times10^{23}
\end{aligned}" />

Check: each chain has <InlineMath math="\tfrac{31{,}250}{62.5}=500" /> units, and the sample holds <InlineMath math="\tfrac{15.625}{31{,}250}=5.0\times10^{-4}" /> mol of chains, so <InlineMath math="500\times5.0\times10^{-4}=0.25" /> mol of units, the same result. So the sample contains about <InlineMath math="1.51\times10^{23}" /> chlorine atoms.

# Why the other options are wrong

- <InlineMath math="3.01\times10^{20}" /> is the number of **polymer chains**, but each chain carries <InlineMath math="500" /> chlorine atoms.
- <InlineMath math="3.01\times10^{23}" /> assumes each repeating unit carries two chlorine atoms.
- <InlineMath math="3.36\times10^{23}" /> uses the mass of ethene, <InlineMath math="28" />, as the mass of the repeating unit.
