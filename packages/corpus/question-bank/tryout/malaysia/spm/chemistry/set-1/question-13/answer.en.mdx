# Back titration: the acid used is the difference

Sodium hydroxide neutralises only **the acid left over**. So the acid that reacted with calcium carbonate is the starting acid minus the leftover acid. Then use the <InlineMath math="1:2" /> ratio between calcium carbonate and hydrochloric acid.

The chart splits the starting acid into two parts. The sodium hydroxide measures the leftover part, so the rest is what the calcium carbonate used.

<BlockMath math="\begin{aligned}
n(\text{HCl at start})&=1.00\times0.0500=0.0500\text{ mol}\\
n(\text{HCl left})&=n(\text{NaOH})=1.00\times0.0300=0.0300\text{ mol}\\
n(\text{HCl reacted})&=0.0500-0.0300=0.0200\text{ mol}\\
n(\text{CaCO}_3)&=\tfrac12\times0.0200=0.0100\text{ mol}\ \Rightarrow\ m=1.00\text{ g}\\
\text{percentage}&=\frac{1.00}{2.50}\times100\%=40\%
\end{aligned}" />

So the sample contains <InlineMath math="40\%" /> calcium carbonate.

# Why the other options are wrong

- <InlineMath math="80\%" /> uses a <InlineMath math="1:1" /> ratio, but **one mole of calcium carbonate reacts with two moles of acid**.
- <InlineMath math="60\%" /> uses the leftover acid as the acid that reacted.
- <InlineMath math="100\%" /> uses all of the starting acid, as if none were left over.
