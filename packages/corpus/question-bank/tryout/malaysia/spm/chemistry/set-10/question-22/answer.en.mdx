# The zinc lost counts the electrons, which set the copper deposited, the copper ions removed and the time

The zinc is <InlineMath math="0.325\div65=0.00500\text{ mol}" />, and **each zinc atom gives two electrons**, <InlineMath math="0.0100\text{ mol}" />. At the cathode each copper(II) ion takes two, so <InlineMath math="0.00500\text{ mol}" /> of copper, <InlineMath math="0.320\text{ g}" />, is deposited. The solution started with <InlineMath math="0.0200\text{ mol}" /> of copper(II) ions and **loses the <InlineMath math="0.00500\text{ mol}" /> deposited**, leaving <InlineMath math="0.0150\text{ mol}" /> in <InlineMath math="0.100\text{ dm}^3" />, <InlineMath math="0.150\text{ mol dm}^{-3}" />. The charge is <InlineMath math="0.0100\times96\,500=965\text{ C}" />, so at <InlineMath math="0.0500\text{ A}" /> the time is <InlineMath math="965\div0.0500=19\,300\text{ s}" />.

# Why the other options are wrong

- <InlineMath math="9650\text{ s}" /> gives one electron per zinc atom, but zinc forms <InlineMath math="\text{Zn}^{2+}" />, **two electrons per atom**.
- <InlineMath math="0.640\text{ g}" /> deposits two copper per zinc, but both ions carry the same charge, so they swap one for one.
- <InlineMath math="0.200\text{ mol dm}^{-3}" /> keeps the copper ions constant, but in this cell the copper electrode only receives copper, so the solution loses it.
