# The sulfur sets the number of cross-links, and each link ties up one repeat unit on each of two chains

The repeat unit <InlineMath math="\text{C}_5\text{H}_8" /> has <InlineMath math="M_r=68" />, so the rubber is <InlineMath math="6.80\div68=0.100\text{ mol}" /> of units. The sulfur is <InlineMath math="0.32\div32=0.0100\text{ mol}" /> of atoms, and **each cross-link uses two**, so there are <InlineMath math="0.00500\text{ mol}" /> of links, <InlineMath math="0.00500\times6.02\times10^{23}=3.01\times10^{21}" />. **Each link joins one unit on each of two chains**, so <InlineMath math="0.0100\text{ mol}" /> of units are joined, <InlineMath math="10.0\%" />.

# Why the other options are wrong

- <InlineMath math="6.02\times10^{21}" /> makes a link from each sulfur atom, but **each link is a pair of sulfur atoms**.
- <InlineMath math="5.00\%" /> counts one unit per link, but a link joins two chains, one unit on each.
- <InlineMath math="0.0500\text{ mol}" /> treats two isoprene units as one repeat unit, but the repeat unit is <InlineMath math="\text{C}_5\text{H}_8" />.
