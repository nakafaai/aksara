# The sulfur sets the number of cross-links, each link ties up two repeat units, and a higher target needs more links

The repeat unit <InlineMath math="\text{C}_5\text{H}_8" /> has <InlineMath math="M_r=68" />, so the rubber is <InlineMath math="6.80\div68=0.100\text{ mol}" /> of units. The sulfur is <InlineMath math="0.32\div32=0.0100\text{ mol}" /> of atoms, and **each cross-link uses two**, <InlineMath math="0.00500\text{ mol}" /> of links. **Each link joins one unit on each of two chains**, so <InlineMath math="0.0100\text{ mol}" /> of units are joined, <InlineMath math="10.0\%" />. For <InlineMath math="20\%" /> the links must double to <InlineMath math="0.0100\text{ mol}" />, using <InlineMath math="0.0200\text{ mol}" /> of sulfur, <InlineMath math="0.64\text{ g}" />, so <InlineMath math="0.32\text{ g}" /> more is needed.

# Why the other options are wrong

- <InlineMath math="20.0\%" /> makes a link from each sulfur atom, but **each link is a pair of sulfur atoms**.
- <InlineMath math="5.00\%" /> counts one unit per link, but a link joins two chains, one unit on each.
- <InlineMath math="0.0500\text{ mol}" /> treats two isoprene units as one repeat unit, but the repeat unit is <InlineMath math="\text{C}_5\text{H}_8" />.
