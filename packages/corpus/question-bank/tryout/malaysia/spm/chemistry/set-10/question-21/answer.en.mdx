# Chromium's change in oxidation number gives six electrons per dichromate, so each dichromate takes six iron(II), and the portion scales up to the wire

In <InlineMath math="\text{Cr}_2\text{O}_7^{2-}" /> each chromium is <InlineMath math="+6" />, from <InlineMath math="2x-14=-2" />, and it ends as <InlineMath math="\text{Cr}^{3+}" />, <InlineMath math="+3" />, so **each dichromate takes six electrons, one from each of six iron(II) ions**. The dichromate is <InlineMath math="0.0200\times0.0200=4.00\times10^{-4}\text{ mol}" />, so the portion holds <InlineMath math="2.40\times10^{-3}\text{ mol}" /> of iron(II), <InlineMath math="0.0960\text{ mol dm}^{-3}" />. The flask holds ten portions, <InlineMath math="0.0240\text{ mol}" />, <InlineMath math="0.0240\times56=1.344\text{ g}" />, <InlineMath math="96.0\%" /> of the wire.

# Why the other options are wrong

- <InlineMath math="+7" /> is the oxidation number of manganese in manganate(VII). **In dichromate(VI) chromium is <InlineMath math="+6" />**.
- <InlineMath math="0.0160\text{ mol dm}^{-3}" /> reacts dichromate and iron(II) one to one, but each dichromate takes six.
- <InlineMath math="9.60\%" /> uses the iron in one portion, not in the whole <InlineMath math="250\text{ cm}^3" />.
