# The ammonia runs out first, and each ammonium ion it makes has one dative bond among its four <InlineMath math="\text{N–H}" /> bonds

The ammonia is <InlineMath math="480\div24\,000=0.0200\text{ mol}" /> and the hydrogen chloride <InlineMath math="0.0300\text{ mol}" />. **They react one to one, so the ammonia runs out**, giving <InlineMath math="0.0200\text{ mol}" /> of ammonium chloride, <InlineMath math="0.0200\times53.5=1.07\text{ g}" />. Each ammonium ion forms by one dative bond, so <InlineMath math="0.0200\times6.02\times10^{23}=1.20\times10^{22}" /> dative bonds form. **Once formed, the dative bond is the same as the other three**, so each ion has four <InlineMath math="\text{N–H}" /> bonds, <InlineMath math="0.0800\text{ mol}" />, <InlineMath math="4.82\times10^{22}" />.

# Why the other options are wrong

- <InlineMath math="1.61\text{ g}" /> lets the hydrogen chloride decide, but only <InlineMath math="0.0200\text{ mol}" /> of ammonia is there to take it.
- <InlineMath math="3.61\times10^{22}" /> counts only the three bonds the ammonia brought, but **the dative bond is also an <InlineMath math="\text{N–H}" /> bond**.
- <InlineMath math="4.82\times10^{22}" /> dative bonds calls all four bonds dative, but only the bond to the added hydrogen ion is.
