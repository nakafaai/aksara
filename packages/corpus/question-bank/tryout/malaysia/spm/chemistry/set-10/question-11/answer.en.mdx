# The ammonia runs out first, each ammonium ion it makes has one dative bond, and the acid left over goes to the burette

The ammonia is <InlineMath math="480\div24\,000=0.0200\text{ mol}" /> and the hydrogen chloride <InlineMath math="0.0300\text{ mol}" />. **They react one to one, so the ammonia runs out**, giving <InlineMath math="0.0200\text{ mol}" /> of ammonium chloride, <InlineMath math="0.0200\times53.5=1.07\text{ g}" />. Each ammonium ion forms by one dative bond, so <InlineMath math="0.0200\times6.02\times10^{23}=1.20\times10^{22}" /> dative bonds form. **The hydrogen chloride left is <InlineMath math="0.0100\text{ mol}" />**, which needs <InlineMath math="0.0100\div0.100=0.100\text{ dm}^3" />, <InlineMath math="100\text{ cm}^3" /> of alkali.

# Why the other options are wrong

- <InlineMath math="1.61\text{ g}" /> lets the hydrogen chloride decide, but only <InlineMath math="0.0200\text{ mol}" /> of ammonia is there to take it, so some acid must be left.
- <InlineMath math="300\text{ cm}^3" /> titrates all the hydrogen chloride, but **the ammonia used <InlineMath math="0.0200\text{ mol}" /> of it**.
- <InlineMath math="4.82\times10^{22}" /> dative bonds calls all four bonds dative, but only the bond to the added hydrogen ion is.
