# The repeat unit sets both the chain length and the moles, and each unit releases two water and uses one acid

An average chain holds <InlineMath math="22\,600\div226=100" /> repeat units. The batch is <InlineMath math="22\,600\div226=100\text{ mol}" /> of units, and **each unit forms two amide links, each releasing one water**, <InlineMath math="200\text{ mol}" />, <InlineMath math="200\times18=3.60\text{ kg}" />. Each unit contains one acid, <InlineMath math="M_r=146" />, so the acid used is <InlineMath math="100\times146=14.6\text{ kg}" />.

# Why the other options are wrong

- <InlineMath math="1.80\text{ kg}" /> releases one water per unit, but **each unit has two amide links**, and each link releases one water.
- <InlineMath math="29.2\text{ kg}" /> uses two acid per unit, but each unit holds one acid and one diamine.
- <InlineMath math="155" /> divides by the acid's <InlineMath math="M_r" />, but the repeat unit, <InlineMath math="M_r=226" />, is what repeats along the chain.
