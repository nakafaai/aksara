# Tiap ion kalsium mengambil dua anion sabun menjadi buih kerak, sedangkan satu ion karbonat cukup untuk menyingkirkannya lebih dulu

Air memuat <InlineMath math="0{,}00200\text{ mol}" /> ion kalsium. **Tiap ion mengambil dua ion stearat**, jadi <InlineMath math="0{,}00400\text{ mol}" /> sabun, <InlineMath math="M_r=306" />, <InlineMath math="1{,}22\text{ g}" />, terbuang, membentuk <InlineMath math="0{,}00200\text{ mol}" /> buih kerak, <InlineMath math="M_r=606" />, <InlineMath math="1{,}21\text{ g}" />. Natrium karbonat menyingkirkan tiap ion kalsium dengan satu ion karbonat, <InlineMath math="0{,}00200\text{ mol}" />, <InlineMath math="M_r=106" />, <InlineMath math="0{,}212\text{ g}" />.
