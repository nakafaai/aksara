# Find what runs out in each run, and notice that making the copper catalyst uses up some zinc

The zinc is <InlineMath math="0.325\div65=0.00500\text{ mol}" /> and the acid <InlineMath math="0.0200\text{ mol}" />, more than the <InlineMath math="0.0100\text{ mol}" /> the zinc needs, so **the zinc runs out**, <InlineMath math="0.00500\text{ mol}" /> of hydrogen, <InlineMath math="120\text{ cm}^3" />. In the second run the copper(II) ions, <InlineMath math="0.00100\text{ mol}" />, **each take one zinc atom** before any hydrogen forms, leaving <InlineMath math="0.00400\text{ mol}" /> of zinc, <InlineMath math="96.0\text{ cm}^3" />. In the third run the acid is <InlineMath math="0.00500\text{ mol}" />, enough for only <InlineMath math="0.00250\text{ mol}" /> of zinc, so the gas is <InlineMath math="60\text{ cm}^3" />.

# Why the other options are wrong

- <InlineMath math="120\text{ cm}^3" /> with less acid keeps the zinc limiting, but <InlineMath math="0.00500\text{ mol}" /> of acid dissolves only half the zinc.
- <InlineMath math="120\text{ cm}^3" /> with copper(II) sulfate treats it only as a catalyst, but **forming the copper uses up <InlineMath math="0.00100\text{ mol}" /> of zinc**.
- <InlineMath math="60\text{ cm}^3" /> in the first run gives one hydrogen per two zinc, but each zinc gives one hydrogen molecule.
