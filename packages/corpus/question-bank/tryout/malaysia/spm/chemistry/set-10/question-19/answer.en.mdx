# Find what runs out in each run, and remember that a catalyst changes only how fast the gas comes

The zinc is <InlineMath math="0.325\div65=0.00500\text{ mol}" /> and the acid <InlineMath math="0.00500\text{ mol}" />. **Each zinc takes two acid**, so the acid runs out, giving <InlineMath math="0.00250\text{ mol}" /> of hydrogen, <InlineMath math="60\text{ cm}^3" />. **A catalyst speeds the reaction but adds no reactant**, so the second run also stops at <InlineMath math="60\text{ cm}^3" />. With <InlineMath math="50.0\text{ cm}^3" /> the acid is <InlineMath math="0.0100\text{ mol}" />, exactly enough for all the zinc, so the gas is <InlineMath math="0.00500\text{ mol}" />, <InlineMath math="120\text{ cm}^3" />.

# Why the other options are wrong

- <InlineMath math="120\text{ cm}^3" /> in every run lets the zinc decide, but <InlineMath math="0.00500\text{ mol}" /> of acid dissolves only half of it.
- <InlineMath math="120\text{ cm}^3" /> with the catalyst treats the catalyst as making more gas, but **it only makes the gas come faster**.
- <InlineMath math="60\text{ cm}^3" /> with more acid keeps the acid limiting, but twice the acid dissolves all the zinc.
