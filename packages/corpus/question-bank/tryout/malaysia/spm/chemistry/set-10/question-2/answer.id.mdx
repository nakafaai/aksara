# Bobot isotop untuk massa atom, pasangkan isotop untuk molekul, lalu timbang hanya pasangan paling berat

Massa atom relatifnya <InlineMath math="0{,}75\times35+0{,}25\times37=35{,}5" />. Molekul bermassa <InlineMath math="72" /> punya satu atom dari tiap isotop, dan **ini bisa terjadi dengan dua cara**, jadi bagiannya <InlineMath math="2\times0{,}75\times0{,}25=0{,}375" />, <InlineMath math="37{,}5\%" />. Gasnya <InlineMath math="7{,}10\div71=0{,}100\text{ mol}" /> molekul, dan **molekul bermassa <InlineMath math="74" /> butuh kedua atomnya <InlineMath math="^{37}\text{Cl}" />**, <InlineMath math="0{,}25\times0{,}25=0{,}0625" />, jadi <InlineMath math="0{,}00625\text{ mol}" />, <InlineMath math="0{,}00625\times74=0{,}463\text{ g}" />.
