# Bobot isotop untuk massa atom, pasangkan isotop untuk molekul, lalu ikuti tiap atom ke hidrogen kloridanya sendiri

Massa atom relatifnya <InlineMath math="0{,}75\times35+0{,}25\times37=35{,}5" />. Molekul bermassa <InlineMath math="72" /> punya satu atom dari tiap isotop, dan **ini bisa terjadi dengan dua cara**, jadi bagiannya <InlineMath math="2\times0{,}75\times0{,}25=0{,}375" />, <InlineMath math="37{,}5\%" />. Gasnya <InlineMath math="7{,}10\div71=0{,}100\text{ mol}" /> molekul, yang memberi <InlineMath math="0{,}200\text{ mol}" /> hidrogen klorida, **satu untuk tiap atom klorin**. Seperempat atomnya <InlineMath math="^{37}\text{Cl}" />, jadi <InlineMath math="0{,}0500\text{ mol}" /> <InlineMath math="\text{H}^{37}\text{Cl}" />, <InlineMath math="M_r=38" />, <InlineMath math="1{,}90\text{ g}" />.
