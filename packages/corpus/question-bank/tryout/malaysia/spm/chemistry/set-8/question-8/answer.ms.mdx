# Jisim daripada isi padu, bilangan mol daripada jisim, kemudian molekul daripada bilangan mol

Titisan itu berjisim <InlineMath math="0.050\text{ g}" />, iaitu <InlineMath math="0.050\div18=2.78\times10^{-3}\text{ mol}" />. **Mendarab dengan pemalar Avogadro menukar bilangan mol kepada molekul**: <InlineMath math="1.67\times10^{21}" />. Setiap molekul mempunyai tiga atom, jadi titisan itu mengandungi tiga kali ganda atom.

# Kenapa pilihan lain salah

- <InlineMath math="2.78\times10^{-3}" /> ialah bilangan mol. **Darab dengan pemalar Avogadro untuk membilang molekul**.
- <InlineMath math="5.02\times10^{21}" /> membilang atom, tiga bagi setiap molekul, tetapi soalan bertanya tentang molekul.
- <InlineMath math="3.01\times10^{22}" /> mendarab jisim dengan pemalar Avogadro tanpa membahagi dengan jisim molar dahulu.
