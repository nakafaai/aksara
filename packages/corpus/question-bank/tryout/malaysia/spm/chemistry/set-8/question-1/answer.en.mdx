# Two variables changed at once, so the effect of temperature cannot be separated

A fair test changes only the manipulated variable and keeps every other factor fixed. Here **the particle size changed along with the temperature**: powder has a far larger surface area than chips, and that alone speeds the reaction up. The fourfold change mixes both effects, so the student must repeat the experiment with chips, or with powder, at both temperatures.

# Why the other options are wrong

- Temperature was meant to be the manipulated variable. **Particle size changed as well**, so it was not the only one.
- Keeping the acid the same is necessary, but it does not make up for changing the size of the pieces.
- The mass of calcium carbonate must stay the same, which it did. The fault is the change from chips to powder.
