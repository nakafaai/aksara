# Mengubah etanol menjadi asam etanoat memerlukan satu molekul oksigen, jauh lebih sedikit daripada membakarnya

Etanolnya <InlineMath math="0{,}0500\text{ mol}" />. **Oksidasi ini hanya menukar dua atom hidrogen dengan satu atom oksigen pada karbon ujung**, memakai satu molekul oksigen per molekul etanol, <InlineMath math="0{,}0500\text{ mol}" />. Pembakaran sempurna etanol akan memerlukan tiga. Tiap molekul etanol menjadi satu molekul asam etanoat, <InlineMath math="0{,}0500\times60=3{,}00\text{ g}" />.
