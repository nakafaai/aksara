# Timbang satu liter untuk mencari garamnya, lalu biarkan tiap ion klorida mengambil satu ion perak

**Satu desimeter kubik air laut bermassa <InlineMath math="1030\text{ g}" />, bukan <InlineMath math="1000\text{ g}" />**, jadi memuat <InlineMath math="0{,}035\times1030=36{,}1\text{ g}" /> garam, <InlineMath math="0{,}616\text{ mol dm}^{-3}" />.
