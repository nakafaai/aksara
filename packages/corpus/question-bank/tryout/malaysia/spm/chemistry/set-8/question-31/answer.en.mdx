# Only the acid reacts with carbonate, two acid molecules for each carbon dioxide molecule

The sample is <InlineMath math="0.740\div74=0.0100\text{ mol}" /> in all, since both compounds have molar mass <InlineMath math="74" />. **The ester has no acidic hydrogen, so only the acid gives carbon dioxide**: <InlineMath math="2\text{C}_2\text{H}_5\text{COOH}+\text{Na}_2\text{CO}_3\rightarrow2\text{C}_2\text{H}_5\text{COONa}+\text{CO}_2+\text{H}_2\text{O}" />. The <InlineMath math="0.00250\text{ mol}" /> of gas means <InlineMath math="0.00500\text{ mol}" /> of acid, half the sample.

# Why the other options are wrong

- <InlineMath math="25\%" /> takes one acid molecule per carbon dioxide molecule. **Two acid molecules give one**.
- The ester has the same formula but no <InlineMath math="\text{COOH}" /> group, so it does not react with carbonate.
- <InlineMath math="75\%" /> assigns the gas the wrong way round, as if it came from the ester.
