# Tiga perempat blok larut, dan tiap atom seng memberi dua elektron

Seperempat tersisa berarti tiga perempat hilang: <InlineMath math="975\text{ g}" />, <InlineMath math="15{,}0\text{ mol}" /> seng. **Tiap atom seng memberi dua elektron**, jadi muatannya <InlineMath math="30{,}0\times96{.}500=2{,}90\times10^6\text{ C}" />. Pada <InlineMath math="0{,}050\text{ A}" /> itu memerlukan <InlineMath math="5{,}79\times10^7\text{ s}" />, yaitu <InlineMath math="1{,}84" /> tahun.
