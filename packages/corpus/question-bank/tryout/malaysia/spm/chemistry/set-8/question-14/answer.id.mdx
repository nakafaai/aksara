# Kenapa pilihan lain salah

- <InlineMath math="0{,}10\text{ g}" /> berhenti setelah reaksi pertama. **Karbon dioksida berlebih melarutkan endapan itu lagi**.
- <InlineMath math="0{,}20\text{ g}" /> membentuk karbonat dari semua karbon dioksida, padahal kalsiumnya hanya cukup untuk separuh.
