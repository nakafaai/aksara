# Bandingkan per kilojoule, bukan per mol, karena oktana memberi empat kali kalor per molekul

Untuk <InlineMath math="1000\text{ kJ}" /> mobil membakar <InlineMath math="0{,}730\text{ mol}" /> etanol atau <InlineMath math="0{,}183\text{ mol}" /> oktana. **Oktana memberi empat kali karbon dioksida per molekul tetapi juga sekitar empat kali kalornya**, jadi kedua perbandingan hampir saling meniadakan. Etanol membuat <InlineMath math="1{,}46\text{ mol}" /> karbon dioksida dan oktana <InlineMath math="1{,}46\text{ mol}" />, sekitar <InlineMath math="64\text{ g}" /> masing-masing.

# Kenapa pilihan lain salah

- <InlineMath math="88\text{ g}" /> dan <InlineMath math="352\text{ g}" /> membandingkan satu mol tiap bahan bakar. **Soal menanyakan per kilojoule**.
- <InlineMath math="32\text{ g}" /> untuk etanol memberinya satu molekul karbon dioksida per molekul, padahal dua atom karbonnya membuat dua.
- <InlineMath math="16\text{ g}" /> untuk oktana membagi delapan alih-alih mengalikan, padahal tiap molekul oktana membuat delapan molekul karbon dioksida.
