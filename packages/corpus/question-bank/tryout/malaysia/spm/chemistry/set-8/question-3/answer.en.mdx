# Volume grows in three dimensions, so the spacing grows by only the cube root

The water is <InlineMath math="18.0\text{ g}" />, one mole, so it becomes <InlineMath math="30\,600\text{ cm}^3" /> of steam: <InlineMath math="30\,600\div18.0=1700" /> times the volume. Each molecule now has <InlineMath math="1700" /> times the space, but that space is a cube. **The distance between neighbours grows by the cube root**, <InlineMath math="\sqrt[3]{1700}\approx12" />.
