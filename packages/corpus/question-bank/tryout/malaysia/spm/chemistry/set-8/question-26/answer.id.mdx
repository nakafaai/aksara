# Tiap molekul klorin mengambil satu elektron dari tiap dua ion besi(II)

Larutan itu memuat <InlineMath math="0{,}050\text{ mol}" /> ion besi(II). Masing-masing melepas satu elektron, dan **tiap molekul klorin menerima dua elektron**, jadi mengoksidasi dua ion besi(II). Hanya <InlineMath math="0{,}025\text{ mol}" /> klorin yang diperlukan. Larutan besi(II) berwarna hijau pucat dan larutan besi(III) cokelat kekuningan.
