# Biarkan iodin menghitung asam askorbat, kurangkan dari natrium hidroksida, lalu berikan sisanya ke asam sitrat tiga per tiga

Iodinnya <InlineMath math="0{,}0100\times0{,}0250=2{,}50\times10^{-4}\text{ mol}" />, dan satu iodin mengambil satu asam askorbat. **Bagian itu sepersepuluh larutan**, jadi tablet memuat <InlineMath math="2{,}50\times10^{-3}\text{ mol}" />, <InlineMath math="0{,}440\text{ g}" />, <InlineMath math="88\%" /> dari <InlineMath math="500\text{ mg}" />. Natrium hidroksidanya <InlineMath math="4{,}50\times10^{-4}\text{ mol}" />, <InlineMath math="2{,}50\times10^{-4}" /> di antaranya untuk asam askorbat, menyisakan <InlineMath math="2{,}00\times10^{-4}\text{ mol}" /> untuk asam sitrat. **Tiap asam sitrat mengambil tiga ion hidroksida**, jadi bagian itu memuat <InlineMath math="6{,}67\times10^{-5}\text{ mol}" />, dan tablet sepuluh kalinya, <InlineMath math="6{,}67\times10^{-4}\times192=0{,}128\text{ g}" />.

# Kenapa pilihan lain salah

- <InlineMath math="44\%" /> mengambil dua asam askorbat untuk tiap iodin. **Persamaannya satu banding satu**.
- <InlineMath math="0{,}384\text{ g}" /> menganggap asam sitrat monoprotik, padahal tiap molekul menetralkan tiga ion hidroksida.
- <InlineMath math="0{,}0128\text{ g}" /> adalah asam sitrat dalam satu bagian, padahal bagian itu hanya sepersepuluh tablet.
