# Titrasi hanya mengukur sepersepuluh tablet, jadi skalakan dulu sebelum dibandingkan dengan label

Bagian itu memakai <InlineMath math="2{,}50\times10^{-4}\text{ mol}" /> iodin, dan tiap molekul iodin bereaksi dengan satu molekul asam askorbat. **Bagian itu hanya <InlineMath math="25{,}0" /> dari <InlineMath math="250\text{ cm}^3" />, sepersepuluh tablet**, jadi seluruh tablet memuat <InlineMath math="2{,}50\times10^{-3}\text{ mol}" />. Dengan massa molar <InlineMath math="176" /> itu sama dengan <InlineMath math="0{,}440\text{ g}" />, <InlineMath math="440\text{ mg}" /> dibanding <InlineMath math="500\text{ mg}" /> di label. Sebagian vitamin mungkin teroksidasi udara selama penyimpanan.
