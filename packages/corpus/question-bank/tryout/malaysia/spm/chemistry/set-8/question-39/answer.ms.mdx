# Pentitratan hanya mengukur satu persepuluh tablet, jadi skalakan dahulu sebelum dibandingkan dengan label

Bahagian itu menggunakan <InlineMath math="2.50\times10^{-4}\text{ mol}" /> iodin, dan setiap molekul iodin bertindak balas dengan satu molekul asid askorbik. **Bahagian itu hanya <InlineMath math="25.0" /> daripada <InlineMath math="250\text{ cm}^3" />, satu persepuluh tablet**, jadi seluruh tablet mengandungi <InlineMath math="2.50\times10^{-3}\text{ mol}" />. Dengan jisim molar <InlineMath math="176" /> itu ialah <InlineMath math="0.440\text{ g}" />, <InlineMath math="440\text{ mg}" /> berbanding <InlineMath math="500\text{ mg}" /> pada label. Sebahagian vitamin mungkin telah dioksidakan oleh udara semasa disimpan.
