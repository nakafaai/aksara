# Kalornya untuk empat mol besi, dan pertambahan massa hanyalah oksigen yang diikat

# Kenapa pilihan lain salah

- <InlineMath math="330\text{ kJ}" /> menganggap <InlineMath math="1650\text{ kJ}" /> sebagai kalor per mol besi. **Nilai itu untuk empat mol**.

- <InlineMath math="41{,}3\text{ kJ}" /> membagi delapan, seakan persamaannya memuat delapan mol besi.
