# Tiap satuan perak sulfida memuat dua ion perak yang memerlukan dua elektron, dan tiap atom aluminium memberi tiga

Noda itu <InlineMath math="0{,}00300\text{ mol}" /> <InlineMath math="\text{Ag}_2\text{S}" />. **Tiap satuan memuat dua ion perak bermuatan <InlineMath math="+1" />, jadi memerlukan dua elektron, sedangkan tiap atom aluminium memberi tiga**. Tiga satuan, enam elektron, cocok dengan dua atom aluminium, jadi <InlineMath math="0{,}00200\text{ mol}" /> aluminium bereaksi. Tiap satuan mengembalikan dua atom perak, <InlineMath math="0{,}00600\text{ mol}" />.
