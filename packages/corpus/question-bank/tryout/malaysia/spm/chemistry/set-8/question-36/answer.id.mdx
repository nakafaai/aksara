# Mol hidrogen memberi energinya, separuhnya menggerakkan mobil, lalu bagi dengan energi per kilometer

Tangki itu memuat <InlineMath math="4000\div2=2000\text{ mol}" /> molekul hidrogen, karena **tiap molekul punya dua atom, massa molar <InlineMath math="2" />**. Molekul itu melepaskan <InlineMath math="2000\times286=572{.}000\text{ kJ}" />, <InlineMath math="572\text{ MJ}" />, dan separuhnya, <InlineMath math="286\text{ MJ}" />, menggerakkan mobil. Pada <InlineMath math="0{,}70\text{ MJ}" /> per kilometer itu sama dengan <InlineMath math="409\text{ km}" />.
