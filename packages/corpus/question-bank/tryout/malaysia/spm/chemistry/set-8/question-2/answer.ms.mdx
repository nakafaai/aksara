# Wajarkan jisim mengikut kelimpahan, kemudian ambil bahagian atom magnesium-26

**Jisim atom relatif ialah min berwajaran kelimpahan, bukan min biasa tiga nombor nukleon**: <InlineMath math="0.79\times24+0.10\times25+0.11\times26=24.32" />. Sampel itu kemudian <InlineMath math="2.432\div24.32=0.1000\text{ mol}" /> atom, <InlineMath math="6.02\times10^{22}" />, dan hanya <InlineMath math="11\%" /> daripadanya magnesium-26. Pembakaran tidak mengubah nukleus, jadi bilangannya sama dalam oksida.

# Kenapa pilihan lain salah

- <InlineMath math="25.00" /> mempuratakan tiga nombor nukleon secara sama rata. **Magnesium-24 jauh lebih banyak**.
- <InlineMath math="2.01\times10^{22}" /> memberi setiap isotop satu pertiga daripada atom dan bukan menggunakan kelimpahan.
- <InlineMath math="6.02\times10^{22}" /> mengira semua atom magnesium, bukan magnesium-26 sahaja.
