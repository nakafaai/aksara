# Wajarkan jisim mengikut kelimpahan, gunakan jisim itu untuk mengira oksida, kemudian timbang bahagian atom magnesium-26

**Jisim atom relatif ialah min berwajaran kelimpahan**: <InlineMath math="0.79\times24+0.10\times25+0.11\times26=24.32" />, jadi magnesium oksida mempunyai <InlineMath math="M_r=40.32" />. Oksida itu <InlineMath math="4.032\div40.32=0.1000\text{ mol}" />, dan setiap unit formula mengandungi satu atom magnesium, jadi pita itu <InlineMath math="0.1000\text{ mol}" />, <InlineMath math="2.432\text{ g}" />. **<InlineMath math="11\%" /> itu membilang atom, bukan jisim**, jadi magnesium-26 ialah <InlineMath math="0.0110\text{ mol}" />, <InlineMath math="0.0110\times26=0.286\text{ g}" />.

# Kenapa pilihan lain salah

- <InlineMath math="2.459\text{ g}" /> mempuratakan tiga nombor nukleon secara sama rata, seolah-olah setiap isotop satu pertiga daripada atom. **Magnesium-24 jauh lebih banyak**.
- <InlineMath math="0.268\text{ g}" /> mengambil <InlineMath math="11\%" /> daripada jisim pita, tetapi kelimpahan membilang atom, dan atom magnesium-26 lebih berat daripada purata.
- <InlineMath math="4.032\text{ g}" /> mengambil jisim oksida sebagai magnesium dan terlupa oksigen di dalamnya.
