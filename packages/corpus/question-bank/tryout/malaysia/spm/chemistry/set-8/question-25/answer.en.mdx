# Each silver sulfide unit holds two silver ions that need two electrons, and each aluminium atom gives three

The tarnish is <InlineMath math="0.00300\text{ mol}" /> of <InlineMath math="\text{Ag}_2\text{S}" />. **Each unit holds two silver ions at <InlineMath math="+1" />, so it needs two electrons, while each aluminium atom gives three**. Three units, six electrons, match two aluminium atoms, so <InlineMath math="0.00200\text{ mol}" /> of aluminium reacts. Each unit returns two silver atoms, <InlineMath math="0.00600\text{ mol}" />.

# Why the other options are wrong

- <InlineMath math="0.081\text{ g}" /> uses one aluminium atom per silver sulfide unit. **Six electrons from three units need only two aluminium atoms**.
- <InlineMath math="0.324\text{ g}" /> returns one silver atom per unit, but each unit holds two.
- <InlineMath math="0.027\text{ g}" /> halves the aluminium again, as if each atom gave six electrons.
