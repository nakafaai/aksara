# Nyalaan padam ketika kebanyakan oksigen masih ada, jadi hanya penurunan daripada satu peratusan ke peratusan lain yang terbakar

Balang itu bermula dengan <InlineMath math="0.21\times1.20=0.252\text{ dm}^3" /> oksigen dan nyalaan berhenti pada <InlineMath math="0.192\text{ dm}^3" />. **Hanya <InlineMath math="0.060\text{ dm}^3" /> di antaranya digunakan**, <InlineMath math="0.00250\text{ mol}" />. Setiap molekul lilin memerlukan <InlineMath math="38" /> molekul oksigen, jadi <InlineMath math="6.58\times10^{-5}\text{ mol}" /> lilin terbakar, dengan jisim molar <InlineMath math="352" />.
