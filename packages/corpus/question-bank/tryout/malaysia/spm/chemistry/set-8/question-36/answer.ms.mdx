# Bilangan mol hidrogen memberi tenaga, separuh daripadanya menggerakkan kereta, kemudian bahagi dengan tenaga bagi setiap kilometer

Tangki itu mengandungi <InlineMath math="4000\div2=2000\text{ mol}" /> molekul hidrogen, kerana **setiap molekul mempunyai dua atom, jisim molar <InlineMath math="2" />**. Ia membebaskan <InlineMath math="2000\times286=572\,000\text{ kJ}" />, <InlineMath math="572\text{ MJ}" />, dan separuh daripadanya, <InlineMath math="286\text{ MJ}" />, menggerakkan kereta. Pada <InlineMath math="0.70\text{ MJ}" /> bagi setiap kilometer itu ialah <InlineMath math="409\text{ km}" />.

# Kenapa pilihan lain salah

- <InlineMath math="817\text{ km}" /> menggunakan semua tenaga. **Hanya <InlineMath math="50\%" /> daripadanya menggerakkan kereta**.
- <InlineMath math="204\text{ km}" /> mengambil jisim molar hidrogen sebagai <InlineMath math="4" />, atau menggunakan kecekapan dua kali.
- <InlineMath math="817\,000\text{ km}" /> membahagi kilojoule dengan megajoule tanpa menukar unit.
