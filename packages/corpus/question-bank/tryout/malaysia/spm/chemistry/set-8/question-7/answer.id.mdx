# Dua satuan hidroksida mengambil tiap molekul karbon dioksida, dan tabung menyimpan gasnya tetapi kehilangan air

Awak pesawat menghembuskan <InlineMath math="21{,}0\text{ kg}" />, <InlineMath math="477\text{ mol}" /> karbon dioksida. Tiap molekul memerlukan dua satuan litium hidroksida, <InlineMath math="954\text{ mol}" />, <InlineMath math="22{,}9\text{ kg}" />. **Tabung menyerap karbon dioksida tetapi melepaskan satu molekul air untuk tiap molekul**, jadi tiap mol hanya menambah <InlineMath math="44-18=26\text{ g}" />.
