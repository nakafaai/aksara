# Warum die anderen Antworten falsch sind

- <InlineMath math="1{,}00\text{ dm}^3" /> deckt nur das Ammoniak ab. **Der Kautschuk braucht weitere <InlineMath math="5{,}0\text{ g}" /> Säure zum Koagulieren**.
