# Tembaga di bawah hidrogen dan tertinggal, sedangkan tiap atom aluminium memberi satu setengah molekul hidrogen

Sampel itu memuat <InlineMath math="4{,}75\text{ g}" /> aluminium, <InlineMath math="0{,}20\text{ g}" /> tembaga, dan <InlineMath math="0{,}050\text{ g}" /> magnesium. **Tembaga berada di bawah hidrogen dalam deret kereaktifan, jadi tidak bereaksi dengan asam**. Aluminium memberi <InlineMath math="2\text{Al}+6\text{HCl}\rightarrow2\text{AlCl}_3+3\text{H}_2" />, tiga molekul hidrogen untuk tiap dua atom, dan magnesium memberi satu per atom.

- <InlineMath math="6{,}46\text{ dm}^3" /> membiarkan tembaga ikut memberi hidrogen. **Tembaga tidak bereaksi dengan asam encer**.
- <InlineMath math="4{,}27\text{ dm}^3" /> memberi satu molekul hidrogen per atom aluminium, padahal tiap atom melepas tiga elektron, cukup untuk satu setengah.
- <InlineMath math="6{,}67\text{ dm}^3" /> menganggap seluruh <InlineMath math="5{,}00\text{ g}" /> sebagai aluminium.
