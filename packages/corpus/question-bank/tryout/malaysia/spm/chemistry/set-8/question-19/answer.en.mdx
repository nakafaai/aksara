# Find which reactant runs out in each flask before counting the hydrogen

The zinc is <InlineMath math="2.60\div65=0.0400\text{ mol}" />. I and II each hold <InlineMath math="0.050\text{ mol}" /> of hydrogen ions, which need only <InlineMath math="0.025\text{ mol}" /> of zinc, so the acid runs out and each gives <InlineMath math="0.025\text{ mol}" /> of hydrogen, <InlineMath math="600\text{ cm}^3" />. **Sulfuric acid gives two hydrogen ions per molecule**, so III holds <InlineMath math="0.10\text{ mol}" />, which would need <InlineMath math="0.050\text{ mol}" /> of zinc. **In III the zinc runs out first**, so it gives <InlineMath math="0.0400\text{ mol}" /> of hydrogen, <InlineMath math="960\text{ cm}^3" />. The start follows the hydrogen ion concentration: II has half that of I, so it is slower, and III has twice, so it is faster.

# Why the other options are wrong

- <InlineMath math="300\text{ cm}^3" /> for II halves the hydrogen with the concentration. **II has twice the volume, so the same moles of acid**.
- <InlineMath math="1200\text{ cm}^3" /> for III assumes the zinc is still in excess, but <InlineMath math="0.10\text{ mol}" /> of hydrogen ions needs <InlineMath math="0.050\text{ mol}" /> of zinc and only <InlineMath math="0.0400\text{ mol}" /> is there.
- II does not start as fast as I, because its hydrogen ion concentration is only half.
