# Besarkan mengikut kecekapan enjin, tukar mol kepada jisim, kemudian bahagi dengan ketumpatan

**Bahan api mesti membebaskan empat kali ganda kerja itu**, <InlineMath math="12\,500\div0.25=50\,000\text{ kJ}" />. Ini ialah <InlineMath math="50\,000\div1370=36.5\text{ mol}" /> etanol, <InlineMath math="1.68\text{ kg}" />, atau <InlineMath math="50\,000\div5470=9.14\text{ mol}" /> oktana, <InlineMath math="1.04\text{ kg}" />. **Soalan bertanya tentang isi padu**, jadi membahagi dengan ketumpatan memberi <InlineMath math="2.13\text{ dm}^3" /> etanol dan <InlineMath math="1.49\text{ dm}^3" /> oktana. Etanol mempunyai dua atom karbon dan oktana lapan, jadi setiap satu memberi kira-kira <InlineMath math="73\text{ mol}" /> karbon dioksida, <InlineMath math="3.2\text{ kg}" />.

# Kenapa pilihan lain salah

- <InlineMath math="0.53\text{ dm}^3" /> dan <InlineMath math="0.37\text{ dm}^3" /> menggunakan <InlineMath math="12\,500\text{ kJ}" /> sebagai haba. **Hanya satu perempat haba menjadi kerja**, jadi bahan api mesti membebaskan <InlineMath math="50\,000\text{ kJ}" />.
- <InlineMath math="1.33\text{ dm}^3" /> dan <InlineMath math="0.73\text{ dm}^3" /> mendarabkan jisim dengan ketumpatan dan bukan membahagikannya.
- <InlineMath math="1.6\text{ kg}" /> bagi etanol mengira satu atom karbon bagi setiap molekul, walhal etanol mempunyai dua.
