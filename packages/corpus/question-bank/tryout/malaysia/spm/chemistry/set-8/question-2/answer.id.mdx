# Bobotkan massa dengan kelimpahan, pakai massa itu untuk menghitung oksida, lalu timbang bagian atom magnesium-26

**Massa atom relatif adalah rata-rata berbobot kelimpahan**: <InlineMath math="0{,}79\times24+0{,}10\times25+0{,}11\times26=24{,}32" />, jadi magnesium oksida punya <InlineMath math="M_r=40{,}32" />. Oksidanya <InlineMath math="4{,}032\div40{,}32=0{,}1000\text{ mol}" />, dan tiap satuan rumus memuat satu atom magnesium, jadi pitanya <InlineMath math="0{,}1000\text{ mol}" />, <InlineMath math="2{,}432\text{ g}" />. **Angka <InlineMath math="11\%" /> menghitung atom, bukan massa**, jadi magnesium-26 sebanyak <InlineMath math="0{,}0110\text{ mol}" />, <InlineMath math="0{,}0110\times26=0{,}286\text{ g}" />.

# Kenapa pilihan lain salah

- <InlineMath math="2{,}459\text{ g}" /> merata-ratakan ketiga nomor massa sama rata, seolah tiap isotop sepertiga atom. **Magnesium-24 jauh lebih banyak**.
- <InlineMath math="0{,}268\text{ g}" /> mengambil <InlineMath math="11\%" /> dari massa pita, padahal kelimpahan menghitung atom, dan atom magnesium-26 lebih berat dari rata-rata.
- <InlineMath math="4{,}032\text{ g}" /> menganggap massa oksida sebagai magnesium dan melupakan oksigen di dalamnya.
