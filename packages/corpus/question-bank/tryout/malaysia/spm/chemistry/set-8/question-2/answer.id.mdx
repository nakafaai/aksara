# Bobotkan massa dengan kelimpahan, lalu ambil bagian atom magnesium-26

**Massa atom relatif adalah rata-rata berbobot kelimpahan, bukan rata-rata biasa ketiga nomor massa**: <InlineMath math="0{,}79\times24+0{,}10\times25+0{,}11\times26=24{,}32" />. Sampel itu lalu <InlineMath math="2{,}432\div24{,}32=0{,}1000\text{ mol}" /> atom, <InlineMath math="6{,}02\times10^{22}" />, dan hanya <InlineMath math="11\%" /> di antaranya magnesium-26. Pembakaran tidak mengubah inti, jadi jumlahnya sama dalam oksida.

# Kenapa pilihan lain salah

- <InlineMath math="25{,}00" /> merata-ratakan ketiga nomor massa sama rata. **Magnesium-24 jauh lebih banyak**.
- <InlineMath math="2{,}01\times10^{22}" /> memberi tiap isotop sepertiga atom alih-alih memakai kelimpahan.
- <InlineMath math="6{,}02\times10^{22}" /> menghitung semua atom magnesium, bukan hanya magnesium-26.
