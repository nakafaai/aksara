# The percentage is by mass, so weigh the litre first, then count both ions of each formula unit

**One cubic decimetre of seawater weighs <InlineMath math="1030\text{ g}" />, not <InlineMath math="1000\text{ g}" />**, so it holds <InlineMath math="0.035\times1030=36.1\text{ g}" /> of salt, <InlineMath math="0.616\text{ mol}" />. Each formula unit gives one sodium ion and one chloride ion, so the ions total <InlineMath math="1.23\text{ mol dm}^{-3}" />.

# Why the other options are wrong

- <InlineMath math="35.0\text{ g}" /> takes a litre of seawater as <InlineMath math="1000\text{ g}" />. **Its density is <InlineMath math="1.03\text{ g cm}^{-3}" />**.
- <InlineMath math="0.616\text{ mol dm}^{-3}" /> is the salt, but each formula unit gives two ions.
- <InlineMath math="2.46\text{ mol dm}^{-3}" /> doubles the ions a second time.
