# Volume bertambah dalam tiga dimensi, jadi jaraknya hanya bertambah sebesar akar pangkat tiga

Airnya <InlineMath math="18{,}0\text{ g}" />, satu mol, jadi menjadi <InlineMath math="30{.}600\text{ cm}^3" /> uap: <InlineMath math="30{.}600\div18{,}0=1700" /> kali volumenya. Tiap molekul kini punya ruang <InlineMath math="1700" /> kali lipat, tetapi ruang itu berbentuk kubus. **Jarak antarmolekul tetangga bertambah sebesar akar pangkat tiga**, <InlineMath math="\sqrt[3]{1700}\approx12" />.
