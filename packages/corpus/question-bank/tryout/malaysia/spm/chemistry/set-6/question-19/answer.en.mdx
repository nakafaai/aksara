# The first run makes more gas than the syringe can hold, and the second has half the peroxide

The first run has <InlineMath math="0.0100\text{ mol}" /> of peroxide, and every two peroxide molecules give one oxygen molecule, so <InlineMath math="120\text{ cm}^3" /> of oxygen forms. **The syringe holds only <InlineMath math="100\text{ cm}^3" />**, so it stops at its full mark and the rest escapes. The second run has half the peroxide in the same volume of liquid, so it makes <InlineMath math="60\text{ cm}^3" />, which the syringe can hold. Heat changes the shape of the enzyme's active site, so at <InlineMath math="65^\circ\text{C}" /> the peroxide decomposes only at its slow uncatalysed rate.

# Why the other options are wrong

- <InlineMath math="120\text{ cm}^3" /> is the oxygen that forms. **A <InlineMath math="100\text{ cm}^3" /> syringe cannot read more than its scale**.
- The second run holds half the peroxide, so it makes only <InlineMath math="60\text{ cm}^3" />, not a full syringe.
- A catalyst is not used up. **The enzyme is still present at <InlineMath math="65^\circ\text{C}" /> but has lost its shape**.
