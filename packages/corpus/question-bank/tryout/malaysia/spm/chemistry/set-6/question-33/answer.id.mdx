# Kenapa pilihan lain salah

- <InlineMath math="9{,}20\text{ kJ}" /> menganggap <InlineMath math="92\text{ kJ}" /> sebagai kalor untuk satu mol amonia. **Itu untuk dua mol**.
- <InlineMath math="138\text{ kJ}" /> mengurangkan penurunan dari penghalang. **Reaksi balik juga harus mendaki penurunan itu**.
- <InlineMath math="230\text{ kJ}" /> adalah penghalang maju, diukur dari pereaksi, bukan dari produk.
