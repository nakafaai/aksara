# Each double bond takes one bromine molecule or one hydrogen molecule, so both reagents count the double bonds

The <InlineMath math="0.0100\text{ mol}" /> of X takes <InlineMath math="0.0200\text{ mol}" /> of bromine, two per molecule, so X has two double bonds, as in buta-1,3-diene. **Four bromine atoms join each chain**, giving <InlineMath math="\text{C}_4\text{H}_6\text{Br}_4" /> of molar mass <InlineMath math="374" />. Hydrogen adds across the same two double bonds, so it too is needed two molecules per X.

# Why the other options are wrong

- <InlineMath math="2.14\text{ g}" /> and <InlineMath math="240\text{ cm}^3" /> assume one double bond. **The bromine used is twice the X**.
- <InlineMath math="2.14\text{ g}" /> is <InlineMath math="\text{C}_4\text{H}_6\text{Br}_2" />. **Two double bonds add four bromine atoms**.
- <InlineMath math="240\text{ cm}^3" /> saturates only one of the two double bonds.
