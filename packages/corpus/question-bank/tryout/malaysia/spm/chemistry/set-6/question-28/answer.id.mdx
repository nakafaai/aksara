# Tiap ikatan rangkap dua mengikat satu molekul bromin atau satu molekul hidrogen, jadi kedua pereaksi menghitung ikatan rangkapnya

<InlineMath math="0{,}0100\text{ mol}" /> X mengikat <InlineMath math="0{,}0200\text{ mol}" /> bromin, dua per molekul, jadi X punya dua ikatan rangkap, seperti buta-1,3-diena. **Empat atom bromin terikat pada tiap rantai**, memberi <InlineMath math="\text{C}_4\text{H}_6\text{Br}_4" /> bermassa molar <InlineMath math="374" />. Hidrogen teradisi pada dua ikatan rangkap yang sama, jadi juga diperlukan dua molekul per X.
