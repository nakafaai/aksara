# Scale each solubility to the water given, and remember longer chains attract each other more

The single hydroxyl group can hydrogen bond with water, but the growing hydrocarbon chain cannot, so solubility falls. **The chart is per <InlineMath math="100\text{ g}" /> of water**, so <InlineMath math="50\text{ g}" /> dissolves only <InlineMath math="3.7\text{ g}" /> of butan-1-ol, leaving <InlineMath math="1.3\text{ g}" />, <InlineMath math="0.018\text{ mol}" />. Longer chains have stronger forces between molecules, so boiling points rise along the series.
