# Scale each solubility to the water given, and remember that longer chains attract each other more

The single hydroxyl group can hydrogen bond with water, but the growing hydrocarbon chain cannot, so solubility falls. **Solubility is per <InlineMath math="100\text{ g}" /> of water, so halve it for <InlineMath math="50\text{ g}" />**: butan-1-ol can still dissolve <InlineMath math="3.7\text{ g}" />. Longer chains have stronger forces between molecules, so boiling points rise along the series.
