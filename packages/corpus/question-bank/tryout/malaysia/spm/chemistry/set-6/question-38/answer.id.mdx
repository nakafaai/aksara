# Panjang rantai tidak berpengaruh, karena tiap satuan ulang membawa atom yang sama

<InlineMath math="4{,}16\text{ g}" /> itu sama dengan <InlineMath math="0{,}0400\text{ mol}" /> satuan <InlineMath math="\text{C}_8\text{H}_8" />, sepanjang apa pun rantainya. **Hitung atom, bukan satuan**: <InlineMath math="0{,}320\text{ mol}" /> karbon dan <InlineMath math="0{,}320\text{ mol}" /> hidrogen. Seperempat karbon, <InlineMath math="0{,}0800\text{ mol}" />, menjadi karbon monoksida, dan tiap dua atom hidrogen membentuk satu molekul air.
