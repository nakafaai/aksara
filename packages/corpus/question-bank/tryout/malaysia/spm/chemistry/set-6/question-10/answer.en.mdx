# The oxidising agent sets the oxidation state, and chlorine then lifts iron(II) to iron(III)

Chlorine takes iron straight to <InlineMath math="+3" />, but hydrogen ions take it only to <InlineMath math="+2" />, so the same <InlineMath math="0.0500\text{ mol}" /> of iron gives two different chlorides. **Each iron(II) ion then gives one more electron, and each chlorine molecule takes two**, so the solution from Y takes up half as many chlorine molecules as it has iron ions.

# Why the other options are wrong

- Chlorine does not stop at <InlineMath math="+2" />. **It oxidises iron fully to iron(III)**, so X gives the heavier chloride.
- Hydrogen ions oxidise iron only to iron(II), so Y's solution still needs chlorine to reach iron(III).
- <InlineMath math="1200\text{ cm}^3" /> uses one chlorine molecule per iron ion. **One chlorine molecule takes two electrons, enough for two iron(II) ions**.
