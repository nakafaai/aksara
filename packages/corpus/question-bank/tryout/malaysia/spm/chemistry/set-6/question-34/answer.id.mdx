# Kalor dalam persamaan itu untuk dua atom aluminium, dan penghalang tinggi menjelaskan sumbunya

<InlineMath math="850\text{ kJ}" /> dilepas saat **dua** mol aluminium bereaksi, jadi <InlineMath math="0{,}200\text{ mol}" /> adalah sepersepuluh persamaan. Tiap atom aluminium membebaskan satu atom besi. Reaksi ini sangat eksoterm, tetapi padatannya tidak bereaksi pada suhu ruang karena energi aktivasinya tinggi, jadi nyala magnesium yang sangat panas yang memulainya.

# Kenapa pilihan lain salah

- <InlineMath math="170\text{ kJ}" /> memberi <InlineMath math="850\text{ kJ}" /> untuk tiap mol aluminium. **Itu untuk dua mol**.
- <InlineMath math="5{,}6\text{ g}" /> membentuk satu atom besi per dua atom aluminium. **Persamaannya memberi dua besi untuk dua aluminium**.
- <InlineMath math="\Delta H" /> negatif berarti reaksi melepas kalor secara keseluruhan. **Sumbu hanya menyediakan energi untuk memulainya**.
