# Senyawa ion padat tidak menghantarkan listrik, jadi muatan baru mengalir setelah garam meleleh

Dalam timbal(II) bromida padat ion-ionnya terkunci di kisi, jadi **tidak ada arus sampai garam meleleh**, berapa pun setelan catu dayanya. Arus mengalir selama <InlineMath math="41\text{ min }20\text{ s}" /> dikurangi <InlineMath math="9\text{ min }10\text{ s}" />, <InlineMath math="1930\text{ s}" />, membawa <InlineMath math="965\text{ C}" />. Ion timbal masing-masing menerima dua elektron di katode, dan ion bromida melepasnya di anode, membentuk <InlineMath math="\text{Br}_2" />.
