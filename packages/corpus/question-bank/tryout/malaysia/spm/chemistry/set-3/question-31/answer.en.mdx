# One ethanol molecule gives one ethene molecule

Hot porcelain removes a water molecule from each ethanol molecule: <InlineMath math="\text{C}_2\text{H}_5\text{OH} \rightarrow \text{C}_2\text{H}_4 + \text{H}_2\text{O}" />. The ratio is **one to one**.

Ethanol has <InlineMath math="M_r = 46" />, so <InlineMath math="2.3 \div 46 = 0.050" /> mol reacts and gives <InlineMath math="0.050" /> mol of ethene, which occupies <InlineMath math="0.050 \times 24 = 1.2" /> dm³. Ethene has a **carbon-carbon double bond**, so it adds bromine and decolourises bromine water.

# Why the other options are wrong

- Dehydration gives ethene, not ethane. Ethane is saturated and does not decolourise bromine water.
- <InlineMath math="2.4\text{ dm}^3" /> would need <InlineMath math="0.10" /> mol, twice the ethanol present.
- <InlineMath math="0.6\text{ dm}^3" /> halves the amount, and ethene does react with bromine water.
