# Read the end point, then use the mole ratio

The pH jumps from <InlineMath math="1.94" /> to <InlineMath math="12.04" /> around **<InlineMath math="20.0\text{ cm}^3" />**, so that is the volume that neutralises the acid exactly.

Moles of potassium hydroxide are <InlineMath math="0.50 \times \tfrac{20.0}{1000} = 0.010" />. The equation <InlineMath math="\text{H}_2\text{SO}_4 + 2\text{KOH} \rightarrow \text{K}_2\text{SO}_4 + 2\text{H}_2\text{O}" /> shows **one mole of acid for two moles of alkali**, so the acid holds <InlineMath math="0.0050" /> mol.

Its concentration is <InlineMath math="0.0050 \div \tfrac{25.0}{1000} = 0.20" /> mol dm⁻³. With <InlineMath math="M_r = 2(1) + 32 + 4(16) = 98" />, that is <InlineMath math="0.20 \times 98 = 19.6" /> g dm⁻³.

# Why the other options are wrong

- <InlineMath math="9.8\text{ g}" /> dm⁻³ uses the ratio the wrong way round, as if **two acid molecules** used one hydroxide ion.
- <InlineMath math="39.2\text{ g}" /> dm⁻³ treats the reaction as one to one and ignores the second hydrogen ion.
- <InlineMath math="30.6\text{ g}" /> dm⁻³ swaps the two volumes, using <InlineMath math="25.0\text{ cm}^3" /> for the alkali and <InlineMath math="20.0\text{ cm}^3" /> for the acid.
