# Let the titre decide how many protons each molecule gives

Acid: <InlineMath math="1.80 \div 90 = 0.020" /> mol. Sodium hydroxide: <InlineMath math="0.0400 \times 1.00 = 0.040" /> mol. Each acid molecule neutralises **two hydroxide ions**, so the acid is dibasic, <InlineMath math="\text{H}_2\text{X}" />.

With carbonate: <InlineMath math="\text{H}_2\text{X} + \text{Na}_2\text{CO}_3 \rightarrow \text{Na}_2\text{X} + \text{H}_2\text{O} + \text{CO}_2" />. Two protons release one carbon dioxide, so each acid molecule gives one: <InlineMath math="0.020" /> mol, or <InlineMath math="0.020 \times 24 = 0.48\text{ dm}^3 = 480\text{ cm}^3" />.

**Salt**: the titration replaces both acidic hydrogens with sodium, <InlineMath math="\text{H}_2\text{X} + 2\text{NaOH} \rightarrow \text{Na}_2\text{X} + 2\text{H}_2\text{O}" />. The salt's mass is <InlineMath math="90 - 2 + 2 \times 23 = 134" />, so <InlineMath math="0.020 \times 134 = 2.68" /> g is left.

# Why the other options are wrong

- Basicity <InlineMath math="1" /> would use only <InlineMath math="20.0\text{ cm}^3" /> of the alkali, **half** the titre.
- <InlineMath math="960\text{ cm}^3" /> gives one carbon dioxide per proton, but one carbonate ion takes two protons.
- <InlineMath math="1.34\text{ g}" /> makes one formula unit of salt from two acid molecules.
