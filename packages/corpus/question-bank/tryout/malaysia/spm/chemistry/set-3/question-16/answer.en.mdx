# The amount of acid sets the volume, the hydrogen ions set the speed

Each flask holds <InlineMath math="0.10 \times \tfrac{50}{1000} = 0.0050" /> mol of a **monoprotic acid**. With excess magnesium, <InlineMath math="\text{Mg} + 2\text{H}^+ \rightarrow \text{Mg}^{2+} + \text{H}_2" /> gives <InlineMath math="0.0025" /> mol of hydrogen from each, which is <InlineMath math="0.0025 \times 24\,000 = 60\text{ cm}^3" />.

In the first <InlineMath math="30" /> s hydrochloric acid gives <InlineMath math="32\text{ cm}^3" /> and ethanoic acid <InlineMath math="12\text{ cm}^3" />, so <InlineMath math="32 \div 12 \approx 2.7" /> times as fast. Hydrochloric acid ionises completely, while ethanoic acid **ionises only partly**, so far fewer hydrogen ions meet the magnesium at any moment.

# Why the other options are wrong

- A strong acid reacts faster, but the final volume depends on the moles of acid, which are equal.
- Ethanoic acid stays slower from start to finish. It reaches <InlineMath math="60\text{ cm}^3" /> only because more molecules ionise as hydrogen ions are used up, **not because it speeds up**.
- Partial ionisation slows the reaction, but every ethanoic acid molecule ionises in the end, so the volume is still <InlineMath math="60\text{ cm}^3" />.
