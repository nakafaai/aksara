# Pelet membebaskan haba dua kali

Natrium hidroksida: <InlineMath math="2.0 \div 40 = 0.050" /> mol. Asid mengandungi <InlineMath math="0.10" /> mol ion hidrogen, lebih daripada cukup, jadi **kesemua <InlineMath math="0.050" /> mol** larut dan kemudian dineutralkan.

Pelarutan: <InlineMath math="0.050 \times 44.5 = 2.225" /> kJ. Peneutralan: <InlineMath math="0.050 \times 57.3 = 2.865" /> kJ.

Jumlah haba: <InlineMath math="5.09" /> kJ, iaitu <InlineMath math="5090" /> J. Kenaikan: <InlineMath math="\Delta T = 5090 \div (100 \times 4.2) = 12.1^\circ\text{C}" />.

# Kenapa pilihan lain salah

- <InlineMath math="6.8^\circ\text{C}" /> hanya mengira peneutralan dan **terlupa** bahawa pepejal membebaskan haba semasa melarut.
- <InlineMath math="5.3^\circ\text{C}" /> hanya mengira pelarutan.
- <InlineMath math="18.9^\circ\text{C}" /> meneutralkan kesemua <InlineMath math="0.10" /> mol asid, tetapi hanya <InlineMath math="0.050" /> mol hidroksida yang ada untuk bertindak balas.
