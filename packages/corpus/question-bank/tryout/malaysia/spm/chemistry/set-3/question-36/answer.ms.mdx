# Keperluan haba, bekalan bahan api, dan karbon dioksida daripada kedua-duanya

Kalsium karbonat: <InlineMath math="1000 \div 100 = 10" /> mol, yang memerlukan <InlineMath math="10 \times 178 = 1780" /> kJ. Hanya separuh haba bahan api sampai, jadi bahan api karbon mesti membebaskan <InlineMath math="1780 \div 0.50 = 3560" /> kJ.

Karbon: <InlineMath math="3560 \div 393.5 = 9.05" /> mol, atau <InlineMath math="9.05 \times 12 = 109" /> g.

Karbon dioksida datang daripada **kedua-dua tindak balas**: <InlineMath math="10" /> mol daripada karbonat dan <InlineMath math="9.05" /> mol daripada bahan api karbon, <InlineMath math="19.05" /> mol kesemuanya, atau <InlineMath math="19.05 \times 24 = 457\text{ dm}^3" />.

# Kenapa pilihan lain salah

- <InlineMath math="54\text{ g}" /> mengabaikan kecekapan <InlineMath math="50\%" />, jadi tanur akan **kekurangan** haba.
- <InlineMath math="240\text{ dm}^3" /> hanya mengira karbon dioksida daripada karbonat.
- <InlineMath math="217\text{ dm}^3" /> hanya mengira karbon dioksida daripada bahan api karbon yang terbakar.
