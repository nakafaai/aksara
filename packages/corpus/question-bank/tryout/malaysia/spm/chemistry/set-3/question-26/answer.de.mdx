# Das Brom verändert das Eisen, bevor das Hydroxid kommt

Eisen(II): <InlineMath math="0{,}0250 \times 0{,}20 = 0{,}0050" /> mol. **Ein Brommolekül oxidiert zwei Eisen(II)-Ionen**, also braucht man <InlineMath math="0{,}0025" /> mol Brom: <InlineMath math="0{,}0025 \div 0{,}050 = 0{,}050\text{ dm}^3 = 50{,}0\text{ cm}^3" />.

Am Endpunkt ist jedes Eisenion Eisen(III). Das Hydroxid gibt <InlineMath math="\text{Fe}^{3+} + 3\text{OH}^- \rightarrow \text{Fe(OH)}_3" />, einen **braunen** Niederschlag mit <InlineMath math="M_r = 56 + 3 \times 17 = 107" />: <InlineMath math="0{,}0050 \times 107 = 0{,}535" /> g.

**Bromid**: Jedes Brommolekül wird zu **zwei Bromidionen**, also sind <InlineMath math="0{,}0050" /> mol Bromid in <InlineMath math="25{,}0 + 50{,}0 = 75{,}0\text{ cm}^3" />: <InlineMath math="0{,}0050 \div 0{,}0750 = 0{,}067\text{ mol dm}^{-3}" />.

# Warum die anderen Antworten falsch sind

- <InlineMath math="25{,}0\text{ cm}^3" /> übernimmt einfach das Volumen der Eisen(II)-Lösung, und grünes Eisen(II)-hydroxid übersieht, dass das Brom alles Eisen **oxidiert** hat.
- <InlineMath math="100\text{ cm}^3" /> rechnet ein Brommolekül je Eisenion.
- <InlineMath math="0{,}033\text{ mol dm}^{-3}" /> gibt ein Bromidion je Brommolekül statt zwei.
