# Dua molekul alkohol menghasilkan satu molekul hidrogen

Hidrogen: <InlineMath math="0{,}120 \div 24 = 0{,}0050" /> mol. Persamaannya membuat **satu molekul hidrogen dari dua molekul alkohol**, jadi ada <InlineMath math="0{,}010" /> mol alkohol, dan <InlineMath math="M_r = 0{,}74 \div 0{,}010 = 74" />.

Untuk <InlineMath math="\text{C}_n\text{H}_{2n+1}\text{OH}" />, <InlineMath math="M_r = 12n + 2n + 1 + 17 = 14n + 18" />. Jadi <InlineMath math="14n + 18 = 74" /> dan <InlineMath math="n = 4" />: <InlineMath math="\text{C}_4\text{H}_9\text{OH}" />.

Empat atom karbon bisa membentuk **rantai lurus atau rantai bercabang**, dan gugus hidroksil bisa di ujung atau di dalam masing-masing: butan-1-ol, butan-2-ol, 2-metilpropan-1-ol, dan 2-metilpropan-2-ol. Jadi ada empat.

**Natrium**: persamaannya memakai **satu atom natrium per molekul alkohol**, jadi <InlineMath math="0{,}010" /> mol natrium bereaksi, <InlineMath math="0{,}010 \times 23 = 0{,}23" /> g.

# Kenapa pilihan lain salah

- <InlineMath math="\text{C}_3\text{H}_7\text{OH}" /> punya <InlineMath math="M_r = 60" />, yang tidak cocok dengan <InlineMath math="74" /> dari data.
- Dua isomer hanya menghitung **rantai lurus** dan melewatkan dua alkohol bercabang.
- <InlineMath math="0{,}12\text{ g}" /> memakai satu atom natrium per molekul hidrogen, padahal dua atom natrium memberi satu molekul hidrogen.
