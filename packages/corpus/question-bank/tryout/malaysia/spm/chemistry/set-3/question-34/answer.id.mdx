# Peletnya melepas kalor dua kali

Natrium hidroksida: <InlineMath math="2{,}0 \div 40 = 0{,}050" /> mol. Asamnya berisi <InlineMath math="0{,}10" /> mol ion hidrogen, lebih dari cukup, jadi **seluruh <InlineMath math="0{,}050" /> mol** larut lalu dinetralkan.

Pelarutan: <InlineMath math="0{,}050 \times 44{,}5 = 2{,}225" /> kJ. Penetralan: <InlineMath math="0{,}050 \times 57{,}3 = 2{,}865" /> kJ.

Kalor total: <InlineMath math="5{,}09" /> kJ, yaitu <InlineMath math="5090" /> J. Kenaikan: <InlineMath math="\Delta T = 5090 \div (100 \times 4{,}2) = 12{,}1^\circ\text{C}" />.

# Kenapa pilihan lain salah

- <InlineMath math="6{,}8^\circ\text{C}" /> hanya menghitung penetralan dan **lupa** bahwa padatan melepas kalor saat larut.
- <InlineMath math="5{,}3^\circ\text{C}" /> hanya menghitung pelarutan.
- <InlineMath math="18{,}9^\circ\text{C}" /> menetralkan seluruh <InlineMath math="0{,}10" /> mol asam, padahal hanya ada <InlineMath math="0{,}050" /> mol hidroksida yang bereaksi.
