# Nama daripada kedua-dua induk, jisim daripada bahan pengehad

Ester mengambil **bahagian alkil daripada alkohol** dan **bahagian asid daripada asid karboksilik**: etanol dan asid propanoik menghasilkan etil propanoat, <InlineMath math="\text{C}_2\text{H}_5\text{COOC}_2\text{H}_5" />.

Etanol, <InlineMath math="M_r = 46" />, ialah bahan pengehad: <InlineMath math="4.6 \div 46 = 0.10" /> mol. Ester mempunyai <InlineMath math="M_r = 5(12) + 10(1) + 2(16) = 102" />, jadi jisim teori ialah <InlineMath math="10.2" /> g dan jisim sebenar <InlineMath math="0.80 \times 10.2 = 8.16" /> g.

# Kenapa pilihan lain salah

- Metil propanoat memerlukan metanol, bukan etanol.
- <InlineMath math="10.2\text{ g}" /> ialah jisim teori, sebelum peratus hasil <InlineMath math="80\%" /> diambil kira.
- Propil etanoat **menukar kedua-dua bahagian**: ia terhasil daripada propanol dan asid etanoik. Jisimnya sama, tetapi namanya berbeza.
