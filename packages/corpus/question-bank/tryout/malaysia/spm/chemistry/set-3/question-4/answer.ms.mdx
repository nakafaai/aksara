# Natrium daripada peringkat pertama menjadi bahan peringkat kedua

<InlineMath math="M_r(\text{NaN}_3) = 23 + 3 \times 14 = 65" />, jadi <InlineMath math="130" /> g ialah <InlineMath math="2.0" /> mol. **Peringkat pertama**: dua mol azida menghasilkan tiga mol nitrogen, jadi <InlineMath math="3.0" /> mol nitrogen dan <InlineMath math="2.0" /> mol natrium.

**Peringkat kedua**: sepuluh mol natrium menghasilkan satu mol nitrogen, jadi <InlineMath math="2.0" /> mol natrium menghasilkan <InlineMath math="0.20" /> mol. Jumlah nitrogen: <InlineMath math="3.0 + 0.20 = 3.2" /> mol, atau <InlineMath math="3.2 \times 24 = 76.8\text{ dm}^3" />.
