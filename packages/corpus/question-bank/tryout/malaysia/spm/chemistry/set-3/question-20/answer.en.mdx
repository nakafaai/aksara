# Only the zinc reacts, so the hydrogen measures the zinc

Copper is below hydrogen in the reactivity series, so it **does not react** with dilute hydrochloric acid. The pink-brown solid left is the copper. All the hydrogen comes from <InlineMath math="\text{Zn} + 2\text{HCl} \rightarrow \text{ZnCl}_2 + \text{H}_2" />.

Hydrogen: <InlineMath math="0.480 \div 24 = 0.020" /> mol, so zinc is <InlineMath math="0.020" /> mol, <InlineMath math="0.020 \times 65 = 1.30" /> g, which is <InlineMath math="1.30 \div 5.00 \times 100\% = 26\%" />.

Copper: <InlineMath math="5.00 - 1.30 = 3.70" /> g, <InlineMath math="3.70 \div 64 = 0.0578" /> mol. That is <InlineMath math="0.0578 \div 0.020 = 2.9" />, about three copper atoms for each zinc atom. The zinc atoms are a different size, so they **disrupt the layers** of copper atoms, which then slide less easily. Brass is harder than copper.

# Why the other options are wrong

- An alloy is harder, **not softer**, than its pure metal, because atoms of a different size stop the layers sliding.
- <InlineMath math="52\%" /> counts two zinc atoms per hydrogen molecule, but one zinc atom gives one molecule.
- Brass conducts electricity less well than pure copper, because the zinc atoms scatter the moving electrons.
