# Apply both yields, and let the smaller reactant decide

Propan-1-ol, <InlineMath math="M_r = 60" />: <InlineMath math="12.0 \div 60 = 0.20" /> mol, so each portion is <InlineMath math="0.10" /> mol. The first portion gives <InlineMath math="0.80 \times 0.10 = 0.080" /> mol of propanoic acid.

The ester forms one to one from <InlineMath math="0.080" /> mol of acid and <InlineMath math="0.10" /> mol of alcohol, so the **acid limits it**. Only <InlineMath math="60\%" /> reacts: <InlineMath math="0.60 \times 0.080 = 0.048" /> mol.

The acid part has three carbons and so does the alcohol part, so the ester is **propyl propanoate**, <InlineMath math="\text{C}_2\text{H}_5\text{COOC}_3\text{H}_7" />, with <InlineMath math="M_r = 116" />: <InlineMath math="0.048 \times 116 = 5.57" /> g.

- <InlineMath math="6.96\text{ g}" /> uses only the <InlineMath math="60\%" /> yield and forgets that just <InlineMath math="80\%" /> of the first portion became acid.
- Ethyl propanoate would need ethanol, but **both parts** come from propan-1-ol here.
