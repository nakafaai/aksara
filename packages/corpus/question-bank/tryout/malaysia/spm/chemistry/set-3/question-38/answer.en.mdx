# Count units and links in the same <InlineMath math="100\text{ g}" />

Isoprene units: <InlineMath math="96.8 \div 68 = 1.42" /> mol. Sulfur atoms: <InlineMath math="3.2 \div 32 = 0.10" /> mol. Each cross-link uses **two sulfur atoms**, so there are <InlineMath math="0.050" /> mol of cross-links, and <InlineMath math="1.42 \div 0.050 \approx 28" /> isoprene units for every one.

A cross-link every <InlineMath math="28" /> units or so ties neighbouring chains together. When the rubber is stretched the chains straighten, but the links stop them sliding apart and **pull them back** when the force goes. So vulcanised rubber is more elastic, harder and stronger than natural rubber.

# Why the other options are wrong

- <InlineMath math="14" /> treats each sulfur atom as a whole cross-link, though every link needs two.
- <InlineMath math="30" /> divides the masses, <InlineMath math="96.8 \div 3.2" />, instead of the moles.
- Sulfur joins chains rather than breaking them, so vulcanised rubber is harder, not softer.
