# The repeating unit has the monomer's mass

In addition polymerisation **no atoms are lost**, so each repeating unit has the same mass as one propene molecule: <InlineMath math="3(12) + 6(1) = 42" />. The number of units is <InlineMath math="42\,000 \div 42 = 1000" />.

  title={<>Addition Polymerisation of Propene</>}

Each double bond opens to form two new single bonds to the neighbouring units. The finished chain has only single bonds between carbon atoms, so the polymer is **saturated** and does not react with bromine water.

# Why the other options are wrong

- The double bonds were used to build the chain, so none are left to decolourise bromine water.
- n = 1500 divides by <InlineMath math="28" />, the mass of ethene, but the monomer is propene.
- Condensation polymers give off small molecules such as water. Propene joins by **addition**, with nothing given off.
