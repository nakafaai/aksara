# The repeating unit has the monomer's formula

Addition polymerisation **loses no atoms**, so each repeating unit has the formula and mass of one chloroethene molecule: <InlineMath math="2(12) + 3(1) + 35.5 = 62.5" />. The number of units is <InlineMath math="125\,000 \div 62.5 = 2000" />.

Because every unit is the same, the polymer has the same composition as the monomer. Chlorine is <InlineMath math="\tfrac{35.5}{62.5} \times 100\% = 56.8\%" /> of the mass. The finished chain has **only single bonds** between carbon atoms, so it does not react with bromine water.

# Why the other options are wrong

- <InlineMath math="35.5\%" /> treats the mass of chlorine as a percentage by itself, without dividing by the unit's mass of <InlineMath math="62.5" />.
- n = 1000 divides by <InlineMath math="125" />, twice the unit's mass.
- The double bonds were used to build the chain, so the polymer is saturated and leaves bromine water orange.
