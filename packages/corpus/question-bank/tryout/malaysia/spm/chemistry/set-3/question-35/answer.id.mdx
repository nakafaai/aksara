# Nyala api harus melepas lebih banyak kalor dari yang diterima air

Kalor yang dibutuhkan air: <InlineMath math="Q = 2000 \times 4{,}2 \times 75 = 630\,000" /> J, atau <InlineMath math="630" /> kJ. Kenaikannya <InlineMath math="100 - 25 = 75^\circ\text{C}" />.

Hanya <InlineMath math="60\%" /> kalor nyala yang sampai, jadi metana harus melepas <InlineMath math="630 \div 0{,}60 = 1050" /> kJ. **Bagi dengan efisiensi**, karena nyala api harus memberi lebih dari yang diterima air.

Metana: <InlineMath math="1050 \div 890 = 1{,}18" /> mol, yaitu <InlineMath math="1{,}18 \times 24 = 28{,}3\text{ dm}^3" />.

**Karbon dioksida**: <InlineMath math="\text{CH}_4 + 2\text{O}_2 \rightarrow \text{CO}_2 + 2\text{H}_2\text{O}" /> memberi **satu karbon dioksida per metana**: <InlineMath math="1{,}18 \times 44 = 51{,}9" /> g.

# Kenapa pilihan lain salah

- <InlineMath math="10{,}2\text{ dm}^3" /> **mengalikan** dengan <InlineMath math="0{,}60" />, yang membuat nyala api memberi kalor lebih sedikit dari yang diserap air.
- <InlineMath math="17{,}0\text{ dm}^3" /> menganggap seluruh kalor sampai ke air.
- <InlineMath math="37{,}8\text{ dm}^3" /> memanaskan air sebesar <InlineMath math="100^\circ\text{C}" />, bukan kenaikan <InlineMath math="75^\circ\text{C}" />.
