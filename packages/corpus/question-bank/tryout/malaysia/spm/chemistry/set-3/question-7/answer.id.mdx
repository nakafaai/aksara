# Cari pereaksi pembatas sebelum memakai rendemen

Aluminium: <InlineMath math="5{,}4 \div 27 = 0{,}20" /> mol. Besi(III) oksida: <InlineMath math="24{,}0 \div 160 = 0{,}15" /> mol. Dua mol aluminium butuh satu mol oksida, jadi <InlineMath math="0{,}20" /> mol aluminium hanya butuh <InlineMath math="0{,}10" /> mol oksida: **aluminium habis lebih dulu**.

# Kenapa pilihan lain salah

- <InlineMath math="13{,}4\text{ g}" /> dihitung dari oksida, <InlineMath math="0{,}15" /> mol menjadi <InlineMath math="0{,}30" /> mol besi, padahal oksidanya **berlebih**.
- <InlineMath math="11{,}2\text{ g}" /> tanpa sisa oksida mengabaikan oksida berlebih sekaligus rendemen <InlineMath math="80\%" />.
- <InlineMath math="16{,}0\text{ g}" /> sisa memakai satu mol oksida per mol aluminium.
