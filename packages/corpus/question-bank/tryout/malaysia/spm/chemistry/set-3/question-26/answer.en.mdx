# Electrons first, then the mole ratio

Iron goes from <InlineMath math="+2" /> to <InlineMath math="+3" />: each ion **loses one electron**, so iron(II) is oxidised. Bromine goes from <InlineMath math="0" /> to <InlineMath math="-1" /> in both atoms, so one molecule takes two electrons and is reduced.

The flask holds <InlineMath math="0.20 \times \tfrac{25.0}{1000} = 0.0050" /> mol of iron(II). The equation needs **one bromine molecule for two iron(II) ions**, so <InlineMath math="0.0025" /> mol of bromine reacts. That is <InlineMath math="0.0025 \div 0.050 = 0.050\text{ dm}^3" />, or <InlineMath math="50.0\text{ cm}^3" />.

# Why the other options are wrong

- An iron(II) ion that becomes iron(III) has **lost** an electron, so it is oxidised, not reduced.
- Bromine takes electrons, so it is the oxidising agent. <InlineMath math="25.0\text{ cm}^3" /> would supply only <InlineMath math="0.00125" /> mol.
- <InlineMath math="100\text{ cm}^3" /> treats the ratio as one to one, as if each iron(II) ion needed a whole bromine molecule.
