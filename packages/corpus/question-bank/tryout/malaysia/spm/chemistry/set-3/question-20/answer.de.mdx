# Nur das Zink reagiert, also misst der Wasserstoff das Zink

Kupfer steht in der Spannungsreihe unter Wasserstoff, es **reagiert nicht** mit verdünnter Salzsäure. Der rotbraune Rest ist das Kupfer. Aller Wasserstoff stammt aus <InlineMath math="\text{Zn} + 2\text{HCl} \rightarrow \text{ZnCl}_2 + \text{H}_2" />.

Wasserstoff: <InlineMath math="0{,}480 \div 24 = 0{,}020" /> mol, also <InlineMath math="0{,}020" /> mol Zink, <InlineMath math="0{,}020 \times 65 = 1{,}30" /> g, das sind <InlineMath math="1{,}30 \div 5{,}00 \times 100\% = 26\%" />.

Kupfer: <InlineMath math="5{,}00 - 1{,}30 = 3{,}70" /> g, <InlineMath math="3{,}70 \div 64 = 0{,}0578" /> mol. Das sind <InlineMath math="0{,}0578 \div 0{,}020 = 2{,}9" />, etwa drei Kupferatome je Zinkatom. Die Zinkatome sind anders groß und **stören die Schichten** der Kupferatome, die dann schwerer gleiten. Messing ist härter als Kupfer.

# Warum die anderen Antworten falsch sind

- Eine Legierung ist härter, **nicht weicher**, als ihr reines Metall, weil Atome anderer Größe das Gleiten der Schichten behindern.
- <InlineMath math="52\%" /> zählt zwei Zinkatome je Wasserstoffmolekül, doch ein Zinkatom gibt ein Molekül.
- Messing leitet schlechter als reines Kupfer, weil die Zinkatome die beweglichen Elektronen streuen.
