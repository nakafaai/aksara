# Ein Brommolekül je Molekül X gibt die molare Masse

Brom: <InlineMath math="M_r(\text{Br}_2) = 160" />, also <InlineMath math="2{,}0 \div 160 = 0{,}0125" /> mol. Jedes Molekül X nimmt **ein Brommolekül** auf, also waren es <InlineMath math="0{,}0125" /> mol X, und <InlineMath math="M_r = 0{,}70 \div 0{,}0125 = 56" />.

Eine Doppelbindung macht X zu einem Alken, <InlineMath math="\text{C}_n\text{H}_{2n}" />: <InlineMath math="14n = 56" />, also <InlineMath math="n = 4" />, und X ist <InlineMath math="\text{C}_4\text{H}_8" />.

Alkenstrukturen von <InlineMath math="\text{C}_4\text{H}_8" />: die Doppelbindung am Ende einer geraden Kette, **But-1-en**, in ihrer Mitte, **But-2-en**, oder an einer verzweigten Kette, **2-Methylpropen**. Das sind drei.

**Wasserstoff**: Er lagert sich an dieselbe Doppelbindung an wie Brom, **ein Molekül je Molekül X**: <InlineMath math="0{,}0125" /> mol, also <InlineMath math="0{,}0125 \times 24\,000 = 300\text{ cm}^3" />.

# Warum die anderen Antworten falsch sind

- <InlineMath math="150\text{ cm}^3" /> mit <InlineMath math="\text{C}_4\text{H}_8" /> lagert ein Wasserstoffmolekül an zwei Moleküle X an, doch jede Doppelbindung nimmt eines auf.
- <InlineMath math="\text{C}_8\text{H}_{16}" /> entsteht, wenn man **zwei Brommoleküle** je Molekül X annimmt, was die molare Masse verdoppelt und den Wasserstoff halbiert.
- Zwei Isomere lassen das verzweigte aus, 2-Methylpropen.
