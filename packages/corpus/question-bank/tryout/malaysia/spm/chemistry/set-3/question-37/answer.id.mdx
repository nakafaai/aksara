# Unit berulang punya rumus monomer

Polimerisasi adisi **tidak kehilangan atom**, jadi tiap unit berulang punya rumus dan massa satu molekul kloroetena: <InlineMath math="2(12) + 3(1) + 35.5 = 62.5" />. Jumlah unitnya <InlineMath math="125\,000 \div 62.5 = 2000" />.

Karena tiap unit sama, komposisi polimer sama dengan monomernya. Klor menyumbang <InlineMath math="\tfrac{35.5}{62.5} \times 100\% = 56.8\%" /> dari massanya. Rantai yang jadi hanya punya **ikatan tunggal** antaratom karbon, jadi tidak bereaksi dengan air brom.

# Kenapa pilihan lain salah

- <InlineMath math="35.5" />% menganggap massa klor sebagai persen begitu saja, tanpa membagi dengan massa unit <InlineMath math="62.5" />.
- n = 1000 membagi dengan <InlineMath math="125" />, dua kali massa unit.
- Ikatan rangkap dua sudah terpakai untuk membangun rantai, jadi polimernya jenuh dan air brom tetap jingga.
