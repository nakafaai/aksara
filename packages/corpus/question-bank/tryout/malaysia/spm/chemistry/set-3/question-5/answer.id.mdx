# Mol molekul, lalu atom per molekul, lalu partikel

Tiga langkah, masing-masing dengan jebakannya: **massa ke mol molekul, molekul ke atom hidrogen, mol ke partikel**.

- Mol air, <InlineMath math="M_r = 18" />: <InlineMath math="\dfrac{4{,}5}{18} = 0{,}25\text{ mol}" />.
- Tiap molekul punya <InlineMath math="2" /> atom hidrogen: <InlineMath math="0{,}25 \times 2 = 0{,}50\text{ mol}" /> atom H.
- Jumlah atom H: <InlineMath math="0{,}50 \times 6{,}02 \times 10^{23} = 3{,}01 \times 10^{23}" />.

# Kenapa pilihan lain salah

- <InlineMath math="1{,}51 \times 10^{23}" /> adalah jumlah **molekul air**, sebelum menghitung dua atom hidrogen di tiap molekul.
- <InlineMath math="6{,}02 \times 10^{23}" /> menganggap sampelnya satu mol.
- <InlineMath math="4{,}52 \times 10^{23}" /> menghitung ketiga atom tiap molekul, termasuk oksigen.
