# Nama dari kedua induk, massa dari pereaksi pembatas

Ester mengambil **bagian alkil dari alkohol** dan **bagian asam dari asam karboksilat**: etanol dan asam propanoat menghasilkan etil propanoat, <InlineMath math="\text{C}_2\text{H}_5\text{COOC}_2\text{H}_5" />.

  `}
/>

Etanol, <InlineMath math="M_r = 46" />, adalah pereaksi pembatas: <InlineMath math="4.6 \div 46 = 0.10" /> mol. Ester punya <InlineMath math="M_r = 5(12) + 10(1) + 2(16) = 102" />, jadi massa teoretisnya <InlineMath math="10.2" /> g dan massa nyatanya <InlineMath math="0.80 \times 10.2 = 8.16" /> g.

# Kenapa pilihan lain salah

- Metil propanoat butuh metanol, bukan etanol.
- <InlineMath math="10.2" /> g adalah massa teoretis, sebelum rendemen <InlineMath math="80\%" /> diterapkan.
- Propil etanoat **menukar kedua bagian**: ester ini berasal dari propanol dan asam etanoat. Massanya sama, tapi namanya beda.
