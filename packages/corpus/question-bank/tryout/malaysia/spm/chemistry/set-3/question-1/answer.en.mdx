# Precision is the spread, accuracy is the distance from the true value

Precise readings **agree closely with each other**. Accurate readings sit **close to the true value**. Check each student for both.

# Why the other options are wrong

- R's mean is <InlineMath math="25.00" />, but the readings spread over <InlineMath math="2.90" /> cm³. A mean that lands on the true value by luck does not make scattered readings precise.
- A wide range is the opposite of precision.
- Q's readings spread over only <InlineMath math="0.04" /> cm³ around the true value, so Q has a small random error, not the largest.
