# Keep only the titres that agree, then use the mole ratio

The rough titre only finds the end point, so it never enters the mean. Of the four runs, <InlineMath math="24.10" />, <InlineMath math="24.15" /> and <InlineMath math="24.12" /> agree within <InlineMath math="0.05\text{ cm}^3" />, while <InlineMath math="24.60" /> overshoots by about <InlineMath math="0.5\text{ cm}^3" />. The **concordant mean** is <InlineMath math="\tfrac{24.10 + 24.15 + 24.12}{3} = 24.12\text{ cm}^3" />.

The alkali holds <InlineMath math="0.100 \times \tfrac{25.0}{1000} = 0.00250" /> mol, and <InlineMath math="\text{NaOH} + \text{HCl} \rightarrow \text{NaCl} + \text{H}_2\text{O}" /> is one to one. So <InlineMath math="c = 0.00250 \div \tfrac{24.12}{1000} = 0.104\text{ mol dm}^{-3}" />.

# Why the other options are wrong

- <InlineMath math="0.102\text{ mol dm}^{-3}" /> averages all five readings, **the rough one and the overshoot included**.
- <InlineMath math="0.0965\text{ mol dm}^{-3}" /> turns the ratio upside down: <InlineMath math="0.100 \times 24.12 \div 25.0" />.
- <InlineMath math="0.0984\text{ mol dm}^{-3}" /> uses the rough titre alone.
