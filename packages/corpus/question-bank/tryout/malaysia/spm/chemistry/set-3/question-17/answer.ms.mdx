# Tiga langkah, satu jumlah dibawa terus

Jisim: <InlineMath math="0.200 \times \tfrac{250}{1000} = 0.0500" /> mol <InlineMath math="\text{Na}_2\text{CO}_3" />, dengan <InlineMath math="M_r = 2(23) + 12 + 3(16) = 106" />, ialah <InlineMath math="0.0500 \times 106 = 5.30" /> g.

Pencairan: bilangan mol yang sama dalam **empat kali isi padu**, jadi <InlineMath math="0.200 \div 4 = 0.0500" /> mol dm⁻³. Kelalang untuk pentitratan mengandungi <InlineMath math="0.0500 \times \tfrac{25.0}{1000} = 0.00125" /> mol karbonat, yang memerlukan **dua mol asid bagi setiap mol**: <InlineMath math="0.00250" /> mol. Pada <InlineMath math="0.100" /> mol dm⁻³, isi padunya <InlineMath math="0.0250\text{ dm}^3" />, atau <InlineMath math="25.0\text{ cm}^3" />.
