# Cari bahan pengehad sebelum menggunakan hasil

Aluminium: <InlineMath math="5.4 \div 27 = 0.20" /> mol. Ferum(III) oksida: <InlineMath math="24.0 \div 160 = 0.15" /> mol. Dua mol aluminium memerlukan satu mol oksida, jadi <InlineMath math="0.20" /> mol aluminium hanya memerlukan <InlineMath math="0.10" /> mol oksida: **aluminium habis dahulu**.

# Kenapa pilihan lain salah

- <InlineMath math="13.4\text{ g}" /> dikira daripada oksida, <InlineMath math="0.15" /> mol menghasilkan <InlineMath math="0.30" /> mol ferum, walhal oksida itu **berlebihan**.
- <InlineMath math="11.2\text{ g}" /> tanpa oksida berbaki mengabaikan oksida berlebihan dan hasil <InlineMath math="80\%" />.
- <InlineMath math="16.0\text{ g}" /> berbaki mengambil satu mol oksida bagi setiap mol aluminium.
