# Hitung besi dari oksida, lalu belerang dari selisihnya

<InlineMath math="M_r(\text{Fe}_2\text{O}_3) = 160" />, jadi <InlineMath math="3{,}20" /> g adalah <InlineMath math="0{,}020" /> mol. Tiap satuan rumus berisi **dua atom besi**, jadi mineralnya berisi <InlineMath math="0{,}040" /> mol besi, <InlineMath math="0{,}040 \times 56 = 2{,}24" /> g.

Sisa mineral adalah belerang: <InlineMath math="4{,}80 - 2{,}24 = 2{,}56" /> g, yaitu <InlineMath math="2{,}56 \div 32 = 0{,}080" /> mol.

Perbandingan besi dan belerang <InlineMath math="0{,}040 : 0{,}080 = 1 : 2" />, jadi mineralnya <InlineMath math="\text{FeS}_2" />, pirit. Tiap atom belerang keluar sebagai satu molekul <InlineMath math="\text{SO}_2" />: <InlineMath math="0{,}080 \times 24 = 1{,}92\text{ dm}^3" />.

# Kenapa pilihan lain salah

- <InlineMath math="\text{FeS}" /> butuh satu atom belerang per atom besi, padahal massanya memberi **dua kali lipat** atom belerang dibanding atom besi.
- <InlineMath math="\text{Fe}_2\text{S}_3" /> butuh <InlineMath math="1{,}5" /> atom belerang per besi, bukan <InlineMath math="2" /> seperti hasil dari massanya.
- <InlineMath math="0{,}96\text{ dm}^3" /> membuat satu molekul belerang dioksida dari tiap dua atom belerang.
