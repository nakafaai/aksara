# Count the iron from the oxide, then the sulfur by difference

<InlineMath math="M_r(\text{Fe}_2\text{O}_3) = 160" />, so <InlineMath math="3.20" /> g is <InlineMath math="0.020" /> mol. Each formula unit holds **two iron atoms**, so the mineral held <InlineMath math="0.040" /> mol of iron, <InlineMath math="0.040 \times 56 = 2.24" /> g.

The rest of the mineral is sulfur: <InlineMath math="4.80 - 2.24 = 2.56" /> g, which is <InlineMath math="2.56 \div 32 = 0.080" /> mol.

Iron to sulfur is <InlineMath math="0.040 : 0.080 = 1 : 2" />, so the mineral is <InlineMath math="\text{FeS}_2" />, pyrite. Each sulfur atom leaves as one <InlineMath math="\text{SO}_2" /> molecule: <InlineMath math="0.080 \times 24 = 1.92\text{ dm}^3" />.

# Why the other options are wrong

- <InlineMath math="\text{FeS}" /> needs one sulfur atom per iron atom, but the masses give **twice as many** sulfur atoms as iron atoms.
- <InlineMath math="\text{Fe}_2\text{S}_3" /> would need <InlineMath math="1.5" /> sulfur atoms per iron, not the <InlineMath math="2" /> the masses give.
- <InlineMath math="0.96\text{ dm}^3" /> makes one sulfur dioxide molecule from every two sulfur atoms.
