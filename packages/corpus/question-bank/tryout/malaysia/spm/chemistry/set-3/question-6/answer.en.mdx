# Percentages become grams in a <InlineMath math="100\text{ g}" /> sample

Take <InlineMath math="100\text{ g}" />, so each percentage is a mass in grams. **Divide by atomic mass, find the simplest ratio, then scale to the molecular mass**.

- Moles: C <InlineMath math="\dfrac{40.0}{12} = 3.33" />, H <InlineMath math="\dfrac{6.7}{1} = 6.7" />, O <InlineMath math="\dfrac{53.3}{16} = 3.33" />.
- Divide by <InlineMath math="3.33" />: <InlineMath math="1 : 2 : 1" />, so the empirical formula is <InlineMath math="\text{CH}_2\text{O}" />, mass <InlineMath math="30" />.
- <InlineMath math="\dfrac{180}{30} = 6" />, so the molecular formula is <InlineMath math="\text{C}_6\text{H}_{12}\text{O}_6" />.

# Why the other options are wrong

- <InlineMath math="\text{CH}_2\text{O}" /> is the empirical formula: it **stops before using the molecular mass**.
- <InlineMath math="\text{C}_3\text{H}_6\text{O}_3" /> has mass <InlineMath math="90" />, half of <InlineMath math="180" />.
- <InlineMath math="\text{C}_2\text{H}_4\text{O}_2" /> has mass <InlineMath math="60" />, a third of it.
