# Kira ferum daripada oksida, kemudian sulfur melalui beza

<InlineMath math="M_r(\text{Fe}_2\text{O}_3) = 160" />, jadi <InlineMath math="3.20" /> g ialah <InlineMath math="0.020" /> mol. Setiap unit formula mengandungi **dua atom ferum**, jadi mineral itu mengandungi <InlineMath math="0.040" /> mol ferum, <InlineMath math="0.040 \times 56 = 2.24" /> g.

Baki mineral ialah sulfur: <InlineMath math="4.80 - 2.24 = 2.56" /> g, iaitu <InlineMath math="2.56 \div 32 = 0.080" /> mol.

Nisbah ferum kepada sulfur ialah <InlineMath math="0.040 : 0.080 = 1 : 2" />, jadi mineral itu <InlineMath math="\text{FeS}_2" />, pirit. Setiap atom sulfur keluar sebagai satu molekul <InlineMath math="\text{SO}_2" />: <InlineMath math="0.080 \times 24 = 1.92\text{ dm}^3" />.

# Kenapa pilihan lain salah

- <InlineMath math="\text{FeS}" /> memerlukan satu atom sulfur bagi setiap atom ferum, tetapi jisim memberi **dua kali ganda** atom sulfur berbanding atom ferum.
- <InlineMath math="\text{Fe}_2\text{S}_3" /> memerlukan <InlineMath math="1.5" /> atom sulfur bagi setiap ferum, bukan <InlineMath math="2" /> seperti yang diberi oleh jisim.
- <InlineMath math="0.96\text{ dm}^3" /> menghasilkan satu molekul sulfur dioksida daripada setiap dua atom sulfur.
