# The salt fixes the acid part, and the rest is the alcohol

Test the possible salts: sodium methanoate, <InlineMath math="\text{HCOONa}" />, is <InlineMath math="68" />. Sodium ethanoate, <InlineMath math="\text{CH}_3\text{COONa}" />, is <InlineMath math="15 + 44 + 23 = 82" />. Sodium propanoate is <InlineMath math="96" />. So the acid part is **ethanoate**, with two carbons.

The ester has four carbons, so the alcohol part has the other two: ethanol. The ester is **ethyl ethanoate**, <InlineMath math="\text{CH}_3\text{COOC}_2\text{H}_5" />.

Ester: <InlineMath math="M_r = 88" />, so <InlineMath math="4.4 \div 88 = 0.050" /> mol. Each ester molecule gives **one alcohol molecule**: <InlineMath math="0.050 \times 46 = 2.3" /> g of ethanol.

**Alkali**: the ester has **one ester link**, so each molecule takes one sodium hydroxide: <InlineMath math="0.050" /> mol, which is <InlineMath math="0.050 \div 1.0 = 0.050\text{ dm}^3 = 50\text{ cm}^3" /> at the least.

# Why the other options are wrong

- Methyl propanoate would give sodium propanoate, <InlineMath math="M_r = 96" />, **not** <InlineMath math="82" />.
- Propyl methanoate would give sodium methanoate, <InlineMath math="M_r = 68" />.
- <InlineMath math="100\text{ cm}^3" /> uses two sodium hydroxide per ester molecule, but one ester link takes one.
