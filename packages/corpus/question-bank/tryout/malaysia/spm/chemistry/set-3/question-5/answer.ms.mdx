# Mol molekul, kemudian atom setiap molekul, kemudian zarah

Tiga langkah, setiap satu dengan perangkapnya: **jisim kepada mol molekul, molekul kepada atom hidrogen, mol kepada zarah**.

- Mol air, <InlineMath math="M_r = 18" />: <InlineMath math="\dfrac{4.5}{18} = 0.25\text{ mol}" />.
- Setiap molekul mempunyai <InlineMath math="2" /> atom hidrogen: <InlineMath math="0.25 \times 2 = 0.50\text{ mol}" /> atom H.
- Bilangan atom H: <InlineMath math="0.50 \times 6.02 \times 10^{23} = 3.01 \times 10^{23}" />.
