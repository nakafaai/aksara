# Atom lebih besar, gaya antaratom lebih kuat

Gas mulia berupa atom tunggal. Mendidihkannya berarti mengatasi **gaya tarik lemah antaratom**, yang bertambah seiring atom makin besar dan punya lebih banyak elektron.

# Kenapa pilihan lain salah

- Semua gas mulia kecuali helium punya <InlineMath math="8" /> elektron valensi, jadi radon tidak punya lebih sedikit.
- Trennya berlawanan arah, dan **kereaktifan tidak menentukan titik didih**.
- Oktet stabil menjelaskan mengapa gas mulia tidak reaktif, bukan mengapa titik didihnya berbeda.
