# Perbandingan atom yang tetap memberi persen yang tetap

Tiap alkena berumus <InlineMath math="\text{C}_n\text{H}_{2n}" />, jadi ia punya **dua atom hidrogen untuk tiap atom karbon**, berapa pun panjangnya. Persen karbonnya <InlineMath math="\tfrac{12n}{14n} \times 100\% = 85.7\%" /> untuk tiap <InlineMath math="n" />.

Alkana <InlineMath math="\text{C}_n\text{H}_{2n+2}" /> selalu punya dua atom hidrogen lebih, jadi persennya tetap di bawah <InlineMath math="85.7\%" />. Per atom karbon, alkena punya lebih sedikit hidrogen untuk dibakar, jadi lebih banyak karbon tersisa sebagai jelaga. Itulah sebabnya etena terbakar dengan nyala lebih berjelaga dibanding etana.

# Kenapa pilihan lain salah

- Garis alkena **datar di <InlineMath math="85.7" />%**, jadi persennya tidak naik.
- Persen alkana naik dari <InlineMath math="75.0\%" /> mendekati <InlineMath math="85.7\%" />, jadi tidak turun.
- Metana punya persen paling rendah, <InlineMath math="75.0\%" />, di antara semua alkana.
