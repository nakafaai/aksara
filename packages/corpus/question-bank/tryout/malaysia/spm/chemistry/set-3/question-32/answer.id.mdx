# Garam menentukan bagian asam, sisanya adalah alkohol

Uji garam yang mungkin: natrium metanoat, <InlineMath math="\text{HCOONa}" />, bernilai <InlineMath math="68" />. Natrium etanoat, <InlineMath math="\text{CH}_3\text{COONa}" />, bernilai <InlineMath math="15 + 44 + 23 = 82" />. Natrium propanoat bernilai <InlineMath math="96" />. Jadi bagian asamnya **etanoat**, dengan dua karbon.

Esternya punya empat karbon, jadi bagian alkoholnya dua karbon sisanya: etanol. Esternya **etil etanoat**, <InlineMath math="\text{CH}_3\text{COOC}_2\text{H}_5" />.

Ester: <InlineMath math="M_r = 88" />, jadi <InlineMath math="4{,}4 \div 88 = 0{,}050" /> mol. Tiap molekul ester memberi **satu molekul alkohol**: <InlineMath math="0{,}050 \times 46 = 2{,}3" /> g etanol.

**Basa**: esternya punya **satu ikatan ester**, jadi tiap molekul memakai satu natrium hidroksida: <InlineMath math="0{,}050" /> mol, yaitu paling sedikit <InlineMath math="0{,}050 \div 1{,}0 = 0{,}050\text{ dm}^3 = 50\text{ cm}^3" />.

# Kenapa pilihan lain salah

- Metil propanoat akan memberi natrium propanoat, <InlineMath math="M_r = 96" />, **bukan** <InlineMath math="82" />.
- Propil metanoat akan memberi natrium metanoat, <InlineMath math="M_r = 68" />.
- <InlineMath math="100\text{ cm}^3" /> memakai dua natrium hidroksida per molekul ester, padahal satu ikatan ester memakai satu.
