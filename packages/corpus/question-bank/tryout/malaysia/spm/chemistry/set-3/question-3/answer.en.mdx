# Same mass, different molar mass, so count each sample separately

Deuterium has **one neutron** and ordinary hydrogen has none, so <InlineMath math="M_r(\text{D}_2\text{O}) = 2 + 2 + 16 = 20" /> and <InlineMath math="M_r(\text{H}_2\text{O}) = 18" />. In <InlineMath math="2.0" /> g there are <InlineMath math="0.10" /> mol of heavy water but <InlineMath math="0.111" /> mol of ordinary water.

Per molecule, both have <InlineMath math="10" /> protons. Heavy water has <InlineMath math="1 + 1 + 8 = 10" /> neutrons, ordinary water only the <InlineMath math="8" /> in oxygen.

Neutrons: <InlineMath math="0.10 \times 10 = 1.0" /> mol against <InlineMath math="0.111 \times 8 = 0.889" /> mol, a difference of <InlineMath math="0.111" /> mol, or <InlineMath math="0.111 \times 6.02 \times 10^{23} = 6.69 \times 10^{22}" />. Protons: <InlineMath math="1.0" /> mol against <InlineMath math="1.11" /> mol, so **ordinary water has more protons**, because it has more molecules.

# Why the other options are wrong

- Equal masses do not hold **equal numbers of molecules** when the molar masses differ, so the counts cannot all match.
- <InlineMath math="1.20 \times 10^{23}" /> adds two neutrons for each of the <InlineMath math="0.10" /> mol of heavy water, as if both samples had the same number of molecules.
- Heavy water has fewer molecules in <InlineMath math="2.0" /> g, each with the same <InlineMath math="10" /> protons, so it has fewer protons, not more.
