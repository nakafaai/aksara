# Bromin mengubah besi sebelum hidroksida datang

Besi(II): <InlineMath math="0{,}0250 \times 0{,}20 = 0{,}0050" /> mol. **Satu molekul bromin mengoksidasi dua ion besi(II)**, jadi dibutuhkan <InlineMath math="0{,}0025" /> mol bromin: <InlineMath math="0{,}0025 \div 0{,}050 = 0{,}050\text{ dm}^3 = 50{,}0\text{ cm}^3" />.

Pada titik akhir semua ion besi sudah menjadi besi(III). Hidroksida memberi <InlineMath math="\text{Fe}^{3+} + 3\text{OH}^- \rightarrow \text{Fe(OH)}_3" />, endapan **cokelat** dengan <InlineMath math="M_r = 56 + 3 \times 17 = 107" />: <InlineMath math="0{,}0050 \times 107 = 0{,}535" /> g.

**Bromida**: tiap molekul bromin menjadi **dua ion bromida**, jadi <InlineMath math="0{,}0050" /> mol bromida ada dalam <InlineMath math="25{,}0 + 50{,}0 = 75{,}0\text{ cm}^3" />: <InlineMath math="0{,}0050 \div 0{,}0750 = 0{,}067\text{ mol dm}^{-3}" />.

# Kenapa pilihan lain salah

- <InlineMath math="25{,}0\text{ cm}^3" /> hanya menyamakan volume larutan besi(II), dan besi(II) hidroksida hijau mengabaikan bahwa bromin sudah **mengoksidasi** semua besi.
- <InlineMath math="100\text{ cm}^3" /> memakai satu molekul bromin per ion besi.
- <InlineMath math="0{,}033\text{ mol dm}^{-3}" /> memberi satu ion bromida per molekul bromin, bukan dua.
