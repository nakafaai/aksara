# Timbang kristal beserta airnya, biarkan asam menghitung hidroksida dua per dua, lalu perbesar bagian itu ke labu

Asamnya <InlineMath math="0{,}250\times0{,}0500=0{,}0125\text{ mol}" />. **Kristalnya membawa dua molekul air**, <InlineMath math="M_r=126" />, jadi ditimbang <InlineMath math="0{,}0125\times126=1{,}58\text{ g}" />. Bagian <InlineMath math="25{,}0\text{ cm}^3" /> memuat <InlineMath math="1{,}25\times10^{-3}\text{ mol}" /> asam. **Tiap molekul asam menetralkan dua ion hidroksida**, jadi <InlineMath math="26{,}0\text{ cm}^3" /> basa itu memuat <InlineMath math="2{,}50\times10^{-3}\text{ mol}" />, <InlineMath math="0{,}0962\text{ mol dm}^{-3}" />. Labu <InlineMath math="250\text{ cm}^3" /> itu memuat <InlineMath math="0{,}0240\text{ mol}" />, <InlineMath math="0{,}962\text{ g}" /> natrium hidroksida, <InlineMath math="96{,}2\%" /> dari <InlineMath math="1{,}00\text{ g}" />.
