# Tukar setiap isi padu kepada jisim dengan ketumpatannya sendiri, kemudian kira atom karbon dalam setiap bahan api

Satu liter itu mengandungi <InlineMath math="100\text{ cm}^3" /> etanol, <InlineMath math="79\text{ g}" />, dan <InlineMath math="900\text{ cm}^3" /> oktana, <InlineMath math="630\text{ g}" />. **Setiap bahan api membawa karbonnya sendiri**: etanol <InlineMath math="1.72\text{ mol}" /> dengan dua atom karbon setiap satu, dan oktana <InlineMath math="5.53\text{ mol}" /> dengan lapan. Setiap atom karbon menjadi satu molekul karbon dioksida.

# Kenapa pilihan lain salah

- <InlineMath math="2.16\text{ kg}" /> membakar seluruh liter sebagai oktana. **Satu persepuluh isi padu ialah etanol, dengan ketumpatan dan bilangan karbonnya sendiri**.
- <InlineMath math="1.95\text{ kg}" /> mengira oktana sahaja dan tertinggal karbon dioksida daripada etanol.
- <InlineMath math="1.05\text{ kg}" /> memberi satu karbon dioksida bagi setiap dua atom karbon.
