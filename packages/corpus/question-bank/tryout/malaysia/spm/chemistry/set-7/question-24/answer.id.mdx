# Hidrogen mengambil empat atom oksigen, tetapi besi hanya larut menjadi besi(II)

Magnetitnya <InlineMath math="0{,}0200\text{ mol}" />. **Tiap satuan rumus memuat empat atom oksigen, dan masing-masing memerlukan satu molekul hidrogen untuk keluar sebagai air**, <InlineMath math="\text{Fe}_3\text{O}_4+4\text{H}_2\rightarrow3\text{Fe}+4\text{H}_2\text{O}" />, jadi <InlineMath math="0{,}0800\text{ mol}" /> terpakai. Itu memberi <InlineMath math="0{,}0600\text{ mol}" /> besi. Asam encer hanya membawa besi ke besi(II), <InlineMath math="\text{Fe}+2\text{HCl}\rightarrow\text{FeCl}_2+\text{H}_2" />, jadi <InlineMath math="0{,}0600\text{ mol}" /> hidrogen keluar lagi, meskipun magnetit sendiri memuat besi(III).

# Kenapa pilihan lain salah

- <InlineMath math="1{,}44\text{ dm}^3" /> untuk reduksi memakai satu molekul hidrogen per atom besi. **Hidrogen mengambil oksigen, dan ada empat atom oksigen**.
- <InlineMath math="2{,}16\text{ dm}^3" /> melarutkan besi menjadi besi(III), padahal asam klorida encer memberi besi(II).
- <InlineMath math="0{,}960\text{ dm}^3" /> memakai satu molekul hidrogen per ion besi(III) dan menyisakan oksigen dalam padatan.
