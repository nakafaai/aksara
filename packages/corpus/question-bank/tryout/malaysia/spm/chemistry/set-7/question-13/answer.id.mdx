# Massa memberi jumlah molekul, dan tiap ikatan dipakai bersama dua atom

Satu mol <InlineMath math="\text{C}_{60}" /> bermassa <InlineMath math="720\text{ g}" />, jadi <InlineMath math="0{,}72\text{ g}" /> sama dengan <InlineMath math="1{,}00\times10^{-3}\text{ mol}" /> molekul. Tiap dari <InlineMath math="60" /> atom punya tiga ikatan, tetapi **tiap ikatan menghubungkan dua atom, jadi menghitung dari tiap atom menghitung tiap ikatan dua kali**: satu molekul punya <InlineMath math="\tfrac{60\times3}{2}=90" /> ikatan.

N(\text{C}_{60})&=\tfrac{0{,}72}{720}\times6{,}02\times10^{23}=6{,}02\times10^{20}\\

\end{aligned}" />

# Kenapa pilihan lain salah

- <InlineMath math="3{,}61\times10^{22}" /> adalah jumlah atom karbon. **Tiap molekul berisi enam puluh**.
- <InlineMath math="1{,}08\times10^{23}" /> menghitung <InlineMath math="180" /> ikatan per molekul. **Tiap ikatan dipakai bersama dua atom**.
- <InlineMath math="3{,}61\times10^{22}" /> ikatan memberi tiap atom satu ikatan.
