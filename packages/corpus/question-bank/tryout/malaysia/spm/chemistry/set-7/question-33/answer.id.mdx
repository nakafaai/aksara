# Kenapa pilihan lain salah

- <InlineMath math="120{,}5^\circ\text{C}" /> memakai semua kalor untuk memanaskan air. **Air terbuka berhenti di <InlineMath math="100^\circ\text{C}" />**.
- Berhenti di <InlineMath math="100^\circ\text{C}" /> memang benar, tetapi sisa <InlineMath math="34{,}4\text{ kJ}" /> tidak hilang: kalor itu menguapkan air.
- <InlineMath math="101\text{ kJ}" /> memakai seluruh <InlineMath math="222\text{ kJ}" /> dari nyala api, padahal hanya <InlineMath math="70\%" /> yang sampai ke air.
