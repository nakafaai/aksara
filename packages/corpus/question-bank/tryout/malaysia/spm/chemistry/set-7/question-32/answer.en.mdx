# Recycling means the low conversion per pass does not set the yield, the overall figure does

One tonne of ethene is <InlineMath math="35.7\times10^3\text{ mol}" />. **The <InlineMath math="5\%" /> per pass is not the yield**: the ethene that does not react goes round again and again, so what matters is the overall <InlineMath math="95\%" />. Each ethene molecule gives one ethanol molecule, and ethanol's molar mass of <InlineMath math="46" /> is larger than ethene's <InlineMath math="28" />, so the ethanol weighs more than the ethene used.

# Why the other options are wrong

- <InlineMath math="0.0821" /> tonnes uses the <InlineMath math="5\%" /> per pass. **The recycled ethene reacts in later passes**.
- <InlineMath math="1.64" /> tonnes assumes every molecule of ethene ends as ethanol. **Overall only <InlineMath math="95\%" /> does**.
- <InlineMath math="1.48" /> tonnes applies the <InlineMath math="95\%" /> twice.
