# Susunan menamakan sulfur, molekul mengandungi lapan atom, dan setiap atom membentuk dioksidanya sendiri

Ion <InlineMath math="\text{X}^{2-}" /> dengan lapan belas elektron mempunyai enam belas proton, jadi X ialah sulfur. **Setiap molekul ialah gelang lapan atom**, <InlineMath math="256" /> per mol, jadi <InlineMath math="1.60\text{ g}" /> hanya <InlineMath math="0.00625\text{ mol}" /> molekul tetapi <InlineMath math="0.0500\text{ mol}" /> atom. Pembakaran memberi satu molekul sulfur dioksida bagi setiap atom sulfur.
