# Kenal pasti X daripada ionnya, kira molekul lapan atom, kemudian ikut setiap atom hingga menjadi asid diprotik

<InlineMath math="\text{X}^{2-}" /> mempunyai <InlineMath math="18" /> elektron, jadi X mempunyai <InlineMath math="16" /> proton, iaitu sulfur, dan pepejal itu <InlineMath math="\text{S}_8" />, <InlineMath math="M_r=256" />. Sampel itu <InlineMath math="1.60\div256=0.00625\text{ mol}" /> molekul, <InlineMath math="3.76\times10^{21}" />. **Setiap molekul mengandungi lapan atom**, jadi <InlineMath math="0.0500\text{ mol}" /> atom sulfur memberi <InlineMath math="0.0500\text{ mol}" /> <InlineMath math="\text{SO}_2" /> dan kemudian <InlineMath math="0.0500\text{ mol}" /> <InlineMath math="\text{H}_2\text{SO}_4" />. **Asid sulfurik ialah asid diprotik**, jadi ia memerlukan <InlineMath math="0.100\text{ mol}" /> natrium hidroksida, <InlineMath math="200\text{ cm}^3" />.
