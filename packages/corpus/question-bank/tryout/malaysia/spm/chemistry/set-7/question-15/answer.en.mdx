# The barium sulfate fixes the sulfuric acid, which uses two hydroxide ions per molecule

The alkali is <InlineMath math="0.00600\text{ mol}" />. The barium sulfate, <InlineMath math="0.00100\text{ mol}" />, counts the sulfate ions, so the portion holds <InlineMath math="0.00100\text{ mol}" /> of sulfuric acid. **Each sulfuric acid molecule gives two hydrogen ions**, so it uses <InlineMath math="0.00200\text{ mol}" /> of the alkali. The other <InlineMath math="0.00400\text{ mol}" /> neutralises hydrochloric acid in <InlineMath math="25.0\text{ cm}^3" />.

# Why the other options are wrong

- <InlineMath math="0.200\text{ mol dm}^{-3}" /> lets each sulfuric acid molecule use one hydroxide ion. **It is diprotic and uses two**.
- <InlineMath math="0.240\text{ mol dm}^{-3}" /> gives all the alkali to hydrochloric acid and ignores the sulfuric acid.
- <InlineMath math="0.0800\text{ mol dm}^{-3}" /> divides by both portions together, but the titration used only one.
