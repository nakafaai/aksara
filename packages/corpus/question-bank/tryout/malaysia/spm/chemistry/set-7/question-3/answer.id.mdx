# Kenali X dari ionnya, hitung molekul delapan atom, lalu ikuti tiap atom hingga menjadi asam diprotik

<InlineMath math="\text{X}^{2-}" /> punya <InlineMath math="18" /> elektron, jadi X punya <InlineMath math="16" /> proton, yaitu belerang, dan padatannya <InlineMath math="\text{S}_8" />, <InlineMath math="M_r=256" />. Sampelnya <InlineMath math="1{,}60\div256=0{,}00625\text{ mol}" /> molekul, <InlineMath math="3{,}76\times10^{21}" />. **Tiap molekul memuat delapan atom**, jadi <InlineMath math="0{,}0500\text{ mol}" /> atom belerang memberi <InlineMath math="0{,}0500\text{ mol}" /> <InlineMath math="\text{SO}_2" /> lalu <InlineMath math="0{,}0500\text{ mol}" /> <InlineMath math="\text{H}_2\text{SO}_4" />. **Asam sulfat bersifat diprotik**, jadi perlu <InlineMath math="0{,}100\text{ mol}" /> natrium hidroksida, <InlineMath math="200\text{ cm}^3" />.
