# Susunan elektron menunjuk belerang, molekulnya berisi delapan atom, dan tiap atom membentuk dioksidanya sendiri

Ion <InlineMath math="\text{X}^{2-}" /> berelektron delapan belas punya enam belas proton, jadi X adalah belerang. **Tiap molekul berupa cincin delapan atom**, <InlineMath math="256" /> per mol, jadi <InlineMath math="1{,}60\text{ g}" /> hanya <InlineMath math="0{,}00625\text{ mol}" /> molekul tetapi <InlineMath math="0{,}0500\text{ mol}" /> atom. Pembakaran memberi satu molekul belerang dioksida per atom belerang.

- <InlineMath math="3{,}01\times10^{22}" /> adalah jumlah atom belerang. **Tiap molekul berisi delapan**.
