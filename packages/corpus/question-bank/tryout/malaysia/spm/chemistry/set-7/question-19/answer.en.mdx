# The copper(II) ions take some zinc before the copper they leave behind speeds up the rest

The zinc is <InlineMath math="0.0100\text{ mol}" /> and the acid is in excess. **Zinc displaces copper from the <InlineMath math="0.00250\text{ mol}" /> of copper(II) ions first**, so that much zinc gives no hydrogen. The copper deposited on the zinc catalyses the reaction, so the start is faster, but only <InlineMath math="0.00750\text{ mol}" /> of zinc is left to make hydrogen.

# Why the other options are wrong

- <InlineMath math="240\text{ cm}^3" /> treats the copper(II) ions as a catalyst that changes nothing else. **They first use up some of the zinc**.
- The copper deposited on the zinc speeds the reaction up, so the start cannot be slower.
- <InlineMath math="240\text{ cm}^3" /> with the same rate ignores both the zinc used in displacement and the copper's catalysis.
