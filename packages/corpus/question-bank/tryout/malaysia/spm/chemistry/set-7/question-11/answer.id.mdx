# Ubah kubus ke sentimeter kubik sebelum memakai massa jenis, lalu hitung dua ion per satuan rumus

**Kubus berusuk <InlineMath math="1{,}00\text{ mm}" /> berukuran <InlineMath math="0{,}100\text{ cm}" /> di tiap sisi**, jadi volumenya <InlineMath math="1{,}00\times10^{-3}\text{ cm}^3" />, bukan <InlineMath math="1\text{ cm}^3" />.
