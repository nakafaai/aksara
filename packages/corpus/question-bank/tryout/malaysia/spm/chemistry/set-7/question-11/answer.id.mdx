# Ubah kubus menjadi gram dan mol, hitung dua ion per satuan rumus, lalu biarkan dua ion klorida membentuk tiap molekul klorin

Kubus itu bersisi <InlineMath math="0{,}100\text{ cm}" />, <InlineMath math="1{,}00\times10^{-3}\text{ cm}^3" />, jadi massanya <InlineMath math="2{,}16\times10^{-3}\text{ g}" />, <InlineMath math="3{,}69\times10^{-5}\text{ mol}" />. **Tiap satuan rumus adalah dua ion**, jadi kristal itu memuat <InlineMath math="7{,}38\times10^{-5}\times6{,}02\times10^{23}=4{,}45\times10^{19}" /> ion.
