# The gas lost is the oxygen, four iron rust for every three oxygen, and the wool gains only the oxygen it takes in

The <InlineMath math="21.0\text{ cm}^3" /> lost is oxygen, <InlineMath math="21.0\div24\,000=8.75\times10^{-4}\text{ mol}" />. **<InlineMath math="4\text{Fe}+3\text{O}_2\rightarrow2\text{Fe}_2\text{O}_3" /> uses four iron for every three oxygen**, so <InlineMath math="1.17\times10^{-3}\text{ mol}" /> of iron, <InlineMath math="0.0653\text{ g}" />, has rusted. The wool keeps all its iron and gains only the oxygen, <InlineMath math="8.75\times10^{-4}\times32=0.0280\text{ g}" />. **Only <InlineMath math="0.0653\text{ g}" /> of the <InlineMath math="0.500\text{ g}" /> has rusted**, so iron is left: the volume stops falling because the oxygen, <InlineMath math="21\%" /> of the air, has run out.

# Why the other options are wrong

- <InlineMath math="0.0490\text{ g}" /> takes one iron per oxygen molecule. **The equation uses four iron for three oxygen**.
- <InlineMath math="0.0933\text{ g}" /> is the whole mass of the rust, but its iron was already in the wool, so the wool gains only the oxygen.
- Most of the steel wool is still iron, so it has not all rusted. The oxygen ran out first.
