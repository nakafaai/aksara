# Scale the sample to the field, halve for the carbonate, then allow for the limestone's impurity

The field is <InlineMath math="2.0\times10^8" /> times the sample, so it holds <InlineMath math="4.0\times10^4\text{ mol}" /> of hydrogen ions. **Each carbonate ion takes two hydrogen ions**, so <InlineMath math="2.0\times10^4\text{ mol}" /> of calcium carbonate, <InlineMath math="2.00" /> tonnes, is needed. **Only <InlineMath math="80\%" /> of the limestone is carbonate**, so more limestone than that must be spread.

# Why the other options are wrong

- <InlineMath math="2.00" /> tonnes is the calcium carbonate alone. **The limestone is only <InlineMath math="80\%" /> carbonate**.
- <InlineMath math="1.60" /> tonnes multiplies by <InlineMath math="0.80" /> instead of dividing, as if the impurity also neutralised acid.
- <InlineMath math="5.00" /> tonnes uses one hydrogen ion per carbonate. **Each carbonate takes two**.
