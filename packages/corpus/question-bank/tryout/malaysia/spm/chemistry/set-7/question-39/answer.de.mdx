# Warum die anderen Antworten falsch sind

- <InlineMath math="840\text{ cm}^3" /> lässt das Hypochlorit die Menge bestimmen. **Die Säure geht zuerst aus, denn jedes Hypochlorit braucht zwei**.
- <InlineMath math="1440\text{ cm}^3" /> gibt ein Chlor je Säuremolekül, doch zwei Säure geben ein Chlor.
- <InlineMath math="88{,}8\text{ mg m}^{-3}" /> nimmt <InlineMath math="35{,}5" /> für Chlor, doch das Gas ist <InlineMath math="\text{Cl}_2" /> mit <InlineMath math="M_r=71" />.
