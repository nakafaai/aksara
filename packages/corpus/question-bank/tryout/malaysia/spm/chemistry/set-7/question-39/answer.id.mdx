# Kedua aditif membawa natrium, dan hanya bagian natrium tiap aditif yang dihitung

MSG bermassa molar <InlineMath math="169" />, dan <InlineMath math="23" /> di antaranya natrium, jadi <InlineMath math="5{,}0\text{ g}" /> membawa <InlineMath math="0{,}68\text{ g}" />. **Garam dapur adalah natrium klorida dan juga membawa natrium**: <InlineMath math="\tfrac{23}{58{,}5}" /> dari <InlineMath math="3{,}0\text{ g}" />, <InlineMath math="1{,}18\text{ g}" />. Bersama keduanya memberi <InlineMath math="1{,}86\text{ g}" />, sedikit di bawah pedoman.

# Kenapa pilihan lain salah

- <InlineMath math="0{,}68\text{ g}" /> hanya menghitung MSG. **Garam dapur juga membawa natrium**.
- <InlineMath math="1{,}18\text{ g}" /> hanya menghitung garam dapur dan lupa bahwa MSG adalah garam natrium.
- <InlineMath math="8{,}0\text{ g}" /> menjumlahkan seluruh massa aditif, bukan natriumnya.
