# The mass gives the molecules, and each link is shared by two atoms

One mole of <InlineMath math="\text{C}_{60}" /> weighs <InlineMath math="720\text{ g}" />, so <InlineMath math="0.72\text{ g}" /> is <InlineMath math="1.00\times10^{-3}\text{ mol}" /> of molecules. Each of the <InlineMath math="60" /> atoms has three links, but **every link joins two atoms, so counting from each atom counts every link twice**: a molecule has <InlineMath math="\tfrac{60\times3}{2}=90" /> links.

# Why the other options are wrong

- <InlineMath math="3.61\times10^{22}" /> is the number of carbon atoms. **Each molecule holds sixty**.
- <InlineMath math="1.08\times10^{23}" /> counts <InlineMath math="180" /> links per molecule. **Each link is shared by two atoms**.
- <InlineMath math="3.61\times10^{22}" /> links gives each atom one link.
