# Both acids hold the same moles and run out before the metal, so they give the same total, and the leftover metal displaces copper

Each flask holds <InlineMath math="0.025\text{ mol}" /> of acid, and the magnesium is <InlineMath math="0.020\text{ mol}" />. <InlineMath math="\text{Mg}+2\text{H}^+\rightarrow\text{Mg}^{2+}+\text{H}_2" /> needs two acid per magnesium, **so the acid runs out after <InlineMath math="0.0125\text{ mol}" /> of magnesium** in both flasks. Each gives <InlineMath math="0.0125\text{ mol}" /> of hydrogen, <InlineMath math="300\text{ cm}^3" />, because the weak acid still gives up all its hydrogen ions in the end, only more slowly. Each flask keeps <InlineMath math="0.0075\text{ mol}" /> of magnesium, <InlineMath math="0.0150\text{ mol}" /> in all, **and each magnesium atom displaces one copper atom**, <InlineMath math="0.0150\times64=0.96\text{ g}" />.
