# The acid runs out in both flasks, and the weak acid gives the same total, only more slowly

Each flask holds <InlineMath math="0.025\text{ mol}" /> of acid and <InlineMath math="0.0200\text{ mol}" /> of magnesium. **Each magnesium atom needs two acid molecules**, so the acid runs out after <InlineMath math="0.0125\text{ mol}" /> of magnesium, giving <InlineMath math="0.0125\text{ mol}" /> of hydrogen and leaving <InlineMath math="0.0075\text{ mol}" /> of magnesium. Ethanoic acid ionises only partly, so its hydrogen ion concentration is lower and it reacts more slowly, but as ions are used up more molecules ionise, so in the end it gives the same hydrogen.

# Why the other options are wrong

- <InlineMath math="480\text{ cm}^3" /> lets all the magnesium react. **The acid runs out first**.
- The weak acid ionises slowly, but all its molecules react in the end, so it gives the same hydrogen as the strong acid.
- The totals are equal, but hydrochloric acid has the higher hydrogen ion concentration, so it reacts faster.
