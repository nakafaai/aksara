# Same electrons, different charges on the ions

In series, **every electron passes through both cells**. Silver: <InlineMath math="2.16 \div 108 = 0.020" /> mol, and <InlineMath math="\text{Ag}^+ + e^- \rightarrow \text{Ag}" /> takes one electron per atom, so <InlineMath math="0.020" /> mol of electrons flowed.

In the copper cell, <InlineMath math="\text{Cu}^{2+} + 2e^- \rightarrow \text{Cu}" /> needs two electrons per atom, so the same electrons deposit <InlineMath math="0.010" /> mol of copper: <InlineMath math="0.010 \times 64 = 0.64" /> g.

# Why the other options are wrong

- The same current means the same electrons, not the same mass: silver and copper atoms differ in mass **and in charge**.
- Equal moles of metal would need equal charges on the ions, but copper ions carry <InlineMath math="2+" />.
- <InlineMath math="0.32\text{ g}" /> halves the moles a second time. The order in the electrochemical series does not set the mass deposited here.
