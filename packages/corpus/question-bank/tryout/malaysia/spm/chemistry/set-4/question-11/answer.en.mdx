# Draw each molecule to octets, then count both kinds of pair

Each bond pair holds two shared electrons. Building every molecule so that each atom except hydrogen has eight outer electrons:

- <InlineMath math="\text{O=C=O}" />: two double bonds, <InlineMath math="8" /> shared electrons, and two lone pairs on each oxygen, <InlineMath math="4" /> in all.
- <InlineMath math="\text{N}\equiv\text{N}" />: <InlineMath math="6" /> shared electrons, one lone pair on each nitrogen.
- <InlineMath math="\text{H-C}\equiv\text{C-H}" />: <InlineMath math="2 + 6 + 2 = 10" /> shared electrons, no lone pairs.
- <InlineMath math="\text{H-O-H}" />: <InlineMath math="4" /> shared electrons, two lone pairs on oxygen.
- <InlineMath math="\text{H-C}\equiv\text{N}" />: <InlineMath math="2 + 6 = 8" /> shared electrons, and **one lone pair** on nitrogen.

Only hydrogen cyanide matches the <InlineMath math="8" /> shared electrons of carbon dioxide, and it has one lone pair instead of four.

# Why the other options are wrong

- Nitrogen shares only <InlineMath math="6" /> electrons in **its triple bond**.
- Ethyne shares <InlineMath math="10" />, because its two C-H bonds add to the triple bond.
- Water has fewer lone pairs, but it shares only <InlineMath math="4" /> electrons.
