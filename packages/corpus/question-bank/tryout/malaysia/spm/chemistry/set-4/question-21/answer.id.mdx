# Atom lain menentukan bilangan mangan

Dalam senyawa, jumlah bilangan oksidasi adalah nol. Kalium selalu <InlineMath math="+1" />, oksigen <InlineMath math="-2" />, dan klor dalam klorida <InlineMath math="-1" />:

- <InlineMath math="\text{KMnO}_4" />: <InlineMath math="+1 + x + 4(-2) = 0" />, jadi <InlineMath math="x = +7" />.
- <InlineMath math="\text{K}_2\text{MnO}_4" />: <InlineMath math="2(+1) + x + 4(-2) = 0" />, jadi <InlineMath math="x = +6" />.
- <InlineMath math="\text{MnO}_2" />: <InlineMath math="x + 2(-2) = 0" />, jadi <InlineMath math="x = +4" />.
- <InlineMath math="\text{MnCl}_2" />: <InlineMath math="x + 2(-1) = 0" />, jadi <InlineMath math="x = +2" />.

Nama IUPAC menaruh bilangan oksidasi mangan dalam **angka Romawi**, jadi <InlineMath math="\text{K}_2\text{MnO}_4" /> adalah kalium manganat(VI).

# Kenapa pilihan lain salah

- <InlineMath math="\text{K}_2\text{MnO}_4" /> punya dua ion kalium, jadi mangan <InlineMath math="+6" />, di bawah <InlineMath math="\text{KMnO}_4" />, **dan namanya manganat(VI)**.
- <InlineMath math="\text{MnO}_2" /> memuat mangan pada <InlineMath math="+4" />, jadi ia mangan(IV) oksida dan berada setelah <InlineMath math="\text{K}_2\text{MnO}_4" />.
- Urutan ini terbalik, dan <InlineMath math="\text{MnCl}_2" /> adalah mangan(II) klorida.
