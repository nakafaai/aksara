# The other atoms set manganese's number

In a compound the oxidation numbers add up to zero. Potassium is always <InlineMath math="+1" />, oxygen <InlineMath math="-2" /> and chlorine in a chloride <InlineMath math="-1" />:

- <InlineMath math="\text{KMnO}_4" />: <InlineMath math="+1 + x + 4(-2) = 0" />, so <InlineMath math="x = +7" />.
- <InlineMath math="\text{K}_2\text{MnO}_4" />: <InlineMath math="2(+1) + x + 4(-2) = 0" />, so <InlineMath math="x = +6" />.
- <InlineMath math="\text{MnO}_2" />: <InlineMath math="x + 2(-2) = 0" />, so <InlineMath math="x = +4" />.
- <InlineMath math="\text{MnCl}_2" />: <InlineMath math="x + 2(-1) = 0" />, so <InlineMath math="x = +2" />.

The IUPAC name puts manganese's oxidation number in **Roman numerals**, so <InlineMath math="\text{K}_2\text{MnO}_4" /> is potassium manganate(VI).

# Why the other options are wrong

- <InlineMath math="\text{K}_2\text{MnO}_4" /> has two potassium ions, so manganese is <InlineMath math="+6" />, below <InlineMath math="\text{KMnO}_4" />, and its **name is manganate(VI)**.
- <InlineMath math="\text{MnO}_2" /> holds manganese at <InlineMath math="+4" />, so it is manganese(IV) oxide and comes after <InlineMath math="\text{K}_2\text{MnO}_4" />.
- This order runs backwards, and <InlineMath math="\text{MnCl}_2" /> is manganese(II) chloride.
