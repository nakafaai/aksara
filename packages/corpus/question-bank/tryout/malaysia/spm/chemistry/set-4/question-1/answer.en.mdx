# The value from the mole ratio, the uncertainty from both volumes

Titre: <InlineMath math="24.80 - 1.25 = 23.55\text{ cm}^3" />. Acid: <InlineMath math="0.100 \times 0.02355 = 2.355 \times 10^{-3}" /> mol. **Each barium hydroxide unit releases two hydroxide ions**, so it takes two acid molecules: the alkali held <InlineMath math="1.178 \times 10^{-3}" /> mol in <InlineMath math="0.02500\text{ dm}^3" />, which is <InlineMath math="0.0471\text{ mol dm}^{-3}" />.

The concentration uses both volumes, so their percentage uncertainties add. Pipette: <InlineMath math="\tfrac{0.06}{25.00} \times 100\% = 0.24\%" />. Titre: two readings, <InlineMath math="\pm 0.10\text{ cm}^3" />, so <InlineMath math="\tfrac{0.10}{23.55} \times 100\% = 0.42\%" />. Total <InlineMath math="0.66\%" />, and <InlineMath math="0.66\% \times 0.0471 = 0.0003\text{ mol dm}^{-3}" />.

# Why the other options are wrong

- <InlineMath math="0.0942" /> takes one acid molecule per barium hydroxide, but each unit holds **two hydroxide ions**.
- <InlineMath math="\pm 0.0002" /> uses only the titre's <InlineMath math="0.42\%" /> and leaves out the pipette.
- <InlineMath math="\pm 0.0001" /> subtracts the two percentages, <InlineMath math="0.42 - 0.24 = 0.18\%" />, but uncertainties always add.
