# Each halogen takes electrons from the halide below it

Chlorine sits above bromine, so <InlineMath math="\text{Cl}_2 + 2\text{Br}^- \rightarrow 2\text{Cl}^- + \text{Br}_2" />: <InlineMath math="0.71 \div 71 = 0.010" /> mol of chlorine frees <InlineMath math="0.010" /> mol of bromine, <InlineMath math="1.60" /> g, which colours the organic layer orange-brown.

Bromine in turn sits above iodine, so it **frees iodine** from potassium iodide: <InlineMath math="\text{Br}_2 + 2\text{I}^- \rightarrow 2\text{Br}^- + \text{I}_2" />. Again <InlineMath math="0.010" /> mol carries over: <InlineMath math="0.010 \times 254 = 2.54" /> g of iodine, which turns the organic layer purple.

# Why the other options are wrong

- <InlineMath math="1.27\text{ g}" /> uses one iodine atom, but iodine forms diatomic molecules of mass <InlineMath math="254" />.
- Bromine is higher in Group 17 than iodine, so it **can** displace it.
- Iodine colours the organic layer purple. The layer does not become colourless.
