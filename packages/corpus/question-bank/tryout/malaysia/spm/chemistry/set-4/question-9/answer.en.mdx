# Check which reactant runs out before carrying the moles on

Chlorine: <InlineMath math="0.71 \div 71 = 0.010" /> mol. Bromide: <InlineMath math="0.20 \times 0.0500 = 0.010" /> mol. <InlineMath math="\text{Cl}_2 + 2\text{Br}^- \rightarrow 2\text{Cl}^- + \text{Br}_2" /> needs **two bromide ions per chlorine molecule**, so the bromide runs out after <InlineMath math="0.0050" /> mol of chlorine. Bromine formed: <InlineMath math="0.0050 \times 160 = 0.80" /> g. The extra chlorine stays in the water layer.

The organic layer carries only the bromine. <InlineMath math="\text{Br}_2 + 2\text{I}^- \rightarrow 2\text{Br}^- + \text{I}_2" /> gives <InlineMath math="0.0050" /> mol of iodine, <InlineMath math="0.0050 \times 254 = 1.27" /> g, which dissolves in the organic layer and turns it purple.

# Why the other options are wrong

- <InlineMath math="1.60\text{ g}" /> lets all the chlorine react, but there is bromide for only **half of it**.
- <InlineMath math="0.635\text{ g}" /> halves the iodine again, as if each bromine molecule freed half an iodine molecule.
- Iodine in an organic solvent is purple, so the layer does not turn colourless.
