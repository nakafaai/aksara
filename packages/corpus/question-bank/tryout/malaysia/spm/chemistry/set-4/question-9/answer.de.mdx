# Erst prüfen, was zuerst verbraucht ist, dann die Stoffmenge weitertragen

Chlor: <InlineMath math="0{,}71 \div 71 = 0{,}010" /> mol. Bromid: <InlineMath math="0{,}20 \times 0{,}0500 = 0{,}010" /> mol. <InlineMath math="\text{Cl}_2 + 2\text{Br}^- \rightarrow 2\text{Cl}^- + \text{Br}_2" /> braucht **zwei Bromidionen je Chlormolekül**, also ist das Bromid nach <InlineMath math="0{,}0050" /> mol Chlor verbraucht. Gebildetes Brom: <InlineMath math="0{,}0050 \times 160 = 0{,}80" /> g. Das überschüssige Chlor bleibt in der wässrigen Phase.

Die organische Phase enthält nur das Brom. <InlineMath math="\text{Br}_2 + 2\text{I}^- \rightarrow 2\text{Br}^- + \text{I}_2" /> liefert <InlineMath math="0{,}0050" /> mol Iod, <InlineMath math="0{,}0050 \times 254 = 1{,}27" /> g, das sich in der organischen Phase löst und sie violett färbt.

# Warum die anderen Antworten falsch sind

- <InlineMath math="1{,}60\text{ g}" /> lässt alles Chlor reagieren, doch das Bromid reicht nur **für die Hälfte**.
- <InlineMath math="0{,}635\text{ g}" /> halbiert das Iod noch einmal, als setzte jedes Brommolekül ein halbes Iodmolekül frei.
- Iod in einem organischen Lösungsmittel ist violett, also wird die Phase nicht farblos.
