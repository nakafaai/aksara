# Nilai daripada nisbah mol, ketidakpastian daripada kedua-dua isi padu

Titratan: <InlineMath math="24.80 - 1.25 = 23.55\text{ cm}^3" />. Asid: <InlineMath math="0.100 \times 0.02355 = 2.355 \times 10^{-3}" /> mol. **Setiap unit barium hidroksida membebaskan dua ion hidroksida**, jadi ia memerlukan dua molekul asid: alkali itu mengandungi <InlineMath math="1.178 \times 10^{-3}" /> mol dalam <InlineMath math="0.02500\text{ dm}^3" />, iaitu <InlineMath math="0.0471\text{ mol dm}^{-3}" />.

Kepekatan menggunakan kedua-dua isi padu, jadi peratus ketidakpastiannya dijumlahkan. Pipet: <InlineMath math="\tfrac{0.06}{25.00} \times 100\% = 0.24\%" />. Titratan: dua bacaan, <InlineMath math="\pm 0.10\text{ cm}^3" />, jadi <InlineMath math="\tfrac{0.10}{23.55} \times 100\% = 0.42\%" />. Jumlahnya <InlineMath math="0.66\%" />, dan <InlineMath math="0.66\% \times 0.0471 = 0.0003\text{ mol dm}^{-3}" />.

# Kenapa pilihan lain salah

- <InlineMath math="0.0942" /> mengambil satu molekul asid bagi setiap barium hidroksida, sedangkan setiap unit mengandungi **dua ion hidroksida**.
- <InlineMath math="\pm 0.0002" /> hanya menggunakan <InlineMath math="0.42\%" /> titratan dan meninggalkan pipet.
- <InlineMath math="\pm 0.0001" /> menolak dua peratusan itu, <InlineMath math="0.42 - 0.24 = 0.18\%" />, sedangkan ketidakpastian sentiasa dijumlahkan.
