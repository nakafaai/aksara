# Kira oksigen yang perlu dibawa roket, kemudian bahagikan

Seimbangkan setiap pembakaran bagi satu mol bahan api dan tambahkan jisim oksigen (<InlineMath math="\text{O}_2 = 32" />) kepada jisim bahan api:

- Metanol: <InlineMath math="\text{CH}_3\text{OH} + \tfrac{3}{2}\text{O}_2" />, jisim <InlineMath math="32 + 48 = 80" />, haba <InlineMath math="726 \div 80 = 9.08\text{ kJ g}^{-1}" />.
- Etanol: <InlineMath math="\text{C}_2\text{H}_5\text{OH} + 3\text{O}_2" />, jisim <InlineMath math="46 + 96 = 142" />, haba <InlineMath math="1376 \div 142 = 9.69\text{ kJ g}^{-1}" />.
- Oktana: <InlineMath math="\text{C}_8\text{H}_{18} + \tfrac{25}{2}\text{O}_2" />, jisim <InlineMath math="114 + 400 = 514" />, haba <InlineMath math="5470 \div 514 = 10.6\text{ kJ g}^{-1}" />.
- Hidrogen: <InlineMath math="\text{H}_2 + \tfrac{1}{2}\text{O}_2" />, jisim <InlineMath math="2 + 16 = 18" />, haba <InlineMath math="286 \div 18 = 15.9\text{ kJ g}^{-1}" />.

Hidrogen masih menang, tetapi jauh kurang daripada yang disangka jika dikira bahan api sahaja: oksigen itu **lapan kali** jisim hidrogen yang dibakarnya.

# Kenapa pilihan lain salah

- <InlineMath math="143\text{ kJ}" /> membahagi dengan hidrogen sahaja dan terlupa <InlineMath math="16" /> g oksigen yang diperlukan oleh setiap <InlineMath math="2" /> g hidrogen.
- Oktana mempunyai haba per mol paling besar, tetapi memerlukan <InlineMath math="400" /> g oksigen per mol, jadi bagi setiap gram bahan api dan oksigen ia di tempat kedua.
- <InlineMath math="8.4\text{ kJ}" /> menambah satu mol penuh oksigen, <InlineMath math="32" /> g, bagi setiap mol hidrogen, bukan **setengah mol**.
