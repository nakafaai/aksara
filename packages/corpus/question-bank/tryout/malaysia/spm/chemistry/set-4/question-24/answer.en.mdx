# One electrode dissolves, the other grows

Zinc is more electropositive, so it is the negative terminal: <InlineMath math="\text{Zn} \rightarrow \text{Zn}^{2+} + 2e^-" />. <InlineMath math="0.010" /> mol of zinc leaves as ions, so the zinc electrode **loses** <InlineMath math="0.010 \times 65 = 0.65" /> g.

The electrons cross the wire to copper, where <InlineMath math="\text{Cu}^{2+} + 2e^- \rightarrow \text{Cu}" />. The same <InlineMath math="0.020" /> mol of electrons deposits <InlineMath math="0.010" /> mol of copper, so the copper electrode gains <InlineMath math="0.64" /> g. Copper(II) ions leave the solution, so its blue colour fades.

# Why the other options are wrong

- Copper ions take electrons at the copper electrode, so it gains mass rather than losing it.
- Zinc atoms become ions and **leave** the zinc electrode, so it loses mass.
- Electrons leave the more electropositive metal, so they flow from zinc to copper.
