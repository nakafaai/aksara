# Two reactions, each needing two acid molecules per gas molecule

Ethanoic acid, <InlineMath math="M_r = 60" />: <InlineMath math="6.0 \div 60 = 0.10" /> mol, each molecule giving one hydrogen ion.

- <InlineMath math="2\text{CH}_3\text{COOH} + \text{Mg} \rightarrow (\text{CH}_3\text{COO})_2\text{Mg} + \text{H}_2" />: <InlineMath math="0.050" /> mol of hydrogen.
- <InlineMath math="2\text{CH}_3\text{COOH} + \text{Na}_2\text{CO}_3 \rightarrow 2\text{CH}_3\text{COONa} + \text{H}_2\text{O} + \text{CO}_2" />: <InlineMath math="0.050" /> mol of carbon dioxide.

Both reactions need **two acid molecules per gas molecule**, so each gives <InlineMath math="0.050 \times 24 = 1.2\text{ dm}^3" />.

# Why the other options are wrong

- Each hydrogen molecule needs two hydrogen ions, so two acid molecules make one hydrogen molecule.
- Carbonate also takes two hydrogen ions per carbon dioxide molecule, so it gives <InlineMath math="1.2\text{ dm}^3" /> too.
- A weak acid reacts **more slowly**, but its molecules all react in the end, so the volume is not halved.
