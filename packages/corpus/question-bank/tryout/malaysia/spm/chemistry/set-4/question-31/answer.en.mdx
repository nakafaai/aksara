# Find the limiting reactant in each flask

Ethanoic acid, <InlineMath math="M_r = 60" />: <InlineMath math="6.0 \div 60 = 0.10" /> mol in each sample.

**Magnesium**: <InlineMath math="2\text{CH}_3\text{COOH} + \text{Mg} \rightarrow (\text{CH}_3\text{COO})_2\text{Mg} + \text{H}_2" />. Magnesium: <InlineMath math="1.80 \div 24 = 0.075" /> mol, but the acid can use only <InlineMath math="0.050" /> mol, so **the acid runs out first**. Hydrogen: <InlineMath math="0.050" /> mol, <InlineMath math="1.20\text{ dm}^3" />. Magnesium left: <InlineMath math="0.025 \times 24 = 0.60" /> g.

**Sodium carbonate**: <InlineMath math="2\text{CH}_3\text{COOH} + \text{Na}_2\text{CO}_3 \rightarrow 2\text{CH}_3\text{COONa} + \text{H}_2\text{O} + \text{CO}_2" />. Sodium carbonate, <InlineMath math="M_r = 106" />: <InlineMath math="3.18 \div 106 = 0.030" /> mol, which needs only <InlineMath math="0.060" /> mol of acid, so **the carbonate runs out first**. Carbon dioxide: <InlineMath math="0.030" /> mol, <InlineMath math="0.72\text{ dm}^3" />.

# Why the other options are wrong

- <InlineMath math="1.80\text{ dm}^3" /> lets all the magnesium react, but there is not enough **acid for it**.
- <InlineMath math="2.40\text{ dm}^3" /> gives one hydrogen molecule per acid molecule, yet each acid molecule gives only one hydrogen atom.
- <InlineMath math="1.20\text{ dm}^3" /> of carbon dioxide treats the acid as limiting in both flasks, but in the second the carbonate is used up first.
