# Dua ion hidroksida di tiap satuan rumus

<InlineMath math="M_r = 24 + 2(16 + 1) = 58" />, jadi tabletnya memuat <InlineMath math="0{,}50 \div 58 = 0{,}00862" /> mol. Tiap satuan rumus membawa **dua ion hidroksida**, jadi menetralkan dua mol asam: <InlineMath math="0{,}0172" /> mol asam klorida.

Pada <InlineMath math="0{,}10\text{ mol dm}^{-3}" />, asam itu memenuhi <InlineMath math="0{,}0172 \div 0{,}10 = 0{,}172\text{ dm}^3" />, atau <InlineMath math="172\text{ cm}^3" />. Magnesium hidroksida dipilih karena basa lemah yang nyaris tidak larut, jadi menetralkan kelebihan asam tanpa membuat lambung menjadi basa.
