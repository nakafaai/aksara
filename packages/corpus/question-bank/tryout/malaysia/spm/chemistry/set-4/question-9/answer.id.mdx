# Periksa pereaksi mana yang habis sebelum membawa molnya

Klorin: <InlineMath math="0{,}71 \div 71 = 0{,}010" /> mol. Bromida: <InlineMath math="0{,}20 \times 0{,}0500 = 0{,}010" /> mol. <InlineMath math="\text{Cl}_2 + 2\text{Br}^- \rightarrow 2\text{Cl}^- + \text{Br}_2" /> butuh **dua ion bromida per molekul klorin**, jadi bromida habis setelah <InlineMath math="0{,}0050" /> mol klorin. Bromin terbentuk: <InlineMath math="0{,}0050 \times 160 = 0{,}80" /> g. Kelebihan klorin tetap di lapisan air.

Lapisan organik hanya membawa bromin. <InlineMath math="\text{Br}_2 + 2\text{I}^- \rightarrow 2\text{Br}^- + \text{I}_2" /> memberi <InlineMath math="0{,}0050" /> mol iodin, <InlineMath math="0{,}0050 \times 254 = 1{,}27" /> g, yang larut di lapisan organik dan membuatnya ungu.

# Kenapa pilihan lain salah

- <InlineMath math="1{,}60\text{ g}" /> membiarkan seluruh klorin bereaksi, padahal bromidanya hanya **cukup untuk separuh**.
- <InlineMath math="0{,}635\text{ g}" /> membagi dua iodin sekali lagi, seolah tiap molekul bromin membebaskan setengah molekul iodin.
- Iodin dalam pelarut organik berwarna ungu, jadi lapisannya tidak menjadi tak berwarna.
