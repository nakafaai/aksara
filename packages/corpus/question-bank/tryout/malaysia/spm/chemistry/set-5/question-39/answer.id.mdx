# Hitung dosis menurut massa tubuh dulu, lalu ubah miligram menjadi mililiter

Dosisnya bergantung pada massa anak: <InlineMath math="15\text{ mg}" /> untuk tiap <InlineMath math="18\text{ kg}" />. **Kekuatan sirop mengubah miligram menjadi mililiter**: <InlineMath math="120\text{ mg}" /> dalam tiap <InlineMath math="5{,}0\text{ mL}" />. Batas harian adalah empat dosis, bukan satu.

# Kenapa pilihan lain salah

- <InlineMath math="11{,}3\text{ mL}" /> sehari hanya mengizinkan satu dosis, padahal empat diizinkan.
- <InlineMath math="2{,}25\text{ mL}" /> membagi miligram dengan miligram dan lupa bahwa tiap <InlineMath math="120\text{ mg}" /> ada dalam <InlineMath math="5{,}0\text{ mL}" />.
- <InlineMath math="67{,}5\text{ mL}" /> memberi enam dosis sehari. **Resepnya mengizinkan paling banyak empat**.
