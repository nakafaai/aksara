# Tiap atom magnesium berakhir di salah satu dari dua produk, jadi susun dua persamaan

Kalau semua atom menjadi oksida, produknya <InlineMath math="1{,}20\text{ g}" />, dan kalau semuanya menjadi nitrida, <InlineMath math="1{,}00\text{ g}" />. **Massa terukur ada di antaranya, dan posisinya menunjukkan pembagiannya**. Misalkan <InlineMath math="x" /> mol magnesium membentuk oksida dan <InlineMath math="y" /> mol membentuk nitrida.

# Kenapa pilihan lain salah

- <InlineMath math="3{,}3\%" /> menganggap kekurangan <InlineMath math="0{,}04\text{ g}" /> sebagai nitrida, padahal massa nitrida bukan kekurangan itu.
- <InlineMath math="0{,}60\text{ g}" /> lupa bahwa satu satuan rumus nitrida berisi tiga atom magnesium.
- <InlineMath math="6{,}7\%" /> membandingkan satuan rumus nitrida, <InlineMath math="0{,}0020\text{ mol}" />, dengan atom magnesium. **Hitung atom magnesium di kedua sisi**.
