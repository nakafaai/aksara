# Kira dos mengikut jisim badan dahulu, kemudian tukar miligram kepada mililiter

Dos bergantung pada jisim kanak-kanak: <InlineMath math="15\text{ mg}" /> bagi setiap <InlineMath math="18\text{ kg}" />. **Kekuatan sirap menukar miligram kepada mililiter**: <InlineMath math="120\text{ mg}" /> dalam setiap <InlineMath math="5.0\text{ mL}" />. Had harian ialah empat dos, bukan satu.
