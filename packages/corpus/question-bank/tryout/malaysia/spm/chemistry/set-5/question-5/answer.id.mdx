# Cari perbandingan atom dulu, lalu ingat klor berpasangan

# Kenapa pilihan lain salah

- <InlineMath math="\text{SnCl}_2" /> hanya butuh <InlineMath math="1{,}42\text{ g}" /> klor, dan klorida ionik adalah padatan bertitik leleh tinggi.
- <InlineMath math="1{,}92\text{ dm}^3" /> menghitung atom klor sebagai partikel gas. **Gas klor adalah <InlineMath math="\text{Cl}_2" />, dua atom per molekul**.
- Cairan molekul kovalen tidak punya ion untuk membawa muatan, jadi tidak menghantarkan listrik.
