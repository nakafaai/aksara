# Count the particles of one ion, then weigh it with its own isotopes

A charge of <InlineMath math="2-" /> means **two more electrons than protons**. The isotopes change only the neutrons, but they set the ion's mass, so the moles must come from <InlineMath math="106" />, not from the usual <InlineMath math="96" />.

<BlockMath math="\begin{aligned}
p&=16+4(8)=48,\quad e=48+2=50\\
M&=34+4(18)=106\text{ g mol}^{-1}\\
n&=\frac{2.12}{106}=0.0200\text{ mol}\\
N_e&=0.0200\times50\times6.02\times10^{23}=6.02\times10^{23}
\end{aligned}" />

So <InlineMath math="2.12\text{ g}" /> holds exactly one mole of electrons.

# Why the other options are wrong

- <InlineMath math="46" /> takes electrons away for a negative charge, the wrong way round.
- <InlineMath math="6.65\times10^{23}" /> uses the mass of ordinary sulfate, <InlineMath math="96" />. **These heavy isotopes make the ion weigh <InlineMath math="106" />**.
- <InlineMath math="48" /> is the number of protons, which ignores the charge.
