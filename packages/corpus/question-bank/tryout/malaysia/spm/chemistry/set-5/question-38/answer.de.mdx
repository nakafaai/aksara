# Was der getrocknete Feststoff zulegt

**Jede umgewandelte Gruppe tauscht ein Wasserstoffatom gegen ein Natriumatom**, sie wird also um <InlineMath math="23-1=22" /> schwerer, und das entstandene Wasser verdampft beim Trocknen. Wer das ganze Natriumhydroxid addiert, <InlineMath math="40" /> pro Gruppe, kommt auf <InlineMath math="20{,}4\text{ g}" /> und behält das Wasser, das längst weg ist. Alle <InlineMath math="0{,}200\text{ mol}" /> umzuwandeln ergibt <InlineMath math="18{,}8\text{ g}" />.

n&=\tfrac{14{,}4}{72}=0{,}200\text{ mol},\quad n(\text{NaOH})=0{,}750\times0{,}200=0{,}150\text{ mol}\ \Rightarrow\ V=\tfrac{0{,}150}{2{,}00}=0{,}0750\text{ dm}^3\\
m&=14{,}4+0{,}150\times(23-1)=17{,}7\text{ g},\quad 200\times17{,}7=3540\text{ g}=3{,}54\text{ kg}

# Das Zweihundertfache der Trockenmasse

Die Saugkraft gehört zum fertigen Produkt, dessen ionische Gruppen Wasser ins Netzwerk ziehen, also **multipliziert der Faktor <InlineMath math="200" /> die <InlineMath math="17{,}7\text{ g}" />**. Auf die <InlineMath math="14{,}4\text{ g}" /> Ausgangspolymer angewandt ergibt er <InlineMath math="2{,}88\text{ kg}" />, für ein Polymer, das die Lauge noch gar nicht gesehen hat.
