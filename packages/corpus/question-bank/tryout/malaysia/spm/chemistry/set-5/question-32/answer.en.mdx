# Only the primary alcohol becomes an acid, so the titration counts propan-1-ol alone

Steam adds across the double bond in two ways. **Propan-2-ol oxidises only to propanone, which no alkali neutralises**, so the acid in the titration comes from propan-1-ol alone. Scaling the tenth up by ten and subtracting from the total gives the propan-2-ol. It is four times the propan-1-ol, because the hydrogen joins the end carbon that already holds more hydrogen.

# Why the other options are wrong

- <InlineMath math="0.96\text{ g}" /> is the propan-1-ol that the titration measures, not the propan-2-ol.
- <InlineMath math="5.04\text{ g}" /> starts from all <InlineMath math="0.100\text{ mol}" /> of propene. **Only <InlineMath math="80\%" /> reacts**.
- An acid forms on oxidation, so some propan-1-ol is present. Propene is unsymmetrical, so both alcohols form.
