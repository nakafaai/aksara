# Kantong airnya habis duluan

Kalengnya berisi <InlineMath math="1{,}00\text{ mol}" /> kalsium oksida tetapi hanya <InlineMath math="0{,}750\text{ mol}" /> air, dan keduanya bereaksi satu banding satu. **Air adalah pereaksi pembatas**, jadi seperempat oksidanya tertinggal sebagai serbuk kering. Menghitung dari <InlineMath math="1{,}00\text{ mol}" /> oksida memberi <InlineMath math="65{,}0\text{ kJ}" /> dan, setelah kehilangan kalor, opsi <InlineMath math="45{,}5^\circ\text{C}" />.

# Tujuh persepuluh sampai ke sup

Reaksinya melepas <InlineMath math="0{,}750\times65=48{,}75\text{ kJ}" />, tetapi **hanya <InlineMath math="70\%" /> yang masuk ke sup**: <InlineMath math="34{,}1\text{ kJ}" />. Kalau potongan itu dilewati, sup tampak naik <InlineMath math="48{,}8^\circ\text{C}" />.
