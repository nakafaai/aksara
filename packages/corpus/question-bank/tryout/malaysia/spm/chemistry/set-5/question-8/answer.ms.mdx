# Setiap atom magnesium berakhir dalam salah satu daripada dua hasil, jadi bina dua persamaan

Jika semua atom menjadi oksida, hasil menimbang <InlineMath math="1.20\text{ g}" />, dan jika semuanya menjadi nitrida, <InlineMath math="1.00\text{ g}" />. **Jisim diukur berada di antaranya, dan kedudukannya memberi pembahagian**. Andaikan <InlineMath math="x" /> mol magnesium membentuk oksida dan <InlineMath math="y" /> mol membentuk nitrida.

# Kenapa pilihan lain salah

- <InlineMath math="3.3\%" /> menganggap kekurangan <InlineMath math="0.04\text{ g}" /> sebagai nitrida, walhal jisim nitrida bukan kekurangan itu.
- <InlineMath math="0.60\text{ g}" /> terlupa bahawa satu unit formula nitrida mengandungi tiga atom magnesium.
- <InlineMath math="6.7\%" /> membandingkan unit formula nitrida, <InlineMath math="0.0020\text{ mol}" />, dengan atom magnesium. **Kira atom magnesium di kedua-dua belah**.
