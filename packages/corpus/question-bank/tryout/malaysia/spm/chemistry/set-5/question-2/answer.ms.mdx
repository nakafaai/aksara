# Bahagian mendatar lengkung ialah tempat peleburan berlaku

Suhu kekal pada <InlineMath math="80^\circ\text{C}" /> dari minit <InlineMath math="3.2" /> hingga <InlineMath math="4.8" />. **Sepanjang <InlineMath math="96\text{ s}" /> itu, setiap joule digunakan untuk memisahkan molekul**, bukan untuk mempercepatnya, jadi suhu, ukuran tenaga kinetik purata, berhenti naik.

<BlockMath math="\begin{aligned}
t&=(4.8-3.2)\times60=96\text{ s}\\
E&=40\times96=3840\text{ J}=3.84\text{ kJ}\\
n&=\frac{25.6}{128}=0.200\text{ mol}\\
\frac{3.84}{0.200}&=19.2\text{ kJ mol}^{-1}
\end{aligned}" />

Jadi satu mol memerlukan <InlineMath math="19.2\text{ kJ}" /> untuk melebur.

# Kenapa pilihan lain salah

- Tenaga kinetik yang meningkat akan menaikkan suhu, sedangkan bahagian mendatar menunjukkan perkara itu tidak berlaku.
- <InlineMath math="3.84\text{ kJ}" /> meleburkan sampel, <InlineMath math="0.200\text{ mol}" />. **Bahagikan dengan bilangan mol untuk nilai per mol**.
- <InlineMath math="38.4\text{ kJ mol}^{-1}" /> membaca permulaan bahagian mendatar, minit <InlineMath math="3.2" />, sebagai tempohnya.
