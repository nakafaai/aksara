# Das Verhältnis der Gleichung nutzen, drei Alkoholmoleküle auf zwei Dichromationen

Die ausgeglichene Gleichung legt das Verhältnis fest: **zwei Dichromationen auf je drei Alkoholmoleküle**. Das orange Dichromat(VI)-Ion wird zu grünem Chrom(III) reduziert, also wechselt das Gemisch von Orange zu Grün.

# Warum die anderen Antworten falsch sind

- <InlineMath math="100\text{ cm}^3" /> lässt ein Dichromation mit jedem Alkoholmolekül reagieren.
- Dichromat(VI) ist orange und wird zu grünem Chrom(III) reduziert. **Die Farbe geht von Orange zu Grün, nicht umgekehrt**.
- <InlineMath math="150\text{ cm}^3" /> stellt das Verhältnis auf den Kopf, drei Dichromationen auf zwei Alkoholmoleküle.
