# Bagian datar kurva adalah saat peleburan terjadi

Suhu tertahan di <InlineMath math="80^\circ\text{C}" /> dari menit <InlineMath math="3{,}2" /> sampai <InlineMath math="4{,}8" />. **Selama <InlineMath math="96\text{ s}" /> itu, setiap joule dipakai untuk memisahkan molekul**, bukan mempercepatnya, jadi suhu, ukuran energi kinetik rata-rata, berhenti naik.

<BlockMath math="\begin{aligned}
t&=(4{,}8-3{,}2)\times60=96\text{ s}\\

Jadi satu mol butuh <InlineMath math="19{,}2\text{ kJ}" /> untuk meleleh.

# Kenapa pilihan lain salah

- Energi kinetik yang naik akan menaikkan suhu, padahal bagian datar menunjukkan hal itu tidak terjadi.
- <InlineMath math="3{,}84\text{ kJ}" /> melelehkan sampel, <InlineMath math="0{,}200\text{ mol}" />. **Bagi dengan jumlah mol untuk nilai per mol**.
- <InlineMath math="38{,}4\text{ kJ mol}^{-1}" /> membaca awal bagian datar, menit <InlineMath math="3{,}2" />, sebagai lamanya.
