# Count chains with the chain's mass, but count carbon with the repeating unit

Each chain is a molecule of mass <InlineMath math="28\,000" />, so the chains are few. **The carbon does not care how the units are joined**: polyethene is <InlineMath math="(\text{CH}_2)_n" />, and every <InlineMath math="14\text{ g}" /> of it holds one mole of carbon atoms, each of which becomes one carbon dioxide molecule.

# Why the other options are wrong

- <InlineMath math="6.0\text{ dm}^3" /> counts one carbon for each ethene unit, <InlineMath math="\text{C}_2\text{H}_4" />, which has two.
- <InlineMath math="1.51\times10^{23}" /> counts the <InlineMath math="\text{CH}_2" /> units as chains. **A chain is one molecule made of a thousand ethene units**.
- <InlineMath math="24.0\text{ dm}^3" /> counts each carbon atom twice.
