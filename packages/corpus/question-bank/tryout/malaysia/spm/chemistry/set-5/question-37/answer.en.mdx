# From one slice back to the whole cake

If one slice is a tenth of a cake, the whole cake is ten slices. The flask works the same way. The portion used <InlineMath math="0.0300\times0.500=0.0150\text{ mol}" /> of bromine. One bromine molecule goes to each styrene, so those <InlineMath math="25.0\text{ cm}^3" /> held <InlineMath math="0.0150\text{ mol}" /> of styrene. **But that portion is only one tenth of the <InlineMath math="250\text{ cm}^3" />**, so the whole solution holds <InlineMath math="0.150\text{ mol}" />. At <InlineMath math="M_r=104" /> that is <InlineMath math="15.6\text{ g}" />.

Forget the factor of ten and you stop at <InlineMath math="1.56\text{ g}" /> and a recovery of only <InlineMath math="7.50\%" />.

# How much of the foam came back

Making the polymer is like snapping beads onto a necklace. Each bead keeps all its own atoms, only the clasp changes. **So a repeating unit has the same atoms as styrene, <InlineMath math="\text{C}_8\text{H}_8" />**. The block holds <InlineMath math="0.200\text{ mol}" /> of units, and <InlineMath math="0.150\text{ mol}" /> of them came back.

<BlockMath math="\begin{aligned}
n(\text{C}_8\text{H}_8)&=\tfrac{20.8}{104}=0.200\text{ mol}\\
\tfrac{0.150}{0.200}\times100\%&=75.0\%
\end{aligned}" />

# Only the slice met the bromine

You tested one slice, so only that slice turned into product. **The product in the flask comes from <InlineMath math="0.0150\text{ mol}" /> of styrene**. Each <InlineMath math="\text{C}_8\text{H}_8\text{Br}_2" /> has <InlineMath math="M_r=104+160=264" />, so the flask holds <InlineMath math="3.96\text{ g}" />. The product for the whole <InlineMath math="250\text{ cm}^3" /> would be <InlineMath math="39.6\text{ g}" />, but that never formed. And adding one bromine atom instead of two gives <InlineMath math="M_r=184" /> and <InlineMath math="2.76\text{ g}" />.
