# Lacak asal setiap jaringan

Gamet betina berasal dari tumbuhan <InlineMath math="4n=48" />, jadi sel telur dan tiap inti kutub membawa <InlineMath math="24" /> kromosom. Gamet jantan dari tumbuhan <InlineMath math="2n=24" /> membawa <InlineMath math="12" />. **Kulit biji berkembang dari integumen bakal biji**, jadi jaringan itu milik induk betina dan tidak ikut dibuahi.

<BlockMath math="\begin{aligned}
\text{endosperma}&=24+24+12=60\\
\text{embrio}&=24+12=36\\
\text{kulit biji}&=48
\end{aligned}" />

Jadi, jawabannya <InlineMath math="60" />, <InlineMath math="36" />, dan <InlineMath math="48" />.

# Mengapa pilihan lain salah

- <InlineMath math="36" /> untuk endosperma menghitung tiga set dari gamet jantan, padahal **dua inti kutub datang dari induk tetraploid**.
- <InlineMath math="36" /> untuk kulit biji menyamakannya dengan embrio, padahal kulit biji adalah jaringan induk betina.
- <InlineMath math="72" /> untuk endosperma mengira gamet jantan juga membawa <InlineMath math="24" />, padahal induk jantan diploid.
