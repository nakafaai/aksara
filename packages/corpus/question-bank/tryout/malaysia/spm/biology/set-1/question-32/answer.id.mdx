# Kalikan efisiensi tiap tingkat, lalu skalakan luasnya

Energi berpindah lewat tiga tingkat, jadi **ketiga efisiensi dikalikan berurutan**. Lalu ubah energi per meter persegi menjadi energi per hektar.

<BlockMath math="\begin{aligned}
E_{\text{tersier}}&=20{.}000\times0{,}10\times0{,}15\times0{,}20=60\text{ kJ m}^{-2}\\
\text{per hektar}&=60\times10{.}000=600{.}000\text{ kJ}\\
\text{jumlah}&=\frac{600{.}000}{1200}=500
\end{aligned}" />

Jadi, satu hektar dapat menopang paling banyak <InlineMath math="500" /> konsumen tersier.
