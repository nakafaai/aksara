# Darab kecekapan setiap aras, kemudian skalakan luasnya

Tenaga melalui tiga aras, jadi **ketiga-tiga kecekapan didarab berturut-turut**. Kemudian tukar tenaga bagi setiap meter persegi kepada tenaga bagi setiap hektar.

<BlockMath math="\begin{aligned}
E_{\text{tertier}}&=20{,}000\times0.10\times0.15\times0.20=60\text{ kJ m}^{-2}\\
\text{bagi setiap hektar}&=60\times10{,}000=600{,}000\text{ kJ}\\
\text{bilangan}&=\frac{600{,}000}{1200}=500
\end{aligned}" />

Jadi, satu hektar boleh menampung paling banyak <InlineMath math="500" /> ekor pengguna tertier.
