# Masa pertumbuhan selepas fasa lag

Sel tidak membahagi semasa fasa lag, jadi **hanya masa selepas fasa lag** menghasilkan pembahagian. Daripada <InlineMath math="120" /> minit, <InlineMath math="40" /> minit pertama ialah fasa lag, jadi tinggal <InlineMath math="80" /> minit untuk membiak.

<BlockMath math="\begin{aligned}
\text{bilangan gandaan}&=\frac{120-40}{20}=4\\
N&=100\times2^4=1600
\end{aligned}" />

Jadi, selepas <InlineMath math="2" /> jam terdapat <InlineMath math="1600" /> sel bakteria.
