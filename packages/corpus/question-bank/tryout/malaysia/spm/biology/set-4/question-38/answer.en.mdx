# Read each gene on its own from the offspring of the test cross

The <InlineMath math="rryy" /> parent passes on only recessive alleles, so **every offspring shows the allele it got from the other parent**. Each gene can therefore be read separately.

- Shape: all <InlineMath math="100" /> seeds are round and none is wrinkled. If the parent carried <InlineMath math="r" />, about half the seeds would be wrinkled, so the parent is <InlineMath math="RR" />.
- Colour: <InlineMath math="52" /> yellow to <InlineMath math="48" /> green is about <InlineMath math="1:1" />. Half the gametes carry <InlineMath math="Y" /> and half carry <InlineMath math="y" />, so the parent is <InlineMath math="Yy" />.

The parent is <InlineMath math="RRYy" />. Every gamete carries <InlineMath math="R" />, and half carry <InlineMath math="y" />:

<BlockMath math="P(R\text{ and }y)=1\times\tfrac{1}{2}=\tfrac{1}{2}" />

So the parent is <InlineMath math="RRYy" />, and <InlineMath math="\tfrac{1}{2}" /> of its gametes carry both <InlineMath math="R" /> and <InlineMath math="y" />.

# Why the other options are wrong

- <InlineMath math="RrYy" /> would give a quarter of each kind of seed, **including wrinkled ones**, which never appear.
- <InlineMath math="RRYY" /> would give only yellow seeds, **but nearly half the seeds are green**.
- <InlineMath math="RrYY" /> swaps the two genes, **predicting wrinkled seeds and no green ones**, the opposite of the results.
