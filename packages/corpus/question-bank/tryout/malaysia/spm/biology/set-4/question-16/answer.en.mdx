# A second column works only on the lactose the first one missed

In a column the enzyme converts a **fixed share** of the lactose passing through it. A second column in a row converts that same share again, but only of the lactose that is still left.

Two columns at <InlineMath math="20\text{ cm}^3" /> per minute reach <InlineMath math="91\%" />, while doubling up at <InlineMath math="40" /> falls short. One column alone would need <InlineMath math="10\text{ cm}^3" /> per minute and <InlineMath math="240" /> minutes.

So the shortest time is <InlineMath math="120" /> minutes, because the second column converts <InlineMath math="70\%" /> of the lactose left by the first.

# Why the other options are wrong

- <InlineMath math="240" /> minutes forgets the **second column**, which lets the milk run twice as fast.
- <InlineMath math="60" /> minutes adds the two percentages, **but the second column only sees the** <InlineMath math="55\%" /> left by the first.
- <InlineMath math="140\%" /> has the right time but impossible reasoning, **since no column can convert lactose that is already gone**.
