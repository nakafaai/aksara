# Doubling is a power of two

After <InlineMath math="n" /> cycles the <InlineMath math="10" /> starting copies have doubled <InlineMath math="n" /> times, so there are <InlineMath math="10\times2^{n}" /> copies. The count must be **more than** a million:

<BlockMath math="10\times2^{n}>1\,000\,000\quad\Rightarrow\quad2^{n}>100\,000." />

Since <InlineMath math="2^{16}=65\,536" /> is too small and <InlineMath math="2^{17}=131\,072" /> is enough, the smallest number of cycles is <InlineMath math="17" />. The chart shows the count crossing the target between cycles <InlineMath math="16" /> and <InlineMath math="17" />.

So the smallest number of cycles is <InlineMath math="17" />.

# Why the other options are wrong

- <InlineMath math="16" /> cycles give <InlineMath math="655\,360" /> copies, which is **still below** a million.
- <InlineMath math="20" /> uses <InlineMath math="2^{20}\approx1\,000\,000" /> and forgets that the reaction already starts with <InlineMath math="10" /> copies.
- <InlineMath math="100\,000" /> treats each cycle as adding <InlineMath math="10" /> copies, but each cycle doubles the number.
