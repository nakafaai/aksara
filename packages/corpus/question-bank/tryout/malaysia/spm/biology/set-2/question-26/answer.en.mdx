# One tube per ovule, then count the triploid nuclei

Each pollen tube enters **one** ovule, so <InlineMath math="30" /> ovules need at least <InlineMath math="30" /> pollen grains. In each ovule, one male gamete fuses with the egg and the other with the two polar nuclei.

The gametes and polar nuclei are haploid, <InlineMath math="n=12" />, so each endosperm nucleus is triploid:

<BlockMath math="3n=12+12+12=36,\qquad 30\times36=1080\text{ chromosomes}." />

So at least <InlineMath math="30" /> pollen grains are needed, and the <InlineMath math="30" /> endosperm nuclei hold <InlineMath math="1080" /> chromosomes altogether.

# Why the other options are wrong

- <InlineMath math="15" /> pollen grains sends one tube's two gametes into **two different ovules**, which also halves the endosperm count.
- <InlineMath math="720" /> treats the endosperm as diploid, <InlineMath math="30\times24" />, and forgets the second polar nucleus.
- <InlineMath math="60" /> pollen grains counts one grain per gamete, but each grain brings two.
