# Keep everything fixed except temperature, then read the rate

Temperature must be the only variable that changes. The responding variable is a **rate per minute**, so a different counting time does not spoil a set-up: <InlineMath math="40" /> bubbles in <InlineMath math="5" /> minutes and <InlineMath math="80" /> in <InlineMath math="10" /> minutes are the same rate of <InlineMath math="8" /> per minute.

- Q and U change only the temperature, so they stay.
- T counts for <InlineMath math="5" /> minutes, but its count is divided by <InlineMath math="5" /> to give bubbles per minute, so it stays too.
- R doubles the yeast and S doubles the glucose, so each changes a second variable and must leave.

So the largest valid group is P, Q, T and U, which covers four temperatures.

# Why the other options are wrong

- P, Q and U leaves out T, as if its shorter count spoiled it, but **a rate per minute already allows for the time**.
- P, Q, S, T and U accepts S, which also doubles the glucose.
- P, Q, R, T and U accepts R, which also doubles the yeast.
