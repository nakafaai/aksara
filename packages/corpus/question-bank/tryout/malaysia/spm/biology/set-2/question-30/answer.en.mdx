# Each event causes the next

This is eutrophication. Build the chain by asking what each event needs before it can happen.

<Mermaid
  title={<>From Fertiliser to Dead Fish</>}
  description={<>Fertiliser washes in, algae bloom, algae die, bacteria multiply, the BOD rises, and the fish die.</>}
  chart={"flowchart LR\n  Q[Q: fertiliser washes in] --> S[S: algae bloom]\n  S --> P[P: algae die]\n  P --> R[R: bacteria multiply on dead algae]\n  R --> U[U: BOD rises]\n  U --> T[T: fish die]"}
/>

- The nutrients must arrive first (Q), because they feed the algae, which then bloom (S).
- The bloom blocks light below the surface, so the algae die in huge numbers (P).
- Bacteria can only multiply (R) once there is **dead algae to decompose**, so R comes after P.
- Many respiring bacteria use up dissolved oxygen, which is what a high BOD means (U).
- With too little oxygen left, the fish die (T).

So the order is Q, S, P, R, U, T.

# Why the other options are wrong

- Q, S, R, P puts the bacteria before the algae die, but **they decompose dead algae**, so they cannot multiply first.
- Q, R, S, P lets the bacteria multiply straight after the fertiliser arrives, before there is any bloom to die.
- Q, S, P, U, R raises the BOD before the bacteria multiply, but it is their respiration that raises it.
