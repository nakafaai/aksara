# Ask what each test rules in and what it rules out

The filter tells the **size**. Ten tenfold dilutions would leave almost nothing of the first sap, so a disease that stays strong means the agent **multiplies**. Agar tells whether it can grow **outside cells**, and survival is not the same as growth. Together the tests describe a virus.

- I: the agent passes pores that stop all bacteria, so it must be smaller than <InlineMath math="0.2\text{ µm}" />. Statement I is correct.
- II: ten tenfold dilutions dilute the first sap <InlineMath math="10^{10}" /> times, yet the disease stays as strong, so the agent must multiply in each plant. It forms no colonies on agar, so it multiplies only inside living cells. Statement II is correct.
- III: heat destroys many things that are not alive, such as enzymes, and also kills living cells. Losing its effect when heated shows only that heat damages the agent, not that it was never alive. Statement III is wrong.
- IV: surviving in dried sap is not the same as growing. The agar test shows that the agent cannot multiply outside cells, it only stays intact until it reaches a host. Statement IV is wrong.

So statements I and II are correct.

# Why the other options are wrong

- I, II and III only accepts III, **drawing a conclusion that heat sensitivity cannot support**.
- II and IV only rejects I and **mistakes lasting for a year with growing**.
- I, III and IV only rejects II, **although <InlineMath math="10^{10}" /> dilution would wipe out an agent that did not multiply**.
