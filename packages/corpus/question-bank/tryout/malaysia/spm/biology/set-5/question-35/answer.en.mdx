# Interpolate by a factor, not by a difference

Between the <InlineMath math="2000" /> and <InlineMath math="1000" /> base pair markers the gel covers <InlineMath math="9\text{ mm}" /> and the size **halves**. Fragment X is <InlineMath math="4.5\text{ mm}" /> past the <InlineMath math="2000" /> marker, half of that step, so its size has been divided by **the square root of <InlineMath math="2" />**, not reduced by half of <InlineMath math="1000" />.

<BlockMath math="\frac{35.5-31}{40-31}=\frac{4.5}{9}=\frac{1}{2}\text{ of a halving},\qquad 2000\div2^{1/2}=\frac{2000}{1.41}\approx1400\text{ base pairs}" />

Smaller fragments slip through the pores of the gel more easily and move further, so a fragment between two markers has a size between theirs. Fragment X is about <InlineMath math="1400" /> base pairs.

# Why the other options are wrong

- About <InlineMath math="1500" /> base pairs takes the **midpoint of 2000 and <InlineMath math="1000" />**, treating size as falling evenly with distance.
- About <InlineMath math="2800" /> base pairs multiplies <InlineMath math="2000" /> by <InlineMath math="1.41" />, as if fragments that move **further were larger**.
- About <InlineMath math="700" /> base pairs halves <InlineMath math="1400" /> once more, as if X had moved a **full extra step** of <InlineMath math="9\text{ mm}" />.
