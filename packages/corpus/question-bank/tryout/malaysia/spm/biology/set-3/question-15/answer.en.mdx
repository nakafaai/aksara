# Match each fraction to its test results and its size

Larger, heavier organelles settle at **lower speeds**. So the fractions come out from largest to smallest: nuclei, then chloroplasts, then mitochondria, then ribosomes.

The decisive result for fraction <InlineMath math="3" /> is that it uses oxygen with pyruvate but not with glucose. That is exactly how a mitochondrion behaves.

- Fraction <InlineMath math="2" /> releases oxygen in light, so it holds the chloroplasts.
- Fraction <InlineMath math="3" /> uses oxygen only when it is given **pyruvate**. Mitochondria cannot take in glucose, because glucose is first split into pyruvate in the cytoplasm, which was removed.
- Fraction <InlineMath math="4" /> makes polypeptides but uses no oxygen at all, so it holds the ribosomes.
- Fractions <InlineMath math="2" /> and <InlineMath math="3" /> also make polypeptides because chloroplasts and mitochondria hold small ribosomes of their own.

So fraction <InlineMath math="3" /> holds mitochondria, which can use pyruvate but not glucose.

# Why the other options are wrong

- Chloroplasts belong to fraction <InlineMath math="2" />, which is the only one that **releases oxygen in light**.
- Ribosomes belong to fraction <InlineMath math="4" />, which makes polypeptides but **takes up no oxygen** with either substrate.
- No mitochondria would follow only if mitochondria used glucose, **but they take in pyruvate made in the cytoplasm**.
