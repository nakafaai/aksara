# Compare the body with the set point, not with <InlineMath math="37^\circ\text{C}" />

The hypothalamus acts on the **difference between body temperature and its set point**. While the body is below the set point, it makes and keeps heat. While it is above, it loses heat. Normal temperature does not enter into it.

- I: from hour <InlineMath math="1" /> the set point is <InlineMath math="39" /> but the body is only <InlineMath math="37.5" /> to <InlineMath math="38.3\,^\circ\text{C}" />. Below the set point, the hypothalamus triggers shivering and narrows the skin arterioles, so the patient feels cold. Statement I is correct.
- II: at hour <InlineMath math="6" /> the body is at <InlineMath math="39" /> but the set point is back at <InlineMath math="37" />. Now the body is too warm, so sweating and widened skin arterioles lose heat until it reaches <InlineMath math="37" />. Statement II is correct.
- III: on the plateau the temperature stays at <InlineMath math="39\,^\circ\text{C}" />, so heat produced must equal heat lost. If production were higher, the temperature would keep rising. Statement III is wrong.
- IV: shivering is the hypothalamus **working**, pushing the body up to the new set point it has chosen. Statement IV is wrong.

So statements I and II are correct.

# Why the other options are wrong

- I, II and III only accepts III, **although a steady temperature means heat in equals heat out**.
- II and IV only rejects I and **reads shivering as a failure of control**.
- I, III and IV only rejects II, **the heat loss that follows when the set point drops**.
