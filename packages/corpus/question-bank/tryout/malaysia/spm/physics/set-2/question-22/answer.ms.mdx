# Simpan tenaga dalam kedua-dua tali

Setiap tali menyimpan luas di bawah garisnya sendiri, dan **dua tali bersebelahan masing-masing memanjang <InlineMath math="8.0\text{ cm}" /> penuh**, jadi tenaganya berganda.

<BlockMath math="E=2\times\tfrac12(16)(0.080)=1.28\text{ J},\qquad 0.80\times1.28=1.024\text{ J}" />

# Kira pendakian di dalam tali

Peluru dilepaskan <InlineMath math="8.0\text{ cm}" /> di bawah titik ia meninggalkan tali. **Tenaga <InlineMath math="1.024\text{ J}" /> menaikkannya dari titik lepasan**, jadi sebahagiannya digunakan sebelum peluru bebas.

<BlockMath math="h_{\text{lepasan}}=\frac{1.024}{0.025\times10}=4.10\text{ m},\qquad h=4.10-0.08=4.02\text{ m}" />
