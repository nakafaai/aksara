# Ikuti daya melewati transformator dan kabel baru

**Transformator hanya meneruskan <InlineMath math="90\%" />**, jadi kabel menerima <InlineMath math="180\text{ kW}" /> pada <InlineMath math="2{,}0\text{ kV}" />.

<BlockMath math="\begin{aligned}
I&=\frac{180\,000}{2000}=90\text{ A}\\

\end{aligned}" />
