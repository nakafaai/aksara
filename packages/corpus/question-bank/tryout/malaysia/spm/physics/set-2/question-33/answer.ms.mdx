# Ikuti kuasa melalui transformer dan kabel baru

**Transformer hanya menyalurkan <InlineMath math="90\%" />**, jadi kabel menerima <InlineMath math="180\text{ kW}" /> pada <InlineMath math="2.0\text{ kV}" />.

<BlockMath math="\begin{aligned}
I&=\frac{180\,000}{2000}=90\text{ A}\\

P_{\text{hujung}}&=180-3.24=177\text{ kW}
\end{aligned}" />
