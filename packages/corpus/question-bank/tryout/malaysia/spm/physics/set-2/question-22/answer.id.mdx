# Simpan energi di kedua tali

Tiap tali menyimpan luas di bawah garisnya sendiri, dan **dua tali berdampingan masing-masing teregang penuh <InlineMath math="8{,}0\text{ cm}" />**, jadi energinya dua kali lipat.

<BlockMath math="E=2\times\tfrac12(16)(0{,}080)=1{,}28\text{ J},\qquad 0{,}80\times1{,}28=1{,}024\text{ J}" />

# Hitung kenaikan di dalam tali

Peluru dilepas <InlineMath math="8{,}0\text{ cm}" /> di bawah titik peluru meninggalkan tali. **Energi <InlineMath math="1{,}024\text{ J}" /> mengangkatnya dari titik lepas**, jadi sebagian terpakai sebelum peluru bebas.

<BlockMath math="h_{\text{lepas}}=\frac{1{,}024}{0{,}025\times10}=4{,}10\text{ m},\qquad h=4{,}10-0{,}08=4{,}02\text{ m}" />
