# Use Lenz's law and the speed of the magnet

Entering, the flux through the coil rises, and leaving, it falls, so by Lenz's law the two e.m.f.s have opposite signs, and I is true. **The magnet speeds up while it falls**, so it leaves faster than it enters: the flux changes faster, giving a larger peak, and II is true. The same speed makes the second pulse shorter, so III is false.

IV is false because an e.m.f. is induced whenever the flux through the coil changes. A broken circuit stops the current, not the e.m.f.

So only I and II are correct.

# Why the other options are wrong

- I, II and III only accepts III. **A faster magnet passes the coil's end in less time**, so the second pulse is shorter, not longer.
- I, II and IV only accepts IV, which mixes up e.m.f. with current.
- II and III only rejects I, but rising and falling flux give opposite e.m.f.s.
