# Find which wire reaches <InlineMath math="30\text{ N}" /> first

Balance the horizontal and vertical components for a picture of weight <InlineMath math="W" />.

<BlockMath math="\begin{aligned}
T_P\cos30^\circ&=T_Q\cos60^\circ\ \Rightarrow\ T_Q=\sqrt3\,T_P\\
T_P\sin30^\circ+T_Q\sin60^\circ&=W\ \Rightarrow\ T_P=\frac{W}{2},\ T_Q=0.87W
\end{aligned}" />

**The steeper wire carries more**, so Q snaps first: <InlineMath math="0.87W=30\text{ N}" /> gives <InlineMath math="W=34.6\text{ N}" />.

# Hang the same picture symmetrically

**Each wire now supports half the weight through its vertical component**. The tension falls as the wires get steeper, so the smallest safe angle is the one where the tension is exactly <InlineMath math="30\text{ N}" />.

<BlockMath math="2(30)\sin\theta=34.6\ \Rightarrow\ \sin\theta=0.577\ \Rightarrow\ \theta=35.3^\circ" />

# Why the other options are wrong

- <InlineMath math="54.7^\circ" /> **solves <InlineMath math="\cos\theta=0.577" />, using the horizontal component as if it held the weight**.
- <InlineMath math="30.0^\circ" /> solves <InlineMath math="\tan\theta=0.577" />, and at <InlineMath math="30^\circ" /> each wire would need <InlineMath math="34.6\text{ N}" /> and snap.
- <InlineMath math="60.0\text{ N}" /> lets wire P reach <InlineMath math="30\text{ N}" /> first, but Q has already snapped at <InlineMath math="34.6\text{ N}" />.
