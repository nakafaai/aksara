# Split the speeds as if the pair were at rest

**In a frame moving with the pair, the total momentum is zero, so the <InlineMath math="1.0\text{ kg}" /> trolley moves <InlineMath math="3" /> times as fast as the <InlineMath math="3.0\text{ kg}" /> one, and the <InlineMath math="6.0\text{ J}" /> is shared between them**.
