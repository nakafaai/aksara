# Find the resistance of the old cables

**At <InlineMath math="1.0\text{ kV}" /> the current is <InlineMath math="200\text{ kW}/1.0\text{ kV}=200\text{ A}" />, and the loss is <InlineMath math="0.16\times200=32\text{ kW}" />**.

<BlockMath math="R=\frac{32\,000}{200^2}=0.80\,\Omega\ \Rightarrow\ R_{\text{new}}=0.40\,\Omega" />

# Follow the power through the transformer and the new cables

**The transformer passes on only <InlineMath math="90\%" />**, so the cables receive <InlineMath math="180\text{ kW}" /> at <InlineMath math="2.0\text{ kV}" />.

<BlockMath math="\begin{aligned}
I&=\frac{180\,000}{2000}=90\text{ A}\\

\end{aligned}" />
