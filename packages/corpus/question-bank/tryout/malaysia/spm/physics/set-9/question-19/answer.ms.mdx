# Ukur kedua-dua kedalaman ke bawah dari permukaan atas

Dalam nyata ialah ketebalan blok, <InlineMath math="5.50 - 2.50 = 3.00" /> cm. Dalam ketara diukur dari permukaan atas ke **imej** tanda, <InlineMath math="5.50 - 3.70 = 1.80" /> cm. Jadi <InlineMath math="n = 3.00 \div 1.80 = 1.67" />.

Sudut genting memenuhi <InlineMath math="\sin c = 1 \div n = 0.60" />, jadi <InlineMath math="c = 37^\circ" />.

# Mengapa pilihan lain salah

- <InlineMath math="2.5" /> membahagi dengan **kenaikan** imej tanda, <InlineMath math="1.20" /> cm, dan bukan dengan dalam ketaranya.
- <InlineMath math="53^\circ" /> ialah **pelengkap** sudut genting.
- <InlineMath math="31^\circ" /> menggunakan <InlineMath math="\tan c = 1 \div n" />, tetapi sudut genting diperoleh daripada **sinus**.
