# Ukur kedua kedalaman ke bawah dari permukaan atas

Kedalaman nyata adalah tebal balok, <InlineMath math="5{,}50 - 2{,}50 = 3{,}00" /> cm. Kedalaman semu diukur dari permukaan atas ke **bayangan** tanda, <InlineMath math="5{,}50 - 3{,}70 = 1{,}80" /> cm. Jadi <InlineMath math="n = 3{,}00 \div 1{,}80 = 1{,}67" />.

Sudut kritis memenuhi <InlineMath math="\sin c = 1 \div n = 0{,}60" />, jadi <InlineMath math="c = 37^\circ" />.

# Kenapa pilihan lain salah

- <InlineMath math="2{,}5" /> membagi dengan **naiknya** bayangan tanda, <InlineMath math="1{,}20" /> cm, bukan dengan kedalaman semunya.
- <InlineMath math="53^\circ" /> adalah **pelengkap** sudut kritis.
- <InlineMath math="31^\circ" /> memakai <InlineMath math="\tan c = 1 \div n" />, padahal sudut kritis berasal dari **sinus**.
