# Balance the components for the wind, then notice what is left when the string goes

The string pulls <InlineMath math="9.19" /> N sideways and <InlineMath math="7.71" /> N down, and the weight adds <InlineMath math="2.0" /> N down. In balance the wind must supply <InlineMath math="9.19" /> N sideways and <InlineMath math="9.71" /> N up: <InlineMath math="\sqrt{9.19^2 + 9.71^2} = 13" /> N at <InlineMath math="\tan^{-1}(9.71 \div 9.19) = 47^\circ" /> above the horizontal.

When the string snaps, the wind and the weight still add to exactly **the tension reversed**, <InlineMath math="12" /> N, so the kite accelerates at <InlineMath math="12 \div 0.20 = 60\text{ m s}^{-2}" /> away from the holder.

# Why the other options are wrong

- <InlineMath math="67\text{ m s}^{-2}" /> divides the wind’s force alone by the mass, forgetting the **weight** still acts.
- <InlineMath math="14\text{ N}" /> at <InlineMath math="40^\circ" /> adds the weight straight onto the tension, but forces add as **vectors**.
- <InlineMath math="9.2\text{ N}" /> keeps only the horizontal parts and ignores the **vertical balance**.
