# Bahagikan penerbangan kepada pendakian berkuasa, luncuran ke puncak dan kejatuhan

Roket tidak berhenti apabila bahan api habis: ia **terus naik pada <InlineMath math="60\text{ m s}^{-1}" />** dan hanya menjadi perlahan oleh graviti. Jadi penerbangan mempunyai tiga peringkat. Cari ketinggian dan laju semasa bahan api habis, kemudian sejauh mana ia meluncur lebih tinggi, kemudian berapa lama ia jatuh dari keseluruhan ketinggian bermula dari pegun.

<BlockMath math="\text{nyala}: v=20(3.0)=60,\ s=\tfrac12(20)(3.0)^2=90,\qquad \text{luncur}: t=\frac{60}{10}=6.0,\ s=\frac{60^2}{2(10)}=180" />

<BlockMath math="H=90+180=270\text{ m},\qquad 270=5t^2\Rightarrow t=7.35\text{ s},\qquad T=3.0+6.0+7.35\approx16\text{ s}" />

Roket berada <InlineMath math="90\text{ m}" /> di atas apabila enjin berhenti dan meluncur <InlineMath math="180\text{ m}" /> lagi, mencapai <InlineMath math="270\text{ m}" /> selepas <InlineMath math="9.0\text{ s}" />. Jatuh <InlineMath math="270\text{ m}" /> dari pegun mengambil masa <InlineMath math="7.35\text{ s}" />, jadi ia mendarat kira-kira <InlineMath math="16\text{ s}" /> selepas pelancaran.

# Kenapa pilihan lain salah

- <InlineMath math="180\text{ m}" /> hanyalah **luncuran selepas bahan api habis**, tanpa <InlineMath math="90\text{ m}" /> yang didaki semasa enjin menyala.
- <InlineMath math="15\text{ s}" /> menganggap kejatuhan mengambil masa yang sama dengan **pendakian selepas bahan api habis**, <InlineMath math="6.0\text{ s}" />, tetapi roket jatuh dari <InlineMath math="270\text{ m}" />, bukan dari <InlineMath math="180\text{ m}" />, dan mula jatuh dari pegun.
- <InlineMath math="9.0\text{ s}" /> ialah masa ke **puncak**, bukan ke tanah.
