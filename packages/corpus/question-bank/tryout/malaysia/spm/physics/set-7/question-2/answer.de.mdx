# Die Steigung im Log-Diagramm ist der Exponent

Logarithmieren von <InlineMath math="t=kd^{\,n}" /> ergibt <InlineMath math="\lg t=\lg k+n\lg d" />, eine Gerade, deren **Steigung der Exponent <InlineMath math="n" /> ist**. Die Endpunkte liefern <InlineMath math="(1{,}000-2{,}505)\div(0{,}903-0{,}301)=-2{,}50" />. Teilst du andersherum, <InlineMath math="\Delta\lg d\div\Delta\lg t" />, kommt <InlineMath math="-0{,}40" /> heraus, und damit landet die Zeit für das <InlineMath math="5{,}0\text{ mm}" />-Loch bei etwa <InlineMath math="220\text{ s}" />.

# Auf das weitere Loch hochrechnen

Der erste Punkt ist das <InlineMath math="2{,}0\text{ mm}" />-Loch, <InlineMath math="10^{2{,}505}=320\text{ s}" />. # Zwei kleine Löcher gegen ein großes

Bei zwei <InlineMath math="4{,}0\text{ mm}" />-Löchern **addieren sich die Durchflüsse, nicht die Zeiten**. # Wie schnell der Sand hindurchrieselt

Durch dieses Loch laufen <InlineMath math="0{,}40\text{ kg}" /> in <InlineMath math="28{,}3\text{ s}" />, **doppelt so viel pro Sekunde wie durch ein kleines Loch**.

<BlockMath math="\begin{aligned}
n&=\frac{1{,}000-2{,}505}{0{,}903-0{,}301}=-2{,}50,\qquad t_{5{,}0}=320\times2{,}5^{-2{,}5}=32\text{ s}\\
t_{2\times4{,}0}&=\tfrac12\times56{,}6=28{,}3\text{ s},\quad d=4{,}0\times2^{1/2{,}5}=5{,}3\text{ mm},\quad \frac{0{,}40\text{ kg}}{28{,}3\text{ s}}=14\text{ g s}^{-1}
\end{aligned}" />
