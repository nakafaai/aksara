# Only the vertical part of the tie's pull holds the sign up

The light rod pushes horizontally, so the sign's weight is held by the **vertical component** of the tie's tension alone. The tie, the rod and the wall form a right-angled triangle, so the tie's angle above the horizontal has <InlineMath math="\sin\theta=\dfrac{0.90}{1.5}" />. The tension is proportional to the load, so the breaking tension sets the **largest load in the same ratio**.

The tie pulls with about <InlineMath math="67\text{ N}" />, more than the sign's weight, because it is inclined. It can hold a sign of at most <InlineMath math="60\text{ N}" /> before reaching <InlineMath math="100\text{ N}" />.

# Why the other options are wrong

- <InlineMath math="50\text{ N}" /> with <InlineMath math="80\text{ N}" /> uses the **cosine**, <InlineMath math="\dfrac{1.2}{1.5}" />, for the vertical component.
- <InlineMath math="40\text{ N}" /> with <InlineMath math="100\text{ N}" /> assumes the tie **carries exactly the sign's weight**, as if it hung vertically.
- <InlineMath math="100\text{ N}" /> for the heaviest sign forgets that the **tension exceeds the weight**, so the tie breaks before the sign reaches <InlineMath math="100\text{ N}" />.
