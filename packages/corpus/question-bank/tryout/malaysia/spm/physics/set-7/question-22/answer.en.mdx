# Friction is not one fixed push: it can act up or down the ramp, so the box rests over a range

Along the ramp, the weight pulls the box down with <InlineMath math="mg\sin30°" /> and the spring pulls it up. Friction makes up whatever difference there is, **in whichever direction is needed**, up to <InlineMath math="6.0\text{ N}" />. With a slack spring the box tends to slide down, so friction acts up the ramp. With a well-stretched spring the box tends to be dragged up, so friction acts down. That gives **two limits**, not one.

<BlockMath math="x_{\min}=\frac{4.0}{200}=2.0\text{ cm},\qquad x_{\max}=\frac{16}{200}=8.0\text{ cm},\qquad E=\tfrac12(200)(0.080)^2=0.64\text{ J}" />

The box stays at rest anywhere the spring is stretched between <InlineMath math="2.0\text{ cm}" /> and <InlineMath math="8.0\text{ cm}" />. At the upper limit the spring stores <InlineMath math="0.64\text{ J}" />.

# Why the other options are wrong

- <InlineMath math="5.0\text{ cm}" /> for both limits **ignores friction**, so the box could rest at only one position.
- <InlineMath math="2.0\text{ cm}" /> and <InlineMath math="5.0\text{ cm}" /> let friction **only help the spring**, never resist it, but friction opposes whichever way the box tends to slide.
- <InlineMath math="7.0\text{ cm}" /> and <InlineMath math="13\text{ cm}" /> use the **whole weight** along the ramp instead of its component <InlineMath math="mg\sin30°" />.
