# Ask what force each spring carries, then add extensions or energies

In **series** each spring carries the **whole load**, so each stretches by <InlineMath math="\dfrac Fk" /> and the extensions add. In **parallel** each spring carries **half the load**, so each stretches only a quarter as far as the series pair. The stored energy is <InlineMath math="\tfrac12Fx" /> for each spring, added over both springs.

In series each spring stretches <InlineMath math="0.10\text{ m}" />, so the pair stretches <InlineMath math="0.20\text{ m}" />. In parallel each spring carries <InlineMath math="10\text{ N}" /> and stretches <InlineMath math="0.050\text{ m}" />, storing <InlineMath math="0.25\text{ J}" />, so the two together store <InlineMath math="0.50\text{ J}" />.

<BlockMath math="k_{\text{series}}=\frac{200}{2}=100\text{ N m}^{-1},\qquad k_{\text{parallel}}=2\times200=400\text{ N m}^{-1},\qquad x=0.30\times\frac{100}{400}=0.075\text{ m}" />

A load that stretches the series pair <InlineMath math="0.30\text{ m}" /> is <InlineMath math="30\text{ N}" />. The parallel pair is four times as stiff, so it stretches only <InlineMath math="0.075\text{ m}" />.

# Why the other options are wrong

- <InlineMath math="0.050\text{ m}" /> with <InlineMath math="2.0\text{ J}" /> **swaps the two arrangements**, and the swap carries into the third value.
- <InlineMath math="0.10\text{ m}" /> treats the series pair as **one spring**, forgetting that both springs stretch.
- <InlineMath math="0.25\text{ J}" /> counts **only one spring** of the parallel pair, so the pair looks half as stiff as it is.
