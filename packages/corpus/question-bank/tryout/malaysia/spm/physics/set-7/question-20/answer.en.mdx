# A slanted path through the window

The beam crosses <InlineMath math="3.0\text{ mm}" /> of thickness at <InlineMath math="25.6^\circ" />, so its path is <InlineMath math="3.0/\cos25.6^\circ=3.33\text{ mm}" />, and **statement II holds**. Inside, light travels at <InlineMath math="3.0\times10^{8}/1.77=1.69\times10^{8}\text{ m s}^{-1}" />, so the crossing takes about <InlineMath math="2.0\times10^{-11}\text{ s}" />, and statement III holds too. Dividing the bare thickness by that speed gives <InlineMath math="1.8\times10^{-11}\text{ s}" />, which misses the slant.

<BlockMath math="\begin{aligned}
\sin r&=\frac{\sin50^\circ}{1.77}=0.433\ \Rightarrow\ r=25.6^\circ,\quad s=\frac{3.0\text{ mm}}{\cos25.6^\circ}=3.33\text{ mm}\\
v&=\frac{3.0\times10^{8}}{1.77}=1.69\times10^{8}\text{ m s}^{-1},\quad t=\frac{3.33\times10^{-3}}{1.69\times10^{8}}=2.0\times10^{-11}\text{ s}\\
\lambda'&=\frac{633\text{ nm}}{1.77}=358\text{ nm},\quad f=\frac{3.0\times10^{8}}{633\times10^{-9}}=4.7\times10^{14}\text{ Hz}
\end{aligned}" />

# Wavelength changes but the colour does not

Statement IV gets its number right, <InlineMath math="633/1.77=358\text{ nm}" />, and then draws the wrong conclusion. **Colour is set by frequency, which the sapphire cannot change**: it stays <InlineMath math="4.7\times10^{14}\text{ Hz}" />, so the light inside is still red, and it is red again when it leaves. That leaves I, II and III as the correct set.
