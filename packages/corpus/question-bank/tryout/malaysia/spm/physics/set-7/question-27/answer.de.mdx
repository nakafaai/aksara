# Der Auftrieb bleibt gleich dem Gewicht, also muss sich das verdrängte Volumen ändern

Ein schwimmendes Schiff verdrängt immer sein **eigenes Gewicht** an Wasser. Süßwasser ist weniger dicht, also muss das Schiff **mehr Volumen** verdrängen und sinkt tiefer ein. Das Zusatzvolumen verteilt auf die Wasserlinienfläche ergibt die Tiefenänderung. Um im Fluss so tief wie auf See zu liegen, darf das Schiff nur so viel wiegen wie das **Flusswasser im Volumen der Seetiefe**.

Im Fluss sinkt das Schiff etwa <InlineMath math="0{,}15\text{ m}" /> tiefer ein. Werden etwa <InlineMath math="5{,}8\cdot10^{5}\text{ kg}" /> Ladung gelöscht, liegt es wieder so tief wie auf See.

<BlockMath math="d_{\text{Fluss}}=5{,}90+0{,}146\approx6{,}046\text{ m},\qquad \Delta V=(6{,}046-6{,}00)\cdot4000\approx182\text{ m}^3,\qquad \Delta m=1000\cdot182\approx1{,}8\cdot10^{5}\text{ kg}" />

Im Fluss läge der Kiel etwa <InlineMath math="4{,}6\text{ cm}" /> unter dem Grund. Ihn so weit zu heben, heißt <InlineMath math="182\text{ m}^3" /> weniger Flusswasser zu verdrängen, also müssen etwa <InlineMath math="1{,}8\cdot10^{5}\text{ kg}" /> Ladung von Bord.

# Warum die anderen Antworten falsch sind

- **Flacher** hat die Richtung vertauscht: Weniger dichtes Wasser trägt pro Kubikmeter weniger, das Schiff liegt tiefer und muss entladen werden.
- <InlineMath math="6{,}0\cdot10^{5}\text{ kg}" /> nimmt **<InlineMath math="3\%" /> der Schiffsmasse**, weil die Dichten um <InlineMath math="3\%" /> der Flussdichte abweichen, doch der Anteil ist <InlineMath math="\dfrac{30}{1030}" />, etwas weniger.
- <InlineMath math="1{,}9\cdot10^{5}\text{ kg}" /> rechnet das fehlende Volumen mit **Meerwasser**, doch das Schiff schwimmt jetzt in Flusswasser.
