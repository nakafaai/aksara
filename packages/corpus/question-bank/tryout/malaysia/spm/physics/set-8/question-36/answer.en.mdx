# Why the other options are wrong

- <InlineMath math="0" /> and <InlineMath math="4" /> treat the NOR gate as if it **behaved like OR**, so nothing seems to change.
- <InlineMath math="1" /> and <InlineMath math="0" /> assume the fault simply **inverts the whole output**, but only one input of the AND gate is inverted.
