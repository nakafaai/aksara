# Satu beban jatuh mempercepat dua massa

Truk derek yang menarik sebuah mobil harus mempercepat dirinya sendiri sekaligus mobil itu. Berat beban <InlineMath math="mg" /> ada di posisi yang sama: sebagian menarik tali dengan tegangan <InlineMath math="T" />, dan sisanya mempercepat beban itu sendiri. Untuk beban <InlineMath math="mg-T=ma" />, dan untuk troli <InlineMath math="T=Ma" />.

<BlockMath math="\begin{aligned}
m&=\frac{Ma}{g-a}=\frac{0{,}94\times0{,}60}{10-0{,}60}=0{,}060\text{ kg}
\end{aligned}" />

**Massa beban itu <InlineMath math="60\text{ g}" />**. Menulis <InlineMath math="mg=Ma" /> menyerahkan seluruh berat kepada troli, seakan beban tidak perlu didorong sendiri, dan memberi <InlineMath math="56\text{ g}" />.
