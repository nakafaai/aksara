# Only the horizontal momentum survives the landing, and all of the putty's falling energy is lost

The putty arrives moving **straight down**, so it brings no horizontal momentum. The track's push stops its vertical motion, so **only horizontal momentum** is conserved: the trolley's momentum is now shared by more mass. The landing is a sticking collision, so kinetic energy is lost: all of the putty's falling energy, plus part of the trolley's. Afterwards the track is smooth, so the remaining kinetic energy all goes into the spring.

# Why the other options are wrong

- <InlineMath math="3.2\text{ m s}^{-1}" /> adds the putty's **vertical momentum** to the horizontal motion, but the track absorbs the vertical motion.
- <InlineMath math="1.8\text{ J}" /> counts only the trolley's lost kinetic energy, **forgetting the <InlineMath math="4.0\text{ J}" />** the putty brought from its fall.
- <InlineMath math="3.0\text{ m s}^{-1}" /> assumes the trolley **keeps its speed** because the putty pushes it no further, but the same momentum is now shared by more mass.
