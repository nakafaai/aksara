# A rising flux induces a current that opposes it, but only in a complete loop

Closing the switch makes the magnetic flux through the ring **rise** suddenly. By Faraday's law this induces an e.m.f. in the ring, and by **Lenz's law** the induced current flows so as to **oppose** the rise: the ring becomes a magnet facing the coil like pole to like pole, and it is repelled. A cut ring still has an e.m.f., but there is **no closed path**, so no current flows and there is no force. Cooling lowers the ring's resistance, so the same e.m.f. drives a **larger** current and a larger force.

The uncut ring jumps up when the switch is closed. The ring with a cut stays where it is, because no current can flow round it. The cooled ring carries a larger induced current, so it jumps higher.

# Why the other options are wrong

- **Pulled down** gets Lenz's law backwards: the induced current opposes the rising flux, so the ring is repelled, not attracted.
- **Jumps just as high** forgets that the cut breaks the loop, so the e.m.f. cannot drive a current.
- **Jumps less high** thinks cooling weakens the effect, but lower resistance lets the same e.m.f. drive a bigger current.
