# Ikut get mengikut urutan, kemudian baca output sebagai nombor perduaan

<InlineMath math="N_1" /> mempunyai kedua-dua input <InlineMath math="1" />, jadi ia memberi <InlineMath math="0" />. <InlineMath math="N_2" /> dan <InlineMath math="N_3" /> masing-masing menerima <InlineMath math="0" />, jadi kedua-duanya memberi <InlineMath math="1" />.

<InlineMath math="N_4" /> kemudian menerima dua <InlineMath math="1" /> dan memberi <InlineMath math="S = 0" />, manakala get TAK menukar <InlineMath math="0" /> daripada <InlineMath math="N_1" /> kepada <InlineMath math="C = 1" />. Dibaca sebagai <InlineMath math="CS = 10" />, litar itu menunjukkan dua: ia ialah **penambah separuh**, dan <InlineMath math="1 + 1 = 2" />.

**Penambah separuh kedua**: ia menambah <InlineMath math="S = 0" /> dan input ketiga <InlineMath math="1" />, memberi hasil tambah <InlineMath math="1" /> dan bawa <InlineMath math="0" />. Get ATAU menggabungkan bawa <InlineMath math="1" /> dan <InlineMath math="0" /> menjadi <InlineMath math="1" />. Output dibaca <InlineMath math="11" /> dalam perduaan, iaitu tiga: <InlineMath math="1 + 1 + 1 = 3" />.

# Mengapa pilihan lain salah

- Dua ialah penambah separuh pertama sahaja, sebelum **input ketiga** ditambah.
- Satu menggugurkan bawa penambah separuh pertama, tetapi get ATAU menghantarnya kepada bawa akhir.
- Sebelas membaca digit perduaan <InlineMath math="11" /> sebagai nombor perpuluhan, tetapi dalam perduaan ia bermaksud tiga.
