# Samakan dasar sampel dengan nilai makhluk hidup, lalu hitung paruhannya

Kurangi latar dulu: <InlineMath math="16 - 1{,}0 = 15" /> cacahan per menit. Nilai makhluk hidup adalah **per gram**, jadi bagi dengan massa: <InlineMath math="15 \div 4{,}0 = 3{,}75" /> cacahan per menit per gram.

Sampel menyisakan <InlineMath math="3{,}75 \div 15 = \tfrac{1}{4}" /> aktivitas makhluk hidup, yaitu dua kali paruh. Api unggun itu berumur <InlineMath math="2 \times 5730 = 11\,460" /> tahun.

**Api unggun kedua**: <InlineMath math="4{,}75 - 1{,}0 = 3{,}75" /> cacahan per menit untuk <InlineMath math="4{,}0" /> g adalah <InlineMath math="0{,}94" /> per gram, seperenam belas nilai makhluk hidup: empat waktu paruh, <InlineMath math="22\,920" /> tahun. Api itu dinyalakan <InlineMath math="22\,920 - 11\,460 = 11\,460" /> tahun sebelum api unggun pertama.

# Kenapa pilihan lain salah

- Sekitar <InlineMath math="10\,900" /> tahun lupa mengurangi **latar**, yang makin penting saat cacahan makin kecil.
- Sekitar <InlineMath math="22\,900" /> tahun menghitung empat waktu paruh untuk seperempat, padahal seperempat adalah dua kali paruh.
- Sekitar <InlineMath math="22\,920" /> tahun lebih awal adalah seluruh umur api unggun kedua, bukan selisihnya dengan yang pertama.
