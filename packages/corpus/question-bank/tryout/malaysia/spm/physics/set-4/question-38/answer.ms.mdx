# Letakkan sampel pada asas yang sama dengan nilai hidup, kemudian kira penyeparuhan

Tolak latar belakang dahulu: <InlineMath math="16 - 1.0 = 15" /> bilangan seminit. Nilai hidup adalah **setiap gram**, jadi bahagi dengan jisim: <InlineMath math="15 \div 4.0 = 3.75" /> bilangan seminit setiap gram.

Sampel itu mengekalkan <InlineMath math="3.75 \div 15 = \tfrac{1}{4}" /> daripada keaktifan hidup, iaitu dua penyeparuhan. Unggun api itu berusia <InlineMath math="2 \times 5730 = 11\,460" /> tahun.

**Unggun api kedua**: <InlineMath math="4.75 - 1.0 = 3.75" /> bilangan seminit bagi <InlineMath math="4.0" /> g ialah <InlineMath math="0.94" /> setiap gram, satu perenam belas nilai hidup: empat separuh hayat, <InlineMath math="22\,920" /> tahun. Ia dinyalakan <InlineMath math="22\,920 - 11\,460 = 11\,460" /> tahun sebelum unggun api pertama.

# Mengapa pilihan lain salah

- Kira-kira <InlineMath math="10\,900" /> tahun terlupa menolak **latar belakang**, yang semakin penting apabila bilangan semakin kecil.
- Kira-kira <InlineMath math="22\,900" /> tahun mengira empat separuh hayat bagi satu perempat, tetapi satu perempat ialah dua penyeparuhan.
- Kira-kira <InlineMath math="22\,920" /> tahun lebih awal ialah seluruh usia unggun api kedua, bukan berapa lebih tua ia daripada yang pertama.
