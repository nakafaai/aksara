# Read g from the gradient, the bob's radius from the intercept, then size the string

The true length is <InlineMath math="l + r" />, so <InlineMath math="T^2 = \tfrac{4\pi^2}{g}(l + r)" />. The gradient gives <InlineMath math="g = 4\pi^2 \div 4.05 = 9.75\text{ m s}^{-2}" />, and the line reaches <InlineMath math="T^2 = 0" /> at <InlineMath math="l = -r" />, so the **bob's radius** is <InlineMath math="1.5" /> cm.

For <InlineMath math="T = 2.00" /> s the true length is <InlineMath math="L = 9.75 \times 4.00 \div 4\pi^2 = 0.988" /> m. The string to the top of the bob is <InlineMath math="0.988 - 0.015 = 0.97" /> m.

**In the rising lift**: the pendulum feels <InlineMath math="9.75 + 1.0 = 10.75\text{ m s}^{-2}" />, and its true length is still <InlineMath math="0.988" /> m to the centre of the bob, so <InlineMath math="T = 2\pi\sqrt{0.988 \div 10.75} = 1.91" /> s.

**A quick check by ratio**: the period goes as <InlineMath math="1 \div \sqrt{g}" />, so <InlineMath math="2.00 \times \sqrt{9.75 \div 10.75} = 1.9" /> s, the same answer **without recomputing the length**.

# Why the other options are wrong

- <InlineMath math="2.1\text{ s}" /> subtracts the lift’s acceleration, but a lift **speeding up upwards** makes the pendulum feel heavier.
- <InlineMath math="1.8\text{ s}" /> scales the period by the ratio of the g values **without the square root**.
- Still <InlineMath math="2.0\text{ s}" /> treats the period as fixed by the length, but it also depends on the **effective g**.
