# Cari kekerasan daripada hadapan, kemudian jumlahkan semua yang dibawa spring belakang

Spring hadapan membawa <InlineMath math="0.60 \times 3140 = 1880" /> N, jadi **setiap spring hadapan** menerima <InlineMath math="942" /> N untuk <InlineMath math="0.050" /> m: <InlineMath math="k = 1.9 \times 10^4" /> N/m.

Setiap spring belakang menerima <InlineMath math="628" /> N daripada penumpang, turun <InlineMath math="3.3" /> cm, dan kemudian <InlineMath math="491" /> N daripada bagasi, turun <InlineMath math="2.6" /> cm lagi. Semuanya bahagian belakang turun <InlineMath math="5.9" /> cm, **lebih daripada bahagian hadapan**.

# Mengapa pilihan lain salah

- <InlineMath math="1.6 \times 10^4\text{ N m}^{-1}" /> mengongsi penumpang **sama rata pada empat spring**, tetapi bahagian hadapan membawa lebih.
- <InlineMath math="4.6\text{ cm}" /> menyebarkan bagasi ke atas keempat-empat spring, tetapi hanya **spring belakang** berada di bawah but.
- <InlineMath math="2.6\text{ cm}" /> hanya mengira bagasi dan terlupa bahagian belakang **sudah turun** di bawah penumpang.
