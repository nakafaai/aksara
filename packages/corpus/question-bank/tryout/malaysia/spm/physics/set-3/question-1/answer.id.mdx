# Massa jenis dari pangkat tiga diameter

<BlockMath math="\begin{aligned}
V&=\frac{\pi(6{,}75\times10^{-3})^3}{6}=1{,}61\times10^{-7}\text{ m}^3\\
\rho&=\frac{1{,}26\times10^{-3}}{1{,}61\times10^{-7}}=7{,}82\times10^3\text{ kg m}^{-3}
\end{aligned}" />

**Kekeliruan kecil pada <InlineMath math="d" /> menjadi tiga kali lipat pada volume, karena itu pilihannya berdekatan**.
