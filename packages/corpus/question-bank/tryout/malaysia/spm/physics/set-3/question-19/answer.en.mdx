# Keep the image virtual, then solve for the new object distance

The stamp is **inside the focal length**: <InlineMath math="\dfrac{1}{v} = \dfrac{1}{10} - \dfrac{1}{8} = -\dfrac{1}{40}" />, so <InlineMath math="v = -40" /> cm. The image is virtual and upright, on the same side as the stamp, magnified <InlineMath math="40 \div 8 = 5" /> times.

An **upright** image twice the size must also be virtual, so <InlineMath math="v = -2u" />: <InlineMath math="\dfrac{1}{u} - \dfrac{1}{2u} = \dfrac{1}{10}" />, which gives <InlineMath math="\dfrac{1}{2u} = \dfrac{1}{10}" /> and <InlineMath math="u = 5.0" /> cm. The stamp moves closer to the lens.

**A real image on a card**: a real, inverted image twice the size needs <InlineMath math="v = +2u" />, so <InlineMath math="\tfrac{1}{u} + \tfrac{1}{2u} = \tfrac{1}{10}" />, which gives <InlineMath math="u = 15" /> cm and <InlineMath math="v = 30" /> cm. The same magnification needs the stamp outside the focal length this time.

# Why the other options are wrong

- At <InlineMath math="20" /> cm the stamp would be at <InlineMath math="2f" />, giving a real, inverted image of the **same size**.
- An object inside the focal length always gives a **virtual** image, never a real one.
- The two distances are swapped: at <InlineMath math="15\text{ cm}" /> the image is real and inverted, and at <InlineMath math="5.0\text{ cm}" /> it is upright.
