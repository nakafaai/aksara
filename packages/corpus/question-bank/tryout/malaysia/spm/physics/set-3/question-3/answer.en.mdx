# Judge each statement

**A parallax reading is too large or too small depending on where the eye is and how the scale runs**, so I is wrong.

Random variation scatters both ways and averages out, but the late start shifts every reading the same way, so averaging leaves it. II is correct.

Starting late and stopping on time cuts <InlineMath math="0.2\text{ s}" /> from every interval, the same way each time. That is a systematic error, so III is correct.
