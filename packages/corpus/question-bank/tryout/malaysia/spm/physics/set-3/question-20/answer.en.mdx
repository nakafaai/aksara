# Magnification gives the slide distance, the lens equation gives f

Magnification: <InlineMath math="140 \div 3.5 = 40" />, so the slide sits <InlineMath math="u = 5.0 \div 40 = 0.125" /> m from the lens.

Then <InlineMath math="\dfrac{1}{f} = \dfrac{1}{0.125} + \dfrac{1}{5.0} = 8.0 + 0.2 = 8.2" />, so <InlineMath math="f = 0.122" /> m, or <InlineMath math="12.2" /> cm, and the power is <InlineMath math="+8.2" /> D. The slide sits **just outside** the focal point, as a projector needs for a large real image.

**A nearer wall**: now <InlineMath math="v = 1.0" /> m, so <InlineMath math="\tfrac{1}{u} = 8.2 - 1.0 = 7.2" />, <InlineMath math="u = 0.139" /> m and <InlineMath math="m = 1.0 \div 0.139 = 7.2" />. The image is <InlineMath math="3.5 \times 7.2 = 25" /> cm wide, not the <InlineMath math="28" /> cm that a fifth of <InlineMath math="1.40" /> m suggests, because refocusing moves the slide too.

# Why the other options are wrong

- <InlineMath math="12.5\text{ cm}" /> takes the slide distance as the focal length and **leaves out** the <InlineMath math="\tfrac{1}{5.0}" /> term.
- A projector makes a real image, so its lens is converging and its power is positive.
- <InlineMath math="28\text{ cm}" /> scales the width with the distance, but refocusing changes <InlineMath math="u" />, so the magnification is <InlineMath math="7.2" />, not <InlineMath math="8" />.
