# Mengapa pilihan lain salah

- <InlineMath math="2.6\text{ mA}" /> **membiarkan setiap foton membebaskan elektron**.
- <InlineMath math="0.026\text{ mA}" /> menggunakan <InlineMath math="10\%" /> dua kali.
