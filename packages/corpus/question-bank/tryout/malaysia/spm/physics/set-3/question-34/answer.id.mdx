# Gelap atau terang

**Hambatan LDR naik saat cahaya meredup**, yang menaikkan bagian tegangannya. Basis mencapai <InlineMath math="0{,}7\text{ V}" /> begitu LDR di atas <InlineMath math="1{,}3\text{ k}\Omega" />, jadi lampu menyala dalam gelap.

# Kenapa pilihan lain salah

- **Cahaya terang menurunkan hambatan LDR dan mematikan transistor**.
