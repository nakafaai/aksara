# Hitung mundur dari sisi inti ke ujung serat

Di batas inti-selubung, <InlineMath math="\sin c = 1{,}40 \div 1{,}50 = 0{,}933" />, jadi <InlineMath math="c = 69^\circ" />. Selubung, **bukan udara**, adalah medium kedua di sini.

Untuk pemantulan sempurna, sinar harus mengenai sisi pada <InlineMath math="69^\circ" /> atau lebih terhadap garis normal, jadi di dalam inti sinar membentuk paling banyak <InlineMath math="90 - 69 = 21^\circ" /> dengan sumbu. Di ujung datar, pembiasan dari udara: <InlineMath math="\sin \theta = 1{,}50 \sin 21^\circ = 0{,}54" />, jadi <InlineMath math="\theta = 33^\circ" />.

# Kenapa pilihan lain salah

- <InlineMath math="42^\circ" /> adalah sudut kritis kaca terhadap **udara**, padahal inti dikelilingi selubung.
- <InlineMath math="21^\circ" /> adalah sudut di dalam inti, sebelum pembiasan di ujung membelokkannya menjadi <InlineMath math="33^\circ" /> di udara.
- <InlineMath math="21^\circ" /> adalah pelengkap sudut kritis, bukan sudut kritis itu sendiri.
