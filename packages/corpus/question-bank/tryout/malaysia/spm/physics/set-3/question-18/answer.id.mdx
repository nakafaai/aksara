# Kenapa bayangan menjauh

**Di dekat titik fokus, perubahan kecil jarak benda membuat perubahan besar jarak bayangan**. Benda bergeser <InlineMath math="5\text{ cm}" /> ke arah fokus, dan bayangan nyata bergeser <InlineMath math="40\text{ cm}" /> menjauhi cermin.

# Kenapa pilihan lain salah

- **Mendekati cermin membalik arahnya: saat benda mendekati fokus, bayangan menjauh**.
- Perbesaran <InlineMath math="2" /> adalah nilai sebelum benda digeser.
- <InlineMath math="5\text{ cm}" /> menganggap bayangan bergeser sejauh benda.
