# Warum das Bild davonläuft

**Nahe dem Brennpunkt bewirkt eine kleine Änderung der Gegenstandsweite eine große Änderung der Bildweite**. Der Gegenstand rückte <InlineMath math="5\text{ cm}" /> zum Brennpunkt, und das reelle Bild wanderte <InlineMath math="40\text{ cm}" /> vom Spiegel weg.

# Warum die anderen Antworten falsch sind

- **Zum Spiegel hin kehrt die Richtung um: Nähert sich der Gegenstand dem Brennpunkt, entfernt sich das Bild**.
- Eine Vergrößerung von <InlineMath math="2" /> ist der Wert vor der Verschiebung.
- <InlineMath math="5\text{ cm}" /> nimmt an, das Bild wandere so weit wie der Gegenstand.
