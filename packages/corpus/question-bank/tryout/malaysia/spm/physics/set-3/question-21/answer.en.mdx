# Both ropes pulling

**The sideways components cancel, and the forward components add**.

# One rope left

**With one rope gone, its sideways pull is no longer cancelled**, and the forward pull drops below the water's resistance.

<BlockMath math="\begin{aligned}
F_{\text{forward}}&=2000\cos30^\circ-3000=-1268\text{ N}\\
F_{\text{side}}&=2000\sin30^\circ=1000\text{ N}\\
F&=\sqrt{1268^2+1000^2}=1615\text{ N}
\end{aligned}" />

# Why the other options are wrong

- <InlineMath math="1268\text{ N}" /> **keeps only the forward-backward part and drops the uncancelled sideways pull**.
- <InlineMath math="0.67\text{ m s}^{-2}" /> adds the rope tensions without resolving them.
- <InlineMath math="1000\text{ N}" /> keeps only the sideways part.
