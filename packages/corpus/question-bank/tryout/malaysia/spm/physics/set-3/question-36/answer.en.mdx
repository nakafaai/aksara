# Before the reversal

**A diode conducts only when forward biased**. At first the diode in P's branch points along the current and conducts, and the diode in Q's branch blocks. Current flows through R and P.

# After the reversal

**Reversing the battery reverses the current, so each diode swaps role**: the diode in Q's branch is now forward biased and the one in P's branch blocks.

R carries the whole current either way, so it stays lit, and Q and R light.

# Why the other options are wrong

- **P and R only is the state before the reversal**.
- R only assumes both diodes block, but one of them always conducts.
- P, Q and R would need both diodes to conduct at once.
