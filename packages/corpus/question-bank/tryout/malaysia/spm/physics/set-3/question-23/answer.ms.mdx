# Tolakan juga menekan blok ke dalam cerun

Tolakan mengufuk mempunyai bahagian di sepanjang cerun, <InlineMath math="F\cos30^\circ" />, dan bahagian ke dalamnya, <InlineMath math="F\sin30^\circ" />. **Bahagian kedua itu menambah daya normal, dan bersamanya geseran**.

<BlockMath math="N=mg\cos30^\circ+F\sin30^\circ=17.32+0.5F,\qquad f=0.20N=3.46+0.10F" />

# Imbangan di sepanjang cerun

<BlockMath math="\begin{aligned}
F\cos30^\circ&=mg\sin30^\circ+f\\
0.866F&=10.0+3.46+0.10F\ \Rightarrow\ F=\frac{13.46}{0.766}=17.6\text{ N}
\end{aligned}" />
