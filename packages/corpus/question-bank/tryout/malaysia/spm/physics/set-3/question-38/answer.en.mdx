# Remove the background first

**The background reaches the detector whether or not the wood is there**, so it is not part of the wood's activity.

<BlockMath math="66-2=64,\qquad 18-2=16,\qquad \frac{16}{64}=\frac14=\left(\frac12\right)^2" />

# Why the other options are wrong

- <InlineMath math="10\,700" /> **years keeps the background in both counts, using the ratio <InlineMath math="18/66" />**.
- <InlineMath math="22\,920" /> years counts four half-lives, as if a quarter were <InlineMath math="(1/2)^4" />.
- <InlineMath math="5730" /> years is a single half-life, which would leave half the activity.
