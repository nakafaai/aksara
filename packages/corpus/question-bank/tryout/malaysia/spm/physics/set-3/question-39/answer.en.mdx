# Intensity and wavelength

**Intensity sets how many photons arrive, not how much energy each one carries**. Brighter light emits more electrons, but each still gets at most <InlineMath math="0.80\text{ eV}" />, so II is wrong.

A <InlineMath math="600\text{ nm}" /> photon carries <InlineMath math="1240/600=2.07\text{ eV}" />, less than the work function, so no single photon can free an electron, however many arrive. III is correct.

The threshold wavelength is <InlineMath math="1240/2.3=539\text{ nm}" />, about <InlineMath math="540\text{ nm}" />. IV is correct.

# Why the other options are wrong

- I and III only **misses the threshold wavelength in IV**.
- Options with II treat brighter light as more energetic photons.
