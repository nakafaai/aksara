# Alpha decays from the mass number

**Only alpha decay changes the mass number, by <InlineMath math="4" /> each time**.

<BlockMath math="n_\alpha=\frac{238-206}{4}=8" />

# Beta decays from the proton number

Eight alpha decays alone would lower the proton number by <InlineMath math="16" />, to <InlineMath math="76" />. **Lead has <InlineMath math="82" />, so beta decays must raise it by <InlineMath math="6" />**, each turning a neutron into a proton.

<BlockMath math="n_\beta=82-(92-16)=6" />

# Why the other options are wrong

- <InlineMath math="32" /> **fewer is the drop in mass number, which also counts the protons lost in the alpha particles**.
- <InlineMath math="10" /> beta decays subtracts the proton numbers directly and forgets that each alpha decay takes <InlineMath math="2" /> protons.
- <InlineMath math="6" /> alpha and <InlineMath math="8" /> beta swap the two counts.
