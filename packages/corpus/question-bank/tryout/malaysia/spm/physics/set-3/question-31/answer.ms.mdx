# Sebelah sekunder

**Tiga mentol secara selari masing-masing mengambil <InlineMath math="24/12=2.0\text{ A}" />, jadi sekunder membawa <InlineMath math="6.0\text{ A}" /> dan membekalkan <InlineMath math="72\text{ W}" />**.

# Sebelah primer, dengan kehilangan

**Input mesti melebihi output, kerana hanya <InlineMath math="90\%" /> daripada input sampai ke mentol**.
