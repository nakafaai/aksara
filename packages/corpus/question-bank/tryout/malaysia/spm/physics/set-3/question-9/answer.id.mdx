# Kenapa pilihan lain salah

- <InlineMath math="42\,000\text{ km}" /> **adalah jari-jari orbit, diukur dari pusat**.
- <InlineMath math="14\,000\text{ km}" /> menskalakan jari-jari sebanding dengan periode.
- <InlineMath math="7\,700\text{ km}" /> menskalakan sebanding dengan periode lalu mengurangkan jari-jari Bumi.
