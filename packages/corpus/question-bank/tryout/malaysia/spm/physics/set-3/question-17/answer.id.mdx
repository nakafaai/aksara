# Pembiasan di muka masuk

**Sinar membias mendekati garis normal saat masuk, jadi di luar ujung sudutnya lebih besar**.

<BlockMath math="\sin\theta=1{,}50\sin21{,}0^\circ=0{,}538\ \Rightarrow\ \theta=33^\circ" />

# Kenapa pilihan lain salah

- <InlineMath math="21^\circ" /> **adalah sudut di dalam inti, sebelum pembiasan di ujung diperhitungkan**.
- <InlineMath math="69^\circ" /> adalah sudut kritis itu sendiri, diukur dari garis normal sisi.
- <InlineMath math="90^\circ" /> memakai sudut kritis kaca-udara <InlineMath math="42^\circ" />, seolah tidak ada selubung.
