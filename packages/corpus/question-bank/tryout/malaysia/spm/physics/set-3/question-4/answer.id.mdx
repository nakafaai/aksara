# Kapan jaraknya paling kecil

**Mobil mengerem lebih lembut, jadi mobil masih bergerak setelah truk berhenti**, dan jaraknya terus mengecil sampai mobil berhenti. Jarak terkecil tercapai di akhir, jadi jarak awal harus menutupi selisihnya.

# Kenapa pilihan lain salah

- <InlineMath math="17{,}5\text{ m}" /> **hanya menghitung jarak reaksi, seolah keduanya mengerem sama kuat**.
- <InlineMath math="69{,}6\text{ m}" /> adalah seluruh jarak henti mobil, seolah truk berhenti seketika.
- <InlineMath math="13{,}0\text{ m}" /> membandingkan jarak pengereman dan lupa jarak reaksi mobil.
