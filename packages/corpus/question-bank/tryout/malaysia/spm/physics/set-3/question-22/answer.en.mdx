# The same force runs through both springs

**In series, each spring carries the whole <InlineMath math="30\text{ N}" />**, so each stretches by <InlineMath math="F/k" />.

<BlockMath math="x_P=\frac{30}{200}=0.15\text{ m},\qquad x_Q=\frac{30}{300}=0.10\text{ m},\qquad x=0.25\text{ m}=25\text{ cm}" />

# Energy goes with the stretch

**With the same force, the energy <InlineMath math="\tfrac12Fx" /> is larger where the stretch is larger, so the softer spring P stores more**.

<BlockMath math="E_P=\tfrac12(30)(0.15)=2.25\text{ J},\qquad E_Q=\tfrac12(30)(0.10)=1.50\text{ J}" />

# Why the other options are wrong

- **Q assumes the stiffer spring stores more, which holds only for equal extensions**.
- <InlineMath math="6.0\text{ cm}" /> treats the springs as side by side, with constants adding to <InlineMath math="500\text{ N m}^{-1}" />.
- <InlineMath math="4.5\text{ J}" /> drops the half in <InlineMath math="\tfrac12Fx" />.
