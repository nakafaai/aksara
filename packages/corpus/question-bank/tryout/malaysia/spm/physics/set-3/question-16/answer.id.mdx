# Bunyi dan mobil berbagi perjalanan pulang-pergi

**Mobil terus bergerak, jadi bunyi tidak kembali ke tempat klakson dibunyikan**. Jika mobil mulai pada jarak <InlineMath math="d" />, lintasan bunyi pergi dan pulang serta lintasan mobil bersama-sama berjumlah <InlineMath math="2d" />.

<BlockMath math="340(4{,}0)+20(4{,}0)=2d\ \Rightarrow\ d=\frac{1360+80}{2}=720\text{ m}" />
