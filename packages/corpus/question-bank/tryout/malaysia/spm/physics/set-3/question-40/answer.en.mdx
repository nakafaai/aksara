# Only one photon in ten makes current

**Each freed electron carries one electronic charge, but only <InlineMath math="10\%" /> of the photons free one**.

# Why the other options are wrong

- <InlineMath math="2.6\text{ mA}" /> **lets every photon free an electron**.
- <InlineMath math="0.026\text{ mA}" /> applies the <InlineMath math="10\%" /> twice.
- <InlineMath math="0.16\text{ mA}" /> uses a wavelength of <InlineMath math="400\text{ nm}" />, whose photons carry more energy, so fewer arrive each second.
