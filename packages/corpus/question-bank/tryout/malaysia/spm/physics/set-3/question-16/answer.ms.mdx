# Bunyi dan kereta berkongsi perjalanan pergi balik

**Kereta terus bergerak, jadi bunyi tidak kembali ke tempat hon dibunyikan**. Jika kereta bermula pada jarak <InlineMath math="d" />, laluan bunyi pergi dan balik serta laluan kereta bersama-sama ialah <InlineMath math="2d" />.

<BlockMath math="340(4.0)+20(4.0)=2d\ \Rightarrow\ d=\frac{1360+80}{2}=720\text{ m}" />

# Mengapa pilihan lain salah

- <InlineMath math="680\text{ m}" /> **menganggap kereta pegun semasa bunyi bergerak**.
