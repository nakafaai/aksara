# Kira ke belakang dari sisi teras ke hujung gentian

Di sempadan teras-salutan, <InlineMath math="\sin c = 1.40 \div 1.50 = 0.933" />, jadi <InlineMath math="c = 69^\circ" />. Salutan, **bukan udara**, ialah medium kedua di sini.

  title={<>Daripada Sempadan Kembali ke Hujung</>}
  description={<>Sinar mesti menuju sisi pada sekurang-kurangnya <InlineMath math="69^\circ" />, jadi di dalam hujung ia boleh condong paling banyak <InlineMath math="21^\circ" />, iaitu <InlineMath math="33^\circ" /> di udara.</>}

      N0["sin c = 1.40 ÷ 1.50"] --> N1["c = 69°"]
      N1 --> N2["Sudut di dalam hujung: 90 − 69 = 21°"]
      N2 --> N3["Snell di hujung: sin θ = 1.50 sin 21°"]
      N3 --> N4["θ = 33°"]
  `}
/>

Untuk pantulan dalam penuh, sinar mesti mengenai sisi pada <InlineMath math="69^\circ" /> atau lebih kepada normal, jadi di dalam teras ia membuat paling banyak <InlineMath math="90 - 69 = 21^\circ" /> dengan paksi. Di hujung rata, pembiasan dari udara: <InlineMath math="\sin \theta = 1.50 \sin 21^\circ = 0.54" />, jadi <InlineMath math="\theta = 33^\circ" />.

# Mengapa pilihan lain salah

- <InlineMath math="42^\circ" /> ialah sudut genting kaca dengan **udara**, tetapi teras dikelilingi salutan.
- <InlineMath math="21^\circ" /> ialah sudut di dalam teras, sebelum pembiasan di hujung membengkokkannya kepada <InlineMath math="33^\circ" /> di udara.
- <InlineMath math="21^\circ" /> ialah pelengkap sudut genting, bukan sudut genting itu sendiri.
