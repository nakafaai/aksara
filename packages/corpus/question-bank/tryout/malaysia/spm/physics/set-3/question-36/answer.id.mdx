# Sebelum dibalik

**Dioda hanya menghantarkan arus saat dibias maju**. Awalnya dioda di cabang P searah arus dan menghantarkan, dan dioda di cabang Q menahan. Arus mengalir lewat R dan P.

# Sesudah dibalik

**Membalik baterai membalik arus, jadi tiap dioda bertukar peran**: dioda di cabang Q kini dibias maju dan yang di cabang P menahan.

# Kenapa pilihan lain salah

- **P dan R saja adalah keadaan sebelum dibalik**.
- R saja menganggap kedua dioda menahan, padahal salah satunya selalu menghantarkan.
- P, Q, dan R memerlukan kedua dioda menghantarkan sekaligus.
