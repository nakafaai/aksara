# From base current to collector-emitter voltage

There are three linked steps. First, the voltage across the base resistor is the supply voltage **minus the <InlineMath math="0.70\text{ V}" /> between base and emitter**, so the base current comes from <InlineMath math="4.0\text{ V}" />. Second, the collector current is <InlineMath math="100" /> times the base current. Third, the <InlineMath math="9.0\text{ V}" /> supply is shared between the collector resistor and the transistor.

Change the base resistor in the lab. The base current sets the collector current, and the voltage left across the transistor is whatever the collector resistor does not take.

<BlockMath math="\begin{aligned}
I_B&=\frac{4.7-0.70}{100\times10^3}=4.0\times10^{-5}\text{ A}\\
I_C&=100\times4.0\times10^{-5}=4.0\times10^{-3}\text{ A}\\
V_{CE}&=9.0-(4.0\times10^{-3})(1.0\times10^3)=9.0-4.0=5.0\text{ V}
\end{aligned}" />

So the potential difference between the collector and the emitter is <InlineMath math="5.0\text{ V}" />.

# Why the other options are wrong

- <InlineMath math="4.0\text{ V}" /> is the voltage across the collector resistor, not between collector and emitter.
- <InlineMath math="4.3\text{ V}" /> uses the full <InlineMath math="4.7\text{ V}" /> for the base current, but **<InlineMath math="0.70\text{ V}" /> is already taken** between base and emitter.
- <InlineMath math="9.0\text{ V}" /> assumes there is no collector current, so no voltage across the collector resistor.
