# The whole system, then one block

The tension is an internal force, so it does not appear when you treat both blocks as one system. Find the system's acceleration first, then **isolate the block that only the string pulls**, which is P at the back.

Change the pull in the lab. The acceleration is shared, and the string has to give P exactly enough force to beat its friction and keep up.

# Why the other options are wrong

- <InlineMath math="18\text{ N}" /> ignores friction, so the acceleration becomes <InlineMath math="3.0\text{ m s}^{-2}" /> and the tension <InlineMath math="6.0\times3.0" />.
- <InlineMath math="15\text{ N}" /> uses the correct acceleration but **forgets that the string also overcomes the friction** on P.
- <InlineMath math="5.0\text{ N}" /> is the net force on Q, as if the string pulled Q, when it pulls P.
