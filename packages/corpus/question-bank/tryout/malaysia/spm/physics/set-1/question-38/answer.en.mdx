# Remove the background first

The counter also records background radiation, which does not decay. **Only the sample's count rate halves every half-life**, so subtract the background from both readings first.

<BlockMath math="\begin{aligned}
\text{start: }&520-20=500\text{ counts per minute}\\
\text{after }12\text{ hours: }&145-20=125\text{ counts per minute}\\
500\to250\to125:\ &2\text{ half-lives}\ \Rightarrow\ T_{1/2}=\frac{12}{2}=6.0\text{ hours}
\end{aligned}" />

The ratio is exactly <InlineMath math="\tfrac{125}{500}=\tfrac14" />, so two half-lives pass in <InlineMath math="12" /> hours. So the half-life of the sample is <InlineMath math="6.0" /> hours.

# Why the other options are wrong

- <InlineMath math="6.5" /> hours uses the raw readings <InlineMath math="520" /> and <InlineMath math="145" />, which **still include the background**, so the ratio is not a quarter.
- <InlineMath math="24" /> hours multiplies <InlineMath math="12" /> hours by the number of half-lives, when it should divide.
- <InlineMath math="3.0" /> hours assumes four half-lives, as if the count fell to a sixteenth.
