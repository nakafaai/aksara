# The direction of friction while the block rises

While the block moves up, the component of weight along the plane and **the friction both point down the plane**, because friction always opposes the motion. Both slow the block down.

Add the forces along the plane to the picture, drawn to scale. The two downhill arrows add up to <InlineMath math="35\text{ N}" />, and that total sets the deceleration.

<BlockMath math="\begin{aligned}
mg\sin30^\circ&=(5.0)(10)(0.5)=25\text{ N}\\
a&=\frac{25+10}{5.0}=7.0\text{ m s}^{-2}\ \text{(deceleration)}\\
s&=\frac{u^2}{2a}=\frac{7.0^2}{2(7.0)}=3.5\text{ m}
\end{aligned}" />

The component perpendicular to the plane is balanced by the normal force, so it does not enter. So the block travels <InlineMath math="3.5\text{ m}" /> up before it momentarily stops.

# Why the other options are wrong

- <InlineMath math="8.2\text{ m}" /> subtracts friction from the weight component, as if friction helped the block up, but **friction opposes the motion**.
- <InlineMath math="2.3\text{ m}" /> uses <InlineMath math="\cos30^\circ" />, the component perpendicular to the plane.
- <InlineMath math="4.9\text{ m}" /> ignores friction.
