# Which formula contains what

The four statements use different formulas, and **the ratios <InlineMath math="M/R" /> and <InlineMath math="M/R^2" /> behave differently**. For planet Z, <InlineMath math="M/R" /> is unchanged because <InlineMath math="2M/2R=M/R" />, but <InlineMath math="M/R^2" /> halves because <InlineMath math="2M/(2R)^2=M/(2R^2)" />.

<BlockMath math="\begin{aligned}
g&=\frac{GM}{R^2} &&\Rightarrow\ g_Z=\tfrac12 g\\
v_{\text{escape}}&=\sqrt{\frac{2GM}{R}} &&\Rightarrow\ \text{equal}\\
v_{\text{orbit}}&=\sqrt{\frac{GM}{R}} &&\Rightarrow\ \text{equal}\\
T&=2\pi\sqrt{\frac{R^3}{GM}} &&\Rightarrow\ T_Z=\sqrt{\tfrac{8}{2}}\,T=2T
\end{aligned}" />

So statements I and II are correct. Statement III is wrong because the orbital speed near the surface depends on <InlineMath math="M/R" />, which is unchanged. Statement IV is wrong because the period doubles. So only I and II are correct.

# Why the other options are wrong

- I, II and IV assumes the period is unchanged, but the period contains <InlineMath math="R^3" />, so **the period doubles**.
- I and III assumes the orbital speed rises with the mass, but the larger radius cancels it.
- II, III and IV rejects statement I, but <InlineMath math="g" /> contains <InlineMath math="R^2" />, so it drops to half.
