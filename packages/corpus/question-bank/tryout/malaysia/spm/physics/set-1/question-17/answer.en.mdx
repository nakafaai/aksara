# The two object positions worked separately

Use the lens formula <InlineMath math="\dfrac1f=\dfrac1u+\dfrac1v" /> with the real-is-positive convention for each position, then compare the nature and the magnification. **The object crosses the focal point**, so the nature of the image must change.

Drag the object in the lab from <InlineMath math="10\text{ cm}" /> to <InlineMath math="20\text{ cm}" />. Watch the image jump to the other side of the lens as the object crosses the focal point.

At the first position the image is virtual and upright, at the second it is real and inverted on the far side. The magnification happens to be equal, because both object distances are the same <InlineMath math="5\text{ cm}" /> from the focal point. So the image changes from virtual and upright to real and inverted, and its magnification stays at <InlineMath math="3" /> times.

# Why the other options are wrong

- <InlineMath math="1.5" /> times assumes the magnification falls in proportion to the object distance, but **magnification comes from <InlineMath math="v/u" />** at the new position.
- The image does not stay virtual, because at <InlineMath math="20\text{ cm}" /> the object is beyond the focal length.
- <InlineMath math="6" /> times divides the new image distance by the old object distance, <InlineMath math="60/10" />.
