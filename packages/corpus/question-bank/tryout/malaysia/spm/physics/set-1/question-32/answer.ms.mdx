# Lilitan daripada voltan, arus daripada kuasa

Nisbah lilitan mengikut nisbah voltan, <InlineMath math="\dfrac{N_p}{N_s}=\dfrac{V_p}{V_s}" />. Untuk arus primer, ingat bahawa transformer itu tidak unggul: **kuasa input lebih besar daripada kuasa output**, kerana sebahagian tenaga hilang sebagai haba.

<BlockMath math="\begin{aligned}
\frac{N_p}{N_s}&=\frac{240}{12}=\frac{20}{1}\\
P_p&=\frac{P_s}{0.80}=\frac{24}{0.80}=30\text{ W}\\
I_p&=\frac{P_p}{V_p}=\frac{30}{240}=0.125\text{ A}
\end{aligned}" />

Jadi, nisbah lilitan ialah <InlineMath math="20:1" /> dan arus dalam gegelung primer ialah <InlineMath math="0.125\text{ A}" />.

# Kenapa pilihan lain salah

- <InlineMath math="0.10\text{ A}" /> menganggap kecekapan <InlineMath math="100\%" />, iaitu <InlineMath math="24/240" />.
- <InlineMath math="1:20" /> menyongsangkan nisbah, sedangkan transformer injak turun mempunyai **lebih banyak lilitan pada gegelung primer**.
- <InlineMath math="0.080\text{ A}" /> mendarabkan arus dengan kecekapan, sedangkan kuasa input mesti lebih besar daripada kuasa output, bukan lebih kecil.
