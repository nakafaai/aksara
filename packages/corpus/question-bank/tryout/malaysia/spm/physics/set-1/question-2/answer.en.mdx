# The true equation of the line

The period depends on the effective length to the centre of the bob, which is <InlineMath math="l+r" /> with <InlineMath math="r=0.010\text{ m}" />. So the data really follow

<BlockMath math="T^2=\frac{4\pi^2}{g}\,l+\frac{4\pi^2}{g}\,r" />

This is a straight line with gradient <InlineMath math="\dfrac{4\pi^2}{g}" /> and a positive intercept of <InlineMath math="\dfrac{4\pi^2}{g}r" /> on the <InlineMath math="T^2" /> axis. **The length error only shifts the line**, it does not change the slope.

Now judge each statement. Statement I is correct because <InlineMath math="g=\dfrac{4\pi^2}{4.0}\approx9.87\text{ m s}^{-2}" /> and the gradient does not contain <InlineMath math="r" />. Statement II is correct because the intercept is <InlineMath math="4.0\times0.010=0.040\text{ s}^2" />. Statement III is wrong: measuring to the centre only shifts the line left by <InlineMath math="r" />, and the gradient stays <InlineMath math="4.0\text{ s}^2\text{ m}^{-1}" />. Statement IV is correct because <InlineMath math="T^2=0" /> when <InlineMath math="l+r=0" />, that is, at <InlineMath math="l=-0.010\text{ m}" />. So I, II and IV are correct.

# Why the other options are wrong

- I and II only misses statement IV, usually because the intercept on the <InlineMath math="l" /> axis is taken as positive.
- II, III and IV assumes the length error changes the gradient, but the gradient **depends on <InlineMath math="g" /> alone**.
- I, II, III and IV also accepts the wrong statement III.
