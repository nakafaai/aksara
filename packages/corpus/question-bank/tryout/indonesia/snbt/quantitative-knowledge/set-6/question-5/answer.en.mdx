We need **all integer pairs**, not just one Pythagorean triple. Squaring removes the sign, so let <InlineMath math="u=\min(|x|,|y|)" /> and <InlineMath math="v=\max(|x|,|y|)" />. Then <InlineMath math="2u^2\le169" />, so we only need to test <InlineMath math="u=0,1,\ldots,9" />. The value <InlineMath math="169-u^2" /> must be a **perfect square**.

| <InlineMath math="u" /> | <InlineMath math="169-u^2" /> | <InlineMath math="v" /> |
| --- | --- | --- |
| 0 | 169 | 13 |
| 1 | 168 | Not an integer |
| 2 | 165 | Not an integer |
| 3 | 160 | Not an integer |
| 4 | 153 | Not an integer |
| 5 | 144 | 12 |
| 6 | 133 | Not an integer |
| 7 | 120 | Not an integer |
| 8 | 105 | Not an integer |
| 9 | 88 | Not an integer |

Thus the absolute values are only <InlineMath math="(0,13)" /> or <InlineMath math="(5,12)" />, including swapped coordinates. The first pair gives sums <InlineMath math="\pm13" />. For the second pair, check both signs:

<BlockMath math="\begin{aligned}5+12&=17\\5-12&=-7\\-5+12&=7\\-5-12&=-17\end{aligned}" />

All possible sums are <InlineMath math="\{-17,-13,-7,7,13,17\}" />. Neither <InlineMath math="\pm10" /> nor <InlineMath math="\pm14" /> occurs, so only **statements 1 and 3** are correct.
