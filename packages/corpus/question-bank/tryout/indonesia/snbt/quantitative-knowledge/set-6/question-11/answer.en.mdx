Let <InlineMath math="b" /> be the actual width in metres. Dividing the rectangle’s area by its length gives:

<BlockMath math="b=\frac{540}{30}=18" />

Convert to cm:

<BlockMath math="\begin{aligned}18\text{ m}&=18\cdot100\text{ cm}\\&=1800\text{ cm}\end{aligned}" />

The linear scale is <InlineMath math="5 : 2500 = 1 : 500" />. Apply it to the actual width in the same unit:

With <InlineMath math="b_m" /> denoting the miniature’s width in centimetres:

<BlockMath math="\begin{aligned}b_m&=\frac{5}{2500}\cdot1800\\&=\frac{1}{500}\cdot1800\\&=\frac{1800}{500}\\&=3.6\end{aligned}" />

So, the width of the miniature object is <InlineMath math="3.6\text{ cm}" />.
