# The difference property

For integers <InlineMath math="a\ne b" />, <InlineMath math="a-b" /> divides <InlineMath math="P(a)-P(b)" />. Here's why: <InlineMath math="P(a)-P(b)" /> is a sum of terms <InlineMath math="c_k\left(a^k-b^k\right)" /> with integer <InlineMath math="c_k" />, and each <InlineMath math="a^k-b^k" /> factors.

<BlockMath math="a^k-b^k=(a-b)\left(a^{k-1}+a^{k-2}b+\dots+b^{k-1}\right)" />

The second factor is an integer, so **every term is divisible by <InlineMath math="a-b" />**, and so is the sum. The given data pass this test: <InlineMath math="4-1=3" /> divides <InlineMath math="12-6=6" />.

# Why the other options fail

The other options only look impossible if you **assume the polynomial must be linear** or pair the values wrongly.

- <InlineMath math="P(0)=0" /> and <InlineMath math="P(7)=0" /> look impossible if you think this polynomial can't have an integer root. The polynomial <InlineMath math="7x-x^2=x(7-x)" /> shows that roots at <InlineMath math="0" /> and <InlineMath math="7" /> are both possible.
- <InlineMath math="P(6)=6" /> looks impossible if you think <InlineMath math="P" /> must keep rising because <InlineMath math="P(1)<P(4)" />. The polynomial <InlineMath math="7x-x^2" /> rises and then falls.
- <InlineMath math="P(5)=14" /> looks impossible if you pair <InlineMath math="5-1=4" /> with <InlineMath math="14-12=2" />, but the difference of values has to use the same pair of points.

So the statement that can't be true is <InlineMath math="P(-1)=7" />.
