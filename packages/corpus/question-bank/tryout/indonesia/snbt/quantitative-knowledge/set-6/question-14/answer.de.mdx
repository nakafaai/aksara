Wir setzen <InlineMath math="g(x) = 3x + 2" /> in die Gleichung ein. Dabei bedeutet <InlineMath math="(g(x))^2" /> das Quadrat des Funktionswerts, während <InlineMath math="g(x^2)" /> die Auswertung von <InlineMath math="g" /> an der Stelle <InlineMath math="x^2" /> bezeichnet.

<MathContainer>
  <BlockMath math="2(g(x))^2 - g(x^2) - 5g(x) - 7 = 0" />
</MathContainer>

Wir berechnen die beiden unterschiedlichen Ausdrücke:

<MathContainer>
  <BlockMath math="(g(x))^2 = (3x + 2)^2 = 9x^2 + 12x + 4" />
  <BlockMath math="g(x^2) = 3(x^2) + 2 = 3x^2 + 2" />
</MathContainer>

Nun setzen wir beide Ausdrücke in die Ausgangsgleichung ein:

<MathContainer>
  <BlockMath math="2(9x^2 + 12x + 4) - (3x^2 + 2) - 5(3x + 2) - 7 = 0" />
  <BlockMath math="(18x^2 + 24x + 8) - (3x^2 + 2) - (15x + 10) - 7 = 0" />
</MathContainer>

Nach dem Zusammenfassen gleichartiger Terme erhalten wir:

<MathContainer>
  <BlockMath math="(18 - 3)x^2 + (24 - 15)x + (8 - 2 - 10 - 7) = 0" />
  <BlockMath math="15x^2 + 9x - 11 = 0" />
</MathContainer>

Diese quadratische Gleichung hat die Lösungen <InlineMath math="x_1" /> und <InlineMath math="x_2" />. Für <InlineMath math="ax^2 + bx + c = 0" /> liefert der Satz von Vieta die Beziehung <InlineMath math="x_1 + x_2 = -\frac{b}{a}" />.

<MathContainer>
  <BlockMath math="x_1 + x_2 = -\frac{9}{15}" />
  <BlockMath math="x_1 + x_2 = -\frac{3}{5}" />
</MathContainer>

Somit ist der Wert von <InlineMath math="x_1 + x_2" /> <InlineMath math="-\frac{3}{5}" />.
