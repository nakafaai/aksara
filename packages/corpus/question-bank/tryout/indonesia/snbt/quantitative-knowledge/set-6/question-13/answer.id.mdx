Kita bandingkan **rentang nilai kedua kuantitas**. Syarat <InlineMath math="0<x<1" /> memberi <InlineMath math="1-x^2>0" />, sehingga faktor penyebut boleh dicoret saat menyederhanakan pecahan.

# Analisis Kuantitas Pertama

Gunakan **selisih dua kuadrat** pada pembilang:

<BlockMath math="P = \frac{1-x^4}{1-x^2}" />

<BlockMath math="P = \frac{(1-x^2)(1+x^2)}{1-x^2}" />

<BlockMath math="P = 1+x^2" />

Diketahui <InlineMath math="0 < x < 1" />. Maka:

<BlockMath math="0 < x^2 < 1" />

<BlockMath math="1 < 1+x^2 < 2" />

<BlockMath math="1 < P < 2" />

# Analisis Kuantitas Kedua

Kuantitas kedua diperoleh dengan **menambahkan dua** pada <InlineMath math="x" />.
Karena <InlineMath math="0 < x < 1" />, maka:

<BlockMath math="2 < 2+x < 3" />

<BlockMath math="2 < Q < 3" />

Dari analisis di atas, kita peroleh:
*   <InlineMath math="1 < P < 2" />
*   <InlineMath math="2 < Q < 3" />

Setiap nilai <InlineMath math="P" /> lebih kecil dari <InlineMath math="2" />, sedangkan setiap nilai <InlineMath math="Q" /> lebih besar dari <InlineMath math="2" />.

Jadi, <InlineMath math="P < Q" />.
