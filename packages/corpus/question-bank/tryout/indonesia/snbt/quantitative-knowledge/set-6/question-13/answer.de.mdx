Wir bestimmen <InlineMath math="P" /> und <InlineMath math="Q" /> getrennt und vergleichen anschließend ihre Werte.

#### Analyse der ersten Größe

Der Ausdruck für <InlineMath math="P" /> kann wie folgt vereinfacht werden:

<MathContainer>
  <BlockMath math="P = \frac{1-x^4}{1-x^2}" />
  <BlockMath math="P = \frac{(1-x^2)(1+x^2)}{1-x^2}" />
  <BlockMath math="P = 1+x^2" />
</MathContainer>

Aus <InlineMath math="0 < x < 1" /> folgt:

<MathContainer>
  <BlockMath math="0 < x^2 < 1" />
  <BlockMath math="1 < 1+x^2 < 2" />
  <BlockMath math="1 < P < 2" />
</MathContainer>

#### Analyse der zweiten Größe

Gegeben <InlineMath math="Q = 2+x" />.
Aus <InlineMath math="0 < x < 1" /> folgt:

<MathContainer>
  <BlockMath math="2 < 2+x < 3" />
  <BlockMath math="2 < Q < 3" />
</MathContainer>

#### Vergleich der Größen

Aus der obigen Analyse haben wir:
*   <InlineMath math="1 < P < 2" />
*   <InlineMath math="2 < Q < 3" />

Jeder mögliche Wert von <InlineMath math="P" /> ist damit kleiner als jeder mögliche Wert von <InlineMath math="Q" />.

Folglich gilt stets <InlineMath math="P < Q" />.
