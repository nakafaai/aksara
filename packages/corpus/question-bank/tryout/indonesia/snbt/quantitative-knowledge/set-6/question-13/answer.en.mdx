Compare the **ranges of the two quantities**. Since <InlineMath math="0<x<1" />, we have <InlineMath math="1-x^2>0" />, so this denominator factor may be canceled when simplifying.

#### Analyzing the First Quantity

Factor the numerator as a **difference of squares**:

<MathContainer>
  <BlockMath math="P = \frac{1-x^4}{1-x^2}" />
  <BlockMath math="P = \frac{(1-x^2)(1+x^2)}{1-x^2}" />
  <BlockMath math="P = 1+x^2" />
</MathContainer>

Given <InlineMath math="0 < x < 1" />. Thus:

<MathContainer>
  <BlockMath math="0 < x^2 < 1" />
  <BlockMath math="1 < 1+x^2 < 2" />
  <BlockMath math="1 < P < 2" />
</MathContainer>

#### Analyzing the Second Quantity

The second quantity **adds two** to <InlineMath math="x" />.
Since <InlineMath math="0 < x < 1" />, then:

<MathContainer>
  <BlockMath math="2 < 2+x < 3" />
  <BlockMath math="2 < Q < 3" />
</MathContainer>

From the analysis above, we have:
*   <InlineMath math="1 < P < 2" />
*   <InlineMath math="2 < Q < 3" />

Every value of <InlineMath math="P" /> is below <InlineMath math="2" />, while every value of <InlineMath math="Q" /> is above <InlineMath math="2" />.

Thus, <InlineMath math="P < Q" />.
