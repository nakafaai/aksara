The fraction is easier to check once the numerator is **rewritten to contain the denominator**. Then the integer condition depends on one simple fraction.

# Rewriting the fraction

<BlockMath math="\frac{n+6}{n-2}=\frac{(n-2)+8}{n-2}=1+\frac{8}{n-2}" />

This is an integer exactly when <InlineMath math="n-2" /> **divides 8**. The divisors of 8 include negative numbers.

<BlockMath math="n-2\in\{-8,-4,-2,-1,1,2,4,8\}" />

# Adding the values of n

Each divisor <InlineMath math="d" /> gives <InlineMath math="n=d+2" />, namely <InlineMath math="-6,-2,0,1,3,4,6,10" />. The positive and negative divisors cancel, so the sum is <InlineMath math="8\times2=16" />.

<BlockMath math="-6-2+0+1+3+4+6+10=16" />

The value 23 uses only the positive divisors. The value 8 is the number of values of <InlineMath math="n" />, not their sum. The value 15 adds the positive divisors of 8, which are values of <InlineMath math="n-2" />, not of <InlineMath math="n" />. The value 12 comes from the slip <InlineMath math="1+\frac{4}{n-2}" />.

So the sum of all values of <InlineMath math="n" /> is **16**.
