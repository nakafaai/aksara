The question asks for **a single value of <InlineMath math="x" />**. A statement is sufficient only if it leaves exactly one value.

# Statement one alone

Move every term to one side and factor. Do not divide by <InlineMath math="x" />, because that **loses the solution <InlineMath math="x=0" />**.

<BlockMath math="x^2-4x=x(x-4)=0\quad\Rightarrow\quad x=0\ \text{or}\ x=4" />

There are two values, so statement (1) alone is not sufficient.

# Statement two alone

In the same way:

<BlockMath math="x^3-16x=x(x-4)(x+4)=0\quad\Rightarrow\quad x\in\{-4,0,4\}" />

There are **three values**, so statement (2) alone is not sufficient.

# Both statements together

The values that satisfy both statements form **the intersection of the two solution sets**.

<BlockMath math="\{0,4\}\cap\{-4,0,4\}=\{0,4\}" />

Two values remain, 0 and 4. If you divide both equations by <InlineMath math="x" />, you get only <InlineMath math="x=4" /> and wrongly conclude that both statements together are sufficient.

So **statements (1) and (2) together are not sufficient** to answer the question.
