A percentage change is always computed **relative to the starting value**, which here is the previous month. Read the value of each bar, then check the statements one by one.

# Percentage changes

<BlockMath math="\begin{aligned}
\text{product } A\text{, February to March}&=\frac{60-50}{50}\times100\%=20\%\\
\text{product } B\text{, January to February}&=\frac{45-60}{60}\times100\%=-25\%
\end{aligned}" />

The first statement is **true**. Product <InlineMath math="B" /> fell by 25%, not 15%, so the third statement is false. The number 15 is the difference in units, not yet divided by the starting value.

# Totals and means

The January total is <InlineMath math="40+60=100" /> units, while the February total is <InlineMath math="50+45=95" /> units. **The February total is lower**, so the second statement is false.

<BlockMath math="\begin{aligned}
\bar x_A&=\frac{40+50+60}{3}=50\\
\bar x_B&=\frac{60+45+54}{3}=53
\end{aligned}" />

The mean for product <InlineMath math="B" /> is larger, so the fourth statement is true.

So the first statement is **true**, the second is **false**, the third is **false**, and the fourth is **true**.
