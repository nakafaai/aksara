First, we need to determine the function <InlineMath math="g(x)" />.

Given <InlineMath math="f(x) = 2x + 5" /> and <InlineMath math="(f \circ g)(x) = 2x^2 - 6x + 9" />.

Based on the definition of **function composition** <InlineMath math="(f \circ g)(x) = f(g(x))" />, we have:

<MathContainer>
  <BlockMath math="f(g(x)) = 2(g(x)) + 5" />
  <BlockMath math="2(g(x)) + 5 = 2x^2 - 6x + 9" />
  <BlockMath math="2(g(x)) = 2x^2 - 6x + 4" />
  <BlockMath math="g(x) = x^2 - 3x + 2" />
</MathContainer>

Now, check the truth of each statement.

#### Statement One

**Substitute the input** <InlineMath math="x=1" />:

<BlockMath math="\begin{aligned}g(1)&=1^2 - 3(1) + 2\\&=1 - 3 + 2\\&=0\end{aligned}" />

Statement (1) is true.

#### Statement Two

To determine the number of intersection points of the quadratic function <InlineMath math="g(x) = x^2 - 3x + 2" /> with the <InlineMath math="x" />-axis, we check the discriminant (<InlineMath math="D = b^2 - 4ac" />).

<MathContainer>
  <BlockMath math="\begin{aligned}a&=1\\b&=-3\\c&=2\end{aligned}" />
  <BlockMath math="\begin{aligned}D&=(-3)^2 - 4(1)(2)\\&=9 - 8\\&=1\end{aligned}" />
</MathContainer>

Since <InlineMath math="D > 0" />, the function <InlineMath math="g" /> intersects the <InlineMath math="x" />-axis at **two distinct points**. The statement says there is only one intersection, so it is false.

Statement (2) is false.

#### Statement Three

Finding the **inverse function** of <InlineMath math="f(x) = 2x + 5" />:

Let <InlineMath math="f(x) = y" />, then:

<MathContainer>
  <BlockMath math="y = 2x + 5" />
  <BlockMath math="2x = y - 5" />
  <BlockMath math="x = \frac{y - 5}{2}" />
  <BlockMath math="x = \frac{1}{2}y - \frac{5}{2}" />
</MathContainer>

So the inverse is:

<BlockMath math="f^{-1}(x) = \frac{1}{2}x - \frac{5}{2}" />

Statement (3) is false because the term is <InlineMath math="-\frac{5}{2}" />.

#### Statement Four

Add the functions by **collecting like terms**:

<MathContainer>
  <BlockMath math="\begin{aligned}f(x)+g(x)&=(2x+5)\\&\quad+(x^2-3x+2)\end{aligned}" />
  <BlockMath math="= x^2 + (2x - 3x) + (5 + 2)" />
  <BlockMath math="= x^2 - x + 7" />
</MathContainer>

Statement (4) is true.

The correct statements are statements (1) and (4). Thus, there are <InlineMath math="2" /> true statements.
