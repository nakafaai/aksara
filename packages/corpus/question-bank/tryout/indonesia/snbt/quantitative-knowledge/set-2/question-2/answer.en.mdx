You could rationalize each fraction separately, but it is quicker to **put both fractions over a common denominator** first.

<BlockMath math="\frac xy+\frac yx=\frac{x^2+y^2}{xy}" />

# Computing the numerator and denominator

The denominator is a difference of squares, and the numerator adds two squares whose **middle terms cancel**.

<BlockMath math="\begin{aligned}
xy&=\left(\sqrt5+\sqrt3\right)\left(\sqrt5-\sqrt3\right)=5-3=2\\
x^2+y^2&=\left(8+2\sqrt{15}\right)+\left(8-2\sqrt{15}\right)=16
\end{aligned}" />

So <InlineMath math="\frac{x^2+y^2}{xy}=\frac{16}{2}=8" />. A check with the separate fractions: <InlineMath math="\frac xy=4+\sqrt{15}" /> and <InlineMath math="\frac yx=4-\sqrt{15}" />, which add up to 8.

# The wrong options

The value 16 forgets to divide by <InlineMath math="xy" />. The value <InlineMath math="4+\sqrt{15}" /> computes only <InlineMath math="\frac xy" />. The value <InlineMath math="2\sqrt{15}" /> is the **difference** of the two fractions, not their sum. The value 4 divides the numerator by <InlineMath math="2xy" />.

So the value of <InlineMath math="\frac xy+\frac yx" /> is **8**.
