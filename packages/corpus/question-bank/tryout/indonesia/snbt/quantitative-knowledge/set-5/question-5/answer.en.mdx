A piecewise function uses a different rule on each interval. Solve <InlineMath math="f(x)=5" /> on each piece, then **keep only the solutions that lie in that piece's own interval**.

# The piece for x less than three

<BlockMath math="2x+1=5\quad\Rightarrow\quad x=2" />

The value <InlineMath math="x=2" /> is indeed less than 3, so **this solution is valid**.

# The piece for x at least three

<BlockMath math="x^2-4=5\quad\Rightarrow\quad x^2=9\quad\Rightarrow\quad x=3\ \text{or}\ x=-3" />

This piece applies only for <InlineMath math="x\ge3" />. The value <InlineMath math="x=3" /> is valid, while <InlineMath math="x=-3" /> is **rejected**, because for <InlineMath math="x=-3" /> the rule in force is <InlineMath math="2x+1" />, which gives <InlineMath math="f(-3)=-5" />.

The solutions are 2 and 3, so their sum is <InlineMath math="2+3=5" />.

The value 2 uses only the first piece, and the value 3 uses only the second. The value <InlineMath math="-1" /> uses <InlineMath math="-3" /> instead of 3. The value 6 counts <InlineMath math="x=3" /> twice.

So the sum of all values of <InlineMath math="x" /> that work is **5**.
