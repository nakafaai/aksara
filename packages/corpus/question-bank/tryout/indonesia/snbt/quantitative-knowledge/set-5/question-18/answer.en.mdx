For the same order, the number of workers and the work time are **inversely proportional**. Each worker has the same constant rate, so four times as many workers need one quarter of the time.

Given:

- <InlineMath math="x\text{ workers}" /> can complete the order in <InlineMath math="20\text{ days}" />.
- The order must be completed in <InlineMath math="5\text{ days}" /> with <InlineMath math="P\text{ workers}" />.

If <InlineMath math="n" /> is the number of workers and <InlineMath math="t" /> the time in days, the fixed workload gives:

<BlockMath math="n_1t_1=n_2t_2" />

Substitute the known values:

<BlockMath math="x \cdot 20 = P \cdot 5" />

<BlockMath math="20x = 5P" />

Then the value of <InlineMath math="P" /> is:

<BlockMath math="P = \frac{20x}{5}" />

<BlockMath math="P = 4x" />

It is known that <InlineMath math="Q = 4x" />.

Therefore:

<BlockMath math="P = 4x \quad \text{and} \quad Q = 4x" />

<BlockMath math="P = Q" />

So, the correct relationship is <InlineMath math="P = Q" />.
