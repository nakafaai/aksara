The question asks for a yes or a no. A statement is sufficient when **every value of <InlineMath math="x" /> that satisfies it gives the same answer**, either always yes or always no. The plan: rewrite the question as a condition that's easy to read, then test each statement carefully, especially at <InlineMath math="x=0" />.

# When the answer is yes

Move <InlineMath math="x" /> to the left side and factor.

<BlockMath math="\begin{aligned}
x^2-x&>0\\
x(x-1)&>0
\end{aligned}" />

A product of two factors is positive when both have the same sign, which happens for <InlineMath math="x<0" /> or <InlineMath math="x>1" />. So **the answer is no for <InlineMath math="0\le x\le1" />**, including <InlineMath math="x=0" />, because <InlineMath math="0^2=0" /> isn't greater than <InlineMath math="0" />.

# The first statement alone

A square root is never negative, so **<InlineMath math="\sqrt{x^2}" /> equals <InlineMath math="|x|" />, not <InlineMath math="x" />**. Statement (1) says <InlineMath math="|x|=-x" />, which is true exactly when <InlineMath math="x\le0" />. The value <InlineMath math="x=-1" /> gives <InlineMath math="1>-1" />, so the answer is yes. The value <InlineMath math="x=0" /> also satisfies (1), but <InlineMath math="0>0" /> is false, so the answer is no. Statement (1) alone isn't sufficient.

If you write <InlineMath math="\sqrt{x^2}" /> as <InlineMath math="x" />, you only get <InlineMath math="2x=0" /> and wrongly think the answer is a definite no.

# The second statement alone

The fraction <InlineMath math="\tfrac1x" /> only exists when <InlineMath math="x\ne0" />. To solve <InlineMath math="\tfrac1x<2" />, use **cases based on the sign of <InlineMath math="x" />**, because multiplying by a negative number flips the inequality.

<BlockMath math="\begin{aligned}
x>0:&\quad 1<2x\ \Rightarrow\ x>\tfrac12\\
x<0:&\quad \tfrac1x<0<2\ \text{(always true)}
\end{aligned}" />

So statement (2) means <InlineMath math="x<0" /> or <InlineMath math="x>\tfrac12" />. The value <InlineMath math="x=-1" /> gives yes, while <InlineMath math="x=\tfrac34" /> gives <InlineMath math="\tfrac{9}{16}<\tfrac34" />, so the answer is no. Statement (2) alone isn't sufficient.

# Both statements together

Statement (1) gives <InlineMath math="x\le0" />, and the only value there that answers no is <InlineMath math="x=0" />. **Statement (2) removes the case <InlineMath math="x=0" />**, because <InlineMath math="\tfrac10" /> isn't defined, and its part <InlineMath math="x>\tfrac12" /> doesn't fit <InlineMath math="x\le0" />. What's left is <InlineMath math="x<0" />, and every negative <InlineMath math="x" /> has <InlineMath math="x^2>0>x" />. The answer is always yes, so both statements together are sufficient.

Together, the statements leave **the thick piece <InlineMath math="x<0" />**, where the parabola is always above the line, while the point <InlineMath math="x=0" /> is already thrown out.
