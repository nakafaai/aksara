You're counting circular seatings that avoid two forbidden pairs at once. Counting the good seatings directly is messy, so the plan is to count all seatings, take away the ones that break a rule, and use **the inclusion-exclusion principle** so no seating gets taken away twice.

# All circular seatings

Two seatings count as the same when everyone has the same left and right neighbours, which means **rotating everyone together doesn't give a new seating**. So put Ani in one chair as a fixed reference, then arrange the other <InlineMath math="6" /> people in the remaining <InlineMath math="6" /> chairs.

<BlockMath math="(7-1)!=6!=720" />

# Seatings that break a rule

If Ani and Budi sit together, **glue them into one block**. Then <InlineMath math="6" /> units sit in a circle, and inside the block there are <InlineMath math="2" /> orders (Ani on Budi's left or right). The same goes for Citra and Dodi. If both pairs sit together, you have two blocks and <InlineMath math="3" /> other people, so <InlineMath math="5" /> units.

<BlockMath math="\begin{aligned}
\text{Ani and Budi together}&=(6-1)!\times2=240\\
\text{Citra and Dodi together}&=(6-1)!\times2=240\\
\text{both pairs together}&=(5-1)!\times2\times2=96
\end{aligned}" />

# Inclusion and exclusion

A seating where both pairs sit together is counted in the first group and again in the second. So **the seatings with both violations have to be added back once**.

<BlockMath math="\begin{aligned}
\text{at least one violation}&=240+240-96=384\\
\text{allowed seatings}&=720-384=336
\end{aligned}" />

# A check by another route

Count in stages. There are <InlineMath math="720-240=480" /> seatings where Ani and Budi aren't neighbours. Of the <InlineMath math="240" /> seatings where Citra and Dodi are neighbours, <InlineMath math="96" /> also have Ani and Budi together, so <InlineMath math="240-96=144" /> keep Ani and Budi apart. Remove those from the <InlineMath math="480" />.

<BlockMath math="480-144=336" />

You get the same answer. **The usual mistakes** are forgetting to add back the <InlineMath math="96" />, which gives <InlineMath math="720-480=240" />, using <InlineMath math="7!" /> even though rotations count as the same, or forgetting the factor <InlineMath math="2" /> for the order inside each block.

So the number of allowed seatings is <InlineMath math="336" />.
