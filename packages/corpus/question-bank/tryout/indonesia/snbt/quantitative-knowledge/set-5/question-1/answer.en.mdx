There is no need to compute <InlineMath math="N" /> directly. Each pair of a factor 2 and a factor 5 makes a factor 10, so **pair the factors 2 with the factors 5** as far as possible.

# Forming a power of ten

There are **seven factors 5**, so seven factors 2 can be paired with them. Three factors 2 remain.

<BlockMath math="\begin{aligned}
N&=2^{3}\times\left(2^{7}\times5^{7}\right)\times3\\
&=2^3\times3\times10^7\\
&=24\times10^7=240{,}000{,}000
\end{aligned}" />

# Counting the digits

The number <InlineMath math="24\times10^7" /> consists of the digits 2 and 4 followed by **seven zeros**, so it has <InlineMath math="2+7=9" /> digits.

The value 7 counts only the trailing zeros. The value 8 treats <InlineMath math="2^3\times3" /> as a single digit. The value 10 is the exponent of 2, and the value 17 adds the two exponents <InlineMath math="10+7" />.

So <InlineMath math="N" /> has **9 digits**.
