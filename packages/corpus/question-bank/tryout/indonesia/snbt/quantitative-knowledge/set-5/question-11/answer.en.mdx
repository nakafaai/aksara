Given:
- <InlineMath math="700" /> students in total.
- <InlineMath math="350" /> students choosing sports.
- <InlineMath math="450" /> students choosing arts.

We want to find the value of <InlineMath math="P" /> (**maximum intersection**) and <InlineMath math="Q" /> (minimum intersection).

#### Maximum intersection
The maximum number of students participating in both occurs if the **smaller set is contained in the larger set** (or as many members of the smaller set as possible are included in the larger set).

<BlockMath math="P = \min(350, 450) = 350 " />

#### Minimum intersection
The minimum number of students participating in both occurs if the **union is as large as possible** (equal to the total universe, which is <InlineMath math="700" />).
Using the Inclusion-Exclusion Principle:

<MathContainer>
  <BlockMath math="Q = (350 + 450) - 700" />
  <BlockMath math="Q = 800 - 700 = 100 " />
</MathContainer>

#### Difference between the bounds

Both bounds are attainable. These **nonoverlapping groups** account for all 700 students in each case.

| Intersection | Sports only | Both | Arts only | Neither |
| --- | --- | --- | --- | --- |
| P | 0 | 350 | 100 | 250 |
| Q | 250 | 100 | 350 | 0 |

<BlockMath math="P - Q = 350 - 100 = 250 " />

Thus, the difference between <InlineMath math="P" /> and <InlineMath math="Q" /> is <InlineMath math="250" /> students.
