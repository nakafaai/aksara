Both expressions under the square roots are perfect squares, so this is really an absolute value equation. The plan: turn the roots into absolute values, use the condition of **infinitely many solutions to find <InlineMath math="a" />**, then find every integer that works and add them up.

# Square roots hiding absolute values

The expressions under the roots factor: <InlineMath math="x^2-2ax+a^2=(x-a)^2" /> and <InlineMath math="x^2+2x+1=(x+1)^2" />. A square root is never negative, so **<InlineMath math="\sqrt{t^2}" /> equals <InlineMath math="|t|" />, not <InlineMath math="t" />**.

# When there are infinitely many solutions

The expression <InlineMath math="|x-a|" /> is the distance from <InlineMath math="x" /> to <InlineMath math="a" /> on the number line, and <InlineMath math="|x+1|" /> is the distance from <InlineMath math="x" /> to <InlineMath math="-1" />. **The sum of those two distances is at least the distance from <InlineMath math="a" /> to <InlineMath math="-1" />**, which is <InlineMath math="|a+1|" />, and every <InlineMath math="x" /> between the two points reaches that smallest value. So there are three possibilities. If <InlineMath math="|a+1|=6" />, every point between them works, so there are infinitely many solutions. If <InlineMath math="|a+1|<6" />, there are only <InlineMath math="2" /> points, one on each side. For example, with <InlineMath math="a=3" /> the only solutions are <InlineMath math="x=-2" /> and <InlineMath math="x=4" />. If <InlineMath math="|a+1|>6" />, there are no solutions.

<BlockMath math="\begin{aligned}
|a+1|&=6\\
a+1=6\quad&\text{or}\quad a+1=-6\\
a=5\quad&\text{or}\quad a=-7
\end{aligned}" />

The number <InlineMath math="a" /> is a natural number, so **the natural-number condition rules out <InlineMath math="a=-7" />**, which leaves <InlineMath math="a=5" />.

# Solving the equation

For <InlineMath math="a=5" />, the equation is <InlineMath math="|x-5|+|x+1|=6" />. Check the three parts of the number line split at <InlineMath math="-1" /> and <InlineMath math="5" />.

<BlockMath math="\begin{aligned}
x<-1:&\quad(5-x)+(-x-1)=6\ \Rightarrow\ x=-1\ \text{(not in this case)}\\
-1\le x\le5:&\quad(5-x)+(x+1)=6\ \Rightarrow\ 6=6\ \text{(always true)}\\
x>5:&\quad(x-5)+(x+1)=6\ \Rightarrow\ x=5\ \text{(not in this case)}
\end{aligned}" />

The solution set is <InlineMath math="-1\le x\le5" />, and **both ends count**.
