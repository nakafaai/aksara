We verify each statement based on the **two functions in the graph**:
Exponential function: <InlineMath math="y = 2^x - 2" />
Linear function: <InlineMath math="y = -2x + 4" />

#### Checking the First Statement

Point <InlineMath math="A" /> is the **vertical axis intercept of the exponential curve** (<InlineMath math="x=0" />).

<BlockMath math="y = 2^0 - 2 = 1 - 2 = -1" />

So, <InlineMath math="A(0, -1)" />. Statement (1) is true.

#### Checking the Second Statement

Point <InlineMath math="B" /> is the **horizontal axis intercept of the exponential curve** (<InlineMath math="y=0" />).

<BlockMath math="\begin{aligned}0&=2^x-2\\2^x&=2\\x&=1\end{aligned}" />

So, <InlineMath math="B(1, 0)" />. Statement (2) is true.

#### Checking the Third Statement

Point <InlineMath math="C" /> is the **horizontal axis intercept of the line** (<InlineMath math="y=0" />).

<BlockMath math="\begin{aligned}0&=-2x+4\\2x&=4\\x&=2\end{aligned}" />

So, <InlineMath math="C(2, 0)" />. Statement (3) is true.

#### Checking the Fourth Statement

Point <InlineMath math="D" /> is the **intersection of both graphs**. The statement claims <InlineMath math="D(2, 2)" />.
If we test coordinate <InlineMath math="(2, 2)" /> into the line equation <InlineMath math="y = -2x + 4" />:

<BlockMath math="y = -2(2) + 4 = -4 + 4 = 0" />

Substituting <InlineMath math="x = 2" /> gives <InlineMath math="y = 0" />. Since the point <InlineMath math="(2, 2)" /> has <InlineMath math="y = 2" />, it does not lie on the line <InlineMath math="y = -2x + 4" />.
Statement (4) is false.
