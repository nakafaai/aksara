Kita periksa kebenaran masing-masing pernyataan berdasarkan fungsi yang diberikan pada grafik:
Fungsi eksponen: <InlineMath math="y = 2^x - 2" />
Fungsi linear: <InlineMath math="y = -2x + 4" />

#### Memeriksa Pernyataan Pertama

Titik <InlineMath math="A" /> adalah titik potong kurva eksponen dengan sumbu <InlineMath math="y" /> (<InlineMath math="x=0" />).

<BlockMath math="y = 2^0 - 2 = 1 - 2 = -1" />

Jadi, <InlineMath math="A(0, -1)" />. Pernyataan <InlineMath math="(1)" /> **BENAR**.

#### Memeriksa Pernyataan Kedua

Titik <InlineMath math="B" /> adalah titik potong kurva eksponen dengan sumbu <InlineMath math="x" /> (<InlineMath math="y=0" />).

<BlockMath math="\begin{aligned}0&=2^x-2\\2^x&=2\\x&=1\end{aligned}" />

Jadi, <InlineMath math="B(1, 0)" />. Pernyataan <InlineMath math="(2)" /> **BENAR**.

#### Memeriksa Pernyataan Ketiga

Titik <InlineMath math="C" /> adalah titik potong garis dengan sumbu <InlineMath math="x" /> (<InlineMath math="y=0" />).

<BlockMath math="\begin{aligned}0&=-2x+4\\2x&=4\\x&=2\end{aligned}" />

Jadi, <InlineMath math="C(2, 0)" />. Pernyataan <InlineMath math="(3)" /> **BENAR**.

#### Memeriksa Pernyataan Keempat

Titik <InlineMath math="D" /> adalah titik potong kedua grafik. Pernyataan menyebutkan <InlineMath math="D(2, 2)" />.
Jika kita uji koordinat <InlineMath math="(2, 2)" /> ke dalam persamaan garis <InlineMath math="y = -2x + 4" />:

<BlockMath math="y = -2(2) + 4 = -4 + 4 = 0" />

Saat <InlineMath math="x = 2" /> dimasukkan, hasilnya <InlineMath math="y = 0" />. Titik <InlineMath math="(2, 2)" /> memiliki <InlineMath math="y = 2" />, sehingga tidak terletak pada garis <InlineMath math="y = -2x + 4" />.
Pernyataan <InlineMath math="(4)" /> **SALAH**.

Kesimpulan: Pernyataan <InlineMath math="(1)" />, <InlineMath math="(2)" />, dan <InlineMath math="(3)" /> benar.
