A "can" statement is proved by one valid data set. A "must" or "can't" statement needs a proof for every data set, or it's broken by **one counterexample**. So translate the conditions first, then check the four statements one at a time.

# Translating the conditions

Sort the data as <InlineMath math="a\le b\le c\le d\le e" />. A mean of <InlineMath math="10" /> means the sum is <InlineMath math="50" />, and a median of <InlineMath math="8" /> means <InlineMath math="c=8" />.

<BlockMath math="a+b+d+e=42,\qquad a\le b\le8\le d\le e" />

A single mode of <InlineMath math="8" /> means **<InlineMath math="8" /> shows up more often than any other value**. If <InlineMath math="8" /> shows up twice, every other value can show up only once. If <InlineMath math="8" /> shows up three times, another value may still show up twice.

# Statement one

For a big range, make the smallest value as small as possible and the largest as large as possible. The data <InlineMath math="1, 2, 8, 8, 31" /> add up to <InlineMath math="50" />, the median is <InlineMath math="8" />, and <InlineMath math="8" /> shows up twice while every other value shows up once. The range is <InlineMath math="31-1=30" />. **One valid example is enough** for a "can" statement, so statement one is true.

# Statement two

Try the data <InlineMath math="8, 8, 8, 13, 13" />. They add up to <InlineMath math="50" />, the median is <InlineMath math="8" />, and <InlineMath math="8" /> shows up three times while <InlineMath math="13" /> shows up only twice, so the only mode is still <InlineMath math="8" />. **A single mode doesn't stop another value from showing up twice**, as long as <InlineMath math="8" /> shows up more often. The range is <InlineMath math="13-8=5" />, which is less than <InlineMath math="6" />. Statement two is false.

# Statement three

Suppose the largest value is <InlineMath math="e\le12" />. Then <InlineMath math="d\le12" />, and <InlineMath math="a" />, <InlineMath math="b" />, and <InlineMath math="c" /> are at most <InlineMath math="8" />.

The sum can't reach <InlineMath math="50" />, so **that assumption is impossible**. The largest value must be at least <InlineMath math="13" />, and statement three is true. The example <InlineMath math="8, 8, 8, 13, 13" /> shows that <InlineMath math="13" /> really can happen.

# Statement four

If <InlineMath math="8" /> shows up exactly twice, all the other values must be different. There are two ways to place the two eights.

If <InlineMath math="b=c=8" />, then <InlineMath math="a\le7" />, <InlineMath math="9\le d<e" />, and <InlineMath math="d+e=34-a" />. Since <InlineMath math="d<e" />, the largest value is more than half of their sum, so <InlineMath math="e\ge\frac{35-a}{2}" />.

<BlockMath math="e-a\ge\frac{35-a}{2}-a=\frac{35-3a}{2}\ge\frac{35-21}{2}=7" />

If <InlineMath math="c=d=8" />, then <InlineMath math="a<b\le7" /> and <InlineMath math="e=34-a-b\ge34-6-7=21" />, so <InlineMath math="e-a\ge21-6=15" />. So statement one is true, statement two is false, statement three is true, and statement four is true.
