A four-digit number greater than 4,000 with distinct digits must start with 4, 5, or 6, because 4,000 itself repeats the digit 0. An even number must end in 0, 2, 4, or 6. The first and last digits **affect each other** when the first digit is even, so count case by case on the first digit.

# Counting by cases

Once the first and last digits are chosen, 5 digits remain for the two middle positions, which gives <InlineMath math="5\times4=20" /> arrangements.

| First digit | Possible last digits | Number of choices | Numbers formed |
| :---: | :---: | :---: | :---: |
| 4 | 0, 2, 6 | 3 | <InlineMath math="3\times20=60" /> |
| 5 | 0, 2, 4, 6 | 4 | <InlineMath math="4\times20=80" /> |
| 6 | 0, 2, 4 | 3 | <InlineMath math="3\times20=60" /> |

The digits 4 and 6 **cannot be used again** in the last position once they are the first digit.

<BlockMath math="60+80+60=200" />

The value 240 allows four last digits in every case, although a first digit of 4 or 6 already uses one even digit. The value 180 allows three last digits in every case, including when the first digit is 5. The value 140 drops the case with first digit 4. The value 160 counts odd numbers instead of even ones.

So **200** numbers can be formed.
