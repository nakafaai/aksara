# Reflecting point B

The reflection of <InlineMath math="B(7,4)" /> in the <InlineMath math="x" />-axis is <InlineMath math="B'(7,-4)" />. Every point <InlineMath math="P" /> on the <InlineMath math="x" />-axis is equally far from <InlineMath math="B" /> and from <InlineMath math="B'" />, so <InlineMath math="AP+PB=AP+PB'" />. A path from <InlineMath math="A" /> to <InlineMath math="B'" /> is **shortest when it is straight**, and that straight line does cross the <InlineMath math="x" />-axis because <InlineMath math="A" /> is above the axis and <InlineMath math="B'" /> is below it.

<BlockMath math="AP+PB\ge AB'=\sqrt{(7-1)^2+(-4-2)^2}=\sqrt{72}=6\sqrt2" />

# Finding point P

The line <InlineMath math="AB'" /> has gradient <InlineMath math="\frac{-4-2}{7-1}=-1" />, so its equation is <InlineMath math="y-2=-(x-1)" />. It meets the <InlineMath math="x" />-axis at <InlineMath math="P(3,0)" />. **Check the value**: <InlineMath math="AP=\sqrt{4+4}=2\sqrt2" /> and <InlineMath math="PB=\sqrt{16+16}=4\sqrt2" />, which add up to <InlineMath math="6\sqrt2" />.

The value <InlineMath math="2\sqrt{10}" /> is the direct distance <InlineMath math="AB" />, which never touches the <InlineMath math="x" />-axis. The value <InlineMath math="5+\sqrt{13}" /> chooses <InlineMath math="P(4,0)" /> below the midpoint of the <InlineMath math="x" />-coordinates. The value <InlineMath math="2+2\sqrt{13}" /> chooses <InlineMath math="P" /> directly below <InlineMath math="A" />, and <InlineMath math="4+2\sqrt{10}" /> chooses <InlineMath math="P" /> directly below <InlineMath math="B" />. All three are longer than <InlineMath math="6\sqrt2" />.

So the smallest value of <InlineMath math="AP+PB" /> is <InlineMath math="6\sqrt2" />.
