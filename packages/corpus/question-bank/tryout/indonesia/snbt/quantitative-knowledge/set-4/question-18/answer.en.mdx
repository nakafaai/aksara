The students are different and named, so the books can be handed out **one student after another**. The order of books in one student's hands does not matter, so each step is a combination.

# Choosing books for each student

Rani chooses 2 books from 6, Sena chooses 2 of the remaining 4, and Tio receives the last 2. **The three choices are multiplied** because they happen in sequence.

<BlockMath math="\binom62\cdot\binom42\cdot\binom22=15\cdot6\cdot1=90" />

# Checking the other options

The value 15 divides again by <InlineMath math="3!" />, as if the three students were indistinguishable. The value 540 multiplies by <InlineMath math="3!" /> instead, although the students are already distinguished from the first step, so **every distribution is counted six times**. The value 360 computes <InlineMath math="\frac{6!}{2!}" />, which removes the order of the books for only one student. The value 729 is <InlineMath math="3^6" />, which lets a student receive any number of books.

So there are **90** ways to distribute the books.
