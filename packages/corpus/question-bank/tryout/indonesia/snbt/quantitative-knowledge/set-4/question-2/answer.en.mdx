Each percentage change is taken from the price **just before that change**, not from the original price. That is why successive changes are multiplied, not added.

# The factors of the successive changes

Let the original price be <InlineMath math="H" />. A 20% rise means **multiplying by 1.2**, and a 25% drop means multiplying by 0.75.

<BlockMath math="H\times1.2\times0.75=0.9H" />

The final price is 90% of the original price.

# The increase needed

An increase of <InlineMath math="k\%" /> must bring <InlineMath math="0.9H" /> back to <InlineMath math="H" />. This percentage is **taken from <InlineMath math="0.9H" />**, so the divisor is 0.9.

<BlockMath math="\begin{aligned}
0.9H\left(1+\frac{k}{100}\right)&=H\\
1+\frac{k}{100}&=\frac{10}{9}\\
k&=\frac{100}{9}=11\tfrac19
\end{aligned}" />

The value 10% assumes that a 10% increase cancels a 10% decrease, although 10% of the smaller price is not enough. The value 5% adds the percentages, <InlineMath math="20-25=-5" />. The value 25% only reverses the last decrease, and the value 20% only reverses the first increase.

So the final price must be raised by <InlineMath math="11\tfrac19\%" />.
