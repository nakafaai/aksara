# The tangent at that point

A line through a point on the circle meets the circle at two points, except the tangent at that point, which touches it only once. The tangent is **perpendicular to the radius** at the point of contact. The radius from <InlineMath math="M(2,-3)" /> to <InlineMath math="(5,1)" /> has slope <InlineMath math="\frac{1-(-3)}{5-2}=\frac43" />, so the tangent has slope <InlineMath math="-\frac34" />, because perpendicular slopes multiply to <InlineMath math="-1" />.

The distance equals the radius, so this line really only touches the circle.
