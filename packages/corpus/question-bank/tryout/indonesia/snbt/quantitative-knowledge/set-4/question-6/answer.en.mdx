You're looking for every integer <InlineMath math="m" /> that keeps <InlineMath math="f(x)=x^2-2mx+m+6" /> positive, but **only for <InlineMath math="x\ge0" />, not for all real numbers**. # Where the vertex is

Complete the square so the vertex shows.

<BlockMath math="f(x)=x^2-2mx+m+6=(x-m)^2-m^2+m+6" />

This parabola opens upward and **its lowest point is at <InlineMath math="x=m" />**. The smallest value of <InlineMath math="f" /> on the region <InlineMath math="x\ge0" /> depends on whether <InlineMath math="x=m" /> lies inside that region.

# Vertex on the left

If <InlineMath math="m\le0" />, the vertex is left of the region or exactly at <InlineMath math="x=0" />. For <InlineMath math="x\ge0" /> the parabola keeps rising, so **its smallest value is <InlineMath math="f(0)" />**.

<BlockMath math="\begin{aligned}
f(0)=m+6&>0\\
m&>-6
\end{aligned}" />

The integers with <InlineMath math="-6<m\le0" /> are <InlineMath math="-5, -4, -3, -2, -1, 0" />. The value <InlineMath math="m=-6" /> doesn't count, since <InlineMath math="f(0)=0" /> and the inequality is strict.

# Vertex on the right

If <InlineMath math="m>0" />, the vertex is inside the region, so **the smallest value is the value at the vertex**.

<BlockMath math="\begin{aligned}
f(m)=-m^2+m+6&>0\\
m^2-m-6&<0\\
(m-3)(m+2)&<0\\
-2<m&<3
\end{aligned}" />

Together with <InlineMath math="m>0" />, the integers are <InlineMath math="1" /> and <InlineMath math="2" />. The value <InlineMath math="m=3" /> doesn't count, because <InlineMath math="f(3)=9-18+9=0" />.

# Adding up all the values

**The two cases together** give <InlineMath math="m=-5, -4, \ldots, 2" />.

<BlockMath math="(-5)+(-4)+(-3)+(-2)+(-1)+0+1+2=-12" />

Check one value from each case. For <InlineMath math="m=-5" />, <InlineMath math="f(x)=x^2+10x+1" />, and every term is positive when <InlineMath math="x\ge0" />. For <InlineMath math="m=2" />, <InlineMath math="f(x)=(x-2)^2+4>0" />.
