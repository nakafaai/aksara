Squaring both sides is safe only when **neither side is negative**. So first find the conditions under which the inequality makes sense, and only then square.

# Conditions before squaring

The root is defined when <InlineMath math="x+3\ge0" />, that is, <InlineMath math="x\ge-3" />. The left side is never negative, so the right side must be **positive** for the left side to be smaller.

<BlockMath math="x-3>0\quad\Rightarrow\quad x>3" />

The condition <InlineMath math="x>3" /> already includes <InlineMath math="x\ge-3" />.

# Squaring both sides

For <InlineMath math="x>3" /> both sides are positive, so **squaring keeps the direction of the inequality**.

<BlockMath math="\begin{aligned}
x+3&<x^2-6x+9\\
0&<x^2-7x+6\\
0&<(x-1)(x-6)
\end{aligned}" />

The product is positive for <InlineMath math="x<1" /> or <InlineMath math="x>6" />. Its intersection with <InlineMath math="x>3" /> is <InlineMath math="x>6" />. Check <InlineMath math="x=7" />: <InlineMath math="\sqrt{10}\approx3.16<4" />, while <InlineMath math="x=6" /> gives the false statement <InlineMath math="3<3" />.

The set <InlineMath math="x<1" /> or <InlineMath math="x>6" /> squares without any condition. The set containing <InlineMath math="-3\le x<1" /> uses only the root condition, although the right side is negative there. The set <InlineMath math="1<x<6" /> flips the sign, and the set <InlineMath math="x\ge3" /> stops at the condition on the right side.

So the solution set is <InlineMath math="\{x\mid x>6\}" />.
