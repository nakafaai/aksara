An upward parabola has its minimum at the vertex, **but only if the vertex lies in the interval**. So first locate the vertex.

# The position of the vertex

<BlockMath math="f(x)=x^2-6x+13=(x-3)^2+4" />

The vertex is at <InlineMath math="x=3" /> with value 4. The point <InlineMath math="x=3" /> **lies outside the interval** <InlineMath math="4\le x\le7" />, so the value 4 is not reached there.

# Values on the interval

To the right of the vertex, the parabola keeps rising. On <InlineMath math="4\le x\le7" /> the smallest value is at the left end and the largest at the right end.

<BlockMath math="\begin{aligned}
f(4)&=(4-3)^2+4=5\\
f(7)&=(7-3)^2+4=20
\end{aligned}" />

The minimum value is 5, reached at <InlineMath math="x=4" />.

The value 4 is the value at the vertex, which lies outside the interval. The value 20 is the maximum on the interval. The value 8 is <InlineMath math="f(5)" />, the value in the middle of the interval, and the value 13 is the constant term, which also equals <InlineMath math="f(6)" />.

So the minimum value of the function on the interval is **5**.
