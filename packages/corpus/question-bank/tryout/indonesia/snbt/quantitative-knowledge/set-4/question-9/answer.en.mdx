The <InlineMath math="n" />th term of a geometric sequence is <InlineMath math="u_n=ar^{n-1}" />. From the first and fourth terms, **the ratio can be found first**, and every other statement follows.

# Finding the ratio

<BlockMath math="\begin{aligned}
u_4&=ar^3=48r^3=6\\
r^3&=\tfrac18\\
r&=\tfrac12
\end{aligned}" />

The only real number whose cube is <InlineMath math="\tfrac18" /> is <InlineMath math="\tfrac12" />, so **the ratio is unique**. The first statement is true.

# Terms and sums

<BlockMath math="\begin{aligned}
u_6&=48\left(\tfrac12\right)^5=\tfrac{48}{32}=1.5\\
S_5&=\frac{48\left(1-\left(\tfrac12\right)^5\right)}{1-\tfrac12}=96\cdot\tfrac{31}{32}=93\\
S_\infty&=\frac{48}{1-\tfrac12}=96
\end{aligned}" />

The third statement is true. The sixth term is 1.5, not 3, so the fourth statement is false. The number 3 is the fifth term. The infinite sum exists because <InlineMath math="\lvert r\rvert<1" />, and its value is 96. The number 64 appears when the ratio is taken as <InlineMath math="\tfrac14" />, so **the second statement is false**.

So the first statement is **true**, the second is **false**, the third is **true**, and the fourth is **false**.
