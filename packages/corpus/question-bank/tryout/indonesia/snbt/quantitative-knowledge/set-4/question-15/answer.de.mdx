Zunächst vereinfachen wir <InlineMath math="P" /> und <InlineMath math="Q" />.

#### Vereinfachung der ersten Größe

Wir verwenden <InlineMath math="a^2 - b^2 = (a - b)(a + b)" /> und <InlineMath math="16^x = (4^x)^2" />.

<MathContainer>
  <BlockMath math="P = \frac{1 - 16^x}{1 - 4^x} = \frac{1 - (4^x)^2}{1 - 4^x}" />
  <BlockMath math="P = \frac{(1 - 4^x)(1 + 4^x)}{1 - 4^x}" />
  <BlockMath math="P = 1 + 4^x" />
</MathContainer>

#### Vereinfachung der zweiten Größe

Ebenso gilt <InlineMath math="16^{-x} = (4^{-x})^2" />.

<MathContainer>
  <BlockMath math="Q = \frac{1 - 16^{-x}}{1 - 4^{-x}} = \frac{1 - (4^{-x})^2}{1 - 4^{-x}}" />
  <BlockMath math="Q = \frac{(1 - 4^{-x})(1 + 4^{-x})}{1 - 4^{-x}}" />
  <BlockMath math="Q = 1 + 4^{-x}" />
</MathContainer>

#### Analyse der ersten Größe

Aus <InlineMath math="1 < x < 2" /> folgt:

<MathContainer>
  <BlockMath math="4^1 < 4^x < 4^2" />
  <BlockMath math="4 < 4^x < 16" />
  <BlockMath math="1 + 4 < 1 + 4^x < 1 + 16" />
  <BlockMath math="5 < P < 17" />
</MathContainer>

#### Analyse der zweiten Größe

Multiplizieren wir <InlineMath math="1 < x < 2" /> mit <InlineMath math="-1" />, kehrt sich die Richtung der Ungleichungen um.

<MathContainer>
  <BlockMath math="-2 < -x < -1" />
  <BlockMath math="4^{-2} < 4^{-x} < 4^{-1}" />
  <BlockMath math="\frac{1}{16} < 4^{-x} < \frac{1}{4}" />
  <BlockMath math="1 + \frac{1}{16} < 1 + 4^{-x} < 1 + \frac{1}{4}" />
  <BlockMath math="\frac{17}{16} < Q < \frac{5}{4}" />
</MathContainer>

#### Vergleich der Größen

Aus den obigen Ergebnissen erhalten wir:
*   <InlineMath math="P > 5" />
*   <InlineMath math="Q < \frac{5}{4} = 1{,}25" />

Damit ist <InlineMath math="P" /> im gesamten angegebenen Bereich von <InlineMath math="x" /> größer als <InlineMath math="Q" />.

Also, <InlineMath math="P > Q" />.
