A perfect square has an even exponent on every prime, and a perfect cube has exponents that are multiples of 3. So write <InlineMath math="n=2^a\,3^b\,5^c" /> and decide **each exponent separately**. Any other prime factor would only make <InlineMath math="n" /> larger.

# The conditions on each exponent

With <InlineMath math="20=2^2\cdot5" /> and <InlineMath math="12=2^2\cdot3" />:

<BlockMath math="\begin{aligned}
20n&=2^{a+2}\,3^{b}\,5^{c+1}\\
12n&=2^{a+2}\,3^{b+1}\,5^{c}
\end{aligned}" />

| Prime | Square condition from <InlineMath math="20n" /> | Cube condition from <InlineMath math="12n" /> | Smallest exponent |
| :---: | :---: | :---: | :---: |
| 2 | <InlineMath math="a+2" /> even | <InlineMath math="a+2" /> a multiple of 3 | <InlineMath math="a=4" /> |
| 3 | <InlineMath math="b" /> even | <InlineMath math="b+1" /> a multiple of 3 | <InlineMath math="b=2" /> |
| 5 | <InlineMath math="c+1" /> even | <InlineMath math="c" /> a multiple of 3 | <InlineMath math="c=3" /> |

Every exponent must **satisfy both conditions at once**. For example, <InlineMath math="a" /> is even and <InlineMath math="a+2" /> is a multiple of 3, so its smallest value is 4.

# Computing and checking

<BlockMath math="n=2^4\cdot3^2\cdot5^3=16\cdot9\cdot125=18{,}000" />

Check: <InlineMath math="20n=360{,}000=600^2" /> and <InlineMath math="12n=216{,}000=60^3" />.

The value 5 satisfies only the square condition, since <InlineMath math="20\cdot5=100" />. The value 18 satisfies only the cube condition, since <InlineMath math="12\cdot18=216" />. The value 90 is the least common multiple of the two, but <InlineMath math="20\cdot90=1800" /> is not a perfect square. The value 720 satisfies the square condition, but <InlineMath math="12\cdot720" /> contains only <InlineMath math="5^1" />.

So the smallest <InlineMath math="n" /> is **18,000**.
