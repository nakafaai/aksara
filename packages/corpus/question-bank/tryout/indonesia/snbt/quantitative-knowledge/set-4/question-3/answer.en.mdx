A quadratic equation usually has two roots, so check **both values of <InlineMath math="x" />**, not only the positive one.

<BlockMath math="x^2-2x-3=(x-3)(x+1)=0\quad\Rightarrow\quad x=3\ \text{or}\ x=-1" />

# Comparing for each root

| <InlineMath math="x" /> | <InlineMath math="P=x^3" /> | <InlineMath math="Q=9x" /> | Relation |
| :---: | :---: | :---: | :---: |
| 3 | 27 | 27 | <InlineMath math="P=Q" /> |
| <InlineMath math="-1" /> | <InlineMath math="-1" /> | <InlineMath math="-9" /> | <InlineMath math="P>Q" /> |

Both roots are valid, but **the relations differ**. A student who uses only <InlineMath math="x=3" /> would choose <InlineMath math="P=Q" />.

# The algebraic route

Since <InlineMath math="x^2=2x+3" />, we have <InlineMath math="x^3=x\cdot x^2=2x^2+3x=2(2x+3)+3x=7x+6" />. So <InlineMath math="P-Q=7x+6-9x=6-2x" />, which is 0 for <InlineMath math="x=3" /> and 8 for <InlineMath math="x=-1" />. The sign of the difference **depends on which root is chosen**.

So **the information given is not enough** to decide the relation between <InlineMath math="P" /> and <InlineMath math="Q" />.
