# The first and fourth statements

For <InlineMath math="f(x)=4" />, the inside of the absolute value has two options.

<BlockMath math="\begin{aligned}
x^2-4=4&\quad\Rightarrow\quad x^2=8\quad\Rightarrow\quad x=\pm2\sqrt2\\
x^2-4=-4&\quad\Rightarrow\quad x^2=0\quad\Rightarrow\quad x=0
\end{aligned}" />

There are exactly <InlineMath math="3" /> solutions, because **the line <InlineMath math="y=4" /> only touches the small peak at one point**. The first statement is true.

For the fourth statement, the table shows that four solutions happen only when <InlineMath math="0<k<4" />. The integers there are <InlineMath math="1, 2, 3" />, so there are exactly <InlineMath math="3" />. The values <InlineMath math="k=0" /> and <InlineMath math="k=4" /> don't count, since they give <InlineMath math="2" /> and <InlineMath math="3" /> solutions. The fourth statement is true.

# The second statement

The left side <InlineMath math="f(x)" /> is never negative, so **the right side <InlineMath math="x+2" /> can't be negative either**, which means <InlineMath math="x\ge-2" />. On that region <InlineMath math="|x+2|=x+2" />, so you can factor instead of dividing.

<BlockMath math="\begin{aligned}
|x-2|\cdot|x+2|&=x+2\\
(x+2)|x-2|-(x+2)&=0\\
(x+2)\bigl(|x-2|-1\bigr)&=0
\end{aligned}" />

The first factor gives <InlineMath math="x=-2" />. The second gives <InlineMath math="|x-2|=1" />, so <InlineMath math="x=1" /> or <InlineMath math="x=3" />. Check them: <InlineMath math="f(-2)=0=-2+2" />, <InlineMath math="f(1)=3=1+2" />, and <InlineMath math="f(3)=5=3+2" />. There are <InlineMath math="3" /> solutions, so the second statement is false. The count <InlineMath math="2" /> comes from dividing both sides by <InlineMath math="x+2" />, which loses the root <InlineMath math="x=-2" />.

# The third statement

Let <InlineMath math="y=f(x)" />. The equation becomes <InlineMath math="\left|y^2-4\right|=2" />, so <InlineMath math="y^2=6" /> or <InlineMath math="y^2=2" />. Since **<InlineMath math="y=f(x)" /> is never negative**, only <InlineMath math="y=\sqrt6" /> and <InlineMath math="y=\sqrt2" /> are allowed.

Both values lie between <InlineMath math="0" /> and <InlineMath math="4" />, because <InlineMath math="\sqrt6<\sqrt{16}=4" />. By the table, each one gives <InlineMath math="4" /> solutions: <InlineMath math="x^2=4\pm\sqrt6" /> and <InlineMath math="x^2=4\pm\sqrt2" />. Those four values of <InlineMath math="x^2" /> are positive and different, so there are <InlineMath math="8" /> solutions in total. The third statement is true. If you also used the negative values <InlineMath math="y=-\sqrt6" /> and <InlineMath math="y=-\sqrt2" />, you'd think there were more solutions, but <InlineMath math="f(x)" /> can't be negative.

So the first statement is true, the second is false, the third is true, and the fourth is true.
