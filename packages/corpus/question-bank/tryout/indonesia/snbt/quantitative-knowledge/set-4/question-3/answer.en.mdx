Because every worker has the same constant rate, measure the work in **worker-days**: one worker working for one day completes one unit.

| Stage | Calculation | Work in worker-days |
| --- | --- | --- |
| Entire project | <InlineMath math="12\cdot16" /> | 192 |
| First four days | <InlineMath math="12\cdot4" /> | 48 |
| Remaining work | <InlineMath math="192-48" /> | 144 |

After four workers stop, <InlineMath math="12-4=8" /> workers remain. They must complete 144 worker-days. If <InlineMath math="w" /> is the number of days still needed, then:

<BlockMath math="\begin{aligned}8w&=144\\w&=144/8\\w&=18\end{aligned}" />

The question asks for **time from the first day**, so include the four days already worked.

<BlockMath math="4+18=22" />
