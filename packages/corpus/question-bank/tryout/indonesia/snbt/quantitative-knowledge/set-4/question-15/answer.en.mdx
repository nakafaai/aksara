We will simplify <InlineMath math="P" /> and <InlineMath math="Q" /> first.

Since <InlineMath math="1<x<2" />, **neither denominator is zero**, so the common factors may be cancelled.

# Simplifying the First Quantity

Use the **difference of squares identity** <InlineMath math="a^2 - b^2 = (a - b)(a + b)" />.
The power can be written as <InlineMath math="16^x = (4^x)^2" />.

<BlockMath math="\begin{aligned}
P&=\frac{1-16^{x}}{1-4^{x}} \\
&=\frac{1-(4^{x})^2}{1-4^{x}} \\
&=\frac{(1-4^{x})(1+4^{x})}{1-4^{x}} \\
&=1+4^{x}
\end{aligned}" />

# Simplifying the Second Quantity

Use the **same identity** for the second expression, <InlineMath math="16^{-x} = (4^{-x})^2" />.

<BlockMath math="\begin{aligned}
Q&=\frac{1-16^{-x}}{1-4^{-x}} \\
&=\frac{1-(4^{-x})^2}{1-4^{-x}} \\
&=\frac{(1-4^{-x})(1+4^{-x})}{1-4^{-x}} \\
&=1+4^{-x}
\end{aligned}" />

# Analyzing the First Quantity

The **exponential function with base four is increasing**, so <InlineMath math="1<x<2" /> gives:

<BlockMath math="4^1 < 4^x < 4^2" />

<BlockMath math="4 < 4^x < 16" />

<BlockMath math="1 + 4 < 1 + 4^x < 1 + 16" />

<BlockMath math="5 < P < 17" />

# Analyzing the Second Quantity

Given <InlineMath math="1 < x < 2" />. Multiply by <InlineMath math="-1" /> so the **inequality signs reverse**.

<BlockMath math="-2 < -x < -1" />

<BlockMath math="4^{-2} < 4^{-x} < 4^{-1}" />

<BlockMath math="\frac{1}{16} < 4^{-x} < \frac{1}{4}" />

<BlockMath math="1 + \frac{1}{16} < 1 + 4^{-x} < 1 + \frac{1}{4}" />

<BlockMath math="\frac{17}{16} < Q < \frac{5}{4}" />

# Comparing the Quantities

From the results above, we get:
*   <InlineMath math="P > 5" />
*   <InlineMath math="Q < \frac{5}{4} = 1.25" />

The **lower bound of the first quantity**, <InlineMath math="P" />, exceeds the upper bound for <InlineMath math="Q" /> throughout the given range.

So, <InlineMath math="P > Q" />.
