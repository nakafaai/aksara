The two x-intercepts give **the factored form <InlineMath math="f(x)=a(x+1)(x-5)" />**. The y-intercept fixes the value of <InlineMath math="a" />.

# Finding the function

<BlockMath math="\begin{aligned}
f(0)=a(1)(-5)&=10\;\Longrightarrow\; a=-2\\
f(x)&=-2(x+1)(x-5)=-2x^2+8x+10
\end{aligned}" />

Since <InlineMath math="a<0" />, the graph **opens downward** and has a maximum value.

# Axis of symmetry and maximum value

The axis of symmetry lies **midway between the two roots**, at <InlineMath math="x=\tfrac{-1+5}{2}=2" />, not at <InlineMath math="x=3" />. The second statement is false.

<BlockMath math="f(2)=-2(3)(-3)=18" />

The maximum value is 18, so the first statement is true.

# Sign of the function and the value at one

A downward parabola is positive **only between its two roots**, on <InlineMath math="-1<x<5" />. For <InlineMath math="5<x<6" /> it is negative, for example <InlineMath math="f(5.5)=-2(6.5)(0.5)=-6.5" />. The third statement is false.

The sum <InlineMath math="a+b+c" /> equals <InlineMath math="f(1)" />.

<BlockMath math="a+b+c=-2+8+10=16" />

The fourth statement is true.

So the first statement is **true**, the second is **false**, the third is **false**, and the fourth is **true**.
