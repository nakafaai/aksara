Ada dua jalan: menghitung data baru dari awal, atau memakai **sifat simpangan baku terhadap perkalian dan penjumlahan**. Jalan kedua lebih cepat, tetapi kita hitung dulu simpangan baku data awal.

# Simpangan baku data awal

Rata-rata data awal adalah 6. **Simpangan setiap data terhadap rata-rata** adalah <InlineMath math="-4,-2,0,2,4" />.

<BlockMath math="\begin{aligned}
s^2&=\frac{16+4+0+4+16}{5}=\frac{40}{5}=8\\
s&=\sqrt8=2\sqrt2
\end{aligned}" />

# Pengaruh transformasi

Menambah 5 menggeser setiap data dan rata-ratanya sejauh 5, jadi **simpangan terhadap rata-rata tidak berubah**. Mengalikan dengan 3 membuat setiap simpangan 3 kali lebih besar, sehingga simpangan bakunya juga dikalikan 3.

<BlockMath math="s_{\text{baru}}=3\cdot2\sqrt2=6\sqrt2" />

Pemeriksaan: data baru 11, 17, 23, 29, 35 memiliki rata-rata 23 dan simpangan <InlineMath math="-12,-6,0,6,12" />, sehingga variansnya <InlineMath math="\tfrac{360}{5}=72" /> dan simpangan bakunya <InlineMath math="\sqrt{72}=6\sqrt2" />.

Nilai <InlineMath math="6\sqrt2+5" /> ikut menambahkan 5, padahal pergeseran tidak mengubah sebaran. Nilai <InlineMath math="2\sqrt2" /> mengabaikan perkalian, nilai <InlineMath math="18\sqrt2" /> mengalikan dengan 9, dan nilai 72 adalah varians, bukan simpangan baku.

Jadi, simpangan baku data yang baru adalah **<InlineMath math="6\sqrt2" />**.
