Sebuah robot bergerak pada titik-titik berkoordinat bulat dalam ruang. Pada setiap langkah, robot menambah tepat satu koordinatnya, yaitu <InlineMath math="x" />, <InlineMath math="y" />, atau <InlineMath math="z" />, sebesar <InlineMath math="1" />.

Robot berangkat dari titik <InlineMath math="O(0,0,0)" /> menuju titik <InlineMath math="T(3,3,2)" />. Robot wajib melewati titik <InlineMath math="A(1,2,1)" />, tetapi tidak boleh melewati titik <InlineMath math="B(0,1,1)" /> maupun titik <InlineMath math="C(2,3,1)" />.
