Substitusikan <InlineMath math="f(x) = x + 1" /> langsung ke persamaan yang diberikan:

<MathContainer>
  <BlockMath math="(x+1)^2 = 5(x+1) - 4" />
  <BlockMath math="x^2 + 2x + 1 = 5x + 1" />
  <BlockMath math="x^2 - 3x = 0" />
  <BlockMath math="x(x-3) = 0" />
</MathContainer>

Dengan demikian, kedua penyelesaiannya adalah

<MathContainer>
  <BlockMath math="x_1 = 0 \quad \text{dan} \quad x_2 = 3" />
</MathContainer>

Jumlah keduanya adalah

<MathContainer>
  <BlockMath math="x_1 + x_2 = 0 + 3 = 3" />
</MathContainer>

Jadi, <InlineMath math="x_1 + x_2 = 3" />.
