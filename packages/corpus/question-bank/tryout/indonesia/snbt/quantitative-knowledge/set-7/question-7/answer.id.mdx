Substitusikan <InlineMath math="f(x) = x + 1" /> melalui **substitusi langsung** ke persamaan yang diberikan:

<MathContainer>
  <BlockMath math="(x+1)^2 = 5(x+1) - 4" />
  <BlockMath math="x^2 + 2x + 1 = 5x + 1" />
  <BlockMath math="x^2 - 3x = 0" />
  <BlockMath math="x(x-3) = 0" />
</MathContainer>

Menurut **sifat hasil kali nol**, faktor <InlineMath math="x" /> atau <InlineMath math="x-3" /> harus nol. Jadi, kedua penyelesaian persamaan adalah

<BlockMath math="x_1 = 0 \quad \text{dan} \quad x_2 = 3" />

Jumlah keduanya adalah

<BlockMath math="x_1 + x_2 = 0 + 3 = 3" />

Jadi, <InlineMath math="x_1 + x_2 = 3" />.
