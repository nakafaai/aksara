Once four different digits are chosen, **there is exactly one increasing arrangement and exactly one decreasing arrangement**. So each kind is counted by choosing a set of four digits, with special care for the digit 0.

# Increasing arrangements

In an increasing arrangement, the smallest digit comes first. If 0 were chosen, the number would start with 0 and **would not be a four-digit number**. So the four digits come from 1 to 9.

<BlockMath math="\binom94=\frac{9\cdot8\cdot7\cdot6}{4\cdot3\cdot2\cdot1}=126" />

# Decreasing arrangements

In a decreasing arrangement, the largest digit comes first, so 0 always ends up last when it is chosen. **The digit 0 is allowed**, so the four digits come from 0 to 9.

<BlockMath math="\binom{10}{4}=\frac{10\cdot9\cdot8\cdot7}{4\cdot3\cdot2\cdot1}=210" />

No number is both increasing and decreasing, so the two counts are added: <InlineMath math="126+210=336" />.

The values 126 and 210 each count only one kind of arrangement. The value 252 forbids 0 in both kinds, and 420 allows 0 in both kinds.

So the number of interesting four-digit numbers is **336**.
