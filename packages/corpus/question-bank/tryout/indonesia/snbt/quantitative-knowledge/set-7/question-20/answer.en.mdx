The sign of a product is decided by the sign of each factor, so the first step is to factor everything. Here's the plan: factor, watch out for **the factor that is a square**, build a sign table, then count the integers that work between <InlineMath math="-10" /> and <InlineMath math="10" />.

# Factoring each part

The first part has roots <InlineMath math="1" /> and <InlineMath math="4" />, and **the second part is a perfect square**.

<BlockMath math="\begin{aligned}
x^2-5x+4&=(x-1)(x-4)\\
x^2-14x+49&=(x-7)^2
\end{aligned}" />

So the inequality becomes <InlineMath math="(x-1)(x-4)(x-7)^2(x+3)\le0" />.

# What the square factor does

The factor <InlineMath math="(x-7)^2" /> is never negative. For <InlineMath math="x\ne7" /> it's positive, so it **doesn't change the sign of the product**, and the inequality is the same as <InlineMath math="(x-1)(x-4)(x+3)\le0" />. At <InlineMath math="x=7" /> that factor is zero, so the whole product equals <InlineMath math="0" />, and <InlineMath math="x=7" /> **counts as a solution** because the sign is <InlineMath math="\le" />.

# A sign table for three factors

The three factors are zero at <InlineMath math="-3" />, <InlineMath math="1" />, and <InlineMath math="4" />. **A sign can only change at a zero**, so one test point in each interval is enough to work out the signs.

The product is negative or zero for <InlineMath math="x\le-3" /> and for <InlineMath math="1\le x\le4" />. Add the isolated point <InlineMath math="x=7" />, and the solution set is <InlineMath math="x\le-3" />, <InlineMath math="1\le x\le4" />, or <InlineMath math="x=7" />.

# Counting the integers

Restrict to <InlineMath math="-10\le x\le10" /> and count each part, **including both ends** because the sign is <InlineMath math="\le" />.

<BlockMath math="\begin{aligned}
-10\le x\le-3&: \ 8 \text{ integers}\\
1\le x\le4&: \ 4 \text{ integers}\\
x=7&: \ 1 \text{ integer}\\
\text{total}&: \ 8+4+1=13
\end{aligned}" />

A check at a few points in the original form: at <InlineMath math="x=7" /> the value is <InlineMath math="(18)(0)(10)=0" />, so it works. At <InlineMath math="x=6" /> the value is <InlineMath math="(10)(1)(9)=90>0" />, and at <InlineMath math="x=0" /> it's <InlineMath math="(4)(49)(3)=588>0" />, so neither works.

If you divide both sides by <InlineMath math="(x-7)^2" /> without checking <InlineMath math="x=7" />, you lose one solution and get <InlineMath math="12" />. If you treat <InlineMath math="(x-7)^2" /> like an ordinary factor that changes sign, you get <InlineMath math="-3\le x\le1" /> or <InlineMath math="4\le x\le7" />, which is <InlineMath math="9" /> integers.

So the number of integers <InlineMath math="x" /> with <InlineMath math="-10\le x\le10" /> that satisfy the inequality is <InlineMath math="13" />.
