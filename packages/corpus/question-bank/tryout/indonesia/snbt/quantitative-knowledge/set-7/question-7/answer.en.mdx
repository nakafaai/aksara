Let one pencil cost <InlineMath math="p" /> rupiah and one exercise book <InlineMath math="b" /> rupiah. There are two unknowns, so we need **two genuinely different equations**.

# Each statement alone

Statement (1) gives <InlineMath math="2p+3b=27{,}000" />. One equation in two unknowns has many solutions, for example <InlineMath math="p=3{,}000" /> with <InlineMath math="b=7{,}000" />, or <InlineMath math="p=6{,}000" /> with <InlineMath math="b=5{,}000" />. The price of a book is **not yet unique**, so statement (1) alone is not sufficient.

Statement (2) gives <InlineMath math="4p+6b=54{,}000" />, and the same reason makes it insufficient.

# Both statements together

Divide the second equation by 2.

<BlockMath math="4p+6b=54{,}000\;\Longleftrightarrow\;2p+3b=27{,}000" />

The second equation is **exactly the first equation**, only multiplied by 2. Both example pairs above still satisfy both statements, so the book can still cost Rp7,000 or Rp5,000.

So **statements (1) and (2) together are not sufficient** to answer the question.
