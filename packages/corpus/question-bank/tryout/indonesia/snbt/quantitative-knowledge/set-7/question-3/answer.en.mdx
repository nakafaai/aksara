Both numbers are small differences between a root and a nearby integer, so rough decimal estimates can mislead. The reliable method is **multiplying by the conjugate** so that each difference becomes a fraction.

# Conjugate form

<BlockMath math="\begin{aligned}
P&=\sqrt{17}-4=\frac{(\sqrt{17}-4)(\sqrt{17}+4)}{\sqrt{17}+4}=\frac{17-16}{\sqrt{17}+4}=\frac{1}{\sqrt{17}+4}\\
Q&=5-\sqrt{24}=\frac{(5-\sqrt{24})(5+\sqrt{24})}{5+\sqrt{24}}=\frac{25-24}{5+\sqrt{24}}=\frac{1}{5+\sqrt{24}}
\end{aligned}" />

# Comparing the denominators

Both fractions have numerator 1, so **the fraction with the smaller denominator is larger**. Compare the denominators.

<BlockMath math="\sqrt{17}+4<\sqrt{25}+4=9<5+\sqrt{24}" />

The last inequality holds because <InlineMath math="\sqrt{24}>4" />. The denominator of <InlineMath math="P" /> is smaller, so <InlineMath math="P>Q" />. As a check, <InlineMath math="P\approx0.123" /> and <InlineMath math="Q\approx0.101" />.

So the correct relation is **<InlineMath math="P>Q" />**.
