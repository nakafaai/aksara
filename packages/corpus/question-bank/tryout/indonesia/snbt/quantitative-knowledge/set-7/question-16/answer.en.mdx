You need three things in order: the formula for <InlineMath math="f^{-1}" />, the formula for the composition, and the solution of the inequality. The part people miss most often is **the condition for a logarithm to exist**, so you write it down as soon as you build the composition and carry it to the end. The notation <InlineMath math="{}^{a}\log x" /> means the logarithm of <InlineMath math="x" /> to base <InlineMath math="a" />.

# Finding the inverse function

The function <InlineMath math="f" /> raises <InlineMath math="2" /> to a power and then subtracts <InlineMath math="1" />. **The inverse undoes those steps in reverse order**: add <InlineMath math="1" /> first, then take the logarithm to base <InlineMath math="2" />.

<BlockMath math="\begin{aligned}
y&=2^x-1\\
2^x&=y+1\\
x&={}^{2}\log(y+1)
\end{aligned}" />

So <InlineMath math="f^{-1}(x)={}^{2}\log(x+1)" />, which only exists for <InlineMath math="x+1>0" />.

# Building the composition and its condition

The composition <InlineMath math="f^{-1}\circ g" /> means you apply <InlineMath math="g" /> first and feed the result into <InlineMath math="f^{-1}" />.

<BlockMath math="(f^{-1}\circ g)(x)=f^{-1}\big(g(x)\big)={}^{2}\log\left({}^{3}\log x+1\right)" />

There are two conditions. The function <InlineMath math="g" /> needs <InlineMath math="x>0" />, and the base <InlineMath math="2" /> logarithm needs <InlineMath math="{}^{3}\log x+1>0" />, that is <InlineMath math="{}^{3}\log x>-1" />, or <InlineMath math="x>\frac13" />. **The second condition is stricter**, so the domain of the composition is <InlineMath math="x>\frac13" />.

# Solving the inequality

Write <InlineMath math="1={}^{2}\log2" />. The base <InlineMath math="2" /> is bigger than <InlineMath math="1" />, so the base <InlineMath math="2" /> logarithm is increasing and **the inequality sign doesn't flip**. Combine that with the condition that the inside of the logarithm is positive.

<BlockMath math="\begin{aligned}
{}^{2}\log\left({}^{3}\log x+1\right)&\le{}^{2}\log2\\
0<{}^{3}\log x+1&\le2\\
-1<{}^{3}\log x&\le1\\
\tfrac13<x&\le3
\end{aligned}" />

Checking the ends: for <InlineMath math="x=3" />, the value is <InlineMath math="{}^{2}\log(1+1)=1" />, so <InlineMath math="x=3" /> is included. For <InlineMath math="x=\frac13" />, the inside of the logarithm is <InlineMath math="-1+1=0" />, and <InlineMath math="{}^{2}\log0" /> doesn't exist, so <InlineMath math="x=\frac13" /> is left out. For <InlineMath math="x=1" /> in the middle, the value is <InlineMath math="{}^{2}\log1=0\le1" />.

# The wrong options

- <InlineMath math="\frac13\le x\le3" /> includes <InlineMath math="x=\frac13" />, where the logarithm doesn't exist.
- <InlineMath math="0<x\le3" /> uses only the condition <InlineMath math="x>0" /> from <InlineMath math="g" /> and **forgets the condition of the outer logarithm**.
- <InlineMath math="0<x\le7" /> comes from reversing the order of the composition, <InlineMath math="g\big(f^{-1}(x)\big)={}^{3}\log\left({}^{2}\log(x+1)\right)\le1" />.
- <InlineMath math="1<x\le81" /> comes from writing the inverse wrongly as <InlineMath math="{}^{2}\log x-1" />, which turns the inequality into <InlineMath math="{}^{2}\log\left({}^{3}\log x\right)\le2" />.

So the solution set is every <InlineMath math="x" /> with <InlineMath math="\frac13<x\le3" />.
