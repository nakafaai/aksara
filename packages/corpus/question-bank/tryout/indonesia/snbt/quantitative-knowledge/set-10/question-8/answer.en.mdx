A statement is sufficient when **the answer is always the same** for every <InlineMath math="k" /> that satisfies it, either always "yes" or always "no". The plan is to use two facts about the number of divisors and then test each statement on its own.

# Two facts about the number of divisors

First fact: the positive divisors of a number <InlineMath math="m" /> can be paired, <InlineMath math="d" /> with <InlineMath math="\tfrac{m}{d}" />. A pair only collapses into one divisor when <InlineMath math="d=\tfrac{m}{d}" />, that is, when <InlineMath math="d^2=m" />. So **the number of divisors is odd exactly when <InlineMath math="m" /> is a perfect square**.

Second fact: if <InlineMath math="m=p_1^{e_1}p_2^{e_2}\cdots" /> with different primes <InlineMath math="p_i" />, the number of divisors is <InlineMath math="(e_1+1)(e_2+1)\cdots" />, because the exponent of each prime in a divisor can be anything from <InlineMath math="0" /> to <InlineMath math="e_i" />. The number <InlineMath math="m" /> is a perfect square exactly when all its exponents are even.

# Statement one alone

By the first fact, <InlineMath math="2k" /> is a perfect square, say <InlineMath math="2k=m^2" />. The left side is even, so <InlineMath math="m" /> is even. Write <InlineMath math="m=2j" />.

<BlockMath math="\begin{aligned}
2k &= (2j)^2=4j^2 \\
k &= 2j^2
\end{aligned}" />

The exponent of <InlineMath math="2" /> in <InlineMath math="j^2" /> is even, so **the exponent of <InlineMath math="2" /> in <InlineMath math="k=2j^2" /> is odd**. A perfect square can't have an odd exponent, so <InlineMath math="k" /> is definitely not a perfect square. Examples are <InlineMath math="k=2" />, <InlineMath math="k=8" /> and <InlineMath math="k=18" />, which give <InlineMath math="2k=4" />, <InlineMath math="16" /> and <InlineMath math="36" />. The answer is always "no", so statement (1) alone is sufficient.

# Statement two alone

If <InlineMath math="k=p_1^{e_1}p_2^{e_2}\cdots" />, then <InlineMath math="k^2=p_1^{2e_1}p_2^{2e_2}\cdots" />. By the second fact, the number of divisors of <InlineMath math="k^2" /> is <InlineMath math="(2e_1+1)(2e_2+1)\cdots" />, and that has to be <InlineMath math="15" />. You can only write <InlineMath math="15" /> as <InlineMath math="15" /> or <InlineMath math="3\cdot 5" />, so there are two cases.

<BlockMath math="\begin{aligned}
2e_1+1=15 &\;\Longrightarrow\; e_1=7,\quad k=p^7 \\
2e_1+1=3,\ 2e_2+1=5 &\;\Longrightarrow\; e_1=1,\ e_2=2,\quad k=pq^2
\end{aligned}" />

In both cases **there's always an odd exponent**, <InlineMath math="7" /> or <InlineMath math="1" />, so <InlineMath math="k" /> is definitely not a perfect square. Examples are <InlineMath math="k=128=2^7" /> and <InlineMath math="k=12=3\cdot 2^2" />. You can check that <InlineMath math="144=12^2" /> really has <InlineMath math="15" /> divisors. The answer is always "no", so statement (2) alone is sufficient too.

The number <InlineMath math="15" /> matters here. If <InlineMath math="k^2" /> had <InlineMath math="9" /> divisors, the case <InlineMath math="k=p^4" /> would answer "yes", while the case <InlineMath math="k=pq" /> would answer "no".

# The wrong options

Each statement is sufficient on its own, so **every option that calls one of them insufficient is wrong**.

- The option "statement (1) alone is sufficient, but (2) isn't" usually comes from thinking the two cases of statement (2) give different answers, but both give "no".
- The option "statement (2) alone is sufficient, but (1) isn't" comes from thinking an odd divisor count only tells you something about <InlineMath math="2k" />, not about <InlineMath math="k" />.
- The options "both statements together" and "not sufficient" ignore that each statement already forces the answer "no" by itself.

So statement (1) alone is sufficient and statement (2) alone is sufficient, and the answer is that <InlineMath math="k" /> is not a perfect square.
