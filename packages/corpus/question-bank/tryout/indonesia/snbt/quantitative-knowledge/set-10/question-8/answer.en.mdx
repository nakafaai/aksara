Start with the inequality:

<MathContainer>
  <BlockMath math="x^2 + x - 6 > 0" />
</MathContainer>

Factor its left-hand side:

<MathContainer>
  <BlockMath math="(x - 2)(x + 3) > 0" />
</MathContainer>

The factors are zero at the two boundary points:

<MathContainer>
  <BlockMath math="x = 2 \quad \text{or} \quad x = -3" />
</MathContainer>

These points divide the number line into three intervals. Test one value from each interval:

  title="Number Line"
  description="Visualization of the inequality solution region."
/>

-   For <InlineMath math="x < -3" /> (e.g., <InlineMath math="-4" />): <InlineMath math="(-4-2)(-4+3) = (-6)(-1) = 6" /> (Positive)
-   For <InlineMath math="-3 < x < 2" /> (e.g., <InlineMath math="0" />): <InlineMath math="(0-2)(0+3) = (-2)(3) = -6" /> (Negative)
-   For <InlineMath math="x > 2" /> (e.g., <InlineMath math="3" />): <InlineMath math="(3-2)(3+3) = (1)(6) = 6" /> (Positive)

The product must be positive, so keep the first and third intervals:

<MathContainer>
  <BlockMath math="x < -3 \quad \text{or} \quad x > 2" />
</MathContainer>

Compare this solution with the four statements:
1.  <InlineMath math="x > 2" /> (Matches)
2.  <InlineMath math="-3 < x < 2" /> (Does not match)
3.  <InlineMath math="x < -3" /> (Matches)
4.  <InlineMath math="x > -3" /> (Does not match)

Therefore, statements <InlineMath math="1" /> and <InlineMath math="3" /> describe the solution.
