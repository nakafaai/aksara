First find the number of sides. The quickest way uses **exterior angles**, because the exterior angles of any polygon add up to <InlineMath math="360^\circ" />.

# Number of sides

An exterior angle and an interior angle **sit next to each other on a straight line**, so the exterior angle is <InlineMath math="180^\circ-156^\circ=24^\circ" />.

<BlockMath math="n=\frac{360^\circ}{24^\circ}=15" />

# Number of diagonals

Each vertex joins every vertex that is **neither itself nor one of its two neighbours**, that is <InlineMath math="15-3=12" /> vertices. Each diagonal is counted twice, once from each end.

<BlockMath math="\frac{15\cdot12}{2}=90" />

The value 105 is <InlineMath math="\binom{15}{2}" />, which also counts the 15 sides. The value 15 is the number of sides, and 75 subtracts the sides twice from 105.

So the polygon has **90** diagonals.
