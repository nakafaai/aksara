The ratio <InlineMath math="a:b=3:4" /> means **<InlineMath math="a=3k" /> and <InlineMath math="b=4k" />** for some number <InlineMath math="k\ne0" />. The expression depends only on the ratio, so <InlineMath math="k" /> will cancel.

# Substitution

<BlockMath math="\begin{aligned}
\frac{2a+b}{a-3b}&=\frac{2(3k)+4k}{3k-3(4k)}\\
&=\frac{10k}{-9k}=-\frac{10}{9}
\end{aligned}" />

# Checking the sign

The denominator <InlineMath math="a-3b" /> is negative because <InlineMath math="3b" /> **is much larger than <InlineMath math="a" />**, while the numerator is positive for <InlineMath math="k>0" />. So the result must be negative. For <InlineMath math="k<0" />, the numerator and denominator both change sign, and the result is still <InlineMath math="-\tfrac{10}{9}" />.

The value <InlineMath math="\tfrac{10}{9}" /> ignores the negative sign of the denominator. The value <InlineMath math="-\tfrac{9}{10}" /> turns the fraction upside down.

So the value of the expression is **<InlineMath math="-\tfrac{10}{9}" />**.
