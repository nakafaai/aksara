Given the system of inequalities:

<BlockMath math="\begin{cases} x \ge 0 \\ y \ge 0 \\ x + 5y \le 10 \\ 5x + y \le a^2 - 5 \end{cases}" />

Adding the two slanted constraints gives an upper bound for <InlineMath math="x + y" />:

<MathContainer>
  <BlockMath math="\begin{aligned}&(x+5y)+(5x+y)\\&\quad\le10+(a^2-5)\end{aligned}" />
  <BlockMath math="6x + 6y \le 5 + a^2" />
  <BlockMath math="x + y \le \frac{a^2 + 5}{6}" />
</MathContainer>

If <InlineMath math="a=3" /> or <InlineMath math="a=4" />, this bound is respectively <InlineMath math="\frac{7}{3}" /> or <InlineMath math="\frac{7}{2}" />, both below <InlineMath math="5" />. If <InlineMath math="a=16" /> or <InlineMath math="a=25" />, the feasible point <InlineMath math="(6,0)" /> already gives <InlineMath math="x+y=6" />, so the maximum would exceed <InlineMath math="5" />.

It remains to check <InlineMath math="a=5" />. The bound becomes:

<BlockMath math="x+y \le \frac{5^2+5}{6}=5" />

The intersection point <InlineMath math="\left(\frac{15}{4},\frac{5}{4}\right)" /> satisfies both boundary equations:

<MathContainer>
  <BlockMath math="\frac{15}{4}+5\left(\frac{5}{4}\right)=10" />
  <BlockMath math="\begin{aligned}5\left(\frac{15}{4}\right)+\frac54&=20\\&=5^2-5\end{aligned}" />
  <BlockMath math="\frac{15}{4}+\frac{5}{4}=5" />
</MathContainer>

Thus, <InlineMath math="5" /> is both an upper bound and an attainable value. Therefore, <InlineMath math="a=5" />.
