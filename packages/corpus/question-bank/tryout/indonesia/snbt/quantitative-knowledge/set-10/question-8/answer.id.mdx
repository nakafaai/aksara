Mulai dari pertidaksamaan:

<BlockMath math="x^2 + x - 6 > 0" />

Faktorkan ruas kirinya:

<BlockMath math="(x - 2)(x + 3) > 0" />

Kedua faktor bernilai nol pada titik batas berikut:

<BlockMath math="x = 2 \quad \text{atau} \quad x = -3" />

Kedua titik itu membagi garis bilangan menjadi tiga interval. Uji satu nilai dari setiap interval:

<Set10Question8Graph
  title="Garis Bilangan"
  description="Visualisasi daerah penyelesaian pertidaksamaan."
/>

-   Untuk <InlineMath math="x < -3" /> (misal <InlineMath math="-4" />):

    <BlockMath math="\begin{aligned}(-4-2)(-4+3)&=(-6)(-1)\\&=6\end{aligned}" />

    (Positif)
-   Untuk <InlineMath math="-3 < x < 2" /> (misal <InlineMath math="0" />):

    <BlockMath math="\begin{aligned}(0-2)(0+3)&=(-2)(3)\\&=-6\end{aligned}" />

    (Negatif)
-   Untuk <InlineMath math="x > 2" /> (misal <InlineMath math="3" />):

    <BlockMath math="\begin{aligned}(3-2)(3+3)&=(1)(6)\\&=6\end{aligned}" />

    (Positif)

Hasil kalinya harus positif, sehingga interval pertama dan ketiga menjadi penyelesaian:

<BlockMath math="x < -3 \quad \text{atau} \quad x > 2" />

Bandingkan himpunan penyelesaian dengan keempat pernyataan:
1.  <InlineMath math="x > 2" /> (Sesuai)
2.  <InlineMath math="-3 < x < 2" /> (Tidak sesuai)
3.  <InlineMath math="x < -3" /> (Sesuai)
4.  <InlineMath math="x > -3" /> (Tidak sesuai)

Jadi, pernyataan 1 dan 3 sesuai dengan himpunan penyelesaian.
