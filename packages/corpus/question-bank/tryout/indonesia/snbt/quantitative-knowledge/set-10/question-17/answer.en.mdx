A statement is sufficient if **only one real number** satisfies it. Solve each statement, then compare the solution sets.

# Each statement alone

Statement (1) means <InlineMath math="x" /> is 3 away from 2.

<BlockMath math="x-2=3\;\text{or}\;x-2=-3\;\Longrightarrow\;x=5\;\text{or}\;x=-1" />

Statement (2) factorises.

<BlockMath math="x^2-4x-5=(x-5)(x+1)=0\;\Longrightarrow\;x=5\;\text{or}\;x=-1" />

Each gives **two values**, so neither is sufficient alone.

# Both statements together

The two statements have **exactly the same solution set**, <InlineMath math="\{-1,5\}" />. Combining them removes no value, so <InlineMath math="x" /> can still be 5 or <InlineMath math="-1" />. This is no accident: squaring <InlineMath math="\lvert x-2\rvert=3" /> gives <InlineMath math="x^2-4x+4=9" />, which is equation (2).

So **statements (1) and (2) together are not sufficient** to answer the question.
