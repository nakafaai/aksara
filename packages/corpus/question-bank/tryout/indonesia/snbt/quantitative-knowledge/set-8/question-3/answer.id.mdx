Ubah persentase pecahan campuran menjadi persentase desimal:

<BlockMath math="22\frac{1}{4}\% = 22{,}25\%" />

Maka nilai <InlineMath math="A" /> adalah:

<BlockMath math="\begin{aligned}A&=\frac{22{,}25}{100} \times 25\\&=\frac{22{,}25}{4}\\&=5{,}5625\end{aligned}" />

Dan nilai <InlineMath math="B" /> adalah:

<BlockMath math="B = \frac{1}{8} \times 32 = 4" />

Karena <InlineMath math="5{,}5625 > 4" />, maka <InlineMath math="A > B" />.
