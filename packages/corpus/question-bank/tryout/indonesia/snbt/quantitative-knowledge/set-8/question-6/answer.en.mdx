Square both sides to remove the root. This step can create false roots, so **every result must be checked in the original equation**.

# Squaring both sides

<BlockMath math="\begin{aligned}
x+10&=(x-2)^2\\
x+10&=x^2-4x+4\\
x^2-5x-6&=0\\
(x-6)(x+1)&=0
\end{aligned}" />

# Checking both candidates

The left side is a square root, so it is never negative. Therefore **the right side must also be non-negative**, which means <InlineMath math="x\ge2" />.

<BlockMath math="\begin{aligned}
x=6&:\quad \sqrt{16}=4=6-2\\
x=-1&:\quad \sqrt{9}=3\ne-1-2
\end{aligned}" />

Only <InlineMath math="x=6" /> works. The candidate <InlineMath math="x=-1" /> appears because <InlineMath math="3^2" /> and <InlineMath math="(-3)^2" /> are both 9.

The value 5 adds both candidates without checking. The value <InlineMath math="-1" /> is the false root, 4 is the value of <InlineMath math="\sqrt{x+10}" />, and 1 comes from a sign error in the factorisation.

So the sum of all solutions is **6**.
