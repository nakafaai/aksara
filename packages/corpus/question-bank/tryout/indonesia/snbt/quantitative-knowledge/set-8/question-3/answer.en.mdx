Convert the mixed percentage to a decimal percentage:

<BlockMath math="22\frac{1}{4}\% = 22.25\%" />

Then the value of <InlineMath math="A" /> is:

<BlockMath math="\begin{aligned}A&=\frac{22.25}{100} \times 25\\&=\frac{22.25}{4}\\&=5.5625\end{aligned}" />

And the value of <InlineMath math="B" /> is:

<BlockMath math="B = \frac{1}{8} \times 32 = 4" />

Since <InlineMath math="5.5625 > 4" />, it follows that <InlineMath math="A > B" />.
