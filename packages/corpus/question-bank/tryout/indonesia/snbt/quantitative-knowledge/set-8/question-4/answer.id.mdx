Diketahui data baru mengikuti pola:

<BlockMath math="\begin{gathered}y_1=\frac{x_1}{2}+3,\\y_2=\frac{x_2}{2}+5,\\y_3=\frac{x_3}{2}+7,\dots\end{gathered}" />

Maka rata-rata barunya dapat diperoleh dengan:

Tuliskan jumlah data awal sebagai <InlineMath math="S=x_1+x_2+\dots+x_{10}" />. Jumlah tambahan <InlineMath math="3+5+\dots+21" /> kita tuliskan sebagai <InlineMath math="T" />. Rata-rata data baru adalah:

<BlockMath math="\bar{y}=\frac{S/2+T}{10}" />

Pertama, kita cari jumlah barisan aritmetika <InlineMath math="3, 5, 7, \dots" />. Suku pertamanya <InlineMath math="a_1 = 3" /> dan bedanya <InlineMath math="d = 2" />. Suku kesepuluh adalah:

<BlockMath math="a_{10} = 3 + 9(2) = 21" />

Jumlah <InlineMath math="10" /> suku pertama adalah:

<BlockMath math="\begin{aligned}T=S_{10}&=\frac{10}{2}(3+21)\\&=5(24)\\&=120\end{aligned}" />

Rata-rata data baru dapat ditulis sebagai berikut:

<BlockMath math="\begin{aligned}\bar{y}&=\frac{S/2+120}{10}\\&=\frac12\cdot\frac{S}{10}+12\\&=\frac12x_0+12\end{aligned}" />

Jadi, rata-rata barunya adalah <InlineMath math="\frac{1}{2}x_0 + 12" />.
