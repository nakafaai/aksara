The dice have different colours, so the sample space consists of **36 equally likely ordered pairs**, from <InlineMath math="(1,1)" /> to <InlineMath math="(6,6)" />.

# At least one six

It is easier to count **the opposite event**, no six at all. Each die has 5 outcomes other than 6.

<BlockMath math="P=1-\frac{5\cdot5}{36}=\frac{11}{36}" />

The value <InlineMath math="\tfrac{11}{36}" /> is less than <InlineMath math="\tfrac{12}{36}=\tfrac13" />, because the pair <InlineMath math="(6,6)" /> is counted only once. The first statement is false.

# Sum 7 and sum 8

List the pairs for each sum.

| Sum | Pairs (red, blue) | Count |
| :---: | :---: | :---: |
| 7 | <InlineMath math="(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)" /> | 6 |
| 8 | <InlineMath math="(2,6),(3,5),(4,4),(5,3),(6,2)" /> | 5 |

The probability of sum 7 is <InlineMath math="\tfrac{6}{36}=\tfrac16" />, so the second statement is true. The probability of sum 8 is <InlineMath math="\tfrac{5}{36}" />, because **the pair <InlineMath math="(4,4)" /> has no mirror pair**. The third statement is false.

# Odd product

The product is odd only when **both dice show odd numbers**. Each die has 3 odd faces.

<BlockMath math="P=\frac{3\cdot3}{36}=\frac14" />

The fourth statement is true.

So the first statement is **false**, the second is **true**, the third is **false**, and the fourth is **true**.
