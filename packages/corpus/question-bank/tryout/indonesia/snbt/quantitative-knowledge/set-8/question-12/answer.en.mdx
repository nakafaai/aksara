Both quantities are counts with different contexts. Compute each with **the right counting rule**, then compare.

# Number of diagonals of an octagon

Every two vertices are joined by one segment, so there are <InlineMath math="\binom82" /> segments. **Eight of them are sides**, not diagonals.

<BlockMath math="P=\binom82-8=28-8=20" />

Another way: each vertex joins 5 non-neighbouring vertices, and each diagonal is counted twice, so <InlineMath math="P=\tfrac{8\cdot5}{2}=20" />.

# Number of ways to choose the committee

The order of the committee members does not matter, so this is **a combination of 3 from 6**.

<BlockMath math="Q=\binom63=\frac{6\cdot5\cdot4}{3\cdot2\cdot1}=20" />

Both quantities equal 20.

So the correct relation is **<InlineMath math="P=Q" />**.
