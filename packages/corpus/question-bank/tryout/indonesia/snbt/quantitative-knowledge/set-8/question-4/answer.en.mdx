This function is the graph of <InlineMath math="y=2^{x}" /> shifted 1 unit right and 4 units down. The key property it keeps is that **<InlineMath math="2^{x-1}" /> is always positive**.

# Intercepts

The x-intercept satisfies <InlineMath math="f(x)=0" />.

<BlockMath math="2^{x-1}=4=2^2\;\Longrightarrow\;x-1=2\;\Longrightarrow\;x=3" />

The first statement is true. The y-intercept comes from **replacing <InlineMath math="x" /> with 0**.

<BlockMath math="f(0)=2^{-1}-4=\tfrac12-4=-3.5" />

The intercept is <InlineMath math="(0,-3.5)" />, not <InlineMath math="(0,-3)" />. The second statement is false.

# A value never reached and the value at five

The equation <InlineMath math="f(x)=-4" /> means <InlineMath math="2^{x-1}=0" />. A power of 2 **is never zero**, so no <InlineMath math="x" /> works. The line <InlineMath math="y=-4" /> is a horizontal asymptote that the graph approaches but never touches. The third statement is false.

<BlockMath math="f(5)=2^{4}-4=16-4=12" />

The fourth statement is true.

So the first statement is **true**, the second is **false**, the third is **false**, and the fourth is **true**.
