The sweets are identical, so one way differs from another only in **how many sweets each child receives**. Count the triples <InlineMath math="(a,b,c)" /> with <InlineMath math="a+b+c=8" /> and every number at least 1.

# Using dividers between the sweets

Line up the 8 sweets. There are 7 gaps between them. Choosing **2 gaps as dividers** splits the line into 3 non-empty groups, and each choice gives one way to share.

<BlockMath math="\binom72=\frac{7\cdot6}{2}=21" />

# Check by another method

First give one sweet to each child. The remaining 5 sweets are shared freely, zero allowed, in <InlineMath math="\binom{5+2}{2}=\binom72=21" /> ways.

The value 45 is <InlineMath math="\binom{10}{2}" />, the count when a child may receive nothing. The value 28 chooses 2 of the 8 sweets as dividers, although the dividers go in the gaps. The value 56 is <InlineMath math="\binom83" />.

So the number of ways to share the sweets is **21**.
