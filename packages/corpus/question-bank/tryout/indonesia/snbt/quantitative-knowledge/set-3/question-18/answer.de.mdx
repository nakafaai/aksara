-   <InlineMath math="B_5 = -1" />
-   <InlineMath math="B_n = B_{n+2} + B_{n-1}" />

Damit <InlineMath math="B_2" /> in der Rekursion erscheint, setzen wir <InlineMath math="n = 3" /> ein.

#### Das vorherige Glied bestimmen

<MathContainer>
  <BlockMath math="B_3 = B_{3+2} + B_{3-1}" />
  <BlockMath math="B_3 = B_5 + B_2" />

<MathContainer>
  <BlockMath math="2 = -1 + B_2" />
  <BlockMath math="B_2 = 3" />

#### Überprüfung

Setzen wir das Ergebnis wieder in die Rekursion ein:

<BlockMath math="-1 + 3 = 2" />
