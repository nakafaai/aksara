Compute three measures for each class: the mean, the median, and the range. Both data sets are **already in order**, so the median is the third of the five values.

# The measures of each class

| Measure | Class A | Class B |
| :--- | :---: | :---: |
| Total | 375 | 375 |
| Mean | <InlineMath math="\tfrac{375}{5}=75" /> | <InlineMath math="\tfrac{375}{5}=75" /> |
| Median | 70 | 75 |
| Range | <InlineMath math="95-60=35" /> | <InlineMath math="90-65=25" /> |

The two means are **equal**, so the first statement is false. The median of class A is smaller, so the second statement is false. The range of class A is larger, so the third statement is true.

# Replacing one score

Replacing 95 with 85 **lowers the total of class A by 10**.

<BlockMath math="\bar x_A=\frac{375-10}{5}=\frac{365}{5}=73<75" />

The new mean of class A is smaller than the mean of class B, so the fourth statement is true.

So the first statement is **false**, the second is **false**, the third is **true**, and the fourth is **true**.
