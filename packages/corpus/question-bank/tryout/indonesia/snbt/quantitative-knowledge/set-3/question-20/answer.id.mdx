Kita periksa **pengaruh penyebut** ketika <InlineMath math="-1<x<1" />, dengan:

-   <InlineMath math="P = \frac{1 + x^4}{1 - x^2}" />
-   <InlineMath math="Q = 1 + x^4" />

#### Menganalisis Penyebut

Dari <InlineMath math="-1 < x < 1" />, **kuadrat tidak negatif** dan tetap kurang dari satu:

<BlockMath math="0 \leq x^2 < 1" />

Dengan demikian, nilai penyebut memenuhi:

<BlockMath math="0 < 1 - x^2 \leq 1" />

#### Membandingkan Kuantitas

Karena <InlineMath math="Q=1+x^4\ge1" /> selalu **bernilai positif**, kita dapat membagi kedua kuantitas dengan <InlineMath math="Q" /> tanpa membalik ketaksamaan:

<MathContainer>
  <BlockMath math="\frac{P}{Q} = \frac{\frac{1 + x^4}{1 - x^2}}{1 + x^4} = \frac{1}{1 - x^2}" />
</MathContainer>

Sekarang kita analisis dua kasus:

**Kasus 1**: Jika <InlineMath math="0 < 1 - x^2 < 1" />

Maka <InlineMath math="\frac{1}{1 - x^2} > 1" />, sehingga <InlineMath math="P > Q" />.

**Kasus 2**: Jika <InlineMath math="1 - x^2 = 1" /> (yaitu saat <InlineMath math="x = 0" />)

Maka <InlineMath math="\frac{1}{1 - x^2} = 1" />, sehingga <InlineMath math="P = Q" />.

Untuk <InlineMath math="x\ne0" />, berlaku <InlineMath math="P>Q" />. Untuk <InlineMath math="x=0" />, berlaku <InlineMath math="P=Q" />. Kedua kasus memberikan hubungan yang selalu benar, yaitu <InlineMath math="P\ge Q" />.
