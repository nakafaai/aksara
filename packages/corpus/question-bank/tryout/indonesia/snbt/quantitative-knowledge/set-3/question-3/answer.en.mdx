An equation with algebraic fractions has to be solved together with **the condition that no denominator is zero**. Since <InlineMath math="x^2-4=(x-2)(x+2)" />, the values <InlineMath math="x=2" /> and <InlineMath math="x=-2" /> are excluded from the start.

# Clearing the denominators

**Multiply both sides** by <InlineMath math="(x-2)(x+2)" />.

<BlockMath math="\begin{aligned}
x(x+2)+4(x-2)&=8\\
x^2+2x+4x-8&=8\\
x^2+6x-16&=0\\
(x+8)(x-2)&=0
\end{aligned}" />

The candidates are <InlineMath math="x=-8" /> and <InlineMath math="x=2" />.

# Checking the condition

The value <InlineMath math="x=2" /> makes a denominator zero, so **<InlineMath math="x=2" /> is not a solution**. It appears because multiplying by <InlineMath math="(x-2)(x+2)" /> adds an extraneous root. Check <InlineMath math="x=-8" />: the left side is <InlineMath math="\frac{-8}{-10}+\frac{4}{-6}=\frac45-\frac23=\frac2{15}" /> and the right side is <InlineMath math="\frac8{60}=\frac2{15}" />.

The only solution is <InlineMath math="x=-8" />, so the sum is <InlineMath math="-8" />.

The value <InlineMath math="-6" /> adds both candidates without checking the condition. The value 2 takes only the extraneous root. The values 6 and 8 come from sign slips when factoring.

So the sum of all solutions is <InlineMath math="-8" />.
