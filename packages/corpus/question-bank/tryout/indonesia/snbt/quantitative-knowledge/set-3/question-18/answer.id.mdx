-   <InlineMath math="B_3 = 2" />
-   <InlineMath math="B_5 = -1" />
-   <InlineMath math="B_n = B_{n+2} + B_{n-1}" />

Agar <InlineMath math="B_2" /> muncul dalam rumus rekursif, substitusikan <InlineMath math="n = 3" />.

#### Mencari Suku Sebelumnya

<MathContainer>
  <BlockMath math="B_3 = B_{3+2} + B_{3-1}" />
  <BlockMath math="B_3 = B_5 + B_2" />
</MathContainer>

Sekarang substitusikan <InlineMath math="B_3 = 2" /> dan <InlineMath math="B_5 = -1" />.

<MathContainer>
  <BlockMath math="2 = -1 + B_2" />
  <BlockMath math="B_2 = 3" />
</MathContainer>

#### Verifikasi

Substitusikan hasilnya kembali ke rumus rekursif:

<BlockMath math="-1 + 3 = 2" />

Hasilnya sesuai dengan <InlineMath math="B_3 = 2" />, sehingga <InlineMath math="B_2" /> bernilai <InlineMath math="3" />.
