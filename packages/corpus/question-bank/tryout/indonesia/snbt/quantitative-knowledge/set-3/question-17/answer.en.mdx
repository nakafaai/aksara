A statement is sufficient when it **forces one answer**, either definitely even or definitely odd. Check whether each statement really separates even <InlineMath math="n" /> from odd <InlineMath math="n" />.

# Statement one alone

Factor <InlineMath math="n^2+3n=n(n+3)" />. If <InlineMath math="n" /> is even, the factor <InlineMath math="n" /> is even. If <InlineMath math="n" /> is odd, the factor <InlineMath math="n+3" /> is even. So <InlineMath math="n^2+3n" /> is **even for every integer**: for example <InlineMath math="n=2" /> gives 10 and <InlineMath math="n=1" /> gives 4. Statement (1) gives no new information, so it is not sufficient.

# Statement two alone

The expression <InlineMath math="n^2+2n+1" /> is the perfect square <InlineMath math="(n+1)^2" />. The square of an integer is odd exactly when **the integer itself is odd**, so <InlineMath math="n+1" /> is odd and <InlineMath math="n" /> is even. The answer is a definite yes, so statement (2) alone is sufficient.

So **statement (2) alone is sufficient**, but statement (1) alone is not.
