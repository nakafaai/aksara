Both quantities ask about the same event under two ways of drawing. The plan: find what's in the box from the given probability, compute <InlineMath math="P" /> and <InlineMath math="Q" />, and compare them. Careful: **the direction of the comparison depends on what's in the box**, so the condition about which colour there's more of helps decide the answer.

# What's in the box

Say there are <InlineMath math="r" /> red balls and <InlineMath math="10-r" /> white balls. Two balls differ in colour when one is red and one is white, and there are <InlineMath math="\binom{10}{2}=45" /> equally likely pairs.

<BlockMath math="\begin{aligned}
\frac{r(10-r)}{45}&=\frac{7}{15}\\
r^2-10r+21&=0\\
(r-3)(r-7)&=0
\end{aligned}" />

Both roots make sense as a number of balls, so **the condition that there are more red balls decides**: <InlineMath math="r=7" />. The box holds <InlineMath math="7" /> red balls and <InlineMath math="3" /> white balls.

# The probability with replacement

Every draw uses the same box, so red always has probability <InlineMath math="\tfrac{7}{10}" /> and white <InlineMath math="\tfrac{3}{10}" />. The single white ball can come up in **any one of three positions**.

<BlockMath math="P=3\cdot\left(\frac{7}{10}\right)^2\cdot\frac{3}{10}=\frac{441}{1000}" />

# The probability without replacement

Without replacement, the order of drawing doesn't change which balls end up drawn, so **count it like drawing three balls at once**: choose <InlineMath math="2" /> of the <InlineMath math="7" /> red balls and <InlineMath math="1" /> of the <InlineMath math="3" /> white balls.

<BlockMath math="Q=\frac{\binom{7}{2}\binom{3}{1}}{\binom{10}{3}}=\frac{21\cdot 3}{120}=\frac{21}{40}" />

Check with a tree: each order RRW, RWR, and WRR (R for red, W for white) has probability <InlineMath math="\tfrac{7\cdot 6\cdot 3}{720}=\tfrac{126}{720}" />, and together they give <InlineMath math="\tfrac{378}{720}=\tfrac{21}{40}" />.

# Comparing the two probabilities

Use a common denominator: <InlineMath math="Q=\tfrac{21}{40}=\tfrac{525}{1000}" /> and <InlineMath math="P=\tfrac{441}{1000}" />. So **<InlineMath math="Q" /> is greater than <InlineMath math="P" />**.

Now see why the colour condition matters. For <InlineMath math="r=3" />, you'd get <InlineMath math="P=3\cdot\left(\tfrac{3}{10}\right)^2\cdot\tfrac{7}{10}=\tfrac{189}{1000}" /> and <InlineMath math="Q=\tfrac{\binom{3}{2}\binom{7}{1}}{120}=\tfrac{175}{1000}" />, so <InlineMath math="P>Q" />. Without the condition that there are more red balls, the answer couldn't be decided.

# Checking the other options

The option <InlineMath math="P>Q" /> comes from using <InlineMath math="r=3" />, or from guessing that drawing without replacement **always lowers the probability**. The option <InlineMath math="P=Q" /> comes from noticing that one draw is red with probability <InlineMath math="\tfrac{7}{10}" /> in both schemes and then assuming the same holds for the combined event over three draws. The option that the information isn't enough comes from not using the condition about more red balls to throw out <InlineMath math="r=3" />.

So <InlineMath math="Q>P" />, because <InlineMath math="\tfrac{21}{40}" /> is greater than <InlineMath math="\tfrac{441}{1000}" />.
