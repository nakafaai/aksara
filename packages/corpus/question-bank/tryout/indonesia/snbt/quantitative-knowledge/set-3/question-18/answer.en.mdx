One-, two-, and three-digit numbers can be counted together if each number is written **as three digits with leading zeros**, for example 5 as 005 and 42 as 042. This adds no 7 and removes no 7.

# Counting three-digit strings

Each position can hold any digit from 0 to 9 except 7, so there are 9 choices per position. The three positions are **chosen independently**.

<BlockMath math="9\times9\times9=729" />

This count includes the string 000, which is not a positive integer.

<BlockMath math="729-1=728" />

# Checking the other options

The value 729 forgets to remove 000. The value 648 counts only three-digit numbers, <InlineMath math="8\times9\times9" />, and forgets the one- and two-digit numbers. The value 700 subtracts 100 numbers for each position of the digit 7 without accounting for numbers that contain 7 more than once. The value 810 forbids 7 in only two positions, <InlineMath math="9\times9\times10" />.

So **728** such numbers exist.
