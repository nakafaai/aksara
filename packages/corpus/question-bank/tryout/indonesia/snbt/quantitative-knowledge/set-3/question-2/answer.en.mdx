Neither <InlineMath math="a" /> nor <InlineMath math="b" /> is an integer, but their product can be found exactly. Write both as logarithms and use the property of **two reciprocal logarithms**, <InlineMath math="\log_p q\cdot\log_q p=1" />.

# Writing them as logarithms

<BlockMath math="\begin{aligned}
a&=\log_2 9=\log_2 3^2=2\log_2 3\\
b&=\log_3 16=\log_3 2^4=4\log_3 2
\end{aligned}" />

# Multiplying them

The factors <InlineMath math="\log_2 3" /> and <InlineMath math="\log_3 2" /> are **reciprocals of each other**, because <InlineMath math="\log_2 3=\frac{\log3}{\log2}" /> and <InlineMath math="\log_3 2=\frac{\log2}{\log3}" />.

<BlockMath math="ab=2\cdot4\cdot\log_2 3\cdot\log_3 2=8\cdot1=8" />

The value 1 multiplies only the two logarithms and forgets the coefficients 2 and 4. The value 6 adds the coefficients, although they are multiplied. The value 24 takes <InlineMath math="a=\tfrac92" /> and <InlineMath math="b=\tfrac{16}3" />, as if a power were a division. The value 12 estimates <InlineMath math="a\approx3" /> and <InlineMath math="b\approx4" />, which is too rough for an exact result.

So the value of <InlineMath math="ab" /> is **8**.
