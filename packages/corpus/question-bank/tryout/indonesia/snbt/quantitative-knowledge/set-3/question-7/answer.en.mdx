# The pattern in the base angles

Triangle <InlineMath math="AP_1P_2" /> is isosceles because <InlineMath math="AP_1=P_1P_2" />, with apex <InlineMath math="P_1" />. So both base angles are <InlineMath math="12^\circ" />. The rule: **an exterior angle of a triangle equals the sum of the two interior angles that aren't next to it**.

# When a new point can still be made

The new point is the second place where the circle centred at the apex with radius <InlineMath math="1" /> meets the ray. That point is farther from <InlineMath math="A" /> than the old point only if **the base angle of the triangle is acute**. If the base angle is <InlineMath math="90^\circ" /> or more, the second intersection lands on the old point or closer to <InlineMath math="A" />. The angle sum shows the same thing: two base angles of <InlineMath math="90^\circ" /> or more can't fit inside <InlineMath math="180^\circ" />.
