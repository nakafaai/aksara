Write every number as **a power of the same base**, 2 for the first equation and 3 for the second. Then both equations become linear.

# Matching the bases

<BlockMath math="\begin{aligned}
2^x\cdot2^{2y}=2^5&\;\Longrightarrow\;x+2y=5\\
\frac{3^x}{3^{2y}}=3^{-1}&\;\Longrightarrow\;x-2y=-1
\end{aligned}" />

# Solving the system

Add the two equations to get <InlineMath math="2x=4" />, so <InlineMath math="x=2" />. Substituting into the first equation gives <InlineMath math="2y=3" />, so **<InlineMath math="y=\tfrac32" />**.

<BlockMath math="xy=2\cdot\tfrac32=3" />

Check: <InlineMath math="2^2\cdot4^{3/2}=4\cdot8=32" /> and <InlineMath math="\tfrac{3^2}{9^{3/2}}=\tfrac{9}{27}=\tfrac13" />.

The values 2 and <InlineMath math="\tfrac32" /> are <InlineMath math="x" /> and <InlineMath math="y" />, not their product. The value <InlineMath math="\tfrac72" /> is <InlineMath math="x+y" />.

So the value of <InlineMath math="xy" /> is **3**.
