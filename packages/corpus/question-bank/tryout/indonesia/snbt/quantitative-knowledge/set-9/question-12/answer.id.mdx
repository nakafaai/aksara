# Menyelesaikan pertidaksamaan

| Selang | Tanda <InlineMath math="x(x-2)(x+2)" /> |
| :---: | :---: |
| <InlineMath math="x<-2" /> | negatif |
| <InlineMath math="-2<x<0" /> | positif |
| <InlineMath math="0<x<2" /> | negatif |
