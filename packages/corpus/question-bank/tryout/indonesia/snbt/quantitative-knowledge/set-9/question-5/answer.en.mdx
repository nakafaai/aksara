Computing the roots <InlineMath math="x=\tfrac{-1\pm\sqrt5}{2}" /> and raising them to the fourth power takes long. It is faster to **look for <InlineMath math="x^2+x" /> inside the expression**, because the equation gives <InlineMath math="x^2+x=1" />.

# Factorising the expression

<BlockMath math="\begin{aligned}
x^4+2x^3+x^2&=x^2\left(x^2+2x+1\right)\\
&=x^2(x+1)^2\\
&=\left(x^2+x\right)^2
\end{aligned}" />

# Substitution

From the equation, **<InlineMath math="x^2+x=1" />**.

<BlockMath math="\left(x^2+x\right)^2=1^2=1" />

This holds for both roots at once, so there is no need to choose one.

The value 0 appears if <InlineMath math="x^2+x" /> is taken as 0, ignoring the constant <InlineMath math="-1" />. The value <InlineMath math="-1" /> forgets that the expression is squared.

So the value of <InlineMath math="x^4+2x^3+x^2" /> is **1**.
