Convert the percentage to a **fraction with denominator one hundred**, then calculate both values before comparing them.

The value <InlineMath math="x" /> is <InlineMath math="\frac34" /> of <InlineMath math="34" />. Therefore:

<MathContainer>
  <BlockMath math="x = \frac{3}{4} \times 34" />
  <BlockMath math="x = \frac{102}{4} = 25.5" />
</MathContainer>

The value <InlineMath math="y" /> is <InlineMath math="46\%" /> of <InlineMath math="86" />. Therefore:

<MathContainer>
  <BlockMath math="y = 46\% \times 86" />
  <BlockMath math="y = \frac{46}{100} \times 86" />
  <BlockMath math="y = \frac{3956}{100} = 39.56" />
</MathContainer>

Based on the calculations above, we get <InlineMath math="x = \frac{102}{4} = 25.5" /> and <InlineMath math="y = \frac{3956}{100} = 39.56" />.

Consequently, <InlineMath math="x < y" />.
