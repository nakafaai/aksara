First compute three basic measures, then check how each measure **reacts to changes in the data**.

# Mean, median and range

<BlockMath math="\begin{aligned}
\bar x&=\frac{70+75+80+80+85+90}{6}=\frac{480}{6}=80\\
\text{median}&=\frac{80+80}{2}=80\\
\text{range}&=90-70=20
\end{aligned}" />

The second statement is true. The range is **the largest value minus the smallest**, 20, so the third statement is false.

# Effect of changing the data

Replacing 90 with 100 does not change the order, and the two middle values stay 80 and 80. **The median does not depend on the size of an extreme value**, so it stays 80 and the first statement is false. The change only raises the mean.

Adding 5 to every value shifts the whole data set by 5, so the two middle values become 85 and 85. The median becomes 85, so the fourth statement is true.

So the first statement is **false**, the second is **true**, the third is **false**, and the fourth is **true**.
