The word PELANGI has 7 letters, all different: the vowels E, A, I and the consonants P, L, N, G. The way to guarantee that no two vowels touch is **arranging the consonants first, then inserting the vowels into the gaps**.

# Arranging the consonants

The four consonants can be arranged in <InlineMath math="4!=24" /> ways. Each arrangement has **five gaps**: before the first letter, between letters, and after the last letter.

# Inserting the vowels

The three different vowels go into **3 different gaps**, and their order matters.

<BlockMath math="\begin{aligned}
P(5,3)&=5\cdot4\cdot3=60\\
\text{arrangements}&=24\cdot60=1{,}440
\end{aligned}" />

Since each gap holds at most one vowel, no two vowels can be next to each other.

The value 5,040 is <InlineMath math="7!" />, all arrangements without the condition. The value 576 uses only the 4 gaps between consonants and forgets both ends. The value 720 is <InlineMath math="6!" />, and 2,880 doubles the result for no reason.

So the number of possible arrangements is **1,440**.
