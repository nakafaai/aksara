A linear function has the form <InlineMath math="f(x)=ax+b" />. The first condition usually gives **two functions that both work**, and the sentence about the triple composition's graph picks one of them.

# Two possible functions

The double composition is

<BlockMath math="f\big(f(x)\big)=a(ax+b)+b=a^2x+(ab+b)." />

For it to equal <InlineMath math="4x+9" /> for every <InlineMath math="x" />, the coefficients must match: <InlineMath math="a^2=4" /> and <InlineMath math="b(a+1)=9" />. **A square root has two signs**:

- <InlineMath math="a=2" /> gives <InlineMath math="3b=9" />, so <InlineMath math="f(x)=2x+3" />.
- <InlineMath math="a=-2" /> gives <InlineMath math="-b=9" />, so <InlineMath math="f(x)=-2x-9" />.

Both meet the first condition. Check: <InlineMath math="-2(-2x-9)-9=4x+9" />.

# The condition on the triple composition

The triple composition is <InlineMath math="f\big(f(f(x))\big)=a^3x+b\left(a^2+a+1\right)" />, so **its <InlineMath math="y" />-intercept** is <InlineMath math="b\left(a^2+a+1\right)" />.

<BlockMath math="\begin{aligned}
a=2,\ b=3&:\quad 3(4+2+1)=21>0,\\
a=-2,\ b=-9&:\quad -9(4-2+1)=-27<0.
\end{aligned}" />

# The tempting wrong options

- <InlineMath math="-6" /> adds <InlineMath math="f(3)" /> from both functions, <InlineMath math="9+(-15)" />, **without using the graph condition**.
- <InlineMath math="-15" /> picks <InlineMath math="f(x)=-2x-9" />, the function whose triple composition crosses the <InlineMath math="y" />-axis below the <InlineMath math="x" />-axis.
- <InlineMath math="15" /> takes <InlineMath math="b=9" /> straight from <InlineMath math="4x+9" />, then computes <InlineMath math="2\cdot3+9" />.
- <InlineMath math="21" /> computes <InlineMath math="f\big(f(3)\big)=4\cdot3+9" />, not <InlineMath math="f(3)" />.

So the value of <InlineMath math="f(3)" /> is <InlineMath math="9" />.
