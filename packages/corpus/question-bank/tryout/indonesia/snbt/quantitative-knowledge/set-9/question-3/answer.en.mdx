This fraction has **two kinds of special points**: zeros of the numerator, <InlineMath math="x=1" /> and <InlineMath math="x=-2" />, which may belong because the sign is <InlineMath math="\ge" />, and zeros of the denominator, <InlineMath math="x=0" /> and <InlineMath math="x=2" />, which never belong. The factor <InlineMath math="(x-1)^2" /> is never negative, so it doesn't change the sign.

# Building the set S

The fraction has the same sign as <InlineMath math="\tfrac{x+2}{x(x-2)}" />, except at <InlineMath math="x=1" />, where the fraction is zero.

- For <InlineMath math="x<-2" />: the numerator is negative and the denominator positive, so negative.
- For <InlineMath math="-2\le x<0" />: the numerator is non-negative and the denominator positive, so non-negative.
- For <InlineMath math="0<x<2" />: the denominator is negative, so negative, **except at <InlineMath math="x=1" />**, where the value is exactly zero.
- For <InlineMath math="x>2" />: positive.

So <InlineMath math="S=[-2,0)\cup\{1\}\cup(2,\infty)" />. The number line below shows that **<InlineMath math="x=1" /> is a single point** in the middle of a negative region.

# Statement one

Between <InlineMath math="0" /> and <InlineMath math="2" />, the only member of <InlineMath math="S" /> is the single point <InlineMath math="1" />, and it's an integer. **This single point is easy to lose** if <InlineMath math="(x-1)^2" /> is simply crossed out. The statement is true.

# Statement two

The integer members of <InlineMath math="S" /> below <InlineMath math="3" /> are <InlineMath math="-2" />, <InlineMath math="-1" />, and <InlineMath math="1" />, so there are three. **Four comes from counting <InlineMath math="0" /> or <InlineMath math="2" />**, where the denominator is zero. The statement is false.

# Statement three

One counterexample is enough. **Take <InlineMath math="x=-1" />**, a member of <InlineMath math="S" />. Then <InlineMath math="x+3=2" />, which isn't in <InlineMath math="S" />. Another one: <InlineMath math="x=-1.5" /> gives <InlineMath math="1.5" />, which lies in the negative region. The statement is false.

# Statement four

The negative members of <InlineMath math="S" /> all lie in <InlineMath math="[-2,0)" />, so **their distance from zero is at most <InlineMath math="2" />** and <InlineMath math="x^2\le4" />. The endpoint <InlineMath math="x=-2" /> belongs, and there <InlineMath math="x^2=4" />, which still fits. The statement is true.

So statements one and four are true, while statements two and three are false.
