Wärmeleitung bezeichnet **Wärmeübertragung durch Material**, etwa von der Innen- zur Außenseite der Gefäßwand. Unterscheide sie von den weiteren Vorgängen im Text.

| Mechanismus | Beispiel im Versuch |
| --- | --- |
| Wärmeleitung | Energie gelangt durch die Gefäßwand |
| Konvektion | Bewegtes Wasser oder bewegte Luft transportiert Energie |
| Strahlung | Energie wird durch elektromagnetische Wellen übertragen |
| Verdunstung | Oberflächenwasser wird zu Dampf und führt Energie ab |

Die Temperaturtabelle zeigt das gemeinsame Ergebnis der wirksamen Vorgänge. Die Definition benennt einen Mechanismus, misst aber weder seinen Beitrag noch belegt sie das Fehlen der anderen.
