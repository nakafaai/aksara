**Pengukuran ulang yang mengelompok di sekitar 4,81 meter memberi alasan untuk tidak memakai 4,35 meter, sedangkan penandaan mempertahankan jejak alasan pengecualiannya.**

The values 4.80, 4.82, and 4.81 metres cluster closely and come from the same procedure. The mud mark provides a physical explanation for the different 4.35-metre reading. Because this reason is recorded, a reader can review the team's decision to exclude that value. This differs from silently deleting data simply because the number is inconvenient.
