**Mendorong tim menilai keragaman sejak tahap perancangan dan membedakan perbaikan informasi dari akses nyata terhadap alat bermain.**

The definition becomes an evaluation standard. If diversity is considered from the beginning, different groups should help shape the icons before failure leads to a patch. The definition also prevents an oversized claim. A map can improve information, but an inclusive playground still depends on what happens when children try to use its equipment.
