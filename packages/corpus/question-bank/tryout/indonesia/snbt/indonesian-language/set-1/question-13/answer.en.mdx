A factual sentence presents **information that can be checked** against evidence. Compare the functions of the answer choices.

| Sentence | Content and function |
| --- | --- |
| (1) | An invitation in a quotation |
| (3) | An interpretation of the quotation |
| (7) | A figurative description of traffic |
| (8) | The opening of an imagined scene |
| (10) | Data giving Lake Semayang an area of about <InlineMath math="13{,}000\,\text{ha}" /> and an average depth of about <InlineMath math="3.5\,\text{m}" /> |

The data in **sentence (10)** can be compared with measurements or geographic records. That makes it the measurable fact requested. Numbers help us recognize data, but they still need verification. Including a number does not automatically make a claim true.
