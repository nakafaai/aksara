Ein Tatsachensatz enthält Angaben, die sich anhand von Belegen überprüfen lassen. Satz <InlineMath math="(10)" /> nennt messbare Daten zum Semayang-See: eine Fläche von etwa <InlineMath math="13{.}000\text{ hektare}" />, also dreizehntausend Hektar, und eine mittlere Tiefe von ungefähr <InlineMath math="3{,}5\text{ meter}" />, also dreieinhalb Metern.

Die anderen Sätze erfüllen andere Funktionen:

- Satz <InlineMath math="(1)" /> ist eine Aufforderung in einem Zitat.
- Satz <InlineMath math="(3)" /> deutet dieses Zitat.
- Satz <InlineMath math="(7)" /> verwendet eine bildhafte Formulierung.
- Satz <InlineMath math="(8)" /> eröffnet eine vorgestellte Szene.

Die messbare Tatsache steht daher in **Satz <InlineMath math="(10)" />**.
