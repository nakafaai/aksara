Ein Tatsachensatz enthält **überprüfbare Angaben**. Vergleiche die Funktionen der angebotenen Sätze.

| Satz | Inhalt und Funktion |
| --- | --- |
| (1) | Eine Aufforderung in einem Zitat |
| (3) | Eine Deutung des Zitats |
| (7) | Eine bildhafte Beschreibung des Verkehrsstaus |
| (8) | Der Beginn einer vorgestellten Szene |
| (10) | Angaben zum Semayang-See: etwa <InlineMath math="13{.}000\,\text{ha}" /> Fläche und ungefähr <InlineMath math="3{,}5\,\text{m}" /> mittlere Tiefe |

Die Daten in **Satz (10)** lassen sich mit Messungen oder geografischen Aufzeichnungen vergleichen. Darin liegt die gesuchte messbare Tatsache. Zahlen helfen, Daten zu erkennen, müssen aber ebenfalls geprüft werden: Eine Behauptung wird nicht allein dadurch wahr, dass sie eine Zahl enthält.
