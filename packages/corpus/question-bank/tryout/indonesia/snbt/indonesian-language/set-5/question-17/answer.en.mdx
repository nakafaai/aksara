**Buku pesanan menunjukkan pola jenis perbaikan lintas waktu, sedangkan wawancara memberi kemungkinan alasan; keduanya saling melengkapi tanpa menjadi bukti yang setara.**

Consider what each source actually preserves. The order book records transactions as they occur, so it is useful for tracing repair types over time. The later interviews rely on memory but can add context about possible reasons. Their different functions allow them to complement each other without becoming equivalent evidence.
