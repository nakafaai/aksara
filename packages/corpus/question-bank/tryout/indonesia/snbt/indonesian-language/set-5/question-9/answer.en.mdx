*Rangkaian tertutup*, a closed circuit, identifies **a complete path for current** in the model. The connections determine the shape of that path.

| Arrangement | Path through the two bulbs |
| --- | --- |
| Series | One path passes through both bulbs in sequence |
| Parallel | The path splits, with one bulb on each branch |

With a battery connected, a closed path allows current to flow. The definition links the component arrangement to the electrical process being discussed. Naming the condition does not remove the voltage and scale differences between the model and household wiring.
