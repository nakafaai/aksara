More light passes through the filtered sample. Use **percentage-point differences**, because the original values are already percentages.

| Unfiltered reference | Calculation | Meaning |
| --- | --- | --- |
| Baseline | <InlineMath math="68-46=22" /> | Light transmission is 22 percentage points higher |
