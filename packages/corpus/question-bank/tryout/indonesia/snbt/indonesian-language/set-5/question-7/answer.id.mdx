**Pengulangan model membantu memeriksa bahwa susunan komponen menentukan jalur arus dan perilaku setiap lampu. Karena model memakai tegangan rendah dan tidak mewakili instalasi rumah, hasilnya tidak boleh langsung diterapkan pada jaringan listrik bangunan.**

Perbandingan rangkaian seri dan paralel mengisolasi hubungan susunan dengan perilaku lampu. Batas tegangan dan skala instalasi membuat model cocok untuk menguji prinsip, bukan untuk menyimpulkan keselamatan atau kinerja instalasi rumah.
