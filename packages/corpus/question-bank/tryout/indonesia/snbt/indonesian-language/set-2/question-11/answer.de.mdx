Ein Tatsachensatz enthält Angaben, deren Richtigkeit überprüft werden kann. Eine genannte Quelle, ein Datum, ein Ort oder konkrete Daten schaffen dafür einen klaren Prüfweg.

Satz <InlineMath math="(2)" /> enthält all diese Merkmale. Er nennt *Media Indonesia* und das Veröffentlichungsdatum, führt KLHK als Quelle der Schätzung an, bezeichnet Riau als Gebiet und gibt mit <InlineMath math="200\text{-}300" /> Elefanten einen konkreten Wertebereich an. Diese Angabe lässt sich über die verlinkte Quelle prüfen.

Die übrigen Optionen erfüllen eine andere Funktion:

- Satz <InlineMath math="(7)" /> ist eine Frage.
- Satz <InlineMath math="(12)" /> kennzeichnet mit *menurut penulis* ausdrücklich eine Ansicht des Verfassers.
- Satz <InlineMath math="(29)" /> formuliert eine diskutierbare Bewertung.
- Satz <InlineMath math="(32)" /> drückt mit *mungkin* lediglich eine Möglichkeit aus.

Damit ist **Satz <InlineMath math="(2)" />** der Satz, der am eindeutigsten überprüfbare Daten mit einer Quelle verbindet.
