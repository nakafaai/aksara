**Ausgangsdaten**, im Text *data dasar*, liefern einen Bezug vor der Änderung. Die drei Werte erfüllen unterschiedliche Aufgaben, obwohl sie dieselbe Messeinheit verwenden.

| Mittlere abgeschlossene Ausleihen pro Besuch | Funktion |
| --- | --- |
| <InlineMath math="24" /> | Ausgangsdaten vor dem Test des Fahrplanaushangs |
| <InlineMath math="35" /> | Ergebnis während des Aushangtests |
| <InlineMath math="26" /> | Ergebnis unter der Vergleichsbedingung ohne Aushang |

Die Definition erklärt, warum <InlineMath math="24" /> als Bezug für die Veränderung dient. Der Wert <InlineMath math="26" /> bleibt eine weitere Vergleichsgröße. Ein **Bezugswert beweist allein keine Ursache** und ersetzt weder Rückmeldungen noch die Prüfung von Wettereinflüssen.
