**Baseline data**, or *data dasar*, provides a reference before the change. The three values have different roles even though they use the same measurement unit.

| Average completed loans per visit | Role |
| --- | --- |
| <InlineMath math="24" /> | Initial data before the timetable summary was tested |
| <InlineMath math="35" /> | Result during the timetable-summary trial |
| <InlineMath math="26" /> | Result in the comparison condition without the summary |

The definition explains why <InlineMath math="24" /> is used to assess change from the initial situation. The value <InlineMath math="26" /> remains another comparison. A **reference point does not establish causation** by itself, nor replace user feedback or checks on weather effects.
