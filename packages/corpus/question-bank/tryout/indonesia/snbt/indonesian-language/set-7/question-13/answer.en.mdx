Convert the patient counts to **proportions with the same denominator**: 60 patients in each condition.

| Signs | Proportion calculation | Result |
| --- | --- | --- |
| Old | <InlineMath math="\frac{42}{60}\times100\%" /> | 70 percent |
| New | <InlineMath math="\frac{56}{60}\times100\%" /> | About 93.3 percent |

The difference between proportions is expressed in **percentage points**. Use the original fractions so rounding occurs at the end:

<BlockMath math="\left(\frac{56}{60}-\frac{42}{60}\right)\times100=\frac{14}{60}\times100\approx23.3" />

Relative increase uses the old proportion as its base and gives a different result:

<BlockMath math="\frac{56-42}{42}\times100\%\approx33.3\%" />

The correct difference is therefore about 23.3 percentage points. The value 14 counts people, while 33.3 percent is a relative increase, not a percentage-point difference.
