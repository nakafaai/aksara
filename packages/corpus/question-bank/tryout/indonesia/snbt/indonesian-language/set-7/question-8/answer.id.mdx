**Mengikuti populasi dan sumber dayanya dari waktu ke waktu sambil mencatat migrasi, kelahiran, kematian, serta struktur umur.**

Model mengusulkan bahwa batas sumber daya berkaitan dengan batas populasi. Jadi, pengujian lanjutannya perlu mencatat keduanya pada populasi nyata. Menambah keping di kelas saja tidak cukup. Catatan kelahiran, kematian, migrasi, dan struktur umur diperlukan untuk menafsirkan perubahan jumlah individu. Pengamatan berulang kemudian dapat menguji apakah batas itu tetap atau ikut bergeser saat kondisi lingkungan berubah.
