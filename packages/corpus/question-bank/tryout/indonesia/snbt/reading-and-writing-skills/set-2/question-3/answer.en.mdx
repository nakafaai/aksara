Sentence <InlineMath math="(9)" /> assigns boundaries to children. Sentence <InlineMath math="(10)" /> adds the contrasting point that adults should follow those boundaries too.

The coordinating conjunction **but** preserves that contrast and joins two independent clauses correctly after a comma.

The correct combination is: _A family media plan should set boundaries for children, but the same boundaries should also apply to adults._ The alternatives either change the relationship to cause or result, leave a subordinate clause unfinished, or create a comma splice.
