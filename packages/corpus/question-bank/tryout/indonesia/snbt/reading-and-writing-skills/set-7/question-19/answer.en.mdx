**The team changed only one factor: adding a return code to each handle.**

**One factor** requires a singular noun, and **only** supplies the restriction once. The colon introduces the specified change after a complete clause.

The alternatives use plural *factors*, repeat the restriction with *merely only*, put an unnecessary colon after *namely*, or use a semicolon before a phrase that is not an independent clause.
