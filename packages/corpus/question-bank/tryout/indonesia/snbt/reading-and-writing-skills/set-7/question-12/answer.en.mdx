**On Monday, the team tested the return code on each umbrella handle.**

**On** begins the sentence, and **Monday** is a weekday, so both take capitals. **The team** remains lowercase within the sentence, and a full stop ends the statement.

A comma after a short time phrase can be optional. The final option nevertheless fails because it omits the full stop. The other options incorrectly capitalise one of these words.
