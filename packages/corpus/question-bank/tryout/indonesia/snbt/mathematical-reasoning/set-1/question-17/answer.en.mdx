Each match is determined by **a pair of teams**, and the order of the two teams does not matter. So the number of matches equals the number of ways to choose 2 teams from 6.

# Counting pairs of teams

<BlockMath math="\binom62=\frac{6\cdot5}{2}=15" />

# Check from each team's side

Each team plays the 5 other teams, giving <InlineMath math="6\cdot5=30" /> match records. Each match **is recorded twice**, once by each team in it, so the number of matches is <InlineMath math="\tfrac{30}{2}=15" />.

So the competition has **15 matches**.
