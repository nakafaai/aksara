<BlockMath math="\begin{aligned}

\end{aligned}" />

# The number of books

The actual weight of a parcel with <InlineMath math="n" /> books is the box's mass plus the books' mass. The empty box **is weighed too**.

<BlockMath math="\begin{aligned}
0.6+0.6n &\le 7.3\\
0.6n &\le 6.7\\
n &\le 11\tfrac{1}{6}
\end{aligned}" />

The number of books has to be a whole number, so <InlineMath math="n=11" />. That many also fits, since the box holds up to <InlineMath math="20" /> books.
