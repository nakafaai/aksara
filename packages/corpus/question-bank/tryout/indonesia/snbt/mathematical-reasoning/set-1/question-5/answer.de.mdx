# Das Volumengewicht jedes Kartons

Das Volumengewicht ist das Produkt der Kartonmaße geteilt durch <InlineMath math="6{.}000" />. Diese Regel gibt es, weil ein großer, leichter Karton im Fahrzeug trotzdem Platz braucht. Darum wird **das größere von tatsächlichem Gewicht und Volumengewicht berechnet**.

<BlockMath math="\begin{aligned}
