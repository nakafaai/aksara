Compute the bill for each usage in the same way: **the fixed charge plus the cost of every block passed**.

# Bills for 100 kWh and 200 kWh

<BlockMath math="\begin{aligned}
T(100)&=20{,}000+100\cdot1{,}000=120{,}000\\
T(200)&=20{,}000+100{,}000+100\cdot1{,}500=270{,}000
\end{aligned}" />

The first statement is true. Twice <InlineMath math="T(100)" /> is 240,000, not 270,000, because **the fixed charge is paid only once** and the second 100 kWh fall in block 2. The third statement is false.

# The 301st kWh and a usage of 400 kWh

The 301st kWh is already in block 3, so **it adds Rp2,000**, not Rp1,500. The second statement is false.

<BlockMath math="\begin{aligned}
T(400)&=20{,}000+100{,}000+300{,}000+100\cdot2{,}000=620{,}000\\
\frac{620{,}000}{400}&=1{,}550
\end{aligned}" />

The fourth statement is true.

So the first statement is **true**, the second is **false**, the third is **false**, and the fourth is **true**.
