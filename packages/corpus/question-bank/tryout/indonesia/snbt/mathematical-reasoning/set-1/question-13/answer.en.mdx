You need to count the odd-numbered seats in each category, then multiply by that category's price. What decides it: **every row has an odd number of seats, so the odd-numbered seats are always one more than half**.

# The number of seats in each row

Row <InlineMath math="1" /> has <InlineMath math="19" /> seats and each row after it adds <InlineMath math="2" />. That's an arithmetic sequence, so row <InlineMath math="n" /> has <InlineMath math="19+2(n-1)=17+2n" /> seats. The number <InlineMath math="17+2n" /> is **always odd**.

In a row with <InlineMath math="s" /> seats and <InlineMath math="s" /> odd, the odd seat numbers are <InlineMath math="1,3,\ldots,s" />, which makes <InlineMath math="\tfrac{s+1}{2}" /> of them. For row <InlineMath math="n" /> that's <InlineMath math="\tfrac{17+2n+1}{2}=9+n" />.

# Odd-numbered seats per category

The number of odd seats per row, <InlineMath math="9+n" />, is an arithmetic sequence too. Add it up with **the number of terms times the average of the first and last terms**.

<BlockMath math="\begin{aligned}
\text{A, rows }1\text{ to }6 &: 10+11+\cdots+15=\tfrac{6(10+15)}{2}=75\\
\text{B, rows }7\text{ to }16 &: 16+17+\cdots+25=\tfrac{10(16+25)}{2}=205\\
\text{C, rows }17\text{ to }30 &: 26+27+\cdots+39=\tfrac{14(26+39)}{2}=455
\end{aligned}" />

# The revenue

Multiply each category's seat count by its price, because **each category has its own price**.

<BlockMath math="\begin{aligned}
\text{revenue} &= 75\cdot250{,}000+205\cdot150{,}000+455\cdot100{,}000\\
&= 18{,}750{,}000+30{,}750{,}000+45{,}500{,}000\\
&= 95{,}000{,}000
\end{aligned}" />

# Checking the answer

The whole stand has <InlineMath math="\tfrac{30(19+77)}{2}=1{,}440" /> seats. In each row the odd seats are half the seats plus one half, so the total is <InlineMath math="\tfrac{1{,}440+30}{2}=735" />. That **matches** <InlineMath math="75+205+455=735" />.
