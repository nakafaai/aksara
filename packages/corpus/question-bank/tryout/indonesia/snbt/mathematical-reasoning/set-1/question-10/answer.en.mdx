The lower quartile is the value **with a quarter of the data below it**. For 40 values, the lower quartile lies around the 10th value.

# Cumulative frequency

The cumulative frequency shows **how many values lie up to the end of each class**.

| Class | Frequency | Cumulative frequency |
| :---: | :---: | :---: |
| 0-9 | 4 | 4 |
| 10-19 | 10 | 14 |
| 20-29 | 15 | 29 |

# Finding the class

The class 0-9 holds only values 1 to 4. The class 10-19 holds **values 5 to 14**, so the 10th value is in this class.

The class 20-29 is the median class and the modal class, not the lower quartile class. The class 0-9 holds only 4 values, less than a quarter of 40.

So the lower quartile lies in the class **10-19 minutes**.
