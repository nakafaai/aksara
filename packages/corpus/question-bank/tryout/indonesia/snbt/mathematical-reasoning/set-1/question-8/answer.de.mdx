# Die Rolle des Volumengewichts

Das Volumengewicht des Kartons ist

<BlockMath math="\frac{56\cdot40\cdot30}{6{.}000}=\frac{67{.}200}{6{.}000}=11{,}2\text{ kg}" />

Das Ausgangsgewicht ist das größere von tatsächlichem Gewicht und <InlineMath math="11{,}2\text{ kg}" />, also ist es **nie kleiner als** <InlineMath math="11{,}2\text{ kg}" />. Teile jetzt in zwei Fälle auf.

- Wiegt das Paket höchstens <InlineMath math="11{,}2\text{ kg}" />, ist das Ausgangsgewicht <InlineMath math="11{,}2\text{ kg}" />.
