The median is the value between the 20th and 21st of the 40 sorted values, **the point that splits the data into two equal halves**. For grouped data, find its class and then estimate it by interpolation.

# Finding the median class

Add the frequencies from the lowest class: 4, then <InlineMath math="4+10=14" />, then <InlineMath math="14+15=29" />. The 20th value lies **in the class 20-29**, because 14 values come before that class.

# Interpolating inside the class

The class 20-29 has lower boundary 19.5, width 10 and 15 values. We need <InlineMath math="20-14=6" /> more values from that class.

<BlockMath math="\text{Me}=19.5+\frac{20-14}{15}\cdot10=19.5+4=23.5" />

The result does lie between 19.5 and 29.5, matching the median class.

So the median travel time is **23.5 minutes**.
