Compare the actual weight with the volumetric weight, take **the larger one**, round it up, then multiply by the rate.

# Volumetric weight

# Charged weight and cost

The volumetric weight of 5 kg **is greater than the actual 4.2 kg**, so 5 kg is charged. The number 5 is already whole.

<BlockMath math="5\cdot9{,}000=45{,}000" />

In thousands of rupiah the cost is 45. Using the actual 4.2 kg rounded up to 5 kg happens to give the same number, but for a different reason.

So shipping the parcel costs **45 thousand rupiah**.
