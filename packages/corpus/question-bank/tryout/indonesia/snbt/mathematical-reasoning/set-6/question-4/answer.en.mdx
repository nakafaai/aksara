The average number of goals per match is **the total number of goals divided by the number of matches**. Both numbers must be counted carefully so that nothing is counted twice.

# Total number of goals

Each goal is recorded as a goal scored by one team. The goals scored column adds up to

<BlockMath math="8+6+5+3+2=24" />

The goals conceded column also adds up to 24, because it **records the same goals from the opponent's side**, so the two columns must not be added together.

# Number of matches and the average

Every two teams play once, so there are <InlineMath math="\binom52=10" /> matches.

<BlockMath math="\frac{24}{10}=2.4" />

The value 4.8 adds goals scored and goals conceded, so every goal is counted twice. The value 6 divides 24 by 4, the number of matches per team, not the total number of matches.

So the average number of goals per match is **2.4**.
