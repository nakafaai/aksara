#### Defining Variables

Let:
- Number of type <InlineMath math="\text{I}" /> trucks be <InlineMath math="x" />.
- Number of type <InlineMath math="\text{II}" /> trucks be <InlineMath math="y" />.
- Number of type <InlineMath math="\text{III}" /> trucks be <InlineMath math="z" />.

#### Forming System of Equations

From the problem, we know:
1. The total number of trucks rented is <InlineMath math="20" />.

   <BlockMath math="x + y + z = 20 \quad (1)" />

2. The total carrying capacity is <InlineMath math="96\text{ t}" />, with capacities for each type being <InlineMath math="3" />, <InlineMath math="4" />, and <InlineMath math="6\text{ t}" />, respectively.

   <BlockMath math="3x + 4y + 6z = 96 \quad (2)" />

3. It is known that the company rents <InlineMath math="4" /> type <InlineMath math="\text{I}" /> trucks.

   <BlockMath math="x = 4" />

#### Solving the System

Substitute <InlineMath math="x = 4" /> into equation <InlineMath math="(1)" />:

<MathContainer>
  <BlockMath math="4 + y + z = 20" />
  <BlockMath math="y + z = 16 \quad (3)" />
</MathContainer>

Substitute <InlineMath math="x = 4" /> into equation <InlineMath math="(2)" />:

<MathContainer>
  <BlockMath math="3(4) + 4y + 6z = 96" />
  <BlockMath math="12 + 4y + 6z = 96" />
  <BlockMath math="4y + 6z = 84" />
</MathContainer>

Simplify the equation above by dividing both sides by <InlineMath math="2" />:

<BlockMath math="2y + 3z = 42 \quad (4)" />

Eliminate variable <InlineMath math="z" /> from equations <InlineMath math="(3)" /> and <InlineMath math="(4)" />. Multiply equation <InlineMath math="(3)" /> by <InlineMath math="3" /> (or by <InlineMath math="2" /> to eliminate <InlineMath math="y" />; here we find <InlineMath math="y" /> directly by eliminating <InlineMath math="z" />):

<BlockMath math="\begin{aligned}3(y+z)&=3(16) \\ 3y+3z&=48 \\ 2y+3z&=42\end{aligned}" />

Subtract the second equation from the first:

<MathContainer>
  <BlockMath math="\begin{aligned}&(3y+3z)-(2y+3z) \\ &\quad=48-42\end{aligned}" />
  <BlockMath math="y = 6" />
</MathContainer>

Thus, the number of type <InlineMath math="\text{II}" /> trucks rented is <InlineMath math="6" />.
