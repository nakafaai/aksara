The draws column records results from each team's point of view. One drawn match **is recorded twice**, once for each team in it.

# Total draw records

<BlockMath math="1+1+2+1+1=6" />

# Number of drawn matches

<BlockMath math="\frac{6}{2}=3" />

Check: the wins add up to <InlineMath math="3+2+1+1+0=7" />, equal to the losses <InlineMath math="0+1+1+2+3=7" />, and <InlineMath math="7+3=10" /> equals the number of matches, <InlineMath math="\binom52" />.

The value 6 is the number of draw records before halving. The value 10 is the total number of matches.

So **3 matches** ended in a draw.
