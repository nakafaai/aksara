After <InlineMath math="n" /> folds the stack has <InlineMath math="2^n" /> layers and **a thickness of <InlineMath math="0.1\cdot2^n" /> mm**. Each statement is checked with this formula.

# Five and seven folds

<BlockMath math="\begin{aligned}
n=5&:\quad 0.1\cdot2^5=0.1\cdot32=3.2\text{ mm}\\
n=7&:\quad 2^7=128\text{ layers}
\end{aligned}" />

The first statement is true. Seven folds give 128 layers, **not 64**, so the third statement is false.

# The doubling pattern and twenty folds

From 1 to 2 folds the thickness rises from 0.2 mm to 0.4 mm, an increase of 0.2 mm, not 0.1 mm. The increase **grows with every fold**, so the second statement is false.

<BlockMath math="0.1\cdot2^{20}=0.1\cdot1{,}048{,}576=104{,}857.6\text{ mm}\approx104.9\text{ m}" />

The thickness is more than 100 m, so the fourth statement is true.

So the first statement is **true**, the second is **false**, the third is **false**, and the fourth is **true**.
