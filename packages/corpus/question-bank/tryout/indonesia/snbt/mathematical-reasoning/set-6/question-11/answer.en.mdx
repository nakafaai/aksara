For each box, compute the volumetric weight, compare it with the actual weight, then **round the larger one up**.

# A small, heavy box

The book: its volumetric weight is <InlineMath math="\tfrac{20\cdot15\cdot5}{6{,}000}=0.25" /> kg, far below the actual 2.3 kg. The charge uses 2.3 kg rounded up to 3 kg, so the second statement is true.

This example also shows that for heavy parcels **the cost is set by the actual weight**. A smaller box for the book would not change the cost, so the first statement is false.

# A large box and a cube

The large box is charged 20 kg because 20 kg is more than 8 kg, so the third statement is true. The cube's volumetric weight is 4.5 kg, **not 5 kg**. Rounding up applies only to the charged weight, so the fourth statement is false.

So the first statement is **false**, the second is **true**, the third is **true**, and the fourth is **false**.
