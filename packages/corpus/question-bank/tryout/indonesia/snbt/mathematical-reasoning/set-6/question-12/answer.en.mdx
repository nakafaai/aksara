Compute **the charged weight for both boxes**, then compare the costs.

# The original box

Its volumetric weight is <InlineMath math="\tfrac{50\cdot40\cdot30}{6{,}000}=10" /> kg, more than 4.8 kg, so **10 kg is charged**, Rp90,000.

# The new box and the saving

The new box has a volumetric weight of <InlineMath math="\tfrac{45\cdot30\cdot20}{6{,}000}=\tfrac{27{,}000}{6{,}000}=4.5" /> kg. This time **the actual 4.8 kg is larger**, and it rounds up to 5 kg.

<BlockMath math="\begin{aligned}
\text{new cost}&=5\cdot9{,}000=45{,}000\\
\text{saving}&=90{,}000-45{,}000=45{,}000
\end{aligned}" />

The smaller box works because the volumetric weight drops almost to the actual weight. Shrinking the box further would not lower the cost, since the actual weight stays 4.8 kg.

So the saving is **Rp45,000**.
