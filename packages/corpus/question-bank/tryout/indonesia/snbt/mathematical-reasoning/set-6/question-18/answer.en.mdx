# The first statement about a mixer filled to the top

If every batch fills the mixer to <InlineMath math="0.2\text{ m}^3" />, the number of batches is <InlineMath math="3.3:0.2=16.5" />. Half a batch isn't possible, so **<InlineMath math="17" /> batches are needed**, and <InlineMath math="17" /> is not fewer than <InlineMath math="17" />. The first statement is false.

# The second statement about the new ratio

With the ratio <InlineMath math="1:3:4" />, one bag of cement carries <InlineMath math="1+3+4=8" /> parts of dry mix.

<BlockMath math="8\cdot0.025=0.2\text{ m}^3" />

That volume is **exactly the capacity of the mixer**, and the mixer holds at most <InlineMath math="0.2\text{ m}^3" />, so the batch still fits. The second statement is true.

# The third statement about the gravel

Gravel is <InlineMath math="3" /> of the <InlineMath math="6" /> parts of the dry mix.

<BlockMath math="\tfrac36\cdot3.3=1.65\text{ m}^3" />

Since <InlineMath math="1.65<1.7" />, the third statement is false. You only get past <InlineMath math="1.7" /> if **the reserve is counted twice**.

# The fourth statement about the reserve

Without the reserve the dry mix is <InlineMath math="3\text{ m}^3" />, so the cement is <InlineMath math="0.5\text{ m}^3" /> or <InlineMath math="20" /> bags. The number of bags falls from <InlineMath math="22" /> to <InlineMath math="20" />.

<BlockMath math="\frac{22-20}{22}=\frac{1}{11}\approx9.1\%" />

The drop is **measured against <InlineMath math="22" /> bags**, not against <InlineMath math="20" />, so it isn't exactly <InlineMath math="10\%" />. The fourth statement is false.

So the first statement is false, the second is true, the third is false and the fourth is false.
