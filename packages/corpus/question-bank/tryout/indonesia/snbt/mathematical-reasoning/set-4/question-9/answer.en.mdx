The number of passengers on the bus changes at each stop: **add those who board and subtract those who alight**. Run this count from the first terminal.

# Counting stop by stop

<BlockMath math="\begin{aligned}
\text{first terminal}&:\quad 0+25=25\\
\text{Stop A}&:\quad 25+12-8=29\\
\text{Stop B}&:\quad 29+6-10=25\\
\text{Stop C}&:\quad 25+9-7=27
\end{aligned}" />

The count must run **in order from the start**, because each stop depends on the number of passengers before it.

So when the bus leaves Stop C there are **27 people** on board.
