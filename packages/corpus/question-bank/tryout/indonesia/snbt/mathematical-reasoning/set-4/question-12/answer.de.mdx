Zuerst bestimmen wir, wie viel Taschengeld pro Schultag insgesamt für alle drei Kinder zur Verfügung steht.

**Tagesgeld insgesamt:**

<MathContainer>
  <BlockMath math="\text{Monatlicher Zuschuss} = 10\% \times 4{.}800{.}000 = 480{.}000" />
  <BlockMath math="\text{Schultage} = 30 - 6 = 24 \text{ Tage}" />
  <BlockMath math="\text{Insgesamt täglich} = \frac{480{.}000}{24} = 20{.}000" />
</MathContainer>

Kind <InlineMath math="A" /> erhält <InlineMath math="\text{Rp}4{.}000" /> und entspricht im Verhältnis dem Anteil <InlineMath math="4" />. Der Gesamtbetrag von <InlineMath math="\text{Rp}20{.}000" /> entspricht der Summe der Anteile <InlineMath math="4 + 3 + x" />.

**Wert von <InlineMath math="x" />:**

<MathContainer>
  <BlockMath math="\frac{\text{Zulage } A}{\text{Gesamtzulage}} = \frac{\text{Anteil } A}{\text{Gesamtanteil}}" />
  <BlockMath math="\frac{4{.}000}{20{.}000} = \frac{4}{4 + 3 + x}" />
  <BlockMath math="\frac{1}{5} = \frac{4}{7 + x}" />
  <BlockMath math="7 + x = 20 \Rightarrow x = 13" />
</MathContainer>

Daher ist der Wert von <InlineMath math="x" /> <InlineMath math="13" />.
