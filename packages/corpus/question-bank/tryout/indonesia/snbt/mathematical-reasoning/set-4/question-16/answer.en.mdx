An upright can takes a square patch of **diameter by diameter** on the floor of the box, and each layer is as tall as a can. Count the cans in each direction.

# Cans in each direction

**The diameter of can A is 8 cm** and its height is 10 cm.

<BlockMath math="\begin{aligned}
32:8&=4\text{ cans}\\
24:8&=3\text{ cans}\\
20:10&=2\text{ layers}
\end{aligned}" />

# Total number of cans

<BlockMath math="4\cdot3\cdot2=24" />

All three divisions come out exactly, so this row-and-column arrangement fills the box tightly. The value 12 counts only **one layer**, although the box is tall enough for two.

So the largest number of cans that fit is **24**.
