The number of passengers on a section is **the number on board when the bus leaves the start of that section**. Compute it for all five sections.

# Passengers on each section

Each section's load is **computed in order from the first terminal**.

| Section | Passengers |
| :---: | :---: |
| first terminal to Stop A | 25 |
| Stop A to Stop B | <InlineMath math="25+12-8=29" /> |
| Stop B to Stop C | <InlineMath math="29+6-10=25" /> |
| Stop C to Stop D | <InlineMath math="25+9-7=27" /> |
| Stop D to last terminal | <InlineMath math="27+14-6=35" /> |

# The busiest section

The largest value is 35, on the section from Stop D to the last terminal. Stop D has the most boarders, but what decides is **the running balance of boarding and alighting since the start**.

The section from Stop A to Stop B was high at 29, but it fell again after 10 passengers left at Stop B.

So the bus is fullest on the section **from Stop D to the last terminal**.
