Das Volumen eines Zylinders ist **Grundfläche mal Höhe**. Berechne das Volumen von Entwurf A und dann die Höhe von Entwurf C mit demselben Volumen.

# Volumen von Entwurf A

<BlockMath math="V_A=\pi\cdot4^2\cdot10=160\pi\text{ cm}^3" />

# Höhe von Entwurf C

<BlockMath math="\begin{aligned}
\pi\cdot2^2\cdot t&=160\pi\\
4t&=160\\
t&=40
\end{aligned}" />

Der Radius wird halbiert, die Grundfläche also geviertelt. Damit das Volumen bleibt, **muss die Höhe viermal so groß werden**, von 10 cm auf 40 cm.

Eine Dose nach Entwurf C ist also **40 cm** hoch.
