Banyak penumpang pada suatu ruas adalah **banyak penumpang ketika bus meninggalkan tempat di awal ruas itu**. Hitung untuk kelima ruas.

# Banyak penumpang pada setiap ruas

Muatan setiap ruas **dihitung berurutan dari terminal awal**.

| Ruas | Penumpang |
| :---: | :---: |
| terminal awal ke Halte A | 25 |
| Halte A ke Halte B | <InlineMath math="25+12-8=29" /> |
| Halte B ke Halte C | <InlineMath math="29+6-10=25" /> |
| Halte C ke Halte D | <InlineMath math="25+9-7=27" /> |
| Halte D ke terminal akhir | <InlineMath math="27+14-6=35" /> |

# Ruas terpadat

Nilai terbesar adalah 35, pada ruas Halte D ke terminal akhir. Halte D memiliki penumpang naik terbanyak, tetapi yang menentukan adalah **selisih naik dan turun yang terkumpul sejak awal**.

Ruas Halte A ke Halte B sempat tinggi, yaitu 29, tetapi turun lagi setelah 10 penumpang turun di Halte B.

Jadi, bus paling penuh pada ruas **Halte D ke terminal akhir**.
