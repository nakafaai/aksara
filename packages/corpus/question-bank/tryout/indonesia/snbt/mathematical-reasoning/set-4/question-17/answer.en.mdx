Every data value is multiplied by <InlineMath math="p" />, then reduced by <InlineMath math="q" />. Two rules apply to this transformation:
1. The mean is multiplied by the same factor and reduced by the same amount as each data value.
2. The range is multiplied by <InlineMath math="|p|" />. Subtracting <InlineMath math="q" /> from every value leaves the difference between the largest and smallest values unchanged.

First, find the value of <InlineMath math="p" /> using the range information. Since the initial range of <InlineMath math="6" /> becomes <InlineMath math="9" /> after being multiplied by <InlineMath math="p" />, we have:

<MathContainer>
  <BlockMath math="9 = p \times 6" />
  <BlockMath math="p = \frac{9}{6} = \frac{3}{2}" />
</MathContainer>

Next, we find the value of <InlineMath math="q" /> using the mean information. The mean is affected by both the multiplication by <InlineMath math="p" /> and the subtraction by <InlineMath math="q" />.

<MathContainer>
  <BlockMath math="20 = \left(\frac{3}{2} \times 16\right) - q" />
  <BlockMath math="20 = 24 - q" />
  <BlockMath math="q = 4" />
</MathContainer>

Finally, calculate the requested value using <InlineMath math="p" /> and <InlineMath math="q" />.

<MathContainer>
  <BlockMath math="2p + q = 2\left(\frac{3}{2}\right) + 4" />
  <BlockMath math="2p + q = 3 + 4 = 7" />
</MathContainer>

Thus, the value of <InlineMath math="2p + q" /> is <InlineMath math="7" />.
