The fare is per passenger per section. So the revenue is **the sum of the passengers on each section**, times Rp1,000, because everyone on board during a section pays for that section.

# Passengers summed over all sections

**The passengers on the five sections** are 25, 29, 25, 27 and 35.

<BlockMath math="25+29+25+27+35=141" />

# Revenue

<BlockMath math="141\cdot1{,}000=141{,}000" />

This equals counting how many sections each passenger rides and adding them up, because **each pair of passenger and section is counted exactly once**.

The value Rp330,000 assumes every passenger rides all five sections. The value Rp175,000 uses the top load of 35 for every section. The value Rp264,000 is a flat fare of Rp4,000 for 66 passengers.

So the revenue from one trip is **Rp141,000**.
