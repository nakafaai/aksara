What you add is **the rate**, the part of the pool filled each hour, not the times.

# Rate of each pump

Pump A fills <InlineMath math="\tfrac16" /> **of the pool per hour** and pump B fills <InlineMath math="\tfrac19" /> per hour.

<BlockMath math="\frac16+\frac19=\frac{3}{18}+\frac{2}{18}=\frac{5}{18}" />

# Filling time

<BlockMath math="1:\frac{5}{18}=\frac{18}{5}=3.6\text{ hours}" />

This is **shorter than 6 hours**, the faster pump's time, as expected because the pumps help each other.

So the pool is full in **3.6 hours**, which is 3 hours 36 minutes.
