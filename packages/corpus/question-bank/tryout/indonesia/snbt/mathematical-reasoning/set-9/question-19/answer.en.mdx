# Good parts per hour

# Traps to avoid

The shortfall is small, so **one miscounted hour already flips the conclusion**.

- If P's hours reset to zero every morning, P runs <InlineMath math="42" /> hours and the total is <InlineMath math="3\times2{,}730=8{,}190" />, so the order looks finished.
- If the faulty parts aren't thrown out, the total is <InlineMath math="40\times120+42\times90=8{,}580" />, so the order also looks finished.

So at 23:00 on Wednesday the order is still <InlineMath math="38" /> good parts short.
