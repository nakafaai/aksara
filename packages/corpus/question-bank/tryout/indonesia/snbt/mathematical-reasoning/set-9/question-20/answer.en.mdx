| Route | Least time with the pass |
| --- | ---: |
| S-A-C-T | <InlineMath math="4/2+4+4=10" /> |
| S-A-D-T | <InlineMath math="4+7/2+6=13.5" /> |
| S-B-C-T | <InlineMath math="7/2+2+4=9.5" /> |
| S-B-D-T | <InlineMath math="7/2+5+6=14.5" /> |

The minimum is <InlineMath math="9.5" /> minutes on route S-B-C-T.
