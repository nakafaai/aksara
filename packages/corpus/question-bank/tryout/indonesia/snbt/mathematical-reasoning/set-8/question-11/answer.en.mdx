# The harvest of sixty and forty trees

With <InlineMath math="60" /> trees, each tree yields <InlineMath math="200-120=80\text{ kg}" />. With <InlineMath math="40" /> trees, the first rule applies, so <InlineMath math="120\text{ kg}" /> per tree.

<BlockMath math="\begin{aligned}

\end{aligned}" />

The totals are **exactly the same**, so the first statement is true. The twenty extra trees add nothing to the harvest.
