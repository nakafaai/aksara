# Pemakaian gas per hari

Makin lama kompor kecil menyala, makin besar <InlineMath math="d" />. Tabung jadi lebih cepat ditukar, sehingga **biaya per hari makin mahal**. Jadi kamu mencari nilai <InlineMath math="h" /> terbesar yang masih memenuhi syarat biaya.
