Blood can only be given when **the ABO rule and the rhesus rule both hold**. So for each patient group, find the donor groups that pass both rules, then add up those donors from the table. Once this matching table is complete, you can test the four statements one at a time.

# Negative donors for positive patients

The first statement says every, so one failing example is enough to refute it. An <InlineMath math="\mathrm{A}^-" /> donor passes the rhesus rule for a <InlineMath math="\mathrm{B}^+" /> patient but **fails the ABO rule**, because A donors only give to A and AB patients. The first statement is false.

# The A positive patient

From the table, <InlineMath math="26" /> donors suit an <InlineMath math="\mathrm{A}^+" /> patient. Half of <InlineMath math="40" /> donors is <InlineMath math="20" />, and <InlineMath math="26" /> is **more than half**. The second statement is true.

# The AB negative and O positive patients

Group AB is often called the universal recipient, but that only covers the ABO rule. An <InlineMath math="\mathrm{AB}^-" /> patient **is still bound by the rhesus rule**, so only the <InlineMath math="6" /> rhesus negative donors suit. An <InlineMath math="\mathrm{O}^+" /> patient gets <InlineMath math="16" /> donors. Since <InlineMath math="6<16" />, the third statement is false.

# Exactly four donors

The matching table shows that a <InlineMath math="\mathrm{B}^-" /> patient suits <InlineMath math="\mathrm{B}^-" /> and <InlineMath math="\mathrm{O}^-" /> donors, that's <InlineMath math="2+2=4" /> donors. So **such a group really exists**, and the fourth statement is true.

So the first statement is false, the second is true, the third is false, and the fourth is true.
