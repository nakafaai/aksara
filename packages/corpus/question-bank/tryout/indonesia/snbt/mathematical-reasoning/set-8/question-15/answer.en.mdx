Split the students into **four groups that do not overlap**: influenza only, dengue only, both, and not vaccinated.

# Four groups of students

| Group | Students |
| :--- | :---: |
| Both vaccines | <InlineMath math="300+200-420=80" /> |
| Influenza only | <InlineMath math="300-80=220" /> |
| Dengue only | <InlineMath math="200-80=120" /> |
| Not vaccinated | 60 |

They add up to <InlineMath math="80+220+120+60=480" />, **matching the number of students**.

# Checking the statements

The probability of no vaccine is <InlineMath math="\tfrac{60}{480}=\tfrac18" />, **not <InlineMath math="\tfrac16" />**. The first statement is false. The second statement is true, since 220 students had the influenza vaccine only.

Students who get only the dengue vaccine **do not get the influenza vaccine**, so the group with both stays at 80. The third statement is false.

Exactly one vaccine: <InlineMath math="220+120=340" /> students, more than half the school, which is 240. The fourth statement is true.

So the first statement is **false**, the second is **true**, the third is **false**, and the fourth is **true**.
