#### Counting every step order

Every path needs six steps right and four steps up. **Choose four of the ten step positions** for the upward steps. The other six positions must then be rightward steps.

<BlockMath math="\binom{10}{4}=\frac{10\times9\times8\times7}{4\times3\times2\times1}=210" />

#### Counting paths through forbidden points

Count the step orders for each part of the journey in the same way. Let <InlineMath math="R" /> be the number of rightward steps and <InlineMath math="U" /> the number of upward steps.

| Journey segment | Steps | Number of orders |
| --- | --- | --- |
| <InlineMath math="O\to A" /> | <InlineMath math="R=2,\ U=2" /> | <InlineMath math="\binom{4}{2}=\frac{4\times3}{2\times1}=6" /> |
| <InlineMath math="A\to T" /> | <InlineMath math="R=4,\ U=2" /> | <InlineMath math="\binom{6}{2}=\frac{6\times5}{2\times1}=15" /> |
| <InlineMath math="O\to B" /> | <InlineMath math="R=4,\ U=3" /> | <InlineMath math="\binom{7}{3}=\frac{7\times6\times5}{3\times2\times1}=35" /> |
| <InlineMath math="B\to T" /> | <InlineMath math="R=2,\ U=1" /> | <InlineMath math="\binom{3}{1}=\frac{3}{1}=3" /> |
| <InlineMath math="A\to B" /> | <InlineMath math="R=2,\ U=1" /> | <InlineMath math="\binom{3}{1}=\frac{3}{1}=3" /> |

Every path choice before an intermediate point can be paired with every choice after that point. Therefore, **multiply** the counts for successive journey segments.

<MathContainer>
  <BlockMath math="N_A=6\times15=90" />
  <BlockMath math="N_B=35\times3=105" />
  <BlockMath math="N_{A\cap B}=6\times3\times3=54" />
</MathContainer>

A path through both points must reach <InlineMath math="A" /> first. Returning from <InlineMath math="B" /> to <InlineMath math="A" /> would require a leftward or downward step.

#### Correcting the double subtraction

Subtracting <InlineMath math="N_A" /> and <InlineMath math="N_B" /> removes the same <InlineMath math="54" /> forbidden paths twice. **Add them back once** so that each forbidden path is removed exactly once.

<BlockMath math="\begin{aligned}N&=210-90-105+54\\&=120-105+54\\&=15+54\\&=69\end{aligned}" />

There are **69 paths** that avoid both forbidden points.
