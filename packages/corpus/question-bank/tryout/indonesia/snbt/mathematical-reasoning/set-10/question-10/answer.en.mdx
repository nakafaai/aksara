Treat Ani and Budi as **one block**. Then remember that inside the block they can still swap places.

# Arranging the block and the other three

Block AB with Citra, Dodi and Eka is 4 units, which **can be arranged in 24 ways**.

# Order inside the block

Inside the block the order can be AB or BA.

<BlockMath math="24\cdot2=48" />

The value 24 forgets that Ani and Budi can swap. The value 72 counts the arrangements where they are **not** side by side, <InlineMath math="120-48" />. The value 60 counts Ani anywhere to the left of Budi, not necessarily next to each other. The value 96 counts the swap inside the block twice.

So there are **48 arrangements** with Ani and Budi side by side.
