A round table has no first seat, because turning everyone round **does not change the arrangement**. So fix one student as a reference.

# Fixing a reference

Seat Ani in one chair as the reference. The other four then **fill the remaining 4 chairs**, counted clockwise from Ani.

<BlockMath math="4!=24" />

# Link with a row

Each circular arrangement shows up as 5 different row arrangements, one for each chair Ani could sit in, so <InlineMath math="\tfrac{120}{5}=24" />.

The value 120 counts arrangements in a row. The value 60 divides 120 by 2 instead of 5. The value 12 also treats mirror images as the same, although **left and right neighbours swap** in a mirror. The value 5 only counts the ways to rotate one arrangement.

So there are **24 different seatings**.
