The frame's area is **the outer rectangle minus the photo**. This automatically counts all four corners of the frame.

# Outer size

With <InlineMath math="x=3" /> **the outer size** is <InlineMath math="30\text{ cm}\times42\text{ cm}" />.

# Frame area

<BlockMath math="30\cdot42-24\cdot36=1{,}260-864=396\text{ cm}^2" />

Another way: four strips along the sides of the photo cover <InlineMath math="3\cdot120=360" /> cm², plus **four 3 cm × 3 cm corners**, which is 36 cm².

The value 360 cm² forgets the four corners, 369 cm² adds only one corner, and 324 cm² subtracts the corners instead. The value 189 cm² adds the frame width only once to each side length, <InlineMath math="27\cdot39-864" />.

So the frame's area is **396 cm²**.
