# The deciding limit

There is flour for 80 chocolate buns, but the oven only holds 70 more. **The smaller limit decides**, so at most 70 chocolate buns.

The value 80 buns checks only the flour. The value 110 buns forgets that a cheese bun uses twice as much flour, and 140 buns ignores the cheese buns already made. The value 40 buns subtracts <InlineMath math="2\cdot30" /> from 100, as if the oven worked like the flour.

So Bu Sari can still bake at most **70 chocolate buns**.
