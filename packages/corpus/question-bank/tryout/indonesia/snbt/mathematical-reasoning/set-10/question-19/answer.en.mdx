# Outer perimeter

<BlockMath math="P=2\bigl[(24+2x)+(36+2x)\bigr]=120+8x" />

The coefficient 8 means each extra centimetre of frame width adds 8 cm to the perimeter. The first statement is true.

For <InlineMath math="x=5" /> the perimeter is <InlineMath math="120+40=160" /> cm, **not 140 cm**. The second statement is false.

# Difference and ratio of the outer size

<BlockMath math="(36+2x)-(24+2x)=12" />

The difference is always 12 cm, whatever <InlineMath math="x" /> is. The third statement is true.

The photo is <InlineMath math="24:36=2:3" />. With a 6 cm frame the outer size is <InlineMath math="36:48=3:4" />. Adding the same length to both sides **changes the ratio**, so the fourth statement is false.
