Count the 30-minute gaps, then **add the first departure at 05.00**.

# Number of gaps

From 05.00 to 22.00 there are **17 hours**, which is <InlineMath math="17\cdot60=1{,}020" /> minutes.

<BlockMath math="\frac{1{,}020}{30}=34\text{ gaps}" />

# Number of departures

A train leaves at the start of every gap and also exactly at 22.00, so there is **one more departure than gaps**.

<BlockMath math="34+1=35" />

So line C departs **35 times**.
