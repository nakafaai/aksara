Line C leaves at 05.00 plus multiples of 40 minutes. Find **the largest multiple that does not pass 22.00**.

# Last departure

From 05.00 to 22.00 there are <InlineMath math="17\cdot60=1{,}020" /> minutes.

<BlockMath math="\frac{1{,}020}{40}=25.5" />

So the last departure is <InlineMath math="25\cdot40=1{,}000" /> minutes after 05.00, at 21.40. The next one would be 22.20, **past the limit**.

# Number of departures

Departures number 0 to 25 make <InlineMath math="25+1=26" />. Remember that the first departure at 05.00 counts too.

So line C departs **26 times**.
