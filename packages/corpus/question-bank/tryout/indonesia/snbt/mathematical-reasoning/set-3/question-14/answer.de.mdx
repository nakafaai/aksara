**Mathematisches Modell**

Das Geld von Amri, Beni und Dimas sei <InlineMath math="A, B," /> bzw. <InlineMath math="D" />. Aus den Angaben können wir ein Gleichungssystem aufstellen:

<MathContainer>
  <BlockMath math="\begin{cases} A = B + 2D + 20{.}000 &amp; \text{(1)} \\ A + B + D = 100{.}000 &amp; \text{(2)} \\ B - D = 5{.}000 &amp; \text{(3)} \end{cases}" />
</MathContainer>

**Das System lösen**

Wir wollen den Wert von <InlineMath math="A" /> ermitteln. Ersetzen Sie die Gleichung (<InlineMath math="1" />) durch die Gleichung (<InlineMath math="2" />):

<MathContainer>
  <BlockMath math="(B + 2D + 20{.}000) + B + D = 100{.}000" />
  <BlockMath math="2B + 3D = 80{.}000 \quad \text{(4)}" />
</MathContainer>

Als nächstes eliminieren wir <InlineMath math="B" /> mithilfe der Gleichungen (<InlineMath math="3" />) und (<InlineMath math="4" />). Multiplizieren Sie die Gleichung (<InlineMath math="3" />) mit <InlineMath math="2" />, sodass die Koeffizienten von <InlineMath math="B" /> übereinstimmen:

<MathContainer>
  <BlockMath math="\begin{aligned} 2B - 2D &= 10{.}000 \\ 2B + 3D &= 80{.}000 \end{aligned}" />
</MathContainer>

Subtrahieren Sie die beiden Gleichungen:

<MathContainer>
  <BlockMath math="-5D = -70{.}000 \implies D = 14{.}000" />
</MathContainer>

Setzen Sie <InlineMath math="D = 14{.}000" /> in die Gleichung (<InlineMath math="3" />) ein, um <InlineMath math="B" /> zu finden:

<MathContainer>
  <BlockMath math="B - 14{.}000 = 5{.}000 \implies B = 19{.}000" />
</MathContainer>

Wir setzen die Werte von <InlineMath math="B" /> und <InlineMath math="D" /> in Gleichung (<InlineMath math="1" />) ein und bestimmen <InlineMath math="A" />:

<MathContainer>
  <BlockMath math="A = 19{.}000 + 2(14{.}000) + 20{.}000" />
  <BlockMath math="A = 19{.}000 + 28{.}000 + 20{.}000" />
  <BlockMath math="A = 67{.}000" />
</MathContainer>

Somit beträgt Amris Geld <InlineMath math="\text{Rp}67{.}000{,}00" />.
