One turn of the wheel moves the bicycle **by the circumference of the wheel**. So the number of turns is the distance divided by the circumference, in the same unit.

# Circumference of the wheel

<BlockMath math="K=\pi d=\tfrac{22}{7}\cdot70=220\text{ cm}=2.2\text{ m}" />

# Number of turns

The distance 1.1 km equals 1,100 m.

<BlockMath math="\frac{1{,}100}{2.2}=500" />

The number of gear teeth **plays no part** here, because the question asks about wheel turns, not pedal turns.

So the wheel turns **500 times**.
