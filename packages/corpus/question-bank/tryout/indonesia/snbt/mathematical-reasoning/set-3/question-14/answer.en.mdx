The tiler's advice asks for **at least 10% more** than the 180 tiles that exactly cover the floor. Then the number of tiles must be rounded up to whole boxes.

# Minimum number of tiles

<BlockMath math="180+10\%\cdot180=180+18=198" />

# Number of boxes

<BlockMath math="\frac{198}{12}=16.5" />

Boxes cannot be bought in part, and 16 boxes hold only 192 tiles, fewer than 198. So the number **must be rounded up** to 17 boxes, which hold 204 tiles.

So at least **17 boxes** must be bought.
