For a rear gear with <InlineMath math="g" /> teeth, one pedal turn turns the wheel <InlineMath math="\tfrac{48}{g}" /> times, so **the distance per pedal turn is <InlineMath math="\tfrac{48}{g}\cdot2.2" /> metres**.

# Effect of the rear gear size

| Rear gear | Wheel turns per pedal | Distance per pedal |
| :---: | :---: | :---: |
| 12 teeth | 4 | 8.8 m |
| 16 teeth | 3 | 6.6 m |
| 24 teeth | 2 | 4.4 m |

The first statement is true. The table shows that **a larger rear gear actually shortens the distance** per pedal turn, so the third statement is false.

# Speed and number of pedal turns

With the 24-tooth gear and 60 turns per minute, the bicycle covers <InlineMath math="60\cdot4.4=264" /> m per minute.

<BlockMath math="264\cdot60=15{,}840\text{ m/h}=15.84\text{ km/h}" />

The speed is 15.84 km/h, not 16 km/h, so the second statement is false. With the 16-tooth gear, <InlineMath math="\tfrac{3{,}300}{6.6}=500" /> pedal turns, so the fourth statement is true.

So the first statement is **true**, the second is **false**, the third is **false**, and the fourth is **true**.
