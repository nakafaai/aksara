The floor dimensions divide evenly by the tile size on both sides, so the tiles fit **in rows and columns without cutting**. First convert to centimetres.

# Tiles along each side

<BlockMath math="\begin{aligned}
450:30&=15\text{ tiles along the 4.5 m side}\\
360:30&=12\text{ tiles along the 3.6 m side}
\end{aligned}" />

# Total number of tiles

<BlockMath math="15\cdot12=180" />

Check with area: the floor is 162,000 square centimetres and one tile is 900 square centimetres. The quotient **is also 180**.

The value 198 already includes the 10% spare, and 204 is the content of 17 boxes. The value 162 appears if the floor area of 16.2 square metres is divided by 0.1, as if one tile covered 0.1 square metres.

So the number of tiles that exactly cover the floor is **180**.
