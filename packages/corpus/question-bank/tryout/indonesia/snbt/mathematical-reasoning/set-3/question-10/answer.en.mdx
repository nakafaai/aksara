Andra wins with **more than half of the valid votes**. Half of 240 is 120, so Andra needs at least 121 votes.

# Setting up the inequality

Let <InlineMath math="k" /> voters switch to Andra. **The number of valid votes stays 240**, because the votes only move from other candidates.

<BlockMath math="96+k>120\;\Longleftrightarrow\;k>24" />

# The smallest whole number

The number of voters is a whole number, so the smallest value is <InlineMath math="k=25" />, giving Andra 121 votes. For <InlineMath math="k=24" />, Andra has exactly 120 votes, **exactly 50%, not more than 50%**.

The value 121 is the number of votes Andra needs, not the number of voters who switch. The values 48 and 49 come from treating the switched voters as removing valid votes or from doubling the extra votes.

So at least **25 voters** must switch.
