The file size is in megabytes, while the speed is in megabits per second. **Convert the file size to megabits first**, then divide by the speed.

# File size in megabits

<BlockMath math="600\text{ MB}\cdot8=4{,}800\text{ megabits}" />

# Download time

<BlockMath math="\frac{4{,}800}{40}=120\text{ seconds}" />

Without matching the units, the result is 15 seconds, which is **eight times too fast**.

So the file downloads in **120 seconds**.
