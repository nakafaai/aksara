The speed needed is **the file size in megabits divided by the time in seconds**. Both units must be matched first.

# Size and time in suitable units

<BlockMath math="\begin{aligned}
1.5\text{ GB}&=1{,}500\text{ MB}=1{,}500\cdot8=12{,}000\text{ megabits}\\
4\text{ minutes}&=240\text{ seconds}
\end{aligned}" />

# Minimum speed

<BlockMath math="\frac{12{,}000}{240}=50\text{ Mbps}" />

A lower speed makes the download **take longer than 4 minutes**, so 50 Mbps is the lowest speed that works. The home's 40 Mbps is not enough, since it needs 300 seconds.

The value 6.25 Mbps forgets to multiply by 8. The value 375 Mbps divides by 4 minutes instead of 240 seconds while still using megabits.

So the lowest speed needed is **50 Mbps**.
