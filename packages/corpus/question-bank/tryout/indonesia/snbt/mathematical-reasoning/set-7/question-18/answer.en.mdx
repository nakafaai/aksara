The outward and return legs use the battery at **different rates**, because the loads differ. Find the time for each leg, then convert it to battery percent.

# Time for each leg

A speed of 36 km/h **is 0.6 km per minute**, so each direction takes <InlineMath math="\tfrac{5.4}{0.6}=9" /> minutes.

# Battery use

With a 2.5 kg load a full battery lasts <InlineMath math="30-4\cdot2.5=20" /> minutes. With no load it lasts 30 minutes.

<BlockMath math="\begin{aligned}
\text{out}&:\quad \tfrac{9}{20}\cdot100\%=45\%\\
\text{back}&:\quad \tfrac{9}{30}\cdot100\%=30\%\\
\text{left}&=100\%-45\%-30\%=25\%
\end{aligned}" />

The value 75% is the battery **used**, not the battery left. The values 30% and 45% are the use of one leg only, and 55% is what is left after the outward leg alone.

So the battery left when the drone returns is **25%**.
