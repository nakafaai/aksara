Convert megabits to megabytes by **dividing by 8**, and remember that the 40 Mbps is shared by every device using it at the same time.

# Speed units and the device limit

40 Mbps means 40 megabits per second, which is <InlineMath math="\tfrac{40}{8}=5" /> MB per second. The first statement is true.

Fourteen HD video devices need <InlineMath math="14\cdot3=42" /> Mbps, **more than 40 Mbps**, so the second statement is false.

# Data for one hour of video

One hour is 3,600 seconds, and HD video uses 3 megabits every second.

<BlockMath math="\begin{aligned}
3\cdot3{,}600&=10{,}800\text{ megabits}\\
\tfrac{10{,}800}{8}&=1{,}350\text{ MB}=1.35\text{ GB}
\end{aligned}" />

That is **more than 1 GB**, so the third statement is false.

# Faster internet

Download time is inversely proportional to speed. At 100 Mbps the time becomes <InlineMath math="\tfrac{40}{100}=0.4" /> times the old time, so it **drops by 60%** for any file. The fourth statement is true.

So the first statement is **true**, the second is **false**, the third is **false**, and the fourth is **true**.
