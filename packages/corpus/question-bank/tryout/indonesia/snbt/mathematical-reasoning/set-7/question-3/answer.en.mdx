Remember that **8 megabits make 1 MB**, and download time is file size divided by speed.

# Speed units and the device limit

<BlockMath math="\frac{40\text{ megabits/s}}{8}=5\text{ MB/s}" />

The first statement is true. Fourteen HD video devices need <InlineMath math="14\cdot3=42" /> Mbps, **more than 40 Mbps**, so the second statement is false.

# Download time and faster internet

<BlockMath math="\frac{2{,}000\cdot8}{40}=400\text{ seconds}\approx6.7\text{ minutes}" />

That is more than 6 minutes, so the third statement is false.

Download time is inversely proportional to speed. At 100 Mbps the time becomes <InlineMath math="\tfrac{40}{100}=0.4" /> of the original, so it **drops by 60%** for any file. The fourth statement is true.

So the first statement is **true**, the second is **false**, the third is **false**, and the fourth is **true**.
