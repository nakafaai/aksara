# Menyusun dan menyelesaikan persamaan

<BlockMath math="\begin{aligned}
\tfrac95C+32-C&=60\\
\tfrac45C&=28\\

\end{aligned}" />

# Pemeriksaan

Suhu <InlineMath math="35^\circ\text{C}" /> dalam Fahrenheit adalah <InlineMath math="\tfrac95\cdot35+32=63+32=95" />, dan <InlineMath math="95-35=60" />. **Selisihnya tepat 60**.

Jadi, suhu hari itu adalah **35 °C**.
