# Catatan tentang tinggi tertinggi

# Catatan tentang hujan terlebat

Hujan terlebat, <InlineMath math="55\text{ mm}" />, turun pada pukul 07.00 sampai 08.00, jadi berhenti pukul 08.00. Jadi, catatan pertama benar, kedua salah, ketiga benar, dan keempat benar.
