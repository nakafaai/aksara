The robot moves only along streets, so it cannot travel in a straight line. Its shortest travel distance is **the number of blocks east plus the number of blocks north** it must cover.

# Number of blocks

From <InlineMath math="(0,0)" /> to <InlineMath math="(3,4)" />, the robot must travel 3 blocks east and 4 blocks north, **in any order**.

<BlockMath math="3+4=7\text{ blocks}" />

# Travel distance

<BlockMath math="7\cdot100=700\text{ m}" />

The straight-line distance <InlineMath math="\sqrt{3^2+4^2}=5" /> blocks, or 500 m, **is not available to the robot**, because it cuts through city blocks.

So the shortest travel distance from G to A is **700 m**.
