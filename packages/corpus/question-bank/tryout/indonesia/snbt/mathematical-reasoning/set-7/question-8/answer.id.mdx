#### Pemodelan Matematika

Diketahui:

- Pendapatan <InlineMath math="y" /> sama dengan gaji pokok ditambah bonus <InlineMath math="x \cdot z" /> rupiah
- Jumlah penumpang adalah <InlineMath math="x" />
- Skor kepuasan <InlineMath math="z" /> adalah <InlineMath math="x - 100" />
- Gaji pokok adalah <InlineMath math="\text{Rp}4{.}680{.}000{,}00" />

Maka model matematikanya adalah:

<MathContainer>
  <BlockMath math="y = 4{.}680{.}000 + xz" />
  <BlockMath math="y = 4{.}680{.}000 + x(x - 100)" />
  <BlockMath math="y = x^2 - 100x + 4{.}680{.}000" />
</MathContainer>

#### Perhitungan Pendapatan

Substitusikan <InlineMath math="x = 200" /> ke dalam model:

<MathContainer>
  <BlockMath math="y = (200)^2 - 100(200) + 4{.}680{.}000" />
  <BlockMath math="y = 40{.}000 - 20{.}000 + 4{.}680{.}000" />
  <BlockMath math="y = 20{.}000 + 4{.}680{.}000" />
  <BlockMath math="y = 4{.}700{.}000" />
</MathContainer>

Jadi, pendapatan pengemudi tersebut adalah <InlineMath math="\text{Rp}4{.}700{.}000{,}00" />.
