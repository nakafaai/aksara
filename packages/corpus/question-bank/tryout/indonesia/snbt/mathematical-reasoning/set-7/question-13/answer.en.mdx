#### Count Segments Before Counting Time

The first trip from <InlineMath math="A" /> to <InlineMath math="C" /> covers **half a lap**, or two equal segments. Each later arrival at <InlineMath math="C" /> adds a full lap of four segments:

| Arrival at C | Total segments from the start |
| --- | ---: |
| First | <InlineMath math="2" /> |
| Second | <InlineMath math="2+4=6" /> |
| Third | <InlineMath math="6+4=10" /> |
| Fourth | <InlineMath math="10+4=14" /> |

#### Convert Segments to Time

At **constant speed**, equal segments take equal amounts of time. The third arrival takes twelve minutes for ten segments, so the time per segment is:

<BlockMath math="t_s=\frac{12}{10}=1.2\text{ minutes}" />

The fourth arrival therefore occurs at:

<BlockMath math="T=14\times1.2=16.8\text{ minutes}" />

This is measured from the start. As a check, one extra lap takes <InlineMath math="4\times1.2=4.8" /> minutes, so <InlineMath math="12+4.8=16.8" /> minutes.
