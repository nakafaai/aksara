Reverse the formula <InlineMath math="F=\tfrac95C+32" /> by undoing its steps from the end: **subtract 32 first, then multiply by <InlineMath math="\tfrac59" />**.

# Reversing the formula

<BlockMath math="\begin{aligned}
F-32&=\tfrac95C\\
C&=\tfrac59(F-32)
\end{aligned}" />

# Substitution

<BlockMath math="C=\tfrac59(356-32)=\tfrac59\cdot324=180" />

Check: <InlineMath math="\tfrac95\cdot180+32=324+32=356" />, **matching the recipe**.

The value 197.8 °C forgets to subtract 32. The value 165.8 °C multiplies first and subtracts 32 afterwards. The value 215.6 °C adds 32 instead. The value 324 °C only subtracts 32 without multiplying by <InlineMath math="\tfrac59" />.

So the oven temperature is **180 °C**.
