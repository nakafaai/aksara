Use the formula <InlineMath math="F=\tfrac95C+32" /> in the right order: **multiply by <InlineMath math="\tfrac95" /> first, then add 32**.

# Substitution

<BlockMath math="\begin{aligned}
F&=\tfrac95\cdot37+32\\
&=66.6+32=98.6
\end{aligned}" />

# Check

One degree Celsius equals 1.8 degrees Fahrenheit, and 37 °C is 37 Celsius degrees above freezing, which is <InlineMath math="37\cdot1.8=66.6" /> Fahrenheit degrees. **Adding 32** gives 98.6 °F.

The value 66.6 °F forgets to add 32. The value 124.2 °F adds 32 before multiplying, <InlineMath math="(37+32)\cdot\tfrac95" />. The values 99.6 °F and 130.6 °F do not fit the formula.

So normal body temperature is **98.6 °F**.
