The distance between two intersections is **the difference in x plus the difference in y**. Compute some orders, then make sure no route is shorter.

# Length of some orders

Compare **the length of each visiting order**, including the way back to G.

| Order | Length in blocks |
| :---: | :---: |
| G, B, A, C, G | <InlineMath math="6+5+4+7=22" /> |
| G, A, C, B, G | <InlineMath math="7+4+9+6=26" /> |
| G, C, B, A, G | <InlineMath math="7+9+5+7=28" /> |

# A lower bound for every route

The route must reach x equal to 5, at B, and come back to x equal to 0, so it needs at least <InlineMath math="2\cdot5=10" /> horizontal blocks. It must also reach y equal to 6, at C, and come back to 0, so at least <InlineMath math="2\cdot6=12" /> vertical blocks. So **every route is at least 22 blocks**.

The order G, B, A, C, G reaches that bound, so 22 blocks or 2,200 m is the shortest. The values 2,600 m and 2,800 m come from poorer orders.

So the shortest route is **2,200 m**.
