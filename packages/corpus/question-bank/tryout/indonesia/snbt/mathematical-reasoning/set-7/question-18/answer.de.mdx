# Jeden Tag in Folgen zerlegen

Ein Praktikum darf nicht durch eine Pause geteilt werden, also **trennt jede Pause zwei Folgen von Stunden**. Stunde <InlineMath math="1" /> fällt ebenfalls weg, weil das Labor noch nicht bereit ist.

# Warum eine Folge aus drei Stunden nur ein Praktikum fasst

Zwei Praktika dürfen keine Stunde teilen, sie brauchen also <InlineMath math="4" /> verschiedene Stunden in einer Folge. **Eine Folge aus <InlineMath math="3" /> Stunden fasst nur ein Praktikum**, die übrige Stunde bleibt ungenutzt. Allgemein fasst eine Folge aus <InlineMath math="n" /> Stunden höchstens <InlineMath math="\left\lfloor \frac{n}{2}\right\rfloor" /> Praktika.
