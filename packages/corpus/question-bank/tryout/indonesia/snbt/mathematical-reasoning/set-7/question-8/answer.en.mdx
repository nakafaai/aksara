The game is fair when **the expected prize equals Rp5,000**. Let the new prize for sum 12 be <InlineMath math="H" /> rupiah, with the other prizes unchanged.

# Setting up the equation

**Multiply both sides by 36** to clear the fraction.

<BlockMath math="\begin{aligned}
\frac{H+2\cdot18{,}000+6\cdot9{,}000}{36}&=5{,}000\\
H+36{,}000+54{,}000&=180{,}000\\
H&=90{,}000
\end{aligned}" />

# Check

With a prize of 90,000, the expected value is <InlineMath math="\tfrac{90{,}000+36{,}000+54{,}000}{36}=\tfrac{180{,}000}{36}=5{,}000" />. **The prize rises by 54,000 rupiah**, from 36,000 to 90,000.

The value Rp54,000 is the increase, not the new prize. The value Rp72,000 only doubles the old prize, and Rp36,000 is the old prize.

So the new prize for sum 12 is **Rp90,000**.
