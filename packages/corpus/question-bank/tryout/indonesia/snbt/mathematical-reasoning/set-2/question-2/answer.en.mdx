The peak fare is the normal fare multiplied by 1.2. So **first divide by 1.2** to get the normal fare, then find the distance.

# Fare before the increase

<BlockMath math="\frac{36{,}000}{1.2}=30{,}000" />

# The charged distance

Let the charged distance be <InlineMath math="k" /> km, with <InlineMath math="k>2" /> because the fare is above the base fare. The normal fare is **the base fare plus the kilometre charge after the first 2 km**.

<BlockMath math="\begin{aligned}
10{,}000+2{,}500(k-2)&=30{,}000\\
2{,}500(k-2)&=20{,}000\\
k-2=8\;\Longrightarrow\;k&=10
\end{aligned}" />

Check: <InlineMath math="1.2\cdot(10{,}000+8\cdot2{,}500)=1.2\cdot30{,}000=36{,}000" />.

So the distance charged to Bayu is **10 km**.
