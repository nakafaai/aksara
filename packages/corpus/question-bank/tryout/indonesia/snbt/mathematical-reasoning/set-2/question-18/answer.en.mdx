You're looking for the most seedlings. Count the seedlings in one row, count the rows in each planting strip while watching **two different distance limits**, from the field edge and from the channel edge, and then multiply.

# Seedlings in one row

Rows run parallel to the <InlineMath math="24\text{ m}" /> side, and seedlings must be at least <InlineMath math="1\text{ m}" /> from both ends of the field. So seedlings can only sit on a stretch of <InlineMath math="24-2\cdot 1=22" /> metres. On that stretch, the most gaps of <InlineMath math="0.8\text{ m}" /> is the largest whole number not above <InlineMath math="22\div 0.8" />.

<BlockMath math="\begin{aligned}
\frac{22}{0.8}&=27.5\ \Rightarrow\ 27\text{ gaps} \\
27+1&=28\text{ seedlings}
\end{aligned}" />

You add one because **there's always one more seedling than gaps** between them.

# Rows in one planting strip

Each planting strip is <InlineMath math="7\text{ m}" /> wide. One side is the field edge, so rows must be at least <InlineMath math="1\text{ m}" /> from it. The other side is the channel edge, and **from the channel only <InlineMath math="0.5\text{ m}" /> is needed**. So rows can only sit in a band <InlineMath math="7-1-0.5=5.5" /> metres wide.

<BlockMath math="\begin{aligned}
\frac{5.5}{1.2}&=4.58\ldots\ \Rightarrow\ 4\text{ gaps} \\
4+1&=5\text{ rows}
\end{aligned}" />

The first row is exactly <InlineMath math="1\text{ m}" /> from the field edge, and the fifth row is <InlineMath math="1+4\cdot 1.2=5.8" /> metres from it. The channel edge is <InlineMath math="7\text{ m}" /> from the field edge, so the fifth row is <InlineMath math="1.2\text{ m}" /> from the channel, which is fine. A sixth row would be <InlineMath math="7.0" /> metres from the field edge, right at the channel edge, so it isn't allowed.

# All the seedlings

There are **two identical planting strips**, each with <InlineMath math="5" /> rows, and each row has <InlineMath math="28" /> seedlings.

<BlockMath math="2\cdot 5\cdot 28=280" />
