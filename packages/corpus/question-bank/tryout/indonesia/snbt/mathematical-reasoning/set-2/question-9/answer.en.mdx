There are two unknowns, the number of correct answers <InlineMath math="b" /> and of wrong answers <InlineMath math="w" />. The question gives **two equations**: the number of answered questions and the total score.

# Setting up the system

<BlockMath math="\begin{aligned}
b+w&=34\\
4b-w&=106
\end{aligned}" />

# Solving the system

Add the equations so that **<InlineMath math="w" /> cancels**.

<BlockMath math="5b=140\;\Longrightarrow\;b=28,\quad w=6" />

Check: <InlineMath math="4\cdot28-6=112-6=106" />. Another way: if all 34 answers were correct, the score would be 136. Each wrong answer takes 5 off that score, losing 4 and gaining <InlineMath math="-1" />. The gap <InlineMath math="136-106=30" /> means 6 wrong answers.

The value 26 appears if the score 106 is divided by 4 without accounting for the penalty for wrong answers. The other values do not satisfy both equations.

So the candidate answered **28 questions** correctly.
