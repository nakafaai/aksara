The roof area needed is **the number of panels times the area of one panel**. So first find the number of panels.

# Number of panels

One panel makes <InlineMath math="0.2\cdot4.5=0.9" /> kWh a day, so **10 panels are needed**, because <InlineMath math="\tfrac{9}{0.9}=10" />.

# Roof area

<BlockMath math="10\cdot1.6=16\text{ m}^2" />

This is the net panel area, assuming the panels can be mounted **tightly with no gaps**.

So the smallest roof area is **16 square metres**.
