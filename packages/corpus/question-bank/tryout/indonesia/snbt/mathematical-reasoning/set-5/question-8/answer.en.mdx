The free space to keep is **10% of the full 128 GB capacity**, not of the available memory. Subtract that reserve from the user's memory, then divide by the photo size.

# Memory that may be used

<BlockMath math="\begin{aligned}
10\%\cdot128&=12.8\text{ GB}\\
110-12.8&=97.2\text{ GB}\\
97.2\cdot1{,}024&=99{,}532.8\text{ MB}
\end{aligned}" />

# Number of photos

<BlockMath math="\frac{99{,}532.8}{4}=24{,}883.2" />

Photo number 24,884 would leave less than 10% free, so **the result is rounded down** to 24,883.

The value 25,344 takes 10% of 110 GB instead of 128 GB. The value 24,300 uses 1 GB as 1,000 MB. The value 28,160 keeps no free space, and 29,491 ignores the system share.

So the largest number of photos is **24,883 photos**.
