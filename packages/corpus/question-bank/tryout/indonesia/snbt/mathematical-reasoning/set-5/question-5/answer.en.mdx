The memory available to the user is **the capacity minus the system share**. Convert it to megabytes, then divide by the size of one photo.

# Available memory

<BlockMath math="\begin{aligned}
128-18&=110\text{ GB}\\
110\cdot1{,}024&=112{,}640\text{ MB}
\end{aligned}" />

# Number of photos

<BlockMath math="\frac{112{,}640}{4}=28{,}160" />

The division is exact, so **28,160 photos fill the memory exactly**.

So at most **28,160 photos** can be stored.
