Use the sorted data 13.5, 13.8, 14.0, 14.2, 14.4, 14.6, 15.1, 16.4 with **mean 14.5 seconds and median 14.3 seconds**.

# Range and faster students

The range is <InlineMath math="16.4-13.5=2.9" /> seconds, so the first statement is true.

Running faster means a time **below 14.5 seconds**. Five students have such times: 13.5, 13.8, 14.0, 14.2 and 14.4. Five of eight is more than half, so the second statement is true.

# Effect of changing the data

Without Fajar's 16.4 seconds, seven sorted values remain: 13.5, 13.8, 14.0, 14.2, 14.4, 14.6, 15.1. The median is the 4th value, 14.2 seconds, **not 14.3 seconds**. The third statement is false.

Taking 0.3 seconds off every time shifts all the data, so the slowest and fastest times drop by the same amount. **The range stays 2.9 seconds**, so the fourth statement is false.

So the first statement is **true**, the second is **true**, the third is **false**, and the fourth is **false**.
