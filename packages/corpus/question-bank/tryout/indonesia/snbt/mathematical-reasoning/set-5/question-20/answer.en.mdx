Knowing that the digits differ **narrows the sample space** to 5,040 PINs, not 10,000. Three different guesses cover 3 of those PINs.

# The new sample space

<BlockMath math="10\cdot9\cdot8\cdot7=5{,}040" />

# Probability of success

The fraudster succeeds if the true PIN is one of **the 3 PINs guessed**.

<BlockMath math="\frac{3}{5{,}040}=\frac{1}{1{,}680}" />

This probability is very small, so the limit of 3 guesses protects the account well.

The value <InlineMath math="\tfrac{1}{5040}" /> is for a single guess. The values <InlineMath math="\tfrac{3}{1000}" /> and <InlineMath math="\tfrac{1}{1000}" /> use the wrong sample space, and <InlineMath math="\tfrac{1}{3360}" /> counts only 1.5 guesses.

So the probability that the fraudster succeeds is **<InlineMath math="\tfrac{1}{1680}" />**.
