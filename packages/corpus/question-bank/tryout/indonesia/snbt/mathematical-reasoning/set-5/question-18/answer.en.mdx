The sample space is **10,000 equally likely PINs**. The probability is the number of PINs with different digits divided by 10,000.

# PINs with different digits

**The first digit may be 0**, so there are <InlineMath math="10\cdot9\cdot8\cdot7=5{,}040" />.

# Probability

<BlockMath math="\frac{5{,}040}{10{,}000}=0.504" />

This is just over one half, so **almost half of all PINs repeat a digit**.

The value 0.496 is the probability of the opposite event, a repeated digit. The value 0.4536 forbids a leading 0, although a PIN may start with 0. The value 0.3024 uses <InlineMath math="9\cdot8\cdot7\cdot6" />, and 0.0504 misplaces the decimal point.

So the probability is **0.504**.
