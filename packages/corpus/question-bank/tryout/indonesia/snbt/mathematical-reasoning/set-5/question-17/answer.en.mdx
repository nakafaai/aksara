Choose the digits from left to right. A digit already used **may not be used again**, so the number of choices drops by one at each position.

# Choices at each position

The first digit may be 0, because a PIN may start with 0. So there are 10 choices for the first digit, 9 for the second, 8 for the third and 7 for the fourth.

<BlockMath math="10\cdot9\cdot8\cdot7=5{,}040" />

This is **a permutation of 4 from 10**, because the order of digits in a PIN matters.

So there are **5,040 PINs** with four different digits.
