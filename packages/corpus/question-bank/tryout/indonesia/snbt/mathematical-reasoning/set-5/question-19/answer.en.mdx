Each statement needs a different way of counting. Choose a way that **counts every PIN exactly once**.

# Increasing PINs and palindromic PINs

For a PIN with increasing digits, choose 4 different digits from 0 to 9. Each choice can be arranged in increasing order in only one way, so there are <InlineMath math="\binom{10}{4}=210" />, **not 252**. The first statement is false.

A PIN that reads the same backwards has the form <InlineMath math="abba" />. The first two digits are free, and the last two are fixed by them, so there are <InlineMath math="10\cdot10=100" />. The second statement is true.

# The digit 7 and the sum 36

Count the opposite: a PIN with no 7 has 9 choices at each position.

<BlockMath math="10{,}000-9^4=10{,}000-6{,}561=3{,}439" />

There are 3,439, **not 4,000**. The third statement is false.

The largest digit is 9, so the largest sum of four digits is <InlineMath math="4\cdot9=36" />. A sum of 36 happens only when every digit is 9, the PIN 9999. The fourth statement is true.

So the first statement is **false**, the second is **true**, the third is **false**, and the fourth is **true**.
