Pemakaian bensin berbeda untuk kedua jenis jalan, jadi **hitung setiap bagian perjalanan terpisah**, lalu jumlahkan.

# Bensin untuk setiap bagian

<BlockMath math="\begin{aligned}
\text{jalan kota}&:\quad \frac{60}{10}=6\text{ liter}\\
\text{jalan tol}&:\quad \frac{150}{15}=10\text{ liter}
\end{aligned}" />

# Jumlah bensin

<BlockMath math="6+10=16\text{ liter}" />

Banyak bensin adalah **jarak dibagi jarak tempuh per liter**, bukan jarak dikali jarak tempuh per liter.

Jadi, mobil itu memakai **16 liter** bensin.
