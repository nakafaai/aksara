Compute **the memory left after the photos**, then divide by the size of one minute of 4K video. Round down, because video counts only in full minutes.

# Remaining memory

<BlockMath math="\begin{aligned}
\text{available}&=110\cdot1{,}024=112{,}640\text{ MB}\\
\text{photos}&=20{,}000\cdot4=80{,}000\text{ MB}\\
\text{remaining}&=32{,}640\text{ MB}
\end{aligned}" />

# Length of 4K video

<BlockMath math="\frac{32{,}640}{400}=81.6" />

An 82nd minute would need 32,800 MB, **more than the memory left**, so the longest video is 81 minutes.

The value 82 minutes rounds up. The value 217 minutes uses the HD size, and 281 minutes forgets the stored photos. The value 750 minutes makes both mistakes.

So the longest 4K video is **81 minutes**.
