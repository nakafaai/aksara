Ein Stadtmarkt wollte Herkunftsangaben für verarbeitete Lebensmittel einführen. In einem Test stand auf einer Chipstüte: hergestellt in Dorf Rawa. Der Maniok stammte jedoch aus zwei Bezirken, wurde im Dorf geschnitten, in der Stadt frittiert und von einem anderen Händler verpackt. Alle Angaben waren wahr, doch das Wort Herkunft ließ Käufer an einen einzigen Ort denken.

Händler verlangten kurze Angaben wegen des knappen Platzes. Verbrauchergruppen wollten überprüfbare Informationen für Qualitätsprobleme. Das Team trennte deshalb Rohstoffherkunft, Verarbeitungsort und verantwortliche Stelle jeder Phase. Ein Code führte zu einem vollständigen Datensatz, während vorn nur die zwei für das Produkt wichtigsten Angaben standen.

Das System wurde mit einem simulierten Rückruf geprüft. Als eine Speiseölcharge als fehlerhaft markiert wurde, begrenzten geschichtete Aufzeichnungen die betroffenen Produkte. Ein einzelner Ortsname vermischte dagegen Produkte aus verschiedenen Rohstoffen und Produktionszeiten. Ein Code erwies sich allerdings als nutzlos, wenn Lieferantendaten nicht aktualisiert waren.

Der Markt versteht Rückverfolgbarkeit als die Fähigkeit, den Weg eines Produkts nachzuvollziehen, nicht nur einen Ortsnamen anzubringen. Ein gutes System muss für Käufer knapp, für Prüfungen ausreichend genau und entlang der Lieferkette aktuell sein.
