A mapping team updated place names on a district map. The old database used one official name for each location. During fieldwork, the team found that one spring had three names: an administrative name, a name used by farmers, and an older name found in family stories.

Some mapmakers wanted to choose one name to simplify search. Residents argued that doing so could erase information about the place's use and history. For them, toponymy was more than labelling. Different names could indicate who used a place, the direction from which people approached it, or an event they remembered.

The team checked old signs, land letters, interview recordings, and coordinates. The names did not have equal evidential support, but all clearly referred to the same location. The team made the administrative name the primary index and stored the other two as aliases with source and usage notes.

The decision did not treat every name as equal in every setting. Official documents still use the primary index, while public search can find the location through all three names. New evidence may lead to a revision, but the earlier history must remain visible.
