Sentence (4) has a **transitive predicate and an object**. Compare its main elements with the assignment sentence.

| Element | Sentence (4) | Correct choice |
| --- | --- | --- |
| Opening adjunct | If a stinger remains in the skin | After the lesson ends |
| Subject | an adult | each student |
| Predicate | should remove | should submit |
| Object | it, the stinger | the assignment |
| Manner adjunct | as quickly as possible | promptly |

Both sentences have an opening adjunct followed by a subject acting on an object. The complete matching sentence is *After the lesson ends, each student should submit the assignment promptly*. The other choices use predicates without objects, such as *sing*, or predicates with complements, such as *become wet*.
