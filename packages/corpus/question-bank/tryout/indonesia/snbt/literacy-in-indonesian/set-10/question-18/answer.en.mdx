Text 1 says the return **is only right**. Text 2 opens by saying that **no one doubts** looted objects **deserve to go home**. The texts differ only on how and when to return them, not on the right itself.

- Text 1 asks for no further delay, and Text 2 does not demand new museums.
- Neither text says European museums are better.
- Only Text 2 asks for a gradual return.
- Trade is not discussed.

So both texts agree that looted objects deserve to return to where they came from.
