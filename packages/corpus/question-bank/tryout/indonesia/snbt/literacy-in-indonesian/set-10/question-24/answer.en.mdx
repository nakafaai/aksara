# Given

**The passage traces** seventh-century Malay inscriptions, colonial administrative use of Malay, Javanese speakers, and the 1928 Youth Pledge.

# Asked

Which statements can be concluded from the historical facts on Malay and Indonesian in the passage.

# Solution

> Count the centuries from the earliest inscriptions to 1928 carefully and reject sweeping claims like only Malay words or Javanese rejection.

One statement needs year arithmetic, the rest trap you with words that are too strong.

The statement about twelve centuries can be concluded. The inscription is **"bertanggal 683 Masehi"** (dated 683 CE), and the Youth Pledge was in 1928. That's <InlineMath math="1928-683=1245" /> years, more than <InlineMath math="1200" />.

The statement about the colonial government can be concluded. It used Malay **"dalam administrasi dan di sekolah-sekolah pribumi"** (in administration and in native schools), that is, beyond trade.

The statement about an exact number can't be concluded. The text only says native Javanese speakers were **"jauh lebih banyak"** (far more numerous), with no figure.

The statement that Indonesian has only Malay words can't be concluded. Indonesian **"menyerap banyak kata dari bahasa Jawa, Belanda, Arab, Sanskerta, dan bahasa lain"** (absorbs many words from Javanese, Dutch, Arabic, Sanskrit and other languages).

The statement that leaders from Java rejected Malay can't be concluded. **"Banyak tokoh pergerakan dari Jawa sendiri mendukung bahasa Melayu"** (many movement leaders from Java itself supported Malay).

# Answer

**The table below summarizes the verdict for each statement**.

| Statement | Answer |
| --- | --- |
| Malay written more than twelve centuries before 1928 | Ya |
| The colonial government used Malay beyond trade | Ya |
| The text gives an exact number of Javanese speakers | Tidak |
| Indonesian has only Malay words | Tidak |
| Leaders from Java rejected Malay | Tidak |
