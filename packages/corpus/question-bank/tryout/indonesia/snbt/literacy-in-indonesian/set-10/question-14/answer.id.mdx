Rata-rata perjalanan per sepeda diperoleh dengan membagi **jumlah perjalanan** dengan **jumlah sepeda**.

| Bulan | Perhitungan | Perjalanan per sepeda |
| --- | --- | ---: |
| Januari | <InlineMath math="6.000 : 200" /> | <InlineMath math="30" /> |
| Februari | <InlineMath math="5.400 : 200" /> | <InlineMath math="27" /> |
| Maret | <InlineMath math="7.000 : 200" /> | <InlineMath math="35" /> |
| April | <InlineMath math="10.400 : 400" /> | <InlineMath math="26" /> |
| Mei | <InlineMath math="12.800 : 400" /> | <InlineMath math="32" /> |
| Juni | <InlineMath math="15.200 : 400" /> | <InlineMath math="38" /> |

Nilai terendah adalah **26 perjalanan per sepeda pada April**. Februari memang memiliki jumlah perjalanan paling sedikit, tetapi pada bulan itu sepedanya juga hanya 200, sehingga rata-ratanya 27.

Jadi, rata-rata perjalanan per sepeda paling rendah terjadi pada April.
