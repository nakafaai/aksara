# Diketahui

**Teks menyajikan nilai** awal dan nilai akhir kelompok kelas tambahan, kelompok pembanding, dan kelompok nilai tertinggi.

# Ditanyakan

Kebenaran setiap pernyataan tentang selisih poin dan persentase perubahan masing-masing kelompok dari nilai awalnya.

# Penyelesaian

> Selalu bagi perubahan poin setiap kelompok dengan nilai awalnya sendiri supaya persentase kenaikan tidak pernah salah pembanding.

Hitung selisih dan persentase setiap kelompok dari nilai **awalnya**.

| Hitungan | Hasil |
| --- | --- |
| Selisih kenaikan dengan kelompok pembanding | <InlineMath math="10-6=4" /> poin |
| Kenaikan kelompok kelas tambahan | <InlineMath math="\frac{10}{45}\approx22{,}2\%" /> |
| Perubahan kelompok tertinggi | <InlineMath math="88-92=-4" /> poin |
| Kenaikan kelompok pembanding | <InlineMath math="\frac{6}{46}\approx13\%" /> |

Pernyataan tentang sekitar <InlineMath math="4" /> poin benar. Guru menyebut yang dapat dikaitkan dengan kelas tambahan adalah **"selisihnya dengan kelompok pembanding"**, yaitu <InlineMath math="10-6=4" />.

Pernyataan bahwa kenaikan kelompok kelas tambahan lebih dari <InlineMath math="25\%" /> tidak benar. Kenaikannya sekitar <InlineMath math="22{,}2\%" />.

Pernyataan bahwa kelompok tertinggi turun <InlineMath math="4" /> poin benar. Nilainya turun dari <InlineMath math="92" /> menjadi <InlineMath math="88" />.

Pernyataan bahwa kenaikan kelompok pembanding lebih dari <InlineMath math="15\%" /> tidak benar. Kenaikannya sekitar <InlineMath math="13\%" />.
