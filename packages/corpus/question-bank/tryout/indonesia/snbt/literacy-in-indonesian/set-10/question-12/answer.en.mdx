# Given

**Both texts report** students unable to explain essays, detector bias against non-native writers, and proposals for in-class tasks.

# Asked

Whether each statement is true or false based on the data and claims in both texts.

# Solution

> Failing to explain an essay does not prove AI use, and a flawed detector is not wrong every single time, so watch words like proven and never.

Some statements trap you with words that are too strong, such as **proven**, **never** and **all**.

The statement about more than half can be concluded. <InlineMath math="18" /> of <InlineMath math="32" /> students, about <InlineMath math="56\%" />.

The statement that <InlineMath math="18" /> students were proven to use AI can't be concluded. Text A's writer is only **"hampir yakin"** (almost sure).

The statement about non-native speakers can be concluded. Detectors **"salah menandai lebih dari separuh esai bahasa Inggris karya siswa yang bukan penutur asli"** (wrongly flagged over half of non-native students' English essays) as machine-written.

The statement that detectors are never right can't be concluded. The study says only **"beberapa alat"** (some tools) wrongly flagged over half the essays, not all tools and not always.

The statement that all essays are done in class can't be concluded. Text B proposes essays **"dimulai di kelas dan dilanjutkan di rumah"** (started in class and continued at home).

# Answer

The table below summarizes the verdict for each statement.

| Statement | Answer |
| --- | --- |
| More than half couldn't explain | Ya |
| <InlineMath math="18" /> students proven to use AI | Tidak |
| Detectors can harm non-native speakers | Ya |
| Detectors are never right | Tidak |
| All essays done in class | Tidak |
