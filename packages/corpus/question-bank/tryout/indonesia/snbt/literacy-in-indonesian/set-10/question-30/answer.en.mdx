# Given

The principal wants to repeat the extra-class program next year using a design that directly answers **the teacher's methodological doubts**.

# Asked

The best next-year program design to answer the teacher's methodological doubts and why it works.

# Solution

A valid evaluation design must satisfy **two core requirements** highlighted by the teacher:

- **A concurrent comparison group**. The gain attributable to the class is **"the difference relative to the comparison group"** tested over the same period.
- **Random assignment**. The teacher warned that this year's comparison group **"was not chosen at random"**. Random assignment ensures both groups experience the same regression to the mean without systematic confounding differences.

Check why the other designs fail one of these requirements:

| Distractor | Requirement violated |
| --- | --- |
| Using top-scoring students as the control | Top scorers regress downward, making them an unfair baseline for the lowest scorers. |
| Counting only diligent attendees | Filtering after assignment breaks randomization because diligent students differ on motivation and habits. |
| Using students with schedule conflicts | Regardless of group size, schedule-conflict students are not randomly assigned. |
| Comparing against this year's <InlineMath math="10" />-point gain | Last year's figure is not a concurrent control and still blends class impact with regression. |

> Randomly splitting the target low-scoring group into concurrent treatment and control groups cancels out regression to the mean.

# Answer

The strongest design is **randomly assigning the lowest-scoring students** into extra-class and no-extra-class groups, then **comparing the score gains of both groups**.
