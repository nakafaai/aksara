# Given

A youth organization with members from diverse regions and mother tongues wants to select a shared language using **the criteria for choosing the unifying language in the passage**.

# Asked

All considerations consistent with the passage's reasoning for choosing a shared language for a multi-regional youth organization.

# Solution

Apply the passage's three reasons directly to each candidate criterion:

| Consideration | Verdict | Grounding in the text |
| --- | --- | --- |
| Already familiar across regions | **Appropriate** | Malay was chosen because **"many people from various regions already knew it"**. |
| Does not encode social rank | **Appropriate** | A language without strict speech levels **"better suited"** a movement treating all members equally. |
| Does not favor one origin group | **Appropriate** | Picking one group's language **"could look like favoring one ethnic group"**. |
| Picking the largest native-speaker tongue | **Inappropriate** | Native-speaker count was explicitly not decisive, as Javanese was not selected. |
| Using the chairperson's native language | **Inappropriate** | This privileges one leader and that leader's home group. |

> Applying the passage's principles to a new organization requires broad familiarity, rank neutrality, and avoiding favoritism toward any single group.

# Answer

The fitting criteria are choosing a language that is **already known across regions**, **does not mark listener rank**, and **does not favor any single member's home group**.
