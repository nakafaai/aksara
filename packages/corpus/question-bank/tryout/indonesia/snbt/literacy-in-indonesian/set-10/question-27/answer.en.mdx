# Given

**The passage compares** score changes for lowest scorers given extra classes, a matched control group with no extra classes, and the highest scorers.

# Asked

Which statements can be concluded about the extra classes and regression toward the mean.

# Solution

> The lowest scorers tend to bounce back somewhat even without help, so the classes' real effect is only the extra gain above the control group.

Compare the three groups, then check whether a statement brings in a cause the text doesn't give.

| Group | First test | Second test | Change |
| --- | ---: | ---: | ---: |
| Extra classes | <InlineMath math="45" /> | <InlineMath math="55" /> | <InlineMath math="+10" /> |
| Comparison, lowest without classes | <InlineMath math="46" /> | <InlineMath math="52" /> | <InlineMath math="+6" /> |
| Highest, no treatment | <InlineMath math="92" /> | <InlineMath math="88" /> | <InlineMath math="-4" /> |

The statement that the extra-class group rose more can be concluded. <InlineMath math="10" /> is more than <InlineMath math="6" />.

The statement that the classes raised scores by <InlineMath math="10" /> points can't be concluded. The group without classes also rose <InlineMath math="6" /> points, so not all <InlineMath math="10" /> points can be put down to the classes.

The statement that the lowest scorers can rise without treatment can be concluded. The comparison group rose from <InlineMath math="46" /> to <InlineMath math="52" />.

The statement that the top scorers fell because they got lazy can't be concluded. By the teacher's account, the fall is explained by regression to the mean, not laziness.

The statement that the comparison group attended some classes can't be concluded. They **"tidak mengikuti kelas tambahan"** (didn't attend the extra classes) because of a timetable clash.

# Answer

The table below summarizes the verdict for each statement.

| Statement | Answer |
| --- | --- |
| The extra-class group rose more | Ya |
| The classes raised scores by <InlineMath math="10" /> points | Tidak |
| The lowest scorers can rise without treatment | Ya |
| The top scorers fell because they got lazy | Tidak |
| The comparison group attended some classes | Tidak |
