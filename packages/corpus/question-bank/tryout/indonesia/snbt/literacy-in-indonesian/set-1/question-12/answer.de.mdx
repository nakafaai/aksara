# Gegeben

**Text B** stützt sich auf die Vergleichsschule SMA Pelita, die ohne Handyverbot im selben Jahr ebenfalls von <InlineMath math="70" /> auf <InlineMath math="75" /> Punkte stieg, um den Anstieg an der SMA Harapan Bangsa dem neuen Prüfungsformat zuzuschreiben.

# Gesucht

Der Befund, der den SMA-Pelita-Beleg aus Text B am stärksten schwächt, falls er zutrifft.

# Lösung

Der Vergleich von Text B setzt voraus, dass **der Wechsel des Prüfungsformats** den Zuwachs von <InlineMath math="5" /> Punkten an der SMA Pelita erklärt. Er wird am stärksten geschwächt, wenn eine **andere Ursache** an der SMA Pelita im selben Jahr hinzukam.

> Wenn die SMA Pelita genau in jenem Jahr zusätzlichen Förderunterricht für alle Abschlussklassen einführte, lässt sich ihr Anstieg nicht mehr dem Prüfungsformat zuschreiben.

## Wirkung der fünf Befunde auf den Vergleich

Die Einordnung nach **schwächender, stärkender oder neutraler Wirkung** liefert eine eindeutige Entscheidung.

| Befund | Wirkung auf den SMA-Pelita-Beleg | Urteil |
| --- | --- | --- |
| SMA Pelita führte im selben Prüfungsjahr zusätzlichen Förderunterricht für alle Abschlussklassen ein | Liefert eine konkurrierende Ursache speziell an der SMA Pelita | **Schwächt am stärksten** |
| Andere Schulen ohne Verbot stiegen ebenfalls um etwa <InlineMath math="5" /> Punkte | Bestätigt das Muster von Text B | **Stärkt** |
| Beide Schulen haben ein sehr ähnliches Umfeld | Macht den Vergleich von Text B noch belastbarer | **Stärkt** |
| Lehrkräfte der SMA Harapan Bangsa berichten von ruhigeren Klassen | Steht schon in Text A und berührt SMA Pelita nicht | **Ohne Wirkung** |
| Lernende der SMA Pelita bringen weiter Handys mit | Wiederholt nur die Voraussetzung von Text B | **Ohne Wirkung** |

# Antwort

Am stärksten schwächt der Befund, dass **die SMA Pelita im selben Prüfungsjahr zusätzlichen Förderunterricht für alle Abschlussklassen eingeführt hat**.
