# Given

**Text A and** Text B debate school phone rules from perspectives that overlap on some points and diverge on others.

# Asked

Which statements both the writer of Text A and the writer of Text B agree with at once.

# Solution

> Both writers agree only when each text clearly backs the claim, never when just one side mentions or supports it.

The key word is **sekaligus** (both at once). A statement goes in the Ya (Yes) column only if both writers agree with it. A statement held by just one writer, or not touched by one of them, goes in Tidak (No).

- **Statement 1**. A writes that **"setiap notifikasi menarik perhatian dari pelajaran"** (every notification pulls attention from the lesson). B writes, **"Saya setuju bahwa ponsel yang bergetar di saku merusak konsentrasi."** (I agree that a phone buzzing in a pocket ruins concentration.) Both agree.
- **Statement 2**. This is the trap. B rejects a full ban, but B still **"mendukung loker ponsel di setiap kelas selama jam pelajaran"** (supports phone lockers in every class during lessons). A's ban also covers lessons. They differ about the whole day, not about lesson time, so both agree.
- **Statement 3**. Only A holds this, when rejecting the middle way. B never talks about supervision.
- **Statement 4**. Only B. B points to the changed exam format and the rise at SMA Pelita. A calls the figure **"sudah cukup sebagai bukti"** (enough proof).
- **Statement 5**. Only A. A's ban runs until the last bell, and A is glad students chat again at break. B mentions students whose group work can only be done in an app **"pada jam istirahat"** (during break).

# Answer

The table below summarizes the verdict for each statement.

| Statement | Answer |
| --- | --- |
| Notifications break attention | Ya |
| Keep phones away during lessons | Ya |
| Unsupervised rules are kept only by orderly students | Tidak |
| Part of the rise comes from something else | Tidak |
| Break time should be phone-free | Tidak |
