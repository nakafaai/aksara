The Ejaan Republik (Republic spelling) was in force from 1947 to 1972. From the text you can put together **four features** that must all hold at once.

- The /u/ sound is written *u*, not *oe*, because *oe* was replaced in 1947.
- A glottal stop at the end of a syllable is written *k*, not an apostrophe, also since 1947.
- The /j/ sound is still written *dj*, because *dj* was only replaced in 1972.
- The /y/ sound is still written *j*, because *j* for /y/ was also only replaced in 1972.

Now test each sentence. One wrong feature is enough to rule it out.

| Sentence | /u/ | glottal stop | /j/ | /y/ | Republic spelling? |
| --- | :---: | :---: | :---: | :---: | :---: |
| *Goeroe ... makmur* | *oe* | *k* | *dj* | *j* | no |
| *Guru ... mengadjar ... rakjat jang makmur* | *u* | *k* | *dj* | *j* | yes |
| *Guru ... mengajar ... jang* | *u* | *k* | *j* | *j* | no |
| *Guru ... mengadjar ... rakyat yang* | *u* | *k* | *dj* | *y* | no |
| *Guru ... ra'jat jang ma'moer* | *u* and *oe* | apostrophe | *dj* | *j* | no |

The other options fail because they mix features from two periods.

- *Goeroe* uses *oe* from the 1901 spelling, while *makmur* already uses the *k* of 1947.
- *mengajar* uses *j* for /j/ as in EYD, while *jang* still uses *j* for /y/. Those two ways never held at the same time.
- *rakyat yang* uses the *y* of 1972, while *mengadjar* still uses *dj*.
- *ra'jat* and *ma'moer* use the apostrophe and *oe* of 1901, while *Guru* already uses *u*.

So the sentence written entirely in the Republic spelling is *Guru itu mengadjar anak-anak rakjat jang makmur.*
