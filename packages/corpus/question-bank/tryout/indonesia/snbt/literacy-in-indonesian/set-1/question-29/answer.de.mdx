# Gegeben

Die Verbreitung der Geschichte von 1964 enthielt **zwei Fehler zugleich**: Die Zahl der untätigen Zeugen wurde auf <InlineMath math="38" /> übertrieben, und dieser Einzelfall wurde auf alle Stadtbewohner verallgemeinert.

# Gesucht

Die Situation, die genau beide Fehler zugleich enthält.

# Lösung

Suche das Beispiel, das **eine faktische Übertreibung** mit einer **unzulässigen Verallgemeinerung auf eine ganze Gruppe** verbindet.

> Die gesuchte Parallele muss sowohl die Tatsachen aufbauschen als auch aus einem Einzelfall ein Urteil über eine ganze Gruppe ableiten.

## Prüfung beider Fehler in allen Szenarien

Der **doppelte Kriterientest** trennt das passende Beispiel eindeutig von den übrigen.

| Szenario | Fakten übertrieben | Einzelfall auf Gruppe verallgemeinert | Urteil |
| --- | --- | --- | --- |
| Bericht über Touristen, "umringt von Dutzenden Händlern" statt nur <InlineMath math="3" />, als Beweis gegen alle Händler der Urlaubsstadt | Ja (<InlineMath math="3" /> zu Dutzenden) | Ja (alle Händler der Stadt) | **Richtig** |
| Veranstalter übertreiben Zahlen ohne Gruppenurteil | Ja | Nein | **Falsch** |
| Echter Taschendiebstahl auf alle Bahnhöfe verallgemeinert | Nein | Ja | **Falsch** |
| Korrekter Laborversuch auf jede Menge übertragen | Nein | Ja | **Falsch** |
| Vollständiges Video nur auf gezeigte Personen bezogen | Nein | Nein | **Falsch** |

# Antwort

Beide Fehler zugleich enthält **der Bericht über einen Touristen, der angeblich von Dutzenden Händlern statt nur <InlineMath math="3" /> umringt wurde und als Beweis für die Unfreundlichkeit aller Händler der Urlaubsstadt dient**.
