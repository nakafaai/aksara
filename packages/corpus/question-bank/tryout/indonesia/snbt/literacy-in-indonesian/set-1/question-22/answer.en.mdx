# Given

**The text traces** Indonesian spelling reforms in 1947, 1972, 2015, and 2022 along with how personal names are spelled.

# Asked

Which statements can be concluded from the reform timeline and the rule on personal names.

# Solution

> Keep the timeline straight in your head because each spelling change applies only from its reform year onward, never before.

Each statement has to be matched to the **year** of a reform or to what the text says about **personal names**.

The statement about the 1960 textbook can be concluded. 1960 falls between 1947 and 1972. The change from *j* to *y* only came in 1972, and the text says *j* for the /y/ sound was "dibiarkan seperti semula" (left as it was) in 1947. So an official book from 1960 still writes *jang*.

The statement about *oe* can be concluded. In 1947, **"oe diganti u"** (oe was replaced by u), and no later reform brought *oe* back.

The statement about pronouncing *cinta* can't be concluded. The text stresses, **"Yang berubah adalah lambang untuk bunyi, bukan bunyi itu sendiri"** (What changed was the symbol for the sound, not the sound itself). People still say the same word. Only the way it's written changed, from *tjinta* to *cinta*.

The statement about personal names can be concluded. The text says names such as *Soeharto* or *Djuanda* are **"masih tertulis dalam dokumen resmi puluhan tahun setelah 1972"** (still written in official documents decades after 1972). Those names use *oe* and *dj*, which stopped being standard in 1947 and 1972. So personal names in official documents don't always follow the spelling in force.

# Answer

**The table below summarizes the verdict for each statement**.

| Statement | Answer |
| --- | --- |
| An official 1960 book writes *jang* | Ya |
| Since 1947 the official spelling hasn't used *oe* | Ya |
| The 1972 reform changed how *cinta* is pronounced | Tidak |
| Names in official documents don't always follow the spelling in force | Ya |
