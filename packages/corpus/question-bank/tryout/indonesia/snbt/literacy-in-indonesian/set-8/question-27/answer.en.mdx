# Given

The 1981 **framing experiment is** repeated with <InlineMath math="300" /> students split evenly into two groups of <InlineMath math="150" />, keeping the <InlineMath math="72" /> percent choice for A and <InlineMath math="22" /> percent for C.

# Asked

How many students in total choose a sure programme, either A or C.

# Solution

> Even though A and C save the exact same number of lives, framing them as gains versus losses shifts how many people pick the sure choice.

The sure programme is A in the first group and C in the second. Work out each group, then add them.

| Group | Sure programme | Percentage | Students |
| --- | --- | ---: | ---: |
| First | A | <InlineMath math="72\%" /> | <InlineMath math="72\%\times150=108" /> |
| Second | C | <InlineMath math="100\%-78\%=22\%" /> | <InlineMath math="22\%\times150=33" /> |
| Total | | | <InlineMath math="141" /> |

In the second group <InlineMath math="78\%" /> chose the risky programme D, so only <InlineMath math="22\%" /> chose C.

The other options are wrong.

- <InlineMath math="150" /> assumes the same content means the same choice. The experiment shows choices change when the frame changes.
- <InlineMath math="225" /> uses the average of <InlineMath math="72\%" /> and <InlineMath math="78\%" />, but <InlineMath math="78\%" /> is the share choosing the **risky** programme.
- <InlineMath math="108" /> counts only the first group.
- <InlineMath math="33" /> counts only the second group.

# Answer

So <InlineMath math="141" /> students chose a sure programme: <InlineMath math="108" /> from the first group and <InlineMath math="33" /> from the second.
