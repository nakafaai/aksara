# Given

**The text sets** out programmes A, B, C, and D in the 1981 framing study alongside the psychological explanation for students' choices.

# Asked

Which statements can be concluded by separating experimental results from their explanation.

# Solution

> Programmes A and C both save <InlineMath math="200" /> of <InlineMath math="600" /> lives, and the flip in choices comes from how people react to gains versus losses rather than poor arithmetic.

Check each statement against the figures in the text, and tell **the experiment's results** apart from **its explanation**.

The statement that A and C have the same outcome can be concluded. C says <InlineMath math="400" /> of <InlineMath math="600" /> die, so <InlineMath math="200" /> are saved, as in A.

The statement that most of the first group chose the sure programme can be concluded. <InlineMath math="72\%" /> chose A.

The statement that most of the second group chose the sure programme can't be concluded. <InlineMath math="78\%" /> chose the risky programme D. Only <InlineMath math="22\%" /> chose the sure one.

The statement that B saves as many people as A on average can be concluded. One third of <InlineMath math="600" /> is <InlineMath math="200" />, the same as A.

The statement that the students couldn't work out probabilities can't be concluded. The text explains the choices by attitudes to gains and losses, not by arithmetic skill.

# Answer

The table below summarizes the verdict for each statement.

| Statement | Answer |
| --- | --- |
| A and C have the same outcome | Ya |
| Most of the first group chose the sure programme | Ya |
| Most of the second group chose the sure programme | Tidak |
| On average, B saves as many as A | Ya |
| The students couldn't work out probabilities | Tidak |
