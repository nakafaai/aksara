# Diketahui

**Teks menguraikan empat** pilihan program A, B, C, dan D dalam percobaan pembingkaian 1981 beserta penjelasan psikologis di balik pilihan mahasiswa.

# Ditanyakan

Pernyataan mana yang dapat disimpulkan dengan membedakan hasil percobaan dan penjelasannya.

# Penyelesaian

> Program A dan C sama-sama menyelamatkan <InlineMath math="200" /> dari <InlineMath math="600" /> orang, dan perbedaannya lahir dari sikap menghadapi untung-rugi bukan karena gagal berhitung.

Periksa setiap pernyataan dengan angka di teks, dan bedakan antara **hasil percobaan** dan **penjelasannya**.

Pernyataan bahwa A dan C memberi hasil yang sama dapat disimpulkan. C menyebut <InlineMath math="400" /> meninggal dari <InlineMath math="600" />, jadi <InlineMath math="200" /> selamat, sama dengan A.

Pernyataan bahwa sebagian besar kelompok pertama memilih program pasti dapat disimpulkan. <InlineMath math="72\%" /> memilih program A.

Pernyataan bahwa sebagian besar kelompok kedua memilih program pasti tidak dapat disimpulkan. <InlineMath math="78\%" /> memilih program D, yang berisiko. Yang memilih program pasti hanya <InlineMath math="22\%" />.

Pernyataan bahwa program B rata-rata menyelamatkan orang sebanyak A dapat disimpulkan. Harapan penyelamatannya <InlineMath math="200" /> orang (<InlineMath math="\frac{1}{3}" /> dari <InlineMath math="600" />), sama dengan A.

Pernyataan bahwa mahasiswa tidak dapat menghitung peluang tidak dapat disimpulkan. Teks menjelaskan pilihan itu dengan sikap terhadap keuntungan dan kerugian, bukan dengan kemampuan berhitung.

# Jawaban

**Ringkasan penilaian untuk setiap pernyataan tercantum pada tabel berikut**.

| Sebagian besar kelompok kedua memilih program pasti | Tidak |
| Rata-rata, B menyelamatkan orang sebanyak A | Ya |
