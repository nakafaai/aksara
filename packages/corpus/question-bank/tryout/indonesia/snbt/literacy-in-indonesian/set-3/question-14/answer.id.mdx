**Data dasar** adalah titik acuan sebelum perubahan. Dalam bacaan, tiga angka memiliki peran berbeda meskipun satuan pengukurannya sama.

| Nilai rata-rata peminjaman per kunjungan | Peran |
| --- | --- |
| <InlineMath math="24" /> | Data awal sebelum ringkasan jadwal diuji |
| <InlineMath math="35" /> | Hasil selama uji ringkasan jadwal |
| <InlineMath math="26" /> | Hasil pada kondisi pembanding tanpa ringkasan jadwal |

Definisi itu menjelaskan mengapa nilai <InlineMath math="24" /> dipakai untuk membaca perubahan dari keadaan awal. Nilai <InlineMath math="26" /> tetap memberi pembanding lain. **Titik acuan tidak membuktikan penyebab** sendirian dan tidak menggantikan masukan pengguna atau pemeriksaan pengaruh cuaca.
