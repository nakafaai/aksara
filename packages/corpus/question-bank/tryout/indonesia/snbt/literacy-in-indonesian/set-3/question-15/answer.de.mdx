# Gegeben

**Text A und** Text B diskutieren Onlinekredite, Finanzwissen der Bewohner, Kostenanzeige und die Monatslast von Tageszinsen.

# Gesucht

Welchen Aussagen die Autoren von Text A und Text B zugleich zustimmen.

# Lösung

> Prüfe, ob wirklich beide Texte den Punkt mittragen, vertritt ihn nur eine Seite, lautet die Antwort sofort Nein.

Das Schlüsselwort ist **sekaligus** (beide zugleich). Eine Aussage kommt nur in Ya (Ja), wenn **beide** Autoren zustimmen.

- **Aussage 1: Ya**. Text A stellt Finanzbildung in den Mittelpunkt. Text B schreibt: **"Edukasi tetap berguna, tetapi tidak cukup."** (Bildung bleibt nützlich, reicht aber nicht.)
- **Aussage 2: Tidak (Nein)**. Text A nutzt die Umfrage als Beleg für die Ursache, Text B sagt aber, sie **"perlu dibaca hati-hati"** (müsse vorsichtig gelesen werden), weil eine Vergleichsgruppe fehlt.
- **Aussage 3: Tidak**. Das schlägt nur **Text B** vor. Text A verlangt keine neuen Regeln und sagt sogar, es gebe **"sudah banyak"** (schon viele).
- **Aussage 4: Ya**. Text A schreibt, Zinsen von <InlineMath math="0{,}4\%" /> **"terdengar kecil, padahal dalam sebulan nilainya jauh lebih besar"** (klingen klein, sind aber im Monat viel größer). Text B rechnet es aus: In <InlineMath math="30" /> Tagen werden daraus Rp<InlineMath math="120{.}000" />.
- **Aussage 5: Tidak**. Für Text A sind alle Zahlen **"terbuka bagi siapa pun yang mau membaca"** (für jeden offen, der lesen will), Text B schreibt dagegen, sie seien **"baru terlihat lengkap setelah pinjaman disetujui"** (erst nach der Bewilligung vollständig zu sehen). Sie sind uneins.

# Antwort

Die folgende Tabelle fasst die Bewertung jeder Aussage zusammen.

| Aussage | Antwort |
| --- | --- |
| Verständnis der Bewohner bleibt nützlich | Ya |
| Die Umfrage zeigt die Ursache hinreichend | Tidak |
| Gesamtkosten auf einer Seite vorschreiben | Tidak |
| Tageszinsen sind im Monat viel größer | Ya |
| Kosten vor der Bewilligung vollständig sichtbar | Tidak |
