# Given

According to the passage, an **anchor** is a number seen or heard beforehand that becomes the starting point for an **estimate**, even though the number **carries no genuine information about the true value**.

# Asked

All cases in which an earlier number works as an anchor as explained in the passage.

# Solution

Test all five cases against **both anchoring criteria together**: someone is making an estimate, and the initial number supplies no real value information.

> The painting auction and tower-height estimate satisfy both anchoring conditions, whereas the other three cases rely on real cost data, identical-item price comparison, or an actual market receipt.
