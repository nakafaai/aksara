# Given

**The story follows** bus driver Warsito, Ardi, Bu Tarmi at the roadside restaurant, the route board, and warming up the engine.

# Asked

Which statements can be concluded from the characters' actions and story details.

# Solution

> Separate what the characters' actions genuinely reveal from extra details that never appear anywhere in the story.

Each statement has to be matched with **the right part of the story**. Some must be inferred from what the characters do, and some set a trap with a detail that never appears.

- **Statement 1: Ya (Yes)**. Warsito hands over money **"untuk melunasi bon"** (to pay off the tab). Bu Tarmi tears out the tab page, tucks it into Warsito's pocket and **pushes the money back**. On the route's last night, that means the debt is wiped out as a farewell.
- **Statement 2: Tidak (No)**. Ardi asks for the opposite: **no stop at Pemalang**, so they arrive sooner. It's Warsito who still turns the bus in there.
- **Statement 3: Tidak**. Ardi says the bus is **"telat empat puluh menit"** (forty minutes late).
- **Statement 4: Ya**. Ardi offers to take the sign to the scrap dealer because **"besinya lumayan"** (the metal's worth something). Warsito declines and **wraps the sign in a jacket**, as if keeping something precious.
- **Statement 5: Tidak**. That habit is one Warsito **"pegang selama dua puluh tiga tahun"** (has kept for twenty-three years).

# Answer

**The table below summarizes the verdict for each statement**.

| Statement | Answer |
| --- | --- |
| Bu Tarmi wipes out the tab | Ya |
| Ardi asked to stop at the restaurant | Tidak |
| The bus arrived on time | Tidak |
| The sign is kept because it matters to Warsito | Ya |
| The warming-up habit only started that night | Tidak |
