# Given

**Text A proposes** smaller classes citing the STAR project, while Text B examines extra classrooms needed and effects on poor pupils.

# Asked

Which statements can be concluded by combining the views and figures from both texts.

# Solution

> Separate what both writers agree on about smaller classes from Text B's practical worries about extra classrooms and staffing.

Three statements test what Text B's writer accepts and rejects. One asks you to combine figures from both texts.

The statement that both writers agree small classes help can be concluded. Text A cites STAR's result as the basis for its proposal, and Text B says, **"saya setuju bahwa anak kelas 1 belajar lebih baik dalam kelas yang lebih kecil"** (I agree that grade 1 children learn better in smaller classes).

The statement that Text B rejects STAR because it wasn't random can't be concluded. Text B says, **"Saya tidak meragukan Project STAR"** (I don't doubt Project STAR), and calls it **"dirancang dengan baik"** (well designed). Text A also says the assignment was random.

The statement about <InlineMath math="20" /> extra classes can be concluded, but the figures have to be combined from both texts. The number of pupils is in Text B, and the class sizes are in Text A.

| Class size | Classes for <InlineMath math="1{,}440" /> pupils |
| --- | ---: |
| <InlineMath math="36" /> pupils, now | <InlineMath math="1{,}440:36=40" /> |
| <InlineMath math="24" /> pupils, Text A's proposal | <InlineMath math="1{,}440:24=60" /> |

The difference is <InlineMath math="60-40=20" /> classes.

The statement that California's result was small because small classes don't help poor pupils can't be concluded. According to Text B, the problem was new teachers who **"belum memiliki sertifikat mengajar penuh"** (didn't yet have full teaching certificates) and worked mostly in poor areas. Text B still says, **"Kelas kecil bermanfaat kalau diajar oleh guru yang layak"** (Small classes help if taught by qualified teachers).

# Answer

**The table below summarizes the verdict for each statement**.

| Statement | Answer |
| --- | --- |

| Text B rejects STAR because it wasn't random | Tidak |
