Die beiden falschen Aussagen **vertauschen einen Begriff** oder **kehren die Richtung einer Übergabe um**.

| Aussage | Antwort | Beleg |
| --- | --- | --- |
| Muskat wuchs bis ins 18. Jahrhundert nur auf Banda | Benar (richtig) | Der erste Absatz sagt das direkt. |
| Macis ist eine Muskatsorte aus Mauritius | Salah (falsch) | Erster Absatz: *fuli* (Macis) ist die rote Hülle um den Muskatsamen. Mauritius erscheint erst später als Ort, an dem Setzlinge gepflanzt wurden. |
| Die Niederländer gaben Run an England | Salah (falsch) | Vierter Absatz: England verzichtete auf Run, die Niederlande auf New Amsterdam. |
| Die Pflanzungen bearbeiteten als Sklaven verschleppte Menschen | Benar (richtig) | Der dritte Absatz sagt, die Pflanzungen wurden von als Sklaven hergebrachten Menschen bearbeitet. |

Die dritte Aussage prüft **die Richtung der ausgetauschten Ansprüche** im Vertrag von Breda.
