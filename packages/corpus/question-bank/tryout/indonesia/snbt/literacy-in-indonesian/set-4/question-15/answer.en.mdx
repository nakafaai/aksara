# Given

In **Text B**, California's statewide cap triggered a scramble for teachers that filled classrooms with uncertified hires. In **Lembah Hijau District**, capping classes at <InlineMath math="24" /> demands many new teachers, yet last year the office received only **<InlineMath math="8" /> certified primary-teacher applicants**.

# Asked

The shared feature between California and Lembah Hijau that makes California strongest support for Text B's proposal.

# Solution

Find the **exact bottleneck behind California's weak result** that also appears in Lembah Hijau's staffing figures.

> Both places require a surge of new teachers while having far too few qualified certified teachers available.

## Checking each claimed similarity

Verifying **every option against facts for both places** rules out all four distractors.

| Claimed similarity | Facts for California and Lembah Hijau | Verdict |
| --- | --- | --- |
| Both need many new teachers while far fewer qualified teachers are available | California hired uncertified staff, Lembah Hijau had only <InlineMath math="8" /> certified applicants | **Correct** |
| Both used a cap of <InlineMath math="24" /> students | False, California used <InlineMath math="20" />, Lembah Hijau proposed <InlineMath math="24" /> | **Incorrect** |
| Both used random student assignment | False, randomization belonged to Project STAR | **Incorrect** |
| Both started with the neediest schools | False, that is Text B's proposal, California left poor areas with uncertified staff | **Incorrect** |
| Both saw test scores decline | False, California's gains were merely smaller than STAR's | **Incorrect** |

# Answer

California most strongly supports Text B's proposal because **both places demand many new teachers while far fewer qualified teachers are available**.
