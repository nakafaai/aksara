# Given

The education office wants to pair **Text A's Project STAR finding** (smaller classes help low-income students most) with **Text B's safeguards** (start with the neediest schools and expand only as fast as certified teachers become available).

# Asked

All policies that use Project STAR's findings while answering Text B's objection.

# Solution

Choose options that **actually implement smaller classes** where gains are largest while **protecting certified teacher supply** instead of repeating California's rush.

> Starting with schools serving the lowest-income students and adding small classes only as fast as certified teachers can be hired satisfies both texts together.

## Testing all five policy options

Checking **alignment with STAR and Text B's teacher constraint** isolates the two matching policies.

| Policy option | Uses STAR findings | Answers Text B's teacher concern | Verdict |
| --- | --- | --- | --- |
| Prioritize schools with the lowest-income students first | Yes (largest STAR gains) | Yes (matches Text B's advice) | **Fits** |
| Add small classes each year only as certified teachers are hired | Yes (shrinks classes) | Yes (avoids uncertified shortcuts) | **Fits** |
| Shrink all classes at once using uncertified teachers | Repeats California's mistake | Violates Text B's core warning | **Does not fit** |
| Cancel class-size reduction altogether | Ignores STAR completely | Overreaches (B does not reject small classes) | **Does not fit** |
| Wait for a brand-new local randomized trial | Both authors accept STAR | B only asks for phased rollout | **Does not fit** |

# Answer

The matching policies are **reducing class sizes first in schools with the lowest-income students** and **adding small classes each year in step with the number of certified teachers who can be hired**.
