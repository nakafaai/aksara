# Given

Text A's **smaller class size** creates extra classes needing one teacher each, while Text B notes only <InlineMath math="8" /> certified applicants arrive each year.

# Asked

How many new teachers are needed and in which year that need is finally met.

# Solution

> Find how many extra classes the smaller class size creates first, then count year by year at <InlineMath math="8" /> new teachers per year.

This question combines the class sizes from Text A with the numbers of pupils and applicants from Text B.

**Step 1. Extra classes**. There are now <InlineMath math="1{,}440:36=40" /> classes. With at most <InlineMath math="24" /> pupils per class, <InlineMath math="1{,}440:24=60" /> classes are needed. So there are <InlineMath math="60-40=20" /> new classes, needing <InlineMath math="20" /> new teachers.

**Step 2. The year it's met**. Each year brings <InlineMath math="8" /> new teachers.

| Year | New teachers so far |
| --- | ---: |
| First | <InlineMath math="8" /> |
| Second | <InlineMath math="16" /> |
| Third | <InlineMath math="24" /> |

In the second year there are only <InlineMath math="16" />, still short of <InlineMath math="20" />. The need is only met in the third year.

The other options are wrong.

- <InlineMath math="12" /> teachers is the difference in class size, <InlineMath math="36-24" />. That's a number of pupils, not of classes.
- <InlineMath math="40" /> teachers is the number of classes that already exist. Those classes already have teachers.
- <InlineMath math="20" /> teachers is right, but <InlineMath math="20:8=2.5" /> mustn't be rounded down. At the end of the second year there are only <InlineMath math="16" />.
- <InlineMath math="60" /> teachers is all the classes after the cut, including <InlineMath math="40" /> that already have teachers.

# Answer

So **<InlineMath math="20" />** new teachers are needed, and the need is only met in the third year.
