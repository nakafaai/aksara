For a statement about **both texts**, find evidence in each one. For the others, separate **reinterpreting** a figure from claiming it was miscalculated.

| Statement | Answer | Evidence |
| --- | --- | --- |
| Both texts acknowledge fast feedback | Ya (yes) | Text 1: written feedback within seconds. Text 2: fast feedback is very useful while students draft. |
| Text 1 explains how off-topic essays are scored | Tidak (no) | The example of an essay that misses the question appears only in Text 2. |
| Text 2 wants teachers to set final grades | Ya (yes) | Text 2: "nilai akhir sebaiknya tetap ditentukan guru" (final grades should still be decided by teachers). |
| Text 2 says the agreement figure was miscalculated | Tidak (no) | Text 2 accepts the 78 percent but calls it an average that hides problems with unusual essays. |

The fourth statement is often marked Ya because Text 2 criticises Text 1. The criticism concerns **what the figure means**, not how it was calculated.
