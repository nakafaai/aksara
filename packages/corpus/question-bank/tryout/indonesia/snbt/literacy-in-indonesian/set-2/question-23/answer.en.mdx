# Given

**The passage traces** Bogor Botanical Gardens, oil palm seedlings, the herbarium, researchers' aims, and historians' views.

# Asked

Which statements can be concluded directly from the passage without overstating its wording.

# Solution

> One overstated word like all or living can flip a fact into a trap, so anchor each check to the exact sentence in the text.

Each statement has to be matched with **the exact sentence** in the text. Some set a trap with one word too many.

- **Statement 1: Ya (Yes)**. The text calls oil palm **"tanaman yang berasal dari Afrika Barat"** (a plant from West Africa). So the seedlings planted in 1848 came from outside the archipelago.
- **Statement 2: Tidak (No)**. The herbarium is **"kumpulan spesimen tumbuhan yang dikeringkan"** (a collection of dried plant specimens), not living plants. Keeping threatened plants alive is part of today's conservation.
- **Statement 3: Ya**. Researchers came to the laboratory to study tropical plants, **"termasuk jenis-jenis yang tidak punya nilai dagang"** (including species with no trade value).
- **Statement 4: Tidak**. The text says genetic diversity in the garden is **"jauh lebih sempit daripada di alam"** (far narrower than in the wild), because each species is represented by only a few individuals.
- **Statement 5: Tidak**. The text says **"sebagian sejarawan"** (some historians), not all.

# Answer

**The table below summarizes the verdict for each statement**.

| Statement | Answer |
| --- | --- |
| The oil palm seedlings came from outside the archipelago | Ya |
| The herbarium keeps living plants | Tidak |
| Some researchers weren't after profitable crops | Ya |
