# Given

**The passage describes** mercury pollution from upstream mining, safety limits, and lingering mercury levels in swamp fish.

# Asked

Which statements can genuinely be concluded from the river mercury passage.

# Solution

> Check every claim straight against the passage because a statement can sound scientifically sensible and still go beyond the text.

This question tests whether each statement is really backed by the text, not just plausible. Judge them one by one.

**Statement 1**. The team's limit is <InlineMath math="0.5" />. The averages in the table are <InlineMath math="0.06" />, <InlineMath math="0.15" />, <InlineMath math="0.42" />, <InlineMath math="0.10" />, <InlineMath math="0.32" /> and <InlineMath math="0.90" />. Only <InlineMath math="0.90" /> goes over the limit. The level <InlineMath math="0.42" /> is close, but still below it. The answer is Ya.

**Statement 2**. The figure <InlineMath math="0.90" /> is an average of <InlineMath math="10" /> fish. An average above the limit doesn't mean **every fish** is above it, because some fish can be far above and others below. The answer is Tidak.

**Statement 3**. The fifth paragraph says mercury already settled in swamp mud "dapat terus diubah oleh bakteri selama bertahun-tahun" (can keep being converted by bacteria for years). So stopping mercury use doesn't guarantee fish levels drop quickly. The answer is Ya.

**Statement 4**. The level <InlineMath math="0.42" /> is below the limit, but the text never says that limit is safe for a pregnant woman to eat every day. The fifth paragraph advises pregnant women to choose plant-eating fish more often than predators. The answer is Tidak.

**Statement 5**. The team only says swamp mud "kemungkinan besar" (most likely) converts more mercury. The team also admits fish size wasn't recorded and fish were caught in only one season. That's **a strong guess, not proof**. The answer is Tidak.

| Statement | Answer |
| --- | --- |
| Exactly <InlineMath math="1" /> average level is above the limit | Ya |
| Every downstream predator is above the limit | Tidak |
| Swamp fish levels won't necessarily fall soon | Ya |
| Upstream predators are safe for pregnant women every day | Tidak |
| The team proved swamp mud is the cause | Tidak |

# Answer

So only two statements can be concluded: that one average level is above the limit, and that swamp fish levels won't necessarily fall soon.
