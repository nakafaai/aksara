# Given

The story inserts a memory of **seven-year-old Laras** learning to count warp threads under Mother's rule: "One thread wrong, the whole pattern tilts." On the bus at the end, Laras counts the threads of the new blueprint-like pattern twice and finds "not a single one was wrong."

# Asked

The primary narrative role of the childhood memory about counting warp threads.

# Solution

Connect the **childhood precision lesson** to the closing scene on the bus to see how the flashback unlocks the meaning of Laras's final act.

> Without the childhood memory of "one thread wrong, the whole pattern tilts", Laras's careful counting on the bus would not show that Mother's precision lives on inside the new pattern.

## Checking the five candidate roles

Examining **the second half of each option** isolates the exact narrative payoff.

| Candidate role | Fit with the story | Verdict |
| --- | --- | --- |
| Prepares the ending so finding zero wrong threads shows inherited precision living on in a new form | Directly links the flashback to the bus scene | **Correct** |
| Shows Laras is afraid of Mother | False, she secretly grew to love it once her first pattern came out straight | **Incorrect** |
| Orders Laras to keep weaving bamboo-shoot patterns | False, Mother herself switched the motif and said "with whatever thread" | **Incorrect** |
| Shows the new motif came out tilted | False, not a single thread was wrong | **Incorrect** |
| Frames Laras's departure as an escape | False, the story never portrays her leaving as running away | **Incorrect** |

# Answer

The memory primarily **prepares the ending so that when Laras finds not a single thread wrong, the reader sees that the inherited precision stays alive in a new form**.
