The memory holds one lesson: **"Satu benang salah, seluruh motif miring."** (One wrong thread and the whole pattern slants.) Look for the part of the story that echoes it.

- **The echo at the end**. On the bus, Laras opens the cloth and sees a new pattern of lines like floor plans. Laras **counts the threads once, then once more**, just as Ibu (Mother) taught. The result: **"Tidak ada satu pun yang salah."** (Not a single one is wrong.)
- **What it means**. The pattern has changed from bamboo shoots to floor-plan lines, but the care that was handed down is the same. Without the memory, that count on the bus would mean nothing.

Three options open with the same part, so the second part decides.

- Nothing shows fear. Laras hated the lessons at first, but **"diam-diam menyukainya"** (secretly came to like them) when the first pattern came out straight.
- Ibu says **"entah dengan benang apa"** (with whatever thread), so it isn't an order to keep the bamboo-shoot pattern. Ibu has already changed the pattern herself.
- The count finds no wrong thread at all, so the pattern doesn't slant.
- Laras only hated the counting lessons at first, then secretly came to like them. Leaving isn't shown as an escape either.

So the memory mainly sets up the ending, so that when Laras finds no wrong thread, the reader sees that the inherited care lives on in a new form.
