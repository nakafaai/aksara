The answer has to be right in **two parts**: the data used and the assumption needed.

- **Data**. Only in corridors C and D was frequency **"tidak berubah"** (unchanged), so only there does the fare effect show on its own. Both rose <InlineMath math="10\%" />.
- **Assumption**. Corridors A and B also got the lower fare, but its effect is mixed with more frequent buses. For the C and D figure to apply citywide, riders on A and B have to be assumed to respond to the cheaper fare in the same way.

The other options are wrong.

- Assuming more frequent buses add no riders isn't needed, and it clashes with the big rises on A and B.
- Not every corridor got the same change. Only A and B got more frequent buses.
- A and B got two changes at once, so the fare effect can't be separated there.
- How riders pay has nothing to do with how much the fare affects rider numbers.

So the best data is corridors C and D, assuming riders on A and B respond to the cheaper fare like riders on C and D.
