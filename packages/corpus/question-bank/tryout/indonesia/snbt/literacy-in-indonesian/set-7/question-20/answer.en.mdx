A shared view must be found in **both texts**. Text 1 wants class time used for **discussion and practice problems**. Text 2 values in-person classes because **questions can be asked when confusion arises**. Both value asking and practising in class, though they differ about lectures.

- Watching for many hours at once is criticised by Text 2 and not recommended by Text 1.
- Text 2 says not every student has a stable connection.
- Text 1 still uses lectures, only as recordings.
- Text 1 keeps class time for discussion, and Text 2 defends in-person teaching.

So both writers would most likely agree that students need chances to ask questions and practise together in class.
