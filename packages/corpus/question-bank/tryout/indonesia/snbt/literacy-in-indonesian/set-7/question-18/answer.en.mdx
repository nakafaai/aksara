# Given

**The text and** table record weekday ridership across four city bus corridors before and after the fare cut.

# Asked

Which statements can be concluded from each corridor's percentage rise and the text.

# Solution

> Compute each corridor's percentage gain from its starting ridership and remember that table numbers alone never prove a single cause.

First work out each corridor's percentage rise.

| Corridor | Rise | Percentage |
| --- | ---: | ---: |
| A | <InlineMath math="16-10=6" /> | <InlineMath math="60\%" /> |
| B | <InlineMath math="12-8=4" /> | <InlineMath math="50\%" /> |
| C | <InlineMath math="13.2-12=1.2" /> | <InlineMath math="10\%" /> |
| D | <InlineMath math="6.6-6=0.6" /> | <InlineMath math="10\%" /> |
| Total | <InlineMath math="47.8-36=11.8" /> | about <InlineMath math="33\%" /> |

The statement that passengers rose on every corridor can be concluded. All four rose.

The statement that Corridor A had the biggest percentage rise can be concluded. Its <InlineMath math="60\%" /> is bigger than any other corridor's.

The statement that the fare cut caused the <InlineMath math="60\%" /> rise on Corridor A can't be concluded. Corridor A also got more frequent buses, so the rise can't be put down to the fare alone. On corridors that got only the cheaper fare, the rise was just <InlineMath math="10\%" />.

The statement that Corridors C and D rose by the same percentage can be concluded. Both rose <InlineMath math="10\%" />.

The statement that total passengers rose by more than <InlineMath math="50\%" /> can't be concluded. The total rise is about <InlineMath math="33\%" />, matching the mayor's **"hampir sepertiga"** (almost a third).

# Answer

The table below summarizes the verdict for each statement.

| Statement | Answer |
| --- | --- |
| Passengers rose on every corridor | Ya |
| Corridor A had the biggest percentage rise | Ya |
| The fare caused the <InlineMath math="60\%" /> rise on Corridor A | Tidak |
| Corridors C and D rose by the same percentage | Ya |
| Total passengers rose by more than <InlineMath math="50\%" /> | Tidak |
