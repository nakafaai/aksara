Penyebutan kebakaran 2015 muncul setelah uraian bahwa api gambut **menghasilkan asap tebal** dan dapat bertahan berminggu-minggu. Peristiwa itu menjadi contoh nyata **besarnya dampak** asap tersebut: kabut asap menyelimuti sebagian Asia Tenggara selama berbulan-bulan.

- Bacaan tidak menyebut kebakaran gambut hanya terjadi di Indonesia.
- Pembentukan gambut dijelaskan di paragraf pertama, bukan melalui peristiwa 2015.
- Negara tetangga tidak disalahkan. Kabut asap justru menyelimuti mereka.
- Penggalian kanal baru justru menjadi penyebab gambut mengering.

Jadi, penulis menyebut kebakaran 2015 untuk menunjukkan betapa luas dampak asap dari kebakaran gambut.
