# Given

**The text describes** pantun structure, a-b-a-b rhyme, sampiran and message lines, regional heritage, and how exchanged pantun stays alive.

# Asked

Which statements can be concluded accurately without falling for overly strong words or half-met rules.

# Solution

> A true pantun needs both an opening sampiran and a closing message, not just any four a-b-a-b lines packed with advice.

Some statements trap you with a word that's too strong or a feature that's only partly met.

The statement about a stanza of message can be concluded. The rhyme fits, but a pantun has **"Dua baris pertama"** (the first two lines) as sampiran and the last two as content. A stanza whose four lines are all message has no sampiran.

The statement that pantun comes from Indonesia can't be concluded. The text says pantun **"hidup di banyak masyarakat berbahasa Melayu, tidak terikat pada satu negara"** (lives in many Malay-speaking communities, not tied to one country).

The statement about guessing the sound can be concluded. The sampiran prepares the sound, **"sehingga pendengar sudah dapat menebak rima isi sebelum isi itu diucapkan"** (so listeners can guess the content's rhyme before it's spoken).

The statement that the echo is always there can't be concluded. The echo is **"longgar dan tidak selalu ada"** (loose and not always there).

The statement about pantun lasting can be concluded. **"Pantun bertahan selama orang masih membalasnya"** (pantun lasts as long as people still answer it).

# Answer

The table below summarizes the verdict for each statement.

| Statement | Answer |
| --- | --- |
| An a-b-a-b stanza of message doesn't meet every feature | Ya |
| Pantun comes from Indonesia | Tidak |
| Listeners can guess the content's sound | Ya |
| The sampiran's echo is always there | Tidak |
| Pantun lasts while people answer it | Ya |
