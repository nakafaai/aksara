# Given

**A farmer harvests** <InlineMath math="5" /> tonnes per hectare, IRRI's simulation at current <InlineMath math="\mathrm{CO_2}" /> projects a <InlineMath math="32" /> percent gain, and supporters target a <InlineMath math="50" /> percent gain.

# Asked

The projected C4 rice yield per hectare on that farm and how it compares with the supporters' target.

# Solution

> Apply both the <InlineMath math="32" /> percent simulation gain and the <InlineMath math="50" /> percent target gain to the same <InlineMath math="5" />-tonne base, then subtract to see the gap.

The question uses the simulation figure for **current** <InlineMath math="\mathrm{CO_2}" />, a <InlineMath math="32\%" /> gain, then compares it with the <InlineMath math="50\%" /> target.

| Estimate | Working | Yield per hectare |
| --- | --- | ---: |
| Simulation, current <InlineMath math="\mathrm{CO_2}" /> | <InlineMath math="5+32\%\times5" /> | <InlineMath math="6.6" /> t |
| Supporters' target | <InlineMath math="5+50\%\times5" /> | <InlineMath math="7.5" /> t |

The difference is <InlineMath math="7.5-6.6=0.9" /> tonnes. The simulated yield is **less** than the target.

The other options are wrong.

- <InlineMath math="7.5" /> tonnes is the target, but the question asks for the simulation's estimate.
- <InlineMath math="6.05" /> tonnes uses the <InlineMath math="21\%" /> gain, the estimate for higher <InlineMath math="\mathrm{CO_2}" />, not current levels.
- <InlineMath math="1.6" /> tonnes is only the gain, without adding the original <InlineMath math="5" /> tonnes.
- The working is right but the direction is reversed. The simulated yield is smaller than the target.

# Answer

So C4 rice on that farm would yield <InlineMath math="6.6" /> tonnes per hectare, <InlineMath math="0.9" /> tonnes less than the supporters' target.
