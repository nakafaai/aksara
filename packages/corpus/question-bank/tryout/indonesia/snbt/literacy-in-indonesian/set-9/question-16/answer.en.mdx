# Asked

# Solution

Because **group sizes differ**, compute the **weighted average gain** using weights of <InlineMath math="120" /> and <InlineMath math="180" /> students.

<BlockMath math="\text{average gain} = \frac{120 \times 12 + 180 \times 9}{300} = \frac{1{,}440 + 1{,}620}{300} = \frac{3{,}060}{300} = 10.2\text{ points}" />

> The whole-class gain is <InlineMath math="10.2" /> points, lying strictly between <InlineMath math="9" /> and <InlineMath math="12" /> (closer to <InlineMath math="9" /> because non-tutored students outnumber tutored ones).
