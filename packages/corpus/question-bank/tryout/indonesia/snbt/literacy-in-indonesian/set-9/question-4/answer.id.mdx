# Diketahui

**Petani memanen** <InlineMath math="5" /> ton gabah per hektare, simulasi IRRI pada kadar <InlineMath math="\mathrm{CO_2}" /> saat ini memprediksi kenaikan <InlineMath math="32" /> persen, sedangkan target pendukung adalah <InlineMath math="50" /> persen.

# Ditanyakan

Perkiraan hasil padi C4 per hektare di sawah petani itu dan selisihnya terhadap target para pendukung.

# Penyelesaian

> Hitung dua angka dari dasar <InlineMath math="5" /> ton per hektare, yaitu kenaikan <InlineMath math="32" /> persen menurut simulasi dan kenaikan <InlineMath math="50" /> persen menurut target, lalu cari selisihnya.

Soal ini memakai angka simulasi untuk kadar <InlineMath math="\mathrm{CO_2}" /> **saat ini**, yaitu tambahan <InlineMath math="32\%" />, lalu membandingkannya dengan target <InlineMath math="50\%" />.

| Perkiraan | Hitungan | Hasil per hektare |
| --- | --- | ---: |
| Simulasi, <InlineMath math="\mathrm{CO_2}" /> saat ini | <InlineMath math="5+32\%\times5" /> | <InlineMath math="6{,}6" /> ton |
| Target para pendukung | <InlineMath math="5+50\%\times5" /> | <InlineMath math="7{,}5" /> ton |

Selisihnya <InlineMath math="7{,}5-6{,}6=0{,}9" /> ton. Hasil menurut simulasi lebih **sedikit** daripada target.

Pilihan lain keliru.

- <InlineMath math="7{,}5" /> ton adalah target, padahal soal meminta perkiraan simulasi.
- <InlineMath math="6{,}05" /> ton memakai tambahan <InlineMath math="21\%" />, yaitu perkiraan untuk kadar <InlineMath math="\mathrm{CO_2}" /> yang lebih tinggi, bukan kadar saat ini.
- <InlineMath math="1{,}6" /> ton hanya tambahannya, belum ditambah hasil semula <InlineMath math="5" /> ton.
- Hitungannya benar, tetapi arahnya terbalik. Hasil simulasi lebih kecil daripada target.

# Jawaban

Jadi, padi C4 di sawah itu menghasilkan **<InlineMath math="6{,}6" />** ton per hektare, atau **<InlineMath math="0{,}9" />** ton lebih sedikit daripada target para pendukung.
