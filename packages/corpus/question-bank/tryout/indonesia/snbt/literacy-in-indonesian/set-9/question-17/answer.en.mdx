# Given

**Two tables report** mock-exam gains for tutored and untutored students, both overall and among students with the same starting score.

# Asked

Which figure best estimates the true effect of tutoring on mock-exam scores.

# Solution

> Comparing two runners is fair only when both start at the same line, so use the difference in score gains from the matched second table.

The effect of tutoring is best measured by comparing the **rise** in scores of two groups with **the same starting point**.

| Comparison | Rise, tutored | Rise, not tutored | Difference |
| --- | ---: | ---: | ---: |
| First table, all students | <InlineMath math="74-62=12" /> | <InlineMath math="64-55=9" /> | <InlineMath math="3" /> |
| Second table, starting score <InlineMath math="60" /> to <InlineMath math="65" /> | <InlineMath math="73-62=11" /> | <InlineMath math="71-62=9" /> | <InlineMath math="2" /> |

In the second table both groups start from <InlineMath math="62" />. So the <InlineMath math="2" />-point difference in rises comes closest to the effect of tutoring. The teacher warns that even this isn't perfect, because motivation hasn't been matched.

The other options are wrong.

- The <InlineMath math="10" />-point gap in February mixes the effect of tutoring with differences from the start. Tutored students were already <InlineMath math="7" /> points ahead in August.
- The <InlineMath math="7" />-point gap in August came **before** tutoring began, so it can't be caused by tutoring.
- The <InlineMath math="3" />-point difference in rises is better than <InlineMath math="10" /> points, but the two groups in the first table start from different points.
- The score <InlineMath math="73" /> alone shows no effect without a comparison.

# Answer

So the figure closest to the effect of tutoring is the difference in rises in the second table, **<InlineMath math="2" />** points.
