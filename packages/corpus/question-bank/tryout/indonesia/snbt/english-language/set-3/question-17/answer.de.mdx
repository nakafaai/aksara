Zunächst ist die Karte eine offizielle, sachlich richtige Referenz, die vom Eingang aus schwer nutzbar ist. Nora dreht sie und verfolgt die Route aus Sicht der Fahrgäste. Als ein Kind damit die Haltestelle findet, bestätigt sich die neue Funktion. Diese Abfolge trägt **Rotating the recurring map and retracing the route changes it from a staff-facing reference into a passenger-facing guide, a shift confirmed when the child finds the stop.**
