A class designed a simulated investigation of load distribution in paper bridge models. The question was whether folding the deck into a triangular truss was associated with a change in the number of washers held before collapse. Before collecting data, the students agreed to keep paper mass, bridge span, and placement of each weight the same in every condition.

| Condition | Mean result |
| --- | ---: |
| Baseline | 24 |
| With the change | 39 |
| Comparison | 25 |

The condition with the change differed from both other conditions. The class did not treat this pattern as proof that the same result would always occur. Its report identified an important limitation: paper fibres and folds varied slightly between models.

The report used the term *truss* to mean a framework of connected triangles that distributes forces. The students proposed a longer repetition with more units and the same measurement rules. This next step would test the pattern without hiding the uncertainty in the first investigation.
