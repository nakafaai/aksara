A physics class investigated whether a rougher ramp surface would change the time taken by a wooden block to reach the bottom. They measured travel time in tenths of a second. The same block, ramp angle, and release point were used throughout, so the main planned difference was the surface under the block.

| Condition | Mean result |
| --- | ---: |
| Baseline | 42 |
| With the change | 67 |
| Comparison | 41 |

The uncovered ramp gave similar means at the beginning and in the comparison condition. When the ramp was covered with coarse fabric, the mean rose to 67. That pattern supports a link between the fabric and a longer travel time under this setup, but it does not establish a universal rule.

One problem remained: the fabric became worn as blocks travelled across it. Later runs might therefore have used a smoother surface than earlier ones, even though they were recorded as the same condition. The class proposed a longer repetition using several identical fabric strips, rotating them in a planned order and keeping the original controls.

The report used *friction* to mean a force that opposes relative motion between surfaces. This definition explains the scientific idea being investigated. The comparison data, not the definition alone, provide the evidence for the class's conclusion.
