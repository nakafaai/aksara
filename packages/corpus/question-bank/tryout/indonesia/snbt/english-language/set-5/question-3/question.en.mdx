A class designed a simulated investigation of friction on model ramps. The question was whether covering the ramp with coarse fabric was associated with a change in the travel time in tenths of a second. Before collecting data, the students agreed to keep block mass, ramp angle, and release point the same in every condition.

| Condition | Mean result |
| --- | ---: |
| Baseline | 42 |
| With the change | 67 |
| Comparison | 41 |

The condition with the change differed from both other conditions. The class did not treat this pattern as proof that the same result would always occur. Its report identified an important limitation: wear on the fabric could change the surface during repeated trials.

The report used the term *friction* to mean a force that opposes relative motion between surfaces. The students proposed a longer repetition with more units and the same measurement rules. This next step would test the pattern without hiding the uncertainty in the first investigation.
