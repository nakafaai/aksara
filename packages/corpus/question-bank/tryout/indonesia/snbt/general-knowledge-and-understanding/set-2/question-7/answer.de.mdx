Die Vorsilbe *pe-* kann eine Person bezeichnen, die etwas tut, eine Person mit einer Eigenschaft oder **ein Werkzeug, mit dem man etwas tut**. Kläre zuerst, was *pemecah* in Satz (10) bedeutet.

Satz (10) nennt "einen einfachen *pemecah ombak* aus Bambus". Dieser Bambusgegenstand wird aufgestellt, um Wellen zu brechen, also bedeutet *pemecah* **ein Werkzeug zum Brechen** (einen Wellenbrecher).

| Wort | Bedeutung von *pe-* |
| --- | --- |
| *pelari* | Eine Person, die läuft |
| *pengering* | Ein Gerät zum Trocknen |
| *pemalu* | Eine Person, die schüchtern ist |
| *penduduk* | Eine Person, die an einem Ort wohnt |
| *petinju* | Eine Person, die beruflich boxt |

Nur *pengering* bezeichnet ein Gerät. Das Wort *rambut* (Haar) und *tidak menyala* (schaltet sich nicht ein) zeigen, dass ein Gegenstand gemeint ist, ein Haartrockner, keine Person.

*Pe-* in *pemecah* hat also dieselbe Bedeutung wie in *pengering*: ein Werkzeug, mit dem man etwas tut.
