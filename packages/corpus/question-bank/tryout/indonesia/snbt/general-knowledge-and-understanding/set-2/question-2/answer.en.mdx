Choose Ya (yes) or Tidak (no) for each word. *Kekhasan* comes from *khas*, meaning **belonging only to something and setting it apart from others**. Sentence (10) uses it for the tuning that differs in every gamelan set and is seen as the set's sound identity.

| Word | Can replace it? | Reason |
| --- | --- | --- |
| *ciri khas* | Yes | Same meaning: a trait that sets one set apart from others. |
| *keunikan* | Yes | Uniqueness, a quality only that thing has, which fits a sound identity. |
| *keanehan* | No | Strangeness, an odd or abnormal state, which adds a negative tone the sentence lacks. |
| *kemewahan* | No | Luxury, something costly and lavish, unrelated to tuning. |

Sentence (10) treats the tuning as a normal, valued identity, not something odd. So *keanehan* changes the meaning even though it also points to a difference.

So *ciri khas* and *keunikan* can replace *kekhasan*, while *keanehan* and *kemewahan* cannot.
