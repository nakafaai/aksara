# Given

In the **lightning** (*petir*) passage, sentence (<InlineMath math="3" />) states that lightning heats the air and produces thunder (*guruh*).

The question asks for the word pair sharing the same relationship as *petir : guruh*.

# Asked

The word pair with the same analogy relationship as *petir : guruh*.

# Solution

The pair *petir : guruh* expresses a **cause and effect** relationship in that exact order: lightning produces thunder.


> Verify that the chosen pair preserves both the cause-and-effect link and the exact order of terms.
## Testing Every Word Pair

Only a pair where the first term **directly produces** the second matches the pattern.

| Pair | Relationship | Evaluation |
| --- | --- | --- |
| *hujan : payung* | Condition and protective tool | Wrong, not cause and effect |
| *api : asap* | Cause and effect (fire produces smoke) | Correct, exact same order |
| *awan : langit* | Object and location | Wrong, spatial relation |
| *guru : sekolah* | Person and workplace | Wrong, role and location |
| *angin : topan* | Phenomenon and stronger degree | Wrong, intensity relation |

# Answer

The matching word pair is **fire : smoke** (*api : asap*).
