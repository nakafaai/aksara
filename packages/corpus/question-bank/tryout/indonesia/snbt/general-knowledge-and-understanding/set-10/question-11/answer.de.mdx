Das Dorf Rawa war tatsächlich beteiligt, doch nur eine der beschriebenen Stufen fand dort statt:

| Stufe | Angabe im Text |
| --- | --- |
| Maniokanbau | Zwei Bezirke. |
| Schneiden | Dorf Rawa. |
| Frittieren | Die Stadt. |
| Verpacken | Ein anderer Händler übernimmt diese Stufe. Der Text nennt seinen Verpackungsort nicht. |

Wer den Dorfnamen als Herkunft aller Stufen versteht, ergänzt eine Aussage, die das Label nicht belegt. Ein wahrer Ortsname kann daher irreführen, wenn er als **gesamter Weg des Produkts** verstanden wird.

Die Lösung im Text hält die Vorderseite knapp und erschließt ausführlichere Daten über einen Code. Nicht jede Stufe muss vorn aufgedruckt werden. Der Code braucht weiterhin aktualisierte Aufzeichnungen.
