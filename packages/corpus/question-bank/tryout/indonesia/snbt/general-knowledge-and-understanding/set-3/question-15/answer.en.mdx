This question asks for the statement that is **PASTI** ("certainly") true. It has to hold every time according to the text, not just possibly. Every option has the form "if ..., then ...". So for each option, ask: does the text guarantee the "then" part whenever the "if" part holds?

Start from the strongest rule in the text. Sentence (3) says one scroll holds several scenes arranged in order, and sentence (12) says the order of scenes is locked by the order of paintings on the scroll. Those two sentences give you this rule:

- If two shows unroll every scene of the same scroll, their order of scenes is certainly the same.

The option starting *Jika urutan adegan dalam dua pertunjukan berbeda* ("If the order of scenes in two shows differs") is that rule turned around, called the contrapositive. A contrapositive swaps and negates both parts: if "same scroll with every scene unrolled" always leads to "same order", then "different order" certainly means **it's not the case that both unrolled every scene of the same scroll**. A contrapositive always has the same truth value as the original rule, so this option is certainly true.

The other options are only possibly true, or even clash with the text:

- Two shows of the same length don't have to use the same scroll. The text never ties a show's length to a particular scroll. This option runs backward, from a similar effect to the same cause.
- Two storytellers (*dalang*) unrolling the same scroll can narrate at different lengths. Sentence (8) says each scene can be narrated at length or briefly, and sentence (9) says the same scroll can be performed in different lengths of time.
- Dialogue between figures isn't painted. Sentence (7) says dialogue is part of what the *dalang* narrates, and sentence (13) only limits changes to how the figures look and how the painted events go. So two *dalang* aren't guaranteed to narrate exactly the same dialogue.
- Sentence (4) says old scrolls are generally made of *daluang*, bark paper, and sentence (5) says inherited scrolls of that kind are kept as heirlooms. That doesn't make every *daluang* scroll an inherited one. This option reverses the rule, from "inherited, so *daluang*" to "*daluang*, so inherited".

So the statement that is certainly true is that if the order of scenes in two shows differs, the two shows didn't both unroll every scene of one and the same scroll.
