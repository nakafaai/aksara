State the relation in one sentence. Sentence (2) says bees are **among** the pollinators, so a bee (*lebah*) is **one kind of** pollinator (*penyerbuk*). The relation is member and category.

Test each pair with "X is one kind of Y":

- *Mawar* (rose) is one kind of *bunga* (flower). Same relation.
- *Madu* (honey) is produced by *lebah* (bees), so the relation is product and producer.
- *Petani* (farmer) works in a *kebun* (garden), so it is agent and place.
- *Serbuk sari* (pollen) moves to the *putik* (pistil), two flower parts that interact.
- *Pestisida* (pesticide) is used against *hama* (pests), a tool and its target.

So the pair with the same relation as *lebah : penyerbuk* is *mawar : bunga*.
