# Given

Sentence (<InlineMath math="8" />) of the **Komodo dragon** passage identifies deer (*rusa*) as the **prey** of Komodo dragons.

The question asks for the pair matching *komodo : rusa*.

# Asked

The word pair sharing the same relationship as *komodo : rusa*.

# Solution

The pair *komodo : rusa* represents **predator and prey** in that exact order.

> Match both the predator-and-prey relationship and the exact order placing the predator first.

## Testing All Five Pairs

Only one option keeps the **predator-to-prey pattern**.

| Pair | Relationship | Evaluation |
| --- | --- | --- |
| *ikan : air* | Animal and habitat | Wrong, location relation |
| *burung : sarang* | Animal and shelter | Wrong, dwelling relation |
| *ayam : telur* | Producer and product | Wrong, not predator and prey |
| *kucing : tikus* | Predator and prey | Correct, cat preys on mouse |
| *petani : sawah* | Worker and workplace | Wrong, occupation and location |

# Answer

The matching word pair is **cat : mouse** (*kucing : tikus*).
