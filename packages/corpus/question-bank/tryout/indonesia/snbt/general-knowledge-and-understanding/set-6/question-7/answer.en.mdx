First name the relation. Volcanic ash is **produced by** a volcano when it erupts. So the relation is **product and producer**, with the product first.

Honey is produced by bees, so *madu : lebah* (honey : bee) has the same relation in the same order.

The other pairs have different relations:

- *Roda* (wheel) is a part of a *sepeda* (bicycle).
- A *nelayan* (fisher) catches *ikan* (fish), an agent and its target.
- *Air* (water) is held in a *gelas* (glass), contents and container.
- A *dokter* (doctor) treats a *pasien* (patient), an agent and the person served.

So the pair with the same relation is *madu : lebah*.
