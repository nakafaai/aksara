# Given

In the **volcanic ash** passage, volcanic ash is produced and expelled by a volcano during an eruption.

The question asks for the word pair matching the relationship of *abu vulkanik : gunung api*.

# Asked

The word pair with the same analogy relationship as *abu vulkanik : gunung api*.

# Solution

The pair *abu vulkanik : gunung api* follows the pattern **product and its producer**, placing the produced substance first and the source second.


> Match the product-and-producer relationship while keeping the produced item in the first position.
## Testing All Five Pairs

Only one option keeps the **product-to-producer order** intact.

| Pair | Relationship | Evaluation |
| --- | --- | --- |
| *roda : sepeda* | Part and whole | Wrong, structural relation |
| *nelayan : ikan* | Agent and catch | Wrong, person and target |
| *madu : lebah* | Product and producer | Correct, honey is produced by bees |
| *air : gelas* | Contents and container | Wrong, storage relation |
| *dokter : pasien* | Professional and person treated | Wrong, service relation |

# Answer

The matching word pair is **honey : bee** (*madu : lebah*).
