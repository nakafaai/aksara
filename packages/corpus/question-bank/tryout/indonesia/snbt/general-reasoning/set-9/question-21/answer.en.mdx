# Given

**An alternating number sequence** runs **<InlineMath math="3, 20, 6, 17, 12, 14, 24, ?" />**.

# Asked

The **number replacing the question mark** in the eighth slot.

# Solution

> Whenever a sequence zigzags up and down, split the odd positions and even positions into two clean separate sequences.

The differences jump up and down with no pattern, so try **splitting the odd and even places**.

<BlockMath math="\begin{aligned}
\text{terms 1, 3, 5, 7} &: 3,\ 6,\ 12,\ 24 \quad(\times2) \\
\text{terms 2, 4, 6} &: 20,\ 17,\ 14 \quad(-3)
\end{aligned}" />

The chart below separates the two series. **The odd bars double and the even bars drop by three**, so the eighth place is <InlineMath math="11" />.

<Chart
  title={<>Two alternating series</>}
  description={<>The odd-place terms are <InlineMath math="3" />, <InlineMath math="6" />, <InlineMath math="12" />, and <InlineMath math="24" />. The even-place terms are <InlineMath math="20" />, <InlineMath math="17" />, <InlineMath math="14" />, then <InlineMath math="11" />.</>}
  bars="apart"

    { label: "Odd places, times 2", mark: "bar", values: [3, null, 6, null, 12, null, 24, null] },
    { label: "Even places, minus 3", mark: "bar", values: [null, 20, null, 17, null, 14, null, 14 - 3] },
  ]}
  valueLabel="Term value"
/>

The question mark is in the eighth place, so it belongs to the even series. Its next term is <InlineMath math="14-3=11" />.

# Answer

So the number that replaces the question mark is <InlineMath math="11" />.
