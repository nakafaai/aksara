Hitung susunan dengan tepat satu di antara A dan B pada posisi ujung, lalu keluarkan kasus ketika C dan D bersebelahan. Tersisa 240 susunan sebelum urutan C dan D ditetapkan. Tepat setengahnya menempatkan C sebelum D, sehingga ada 120 susunan valid.
