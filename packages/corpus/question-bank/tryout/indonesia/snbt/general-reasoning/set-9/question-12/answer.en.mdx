Find the difference between each pair of consecutive terms:

<BlockMath math="\begin{aligned}8-3&=5\\18-8&=10\\35-18&=17\\61-35&=26\end{aligned}" />

These differences are consecutive squares plus one:

<BlockMath math="\begin{aligned}5&=2^2+1\\10&=3^2+1\\17&=4^2+1\\26&=5^2+1\end{aligned}" />

The next square uses <InlineMath math="6" />, so the next difference is:

<BlockMath math="6^2+1=37" />

Add this difference to the last term:

<BlockMath math="61+37=98" />
