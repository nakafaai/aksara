Die Beziehung lautet **Gerät → angezeigte oder gemessene Eigenschaft**. Ein Kompass zeigt die Richtung an, ein Hygrometer die Luftfeuchtigkeit. Die Reihenfolge von Gerät und beobachteter Eigenschaft bleibt erhalten.

| Anderes Wortpaar | Warum es nicht passt |
| :--- | :--- |
| Temperatur : Thermometer | Die Messgröße steht vor dem Gerät |
| Entfernung : Kilometerzähler | Die Messgröße steht vor dem Gerät |
| Waage : Geschwindigkeit | Eine Waage misst keine Geschwindigkeit |
| Mikroskop : Schallintensität | Ein Mikroskop misst keine Schallintensität |

Daher passt **Hygrometer : Luftfeuchtigkeit**.
