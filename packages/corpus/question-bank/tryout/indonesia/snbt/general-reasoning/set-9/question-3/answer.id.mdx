# Diketahui

Teks mencatat **jumlah awal dan akhir ulat pada petak berperangkap (<InlineMath math="50" /> ke <InlineMath math="20" />) dan tanpa perangkap (<InlineMath math="50" /> ke <InlineMath math="30" />)**.

# Ditanyakan

Nilai **Benar** atau **Salah** untuk keempat pernyataan berdasarkan data teks.

# Penyelesaian

> Hitung besar penurunan dan persentase penurunan tiap kelompok dari angka awal lima puluh sebelum mengecek tiap pernyataan.

Hitung penurunan di setiap kelompok: petak berperangkap turun <InlineMath math="50-20=30" /> ekor, sedangkan petak tanpa perangkap turun <InlineMath math="50-30=20" /> ekor.

Grafik berikut menaruh penurunan kedua kelompok berdampingan. **Batang petak berperangkap <InlineMath math="1{,}5" /> kali batang petak tanpa perangkap**, bukan dua kali.

**Pernyataan 4** bernilai Salah. Teks hanya menyebut hujan turun hampir setiap hari. Hujan **mungkin** ikut berperan, tetapi teks tidak membuktikannya, karena tidak ada pembanding tanpa hujan.
