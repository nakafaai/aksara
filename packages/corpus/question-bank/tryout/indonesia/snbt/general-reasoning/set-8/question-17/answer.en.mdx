# Given

All four rules place **three non-adjacent slow songs and three fast songs** across six slots.

# Asked

The **number of distinct valid song orders**.

# Solution

> List the four legal slot patterns for the three slow songs first, count the valid arrangements inside each pattern, and add them up.

First fix **where the three slow songs go**. Three slow songs in six places with none adjacent can only take places <InlineMath math="(1,3,5)" />, <InlineMath math="(1,3,6)" />, <InlineMath math="(1,4,6)" />, or <InlineMath math="(2,4,6)" />. Remember that T is neither first nor last, and S must be followed right away by R, so S cannot be sixth.

| Slow-song places | Valid orders |
| --- | --- |
| <InlineMath math="(1,3,5)" /> | S, R, T, P, U, Q then U, P, T, Q, S, R then S, R, U, P, T, Q then U, P, S, R, T, Q |
| <InlineMath math="(1,3,6)" /> | S, R, T, P, Q, U |
| <InlineMath math="(1,4,6)" /> | S, R, P, T, Q, U |
| <InlineMath math="(2,4,6)" /> | P, T, Q, S, R, U then P, S, R, T, Q, U |

In the patterns <InlineMath math="(1,3,6)" /> and <InlineMath math="(1,4,6)" />, T must take the slow place that is neither first nor last, S must be first, and P must precede Q, so each gives only one order.
