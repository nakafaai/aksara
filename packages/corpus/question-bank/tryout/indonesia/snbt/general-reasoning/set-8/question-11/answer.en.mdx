Mark each statement Benar (true, it must follow from the rule) or Salah (false, it need not follow). "If and only if" works both ways. The lamp is on **exactly** when both conditions hold: it is dark **and** motion is detected. If either condition fails, the lamp is off.

**Statement 1** is false. Darkness alone is not enough. Without motion, the lamp stays off.

**Statement 2** is true. The lamp is on only when both conditions hold, so it must be dark.

**Statement 3** is false. Without motion, the second condition fails, so the lamp stays off even in the dark.

**Statement 4** is true. If it is still light, the first condition fails, so the lamp is certainly off.

So statements 2 and 4 are true, while statements 1 and 3 are false.
