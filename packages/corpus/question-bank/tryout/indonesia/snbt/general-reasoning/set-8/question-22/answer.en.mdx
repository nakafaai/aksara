# Given

A ball pyramid stacks **<InlineMath math="6" /> triangular layers** starting with <InlineMath math="1" />, <InlineMath math="3" />, and <InlineMath math="6" /> balls in the top three layers.

# Asked

The **total number of balls** in a six-layer pyramid.

# Solution

> List the triangular ball count for each layer from one through six first, then add all six layers together.

Layer <InlineMath math="k" /> is a triangle with <InlineMath math="k" /> balls on each side, so it holds the sum of whole numbers from <InlineMath math="1" /> to <InlineMath math="k" />. Count **each layer**, then add them up.

<BlockMath math="1,\quad 1+2=3,\quad 3+3=6,\quad 6+4=10,\quad 10+5=15,\quad 15+6=21" />

The six layers together:

<BlockMath math="1+3+6+10+15+21=56" />

The chart below draws each layer and the running total from the top. **The running total reaches <InlineMath math="56" /> at the sixth layer**.

# Answer

The value <InlineMath math="35" /> is a five-layer pyramid, and <InlineMath math="84" /> a seven-layer one. So the six-layer pyramid holds <InlineMath math="56" /> balls.
