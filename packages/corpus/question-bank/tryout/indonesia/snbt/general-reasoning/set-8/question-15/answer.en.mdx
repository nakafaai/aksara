If U is first, the second place **cannot** be a slow song (rule 1). The fast songs that could be second are P, Q, or R.

- R cannot be second, because S must come right before R, but first place is U.
- Q cannot be second, because P must come before Q.

So the second place is certainly **P**. The orders meeting every rule are U, P, S, R, T, Q and U, P, T, Q, S, R.

The other options are not certain:

- S is third only in the first of those orders.
- T is fifth also only in the first order.
- Q is last only in the first order.
- R is fourth only in the first order as well. In the second, R is last.

So what must be true is that song P is sung second.
