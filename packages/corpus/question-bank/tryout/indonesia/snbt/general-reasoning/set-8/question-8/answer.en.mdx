Match each label with its required route.

| Label | Required route |
| :--- | :--- |
| Blue | Refrigerated storage |
| Red | Manual inspection |

Parcel M has a blue label, so it must go to **refrigerated storage**. The routes are **mutually exclusive**, so M cannot also go to manual inspection.

The claim that M is sent to manual inspection because it has a blue label contradicts both rules, so it is definitely false. The other statements repeat a rule or follow directly from M's label.
