# Given

The set of all **two-digit numbers whose tens and ones digits add up to <InlineMath math="9" />** (such as <InlineMath math="27" /> and <InlineMath math="63" />).

# Asked

Whether each of the four statements about these numbers is **True** or **False**.

# Solution

> There are only nine such numbers from eighteen up to ninety, so listing all nine makes every claim easy to check.

Mark each statement Benar (true) or Salah (false). First list all the numbers. The tens digit <InlineMath math="a" /> can be <InlineMath math="1" /> to <InlineMath math="9" />, and the units digit is <InlineMath math="9-a" />:

The chart below divides each number by <InlineMath math="9" />. **Every bar stops exactly on a whole number**, from <InlineMath math="2" /> to <InlineMath math="10" />, so all nine numbers are divisible by <InlineMath math="9" />.

**Statement 1** is true. A number is divisible by <InlineMath math="9" /> when its digit sum is, and each of these numbers has a digit sum of exactly <InlineMath math="9" />.

**Statement 2** is false. There are <InlineMath math="9" /> numbers, not <InlineMath math="10" />. The tens digit cannot be <InlineMath math="0" />.

**Statement 3** is false. The digit sum of <InlineMath math="99" /> is <InlineMath math="18" />. The largest such number is <InlineMath math="90" />.

**Statement 4** is true. The original number is <InlineMath math="10a+b" /> and the new one <InlineMath math="10b+a" />, so the difference is <InlineMath math="9(b-a)" />, always a multiple of <InlineMath math="9" />. For example, the gap between <InlineMath math="72" /> and <InlineMath math="27" /> is <InlineMath math="45" /> (five times nine).

# Answer

So statements 1 and 4 are **true, while statements 2 and 3 are false**.
