Check the first and second places for song Q.

- Q **cannot** be first, because P must come before Q (rule 2).
- If Q is second, P must be first. Places 3 to 6 then hold R, S, T, and U, including all three slow songs. Three slow songs among four adjacent places must put two of them next to each other, which breaks rule 1.

So Q is **certainly** sung neither first nor second.

The other options are not certain. The order P, S, R, T, Q, U meets every rule, so S is not certainly first and T not certainly third. The order U, P, T, Q, S, R also works, so U is not certainly last and P not certainly first.

So what must be true is that song Q is sung neither first nor second.
