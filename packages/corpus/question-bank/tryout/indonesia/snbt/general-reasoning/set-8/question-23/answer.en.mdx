Let <InlineMath math="n_B" /> and <InlineMath math="n_C" /> count users of only B and only C.

Subtract both pairwise intersections from each service total. Users of all three were subtracted twice, so add them back once:

<MathContainer>
  <BlockMath math="\begin{aligned}n_B&amp;=79-32-22+11\\&amp;=36\end{aligned}" />
  <BlockMath math="\begin{aligned}n_C&amp;=66-27-22+11\\&amp;=28\end{aligned}" />
</MathContainer>

A user of only B cannot also be a user of only C. These groups are **disjoint**, so the requested total is:

<BlockMath math="36+28=64" />

Therefore, <InlineMath math="64" /> participants use only B or only C.
