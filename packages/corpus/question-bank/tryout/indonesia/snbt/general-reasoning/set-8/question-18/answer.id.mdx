Untuk setiap tim, **buang satu nilai tertinggi dan satu nilai terendah**, lalu rata-ratakan tiga nilai sisanya.

<BlockMath math="\begin{aligned}
\text{A} &: \text{buang } 92 \text{ dan } 78,\quad \frac{85+88+90}{3}=\frac{263}{3}\approx87{,}67 \\
\text{B} &: \text{buang } 95 \text{ dan } 70,\quad \frac{80+84+86}{3}=\frac{250}{3}\approx83{,}33 \\
\text{C} &: \text{buang } 91 \text{ dan } 76,\quad \frac{89+89+88}{3}=\frac{266}{3}\approx88{,}67 \\
\text{D} &: \text{buang } 99 \text{ dan } 60,\quad \frac{85+87+86}{3}=\frac{258}{3}=86
\end{aligned}" />

Urutannya C, A, D, lalu B.

Perhatikan bahwa rata-rata kelima nilai tanpa membuang apa pun memberi A dan C sama-sama <InlineMath math="86{,}6" />, dan D <InlineMath math="83{,}4" />. Aturan pembuangan nilai itulah yang memisahkan C dari A dan menaikkan D di atas B.

Jadi, peringkat pertama sampai ketiga adalah C, A, D.
