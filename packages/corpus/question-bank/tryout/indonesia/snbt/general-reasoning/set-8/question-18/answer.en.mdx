For each team, **drop the single highest and single lowest score**, then average the remaining three.

<BlockMath math="\begin{aligned}
\text{A} &: \text{drop } 92 \text{ and } 78,\quad \frac{85+88+90}{3}=\frac{263}{3}\approx87.67 \\
\text{B} &: \text{drop } 95 \text{ and } 70,\quad \frac{80+84+86}{3}=\frac{250}{3}\approx83.33 \\
\text{C} &: \text{drop } 91 \text{ and } 76,\quad \frac{89+89+88}{3}=\frac{266}{3}\approx88.67 \\
\text{D} &: \text{drop } 99 \text{ and } 60,\quad \frac{85+87+86}{3}=\frac{258}{3}=86
\end{aligned}" />

The order is C, A, D, then B.

Note that the plain average of all five scores gives A and C the same <InlineMath math="86.6" />, and D <InlineMath math="83.4" />. The dropping rule is what separates C from A and lifts D above B.

So first to third place are C, A, D.
