Combine the conditions into two chains and try each possible position. The first chain is **Indah, then Gita, then Hasan** (not necessarily consecutive). The second chain is **Fikri immediately followed by Joni**.

Fikri does not finish first, and Joni must finish right after Fikri. So Fikri can only be in position 2, 3, or 4.

- If Fikri is 2nd, Joni is 3rd. The remaining positions 1, 4, and 5 go to Indah, Gita, and Hasan in that order, so Hasan is 5th. This breaks the condition that Hasan is not last.
- If Fikri is 3rd, Joni is 4th. The remaining positions 1, 2, and 5 put Hasan 5th again, which also breaks the condition.
- If Fikri is 4th, Joni is 5th. The remaining positions 1, 2, and 3 go to Indah, Gita, and Hasan. Every condition holds.
