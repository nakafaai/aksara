Test the same rule on every row. If the first number is <InlineMath math="a" /> and the second is <InlineMath math="b" />, the matching rule can be written as

<MathContainer>
  <BlockMath math="a^2+b" />
</MathContainer>

It gives

<MathContainer>
  <BlockMath math="2^2+5=9,\qquad 3^2+4=13,\qquad 5^2+2=27" />
</MathContainer>

All three outputs match. Therefore, the rule is to **square the first number and add the second**.
