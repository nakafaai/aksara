The form **"P only if Q"** means Q is a condition that must hold for P to happen. So "P only if Q" is equivalent to "if P, then Q", not the other way around.

Translate both statements:

<BlockMath math="\begin{aligned}
\text{the meeting starts} &\Rightarrow \text{the chair is present} \\
\text{the chair is present} &\Rightarrow \text{there is no official visit}
\end{aligned}" />

The meeting started today. Applying modus ponens twice, the chair is present, and then there is no official visit today.

The other options are wrong:

- "Whenever the chair is present, the meeting surely starts" reverses the first statement. The chair being present is only a condition, not a guarantee.
- "There is an official visit, but the chair is still present" contradicts the second statement.
- The premises only describe **today**. Nothing is known about an official visit yesterday.
- "The chair is absent" contradicts the conclusion that the chair must be present.

So the conclusion that must be true is that there is no official visit today.
