Consider the following hypothetical language data:
- **o!miaw** : cat, a cat
- **mee!ow** : girl, a girl
- **o!miawwz** : many cats
- **o!miaw nmee!owi eng** : a girl is watching a cat

Applying the same sentence pattern as in the example, how do you say 'a cat is watching a girl' using this language?
