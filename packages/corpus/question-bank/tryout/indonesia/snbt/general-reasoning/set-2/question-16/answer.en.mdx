Both rules apply **at the final review**. Use the following statements for the same activity.

| Symbol | Statement |
| --- | --- |
| <InlineMath math="p" /> | The activity has been completed |
| <InlineMath math="q" /> | The report has been submitted |
| <InlineMath math="r" /> | The employee’s honorarium has been paid |

For a completed activity, the first rule guarantees a submitted report. The second then guarantees payment. This gives a **chain of implications**:

<BlockMath math="p\Rightarrow q,\qquad q\Rightarrow r\quad\Longrightarrow\quad p\Rightarrow r" />

If payment has not been made, the activity cannot already be completed under these rules: completion would guarantee payment. This is the **contrapositive**, not a reversal of the implication.

<BlockMath math="\neg r\Rightarrow\neg p" />

The fifth option states this conclusion. The premises do not say that a fee must be available before an activity can take place, and they give no rule about the manager’s honorarium.
