Look at **the differences between consecutive terms**:

<BlockMath math="7-5=2,\quad 11-7=4,\quad 19-11=8,\quad 35-19=16" />

Each difference is twice the one before: <InlineMath math="2, 4, 8, 16" />. The next difference is <InlineMath math="32" />.

<BlockMath math="35+32=67" />

The same pattern follows from the rule <InlineMath math="u_{n+1}=2u_n-3" />, for example <InlineMath math="2\times5-3=7" /> and <InlineMath math="2\times35-3=67" />. Both methods agree. So the next number is <InlineMath math="67" />.
