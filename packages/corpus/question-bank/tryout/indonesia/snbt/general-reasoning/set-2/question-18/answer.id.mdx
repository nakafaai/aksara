Gunakan simbol berikut untuk waktu memasak setiap potong daging.

| Daging | Waktu |
| :--- | :---: |
| Domba | <InlineMath math="t_1" /> |
| Sapi | <InlineMath math="t_2" /> |
| Bebek | <InlineMath math="t_3" /> |
| Kelinci | <InlineMath math="t_4" /> |
| Ayam | <InlineMath math="t_5" /> |

Sapi memerlukan waktu lebih lama daripada domba. <InlineMath math="t_2>t_1" />.

Sapi memerlukan waktu tidak lebih lama daripada bebek. <InlineMath math="t_2\leq t_3" />.

Kelinci memerlukan waktu lebih singkat daripada ayam. <InlineMath math="t_4<t_5" />.

Kelinci memerlukan waktu lebih lama daripada bebek. <InlineMath math="t_4>t_3" />.

Gabungkan hubungan tersebut:

<BlockMath math="t_1<t_2\leq t_3<t_4<t_5" />

Jadi, **domba** memiliki waktu memasak paling singkat. Walaupun waktu sapi dan bebek dapat sama, keduanya tetap lebih lama daripada domba.
