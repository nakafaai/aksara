Jede paarweise Schnittmenge enthält die <InlineMath math="10" /> Personen, die alle drei Dienste nutzen. Diese Personen werden von jeder Schnittmenge abgezogen, um genau zwei Dienste zu zählen.

| Nur diese Dienste | Anzahl der Nutzenden |
| :--- | :---: |
| <InlineMath math="A,B" /> | <InlineMath math="25-10=15" /> |
| <InlineMath math="A,C" /> | <InlineMath math="20-10=10" /> |
| <InlineMath math="B,C" /> | <InlineMath math="18-10=8" /> |

Die so bestimmten Gruppen sind disjunkt. Ihre Anzahlen werden daher addiert.

<BlockMath math="15+10+8=33" />

Somit nutzen **<InlineMath math="33" /> Personen** genau zwei Dienste.
