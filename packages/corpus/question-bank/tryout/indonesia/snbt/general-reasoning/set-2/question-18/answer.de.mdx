Wir ordnen die Garzeiten von der **kürzesten** bis zur **längsten**.

1. „Rindfleisch braucht länger zum Garen als Lammfleisch.“
   - Das bedeutet: <InlineMath math="\text{Zeit(Rind)} > \text{Zeit(Lamm)}" />.
   - Bisher gilt: <InlineMath math="\text{Lamm} < \text{Rind}" />.

2. „...aber nicht länger als Ente“ bezieht sich auf das Rindfleisch.
   - Das bedeutet: <InlineMath math="\text{Zeit(Rind)} \leq \text{Zeit(Ente)}" />.
   - Damit gilt: <InlineMath math="\text{Lamm} < \text{Rind} \leq \text{Ente}" />.

3. „Kaninchen gart schneller als Huhn.“
   - Das bedeutet: <InlineMath math="\text{Zeit(Kaninchen)} < \text{Zeit(Huhn)}" />.
   - Bisher gilt: <InlineMath math="\text{Kaninchen} < \text{Huhn}" />.

4. „...braucht aber länger als Ente“ bezieht sich auf das Kaninchen.
   - Das bedeutet: <InlineMath math="\text{Zeit(Kaninchen)} > \text{Zeit(Ente)}" />.
   - Zusammen folgt: <InlineMath math="\text{Ente} < \text{Kaninchen} < \text{Huhn}" />.

Alle Angaben zusammen ergeben:

<MathContainer>
  <BlockMath math="\text{Lamm} < \text{Rind} \leq \text{Ente} < \text{Kaninchen} < \text{Huhn}" />
</MathContainer>

Rind und Ente könnten gleich lange brauchen, beide aber länger als Lamm. Daher gart **Lamm** am schnellsten.
