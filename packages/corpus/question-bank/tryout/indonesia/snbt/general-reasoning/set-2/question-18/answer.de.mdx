Die folgenden Symbole bezeichnen die Garzeit des jeweiligen Fleischstücks.

| Fleisch | Zeit |
| :--- | :---: |
| Lamm | <InlineMath math="t_1" /> |
| Rind | <InlineMath math="t_2" /> |
| Ente | <InlineMath math="t_3" /> |
| Kaninchen | <InlineMath math="t_4" /> |
| Huhn | <InlineMath math="t_5" /> |

Rind benötigt mehr Zeit als Lamm. <InlineMath math="t_2>t_1" />.

Rind benötigt höchstens so viel Zeit wie Ente. <InlineMath math="t_2\leq t_3" />.

Kaninchen benötigt weniger Zeit als Huhn. <InlineMath math="t_4<t_5" />.

Kaninchen benötigt mehr Zeit als Ente. <InlineMath math="t_4>t_3" />.

Zusammen ergeben die Vergleiche:

<BlockMath math="t_1<t_2\leq t_3<t_4<t_5" />

Damit hat **Lamm** die kürzeste Garzeit. Rind und Ente können gleich lange brauchen, benötigen aber beide mehr Zeit als Lamm.
