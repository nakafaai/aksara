Use the following symbols for the cooking time of each piece of meat.

| Meat | Time |
| :--- | :---: |
| Lamb | <InlineMath math="t_1" /> |
| Beef | <InlineMath math="t_2" /> |
| Duck | <InlineMath math="t_3" /> |
| Rabbit | <InlineMath math="t_4" /> |
| Chicken | <InlineMath math="t_5" /> |

Beef takes longer than lamb. <InlineMath math="t_2>t_1" />.

Beef takes no longer than duck. <InlineMath math="t_2\leq t_3" />.

Rabbit takes less time than chicken. <InlineMath math="t_4<t_5" />.

Rabbit takes longer than duck. <InlineMath math="t_4>t_3" />.

Combining the comparisons gives:

<BlockMath math="t_1<t_2\leq t_3<t_4<t_5" />

Therefore, **lamb** has the shortest cooking time. Beef and duck may take the same time, but both take longer than lamb.
