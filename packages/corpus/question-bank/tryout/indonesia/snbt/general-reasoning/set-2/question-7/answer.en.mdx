Each position has a **fixed number of choices**, because repetition is allowed. Choosing one character does not reduce the choices at another position.

| Position | Allowed characters | Number of choices |
| --- | --- | --- |
| <InlineMath math="1" /> | <InlineMath math="\{2,4,6,8\}" /> | <InlineMath math="4" /> |
| <InlineMath math="2" /> | <InlineMath math="\{\mathrm{A},\mathrm{I},\mathrm{O},\mathrm{U}\}" /> | <InlineMath math="4" /> |
| <InlineMath math="3" /> | <InlineMath math="\{5,6,7\}" /> | <InlineMath math="3" /> |
| <InlineMath math="4" /> | <InlineMath math="\{\mathrm{U}\}" /> | <InlineMath math="1" /> |

The first position cannot contain <InlineMath math="0" /> because it is absent from the given set. Each first choice can combine with all four first letters, all three second digits, and the fixed last letter. Apply the **multiplication rule**:

<BlockMath math="4\times4\times3\times1=16\times3=48" />

There are therefore <InlineMath math="48" /> possible passwords.
