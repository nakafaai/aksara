All four statements test the same thing: which number goes in the denominator. Each one has a trap if you divide by the wrong number, so work through them one at a time.

The first statement is about how many seedlings survived overall. Add up the seedlings planted and the seedlings alive across all four villages.

<BlockMath math="\begin{aligned} \text{planted: } 20{,}000 + 5{,}000 + 12{,}000 + 8{,}000 &= 45{,}000 \\ \text{alive: } 2{,}000 + 3{,}500 + 6{,}000 + 1{,}600 &= 13{,}100 \\ \frac{13{,}100}{45{,}000} &\approx 29.1\% \end{aligned}" />

One third is about <InlineMath math="33.3\%" />, so the first statement is **true** (*Benar*). The trap is averaging the four villages' percentages, <InlineMath math="(10\% + 70\% + 50\% + 20\%) : 4 = 37.5\%" />. That plain average is wrong because Karangsari planted far more seedlings than the others, and it had the lowest survival rate.

The second statement involves two different densities: seedlings planted per kilometer and seedlings alive per kilometer. Work out both for each village.

| Village | Planted per km | Alive per km |
| --- | --- | --- |
| Karangsari | <InlineMath math="20{,}000 : 2 = 10{,}000" /> | <InlineMath math="2{,}000 : 2 = 1{,}000" /> |
| Muarabaru | <InlineMath math="5{,}000 : 1 = 5{,}000" /> | <InlineMath math="3{,}500 : 1 = 3{,}500" /> |
| Pasirkuning | <InlineMath math="12{,}000 : 3 = 4{,}000" /> | <InlineMath math="6{,}000 : 3 = 2{,}000" /> |
| Lontar | <InlineMath math="8{,}000 : 2 = 4{,}000" /> | <InlineMath math="1{,}600 : 2 = 800" /> |

Karangsari planted most densely, but the fewest living seedlings per kilometer are in Lontar, <InlineMath math="800" />, not in Karangsari. The second statement is false. It sounds true because Karangsari has the lowest survival rate, <InlineMath math="10\%" />, but Karangsari planted so densely that it still has more seedlings left per kilometer than Lontar.

The third statement is about Pasirkuning. Its retreat rate fell from <InlineMath math="2.5" /> to <InlineMath math="1.0" /> meters a year.

<BlockMath math="\begin{aligned} \text{decrease: } 2.5 - 1.0 &= 1.5 \\ \text{half the earlier rate: } \frac{2.5}{2} &= 1.25 \end{aligned}" />

The decrease is <InlineMath math="1.5" />, bigger than <InlineMath math="1.25" />, so the third statement is false. The trap is comparing the later rate, <InlineMath math="1.0" />, with <InlineMath math="1.25" />. That looks at what's left of the rate, but the statement asks about **the size of the decrease**.

The fourth statement is about the seedlings that died. Dead seedlings are the ones planted minus the ones alive.

<BlockMath math="\begin{aligned} \text{Karangsari: } 20{,}000 - 2{,}000 &= 18{,}000 \\ \text{Muarabaru: } 5{,}000 - 3{,}500 &= 1{,}500 \\ \text{Pasirkuning: } 12{,}000 - 6{,}000 &= 6{,}000 \\ \text{Lontar: } 8{,}000 - 1{,}600 &= 6{,}400 \\ \text{total dead} &= 31{,}900 \end{aligned}" />

Half of <InlineMath math="31{,}900" /> is <InlineMath math="15{,}950" />, and Karangsari accounts for <InlineMath math="18{,}000" />, about <InlineMath math="56\%" />. The fourth statement is true. The trap is using Karangsari's share of the seedlings planted, <InlineMath math="20{,}000 : 45{,}000 \approx 44\%" />, which is under half. The statement asks about seedlings that died, not seedlings planted.

So the first and fourth statements are true, and the second and third are false.
