Setiap irisan dua layanan mencakup <InlineMath math="10" /> pengguna ketiganya. Untuk memperoleh pengguna tepat dua layanan, kurangi kelompok tersebut dari masing-masing irisan.

| Dua layanan saja | Jumlah pengguna |
| :--- | :---: |
| <InlineMath math="A,B" /> | <InlineMath math="25-10=15" /> |
| <InlineMath math="A,C" /> | <InlineMath math="20-10=10" /> |
| <InlineMath math="B,C" /> | <InlineMath math="18-10=8" /> |

Ketiga kelompok hasil pengurangan tidak saling tumpang tindih. Jumlahkan semuanya.

<BlockMath math="15+10+8=33" />

Jadi, **<InlineMath math="33" /> peserta** menggunakan tepat dua layanan.
