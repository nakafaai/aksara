- *hujan* (rain) is in sentences one and three. The only syllable shared by *bi lo ta* and *ta ri ku* is *ta*, so *hujan* = *ta*.
- *sungai* (river) is in sentences two and three. The only syllable shared by *ku lo ne* and *ta ri ku* is *ku*, so *sungai* = *ku*.

The sentence *sungai tenang meluap* is written with **ku, wa, and ri**.

- *ne* is the code for *arus*, not *tenang*.
