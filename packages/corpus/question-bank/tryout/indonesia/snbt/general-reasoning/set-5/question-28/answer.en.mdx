# Given

Three shirt shops run distinct deals, including a **<InlineMath math="\text{Rp}150{,}000" /> minimum spend** and **<InlineMath math="1" /> free shirt for every <InlineMath math="3" /> paid**.

# Asked

Whether each price-comparison statement across the three shops is **True** or **False**.

# Solution

> Which promotion wins depends on the exact quantity bought, so compute each shop bill for the exact shirt count in each statement.

You can't compare these three offers with a single number, because **the result depends on how many T-shirts you buy**. So work out the cost at each shop for the number of T-shirts mentioned after dividing prices by <InlineMath math="1{,}000" /> rupiah.

- Shop A: each T-shirt becomes <InlineMath math="40\cdot0.8=32" />.
- Shop B: buying <InlineMath math="4" /> T-shirts or more comes to at least <InlineMath math="160" />, so it earns the cut of <InlineMath math="35" /> per transaction.
- Shop C: out of every <InlineMath math="4" /> T-shirts taken home, only <InlineMath math="3" /> are paid for.

| T-shirts | Shop A | Shop B, one transaction | Shop C |
| :---: | :---: | :---: | :---: |
| <InlineMath math="4" /> | <InlineMath math="128" /> | <InlineMath math="160-35=125" /> | <InlineMath math="3\cdot40=120" /> |
| <InlineMath math="5" /> | <InlineMath math="160" /> | <InlineMath math="200-35=165" /> | <InlineMath math="4\cdot40=160" /> |
| <InlineMath math="6" /> | <InlineMath math="192" /> | <InlineMath math="240-35=205" /> | <InlineMath math="5\cdot40=200" /> |
| <InlineMath math="8" /> | <InlineMath math="256" /> | <InlineMath math="320-35=285" /> | <InlineMath math="6\cdot40=240" /> |

The chart below draws the three cost columns. **The lines cross each other**, so the cheapest shop changes with the number of T-shirts.

The first statement is true. For <InlineMath math="4" /> T-shirts, shop C asks <InlineMath math="120" />, cheaper than <InlineMath math="125" /> and <InlineMath math="128" />.

The second statement is true. Shop B's cut applies per transaction. One transaction of <InlineMath math="8" /> T-shirts earns only one cut, giving <InlineMath math="285" />. Two transactions of <InlineMath math="4" /> T-shirts earn two cuts.

<BlockMath math="2\cdot(160-35)=250\qquad285-250=35" />

The third statement is false. For <InlineMath math="5" /> T-shirts, shop C gives one free T-shirt with the first four, then the fifth is paid in full. The cost is <InlineMath math="160" />, **the same** as shop A, not higher.

The fourth statement is false. For <InlineMath math="6" /> T-shirts, shop C still gives only one free T-shirt, so the cost is <InlineMath math="200" />. Shop A asks <InlineMath math="192" />. One free T-shirt worth <InlineMath math="40" /> loses to a discount of <InlineMath math="8" /> on six T-shirts, which is <InlineMath math="48" />.

# Answer

So the first and second statements are **true, while the third and fourth are false**.
