Eine Tabelle macht sichtbar, welche Dokumente sich aus den Prämissen ableiten lassen:

| Bürgergruppe | Hat eine Geburtsurkunde? | Hat Personalausweis (KTP)? |
| :--- | :--- | :--- |
| **WNI (Allgemein)** | **Ja** (Alle) | Abhängig vom Alter |
| **WNI <InlineMath math="> 17" /> Jahre** | **Ja** | **Ja** |
| **WNI <InlineMath math="\le 17" /> Jahre** | **Ja** | Nicht durch die Prämissen bestimmt |

**Analyse der Einwohner von Jakarta:**
1.  **Einwohner von Jakarta sind WNI:** Daher besitzen *alle* Einwohner von Jakarta eine **Geburtsurkunde**.
2.  **Alter der Einwohner von Jakarta:** Einige sind älter als **<InlineMath math="> 17\text{ Jahre}" />**. Diese Personen besitzen eine Geburtsurkunde **und** einen Personalausweis.

Dass es Einwohner Jakartas über <InlineMath math="17\text{ Jahre}" /> gibt, steht ausdrücklich in den Prämissen. Da sie WNI sind, müssen sie beide Dokumente besitzen.

Die gültige Schlussfolgerung lautet deshalb: **Einige Einwohner Jakartas besitzen eine Geburtsurkunde und einen Personalausweis (KTP).**
