Consider the following hypothetical language:

- beeppz! : cobra, a cobra.
- !meeongw : kitten.
- beeppzpz! : many cobras.
- yum ybeeppz! ong!meeongw : kitten eats cobra.

Based on the data above, how would you say 'many cobras eat a kitten' using this language?

Use the same sentence pattern: verb, object with the prefix `y-`, then subject with the prefix `ong-`.
