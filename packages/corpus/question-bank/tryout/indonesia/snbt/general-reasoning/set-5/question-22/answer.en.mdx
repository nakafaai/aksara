# Given

A total of <InlineMath math="100" /> students sit across three classes, **<InlineMath math="5" /> Class B scores were recorded <InlineMath math="6" /> points too low**, and after fixing them the overall average is <InlineMath math="67" />.

# Asked

The **average score of Class C**.

# Solution

> Convert every average into a sum of scores first, apply the Class B correction, and divide the remaining total by Class C headcount.

You can't just add averages, because the classes have different numbers of students. What you can add is the **total score**, which is the average times the number of students. So turn every average into a total, fix class B's record, then find class C's share.

The total for all students uses the average after the correction.

<BlockMath math="100\cdot67=6{,}700" />

Here are the totals for class A and class B from the first record, then the correction for class B.

<BlockMath math="\begin{aligned}
\text{Class A}&=40\cdot70=2{,}800\\
\text{Class B, first record}&=35\cdot62=2{,}170\\
\text{Correction}&=5\cdot6=30\\
\text{Class B, corrected}&=2{,}170+30=2{,}200
\end{aligned}" />

What's left is class C's total.

<BlockMath math="\begin{aligned}
\text{Class C}&=6{,}700-2{,}800-2{,}200=1{,}700\\
\text{Class C average}&=\frac{1{,}700}{25}=68
\end{aligned}" />

The chart below puts each class's total next to the overall total. **Class C fills the remaining <InlineMath math="1{,}700" />**, which divided by <InlineMath math="25" /> students gives <InlineMath math="68" />.

Check back: the total is <InlineMath math="6{,}700" /> and the average is <InlineMath math="67" />.

The other answers come from these slips.

- <InlineMath math="69.2" /> comes from forgetting the <InlineMath math="30" />-point correction, so <InlineMath math="(6{,}700-2{,}800-2{,}170):25" />.
- <InlineMath math="70.4" /> comes from subtracting the correction from class B's total.
- <InlineMath math="69" /> comes from treating the three averages as equal, <InlineMath math="3\cdot67-70-62" />, though the class sizes differ.
- <InlineMath math="60.8" /> comes from adding <InlineMath math="6" /> points to all <InlineMath math="35" /> students in class B, not just to <InlineMath math="5" /> of them.

# Answer

So class C's average is **<InlineMath math="68" />**.
