The meter rule is the implication

<BlockMath math="p \rightarrow q." />

An implication fails in exactly one case: its condition is true while its consequence is false.

| <InlineMath math="p" /> | <InlineMath math="q" /> | <InlineMath math="p\rightarrow q" /> |
| :---: | :---: | :---: |
| True | True | True |
| True | False | **False** |
| False | True | True |
| False | False | True |

The contradictory case is therefore

<BlockMath math="p\land\neg q." />

In words, **use exceeds the limit and the power is not cut**.
