The group using **at most one service** includes people using zero or one service. First count its complement: participants using at least two services. Subtract users of all three from each pairwise intersection to count those using exactly two:

| Disjoint group | Participants |
| :--- | :--- |
| <InlineMath math="A,B" /> only | <InlineMath math="28-9=19" /> |
| <InlineMath math="A,C" /> only | <InlineMath math="22-9=13" /> |
| <InlineMath math="B,C" /> only | <InlineMath math="19-9=10" /> |

Add the group using all three, exactly once.

<BlockMath math="19+13+10+9=51" />

Everyone else uses at most one service. Their count is:

<BlockMath math="160-51=109" />
