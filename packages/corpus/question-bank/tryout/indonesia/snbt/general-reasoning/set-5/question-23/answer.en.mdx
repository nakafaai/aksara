The two kinds of quota follow different rules. Night quota only works during night hours, while main quota works at any time, **including night hours** once the night quota runs out. So Dimas's night use can come from two sources.

First add up the quota from both packages.

<BlockMath math="\begin{aligned}
\text{Main quota}&=18+0=18\text{ GB}\\
\text{Night quota}&=12+15=27\text{ GB}
\end{aligned}" />

Use outside night hours can only draw on main quota. Dimas has to set aside <InlineMath math="16" /> GB for that, so the main quota still free for night hours is what's left.

<BlockMath math="18-16=2\text{ GB}" />

During night hours, Dimas uses up the night quota first, then may use that leftover main quota.

<BlockMath math="27+2=29\text{ GB}" />

The other answers come from these misreadings.

- <InlineMath math="27" /> GB comes from forgetting that leftover main quota can be used at night.
- <InlineMath math="30" /> GB comes from counting only the Besar package, <InlineMath math="18+12" />.
- <InlineMath math="33" /> GB comes from adding the Malam package's night quota to the whole main quota, <InlineMath math="15+18" />.
- <InlineMath math="45" /> GB is all the quota, <InlineMath math="18+27" />. That forgets the <InlineMath math="16" /> GB set aside for use outside night hours.

So Dimas can use at most <InlineMath math="29" /> GB during night hours.
