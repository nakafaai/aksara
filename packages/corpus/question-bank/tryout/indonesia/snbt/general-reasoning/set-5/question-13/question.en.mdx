Ziva creates a four-character password with this structure:

| First character | Second character | Third character | Fourth character |
| :---: | :---: | :---: | :---: |
| Letter | Digit | Digit | Digit |

The choices for each position are:

1. The letter is one of the letters in \`ZIVA\`.
2. The second character is a one-digit factor of <InlineMath math="9" />.
3. The third character is a one-digit odd prime.
4. The fourth character is chosen from <InlineMath math="\{2,3,4\}" />.

How many passwords satisfy these rules?
