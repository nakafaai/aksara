Die Gruppe mit **höchstens einem Dienst** umfasst Personen mit null oder einem Dienst. Zähle zuerst die Gegengruppe mit mindestens zwei Diensten. Für genau zwei Dienste werden die Nutzenden aller drei Dienste aus jeder paarweisen Schnittmenge abgezogen:

| Überschneidungsfreie Gruppe | Personenzahl |
| :--- | :--- |
| <InlineMath math="A,B" /> allein | <InlineMath math="28-9=19" /> |
| <InlineMath math="A,C" /> allein | <InlineMath math="22-9=13" /> |
| <InlineMath math="B,C" /> allein | <InlineMath math="19-9=10" /> |

Die Gruppe mit allen drei Diensten wird anschließend genau einmal addiert.

<BlockMath math="19+13+10+9=51" />

Alle übrigen Personen nutzen höchstens einen Dienst. Ihre Anzahl beträgt:

<BlockMath math="160-51=109" />
