# Given

Rani has a budget of **<InlineMath math="\text{Rp}160{,}000" />**, wants only **<InlineMath math="30" />-day plans**, and may buy repeats of the same pack.

# Asked

The **maximum main data (GB)** Rani can obtain.

# Solution

> Filter out plans that expire early or include zero main data, then test the legal combinations that stay within budget.

Rani wants as much main quota as possible on a limited budget. The Hemat package is out because it only lasts <InlineMath math="7" /> days, and the Malam package has no main quota. So the choice is between the Sedang and Besar packages.

The Besar package is cheaper per GB of main quota, about <InlineMath math="3{,}889" /> rupiah against <InlineMath math="4{,}500" /> rupiah for Sedang. But buying as many Besar packages as possible isn't automatically best, because **the money left over can go to waste**. So compare every combination that costs no more than <InlineMath math="160{,}000" /> rupiah.

| Besar packages | Sedang packages | Price (rupiah) | Main quota (GB) |
| :---: | :---: | :---: | :---: |
| <InlineMath math="2" /> | <InlineMath math="0" /> | <InlineMath math="140{,}000" /> | <InlineMath math="36" /> |
| <InlineMath math="1" /> | <InlineMath math="2" /> | <InlineMath math="160{,}000" /> | <InlineMath math="38" /> |
| <InlineMath math="1" /> | <InlineMath math="1" /> | <InlineMath math="115{,}000" /> | <InlineMath math="28" /> |
| <InlineMath math="0" /> | <InlineMath math="3" /> | <InlineMath math="135{,}000" /> | <InlineMath math="30" /> |

No other combination is possible. Three Besar packages cost <InlineMath math="210{,}000" /> rupiah. Two Besar and one Sedang cost <InlineMath math="185{,}000" /> rupiah. Four Sedang cost <InlineMath math="180{,}000" /> rupiah. All of those go over Rani's money.

With two Besar packages, <InlineMath math="20{,}000" /> rupiah is left, which isn't enough for any <InlineMath math="30" />-day package. With one Besar and two Sedang, Rani's money is used up exactly and the main quota is larger.

<BlockMath math="18+2\cdot10=38\text{ GB}" />

You'd get <InlineMath math="36" /> by going straight for the package that's cheapest per GB. You'd get <InlineMath math="40" /> by spending the leftover <InlineMath math="20{,}000" /> rupiah on one Hemat package, though it doesn't last <InlineMath math="30" /> days.

# Answer

So Rani can get at most **<InlineMath math="38" />** GB of main quota.
