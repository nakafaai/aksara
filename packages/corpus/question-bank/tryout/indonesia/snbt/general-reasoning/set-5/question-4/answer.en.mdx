# Given

The coordinator concludes that **class recordings harm student understanding** because live session attendance dropped.

# Asked

The assumption that **must be true** for that conclusion to stand.

# Solution

> Lower live attendance harms learning only if students who switch to recordings fail to gain the same understanding they would have gotten live.

An assumption that _must_ be true is different from a statement that merely helps. Here's the test: **flip the statement**, then see whether the conclusion collapses right away. If it does, the statement really is needed.

The coordinator reasons like this: there are recordings, some students skip the live session, so students' understanding suffers. That last step is never shown. The coordinator only has attendance data, not data on understanding.

The diagram below draws that line of thought. **The last arrow isn't backed by the attendance data**, so the conclusion only stands if some absent students didn't get an equal understanding from the recordings.

Test the statement about understanding from the recordings. Flipped, it says: every absent student got an equal understanding from the recording. In that case, the drop from <InlineMath math="150" /> to <InlineMath math="120" /> students per session hurts nobody, and the coordinator's conclusion collapses. So the conclusion does rest on the idea that at least some absent students didn't get an equal understanding.

Test the other four statements the same way.

- Attending live doesn't need to guarantee understanding of _all_ the material. It's enough that attending live beats the recording for some students. This statement is too strong.
- If some absent students never watched the recording, they fall even further behind. The coordinator's conclusion still stands, so this statement isn't needed.
- Why students were absent in January changes nothing about understanding in February.
- Attendance going back to <InlineMath math="150" /> students is about the decision to remove the recordings, not about the conclusion that recordings hurt understanding.

# Answer

So the assumption that must be true is that **at least some students who skipped the live sessions didn't get an equal understanding from the recordings**.
