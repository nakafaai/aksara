Eine Zusammenfassung muss den **Umfang des Wandels** und die **Ursachen des Wandels** bewahren. Der Absatz sagt, dass jede Gesellschaft sich verändert und dass Ursachen innerhalb oder außerhalb einer Gesellschaft liegen können.

| Aussage | Bezug zum Text |
| :--- | :--- |
| Nur Beziehungen zwischen Einzelpersonen | Zu eng: Gruppenbeziehungen und äußere Einflüsse fehlen. |
| Kontakt von außen als einzige Ursache | Innere Ursachen werden ausgeschlossen. |
| Jede Gesellschaft verändert sich durch innere oder äußere Ursachen | Beide Kernaussagen bleiben erhalten. |
| Alle Veränderungen ohne Bestimmung einer zentralen Veränderung untersuchen | Kehrt das beschriebene Vorgehen um. |
| Wandel nur durch eine andere Gesellschaft | Schließt erneut innere Ursachen aus. |

Damit ist Antwort C die beste Zusammenfassung. Das Wort **nur** in den anderen Antworten macht aus mehreren möglichen Ursachen eine ausschließliche Einschränkung, die im Absatz nicht steht.
