Here <InlineMath math="m" /> is the number of decided matches and <InlineMath math="s" /> the number of draws. This gives <InlineMath math="m=4" /> and <InlineMath math="s=2" />.

Each team plays <InlineMath math="3" /> matches. Break down each team's points:

- A: <InlineMath math="7=3+3+1" />, so <InlineMath math="2" /> wins and <InlineMath math="1" /> draw.
- B: <InlineMath math="5=3+1+1" />, so <InlineMath math="1" /> win and <InlineMath math="2" /> draws.
- C: <InlineMath math="3" /> points. Three draws is impossible because there are only <InlineMath math="2" /> draws, so C has <InlineMath math="1" /> win and <InlineMath math="2" /> losses.
- D: <InlineMath math="1" /> draw and <InlineMath math="2" /> losses.

B drew twice and C never drew, so B drew with A and D. That uses up both draws: A against B and B against D. A never lost, so A beat C and D. B's win was against C. C's win must be against D, since C lost to A and B. So **C beat D**.

The other options contradict this breakdown:

- A did not draw with C. A won.
- B drew with D rather than winning.
- D lost to A rather than drawing.
- A drew with B rather than losing.

So the statement that must be true is that C beat D.
