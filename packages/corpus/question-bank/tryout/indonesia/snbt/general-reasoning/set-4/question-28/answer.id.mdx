Perlakukan AB sebagai satu blok dengan urutan tetap. Dengan syarat C sebelum D, ada <InlineMath math="5!/2=60" /> susunan. Sebanyak 24 di antaranya juga menempatkan C dan D bersebelahan, sehingga tersisa 36 susunan valid.

Peluangnya adalah <InlineMath math="36/6!=36/720=\frac1{20}" />.
