The form of the rule is given, so your job is **to find the exponents** <InlineMath math="m" /> and <InlineMath math="n" />. Start with the examples that contain a <InlineMath math="1" />, because <InlineMath math="1" /> to any power is still <InlineMath math="1" />.

<BlockMath math="\begin{aligned}
3\star1=28 &\Rightarrow 3^m+1=28 \Rightarrow 3^m=27 \Rightarrow m=3 \\
1\star4=17 &\Rightarrow 1+4^n=17 \Rightarrow 4^n=16 \Rightarrow n=2
\end{aligned}" />

Check with the first example: <InlineMath math="2\star3=2^3+3^2=8+9=17" />, which fits. So the rule is <InlineMath math="a\star b=a^3+b^2" />. The exponents for the first and second number are **different**, so the order of the numbers matters.

<BlockMath math="4\star3=4^3+3^2=64+9=73" />

The other options come from wrong exponents:

- <InlineMath math="25" /> is <InlineMath math="4^2+3^2" />, as if both exponents were <InlineMath math="2" />.
- <InlineMath math="43" /> is <InlineMath math="4^2+3^3" />, the two exponents swapped.
- <InlineMath math="67" /> is <InlineMath math="4^3+3" />, the second exponent forgotten.
- <InlineMath math="91" /> is <InlineMath math="4^3+3^3" />, as if both exponents were <InlineMath math="3" />.

So <InlineMath math="4\star3" /> is <InlineMath math="73" />.
