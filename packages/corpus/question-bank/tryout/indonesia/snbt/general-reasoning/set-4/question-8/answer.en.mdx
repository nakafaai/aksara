Every value uses **the same reference mass**, <InlineMath math="100\text{ g}" />. You can therefore compare each nutrient directly.

| Nutrient | Difference calculation | Meaning |
| --- | --- | --- |
| Energy | <InlineMath math="273-201=72\text{ kcal}" /> | Fatty beef contains more energy |
| Protein | <InlineMath math="20.8-17.5=3.3\text{ g}" /> | Tempeh contains more protein |
| Fat | <InlineMath math="22.0-8.8=13.2\text{ g}" /> | Fatty beef contains more fat |

Check **both the size and direction of the difference**. The choice saying tempeh contains more protein matches the protein-row subtraction. The opposite choice reverses the comparison.

Both fat choices are also wrong: <InlineMath math="13.2\text{ g}" /> is the extra fat in beef, not tempeh, while <InlineMath math="12.2\text{ g}" /> does not match the subtraction. The correct answer is that tempeh contains <InlineMath math="3.3\text{ g}" /> more protein per <InlineMath math="100\text{ g}" />.
