Both protein values refer to the same <InlineMath math="100\text{ g}" /> basis, so they can be subtracted directly:

<MathContainer>
  <BlockMath math="20.8\text{ g}-17.5\text{ g}=3.3\text{ g}" />
</MathContainer>

Tempeh therefore contains <InlineMath math="3.3\text{ g}" /> more protein per <InlineMath math="100\text{ g}" /> than the listed fatty beef.

#### Do Not Confuse Grams with Relative Percent

The absolute difference is <InlineMath math="3.3\text{ g}" />. If the question asked for the relative increase compared with beef, the calculation would be:

<MathContainer>
  <BlockMath math="\frac{20.8-17.5}{17.5}\times100\%\approx18.9\%" />
</MathContainer>

Thus, saying "<InlineMath math="3.3\%" /> greater" would be imprecise. The supported statement is **tempeh contains <InlineMath math="3.3\text{ g}" /> more protein per <InlineMath math="100\text{ g}" />**.
