# Given

The printing machine starts at 07:00 on an order of **<InlineMath math="520" /> shirts** and must rest **<InlineMath math="1" /> hour** after each full consecutive work block.

# Asked

The **earliest finishing time** for the order.

# Solution

> Find the total active running time first, then add only the rest breaks that actually fall before the very last shirt finishes.

The finishing time depends on two things: how long the work takes and **how many times the machine really has to rest before the job is done**.

Step 1. Find the working time.

<BlockMath math="520 : 50 = 10.4 \text{ hours} = 10 \text{ hours } 24 \text{ minutes}" />

Step 2. Lay out the schedule. The machine works in <InlineMath math="3" />-hour blocks, and a rest is only needed if there's still work afterwards.

| Time | Activity | T-shirts done |
| --- | --- | --- |
| 07:00 to 10:00 | work | <InlineMath math="150" /> |
| 10:00 to 11:00 | rest | <InlineMath math="150" /> |
| 11:00 to 14:00 | work | <InlineMath math="300" /> |
| 14:00 to 15:00 | rest | <InlineMath math="300" /> |
| 15:00 to 18:00 | work | <InlineMath math="450" /> |
| 18:00 to 19:00 | rest | <InlineMath math="450" /> |
| 19:00 to 20:24 | work | <InlineMath math="520" /> |

The last <InlineMath math="70" /> T-shirts take <InlineMath math="70 : 50 = 1.4" /> hours, which is <InlineMath math="1" /> hour <InlineMath math="24" /> minutes, so the order is done at 20:24. Check: <InlineMath math="10.4" /> hours of work plus <InlineMath math="3" /> hours of rest is <InlineMath math="13" /> hours <InlineMath math="24" /> minutes after 07:00.

The chart below draws the T-shirts done through the day. **The line is flat during the three hours of rest**, and the last stretch of <InlineMath math="1" /> hour <InlineMath math="24" /> minutes brings it to <InlineMath math="520" />.

The other options come from miscounting rests or minutes.

- 17:24 ignores all the rests.
- 19:24 counts only two rests, but the third work block ends at 18:00 with the job still unfinished.
- 20:40 reads <InlineMath math="0.4" /> hours as <InlineMath math="40" /> minutes, but <InlineMath math="0.4" /> hours is <InlineMath math="24" /> minutes.
- 21:24 counts four rests by rounding <InlineMath math="10.4 : 3" /> up, but there's no rest after the last T-shirt is done.

# Answer

So the order is done at 20:24 at the earliest.
