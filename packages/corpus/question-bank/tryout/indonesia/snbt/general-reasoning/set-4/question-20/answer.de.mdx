Der Text nennt **zwei gemeinsam zu berücksichtigende Kriterien**: Lebensmittelsicherheit und eine ausgewogene Nährstoffzusammensetzung. Der Nutzen einer Zwischenmahlzeit hebt keines der beiden Kriterien auf.

| Behauptung einer Antwort | Beziehung zum Text |
| --- | --- |
| Sichere, ausgewogene Pausensnacks können Nährstoffe beitragen | Bewahrt beide Kriterien und den genannten Nutzen |
| Jeder Pausensnack ist unsicher | Macht aus sorgfältiger Auswahl eine pauschale Ablehnung |
| Snacks sollen Hauptmahlzeiten ersetzen | Fügt eine nicht genannte Empfehlung hinzu |
| Genügend Energie erlaubt das Ignorieren mikrobiologischer und chemischer Gefahren | Lässt die Sicherheitsanforderung weg |
| Energie ist das einzige Ernährungskriterium | Lässt die ausgewogene Zusammensetzung weg |

Die erste Schlussfolgerung wird somit am besten gestützt. **Können beitragen** beschreibt den Beitrag eines Snacks, ohne zu versprechen, dass eine Zwischenmahlzeit den gesamten Nährstoffbedarf eines Kindes deckt.
