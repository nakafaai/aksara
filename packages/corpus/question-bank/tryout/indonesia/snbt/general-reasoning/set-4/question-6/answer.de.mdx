Eine schwächende Aussage muss **die Stützkraft einer Prämisse verringern**, ohne die gesamte politische Schlussfolgerung widerlegen zu müssen. Die zweite Prämisse behauptet, dass **nur wenige** der leistungsstärksten Studierenden an führenden Universitäten im Ausland studieren können. Die Antwort, dass **viele** dieser Studierenden bereits dazu in der Lage sind, greift diesen Grund direkt an.

| Andere Antwort | Beziehung zum Argument |
| --- | --- |
| Die Bildungszuweisung wächst | Mit der ersten Prämisse vereinbar |
| Viele Studierende können an führenden inländischen Universitäten studieren | Betrifft einen anderen Ort als die zweite Prämisse |
| Einige Studierende können im Ausland studieren | Weiterhin mit einer kleinen Anzahl vereinbar |
| Ein Teil der Mittel bleibt unausgegeben | Wiederholt den ersten Grund und stützt das Argument |

Am unmittelbarsten schwächt daher die Aussage, dass viele der leistungsstärksten Studierenden an führenden Universitäten im Ausland studieren können. Sie stellt die Beschreibung des Bildungszugangs infrage. Daraus folgt nicht, dass Stipendien nutzlos sind.
