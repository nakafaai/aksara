The code uses a **one-to-one substitution**. A code letter always represents the same ordinary letter, and two different code letters cannot represent the same ordinary letter.

#### Decode the first two digit names

In <InlineMath math="\text{ABQBO}" />, the **second and fourth letters match**, while the other three positions differ. Among the Indonesian names of zero through nine, two have five letters: <InlineMath math="\text{EMPAT}" /> and <InlineMath math="\text{TUJUH}" />. The letters of <InlineMath math="\text{EMPAT}" /> are all different, so only <InlineMath math="\text{TUJUH}" /> fits.

<BlockMath math="\text{ABQBO}=\text{TUJUH}=7" />

Substitute this value into the given equation to find the next digit name:

<BlockMath math="\begin{aligned}7-\text{APNH}&amp;=4\\\text{APNH}&amp;=7-4=3\end{aligned}" />

Therefore, <InlineMath math="\text{APNH}=\text{TIGA}" />. These two decoded words give the mappings we need:

| Code letter | Ordinary letter |
| --- | --- |
| A | T |
| B | U |
| P | I |
| N | G |
| H | A |

#### Decode the requested expression

Using these mappings, <InlineMath math="\text{KBH}" /> becomes <InlineMath math="\text{?UA}" />. The only three-letter Indonesian digit name ending in <InlineMath math="\text{UA}" /> is <InlineMath math="\text{DUA}" />, with value <InlineMath math="2" />.

The code <InlineMath math="\text{SPTH}" /> becomes <InlineMath math="\text{?I?A}" />. Both <InlineMath math="\text{TIGA}" /> and <InlineMath math="\text{LIMA}" /> match this pattern, but check the **mappings already used**. Ordinary <InlineMath math="\mathrm{T}" /> is already represented by code <InlineMath math="\mathrm{A}" />, and ordinary <InlineMath math="\mathrm{G}" /> by code <InlineMath math="\mathrm{N}" />. Choosing <InlineMath math="\text{TIGA}" /> would make codes <InlineMath math="\mathrm{S}" /> and <InlineMath math="\mathrm{T}" /> repeat those mappings, violating the one-to-one rule. Therefore, <InlineMath math="\text{SPTH}=\text{LIMA}=5" />.

Subtract the two values in the requested order:

<BlockMath math="\text{KBH}-\text{SPTH}=2-5=-3" />
