This question asks which option must be true, given that exactly two of the five statements are false. Instead of guessing person by person, first look for **pairs of statements that are tied together**, because those pairs fix how many statements can be false.

There are two such pairs.

- Yosef says Rani's statement is false. So Yosef's statement is true exactly when Rani's is false. In the pair Rani and Yosef, exactly one statement is always false.
- Vina says Putu's statement is true. So Vina's and Putu's statements always have the same value: both true or both false.

Now count. Exactly two statements are false, and the pair Rani and Yosef already supplies one. That leaves exactly one false statement among Putu, Vina and Joko. Putu and Vina can't supply exactly one, because they're always true together or false together. So Putu and Vina are both true, and Joko's statement is the false one.

Joko's statement being false means Vina is the one who forgot. Check the others with Vina as the one who forgot. Putu is true, since the one who forgot is Rani or Vina. Rani is true as well, since it's neither Rani nor Yosef. Then Yosef's statement is false, and the two false statements belong to Yosef and Joko.

The table checks all five possibilities at once, so you can see the answer is unique. T means the statement is true and F means it's false.

| Who forgot | Putu | Rani | Vina | Yosef | Joko | False statements |
| --- | --- | --- | --- | --- | --- | --- |
| Joko | F | T | F | F | T | 3 |
| Putu | F | T | F | F | T | 3 |
| Rani | T | F | T | T | T | 1 |
| Vina | T | T | T | F | F | 2 |
| Yosef | F | F | F | T | T | 3 |

Only the Vina row has exactly two false statements.

Now check each option.

- Rani forgot and Yosef's statement is true leaves only one false statement, Rani's. This trap catches you if you blame Rani in the Rani and Yosef pair and then forget to recount.
- Putu's and Vina's statements both false already uses up the two false statements, but the Rani and Yosef pair always adds one more. That makes three.
- Vina forgot and Rani's statement is true matches the Vina row. It's the only option that must be true.
- Yosef forgot and Joko's statement is true gives three false statements. It only fits if you read the condition as "exactly two true" instead of "exactly two false".
- Vina forgot and Joko's statement is true can't happen, because Joko says precisely that it wasn't Vina.

So what must be true is that Vina forgot to return the key, and Rani's statement is true.
