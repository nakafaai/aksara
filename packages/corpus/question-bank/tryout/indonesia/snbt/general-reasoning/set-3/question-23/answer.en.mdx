The pairwise intersections total

<BlockMath math="30+25+20=75" />

A participant using exactly two services is counted once. Each participant using all three is counted three times, but should count once. Subtract **two extra copies** for each three-service user:

<BlockMath math="75-2\times12=51" />

You can also separate participants using exactly two services from those using all three:

| Group | Participants |
| --- | --- |
| Only A and B | <InlineMath math="30-12=18" /> |
| Only A and C | <InlineMath math="25-12=13" /> |
| Only B and C | <InlineMath math="20-12=8" /> |
| All three services | <InlineMath math="12" /> |

These four groups do not overlap. Their total is <InlineMath math="18+13+8+12=51" />, matching the correction for repeated counting.
