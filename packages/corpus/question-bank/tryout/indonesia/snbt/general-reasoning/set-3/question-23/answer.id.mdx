Jumlah irisan berpasangan adalah

<BlockMath math="30+25+20=75" />

Peserta yang menggunakan tepat dua layanan terhitung sekali. Setiap peserta yang menggunakan ketiga layanan terhitung tiga kali, padahal harus dihitung sekali. Jadi, kurangi **dua hitungan berlebih** untuk setiap pengguna ketiga layanan:

<BlockMath math="75-2\times12=51" />

Kamu juga dapat memisahkan kelompok yang menggunakan tepat dua layanan dan ketiga layanan:

| Kelompok | Jumlah peserta |
| --- | --- |
| Hanya A dan B | <InlineMath math="30-12=18" /> |
| Hanya A dan C | <InlineMath math="25-12=13" /> |
| Hanya B dan C | <InlineMath math="20-12=8" /> |
| Ketiga layanan | <InlineMath math="12" /> |

Keempat kelompok tidak tumpang tindih. Jumlahnya <InlineMath math="18+13+8+12=51" />, sesuai dengan hasil pengurangan hitungan berlebih.
