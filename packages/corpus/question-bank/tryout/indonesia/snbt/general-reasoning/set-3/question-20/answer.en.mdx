Compare each base word with its form in the example sentence.

#### Identify the markers

Example sentence:

**?hmmphng phipllowg cz** = "a mosquito sees a fly"

- **phipll** means "mosquito." In the sentence it becomes **phipllowg**, so **-owg** marks the subject.
- **?hmmp** means "fly." In the sentence it becomes **?hmmphng**, so **-hng** marks the object.
- **cz** means "sees."

#### Read the word order

The word order in this hypothetical language is:

**?hmmphng** (Object) + **phipllowg** (Subject) + **cz** (Verb)

The pattern is therefore **object, subject, verb (OSV)**.

#### Build the target sentence

The target sentence is "A fly sees many flies."

- Subject, "a fly": **?hmmp** + **-owg** becomes **?hmmpowg**.
- Object, "many flies": **?hhmmp** + **-hng** becomes **?hhmmphng**.
- Verb, "sees": **cz**.

Put the object first, the subject second, and the verb last:

**?hhmmphng ?hmmpowg cz**

Therefore, the third choice is correct.
