Only the **four middle digits** can vary. The first four and last four digits are fixed.

<BlockMath math="12-4-4=4" />

| Part of the number | Contents | Choices |
| --- | --- | --- |
| First four digits | <InlineMath math="0844" /> | One fixed arrangement |
| Four middle digits | Each chosen from <InlineMath math="\{2,3,4,5,7,8,9\}" /> | Seven choices at each position |
| Last four digits | <InlineMath math="1221" /> | One fixed arrangement |

Because **repetition is allowed**, choosing a digit at one position does not remove it from the choices for the next position. For example, all four positions may contain <InlineMath math="2" />. Each position therefore still has seven choices, rather than the number falling to six, five, then four.

Multiply the numbers of choices at the four positions:

<BlockMath math="7^4=7\times7\times7\times7=49\times49=2401" />

There are <InlineMath math="2401" /> different card numbers. The prefix and suffix add no choice factor because each has only one arrangement.
