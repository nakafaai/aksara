# Given

A tile pattern adds one surrounding ring per step, with **<InlineMath math="7" /> tiles in pattern <InlineMath math="2" />** and **<InlineMath math="19" /> tiles in pattern <InlineMath math="3" />**.

# Asked

The **total tile count in pattern <InlineMath math="6" />**.

# Solution

> Track how many tiles each new outer ring adds in multiples of six, then sum all the way to pattern six instead of stopping at five.

First find how many tiles **each new ring** adds, then add them up.

- The first added ring, from pattern 1 to pattern 2: <InlineMath math="7-1=6" /> tiles.
- The next ring, from pattern 2 to pattern 3: <InlineMath math="19-7=12" /> tiles.

Each new ring has <InlineMath math="6" /> more tiles than the one before, because every side of the hexagon grows by one tile. So the following rings have <InlineMath math="18" />, <InlineMath math="24" />, and <InlineMath math="30" /> tiles.

<BlockMath math="\begin{aligned}
\text{pattern 4} &= 19+18=37 \\
\text{pattern 5} &= 37+24=61 \\
\text{pattern 6} &= 61+30=91
\end{aligned}" />

# Answer

The value **<InlineMath math="61" />** is the count for pattern 5, not pattern 6. So pattern 6 has **<InlineMath math="91" />** tiles.
