Compare the words that stay the same with the words that change.

| Code | Meaning |
| --- | --- |
| “it pit sit” | “I passed SBMPTN” |
| “it nit sit” | “I passed SIMAK” |

“I” and “passed” appear in both meanings. The shared codes are “it” and “sit”. Those codes represent the two shared words, but their individual mappings remain unknown because the order may change.

The meaning changes only from **SBMPTN to SIMAK**, while the code changes only from **pit to nit**. Therefore, “nit” means SIMAK.
