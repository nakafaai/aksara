Let <InlineMath math="T(x)" /> denote the cooking time of meat <InlineMath math="x" />. Each sentence becomes one comparison:

| Statement | Mathematical Analysis |
| :--- | :--- |
| Beef cooks longer than lamb | <InlineMath math="T(\text{Beef}) > T(\text{Lamb})" /> |
| Beef cooks not longer than duck | <InlineMath math="T(\text{Beef}) \le T(\text{Duck})" /> |
| Rabbit cooks faster than chicken | <InlineMath math="T(\text{Rabbit}) < T(\text{Chicken})" /> |
| Rabbit cooks longer than duck | <InlineMath math="T(\text{Rabbit}) > T(\text{Duck})" /> |

The comparisons join into one chain from the shortest time to the longest:

<MathContainer>
  <BlockMath math="T(\text{Lamb}) < T(\text{Beef}) \le T(\text{Duck}) < T(\text{Rabbit}) < T(\text{Chicken})" />
</MathContainer>

The fastest item has the smallest cooking time. That is **lamb**.
