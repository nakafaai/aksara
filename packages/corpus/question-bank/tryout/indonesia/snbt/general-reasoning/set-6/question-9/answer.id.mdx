Kita perlu menemukan pola pergeseran huruf dari kode **LXMKWKBZ** menjadi **TESPANDA** untuk memecahkan kode **MMVFOBPT**.

Pasangan acuan menunjukkan pola pergeseran berikut:

| Dari | Ke | Geser |
| :--- | :--- | :--- |
| **L** (<InlineMath math="12" />) | **T** (<InlineMath math="20" />) | <InlineMath math="+8" /> |
| **X** (<InlineMath math="24" />) | **E** (<InlineMath math="5" />) | <InlineMath math="+7" /> |
| **M** (<InlineMath math="13" />) | **S** (<InlineMath math="19" />) | <InlineMath math="+6" /> |
| **K** (<InlineMath math="11" />) | **P** (<InlineMath math="16" />) | <InlineMath math="+5" /> |
| **W** (<InlineMath math="23" />) | **A** (<InlineMath math="1" />) | <InlineMath math="+4" /> |
| **K** (<InlineMath math="11" />) | **N** (<InlineMath math="14" />) | <InlineMath math="+3" /> |
| **B** (<InlineMath math="2" />) | **D** (<InlineMath math="4" />) | <InlineMath math="+2" /> |
| **Z** (<InlineMath math="26" />) | **A** (<InlineMath math="1" />) | <InlineMath math="+1" /> |

Alfabet ini memiliki <InlineMath math="26" /> huruf dan berulang dari A setelah Z. Jika hasil penjumlahan melebihi <InlineMath math="26" />, kurangi <InlineMath math="26" />. Karena itu, <InlineMath math="24+7=31" /> kembali ke posisi <InlineMath math="31-26=5" />, sedangkan <InlineMath math="23+4=27" /> dan <InlineMath math="26+1=27" /> kembali ke posisi <InlineMath math="27-26=1" />.

Pola yang ditemukan adalah pergeseran maju yang dimulai dari <InlineMath math="+8" /> dan berkurang <InlineMath math="1" /> setiap langkahnya: <InlineMath math="+8" /> sampai <InlineMath math="+1" />.

Sekarang kita terapkan pola ini pada kode **MMVFOBPT**:

| Dari | Ke | Geser |
| :--- | :--- | :--- |
| **M** (<InlineMath math="13" />) | **U** (<InlineMath math="21" />) | <InlineMath math="+8" /> |
| **M** (<InlineMath math="13" />) | **T** (<InlineMath math="20" />) | <InlineMath math="+7" /> |
| **V** (<InlineMath math="22" />) | **B** (<InlineMath math="2" />) | <InlineMath math="+6" /> |
| **F** (<InlineMath math="6" />) | **K** (<InlineMath math="11" />) | <InlineMath math="+5" /> |
| **O** (<InlineMath math="15" />) | **S** (<InlineMath math="19" />) | <InlineMath math="+4" /> |
| **B** (<InlineMath math="2" />) | **E** (<InlineMath math="5" />) | <InlineMath math="+3" /> |
| **P** (<InlineMath math="16" />) | **R** (<InlineMath math="18" />) | <InlineMath math="+2" /> |
| **T** (<InlineMath math="20" />) | **U** (<InlineMath math="21" />) | <InlineMath math="+1" /> |

Pada huruf V, <InlineMath math="22+6=28" /> kembali ke posisi <InlineMath math="28-26=2" />, yaitu B.

Jadi, arti kode tersebut adalah **UTBKSERU**.
