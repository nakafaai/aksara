# Given

One pen costs <InlineMath math="p" /> and one pencil costs <InlineMath math="q" />, paired with **two price-comparison statements**.

# Asked

Whether statements **(1)** and **(2)** are sufficient to answer the question.

# Solution

> Test each statement on its own first, because a clue that directly locks in the target price needs no help from the other.

Let a pen cost <InlineMath math="p" /> and a pencil <InlineMath math="q" /> rupiah. Test each statement **on its own**.

**Statement (1) alone**: sufficient. The pencil price is known, so only one number is unknown:

<BlockMath math="3p+2\times3{,}000=21{,}000\quad\Rightarrow\quad 3p=15{,}000\quad\Rightarrow\quad p=5{,}000" />

**Statement (2) alone**: not sufficient. <InlineMath math="2p-2q=4{,}000" /> gives only <InlineMath math="p-q=2{,}000" />. Both (<InlineMath math="5{,}000" />, <InlineMath math="3{,}000" />) and (<InlineMath math="6{,}000" />, <InlineMath math="4{,}000" />) fit.

The chart below draws two price pairs that both fit statement (2). **The two bars always differ by <InlineMath math="2{,}000" />**, but the pen price differs.

# Answer

So statement (1) alone is sufficient, but statement (2) alone is not.
