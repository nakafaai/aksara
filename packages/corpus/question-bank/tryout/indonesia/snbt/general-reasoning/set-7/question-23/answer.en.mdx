Let <InlineMath math="n_A" />, <InlineMath math="n_B" />, and <InlineMath math="n_C" /> count participants using only A, only B, and only C.

For A, subtract both pairwise intersections from the total using A. Users of all three have then been subtracted twice, so add them back once. Apply the same method to B and C:

<MathContainer>
  <BlockMath math="\begin{aligned}n_A&=100-38-30+14\\&=46\end{aligned}" />
  <BlockMath math="\begin{aligned}n_B&=84-38-26+14\\&=34\end{aligned}" />
  <BlockMath math="\begin{aligned}n_C&=75-30-26+14\\&=33\end{aligned}" />
</MathContainer>

These three single-service groups are disjoint. Their total is:

<BlockMath math="46+34+33=113" />

The group using all three services is also separate from the single-service groups. The requested count is therefore:

<BlockMath math="113+14=127" />
