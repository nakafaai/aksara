Join the first three statements into one chain: <InlineMath math="A>B>D>C" />. The fourth statement only says <InlineMath math="E<A" />, so **E's position** can be anywhere below A.

A is taller than B, D, C, and E as well. So building A is **certainly** the tallest.

The other options are not certain, because E can take several positions:

- If E is between A and B, E is not the shortest.
- If E is between A and B, B is third tallest, not second.
- If E is shortest, E is shorter than D.
- If E is shortest, C is not the shortest building.

So what must be true is that building A is the tallest.
