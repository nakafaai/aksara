# Given

Five buildings A through E have distinct heights with the **height chain A, B, D, C from tallest to shortest** and **<InlineMath math="E < A" />**.

# Asked

The building-height statement that is **certainly true**.

# Solution

> Because E can slip into any spot below A, the only rank locked in for sure is A standing tallest of all.

Join the first three statements into one chain: A taller than B, B taller than D, and D taller than C. The fourth statement only says <InlineMath math="E<A" />, so **E's position** can be anywhere below A.

The diagram below draws the four statements as "taller than" arrows. **Every arrow starts from A, directly or through another building**.

  title={<>Height relations among the five buildings</>}
  description={<>A is taller than B, B is taller than D, and D is taller than C. A is also taller than E, but E's place relative to B, D, and C is unknown.</>}
  chart={`flowchart TD
    A["Building A"] --> B["Building B"]
    B --> D["Building D"]
    D --> C["Building C"]
    A --> E["Building E, position not fixed"]`}
/>

A is taller than B, D, C, and E as well. So building A is **certainly** the tallest.

The other options are not certain, because E can take several positions:

- If E is between A and B, E is not the shortest.
- If E is between A and B, B is third tallest, not second.
- If E is shortest, E is shorter than D.
- If E is shortest, C is not the shortest building.

# Answer

So what must be true is that **building A is the tallest**.
