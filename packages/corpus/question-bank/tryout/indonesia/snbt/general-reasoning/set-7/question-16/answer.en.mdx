# Given

Four proposed **three-post guard assignments** must be checked against all five rules.

# Asked

Whether each assignment is **Possible** or **Impossible** under all five rules.

# Solution

> Check each lineup against all five rules one by one, because even a single violation rules it out.

Choose Mungkin (possible) or Tidak mungkin (impossible) for each assignment. Test each against all five rules. One broken rule makes an assignment **impossible**.

The chart below counts the rules each assignment breaks. **An assignment with a zero bar is possible**.

**Assignment 1**: impossible. Citra and Eko are both at the south post, which breaks rule 5.

**Assignment 2**: possible. Ayu is north and Bima south (rule 1), Citra is south (rule 2), Dani is not north so rule 3 does not apply, Bima is not in the middle (rule 4), and Eko in the north is apart from Citra (rule 5).

**Assignment 3**: possible. Bima is north and Ayu south, Citra is south, Dani is in the middle, Bima is not in the middle, and Eko in the north is apart from Citra.

**Assignment 4**: impossible. Ayu and Bima are both south, which breaks rule 1. Dani is also north while Eko is not south, which breaks rule 3 as well.

# Answer

So assignments 2 and 3 are possible, while assignments 1 and 4 are impossible.
