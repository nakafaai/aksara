# Given

An integer <InlineMath math="x" /> satisfies the **absolute-value inequality <InlineMath math="|x - 3| < 5" />**.

# Asked

Whether each of the four statements about the allowed integers <InlineMath math="x" /> is **True** or **False**.

# Solution

> Absolute value measures distance on the number line, so list every whole number sitting less than five steps away from three.

Mark each statement Benar (true) or Salah (false). The inequality <InlineMath math="|x-3|<5" /> means **the distance from <InlineMath math="x" /> to <InlineMath math="3" /> is less than <InlineMath math="5" />**:

<BlockMath math="-5<x-3<5\quad\Rightarrow\quad -2<x<8" />

The integers that fit are <InlineMath math="-1, 0, 1, 2, 3, 4, 5, 6, 7" />. The endpoints <InlineMath math="-2" /> and <InlineMath math="8" /> are excluded because the sign is "less than".

The chart below draws each integer's distance to <InlineMath math="3" />. **Only the bars below the <InlineMath math="5" /> line qualify**, from <InlineMath math="-1" /> to <InlineMath math="7" />.

**Statement 1** is false. There are <InlineMath math="9" /> integers, not <InlineMath math="10" />.

**Statement 2** is false. <InlineMath math="x=-2" /> gives <InlineMath math="|{-5}|=5" />, which is not less than <InlineMath math="5" />. The smallest value is <InlineMath math="-1" />.

**Statement 3** is true. The nine integers add up to <InlineMath math="27" />.

**Statement 4** is true. The even ones are <InlineMath math="0, 2, 4, 6" />, four of them.

# Answer

So statements 3 and 4 are true, while statements 1 and 2 are false.
