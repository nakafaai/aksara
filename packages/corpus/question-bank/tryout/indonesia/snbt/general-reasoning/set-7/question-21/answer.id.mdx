# Diketahui

**Barisan bilangan** dimulai dengan **<InlineMath math="3, 1, 2, 6, 9, 17, 32" />**.

# Ditanyakan

**Suku kedelapan** dari barisan bilangan ini.

# Penyelesaian

> Jika selisih antar suku terlihat acak, coba jumlahkan dua atau tiga suku sebelumnya untuk menemukan aturan pembentukannya.

Barisan ini turun lalu naik, dan selisih antarsukunya, yaitu <InlineMath math="-2, 1, 4, 3, 8, 15" />, tidak membentuk pola sederhana. Periksa **hubungan setiap suku dengan beberapa suku sebelumnya**. Mulai suku keempat, setiap suku sama dengan jumlah tiga suku sebelumnya:

<BlockMath math="3+1+2=6,\quad 1+2+6=9,\quad 2+6+9=17,\quad 6+9+17=32" />

Suku kedelapan:

<BlockMath math="9+17+32=58" />

Grafik berikut menggambar kedelapan suku. **Mulai suku keempat garisnya naik makin cepat**, karena setiap suku menjumlahkan tiga suku sebelumnya.

# Jawaban

Jadi, suku kedelapan barisan itu adalah **<InlineMath math="58" />**.
