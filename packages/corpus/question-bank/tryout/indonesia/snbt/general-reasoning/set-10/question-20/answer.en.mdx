The relationship is a **checking mechanism and the property checked**. A checksum is calculated from data and compared to detect changes. A digital signature is used to verify a document's origin and integrity, so digital signature and document authenticity form the matching pair.

| Other choice | Why the relationship differs |
| --- | --- |
| Compression and file size | Compression changes file size instead of checking a property. |
| Password and screen brightness | A password restricts access instead of checking brightness. |
| Backup and network speed | A backup supports data recovery instead of checking speed. |
| Encryption and print resolution | Encryption protects data confidentiality instead of checking print resolution. |

Document authenticity here concerns the document's origin. A digital signature does not prove that every statement in a document is true.
