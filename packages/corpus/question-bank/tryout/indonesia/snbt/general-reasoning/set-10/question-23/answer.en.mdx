Summing the pairwise intersections counts each user of exactly two services once, but each person using all three services three times. To count everyone using at least two once, subtract **two extra counts** for each person using all three services.

<MathContainer>
  <BlockMath math="40+33+29=102" />

  <BlockMath math="102-2\times16=70" />
</MathContainer>

Divide by the total number of participants:

<BlockMath math="\frac{70}{220}=\frac7{22}" />
