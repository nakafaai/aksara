# Given

The principal credits **higher reading scores** to the **fifteen-minute classroom reading slot**.

# Asked

What **must be true** for the principal conclusion to hold.

# Solution

> A program can only explain score gains if students actually spent those fifteen minutes reading rather than doing something else.

The program can raise scores only if it is **actually carried out**. If students chat or do other work during those fifteen minutes, the program cannot be the cause. So the conclusion depends on students really reading.

The diagram below draws the chain the principal has in mind. **The middle link, students really reading, has to be true**.

The other options need not be true:

- Students choose their own books, so the titles need not match.
- The conclusion is about the past semester, not the next one.
- Whether other schools run such a program does not matter.
- The conclusion says fifteen minutes already produced the rise.

# Answer

So what must be true is that students really read during those fifteen minutes instead of doing something else.
