# Diketahui

Tabel paket internet memuat **harga paket dan kuota utama** untuk setiap pilihan paket.

# Ditanyakan

**Nama paket** dengan harga per GB kuota utama paling murah.

# Penyelesaian

> Bagi harga tiap paket hanya dengan kuota utamanya tanpa ikut menghitung bonus malam agar perbandingannya adil.

Bagi harga setiap paket dengan **kuota utamanya saja**, dalam rupiah per GB.

<BlockMath math="\begin{aligned}
\text{Hemat} &: 55.000\div20=2.750 \\
\text{Pelajar} &: 70.000\div30\approx2.333 \\
\text{Keluarga} &: 120.000\div60=2.000 \\
\text{Super} &: 170.000\div80=2.125
\end{aligned}" />

Grafik berikut menggambar harga per GB keempat paket. **Batang Keluarga paling pendek**, sedikit di bawah Super.

Paket Super punya kuota terbesar, tetapi harga per GB-nya masih sedikit di atas Paket Keluarga.

# Jawaban

Jadi, paket dengan harga per GB kuota utama paling murah adalah Paket Keluarga.
