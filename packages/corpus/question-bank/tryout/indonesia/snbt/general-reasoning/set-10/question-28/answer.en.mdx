# Given

A **<InlineMath math="\text{Rp}150{,}000" /> book** gets **<InlineMath math="20\%" /> off first** and then an **extra <InlineMath math="10\%" /> off the discounted price**.

# Asked

Whether each statement about the final price and combined discount is **True** or **False**.

# Solution

> Successive discounts never simply add up, because the second percentage comes off an already smaller price.

Mark each statement Benar (true) or Salah (false). Work out the discounts **step by step**, since the second one is taken from the already reduced price.

<BlockMath math="\begin{aligned}
\text{after }20\% &: 150{,}000\times0.8=120{,}000 \\
10\%\text{ off} &: 10\%\times120{,}000=12{,}000 \\
\text{final price} &: 120{,}000-12{,}000=108{,}000
\end{aligned}" />

The chart below draws the price after each discount. **The second discount is less than <InlineMath math="10\%" /> of the original price**, because it's taken from <InlineMath math="120" /> thousand.

The total saving is <InlineMath math="42" /> thousand, which is <InlineMath math="28\%" />.</>}

**Statement 1** is true, as computed above.

**Statement 2** is false. The total saving is <InlineMath math="150{,}000-108{,}000=42{,}000" />, which is <InlineMath math="28\%" /> of the original price, not <InlineMath math="30\%" />.

**Statement 3** is true. Both orders multiply the price by <InlineMath math="0.8\times0.9=0.72" />, so the order does not change the result.

**Statement 4** is false. The extra discount is taken from <InlineMath math="120{,}000" />, so it is <InlineMath math="12{,}000" />, not <InlineMath math="15{,}000" />.

# Answer

So statements 1 and 3 are true, while statements 2 and 4 are false.
