Drei Aussagen verändern ein Detail, das der Text genau angibt. Prüfe jede einzeln.

| Aussage | Antwort | Beleg |
| --- | --- | --- |
| Musik aus einer einzigen Kultur | False | Absatz 2: Musik **aus vielen Kulturen**. |
| Jede Sonde trug eine Platte | True | Absatz 1: "Each carried an unusual passenger" (jede trug einen ungewöhnlichen Passagier). |
| Bilder als Fotos aufgedruckt | False | Die Bilder sind **als Tonsignale gespeichert**. |
| In wenigen Jahrhunderten nahe einem anderen Stern | False | Absatz 4: Es dauert **Zehntausende Jahre**, bis sie überhaupt in die Nähe eines Sterns kommt. |

Die dritte Aussage nimmt man leicht ungeprüft hin, weil Bilder meist als Bilder gespeichert werden.
