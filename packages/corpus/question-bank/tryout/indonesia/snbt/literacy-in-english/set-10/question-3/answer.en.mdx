The follow-up must address **both limitations**, while keeping the three cell arrangements comparable.

| Gap in the first test | Proposed follow-up |
| --- | --- |
| Only one load resistance | Compare the arrangements across several resistor values. |
| Internal resistance not measured | Estimate each cell's internal resistance. |
| Voltage alone cannot establish power across loads | Measure voltage and current together. |

The correct option connects each gap to a measurement. Repeating the original setup can improve **precision within that setup**, but does not directly test performance under other loads.
