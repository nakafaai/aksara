The author's case rests on two claims: the prompt writer **chooses only the request**, and the system decides the rest, so that **one prompt gives a hundred different pictures**. If detailed prompts can **fix the layout, colour and style** so closely that every run looks alike, then the prompt writer is making the creative choices after all. Both claims are weakened.

- Enjoying the activity says nothing about who makes the creative choices.
- Speed is not part of the author's argument.
- The number of applications does not show who the author is.
- Sharing without credit concerns use of the pictures, not their authorship.

So the finding that most weakens the argument is that detailed prompts can fix layout, colour and style so that each run looks alike.
