Bedakan **jumlah** dari **angka per pesepeda**, dan periksa peringatan dalam laporan.

Pernyataan pertama salah. Jumlah cedera adalah <InlineMath math="12 + 9 + 6 = 27" /> sebelum dan <InlineMath math="14 + 8 + 7 = 29" /> sesudah, jadi naik.

Pernyataan kedua salah: bersepeda naik sekitar <InlineMath math="25" /> persen di seluruh kota, "including on streets where no lanes were built" (termasuk di jalan yang tidak diberi jalur).

Pernyataan ketiga benar: <InlineMath math="800" /> naik menjadi <InlineMath math="1{.}600" />, <InlineMath math="500" /> menjadi <InlineMath math="900" />, dan <InlineMath math="300" /> menjadi <InlineMath math="450" />.

Pernyataan keempat memerlukan angka per <InlineMath math="1{.}000" /> pesepeda harian:

<BlockMath math="\begin{aligned} \text{Sebelum: } &\text{Main } 15, \ \text{River } 18, \ \text{Station } 20 \\ \text{Sesudah: } &\text{Main } 8{,}75, \ \text{River } \approx 8{,}9, \ \text{Station } \approx 15{,}6 \end{aligned}" />
