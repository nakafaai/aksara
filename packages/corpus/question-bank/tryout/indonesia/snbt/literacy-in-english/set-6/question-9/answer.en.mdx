# Given

Text A claims <Highlight>Entrance tests mostly measure how much coaching a family can afford</Highlight>, treating test scores largely as a proxy for wealth and school resources.

# Asked

Which finding, if true, would most weaken that claim?

# Solution

To refute the claim that scores merely reflect wealth and coaching, look for evidence that **holds school quality and family income constant** yet still finds scores predicting **academic performance**.

> Holding both school and family income constant removes differences in affordable coaching, so if test scores still predict first-year university grades, they clearly measure real academic readiness rather than just money.

## Isolating academic readiness from family wealth

Comparing applicants **from the same school** and **with similar family incomes** neutralises differences in school funding and paid coaching. If test scores still predict first-year grades inside that matched group, Text A's claim that scores mostly measure coaching money is **directly weakened**.

## Why the other options fail

- **Score submitters attended better-funded schools** strengthens Text A by linking scores to financial advantage.
- **Free coaching raised scores** also strengthens Text A by confirming coaching moves test scores.
- **No-score admits earned lower grades** supports Text B's standard argument without testing whether scores reflect wealth or ability.
- **Coaching improves essays too** challenges dropping tests overall, not Text A's claim about what tests measure.

# Answer

**Among applicants from the same school and with similar family incomes, test scores still predicted first-year grades**.
