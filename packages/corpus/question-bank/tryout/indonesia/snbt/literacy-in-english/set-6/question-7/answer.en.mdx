# Given

Five statements about the university's test-optional policy must be checked on whether **both** Text A and Text B would accept them.

# Asked

Which statements would both writers accept based on their texts? Choose Yes or No for each.

# Solution

Mark **Yes** only where **shared agreement** exists across both writers, noticing that Text A's phrase "almost as high" implicitly concedes the same small grade gap Text B quantifies.

> Both writers welcome the rise in low-income admissions and acknowledge slightly lower first-year grades for non-submitters, while disagreeing over what tests measure and whether standards slipped.

## Checking the five statements across both texts

| Statement | Verdict | Evidence from Text A and Text B |
| --- | --- | --- |
| <InlineMath math="1" />. The rise in low-income admits is a good result | **Yes** | Text A praises widening the door, and Text B states <Highlight>the rise in low-income admissions is welcome</Highlight>. |
| <InlineMath math="2" />. Entrance tests mainly measure affordable coaching | **No** | Claimed only by Text A, whereas Text B argues contextualised scores help spot strong students from weak schools. |
| <InlineMath math="3" />. No-score admits earned somewhat lower first-year grades | **Yes** | Text A concedes grades were <Highlight>almost as high</Highlight> (meaning slightly lower), and Text B reports <InlineMath math="2.9" /> versus <InlineMath math="3.1" />. |
| <InlineMath math="4" />. The university should reinstate required scores | **No** | Neither writer wants a mandate: Text B explicitly says <Highlight>I would keep tests optional for now</Highlight>. |
| <InlineMath math="5" />. Dropping tests has not lowered the standard | **No** | Claimed by Text A, directly challenged by Text B's grade-gap argument. |

# Answer

Statements **<InlineMath math="1" /> and <InlineMath math="3" />** are **Yes**, while statements **<InlineMath math="2" />, <InlineMath math="4" />, and <InlineMath math="5" />** are **No**.
