Jede Option behauptet etwas darüber, **was ein Text tut**. Bei einer musst du eine Zahl aus Text B auf eine Formulierung in Text A anwenden.

- **Teilt das Ziel, bestreitet die Noten**. "I share the goal" (ich teile das Ziel), dann verbirgt "almost as high" (fast so hoch) eine Lücke. Zutreffend.
- **Tests jetzt wieder verlangen**. Text B sagt "I would keep tests optional for now" (ich würde die Tests vorerst freiwillig lassen). Nicht zutreffend.
- **Eine Lücke von <InlineMath math="0{,}2" />**. Text A sagt "almost as high". Text B nennt die Zahlen dahinter: <InlineMath math="3{,}1-2{,}9=0{,}2" />. Zutreffend.

- **Beide nutzen den Anstieg der Bewerbungen**. Den erwähnt nur Text A. Nicht zutreffend.
