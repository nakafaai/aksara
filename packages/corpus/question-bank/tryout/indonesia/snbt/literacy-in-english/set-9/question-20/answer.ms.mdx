# Diberi

Perenggan <InlineMath math="4" /> membentangkan **peta Peters** (keluasan tepat, bentuk terpicit, didahului James Gall pada <InlineMath math="1855" />), manakala perenggan <InlineMath math="5" /> menggariskan prinsip bahawa **tiada peta rata yang mampu mengekalkan semua bentuk dan keluasan serentak**.

# Ditanya

Apabila dibaca bersama perenggan akhir, bagaimanakah penulis menilai peta Peters?

# Penyelesaian

> No flat map can keep every shape and every area true at once, so the useful question is which property a task needs.

Letakkan perenggan <InlineMath math="4" /> dalam **kerangka keperluan tugasan** di perenggan <InlineMath math="5" />: setiap unjuran peta menuntut pertukaran sifat.

## Menilai peta Peters sebagai satu pertukaran sifat

Sebagaimana Mercator mengekalkan sudut dengan mengorbankan keluasan, peta Peters <Highlight>kept the areas of countries in proportion, but it squeezed their shapes</Highlight>. Berpandukan soalan penutup tentang <Highlight>which property a task needs</Highlight>, penulis melihatnya sebagai **satu lagi pertukaran sifat**: sesuai bagi perbandingan keluasan tetapi bukan peta terbaik untuk setiap tugasan.

Pilihan lain tersilap membaca pendirian penulis. Unjuran James Gall pada <InlineMath math="1855" /> membuktikan Peters bukan perintisnya. Penulis sekadar melaporkan dakwaan keadilan Peters tanpa menerimanya, tidak menterbalikkan pertukaran bentuk dan keluasan, serta tidak menolak peta sama luas secara mutlak.

# Jawapan

Penulis menganggap peta Peters **sebagai satu lagi pertukaran sifat yang mengekalkan keluasan tepat dengan melepaskan bentuk, sesuai bagi sesetengah tugasan tetapi bukan peta tepat untuk setiap kerja**.

(*As one more trade-off, keeping areas true by giving up shapes, which suits some tasks but is not the right map for every job.*)
