Paragraph 3 names the problem: each symbol "needed up to twelve dots, too many to feel with a single touch of the fingertip". A reader would have to **move a finger around each symbol**, which made reading slow. Braille's six-dot cell solved exactly this.

- Barbier designed it for writing in the dark, but the passage does not say only soldiers could use it.
- Large raised letters describe the school's existing books, not Barbier's system.
- Barbier's system represented sounds rather than spelling, the reverse of this option.
- Cost is mentioned for the raised-letter books, not for Barbier's system.

So the main drawback of Barbier's system was that its symbols used too many dots to be felt with one touch.
