Bandingkan kedua kolom baris demi baris, dan **jumlahkan baris siang hari** untuk pernyataan ketiga.

Pernyataan pertama benar: 120 kurang dari 140, 150 kurang dari 160, dan 190 kurang dari 210.

Pernyataan kedua benar: 130 pengunjung malam dibanding 120 pengunjung pagi.

Pernyataan ketiga memerlukan jumlah kunjungan siang hari:

<BlockMath math="140 + 160 + 210 = 510 \qquad 120 + 150 + 190 = 460 \qquad 510 - 460 = 50" />

Kunjungan siang turun 50 orang, bukan lebih dari 100, jadi pernyataan ini salah.

Pernyataan keempat salah karena kuesioner hanya dibagikan kepada **pengunjung malam**.

| Pernyataan | Jawaban |
| --- | --- |
| Setiap jam siang turun | True |
| Jam malam mengungguli jam pagi | True |
| Kunjungan siang turun lebih dari 100 | False |
| Semua pengunjung menerima kuesioner | False |
