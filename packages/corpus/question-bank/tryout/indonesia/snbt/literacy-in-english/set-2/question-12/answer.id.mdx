Bandingkan kedua kolom baris demi baris, dan **jumlahkan baris siang hari** untuk pernyataan ketiga.

Pernyataan pertama benar: <InlineMath math="120" /> kurang dari <InlineMath math="140" />, <InlineMath math="150" /> kurang dari <InlineMath math="160" />, dan <InlineMath math="190" /> kurang dari <InlineMath math="210" />.

Pernyataan kedua benar: <InlineMath math="130" /> pengunjung malam dibanding <InlineMath math="120" /> pengunjung pagi.

Pernyataan ketiga memerlukan jumlah kunjungan siang hari:

<BlockMath math="140 + 160 + 210 = 510 \qquad 120 + 150 + 190 = 460 \qquad 510 - 460 = 50" />

Kunjungan siang turun <InlineMath math="50" /> orang, bukan lebih dari <InlineMath math="100" />, jadi pernyataan ini salah.

Pernyataan keempat salah karena kuesioner hanya dibagikan kepada **pengunjung malam**.

| Pernyataan | Jawaban |
| --- | --- |
| Setiap jam siang turun | True |
| Jam malam mengungguli jam pagi | True |
| Kunjungan siang turun lebih dari <InlineMath math="100" /> | False |
| Semua pengunjung menerima kuesioner | False |
