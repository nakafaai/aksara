# Diketahui

# Ditanyakan

Apakah masing-masing dari lima pernyataan dapat disimpulkan dari teks (**Yes** atau **No**)?

# Penyelesaian

> When the researchers measured how alert and cheerful the students felt, the differences in mood accounted for the differences in scores.

Setiap pernyataan menguji kalimat tertentu di dalam teks atau menerapkan **penjelasan suasana hati** pada situasi baru.
