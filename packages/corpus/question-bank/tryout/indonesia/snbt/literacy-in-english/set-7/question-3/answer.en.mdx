A memory stores information about the past. The slime trail marks **where the organism has already been**, and the slime mould tends to avoid it, so it does not search the same empty area twice. Because this information is kept **in the environment rather than inside the organism**, researchers call it an external memory.

- The trail is outside the body, not in its nuclei.
- The Tokyo experiment involved oat flakes, not a trail that remembers a city.
- The passage says the slime mould has no nerves.
- Nothing suggests it remembers food from years ago.

So the trail is called an external memory because it records where the slime mould has been, outside its own body.
