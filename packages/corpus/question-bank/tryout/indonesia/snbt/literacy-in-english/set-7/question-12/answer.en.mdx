# Given

The table compares Eastvale (<InlineMath math="60" /> injuries, <InlineMath math="10" /> million km, <InlineMath math="200{,}000" /> residents) and Riverton (<InlineMath math="120" /> injuries, <InlineMath math="40" /> million km, <InlineMath math="300{,}000" /> residents) across **three distinct metrics**.

# Asked

Which of the five statements are supported by the passage and the table (**Yes** or **No**)?

# Solution

> Riverton has spent ten years building bike lanes separated from traffic, while Eastvale has very few.

Compute all three **comparison rates** first because the five statements switch denominators between distance, raw totals, and population.

## Computing the three metrics

Divide injuries by distance, injuries by resident groups, and total distance by residents to get each **city rate**:

<BlockMath math="\begin{aligned} \text{Per million km:} &\quad \text{Eastvale } \frac{60}{10} = 6, \quad \text{Riverton } \frac{120}{40} = 3 \\ \text{Per } 10{,}000 \text{ residents:} &\quad \text{Eastvale } \frac{60}{20} = 3, \quad \text{Riverton } \frac{120}{30} = 4 \\ \text{Km per resident:} &\quad \text{Eastvale } \frac{10{,}000{,}000}{200{,}000} = 50, \quad \text{Riverton } \frac{40{,}000{,}000}{300{,}000} \approx 133 \end{aligned}" />

| Statement | Comparison check | Supported |
| --- | --- | --- |
| <InlineMath math="1" /> | <InlineMath math="6" /> vs <InlineMath math="3" /> injuries per million km (twice as often) | **Yes** |
| <InlineMath math="2" /> | Riverton had <InlineMath math="120" /> vs Eastvale's <InlineMath math="60" /> total injuries | **No** |
| <InlineMath math="3" /> | <InlineMath math="3" /> vs <InlineMath math="4" /> per <InlineMath math="10{,}000" /> residents (Eastvale lower) | **Yes** |
| <InlineMath math="4" /> | Table gives rates, not causal proof for bike lanes | **No** |
| <InlineMath math="5" /> | Riverton averaged about <InlineMath math="133" /> km vs Eastvale's <InlineMath math="50" /> km | **No** |

Watch Statement <InlineMath math="4" /> closely: although the passage notes Riverton built <Highlight>bike lanes separated from traffic</Highlight>, the table shows an association, not a causal test.

# Answer

- Statement <InlineMath math="1" />: **Yes**
- Statement <InlineMath math="2" />: **No**
- Statement <InlineMath math="3" />: **Yes**
- Statement <InlineMath math="4" />: **No**
- Statement <InlineMath math="5" />: **No**
