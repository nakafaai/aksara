- Riding mostly on separated lanes would explain why Riverton is safer. It supports the conclusion.
- More residents is about totals, but the rate is per kilometre, so the number of residents doesn't change it.
- The four-times distance is already inside the rate, <InlineMath math="120\div40" />, so it can't weaken it.
- How many bicycles residents own says nothing about the injuries per kilometre ridden.
