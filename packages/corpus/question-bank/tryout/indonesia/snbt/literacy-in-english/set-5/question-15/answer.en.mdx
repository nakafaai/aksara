# Given

**The provincial measles table** reports population, coverage, and cases across four districts alongside the <InlineMath math="95\%" /> target.

# Asked

Which statements about district coverage, target shortfalls, and outbreak origin follow from the data.

# Solution

**Three statements need arithmetic**, one needs a careful read of "at least", and one asks for something the table can't show.

> A scoreboard showing how many goals each team scored tells you the totals, not who scored the very first goal of the match.

## Checking arithmetic threshold wording and table limits

Statement <InlineMath math="1" />. The aim is about <InlineMath math="95\%" /> and Northgate reached <InlineMath math="80\%" />: <InlineMath math="95 - 80 = 15" /> percentage points. Yes.

Statement <InlineMath math="2" />. Eastport's coverage is <InlineMath math="95\%" />, and "at least <InlineMath math="95\%" />" includes <InlineMath math="95\%" /> itself. Only Northgate fell short. No.

Statement <InlineMath math="3" />. The table counts cases by district. It says nothing about **when or where** the outbreak started, so the order of events can't be read from it. No.

Statement <InlineMath math="4" />. Northgate has <InlineMath math="10{,}000" /> children, and going from <InlineMath math="80\%" /> to <InlineMath math="95\%" /> adds <InlineMath math="15\%" /> of them:

<BlockMath math="15\% \times 10{,}000 = 1{,}500" />

Yes.

Statement <InlineMath math="5" />. Count the vaccinated children across all four districts first.

<BlockMath math="48{,}000 + 19{,}000 + 8{,}000 + 19{,}000 = 94{,}000" />

That gives <InlineMath math="94{,}000" /> of <InlineMath math="100{,}000" /> children, which is the <InlineMath math="94\%" /> figure. Adding Northgate's <InlineMath math="1{,}500" /> raises the provincial rate to <InlineMath math="95.5\%" />.

<BlockMath math="\dfrac{95{,}500}{100{,}000} = 95.5\%" />

Yes.

# Answer

Checking exact differences, inclusive wording for **at least**, and what the table omits resolves all five statements.

| Statement | Answer |
| --- | --- |
| Northgate was <InlineMath math="15" /> points below the aim | Yes |
| Northgate and Eastport both fell short | No |
| The outbreak began in Northgate | No |
| About <InlineMath math="1{,}500" /> more children to reach <InlineMath math="95\%" /> | Yes |
| The provincial figure would rise to about <InlineMath math="95.5\%" /> | Yes |
