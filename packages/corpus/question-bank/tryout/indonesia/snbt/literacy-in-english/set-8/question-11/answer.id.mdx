Satu terjemahan terdengar hangat di rumah, tetapi terlalu santai untuk papan pengumuman. Jonas tidak menyembunyikan ketegangan itu dengan memilih satu versi. Ia **mempertahankan keduanya** dan menjelaskan **konteks masing-masing**, sehingga penyelenggara dapat memilih versi formal untuk papan dan versi lain untuk sapaan lisan.
