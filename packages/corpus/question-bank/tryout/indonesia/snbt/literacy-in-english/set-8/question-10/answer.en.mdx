# Given

Five statements summarise how **Text A and Text B** relate to each other regarding the <InlineMath math="18\%" /> figure, support for the charge, exempt ride-hailing cars, centre speeds, and bus speeds.

# Asked

Which statements about the two texts are accurate?

# Solution

> Most of it comes from ride-hailing cars, which were almost unknown in the city before the charge and which the city chose to exempt from it.

Verify each statement by reading **both passages side by side** and checking tense and scope carefully.

## Verifying all five statements

| Statement | Verification from Text A and Text B | Accurate |
| --- | --- | --- |
| Text B accepts all-cars figure, disputes private-car reading | Accepts <InlineMath math="18\%" />, says private cars fell <Highlight><InlineMath math="45\%" />, not <InlineMath math="18\%" /></Highlight> | **Yes** |
| Text B argues the charge should be scrapped | Contradicted by <Highlight>I support the charge</Highlight> | **No** |
| Text A's <InlineMath math="18\%" /> includes exempt ride-hailing cars | Text A counts all cars and Text B notes ride-hailing cars are exempt | **Yes** |
| Text B links slower speeds to empty driving | <Highlight>driving empty between passengers, so average speeds</Highlight> fell | **Yes** |
| Text A says buses are still running faster now | Text A only says <Highlight>In the first year</Highlight> buses ran faster | **No** |

Watch the subtle **time-scope error** in the last option: Text A reports faster buses only in the first year, and says nothing about bus speeds today.

# Answer

**The accurate statements are**:

- Text B accepts Text A's figure for all cars but disputes what it shows about private cars.
- Text A's <InlineMath math="18\%" /> includes ride-hailing cars, which pay no charge.
- Text B links the fall in average speeds to ride-hailing cars driving empty between passengers.
