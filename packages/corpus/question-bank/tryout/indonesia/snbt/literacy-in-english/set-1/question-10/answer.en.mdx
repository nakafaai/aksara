# Given

Text <InlineMath math="2" /> **lists four specific doubts** about Westbrook's pilot: young age group, one-term length, comparing with last year's cohort, and low-stakes tests.

# Asked

Which single redesign of the pilot resolves the highest number of doubts raised by Text <InlineMath math="2" />.

# Solution

First list the doubts. Text <InlineMath math="2" /> raises **four** problems with the pilot:

> To test a recipe fairly, cook for the right crowd, compare side by side on the same day, and judge with a real tasting.

## Counting how many doubts each redesign fixes

1. It "involved only Years <InlineMath math="3" /> to <InlineMath math="6" />", the group where little effect was expected.
2. It "lasted a single term".
3. It compared the pupils with "a different group of children", last year's.
4. The tests "count for nothing".

Now count how many each change fixes.

| Change | Doubts it fixes |
| --- | --- |
| Full year, Years 3 to 6, parent surveys | <InlineMath math="2" /> only |
| Older pupils, same-year comparison group, tests that count | <InlineMath math="1" />, <InlineMath math="3" /> and <InlineMath math="4" /> |
| Second term, average of last three years | <InlineMath math="2" /> only (still other children) |
| Older pupils for one term, effort ratings | <InlineMath math="1" /> only |
| Last year's groups, tests that count | <InlineMath math="4" /> only (still other children) |

The second change fixes three of the four doubts, more than any other. Comparing with **similar pupils in the same year** removes the different-group problem, and tests that count remove the no-stakes problem.

- A full year fixes the length, but monthly surveys about bedtimes don't touch any doubt Text <InlineMath math="2" /> raises.
- Averaging three earlier years still compares the pilot with **different children**.
- Effort ratings by teachers aren't something Text <InlineMath math="2" /> asks for, and one term keeps the short-pilot problem.
- Tests that count fix one doubt, but last year's groups are still a different set of children.

# Answer

Including older pupils, comparing with similar same-year peers who keep homework, and using tests that count fixes **three of the four doubts**.

The change that answers the most of Text 2's doubts is to include older pupils and compare them with similar pupils in the same year who keep homework, on tests that count.
