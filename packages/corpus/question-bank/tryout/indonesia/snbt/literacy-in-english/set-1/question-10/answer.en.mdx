First list the doubts. Text 2 raises **four** problems with the pilot:

1. It "involved only Years 3 to 6", the group where little effect was expected.
2. It "lasted a single term".
3. It compared the pupils with "a different group of children", last year's.
4. The tests "count for nothing".

Now count how many each change fixes.

| Change | Doubts it fixes |
| --- | --- |
| Full year, Years 3 to 6, parent surveys | 2 only |
| Older pupils, same-year comparison group, tests that count | 1, 3 and 4 |
| Second term, average of last three years | 2 only (still other children) |
| Older pupils for one term, effort ratings | 1 only |
| Last year's groups, tests that count | 4 only (still other children) |

The second change fixes three of the four doubts, more than any other. Comparing with **similar pupils in the same year** removes the different-group problem, and tests that count remove the no-stakes problem.

- A full year fixes the length, but monthly surveys about bedtimes don't touch any doubt Text 2 raises.
- Averaging three earlier years still compares the pilot with **different children**.
- Effort ratings by teachers aren't something Text 2 asks for, and one term keeps the short-pilot problem.
- Tests that count fix one doubt, but last year's groups are still a different set of children.

The change that answers the most of Text 2's doubts is to include older pupils and compare them with similar pupils in the same year who keep homework, on tests that count.
