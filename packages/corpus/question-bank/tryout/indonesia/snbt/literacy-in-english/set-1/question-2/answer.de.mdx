Kläre zuerst, was das Bild bedeutet. Absatz 4 erklärt es sofort: Jeder Rezeptor "reports only that light in its own band has arrived" (meldet nur, dass Licht in seinem eigenen Bereich angekommen ist), und das Tier erkennt eine Farbe "from which wire has been tripped, without weighing one signal against another" (daran, welcher Draht ausgelöst hat, ohne ein Signal gegen ein anderes abzuwägen). Ein Draht gibt also **eine Ja-oder-Nein-Meldung**, und die Farbe ergibt sich daraus, **welche Drähte ausgelöst haben**. Prüf jede Aussage daran.

Aussage 1. Wenn die Farbe nur davon abhängt, welche Drähte auslösen, geben zwei Lichter, die genau dieselben Drähte auslösen, dem Krebs dieselbe Meldung. Die beiden Lichter sähen gleich aus. Yes.

Aussage 2. Ein Draht meldet nur, dass Licht "has arrived" (angekommen ist). Wie viel Licht kam, sagt er nicht. Helles und schwaches Licht im selben Bereich lösen also denselben Draht aus und geben dieselbe Meldung. Die Aussage widerspricht dem Bild. No.

Aussage 3. Zwei Farben im Bereich eines einzigen Rezeptors lösen denselben Draht aus, also kann der Krebs sie nicht unterscheiden. Das passt zu den schwachen Ergebnissen in Absatz 3. Yes.

Aussage 4. Ein Stolperdraht wird wörtlich durch etwas ausgelöst, das vorbeikommt. Der Text nutzt das Bild aber für Licht in einem Wellenlängenbereich. Das Abtasten ist ein eigener Punkt darüber, wo die Rezeptoren sitzen. No.

Aussage 5. Absatz 4 sagt, so ein System "would give up fine distinctions in exchange for speed" (würde feine Unterscheidungen gegen Tempo eintauschen), und aufgegeben wird dabei das Vergleichen. Yes.

| Aussage | Antwort |
| --- | --- |
| Lichter, die dieselben Rezeptoren auslösen, sehen gleich aus | Yes |
| Helles und schwaches Licht in einem Bereich sehen verschieden aus | No |
| Passt zum Scheitern innerhalb des Bereichs eines Rezeptors | Yes |
| Jeder Rezeptor reagiert auf Bewegung | No |
| Das Tempo kommt teils daher, dass nichts verglichen wird | Yes |
