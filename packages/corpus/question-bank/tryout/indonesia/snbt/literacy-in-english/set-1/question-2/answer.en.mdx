# Given

Paragraph <InlineMath math="4" /> compares the mantis shrimp's colour receptors to **a row of tripwires** that only signal whether light in each band arrived.

# Asked

Whether each statement follows from the tripwire comparison and the passage.

# Solution

First pin down what the image means. Paragraph <InlineMath math="4" /> explains it right away: each receptor "reports only that light in its own band has arrived", and the animal recognises a colour "from which wire has been tripped, without weighing one signal against another". So a wire gives **a yes-or-no report**, and the colour is read from **which wires fired**. Now test each statement against that.

> Think of a tripwire like a simple light switch that only clicks on or off without measuring how strong the push was.

## Testing each statement against the tripwire picture

Statement <InlineMath math="1" />. If the colour comes only from **which wires fired**, two lights that trip exactly the same wires give the shrimp the same report. They would look alike. Yes.

Statement <InlineMath math="2" />. A wire reports only that light "has arrived". It says nothing about how much light came, so a brighter and a dimmer light in the same band trip the same wire and give the same report. The statement goes against the image. No.

Statement <InlineMath math="3" />. Two colours inside one receptor's band trip the same wire, so the shrimp has no way to tell them apart. That fits the poor scores in paragraph <InlineMath math="3" />. Yes.

Statement <InlineMath math="4" />. A tripwire is literally set off by something passing, but the passage uses the image for light in a band of wavelengths. Scanning is a separate point about where the receptors sit. No.

Statement <InlineMath math="5" />. Paragraph <InlineMath math="4" /> says a system like this "would give up fine distinctions in exchange for speed", and what it gives up is the comparing. Yes.

# Answer

Only the three statements matching a fast **yes-or-no detector** hold.

| Statement | Answer |
| --- | --- |
| Lights that trip the same receptors look alike | Yes |
| Brighter and dimmer light in one band look different | No |
| Fits the failure inside one receptor's band | Yes |
| Each receptor reacts to movement | No |
| Speed comes partly from not comparing | Yes |
