# Given

Text <InlineMath math="1" /> jumps from **Westbrook's one-term primary pilot** to claiming every school should drop homework at every age.

# Asked

Which hidden assumptions Text <InlineMath math="1" /> depends on to make that leap.

# Solution

An assumption is a missing link the argument needs. A quick test: **deny it**. If the argument falls apart once the assumption is false, the step depends on it.

> If flipping a bridge plank upside down makes the argument fall into the river, then that plank is a hidden assumption the argument needs.

## Testing each assumption by denying it

**Text <InlineMath math="1" />'s chain**: the pilot pupils had no homework for "a single term", their scores were "no lower than those of the same year groups the year before", so removing homework "costs nothing", so schools should drop it "at every age".

Statement <InlineMath math="1" />. Deny it: older pupils lose more than the pilot pupils did. Then the pilot can't support "every age". Yes.

Statement <InlineMath math="2" />. Parents finishing worksheets is only a picture of stressful evenings. Deny it, and the chain from the scores to the conclusion still stands. No.

Statement <InlineMath math="3" />. Deny it: one term is too short for a cost to show. Then "no lower" after one term doesn't mean "costs nothing". Yes.

Statement <InlineMath math="4" />. Text <InlineMath math="1" /> wants homework gone whatever the current amount, so the step doesn't need this. No.

Statement <InlineMath math="5" />. Deny it: last year's groups differ in some way that matters. Then "no lower than last year" stops showing that nothing was lost. Yes.

# Answer

The leap depends on matching the pilot cohort fairly, keeping results over time, and carrying primary findings over to older pupils.

| Statement | Answer |
| --- | --- |
| Older pupils would lose no more than the pilot pupils | Yes |
| Parent-finished worksheets mean less learning | No |
| One term is long enough to show a cost | Yes |
| Older pupils already exceed <InlineMath math="40" /> minutes | No |
| Last year's groups are a fair comparison | Yes |
