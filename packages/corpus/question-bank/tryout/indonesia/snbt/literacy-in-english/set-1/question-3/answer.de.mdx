Prüfe jede Aussage am Absatz, aus dem sie stammt, und achte auf **Behauptungen, die stärker sind als der Text**.

| Aussage | Antwort | Beleg |
| --- | --- | --- |
| Eine menschliche Hand braucht weniger koordinierte Winkel | True | Absatz 3: Ein menschlicher Arm hat eine begrenzte Zahl von Gelenken, ein Oktopusarm kann sich an jeder Stelle biegen. |
| Oktopusgehirne sind zu klein, um irgendeine Bewegung zu planen | False | Absatz 3 sagt, zentrales Planen jeder Form würde enorme Kapazität verlangen, und Absatz 5 sagt, das Gehirn setze Ziele. |
| Saugnäpfe nehmen Chemikalien wahr | True | Absatz 4: Jeder Saugnapf hat Rezeptoren für Berührung und für Chemikalien. |
| Abgetrennte Arme lösen Labyrinthe | False | Absatz 5 nennt das Lösen von Labyrinthen eine Aufgabe, die zentrales Lernen erfordert, nicht etwas, das Arme allein tun. |

Die zweite Aussage macht aus "would demand enormous processing capacity" (würde enorme Rechenkapazität verlangen) die Behauptung, das Gehirn sei zu klein, um **irgendeine** Bewegung zu planen. Der Text sagt nur, dass das Abgeben von Routinedetails das Gehirn entlastet.
