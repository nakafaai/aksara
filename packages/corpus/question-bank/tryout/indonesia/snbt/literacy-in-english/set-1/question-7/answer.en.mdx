Check each view against both writers. A view gets Yes only if Text 1 and Text 2 both hold it.

Statement 1. Text 1 praises a pilot in which Years 3 to 6 "received no homework except reading" and scored "no lower". Text 2 says "for the youngest pupils I would go as far as the pilot did" and calls them the group "in which little effect was expected". Both hold it. Yes.

Statement 2. Only Text 2 describes "a weak link" in primary school and "a clearly stronger one" for older pupils. Text 1 treats every age alike and wants homework dropped "at every age". That view is one-sided. No.

Statement 3. Text 1 says homework "falls hardest on those least able to pay", such as children without a quiet room. Text 2 says scrapping practice "could hurt most those who have the least help at home". Both writers put **the same group of pupils** at the centre. Yes.

Statement 4. This is where they split. Text 1 thinks dropping homework helps those pupils. Text 2 thinks that, for older pupils, dropping it could hurt them most. Same concern, **opposite conclusions**. No.

| Statement | Answer |
| --- | --- |
| Pilot-age pupils lose little without set homework | Yes |
| Homework's link to achievement differs by age | No |
| Pupils with little support should weigh heavily | Yes |
| Removing homework helps pupils with little support most | No |

Statements 3 and 4 look alike. Caring about the same pupils doesn't mean agreeing on what helps them.
