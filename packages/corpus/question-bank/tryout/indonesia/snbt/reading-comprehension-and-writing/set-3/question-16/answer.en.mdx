# Given

Sentence (3) reads: *"Melalui program itu, pemerintah kabupaten berharap pengeluaran keluarga untuk ongkos ojek dapat berkurang dan supaya siswa tidak lagi tiba di sekolah dalam keadaan sangat lelah sekali."*

# Asked

The best effective-sentence fix for sentence (3) without changing its meaning.

# Solution

Fix **both flaws together**: delete ***supaya*** ("so that") so both hoped-for outcomes joined by *dan* ("and") are parallel clauses, and delete ***sekali*** so it does not double up with *sangat* (*sangat lelah*, "very tired").

> Clauses joined by *dan* must share parallel structure, and intensifiers like *sangat* and *sekali* must never be stacked together.

## Fixing parallelism and double intensifier in sentence three

Sentence (3) displays both errors side by side: <Highlight>pengeluaran keluarga untuk ongkos ojek dapat berkurang dan supaya siswa tidak lagi tiba di sekolah dalam keadaan sangat lelah sekali</Highlight>.

1. Drop **supaya** so both clauses after *berharap* are parallel.
2. Shorten **sangat lelah sekali** to **sangat lelah**.

## Why the other four options fail

- Keeping **sangat lelah sekali** leaves the double intensifier unfixed.
- Keeping **dan supaya** leaves the parallelism error unfixed.
- Replacing *dan* with **sehingga** ("so that") turns two parallel hopes into a false cause-and-effect claim.
- Changing to **pengurangan pengeluaran ... dan siswa tidak lagi tiba...** mixes a noun phrase with a clause.

# Answer

The best revision is **"Melalui program itu, pemerintah kabupaten berharap pengeluaran keluarga untuk ongkos ojek dapat berkurang dan siswa tidak lagi tiba di sekolah dalam keadaan sangat lelah."**
