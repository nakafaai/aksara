An effective sentence **does not carry two parts with the same meaning**. The word _saling_ (each other) already marks a reciprocal action, and the doubled form _bantu-membantu_ (help one another) marks it too. Using both is wordy. One is enough, for example _saling membantu_.

The effective sentence (8): _Namun, biaya membangun satu rumah prisma cukup besar sehingga petambak di desa itu saling membantu mengumpulkan modal melalui koperasi._

So sentence (8) becomes effective when _saling bantu-membantu_ is replaced with _saling membantu_.

- _Namun_ (however) should stay, because it marks the contrast with the gains in sentence (7).
- _cukup_ (quite) and _sangat_ (very) both work, so swapping them fixes nothing.
- _melalui_ (through) is right for the channel, the cooperative.
- _uang modal_ (capital money) only adds a needless word, since _modal_ (capital) is already clear.
