# Given

**Sentence (5) about** peatland firefighting contains two effectiveness errors at once: a doubled conjunction and a non-parallel list.

# Asked

The revision that fixes both errors in sentence (5).

# Solution

> Fix both flaws together: **keep only one of *meskipun* or *tetapi*, and make all three listed actions match as *me-* verbs (*menusukkan*, *menyemprotkan*, *memantau*)**.

Sentence (5) has **two faults at once**, and the right repair has to clear both. Find the two faults first.

The first fault is in the connectors. The sentence opens with _meskipun_ ("although") and then continues with _tetapi_ ("but"). _Meskipun_ turns the first part into a subordinate clause. If the second part starts with _tetapi_, it can no longer be the main clause, so the sentence has no main clause. Use just one: _meskipun_ at the front, or _tetapi_ in the middle.

The second fault is in the list. Three activities are listed: _menusukkan pipa_ ("pushing a pipe in"), _menyemprotkan air_ ("spraying water") and _pemantauan suhu_ ("the monitoring of temperature"). The first two are verbs with the prefix _me-_, while the third is a noun. Items in a list have to share the same form, so the third has to be _memantau suhu_ ("monitoring the temperature").

Now test each repair with those two questions.

| Repair | Connectors fixed? | List parallel? |
| --- | --- | --- |
| _Meskipun ..., mereka tetap ... dan memantau_ | Yes | Yes |
| _..., tetapi mereka tetap ... dan pemantauan_ | Yes | No |
| _Meskipun ..., tetapi mereka tetap ... dan memantau_ | No | Yes |
| _Meskipun ..., mereka tetap ..., penyemprotan ..., dan pemantauan_ | Yes | No, now there are two nouns |
| _Meskipun ..., namun mereka tetap ... dan memantau_ | No | Yes |

The repair with _namun_ ("however") is the subtlest trap. _Namun_ replaces _tetapi_, but the problem stays: _meskipun_ and _namun_ both express contrast, so one of them is surplus. Besides, _namun_ is a connector between sentences and belongs at the start of a new sentence.

So the right repair is: _Meskipun api di permukaan lahan sudah padam, mereka tetap menusukkan pipa berujung runcing ke dalam gambut, menyemprotkan air sampai lapisan bawahnya basah, dan memantau suhu gambut selama sedikitnya tiga hari._

# Answer

The right repair is *"Meskipun api di permukaan lahan sudah padam, mereka tetap menusukkan pipa berujung runcing ke dalam gambut, menyemprotkan air sampai lapisan bawahnya basah, dan memantau suhu gambut selama sedikitnya tiga hari."*
