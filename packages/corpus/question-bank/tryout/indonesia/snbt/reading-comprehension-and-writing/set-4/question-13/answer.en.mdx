Where an inserted sentence goes is decided by its reference words. This one has **two hooks**: one points backwards, and the other is waited for by the sentence after it. The sentence to insert says: "From those two station names, the organisers count how many stations each book has passed."

The first hook is _kedua nama stasiun itu_ ("those two station names"). The words _kedua_ ("the two") and _itu_ ("those") demand two station names that have already been mentioned.

- Sentence (6) mentions the name of the station where the borrower picked up the book. That's only one.
- Sentence (7) mentions the name of the station where the book was put back. Now there are two.

So the inserted sentence can't appear before sentence (7) is done.

The second hook is in sentence (8), which opens with _hasilnya_ ("the result"). A result needs an activity that produces it. Sentence (7) only says the borrower writes a station name, and writing a name doesn't yet produce anything about the book that _paling jauh berpindah_ ("travelled farthest"). The inserted sentence fills that gap: the organisers count how many stations each book has passed, and the result shows which book travelled farthest.

Both hooks fit in only one place, after sentence (7).

The other places fail on the first hook.

- After sentence (6), there's only one station name. This is the closest trap, because the word _stasiun_ has just appeared.
- After sentence (5), only the loan card has been introduced, and no station name has been written yet.
- After sentence (3) or (4), the text is still about the rules for taking and leaving books. Cards and station names haven't come up at all.

So the sentence fits best after sentence (7).
