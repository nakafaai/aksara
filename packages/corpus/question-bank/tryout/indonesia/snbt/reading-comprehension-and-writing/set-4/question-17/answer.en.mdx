The order of the sentences is decided by **reference words**. Every word like _itu_ ("that"), _tersebut_ ("the said") or the ending _-nya_ ("it") demands something mentioned just before. Gather all those demands first.

- (Q) has _pesanan pertama itu_ ("that first order"). An order has to be mentioned before it.
- (T) has _kedai tersebut_ ("the said shop") and the word _lalu_ ("then"). A shop and an earlier event have to come before it.
- (S) has _lonjakan itu_ ("that surge"). A sharp rise has to come right before it.
- (P) has _untuk mengatasinya_ ("to deal with it"). A problem has to come right before it.
- (R) demands nothing. It introduces _sebuah kedai kopi_ ("a coffee shop") and uses _mula-mula_ ("at first"), so (R) is the opener.

Now link them.

1. (R) opens: the shop orders ten packs.
2. (Q) follows, because _pesanan pertama itu_ is those ten packs.
3. (T) follows: once the first order sells out, the shop orders five times as much.
4. (S) follows, because _lonjakan itu_ is the order that rose fivefold.
5. (P) closes, because _-nya_ in _mengatasinya_ points to the group being overwhelmed in (S).

The order is R - Q - T - S - P.

Every other order breaks at one link.

- R - T - Q - S - P looks possible, because (T) can follow (R). But then (S) stands after (Q). _Lonjakan itu_ can't point to an order that _habis terjual_ ("sold out"), because selling out isn't a rise in orders.
- Q - R - T - S - P opens with _pesanan pertama itu_ when no order has been mentioned yet.
- R - Q - S - T - P puts _lonjakan itu_ before the order rises, so (P) deals with something that isn't the problem.
- R - Q - T - P - S puts _untuk mengatasinya_ before the problem appears.

So the coherent order is R - Q - T - S - P.
