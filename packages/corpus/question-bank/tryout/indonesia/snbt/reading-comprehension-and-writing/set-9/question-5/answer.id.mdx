# Diketahui

Kalimat (2) bacaan *fire-volunteers* memakai **ungkapan kiasan api** pada <Highlight>api sudah melahap lima rumah sebelum petugas sampai</Highlight>.

# Ditanyakan

Makna kata *melahap* dalam konteks kalimat (2).

# Penyelesaian

Baca kata *melahap* bersama **subjek *api* dan objek *lima rumah***. Dalam konteks kebakaran, *melahap* dipakai secara kiasan untuk menggambarkan api yang merambat ganas hingga **membakar habis** bangunan yang dilaluinya.

> Kata bermakna kiasan ditentukan oleh pasangannya dalam kalimat, bukan oleh arti harfiahnya saat dipakai untuk makhluk hidup.

## Membandingkan lima pilihan makna

| Pilihan makna | Kecocokan dengan subjek *api* dan objek *lima rumah* | Status |
| --- | --- | --- |
| Membakar habis | Tepat sebagai makna kiasan *melahap* untuk kebakaran | **Tepat** |
| Memadamkan | Berlawanan makna dengan tindakan api | **Salah** |
| Memakan makanan dengan rakus | Makna harfiah untuk makanan, bukan makna kontekstual api | **Salah** |
| Mendekati | Terlalu lemah dibanding kerusakan lima rumah | **Salah** |
| Menerangi | Tidak menggambarkan kehancuran akibat kebakaran | **Salah** |

# Jawaban

Makna kata *melahap* dalam kalimat (2) adalah **membakar habis**.
