EYD says **a number that can be written in one or two words is written in letters**, except in itemised lists or measurements. Sentence (7) writes _3 kelas_, three classes, as a digit, although the number takes a single word, _tiga_.

So the right revision is _Hasil percobaan ini akan dipresentasikan kepada tiga kelas lain pada pekan depan._

- _tiga kelas-kelas_ is redundant, because the number _tiga_ already marks the plural, so _kelas_ needs no doubling.
- _di presentasikan_ is wrong because _di-_ here is a prefix and must be joined.
- _Pekan Depan_, next week, is not a proper name, so it takes no capitals.
- _3 kelas-kelas_ keeps the digit and also doubles _kelas_ needlessly.
