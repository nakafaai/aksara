# Gegeben

Satz (4) des *Rattanflecht*-Textes enthält **eine überladene Mischform**: <Highlight>menganyamnya berulang-ulang kali sampai para pemuda hafal</Highlight>.

# Gesucht

Die standardsprachlich wirksame Korrektur von Satz (4).

# Lösung

Beseitige **die Vermischung von *berulang-ulang* und *berulang kali***. Verwende ausschließlich eine knappe Normform, nämlich **berulang kali** (wiederholt), ohne überflüssiges Komma.

> Wirksames Standardindonesisch meidet doppelte Mischformen wie *berulang-ulang kali* oder *berkali-kali kali*.

## Prüfung aller fünf Überarbeitungen

| Vorgeschlagene Korrektur | Prüfung auf Sprachökonomie und Norm | Urteil |
| --- | --- | --- |
| *... menganyamnya berulang kali sampai para pemuda hafal.* | Knapp, normgerecht und ohne Doppelung | **Korrekt** |
| *... berulang-ulang kali hingga para pemuda hafal.* | Behält die fehlerhafte Mischform bei | **Fehlerhaft** |
| Form mit doppeltem *kali* nach *berkali-kali* | Wiederholt *kali* überflüssig | **Fehlerhaft** |
| *... ulang-ulang kali sampai para pemuda hafal.* | Keine gültige Standardform | **Fehlerhaft** |
| *... berulang-ulang kali, sampai para pemuda hafal.* | Behält die Mischform bei und ergänzt ein unnötiges Komma | **Fehlerhaft** |

# Antwort

Die wirksame Korrektur lautet ***Para perajin tua mengajarkan cara memilih rotan, merendamnya, dan menganyamnya berulang kali sampai para pemuda hafal***.
