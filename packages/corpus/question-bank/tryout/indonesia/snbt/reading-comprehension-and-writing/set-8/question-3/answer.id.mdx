# Diketahui

Kalimat (4) bacaan *rattan-weaving* memuat **bentuk rancu yang berlebihan**: <Highlight>menganyamnya berulang-ulang kali sampai para pemuda hafal</Highlight>.

# Ditanyakan

Perbaikan kalimat (4) agar menjadi kalimat efektif.

# Penyelesaian

Hilangkan **kerancuan gabungan *berulang-ulang* dan *berulang kali***. Cukup gunakan satu bentuk baku yang hemat, yaitu **berulang kali**, tanpa menambahkan koma yang memutus alur klausa.

> Kalimat efektif menghindari kontaminasi dua ungkapan bermakna sama seperti *berulang-ulang kali* atau *berkali-kali kali*.

## Menilai keefektifan lima pilihan perbaikan

| Pilihan perbaikan | Analisis kehematan dan kebakuan | Status |
| --- | --- | --- |
| *... menganyamnya berulang kali sampai para pemuda hafal.* | Bentuk baku, hemat, dan tidak rancu | **Efektif** |
| *... berulang-ulang kali hingga para pemuda hafal.* | Masih mempertahankan bentuk rancu *berulang-ulang kali* | **Tidak efektif** |
| Bentuk *berkali-kali* diikuti *kali* lagi | Mengulang kata *kali* secara mubazir | **Tidak efektif** |
| *... ulang-ulang kali sampai para pemuda hafal.* | Bukan bentuk baku bahasa Indonesia | **Tidak efektif** |
| *... berulang-ulang kali, sampai para pemuda hafal.* | Masih rancu sekaligus menambah koma yang tidak perlu | **Tidak efektif** |

# Jawaban

Perbaikan kalimat efektif yang tepat adalah ***Para perajin tua mengajarkan cara memilih rotan, merendamnya, dan menganyamnya berulang kali sampai para pemuda hafal***.
