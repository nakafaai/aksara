Der Punkt <InlineMath math="(a, b)" /> liegt auf der Kurve <InlineMath math="y = x^2 + 2" />. Ersetzen Sie <InlineMath math="a" /> und <InlineMath math="b" /> in der Kurvenfunktion, um zu erhalten

<BlockMath math="b = a^2 + 2" />

Der Punkt wird zu <InlineMath math="(a, a^2 + 2)" />. Bestimmen Sie dann den Abstand vom Punkt <InlineMath math="(a, a^2 + 2)" /> zur Linie <InlineMath math="y = x" />

<MathContainer>
<BlockMath math="\text{Entfernung} = \frac{|pm + qn + c|}{\sqrt{p^2 + q^2}}" />
<BlockMath math="f(a) = \frac{|a - (a^2 + 2)|}{\sqrt{1^2 + (-1)^2}}" />
<BlockMath math="f(a) = \frac{a^2 - a + 2}{\sqrt{2}}" />
<BlockMath math="f'(a) = \frac{1}{\sqrt{2}}(2a - 1)" />
</MathContainer>

Der kleinste Abstand ist der Mindestabstand. Der Mindestabstand liegt vor, wenn

<MathContainer>
<BlockMath math="f'(a) = 0" />
<BlockMath math="\frac{1}{\sqrt{2}}(2a - 1) = 0" />
<BlockMath math="a = \frac{1}{2}" />
</MathContainer>

Der Mindestabstand tritt auf, wenn <InlineMath math="a = \frac{1}{2}" />, ersetzen Sie ihn, um den Wert von <InlineMath math="b" /> zu erhalten.

<MathContainer>
<BlockMath math="b = a^2 + 2" />
<BlockMath math="b = \left(\frac{1}{2}\right)^2 + 2" />
<BlockMath math="b = \frac{9}{4}" />
</MathContainer>
