Misalkan akar-akar <InlineMath math="x^3 - 7x^2 + px + q = 0" /> adalah <InlineMath math="x_1, x_2, x_3" />. Karena ketiganya membentuk barisan geometri dengan rasio <InlineMath math="2" />, tuliskan secara berurutan sebagai <InlineMath math="x_1 = k" />, <InlineMath math="x_2 = 2k" />, dan <InlineMath math="x_3 = 4k" />.

Untuk suku banyak monik ini, rumus Vieta memberikan jumlah akar dari koefisien <InlineMath math="x^2" />:

<MathContainer>
<BlockMath math="x_1 + x_2 + x_3 = -\frac{b}{a}" />
<BlockMath math="k + 2k + 4k = -\frac{(-7)}{1}" />
<BlockMath math="7k = 7" />
<BlockMath math="k = 1" />
</MathContainer>

Jadi, <InlineMath math="k = 1" /> dan salah satu akarnya adalah <InlineMath math="x_1 = 1" />. Substitusikan <InlineMath math="x = 1" /> ke persamaan untuk memperoleh jumlah yang diminta:

<MathContainer>
<BlockMath math="x^3 - 7x^2 + px + q = 0" />
<BlockMath math="1^3 - 7(1)^2 + p(1) + q = 0" />
<BlockMath math="1 - 7 + p + q = 0" />
<BlockMath math="-6 + p + q = 0" />
<BlockMath math="p + q = 6" />
</MathContainer>
