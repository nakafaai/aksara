Die Definition des Absolutwerts <InlineMath math="|x + 1|" /> lautet

<BlockMath math="|x + 1| = \begin{cases} x + 1, &amp; \text{für } x + 1 \geq 0 \text{ oder} x \geq -1 \\ -(x + 1), &amp; \text{für } x + 1 &lt; 0 \text{ oder} x &lt; -1 \end{cases}" />

Für <InlineMath math="x \geq -1" />

<MathContainer>
<BlockMath math="|x + 1| = x + 1" />
<BlockMath math="|x + 1| > x + 3" />
<BlockMath math="x + 1 > x + 3" />
<BlockMath math="1 > 3" />
</MathContainer>

Es gibt keinen Wert von <InlineMath math="x" />, der <InlineMath math="x \geq -1" /> erfüllt.

Für <InlineMath math="x < -1" />

<MathContainer>
<BlockMath math="|x + 1| = -(x + 1)" />
<BlockMath math="|x + 1| > x + 3" />
<BlockMath math="-(x + 1) > x + 3" />
<BlockMath math="-x - 1 > x + 3" />
<BlockMath math="-2x > 4" />
<BlockMath math="x < -2" />
</MathContainer>

Der Wert von <InlineMath math="x" />, der die Anforderungen erfüllt, ist <InlineMath math="x < -2" />. Die Lösungsmenge ist also <InlineMath math="\{x < -2\}" />.

Nun lösen wir die zweite Ungleichung <InlineMath math="|x + 2| < 3" />:

<MathContainer>
<BlockMath math="|x + 2| < 3" />
<BlockMath math="-3 < x + 2 < 3" />
<BlockMath math="-3 - 2 < x < 3 - 2" />
<BlockMath math="-5 < x < 1" />
</MathContainer>

Die Lösungsmenge ist also <InlineMath math="\{-5 < x < 1\}" />.

Da <InlineMath math="x" /> beide Ungleichungen <InlineMath math="|x + 1| > x + 3" /> und <InlineMath math="|x + 2| < 3" /> erfüllen muss, bilden wir die Schnittmenge:

<BlockMath math="\{x < -2\} \cap \{-5 < x < 1\} = \{-5 < x < -2\}" />
