Seien <InlineMath math="\alpha" /> und <InlineMath math="\beta" /> die Wurzeln der Gleichung <InlineMath math="x^2 - bx + 6 = 0" />, also erhalten wir

<MathContainer>
<BlockMath math="\alpha + \beta = \frac{-(-b)}{1} = b" />
<BlockMath math="\alpha\beta = \frac{6}{1} = 6" />
</MathContainer>

Seien also <InlineMath math="p" /> und <InlineMath math="q" /> die Wurzeln der Gleichung <InlineMath math="x^2 - 4x + c = 0" />.

<MathContainer>
<BlockMath math="p = \alpha + \beta \quad \text{und} \quad q = \alpha - \beta" />
<BlockMath math="p + q = 4" />
<BlockMath math="(\alpha + \beta) + (\alpha - \beta) = 4" />
<BlockMath math="2\alpha = 4" />
<BlockMath math="\alpha = 2" />
</MathContainer>

Als nächstes setzen Sie den Wert <InlineMath math="\alpha = 2" /> in die erste quadratische Gleichung ein, die Sie erhalten möchten

<MathContainer>
<BlockMath math="x^2 - bx + 6 = 0" />
<BlockMath math="2^2 - b(2) + 6 = 0" />
<BlockMath math="4 - 2b + 6 = 0" />
<BlockMath math="-2b = -10" />
<BlockMath math="b = 5" />
</MathContainer>

Also <InlineMath math="p = \alpha + \beta = b = 5" />, dann ersetzen Sie den Wert <InlineMath math="p = 5" /> in die zweite quadratische Gleichung, um zu erhalten

<MathContainer>
<BlockMath math="x^2 - 4x + c = 0" />
<BlockMath math="5^2 - 4(5) + c = 0" />
<BlockMath math="25 - 20 + c = 0" />
<BlockMath math="c = -5" />
</MathContainer>

<MathContainer>

<BlockMath math="x^2 - (5 + (-5))x + 5(-5) = 0" />
<BlockMath math="x^2 - 0x - 25 = 0" />

<BlockMath math="x^2 - 5^2 = 0" />
</MathContainer>
