Wir setzen <InlineMath math="p = |x - 5|" />. Dann wird die Ungleichung zu

<MathContainer>
<BlockMath math="|x - 5|^2 - 3|x - 5| + 2 < 0" />
<BlockMath math="p^2 - 3p + 2 < 0" />
<BlockMath math="(p - 1)(p - 2) < 0" />
<BlockMath math="1 < p < 2" />
</MathContainer>

Nun setzen wir <InlineMath math="p = |x - 5|" /> wieder ein:

<MathContainer>
<BlockMath math="1 < |x - 5| < 2" />
<BlockMath math="x \in (3,4) \cup (6,7)" />
</MathContainer>
