Das Polynom <InlineMath math="x^3 - 12x^2 + (p + 4)x - (p + 8) = 0" /> mit <InlineMath math="a = 1" />, <InlineMath math="b = -12" />, <InlineMath math="c = p + 4" /> und <InlineMath math="d = -(p + 8)" />. Die Wurzeln <InlineMath math="x_1, x_2, x_3" /> bilden eine arithmetische Folge mit gemeinsamer Differenz <InlineMath math="2" />. Also <InlineMath math="x_1 = k" />, <InlineMath math="x_2 = k + 2" />, <InlineMath math="x_3 = k + 4" />.

Bestimmen des Werts von <InlineMath math="k" /> anhand der Summe der Wurzeln

<MathContainer>
<BlockMath math="x_1 + x_2 + x_3 = -\frac{b}{a}" />
<BlockMath math="k + (k + 2) + (k + 4) = -\frac{(-12)}{1}" />
<BlockMath math="3k + 6 = 12" />
<BlockMath math="3k = 6" />
<BlockMath math="k = 2" />
</MathContainer>

Die Wurzeln sind also <InlineMath math="x_1 = 2" />, <InlineMath math="x_2 = 4" />, <InlineMath math="x_3 = 6" />. Bestimmen Sie dann den Wert von <InlineMath math="p" /> aus dem Produkt seiner Wurzeln

<MathContainer>
<BlockMath math="x_1 \cdot x_2 \cdot x_3 = -\frac{d}{a}" />
<BlockMath math="2(4)(6) = -\frac{[-(p + 8)]}{1}" />
<BlockMath math="48 = p + 8" />
<BlockMath math="p = 40" />
</MathContainer>

Also der Wert von <InlineMath math="p - 36 = 40 - 36 = 4" />.
