Die Tangente hat die allgemeine Gleichung <InlineMath math="y = mx + c" />, die durch den Punkt <InlineMath math="(-8, 0)" /> verläuft. Ersetzen Sie den zu erhaltenden Punkt

<MathContainer>
<BlockMath math="y = mx + c" />
<BlockMath math="0 = -8m + c" />
<BlockMath math="c = 8m" />
</MathContainer>

Somit wird die Tangente

<MathContainer>
<BlockMath math="y = mx + 8m" />
<BlockMath math="x = \frac{y - 8m}{m}" />
</MathContainer>

Ändern Sie die Parabelfunktion in die Form <InlineMath math="x" />.

<MathContainer>
<BlockMath math="y = \sqrt{x} + 1" />
<BlockMath math="\sqrt{x} = y - 1" />
<BlockMath math="x = (y - 1)^2" />
</MathContainer>

Ersetzen Sie die Linie durch die Parabel

<MathContainer>
<BlockMath math="\frac{y - 8m}{m} = (y - 1)^2" />
<BlockMath math="\frac{y - 8m}{m} = y^2 - 2y + 1" />
<BlockMath math="y - 8m = my^2 - 2my + m" />
<BlockMath math="0 = my^2 - 2my - y + m + 8m" />
<BlockMath math="my^2 - (2m + 1)y + 9m = 0" />
</MathContainer>

Dies wird zu einer quadratischen Gleichung mit <InlineMath math="a = m" />, <InlineMath math="b = -(2m + 1)" />, <InlineMath math="c = 9m" />. Die Bedingung für Tangentialität ist <InlineMath math="D = 0" />

<MathContainer>
<BlockMath math="b^2 - 4ac = 0" />
<BlockMath math="\{-(2m + 1)\}^2 - 4m(9m) = 0" />
<BlockMath math="4m^2 + 4m + 1 - 36m^2 = 0" />
<BlockMath math="-32m^2 + 4m + 1 = 0" />
<BlockMath math="32m^2 - 4m - 1 = 0" />
<BlockMath math="(8m + 1)(4m - 1) = 0" />
<BlockMath math="m = -\frac{1}{8} \cup m = \frac{1}{4}" />
</MathContainer>

Der Zweig <InlineMath math="m=-\frac18" /> ergibt <InlineMath math="y=-\frac18x-1" />. Für <InlineMath math="x\geq0" /> liegt diese Gerade unterhalb von <InlineMath math="y=1" />, während die Kurve <InlineMath math="y=\sqrt{x}+1\geq1" /> erfüllt. Beide können sich daher nicht berühren.
