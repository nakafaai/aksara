Die Nullstellen von <InlineMath math="x^3 - 7x^2 + px + q = 0" /> seien <InlineMath math="x_1, x_2, x_3" />. Da sie eine geometrische Folge mit dem Quotienten <InlineMath math="2" /> bilden, schreiben wir sie der Reihe nach als <InlineMath math="x_1 = k" />, <InlineMath math="x_2 = 2k" /> und <InlineMath math="x_3 = 4k" />.

Für dieses normierte Polynom liefert der Satz von Vieta die Summe der Nullstellen aus dem Koeffizienten von <InlineMath math="x^2" />:

<MathContainer>
<BlockMath math="x_1 + x_2 + x_3 = -\frac{b}{a}" />
<BlockMath math="k + 2k + 4k = -\frac{(-7)}{1}" />
<BlockMath math="7k = 7" />
<BlockMath math="k = 1" />
</MathContainer>

Damit ist <InlineMath math="k = 1" /> und eine Nullstelle lautet <InlineMath math="x_1 = 1" />. Setzen wir <InlineMath math="x = 1" /> in das Polynom ein, erhalten wir die gesuchte Summe:

<MathContainer>
<BlockMath math="x^3 - 7x^2 + px + q = 0" />
<BlockMath math="1^3 - 7(1)^2 + p(1) + q = 0" />
<BlockMath math="1 - 7 + p + q = 0" />
<BlockMath math="-6 + p + q = 0" />
<BlockMath math="p + q = 6" />
</MathContainer>
