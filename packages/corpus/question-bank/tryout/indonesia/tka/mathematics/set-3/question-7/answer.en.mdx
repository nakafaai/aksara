Evaluate the composition starting with the rightmost function.

<BlockMath math="g(2)=2^2-3=1" />

The value <InlineMath math="f^{-1}(1)" /> is the number <InlineMath math="x" /> for which <InlineMath math="f(x)=1" />.

<BlockMath math="\begin{aligned}
\frac{2x-1}{x+3}&=1 \\
2x-1&=x+3 \\
x&=4
\end{aligned}" />

The value <InlineMath math="4" /> satisfies <InlineMath math="x\ne-3" />. Thus <InlineMath math="(f^{-1}\circ g)(2)=4" />.
