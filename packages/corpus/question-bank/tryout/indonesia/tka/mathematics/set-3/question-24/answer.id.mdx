Pertama, tuliskan setiap nilai mutlak berdasarkan tanda ekspresi di dalamnya.

<MathContainer>
<BlockMath math="|2x + 1| = \begin{cases} 2x + 1, & \text{jika } x \geq -\frac{1}{2} \\ -(2x + 1), & \text{jika } x < -\frac{1}{2} \end{cases}" />
<BlockMath math="|2x| = \begin{cases} 2x, & \text{jika } x \geq 0 \\ -2x, & \text{jika } x < 0 \end{cases}" />
</MathContainer>

Ekspresi di dalam nilai mutlak berubah tanda pada <InlineMath math="x = -\frac{1}{2}" /> dan <InlineMath math="x = 0" />. Kedua titik batas ini membagi garis bilangan menjadi tiga daerah: <InlineMath math="\text{Daerah I } (x < -\frac{1}{2})" />, <InlineMath math="\text{Daerah II } (-\frac{1}{2} \leq x < 0)" />, dan <InlineMath math="\text{Daerah III } (x \geq 0)" />. Kita selesaikan pertidaksamaan pada setiap daerah dengan tanda yang sesuai.

<InlineMath math="\text{Daerah I:}" /> <InlineMath math="(x < -\frac{1}{2})" />

<MathContainer>
<BlockMath math="|2x + 1| = -(2x + 1)" />
<BlockMath math="|2x| = -2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="-(2x + 1) < 5 - (-2x)" />
<BlockMath math="-2x - 1 < 5 + 2x" />
<BlockMath math="-4x < 6" />
<BlockMath math="x > -\frac{3}{2}" />
</MathContainer>

Solusi untuk <InlineMath math="\text{Daerah I}" /> adalah <InlineMath math="\{x < -\frac{1}{2}\} \cap \{x > -\frac{3}{2}\} = \{-\frac{3}{2} < x < -\frac{1}{2}\}" />.

<InlineMath math="\text{Daerah II:}" /> <InlineMath math="(-\frac{1}{2} \leq x < 0)" />

<MathContainer>
<BlockMath math="|2x + 1| = 2x + 1" />
<BlockMath math="|2x| = -2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="2x + 1 < 5 - (-2x)" />
<BlockMath math="2x + 1 < 5 + 2x" />
<BlockMath math="1 < 5" />
</MathContainer>

Pertidaksamaan menyederhana menjadi pernyataan <InlineMath math="1 < 5" /> yang selalu benar. Jadi, setiap <InlineMath math="x" /> di <InlineMath math="\text{Daerah II}" /> merupakan solusi, yaitu <InlineMath math="\{-\frac{1}{2} \leq x < 0\}" />.

<InlineMath math="\text{Daerah III:}" /> <InlineMath math="(x \geq 0)" />

<MathContainer>
<BlockMath math="|2x + 1| = 2x + 1" />
<BlockMath math="|2x| = 2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="2x + 1 < 5 - 2x" />
<BlockMath math="4x < 4" />
<BlockMath math="x < 1" />
</MathContainer>

Solusinya adalah <InlineMath math="\{x \geq 0\} \cap \{x < 1\} = \{0 \leq x < 1\}" />.

Terakhir, gabungkan solusi dari ketiga daerah:

<BlockMath math="\left\{-\frac{3}{2} < x < -\frac{1}{2}\right\} \cup \left\{-\frac{1}{2} \leq x < 0\right\} \cup \{0 \leq x < 1\} = \left\{-\frac{3}{2} < x < 1\right\}" />
