Set <InlineMath math="a = \log_3 x" /> and <InlineMath math="b = \log_2 y" />. Rewriting the first equation with base <InlineMath math="2" /> gives:

<MathContainer>
<BlockMath math="\log_3 x + \log_4 y^2 = 5" />
<BlockMath math="\log_3 x + \log_{2^2} y^2 = 5" />
<BlockMath math="\log_3 x + \frac{2}{2} \log_2 y = 5" />
<BlockMath math="\log_3 x + \log_2 y = 5" />
<BlockMath math="a + b = 5" />
<BlockMath math="a = 5 - b \tag{1}" />
</MathContainer>

The expression to maximize is <InlineMath math="\log_3 x \cdot \log_2 y = ab" />. Substitute equation <InlineMath math="(1)" />:

<MathContainer>
<BlockMath math="ab = (5 - b)b" />
<BlockMath math="f(b) = 5b - b^2" />
</MathContainer>

The target expression is therefore the downward-opening quadratic <InlineMath math="f(b) = 5b - b^2" />. Its maximum occurs where <InlineMath math="f'(b) = 0" />:

<MathContainer>
<BlockMath math="f'(b) = 0" />
<BlockMath math="5 - 2b = 0" />
<BlockMath math="2b = 5" />
<BlockMath math="b = \frac{5}{2}" />
</MathContainer>

Use equation <InlineMath math="(1)" /> to recover <InlineMath math="a" />:

<MathContainer>
<BlockMath math="a = 5 - b" />
<BlockMath math="a = 5 - \frac{5}{2}" />
<BlockMath math="a = \frac{10}{2} - \frac{5}{2}" />
<BlockMath math="a = \frac{5}{2}" />
</MathContainer>

Thus <InlineMath math="ab" /> is maximal when <InlineMath math="a = \frac{5}{2}" /> and <InlineMath math="b = \frac{5}{2}" />. Their product is:

<BlockMath math="ab = \frac{5}{2} \cdot \frac{5}{2} = \frac{25}{4}" />
