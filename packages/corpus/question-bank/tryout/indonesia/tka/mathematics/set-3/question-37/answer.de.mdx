Die Ungleichung hat die Form

<BlockMath math="\sin x + \sin 2x > \sin 3x" />

Subtrahieren Sie <InlineMath math="\sin x" /> von beiden Seiten

<BlockMath math="\sin 2x > \sin 3x - \sin x" />

Verwenden Sie die trigonometrischen Identitäten <InlineMath math="\sin 2x = 2 \sin x \cos x" /> und <InlineMath math="\sin A - \sin B = 2 \cos \frac{A + B}{2} \sin \frac{A - B}{2}" />.

<MathContainer>
<BlockMath math="2 \sin x \cos x > 2 \cos \frac{3x + x}{2} \sin \frac{3x - x}{2}" />
<BlockMath math="2 \sin x \cos x > 2 \cos 2x \sin x" />
</MathContainer>

Teilen Sie beide Seiten durch <InlineMath math="2" /> und verwenden Sie die Identität <InlineMath math="\cos 2x = 2 \cos^2 x - 1" />

<MathContainer>
<BlockMath math="\sin x \cos x > \cos 2x \sin x" />
<BlockMath math="\sin x \cos x > (2 \cos^2 x - 1) \sin x" />
<BlockMath math="\sin x \cos x - (2 \cos^2 x - 1) \sin x > 0" />
<BlockMath math="\sin x (\cos x - 2 \cos^2 x + 1) > 0" />
<BlockMath math="\sin x (2 \cos^2 x - \cos x - 1) < 0" />
</MathContainer>

Faktor <InlineMath math="2 \cos^2 x - \cos x - 1 = (2 \cos x + 1)(\cos x - 1)" />

<BlockMath math="\sin x (2 \cos x + 1)(\cos x - 1) < 0" />

Somit lauten die Werte von <InlineMath math="x" />, die den Ausdruck auf Null setzen

<MathContainer>
<BlockMath math="\sin x = 0 \Rightarrow x = 0^\circ, 180^\circ, 360^\circ" />
<BlockMath math="2 \cos x + 1 = 0 \Rightarrow \cos x = -\frac{1}{2} \Rightarrow x = 120^\circ, 240^\circ" />
<BlockMath math="\cos x - 1 = 0 \Rightarrow \cos x = 1 \Rightarrow x = 0^\circ, 360^\circ" />
</MathContainer>

Die kritischen Punkte sind <InlineMath math="x = 0^\circ" />, <InlineMath math="x = 120^\circ" />, <InlineMath math="x = 180^\circ" />, <InlineMath math="x = 240^\circ" /> und <InlineMath math="x = 360^\circ" />.
