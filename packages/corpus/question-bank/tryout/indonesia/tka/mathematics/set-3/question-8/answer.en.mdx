Let the roots of <InlineMath math="x^3 - 7x^2 + px + q = 0" /> be <InlineMath math="x_1, x_2, x_3" />. Because they form a geometric sequence with ratio <InlineMath math="2" />, write them in order as <InlineMath math="x_1 = k" />, <InlineMath math="x_2 = 2k" />, and <InlineMath math="x_3 = 4k" />.

For this monic cubic, Vieta's formula gives the sum of the roots from the coefficient of <InlineMath math="x^2" />:

<MathContainer>
<BlockMath math="x_1 + x_2 + x_3 = -\frac{b}{a}" />
<BlockMath math="k + 2k + 4k = -\frac{(-7)}{1}" />
<BlockMath math="7k = 7" />
<BlockMath math="k = 1" />
</MathContainer>

Thus <InlineMath math="k = 1" />, so one root is <InlineMath math="x_1 = 1" />. Substituting <InlineMath math="x = 1" /> into the polynomial gives the requested sum:

<MathContainer>
<BlockMath math="x^3 - 7x^2 + px + q = 0" />
<BlockMath math="1^3 - 7(1)^2 + p(1) + q = 0" />
<BlockMath math="1 - 7 + p + q = 0" />
<BlockMath math="-6 + p + q = 0" />
<BlockMath math="p + q = 6" />
</MathContainer>
