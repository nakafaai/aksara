Ändern Sie es zunächst so, dass die Bruchform verschwindet

<MathContainer>
<BlockMath math="\left|\frac{x}{3} - \frac{1}{4}\right| = \frac{1}{12}" />
<BlockMath math="\left|\frac{4x - 3}{12}\right| = \frac{1}{12}" />
<BlockMath math="|4x - 3| = 1" />
</MathContainer>

Seine Definition ist

<BlockMath math="|4x - 3| = \begin{cases} 4x - 3, &amp; \text{für } x \geq \frac{3}{4} \\ -(4x - 3), &amp; \text{für } x &lt; \frac{3}{4} \end{cases}" />

Für <InlineMath math="x \geq \frac{3}{4}" /> dann

<MathContainer>
<BlockMath math="|4x - 3| = 1" />
<BlockMath math="4x - 3 = 1" />
<BlockMath math="4x = 4" />
<BlockMath math="x = 1" />
</MathContainer>

Für <InlineMath math="x < \frac{3}{4}" /> dann

<MathContainer>
<BlockMath math="|4x - 3| = 1" />
<BlockMath math="-(4x - 3) = 1" />
<BlockMath math="-4x + 3 = 1" />
<BlockMath math="-4x = -2" />
<BlockMath math="x = \frac{1}{2}" />
</MathContainer>

Die Lösungsmenge ist also <InlineMath math="\left\{\frac{1}{2}, 1\right\}" />.
