Zuerst schreiben wir jeden Betrag passend zum Vorzeichen seines Terms.

<MathContainer>
<BlockMath math="|2x + 1| = \begin{cases} 2x + 1, &amp; \text{falls } x \geq -\frac{1}{2} \\ -(2x + 1), &amp; \text{falls } x &lt; -\frac{1}{2} \end{cases}" />
<BlockMath math="|2x| = \begin{cases} 2x, &amp; \text{falls } x \geq 0 \\ -2x, &amp; \text{falls } x &lt; 0 \end{cases}" />
</MathContainer>

Die Terme wechseln ihr Vorzeichen bei <InlineMath math="x = -\frac{1}{2}" /> und <InlineMath math="x = 0" />. Diese beiden Trennstellen teilen die Zahlengerade in drei Bereiche: <InlineMath math="\text{Bereich I } (x &lt; -\frac{1}{2})" />, <InlineMath math="\text{Bereich II } (-\frac{1}{2} \leq x &lt; 0)" /> und <InlineMath math="\text{Bereich III } (x \geq 0)" />. In jedem Bereich lösen wir die Ungleichung mit den dort geltenden Vorzeichen.

<InlineMath math="\text{Bereich I:}" /> <InlineMath math="(x < -\frac{1}{2})" />

<MathContainer>
<BlockMath math="|2x + 1| = -(2x + 1)" />
<BlockMath math="|2x| = -2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="-(2x + 1) < 5 - (-2x)" />
<BlockMath math="-2x - 1 < 5 + 2x" />
<BlockMath math="-4x < 6" />
<BlockMath math="x > -\frac{3}{2}" />
</MathContainer>

Die Lösung für <InlineMath math="\text{Bereich I}" /> ist <InlineMath math="\{x < -\frac{1}{2}\} \cap \{x > -\frac{3}{2}\} = \{-\frac{3}{2} < x < -\frac{1}{2}\}" />.

<InlineMath math="\text{Bereich II:}" /> <InlineMath math="(-\frac{1}{2} \leq x < 0)" />

<MathContainer>
<BlockMath math="|2x + 1| = 2x + 1" />
<BlockMath math="|2x| = -2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="2x + 1 < 5 - (-2x)" />
<BlockMath math="2x + 1 < 5 + 2x" />
<BlockMath math="1 < 5" />
</MathContainer>

Die Ungleichung vereinfacht sich zur stets wahren Aussage <InlineMath math="1 < 5" />. Deshalb ist jedes <InlineMath math="x" /> aus <InlineMath math="\text{Bereich II}" /> eine Lösung, also <InlineMath math="\{-\frac{1}{2} \leq x < 0\}" />.

<InlineMath math="\text{Bereich III:}" /> <InlineMath math="(x \geq 0)" />

<MathContainer>
<BlockMath math="|2x + 1| = 2x + 1" />
<BlockMath math="|2x| = 2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="2x + 1 < 5 - 2x" />
<BlockMath math="4x < 4" />
<BlockMath math="x < 1" />
</MathContainer>

Die Lösung ist <InlineMath math="\{x \geq 0\} \cap \{x < 1\} = \{0 \leq x < 1\}" />.

Zum Schluss vereinigen wir die Lösungen aus allen drei Bereichen:

<BlockMath math="\left\{-\frac{3}{2} < x < -\frac{1}{2}\right\} \cup \left\{-\frac{1}{2} \leq x < 0\right\} \cup \{0 \leq x < 1\} = \left\{-\frac{3}{2} < x < 1\right\}" />
