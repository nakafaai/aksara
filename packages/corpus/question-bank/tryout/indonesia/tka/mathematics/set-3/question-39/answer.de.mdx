Erinnern Sie sich an das Konzept der Sinusaddition

<BlockMath math="\sin(A + B) = \sin A \cos B + \cos A \sin B" />

Also

<MathContainer>
<BlockMath math="3 \cos \theta - \sin \theta = r \sin(\theta + \alpha)" />
<BlockMath math="3 \cos \theta - \sin \theta = r(\sin \theta \cos \alpha + \cos \theta \sin \alpha)" />
<BlockMath math="3 \cos \theta - \sin \theta = r \sin \alpha \cos \theta + r \cos \alpha \sin \theta" />
</MathContainer>

Durch Vergleich der Koeffizienten von <InlineMath math="\cos \theta" /> und <InlineMath math="\sin \theta" /> erhalten wir

<MathContainer>
<BlockMath math="r \sin \alpha = 3 \quad \ldots \text{(1)}" />
<BlockMath math="r \cos \alpha = -1 \quad \ldots \text{(2)}" />
</MathContainer>

Quadrieren Sie beide Gleichungen

<MathContainer>
<BlockMath math="r^2 \sin^2 \alpha = 9" />
<BlockMath math="r^2 \cos^2 \alpha = 1" />
</MathContainer>

Durch Addition der beiden obigen Gleichungen erhalten wir

<MathContainer>
<BlockMath math="r^2 \sin^2 \alpha + r^2 \cos^2 \alpha = 9 + 1" />
<BlockMath math="r^2(\sin^2 \alpha + \cos^2 \alpha) = 10" />
<BlockMath math="r^2 \cdot 1 = 10" />
<BlockMath math="r^2 = 10" />
<BlockMath math="r = \sqrt{10}" />
</MathContainer>

Um den Quadranten von <InlineMath math="\alpha" /> zu bestimmen, dividieren Sie die Gleichung <InlineMath math="\text{(1)}" /> durch die Gleichung <InlineMath math="\text{(2)}" />.

<BlockMath math="\frac{\text{(1)}}{\text{(2)}}: \quad \frac{r \sin \alpha}{r \cos \alpha} = \frac{3}{-1}" />

<MathContainer>
<BlockMath math="\tan \alpha = -3" />
</MathContainer>

Aus Gleichung <InlineMath math="\text{(1)}" />: <InlineMath math="r \sin \alpha = 3" />. Aus <InlineMath math="r > 0" /> folgt <InlineMath math="\sin \alpha > 0" />.

Aus Gleichung <InlineMath math="\text{(2)}" />: <InlineMath math="r \cos \alpha = -1" />. Aus <InlineMath math="r > 0" /> folgt <InlineMath math="\cos \alpha < 0" />.

Somit befindet sich <InlineMath math="\alpha" /> im Quadranten <InlineMath math="\text{II}" />.
