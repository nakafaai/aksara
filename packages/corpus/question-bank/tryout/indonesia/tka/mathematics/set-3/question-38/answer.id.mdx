Ingat konsep identitas

<MathContainer>
<BlockMath math="\sin x - \sin y = 2 \cos \frac{x + y}{2} \sin \frac{x - y}{2}" />
<BlockMath math="\cos x - \cos y = -2 \sin \frac{x + y}{2} \sin \frac{x - y}{2}" />
</MathContainer>

Maka akan kita dapatkan dua persamaan dari yang diketahui yaitu

<MathContainer>
<BlockMath math="2 \cos \frac{x + y}{2} \sin \frac{x - y}{2} = -\frac{1}{3} \quad \ldots \text{(1)}" />
<BlockMath math="-2 \sin \frac{x + y}{2} \sin \frac{x - y}{2} = \frac{1}{2} \quad \ldots \text{(2)}" />
</MathContainer>

Persamaan <InlineMath math="\text{(2)}" /> dibagi dengan persamaan <InlineMath math="\text{(1)}" />

<BlockMath math="\frac{\text{(2)}}{\text{(1)}}: \quad \frac{-2 \sin \frac{x + y}{2} \sin \frac{x - y}{2}}{2 \cos \frac{x + y}{2} \sin \frac{x - y}{2}} = \frac{\frac{1}{2}}{-\frac{1}{3}}" />

<MathContainer>
<BlockMath math="-\tan \frac{x + y}{2} = -\frac{3}{2}" />
<BlockMath math="\tan \frac{x + y}{2} = \frac{3}{2}" />
</MathContainer>

Nilai tangen tersebut menentukan nilai sudut rangkap yang dibutuhkan tanpa harus memilih kuadran untuk <InlineMath math="\frac{x+y}{2}" />. Gunakan

<BlockMath math="\sin 2A = \frac{2\tan A}{1+\tan^2 A}" />

dengan <InlineMath math="A=\frac{x+y}{2}" />:

<MathContainer>
<BlockMath math="\sin(x+y)=\frac{2\tan\frac{x+y}{2}}{1+\tan^2\frac{x+y}{2}}" />
<BlockMath math="\sin(x+y)=\frac{2\left(\frac{3}{2}\right)}{1+\left(\frac{3}{2}\right)^2}" />
<BlockMath math="\sin(x + y) = \frac{12}{13}" />
</MathContainer>
