Die logarithmische Ungleichung hat spezielle Lösungen für ihre Bedingungen

<MathContainer>
<BlockMath math="2x - 1 > 0 \rightarrow x > \frac{1}{2}" />
<BlockMath math="2 - x > 0 \rightarrow x < 2" />
<BlockMath math="x > 0" />
</MathContainer>

Die spezielle Lösung ist <InlineMath math="\{\frac{1}{2} < x < 2\}" />. Die allgemeine Lösung der Ungleichung ist

<MathContainer>
<BlockMath math="\log_{\frac{1}{2}}(2x - 1) + \log_{\frac{1}{2}}(2 - x) \geq 2 \log_{\frac{1}{2}} x" />
<BlockMath math="\log_{\frac{1}{2}}((2x - 1)(2 - x)) \geq \log_{\frac{1}{2}} x^2" />
<BlockMath math="\log_{\frac{1}{2}}(-2x^2 + 5x - 2) \geq \log_{\frac{1}{2}} x^2" />
<BlockMath math="-2x^2 + 5x - 2 \leq x^2" />
<BlockMath math="-3x^2 + 5x - 2 \leq 0" />
</MathContainer>

Mit <InlineMath math="-1" /> multiplizieren, sodass das Vorzeichen umgekehrt wird

<MathContainer>
<BlockMath math="3x^2 - 5x + 2 \geq 0" />
<BlockMath math="(3x - 2)(x - 1) \geq 0" />
<BlockMath math="x = \frac{2}{3} \cup x = 1" />
</MathContainer>

Der Lösungssatz ist <InlineMath math="\{x \leq \frac{2}{3} \cup x \geq 1\}" />. Also der Schnittpunkt seiner Lösungen

<BlockMath math="\left\{\frac{1}{2} < x < 2\right\} \cap \left\{x \leq \frac{2}{3} \cup x \geq 1\right\} = \left\{\frac{1}{2} < x \leq \frac{2}{3} \cup 1 \leq x < 2\right\}" />
