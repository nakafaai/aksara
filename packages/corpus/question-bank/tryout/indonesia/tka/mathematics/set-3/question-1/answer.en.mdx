Use the conjugate pair for each fraction. Since <InlineMath math="(\sqrt3-\sqrt2)(\sqrt3+\sqrt2)=1" />, the denominators disappear without a decimal approximation:

<BlockMath math="\begin{aligned}
s
&=\frac{\sqrt3+\sqrt2}{3-2}-\frac{\sqrt3-\sqrt2}{3-2}\\
&=2\sqrt2.
\end{aligned}" />

Therefore,

<BlockMath math="s^2+s\sqrt2=(2\sqrt2)^2+(2\sqrt2)(\sqrt2)=8+4=12" />

The requested value is <InlineMath math="12" />.
