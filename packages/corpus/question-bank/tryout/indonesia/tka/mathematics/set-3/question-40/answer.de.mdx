Verwenden Sie die folgenden trigonometrischen Identitäten

<MathContainer>
<BlockMath math="\sin 2x = 2 \sin x \cos x" />
<BlockMath math="\cos 2x = 2 \cos^2 x - 1" />
</MathContainer>

Dann

<MathContainer>
<BlockMath math="\sin 2x + \cos 2x = -16 \cos x + 8 \sin x + \cos^2 x" />
<BlockMath math="2 \sin x \cos x + 2 \cos^2 x - 1 = -16 \cos x + 8 \sin x + \cos^2 x" />
<BlockMath math="2 \sin x \cos x + 2 \cos^2 x - 1 + 16 \cos x - 8 \sin x - \cos^2 x = 0" />
<BlockMath math="2 \sin x \cos x + \cos^2 x + 16 \cos x - 8 \sin x - 1 = 0" />
<BlockMath math="2 \cos x (\sin x + 8) - \sin^2 x - 8 \sin x = 0" />
<BlockMath math="2 \cos x (\sin x + 8) - \sin x (\sin x + 8) = 0" />
<BlockMath math="(2 \cos x - \sin x)(\sin x + 8) = 0" />
</MathContainer>

Also <InlineMath math="2 \cos x - \sin x = 0" /> oder <InlineMath math="\sin x + 8 = 0" />.

Aus <InlineMath math="0 \leq x \leq \frac{\pi}{2}" /> folgt <InlineMath math="\sin x \geq 0" />, also <InlineMath math="\sin x + 8 \neq 0" />.

Daher <InlineMath math="2 \cos x - \sin x = 0" />

<MathContainer>
<BlockMath math="\sin x = 2 \cos x" />
<BlockMath math="\frac{\sin x}{\cos x} = 2" />
<BlockMath math="\tan x = 2 = \frac{2}{1}" />
</MathContainer>

Die Gegenkathete ist <InlineMath math="2" /> und die Ankathete ist <InlineMath math="1" />. Dann ist die Hypotenuse

<BlockMath math="\text{Hypotenuse} = \sqrt{2^2 + 1^2} = \sqrt{4 + 1} = \sqrt{5}" />

Also

<MathContainer>
<BlockMath math="\sin x = \frac{\text{Gegenkathete}}{\text{Hypotenuse}} = \frac{2}{\sqrt{5}}" />
<BlockMath math="\cos x = \frac{\text{Ankathete}}{\text{Hypotenuse}} = \frac{1}{\sqrt{5}}" />
</MathContainer>

Dann ist der Wert von <InlineMath math="\sin 2x" />

<MathContainer>
<BlockMath math="\sin 2x = 2 \sin x \cos x" />
<BlockMath math="\sin 2x = 2 \cdot \frac{2}{\sqrt{5}} \cdot \frac{1}{\sqrt{5}}" />
<BlockMath math="\sin 2x = \frac{4}{5}" />
</MathContainer>
