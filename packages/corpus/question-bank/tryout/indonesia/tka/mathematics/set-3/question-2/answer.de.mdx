Die Bedingung dafür, dass eine quadratische Gleichung keine reellen Wurzeln hat, ist

<MathContainer>
<BlockMath math="D < 0" />
<BlockMath math="b^2 - 4ac < 0 \quad ...(1)" />
</MathContainer>

Da die Linie die Kurve tangiert, gilt die Beziehung zwischen ihnen

<MathContainer>
<BlockMath math="ax^2 + bx + c = -x" />
<BlockMath math="ax^2 + bx + x + c = 0" />
<BlockMath math="ax^2 + (b + 1)x + c = 0" />
</MathContainer>

Die Bedingung für die Tangentialität ist

<MathContainer>
<BlockMath math="D = 0" />
<BlockMath math="(b + 1)^2 - 4ac = 0" />
<BlockMath math="4ac = (b + 1)^2 \quad ...(2)" />
</MathContainer>

Ersetzen Sie die Gleichung <InlineMath math="(2)" /> durch <InlineMath math="(1)" />

<MathContainer>
<BlockMath math="b^2 - 4ac < 0" />
<BlockMath math="b^2 - (b + 1)^2 < 0" />
<BlockMath math="b^2 - (b^2 + 2b + 1) < 0" />
<BlockMath math="b^2 - b^2 - 2b - 1 < 0" />
<BlockMath math="-2b - 1 < 0" />
<BlockMath math="-2b < 1" />
<BlockMath math="b > -\frac{1}{2}" />
</MathContainer>
