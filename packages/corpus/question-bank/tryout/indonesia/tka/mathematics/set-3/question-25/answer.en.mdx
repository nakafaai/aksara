There are <InlineMath math="11" /> balls. Each colour's probability is its count divided by <InlineMath math="11" />. One ball cannot be both red and blue, so the events are mutually exclusive. Since these are the only colours, <InlineMath math="P(\\text{red or blue})=1" />, not <InlineMath math="\\frac12" />. The classifications are true, true, true, false.
