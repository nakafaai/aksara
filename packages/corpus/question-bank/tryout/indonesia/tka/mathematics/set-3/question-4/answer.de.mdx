Gegeben <InlineMath math="f(x) = mx^2 - 2x^2 + 2mx + m - 3" />. Fassen Sie gleichartige Terme zusammen, um zu erhalten

<BlockMath math="f(x) = (m - 2)x^2 + 2mx + (m - 3)" />

mit <InlineMath math="a = m - 2" />, <InlineMath math="b = 2m" /> und <InlineMath math="c = m - 3" />. Die Bedingung dafür, dass die Funktion immer unterhalb der <InlineMath math="x" />-Achse liegt, ist <InlineMath math="D < 0" /> und <InlineMath math="a < 0" />.

Für <InlineMath math="D < 0" />

<MathContainer>
<BlockMath math="D < 0" />
<BlockMath math="b^2 - 4ac < 0" />
<BlockMath math="(2m)^2 - 4(m - 2)(m - 3) < 0" />
<BlockMath math="4m^2 - 4(m^2 - 5m + 6) < 0" />
<BlockMath math="4m^2 - 4m^2 + 20m - 24 < 0" />
<BlockMath math="4(5m - 6) < 0" />
<BlockMath math="5m - 6 < 0" />
<BlockMath math="5m < 6" />
<BlockMath math="m < \frac{6}{5}" />
<BlockMath math="m < 1\frac{1}{5}" />
</MathContainer>

Für <InlineMath math="a < 0" />

<MathContainer>
<BlockMath math="a < 0" />
<BlockMath math="m - 2 < 0" />
<BlockMath math="m < 2" />
</MathContainer>

Die Schnittlösung beider ist <InlineMath math="m < 1\frac{1}{5}" />. Der mögliche Wert von <InlineMath math="m" /> unterhalb der <InlineMath math="x" />-Achse ist also <InlineMath math="m < 1\frac{1}{5}" />.
