Misalkan <InlineMath math="p = |x - 5|" />. Pertidaksamaan tersebut menjadi

<MathContainer>
<BlockMath math="|x - 5|^2 - 3|x - 5| + 2 < 0" />
<BlockMath math="p^2 - 3p + 2 < 0" />
<BlockMath math="(p - 1)(p - 2) < 0" />
<BlockMath math="1 < p < 2" />
</MathContainer>

Substitusikan kembali <InlineMath math="p = |x - 5|" /> ke hasil tersebut:

<MathContainer>
<BlockMath math="1 < |x - 5| < 2" />
<BlockMath math="x \in (3,4) \cup (6,7)" />
</MathContainer>
