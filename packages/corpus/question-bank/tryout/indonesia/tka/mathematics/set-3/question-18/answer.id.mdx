Misalkan <InlineMath math="a = \log_3 x" /> dan <InlineMath math="b = \log_2 y" />. Tulis ulang persamaan pertama dengan basis <InlineMath math="2" />:

<MathContainer>
<BlockMath math="\log_3 x + \log_4 y^2 = 5" />
<BlockMath math="\log_3 x + \log_{2^2} y^2 = 5" />
<BlockMath math="\log_3 x + \frac{2}{2} \log_2 y = 5" />
<BlockMath math="\log_3 x + \log_2 y = 5" />
<BlockMath math="a + b = 5" />
<BlockMath math="a = 5 - b \tag{1}" />
</MathContainer>

Bentuk yang akan dimaksimumkan adalah <InlineMath math="\log_3 x \cdot \log_2 y = ab" />. Substitusikan persamaan <InlineMath math="(1)" />:

<MathContainer>
<BlockMath math="ab = (5 - b)b" />
<BlockMath math="f(b) = 5b - b^2" />
</MathContainer>

Bentuk sasaran menjadi fungsi kuadrat terbuka ke bawah <InlineMath math="f(b) = 5b - b^2" />. Nilai maksimumnya terjadi ketika <InlineMath math="f'(b) = 0" />:

<MathContainer>
<BlockMath math="f'(b) = 0" />
<BlockMath math="5 - 2b = 0" />
<BlockMath math="2b = 5" />
<BlockMath math="b = \frac{5}{2}" />
</MathContainer>

Gunakan persamaan <InlineMath math="(1)" /> untuk memperoleh <InlineMath math="a" />:

<MathContainer>
<BlockMath math="a = 5 - b" />
<BlockMath math="a = 5 - \frac{5}{2}" />
<BlockMath math="a = \frac{10}{2} - \frac{5}{2}" />
<BlockMath math="a = \frac{5}{2}" />
</MathContainer>

Jadi, <InlineMath math="ab" /> maksimum ketika <InlineMath math="a = \frac{5}{2}" /> dan <InlineMath math="b = \frac{5}{2}" />. Hasil kalinya adalah:

<BlockMath math="ab = \frac{5}{2} \cdot \frac{5}{2} = \frac{25}{4}" />
