First, write each absolute value according to the sign of the expression inside it.

<MathContainer>
<BlockMath math="|2x + 1| = \begin{cases} 2x + 1, & \text{if } x \geq -\frac{1}{2} \\ -(2x + 1), & \text{if } x < -\frac{1}{2} \end{cases}" />
<BlockMath math="|2x| = \begin{cases} 2x, & \text{if } x \geq 0 \\ -2x, & \text{if } x < 0 \end{cases}" />
</MathContainer>

The expressions change sign at <InlineMath math="x = -\frac{1}{2}" /> and <InlineMath math="x = 0" />. These two breakpoints divide the number line into three regions: <InlineMath math="\text{Region I } (x < -\frac{1}{2})" />, <InlineMath math="\text{Region II } (-\frac{1}{2} \leq x < 0)" />, and <InlineMath math="\text{Region III } (x \geq 0)" />. We solve the inequality in each region using the corresponding signs.

<InlineMath math="\text{Region I:}" /> <InlineMath math="(x < -\frac{1}{2})" />

<MathContainer>
<BlockMath math="|2x + 1| = -(2x + 1)" />
<BlockMath math="|2x| = -2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="-(2x + 1) < 5 - (-2x)" />
<BlockMath math="-2x - 1 < 5 + 2x" />
<BlockMath math="-4x < 6" />
<BlockMath math="x > -\frac{3}{2}" />
</MathContainer>

The solution for <InlineMath math="\text{Region I}" /> is <InlineMath math="\{x < -\frac{1}{2}\} \cap \{x > -\frac{3}{2}\} = \{-\frac{3}{2} < x < -\frac{1}{2}\}" />.

<InlineMath math="\text{Region II:}" /> <InlineMath math="(-\frac{1}{2} \leq x < 0)" />

<MathContainer>
<BlockMath math="|2x + 1| = 2x + 1" />
<BlockMath math="|2x| = -2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="2x + 1 < 5 - (-2x)" />
<BlockMath math="2x + 1 < 5 + 2x" />
<BlockMath math="1 < 5" />
</MathContainer>

The inequality reduces to the always true statement <InlineMath math="1 < 5" />. Therefore, every <InlineMath math="x" /> in <InlineMath math="\text{Region II}" /> is a solution, giving <InlineMath math="\{-\frac{1}{2} \leq x < 0\}" />.

<InlineMath math="\text{Region III:}" /> <InlineMath math="(x \geq 0)" />

<MathContainer>
<BlockMath math="|2x + 1| = 2x + 1" />
<BlockMath math="|2x| = 2x" />
<BlockMath math="|2x + 1| < 5 - |2x|" />
<BlockMath math="2x + 1 < 5 - 2x" />
<BlockMath math="4x < 4" />
<BlockMath math="x < 1" />
</MathContainer>

The solution is <InlineMath math="\{x \geq 0\} \cap \{x < 1\} = \{0 \leq x < 1\}" />.

Finally, take the union of the three regional solutions:

<BlockMath math="\left\{-\frac{3}{2} < x < -\frac{1}{2}\right\} \cup \left\{-\frac{1}{2} \leq x < 0\right\} \cup \{0 \leq x < 1\} = \left\{-\frac{3}{2} < x < 1\right\}" />
