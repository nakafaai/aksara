Fassen Sie gleichartige Terme zusammen, sodass die Funktion wird

<BlockMath math="f(x) = (m - 2)x^2 + 2mx + (m - 3)" />

Die Bedingung dafür, dass die Funktion immer unterhalb der <InlineMath math="x" />-Achse liegt, ist <InlineMath math="D < 0" /> und <InlineMath math="a < 0" />.
