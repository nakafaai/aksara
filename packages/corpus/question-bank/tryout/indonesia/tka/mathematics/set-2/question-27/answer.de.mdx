Gegeben sei das Gleichungssystem

<MathContainer>
<BlockMath math="3x + 2y - z = 3 \quad ...(1)" />
<BlockMath math="2x + y - 3z = 4 \quad ...(2)" />
<BlockMath math="x - y + 2z = -1 \quad ...(3)" />
</MathContainer>

#### Eliminieren Sie die erste und zweite Gleichung

Multiplizieren Sie die erste Gleichung mit <InlineMath math="3" /> und die zweite Gleichung mit <InlineMath math="1" /> und subtrahieren Sie dann.

<MathContainer>
<BlockMath math="3x + 2y - z = 3 \quad |\times 3| \quad 9x + 6y - 3z = 9" />
<BlockMath math="2x + y - 3z = 4 \quad |\times 1| \quad 2x + y - 3z = 4 \quad -" />
<BlockMath math="7x + 5y = 5 \quad ...(4)" />
</MathContainer>

#### Eliminieren Sie die erste und dritte Gleichung

Wir multiplizieren die erste Gleichung mit <InlineMath math="2" /> und addieren anschließend die dritte Gleichung. Dabei heben sich die <InlineMath math="z" />-Terme auf.

<MathContainer>
<BlockMath math="3x + 2y - z = 3 \quad |\times 2| \quad 6x + 4y - 2z = 6" />
<BlockMath math="x - y + 2z = -1 \quad |\times 1| \quad x - y + 2z = -1 \quad +" />
<BlockMath math="7x + 3y = 5 \quad ...(5)" />
</MathContainer>

#### Eliminieren Sie die vierte und fünfte Gleichung

Subtrahieren Sie die fünfte Gleichung von der vierten Gleichung, um den Wert von <InlineMath math="y" /> zu ermitteln.

<MathContainer>
<BlockMath math="7x + 5y = 5" />
<BlockMath math="7x + 3y = 5 \quad -" />
<BlockMath math="2y = 0" />
<BlockMath math="y = 0" />
</MathContainer>

#### Ersetzen Sie den ersten Variablenwert

Setzen Sie <InlineMath math="y = 0" /> in die vierte Gleichung ein, um den Wert von <InlineMath math="x" /> zu ermitteln.

<MathContainer>
<BlockMath math="7x + 5y = 5" />
<BlockMath math="7x + 5(0) = 5" />
<BlockMath math="7x = 5" />
<BlockMath math="x = \frac{5}{7}" />
</MathContainer>

#### Ersetzen Sie alle Variablenwerte

Setzen Sie <InlineMath math="x = \frac{5}{7}" /> und <InlineMath math="y = 0" /> in die dritte Gleichung ein, um den Wert von <InlineMath math="z" /> zu ermitteln.

<MathContainer>
<BlockMath math="x - y + 2z = -1" />
<BlockMath math="\frac{5}{7} - 0 + 2z = -1" />
<BlockMath math="2z = -\frac{12}{7}" />
<BlockMath math="z = -\frac{6}{7}" />
</MathContainer>

#### Berechnen Sie den angeforderten Wert

Ersetzen Sie die Werte <InlineMath math="x = \frac{5}{7}" />, <InlineMath math="y = 0" /> und <InlineMath math="z = -\frac{6}{7}" /> durch <InlineMath math="2x + 2y - 3z" />.

<MathContainer>
<BlockMath math="2x + 2y - 3z = 2\left(\frac{5}{7}\right) + 2(0) - 3\left(-\frac{6}{7}\right)" />
<BlockMath math="2x + 2y - 3z = \frac{10}{7} - 0 + \frac{18}{7}" />
<BlockMath math="2x + 2y - 3z = \frac{28}{7}" />
<BlockMath math="2x + 2y - 3z = 4" />
</MathContainer>

Daher ist der Wert von <InlineMath math="2x + 2y - 3z" /> <InlineMath math="4" />.
