<MathContainer>

<BlockMath math="\frac{y - (-2)}{0 - (-2)} = \frac{x - 0}{\frac{3}{2} - 0}" />
<BlockMath math="\frac{y + 2}{2} = \frac{2x}{3}" />
<BlockMath math="3y + 6 = 4x" />
<BlockMath math="-4x + 3y + 6 = 0" />

<MathContainer>

</MathContainer>

Apply the point-to-line distance formula to <InlineMath math="(a, a^2 - 1)" />.

<MathContainer>
<BlockMath math="f(a) = \frac{|-4a + 3(a^2 - 1) + 6|}{\sqrt{(-4)^2 + 3^2}}" />
<BlockMath math="f(a) = \frac{|-4a + 3(a^2 - 1) + 6|}{5}" />
<BlockMath math="f(a) = \frac{|3a^2 - 4a + 3|}{5}" />
<BlockMath math="3a^2 - 4a + 3 = 3\left(a - \frac{2}{3}\right)^2 + \frac{5}{3} > 0" />
<BlockMath math="f(a) = \frac{1}{5}(3a^2 - 4a + 3)" />
</MathContainer>

The completed-square form proves that the expression inside the absolute value is always positive. We may therefore remove the absolute value. At the minimum, <InlineMath math="f'(a) = 0" />.

<MathContainer>
<BlockMath math="f'(a) = \frac{1}{5}(6a - 4)" />
<BlockMath math="f'(a) = 0" />
<BlockMath math="\frac{1}{5}(6a - 4) = 0" />
<BlockMath math="6a = 4" />
<BlockMath math="a = \frac{4}{6} = \frac{2}{3}" />
</MathContainer>

Substitute <InlineMath math="a = \frac{2}{3}" /> to obtain the minimum distance between the parabola and the line.

<MathContainer>
<BlockMath math="f(a) = \frac{1}{5}(3a^2 - 4a + 3)" />
<BlockMath math="f(a) = \frac{1}{5}\left(3\left(\frac{2}{3}\right)^2 - 4\left(\frac{2}{3}\right) + 3\right)" />
<BlockMath math="f(a) = \frac{1}{5}\left(\frac{4}{3} - \frac{8}{3} + \frac{9}{3}\right)" />
<BlockMath math="f(a) = \frac{1}{5}\left(\frac{5}{3}\right) = \frac{1}{3}" />
</MathContainer>
