Karena <InlineMath math="a" /> dan <InlineMath math="b" /> merupakan akar-akar <InlineMath math="2x^2 + kx + 6 = 0" />, rumus Vieta memberikan

<MathContainer>
<BlockMath math="ab = \frac{6}{2} = 3" />
<BlockMath math="a \neq 0 \quad \text{dan} \quad b \neq 0" />
</MathContainer>

Tiga suku pertama <InlineMath math="a, b, b^2" /> membentuk barisan geometri, sehingga rasio dua suku berurutan harus sama.

<MathContainer>
<BlockMath math="\frac{b}{a} = \frac{b^2}{b} = b" />
<BlockMath math="\frac{1}{a} = 1" />
<BlockMath math="a = 1" />
</MathContainer>

Pembagian dengan <InlineMath math="b" /> sah karena <InlineMath math="b \neq 0" />. Gunakan kembali hasil kali akar untuk menentukan <InlineMath math="b" />.

<MathContainer>
<BlockMath math="ab = 3" />
<BlockMath math="(1)b = 3" />
<BlockMath math="b = 3" />
</MathContainer>

Selanjutnya, jumlah akar menentukan nilai <InlineMath math="k" />.

<MathContainer>
<BlockMath math="x_1 + x_2 = \frac{-k}{2}" />
<BlockMath math="1 + 3 = \frac{-k}{2}" />
<BlockMath math="4 = \frac{-k}{2}" />
<BlockMath math="k = -8" />
</MathContainer>

Sehingga barisan geometrinya adalah

<BlockMath math="a, b, b^2 = 1, 3, 9, ..." />

Maka suku ke-<InlineMath math="4" /> nya adalah

<MathContainer>
<BlockMath math="u_4 = ar^3" />
<BlockMath math="u_4 = (1)(3)^3" />
<BlockMath math="u_4 = 27" />
</MathContainer>

Jadi nilai <InlineMath math="u_4" /> dan <InlineMath math="k" /> berturut-turut adalah <InlineMath math="27" /> dan <InlineMath math="-8" />.
