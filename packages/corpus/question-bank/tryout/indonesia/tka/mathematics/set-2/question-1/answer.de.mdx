Da der Punkt <InlineMath math="(a, b)" /> auf der Kurve liegt, erfüllen seine Koordinaten

<BlockMath math="b = a^3 - 3a^2 - 9a \quad ...(1)" />

Nun leiten wir die Funktion ab:

<MathContainer>
<BlockMath math="f(x) = x^3 - 3x^2 - 9x" />
<BlockMath math="f'(x) = 3x^2 - 6x - 9" />
</MathContainer>

Im Berührpunkt entspricht die Ableitung der Steigung der Tangente:

<BlockMath math="f'(a) = m" />

<MathContainer>
<BlockMath math="3a^2 - 6a - 9 = 15" />
<BlockMath math="3a^2 - 6a - 24 = 0" />
<BlockMath math="a^2 - 2a - 8 = 0" />
<BlockMath math="(a + 2)(a - 4) = 0" />
<BlockMath math="a = -2 \cup a = 4" />
</MathContainer>

Bestimmen Sie den Wert von <InlineMath math="b" /> aus den Gleichungen <InlineMath math="(1)" /> und <InlineMath math="a + b" />.

<BlockMath math="b = a^3 - 3a^2 - 9a" />

Wenn <InlineMath math="a = -2" />

<MathContainer>
<BlockMath math="b = (-2)^3 - 3(-2)^2 - 9(-2)" />
<BlockMath math="b = -8 - 12 + 18" />
<BlockMath math="b = -2" />
<BlockMath math="a + b = -2 + (-2) = -4" />
</MathContainer>

Wenn <InlineMath math="a = 4" />

<MathContainer>
<BlockMath math="b = 4^3 - 3(4)^2 - 9(4)" />
<BlockMath math="b = -20" />
<BlockMath math="a + b = 4 + (-20) = -16" />
</MathContainer>

Die beiden möglichen Werte sind <InlineMath math="-4" /> und <InlineMath math="-16" />. Von ihnen steht nur <InlineMath math="-4" /> zur Auswahl.
