Dengan melengkapkan kuadrat, <InlineMath math="f(x)=(x-2)^2-1" />. Jadi, titik puncaknya <InlineMath math="(2,-1)" />, range-nya <InlineMath math="[-1,\infty)" />, dan fungsi menurun sampai <InlineMath math="x=2" />. Fungsi tidak satu-satu pada seluruh <InlineMath math="\mathbb R" />. Pada domain <InlineMath math="[2,\infty)" />, inversnya <InlineMath math="f^{-1}(y)=2+\sqrt{y+1}" />.
