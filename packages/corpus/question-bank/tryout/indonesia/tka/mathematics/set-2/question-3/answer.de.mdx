Die Ganzzahl <InlineMath math="p" /> ist eine Wurzel von <InlineMath math="f(x) = 0" />. Wir können daraus schließen, dass <InlineMath math="x = p" /> also <InlineMath math="f(p) = 0" />

<MathContainer>
<BlockMath math="f(x) = px^2 - 3x - p - 3" />
<BlockMath math="f(p) = 0" />
<BlockMath math="p \cdot p^2 - 3p - p - 3 = 0" />
<BlockMath math="p^3 - 3p - p - 3 = 0" />
<BlockMath math="p^3 - 4p - 3 = 0" />
<BlockMath math="(p + 1)(p^2 - p - 3) = 0" />
<BlockMath math="p = -1 \cup p^2 - p - 3 = 0" />
</MathContainer>

Die Faktorisierung lässt sich mit dem Horner-Schema bestimmen. Die verbleibende quadratische Gleichung hat die Diskriminante

<BlockMath math="\Delta = (-1)^2 - 4(1)(-3) = 13" />

Da <InlineMath math="13" /> keine Quadratzahl ist, sind ihre beiden Lösungen nicht ganzzahlig. Damit bleibt als einziger ganzzahliger Wert <InlineMath math="p = -1" />. Eingesetzt in die Funktion ergibt das

<MathContainer>
<BlockMath math="f(x) = -1x^2 - 3x - (-1) - 3" />
<BlockMath math="f(x) = -x^2 - 3x - 2" />
<BlockMath math="f'(x) = -2x - 3" />
</MathContainer>

Bei <InlineMath math="x = p = -1" /> beträgt der Gradient

<MathContainer>
<BlockMath math="m = f'(x)" />
<BlockMath math="m = f'(-1)" />
<BlockMath math="m = -2(-1) - 3" />
<BlockMath math="m = 2 - 3" />
<BlockMath math="m = -1" />
</MathContainer>
