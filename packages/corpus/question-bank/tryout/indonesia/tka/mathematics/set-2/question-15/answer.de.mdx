Die im Aufgabentext genannte unbestimmte Form bedeutet, dass Zähler und Nenner bei <InlineMath math="x = -3" /> beide null werden. Aus dem Zähler folgt

<MathContainer>
<BlockMath math="\frac{1}{a(-3)} + \frac{1}{3} = 0" />
<BlockMath math="-1 + a = 0" />
<BlockMath math="a = 1" />
</MathContainer>

Aus dem Nenner folgt

<MathContainer>
<BlockMath math="b(-3)^3 + 27 = 0" />
<BlockMath math="-27b + 27 = 0" />
<BlockMath math="b = 1" />
</MathContainer>

Durch Faktorisieren des Nenners prüfen wir, dass diese Werte tatsächlich den angegebenen Grenzwert liefern.

<MathContainer>
<BlockMath math="\lim_{x \to -3}\frac{\frac{1}{x}+\frac{1}{3}}{x^3+27}
=\lim_{x \to -3}\frac{x+3}{3x(x+3)(x^2-3x+9)}" />
<BlockMath math="=\frac{1}{3(-3)(9+9+9)}
=-\frac{1}{243}
=-\frac{1}{3^5}" />
</MathContainer>

Damit ist <InlineMath math="a + b = 1 + 1 = 2" />.
