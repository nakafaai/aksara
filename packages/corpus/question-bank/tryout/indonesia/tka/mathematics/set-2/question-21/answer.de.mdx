Lösen Sie die Ungleichung

<MathContainer>
<BlockMath math="|x - 2a| + a \leq b" />
<BlockMath math="|x - 2a| \leq b - a" />
<BlockMath math="-(b - a) \leq x - 2a \leq b - a" />
<BlockMath math="-b + a \leq x - 2a \leq b - a" />
</MathContainer>

Fügen Sie <InlineMath math="2a" /> auf beiden Seiten hinzu

<MathContainer>
<BlockMath math="-b + a + 2a \leq x - 2a + 2a \leq b - a + 2a" />
<BlockMath math="-b + 3a \leq x \leq b + a" />
</MathContainer>

Daher lautet die Lösung <InlineMath math="-b + 3a \leq x \leq b + a" />.
