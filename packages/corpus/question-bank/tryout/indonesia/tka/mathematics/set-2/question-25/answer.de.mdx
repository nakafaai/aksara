Definieren Sie den ersten absoluten Wert für <InlineMath math="|x - 2|" />.

<InlineMath math="x - 2" /> ist nichtnegativ für <InlineMath math="x - 2 \geq 0 \rightarrow x \geq 2" />.

<InlineMath math="x - 2" /> ist negativ für <InlineMath math="x - 2 < 0 \rightarrow x < 2" />.

Die Definition lautet also

<BlockMath math="|x - 2| = \begin{cases} x - 2; \text{für } x \geq 2 \\ -(x - 2); \text{für } x < 2 \end{cases}" />

Für <InlineMath math="|x^2 - 4|" />

<InlineMath math="x^2 - 4" /> ist nichtnegativ für <InlineMath math="x^2 - 4 \geq 0 \rightarrow x \leq -2 \vee x \geq 2" />.

<InlineMath math="x^2 - 4" /> ist negativ für <InlineMath math="x^2 - 4 < 0 \rightarrow -2 < x < 2" />.

Die Definition lautet also

<BlockMath math="|x^2 - 4| = \begin{cases} x^2 - 4; \text{für } x \leq -2 \vee x \geq 2 \\ -(x^2 - 4); \text{für } -2 < x < 2 \end{cases}" />

Nach den obigen Definitionen wird der absolute Wert durch <InlineMath math="x = -2" /> und <InlineMath math="x = 2" /> begrenzt. Dies bedeutet, dass es <InlineMath math="3" /> mögliche Regionen/Werte von <InlineMath math="x" /> gibt.

Lösen Sie das Problem basierend auf Regionen.

<InlineMath math="\text{Region I}" /> wenn <InlineMath math="x < -2" />

<MathContainer>
<BlockMath math="|x^2 - 4| = x + |x - 2|" />
<BlockMath math="x^2 - 4 = x + (-x + 2)" />
<BlockMath math="x^2 = 6" />
<BlockMath math="x = \pm\sqrt{6}" />
</MathContainer>

Da <InlineMath math="\text{Region I}" /> negativ ist, ist die Wurzel, die die Anforderungen erfüllt, <InlineMath math="x_1 = -\sqrt{6}" />.

<InlineMath math="\text{Region II}" /> wenn <InlineMath math="-2 \leq x < 2" />

<MathContainer>
<BlockMath math="|x^2 - 4| = x + |x - 2|" />
<BlockMath math="-x^2 + 4 = x + (-x + 2)" />
<BlockMath math="x^2 = 2" />
<BlockMath math="x = \pm\sqrt{2}" />
</MathContainer>

Da <InlineMath math="\text{Region II}" /> sowohl positive als auch negative Werte enthält, erfüllen alle Wurzeln <InlineMath math="\text{Region II}" />.

<InlineMath math="\text{Region III}" /> wenn <InlineMath math="x \geq 2" />

<MathContainer>
<BlockMath math="|x^2 - 4| = x + |x - 2|" />
<BlockMath math="x^2 - 4 = x + x - 2" />
<BlockMath math="x^2 - 2x - 2 = 0" />
</MathContainer>

Wir lösen die quadratische Gleichung und behalten nur die Nullstelle aus diesem Bereich.

<MathContainer>
<BlockMath math="D = b^2 - 4ac" />
<BlockMath math="D = (-2)^2 - 4(1)(-2)" />
<BlockMath math="D = 4 + 8" />
<BlockMath math="D = 12" />
<BlockMath math="x = \frac{2\pm\sqrt{12}}{2}=1\pm\sqrt{3}" />
</MathContainer>

Nur <InlineMath math="x=1+\sqrt{3}" /> erfüllt <InlineMath math="x\geq2" />.

Die vier Lösungen sind <InlineMath math="-\sqrt6" />, <InlineMath math="-\sqrt2" />, <InlineMath math="\sqrt2" /> und <InlineMath math="1+\sqrt3" />. Die Gleichung besitzt daher <InlineMath math="4" /> reelle Lösungen.
