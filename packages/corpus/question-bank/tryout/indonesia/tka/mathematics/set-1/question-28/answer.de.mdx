Gegeben <InlineMath math="y = \cos^3 x" />

#### Ableitung mittels Kettenregel

Verwenden Sie die Kettenregel, um die zusammengesetzte Funktion zu differenzieren

<MathContainer>
<BlockMath math="y' = 3(\cos^2 x) \cdot (-\sin x)" />
<BlockMath math="= -3\cos^2 x \sin x" />
<BlockMath math="= -3\cos x \cos x \sin x" />
</MathContainer>

#### Verwendung der trigonometrischen Identität

Verwenden Sie die Identität <InlineMath math="2\sin x \cos x = \sin 2x" />

<MathContainer>
<BlockMath math="= \frac{-3}{2}\cos x (2\sin x \cos x)" />
<BlockMath math="= \frac{-3}{2}\cos x \cdot \sin 2x" />
</MathContainer>

Daher ist die erste Ableitung von <InlineMath math="y = \cos^3 x" /> <InlineMath math="y' = \frac{-3}{2}\cos x \cdot \sin 2x" />
