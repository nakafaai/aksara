Um <InlineMath math="\int (2\sin 2x - 3\cos x) dx" /> zu lösen, integrieren Sie jeden Term separat

#### Das Integral trennen

<MathContainer>
<BlockMath math="\int (2\sin 2x - 3\cos x) dx = 2\int \sin 2x \, dx - 3\int \cos x \, dx" />
</MathContainer>

#### Jeden Term integrieren

Für <InlineMath math="\int \sin 2x \, dx" /> verwenden Sie die Substitution <InlineMath math="u = 2x" />

<MathContainer>
<BlockMath math="\int \sin 2x \, dx = -\frac{1}{2}\cos 2x" />
</MathContainer>

Für <InlineMath math="\int \cos x \, dx" />

<MathContainer>
<BlockMath math="\int \cos x \, dx = \sin x" />
</MathContainer>

#### Ergebnisse kombinieren

<MathContainer>
<BlockMath math="\int (2\sin 2x - 3\cos x) dx = 2\left(-\frac{1}{2}\cos 2x\right) - 3\sin x + C" />
<BlockMath math="= -\cos 2x - 3\sin x + C" />
</MathContainer>

Daher ist das Ergebnis von <InlineMath math="\int (2\sin 2x - 3\cos x) dx = -\cos 2x - 3\sin x + C" />
