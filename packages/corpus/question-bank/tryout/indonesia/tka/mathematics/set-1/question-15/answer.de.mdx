Gegeben sei eine arithmetische Reihe mit <InlineMath math="S_n = 2n^2 + 4n" />

#### Bestimmung der allgemeinen Termformel

Wenn <InlineMath math="U_n = S_n - S_{n-1}" />, dann

<MathContainer>
<BlockMath math="U_n = (2n^2 + 4n) - (2(n-1)^2 + 4(n-1))" />
<BlockMath math="= 2n^2 + 4n - (2(n^2 - 2n + 1) + 4n - 4)" />
<BlockMath math="= 2n^2 + 4n - (2n^2 - 4n + 2 + 4n - 4)" />
<BlockMath math="= 2n^2 + 4n - 2n^2 + 4n - 2 - 4n + 4" />
<BlockMath math="= 4n + 2" />
</MathContainer>

#### Berechnung der angeforderten Laufzeit

Der <InlineMath math="10" />-te Term der Reihe ist

<MathContainer>
<BlockMath math="U_n = 4n + 2" />
<BlockMath math="U_{10} = 4(10) + 2" />
<BlockMath math="= 40 + 2 = 42" />
</MathContainer>

Daher ist der <InlineMath math="10" />-te Term der Reihe <InlineMath math="42" />
