Der Preis von <InlineMath math="1" /> Buch sei <InlineMath math="= x" />, der Preis von <InlineMath math="1" /> Stift <InlineMath math="= y" /> und der Preis von <InlineMath math="1" /> Bleistift <InlineMath math="= z" />.

Damit erhalten wir die folgenden Gleichungen:

<MathContainer>
<BlockMath math="\text{Adi: } 4x + 2y + 3z = 26{.}000 \quad \text{...(i)}" />
<BlockMath math="\text{Bima: } 3x + 3y + z = 21{.}500 \quad \text{...(ii)}" />
<BlockMath math="\text{Citra: } 3x + z = 12{.}500 \quad \text{...(iii)}" />
</MathContainer>

Aus der Gleichung <InlineMath math="\text{(iii)}" /> erhalten wir

<BlockMath math="z = 12{.}500 - 3x" />

Setze <InlineMath math="z" /> in die Gleichung <InlineMath math="\text{(ii)}" /> ein.

<MathContainer>
<BlockMath math="3x + 3y + (12{.}500 - 3x) = 21{.}500" />
<BlockMath math="3y + 12{.}500 = 21{.}500" />
<BlockMath math="3y = 9{.}000" />
<BlockMath math="y = 3{.}000" />
</MathContainer>

Setze <InlineMath math="z" /> und <InlineMath math="y" /> in die Gleichung <InlineMath math="\text{(i)}" /> ein.

<MathContainer>
<BlockMath math="4x + 2(3{.}000) + 3(12{.}500 - 3x) = 26{.}000" />
<BlockMath math="4x + 6{.}000 + 37{.}500 - 9x = 26{.}000" />
<BlockMath math="-5x + 43{.}500 = 26{.}000" />
<BlockMath math="-5x = -17{.}500" />
<BlockMath math="x = 3{.}500" />
</MathContainer>

Von <InlineMath math="x = 3{.}500" /> können wir <InlineMath math="z" /> finden

<MathContainer>
<BlockMath math="z = 12{.}500 - 3(3{.}500)" />
<BlockMath math="z = 12{.}500 - 10{.}500 = 2{.}000" />
</MathContainer>

Dina kauft <InlineMath math="2" /> Stifte und <InlineMath math="2" /> Bleistifte, der zu zahlende Betrag beträgt also

<MathContainer>
<BlockMath math="2y + 2z = 2(3{.}000) + 2(2{.}000)" />
<BlockMath math="= 6{.}000 + 4{.}000 = 10{.}000" />
</MathContainer>

Daher muss Dina <InlineMath math="\text{Rp}10{.}000" /> bezahlen.
