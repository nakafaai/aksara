Gegeben sei die quadratische Gleichung <InlineMath math="x^2 + ax - 4 = 0" /> mit Wurzeln <InlineMath math="p" /> und <InlineMath math="q" />

Nach Vietas Formeln wissen wir das

<MathContainer>
<BlockMath math="p + q = -\frac{b}{a} = -a" />
<BlockMath math="p \cdot q = \frac{c}{a} = -4" />
</MathContainer>

Wenn <InlineMath math="p^2 - 2pq + q^2 = 8a" />, können wir die linke Seite vereinfachen

<MathContainer>
<BlockMath math="p^2 + q^2 - 2pq = 8a" />
<BlockMath math="(p + q)^2 - 2pq - 2pq = 8a" />
<BlockMath math="(p + q)^2 - 4pq = 8a" />
</MathContainer>

Ersetzen Sie die Werte <InlineMath math="p + q = -a" /> und <InlineMath math="pq = -4" />

<MathContainer>
<BlockMath math="(-a)^2 - 4(-4) = 8a" />
<BlockMath math="a^2 + 16 = 8a" />
<BlockMath math="a^2 - 8a + 16 = 0" />
</MathContainer>

Faktorisieren Sie die quadratische Gleichung

<MathContainer>
<BlockMath math="(a - 4)^2 = 0" />
<BlockMath math="a = 4" />
</MathContainer>

Daher ist der Wert von <InlineMath math="a" />, der die Anforderungen erfüllt, <InlineMath math="4" />
