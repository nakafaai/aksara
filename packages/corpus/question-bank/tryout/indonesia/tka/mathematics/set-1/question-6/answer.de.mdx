Um die Funktion <InlineMath math="H(t) = A \cos(Bt) + C" /> zu analysieren, müssen wir drei Parameter basierend auf den angegebenen Daten bestimmen.

#### Amplitude

Der Betrag der Amplitude <InlineMath math="A" /> ist die Hälfte der Differenz zwischen Maximum und Minimum:

<BlockMath math="|A| = \frac{\text{Maximum} - \text{Minimum}}{2} = \frac{10 - 2}{2} = \frac{8}{2} = 4" />

Damit gilt <InlineMath math="|A| = 4" />. Die Bedingung <InlineMath math="H(0)=10" /> legt das Maximum auf <InlineMath math="t=0" />. Deshalb gilt <InlineMath math="A = 4" />.

#### Vertikale Verschiebung

Die vertikale Verschiebung <InlineMath math="C" /> liegt in der Mitte zwischen Maximum und Minimum:

<BlockMath math="C = \frac{\text{Maximum} + \text{Minimum}}{2} = \frac{10 + 2}{2} = \frac{12}{2} = 6" />

Daher <InlineMath math="C = 6" />

#### Periode und Frequenzfaktor

Die Periode der Funktion <InlineMath math="\cos(Bt)" /> beträgt <InlineMath math="\frac{2\pi}{B}" />

Die vollständige Gezeitenperiode beträgt <InlineMath math="12 \text{ Stunden}" />:

<MathContainer>
<BlockMath math="\text{Zeitraum} = \frac{2\pi}{B} = 12" />
<BlockMath math="|B| = \frac{2\pi}{12} = \frac{\pi}{6}" />
</MathContainer>

Da laut Aufgabe <InlineMath math="B>0" /> gilt, erhalten wir <InlineMath math="B = \frac{\pi}{6}" />.

Somit sind die Parameterwerte <InlineMath math="A = 4" />, <InlineMath math="B = \frac{\pi}{6}" /> und <InlineMath math="C = 6" />.

Damit gilt <InlineMath math="A = 4, B = \frac{\pi}{6}, C = 6" />.
