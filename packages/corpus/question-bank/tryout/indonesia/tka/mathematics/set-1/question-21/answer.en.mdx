A point on the line through <InlineMath math="A" /> can be written as

<BlockMath math="\mathbf{x}(s)=\mathbf{a}+s\mathbf{t}" />

The circle consists of all vectors whose squared length is <InlineMath math="r^2" />. Because <InlineMath math="A" /> lies on the circle, <InlineMath math="\mathbf{a}\cdot\mathbf{a}=r^2" />.

#### Test the line against the circle

Substitute <InlineMath math="\mathbf{x}(s)" /> into the circle equation:

<MathContainer>
<BlockMath math="(\mathbf{a}+s\mathbf{t})\cdot(\mathbf{a}+s\mathbf{t})=r^2" />
<BlockMath math="\mathbf{a}\cdot\mathbf{a}+2s(\mathbf{a}\cdot\mathbf{t})+s^2(\mathbf{t}\cdot\mathbf{t})=r^2" />
<BlockMath math="s\left(2\mathbf{a}\cdot\mathbf{t}+s\lVert\mathbf{t}\rVert^2\right)=0" />
</MathContainer>

The root <InlineMath math="s=0" /> represents point <InlineMath math="A" />. If <InlineMath math="\mathbf{a}\cdot\mathbf{t}\neq0" />, the equation has a second root, so the line crosses the circle at another point. A tangent has only the contact point, which requires

<BlockMath math="\mathbf{a}\cdot\mathbf{t}=0" />

A zero dot product means <InlineMath math="\mathbf{a}\perp\mathbf{t}" />. Thus, the tangent direction is perpendicular to the radius <InlineMath math="OA" />, so the third choice is correct.
