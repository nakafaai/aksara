Rewrite the function as <InlineMath math="f(x)=2+\frac5{x-1}" />. The asymptote center is therefore <InlineMath math="(1,2)" />, the function decreases on each domain interval, and <InlineMath math="x>1" /> implies <InlineMath math="f(x)>2" />. Solving <InlineMath math="y=f(x)" /> for <InlineMath math="x" /> gives <InlineMath math="f^{-1}(y)=\frac{y+3}{y-2}" />. The function is undefined at <InlineMath math="x=1" />. The first four statements are true.
