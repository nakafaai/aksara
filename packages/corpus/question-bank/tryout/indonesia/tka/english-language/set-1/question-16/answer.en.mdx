Before the first meter reading, select the actions that establish a controlled test without interrupting essential use:

- **Choose a quiet period.**
- **Check whether essential equipment uses water.**

The irrigation timer should be checked so it will remain off during the test. The passage does not ask the observer to start irrigation to test its timer. The passage requires keeping irrigation off during the test. If essential equipment must keep using water, the no-use test should be postponed. Breaking a wall is also outside the purpose and safety limits of this meter check.
