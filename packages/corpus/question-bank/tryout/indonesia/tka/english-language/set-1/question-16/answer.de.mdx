Vor der ersten Ablesung sind die Maßnahmen auszuwählen, die einen kontrollierten Test ermöglichen und notwendige Wassernutzung schützen:

- **Choose a quiet period.**
- **Check whether essential equipment uses water.**

Die Bewässerungssteuerung muss so geprüft werden, dass sie während des Tests ausgeschaltet bleibt. Ein vorheriger Start würde zusätzlichen Wasserverbrauch erzeugen und die ruhige Testphase beeinträchtigen. Das Öffnen einer Wand liegt ebenfalls außerhalb von Zweck und Sicherheitsgrenzen dieser Zählerprüfung.
