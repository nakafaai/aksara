Dua pilihan berikut menunjukkan proses belajar penulis:

- **Listening to an owner's description before touching the bicycle**
- **Sorting mixed bolts by using notes and measurements**

Kedua peristiwa itu menunjukkan bahwa bukti mengarahkan tindakan. Rantai anak diuji sebelum diganti, sehingga menggantinya langsung akan mengulang kekeliruan awal penulis. Pada hari terakhir, penulis bertanya tentang gejala dan mengusulkan pengujian aman. Ia tidak memberi jawaban sebelum mendengarkan.
