Die ersten vier Optionen lassen sich an konkreten Angaben im Text prüfen: ein Schulhalbjahr, fünf genannte Messgrößen, die Möglichkeit zur Rückkehr und das Beispiel mit einem jüngeren Geschwisterkind. Die Behauptung, ein umkehrbarer Versuch sei für **jede** Schule die **fairste** Lösung, fügt dagegen eine Wertung und eine allgemeine Aussage hinzu. Für beides liefert der Text keinen überprüfbaren Nachweis.
