# Given

Four numbered statements test the **true sequence and duration of events** in the Radio Sekar account, including the exact start time of the live broadcast half a minute before the speakers went silent at <InlineMath math="7\text{:}02" />.

# Asked

Which numbered statements about the order and timing of events are correct.

# Solution

Imagine pressing a stopwatch at the very first second the show goes live. Alongside checking the **real chronological sequence**, statement IV requires adding the half minute before silence to the four silent minutes.

> Tiny timing phrases like half a minute into the broadcast matter because they shift the true start time earlier than the silence itself.

## Checking statements I to III

- **Statement I is correct** because the caretaker painted <Highlight>On Saturday</Highlight> (paragraph three) while Rina tested her mic <Highlight>On Monday at <InlineMath math="6\text{:}40" /></Highlight> (paragraph four).
- **Statement II is incorrect** because the room changes were reread <Highlight>at the first break</Highlight> on Monday (paragraph five), whereas Dimas sent his message from Class 11B <Highlight>On Wednesday</Highlight>.
- **Statement III is correct** because the four recorded minutes ended with Pak Hadi's knock, and the writer found the cable only <Highlight>Once Pak Hadi's word sank in</Highlight> (paragraph five).

## Computing the duration for statement IV

Paragraph one states silence hit <Highlight>At two minutes past seven</Highlight>, already <Highlight>half a minute into the first live broadcast</Highlight>, so the broadcast started at <InlineMath math="7\text{:}01\text{:}30" />. Pak Hadi knocked <Highlight>At <InlineMath math="7\text{:}06" /></Highlight>:

<BlockMath math="\text{7:06:00} - \text{7:01:30} = 4\text{ min } 30\text{ s}" />

That total is **<InlineMath math="4" /> minutes <InlineMath math="30" /> seconds**, which is more than four minutes, making **statement IV correct**. Options dropping IV miss that opening half minute, while options adding II pull Wednesday ahead of Monday's first break.

# Answer

The correct statements about the order of events are **I, III, and IV only**.
