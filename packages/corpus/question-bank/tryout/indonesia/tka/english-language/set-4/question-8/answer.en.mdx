# Given

The mangrove recount **opens with the June count and flashes back to March**, covering **six events (P through U)** anchored by explicit month and week markers.

# Asked

The chronological order in which events P, Q, R, S, T, and U actually happened.

# Solution

Do not copy the paragraph order! Because the writer opens with a flashback hook from late June, **pin every event onto a March-to-July calendar** using the exact time phrases in the text.

> Narrative order and chronological order diverge whenever a writer opens with a later event before stepping back to explain how it began.

## Rebuilding the timeline from text markers

| Order | Code | Event | Explicit time marker |
| --- | --- | --- | --- |
| <InlineMath math="1" /> | **U** | Bu Fitri shows how to tie seedlings to bamboo stakes | Planting day (<Highlight>In March</Highlight>). |
| <InlineMath math="2" /> | **Q** | A flood tears most stakes out of Zone C | Two months later (<Highlight>In May, a flood came down the creek</Highlight>). |
| <InlineMath math="3" /> | **S** | Students replant <InlineMath math="50" /> seedlings | <Highlight>Two weeks after the flood</Highlight> (still May). |
| <InlineMath math="4" /> | **P** | Students wade back to count the mangroves | <Highlight>In the last week of June</Highlight>. |
| <InlineMath math="5" /> | **T** | Newspaper runs its survival-rate headline | <Highlight>A week after the count</Highlight>. |
| <InlineMath math="6" /> | **R** | Narrator's letter appears in the newspaper | Last event (<Highlight>appeared the following Saturday</Highlight>). |

## Why the other options fail

- **P, U, Q, S, T, R** follows the writing order (opening with June count P) rather than real time.
- **U, Q, P, S, T, R** puts replanting S after the June count P instead of two weeks after the May flood.
- **U, S, Q, P, T, R** puts replanting S before the flood Q that triggered it.
- **U, Q, S, P, R, T** puts the reply letter R before the newspaper headline T it answered.

# Answer

The events happened in the chronological order **U, Q, S, P, T, R**.
