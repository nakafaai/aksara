# Ditanyakan

# Penyelesaian

Bayangkan diagram Venn dengan dua lingkaran (Teks <InlineMath math="1" /> dan Teks <InlineMath math="2" />). Sebuah poin hanya sah jika **dinyatakan atau diimplikasikan oleh Teks <InlineMath math="1" /> sekaligus disetujui secara terbuka di Teks <InlineMath math="2" />**.
