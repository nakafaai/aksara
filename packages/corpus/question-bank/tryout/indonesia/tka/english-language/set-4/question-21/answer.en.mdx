# Asked

# Solution

Ask two questions in order: **does either text actually make this claim**? If yes, **is it reported as a measurable finding (fact) or a value judgement (opinion)**? Watch statement <InlineMath math="2" />, which swaps "spent" for "set".

> Swapping a single key verb ("spent" to "set") or inventing a guaranteed cure neither writer promises pushes a statement into Not stated.
