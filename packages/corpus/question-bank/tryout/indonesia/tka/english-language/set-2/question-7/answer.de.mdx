Zur gesamten Entwicklung gehören **Verbesserungen und verbleibende Hindernisse**, die wiederholte Tests sichtbar machen.

Die Nacherzählung folgt einer klaren Entwicklung: Ein erster Test deckt Hindernisse auf, die Klasse überarbeitet den Weg, Regen schafft eine weitere Schwierigkeit, und anschließend werden Verbesserungen wie offene Probleme festgehalten. Die Zusammenfassung muss diese Abfolge und die ehrliche Auswertung erfassen. Eine Antwort, die nur den Start, das Wetter oder einen einzelnen Erfolg nennt, ist zu eng.
