# Given

The gardening club tested **packet A** (sealed indoor jar, seven-day total <InlineMath math="42/50 = 84\%" />) against **packet B** (paper bag in the tool shed, seven-day total <InlineMath math="24/50 = 48\%" />) indoors **at room temperature**.

# Asked

Which claims about the club's test require information that neither the text nor the table provides.

# Solution

Act like a strict science fair judge. For each claim, ask one direct question: **do the text and table settle this already**, or does proving it require missing facts such as shed dampness, packet age, or cold-soil behaviour.

> A difference in outcomes between two packets never proves a specific cause unless the text confirms that condition and rules out other factors.

## Claims that need missing information

- **Plants from packet A will be healthier than those from packet B** needs missing data because the test measures sprouting rate only, never later plant health.
- **Packet B lost viability because the tool shed was damp** needs missing data because the text never states the shed was damp or rules out other differences like seed age.
- **Packet A would sprout at the same rate in a cold spring** needs missing data because paragraph two notes the trays stayed <Highlight>at room temperature</Highlight>, saying nothing about cold soil.

## Why the other two options are already settled

- **Packet A germinated at a higher rate than packet B** is settled straight from the table: packet A reached <InlineMath math="42/50 = 84\%" /> versus packet B's <InlineMath math="24/50 = 48\%" />.
- **Under the club's rule, packet B should be replaced** is settled by paragraph five because <InlineMath math="48\%" /> falls below <InlineMath math="50\%" />, triggering <Highlight>buy new seed</Highlight>.

# Answer

**The claims needing information not provided by the text are that packet A's plants will be healthier, that packet B failed because the tool shed was damp, and that packet A would sprout at the same rate in a cold spring**.
