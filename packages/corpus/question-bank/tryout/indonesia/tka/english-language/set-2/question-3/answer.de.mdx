Ordne jede Einrichtung dem **Problem zu, das sie löst**, nicht bloß ihrem Standort im Boot.

| Einrichtung | Problem | Beleg |
|---|---|---|
| Elastic shelf cords | Movement | Sie halten Bücher bei unruhigem Wasser auf den Regalen. |
| Sealed book boxes | Moisture | Sie schützen Papier bei starkem Regen. |
| A folding ramp with raised edges | Access | Sie verbindet Deck und Anlegestelle, damit Besucher einsteigen können. |
