# Gegeben

Die Geschichte vom gelben Regenschirm enthält gewöhnliche Wetterpannen und mehrere rätselhafte Momente von Montag bis Freitag, darunter **eine verbogene Strebe, die plötzlich wieder gerade ist, obwohl niemand sie berührt hat**.

# Gesucht

Welches Ereignis in der Geschichte lässt sich durch nichts in der gewöhnlichen Welt erklären.

# Lösung

Spiel Detektiv und suche für jedes seltsame Ereignis eine normale Erklärung. Manches wirkt merkwürdig, lässt aber **noch eine menschliche Erklärung zu**, während genau ein Ereignis **jede normale Ursache ausdrücklich ausschließt**.

> Ein ungewöhnlicher Vorfall bleibt realistisch, solange ein unbemerkter Mensch ihn ausgelöst haben könnte, doch ein verbogener Schirm repariert sich nicht unberührt von selbst.

## Warum die wieder gerade Strebe unerklärlich bleibt

- Im zweiten Absatz verbiegt eine Windböe auf der Brücke eine Strebe nach hinten.
- Im dritten Absatz heißt es, als Pak Darmo den Schirm öffnet: <Highlight>the bent rib was straight again. Nobody had touched it</Highlight>. Eine verbogene Strebe richtet sich nicht selbst auf, und der Satz schließt menschliche Hilfe ausdrücklich aus.

## Warum die anderen vier Ereignisse erklärbar sind

- **Der Schirm an Bu Saris Wagen** könnte unbemerkt aufgehängt worden sein, denn der Text sagt nur <Highlight>she was sure</Highlight>.
- **Der bereits geöffnete Schirm an der Haltestelle** könnte von einem Passanten an einer unbeaufsichtigten Bushaltestelle so zurückgelassen worden sein.
- **Eine Windböe verbiegt eine Strebe** passiert bei starkem Wind ganz gewöhnlich.
- **Wulans umgestülpter Schirm** ist im stärksten Regen der Woche völlig normal.

# Antwort

Das einzige im gewöhnlichen Alltag unerklärliche Ereignis ist, dass **die verbogene Strebe beim Öffnen durch Pak Darmo wieder gerade ist, obwohl niemand den Schirm berührt hat**.
