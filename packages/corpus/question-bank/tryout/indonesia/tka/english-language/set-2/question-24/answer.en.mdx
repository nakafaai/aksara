# Given

The observatory passage walks **floor by floor** through the Bukit Kenanga building (ground-floor workshop, first-floor tables, second-floor vault, and top dome), showing how original features shape today's library.

# Asked

Which numbered statements accurately describe the writer's purpose in the text.

# Solution

Think of a writer's purpose like an umbrella that must **cover all six paragraphs neatly** without stretching beyond the text into universal advice or shrinking down to a single background line.

> An accurate purpose statement matches the scope of the entire passage, neither preaching beyond what is written nor elevating one brief detail into the main goal.

## Checking each purpose statement

| Statement | Verdict | Evaluation across the whole passage |
| --- | --- | --- |
| I | Accurate | Paragraph one sets the frame <Highlight>the building has been the town library, and almost every floor now does something its builders never planned</Highlight>, and each floor shows how it serves library needs. |
| II | Inaccurate | Overreaches because the passage describes one specific building and never argues what should happen to other observatories. |
| III | Accurate | Original architecture shapes current use throughout: wide doors aid wheelchairs (paragraph two), windowless walls protect archives (paragraph four), and the dome slit serves sky-watchers (paragraph six). |
| IV | Inaccurate | Far too narrow because astronomers appear only briefly in paragraph three as background for the long tables. |

## Why the other options fail

- **Options including II** turn a description of one landmark into a general campaign about every observatory.
- **Options including IV** mistake a passing detail in paragraph three for the goal of the entire text.
- **I only** misses purpose III, the recurring link between original design and present-day use.

# Answer

The statements describing the writer's purpose are **I and III only**.
