# Diketahui

Catatan kebun menampilkan **lima tumpukan kompos (A sampai E)** tanpa masalah bau busuk. Panduan memberi tiga aturan usia dan suhu:
- Selama <InlineMath math="6" /> minggu pertama: balikkan jika pusat turun di bawah <InlineMath math="45^\circ\text{C}" />.
- Setelah <InlineMath math="6" /> minggu: berhenti membalikkan dan biarkan dingin.
- Siap pakai hanya jika **semua tiga syarat terpenuhi**: usia minimal <InlineMath math="8" /> minggu, suhu pusat berselisih maksimal <InlineMath math="5^\circ\text{C}" /> dari udara pada **dua pemeriksaan berturut-turut**, dan berbau tanah.

# Ditanyakan

Tindakan mana (**Siap dipakai**, **Balik sekarang**, atau **Biarkan saja**) yang tepat untuk setiap tumpukan hari ini.

# Penyelesaian

Bayangkan usia tumpukan sebagai **jalur tiga gerbang**: usia <InlineMath math="\le 6" /> minggu memakai aturan pembalikan, usia <InlineMath math="> 6" /> minggu berhenti dibalik, dan usia <InlineMath math="\ge 8" /> minggu diuji dengan ketiga syarat siap pakai sekaligus.

> Untuk status siap pakai, satu kali pembacaan suhu hari ini saja belum cukup: syarat suhu harus lolos pada dua pemeriksaan berturut-turut.
