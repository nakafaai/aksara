# Gegeben

Sechs Aussagen über die Selaras-Werkzeugbibliothek sind einzuordnen in **Gestützt** (im Text belegt oder rechnerisch folgend), **Widerlegt** (im direkten Widerspruch zum Text) oder **Nicht angegeben** (vom Text offen gelassen).

# Gesucht

Welche der drei Kategorien jeweils auf die sechs Aussagen zutrifft.

# Lösung

Stell dir vor, du prüfst Fakten mit drei Stempeln. Trenne sauber zwischen **Widerlegt** (der Text sagt das Gegenteil) und **Nicht angegeben** (der Text nennt den Wert schlicht nicht).

> Eine höhere Kaution deutet zwar auf wertvollere Geräte hin, ersetzt aber keine ausdrückliche Angabe zu Wiederbeschaffungspreisen.
