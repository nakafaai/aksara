# Given

Uncle Bonar opens the student's unrepaired radio and points out a **loose wire**, explaining that its end touches its terminal **only when the set is tipped forward**.

# Asked

Based on Uncle's explanation, which numbered predictions about the switched-on, unrepaired radio are reasonable.

# Solution

Picture a simple tilt switch inside the radio case. The circuit closes **when the box tilts forward** and opens in every other position (flat or tilted back). Apply **that single physical rule** to all four predictions.

> The strict limiter *only when* splits every position cleanly in two: tipped forward plays, while flat or backwards stays silent.

## Checking each prediction

| Prediction | Verdict | Match with Uncle's loose-wire rule |
| --- | --- | --- |
| I | Reasonable | Kept tilted forward on a shelf, the wire stays in contact because <Highlight>It touched its terminal, he explained, only when the set was tipped forward</Highlight>, so it keeps playing. |
| II | Reasonable | Resting flat on a table is not tipped forward, so the circuit stays open and the radio stays silent. |
| III | Unreasonable | Calling the narrator's hands <Highlight>magic hands</Highlight> was just the student's joke. Touching a flat radio does not tilt it. |
| IV | Unreasonable | Saying <Highlight>only when the set was tipped forward</Highlight> rules out every other angle, including backwards. |

## Why the other options fail

- **I only** overlooks the direct flip side in II (flat means silent).
- **Options including III or IV** violate the strict rule *only when the set was tipped forward*.

# Answer

The reasonable predictions about the student's radio are **I and II only**.
