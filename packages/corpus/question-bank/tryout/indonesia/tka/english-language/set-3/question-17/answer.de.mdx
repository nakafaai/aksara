Die Gliederung muss **Reihenfolge und Zweck** der Schritte bewahren.

| Schritt | Handlung im Text |
| --- | --- |
| Focus and prepare | Eine Frage zeigen, Begriffe klären und stilles Schreiben ermöglichen. |
| Exchange and restate | Den vorherigen Gedanken korrekt wiedergeben, bevor ein Beitrag hinzukommt. |
| Widen participation | Weitere Stimmen einladen und das Recht auszusetzen respektieren. |
| Revise | Notieren, ob sich die Ansicht verändert, verstärkt oder weitere Informationen braucht. |
| Review the process | Genauigkeit, Belege und faire Einladungen prüfen. |

Eine Rangliste oder die Wahl eines Siegers verändert das Ziel. Der Text schützt den Zugang zum Gespräch, statt die schnellste Antwort zu belohnen.
