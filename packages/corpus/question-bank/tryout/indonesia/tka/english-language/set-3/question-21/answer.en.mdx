# Given

The opinion piece **Dim the lights after midnight** mixes **verifiable claims about the world** with **value judgements and verdicts** from the writer about budget savings and street safety.

# Asked

Which statements from the text are **opinions** rather than facts (choose all that apply).

# Solution

Use one clean test: **could you check the claim against the world by counting or observing**? If yes, it is a **fact** (even if the article provides no proof for it). If it expresses a value judgement such as "too large", "matters", or "not a gamble", it is an **opinion**.

> An unproved claim about observable behaviour is still a factual claim, whereas a value judgement remains an opinion no count can settle.

## Sorting facts and opinions

| Statement from the text | Category | Reason |
| --- | --- | --- |
| <Highlight>The people the union speaks for walk mostly along those roads</Highlight> | **Fact** | A testable claim about where workers walk, verifiable by observation even without evidence in the text. |
| <Highlight>The savings, about <InlineMath math="\text{Rp}800" /> million a year, are too large to ignore</Highlight> | **Opinion** | The figure can be checked, yet calling it *too large to ignore* is a value judgement. |
| <Highlight>Residential streets carry <InlineMath math="40\%" /> of the lights</Highlight> | **Fact** | Streetlights can be counted directly to verify the share. |
| <Highlight>That feeling matters</Highlight> | **Opinion** | Declaring what matters states a value, not a measurable fact. |
| <Highlight>Dimming is not a gamble</Highlight> | **Opinion** | Expresses the writer's persuasive verdict on risk. |

# Answer

The statements that are opinions rather than facts are:
- **The savings, about <InlineMath math="\text{Rp}800" /> million a year, are too large to ignore**.
- **That feeling matters**.
- **Dimming is not a gamble**.
