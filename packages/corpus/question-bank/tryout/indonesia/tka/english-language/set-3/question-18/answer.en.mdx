# Given

The **Fixing problems** section pairs a troubleshooting table (ammonia smell calls for adding browns, while sour, rotten, and slimy calls for turning and adding browns) with an **opening exception** stating that fixes apply at any stage.

# Asked

Which numbered statements about the guide's fixes are true.

# Solution

Think of the troubleshooting table as emergency first aid. Read **the first two table rows alongside the sentence right above the table** so you catch the single exception to the six-week no-turning rule.

> Always read the framing sentence directly above a rule table, because it often carries the exact exception that overrides an earlier general rule.

## Checking each statement about the fixes

| Statement | Verdict | Direct evidence in the guide |
| --- | --- | --- |
| I | True | Ammonia calls for <Highlight>Add browns</Highlight>, and slimy calls for <Highlight>Turn the heap and add browns</Highlight>. Both receive browns. |
| II | True | Between those two rows, only the slimy heap's fix includes turning the heap. |
| III | True | The sentence above the table states <Highlight>These fixes apply at any stage, and a turn made to fix a problem is the one exception to the six-week rule</Highlight>, so a slimy heap past six weeks may still be turned. |
| IV | False | Ammonia is caused by <Highlight>Too many greens</Highlight>, so adding greens worsens it. Greens fix a cold, damp, odourless heap instead. |

## Why the other options fail

- **I, II, III, and IV** misassigns adding greens to an ammonia-smelling heap.
- **I and II only**, **I only**, and **II and III only** omit a clearly verified row detail or the six-week exception.

# Answer

The true statements about the guide's fixes are **I, II, and III only**.
