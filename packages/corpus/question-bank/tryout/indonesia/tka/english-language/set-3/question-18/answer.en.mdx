Read the two rows of the problem table together with the sentence above it: "These fixes apply at any stage, and a turn made to fix a problem is the one exception to the six-week rule."

- **I is true**. Ammonia: "Add browns". Sour, rotten and slimy: "Turn the heap and add browns". Both get browns.
- **II is true**. Only the slimy heap's fix includes a turn.
- **III is true**. A turn made to fix a problem is "the one exception to the six-week rule", so it's allowed even after six weeks.
- IV is false. An ammonia smell means "Too many greens", so adding greens would make it worse. Greens are the fix for a cold, damp heap with no smell.

So the true statements are I, II and III only.
