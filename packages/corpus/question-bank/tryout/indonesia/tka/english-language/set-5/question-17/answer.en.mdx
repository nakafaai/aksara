# Given

In another drill, **Staircase A is blocked** and no student is away from class. First-floor classes (**11A to 11D**) join second-floor classes (**12A to 12C**) on **Staircase B** in **alphabetical order** (11A, 11B, 11C, 11D, 12A, 12B, 12C), while ground-floor **10C** uses an outside door in **under <InlineMath math="4" /> minutes**.

# Asked

When each of the six classes (11B, 11C, 11D, 12A, 12B, 10C) reaches the field: **Within <InlineMath math="8" /> minutes**, **After <InlineMath math="8" /> minutes but within <InlineMath math="12" />**, or **After <InlineMath math="12" /> minutes**.

# Solution

Apply the strict alphabetical rule even on Staircase B: **11A through 11D still descend ahead of 12A through 12C**! The class in queue position <InlineMath math="n" /> clears the stairs at <InlineMath math="2n" /> minutes and reaches the field at <InlineMath math="2n + 2" /> minutes.

> "Within <InlineMath math="8" /> minutes" includes exactly <InlineMath math="8" /> minutes, and "within <InlineMath math="12" />" includes exactly <InlineMath math="12" /> minutes.

## Computing arrival times for all six classes

Rule <InlineMath math="4" /> sets <Highlight>Classes on the same staircase go down in alphabetical order of class name</Highlight>, and Rule <InlineMath math="2" /> gives ground-floor classes <Highlight>in under <InlineMath math="4" /> minutes</Highlight>.

| Class | Route and queue place (<InlineMath math="n" />) | Field arrival time | Time bracket |
| --- | --- | --- | --- |
| Class 11B | Staircase B, <InlineMath math="2" />nd | <InlineMath math="6" /> minutes (<InlineMath math="2 \times 2 + 2" />) | **Within <InlineMath math="8" /> minutes** |
| Class 11C | Staircase B, <InlineMath math="3" />rd | <InlineMath math="8" /> minutes (<InlineMath math="3 \times 2 + 2" />), exact boundary counts | **Within <InlineMath math="8" /> minutes** |
| Class 11D | Staircase B, <InlineMath math="4" />th | <InlineMath math="10" /> minutes (<InlineMath math="4 \times 2 + 2" />) | **After <InlineMath math="8" /> minutes but within <InlineMath math="12" />** |
| Class 12A | Staircase B, <InlineMath math="5" />th (after all 11s) | <InlineMath math="12" /> minutes (<InlineMath math="5 \times 2 + 2" />), exact boundary counts | **After <InlineMath math="8" /> minutes but within <InlineMath math="12" />** |
| Class 12B | Staircase B, <InlineMath math="6" />th | <InlineMath math="14" /> minutes (<InlineMath math="6 \times 2 + 2" />) | **After <InlineMath math="12" /> minutes** |
| Class 10C | Ground-floor outside door | Under <InlineMath math="4" /> minutes | **Within <InlineMath math="8" /> minutes** |

# Answer

- **Within <InlineMath math="8" /> minutes**: **Class 11B**, **Class 11C**, and **Class 10C**.
- **After <InlineMath math="8" /> minutes but within <InlineMath math="12" />**: **Class 11D** and **Class 12A**.
- **After <InlineMath math="12" /> minutes**: **Class 12B**.
