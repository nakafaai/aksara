# Diketahui

Saat kedua tangga terbuka dan tidak ada siswa terpisah, **Class 11C** (lantai satu) mencapai lapangan **<InlineMath math="8" /> menit** setelah bel. Tersedia lima aturan bernomor Romawi (I sampai V) dari panduan evakuasi.

# Ditanyakan

Aturan bernomor Romawi mana saja yang **diperlukan untuk menghitung waktu <InlineMath math="8" /> menit** bagi Class 11C.

# Penyelesaian

Bangun ulang hitungan <InlineMath math="8" /> menit untuk Class 11C dari nol lalu **centang hanya aturan yang sungguh terpakai di rumus**: tangga mana yang dipakai (I), urutan antreannya (II), lama tiap kelas di tangga (III), dan lama jalan kaki ke lapangan (IV). Aturan kelas lantai dasar (V) tidak ikut berperan.

> Untuk soal aturan prasyarat, uji apakah hitungan masih bisa diselesaikan bila satu aturan dihapus: jika buntu, aturan itu wajib ikut.

## Melacak peran setiap aturan dalam hitungan waktu

Untuk Class 11C di lantai satu, **hitungan lengkapnya** menggunakan empat aturan berurutan (<Highlight>First-floor classes use Staircase A</Highlight>, <Highlight>alphabetical order of class name</Highlight>, <Highlight><InlineMath math="2" /> minutes to clear a staircase</Highlight>, dan <Highlight>walk to the field takes <InlineMath math="2" /> minutes</Highlight>):

<BlockMath math="3\text{ kelas (11A, 11B, 11C)} \times 2\text{ menit} + 2\text{ menit jalan} = 8\text{ menit}" />

| Aturan | Diperlukan? | Peran dalam hitungan Class 11C |
| --- | --- | --- |
| I | **Ya** | Menentukan bahwa Class 11C masuk antrean Tangga A bersama 11A, 11B, dan 11D. |
| II | **Ya** | Menempatkan Class 11C pada urutan ke-<InlineMath math="3" /> di belakang 11A dan 11B. |
| III | **Ya** | Memberi durasi <InlineMath math="3 \times 2 = 6" /> menit hingga Class 11C keluar dari tangga. |
| IV | **Ya** | Menambahkan <InlineMath math="2" /> menit jalan kaki hingga tiba di lapangan pada menit ke-<InlineMath math="8" />. |
| V | Tidak | Hanya mengatur kelas lantai dasar (10A sampai 10C) yang tidak pernah memakai Tangga A. |

## Mengapa kombinasi pilihan lain salah

- **Pilihan tanpa I, II, atau IV** memutus satu mata rantai wajib dalam hitungan <InlineMath math="8" /> menit.
- **Pilihan yang memuat V** menyertakan aturan lantai dasar yang tidak dipakai menghitung Class 11C.

# Jawaban

Aturan yang diperlukan untuk menghitung waktu Class 11C adalah **I, II, III, dan IV saja**.
