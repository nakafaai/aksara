Der letzte Absatz macht drei Schritte. Zuerst wird die Gegenmeinung genannt, *phones help them relax after a hard morning*. Dann wird sie anerkannt, *This is fair*. Schließlich wird der Vorschlag eingegrenzt, *the rule should cover only the thirty-minute lunch break*. Die beste Zusammenfassung lautet also: Ein **Gegenargument wird anerkannt, die Regel aber** auf die Mittagspause **beschränkt**.

- Das Bedürfnis nach Entspannung wird nicht abgelehnt, sondern als *fair* bezeichnet.
- Eine Regel für den ganzen Tag wird klar ausgeschlossen.
- Im letzten Absatz stehen keine neuen Umfrageergebnisse.
