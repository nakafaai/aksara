# Given

With both staircases open and all students present, **Class 11C** (first floor) reaches the field **<InlineMath math="8" /> minutes** after the bell. Five rules from the procedure (I through V) are listed.

# Asked

Which numbered rules are **needed to work out that <InlineMath math="8" />-minute time** for Class 11C.

# Solution

Rebuild the <InlineMath math="8" />-minute calculation for Class 11C step by step and **keep only the rules the math actually uses**: which staircase it takes (I), its queue position (II), minutes per class on the stairs (III), and the walk to the field (IV). Ground-floor exits (V) never enter the calculation.

> Test necessity by removing one rule at a time: if the <InlineMath math="8" />-minute calculation can no longer be completed, that rule is essential.

## Tracing every rule in the timing calculation

For first-floor Class 11C, **the full calculation** relies on four rules in sequence (<Highlight>First-floor classes use Staircase A</Highlight>, <Highlight>alphabetical order of class name</Highlight>, <Highlight><InlineMath math="2" /> minutes to clear a staircase</Highlight>, and <Highlight>walk to the field takes <InlineMath math="2" /> minutes</Highlight>):

<BlockMath math="3\text{ classes (11A, 11B, 11C)} \times 2\text{ min} + 2\text{ min walk} = 8\text{ minutes}" />

| Rule | Needed? | Role in Class 11C's timing |
| --- | --- | --- |
| I | **Yes** | Assigns Class 11C to Staircase A alongside 11A, 11B, and 11D. |
| II | **Yes** | Places Class 11C <InlineMath math="3" />rd in line behind 11A and 11B. |
| III | **Yes** | Gives <InlineMath math="6" /> minutes to clear the staircase (<InlineMath math="3" /> classes at <InlineMath math="2" /> minutes each). |
| IV | **Yes** | Adds the <InlineMath math="2" />-minute walk to reach <InlineMath math="8" /> minutes total. |
| V | No | Covers ground-floor classes (10A to 10C), which never use Staircase A. |

## Why the other options fail

- **Options dropping I, II, or IV** leave a missing link so the <InlineMath math="8" />-minute time cannot be derived.
- **I, II, III, IV, and V** brings in an irrelevant rule about ground-floor exits.

# Answer

The rules needed to work out Class 11C's time are **I, II, III, and IV only**.
