# Given

Bu Wening's weighing rule says to **weigh the empty basket first**, weigh it full, and record the difference. Lina followed it on the first Friday, whereas Dani and the narrator switched to a bigger basket from the second Friday without ever weighing it empty.

# Asked

Which Roman-numeral statements the account shows about Bu Wening's rule.

# Solution

Separate the **soundness of the rule** from **skipping the rule**: subtracting the empty basket's weight works for any basket size whenever students actually perform the step.

> The error came from skipping the empty-basket step after changing baskets, never from a flaw in Bu Wening's rule itself.

## Evaluating each claim about the rule

| Statement | Shown? | Evidence from passage |
| --- | --- | --- |
| I | **Yes** | Following <Highlight>weigh the basket empty first, then weigh it full, and write down the difference</Highlight> removes basket weight every Friday. |
| II | **Yes** | The error started when switching baskets on the second Friday (<Highlight>used a bigger basket, and we never weighed it empty</Highlight>). |
| III | No | The rule works for big baskets too, and the students simply stopped following it. |
| IV | **Yes** | Only Lina's first-Friday entry excluded the basket, so only that weight needs no correction. |

## Why the other options fail

- **Options with III** blame the rule for a step the students skipped.
- **Options without IV** miss that Lina's first-Friday record was already accurate.
- **Options without I** ignore that obeying the rule every week would have produced the exact harvest total.

# Answer

The account shows **I, II, and IV only** about Bu Wening's rule.
