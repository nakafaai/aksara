Kilat, a prepaid phone company, sells three data packages.

| Mingguan | <InlineMath math="\text{Rp}25{,}000" /> | <InlineMath math="5" /> GB | <InlineMath math="5" /> GB | <InlineMath math="7" /> days |
| Bulanan | <InlineMath math="\text{Rp}80{,}000" /> | <InlineMath math="20" /> GB | <InlineMath math="20" /> GB | <InlineMath math="30" /> days |

Night data can be used only from 0:00 to 6:00; at any other time the phone uses daytime data. A package starts the moment it is bought and ends at 23:59 on its last day, counting the day of purchase as the first day.

Data that is left when a package ends is lost. There is one exception: if you buy the same package again before the old one ends, the old package closes at once and its leftover daytime data is added to the new one. Leftover night data is never carried over. If you hold two different packages at the same time, the phone uses the one that ends sooner first.
