# Given

Five events (P, Q, R, S, T) from the month-long chili harvest are listed out of order:
- **P**: the last weight including a basket is written down.
- **Q**: the only correct weight is written down.
- **R**: the class promises the canteen <InlineMath math="8" /> kg of chili.
- **S**: Dani and the narrator weigh their first full basket.
- **T**: Bu Wening checks the baskets.

# Asked

The chronological order in which these five events happened.

# Solution

Place each event along the real calendar from the first Friday to packing day, separating when things happened from when the final paragraph reveals them.

> The final paragraph looks back to explain earlier Fridays, so true chronological order follows the four harvests before the promise and final check.

## Building the chronological timeline

| Step | Event | Time and textual evidence |
| --- | --- | --- |
| First | **Q** | First Friday when Lina followed the rule (<Highlight>On the first Friday, Lina had used the small basket and weighed it empty</Highlight>). |
| Second | **S** | Second Friday when Dani and the narrator switched baskets (<Highlight>From the second Friday on, the harvest was growing, so Dani and I used a bigger basket</Highlight>). |
| Third | **P** | Fourth Friday when the final basket-included figure (<InlineMath math="2.6" /> kg) was recorded. |
| Fourth | **R** | Month end after summing the notebook (<Highlight>promised the canteen 8 kg of chili</Highlight>). |
| Fifth | **T** | Packing day after discovering only <InlineMath math="6.8" /> kg, when <Highlight>Bu Wening checked the book and the baskets</Highlight>. |

## Why the other options fail

- **Q, P, S, R, T** puts the fourth Friday's weight before the second Friday's first big-basket weighing.
- **S, Q, P, R, T** places the second Friday before Lina's first Friday.
- **Q, S, R, P, T** puts the month-end <InlineMath math="8" /> kg promise before the fourth Friday was even weighed.
- **Q, S, P, T, R** puts Bu Wening's investigation before the promise that triggered the packing shortage.

# Answer

The events happened in the order **Q, S, P, R, T**.
