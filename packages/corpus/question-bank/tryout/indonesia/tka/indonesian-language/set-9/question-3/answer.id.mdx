Paragraf kedua dibuka dengan kalimat utama *Proses pembuatannya memerlukan kehati-hatian*. Kalimat berikutnya merinci tahapnya: **menyaring**, **merendam dengan arang**, **mencampur dengan soda api** sambil memakai alat pelindung, **mengaduk dan mencetak**, lalu **mendiamkan sekitar empat minggu**. Jadi, gagasan utamanya adalah pembuatan sabun melalui beberapa tahap yang menuntut kehati-hatian.

- Jelantah harus disaring, direndam, dan dicampur soda api lebih dulu.
- Sabun didiamkan sekitar **empat minggu** sebelum aman dipakai.
- Arang dipakai untuk **mengurangi bau**, bukan mengeraskan sabun.
- Teks justru menyebut larutan soda api dapat melukai kulit.
