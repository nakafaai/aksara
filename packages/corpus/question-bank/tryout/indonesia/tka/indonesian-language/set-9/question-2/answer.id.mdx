# Diketahui

Pada paragraf kedua teks **sabun dari minyak jelantah**, minyak dicampur dengan larutan soda api. Teks menegaskan bahwa **larutan ini panas dan dapat melukai kulit** sehingga pembuatnya **wajib memakai sarung tangan, kacamata pelindung, dan masker**.

# Ditanyakan

Hubungan antara kewajiban memakai sarung tangan, kacamata pelindung, dan masker dengan larutan soda api.

# Penyelesaian

Kalau kita mengangkat panci yang baru mendidih, kita memakai **cempal tebal agar tangan tidak melepuh**. Di sini persis sama: larutan soda api bisa **membakar atau melukai kulit**, jadi alat pelindung wajib dipakai demi keselamatan.

> Kata hubung *sehingga* selalu menandai sebab di bagian depan dan akibat atau tindakan pencegahan di bagian belakang.

## Membaca hubungan sebab dan akibat pada paragraf kedua

Paragraf kedua menulis kalimat utuhnya dengan sangat jelas: <Highlight>Larutan ini panas dan dapat melukai kulit sehingga pembuatnya wajib memakai sarung tangan, kacamata pelindung, dan masker</Highlight>. Bagian **panas dan dapat melukai kulit** bertindak sebagai sebab.

Bagian sesudah kata *sehingga* adalah akibat langsungnya, yaitu **kewajiban mengenakan alat pelindung** agar tubuh terlindungi dari percikan dan panas.

## Mengapa empat pilihan lain keliru

- **Agar sabun lebih wangi** keliru karena teks tidak pernah mengaitkan alat pelindung dengan **aroma sabun**.
- **Dibuat dari sarung tangan bekas** keliru karena sarung tangan adalah pelindung tangan, bukan bahan campuran larutan.
- **Karena jelantah berbau tidak sedap** keliru karena bau jelantah dikurangi memakai **rendaman arang**, bukan alat pelindung.
- **Tidak berhubungan** keliru karena kata hubung *sehingga* langsung mengikat sifat soda api dengan kewajiban alat pelindung.

# Jawaban

Hubungannya adalah **alat pelindung dipakai karena larutan soda api panas dan dapat melukai kulit**.
