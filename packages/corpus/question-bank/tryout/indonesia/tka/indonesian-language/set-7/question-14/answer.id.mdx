# Diketahui

Paragraf keempat melaporkan survei kecil Bu Anisa di dua kelas: **<InlineMath math="25" /> dari <InlineMath math="64" /> siswa** mengaku membaca di rumah minimal dua kali seminggu. Namun kalimat terakhir menegaskan **angka itu tidak pernah dicatat sebelum program dimulai** sehingga belum dapat dibandingkan.

# Ditanyakan

Gagasan utama yang merangkum keseluruhan isi paragraf keempat.

# Penyelesaian

Bayangkan kamu mengukur tinggi tanaman hari ini dan hasilnya <InlineMath math="25" /> sentimeter, tetapi kamu lupa mencatat tingginya bulan lalu. Kamu punya **gambaran awal sekarang**, namun **belum bisa memastikan berapa kenaikannya**. Kedua sisi itulah gagasan utama paragraf keempat.

> Gagasan utama paragraf survei yang menyertakan keterbatasan data harus merangkum angka temuan sekaligus batas pembandingannya.

## Menyatukan hasil survei dan keterbatasan pembandingnya

Kalimat awal dan tengah memberi gambaran awal: <Highlight>Dari <InlineMath math="64" /> siswa, <InlineMath math="25" /> orang mengaku membaca di rumah setidaknya dua kali seminggu</Highlight>. Kalimat penutup mengunci batasnya: <Highlight>Sebelum program dimulai, angka itu tidak pernah dicatat sehingga belum dapat dibandingkan</Highlight>.

Maka gagasan utamanya adalah **survei awal menunjukkan sebagian siswa membaca di rumah, tetapi hasilnya belum dapat dibandingkan dengan keadaan sebelum program**.

## Mengapa empat pilihan lain keliru

- **Semua siswa membaca di rumah** jauh melampaui data <InlineMath math="25" /> dari <InlineMath math="64" /> siswa (kurang dari separuh).
- **Membuktikan program berhasil** tidak sah tanpa angka pembanding sebelum program.
- **Menyurvei seluruh siswa** salah karena survei hanya dilakukan di *dua kelas*.
- **Peminjaman turun sesudah survei** tidak pernah disebut dalam teks.
