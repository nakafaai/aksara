Gagasan utama harus menyatukan semua paragraf. Paragraf pertama menyebut kemudahan sensor murah, paragraf kedua kelemahannya, paragraf ketiga cara mengatasinya, dan paragraf keempat menyimpulkan bahwa sensor murah **melengkapi** stasiun resmi dan dapat dipasang di banyak sekolah. Jadi, gagasan utamanya adalah sensor murah dapat **memperluas pemantauan** asalkan keterbatasannya diatasi.

- Teks tidak menyebut sensor murah lebih akurat. Sensor itu justru perlu dikoreksi dengan stasiun resmi.
- Udara lembap tidak menambah debu. Butir air hanya **ikut terhitung** sebagai partikel.
- Tidak ada kewajiban membeli stasiun resmi.
- Harga hanya rincian di paragraf pertama.
