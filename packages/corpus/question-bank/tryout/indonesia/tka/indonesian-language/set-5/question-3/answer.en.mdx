# Given

The **Sukamaju Clinic Queue** report unfolds in **three clean sections**: reported wait-time results (paragraph two), patient complaints (paragraph three), and clinic responses (paragraph four).

# Asked

How to assign four statements to reported results, complaints, or clinic response.

# Solution

Think of a review of **a new library checkout system**: announced stats are reported results, user headaches are complaints, and the fixes staff introduce are the response. Matching each statement to its paragraph sorts all four immediately.

> In text-section matrices, classify each detail by whether it states an announced metric, a user obstacle, or an official fix.
