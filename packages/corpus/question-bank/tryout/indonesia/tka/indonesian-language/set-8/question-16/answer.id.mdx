- Panggilan berhasil hampir satu jam, jadi tidak ada alasan menjual ponsel.
- Nenek Sumi justru bersiap dengan kebaya terbaik dan senang bisa melihat Laras.
- Tidak ada tanda Arif meminta bayaran. Kerupuk itu pemberian Nenek Sumi.
- Kertas itu masih berguna. Nenek Sumi meliriknya saat menerima panggilan.
