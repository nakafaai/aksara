# Diketahui

Saat Bagas menawarinya posisi koordinator kebersihan di paragraf kelima, Kirana memandang kertas programnya lalu mengingat **alasan tulus** di balik malam-malam ketika ia menyusun gagasan kebersihan kantin itu.

# Ditanyakan

Bukti paling kuat bahwa Kirana menyusun programnya bukan semata-mata untuk menang pemilihan.

# Penyelesaian

Bayangkan seseorang merancang program taman sekolah bukan agar dipilih jadi ketua, melainkan karena ia sungguh prihatin melihat halaman sekolah gersang. **Kalimat yang langsung mengungkap niat tulus di balik penyusunan program** itulah bukti terkuatnya.

> Bukti motivasi batin tokoh harus menunjuk langsung alasan yang mendorongnya merancang gagasan, bukan sekadar usaha kampanye atau hasil suara.

## Menemukan bukti motivasi langsung di paragraf kelima

Paragraf kelima menuliskan isi hati Kirana secara gamblang: <Highlight>Ia ingat malam-malam ketika menyusun program itu, bukan untuk menang, melainkan karena ia benar-benar kesal melihat sampah di bawah meja kantin</Highlight>. Ia sungguh peduli pada kebersihan kantin, bukan sekadar mengejar jabatan.

Bukti paling kuat adalah **Kirana ingat ia menyusun program itu karena benar-benar kesal melihat sampah di bawah meja kantin**.

## Mengapa empat pilihan lain bukan bukti motivasi program

- **Berkampanye dua minggu** menunjukkan kerja keras mengejar suara, bukan alasan batin menyusun program.
- **Memperoleh <InlineMath math="287" /> suara** hanyalah hasil pemungutan suara.
- **Ikut bertepuk tangan** menunjukkan sikap sportif saat kalah.
- **Menggenggam ujung rok** menggambarkan rasa gugup menunggu pengumuman.
