# Given

In paragraph one of **Audio Labels**, the team explains they want to test whether audio helps visitors understand exhibits because visit length alone falls short. In paragraph five's follow-up test, **both groups answer the exact same comprehension questions**.

# Asked

Why the same comprehension questions are given to both visitor groups.

# Solution

Imagine testing whether **flashcards** help classmates learn vocabulary better than plain lists. For a fair comparison, both groups have to take the **exact same quiz** at the end.

> Comparing two study conditions objectively requires scoring both groups with one shared, identical outcome measure.

## Linking the opening goal to the next test

Paragraph one defines the real goal: <Highlight>Tim ingin mengetahui apakah audio membantu pengunjung memahami benda</Highlight> (the team wants to know whether audio helps visitors understand exhibits). Paragraph five delivers that measure: <Highlight>kedua kelompok akan menjawab pertanyaan pemahaman yang sama</Highlight> (both groups will answer the same comprehension questions).

Using identical questions lets the team **compare learning outcomes with the same yardstick**.

## Why the other four options fail

- **Ensuring identical audio hardware** is false because earphone use is the exact factor being varied.
- **Replacing transcripts** and **making clips longer** have nothing to do with a comprehension quiz.
- **Proving audio and transcripts always tie** presumes the answer instead of testing it neutrally.

# Answer

**The same comprehension questions are given to both groups to compare learning outcomes using the same measure**.
