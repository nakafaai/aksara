Across three weeks, refill volume rises while the number of visible bottles falls. That pattern is useful for improving the service. Changes in canteen sales, temperature, waste collection time, and possible leaks could still affect the figures. The balanced conclusion is a pattern that supports **service improvements**, while **other factors still need measuring**.
