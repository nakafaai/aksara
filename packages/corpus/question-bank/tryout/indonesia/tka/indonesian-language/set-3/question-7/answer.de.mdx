Vergleiche die Linien auf der Karte mit Laras' Beobachtungen vor Ort. Drei Hindernisse werden erst beim tatsächlichen Ablaufen der Nordroute sichtbar:

- Die Bambusbrücke ist **gebrochen**.
- Das Übergangsbrett ist **rutschig**.
- Ein neuer Zaun **versperrt den Weg**.

Die Aussage über die Breite auf der Karte ist keine Beobachtung vor Ort. Laras muss die Anwohner erst fragen, bevor sie einen ausreichend breiten Weg findet.
