# Given

In the **City Museum** follow-up design, every device uses the new question-style filenames, half of the visitors receive earphones at random, and **transcripts remain available to everyone as baseline access** rather than being removed as a test variable.

# Asked

Why the text emphasizes keeping transcripts as universal baseline access instead of withholding them as a test variable.

# Solution

Imagine testing **two classroom reading lamps** while keeping comfortable desks and water available to every student. Basic access stays open to everyone, while only one factor varies so the comparison stays both fair and inclusive.

> Keeping baseline accessibility constant across groups protects every visitor while isolating the exact single factor under study.

## Mapping each element in paragraph five

Paragraph five lays out the plan: <Highlight>memakai nama berkas baru pada semua perangkat, tetapi memberikan earphone hanya pada setengah peserta secara acak</Highlight> (new filenames on all devices, earphones randomly to half), while <Highlight>Transkrip tetap tersedia untuk semua orang sebagai akses dasar</Highlight> (transcripts remain open to everyone as baseline access).

Thus **transcripts stay accessible to every group, while earphone access varies with filenames held constant**.

## Why the other four options fail

- **Giving transcripts only to low scorers** contradicts providing them to everyone.
- **Removing transcripts to boost earphone effects** is explicitly rejected by the team.
- **Calling transcripts the test outcome** confuses access tools with the comprehension questions.
- **Changing every element at once** would recreate week two's confounded design.

# Answer

Transcripts remain as baseline access because every group can use them while earphone provision varies with audio naming held identical.
