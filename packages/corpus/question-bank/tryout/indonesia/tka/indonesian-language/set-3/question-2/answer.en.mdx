The design separates **basic access** from **the treatment being compared**.

| Element | Across the groups | Function |
| --- | --- | --- |
| Transcript | Available to both. | Preserves access to information. |
| New audio titles | The same on every device. | Held constant across treatments. |
| Earphones | Randomly offered to half the participants. | The difference under investigation. |
| Comprehension questions | The same for both groups. | Supplies a common outcome measure. |
