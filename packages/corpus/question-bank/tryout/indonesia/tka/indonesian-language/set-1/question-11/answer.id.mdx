Di kebun belakang, peneduh dan pohon hadir bersamaan sehingga pengaruhnya sulit dipisahkan. Kanopi menyediakan peneduh tanpa pohon. Titik tambahan itu dipakai untuk membandingkan **peneduh tanpa pohon**.

Perbandingan ini mengurangi satu kerancuan, tetapi tidak otomatis menyamakan angin, permukaan, atau kondisi lokasi lainnya. Karena itu, pengukuran lanjutan tetap diperlukan.
