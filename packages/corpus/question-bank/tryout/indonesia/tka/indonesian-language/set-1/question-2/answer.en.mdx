Classify the parts within **one borrowing cycle**, using the boundary specified in the question.

| Part | Category | Reason |
| --- | --- | --- |
| Seed stock before borrowing | Masukan | Already available when the cycle begins. |
| Drying after harvest | Proses | An action that changes the condition of seeds. |
| Completed history card | Keluaran | A completed record returned with the seeds. |
