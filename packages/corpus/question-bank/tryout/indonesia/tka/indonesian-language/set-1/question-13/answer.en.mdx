# Given

During SMA Nusa's heat survey, all four groups measured at <InlineMath math="12.30" /> using the **same digital thermometer model** and a **three-minute wait**, while only the reading room had a running fan.

# Asked

How to classify three measurement factors as either already controlled or still needing control.

# Solution

Picture a footrace between two friends. To keep it fair, both start on the same line and run on the same track. If one runner gets **pushed forward by a giant fan**, that uneven factor still needs to be controlled.

> A controlled variable is held identical across every test group, whereas an uncontrolled variable still differs between sites and clouds comparisons.

## Checking each factor against the report

Paragraph one states every group <Highlight>memakai termometer digital dengan model yang sama</Highlight> (used the same digital thermometer model) and <Highlight>menunggu tiga menit sebelum mencatat angka</Highlight> (waited three minutes before recording). In contrast, only the reading room had <Highlight>Kipas menyala</Highlight> (fan on), so the team plans to turn it off during part of the follow-up.

| Factor | Category | Evidence from passage |
| --- | --- | --- |
| Thermometer model | Already controlled | All four groups used the identical model. |
| Wait time before recording | Already controlled | Every group waited three minutes. |
| Fan use in the reading room | Needs control | Only the reading room ran a fan, creating unequal conditions. |

## Avoiding the recording trap

Simply noting that a fan was on in a table does not control it. A variable becomes **controlled** only when conditions are made consistent across sites.

# Answer

Thermometer model and wait time before recording are already controlled, whereas fan use in the reading room still needs to be controlled.
