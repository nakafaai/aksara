Check **conditions held the same**, not merely recorded conditions.

| Variable | Category | Evidence |
| --- | --- | --- |
| Thermometer model | Sudah dikendalikan | Every group uses the same model. |
| Waiting time | Sudah dikendalikan | Every group waits three minutes. |
| Fan use | Perlu dikendalikan | The reading room has a running fan, creating a difference. |
