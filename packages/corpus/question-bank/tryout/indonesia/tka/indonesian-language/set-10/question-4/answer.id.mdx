# Penyelesaian

Bayangkan jualan es teh di depan sekolah tiba-tiba naik pesat tepat pada **musim kemarau terpanas**. Hasilnya memang **bagus dan menggembirakan**, tetapi kita tetap perlu jujur mengakui bahwa cuaca panas ikut berperan. Di teks ini, **musim berbunga di sekitar sekolah** berperan persis seperti cuaca panas itu.
