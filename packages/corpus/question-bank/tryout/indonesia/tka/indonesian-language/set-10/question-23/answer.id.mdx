- **Tepat.** Spanduk imbauan *dipasang di ujung jalan*, jadi spanduk adalah kain bertuliskan pesan untuk umum.
- **Tidak tepat.** Kebisingan *menyulitkan konsentrasi*, jadi konsentrasi adalah **pemusatan perhatian**, bukan suara mesin.
