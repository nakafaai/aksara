Das erste Ergebnis spricht dafür, eine Pause auszuprobieren. Für eine feste Regel, die für alle gilt, reicht es aber nicht. Sinnvoll ist deshalb, **geplante Pausen auszuprobieren** und **individuelle Ergebnisse zu beobachten**. So kann jede Person prüfen, ob die Pause die eigene Genauigkeit wirklich verbessert.
