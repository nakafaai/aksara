# Given

At **table two of the SMA Tunas Repair Clinic**, students form a hypothesis, test power supply, switch, and bulb in sequence, and log the result of each test step.

# Asked

The purpose of recording the result after each testing step.

# Solution

Imagine hunting for **a missing house key** across four drawers. If you mark each drawer after checking it, you never waste time opening the same empty drawer twice. Recording test steps works the exact same way.

> Logging each test step keeps troubleshooting orderly so technicians narrow down the fault without repeating finished checks.

## Reading the explicit reason in paragraph three

Paragraph three states directly that students <Highlight>memeriksa sumber listrik, sakelar, dan bohlam secara berurutan</Highlight> (check the power source, switch, and bulb in order) and <Highlight>mencatat hasil setiap langkah agar pengujian tidak diulang tanpa alasan</Highlight> (record the outcome of every step so tests are not repeated without reason).

That line gives the exact purpose: **so the same step is not repeated without reason**.

## Why the other options fail

- **Skipping safety inspection** clashes with table one, where safety hazards are checked before any testing.
- **Declaring items ready without extra notes** contradicts the take-home diagnosis sheet every owner receives.
- **Hiding costs from owners** and **letting facilitators discard parts** violate full cost transparency and owner decision-making.

# Answer

The purpose of recording each test step is so the same step is not repeated without reason.
