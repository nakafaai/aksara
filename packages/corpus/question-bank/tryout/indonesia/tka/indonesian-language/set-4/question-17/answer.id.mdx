Di awal cerita, Kakek selalu memegang bidak putih sementara Bima mengira Kakek tidak sungguh-sungguh mengajarinya. Di paragraf keenam, Kakek memutar papan lalu <Highlight>Untuk pertama kalinya, Kakek mengajak Bima mengulang permainan dari langkah kedua puluh, kali ini sambil menyebutkan setiap kemungkinan dengan suara keras</Highlight>.
