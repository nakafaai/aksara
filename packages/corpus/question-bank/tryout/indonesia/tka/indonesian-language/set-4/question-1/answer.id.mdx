# Penyelesaian

> Survei yang dilakukan langsung oleh pelaksana proyek dapat menghasilkan bias keseganan sehingga kesannya tetap perlu dibaca secara hati-hati.

## Membaca kekuatan dan batas survei di paragraf keempat
