# Gegeben

Der Text **Countdown-Ampeln** führt von der Sicherheitsdebatte (Absatz eins) über Befürworter (Absatz zwei) sowie Gegner samt widersprüchlicher Messdaten aus Kota Purwaraja (Absatz drei) bis zur Entscheidung der Behörde für weitere Tests wegen zweier gegensätzlicher Wirkungen (Absatz vier).

# Gesucht

Die Hauptaussage, die den gesamten Text umfasst.

# Lösung

Stell dir eine **Restzeitanzeige an einer Kreuzung** vor: Weniger Fahrer fahren bei Rot, aber mehr Fahrer geben kurz vor Ende von Grün noch kräftig Gas. Weil ein Gerät eine Gefahr senkt und eine andere verstärkt, prüft die Behörde weiter. Genau das bildet die **Hauptaussage**.

> Die Hauptaussage eines ganzen Sachtexts verbindet beide Seiten der Datenlage mit der daraus gezogenen Konsequenz im Schlussabsatz.

## Alle vier Absätze zu einer Kernaussage verbinden

Absatz drei zeigt zwei gegenläufige Trends: Rotlichtverstöße sanken von <InlineMath math="46" /> auf <InlineMath math="31" />, während Raser am Ende von Grün von <InlineMath math="20" /> auf <InlineMath math="34" /> stiegen. Absatz vier zieht die Bilanz: <Highlight>satu alat dapat menimbulkan dua efek yang berlawanan</Highlight> (zwei gegensätzliche Wirkungen), weshalb weitere Tests folgen.

Die Hauptaussage lautet daher: **Countdown-Anzeigen können eine Regelverletzung verringern, aber anderes riskantes Verhalten auslösen und müssen weiter getestet werden**.

## Warum die anderen vier Aussagen nicht zutreffen

- **Alle Fahrer werden geduldiger** nennt nur eine Seite und ignoriert das häufigere Rasen.
- **Ampeln abschaffen** wird nirgends verlangt.
- **Mehr Rotlichtverstöße** kehrt den Rückgang von <InlineMath math="46" /> auf <InlineMath math="31" /> um.
- **Kamerapreise** kommen im Text nicht vor.

# Antwort

Die Hauptaussage des Textes lautet, dass **Countdown-Anzeigen eine Art von Verstoß mindern, jedoch anderes riskantes Verhalten fördern und daher weiter getestet werden müssen**.
