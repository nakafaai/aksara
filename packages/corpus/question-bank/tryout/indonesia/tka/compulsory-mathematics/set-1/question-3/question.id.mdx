Misalkan tarif perjalanan dipandang sebagai fungsi dari jarak tempuh, satu fungsi untuk perjalanan di luar jam sibuk dan satu fungsi untuk perjalanan pada jam sibuk. Jarak tempuh dapat berupa sebarang bilangan real positif.

Berdasarkan aturan tarif tersebut, tentukan benar atau salah setiap pernyataan berikut.
