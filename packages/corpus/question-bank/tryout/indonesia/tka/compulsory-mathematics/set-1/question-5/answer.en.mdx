# Removing the absolute values

Call the left side <InlineMath math="g(x)=|x-3|+2\,|x+1|" />. The absolute values change form at <InlineMath math="x=-1" /> and <InlineMath math="x=3" />, so the number line splits into three parts. **On each part, <InlineMath math="g" /> is an ordinary linear function**:

<BlockMath math="g(x)=\begin{cases}(3-x)+(-2x-2)=1-3x, & x\le-1 \\ (3-x)+(2x+2)=x+5, & -1\le x\le3 \\ (x-3)+(2x+2)=3x-1, & x\ge3\end{cases}" />

The slopes are <InlineMath math="-3" />, then <InlineMath math="1" />, then <InlineMath math="3" />. So <InlineMath math="g" /> falls until <InlineMath math="x=-1" /> and rises after that. Its smallest value is <InlineMath math="g(-1)=4" />.

Every statement is solved part by part, and **each part's result has to be intersected with that part's own condition**.

# Statement one

For <InlineMath math="k=10" />:

<BlockMath math="\begin{aligned}
x\le-1:&\quad 1-3x\le10\iff x\ge-3 \\
-1\le x\le3:&\quad x+5\le10\iff x\le5,\ \text{the whole part works} \\
x\ge3:&\quad 3x-1\le10\iff x\le\tfrac{11}{3}
\end{aligned}" />

Together that's <InlineMath math="-3\le x\le\frac{11}{3}" />. The integers are <InlineMath math="-3,-2,-1,0,1,2,3" />, which makes <InlineMath math="7" />. This statement is **True**.

# Statement two

Since the smallest value of <InlineMath math="g" /> is <InlineMath math="4" />, the inequality <InlineMath math="g(x)\le k" /> has a solution **exactly when <InlineMath math="k\ge4" />**. For <InlineMath math="k<4" /> no <InlineMath math="x" /> makes <InlineMath math="g(x)" /> that small. This statement is **True**.

# Statement three

The solution set for <InlineMath math="k=10" /> is <InlineMath math="\left[-3,\frac{11}{3}\right]" />. Its midpoint is

<BlockMath math="\frac{-3+\frac{11}{3}}{2}=\frac{1}{3}\ne1" />

Symmetry about <InlineMath math="x=1" /> only shows up when both absolute values have the same weight. **The weight <InlineMath math="2" /> on <InlineMath math="|x+1|" /> makes the graph slope differently** on the left and on the right. This statement is **False**.

# Statement four

For <InlineMath math="k=4" /> you need <InlineMath math="g(x)\le4" />, but <InlineMath math="g(x)\ge4" /> for every <InlineMath math="x" />. So only points with <InlineMath math="g(x)=4" /> work. Left of <InlineMath math="-1" /> the graph falls, right of <InlineMath math="-1" /> it rises with slope <InlineMath math="1" />, so the value <InlineMath math="4" /> **is reached only at <InlineMath math="x=-1" />**.

Compare this with <InlineMath math="|x-3|+|x+1|\le4" /> without the weight. There the middle part is flat, so the whole interval <InlineMath math="-1\le x\le3" /> works. The weight <InlineMath math="2" /> tilts the middle part upward. This statement is **True**.

# Statement five

For <InlineMath math="k=6" />:

<BlockMath math="\begin{aligned}
x\le-1:&\quad 1-3x\le6\iff x\ge-\tfrac{5}{3} \\
-1\le x\le3:&\quad x+5\le6\iff x\le1 \\
x\ge3:&\quad 3x-1\le6\iff x\le\tfrac{7}{3},\ \text{which contradicts } x\ge3
\end{aligned}" />

The right part gives no solutions. The solution set is <InlineMath math="-\frac{5}{3}\le x\le1" />, so the largest value is <InlineMath math="1" />. The number <InlineMath math="\frac{7}{3}" /> comes from **forgetting the condition <InlineMath math="x\ge3" /> on the right part**. This statement is **False**.

So the true statements are the first, the second, and the fourth.
