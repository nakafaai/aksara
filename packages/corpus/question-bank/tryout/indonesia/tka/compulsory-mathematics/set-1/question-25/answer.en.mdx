# The intersection first

Almost every statement depends on <InlineMath math="P(A\cap B)" />, so **work out the intersection first** from the union rule:

<BlockMath math="\begin{aligned}
P(A\cup B)&=P(A)+P(B)-P(A\cap B) \\
0.7&=0.5+0.4-P(A\cap B) \\
P(A\cap B)&=0.2
\end{aligned}" />

# Judging each statement

- **False**: mutually exclusive means <InlineMath math="A" /> and <InlineMath math="B" /> can't happen together, so <InlineMath math="P(A\cap B)=0" />. Here the intersection is <InlineMath math="0.2" />.
- **True**: independent means <InlineMath math="P(A\cap B)=P(A)\cdot P(B)" />. Indeed <InlineMath math="0.5\cdot0.4=0.2" />, which equals the intersection.
- **False**: <InlineMath math="P(A\mid B)=\frac{P(A\cap B)}{P(B)}=\frac{0.2}{0.4}=0.5" />. The value <InlineMath math="0.4" /> is <InlineMath math="P(B)" />, not that conditional probability.
- **True**: neither happening is the opposite of "at least one happens", so <InlineMath math="1-P(A\cup B)=1-0.7=0.3" />.
- **True**: "exactly one" is the union minus the part where both happen, <InlineMath math="0.7-0.2=0.5" />. Check another way: <InlineMath math="(0.5-0.2)+(0.4-0.2)=0.3+0.2=0.5" />.

So the true statements are: the events are independent, the probability that neither happens is <InlineMath math="0.3" />, and the probability that exactly one happens is <InlineMath math="0.5" />.
