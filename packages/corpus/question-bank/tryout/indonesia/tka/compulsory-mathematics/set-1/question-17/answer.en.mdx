# How to test each transformation

A transformation maps the square onto itself when **the images of the four corners are exactly the set <InlineMath math="\{A,B,C,D\}" />**, even if they swap places. Write each transformation as one rule first, then test the four corners.

# Judging each option

**Reflection in the <InlineMath math="y" />-axis, then translation by <InlineMath math="(6,0)" />**. The rule is <InlineMath math="(x,y)\mapsto(-x+6,\,y)" />. The images are <InlineMath math="A\mapsto(5,1)=B" />, <InlineMath math="B\mapsto(1,1)=A" />, <InlineMath math="C\mapsto(1,5)=D" />, and <InlineMath math="D\mapsto(5,5)=C" />. This is the same as reflecting in the line <InlineMath math="x=3" />, an axis of symmetry of the square. Correct.

**Rotation, then translation by <InlineMath math="(6,0)" />**. The rule is <InlineMath math="(x,y)\mapsto(-y+6,\,x)" />. The images are <InlineMath math="A\mapsto(5,1)=B" />, <InlineMath math="B\mapsto(5,5)=C" />, <InlineMath math="C\mapsto(1,5)=D" />, and <InlineMath math="D\mapsto(1,1)=A" />. This is the same as a <InlineMath math="90^\circ" /> rotation about the square's centre <InlineMath math="(3,3)" />. Correct.

**Reflection in <InlineMath math="y=x" />, then translation by <InlineMath math="(2,-2)" />**. The rule is <InlineMath math="(x,y)\mapsto(y+2,\,x-2)" />. <InlineMath math="A" /> goes to <InlineMath math="(3,-1)" />, which isn't a corner of the square. Wrong. Reflecting in <InlineMath math="y=x" /> alone already maps the square onto itself, so the extra translation pushes it away.

**Dilation with factor <InlineMath math="-1" />, then translation by <InlineMath math="(6,6)" />**. The rule is <InlineMath math="(x,y)\mapsto(-x+6,\,-y+6)" />. The images are <InlineMath math="A\mapsto C" />, <InlineMath math="B\mapsto D" />, <InlineMath math="C\mapsto A" />, and <InlineMath math="D\mapsto B" />. This is a point reflection through the centre <InlineMath math="(3,3)" />. Correct.

**Rotation, then translation by <InlineMath math="(0,6)" />**. The rule is <InlineMath math="(x,y)\mapsto(-y,\,x+6)" />. <InlineMath math="A" /> goes to <InlineMath math="(-1,7)" />. Wrong.

So the right transformations are the reflection in the <InlineMath math="y" />-axis then translation by <InlineMath math="(6,0)" />, the <InlineMath math="90^\circ" /> rotation then translation by <InlineMath math="(6,0)" />, and the dilation with factor <InlineMath math="-1" /> then translation by <InlineMath math="(6,6)" />.
