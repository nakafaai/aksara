Many properties of a rational function like this one can be read from **splitting it into a number plus a simple fraction**.

<BlockMath math="f(x)=\frac{2x+1}{x-1}=\frac{2(x-1)+3}{x-1}=2+\frac{3}{x-1}" />

- **Domain**: only <InlineMath math="x=1" /> makes the denominator zero. The statement is true.
- **Range**: the fraction <InlineMath math="\frac{3}{x-1}" /> takes every value except <InlineMath math="0" />, so <InlineMath math="f" /> takes every value except <InlineMath math="2" />. Solving <InlineMath math="y=\frac{2x+1}{x-1}" /> for <InlineMath math="x" /> gives <InlineMath math="x=\frac{y+1}{y-2}" />, which exists for every <InlineMath math="y\neq2" />. The statement is true.
- **Zero**: <InlineMath math="2x+1=0" /> gives <InlineMath math="x=-\frac12" />, not <InlineMath math="\frac12" />. The statement is false.
- **<InlineMath math="y" />-intercept**: <InlineMath math="f(0)=\frac{1}{-1}=-1" />. The statement is true.
- **Monotonicity**: for <InlineMath math="x>1" />, <InlineMath math="x-1" /> grows, so <InlineMath math="\frac{3}{x-1}" /> shrinks. For example, <InlineMath math="f(2)=5" /> and <InlineMath math="f(4)=3" />. The function decreases there, so the statement is false.

So the true statements are the ones about the domain, the range and the intercept <InlineMath math="(0,-1)" />.
