Tabel berikut menunjukkan lama <InlineMath math="80" /> panggilan ke layanan pelanggan sebuah perusahaan dalam satu hari. Lama panggilan <InlineMath math="t" /> dinyatakan dalam menit.

| Lama panggilan (menit) | Banyak panggilan |
| :---: | :---: |
| <InlineMath math="0\le t<5" /> | <InlineMath math="6" /> |
| <InlineMath math="5\le t<10" /> | <InlineMath math="22" /> |
| <InlineMath math="10\le t<15" /> | <InlineMath math="14" /> |
| <InlineMath math="15\le t<20" /> | <InlineMath math="18" /> |
| <InlineMath math="20\le t<25" /> | <InlineMath math="12" /> |
| <InlineMath math="25\le t<30" /> | <InlineMath math="8" /> |

Untuk menaksir rata-rata, setiap panggilan dianggap berlangsung selama nilai tengah kelasnya. Untuk menaksir median dan kuartil, panggilan di setiap kelas dianggap tersebar merata di dalam kelas itu. Dengan <InlineMath math="n" /> banyak data, median ditaksir pada data ke-<InlineMath math="\frac{n}{2}" />, kuartil bawah pada data ke-<InlineMath math="\frac{n}{4}" />, dan kuartil atas pada data ke-<InlineMath math="\frac{3n}{4}" />.
