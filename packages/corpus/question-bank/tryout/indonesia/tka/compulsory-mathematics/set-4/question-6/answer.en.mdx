# The domain from the absolute value

The range is the set of all values <InlineMath math="f(x)" /> for the <InlineMath math="x" /> you're allowed to use. So first find out **which <InlineMath math="x" /> are allowed**. The inequality <InlineMath math="2\le|x-1|\le5" /> holds two conditions at once.

<InlineMath math="|x-1|\le5" /> says the distance from <InlineMath math="x" /> to <InlineMath math="1" /> is at most <InlineMath math="5" />. <InlineMath math="|x-1|\ge2" /> says that distance is at least <InlineMath math="2" />, and this one has **two branches**, to the left and to the right.

<BlockMath math="\begin{aligned}
|x-1|\le5 &\iff -4\le x\le 6 \\
|x-1|\ge2 &\iff x-1\le-2 \ \lor\ x-1\ge2 \\
&\iff x\le-1 \ \lor\ x\ge3
\end{aligned}" />

Put them together. The domain of <InlineMath math="f" /> is made of two intervals, <InlineMath math="-4\le x\le-1" /> and <InlineMath math="3\le x\le6" />. The gap <InlineMath math="-1<x<3" /> is left out.

# The values on each interval

Complete the square so you can see the vertex.

<BlockMath math="f(x)=x^2-4x+1=(x-2)^2-3" />

The vertex is at <InlineMath math="x=2" /> with value <InlineMath math="-3" />. But <InlineMath math="x=2" /> sits in the gap <InlineMath math="-1<x<3" />, so **the value <InlineMath math="-3" /> is never reached**. On each interval, <InlineMath math="f" /> only goes down or only goes up, so its smallest and largest values are at the ends of the interval.

<BlockMath math="\begin{aligned}
-4\le x\le-1:&\quad f(-1)=6,\ \ f(-4)=33,\ \text{ values } 6\le y\le 33 \\
3\le x\le 6:&\quad f(3)=-2,\ \ f(6)=13,\ \text{ values } -2\le y\le 13
\end{aligned}" />

The two sets of values overlap, since <InlineMath math="6" /> to <InlineMath math="13" /> is in both. Together they give <InlineMath math="-2\le y\le33" />.

# The tempting options

Each of the other options **forgets one part of the domain**.

- <InlineMath math="\{y\mid -3\le y\le33\}" /> uses the vertex value <InlineMath math="-3" />, but <InlineMath math="x=2" /> isn't in the domain.
- <InlineMath math="\{y\mid y\ge-3\}" /> is the range when <InlineMath math="x" /> can be any real number. The absolute value condition was ignored.
- <InlineMath math="\{y\mid -2\le y\le13\}" /> only uses the branch <InlineMath math="x\ge3" /> and loses the branch <InlineMath math="x\le-1" />.
- <InlineMath math="\{y\mid 6\le y\le33\}" /> only uses the branch <InlineMath math="x\le-1" />.

So the range of <InlineMath math="f" /> is <InlineMath math="\{y\mid -2\le y\le33\}" />.
