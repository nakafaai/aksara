# Bekalan daripada bacaan

Data sepuluh hari disusun: <InlineMath math="31,32,33,38,40,41,45,46,46,48" />. Minnya <InlineMath math="40" /> dan sisihan piawainya <InlineMath math="6" />, jadi **hasil tambah kuasa dua beza daripada <InlineMath math="40" /> ialah <InlineMath math="10\cdot36=360" />**.

Untuk mengira varians baharu dengan cepat, gunakan sifat ini: varians sama dengan min kuasa dua beza daripada sebarang titik rujukan, tolak kuasa dua jarak min ke titik rujukan itu. Titik rujukan yang paling mudah ialah <InlineMath math="40" />.

<BlockMath math="S^2=\frac{\sum(x_i-40)^2}{n}-(\bar x-40)^2" />

# Pernyataan pertama

Dengan <InlineMath math="11" /> data, median ialah data ke-<InlineMath math="6" /> selepas disusun. Nilai <InlineMath math="v" /> boleh jatuh di mana-mana.

| Nilai <InlineMath math="v" /> | Data ke-6 |
| :---: | :---: |
| <InlineMath math="v\le40" /> | <InlineMath math="40" /> |
| <InlineMath math="v\ge41" /> | <InlineMath math="41" /> |

Dalam setiap kes, mediannya **sentiasa <InlineMath math="40" /> atau <InlineMath math="41" />**. Pernyataan ini **Betul**.

# Pernyataan kedua

Untuk <InlineMath math="v=46" />, bezanya daripada <InlineMath math="40" /> ialah <InlineMath math="6" />, dan min baharu <InlineMath math="\tfrac{446}{11}" /> berjarak <InlineMath math="\tfrac{6}{11}" /> daripada <InlineMath math="40" />.

<BlockMath math="S^2=\frac{360+36}{11}-\left(\tfrac{6}{11}\right)^2=36-\tfrac{36}{121}<36" />

Variansnya sedikit **kurang daripada** <InlineMath math="36" />, jadi sisihan piawainya kurang daripada <InlineMath math="6" />. Pernyataan ini **Salah**.

# Pernyataan ketiga

Min <InlineMath math="41" /> bermaksud jumlah <InlineMath math="11\cdot41=451" />, jadi <InlineMath math="v=451-400=51" />. Beza <InlineMath math="v" /> daripada <InlineMath math="40" /> ialah <InlineMath math="11" />.

<BlockMath math="S^2=\frac{360+121}{11}-(41-40)^2=\frac{481}{11}-1=\frac{470}{11}\approx42.7>36" />

Sisihan piawainya **lebih daripada** <InlineMath math="6" />. Pernyataan ini **Betul**.

Jadi, susunannya Betul, Salah, Betul.
