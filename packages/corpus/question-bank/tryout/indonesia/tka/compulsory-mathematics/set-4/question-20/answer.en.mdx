The string, a horizontal line at hand height and a vertical line to the kite form a right triangle. The kite's height above the hand is **the side opposite <InlineMath math="\alpha" />**, so <InlineMath math="\sin\alpha" /> is needed, not <InlineMath math="\cos\alpha" />.

<BlockMath math="\begin{aligned}
\sin\alpha&=\sqrt{1-0.6^2}=\sqrt{0.64}=0.8 \\
h&=50\cdot0.8+1.2=40+1.2=41.2\text{ m}
\end{aligned}" />

As a check, the horizontal distance from the hand to the point below the kite is <InlineMath math="50\cdot0.6=30\text{ m}" />, and <InlineMath math="30^2+40^2=50^2" />.

So the kite is <InlineMath math="41.2\text{ m}" /> above the ground.

- <InlineMath math="30\text{ m}" /> uses <InlineMath math="\cos\alpha" />, which gives the horizontal distance.
- <InlineMath math="31.2\text{ m}" /> uses <InlineMath math="\cos\alpha" /> and then adds the hand height.
- <InlineMath math="40\text{ m}" /> forgets to add the hand height of <InlineMath math="1.2\text{ m}" />.
