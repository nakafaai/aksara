- A translation moves every point by the same vector, so each side keeps its length. The statement is true.
- A reflection is an isometry, so the image is congruent and has the same area. The statement is true.
- With <InlineMath math="k=-2" /> every length doubles, so the area is multiplied by <InlineMath math="(-2)^2=4" />, not by <InlineMath math="2" />. The statement is false.
