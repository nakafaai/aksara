# Smallest and largest possible means

A value between two known positions can be anything between those two known values, including equal to either one. So **the smallest total** comes from setting every unknown value equal to the known value just below it, and the largest total from setting it equal to the known value just above it.

<BlockMath math="\begin{aligned}
\text{smallest A}&=7\cdot40+8\cdot56+8\cdot70+7\cdot82+98=1{,}960,\quad \bar a=\tfrac{1{,}960}{31}\approx63.23 \\

# Judging each statement

**False**. First statement: class A can have the smallest A data with a mean of about <InlineMath math="63.23" />, while class B has the largest B data with a mean of about <InlineMath math="73.41" />. Both fit the table, and here A's mean is **smaller**. A higher median and higher quartiles don't guarantee a higher mean.

**False**. Second statement: with the new student, class B has <InlineMath math="28" /> students, so the median is the mean of the <InlineMath math="14" />th and <InlineMath math="15" />th values. The <InlineMath math="100" /> goes at the top end, so the <InlineMath math="14" />th value is still <InlineMath math="b_{14}=68" /> and the <InlineMath math="15" />th is <InlineMath math="b_{15}" />, which can be anything from <InlineMath math="68" /> to <InlineMath math="76" />.

<BlockMath math="\text{if } b_{15}=76:\quad \text{new median}=\frac{68+76}{2}=72\ne68" />

The new median stays <InlineMath math="68" /> only if <InlineMath math="b_{15}=68" />, and that isn't certain.

**True**. Third statement: every <InlineMath math="a_i" /> is at least the value used in the smallest A data, because that value is the known value at the same position or an earlier one. So the total of class A is always at least <InlineMath math="1{,}960" />.

<BlockMath math="\bar a\ge\frac{1{,}960}{31}\approx63.23>63" />

So the first statement is false, the second is false and the third is true.
