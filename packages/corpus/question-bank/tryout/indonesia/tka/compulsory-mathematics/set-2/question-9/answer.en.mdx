# Removing the absolute value signs

An absolute value changes form where its inside is zero, at <InlineMath math="x=4" /> and <InlineMath math="x=-2" />. So **split the number line into three regions** and write <InlineMath math="f" /> without absolute values in each one.

<BlockMath math="f(x)=\begin{cases}
(4-x)-(-x-2)=6, & x\le-2 \\
(4-x)-(x+2)=2-2x, & -2\le x\le4 \\
(x-4)-(x+2)=-6, & x\ge4
\end{cases}" />

The graph is **flat on the left, falls in the middle, then is flat again on the right**. In the middle it drops from <InlineMath math="6" /> to <InlineMath math="-6" />.

# Judging each statement

1. **False**. The maximum is indeed <InlineMath math="6" />, but every <InlineMath math="x\le-2" /> reaches it, so infinitely many values of <InlineMath math="x" /> do.
2. **True**. The value <InlineMath math="3" /> can only appear in the middle part: <InlineMath math="2-2x=3" /> gives <InlineMath math="x=-\tfrac12" />, which lies between <InlineMath math="-2" /> and <InlineMath math="4" />. The flat parts have values <InlineMath math="6" /> and <InlineMath math="-6" />, so they add no solutions.
3. **False**. Every <InlineMath math="x\ge4" /> gives <InlineMath math="f(x)=-6" />, so there are infinitely many solutions.
4. **False**. For <InlineMath math="x=\tfrac12" /> the value is <InlineMath math="f\left(\tfrac12\right)=2-1=1" />, which is positive. The function only becomes negative for <InlineMath math="x>1" />.
5. **True**. The flat parts have values <InlineMath math="\pm6" />, so only the middle part can meet this condition. From <InlineMath math="-4\le2-2x\le4" /> you get <InlineMath math="-1\le x\le3" />. The integers are <InlineMath math="-1" />, <InlineMath math="0" />, <InlineMath math="1" />, <InlineMath math="2" />, and <InlineMath math="3" />, which makes <InlineMath math="5" />.

So the true statements are the second and the fifth.
