**Complete the square** to reveal the vertex and minimum value.

<BlockMath math="\begin{aligned} f(x)&=x^2-4x+3 \\ &=x^2-4x+4-4+3 \\ &=(x-2)^2-1 \end{aligned}" />

A square is nonnegative, so the vertex is <InlineMath math="(2,-1)" /> and the range is <InlineMath math="[-1,\infty)" />. As <InlineMath math="x" /> approaches <InlineMath math="2" /> from the left, <InlineMath math="(x-2)^2" /> decreases. The function therefore decreases on <InlineMath math="(-\infty,2]" />.

The function is not one-to-one on all real numbers because <InlineMath math="f(1)=f(3)=0" />. On the restricted domain <InlineMath math="x\ge2" />, the inverse uses the positive square root.

<BlockMath math="\begin{aligned}
y+1&=(x-2)^2 \\
x-2&=\sqrt{y+1} \\
f^{-1}(y)&=2+\sqrt{y+1}
\end{aligned}" />

The inverse has domain <InlineMath math="y\ge-1" />. All statements are true except the claim of being one-to-one on all of <InlineMath math="\mathbb R" />.

The orange branch shows the restriction <InlineMath math="x\ge2" />. On this branch, each output comes from exactly one input, so the restricted function has an inverse.
