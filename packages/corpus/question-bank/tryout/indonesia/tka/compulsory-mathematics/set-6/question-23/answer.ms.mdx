# Data yang digunakan

Ketiga-tiga pernyataan mengubah data dan bertanya kesannya, jadi kamu perlu **menyusun data dan mengira semula selepas setiap perubahan**. Data daripada jadual:

- Bandar P: <InlineMath math="330, 270, 240, 200, 120, 40" />. Tertib: <InlineMath math="40, 120, 200, 240, 270, 330" />.
- Bandar Q: <InlineMath math="250, 230, 180, 320, 300, 280" />. Tertib: <InlineMath math="180, 230, 250, 280, 300, 320" />, dengan median <InlineMath math="\tfrac{250+280}{2}=265" /> dan min <InlineMath math="\tfrac{1560}{6}=260" />.

# Pernyataan pertama

Dengan data Julai, Bandar P mempunyai tujuh data, jadi median ialah data ke-<InlineMath math="4" /> selepas disusun. Nilai Julai <InlineMath math="x" /> boleh jatuh di mana-mana, jadi semak semua kemungkinan.

| Nilai Julai | Data ke-4 |
| :---: | :---: |
| <InlineMath math="x\le200" /> | <InlineMath math="200" /> |
| <InlineMath math="200<x<240" /> | <InlineMath math="x" /> |
| <InlineMath math="x\ge240" /> | <InlineMath math="240" /> |

Dalam setiap kes, mediannya **sentiasa di antara <InlineMath math="200" /> dan <InlineMath math="240" />**, termasuk kedua-dua hujungnya. Pernyataan ini **Betul**.

# Pernyataan kedua

Tambahkan <InlineMath math="260" /> kepada data Bandar Q. Susunannya menjadi <InlineMath math="180, 230, 250, 260, 280, 300, 320" />, dan median tujuh data ialah data ke-<InlineMath math="4" />, iaitu <InlineMath math="260" />. Median asal <InlineMath math="265" />, jadi **mediannya berubah**. Menambah min memang tidak mengubah min, tetapi boleh mengubah median. Pernyataan ini **Salah**.
