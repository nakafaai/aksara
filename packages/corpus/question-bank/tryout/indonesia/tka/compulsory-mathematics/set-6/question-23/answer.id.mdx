# Data yang dipakai

Ketiga pernyataan mengubah data lalu bertanya akibatnya, jadi kamu perlu **mengurutkan data dan menghitung ulang setelah setiap perubahan**. Data dari tabel:

- Kota P: <InlineMath math="330, 270, 240, 200, 120, 40" />. Diurutkan: <InlineMath math="40, 120, 200, 240, 270, 330" />.
- Kota Q: <InlineMath math="250, 230, 180, 320, 300, 280" />. Diurutkan: <InlineMath math="180, 230, 250, 280, 300, 320" />, dengan median <InlineMath math="\tfrac{250+280}{2}=265" /> dan rata-rata <InlineMath math="\tfrac{1560}{6}=260" />.

# Pernyataan pertama

Dengan data Juli, Kota P punya tujuh data, jadi median adalah data ke-<InlineMath math="4" /> setelah diurutkan. Nilai Juli <InlineMath math="x" /> bisa jatuh di mana saja, jadi periksa semua kemungkinan.

| Nilai Juli | Data ke-4 |
| :---: | :---: |
| <InlineMath math="x\le200" /> | <InlineMath math="200" /> |
| <InlineMath math="200<x<240" /> | <InlineMath math="x" /> |
| <InlineMath math="x\ge240" /> | <InlineMath math="240" /> |

Di setiap kasus mediannya **selalu di antara <InlineMath math="200" /> dan <InlineMath math="240" />**, termasuk kedua ujungnya. Pernyataan ini **Benar**.

# Pernyataan kedua

Tambahkan <InlineMath math="260" /> ke data Kota Q. Urutannya menjadi <InlineMath math="180, 230, 250, 260, 280, 300, 320" />, dan median tujuh data adalah data ke-<InlineMath math="4" />, yaitu <InlineMath math="260" />. Median semula <InlineMath math="265" />, jadi **mediannya berubah**. Menambahkan rata-rata memang tidak mengubah rata-rata, tetapi bisa mengubah median. Pernyataan ini **Salah**.

# Pernyataan ketiga

Turun <InlineMath math="40\%" /> berarti tinggal <InlineMath math="60\%" />, jadi setiap nilai Kota Q dikali <InlineMath math="0{,}6" />. Lalu bandingkan **bulan demi bulan**, bukan nilai yang sudah diurutkan.
