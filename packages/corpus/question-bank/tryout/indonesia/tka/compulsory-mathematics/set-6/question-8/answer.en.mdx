# The rebound ratio and the starting height

The question asks for the total distance the ball travels, up and down, from the drop until it's caught. The starting height isn't given, so find it from the rebounds first. The rebound heights form a **geometric sequence**, because each height is the previous one times a fixed number <InlineMath math="r" />.

<BlockMath math="\begin{aligned}
162\cdot r^{2}&=72 \\
r^{2}&=\frac{72}{162}=\frac{4}{9}
\end{aligned}" />

Heights are always positive, so <InlineMath math="r=-\tfrac{2}{3}" /> is ruled out and <InlineMath math="r=\tfrac{2}{3}" />. The first rebound is <InlineMath math="\tfrac{2}{3}" /> of the starting height <InlineMath math="h" />:

<BlockMath math="\tfrac{2}{3}\,h=162 \quad\Rightarrow\quad h=243\text{ cm}" />

# Which rebound gets caught

List the rebound heights with ratio <InlineMath math="\tfrac{2}{3}" />:

<BlockMath math="162,\ 108,\ 72,\ 48,\ 32,\ \ldots" />

The fourth rebound is exactly <InlineMath math="48\text{ cm}" />, and **exactly <InlineMath math="48\text{ cm}" /> is not less than <InlineMath math="48\text{ cm}" />**. So the ball isn't caught there. The first rebound below <InlineMath math="48\text{ cm}" /> is the fifth one, <InlineMath math="32\text{ cm}" /> high.

# Adding up the path

There are three kinds of pieces. The first drop only goes down. Rebounds one to four each go up and then down, so they're **counted twice**. The fifth rebound only goes up, because the ball is caught at its top.

<BlockMath math="\begin{aligned}
\text{path length}&=243+2\,(162+108+72+48)+32 \\
&=243+2\cdot390+32 \\
&=1{,}055\text{ cm}
\end{aligned}" />

You can also check <InlineMath math="162+108+72+48=390" /> with the geometric series formula: <InlineMath math="\frac{162\left(1-\left(\frac{2}{3}\right)^{4}\right)}{1-\frac{2}{3}}=162\cdot\frac{65}{81}\cdot3=390" />.
