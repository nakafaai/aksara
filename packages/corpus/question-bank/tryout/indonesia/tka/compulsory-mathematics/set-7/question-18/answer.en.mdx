Take the garden's area minus the paths. The two paths **overlap in a <InlineMath math="1\text{ m}\times1\text{ m}" /> square** that belongs to both paths, so that square may be subtracted only once.

<BlockMath math="\begin{aligned}
L_{\text{paths}}&=20\cdot1+15\cdot1-1\cdot1=34\text{ m}^2 \\
L_{\text{vegetables}}&=20\cdot15-34=300-34=266\text{ m}^2
\end{aligned}" />

Check by sliding both paths to the edges of the garden: what's left is one rectangle of <InlineMath math="19\text{ m}\times14\text{ m}" />, and <InlineMath math="19\cdot14=266" />.

So the vegetable area is <InlineMath math="266\text{ m}^2" />.

- <InlineMath math="265\text{ m}^2" /> subtracts both full paths, so the overlap square is subtracted twice.
- <InlineMath math="267\text{ m}^2" /> removes the overlap square from both paths, so it isn't subtracted at all.
- <InlineMath math="280\text{ m}^2" /> subtracts only the path parallel to the long side.
- <InlineMath math="285\text{ m}^2" /> subtracts only the path parallel to the short side.
