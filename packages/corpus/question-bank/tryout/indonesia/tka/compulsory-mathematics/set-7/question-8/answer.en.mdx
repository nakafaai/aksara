# The first row and the step between rows

The question asks how many seats are in the last row, but the number of rows isn't known yet. So the order is: find the first row <InlineMath math="a" /> and the common difference <InlineMath math="b" />, then the number of rows <InlineMath math="n" />, and only then row <InlineMath math="n" />. **Each step uses the result of the step before**.

The <InlineMath math="k" />-th term of an arithmetic sequence is <InlineMath math="u_k=a+(k-1)b" />.

<BlockMath math="\begin{aligned}
u_{12}-u_5&=(a+11b)-(a+4b)=7b=40-26=14 \\
b&=2 \\
a&=26-4\cdot2=18
\end{aligned}" />

The first row has <InlineMath math="18" /> seats, and each row after it has <InlineMath math="2" /> more.

# The number of rows

The sum of the first <InlineMath math="n" /> terms is <InlineMath math="S_n=\frac n2\left(2a+(n-1)b\right)" />. Set it equal to <InlineMath math="1{,}050" />.

<BlockMath math="\begin{aligned}
\frac n2\left(36+2(n-1)\right)&=1{,}050 \\
n(n+17)&=1{,}050 \\
n^2+17n-1{,}050&=0 \\
(n-25)(n+42)&=0
\end{aligned}" />

# The last row

The last row is row <InlineMath math="25" />. Use the <InlineMath math="k" />-th term formula again with <InlineMath math="a=18" /> and <InlineMath math="b=2" />.

<BlockMath math="u_{25}=18+24\cdot2=66" />

As a check, <InlineMath math="S_{25}=\frac{25}{2}(18+66)=25\cdot42=1{,}050" />. **The total matches the question**.

# Why the other options are wrong

- <InlineMath math="42" /> is the average number of seats per row, <InlineMath math="1{,}050\div25" />. In an arithmetic sequence that average equals the middle row (row <InlineMath math="13" />), **not the last row**.
- <InlineMath math="68" /> uses the wrong formula <InlineMath math="u_n=a+nb=18+25\cdot2" />. The first row hasn't had any step added yet, so the multiplier is <InlineMath math="n-1" />.
- <InlineMath math="84" /> comes from <InlineMath math="S_n=\frac n2(a+u_n)" /> but forgets to subtract <InlineMath math="a" />. The correct value is <InlineMath math="u_n=\frac{2S_n}{n}-a=84-18=66" />.
- <InlineMath math="100" /> uses <InlineMath math="n=42" />, the root <InlineMath math="-42" /> with its sign dropped. With <InlineMath math="42" /> rows the total would be far more than <InlineMath math="1{,}050" />.

So row <InlineMath math="n" /> has <InlineMath math="66" /> seats.
