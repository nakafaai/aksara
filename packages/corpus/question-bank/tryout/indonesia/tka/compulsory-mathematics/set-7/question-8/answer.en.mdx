# The first row and the step between rows

The order is: find the first row <InlineMath math="a" /> and the common difference <InlineMath math="b" />, then the seats left after two rows are removed, then the number of rows <InlineMath math="n" />, and only then row <InlineMath math="n" />. **Each step uses the result of the step before**.

<BlockMath math="\begin{aligned}
u_{12}-u_5&=7b=40-26=14\ \Rightarrow\ b=2 \\
a&=u_5-4b=26-8=18
\end{aligned}" />

# The seats that are left

If the back row is row <InlineMath math="n" />, rows <InlineMath math="1" /> to <InlineMath math="n" /> hold <InlineMath math="S_n=\frac n2\left(2a+(n-1)b\right)=n(n+17)" /> seats. **The two front rows are gone**, so their seats, <InlineMath math="18+20=38" />, have to be subtracted.

<BlockMath math="n(n+17)-38\ge960\ \Leftrightarrow\ n(n+17)\ge998" />

The original <InlineMath math="20" /> rows give only <InlineMath math="20\cdot37-38=702" /> seats, so rows really have to be added. Try the whole numbers near the limit.
