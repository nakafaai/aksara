A cable joins two corners that aren't next to each other, so **each cable is a diagonal of the <InlineMath math="10" />-gon**. From each corner a diagonal can go to every other corner except itself and its two neighbours, that is <InlineMath math="10-3=7" /> corners. Each diagonal is counted twice, once from each end.

<BlockMath math="\frac{10\cdot(10-3)}{2}=\frac{70}{2}=35" />

Check another way: there are <InlineMath math="\binom{10}{2}=45" /> pairs of corners, minus <InlineMath math="10" /> sides, which leaves <InlineMath math="35" />.

So <InlineMath math="35" /> cables are needed.

- <InlineMath math="45" /> counts every pair of corners, including the <InlineMath math="10" /> neighbouring pairs.
- <InlineMath math="70" /> forgets to halve, so each cable is counted twice.
- <InlineMath math="80" /> uses <InlineMath math="10\cdot8" />, which leaves out the two neighbours but not the corner itself.
- <InlineMath math="90" /> uses <InlineMath math="10\cdot9" />, every other corner from each corner, without halving.
