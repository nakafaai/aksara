The PIN is picked from **valid PINs only**, so the sample space is every PIN that meets both rules. The top of the fraction needs a split into cases by digit pattern, because the rule on neighbouring digits decides which patterns are allowed.

# Number of valid PINs

Fill in the digits from left to right. The first digit can be <InlineMath math="1" /> to <InlineMath math="9" />. From the second digit on, **<InlineMath math="0" /> is allowed again**, and the only ban is repeating the digit right before it.

<BlockMath math="n(S)=9\cdot9\cdot9\cdot9=6{,}561" />

# Patterns with exactly three different digits

Three different digits in four places means exactly one digit appears twice. **The repeated digit can't sit in neighbouring places**, so its two places are the first and third, the second and fourth, or the first and fourth. Write each pattern with letters in order of appearance.

<BlockMath math="ABAC,\qquad ABCB,\qquad ABCA" />

In each pattern, <InlineMath math="A" /> is the first digit, so it has <InlineMath math="9" /> choices. The letter <InlineMath math="B" /> may be <InlineMath math="0" /> as long as it differs from <InlineMath math="A" />, so it has <InlineMath math="9" /> choices, and <InlineMath math="C" /> has <InlineMath math="8" />.

<BlockMath math="n(E)=3\cdot(9\cdot9\cdot8)=3\cdot648=1{,}944" />

Compare the number of valid PINs for each pattern. **Each of the three patterns with exactly three different digits holds <InlineMath math="648" /> PINs**, while the two-digit pattern <InlineMath math="ABAB" /> holds only <InlineMath math="81" /> and the four-digit pattern <InlineMath math="ABCD" /> holds <InlineMath math="4{,}536" />.

# The probability

<BlockMath math="P(E)=\frac{1{,}944}{6{,}561}=\frac{8}{27}" />

Check: <InlineMath math="81+1{,}944+4{,}536=6{,}561" />, so **every valid PIN falls into exactly one pattern**.

# Why the other options are wrong

- <InlineMath math="\frac{16}{81}" /> uses only two patterns and **loses the pattern <InlineMath math="ABCA" />**, where the repeated digit is first and last.
- <InlineMath math="\frac{25}{81}" /> is <InlineMath math="1-\frac{56}{81}" />, the probability that some digit repeats. It also includes the pattern <InlineMath math="ABAB" />, which has only two different digits.
- <InlineMath math="\frac{27}{125}" /> uses the sample space <InlineMath math="9{,}000" />, all four-digit numbers, but the PIN is picked from valid PINs.
- <InlineMath math="\frac{4}{15}" /> uses the sample space <InlineMath math="10\cdot9\cdot9\cdot9=7{,}290" />, which allows <InlineMath math="0" /> as the first digit.

So the probability is <InlineMath math="\frac{8}{27}" />.
