# Häufigkeit jeder Klasse

Eine kumulierte Häufigkeit ist eine laufende Summe. Die Häufigkeit einer Klasse ist der Unterschied zweier benachbarter Zeilen, **nicht die kumulierte Zahl selbst**:

| Klasse | Rechnung | Häufigkeit |
| :---: | :---: | :---: |
| <InlineMath math="10\le t<20" /> | <InlineMath math="8-2" /> | <InlineMath math="6" /> |
| <InlineMath math="20\le t<30" /> | <InlineMath math="32-8" /> | <InlineMath math="24" /> |

Weil die Schüler als gleichmäßig verteilt gelten, **ist die Anzahl in einem Stück einer Klasse proportional zur Breite dieses Stücks**.
