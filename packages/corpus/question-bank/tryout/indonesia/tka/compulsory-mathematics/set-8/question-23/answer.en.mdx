All three statements are about the real data, but the table only tells you how many students are in each class. A statement is **certainly true only if it holds for every way the students could be spread inside their classes**. To show a statement is false, one set of data that fits the table but breaks the statement is enough.

# Judging each statement

**Statement 1**. The real mean is largest when every student reads as close as possible to the upper boundary of their class. Work out the total if every student sat exactly on the upper boundary:

<BlockMath math="\begin{aligned}
&2\cdot10+6\cdot20+24\cdot30+20\cdot40+16\cdot50+6\cdot60+6\cdot70 \\
&=20+120+720+800+800+360+420=3{,}240 \\
&\frac{3{,}240}{80}=40.5
\end{aligned}" />

Every student reads less than the upper boundary of their class, so the real total is less than <InlineMath math="3{,}240" /> and the mean is less than <InlineMath math="40.5" />. That's always less than <InlineMath math="41" />, however the students are spread. **True**.

**Statement 2**. Up to the class <InlineMath math="20\le t<30" /> there are <InlineMath math="32" /> students, and up to the class <InlineMath math="30\le t<40" /> there are <InlineMath math="52" />. So the <InlineMath math="40" />th and <InlineMath math="41" />st values are surely in the class <InlineMath math="30\le t<40" />, and the real median is only certain to lie between <InlineMath math="30" /> and <InlineMath math="40" />. A breaking example: all twenty students in that class read exactly <InlineMath math="30" /> minutes. This fits the table, and

<BlockMath math="\text{median}=\frac{30+30}{2}=30\le32" />

The estimated median is <InlineMath math="34" />, but an estimate isn't a certainty. **False**.

**Statement 3**. The only students certain to read at least <InlineMath math="45" /> minutes are those in the classes <InlineMath math="50\le t<60" /> and <InlineMath math="60\le t<70" />, which is <InlineMath math="6+6=12" /> students. The sixteen students in the class <InlineMath math="40\le t<50" /> could all read exactly <InlineMath math="40" /> minutes, and the data would still fit the table. In that example, the number of students who read <InlineMath math="45" /> minutes or more is only

<BlockMath math="6+6=12<20" />

The number <InlineMath math="20" /> comes from the estimate <InlineMath math="\tfrac12\cdot16+12=20" />, which assumes the class <InlineMath math="40\le t<50" /> splits evenly in half. **False**.

So the verdicts are True, False, False.
