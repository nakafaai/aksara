A semicircle is **half the circumference of a circle**, <InlineMath math="\tfrac12\pi d" />. Compare both paths with that formula.

<BlockMath math="\begin{aligned}
\text{path I}&=\tfrac12\cdot\tfrac{22}{7}\cdot28=44 \\
\text{path II}&=2\cdot\tfrac12\cdot\tfrac{22}{7}\cdot14=44
\end{aligned}" />

This isn't a coincidence. Each semicircle in path II has only half the diameter, but there are two of them, so together they still make <InlineMath math="\tfrac12\pi\cdot28" />. However many equal semicircles make up <InlineMath math="AB" />, the path has the same length.

So both paths are the same length, <InlineMath math="44\text{ m}" />.

- Path I isn't longer, because both paths are <InlineMath math="44\text{ m}" />.
- The wiggly path II isn't longer either, because each of its semicircles is only <InlineMath math="22\text{ m}" />.
- <InlineMath math="88\text{ m}" /> is the circumference of a full circle, not a semicircle.
- Path II isn't half of path I, because the halved diameter is balanced by twice as many semicircles.
