The question asks for the total horizontal distance: the horizontal run of the first part, plus the landing, plus the horizontal run of the second part. The two parts have different slopes, so **the height of the second part has to come from whatever height the first part hasn't climbed yet**.

# The first part

Each sloped part is the hypotenuse of a right triangle: the vertical side is the height it climbs, and the horizontal side is its horizontal run. From <InlineMath math="\sin\alpha=\frac{7}{25}" />, the opposite side is <InlineMath math="7" /> and the hypotenuse is <InlineMath math="25" />, so **you find the adjacent side with Pythagoras**:

<BlockMath math="\begin{aligned}
\text{adjacent}&=\sqrt{25^2-7^2}=\sqrt{576}=24 \quad\Rightarrow\quad \cos\alpha=\frac{24}{25} \\
\text{height}_1&=5\cdot\frac{7}{25}=1.4\text{ m} \\
\text{run}_1&=5\cdot\frac{24}{25}=4.8\text{ m}
\end{aligned}" />

# The second part

The flat landing adds no height. So the second part has to climb the rest. For angle <InlineMath math="\beta" />, the adjacent side is <InlineMath math="\sqrt{13^2-5^2}=12" />, so <InlineMath math="\cos\beta=\frac{12}{13}" />:

<BlockMath math="\begin{aligned}
\text{height}_2&=2.9-1.4=1.5\text{ m} \\
\text{slanted length}_2&=\frac{1.5}{\sin\beta}=1.5\cdot\frac{13}{5}=3.9\text{ m} \\
\text{run}_2&=3.9\cdot\frac{12}{13}=3.6\text{ m}
\end{aligned}" />

**Check with Pythagoras**: <InlineMath math="1.5^2+3.6^2=2.25+12.96=15.21=3.9^2" />. It fits.

# The total horizontal distance

All three pieces go in the same direction, so **their horizontal distances add up**:

<BlockMath math="4.8+1.5+3.6=9.9\text{ m}" />

# Why the other options are wrong

- <InlineMath math="13.26\text{ m}" /> uses the whole height <InlineMath math="2.9\text{ m}" /> for the second part: <InlineMath math="2.9\cdot\frac{12}{5}=6.96" />. **The first part has already climbed <InlineMath math="1.4\text{ m}" />**.
- <InlineMath math="10.4\text{ m}" /> adds the slanted lengths <InlineMath math="5+1.5+3.9" />. The question asks for the horizontal distance, not the length of the ramp surface.
- <InlineMath math="8.4\text{ m}" /> forgets to add the <InlineMath math="1.5\text{ m}" /> landing.
- <InlineMath math="7.5\text{ m}" /> takes the horizontal run as slanted length minus height: <InlineMath math="5-1.4=3.6" /> and <InlineMath math="3.9-1.5=2.4" />. You can't just subtract the sides of a right triangle, use Pythagoras or the cosine.
