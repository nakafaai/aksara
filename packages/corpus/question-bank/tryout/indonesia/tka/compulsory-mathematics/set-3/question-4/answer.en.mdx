A pair is a solution only when **both inequalities hold simultaneously**. Substitute each pair into the left-hand sides and compare with the respective bounds.

| Pair | <InlineMath math="x+2y\le4" /> | <InlineMath math="2x-y\ge3" /> |
| --- | --- | --- |
| (1,1) | <InlineMath math="1+2(1)=3\le4" /> | <InlineMath math="2(1)-1=1<3" /> |
| (0,2) | <InlineMath math="0+2(2)=4\le4" /> | <InlineMath math="2(0)-2=-2<3" /> |
| (2,1) | <InlineMath math="2+2(1)=4\le4" /> | <InlineMath math="2(2)-1=3\ge3" /> |
| (3,1) | <InlineMath math="3+2(1)=5>4" /> | <InlineMath math="2(3)-1=5\ge3" /> |
| (1,0) | <InlineMath math="1+2(0)=1\le4" /> | <InlineMath math="2(1)-0=2<3" /> |

Only <InlineMath math="(2,1)" /> satisfies both conditions. The signs ≤ and ≥ include equality, so a point on both boundary lines is a valid solution.
