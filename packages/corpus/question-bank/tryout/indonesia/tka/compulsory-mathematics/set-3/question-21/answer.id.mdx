Frekuensi total adalah <InlineMath math="2+6+4+5+3=20" />. Median sepuluh data terbawah memakai data kelima dan keenam, keduanya <InlineMath math="10" />. Median sepuluh data teratas memakai data kelima belas dan keenam belas, keduanya <InlineMath math="20" />.

<BlockMath math="\begin{aligned}
Q_1&=10 \\
Q_3&=20
\end{aligned}" />

<BlockMath math="\frac{Q_3-Q_1}{Q_3+Q_1}=\frac{20-10}{20+10}=\frac13" />
