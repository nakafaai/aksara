# Finding the translation T

The question asks for the starting point <InlineMath math="B" />, not its image. So there are two steps: find the translation <InlineMath math="T" />, then **undo both transformations in reverse order**.

A translation moves every point by the same vector, so <InlineMath math="T" /> is the difference between <InlineMath math="A'" /> and <InlineMath math="A" />.

<BlockMath math="T=A'-A=(5-2,\ 3-(-1))=(3,4)" />

# Undoing in reverse order

The forward order is: reflect in the <InlineMath math="y" />-axis, then translate. To undo it, start from the last step. First **remove the translation**, then undo the reflection. A reflection in the <InlineMath math="y" />-axis undoes itself.

<BlockMath math="\begin{aligned}
B'-T&=(1-3,\ 6-4)=(-2,2) \\
B&=(2,2)
\end{aligned}" />
