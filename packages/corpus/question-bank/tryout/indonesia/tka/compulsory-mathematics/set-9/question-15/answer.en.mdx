The question asks which single transformation sends <InlineMath math="A" /> to <InlineMath math="A'" /> **and at the same time** <InlineMath math="B" /> to <InlineMath math="B'" />. Careful: every transformation in the first and third statements really does send <InlineMath math="A" /> to <InlineMath math="A'" />. So point <InlineMath math="B" /> is what decides.

# A clue from the direction of the segment

Here's the quick trick: look at the segment from <InlineMath math="A" /> to <InlineMath math="B" />. Each type of transformation changes the vector <InlineMath math="\overrightarrow{AB}" /> in a fixed way, **no matter where its centre or mirror line is**:

<BlockMath math="\begin{aligned}
\overrightarrow{AB}&=(3-1,\ 6-4)=(2,2) \\
\overrightarrow{A'B'}&=(5-7,\ 6-4)=(-2,2)
\end{aligned}" />

| Transformation | Vector <InlineMath math="(2,2)" /> becomes | Matches <InlineMath math="(-2,2)" />? |
| :---: | :---: | :---: |
| Translation | <InlineMath math="(2,2)" /> | no |
| Dilation with factor <InlineMath math="-1" /> | <InlineMath math="(-2,-2)" /> | no |
| Rotation by <InlineMath math="90^\circ" /> clockwise | <InlineMath math="(2,-2)" /> | no |
| Rotation by <InlineMath math="90^\circ" /> anticlockwise | <InlineMath math="(-2,2)" /> | yes |
| Reflection in a vertical line | <InlineMath math="(-2,2)" /> | yes |

This table filters the types. After that, check whether the centre or the mirror line fits too.

# Judging each statement

1. **False**. The translation by <InlineMath math="(6,0)" /> sends <InlineMath math="A(1,4)" /> to <InlineMath math="(7,4)" />, but it sends <InlineMath math="B(3,6)" /> to <InlineMath math="(9,6)" />, not <InlineMath math="(5,6)" />. A translation never changes the direction of a segment.
2. **False**. A <InlineMath math="90^\circ" /> clockwise rotation always turns <InlineMath math="(2,2)" /> into <InlineMath math="(2,-2)" />, but you need <InlineMath math="(-2,2)" />. So every centre fails. For example, the centre <InlineMath math="(4,1)" /> sends <InlineMath math="A" /> to <InlineMath math="(7,4)" />, but it sends <InlineMath math="B" /> to <InlineMath math="(9,2)" />.
3. **False**. The dilation with centre <InlineMath math="(4,4)" /> and factor <InlineMath math="-1" /> maps <InlineMath math="(x,y)" /> to <InlineMath math="(8-x,\ 8-y)" />. That gives <InlineMath math="A\mapsto(7,4)" />, which is right, but <InlineMath math="B\mapsto(5,2)" />, which is wrong.
4. **True**. The reflection in <InlineMath math="x=4" /> maps <InlineMath math="(x,y)" /> to <InlineMath math="(8-x,\ y)" />, so <InlineMath math="A\mapsto(7,4)" /> and <InlineMath math="B\mapsto(5,6)" />. Both are correct.
5. **True**. The type passed the filter, so now find the centre. A <InlineMath math="90^\circ" /> anticlockwise rotation about <InlineMath math="(a,b)" /> maps <InlineMath math="(x,y)" /> to <InlineMath math="\big(a-(y-b),\ b+(x-a)\big)" />. Use <InlineMath math="A\mapsto A'" />:

<BlockMath math="\begin{aligned}
a-(4-b)=7\ &\Rightarrow\ a+b=11 \\
b+(1-a)=4\ &\Rightarrow\ b-a=3 \\
a=4,\ b&=7
\end{aligned}" />

Now test <InlineMath math="B(3,6)" /> with the centre <InlineMath math="(4,7)" />: its image is <InlineMath math="\big(4-(6-7),\ 7+(3-4)\big)=(5,6)=B'" />. **Such a centre exists**, so the fifth statement is true.

So the true statements are the fourth and the fifth: the reflection in <InlineMath math="x=4" /> and the <InlineMath math="90^\circ" /> anticlockwise rotation about <InlineMath math="(4,7)" />.
