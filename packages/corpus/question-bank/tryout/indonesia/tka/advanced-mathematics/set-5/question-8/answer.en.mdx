# Given

We are given a linear function <InlineMath math="f(x)" /> and a **composition equation** involving an invertible function <InlineMath math="g" />.

# Asked

The **inverse value** <InlineMath math="g^{-1}(2)" />.

# Solution

> Find the input that sends the inner function to two by matching it directly against the given composition.

The value <InlineMath math="g^{-1}(2)" /> is **the input that makes <InlineMath math="g" /> equal <InlineMath math="2" />**. In this problem every input of <InlineMath math="g" /> has the form <InlineMath math="f(x)" />, so first find the <InlineMath math="x" /> with <InlineMath math="(g\circ f)(x)=2" />.

<BlockMath math="\begin{aligned}
\frac{x+3}{x-2}&=2 \\
x+3&=2x-4 \\
x&=7
\end{aligned}" />

The diagram below shows the path of <InlineMath math="g\circ f" /> for <InlineMath math="x=7" />. **What goes into <InlineMath math="g" /> is <InlineMath math="f(7)=13" />, not <InlineMath math="7" />**, so <InlineMath math="g^{-1}(2)" /> stops at <InlineMath math="13" />.

So <InlineMath math="g\big(f(7)\big)=2" />. The input of <InlineMath math="g" /> is <InlineMath math="f(7)=13" />, so <InlineMath math="g(13)=2" />, and because <InlineMath math="g" /> has an inverse, <InlineMath math="g^{-1}(2)=13" />.

<BlockMath math="f(7)=2\cdot7-1=13" />

Check with the full rule: let <InlineMath math="u=2x-1" />, so <InlineMath math="x" /> and <InlineMath math="g(u)" />. Indeed <InlineMath math="g(13)=2" />.

<BlockMath math="\begin{gathered}
x=\frac{u+1}{2} \\
g(u)=\frac{\frac{u+1}{2}+3}{\frac{u+1}{2}-2}=\frac{u+7}{u-3} \\
g(13)=\frac{20}{10}=2
\end{gathered}" />

So <InlineMath math="g^{-1}(2)=13" />.

Therefore, the **correct answer** is **<InlineMath math="13" />**.
