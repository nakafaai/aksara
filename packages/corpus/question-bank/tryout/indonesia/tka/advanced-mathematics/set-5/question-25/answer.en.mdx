# Given

We are given two **piecewise functions** <InlineMath math="f" /> and <InlineMath math="g" /> near their boundary points.

# Asked

The **truth value of each statement** about limits and continuity of both functions.

# Solution

> A limit can still exist at a hole in the graph, but continuity demands that the function value fills that exact hole.

These two functions test two different things: <InlineMath math="f" /> tests **the difference between a limit and a function value**, and <InlineMath math="g" /> tests one-sided limits. Simplify both first.

For <InlineMath math="x\ne3" />, <InlineMath math="f(x)=x+3" />. The function <InlineMath math="g" /> equals <InlineMath math="1" /> when <InlineMath math="x>3" /> and <InlineMath math="-1" /> when <InlineMath math="x<3" />, because <InlineMath math="|x-3|" /> is either <InlineMath math="x-3" /> or <InlineMath math="-(x-3)" />.

<BlockMath math="f(x)=\frac{(x-3)(x+3)}{x-3}=x+3" />

Draw <InlineMath math="g" /> with the product <InlineMath math="(x-3)g(x)" />. **The graph of <InlineMath math="g" /> jumps from <InlineMath math="-1" /> to <InlineMath math="1" /> at <InlineMath math="x=3" />, while the product is a V that comes down to zero**.

1. The statement the value <InlineMath math="6" /> is true, because near <InlineMath math="3" /> we have <InlineMath math="f(x)=x+3\to6" />.

   <BlockMath math="\lim_{x\to3}f(x)=6" />

2. The statement that <InlineMath math="f" /> is continuous at <InlineMath math="x=3" /> is false. The limit is <InlineMath math="6" />, but <InlineMath math="f(3)=2" />. Continuity needs the two to agree.
3. The statement the value <InlineMath math="1" /> is true, because <InlineMath math="g" /> stays <InlineMath math="1" /> for <InlineMath math="x>3" />.

   <BlockMath math="\lim_{x\to3^+}g(x)=1" />

4. The statement the value <InlineMath math="0" /> is false. The left limit <InlineMath math="-1" /> and the right limit <InlineMath math="1" /> differ, so the limit does not exist. The value <InlineMath math="0" /> is just their average.

   <BlockMath math="\lim_{x\to3}g(x)=0" />

5. The statement the value <InlineMath math="0" /> is true. For <InlineMath math="x\ne3" />, the equation below, which tends to <InlineMath math="0" /> from both sides.

   <BlockMath math="\begin{gathered} \lim_{x\to3}(x-3)\,g(x)=0 \\ (x-3)\cdot\frac{|x-3|}{x-3}=|x-3| \end{gathered}" />

# Answer

So the true statements are the value <InlineMath math="6" />, the value <InlineMath math="1" /> and the value <InlineMath math="0" />.

<BlockMath math="\begin{gathered}
\lim_{x\to3}f(x)=6 \\
\lim_{x\to3^+}g(x)=1 \\
\lim_{x\to3}(x-3)\,g(x)=0
\end{gathered}" />
