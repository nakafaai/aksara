# Given

We are given a **space vector** <InlineMath math="\vec{v}" /> with integer components.

# Asked

All **true statements** about length, unit vector, and direction angles of <InlineMath math="\vec{v}" />.

# Solution

> Find the vector length first because dividing each component by the length gives both the unit vector and direction cosines.

The length of the vector is the key to almost every statement: <InlineMath math="3" />. The angle with an axis is decided by **the sign of the matching component**, since <InlineMath math="\vec{v}\cdot\vec{i}=-2" />.

<BlockMath math="\left|\vec{v}\right|=\sqrt{4+1+4}=3" />

Draw <InlineMath math="\vec v" /> in the plane that holds <InlineMath math="\vec v" /> and the <InlineMath math="x" />-axis. **The negative <InlineMath math="x" />-component tilts <InlineMath math="\vec v" /> to the left**, so its angle with <InlineMath math="\vec i" /> is obtuse.

## Checking common traps

Let us check why these **common trap choices** miss the mark.

- **True.** <InlineMath math="3" />.

  <BlockMath math="\left|\vec{v}\right|=\sqrt{(-2)^2+1^2+2^2}=3" />

- **False.** A unit vector comes from dividing by the length, <InlineMath math="3" />, not by its square. The unit vector is <InlineMath math="\frac13\left(-2\vec{i}+\vec{j}+2\vec{k}\right)" />.
- **False.** The equation below, a negative multiple, so it points the opposite way.

  <BlockMath math="4\vec{i}-2\vec{j}-4\vec{k}=-2\vec{v}" />

- **True.** <InlineMath math="\cos\alpha<0" />, so the angle is obtuse.

  <BlockMath math="\cos\alpha=\frac{\vec{v}\cdot\vec{i}}{\left|\vec{v}\right|}=-\frac23<0" />

- **True.** <InlineMath math="3" />, because <InlineMath math="\cos\theta\le1" />. The value <InlineMath math="3" /> is reached when <InlineMath math="\vec{w}" /> points the same way as <InlineMath math="\vec{v}" />.

  <BlockMath math="\vec{v}\cdot\vec{w}=\left|\vec{v}\right|\left|\vec{w}\right|\cos\theta=3\cos\theta\le3" />

# Answer

Therefore, the correct choices are **statements <InlineMath math="1" />, <InlineMath math="4" />, and <InlineMath math="5" />**.
