# Given

We are given a **shifted exponential function** <InlineMath math="f(x)" /> on all real numbers.

# Asked

The **range** of the exponential function <InlineMath math="f(x)" />.

# Solution

> A positive power is always strictly positive, so subtracting it from three keeps every output strictly below three.

Start with the exponential part. For every real <InlineMath math="x" />, <InlineMath math="2^{x+1}" /> is positive and can be any positive number, so its range is <InlineMath math="(0,\infty)" />. **Subtracting it from <InlineMath math="3" />** flips and shifts that interval.

<BlockMath math="2^{x+1}>0\ \Leftrightarrow\ -2^{x+1}<0\ \Leftrightarrow\ 3-2^{x+1}<3" />

Draw <InlineMath math="f" /> with the line <InlineMath math="y=3" />. **To the left the curve creeps up to <InlineMath math="y=3" /> from below without ever touching it**, and to the right it falls without bound.

The value <InlineMath math="3" /> is never reached, because <InlineMath math="2^{x+1}" /> is never zero. Conversely, every <InlineMath math="y<3" /> is reached at <InlineMath math="x" />. For example, <InlineMath math="f(0)=1" />, <InlineMath math="f(-5)\approx2.94" /> and <InlineMath math="f(5)=-61" />.

<BlockMath math="x=\log_2(3-y)-1" />

So the range is <InlineMath math="\{y\mid y<3,\ y\in\mathbb{R}\}" />.

## Checking common traps

Let us check why these **common trap choices** miss the mark.

- <InlineMath math="y>3" /> forgets that <InlineMath math="2^{x+1}" /> is subtracted, so the inequality points the wrong way.
- <InlineMath math="y\leq3" /> includes <InlineMath math="3" />, which would need <InlineMath math="2^{x+1}=0" />.
- <InlineMath math="y\leq1" /> takes the smallest value of <InlineMath math="2^{x+1}" /> to be <InlineMath math="2" />, as if <InlineMath math="x" /> could not be negative.
- All real numbers ignores that <InlineMath math="f" /> is bounded above.

# Answer

Therefore, the **correct answer** is **<InlineMath math="\{y\mid y<3,\ y\in\mathbb{R}\}" />**.
