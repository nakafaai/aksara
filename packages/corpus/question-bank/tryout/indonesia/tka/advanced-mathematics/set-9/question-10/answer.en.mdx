# Solution

> Always check which time bracket a rental duration falls into before plugging into that piece formula.

The function has two rules: **a flat fee for the first two hours**, then an extra <InlineMath math="\text{Rp}6{,}000.00" /> per hour after that. Pick the rule that matches the value of <InlineMath math="t" />.

1. **False.** <InlineMath math="t>2" />, so <InlineMath math="B(5)=33{,}000" />, not <InlineMath math="30{,}000" />.

   <BlockMath math="\begin{gathered} t=5>2 \\ B(5)=15{,}000+6{,}000\cdot3=33{,}000 \end{gathered}" />

2. **True.** Both <InlineMath math="1" /> and <InlineMath math="2" /> lie in <InlineMath math="0<t\le2" />, so <InlineMath math="B(1)=15{,}000" />.

   <BlockMath math="B(1)=B(2)=15{,}000" />

3. **True.** For <InlineMath math="t>2" />, the condition is <InlineMath math="15{,}000+6{,}000(t-2)\le45{,}000" />, that is <InlineMath math="t-2\le5" />, so <InlineMath math="t\le7" />. Exactly <InlineMath math="7" /> hours costs <InlineMath math="B(7)=45{,}000" />.
4. **False.** A function has an inverse only if each output comes from exactly one value of <InlineMath math="t" />. Here the output <InlineMath math="15{,}000" /> comes from every <InlineMath math="t" /> in <InlineMath math="0<t\le2" />, for example <InlineMath math="t=1" /> and <InlineMath math="t=2" />.

Therefore, **statements <InlineMath math="2" /> and <InlineMath math="3" /> are True**, while **statements <InlineMath math="1" /> and <InlineMath math="4" /> are False**.
