# Given

We are given a **trigonometric product** as the variable <InlineMath math="x" /> grows without bound.

# Asked

The **limit at infinity** of the sine product.

# Solution

> Substitute a tiny new angle for the reciprocal so the limit at infinity turns into the classic sine limit at zero.

As <InlineMath math="x\to\infty" />, the factor <InlineMath math="x" /> grows while <InlineMath math="\sin\frac3x" /> shrinks toward <InlineMath math="0" />. This <InlineMath math="\infty\cdot0" /> form does not show the limit yet. **Change the variable** so that the basic limit the value <InlineMath math="1" /> appears.

<BlockMath math="\lim_{u\to0}\frac{\sin u}{u}=1" />

Let <InlineMath math="u=\frac3x" />. As <InlineMath math="x\to\infty" />, <InlineMath math="u\to0^+" />, and <InlineMath math="x=\frac3u" />.

<BlockMath math="\lim_{x\to\infty}x\sin\frac3x=\lim_{u\to0^+}\frac3u\sin u=3\lim_{u\to0^+}\frac{\sin u}{u}=3\cdot1=3" />

Draw <InlineMath math="x\sin\frac3x" /> for large <InlineMath math="x" />. **The growing factor and the shrinking sine balance out**, so the curve hugs the line <InlineMath math="y=3" />.
