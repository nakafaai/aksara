# Given

The user count of a **learning app** after <InlineMath math="t" /> months follows an exponential growth model.

# Asked

The **truth of each model statement** or time to reach a user milestone.

# Solution

> In exponential growth, equal time steps always multiply the count by the same constant growth factor.

An exponential model <InlineMath math="N(t)=N_0\cdot2^{t/k}" /> has two meanings you can read off directly: <InlineMath math="N_0" /> is the starting value, and <InlineMath math="k" /> is **the time it takes to double**. Here <InlineMath math="N_0=500" /> and <InlineMath math="k=3" />.

Draw <InlineMath math="N(t)" /> with a point every <InlineMath math="3" /> months. **Every <InlineMath math="3" /> months the height doubles**, from <InlineMath math="500" /> to <InlineMath math="1{,}000" />, <InlineMath math="2{,}000" />, <InlineMath math="4{,}000" />, and then <InlineMath math="8{,}000" />.

1. The statement about the start is false. At <InlineMath math="t=0" />, <InlineMath math="N(0)=500" /> users.

   <BlockMath math="N(0)=500\cdot2^0=500" />

2. The statement about doubling every <InlineMath math="3" /> months is true, because <InlineMath math="2N(t)" />.

   <BlockMath math="N(t+3)=500\cdot2^{(t+3)/3}=2\cdot500\cdot2^{t/3}=2N(t)" />

3. The statement <InlineMath math="N(6)=1{,}500" /> is false. Six months contain two doublings: <InlineMath math="N(6)=2{,}000" />. The value <InlineMath math="1{,}500" /> treats the growth as adding a fixed amount, but this model multiplies.

   <BlockMath math="N(6)=500\cdot2^2=2{,}000" />

4. The statement about <InlineMath math="t=12" /> is true: <InlineMath math="N(12)=8{,}000" />.

   <BlockMath math="N(12)=500\cdot2^4=500\cdot16=8{,}000" />

# Answer

So the statements about doubling every <InlineMath math="3" /> months and about <InlineMath math="t=12" /> are true, and the statements about the start and <InlineMath math="N(6)" /> are false.
