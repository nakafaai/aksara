# Given

We are given a **piecewise function** <InlineMath math="f(x)" /> whose formula changes across boundary points.

# Asked

The **truth value of each statement** about left limits, right limits, and continuity.

# Solution

> A graph connects smoothly only when the left path, right path, and middle dot all meet at the exact same height.

This piecewise function is built from rules that are each continuous. So the interesting limits are only **at the joins**, <InlineMath math="x=1" /> and <InlineMath math="x=3" />, where you compare the left and right limits.

<BlockMath math="\begin{aligned}
\lim_{x\to1^-}f(x)&=1^2-1=0, &\lim_{x\to1^+}f(x)&=2(1)-2=0, &f(1)&=0 \\
\lim_{x\to3^-}f(x)&=2(3)-2=4, &\lim_{x\to3^+}f(x)&=8-3=5, &f(3)&=4
\end{aligned}" />

Draw the three pieces of <InlineMath math="f" />. **At <InlineMath math="x=1" /> the pieces meet with no gap, but at <InlineMath math="x=3" /> the graph jumps from <InlineMath math="4" /> to <InlineMath math="5" />**, so the limit at <InlineMath math="3" /> doesn't exist.

1. The statement the value <InlineMath math="0" /> is true, because the left and right limits are both <InlineMath math="0" />.

   <BlockMath math="\lim_{x\to1}f(x)=0" />

2. The statement the value <InlineMath math="4" /> is false. The left limit is <InlineMath math="4" /> and the right limit is <InlineMath math="5" />, so the limit does not exist. The value <InlineMath math="f(3)=4" /> does not help, because a limit ignores the value at the point.

   <BlockMath math="\lim_{x\to3}f(x)=4" />

3. The statement that <InlineMath math="f" /> is continuous at <InlineMath math="x=1" /> is true: the limit exists and equals <InlineMath math="f(1)=0" />.
4. The statement the value <InlineMath math="4" /> is false. From the right the rule is <InlineMath math="8-x" />, so the limit is <InlineMath math="5" />.

   <BlockMath math="\lim_{x\to3^+}f(x)=4" />

5. The statement the value <InlineMath math="-1" /> is true. For <InlineMath math="x>3" />, <InlineMath math="\frac8x-1" />, which tends to <InlineMath math="0-1=-1" />.

   <BlockMath math="\begin{gathered} \lim_{x\to\infty}\frac{f(x)}{x}=-1 \\ \frac{f(x)}{x}=\frac{8-x}{x}=\frac8x-1 \end{gathered}" />

# Answer

So the true statements are the value <InlineMath math="0" />, the continuity of <InlineMath math="f" /> at <InlineMath math="x=1" />, and the value <InlineMath math="-1" />.

<BlockMath math="\begin{gathered}
\lim_{x\to1}f(x)=0 \\
\lim_{x\to\infty}\frac{f(x)}{x}=-1
\end{gathered}" />
