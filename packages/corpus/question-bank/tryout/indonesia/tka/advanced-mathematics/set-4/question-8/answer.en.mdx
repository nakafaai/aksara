# Given

We are given an **exponential function** <InlineMath math="f(x)" /> defined on all real numbers.

# Asked

The **requested inverse value** of the exponential function.

# Solution

> Evaluating an inverse simply asks which input makes the original function output the target number.

You do not need to write a formula for <InlineMath math="f^{-1}" /> first. The value <InlineMath math="f^{-1}(c)" /> is **the number that <InlineMath math="f" /> sends to <InlineMath math="c" />**, so just solve <InlineMath math="f(x)=c" />. A composition works from the inside, so find <InlineMath math="f^{-1}(67)" /> first.

<BlockMath math="\begin{aligned}
2^{x-1}+3&=67 \\
2^{x-1}&=64=2^6 \\
x-1&=6\ \Rightarrow\ f^{-1}(67)=7
\end{aligned}" />

Now find <InlineMath math="f^{-1}(7)" />.

<BlockMath math="\begin{aligned}
2^{x-1}+3&=7 \\
2^{x-1}&=4=2^2 \\
x-1&=2\ \Rightarrow\ f^{-1}(7)=3
\end{aligned}" />

The diagram below shows both inverse steps. **Each <InlineMath math="f^{-1}" /> steps back through one <InlineMath math="f" />**, so from <InlineMath math="67" /> you step back twice to reach <InlineMath math="3" />.

Check in the other direction: <InlineMath math="f(3)=7" /> and <InlineMath math="f(7)=67" />.

<BlockMath math="\begin{gathered}
f(3)=4+3=7 \\
f(7)=64+3=67
\end{gathered}" />

So <InlineMath math="\left(f^{-1}\circ f^{-1}\right)(67)=3" />.

## Checking common traps

Let us check why these **common trap choices** miss the mark.

- <InlineMath math="7" /> stops after applying <InlineMath math="f^{-1}" /> once.
- <InlineMath math="0" /> uses an inverse formula with a sign slip, <InlineMath math="{}^{2}\log(x-3)-1" />, which gives <InlineMath math="5" /> and then <InlineMath math="0" />.
- <InlineMath math="5" /> is the first step with that same wrong inverse formula.
- <InlineMath math="2" /> forgets to add <InlineMath math="1" /> in the second step and stops at <InlineMath math="x-1=2" />.

# Answer

Combining all the steps above gives the **final answer** requested by the problem.
