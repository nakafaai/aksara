# Given

**The trigonometric function** **<InlineMath math="f(x)" />** is defined on **<InlineMath math="x" /> from <InlineMath math="0^\circ" /> to <InlineMath math="180^\circ" />**.

<BlockMath math="f(x) = 1 + 4\cos(2x - 40^\circ)" />

# Asked

The **minimum value of** <InlineMath math="f" /> and the **value of** <InlineMath math="x" /> where it occurs.

# Solution

> Cosine can never dip below minus one, so set the cosine part equal to minus one and solve for the angle inside the interval.

Cosine only takes values from <InlineMath math="-1" /> to <InlineMath math="1" />. The **smallest function value** therefore occurs when <InlineMath math="\cos(2x-40^\circ)=-1" />.

<BlockMath math="f_{\min}=1+4\cdot(-1)=-3" />

Cosine equals <InlineMath math="-1" /> when its argument is <InlineMath math="180^\circ" /> plus a multiple of <InlineMath math="360^\circ" />.

<BlockMath math="\begin{aligned}
2x-40^\circ&=180^\circ+k\cdot360^\circ \\
x&=110^\circ+k\cdot180^\circ
\end{aligned}" />

Draw <InlineMath math="f" /> over the whole interval. **The graph swings between <InlineMath math="-3" /> and <InlineMath math="5" />, and it has only one lowest point in this interval**.

In the interval <InlineMath math="0^\circ\le x\le180^\circ" /> only <InlineMath math="x=110^\circ" /> qualifies.

As a check, <InlineMath math="f(110^\circ)=-3" />.

<BlockMath math="f(110^\circ)=1+4\cos180^\circ=1-4=-3" />

## Checking common traps

Let us check why these **common trap choices** miss the mark.

- At <InlineMath math="x=20^\circ" />, <InlineMath math="\cos0^\circ=1" />, so this is where the maximum <InlineMath math="5" /> lies, not the minimum.
- <InlineMath math="x=70^\circ" /> comes from the wrong sign of the shift, that is, from <InlineMath math="2x+40^\circ=180^\circ" />. In fact <InlineMath math="f(70^\circ) \approx 0.31" />.

  <BlockMath math="f(70^\circ)=1+4\cos100^\circ\approx0.31" />

- <InlineMath math="-4" /> uses only the amplitude and forgets the upward shift of <InlineMath math="1" />.
- <InlineMath math="5" /> at <InlineMath math="x=20^\circ" /> is the maximum of the function.

# Answer

So the minimum value is <InlineMath math="-3" />, reached at <InlineMath math="x=110^\circ" />.
