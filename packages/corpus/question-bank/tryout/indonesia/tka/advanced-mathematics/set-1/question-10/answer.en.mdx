# Given

Sound intensity level follows a **base-** <InlineMath math="10" /> logarithmic model relative to reference intensity <InlineMath math="I_0 = 10^{-12}\text{ W/m}^2" />.

# Asked

Whether each of the four statements about the model is **True** or **False**.

# Solution

> With logarithms, multiplying the sound intensity by a factor adds a fixed number of decibels instead of multiplying the decibels.

This model is a **logarithmic function**. The most useful property is <InlineMath math="\log(pq)=\log p+\log q" />: multiplying the intensity turns into adding to the intensity level. Use this property to judge each statement.

1. The statement about the intensity becoming <InlineMath math="100" /> times as large is true. The new intensity level splits into two logarithms.

<BlockMath math="L(100I)=10\log\frac{100I}{I_0}=10\left(\log100+\log\frac{I}{I_0}\right)=20+L(I)" />

Draw <InlineMath math="L" /> against <InlineMath math="\frac{I}{I_0}" />. **The curve keeps flattening, so the same added intensity gives smaller and smaller decibel gains**, while every multiplication of the intensity by <InlineMath math="10" /> always adds <InlineMath math="10" /> dB.

2. The statement that an <InlineMath math="80" /> dB sound is twice as intense as a <InlineMath math="40" /> dB sound is false. From <InlineMath math="L" />, the intensity is <InlineMath math="I=I_0\cdot10^{L/10}" />. The <InlineMath math="80" /> dB sound has <InlineMath math="I=I_0\cdot10^8" /> and the <InlineMath math="40" /> dB sound has <InlineMath math="I=I_0\cdot10^4" />, so their ratio is <InlineMath math="10^4=10{,}000" />, not <InlineMath math="2" />.

   <BlockMath math="L=10\log\frac{I}{I_0}" />

3. The statement that every extra <InlineMath math="10^{-12}\text{ W/m}^2" /> adds <InlineMath math="10" /> dB is false. A logarithmic model does not add the same number of decibels for the same added intensity. For example, from <InlineMath math="I_0" /> to <InlineMath math="2I_0" /> the level rises from <InlineMath math="0" /> to <InlineMath math="10\log2" />, which is less than <InlineMath math="10" /> because <InlineMath math="\log2=1" />. A rise of exactly <InlineMath math="10" /> dB from <InlineMath math="I_0" /> needs the intensity <InlineMath math="10I_0" />, an extra <InlineMath math="9\cdot10^{-12}\text{ W/m}^2" />.

   <BlockMath math="\log2<\log10=1" />

4. The statement about the sound with intensity <InlineMath math="10^{-12}\text{ W/m}^2" /> is true. That intensity equals <InlineMath math="I_0" />, so <InlineMath math="L(I_0)=0" /> dB.

   <BlockMath math="L(I_0)=10\log1=10\cdot0=0" />

# Answer

So the statements about the intensity becoming <InlineMath math="100" /> times as large and about the sound with intensity <InlineMath math="I_0" /> are true, while the other two statements are false.
