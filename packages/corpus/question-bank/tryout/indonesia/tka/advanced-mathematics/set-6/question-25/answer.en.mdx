To see how <InlineMath math="h" /> behaves near <InlineMath math="0" />, **remove the root from the numerator** by multiplying by the conjugate <InlineMath math="\sqrt{x+4}+2" />.

<BlockMath math="h(x)=\frac{(x+4)-4}{x\left(\sqrt{x+4}+2\right)}=\frac{1}{\sqrt{x+4}+2},\qquad x\ne0" />

1. The statement <InlineMath math="\lim_{x\to0}h(x)=\frac14" /> is true: <InlineMath math="\frac{1}{\sqrt4+2}=\frac14" />.
2. The statement <InlineMath math="h(0)=\frac14" /> is false. <InlineMath math="h(0)" /> is undefined, because <InlineMath math="x=0" /> is not in the domain. The limit exists, but the function value does not.
3. The statement <InlineMath math="\lim_{x\to\infty}h(x)=1" /> is false. The denominator <InlineMath math="\sqrt{x+4}+2" /> grows without bound, so <InlineMath math="h(x)\to0" />.
4. The statement <InlineMath math="\lim_{x\to-4^+}h(x)=\frac12" /> is true. The simplified form is continuous at <InlineMath math="x=-4" /> from the right, so the limit is <InlineMath math="\frac{1}{0+2}=\frac12" />. The original formula gives the same value, <InlineMath math="h(-4)=\frac{0-2}{-4}=\frac12" />.
5. The statement <InlineMath math="\lim_{x\to0}x\,h(x)=0" /> is true, because <InlineMath math="x\,h(x)=\sqrt{x+4}-2\to2-2=0" />.

So the true statements are <InlineMath math="\lim_{x\to0}h(x)=\frac14" />, <InlineMath math="\lim_{x\to-4^+}h(x)=\frac12" /> and <InlineMath math="\lim_{x\to0}x\,h(x)=0" />.
