# Given

We are given a **radical function** <InlineMath math="h(x)" /> defined for <InlineMath math="x\ge-4" /> with <InlineMath math="x\ne0" />.

# Asked

The **truth value of each statement** about the limit at the hole and function behavior.

# Solution

> Rationalize the square root first so the matching zero factor cancels cleanly from numerator and denominator.

To see how <InlineMath math="h" /> behaves near <InlineMath math="0" />, **remove the root from the numerator** by multiplying by the conjugate <InlineMath math="\sqrt{x+4}+2" />.

<BlockMath math="h(x)=\frac{(x+4)-4}{x\left(\sqrt{x+4}+2\right)}=\frac{1}{\sqrt{x+4}+2},\qquad x\ne0" />

Draw <InlineMath math="h" /> after simplifying. **Its graph is a curve falling slowly towards <InlineMath math="0" />, with one hole at <InlineMath math="x=0" />**, and its left end at <InlineMath math="\left(-4,\ \tfrac12\right)" />.

1. The statement the value <InlineMath math="\frac14" /> is true: the equation below.

   <BlockMath math="\begin{gathered} \lim_{x\to0}h(x)=\frac14 \\ \frac{1}{\sqrt4+2}=\frac14 \end{gathered}" />

2. The statement <InlineMath math="h(0)=\frac14" /> is false. <InlineMath math="h(0)" /> is undefined, because <InlineMath math="x=0" /> is not in the domain. The limit exists, but the function value does not.
3. The statement the value <InlineMath math="1" /> is false. The denominator <InlineMath math="\sqrt{x+4}+2" /> grows without bound, so <InlineMath math="h(x)\to0" />.

   <BlockMath math="\lim_{x\to\infty}h(x)=1" />

4. The statement the value <InlineMath math="\frac12" /> is true. The simplified form is continuous at <InlineMath math="x=-4" /> from the right, so the limit is the equation below. The original formula gives the same value, <InlineMath math="\frac12" />.

   <BlockMath math="\begin{gathered} \lim_{x\to-4^+}h(x)=\frac12 \\ \frac{1}{0+2}=\frac12 \\ h(-4)=\frac{0-2}{-4}=\frac12 \end{gathered}" />

5. The statement the value <InlineMath math="0" /> is true, because <InlineMath math="x\,h(x)=0" />.

   <BlockMath math="\begin{gathered} \lim_{x\to0}x\,h(x)=0 \\ x\,h(x)=\sqrt{x+4}-2\to2-2=0 \end{gathered}" />

# Answer

So the true statements are the value <InlineMath math="\frac14" />, the value <InlineMath math="\frac12" /> and the value <InlineMath math="0" />.

<BlockMath math="\begin{gathered}
\lim_{x\to0}h(x)=\frac14 \\
\lim_{x\to-4^+}h(x)=\frac12 \\
\lim_{x\to0}x\,h(x)=0
\end{gathered}" />
