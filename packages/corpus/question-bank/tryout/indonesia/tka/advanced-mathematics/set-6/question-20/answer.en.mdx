A fixed point satisfies <InlineMath math="(x',y')=(x,y)" />. So **set each image coordinate equal to the original coordinate**.

<BlockMath math="\begin{aligned}
3x-2y&=x\ \Rightarrow\ 2x=2y\ \Rightarrow\ y=x \\
x&=y
\end{aligned}" />

Both equations give the same condition, <InlineMath math="y=x" />, so there are infinitely many fixed points: the whole line <InlineMath math="y=x" />. Check: <InlineMath math="T(5,5)=(15-10,\ 5)=(5,5)" />, while <InlineMath math="T(1,0)=(3,1)\ne(1,0)" />.

So the fixed points of <InlineMath math="T" /> are all the points on the line <InlineMath math="y=x" />.

- Only the point <InlineMath math="O" /> assumes the origin is the only point that stays. The origin is always fixed, but here the two conditions depend on each other.
- The line <InlineMath math="y=-x" /> comes from a sign slip when solving <InlineMath math="3x-2y=x" />. For example <InlineMath math="T(1,-1)=(5,1)" />.
- The <InlineMath math="x" />-axis is not fixed, because <InlineMath math="T(1,0)=(3,1)" />.
- The line <InlineMath math="y=2x" /> is not fixed, because <InlineMath math="T(1,2)=(-1,1)" />.
