# Given

A linear transformation <InlineMath math="T" /> is given by its **coordinate mapping rule** on <InlineMath math="(x,y)" />.

# Asked

The **property or image** produced by linear transformation <InlineMath math="T" />.

# Solution

> Pack the rule coefficients into a two-by-two matrix so its determinant and geometric effect stand out immediately.

A fixed point satisfies <InlineMath math="(x',y')=(x,y)" />. So **set each image coordinate equal to the original coordinate**.

<BlockMath math="\begin{aligned}
3x-2y&=x\ \Rightarrow\ 2x=2y\ \Rightarrow\ y=x \\
x&=y
\end{aligned}" />

Draw the line of fixed points and one point that isn't fixed. **Every point on <InlineMath math="y=x" /> stays put**, while a point off that line moves, for example <InlineMath math="(1,0)" /> to <InlineMath math="(3,1)" />.

Both equations give the same condition, <InlineMath math="y=x" />, so there are infinitely many fixed points: the whole line <InlineMath math="y=x" />. Check: <InlineMath math="T(5,5)=(5,5)" />, while <InlineMath math="T(1,0) \ne (1,0)" />.

<BlockMath math="\begin{gathered}
T(5,5)=(15-10,\ 5)=(5,5) \\
T(1,0)=(3,1)\ne(1,0)
\end{gathered}" />

So the fixed points of <InlineMath math="T" /> are all the points on the line <InlineMath math="y=x" />.

## Checking common traps

Let us check why these **common trap choices** miss the mark.

- Only the point <InlineMath math="O" /> assumes the origin is the only point that stays. The origin is always fixed, but here the two conditions depend on each other.
- The line <InlineMath math="y=-x" /> comes from a sign slip when solving <InlineMath math="3x-2y=x" />. For example <InlineMath math="T(1,-1)=(5,1)" />.
- The <InlineMath math="x" />-axis is not fixed, because <InlineMath math="T(1,0)=(3,1)" />.
- The line <InlineMath math="y=2x" /> is not fixed, because <InlineMath math="T(1,2)=(-1,1)" />.
