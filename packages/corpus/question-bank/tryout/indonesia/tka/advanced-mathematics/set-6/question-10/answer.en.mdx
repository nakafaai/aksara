# Given

We are given two **real functions** <InlineMath math="f" /> and <InlineMath math="g" /> defined on all real numbers.

# Asked

The **truth value of each statement** about compositions and properties of both functions.

# Solution

> Always evaluate compositions from the inside out because machine order changes the final output.

In a composition, **the function written on the right acts first**: the equation below and the equation below.

<BlockMath math="\begin{gathered}
(f\circ g)(x)=f\big(g(x)\big) \\
(g\circ f)(x)=g\big(f(x)\big)
\end{gathered}" />

1. The statement <InlineMath math="(f\circ g)(1)=1" /> is false. <InlineMath math="g(1)=0" />, then <InlineMath math="f(0)=2" />.

   <BlockMath math="f(0)=|0-2|=2" />

2. The statement <InlineMath math="(g\circ f)(5)=8" /> is true. <InlineMath math="f(5)=3" />, then <InlineMath math="g(3)=8" />.

   <BlockMath math="g(3)=9-1=8" />

3. The statement that both compositions always agree is false. One counterexample is enough: at <InlineMath math="x=1" />, <InlineMath math="(f\circ g)(1)=2" /> while <InlineMath math="(g\circ f)(1)=0" />.

   <BlockMath math="(g\circ f)(1)=g(1)=0" />

4. The statement about exactly two solutions is true. Write the equation and solve the absolute value.

<BlockMath math="\begin{aligned}
|x-2|^2-1&=0 \\
|x-2|&=1 \\
x-2=1\ \text{or}\ x-2=-1&\ \Rightarrow\ x=3\ \text{or}\ x=1
\end{aligned}" />

Draw both compositions. **Their graphs differ, so composition isn't commutative**, and <InlineMath math="g\circ f" /> crosses the <InlineMath math="x" />-axis at exactly two points.

The case <InlineMath math="|x-2|=-1" /> is impossible, because an absolute value is never negative. So there are exactly two solutions.

# Answer

So the statements about <InlineMath math="(g\circ f)(5)" /> and the two solutions are true, and the statements about <InlineMath math="(f\circ g)(1)" /> and the equality of the compositions are false.
