# Given

# Asked

# Solution

> More fabric pushes one boundary line outward, so check whether the new corner yields a larger profit.

The cloth limit is now <InlineMath math="2x+y\le43" />, while the sewing limit stays <InlineMath math="x+2y\le50" />. At the old plan <InlineMath math="(10,20)" /> both limits were used up, so **the optimum slides along the sewing line** to the new crossing point.

<BlockMath math="\begin{aligned}
2x+y=43,\ x+2y=50&\ \Rightarrow\ y=43-2x,\ x+86-4x=50 \\
&\ \Rightarrow\ x=12,\quad y=19
\end{aligned}" />

The corner <InlineMath math="(12,19)" /> has whole-number coordinates, so the plan can be made. Compare it with the other corners.

<BlockMath math="\begin{aligned}
P(12,19)&=360+380=740 \\
P(0,25)&=500 \\
P(21.5,\ 0)&=645
\end{aligned}" />

Slide the fabric line from <InlineMath math="2x+y=40" /> to <InlineMath math="2x+y=43" />. **The optimal corner slides along the sewing line**, from <InlineMath math="(10,\ 20)" /> to <InlineMath math="(12,\ 19)" />.
