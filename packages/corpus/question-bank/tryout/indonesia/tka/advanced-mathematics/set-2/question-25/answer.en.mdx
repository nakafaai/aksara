# Given

**The rational function** **<InlineMath math="f(x)" />** is defined for all reals except <InlineMath math="-1" /> and <InlineMath math="2" />.

<BlockMath math="f(x) = \frac{x^2 - 4}{x^2 - x - 2}" />

# Asked

**All true statements** about the limits of <InlineMath math="f" />.

# Solution

> Factor top and bottom first so x minus two cancels cleanly, revealing the hole, vertical asymptote, and limit at infinity at a glance.

Factor the numerator and the denominator first, because **the common factor and the factors that remain** decide how the limit behaves at each point.

<BlockMath math="f(x)=\frac{(x-2)(x+2)}{(x-2)(x+1)}=\frac{x+2}{x+1},\qquad x\ne-1,\ x\ne2" />

Draw <InlineMath math="f" /> after simplifying. **At <InlineMath math="x=2" /> the graph only has a hole, while at <InlineMath math="x=-1" /> the two branches run off in opposite directions**, so the limit exists at <InlineMath math="2" /> but not at <InlineMath math="-1" />.

The simplification is valid at every point of the domain, because there <InlineMath math="x-2\ne0" />.

1. The statement the value <InlineMath math="\frac43" /> is true. A limit only uses values near <InlineMath math="2" />, so the value <InlineMath math="\frac{4}{3}" />.

   <BlockMath math="\begin{gathered} \lim_{x\to2}f(x)=\frac43 \\ \lim_{x\to2}\frac{x+2}{x+1}=\frac{4}{3} \end{gathered}" />

2. The statement the value <InlineMath math="1" /> is true. Numerator and denominator have the same degree and leading coefficient <InlineMath math="1" />, so the limit is <InlineMath math="\frac11=1" />.

   <BlockMath math="\lim_{x\to\infty}f(x)=1" />

3. The statement that <InlineMath math="f" /> is continuous at <InlineMath math="x=2" /> is false. The limit exists, but <InlineMath math="f(2)" /> is undefined, so the condition for continuity fails.
4. The statement that the expression below exists is false. As <InlineMath math="x\to-1" />, the numerator <InlineMath math="x+2\to1" /> while the denominator <InlineMath math="x+1\to0" />. From the right the values go to <InlineMath math="+\infty" />, from the left to <InlineMath math="-\infty" />.

   <BlockMath math="\lim_{x\to-1}f(x)" />

5. The statement the value <InlineMath math="2" /> is true, because <InlineMath math="f" /> is continuous at <InlineMath math="0" /> and <InlineMath math="f(0)=2" />.

   <BlockMath math="\begin{gathered} \lim_{x\to0}f(x)=2 \\ f(0)=\frac{-4}{-2}=2 \end{gathered}" />

# Answer

So the true statements are the value <InlineMath math="\frac43" />, the value <InlineMath math="1" /> and the value <InlineMath math="2" />.

<BlockMath math="\begin{gathered}
\lim_{x\to2}f(x)=\frac43 \\
\lim_{x\to\infty}f(x)=1 \\
\lim_{x\to0}f(x)=2
\end{gathered}" />
