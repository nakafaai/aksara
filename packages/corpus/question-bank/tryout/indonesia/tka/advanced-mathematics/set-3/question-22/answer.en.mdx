# Given

# Asked

The **trigonometric limit** as <InlineMath math="x" /> approaches zero.

# Solution

> For tiny angles in radians, sine and tangent closely match the angle itself, letting us read the limit ratio cleanly.

Direct substitution gives <InlineMath math="\frac00" />. Use the basic limit the value <InlineMath math="a" />. To apply it, **divide numerator and denominator by** <InlineMath math="x" />.

<BlockMath math="\begin{gathered}
\lim_{x\to0}\frac{\sin ax}{x}=a \\
\lim_{x\to0}h(x)=\lim_{x\to0}\frac{\sin5x-\sin x}{\sin2x}=\lim_{x\to0}\frac{\dfrac{\sin5x}{x}-\dfrac{\sin x}{x}}{\dfrac{\sin2x}{x}}=\frac{5-1}{2}=2
\end{gathered}" />

Dividing by <InlineMath math="x" /> is allowed because <InlineMath math="x\ne0" /> near the limit point, and all three basic limits exist with a nonzero limit in the denominator.

The sum-to-product formula agrees: the equation below, so the fraction becomes <InlineMath math="2\cos3x" />, which tends to <InlineMath math="2\cos0=2" />.

<BlockMath math="\sin5x-\sin x=2\cos3x\sin2x" />

So as <InlineMath math="x" /> gets closer to <InlineMath math="0" />, <InlineMath math="h(x)" /> gets closer to <InlineMath math="2" />.
