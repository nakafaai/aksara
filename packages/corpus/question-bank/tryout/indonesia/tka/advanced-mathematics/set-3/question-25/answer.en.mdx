# Given

We are given a **rational function** <InlineMath math="f(x)" /> with a quadratic denominator for <InlineMath math="x\ne\pm1" />.

# Asked

The **truth value of each statement** about limits, vertical asymptotes, and behavior at infinity.

# Solution

> The highest powers govern the limit at infinity, while the roots of the denominator show where the function breaks.

Each statement asks how <InlineMath math="f" /> behaves near a point or for very large <InlineMath math="x" />. Factor first to see **which factor tends to zero** at each point: <InlineMath math="f(x)" />.

<BlockMath math="f(x)=\frac{x(2x+3)}{(x-1)(x+1)}" />

Draw <InlineMath math="f" /> with its boundary lines. **The graph hugs <InlineMath math="y=2" /> for large <InlineMath math="x" /> and shoots off near the two vertical lines <InlineMath math="x=\pm1" />**, where the denominator goes to zero but the numerator doesn't.

1. The statement the value <InlineMath math="2" /> is true. Numerator and denominator both have degree two, so the limit is the ratio of the <InlineMath math="x^2" />-coefficients, <InlineMath math="\frac21" />.

   <BlockMath math="\lim_{x\to\infty}f(x)=2" />

2. The statement the value <InlineMath math="\infty" /> is true. The numerator tends to <InlineMath math="0" />. For <InlineMath math="x" /> slightly above <InlineMath math="1" />, the denominator <InlineMath math="x^2-1" /> is positive and tends to zero, so the fraction becomes a very large positive number.

   <BlockMath math="\begin{gathered} \lim_{x\to1^+}f(x)=\infty \\ 1\cdot5=5>0 \end{gathered}" />

3. The statement the value <InlineMath math="-\frac12" /> is false. The numerator tends to <InlineMath math="2-3=-1\ne0" /> while the denominator tends to zero, so <InlineMath math="f" /> grows without bound and has no real limit there.

   <BlockMath math="\lim_{x\to-1}f(x)=-\frac12" />

4. The statement the value <InlineMath math="-3" /> is true. For <InlineMath math="x\ne0" /> the factor <InlineMath math="x" /> cancels: the equation below, which tends to the equation below.

   <BlockMath math="\begin{gathered} \lim_{x\to0}\frac{f(x)}{x}=-3 \\ \frac{f(x)}{x}=\frac{2x+3}{x^2-1} \\ \frac{3}{-1}=-3 \end{gathered}" />

5. The statement the value <InlineMath math="0" /> is false. Compute the difference first.

   <BlockMath math="\lim_{x\to\infty}x\big(f(x)-2\big)=0" />

<BlockMath math="\begin{aligned}
f(x)-2&=\frac{2x^2+3x-2(x^2-1)}{x^2-1}=\frac{3x+2}{x^2-1} \\
\lim_{x\to\infty}x\cdot\frac{3x+2}{x^2-1}&=\lim_{x\to\infty}\frac{3x^2+2x}{x^2-1}=3
\end{aligned}" />

The difference does tend to zero, but multiplied by <InlineMath math="x" /> it tends to <InlineMath math="3" />, not <InlineMath math="0" />.

# Answer

So the true statements are the value <InlineMath math="2" />, the value <InlineMath math="\infty" /> and the value <InlineMath math="-3" />.

<BlockMath math="\begin{gathered}
\lim_{x\to\infty}f(x)=2 \\
\lim_{x\to1^+}f(x)=\infty \\
\lim_{x\to0}\frac{f(x)}{x}=-3
\end{gathered}" />
