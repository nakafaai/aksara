# Solution

> The dot product connects vector components straight to projection lengths and angles.

Almost every statement depends on **the dot product as a function of <InlineMath math="m" />**, so compute it first, together with the length of <InlineMath math="\vec{a}" />.

<BlockMath math="\vec{a}\cdot\vec{b}=2\cdot1+(-2)\cdot m+1\cdot4=6-2m,\qquad \left|\vec{a}\right|=\sqrt{4+4+1}=3" />

- **False.** If <InlineMath math="\vec{b}=t\,\vec{a}" />, the first components give <InlineMath math="1=2t" />, so <InlineMath math="t=\frac12" />. The third components then need <InlineMath math="4=\frac12" />, which is impossible. No value of <InlineMath math="m" /> makes them parallel.
