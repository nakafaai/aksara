# Given

# Solution

> Faster binding relaxes one boundary line, opening up a new corner to test for higher profit.

The binding limit becomes <InlineMath math="2x+2y\le120" />, that is <InlineMath math="x+y\le60" />. The cutting limit stays <InlineMath math="x+2y\le80" />. The feasible region changes, so **every corner must be found again**, including the ones on the axes.

<BlockMath math="\begin{gathered}
\begin{aligned}

\begin{aligned}
