## Path Length and Position Change

When an object moves from a starting point to an ending point, two quantities can sound similar but mean different things: **distance** and **displacement**.

**Distance** is the total length of the path traveled. If the path turns, every part of the turn is included. **Displacement** is the change in position from start to finish, so it only depends on the starting point, ending point, and direction.

<BlockMath math="\begin{aligned}
s&=\text{path length} \\
\Delta \vec{r}&=\vec{r}_{\text{final}}-\vec{r}_{\text{initial}}
\end{aligned}" />

Here, <InlineMath math="s" /> means the total path length, while <InlineMath math="\Delta \vec{r}" /> means the change in position from start to finish.

In two-dimensional motion, displacement is drawn as the straight line from the starting point to the ending point.

> Distance adds every part of the path traveled. Displacement compares only the starting and ending positions.

## Detours Change Distance

Compare an object that travels from the same start point to the same end point in two ways. A straight route gives a distance equal to the displacement magnitude. A detour gives a longer distance, but the displacement remains the straight line from start to finish.

In the simulation, choose the turning route and then the return route. Compare **path length** with **displacement magnitude**. When the car returns to the start, its path still has length, while the segment connecting its initial and final positions has zero length.

## Distance Describes Path Length

Distance is always zero or positive. It answers the question, "how long is the path traveled?" So distance **does not include direction**.

If an object moves <InlineMath math="4 \text{ m}" /> east and then <InlineMath math="3 \text{ m}" /> south, the distance is:

<BlockMath math="s=4 \text{ m}+3 \text{ m}=7 \text{ m}" />

The symbol <InlineMath math="s" /> is often used for distance traveled.

## Displacement Has Magnitude and Direction

Displacement is a vector quantity. That means displacement has magnitude and direction. For the example <InlineMath math="4 \text{ m}" /> east and then <InlineMath math="3 \text{ m}" /> south, the displacement magnitude is the straight line from start to finish:

<BlockMath math="\begin{aligned}
|\Delta \vec{r}|&=\sqrt{(4 \text{ m})^2+(3 \text{ m})^2} \\
&=\sqrt{16+9}\text{ m} \\
&=\sqrt{25}\text{ m}=5\text{ m}
\end{aligned}" />

The direction of displacement <Highlight>points straight from the starting point to the ending point</Highlight>.

## Returning to the Starting Point

If an object travels around and returns to the starting point, the distance is not zero because a path was still traveled. But the displacement is zero because the **initial and final positions are the same**.

| Trip | Distance | Displacement |
| :--- | :------- | :----------- |
| From start to finish by a straight route | equal to the straight line | line from start to finish |
| From start to finish by a detour | longer | still the line from start to finish |
| Around a loop back to the start | not zero | <InlineMath math="0" /> |

So, distance tells the length of the actual path traveled, while displacement tells the net change in position.

Three trips leave the same start. The straight one has distance equal to the size of its displacement, the detour is longer for the same displacement, and the loop comes home with displacement zero. Zoom in on each path.

## Distance and Displacement on a Turning Path

A student walks <InlineMath math="8 \text{ m}" /> east, then <InlineMath math="6 \text{ m}" /> north. The distance traveled is:

<BlockMath math="s=8 \text{ m}+6 \text{ m}=14 \text{ m}" />

The displacement magnitude is:

<BlockMath math="\begin{aligned}
|\Delta \vec{r}|&=\sqrt{(8 \text{ m})^2+(6 \text{ m})^2} \\
&=\sqrt{64+36}\text{ m} \\
&=\sqrt{100}\text{ m}=10\text{ m}
\end{aligned}" />

The distance is <InlineMath math="14 \text{ m}" />, but the displacement magnitude is <InlineMath math="10 \text{ m}" />. The values are different because the path traveled is not the same as the **straight line from start to finish**.

Rotate the walk below. The orange and violet arrows are the path, <InlineMath math="8+6=14\text{ m}" /> of distance. The fuchsia arrow joins start and finish directly, so its length is the displacement, <InlineMath math="10\text{ m}" />, from the right triangle.
