## Measuring Motion with Distance and Displacement

When an object moves, **speed** states the distance traveled per unit time. **Velocity** states the displacement per unit time together with its direction.

Speed is a scalar quantity, so it has a value and unit without a direction. Velocity is a vector quantity, so it has both a value and a direction.

  <BlockMath math="\begin{aligned}
\text{average speed} &= \frac{s}{\Delta t} \\
\bar{v} &= \frac{\Delta x}{\Delta t}
\end{aligned}" />

The symbol <InlineMath math="s" /> means distance traveled, <InlineMath math="\Delta x" /> means displacement on a straight line, and <InlineMath math="\Delta t" /> means time interval. These formulas calculate average speed and average velocity over that time interval.

> Speed uses the whole distance traveled. Velocity uses net displacement with its sign.

## Speed from Path Length and Velocity from Position Change

To separate the two ideas, check the total path actually traveled and the change in position from start to finish. Speed is calculated from the whole distance, while velocity is calculated from net displacement per time.

Over the same time interval, straight motion **without reversing direction** gives an average speed equal to the magnitude of average velocity. If the object turns back, distance exceeds displacement magnitude, so those two averages differ. At any single instant, instantaneous speed always equals the magnitude of instantaneous velocity.

In the table below, rightward is positive.

| Object motion | Distance traveled | Displacement |
| :------------ | :---------------- | :----------- |
| Moves straight from <InlineMath math="0 \text{ m}" /> to <InlineMath math="8 \text{ m}" /> | <InlineMath math="8 \text{ m}" /> | <InlineMath math="+8 \text{ m}" /> |
| Moves from <InlineMath math="0 \text{ m}" /> to <InlineMath math="8 \text{ m}" />, then returns to <InlineMath math="4 \text{ m}" /> | <InlineMath math="12 \text{ m}" /> | <InlineMath math="+4 \text{ m}" /> |
| Moves from <InlineMath math="0 \text{ m}" /> to <InlineMath math="8 \text{ m}" />, then returns to <InlineMath math="0 \text{ m}" /> | <InlineMath math="16 \text{ m}" /> | <InlineMath math="0 \text{ m}" /> |

Notice the last row. The object clearly moves because its distance is <InlineMath math="16 \text{ m}" />, but its final position change is zero because it returns to the starting point.

## Average Speed Uses Path Length

Suppose an object moves from position <InlineMath math="0 \text{ m}" /> to <InlineMath math="8 \text{ m}" />, then returns to position <InlineMath math="4 \text{ m}" />. The entire journey takes <InlineMath math="4 \text{ s}" />.

The distance traveled is:

<BlockMath math="s=8 \text{ m}+4 \text{ m}=12 \text{ m}" />

The average speed is:

<BlockMath math="\begin{aligned} \text{average speed} &amp;=\frac{12 \text{ m}}{4 \text{ s}} \\ &amp;=3 \text{ m/s} \end{aligned}" />

This value only tells how fast the object moved along the path. It does not describe the net direction.

Average speed is therefore **always nonnegative**. As long as the object keeps moving along a path, the accumulated path length increases.

## Average Velocity Uses Displacement

For the same example, the displacement is:

<BlockMath math="\Delta x=4 \text{ m}-0 \text{ m}=+4 \text{ m}" />

The average velocity is:

<BlockMath math="\bar{v}=\frac{+4 \text{ m}}{4 \text{ s}}=+1 \text{ m/s}" />

The positive sign means the net velocity points right. If the result is negative, the net velocity points left.

Average velocity must therefore be read together with the **positive direction chosen** at the start. Without that reference direction, a positive or negative sign has no clear meaning.

## When Speed and Velocity Have Different Values

Now imagine the object moves from <InlineMath math="0 \text{ m}" /> to <InlineMath math="8 \text{ m}" />, then returns to <InlineMath math="0 \text{ m}" /> in <InlineMath math="4 \text{ s}" />.

The distance traveled is <InlineMath math="16 \text{ m}" />, so the speed is:

<BlockMath math="\begin{aligned} \text{average speed} &amp;=\frac{16 \text{ m}}{4 \text{ s}} \\ &amp;=4 \text{ m/s} \end{aligned}" />

The displacement is <InlineMath math="0 \text{ m}" />, so the velocity is:

<BlockMath math="\bar{v}=\frac{0 \text{ m}}{4 \text{ s}}=0 \text{ m/s}" />

So average speed can be nonzero while average velocity over the trip is zero. <Highlight>Speed uses path length</Highlight>, while velocity uses the change in position from start to finish.

## Choosing the Right Formula

| Quantity | Based on | Has direction? | Example unit |
| :------- | :------- | :------------- | :----------- |
| Average speed | Distance traveled | No | <InlineMath math="\text{m/s}" /> |
| Average velocity | Displacement | Yes | <InlineMath math="\text{m/s}" /> to the right |

If the question asks how fast the path is traveled, use distance and speed. If the question asks how fast position changes in a direction, use **displacement** and velocity.

Run around a track and the two averages split. After a full lap your distance is the whole circle, but you are back where you started, so the average velocity is zero. After half a lap the displacement is the diameter. Zoom in on both labels.
