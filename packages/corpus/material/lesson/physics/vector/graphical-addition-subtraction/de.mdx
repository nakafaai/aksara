## Vektoren zeichnerisch addieren

Folgen mehrere Verschiebungen aufeinander oder greifen mehrere Vektoren an einem Punkt an, lässt sich ihre Vektorsumme durch einen einzigen Pfeil darstellen. Dieser Pfeil heißt **Resultierende**. Greifen Kräfte an verschiedenen Punkten an, beschreibt die resultierende Kraft nur die gesamte Translationswirkung. Die Drehwirkung muss zusätzlich über das Drehmoment geprüft werden.

Bei der grafischen Methode entsteht die Resultierende in einer maßstäblichen Zeichnung. Die Pfeillänge steht für den Betrag, die Pfeilrichtung folgt dem angegebenen Winkel oder der Himmelsrichtung.

> Die Genauigkeit der grafischen Methode hängt vom Maßstab sowie vom sorgfältigen Zeichnen mit Lineal und Winkelmesser ab.

### Dreiecksmethode mit Pfeilspitze und Fußpunkt

Mit der Dreiecksmethode werden zwei Vektoren addiert. Zeichne den ersten Vektor und setze den Fußpunkt des zweiten an seine Spitze. Die Resultierende führt vom ursprünglichen Fußpunkt direkt zur letzten Pfeilspitze.

<LineEquation
  cameraPosition={[3, 2, 9]}
  cameraTarget={[3, 2, 0]}
  title={<>Spitze-an-Fußpunkt-Addition</>}
  description={
    <>
      Auf <InlineMath math="\vec{a}" /> folgt <InlineMath math="\vec{b}" />.
      Die Resultierende <InlineMath math="\vec{R}" /> verbindet den Startpunkt
      direkt mit dem Endpunkt.
    </>
  }
  data={(() => {
    const a = [4, 1, 0];
    const b = [2, 3, 0];
    const resultant = a.map((component, index) => component + b.at(index));

    return [
      {
      points: [{ x: 0, y: 0, z: 0 }, { x: (0) + 0.5 * (((a)[0]) - (0)), y: (0) + 0.5 * (((a)[1]) - (0)), z: (0) + 0.5 * (((a)[2]) - (0)) }, { x: (a)[0], y: (a)[1], z: (a)[2] }],
      color: "#0d9488",
      cone: { position: "end", size: 0.25 },
      showPoints: false,
      smooth: false,
      labels: [{
        text: <InlineMath math="a" />,
        at: 1,
        offset: [0, -0.45, 0],
        anchorX: "center",
      }],
    },
      {
      points: [{ x: (a)[0], y: (a)[1], z: (a)[2] }, { x: ((a)[0]) + 0.5 * (((resultant)[0]) - ((a)[0])), y: ((a)[1]) + 0.5 * (((resultant)[1]) - ((a)[1])), z: ((a)[2]) + 0.5 * (((resultant)[2]) - ((a)[2])) }, { x: (resultant)[0], y: (resultant)[1], z: (resultant)[2] }],
      color: "#d97706",
      cone: { position: "end", size: 0.25 },
      showPoints: false,
      smooth: false,
      labels: [{
        text: <InlineMath math="b" />,
        at: 1,
        offset: [0.35, 0.45, 0.2],
        anchorX: "center",
      }],
    },
      {
      points: [{ x: 0, y: 0, z: 0 }, { x: (0) + 0.6 * (((resultant)[0]) - (0)), y: (0) + 0.6 * (((resultant)[1]) - (0)), z: (0) + 0.6 * (((resultant)[2]) - (0)) }, { x: (resultant)[0], y: (resultant)[1], z: (resultant)[2] }],
      color: "#7c3aed",
      cone: { position: "end", size: 0.25 },
      showPoints: false,
      smooth: false,
      labels: [{
        text: <InlineMath math="R" />,
        at: 1,
        offset: [0.25, 0.75, 0.35],
        anchorX: "center",
      }],
    },
    ];
  })()}
/>

Setze den **Fußpunkt des zweiten Vektors an die Spitze des ersten**. Die Koordinateneinheit im Modell ist Meter: Auf die Verschiebung <InlineMath math="(4,1)" /> folgt <InlineMath math="(2,3)" />. Der Endpunkt liegt bei <InlineMath math="(6,4)" />, weil du die Ortsänderungen entlang jeder Achse addierst.

<BlockMath math="\vec{R}=(4+2,1+3)\text{ m}=(6,4)\text{ m}" />

### Parallelogrammmethode bei gemeinsamem Anfangspunkt

Zwei Kräfte, die an einem Punkt angreifen, lassen sich mit einem **gemeinsamen Fußpunkt** zeichnen. Zum Beispiel ziehen zwei Seile an einem Ring. Die verschobenen Vektoren im Modell behalten Länge und Richtung der ursprünglichen Pfeile. Ob du erst der unteren und dann der rechten Seite folgst oder erst der linken und dann der oberen: Beide Wege enden am selben Punkt.

### Polygonverfahren für viele Vektoren

Für mehr als zwei Vektoren wird die Polygonmethode verwendet. Setze auch hier <Highlight>den Fußpunkt jedes neuen Vektors</Highlight> an die Spitze des vorherigen.

Die Reihenfolge darf sich ändern, solange jeder Vektor Betrag und Richtung behält. Die Resultierende verläuft vom ersten Anfangspunkt bis zur letzten Pfeilspitze.

<BlockMath math="\vec{R}=\vec{a}+\vec{b}+\vec{c}" />

Wenn das Polygon zum Startpunkt zurückkehrt, ist die Vektorsumme null. Bei Kräften bedeutet eine verschwindende Gesamtkraft ein Translationsgleichgewicht. Für ein Rotationsgleichgewicht muss zusätzlich das gesamte Drehmoment null sein.

Füge zum Beispiel nach den beiden Verschiebungen im Modell <InlineMath math="\vec{c}=(-6,-4)" /> hinzu. Der dritte Pfeil führt entlang der Diagonale zum Startpunkt zurück. Der Weg hat weiterhin eine Länge, aber die gesamte Verschiebung ist null.

<BlockMath math="\vec{a}+\vec{b}+\vec{c}=(4+2-6,1+3-4)=(0,0)" />

## Grafische Vektorsubtraktion

Für die Subtraktion **kehrst du den abzuziehenden Vektor um**. Beim selben Vektorpaar wird aus <InlineMath math="\vec{b}=(2,3)" /> der Gegenvektor <InlineMath math="-\vec{b}=(-2,-3)" />.
