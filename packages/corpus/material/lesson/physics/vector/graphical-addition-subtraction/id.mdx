## Menjumlahkan Vektor secara Grafis

Ketika beberapa perpindahan terjadi berurutan, atau beberapa vektor bekerja pada satu titik, jumlah vektornya dapat diwakili oleh satu panah yang disebut **resultan**. Untuk gaya yang bekerja pada titik berbeda, gaya resultan menjelaskan efek translasi bersih, tetapi efek putarnya harus diperiksa terpisah melalui momen gaya.

Metode grafis mencari resultan dengan sketsa berskala. Panjang panah dibuat sebanding dengan besar vektor, sedangkan arah panah dibuat sesuai sudut atau arah mata angin.

> Dalam metode grafis, ketelitian hasil bergantung pada skala sketsa, penggaris, dan pengukuran sudut.

### Metode Segitiga Kepala ke Ekor

Metode segitiga dipakai untuk menjumlahkan dua vektor. Buat panah vektor pertama, lalu letakkan pangkal vektor kedua di ujung vektor pertama. Resultan ditarik dari pangkal vektor pertama ke ujung vektor kedua.

<Vector3d
  cameraPosition={[3, 2, 9]}
  cameraTarget={[3, 2, 0]}
  title={<>Penjumlahan Kepala-ke-Ekor</>}
  description={
    <>
      Vektor <InlineMath math="\vec{a}" /> dilanjutkan dengan{" "}
      <InlineMath math="\vec{b}" />. Resultan <InlineMath math="\vec{R}" /> langsung
      menghubungkan titik awal ke titik akhir.
    </>
  }
  vectors={(() => {
    const a = [4, 1, 0];
    const b = [2, 3, 0];
    const resultant = a.map((component, index) => component + b.at(index));

    return [
      {
        from: [0, 0, 0],
        to: a,
        color: "#0d9488",
        label: <InlineMath math="a" />,
        labelAnchorX: "center",
        labelProgress: 1 / 2,
        labelOffset: [0, -0.45, 0],
      },
      {
        from: a,
        to: resultant,
        color: "#d97706",
        label: <InlineMath math="b" />,
        labelAnchorX: "center",
        labelProgress: 1 / 2,
        labelOffset: [0.35, 0.45, 0.2],
      },
      {
        from: [0, 0, 0],
        to: resultant,
        color: "#7c3aed",
        label: <InlineMath math="R" />,
        labelAnchorX: "center",
        labelProgress: 3 / 5,
        labelOffset: [0.25, 0.75, 0.35],
      },
    ];
  })()}
/>

Letakkan **pangkal vektor kedua di ujung vektor pertama**. Pada model, satuan koordinat adalah meter: perpindahan pertama <InlineMath math="(4,1)" />, lalu perpindahan kedua <InlineMath math="(2,3)" />. Titik akhir berada di <InlineMath math="(6,4)" />. Kamu menambahkan perubahan posisi pada setiap sumbu.

<BlockMath math="\vec{R}=(4+2,1+3)\text{ m}=(6,4)\text{ m}" />

### Metode Jajargenjang untuk Dua Vektor Satu Pangkal

Dua gaya yang bekerja pada satu titik dapat digambar dari **pangkal yang sama**. Contohnya, dua tali menarik sebuah cincin. Pada model, salinan vektor mempertahankan panjang dan arah panah asli. Ikuti sisi bawah lalu sisi kanan, atau sisi kiri lalu sisi atas: kedua jalur berakhir pada titik yang sama.

  cameraPosition={[3, 2, 9]}
  cameraTarget={[3, 2, 0]}
  title={<>Diagonal Jajargenjang</>}
  description={<>Panah ungu menghubungkan pangkal bersama ke titik akhir kedua jalur. Vektor a dan b tetap sama meskipun digeser sejajar.</>}
  vectors={[
    {from: [0,0,0], to: [4,1,0], color: "#0d9488", label: <InlineMath math="a" />, labelProgress: 0.5, labelOffset: [0,-0.4,0]},
    {from: [0,0,0], to: [2,3,0], color: "#d97706", label: <InlineMath math="b" />, labelProgress: 0.5, labelOffset: [-0.5,0,0]},
    {from: [2,3,0], to: [6,4,0], color: "#0d9488", label: <InlineMath math="a" />, labelProgress: 0.5, labelOffset: [0,0.4,0]},
    {from: [4,1,0], to: [6,4,0], color: "#d97706", label: <InlineMath math="b" />, labelProgress: 0.5, labelOffset: [0.5,0,0]},

### Metode Poligon untuk Banyak Vektor

Urutan menggambar boleh diatur ulang selama <Highlight>besar dan arah tiap vektor tidak berubah</Highlight>. Resultan selalu ditarik dari pangkal vektor pertama yang dipilih ke ujung vektor terakhir.

<BlockMath math="\vec{R}=\vec{a}+\vec{b}+\vec{c}" />

Jika poligon vektor kembali ke titik awal, jumlah vektornya nol. Untuk gaya, resultan gaya nol berarti percepatan translasi nol. Agar benda juga tidak mengalami percepatan sudut, resultan momen gaya harus nol.

Sebagai contoh, tambahkan <InlineMath math="\vec{c}=(-6,-4)" /> setelah dua perpindahan pada model. Panah ketiga mengikuti diagonal kembali ke titik awal. Perjalanan tetap memiliki panjang, tetapi perpindahan total nol.

<BlockMath math="\vec{a}+\vec{b}+\vec{c}=(4+2-6,1+3-4)=(0,0)" />

## Pengurangan Vektor secara Grafis

Untuk pengurangan, **balik arah vektor yang dikurangkan**. Pada pasangan yang sama, komponen <InlineMath math="\vec{b}=(2,3)" /> berubah menjadi <InlineMath math="-\vec{b}=(-2,-3)" />.

<BlockMath math="\vec{a}-\vec{b}=(4,1)+(-2,-3)=(2,-2)" />

<Vector3d
  cameraPosition={[2, -0.5, 7]}
  cameraTarget={[2, -0.5, 0]}
  title={<>Menambahkan Vektor Negatif</>}
  description={<>Dari ujung a di (4,1), bergerak dua satuan ke kiri dan tiga satuan ke bawah. Resultan berakhir di (2,-2).</>}
  vectors={[
    {from: [0,0,0], to: [4,1,0], color: "#0d9488", label: <InlineMath math="a" />, labelProgress: 0.5, labelOffset: [0,0.4,0]},
    {from: [4,1,0], to: [2,-2,0], color: "#d97706", label: <InlineMath math="-b" />, labelProgress: 0.5, labelOffset: [0.5,0,0]},
    {from: [0,0,0], to: [2,-2,0], color: "#7c3aed", label: <InlineMath math="a-b" />, labelProgress: 0.5, labelOffset: [-0.5,-0.2,0]}
  ]}
/>
