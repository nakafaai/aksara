## Every Digit Is Worth a Power of Its Base

In **base** <InlineMath math="b" />, numbers are written with the digits <InlineMath math="0" /> to <InlineMath math="b - 1" />, and each position is worth a **power** of <InlineMath math="b" />. The rightmost digit is worth <InlineMath math="b^0 = 1" />, the digit to its left <InlineMath math="b^1" />, then <InlineMath math="b^2" />, and so on. To find a number's value in base ten, multiply each digit by its place value and add them up. In the models here, you break a number into place values, compare how many digits a number needs in different bases and see how the base changes the value of the same digits.

## Converting Numbers between Bases

There are two directions. To convert a number in base <InlineMath math="b" /> to base ten, expand it by place value as above. For the other direction, use repeated division. A conversion between two other bases can go through base ten, or go straight across when one base is a power of the other.

To convert a base ten number to base <InlineMath math="b" />, **divide repeatedly by** <InlineMath math="b" /> and record the remainders. The remainders are read from the bottom up.

### Example Converting to Base Five

<BlockMath math="45 \div 5 = 9 \text{ rem } 0, \quad 9 \div 5 = 1 \text{ rem } 4, \quad 1 \div 5 = 0 \text{ rem } 1" />

**Read the remainders from the bottom**: <InlineMath math="45_{10} = 140_5" />. Check by expanding back: <InlineMath math="1 \times 25 + 4 \times 5 + 0 = 45" />.

### Example Converting between Base Two and Base Eight

Because <InlineMath math="8 = 2^3" />, every **three base two digits** match one base eight digit. Group the digits from the right:

<BlockMath math="101101_2 = \underbrace{101}_{5}\,\underbrace{101}_{5} = 55_8" />

Check through base ten: <InlineMath math="101101_2 = 32 + 8 + 4 + 1 = 45" /> and <InlineMath math="55_8 = 40 + 5 = 45" />.

## Adding and Subtracting in Number Bases

Addition in base <InlineMath math="b" /> works like addition in base ten, but **carry one when a column reaches** <InlineMath math="b" />, not ten. In subtraction, borrow <InlineMath math="b" /> from the column on the left.

### Example Addition in Base Two

<BlockMath math="1011_2 + 110_2 = 10001_2" />

**Start from the rightmost column**: <InlineMath math="1 + 0 = 1" />. Second column: <InlineMath math="1 + 1 = 2 = 10_2" />, write <InlineMath math="0" /> carry <InlineMath math="1" />. Third column: <InlineMath math="0 + 1 + 1 = 10_2" />, write <InlineMath math="0" /> carry <InlineMath math="1" />. Fourth column: <InlineMath math="1 + 1 = 10_2" />. Check: <InlineMath math="11 + 6 = 17" /> and <InlineMath math="10001_2 = 16 + 1 = 17" />.

### Example Subtraction in Base Five

Calculate <InlineMath math="1302_5 - 244_5" />. In base five, **every borrow is worth five**.

<BlockMath math="1302_5 - 244_5 = 1003_5" />

Rightmost column: <InlineMath math="2 - 4" /> doesn't work, so borrow five, <InlineMath math="7 - 4 = 3" />. The second column is now <InlineMath math="0 - 1" />, so borrow again, <InlineMath math="5 - 1 - 4 = 0" />. Third column: <InlineMath math="3 - 1 - 2 = 0" />. Fourth column: <InlineMath math="1" />. Check: <InlineMath math="1302_5 = 202" />, <InlineMath math="244_5 = 74" />, and <InlineMath math="202 - 74 = 128 = 1003_5" />.

## Common Mistakes about Number Bases

| Mistake | Why it's wrong | How to check |
| :--- | :--- | :--- |
| Writing the digit <InlineMath math="5" /> in base five. | Base five only uses the digits <InlineMath math="0" /> to <InlineMath math="4" />. | Every digit must be less than the base. |
| Reading the remainders from top to bottom. | The first remainder is the rightmost digit. | Expand the answer and compare it with the original number. |
| The rightmost place value is <InlineMath math="b^1" />. | The rightmost place value is <InlineMath math="b^0 = 1" />. | Count powers starting from zero. |
| Carrying one when a column reaches ten in base two. | Carry one when a column reaches the base, which is two. | Convert each column total to that base. |

The second mistake is the most common one in conversion questions. **Read the remainders from the bottom up**.

## Practice on Number Bases

These questions move from place value to conversion and addition. **Check every answer through base ten**.

1. Convert <InlineMath math="2341_5" /> to base ten.

2. Convert <InlineMath math="100_{10}" /> to base three.

3. Convert <InlineMath math="11010111_2" /> to base eight.

4. Given <InlineMath math="25_b = 17_{10}" />. Find <InlineMath math="b" />.

### Solutions

**Solution 1**: Multiply each digit by a power of five:

<BlockMath math="2 \times 125 + 3 \times 25 + 4 \times 5 + 1 = 250 + 75 + 20 + 1 = 346" />

Check: every digit is less than <InlineMath math="5" />, so the number is valid in base five.

**Solution 2**: Divide repeatedly by three:

<BlockMath math="100 = 3 \times 33 + 1, \quad 33 = 3 \times 11 + 0, \quad 11 = 3 \times 3 + 2, \quad 3 = 3 \times 1 + 0, \quad 1 = 3 \times 0 + 1" />

**Read the remainders from the bottom**: <InlineMath math="10201_3" />. Check: <InlineMath math="81 + 0 + 18 + 0 + 1 = 100" />.

**Solution 3**: Group three digits from the right, adding a zero in front if needed:

<BlockMath math="011\,010\,111_2 = 3\,2\,7 = 327_8" />

Check: <InlineMath math="327_8 = 192 + 16 + 7 = 215" /> and <InlineMath math="11010111_2 = 128 + 64 + 16 + 4 + 2 + 1 = 215" />.

**Solution 4**: Expand and solve:

<BlockMath math="2b + 5 = 17 \quad\Rightarrow\quad b = 6" />

Check: the digit <InlineMath math="5" /> is less than <InlineMath math="6" />, and <InlineMath math="2 \times 6 + 5 = 17" />.
