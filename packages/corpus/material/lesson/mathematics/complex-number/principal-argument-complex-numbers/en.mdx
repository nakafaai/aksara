## One Representative Angle for Every Direction

The principal argument of a complex number <InlineMath math="z \ne 0" />, written <InlineMath math="\operatorname{Arg} z" />, is **the only argument in the range <InlineMath math="(-\pi, \pi]" />**, or <InlineMath math="(-180^\circ, 180^\circ]" /> in degrees. Every other argument differs from the principal argument by whole turns:

<MathContainer>
  <BlockMath math="-\pi < \operatorname{Arg} z \le \pi" />
  <BlockMath math="\arg z = \operatorname{Arg} z + 2\pi k, \qquad k \in \mathbb{Z}" />
</MathContainer>

For <InlineMath math="z = 1 + i" />, the angles <InlineMath math="45^\circ" />, <InlineMath math="405^\circ" />, and <InlineMath math="-315^\circ" /> point in the same direction, but only <InlineMath math="45^\circ" /> lies in the principal range, so <InlineMath math="\operatorname{Arg}(1 + i) = 45^\circ = \frac{\pi}{4}" />. The interactive graph shows the angles for <InlineMath math="1 + i" /> and <InlineMath math="\sqrt{3} + i" />, both measured from the positive real axis.

The left end of the range is excluded, while the right end is included. That is why a number on the negative real axis, such as <InlineMath math="-4" />, has principal argument <InlineMath math="180^\circ" />, not <InlineMath math="-180^\circ" />. Zero has no argument, because the zero vector has no direction.

## Many Angles for One Direction

Adding one full turn, <InlineMath math="360^\circ" /> or <InlineMath math="2\pi" />, brings a vector back to the same direction. As a result, every nonzero complex number has **infinitely many arguments** <InlineMath math="\theta + 2\pi k" />. The principal argument picks one representative from all of them, so the same direction is always written with the same number.

The reference angle and quadrant rules for the [modulus and argument of a complex number](/en/subjects/mathematics/complex-number/modulus-argument-complex-numbers) give an angle in this range directly. Angles outside the range appear when you add arguments, for example when you multiply two complex numbers, or when a problem gives an angle such as <InlineMath math="750^\circ" />.

## Reducing an Angle to the Principal Range

To get the principal argument from any angle, **add or subtract full turns** until the angle lies in <InlineMath math="(-180^\circ, 180^\circ]" />:

| Starting angle | Calculation | Principal argument |
| --- | --- | --- |
| <InlineMath math="300^\circ" /> | <InlineMath math="300^\circ - 360^\circ" /> | <InlineMath math="-60^\circ" /> |
| <InlineMath math="405^\circ" /> | <InlineMath math="405^\circ - 360^\circ" /> | <InlineMath math="45^\circ" /> |
| <InlineMath math="-315^\circ" /> | <InlineMath math="-315^\circ + 360^\circ" /> | <InlineMath math="45^\circ" /> |
| <InlineMath math="-180^\circ" /> | <InlineMath math="-180^\circ + 360^\circ" /> | <InlineMath math="180^\circ" /> |

A large angle needs several turns at once. For <InlineMath math="1000^\circ" />, three turns bring the angle into the range:

<BlockMath math="1000^\circ - 3 \cdot 360^\circ = -80^\circ" />

Check: <InlineMath math="-80^\circ" /> lies between <InlineMath math="-180^\circ" /> and <InlineMath math="180^\circ" />, and <InlineMath math="-80^\circ + 3 \cdot 360^\circ = 1000^\circ" />, so both angles point in the same direction.

## The Principal Argument from the Components x and y

If <InlineMath math="z = x + iy" /> is given in Cartesian form, the principal argument comes from <InlineMath math="\arctan\frac{y}{x}" /> **plus a half-turn correction for points left of the imaginary axis**:

<BlockMath math="\operatorname{Arg} z = \begin{cases} \arctan\frac{y}{x}, &amp; x > 0 \\ \arctan\frac{y}{x} + 180^\circ, &amp; x < 0,\ y \ge 0 \\ \arctan\frac{y}{x} - 180^\circ, &amp; x < 0,\ y < 0 \\ 90^\circ, &amp; x = 0,\ y > 0 \\ -90^\circ, &amp; x = 0,\ y < 0 \end{cases}" />

The function <InlineMath math="\operatorname{atan2}(y, x)" /> in programming languages follows the same rule and returns an angle in <InlineMath math="(-\pi, \pi]" /> for every <InlineMath math="z \ne 0" />. Many scientific calculators have no atan2 key, but their Pol or R→P function gives the same angle.

**Example 1**. For <InlineMath math="z = -1 + i" />, the value is <InlineMath math="\arctan\frac{1}{-1} = -45^\circ" />. The point lies left of the imaginary axis with <InlineMath math="y \ge 0" />, so add half a turn:

<BlockMath math="\operatorname{Arg}(-1 + i) = -45^\circ + 180^\circ = 135^\circ" />

Check with modulus <InlineMath math="\sqrt{2}" />: <InlineMath math="\sqrt{2}\cos 135^\circ = -1" /> and <InlineMath math="\sqrt{2}\sin 135^\circ = 1" />.

**Example 2**. For <InlineMath math="z = -1 - i" />, the value is <InlineMath math="\arctan\frac{-1}{-1} = 45^\circ" />, the same as for <InlineMath math="1 + i" />. The point lies left of the imaginary axis with <InlineMath math="y < 0" />, so subtract half a turn:

<BlockMath math="\operatorname{Arg}(-1 - i) = 45^\circ - 180^\circ = -135^\circ" />

Check: <InlineMath math="\sqrt{2}\cos(-135^\circ) = -1" /> and <InlineMath math="\sqrt{2}\sin(-135^\circ) = -1" />. The numbers <InlineMath math="1 + i" /> and <InlineMath math="-1 - i" /> have the same tangent, but they point in opposite directions.

## The Zero to Two Pi Convention

Some books choose the principal argument from <InlineMath math="[0, 2\pi)" />, or <InlineMath math="[0^\circ, 360^\circ)" />. Both conventions pick one representative for each direction, and **they differ only for negative angles**. If the principal argument in <InlineMath math="(-180^\circ, 180^\circ]" /> is negative, add <InlineMath math="360^\circ" /> to get the representative in <InlineMath math="[0^\circ, 360^\circ)" />.

For <InlineMath math="-1 - i" />, the argument <InlineMath math="-135^\circ" /> becomes <InlineMath math="225^\circ" />, while <InlineMath math="135^\circ" /> for <InlineMath math="-1 + i" /> stays the same. Check: <InlineMath math="\cos 225^\circ = \cos(-135^\circ)" /> and <InlineMath math="\sin 225^\circ = \sin(-135^\circ)" />, so both angles point in the same direction. Always state the convention you use, because <InlineMath math="225^\circ" /> is wrong for a problem that asks for <InlineMath math="(-180^\circ, 180^\circ]" />.

## Equality of Two Complex Numbers in Polar Form

Two nonzero complex numbers <InlineMath math="z_1 = r_1(\cos \theta_1 + i\sin \theta_1)" /> and <InlineMath math="z_2 = r_2(\cos \theta_2 + i\sin \theta_2)" />, with <InlineMath math="r_1 > 0" /> and <InlineMath math="r_2 > 0" />, are equal if and only if **their moduli are equal and their arguments differ by whole turns**:

<BlockMath math="r_1 = r_2 \quad\text{and}\quad \theta_1 - \theta_2 = 2\pi k \text{ for some } k \in \mathbb{Z}" />

With principal arguments, the second condition becomes simpler: <InlineMath math="\operatorname{Arg} z_1 = \operatorname{Arg} z_2" />. Equal moduli are not enough when the two vectors point in different directions:

| Pair | Moduli | Angle difference | Conclusion |
| --- | --- | --- | --- |
| <InlineMath math="\sqrt{2}(\cos45^\circ+i\sin45^\circ)" />, <InlineMath math="\sqrt{2}(\cos95^\circ+i\sin95^\circ)" /> | <InlineMath math="\sqrt{2}=\sqrt{2}" /> | <InlineMath math="45^\circ-95^\circ=-50^\circ" /> | Different |
| <InlineMath math="\cos30^\circ+i\sin30^\circ" />, <InlineMath math="\cos390^\circ+i\sin390^\circ" /> | <InlineMath math="1=1" /> | <InlineMath math="30^\circ-390^\circ=-360^\circ" /> | Equal |

## Common Mistakes

| Mistake | Why it fails | How to check |
| --- | --- | --- |
| Writing <InlineMath math="-180^\circ" /> for the negative real axis | The left end of the range is excluded | The principal argument of <InlineMath math="-4" /> is <InlineMath math="180^\circ" /> |
| Using <InlineMath math="\arctan\frac{y}{x}" /> for a point with <InlineMath math="x < 0" /> | The result points in the opposite direction | Rebuild <InlineMath math="r\cos\theta" />, its sign must match <InlineMath math="x" /> |
| Stopping after one turn on a large angle | <InlineMath math="1000^\circ - 360^\circ = 640^\circ" /> is still outside the range | The final result must lie between <InlineMath math="-180^\circ" /> and <InlineMath math="180^\circ" /> |
| Mixing the two conventions | <InlineMath math="(-\pi, \pi]" /> and <InlineMath math="[0, 2\pi)" /> differ for negative angles | Read the range the problem asks for before you answer |
| Assuming equal moduli mean equal numbers | The directions must match too | Compare the principal arguments of both numbers |

One check catches almost all of these mistakes: **make sure your answer lies in the requested range and points into the right quadrant**.

## Exercises

The first two problems find the principal argument from the components, the third reduces large angles, and the fourth compares the two conventions. **Find the quadrant or axis first**, then check your answer before you read the solution.

1. Find the principal argument of <InlineMath math="z = 1 + \sqrt{3}i" /> in degrees.

2. Find the principal argument of <InlineMath math="z = -i" /> in degrees.

3. Find the principal argument for the angles <InlineMath math="750^\circ" /> and <InlineMath math="-510^\circ" />.

4. Find the principal argument of <InlineMath math="z = -2 - 2i" /> in <InlineMath math="(-180^\circ, 180^\circ]" />, then in <InlineMath math="[0^\circ, 360^\circ)" />.

### Worked Solutions

**Problem 1**. The point <InlineMath math="(1, \sqrt{3})" /> lies in quadrant I, so no correction is needed:

<BlockMath math="\operatorname{Arg} z = \arctan\sqrt{3} = 60^\circ" />

Check with modulus <InlineMath math="2" />: <InlineMath math="2\cos 60^\circ = 1" /> and <InlineMath math="2\sin 60^\circ = \sqrt{3}" />, so **the angle rebuilds both components**.

**Problem 2**. The number <InlineMath math="-i = 0 - 1i" /> lies on the negative imaginary axis, so the quotient <InlineMath math="\frac{y}{x}" /> is not needed:

<BlockMath math="\operatorname{Arg}(-i) = -90^\circ" />

Check: <InlineMath math="\cos(-90^\circ) = 0" /> and <InlineMath math="\sin(-90^\circ) = -1" />, so **the vector points straight down**.

**Problem 3**. Subtract or add full turns until the angle falls into the principal range:

<MathContainer>
  <BlockMath math="750^\circ - 2 \cdot 360^\circ = 30^\circ" />
  <BlockMath math="-510^\circ + 360^\circ = -150^\circ" />
</MathContainer>

Check: <InlineMath math="30^\circ + 2 \cdot 360^\circ = 750^\circ" /> and <InlineMath math="-150^\circ - 360^\circ = -510^\circ" />, so each result returns to its given angle, and both lie in <InlineMath math="(-180^\circ, 180^\circ]" />. For <InlineMath math="-510^\circ" />, adding two turns gives <InlineMath math="210^\circ" />, which **already passes the right end of the range**.

**Problem 4**. The point <InlineMath math="(-2, -2)" /> lies left of the imaginary axis with <InlineMath math="y < 0" />:

<BlockMath math="\operatorname{Arg} z = \arctan\frac{-2}{-2} - 180^\circ = 45^\circ - 180^\circ = -135^\circ" />

In <InlineMath math="[0^\circ, 360^\circ)" />, add one turn: <InlineMath math="-135^\circ + 360^\circ = 225^\circ" />. Check with modulus <InlineMath math="2\sqrt{2}" />: <InlineMath math="2\sqrt{2}\cos 225^\circ = -2" /> and <InlineMath math="2\sqrt{2}\sin 225^\circ = -2" />, so **both answers point into quadrant III**.
