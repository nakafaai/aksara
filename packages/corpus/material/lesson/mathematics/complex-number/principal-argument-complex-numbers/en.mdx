## Different Angles That Describe the Same Direction

The argument <InlineMath math="\theta" /> of a nonzero complex number <InlineMath math="z = x + iy" /> is the angle formed by the vector <InlineMath math="z" /> with the positive real axis. The zero vector has no direction, so <InlineMath math="\text{Arg}(0)" /> is undefined.

The same direction can be described by <Highlight>infinitely many coterminal angles</Highlight>.

If <InlineMath math="\theta" /> is an argument of <InlineMath math="z" />, then <InlineMath math="\theta + 2\pi k" /> (where <InlineMath math="k" /> is an integer: <InlineMath math="0, \pm 1, \pm 2, \ldots" />) is also an argument of <InlineMath math="z" />, because adding multiples of <InlineMath math="360^\circ" /> or <InlineMath math="2\pi" /> radians results in the same angle on the complex plane.

**Example:**

The angles <InlineMath math="45^\circ" />, <InlineMath math="405^\circ" /> (<InlineMath math="45^\circ + 360^\circ" />), and <InlineMath math="-315^\circ" /> (<InlineMath math="45^\circ - 360^\circ" />) all indicate the same direction.

Because there are infinitely many arguments for a single complex number, we often need a unique standard value. This value is called the **Principal Argument**.

## Definition of Principal Argument

For a nonzero complex number <InlineMath math="z = r(\cos \theta + i\sin \theta)" /> with <InlineMath math="r>0" />, the **Principal Argument** <InlineMath math="\operatorname{Arg}(z)" /> is the unique angle <InlineMath math="\theta" /> chosen from <InlineMath math="(-\pi, \pi]" />. In degrees, the same convention is:

<BlockMath math="\begin{aligned} &amp;-\pi &lt; \theta \leq \pi \\ &amp;\text{or} \\ &amp;-180^\circ &lt; \theta \leq 180^\circ \end{aligned}" />

Some references use <InlineMath math="[0, 2\pi)" /> instead. Both conventions select one representative from each set of coterminal angles. Every example below uses <InlineMath math="(-\pi, \pi]" /> consistently.

## Determining the Principal Argument

Find any argument, then **add or subtract full turns** until the angle lies in the principal interval. In degrees, the left endpoint is excluded and the right endpoint is included. The negative real axis therefore uses positive 180 degrees.

| Starting angle | Calculation | Principal argument |
| --- | --- | --- |
| <InlineMath math="300^\circ" /> | <InlineMath math="300^\circ-360^\circ=-60^\circ" /> | <InlineMath math="-60^\circ" /> |
| <InlineMath math="405^\circ" /> | <InlineMath math="405^\circ-360^\circ=45^\circ" /> | <InlineMath math="45^\circ" /> |
| <InlineMath math="-315^\circ" /> | <InlineMath math="-315^\circ+360^\circ=45^\circ" /> | <InlineMath math="45^\circ" /> |
| <InlineMath math="-180^\circ" /> | <InlineMath math="-180^\circ+360^\circ=180^\circ" /> | <InlineMath math="180^\circ" /> |

### Finding the Principal Argument

Check the **quadrant of the point** before using inverse tangent. The component ratio determines the slope, so two opposite directions can have the same tangent.

For <InlineMath math="z=1+i" />: <InlineMath math="(1,1)" /> lies in quadrant I.

<BlockMath math="\begin{aligned}\tan\theta&amp;=\frac{1}{1}=1\\\operatorname{Arg}(1+i)&amp;=45^\circ=\frac{\pi}{4}\end{aligned}" />

For <InlineMath math="z=\sqrt{3}+i" />: <InlineMath math="(\sqrt{3},1)" /> lies in quadrant I.

<BlockMath math="\begin{aligned}\tan\theta&amp;=\frac{1}{\sqrt{3}}\\\operatorname{Arg}(\sqrt{3}+i)&amp;=30^\circ=\frac{\pi}{6}\end{aligned}" />

For a point in quadrant II, inverse tangent alone gives the wrong direction. The point <InlineMath math="(-1,1)" /> lies in quadrant II, so add half a turn:

<BlockMath math="\begin{aligned}\arctan\left(\frac{1}{-1}\right)&amp;=-45^\circ\\\operatorname{Arg}(-1+i)&amp;=-45^\circ+180^\circ=135^\circ\end{aligned}" />

## Equality of Two Complex Numbers in Polar Form

Two nonzero complex numbers <InlineMath math="z_1 = r_1(\cos \theta_1 + i\sin \theta_1)" /> and <InlineMath math="z_2 = r_2(\cos \theta_2 + i\sin \theta_2)" />, with <InlineMath math="r_1>0" /> and <InlineMath math="r_2>0" />, are said to be **equal** if and only if:

1.  Their moduli are equal:

    <InlineMath math="r_1 = r_2" /> (or <InlineMath math="|z_1| = |z_2|" />)

2.  Their arguments are the same or differ by a multiple of <InlineMath math="2\pi" /> (or <InlineMath math="360^\circ" />):

    <InlineMath math="\theta_1 = \theta_2 + 2k\pi" /> or <InlineMath math="\theta_1 - \theta_2 = 2k\pi" /> for
    some integer <InlineMath math="k" />.

If we use the **Principal Argument** in <InlineMath math="(-\pi, \pi]" />, the second condition simplifies to <InlineMath math="\text{Arg}(z_1) = \text{Arg}(z_2)" />.

### Comparing Equality

Compare **both modulus and direction**. Equal moduli are not enough when the vectors point in different directions.

| Pair | Moduli | Angle difference | Conclusion |
| --- | --- | --- | --- |
| <InlineMath math="\sqrt{2}(\cos45^\circ+i\sin45^\circ)" />, <InlineMath math="\sqrt{2}(\cos95^\circ+i\sin95^\circ)" /> | <InlineMath math="\sqrt{2}=\sqrt{2}" /> | <InlineMath math="45^\circ-95^\circ=-50^\circ" /> | Different |
| <InlineMath math="\cos30^\circ+i\sin30^\circ" />, <InlineMath math="\cos390^\circ+i\sin390^\circ" /> | <InlineMath math="1=1" /> | <InlineMath math="30^\circ-390^\circ=-360^\circ" /> | Equal |

## Exercise

The component signs identify the **quadrant or axis**. Find the angle and check that it lies in the principal interval. Find the principal argument of each number below in degrees. If the real component is zero, the tangent ratio is undefined, but you can still identify the direction of the vector.

1.  <InlineMath math="1 + \sqrt{3}i" />
2.  <InlineMath math="-i" />

### Worked Solutions

In quadrant I, use the component ratio. On the imaginary axis, read the **vector direction** directly to avoid division by zero.

1.  <InlineMath math="z = 1 + \sqrt{3}i" />:

    The point <InlineMath math="(1, \sqrt{3})" /> is in Quadrant <InlineMath math="I" />.

    <MathContainer>
      <BlockMath math="\tan \theta = \frac{\sqrt{3}}{1} = \sqrt{3}" />
      <BlockMath math="\theta = \arctan(\sqrt{3}) = 60^\circ" />
    </MathContainer>

    Since <InlineMath math="60^\circ \in (-180^\circ, 180^\circ]" />, <InlineMath math="\text{Arg}(z) = 60^\circ" />.

2.  <InlineMath math="z = -i" />:

    Write it as <InlineMath math="z = 0 - 1i" />. The point <InlineMath math="(0, -1)" /> lies directly on the negative imaginary axis, so no division by <InlineMath math="x=0" /> is needed.

    <BlockMath math="\text{Arg}(z) = -90^\circ = -\frac{\pi}{2}" />
