## Grundlagen der Operationen

Addition und Skalarmultiplikation komplexer Zahlen folgen denselben vertrauten Rechenregeln wie bei reellen Zahlen. Mit diesen Regeln lassen sich Ausdrücke umformen und vereinfachen, ohne ihren Wert zu verändern.

Seien <InlineMath math="z_1" />, <InlineMath math="z_2" /> und <InlineMath math="z_3" /> beliebige komplexe Zahlen und seien <InlineMath math="c" /> und <InlineMath math="d" /> beliebige Skalare (reelle Zahlen).

## Additionseigenschaften

### Kommutativität

Die Reihenfolge der Summanden verändert die Summe nicht.

<BlockMath math="z_1 + z_2 = z_2 + z_1" />

Beispiel: <InlineMath math="(2+i) + (1-3i) = (1-3i) + (2+i) = 3-2i" />

### Additionsassoziativität

Bei drei komplexen Zahlen kann die Klammerung geändert werden, ohne dass sich die Summe ändert.

<BlockMath math="(z_1 + z_2) + z_3 = z_1 + (z_2 + z_3)" />

### Identitätselement

Die komplexe Zahl <InlineMath math="0 = 0 + 0i" /> ist das neutrale Element der Addition. Addiert man sie zu <InlineMath math="z_1" />, bleibt <InlineMath math="z_1" /> unverändert.

<BlockMath math="z_1 + 0 = z_1" />

### Inverses Element

Zu jeder komplexen Zahl <InlineMath math="z_1 = x + iy" /> gibt es die Gegenzahl <InlineMath math="-z_1 = -x - iy" />. Ihre Summe ist <InlineMath math="0" />.

<BlockMath math="z_1 + (-z_1) = 0" />

Beispiel:

Für <InlineMath math="z_1 = 5-2i" /> ist <InlineMath math="-z_1 = -5+2i" />.

Damit gilt <InlineMath math="(5-2i) + (-5+2i) = (5-5) + i(-2+2) = 0 + 0i = 0" />.

## Skalare Multiplikation

### Assoziativität der Multiplikation

Die Gruppierung der Skalarmultiplikation hat keinen Einfluss auf das Ergebnis.

<BlockMath math="c(dz_1) = (cd)z_1" />

### Skalare Distributivität

Eine Summe von Skalaren kann zuerst gebildet oder auf die komplexe Zahl verteilt werden.

<BlockMath math="(c + d)z_1 = cz_1 + dz_1" />

### Komplexe Distributivität

Ein Skalar kann über die Addition komplexer Zahlen verteilt werden.

<BlockMath math="c(z_1 + z_2) = cz_1 + cz_2" />

### Skalare Identität

Die Multiplikation einer komplexen Zahl mit dem Skalar <InlineMath math="1" /> verändert die komplexe Zahl nicht.

<BlockMath math="1 z_1 = z_1" />

### Nullskalar

Die Multiplikation einer komplexen Zahl mit dem Skalar <InlineMath math="0" /> ergibt die komplexe Null.

<BlockMath math="0 z_1 = 0" />

## Ausdrücke mit Additionseigenschaften vereinfachen

Im nächsten Beispiel werden das Distributivgesetz und die Multiplikation mit dem Nullskalar verwendet, um eine Identität nachzuweisen.

### Das additive Inverse überprüfen

Zeige, dass für jede komplexe Zahl <InlineMath math="z" /> die Gleichung <InlineMath math="4z + (-4)z = 0" /> gilt.

**Lösung:**

Fasse die skalaren Koeffizienten mit dem Distributivgesetz zusammen. Nutze anschließend, dass die Multiplikation mit dem Nullskalar null ergibt.

<MathContainer>
  <BlockMath math="4z + (-4)z = (4 + (-4))z \quad \text{(Distributivgesetz)}" />
  <BlockMath math="= (0)z \quad \text{(Skalare Addition)}" />
  <BlockMath math="= 0 \quad \text{(Multiplikation mit Nullskalareigenschaft)}" />
</MathContainer>

Damit ist bewiesen, dass <InlineMath math="4z + (-4)z = 0" />.

## Übung

Beweise mithilfe der obigen Eigenschaften, dass <InlineMath math="3z - \frac{1}{2}(2z) = 2z" /> für jede komplexe Zahl <InlineMath math="z" /> gilt.

### Ausführliche Lösung

<MathContainer>
  <BlockMath math="3z - \frac{1}{2}(2z) = 3z + (-\frac{1}{2})(2z) \quad \text{(Definition der Subtraktion)}" />
  <BlockMath math="= 3z + ((-\frac{1}{2}) \times 2)z \quad \text{(Assoziativität der Skalarmultiplikation)}" />
  <BlockMath math="= 3z + (-1)z \quad \text{(Skalare Multiplikation)}" />
  <BlockMath math="= (3 + (-1))z \quad \text{(Distributivgesetz)}" />
  <BlockMath math="= (2)z \quad \text{(Skalare Addition)}" />
  <BlockMath math="= 2z" />
</MathContainer>

Damit ist bewiesen, dass <InlineMath math="3z - \frac{1}{2}(2z) = 2z" />.
