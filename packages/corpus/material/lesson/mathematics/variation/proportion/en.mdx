## Variation Links Quantities through One Constant

In **direct variation**, <InlineMath math="y" /> increases as <InlineMath math="x" /> increases, and <InlineMath math="y = kx^n" />. In **inverse variation**, <InlineMath math="y" /> decreases as <InlineMath math="x" /> increases, and <InlineMath math="y = \dfrac{k}{x^n}" />. The number <InlineMath math="k" /> is the **constant of variation**. When <InlineMath math="y" /> varies with two or more variables at once, we get joint or combined variation. The method is always the same: write the equation, find <InlineMath math="k" /> from the given values, then use the equation. In the models here, you change the constant and the power, test experimental data and see the effect of two variables.

### Example Direct Variation with a Square

Given <InlineMath math="y \propto x^2" /> and <InlineMath math="y = 36" /> when <InlineMath math="x = 3" />. Find **the value** of <InlineMath math="y" /> when <InlineMath math="x = 5" />.

<MathContainer>
<BlockMath math="36 = k(3)^2 \quad\Rightarrow\quad k = 4" />
<BlockMath math="y = 4(5)^2 = 100" />
</MathContainer>

Check with the ratio: <InlineMath math="\dfrac{36}{3^2} = 4" /> and <InlineMath math="\dfrac{100}{5^2} = 4" />. In the model, set <InlineMath math="k = 4" />, <InlineMath math="n = 2" /> and <InlineMath math="x = 1.5" />, and it reads <InlineMath math="9" />, which is <InlineMath math="4 \times 1.5^2" />.

## Inverse Variation

If <InlineMath math="y" /> varies inversely as <InlineMath math="x^n" />, written <InlineMath math="y \propto \dfrac{1}{x^n}" />, then <InlineMath math="y = \dfrac{k}{x^n}" /> and **the product** <InlineMath math="yx^n" /> always equals <InlineMath math="k" />. For example, the time to finish a job varies inversely as the number of workers.

### Example Inverse Variation

Four workers build a fence in <InlineMath math="6" /> days. The time <InlineMath math="T" /> varies inversely as the number of workers <InlineMath math="P" />. How many days do **three workers** need?

<MathContainer>
<BlockMath math="T = \frac{k}{P} \quad\Rightarrow\quad 6 = \frac{k}{4} \quad\Rightarrow\quad k = 24" />
<BlockMath math="T = \frac{24}{3} = 8 \text{ days}" />
</MathContainer>

Check: <InlineMath math="4 \times 6 = 3 \times 8 = 24" />, so the product stays the same. In the model, set <InlineMath math="k = 24" />, <InlineMath math="n = 1" /> and <InlineMath math="x = 3" />, and it reads <InlineMath math="8" />.

## Joint and Combined Variation

In **joint variation**, <InlineMath math="y" /> varies directly as the product of two or more variables, for example <InlineMath math="y = kxz" />. In **combined variation**, <InlineMath math="y" /> varies directly as one variable and inversely as another, for example <InlineMath math="y = \dfrac{kx}{z}" />.

### Example Combined Variation

Given <InlineMath math="y \propto \dfrac{x}{z}" />, and <InlineMath math="y = 8" /> when <InlineMath math="x = 4" /> and <InlineMath math="z = 3" />. Find **the value** of <InlineMath math="y" /> when <InlineMath math="x = 6" /> and <InlineMath math="z = 2" />.

<MathContainer>
<BlockMath math="8 = \frac{k(4)}{3} \quad\Rightarrow\quad k = 6" />
<BlockMath math="y = \frac{6(6)}{2} = 18" />
</MathContainer>

Check with the model: with <InlineMath math="k = 6" />, set <InlineMath math="z = 2" /> and <InlineMath math="x = 6" />, and it reads <InlineMath math="18" />. At <InlineMath math="z = 3" /> and <InlineMath math="x = 4" />, it reads <InlineMath math="8" />, the same as the original data.

## Common Mistakes about Variation

| Mistake | Why it's wrong | How to check |
| :--- | :--- | :--- |
| Writing <InlineMath math="y = x + k" /> for direct variation. | Direct variation is a product, <InlineMath math="y = kx^n" />. | The ratio <InlineMath math="\tfrac{y}{x^n}" /> must stay the same. |
| Using <InlineMath math="k" /> from a different question. | Every situation has its own constant. | Find <InlineMath math="k" /> from that question's data. |
| Treating inverse variation as negative values. | Inverse variation means one increases while the other decreases, but both stay positive. | The product <InlineMath math="yx^n" /> must stay the same. |
| Forgetting the power when finding <InlineMath math="k" />. | If <InlineMath math="y \propto x^2" />, the square must be used. | Substitute the original values back. |

The fourth mistake is the most common one in variation questions. **Write the power in the equation before substituting values**.

## Practice on Variation

These questions move from direct variation to combined variation. **Find the constant first** in every question.

1. Given <InlineMath math="p \propto \sqrt{q}" /> and <InlineMath math="p = 12" /> when <InlineMath math="q = 9" />. Find <InlineMath math="p" /> when <InlineMath math="q = 25" />.

2. Given <InlineMath math="y \propto \dfrac{1}{x^2}" /> and <InlineMath math="y = 5" /> when <InlineMath math="x = 2" />. Find <InlineMath math="y" /> when <InlineMath math="x = 5" />.

3. The area <InlineMath math="L" /> of a triangle varies jointly as its base <InlineMath math="t" /> and height <InlineMath math="h" />. Given <InlineMath math="L = 15" /> when <InlineMath math="t = 6" /> and <InlineMath math="h = 5" />. Find the constant and explain what it means.

4. Given <InlineMath math="w \propto \dfrac{u^2}{v}" />, and <InlineMath math="w = 18" /> when <InlineMath math="u = 3" /> and <InlineMath math="v = 2" />. Find <InlineMath math="w" /> when <InlineMath math="u = 4" /> and <InlineMath math="v = 8" />.

### Solutions

**Solution 1**: Write <InlineMath math="p = k\sqrt{q}" /> and find the constant:

<MathContainer>
<BlockMath math="12 = k\sqrt{9} = 3k \quad\Rightarrow\quad k = 4" />
<BlockMath math="p = 4\sqrt{25} = 20" />
</MathContainer>

Check: <InlineMath math="\dfrac{20}{\sqrt{25}} = 4" />.

**Solution 2**: Write <InlineMath math="y = \dfrac{k}{x^2}" /> and **find the constant**:

<MathContainer>
<BlockMath math="5 = \frac{k}{4} \quad\Rightarrow\quad k = 20" />
<BlockMath math="y = \frac{20}{25} = 0.8" />
</MathContainer>

Check: <InlineMath math="0.8 \times 5^2 = 20" />.

**Solution 3**: Write <InlineMath math="L = kth" />:

<BlockMath math="15 = k(6)(5) \quad\Rightarrow\quad k = \frac{1}{2}" />

The constant <InlineMath math="\tfrac{1}{2}" /> is the factor in the triangle area formula, <InlineMath math="L = \tfrac{1}{2}th" />.

**Solution 4**: Write <InlineMath math="w = \dfrac{ku^2}{v}" />:

<MathContainer>
<BlockMath math="18 = \frac{k(9)}{2} \quad\Rightarrow\quad k = 4" />
<BlockMath math="w = \frac{4(16)}{8} = 8" />
</MathContainer>

Check: <InlineMath math="\dfrac{8 \times 8}{16} = 4" />, the same as the constant.
