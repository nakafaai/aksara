## A Graph Shows Connections between Objects

A **graph** is made of **vertices** that stand for objects and **edges** that stand for connections between them. Vertices might be towns and edges roads, or vertices might be students and edges friendships. The **degree** of a vertex is the number of edges that meet at it. The sum of the degrees of all vertices is always twice the number of edges, because every edge has two ends. In the models here, you read a weighted graph, compare a tree with a complete graph and find the shortest path.

### Types of Graph

Graphs are classified by **the shape of their edges**.

| Type | Feature |
| :--- | :--- |
| Simple graph | No loops and no multiple edges |
| Graph with a loop | An edge starts and ends at the same vertex and adds <InlineMath math="2" /> to its degree |
| Multigraph | More than one edge joins the same two vertices |
| Directed graph | Every edge has a direction |
| Weighted graph | Every edge carries a value such as distance, time or cost |

## Subgraphs and Trees

A **subgraph** is a graph whose vertices and edges are all taken from the original graph. A **tree** is a connected graph with no cycles. A tree with <InlineMath math="n" /> vertices always has exactly <InlineMath math="n - 1" /> edges. In contrast, a **complete graph**, where every pair of vertices is joined, has <InlineMath math="\dfrac{n(n - 1)}{2}" /> edges. Change the number of vertices and compare the two.

## Shortest Path

In a weighted graph, the **shortest path** is the path with the smallest total weight. Drivers looking for the nearest route, delivery companies planning trips and map apps all solve this problem. The path with the fewest edges isn't necessarily the shortest, because one long edge can outweigh two short ones.

## Common Mistakes about Networks

| Mistake | Why it's wrong | How to check |
| :--- | :--- | :--- |
| A loop adds <InlineMath math="1" /> to the degree. | A loop has both ends at the same vertex, so it adds <InlineMath math="2" />. | The degrees must add up to twice the number of edges. |
| The path with the fewest edges is the shortest path. | The shortest path depends on total weight, not on the number of edges. | Add up the weights of each path. |
| A tree can have a cycle. | A tree has no cycles at all. | A tree with <InlineMath math="n" /> vertices must have <InlineMath math="n - 1" /> edges. |
| In-degree and out-degree are always equal for every vertex. | Only their totals over the whole graph are equal. | Count the arrows at each vertex separately. |

The second mistake is the most common one in shortest path questions. **Compare total weights, not numbers of edges**.

## Practice on Networks in Graph Theory

These questions move from degrees to trees and shortest paths. **Check every answer with the sum of degrees or the total weight**.

1. A graph has vertices with degrees <InlineMath math="1, 2, 2, 3, 4" />. Find the number of edges.

2. A tree has <InlineMath math="12" /> vertices. How many edges does it have?

3. How many edges does a complete graph with <InlineMath math="7" /> vertices have?

4. In the five-town graph, the road from <InlineMath math="D" /> to <InlineMath math="E" /> is closed. Find the new shortest path from <InlineMath math="A" /> to <InlineMath math="E" />.

### Solutions

**Solution 1**: The sum of degrees is twice the number of edges:

<BlockMath math="\frac{1 + 2 + 2 + 3 + 4}{2} = \frac{12}{2} = 6" />

Check: there are two vertices with an odd degree, an even number, as expected.

**Solution 2**: A tree with <InlineMath math="n" /> vertices has <InlineMath math="n - 1" /> edges, so **<InlineMath math="11" /> edges**.

**Solution 3**: Use the complete graph rule:

<BlockMath math="\frac{7 \times 6}{2} = 21" />

Check with the model: at <InlineMath math="n = 7" />, it shows <InlineMath math="21" /> edges for the complete graph.

**Solution 4**: Without edge <InlineMath math="DE" />, the remaining paths are <InlineMath math="A \to B \to E = 10" />, <InlineMath math="A \to B \to C \to E = 11" />, <InlineMath math="A \to D \to B \to E = 11" /> and <InlineMath math="A \to D \to B \to C \to E = 12" />. **The new shortest path** is <InlineMath math="A \to B \to E" />, at <InlineMath math="10\text{ km}" />.
