## Panjang dan Arah Vektor

Setiap vektor tak nol memiliki dua ciri utama: **besar** dan **arah**. Vektor nol merupakan kasus khusus yang akan dibahas kemudian.

Perhatikan contoh vektor <InlineMath math="\overrightarrow{CD}" /> di bawah ini.

<VectorChart
  title={
    <>
      Vektor <InlineMath math="CD" />
    </>
  }
  description={
    <>
      Vektor <InlineMath math="CD" /> dengan panjang <InlineMath math="4 \text{ cm}" /> dan arah <InlineMath math="45^\circ" />
      terhadap garis horizontal.
    </>
  }
  vectors={[
    {
      id: "cd",
      name: "CD",
      points: [
        { x: 0, y: 0 },
        { x: 4 * Math.cos(Math.PI / 4), y: 4 * Math.sin(Math.PI / 4) },
      ],
    },
  ]}
/>

- **Besar vektor** <InlineMath math="\overrightarrow{CD}" /> adalah <InlineMath math="4 \text{ cm}" />. Nilai ini menunjukkan _besar_ vektor dan bukan _arahnya_. Besar vektor <InlineMath math="\vec{v}" /> dinotasikan dengan <InlineMath math="|\vec{v}|" />. Jadi, <InlineMath math="|\overrightarrow{CD}| = 4 \text{ cm}" />.
- **Arah vektor** <InlineMath math="\overrightarrow{CD}" /> adalah <InlineMath math="45^\circ" /> terhadap garis horizontal. Arah ini sangat penting dan membedakan vektor dari besaran skalar (yang hanya punya nilai). Arah bisa dinyatakan dengan sudut, mata angin (seperti Timur Laut), atau acuan lainnya.

## Vektor Negatif (Vektor Lawan)

Untuk vektor tak nol, vektor negatif atau vektor lawannya memiliki **panjang yang sama** tetapi **arah yang berlawanan**.

Bayangkan Andi berjalan sejauh <InlineMath math="100 \text{ m}" /> dengan sudut <InlineMath math="30^\circ" />. Kita sebut perpindahan ini <InlineMath math="\vec{A}" />. Jika Andi kemudian kembali langsung melalui lintasan yang sama, perpindahan pulangnya adalah vektor lawan dari <InlineMath math="\vec{A}" />, yang ditulis sebagai <InlineMath math="-\vec{A}" />.

<VectorChart
  title="Vektor dan Vektor Lawan"
  description={
    <>
      Vektor <InlineMath math="A" /> dan vektor <InlineMath math="-A" />{" "}
      memiliki panjang yang sama tetapi arah berlawanan.
    </>
  }
  vectors={[
    {
      id: "A",
      name: "A",
      points: [
        { x: 0, y: 0 },
        { x: 5, y: 2 },
      ],
    },
    {
      id: "-A",
      name: "-A",
      points: [
        { x: 0, y: 0.5 },
        { x: 5, y: 2.5 },
      ],
      direction: "backward",
    },
  ]}
/>

- Vektor <InlineMath math="\vec{A}" /> dan <InlineMath math="-\vec{A}" /> memiliki panjang yang sama (<InlineMath math="|\vec{A}| = |-\vec{A}|" />).
- Arah vektor <InlineMath math="-\vec{A}" /> tepat berlawanan dengan arah vektor <InlineMath math="\vec{A}" />. Jika <InlineMath math="\vec{A}" /> menunjuk ke satu arah, <InlineMath math="-\vec{A}" /> menunjuk ke arah sebaliknya (berbeda <InlineMath math="180^\circ" />).

## Vektor Nol

Vektor nol adalah vektor yang istimewa karena memiliki **panjang nol**. Karena panjangnya nol, vektor ini **tidak memiliki arah tertentu**.

Vektor nol bisa dibayangkan sebagai sebuah titik, di mana titik pangkal dan titik ujungnya berimpit. Vektor nol biasanya dinotasikan dengan <InlineMath math="\vec{0}" />.

**Contoh**:

Jika Andi berjalan <InlineMath math="100 \text{ m}" /> ke timur, kemudian berjalan kembali <InlineMath math="100 \text{ m}" /> ke barat, maka total perpindahan Andi adalah nol. Perpindahan total ini dapat direpresentasikan sebagai vektor nol (<InlineMath math="\vec{0}" />).

## Vektor Ekuivalen (Vektor yang Sama)

Dua vektor dikatakan **ekuivalen** atau **sama** jika komponen-komponen yang bersesuaian sama, meskipun titik pangkalnya berbeda. Untuk vektor tak nol, syarat ini setara dengan memiliki **besar dan arah yang sama**. Definisi berdasarkan komponen juga mencakup vektor nol yang tidak memiliki arah terdefinisi.

Perhatikan grafik di bawah ini yang menunjukkan tiga vektor ekuivalen: <InlineMath math="\overrightarrow{CD}" />, <InlineMath math="\overrightarrow{EF}" />, dan <InlineMath math="\overrightarrow{KL}" />.

<VectorChart
  title="Vektor-Vektor Ekuivalen"
  description={
    <>
      Vektor <InlineMath math="CD" />, <InlineMath math="EF" />, dan{" "}
      <InlineMath math="KL" /> memiliki panjang dan arah yang sama.
    </>
  }
  vectors={[
    {
      id: "CD",
      name: "CD",
      points: [
        { x: 2, y: 1 }, // C
        { x: 5, y: 3 }, // D
      ],
    },
    {
      id: "EF",
      name: "EF",
      points: [
        { x: 4, y: 2 }, // E
        { x: 7, y: 4 }, // F
      ],
    },
    {
      id: "KL",
      name: "KL",
      points: [
        { x: 3, y: 0 }, // K
        { x: 6, y: 2 }, // L
      ],
    },
  ]}
/>

Ketiga vektor di atas memiliki panjang dan arah yang sama, sehingga mereka ekuivalen. Kita dapat menuliskannya sebagai:

<BlockMath math="\overrightarrow{CD} = \overrightarrow{EF} = \overrightarrow{KL}" />

Titik pangkalnya berbeda, tetapi setiap anak panah berpindah tiga satuan ke kanan dan dua satuan ke atas. Ketiganya memiliki vektor komponen yang sama, yaitu <InlineMath math="(3, 2)" />.

## Latihan

Perhatikan kedua vektor berikut:

<VectorChart
  title={
    <>
      Perbandingan Vektor <InlineMath math="A" /> dan Vektor{" "}
      <InlineMath math="B" />
    </>
  }
  description={
    <>
      Perbandingan Vektor <InlineMath math="A" /> dan Vektor{" "}
      <InlineMath math="B" />
    </>
  }
  vectors={[
    {
      id: "A",
      name: "A",
      points: [
        { x: 1, y: 4 },
        { x: 0, y: 0 },
      ],
      direction: "backward",
    },
    {
      id: "B",
      name: "B",
      points: [
        { x: 1, y: 4 },
        { x: 5, y: 5 },
      ],
    },
  ]}
/>

Apakah vektor <InlineMath math="\vec{A}" /> merupakan vektor lawan dari <InlineMath math="\vec{B}" />?

**Jawaban:**

Vektor <InlineMath math="\vec{A}" /> **bukan** vektor lawan dari <InlineMath math="\vec{B}" />. Mari periksa kedua syarat yang diperlukan:

1.  **Besarnya harus sama:** Diagram memberikan <InlineMath math="\vec{A} = (-1, -4)" /> dan <InlineMath math="\vec{B} = (4, 1)" />, sehingga <InlineMath math="|\vec{A}| = |\vec{B}| = \sqrt{17}" />. Syarat ini terpenuhi.
2.  **Arahnya harus tepat berlawanan, atau berbeda <InlineMath math="180^\circ" />:** Vektor lawan dari <InlineMath math="\vec{A}" /> adalah <InlineMath math="-\vec{A} = (1, 4)" /> dan bukan <InlineMath math="\vec{B} = (4, 1)" />. Syarat ini tidak terpenuhi.

Karena syarat kedua tidak terpenuhi, <InlineMath math="\vec{A}" /> bukanlah vektor lawan dari <InlineMath math="\vec{B}" />.

**Bagaimana cara membuat vektor <InlineMath math="\vec{A}" /> dan <InlineMath math="\vec{B}" /> berlawanan?**

Dengan mempertahankan <InlineMath math="\vec{A}" />, kita dapat membuat <InlineMath math="\vec{B}" /> menjadi vektor lawannya dengan mengubah titik ujung <InlineMath math="\vec{B}" />:

<VectorChart
  title={
    <>
      Vektor <InlineMath math="A" /> dan <InlineMath math="B" />
    </>
  }
  description={
    <>
      Vektor <InlineMath math="A" /> dan <InlineMath math="B" /> berlawanan
    </>
  }
  vectors={[
    {
      id: "A",
      name: "A",
      points: [
        { x: 1, y: 4 },
        { x: 0, y: 0 },
      ],
      direction: "backward",
    },
    {
      id: "B",
      name: "B",
      points: [
        { x: 1, y: 4 },
        { x: 2, y: 8 },
      ],
      direction: "forward",
    },
  ]}
/>
