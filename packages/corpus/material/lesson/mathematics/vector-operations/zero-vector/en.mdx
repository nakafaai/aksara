## A Vector Whose Endpoints Coincide

The zero vector is a vector with magnitude zero and no defined direction. Its <Highlight>initial and terminal points coincide</Highlight>, so its arrow collapses to a single point in a geometric drawing.

The zero vector is denoted by <InlineMath math="\vec{0}" />, the number <InlineMath math="0" /> with an arrow above it.

## Properties of Zero Vector

Zero vector has several special properties that distinguish it from other vectors:

1. The zero vector is the identity element for vector addition. If <InlineMath math="\vec{a}" /> is any vector, then <InlineMath math="\vec{a} + \vec{0} = \vec{a}" />

2. Its magnitude is zero: <InlineMath math="|\vec{0}| = 0" />

3. It **cannot be normalized** because dividing by its zero magnitude is undefined.

4. Every vector space has exactly one additive identity, so its zero vector is unique.

5. For every vector <InlineMath math="\vec{v}" />, <InlineMath math="\vec{0} \cdot \vec{v} = 0" />, so the zero vector satisfies the algebraic dot-product condition for orthogonality. Because it has no direction, however, it should not be described as geometrically parallel to a direction.

6. Multiplying it by any real scalar still gives the zero vector: <InlineMath math="k \cdot \vec{0} = \vec{0}" />

## Representation of Zero Vector

**Every Cartesian component** of the zero vector equals zero, so its length is zero and it has no direction. The list below shows the coordinates in one, two, and three dimensions.

- In <InlineMath math="1" />-dimensional space: <InlineMath math="\vec{0} = (0)" />
- In <InlineMath math="2" />-dimensional space: <InlineMath math="\vec{0} = (0, 0)" />
- In <InlineMath math="3" />-dimensional space: <InlineMath math="\vec{0} = (0, 0, 0)" />

## Returning to the Starting Point

One example of a zero vector in daily life is the displacement of someone who returns to their starting position. For instance:

If Andi walks <InlineMath math="100 \text{ m}" /> east and then <InlineMath math="100 \text{ m}" /> west, his total displacement is zero. Although Andi has traveled a total distance of <InlineMath math="200 \text{ m}" />, his displacement (the difference between final and initial positions) is zero.

Take east as positive and the starting position as <InlineMath math="0\text{ m}" />. **Distance traveled increases** on the return trip, while the position returns to its starting value.

| Stage | Position from the start | Distance traveled |
| --- | --- | --- |
| Start | <InlineMath math="0\text{ m}" /> | <InlineMath math="0\text{ m}" /> |
| After walking east | <InlineMath math="100\text{ m}" /> | <InlineMath math="100\text{ m}" /> |
| After returning west | <InlineMath math="0\text{ m}" /> | <InlineMath math="200\text{ m}" /> |

<BlockMath math="\Delta x=100\text{ m}+(-100\text{ m})=0\text{ m}" />

Walk from <InlineMath math="A" /> to <InlineMath math="B" />, then to <InlineMath math="C" />, then back to <InlineMath math="A" />. The three displacements <InlineMath math="\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CA}" /> bring you to where you started, so their sum is the zero vector <InlineMath math="\vec 0" />: no change of position at all.

## Zero Vector in Vector Operations

Adding the zero vector and subtracting the zero vector both **preserve the original vector**. Subtraction order matters: subtracting a vector from the zero vector gives that vector's opposite.

### Addition with Zero Vector

If <InlineMath math="\vec{a}" /> is any vector, then:

<BlockMath math="\vec{a} + \vec{0} = \vec{a},\qquad (3,-2)+(0,0)=(3,-2)" />

The zero vector is therefore the **identity element** for vector addition.

### Subtraction with Zero Vector

Subtracting the zero vector **preserves the original vector**. Reversing the subtraction gives the opposite of the original vector.

For any vector <InlineMath math="\vec{a}" />:

<MathContainer>
  <BlockMath math="\vec{a} - \vec{0} = \vec{a},\qquad (3,-2)-(0,0)=(3,-2)" />
  <BlockMath math="\vec{0} - \vec{a} = -\vec{a},\qquad (0,0)-(3,-2)=(-3,2)" />
</MathContainer>

A vector minus itself leaves nothing. <InlineMath math="\vec a = (3, 1)" /> and <InlineMath math="-\vec a = (-3, -1)" /> have the same length and opposite directions, so <InlineMath math="\vec a - \vec a = \vec a + (-\vec a) = \vec 0" />, a vector of length <InlineMath math="0" /> that sits at the origin.

### Scalar Multiplication with Zero Vector

Every zero component remains zero after multiplication, so the result is **still the zero vector** for every scalar.

For any scalar <InlineMath math="k" />:

<BlockMath math="k \cdot \vec{0} = \vec{0}" />

Shrink a vector by smaller and smaller scalars and its tip slides toward the origin: <InlineMath math="2\vec a" />, <InlineMath math="\vec a" />, <InlineMath math="\tfrac12 \vec a" />. At the scalar <InlineMath math="0" /> the tip lands on the starting point, so <InlineMath math="0\vec a = \vec 0" /> for every vector.

## Applications of Zero Vector Concept

The zero vector appears in the following settings:

1. In a homogeneous system of linear equations, the zero vector is always the trivial solution.
2. In physics, a zero resultant force on an object with nonzero mass means **zero acceleration**. In an inertial frame, the object therefore remains at rest or continues with constant velocity, as described by Newton's first law.
3. In computer graphics, the zero vector represents no displacement and therefore leaves a position unchanged when used as a translation vector.
