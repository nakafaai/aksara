## Verschiebungen verstehen

Eine Verschiebung bewegt jeden Punkt eines Objekts um dieselbe Strecke in dieselbe Richtung. Ausrichtung, Größe und Form bleiben dabei erhalten. Nur die Position des Objekts ändert sich.

### Definition einer Verschiebung

Gegeben sei ein beliebiger Punkt <InlineMath math="P(x,y)" />. Die dem Vektor <InlineMath math="\begin{pmatrix} a \\ b \end{pmatrix}" /> zugeordnete Verschiebung des Punktes <InlineMath math="P(x,y)" />, geschrieben als <InlineMath math="T_{(a,b)}(x,y)" /> oder <InlineMath math="\tau_{(a,b)}(x,y)" />, ist definiert durch:

<BlockMath math="P'(x',y') = (x+a, y+b)" />

Das bedeutet:

<MathContainer>
  <BlockMath math="x' = x + a" />
  <BlockMath math="y' = y + b" />
</MathContainer>

Dabei ist <InlineMath math="a" /> die horizontale Verschiebung (positiv nach rechts, negativ nach links) und <InlineMath math="b" /> die vertikale Verschiebung (positiv nach oben, negativ nach unten).

## Einen Punkt verschieben

Ein Punkt <InlineMath math="(3,2)" /> wird durch den Vektor <InlineMath math="\begin{pmatrix} -2 \\ 3 \end{pmatrix}" /> verschoben. Bestimme den Bildpunkt dieser Verschiebung.

Hier: <InlineMath math="x=3" />, <InlineMath math="y=2" />, <InlineMath math="a=-2" /> und <InlineMath math="b=3" />.

Mit der Formel:

<MathContainer>
  <BlockMath math="x' = x + a = 3 + (-2) = 1" />
  <BlockMath math="y' = y + b = 2 + 3 = 5" />
</MathContainer>

Somit ist das Bild des Punktes <InlineMath math="(3,2)" /> <InlineMath math="(1,5)" />.

  }
  description={
    <>
      Der Verschiebungsvektor bildet den Punkt <InlineMath math="P(3,2)" /> auf{" "}
      <InlineMath math="P'(1,5)" /> ab.

  }
  data={[

  ]}
  showZAxis={false}
/>

## Eine Gerade verschieben

Bestimme das Bild der Geraden <InlineMath math="l \equiv 2x + 3y - 1 = 0" /> unter der Verschiebung um den Vektor <InlineMath math="\begin{pmatrix} -1 \\ 1 \end{pmatrix}" />.

Sei <InlineMath math="P(x,y)" /> ein beliebiger Punkt auf der Geraden <InlineMath math="l" />. Wird er um den Vektor <InlineMath math="\begin{pmatrix} -1 \\ 1 \end{pmatrix}" /> verschoben, so ist sein Bild <InlineMath math="P'(x',y')" />. Es gilt:

<MathContainer>
  <BlockMath math="x' = x + (-1) = x - 1 \implies x = x' + 1" />
  <BlockMath math="y' = y + 1 \implies y = y' - 1" />
</MathContainer>

Wir setzen diese Ausdrücke für <InlineMath math="x" /> und <InlineMath math="y" /> in die Gleichung der Geraden <InlineMath math="l" /> ein:

<MathContainer>
  <BlockMath math="2(x' + 1) + 3(y' - 1) - 1 = 0" />
  <BlockMath math="2x' + 2 + 3y' - 3 - 1 = 0" />
  <BlockMath math="2x' + 3y' - 2 = 0" />
</MathContainer>

Ersetzen wir <InlineMath math="x'" /> und <InlineMath math="y'" /> wieder durch <InlineMath math="x" /> und <InlineMath math="y" />, lautet die Gleichung der Bildgeraden <InlineMath math="l'" />:

<ContentStack>

  <BlockMath math="2x + 3y - 2 = 0" />

  <LineEquation
    title={
      <>
        Verschiebung der Geraden <InlineMath math="2x+3y-1=0" /> um den Vektor{" "}
        <InlineMath math="\begin{pmatrix} -1 \\ 1 \end{pmatrix}" />
      </>
    }
    description={
      <>
        Die Verschiebung bildet die Gerade <InlineMath math="2x+3y-1=0" /> auf
        die Bildgerade <InlineMath math="2x+3y-2=0" /> ab.
      </>
    }
    data={[
      {
        // Ursprüngliche Gerade: 2x + 3y - 1 = 0  => y = (-2/3)x + 1/3
        points: Array.from({ length: 11 }, (_, i) => {

          return { x: xVal, y: (-2 / 3) * xVal + 1 / 3, z: 0 };
        }),
        color: "#9333ea",
        labels: [{ text: <InlineMath math="2x+3y-1=0" />, at: 2, offset: [-1, -0.5, 0] }],
      },
      {
        // Bildgerade: 2x + 3y - 2 = 0 => y = (-2/3)x + 2/3
        points: Array.from({ length: 11 }, (_, i) => {
          const xVal = i - 5;
          return { x: xVal, y: (-2 / 3) * xVal + 2 / 3, z: 0 };
        }),
        color: "#db2777",
        labels: [{ text: <InlineMath math="2x+3y-2=0" />, at: 8, offset: [1, 0.5, 0] }],
      },
    ]}
    showZAxis={false}
    cameraPosition={[0, 0, 10]}
  />
</ContentStack>

## Übungen

1.  Ein Punkt <InlineMath math="(-4,4)" /> wird durch den Vektor <InlineMath math="\begin{pmatrix} -2 \\ -3 \end{pmatrix}" /> verschoben. Bestimme den Bildpunkt dieser Verschiebung.
2.  Bestimme das Bild der Geraden <InlineMath math="l \equiv 5x - 2y + 3 = 0" /> unter der Verschiebung um den Vektor <InlineMath math="\begin{pmatrix} 2 \\ -1 \end{pmatrix}" />.
3.  Ein Dreieck mit den Eckpunkten <InlineMath math="A(1,1)" />, <InlineMath math="B(4,1)" /> und <InlineMath math="C(1,5)" /> wird um den Vektor <InlineMath math="\begin{pmatrix} 2 \\ 3 \end{pmatrix}" /> verschoben. Bestimme die Koordinaten des Bilddreiecks <InlineMath math="A'B'C'" />.

### Lösungen

1.  Punkt <InlineMath math="(-4,4)" />, Vektor <InlineMath math="\begin{pmatrix} -2 \\ -3 \end{pmatrix}" />. <InlineMath math="x=-4, y=4, a=-2, b=-3" />.

    <MathContainer>
      <BlockMath math="x' = -4 + (-2) = -6" />
      <BlockMath math="y' = 4 + (-3) = 1" />
    </MathContainer>

    Somit ist der Bildpunkt <InlineMath math="(-6,1)" />.

2.  Gerade <InlineMath math="5x - 2y + 3 = 0" />, Vektor <InlineMath math="\begin{pmatrix} 2 \\ -1 \end{pmatrix}" />. <InlineMath math="a=2, b=-1" />.

    <MathContainer>
      <BlockMath math="x' = x + 2 \implies x = x' - 2" />
      <BlockMath math="y' = y - 1 \implies y = y' + 1" />
    </MathContainer>

    Wir setzen die Ausdrücke in die Geradengleichung ein:

    <MathContainer>
      <BlockMath math="5(x' - 2) - 2(y' + 1) + 3 = 0" />
      <BlockMath math="5x' - 10 - 2y' - 2 + 3 = 0" />
      <BlockMath math="5x' - 2y' - 9 = 0" />
    </MathContainer>

    Die Gleichung der Bildgeraden lautet <InlineMath math="5x - 2y - 9 = 0" />.

3.  Punkte <InlineMath math="A(1,1)" />, <InlineMath math="B(4,1)" />, <InlineMath math="C(1,5)" />. Vektor <InlineMath math="\begin{pmatrix} 2 \\ 3 \end{pmatrix}" />.

    <MathContainer>
      <BlockMath math="A'(1+2, 1+3) = A'(3,4)" />
      <BlockMath math="B'(4+2, 1+3) = B'(6,4)" />
      <BlockMath math="C'(1+2, 5+3) = C'(3,8)" />
    </MathContainer>

    Die Koordinaten des Bilddreiecks sind <InlineMath math="A'(3,4)" />, <InlineMath math="B'(6,4)" /> und <InlineMath math="C'(3,8)" />.
