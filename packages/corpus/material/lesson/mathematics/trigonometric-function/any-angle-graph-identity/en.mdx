## The Unit Circle Gives Every Value

For any angle <InlineMath math="\theta" /> measured from the positive <InlineMath math="x" />-axis, the point on the **unit circle** is <InlineMath math="(\cos\theta, \sin\theta)" />. From these two values you get all six trigonometric functions:

<MathContainer>
<BlockMath math="\tan\theta = \frac{\sin\theta}{\cos\theta}, \qquad \sec\theta = \frac{1}{\cos\theta}" />
<BlockMath math="\operatorname{cosec}\theta = \frac{1}{\sin\theta}, \qquad \cot\theta = \frac{1}{\tan\theta}" />
</MathContainer>

Positive angles are measured **anticlockwise** and negative angles **clockwise**. The sign of each function depends on the quadrant, and its size equals the value for the **reference angle**, the acute angle between the radius and the <InlineMath math="x" />-axis.

In these notes you turn the radius of the unit circle, change the amplitude and period of a sine graph, solve an equation with a graph, and check a compound angle formula.

The signs in each quadrant follow the order **all, sin, tan, cos**: all are positive in the first quadrant, only sin in the second, only tan in the third, and only cos in the fourth.

| Angle | Quadrant | Reference angle | Value |
| :--- | :--- | :--- | :--- |
| <InlineMath math="210^\circ" /> | Third | <InlineMath math="30^\circ" /> | <InlineMath math="\sin 210^\circ = -\sin 30^\circ = -\tfrac{1}{2}" /> |
| <InlineMath math="300^\circ" /> | Fourth | <InlineMath math="60^\circ" /> | <InlineMath math="\cos 300^\circ = \cos 60^\circ = \tfrac{1}{2}" /> |
| <InlineMath math="135^\circ" /> | Second | <InlineMath math="45^\circ" /> | <InlineMath math="\tan 135^\circ = -\tan 45^\circ = -1" /> |
| <InlineMath math="-150^\circ" /> | Third | <InlineMath math="30^\circ" /> | <InlineMath math="\cos(-150^\circ) = -\cos 30^\circ = -\tfrac{\sqrt{3}}{2}" /> |

A reciprocal function has the sign of its original function. For example, <InlineMath math="\operatorname{cosec} 330^\circ = \dfrac{1}{\sin 330^\circ} = \dfrac{1}{-\tfrac{1}{2}} = -2" />. Angles can also be written in radians: <InlineMath math="225^\circ = \dfrac{225}{180}\pi = \dfrac{5\pi}{4}" /> radians.

## Basic Identities and Angle Formulas

Pythagoras' theorem on the unit circle gives the **basic identity** <InlineMath math="\sin^2\theta + \cos^2\theta = 1" />. Divide it by <InlineMath math="\cos^2\theta" /> or <InlineMath math="\sin^2\theta" /> to get two more identities:

<MathContainer>
<BlockMath math="1 + \tan^2\theta = \sec^2\theta" />
<BlockMath math="1 + \cot^2\theta = \operatorname{cosec}^2\theta" />
</MathContainer>

For example, <InlineMath math="(1 - \cos^2 x)(1 + \cot^2 x) = \sin^2 x \cdot \operatorname{cosec}^2 x = 1" />.

The **compound angle formulas** and **double angle formulas** are:

<MathContainer>
<BlockMath math="\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B" />
<BlockMath math="\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B" />
<BlockMath math="\sin 2A = 2\sin A\cos A, \qquad \cos 2A = \cos^2 A - \sin^2 A" />
</MathContainer>

The compound angle formula shows that <InlineMath math="\sin x + \cos x = \sqrt{2}\sin(x + 45^\circ)" />, because <InlineMath math="\sqrt{2}\sin(x + 45^\circ) = \sqrt{2}\left(\sin x \cdot \tfrac{1}{\sqrt{2}} + \cos x \cdot \tfrac{1}{\sqrt{2}}\right)" />. A quadratic equation in <InlineMath math="\sin x" /> is solved by factorising. Solve <InlineMath math="2\sin^2 x - \sin x - 1 = 0" /> for <InlineMath math="0^\circ \le x \le 360^\circ" />:

<MathContainer>
<BlockMath math="(2\sin x + 1)(\sin x - 1) = 0" />
<BlockMath math="\sin x = 1 \quad \Rightarrow \quad x = 90^\circ" />
<BlockMath math="\sin x = -\tfrac{1}{2} \quad \Rightarrow \quad x = 210^\circ, \ 330^\circ" />
</MathContainer>

The sine is negative in the third and fourth quadrants, so the reference angle <InlineMath math="30^\circ" /> gives <InlineMath math="180^\circ + 30^\circ" /> and <InlineMath math="360^\circ - 30^\circ" />.

## Common Mistakes with Trigonometric Functions

| Mistake | Why it is wrong | How to check |
| :--- | :--- | :--- |
| Giving only one solution of <InlineMath math="\sin x = \tfrac{1}{2}" />. | The sine is positive in two quadrants. | Sketch the graph and count the intersection points. |
| Writing <InlineMath math="\sin 2A = 2\sin A" />. | The double angle formula is <InlineMath math="2\sin A\cos A" />. | Test <InlineMath math="A = 90^\circ" />: <InlineMath math="\sin 180^\circ = 0" />, not <InlineMath math="2" />. |
| Taking the period of <InlineMath math="y = \sin 2x" /> as <InlineMath math="720^\circ" />. | The constant <InlineMath math="b = 2" /> shortens the period to <InlineMath math="\tfrac{360^\circ}{2}" />. | Count the cycles in <InlineMath math="360^\circ" />. |
| Giving <InlineMath math="\cos 120^\circ" /> a positive sign. | The cosine is negative in the second quadrant. | Remember the order all, sin, tan, cos. |
| The calculator is in the wrong mode. | Degrees and radians give different values. | Check that <InlineMath math="\sin 90^\circ = 1" /> before you start. |

The first mistake is the most common. **After you find the reference angle**, decide every quadrant that gives the right sign.

## Trigonometric Functions Practice

Sketch the unit circle or the graph for each question so that **the sign and the number of solutions are clear**.

1. Find the exact values of <InlineMath math="\cos 240^\circ" />, <InlineMath math="\tan 300^\circ" /> and <InlineMath math="\operatorname{cosec} 150^\circ" />.

2. State the amplitude, period, maximum value and minimum value of <InlineMath math="y = 2\cos 3x - 1" />.

3. Given <InlineMath math="\tan A = \tfrac{5}{12}" /> with <InlineMath math="A" /> in the third quadrant, find <InlineMath math="\sin A" />, <InlineMath math="\cos A" /> and <InlineMath math="\sin 2A" />.

4. Solve <InlineMath math="\cos 2x = \cos x" /> for <InlineMath math="0^\circ \le x \le 360^\circ" />.

### Solutions

**Solution 1**: Use the reference angle and the sign of the quadrant:

<MathContainer>
<BlockMath math="\cos 240^\circ = -\cos 60^\circ = -\tfrac{1}{2}" />
<BlockMath math="\tan 300^\circ = -\tan 60^\circ = -\sqrt{3}" />
<BlockMath math="\operatorname{cosec} 150^\circ = \frac{1}{\sin 150^\circ} = \frac{1}{\tfrac{1}{2}} = 2" />
</MathContainer>

**Solution 2**: Compare with <InlineMath math="y = a\cos bx + c" />, with <InlineMath math="a = 2" />, <InlineMath math="b = 3" /> and <InlineMath math="c = -1" />. The amplitude is <InlineMath math="2" />, the period is <InlineMath math="\tfrac{360^\circ}{3} = 120^\circ" />, the maximum is <InlineMath math="2 - 1 = 1" /> and the minimum is <InlineMath math="-2 - 1 = -3" />.

**Solution 3**: The reference triangle has sides <InlineMath math="5" />, <InlineMath math="12" /> and <InlineMath math="13" />. In the third quadrant, the sine and cosine are **both negative**:

<MathContainer>
<BlockMath math="\sin A = -\tfrac{5}{13}, \qquad \cos A = -\tfrac{12}{13}" />
<BlockMath math="\sin 2A = 2\left(-\tfrac{5}{13}\right)\left(-\tfrac{12}{13}\right) = \tfrac{120}{169}" />
</MathContainer>

**Solution 4**: Change <InlineMath math="\cos 2x" /> to <InlineMath math="2\cos^2 x - 1" />:

<MathContainer>
<BlockMath math="2\cos^2 x - \cos x - 1 = 0 \quad \Rightarrow \quad (2\cos x + 1)(\cos x - 1) = 0" />
<BlockMath math="\cos x = 1 \quad \Rightarrow \quad x = 0^\circ, 360^\circ" />
<BlockMath math="\cos x = -\tfrac{1}{2} \quad \Rightarrow \quad x = 120^\circ, 240^\circ" />
</MathContainer>

Check <InlineMath math="x = 120^\circ" />: <InlineMath math="\cos 240^\circ = -\tfrac{1}{2} = \cos 120^\circ" />.
