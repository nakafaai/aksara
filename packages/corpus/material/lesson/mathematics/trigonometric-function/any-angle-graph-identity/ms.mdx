## Bulatan Unit Memberi Semua Nilai

Bagi sebarang sudut <InlineMath math="\theta" /> yang diukur dari paksi-<InlineMath math="x" /> positif, titik pada **bulatan unit** ialah <InlineMath math="(\cos\theta, \sin\theta)" />. Daripada dua nilai ini kamu dapat enam fungsi trigonometri:

<MathContainer>
<BlockMath math="\tan\theta = \frac{\sin\theta}{\cos\theta}, \qquad \operatorname{sek}\theta = \frac{1}{\cos\theta}" />
<BlockMath math="\operatorname{kosek}\theta = \frac{1}{\sin\theta}, \qquad \operatorname{kot}\theta = \frac{1}{\tan\theta}" />
</MathContainer>

Sudut positif diukur **lawan arah jam** dan sudut negatif **ikut arah jam**. Tanda setiap fungsi bergantung pada sukuan, dan nilai mutlaknya sama dengan nilai bagi **sudut rujukan**, iaitu sudut tirus antara jejari dengan paksi-<InlineMath math="x" />.

Dalam nota ini kamu putar jejari bulatan unit, ubah amplitud dan kala graf sinus, selesaikan persamaan dengan graf, dan semak rumus sudut majmuk.

Tanda fungsi dalam setiap sukuan boleh diingat dengan susunan **semua, sin, tan, kos**: semua positif dalam sukuan pertama, hanya sin positif dalam sukuan kedua, hanya tan dalam sukuan ketiga, dan hanya kos dalam sukuan keempat.

| Sudut | Sukuan | Sudut rujukan | Nilai |
| :--- | :--- | :--- | :--- |
| <InlineMath math="210^\circ" /> | Ketiga | <InlineMath math="30^\circ" /> | <InlineMath math="\sin 210^\circ = -\sin 30^\circ = -\tfrac{1}{2}" /> |
| <InlineMath math="300^\circ" /> | Keempat | <InlineMath math="60^\circ" /> | <InlineMath math="\cos 300^\circ = \cos 60^\circ = \tfrac{1}{2}" /> |
| <InlineMath math="135^\circ" /> | Kedua | <InlineMath math="45^\circ" /> | <InlineMath math="\tan 135^\circ = -\tan 45^\circ = -1" /> |
| <InlineMath math="-150^\circ" /> | Ketiga | <InlineMath math="30^\circ" /> | <InlineMath math="\cos(-150^\circ) = -\cos 30^\circ = -\tfrac{\sqrt{3}}{2}" /> |

Fungsi salingan mengikut tanda fungsi asalnya. Contohnya <InlineMath math="\operatorname{kosek} 330^\circ = \dfrac{1}{\sin 330^\circ} = \dfrac{1}{-\tfrac{1}{2}} = -2" />. Sudut juga boleh ditulis dalam radian: <InlineMath math="225^\circ = \dfrac{225}{180}\pi = \dfrac{5\pi}{4}" /> radian.

Bagi graf nilai mutlak seperti <InlineMath math="y = |3\sin x|" />, **bahagian di bawah paksi-<InlineMath math="x" /> dipantulkan ke atas**, jadi kalanya menjadi <InlineMath math="180^\circ" />.

## Identiti Asas dan Rumus Sudut

Teorem Pythagoras pada bulatan unit memberi **identiti asas** <InlineMath math="\sin^2\theta + \cos^2\theta = 1" />. Bahagikan identiti ini dengan <InlineMath math="\cos^2\theta" /> atau <InlineMath math="\sin^2\theta" /> untuk mendapat dua identiti lagi:

<MathContainer>
<BlockMath math="1 + \tan^2\theta = \operatorname{sek}^2\theta" />
<BlockMath math="1 + \operatorname{kot}^2\theta = \operatorname{kosek}^2\theta" />
</MathContainer>

Contohnya, <InlineMath math="(1 - \cos^2 x)(1 + \operatorname{kot}^2 x) = \sin^2 x \cdot \operatorname{kosek}^2 x = 1" />.

**Rumus sudut majmuk** dan **rumus sudut berganda** ialah:

<MathContainer>
<BlockMath math="\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B" />
<BlockMath math="\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B" />
<BlockMath math="\sin 2A = 2\sin A\cos A, \qquad \cos 2A = \cos^2 A - \sin^2 A" />
</MathContainer>

Rumus sudut majmuk menunjukkan bahawa <InlineMath math="\sin x + \cos x = \sqrt{2}\sin(x + 45^\circ)" />, kerana <InlineMath math="\sqrt{2}\sin(x + 45^\circ) = \sqrt{2}\left(\sin x \cdot \tfrac{1}{\sqrt{2}} + \cos x \cdot \tfrac{1}{\sqrt{2}}\right)" />. Gerakkan <InlineMath math="x" /> dan semak bahawa dua graf sentiasa bertindih.

Persamaan kuadratik dalam <InlineMath math="\sin x" /> diselesaikan dengan pemfaktoran. Selesaikan <InlineMath math="2\sin^2 x - \sin x - 1 = 0" /> bagi <InlineMath math="0^\circ \le x \le 360^\circ" />:

<MathContainer>
<BlockMath math="(2\sin x + 1)(\sin x - 1) = 0" />
<BlockMath math="\sin x = 1 \quad \Rightarrow \quad x = 90^\circ" />
<BlockMath math="\sin x = -\tfrac{1}{2} \quad \Rightarrow \quad x = 210^\circ, \ 330^\circ" />
</MathContainer>

Sinus negatif dalam sukuan ketiga dan keempat, jadi sudut rujukan <InlineMath math="30^\circ" /> memberi <InlineMath math="180^\circ + 30^\circ" /> dan <InlineMath math="360^\circ - 30^\circ" />.

## Kesilapan Lazim dalam Fungsi Trigonometri

| Kesilapan | Sebab salah | Cara semak |
| :--- | :--- | :--- |
| Hanya memberi satu penyelesaian bagi <InlineMath math="\sin x = \tfrac{1}{2}" />. | Sinus positif dalam dua sukuan. | Lakar graf dan kira titik persilangan. |
| Menulis <InlineMath math="\sin 2A = 2\sin A" />. | Rumus sudut berganda ialah <InlineMath math="2\sin A\cos A" />. | Uji <InlineMath math="A = 90^\circ" />: <InlineMath math="\sin 180^\circ = 0" />, bukan <InlineMath math="2" />. |
| Menganggap kala <InlineMath math="y = \sin 2x" /> ialah <InlineMath math="720^\circ" />. | Pemalar <InlineMath math="b = 2" /> memendekkan kala kepada <InlineMath math="\tfrac{360^\circ}{2}" />. | Kira bilangan kitaran dalam <InlineMath math="360^\circ" />. |
| Memberi tanda positif bagi <InlineMath math="\cos 120^\circ" />. | Kosinus negatif dalam sukuan kedua. | Ingat susunan semua, sin, tan, kos. |
| Kalkulator dalam mod yang salah. | Darjah dan radian memberi nilai berbeza. | Semak <InlineMath math="\sin 90^\circ = 1" /> sebelum mula. |

Kesilapan pertama paling kerap berlaku. **Selepas mendapat sudut rujukan**, tentukan semua sukuan yang memberi tanda yang betul.

## Latihan Fungsi Trigonometri

Lakar bulatan unit atau graf bagi setiap soalan supaya **tanda dan bilangan penyelesaian jelas**.

1. Cari nilai tepat <InlineMath math="\cos 240^\circ" />, <InlineMath math="\tan 300^\circ" /> dan <InlineMath math="\operatorname{kosek} 150^\circ" />.

2. Nyatakan amplitud, kala, nilai maksimum dan nilai minimum bagi <InlineMath math="y = 2\cos 3x - 1" />.

3. Diberi <InlineMath math="\tan A = \tfrac{5}{12}" /> dengan <InlineMath math="A" /> dalam sukuan ketiga. Cari <InlineMath math="\sin A" />, <InlineMath math="\cos A" /> dan <InlineMath math="\sin 2A" />.

4. Selesaikan <InlineMath math="\cos 2x = \cos x" /> bagi <InlineMath math="0^\circ \le x \le 360^\circ" />.

### Penyelesaian

**Penyelesaian 1**: Gunakan sudut rujukan dan tanda sukuan:

<MathContainer>
<BlockMath math="\cos 240^\circ = -\cos 60^\circ = -\tfrac{1}{2}" />
<BlockMath math="\tan 300^\circ = -\tan 60^\circ = -\sqrt{3}" />
<BlockMath math="\operatorname{kosek} 150^\circ = \frac{1}{\sin 150^\circ} = \frac{1}{\tfrac{1}{2}} = 2" />
</MathContainer>

**Penyelesaian 2**: Bandingkan dengan <InlineMath math="y = a\cos bx + c" />, dengan <InlineMath math="a = 2" />, <InlineMath math="b = 3" /> dan <InlineMath math="c = -1" />. Amplitud ialah <InlineMath math="2" />, kala ialah <InlineMath math="\tfrac{360^\circ}{3} = 120^\circ" />, nilai maksimum <InlineMath math="2 - 1 = 1" /> dan nilai minimum <InlineMath math="-2 - 1 = -3" />.

**Penyelesaian 3**: Segi tiga rujukan bersisi <InlineMath math="5" />, <InlineMath math="12" /> dan <InlineMath math="13" />. Dalam sukuan ketiga, sinus dan kosinus negatif:

<MathContainer>
<BlockMath math="\sin A = -\tfrac{5}{13}, \qquad \cos A = -\tfrac{12}{13}" />
<BlockMath math="\sin 2A = 2\left(-\tfrac{5}{13}\right)\left(-\tfrac{12}{13}\right) = \tfrac{120}{169}" />
</MathContainer>

**Penyelesaian 4**: Tukar <InlineMath math="\cos 2x" /> kepada <InlineMath math="2\cos^2 x - 1" />:

<MathContainer>
<BlockMath math="2\cos^2 x - \cos x - 1 = 0 \quad \Rightarrow \quad (2\cos x + 1)(\cos x - 1) = 0" />
<BlockMath math="\cos x = 1 \quad \Rightarrow \quad x = 0^\circ, 360^\circ" />
<BlockMath math="\cos x = -\tfrac{1}{2} \quad \Rightarrow \quad x = 120^\circ, 240^\circ" />
</MathContainer>

Semak <InlineMath math="x = 120^\circ" />: <InlineMath math="\cos 240^\circ = -\tfrac{1}{2} = \cos 120^\circ" />.
