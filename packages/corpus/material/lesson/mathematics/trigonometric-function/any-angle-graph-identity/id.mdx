## Lingkaran Satuan Memberi Semua Nilai

Untuk sudut <InlineMath math="\theta" /> apa pun yang diukur dari sumbu-<InlineMath math="x" /> positif, titik pada **lingkaran satuan** adalah <InlineMath math="(\cos\theta, \sin\theta)" />. Dari dua nilai ini kamu mendapat keenam fungsi trigonometri:

<MathContainer>
<BlockMath math="\tan\theta = \frac{\sin\theta}{\cos\theta}, \qquad \sec\theta = \frac{1}{\cos\theta}" />
<BlockMath math="\operatorname{cosec}\theta = \frac{1}{\sin\theta}, \qquad \cot\theta = \frac{1}{\tan\theta}" />
</MathContainer>

Sudut positif diukur **berlawanan arah jarum jam** dan sudut negatif **searah jarum jam**. Tanda setiap fungsi bergantung pada kuadran, dan besarnya sama dengan nilai untuk **sudut acuan**, yaitu sudut lancip antara jari-jari dan sumbu-<InlineMath math="x" />.

Di catatan ini kamu memutar jari-jari lingkaran satuan, mengubah amplitudo dan periode grafik sinus, menyelesaikan persamaan dengan grafik, dan mengecek rumus sudut rangkap.

Tanda di setiap kuadran mengikuti urutan **semua, sin, tan, cos**: semua positif di kuadran pertama, hanya sin di kuadran kedua, hanya tan di kuadran ketiga, dan hanya cos di kuadran keempat.

| Sudut | Kuadran | Sudut acuan | Nilai |
| :--- | :--- | :--- | :--- |
| <InlineMath math="210^\circ" /> | Ketiga | <InlineMath math="30^\circ" /> | <InlineMath math="\sin 210^\circ = -\sin 30^\circ = -\tfrac{1}{2}" /> |
| <InlineMath math="300^\circ" /> | Keempat | <InlineMath math="60^\circ" /> | <InlineMath math="\cos 300^\circ = \cos 60^\circ = \tfrac{1}{2}" /> |
| <InlineMath math="135^\circ" /> | Kedua | <InlineMath math="45^\circ" /> | <InlineMath math="\tan 135^\circ = -\tan 45^\circ = -1" /> |
| <InlineMath math="-150^\circ" /> | Ketiga | <InlineMath math="30^\circ" /> | <InlineMath math="\cos(-150^\circ) = -\cos 30^\circ = -\tfrac{\sqrt{3}}{2}" /> |

Fungsi kebalikan mengikuti tanda fungsi asalnya. Misalnya <InlineMath math="\operatorname{cosec} 330^\circ = \dfrac{1}{\sin 330^\circ} = \dfrac{1}{-\tfrac{1}{2}} = -2" />. Sudut juga bisa ditulis dalam radian: <InlineMath math="225^\circ = \dfrac{225}{180}\pi = \dfrac{5\pi}{4}" /> radian.

## Identitas Dasar dan Rumus Sudut

Teorema Pythagoras pada lingkaran satuan memberi **identitas dasar** <InlineMath math="\sin^2\theta + \cos^2\theta = 1" />. Bagi identitas ini dengan <InlineMath math="\cos^2\theta" /> atau <InlineMath math="\sin^2\theta" /> untuk mendapat dua identitas lagi:

<MathContainer>
<BlockMath math="1 + \tan^2\theta = \sec^2\theta" />
<BlockMath math="1 + \cot^2\theta = \operatorname{cosec}^2\theta" />
</MathContainer>

Misalnya, <InlineMath math="(1 - \cos^2 x)(1 + \cot^2 x) = \sin^2 x \cdot \operatorname{cosec}^2 x = 1" />.

**Rumus jumlah dan selisih sudut** serta **rumus sudut ganda** adalah:

<MathContainer>
<BlockMath math="\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B" />
<BlockMath math="\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B" />
<BlockMath math="\sin 2A = 2\sin A\cos A, \qquad \cos 2A = \cos^2 A - \sin^2 A" />
</MathContainer>

Rumus jumlah sudut menunjukkan bahwa <InlineMath math="\sin x + \cos x = \sqrt{2}\sin(x + 45^\circ)" />, karena <InlineMath math="\sqrt{2}\sin(x + 45^\circ) = \sqrt{2}\left(\sin x \cdot \tfrac{1}{\sqrt{2}} + \cos x \cdot \tfrac{1}{\sqrt{2}}\right)" />. Geser <InlineMath math="x" /> dan cek bahwa kedua grafik selalu berimpit.

Persamaan kuadrat dalam <InlineMath math="\sin x" /> diselesaikan dengan pemfaktoran. Selesaikan <InlineMath math="2\sin^2 x - \sin x - 1 = 0" /> untuk <InlineMath math="0^\circ \le x \le 360^\circ" />:

<MathContainer>
<BlockMath math="(2\sin x + 1)(\sin x - 1) = 0" />
<BlockMath math="\sin x = 1 \quad \Rightarrow \quad x = 90^\circ" />
<BlockMath math="\sin x = -\tfrac{1}{2} \quad \Rightarrow \quad x = 210^\circ, \ 330^\circ" />
</MathContainer>

Sinus negatif di kuadran ketiga dan keempat, jadi sudut acuan <InlineMath math="30^\circ" /> memberi <InlineMath math="180^\circ + 30^\circ" /> dan <InlineMath math="360^\circ - 30^\circ" />.

## Kesalahan Umum dalam Fungsi Trigonometri

| Kesalahan | Mengapa salah | Cara mengecek |
| :--- | :--- | :--- |
| Hanya memberi satu penyelesaian untuk <InlineMath math="\sin x = \tfrac{1}{2}" />. | Sinus positif di dua kuadran. | Sketsa grafik dan hitung titik potongnya. |
| Menulis <InlineMath math="\sin 2A = 2\sin A" />. | Rumus sudut ganda adalah <InlineMath math="2\sin A\cos A" />. | Uji <InlineMath math="A = 90^\circ" />: <InlineMath math="\sin 180^\circ = 0" />, bukan <InlineMath math="2" />. |
| Menganggap periode <InlineMath math="y = \sin 2x" /> adalah <InlineMath math="720^\circ" />. | Konstanta <InlineMath math="b = 2" /> memendekkan periode menjadi <InlineMath math="\tfrac{360^\circ}{2}" />. | Hitung banyak siklus dalam <InlineMath math="360^\circ" />. |
| Memberi tanda positif untuk <InlineMath math="\cos 120^\circ" />. | Kosinus negatif di kuadran kedua. | Ingat urutan semua, sin, tan, cos. |
| Kalkulator dalam mode yang salah. | Derajat dan radian memberi nilai berbeda. | Cek <InlineMath math="\sin 90^\circ = 1" /> sebelum mulai. |

Kesalahan pertama paling sering terjadi. **Setelah mendapat sudut acuan**, tentukan semua kuadran yang memberi tanda yang benar.

## Latihan Fungsi Trigonometri

Sketsa lingkaran satuan atau grafik untuk setiap soal supaya **tanda dan banyak penyelesaiannya jelas**.

1. Cari nilai eksak <InlineMath math="\cos 240^\circ" />, <InlineMath math="\tan 300^\circ" />, dan <InlineMath math="\operatorname{cosec} 150^\circ" />.

2. Tentukan amplitudo, periode, nilai maksimum, dan nilai minimum <InlineMath math="y = 2\cos 3x - 1" />.

3. Diketahui <InlineMath math="\tan A = \tfrac{5}{12}" /> dengan <InlineMath math="A" /> di kuadran ketiga. Cari <InlineMath math="\sin A" />, <InlineMath math="\cos A" />, dan <InlineMath math="\sin 2A" />.

4. Selesaikan <InlineMath math="\cos 2x = \cos x" /> untuk <InlineMath math="0^\circ \le x \le 360^\circ" />.

### Pembahasan

**Pembahasan 1**: Pakai sudut acuan dan tanda kuadran:

<MathContainer>
<BlockMath math="\cos 240^\circ = -\cos 60^\circ = -\tfrac{1}{2}" />
<BlockMath math="\tan 300^\circ = -\tan 60^\circ = -\sqrt{3}" />
<BlockMath math="\operatorname{cosec} 150^\circ = \frac{1}{\sin 150^\circ} = \frac{1}{\tfrac{1}{2}} = 2" />
</MathContainer>

**Pembahasan 2**: Bandingkan dengan <InlineMath math="y = a\cos bx + c" />, dengan <InlineMath math="a = 2" />, <InlineMath math="b = 3" />, dan <InlineMath math="c = -1" />. Amplitudonya <InlineMath math="2" />, periodenya <InlineMath math="\tfrac{360^\circ}{3} = 120^\circ" />, nilai maksimumnya <InlineMath math="2 - 1 = 1" />, dan nilai minimumnya <InlineMath math="-2 - 1 = -3" />.

**Pembahasan 3**: Segitiga acuannya bersisi <InlineMath math="5" />, <InlineMath math="12" />, dan <InlineMath math="13" />. Di kuadran ketiga, sinus dan kosinus **sama-sama negatif**:

<MathContainer>
<BlockMath math="\sin A = -\tfrac{5}{13}, \qquad \cos A = -\tfrac{12}{13}" />
<BlockMath math="\sin 2A = 2\left(-\tfrac{5}{13}\right)\left(-\tfrac{12}{13}\right) = \tfrac{120}{169}" />
</MathContainer>

**Pembahasan 4**: Ubah <InlineMath math="\cos 2x" /> menjadi <InlineMath math="2\cos^2 x - 1" />:

<MathContainer>
<BlockMath math="2\cos^2 x - \cos x - 1 = 0 \quad \Rightarrow \quad (2\cos x + 1)(\cos x - 1) = 0" />
<BlockMath math="\cos x = 1 \quad \Rightarrow \quad x = 0^\circ, 360^\circ" />
<BlockMath math="\cos x = -\tfrac{1}{2} \quad \Rightarrow \quad x = 120^\circ, 240^\circ" />
</MathContainer>

Cek <InlineMath math="x = 120^\circ" />: <InlineMath math="\cos 240^\circ = -\tfrac{1}{2} = \cos 120^\circ" />.
