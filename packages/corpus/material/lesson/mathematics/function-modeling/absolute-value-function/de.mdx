## Der Abstand einer Zahl von null

Die Absolutwert-Grundfunktion ordnet jeder reellen Zahl <Highlight>ihren Abstand von null auf der Zahlengeraden</Highlight> zu. Da ein Abstand nie negativ ist, liefert <InlineMath math="f(x)=|x|" /> stets einen nichtnegativen Wert. Transformationen können den Grundgraphen verschieben oder spiegeln, sodass die Ausgaben einer transformierten Absolutwertfunktion nicht immer nichtnegativ sein müssen.

### Definition der Betragsfunktion

Für jede reelle Zahl <InlineMath math="x" /> ist die Absolutwertfunktion wie folgt definiert:

<BlockMath math="f(x) = |x| = \begin{cases} x, &amp; \text{wenn } x \geq 0 \\ -x, &amp; \text{wenn } x &lt; 0 \end{cases}" />

**Komponenten von Absolutwertfunktionen**:

- Das Symbol <InlineMath math="|x|" /> liest man als Absolutwert von <InlineMath math="x" />.
- Der Funktionswert ist immer nichtnegativ: <InlineMath math="|x| \geq 0" />.
- Die Funktion ist gerade: <InlineMath math="|-x| = |x|" />.

Die Definition unterscheidet Eingaben nach ihrem **Vorzeichen**. Bei einer negativen Eingabe liefert das vorangestellte Minus einen positiven Abstand.

<BlockMath math="|-3|=-(-3)=3,\qquad|3|=3" />

## Eigenschaften von Absolutwertfunktionen

Aus der Deutung als Abstand folgen diese grundlegenden Eigenschaften:

**Grundlegende Eigenschaften**:

<MathContainer>

<BlockMath math="|x| \geq 0 \text{ für alle } x \in \mathbb{R}" />

<BlockMath math="|-x| = |x|" />

<BlockMath math="|x|^2 = x^2" />

<BlockMath math="|xy| = |x| \cdot |y|" />

<BlockMath math="\left|\frac{x}{y}\right| = \frac{|x|}{|y|}, \text{mit } y \neq 0" />
</MathContainer>

**Eigenschaften der Dreiecksungleichung**:

<MathContainer>

<BlockMath math="|x + y| \leq |x| + |y|" />

<BlockMath math="||x| - |y|| \leq |x - y|" />
</MathContainer>

Bei der **Dreiecksungleichung** ist der Abstand einer Summe höchstens so groß wie die Summe der beiden Abstände. Betrachte zwei Zahlen mit unterschiedlichen Vorzeichen.

<MathContainer>

<BlockMath math="|3+(-5)|=2\leq3+5=|3|+|-5|" />

<BlockMath math="\bigl||3|-|-5|\bigr|=2\leq8=|3-(-5)|" />
</MathContainer>

## Transformationen von Absolutwertfunktionen

Eine **Verschiebung versetzt den Scheitelpunkt**, ohne die Öffnungsrichtung zu ändern. Eine Streckung verändert die Steigungen der beiden Arme des V. Die Spiegelung an der waagerechten Achse öffnet den Graphen nach unten. Diese Operationen lassen sich auf die Grundfunktion <InlineMath math="f(x)=|x|" /> anwenden und kombinieren.

### Streckung und Stauchung

Die Funktion <InlineMath math="f(x) = a|x|" /> **verändert je nach Faktor die Steilheit** und gegebenenfalls die Orientierung des Graphen:

- Für <InlineMath math="|a| > 1" /> wird der Graph steiler.
- Für <InlineMath math="0 < |a| < 1" /> wird der Graph flacher.
- Für <InlineMath math="a < 0" /> wird der Graph zusätzlich an der <InlineMath math="x" />-Achse gespiegelt.

## Allgemeine Form von Absolutwertfunktionen

Die allgemeine Form einer Absolutwertfunktion ist:

<BlockMath math="f(x) = a|x - h| + k" />

Die Parameter in dieser Form bedeuten:

- <InlineMath math="a" /> steuert Streckung, Stauchung und Spiegelung.
- <InlineMath math="h" /> bestimmt die horizontale Verschiebung.
- <InlineMath math="k" /> bestimmt die vertikale Verschiebung.
- Der Scheitelpunkt liegt bei <InlineMath math="(h, k)" />

**Transformationstabelle**:

| Parameter | Wert | Auswirkung auf den Graphen |
| ---------------- | ------------ | --------------------- |
| <InlineMath math="\lvert a \rvert > 1" /> | Betrag <InlineMath math="> 1" /> | Graph wird steiler |
| <InlineMath math="0 < \lvert a \rvert < 1" /> | Betrag <InlineMath math="< 1" /> | Graph wird flacher |
| <InlineMath math="a < 0" /> | Negativ | Graph wird zusätzlich an der <InlineMath math="x" />-Achse gespiegelt |
| <InlineMath math="h > 0" /> | Positiv | Nach rechts verschieben |
| <InlineMath math="h < 0" /> | Negativ | Nach links verschieben |
| <InlineMath math="k > 0" /> | Positiv | Nach oben verschieben |
| <InlineMath math="k < 0" /> | Negativ | Nach unten verschieben |

Für einen V-förmigen Graphen gilt <InlineMath math="a\neq0" />. Bei Faktor null entsteht eine **waagerechte Gerade** ohne einen eindeutigen Scheitelpunkt.

## Absolutwertgleichungen und Ungleichungen

**Absolutwertgleichungen lösen**:

So löst du <InlineMath math="|x| = a" /> mit <InlineMath math="a \geq 0" />:

<MathContainer>

<BlockMath math="|x| = a \Rightarrow x = a \text{ oder } x = -a" />
</MathContainer>

**Beispiel**: Löse <InlineMath math="|x - 3| = 5" />

<MathContainer>

<BlockMath math="|x - 3| = 5" />

<BlockMath math="x - 3 = 5 \text{ oder } x - 3 = -5" />

<BlockMath math="x = 8 \text{ oder } x = -2" />
</MathContainer>

**Absolutwertungleichungen lösen**:

Für <InlineMath math="|x| < a" /> mit <InlineMath math="a > 0" />:

<BlockMath math="|x| < a \Rightarrow -a < x < a" />

Für <InlineMath math="|x| > a" /> mit <InlineMath math="a > 0" />:

<BlockMath math="|x| &gt; a \Rightarrow x &lt; -a \text{ oder } x &gt; a" />

## Übungen

Nutze je nach Aufgabe **Funktionswerte, zwei mögliche Vorzeichen oder verschobene Scheitelpunkte**. In der Abstandsaufgabe werden beide Städte auf einer Geraden modelliert.

1. Bestimme den Wert von <InlineMath math="f(x) = |2x - 6|" /> für <InlineMath math="x = -1, 0, 3, 5" />

2. Löse die Gleichung <InlineMath math="|3x + 1| = 7" />

3. Löse die Ungleichung <InlineMath math="|x - 2| < 4" />

4. Bestimme den Scheitelpunkt der Funktion <InlineMath math="f(x) = 2|x - 3| + 1" />

5. Die Entfernung zwischen zwei Städten beträgt <InlineMath math="150 \text{ km}" />. Wenn sich die Stadt <InlineMath math="A" /> an der Koordinate <InlineMath math="-50 \text{ km}" /> befindet, wo befindet sich dann die Stadt <InlineMath math="B" />?

### Lösungen

**Aufgabe 1**. Ersetze **jeden Wert** von <InlineMath math="x" /> in der Funktion <InlineMath math="f(x) = |2x - 6|" />:

<MathContainer>

<BlockMath math="\begin{aligned} f(-1) &amp;= |2(-1) - 6| \\ &amp;= |-2 - 6| \\ &amp;= |-8| \\ &amp;= 8 \end{aligned}" />

<BlockMath math="\begin{aligned} f(0) &amp;= |2(0) - 6| \\ &amp;= |0 - 6| \\ &amp;= |-6| \\ &amp;= 6 \end{aligned}" />

<BlockMath math="\begin{aligned} f(3) &amp;= |2(3) - 6| \\ &amp;= |6 - 6| \\ &amp;= |0| \\ &amp;= 0 \end{aligned}" />

<BlockMath math="\begin{aligned} f(5) &amp;= |2(5) - 6| \\ &amp;= |10 - 6| \\ &amp;= |4| \\ &amp;= 4 \end{aligned}" />
</MathContainer>

**Aufgabe 2**. Für die Gleichung <InlineMath math="|3x + 1| = 7" /> verwenden wir die Definition des Absolutwerts, die **zwei Möglichkeiten** ergibt:

<MathContainer>

<BlockMath math="3x + 1 = 7 \quad \text{oder} \quad 3x + 1 = -7" />

<BlockMath math="3x = 6 \quad \text{oder} \quad 3x = -8" />

<BlockMath math="x = 2 \quad \text{oder} \quad x = -\frac{8}{3}" />
</MathContainer>

**Aufgabe 3**. Für <InlineMath math="|x - 2| < 4" /> verwenden wir die Eigenschaft, dass <InlineMath math="|a| < b" /> äquivalent zu <InlineMath math="-b < a < b" /> ist:

<MathContainer>

<BlockMath math="-4 < x - 2 < 4" />

<BlockMath math="-4 + 2 < x < 4 + 2" />

<BlockMath math="-2 < x < 6" />
</MathContainer>

Die **Lösungsmenge** ist also <InlineMath math="x \in (-2, 6)" />.

**Aufgabe 4**. Anhand der Funktion <InlineMath math="f(x) = 2|x - 3| + 1" /> können wir **die Parameter identifizieren**:

- <InlineMath math="a = 2" /> (Streckfaktor)
- <InlineMath math="h = 3" /> (horizontale Verschiebung)
- <InlineMath math="k = 1" /> (vertikale Verschiebung)

Der Scheitelpunkt liegt bei <InlineMath math="(h, k) = (3, 1)" />.

Ein Betrag erreicht seinen kleinsten Wert, wenn der Ausdruck innerhalb der Betragsstriche null ist. Bestimme diese Eingabe und berechne den Funktionswert, um beide Koordinaten des Scheitelpunkts zu erhalten.

<BlockMath math="x-3=0 \Rightarrow x=3,\qquad f(3)=2|3-3|+1=1" />

**Aufgabe 5**. Der **Abstand zwischen den Städten** <InlineMath math="A" /> und <InlineMath math="B" /> beträgt <InlineMath math="150 \text{ km}" />. Stadt <InlineMath math="A" /> liegt bei <InlineMath math="-50 \text{ km}" />. Die Koordinate von Stadt <InlineMath math="B" /> nennen wir <InlineMath math="x_B" />:

<MathContainer>

<BlockMath math="|-50 - x_B| = 150" />

<BlockMath math="\begin{aligned} &amp;-50 - x_B = 150 \\ &amp;\text{oder} \\ &amp;-50 - x_B = -150 \end{aligned}" />

<BlockMath math="\begin{aligned} &amp;x_B = -50 - 150 = -200 \\ &amp;\text{oder} \\ &amp;x_B = -50 + 150 = 100 \end{aligned}" />
</MathContainer>

Die Stadt <InlineMath math="B" /> kann also an der Koordinate <InlineMath math="100 \text{ km}" /> oder <InlineMath math="-200 \text{ km}" /> liegen.
