## Pengertian Fungsi Akar

Fungsi akar menerapkan akar kuadrat utama pada suatu ekspresi. Bentuknya <InlineMath math="f(x) = \sqrt{g(x)}" />, dengan <InlineMath math="g(x)" /> sebagai radikan, yaitu ekspresi di bawah tanda akar.

Fungsi induknya adalah <InlineMath math="f(x) = \sqrt{x}" />. Fungsi ini memasangkan setiap input non-negatif dengan akar kuadrat utamanya yang juga non-negatif.

### Karakteristik Fungsi Akar

Tiga ciri berikut menjadi panduan untuk bagian selanjutnya:

1. **Domain terbatas**: Karena akar kuadrat dari bilangan negatif tidak terdefinisi dalam bilangan real, domain fungsi akar terbatas pada nilai-nilai yang membuat ekspresi di dalam akar bernilai non-negatif.

2. **Grafik induk yang khas**: Grafik <InlineMath math="y=\sqrt{x}" /> dimulai dari <InlineMath math="(0,0)" /> dan naik semakin lambat saat <InlineMath math="x" /> membesar. Transformasi dapat menggeser, meregangkan, atau mencerminkan bentuk ini.

3. **Akar utama non-negatif**: Nilai <InlineMath math="\sqrt{g(x)}" /> selalu non-negatif. Namun, pengali atau translasi di luar akar tetap dapat membuat nilai fungsi hasil transformasi menjadi negatif.

## Domain dan Range Fungsi Akar

Untuk memahami fungsi akar dengan baik, penting untuk menentukan domain dan range-nya.

### Menentukan Domain

Domain fungsi akar <InlineMath math="f(x) = \sqrt{g(x)}" /> adalah semua nilai <InlineMath math="x" /> yang membuat <InlineMath math="g(x) \geq 0" />.

**Langkah-langkah menentukan domain:**

| Langkah | Penjelasan                                            | Contoh: <InlineMath math="f(x) = \sqrt{x-2}" />                   |
| ------- | ----------------------------------------------------- | ----------------------------------------------------------------- |
| <InlineMath math="1" /> | Identifikasi ekspresi dalam akar                      | <InlineMath math="g(x) = x-2" />                                  |
| <InlineMath math="2" /> | Buat pertidaksamaan <InlineMath math="g(x) \geq 0" /> | <InlineMath math="x-2 \geq 0" />                                  |
| <InlineMath math="3" /> | Selesaikan pertidaksamaan                             | <InlineMath math="x \geq 2" />                                    |
| <InlineMath math="4" /> | Tuliskan domain                                       | <InlineMath math="D_f = \{x \mid x \geq 2, x \in \mathbb{R}\}" /> |

### Menentukan Range

Range fungsi akar adalah semua nilai output yang mungkin dihasilkan oleh fungsi tersebut.

Pada <InlineMath math="f(x) = \sqrt{x-2}" />, radikannya dapat menghasilkan semua nilai mulai dari nol. Karena itu, akar kuadrat utamanya memiliki range

<BlockMath math="R_f = \{y \mid y \geq 0, y \in \mathbb{R}\}" />

### Translasi Vertikal

Fungsi <InlineMath math="f(x) = \sqrt{x} + k" /> menggeser grafik fungsi akar dasar sejauh <InlineMath math="k \text{ satuan}" /> ke atas (jika <InlineMath math="k > 0" />) atau ke bawah (jika <InlineMath math="k < 0" />).

| Fungsi                                    | Transformasi            | Domain                         | Range                           |
| ----------------------------------------- | ----------------------- | ------------------------------ | ------------------------------- |
| <InlineMath math="f(x) = \sqrt{x}" />     | Fungsi dasar            | <InlineMath math="x \geq 0" /> | <InlineMath math="y \geq 0" />  |
| <InlineMath math="f(x) = \sqrt{x} + 2" /> | Geser <InlineMath math="2 \text{ satuan}" /> ke atas  | <InlineMath math="x \geq 0" /> | <InlineMath math="y \geq 2" />  |
| <InlineMath math="f(x) = \sqrt{x} - 3" /> | Geser <InlineMath math="3 \text{ satuan}" /> ke bawah | <InlineMath math="x \geq 0" /> | <InlineMath math="y \geq -3" /> |

## Fungsi Akar Bentuk Umum

Untuk kasus nondegenerat <InlineMath math="a\neq 0" /> dan <InlineMath math="b\neq 0" />, fungsi akar yang ditransformasi berbentuk:

<BlockMath math="f(x) = a\sqrt{b(x-h)} + k" />

Pada bentuk ini:

- <InlineMath math="a" /> menentukan skala vertikal dan, jika <InlineMath math="a<0" />, pencerminan terhadap sumbu <InlineMath math="x" />
- <InlineMath math="b" /> menentukan skala horizontal dan, jika <InlineMath math="b<0" />, pencerminan horizontal
- <InlineMath math="h" /> menentukan translasi horizontal
- <InlineMath math="k" /> menentukan translasi vertikal

Domain real ditentukan oleh <InlineMath math="b(x-h)\geq 0" />. Tanda <InlineMath math="a" /> kemudian menentukan apakah range memanjang ke atas atau ke bawah dari <InlineMath math="y=k" />.

**Langkah-langkah menggambar grafik:**

| Langkah | Tindakan            | Contoh: <InlineMath math="f(x) = 2\sqrt{x-1} + 3" />                                           |
| ------- | ------------------- | ---------------------------------------------------------------------------------------------- |
| <InlineMath math="1" /> | Tentukan titik awal | <InlineMath math="x-1 = 0 \Rightarrow x = 1" />, <InlineMath math="f(1) = 3" />, Titik: <InlineMath math="(1, 3)" /> |
| <InlineMath math="2" /> | Tentukan domain     | <InlineMath math="x-1 \geq 0 \Rightarrow x \geq 1" />                                          |
| <InlineMath math="3" /> | Buat tabel nilai    | Pilih beberapa nilai <InlineMath math="x \geq 1" />                                            |
| <InlineMath math="4" /> | Hitung nilai fungsi | Untuk <InlineMath math="x = 2" />: <InlineMath math="f(2) = 2\sqrt{1} + 3 = 5" />              |
| <InlineMath math="5" /> | Plot titik-titik    | Plot <InlineMath math="(1,3)" />, <InlineMath math="(2,5)" />, <InlineMath math="(5,7)" />, dst. |
| <InlineMath math="6" /> | Hubungkan titik     | Buat kurva mulus melalui titik-titik                                                           |

## Persamaan Fungsi Akar

Untuk menyelesaikan persamaan yang memuat akar kuadrat, pisahkan bentuk akarnya, kuadratkan kedua ruas, selesaikan persamaan hasilnya, lalu periksa setiap kandidat pada persamaan semula. Penguadratan tidak selalu dapat dibalik untuk sembarang ekspresi real, sehingga dapat menghasilkan solusi semu.

| Langkah | Penjelasan            | Contoh: <InlineMath math="\sqrt{2x+3} = 5" />          |
| ------- | --------------------- | ------------------------------------------------------ |
| <InlineMath math="1" /> | Isolasi akar          | Sudah terisolasi                                       |
| <InlineMath math="2" /> | Kuadratkan kedua ruas | <InlineMath math="(\sqrt{2x+3})^2 = 5^2" />            |
| <InlineMath math="3" /> | Sederhanakan          | <InlineMath math="2x+3 = 25" />                        |
| <InlineMath math="4" /> | Selesaikan            | <InlineMath math="2x = 22 \Rightarrow x = 11" />       |
| <InlineMath math="5" /> | Verifikasi            | <InlineMath math="\sqrt{2(11)+3} = \sqrt{25} = 5" /> ✓ |

## Pertidaksamaan Fungsi Akar

Untuk menyelesaikan pertidaksamaan akar, tentukan domain lebih dahulu. Sebelum menguadratkan, periksa juga tanda ruas lainnya agar pertidaksamaan yang diperoleh tetap ekuivalen.

**Contoh:** Selesaikan <InlineMath math="\sqrt{x-1} < 3" />

<MathContainer>
  <BlockMath math="\text{Syarat: } x-1 \geq 0 \Rightarrow x \geq 1" />
  <BlockMath math="\sqrt{x-1} < 3" />
  <BlockMath math="x-1 < 9" />
  <BlockMath math="x < 10" />
</MathContainer>

Karena kedua ruas non-negatif pada domain, penguadratan mempertahankan pertidaksamaan. Gabungan <InlineMath math="x\geq 1" /> dan <InlineMath math="x<10" /> menghasilkan <InlineMath math="1 \leq x < 10" />.

## Latihan Soal

1. Tentukan domain dan range dari fungsi <InlineMath math="f(x) = \sqrt{3x-6}" />

2. Gambarkan grafik fungsi <InlineMath math="g(x) = -\sqrt{x+4} + 2" />

3. Selesaikan persamaan <InlineMath math="\sqrt{x+5} + \sqrt{x} = 5" />

4. Sebuah roket diluncurkan vertikal. Ketinggiannya setelah <InlineMath math="t \text{ detik}" /> diberikan oleh <InlineMath math="h(t) = 100\sqrt{t} \text{ meter}" />. Berapa ketinggian roket setelah <InlineMath math="9 \text{ detik}" />?

5. Tentukan nilai <InlineMath math="x" /> yang memenuhi <InlineMath math="2\sqrt{x-3} \geq 6" />

### Pembahasan

1. Radikan harus non-negatif:

   <MathContainer>
     <BlockMath math="3x-6\geq 0" />
     <BlockMath math="x\geq 2." />
   </MathContainer>

   Jadi, <InlineMath math="D_f=\{x\in\mathbb{R}\mid x\geq 2\}" />. Saat <InlineMath math="x" /> menjelajahi domain tersebut, <InlineMath math="3x-6" /> menghasilkan setiap nilai non-negatif. Karena itu, <InlineMath math="R_f=\{y\in\mathbb{R}\mid y\geq 0\}" />.

2. **Menggambar grafik** <InlineMath math="g(x) = -\sqrt{x+4} + 2" />

   **Langkah-langkah menggambar:**

   | ------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | <InlineMath math="1" /> | Identifikasi transformasi | <InlineMath math="a = -1" /> (refleksi terhadap sumbu <InlineMath math="x" />), <InlineMath math="h = -4" /> (geser <InlineMath math="4 \text{ satuan}" /> ke kiri), <InlineMath math="k = 2" /> (geser <InlineMath math="2 \text{ satuan}" /> ke atas) |
| <InlineMath math="2" /> | Tentukan titik awal       | <InlineMath math="x+4 = 0 \Rightarrow x = -4" />, <InlineMath math="g(-4) = 0 + 2 = 2" />, Titik awal: <InlineMath math="(-4, 2)" /> |
   | <InlineMath math="3" /> | Tentukan domain           | <InlineMath math="x+4 \geq 0 \Rightarrow x \geq -4" />                                                                                                                |
   | <InlineMath math="4" /> | Tentukan range            | Karena <InlineMath math="a = -1 < 0" />, grafik turun dari titik awal, sehingga <InlineMath math="y \leq 2" />                                                        |

3. Domain mensyaratkan <InlineMath math="x\geq 0" />. Pisahkan salah satu bentuk akar:

   <MathContainer>
     <BlockMath math="\sqrt{x+5}=5-\sqrt{x}" />
     <BlockMath math="x+5=25-10\sqrt{x}+x" />
     <BlockMath math="10\sqrt{x}=20" />
     <BlockMath math="\sqrt{x}=2" />
     <BlockMath math="x=4." />
   </MathContainer>

   Periksa pada persamaan semula: <InlineMath math="\sqrt{4+5}+\sqrt{4}=3+2=5" />. Jadi, <InlineMath math="x=4" /> merupakan solusi yang sah.

4. Substitusikan <InlineMath math="t=9" /> ke dalam model:

   <BlockMath math="h(9)=100\sqrt{9}=100\cdot 3=300\text{ m}." />

   Model memakai <InlineMath math="t\geq 0" />, dan <InlineMath math="9" /> berada dalam domain tersebut. Ketinggian menurut model adalah <InlineMath math="300\text{ m}" />.

5. Catat dahulu domain <InlineMath math="x-3\geq 0" />, sehingga <InlineMath math="x\geq 3" />. Bagi dengan bilangan positif <InlineMath math="2" />, lalu kuadratkan kedua ruas yang non-negatif:

   <MathContainer>
     <BlockMath math="2\sqrt{x-3}\geq 6" />
     <BlockMath math="\sqrt{x-3}\geq 3" />
     <BlockMath math="x-3\geq 9" />
     <BlockMath math="x\geq 12." />
   </MathContainer>

   Irisan hasil ini dengan domain tetap memberikan <InlineMath math="x\geq 12" />.
