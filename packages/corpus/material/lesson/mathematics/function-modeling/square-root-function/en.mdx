## Definition of Square Root Function

A square root function applies the principal square root to an expression. It has the form <InlineMath math="f(x) = \sqrt{g(x)}" />, where <InlineMath math="g(x)" /> is the radicand, the expression under the radical sign.

The parent function is <InlineMath math="f(x) = \sqrt{x}" />. It assigns each non-negative input its non-negative square root.

### Characteristics of Square Root Functions

Three features guide the rest of this lesson:

1. **Limited domain**: Since the square root of negative numbers is not defined in real numbers, the domain of square root functions is limited to values that make the expression inside the square root non-negative.

2. **Recognizable parent graph**: The graph of <InlineMath math="y=\sqrt{x}" /> begins at <InlineMath math="(0,0)" /> and rises more slowly as <InlineMath math="x" /> increases. Transformations can shift, stretch, or reflect this shape.

3. **Non-negative principal root**: The value of <InlineMath math="\sqrt{g(x)}" /> itself is always non-negative. An outside multiplier or translation can still make a transformed function negative.

## Domain and Range of Square Root Functions

To understand square root functions well, it's important to determine their domain and range.

### Determining Domain

The domain of a square root function <InlineMath math="f(x) = \sqrt{g(x)}" /> is all values of <InlineMath math="x" /> that make <InlineMath math="g(x) \geq 0" />.

**Steps to determine domain:**

| Step | Explanation                                             | Example: <InlineMath math="f(x) = \sqrt{x-2}" />                  |
| ---- | ------------------------------------------------------- | ----------------------------------------------------------------- |
| <InlineMath math="1" /> | Identify the expression inside the square root          | <InlineMath math="g(x) = x-2" />                                  |
| <InlineMath math="2" /> | Create the inequality <InlineMath math="g(x) \geq 0" /> | <InlineMath math="x-2 \geq 0" />                                  |
| <InlineMath math="3" /> | Solve the inequality                                    | <InlineMath math="x \geq 2" />                                    |
| <InlineMath math="4" /> | Write the domain                                        | <InlineMath math="D_f = \{x \mid x \geq 2, x \in \mathbb{R}\}" /> |

### Determining Range

The range of a square root function is all possible output values that the function can produce.

For <InlineMath math="f(x) = \sqrt{x-2}" />, the radicand can produce every value from zero upward. Its principal square root therefore has range

<BlockMath math="R_f = \{y \mid y \geq 0, y \in \mathbb{R}\}" />

## General Form of Square Root Functions

For the nondegenerate case <InlineMath math="a\neq 0" /> and <InlineMath math="b\neq 0" />, the transformed square root function has the form:

<BlockMath math="f(x) = a\sqrt{b(x-h)} + k" />

Here:

- <InlineMath math="a" /> determines vertical scaling and, when <InlineMath math="a<0" />, reflection across the <InlineMath math="x" />-axis
- <InlineMath math="b" /> determines horizontal scaling and, when <InlineMath math="b<0" />, horizontal reflection
- <InlineMath math="h" /> determines horizontal translation
- <InlineMath math="k" /> determines vertical translation

The real domain is determined by <InlineMath math="b(x-h)\geq 0" />. The sign of <InlineMath math="a" /> then determines whether the range extends upward or downward from <InlineMath math="y=k" />.

**Steps to draw the graph:**

| Step | Action                    | Example: <InlineMath math="f(x) = 2\sqrt{x-1} + 3" />                                          |
| ---- | ------------------------- | ---------------------------------------------------------------------------------------------- |
| <InlineMath math="1" /> | Determine starting point  | <InlineMath math="x-1 = 0 \Rightarrow x = 1" />, <InlineMath math="f(1) = 3" />, Point: <InlineMath math="(1, 3)" /> |
| <InlineMath math="2" /> | Determine domain          | <InlineMath math="x-1 \geq 0 \Rightarrow x \geq 1" />                                          |
| <InlineMath math="3" /> | Create value table        | Choose several values <InlineMath math="x \geq 1" />                                           |
| <InlineMath math="4" /> | Calculate function values | For <InlineMath math="x = 2" />: <InlineMath math="f(2) = 2\sqrt{1} + 3 = 5" />                |
| <InlineMath math="5" /> | Plot points               | Plot <InlineMath math="(1,3)" />, <InlineMath math="(2,5)" />, <InlineMath math="(5,7)" />, etc. |
| <InlineMath math="6" /> | Connect points            | Create a smooth curve through the points                                                       |

## Square Root Function Equations

To solve an equation containing a square root, isolate the radical, square both sides, solve, and check every candidate in the original equation. Squaring is not reversible for arbitrary real expressions, so it can introduce an extraneous solution.

| Step | Explanation             | Example: <InlineMath math="\sqrt{2x+3} = 5" />         |
| ---- | ----------------------- | ------------------------------------------------------ |
| <InlineMath math="1" /> | Isolate the square root | Already isolated                                       |
| <InlineMath math="2" /> | Square both sides       | <InlineMath math="(\sqrt{2x+3})^2 = 5^2" />            |
| <InlineMath math="3" /> | Simplify                | <InlineMath math="2x+3 = 25" />                        |
| <InlineMath math="4" /> | Solve                   | <InlineMath math="2x = 22 \Rightarrow x = 11" />       |
| <InlineMath math="5" /> | Verify                  | <InlineMath math="\sqrt{2(11)+3} = \sqrt{25} = 5" /> ✓ |

## Square Root Function Inequalities

For a square root inequality, first enforce the domain. Before squaring, also check the sign of the other side so the comparison remains equivalent.

**Example:** Solve <InlineMath math="\sqrt{x-1} < 3" />

<MathContainer>
  <BlockMath math="\text{Condition: } x-1 \geq 0 \Rightarrow x \geq 1" />
  <BlockMath math="\sqrt{x-1} < 3" />
  <BlockMath math="x-1 < 9" />
  <BlockMath math="x < 10" />
</MathContainer>

Because both sides are non-negative on the domain, squaring preserves the inequality. Combining <InlineMath math="x\geq 1" /> with <InlineMath math="x<10" /> gives <InlineMath math="1 \leq x < 10" />.

3. The domain requires <InlineMath math="x\geq 0" />. Isolate one radical:

   <MathContainer>
