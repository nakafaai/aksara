## Definition der Quadratwurzelfunktion

Eine Quadratwurzelfunktion wendet die Hauptquadratwurzel auf einen Ausdruck an. Es hat die Form <InlineMath math="f(x) = \sqrt{g(x)}" />, wobei <InlineMath math="g(x)" /> der Radikand ist, der Ausdruck unter dem Radikalzeichen.

Die Grundfunktion ist <InlineMath math="f(x) = \sqrt{x}" />. Sie ordnet jeder nicht negativen Eingabe ihre nicht negative Quadratwurzel zu.

### Eigenschaften von Quadratwurzelfunktionen

Drei Merkmale bilden die Grundlage für den Rest dieser Lektion:

1. **Eingeschränkter Definitionsbereich**: Im Bereich der reellen Zahlen ist die Quadratwurzel negativer Zahlen nicht definiert. Zulässig sind deshalb nur Eingaben, für die der Ausdruck unter der Wurzel nicht negativ ist.

2. **Erkennbarer Grundgraph**: Der Graph von <InlineMath math="y=\sqrt{x}" /> beginnt bei <InlineMath math="(0,0)" /> und steigt mit zunehmendem <InlineMath math="x" /> immer langsamer. Transformationen können diese Form verschieben, strecken oder spiegeln.

3. **Nichtnegative Hauptwurzel**: Der Wert von <InlineMath math="\sqrt{g(x)}" /> selbst ist immer nicht negativ. Ein vorgelagerter Faktor oder eine Verschiebung kann eine transformierte Funktion dennoch negativ machen.

## Definitions- und Wertebereich von Quadratwurzelfunktionen

Der Definitionsbereich beschreibt die zulässigen Eingaben. Der Wertebereich enthält die Ausgaben, die die Funktion tatsächlich annehmen kann.

### Definitionsbereich bestimmen

Der Definitionsbereich einer Quadratwurzelfunktion <InlineMath math="f(x) = \sqrt{g(x)}" /> umfasst alle Werte von <InlineMath math="x" />, die <InlineMath math="g(x) \geq 0" /> ergeben.

**Schritte zum Ermitteln des Definitionsbereichs:**

| Schritt | Erklärung | Beispiel: <InlineMath math="f(x) = \sqrt{x-2}" /> |
| ---- | ------------------------------------------------------- | ----------------------------------------------------------------- |
| <InlineMath math="1" /> | Identifizieren Sie den Ausdruck innerhalb der Quadratwurzel | <InlineMath math="g(x) = x-2" /> |
| <InlineMath math="2" /> | Erstellen Sie die Ungleichung <InlineMath math="g(x) \geq 0" /> | <InlineMath math="x-2 \geq 0" /> |
| <InlineMath math="3" /> | Lösen Sie die Ungleichung | <InlineMath math="x \geq 2" /> |
| <InlineMath math="4" /> | Definitionsbereich angeben | <InlineMath math="D_f = \{x \mid x \geq 2, x \in \mathbb{R}\}" /> |

### Wertebereich bestimmen

Der Wertebereich einer Quadratwurzelfunktion umfasst alle Ausgabewerte, die bei zulässigen Eingaben tatsächlich entstehen.

Für <InlineMath math="f(x) = \sqrt{x-2}" /> kann der Radikand jeden Wert ab Null annehmen. Die Hauptquadratwurzel hat daher den Wertebereich

<BlockMath math="R_f = \{y \mid y \geq 0, y \in \mathbb{R}\}" />

### Vertikale Verschiebung

Die Funktion <InlineMath math="f(x) = \sqrt{x} + k" /> verschiebt den Graphen der grundlegenden Quadratwurzelfunktion um <InlineMath math="k \text{Einheiten}" /> nach oben (wenn <InlineMath math="k > 0" />) oder nach unten (wenn <InlineMath math="k < 0" />).

| Funktion | Transformation | Definitionsbereich | Wertebereich |
| ----------------------------------------- | ---------------------- | --------------- | ---------------- |
| <InlineMath math="f(x) = \sqrt{x}" /> | Grundfunktion | <InlineMath math="x \geq 0" /> | <InlineMath math="y \geq 0" /> |
| <InlineMath math="f(x) = \sqrt{x} + 2" /> | <InlineMath math="2 \text{Einheiten}" /> nach oben verschieben | <InlineMath math="x \geq 0" /> | <InlineMath math="y \geq 2" /> |
| <InlineMath math="f(x) = \sqrt{x} - 3" /> | <InlineMath math="3 \text{Einheiten}" /> nach unten verschieben | <InlineMath math="x \geq 0" /> | <InlineMath math="y \geq -3" /> |

## Allgemeine Form von Quadratwurzelfunktionen

Für den nicht entarteten Fall <InlineMath math="a\neq 0" /> und <InlineMath math="b\neq 0" /> hat die transformierte Quadratwurzelfunktion die Form:

<BlockMath math="f(x) = a\sqrt{b(x-h)} + k" />

Hier:

- <InlineMath math="a" /> bestimmt die vertikale Skalierung und bei <InlineMath math="a<0" /> die Spiegelung an der <InlineMath math="x" />-Achse
- <InlineMath math="b" /> bestimmt die horizontale Skalierung und bei <InlineMath math="b<0" /> die horizontale Spiegelung
- <InlineMath math="h" /> bestimmt die horizontale Verschiebung
- <InlineMath math="k" /> bestimmt die vertikale Verschiebung

Der reelle Definitionsbereich folgt aus <InlineMath math="b(x-h)\geq 0" />. Das Vorzeichen von <InlineMath math="a" /> bestimmt anschließend, ob sich der Wertebereich von <InlineMath math="y=k" /> aus nach oben oder unten erstreckt.

**Schritte zum Zeichnen des Graphen:**

| Schritt | Aktion | Beispiel: <InlineMath math="f(x) = 2\sqrt{x-1} + 3" /> |
| ---- | ------------------------- | ----------------------------------------------------------------- |
| <InlineMath math="1" /> | Startpunkt bestimmen | <InlineMath math="x-1 = 0 \Rightarrow x = 1" />, <InlineMath math="f(1) = 3" />, Punkt: <InlineMath math="(1, 3)" /> |
| <InlineMath math="2" /> | Definitionsbereich bestimmen | <InlineMath math="x-1 \geq 0 \Rightarrow x \geq 1" /> |
| <InlineMath math="3" /> | Wertetabelle erstellen | Wählen Sie mehrere Werte <InlineMath math="x \geq 1" /> |
| <InlineMath math="4" /> | Funktionswerte berechnen | Für <InlineMath math="x = 2" />: <InlineMath math="f(2) = 2\sqrt{1} + 3 = 5" /> |
| <InlineMath math="5" /> | Punkte eintragen | Tragen Sie <InlineMath math="(1,3)" />, <InlineMath math="(2,5)" />, <InlineMath math="(5,7)" /> usw. ein |
| <InlineMath math="6" /> | Punkte verbinden | Zeichnen Sie eine glatte Kurve durch die Punkte |

## Quadratwurzelfunktionsgleichungen

Um eine Gleichung mit einer Quadratwurzel zu lösen, isolieren Sie die Wurzel, quadrieren Sie beide Seiten und prüfen anschließend jeden Lösungskandidaten in der ursprünglichen Gleichung. Das Quadrieren ist für beliebige reelle Ausdrücke nicht umkehrbar und kann deshalb Scheinlösungen erzeugen.

| Schritt | Erklärung | Beispiel: <InlineMath math="\sqrt{2x+3} = 5" /> |
| ---- | --------- | ----------------------------------------------------- |
| <InlineMath math="1" /> | Isolieren Sie die Quadratwurzel | Bereits isoliert |
| <InlineMath math="2" /> | Beide Seiten quadrieren | <InlineMath math="(\sqrt{2x+3})^2 = 5^2" /> |
| <InlineMath math="3" /> | Vereinfachen | <InlineMath math="2x+3 = 25" /> |
| <InlineMath math="4" /> | Lösen | <InlineMath math="2x = 22 \Rightarrow x = 11" /> |
| <InlineMath math="5" /> | Überprüfen | <InlineMath math="\sqrt{2(11)+3} = \sqrt{25} = 5" /> ✓ |

## Quadratwurzelfunktionsungleichungen

Für eine Quadratwurzelungleichung erzwingen Sie zunächst den Definitionsbereich. Überprüfen Sie vor dem Quadrieren auch das Vorzeichen der anderen Seite, damit der Vergleich gleich bleibt.

**Beispiel:** Lösen Sie <InlineMath math="\sqrt{x-1} < 3" />

<MathContainer>
  <BlockMath math="\text{Bedingung:} x-1 \geq 0 \Rightarrow x \geq 1" />
  <BlockMath math="\sqrt{x-1} < 3" />
  <BlockMath math="x-1 < 9" />
  <BlockMath math="x < 10" />
</MathContainer>

Da beide Seiten im Definitionsbereich nicht negativ sind, bleibt die Ungleichung beim Quadrieren äquivalent. Zusammen mit <InlineMath math="x\geq 1" /> und <InlineMath math="x<10" /> ergibt sich <InlineMath math="1 \leq x < 10" />.
