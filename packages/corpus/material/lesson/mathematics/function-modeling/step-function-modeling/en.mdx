## Constant Outputs on Separate Intervals

A step function <Highlight>has a constant value on each interval</Highlight> and may jump when one interval ends and the next begins. Its graph resembles a staircase: horizontal segments represent the constant values, while separate endpoints mark any jump discontinuities.

### Definition of a Step Function

The formula below shows **a finite set of intervals**. For floor and ceiling functions on all real numbers, the intervals continue indefinitely in both directions.

A step function can be defined as a piecewise function of the form:

<BlockMath math="f(x) = \begin{cases} c_1, & \text{if } a_1 \leq x < b_1 \\ c_2, & \text{if } a_2 \leq x < b_2 \\ c_3, & \text{if } a_3 \leq x < b_3 \\ \vdots \\ c_n, & \text{if } a_n \leq x < b_n \end{cases}" />

In this definition, <InlineMath math="c_1, c_2, c_3, \ldots, c_n" /> are constants and <InlineMath math="[a_i, b_i)" /> are non-overlapping intervals.

**Characteristics of step functions**:

- Constant values on each interval
- Possible jump discontinuities at interval boundaries
- Graph shaped like stairs
- Belongs to the category of piecewise functions

## Types of Step Functions

The floor function rounds **down to an integer**, while the ceiling function rounds up to an integer. An integer input stays unchanged. The Heaviside function uses two constant values with one jump at zero.

### Floor Function

The floor function, denoted by <InlineMath math="\lfloor x \rfloor" />, gives the **largest integer** less than or equal to <InlineMath math="x" />.

<BlockMath math="\lfloor x \rfloor = \max\{n \in \mathbb{Z} : n \leq x\}" />

## Properties of Step Functions

The domain is determined by the **specified intervals**. It is not automatically all real numbers. The examples here have discrete outputs. At a boundary, a jump occurs only if the constants on the two sides differ.

For floor and ceiling, **two integers enclose the input**. At an integer input both outputs coincide. Otherwise the outputs differ by one.

**Special properties of floor and ceiling functions**:

1. <InlineMath math="\lfloor x \rfloor \leq x < \lfloor x \rfloor + 1" />
2. <InlineMath math="\lceil x \rceil - 1 < x \leq \lceil x \rceil" />
3. <InlineMath math="\lceil x \rceil = \lfloor x \rfloor + 1 \text{ if } x \notin \mathbb{Z}" />
4. <InlineMath math="\lceil x \rceil = \lfloor x \rfloor \text{ if } x \in \mathbb{Z}" />

**Comparison table of floor and ceiling functions**:

| <InlineMath math="x" /> | <InlineMath math="\lfloor x \rfloor" /> | <InlineMath math="\lceil x \rceil" /> | Difference |
| ---- | --------------------------------------- | ------------------------------------- | ---------- |
| <InlineMath math="-2.3" /> | <InlineMath math="-3" /> | <InlineMath math="-2" /> | <InlineMath math="1" /> |
| <InlineMath math="-1" /> | <InlineMath math="-1" /> | <InlineMath math="-1" /> | <InlineMath math="0" /> |
| <InlineMath math="0.7" /> | <InlineMath math="0" /> | <InlineMath math="1" /> | <InlineMath math="1" /> |
| <InlineMath math="2" /> | <InlineMath math="2" /> | <InlineMath math="2" /> | <InlineMath math="0" /> |
| <InlineMath math="3.8" /> | <InlineMath math="3" /> | <InlineMath math="4" /> | <InlineMath math="1" /> |

## Transformations of Step Functions

A **vertical shift** changes the height of each step without moving interval boundaries. A horizontal shift moves those boundaries. Vertical scaling changes jump heights, while horizontal scaling changes interval widths.

### Horizontal Translation

The function <InlineMath math="f(x)=\lfloor x-h\rfloor" /> shifts the graph **horizontally**. The jump originally at <InlineMath math="x=m" /> moves to <InlineMath math="x=m+h" /> for every integer <InlineMath math="m" />. With <InlineMath math="h=2" />, the jump at zero moves to two. It is not the first jump: jumps occur at every integer.

## Practice Problems

The problems mix floor and ceiling values with a quantity that changes in whole steps. Evaluate the **whole-number part** before combining the terms.

1. Determine the value of <InlineMath math="\lfloor 3.7 \rfloor + \lceil -2.3 \rceil" />

2. A bookstore gives discounts based on the number of purchases:

- <InlineMath math="1\text{-}5" /> books: no discount
- <InlineMath math="6\text{-}10" /> books: <InlineMath math="10\%" /> discount
- <InlineMath math="11\text{-}20" /> books: <InlineMath math="15\%" /> discount
- <InlineMath math="> 20" /> books: <InlineMath math="20\%" /> discount

   If the price per book is <InlineMath math="\text{Rp}50{,}000" />, create a function that represents the total price after discount!

3. Graph of function <InlineMath math="f(x) = 2\lfloor x \rfloor - 1" /> for <InlineMath math="-3 \leq x \leq 3" />

4. Solve the equation <InlineMath math="\lfloor 2x + 1 \rfloor = 5" />

5. An elevator can accommodate a maximum of <InlineMath math="8 \text{ people}" />. If there are <InlineMath math="n \text{ people}" /> who want to use the elevator, how many times must the elevator operate?

### Worked Solutions

**Problem 1**. For a **negative input**, rounding down moves toward a smaller integer, not toward zero.

<BlockMath math="\lfloor3.7\rfloor=3" />

<InlineMath math="3" /> is the largest integer less than or equal to <InlineMath math="3.7" />.
<BlockMath math="\lceil-2.3\rceil=-2" />

<InlineMath math="-2" /> is the smallest integer greater than or equal to <InlineMath math="-2.3" />.
<BlockMath math="\lfloor 3.7 \rfloor + \lceil -2.3 \rceil = 3 + (-2) = 1" />

**Problem 2**. The discount percentage is a **step function**, but the total price <InlineMath math="H(n)" /> grows with the number of books within each tier. The total-price model below is therefore piecewise on integer book counts, rather than constant within each tier.

The discount applies to the **whole purchase**. For example, six books receive a ten-percent discount:

<BlockMath math="H(6)=50000(6)(1-10/100)=270000" />

Let <InlineMath math="n\in\mathbb{N}" /> be the positive whole number of books purchased. The total price after discount is:

<BlockMath math="H(n) = \begin{cases}\begin{gathered}50000n\\\text{if } 1 \leq n \leq 5\end{gathered}\\[4pt]\begin{gathered}50000n \times 0.9\\\text{if } 6 \leq n \leq 10\end{gathered}\\[4pt]\begin{gathered}50000n \times 0.85\\\text{if } 11 \leq n \leq 20\end{gathered}\\[4pt]\begin{gathered}50000n \times 0.8\\\text{if } n > 20\end{gathered}\end{cases}" />

**Problem 3**. Check the **right endpoint of the domain** separately: the value at <InlineMath math="x=3" /> differs from the value on the interval immediately to its left.

For each interval:

- <InlineMath math="-3 \leq x < -2: f(x) = 2(-3) - 1 = -7" />
- <InlineMath math="-2 \leq x < -1: f(x) = 2(-2) - 1 = -5" />
- <InlineMath math="-1 \leq x < 0: f(x) = 2(-1) - 1 = -3" />
- <InlineMath math="0 \leq x < 1: f(x) = 2(0) - 1 = -1" />
- <InlineMath math="1 \leq x < 2: f(x) = 2(1) - 1 = 1" />
- <InlineMath math="2 \leq x < 3: f(x) = 2(2) - 1 = 3" />
- At the endpoint, <InlineMath math="f(3)=2\lfloor3\rfloor-1=5" />

**Problem 4**. Use the **bounding inequality for floor**, subtract one from all three expressions, and then divide throughout by two.

<MathContainer>

<BlockMath math="5 \leq 2x + 1 < 6" />

<BlockMath math="4 \leq 2x < 5" />

<BlockMath math="2 \leq x < 2.5" />
</MathContainer>

So the solution set is <InlineMath math="x \in [2, 2.5)" />.

**Problem 5**. Count **loaded upward trips**, allowing the elevator to return empty when needed. For nine people, one full trip is insufficient:

<BlockMath math="9=8+1,\qquad \lceil9/8\rceil=2" />

If <InlineMath math="n\in\mathbb{Z}_{\geq0}" /> is the number of people and the elevator can accommodate at most <InlineMath math="8 \text{ people}" />, then the number of elevator trips required is:

<BlockMath math="f(n) = \lceil \frac{n}{8} \rceil" />

The ceiling function is used because any nonzero remainder requires one additional trip. It also gives <InlineMath math="f(0)=0" /> when nobody is waiting.
