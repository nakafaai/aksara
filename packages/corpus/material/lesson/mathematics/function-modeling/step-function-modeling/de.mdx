## Konstante Werte auf einzelnen Intervallen

Eine Stufenfunktion <Highlight>hat in jedem Intervall einen konstanten Wert</Highlight> und kann beim Übergang zum nächsten Intervall springen. Ihr Graph ähnelt einer Treppe: Waagerechte Abschnitte zeigen die konstanten Werte, getrennte Endpunkte kennzeichnen mögliche Sprungstellen.

### Definition einer Treppenfunktion

Die folgende Formel zeigt **endlich viele Intervalle**. Bei der Abrundungs- und Aufrundungsfunktion auf allen reellen Zahlen setzen sich die Intervalle nach links und rechts unbegrenzt fort.

Eine Stufenfunktion kann als stückweise Funktion der Form definiert werden:

<BlockMath math="f(x) = \begin{cases} c_1, &amp; \text{wenn } a_1 \leq x &lt; b_1 \\ c_2, &amp; \text{wenn } a_2 \leq x &lt; b_2 \\ c_3, &amp; \text{wenn } a_3 \leq x &lt; b_3 \\ \vdots \\ c_n, &amp; \text{wenn } a_n \leq x &lt; b_n \end{cases}" />

Dabei sind <InlineMath math="c_1, c_2, c_3, \ldots, c_n" /> Konstanten und <InlineMath math="[a_i, b_i)" /> nicht überlappende Intervalle.

**Eigenschaften von Stufenfunktionen**:

- Konstante Werte in jedem Intervall
- Mögliche Sprungstellen an Intervallgrenzen
- Graph in Form einer Treppe
- Gehört zur Kategorie der stückweisen Funktionen

## Typen von Stufenfunktionen

Die Abrundungsfunktion rundet **zur kleineren ganzen Zahl**, die Aufrundungsfunktion zur größeren. Eine ganze Zahl bleibt unverändert. Die Heaviside-Funktion nimmt zwei konstante Werte an und springt einmal bei null.

### Abrundungsfunktion

Die Abrundungsfunktion, bezeichnet mit <InlineMath math="\lfloor x \rfloor" />, gibt die **größte ganze Zahl** an, die kleiner oder gleich <InlineMath math="x" /> ist.

<BlockMath math="\lfloor x \rfloor = \max\{n \in \mathbb{Z} : n \leq x\}" />

Der Graph markiert jeden enthaltenen linken Randpunkt ausgefüllt und jeden ausgeschlossenen rechten Randpunkt offen.

<BlockMath math="\lceil x \rceil = \min\{n \in \mathbb{Z} : n \geq x\}" />

Der Graph markiert jeden ausgeschlossenen linken Randpunkt offen und jeden enthaltenen rechten Randpunkt ausgefüllt.

## Eigenschaften von Stufenfunktionen

Der Definitionsbereich ergibt sich aus den **festgelegten Intervallen** und umfasst nicht automatisch alle reellen Zahlen. Die Beispiele hier haben diskrete Ausgaben. An einer Grenze entsteht nur dann ein Sprung, wenn sich die Konstanten auf beiden Seiten unterscheiden.

Bei Ab- und Aufrundung **begrenzen zwei ganze Zahlen die Eingabe**. Für ganzzahlige Eingaben stimmen beide Ergebnisse überein, sonst unterscheiden sie sich um eins.

**Besondere Eigenschaften der Abrundungs- und Aufrundungsfunktion**:

1. <InlineMath math="\lfloor x \rfloor \leq x < \lfloor x \rfloor + 1" />
2. <InlineMath math="\lceil x \rceil - 1 < x \leq \lceil x \rceil" />
3. <InlineMath math="\lceil x \rceil = \lfloor x \rfloor + 1 \text{ wenn } x \notin \mathbb{Z}" />
4. <InlineMath math="\lceil x \rceil = \lfloor x \rfloor \text{wenn } x \in \mathbb{Z}" />

**Vergleichstabelle der Abrundungs- und Aufrundungsfunktion**:

| <InlineMath math="x" /> | <InlineMath math="\lfloor x \rfloor" /> | <InlineMath math="\lceil x \rceil" /> | Unterschied |
| ---- | --------------------------------------- | ------------------------------------- | ---------- |
| <InlineMath math="-2{,}3" /> | <InlineMath math="-3" /> | <InlineMath math="-2" /> | <InlineMath math="1" /> |
| <InlineMath math="-1" /> | <InlineMath math="-1" /> | <InlineMath math="-1" /> | <InlineMath math="0" /> |
| <InlineMath math="0{,}7" /> | <InlineMath math="0" /> | <InlineMath math="1" /> | <InlineMath math="1" /> |
| <InlineMath math="2" /> | <InlineMath math="2" /> | <InlineMath math="2" /> | <InlineMath math="0" /> |
| <InlineMath math="3{,}8" /> | <InlineMath math="3" /> | <InlineMath math="4" /> | <InlineMath math="1" /> |

## Transformationen von Stufenfunktionen

Eine **vertikale Verschiebung** ändert die Höhe jeder Stufe, aber nicht die Intervallgrenzen. Eine horizontale Verschiebung bewegt die Grenzen. Vertikales Skalieren verändert die Sprunghöhen, horizontales Skalieren die Intervallbreiten.

### Horizontale Verschiebung

Die Funktion <InlineMath math="f(x)=\lfloor x-h\rfloor" /> verschiebt den Graphen **waagerecht**. Der Sprung bei <InlineMath math="x=m" /> wandert für jede ganze Zahl <InlineMath math="m" /> nach <InlineMath math="x=m+h" />. Bei <InlineMath math="h=2" /> wandert der Sprung von null nach zwei. Es ist kein erster Sprung, denn an jeder ganzen Zahl liegt eine Sprungstelle.

## Übungsaufgaben

Die Aufgaben verbinden Abrundungs- und Aufrundungswerte mit einer Größe, die in ganzen Schritten wächst. Berechne zuerst den **ganzzahligen Anteil** und fasse dann die Terme zusammen.

1. Bestimme den Wert von <InlineMath math="\lfloor 3{,}7 \rfloor + \lceil -2{,}3 \rceil" />

2. Eine Buchhandlung gewährt Rabatte abhängig von der Anzahl der gekauften Artikel:

- <InlineMath math="1\text{-}5" /> Bücher: kein Rabatt
- <InlineMath math="6\text{-}10" /> Bücher: <InlineMath math="10\%" /> Rabatt
- <InlineMath math="11\text{-}20" /> Bücher: <InlineMath math="15\%" /> Rabatt
- <InlineMath math="> 20" /> Bücher: <InlineMath math="20\%" /> Rabatt

Wenn der Preis pro Buch <InlineMath math="\text{Rp}\,50{.}000" /> beträgt, erstelle eine Funktion, die den Gesamtpreis nach Rabatt darstellt!

3. Zeichne den Graphen der Funktion <InlineMath math="f(x) = 2\lfloor x \rfloor - 1" /> für <InlineMath math="-3 \leq x \leq 3" />.

4. Löse die Gleichung <InlineMath math="\lfloor 2x + 1 \rfloor = 5" />

5. Ein Aufzug kann maximal <InlineMath math="8 \text{ Menschen}" /> aufnehmen. Wenn es <InlineMath math="n \text{ Menschen}" /> gibt, die den Aufzug benutzen möchten, wie oft muss der Aufzug fahren?

### Lösungen

**Aufgabe 1**. Bei einer **negativen Eingabe** führt Abrunden zur kleineren ganzen Zahl, nicht in Richtung null.

<BlockMath math="\lfloor3{,}7\rfloor=3" />

<InlineMath math="3" /> ist die größte ganze Zahl, die kleiner oder gleich <InlineMath math="3{,}7" /> ist.
<BlockMath math="\lceil-2{,}3\rceil=-2" />

<InlineMath math="-2" /> ist die kleinste ganze Zahl, die größer oder gleich <InlineMath math="-2{,}3" /> ist.
<BlockMath math="\lfloor 3{,}7 \rfloor + \lceil -2{,}3 \rceil = 3 + (-2) = 1" />

**Aufgabe 2**. Der Rabattsatz ist eine **Stufenfunktion**, der Gesamtpreis <InlineMath math="H(n)" /> steigt jedoch innerhalb jeder Rabattstufe mit der Buchanzahl. Das folgende Preismodell ist daher stückweise auf ganzzahligen Buchanzahlen definiert und innerhalb der Stufen nicht konstant.

Der Rabatt gilt für den **gesamten Einkauf**. Sechs Bücher erhalten beispielsweise zehn Prozent Rabatt:

<BlockMath math="H(6)=50000(6)(1-10/100)=270000" />

Sei <InlineMath math="n\in\mathbb{N}" /> die positive ganzzahlige Anzahl der gekauften Bücher. Dann beträgt der Gesamtpreis nach Rabatt:

<BlockMath math="H(n) = \begin{cases}\begin{gathered}50{.}000n\\\text{wenn } 1 \leq n \leq 5\end{gathered}\\[4pt]\begin{gathered}50{.}000n \times 0{,}9\\\text{wenn } 6 \leq n \leq 10\end{gathered}\\[4pt]\begin{gathered}50{.}000n \times 0{,}85\\\text{wenn } 11 \leq n \leq 20\end{gathered}\\[4pt]\begin{gathered}50{.}000n \times 0{,}8\\\text{wenn } n > 20\end{gathered}\end{cases}" />

**Aufgabe 3**. Prüfe den **rechten Rand des Definitionsbereichs** gesondert: Der Wert bei <InlineMath math="x=3" /> unterscheidet sich vom Wert auf dem Intervall unmittelbar links davon.

Für jedes Intervall:

- <InlineMath math="-3 \leq x < -2: f(x) = 2(-3) - 1 = -7" />
- <InlineMath math="-2 \leq x < -1: f(x) = 2(-2) - 1 = -5" />
- <InlineMath math="-1 \leq x < 0: f(x) = 2(-1) - 1 = -3" />
- <InlineMath math="0 \leq x < 1: f(x) = 2(0) - 1 = -1" />
- <InlineMath math="1 \leq x < 2: f(x) = 2(1) - 1 = 1" />
- <InlineMath math="2 \leq x < 3: f(x) = 2(2) - 1 = 3" />
- Am Endpunkt gilt <InlineMath math="f(3)=2\lfloor3\rfloor-1=5" />

**Aufgabe 5**. Gezählt werden **Aufwärtsfahrten mit Fahrgästen**. Notwendige leere Rückfahrten zählen nicht dazu. Für neun Personen reicht eine volle Fahrt nicht aus:

<BlockMath math="9=8+1,\qquad \lceil9/8\rceil=2" />

Sei <InlineMath math="n\in\mathbb{Z}_{\geq0}" /> die Anzahl der Personen. Wenn der Aufzug höchstens <InlineMath math="8 \text{ Personen}" /> aufnehmen kann, beträgt die erforderliche Anzahl der Fahrten:

<BlockMath math="f(n) = \lceil \frac{n}{8} \rceil" />

Die Aufrundungsfunktion wird verwendet, weil jeder von null verschiedene Rest eine zusätzliche Fahrt erfordert. Für eine leere Warteschlange liefert die Formel außerdem <InlineMath math="f(0)=0" />.
