## Lines That a Graph Approaches

An asymptote is <Highlight>a line that a graph approaches</Highlight> in a particular limiting process. Near a vertical asymptote, the magnitude of the function grows without bound. Near a horizontal or oblique asymptote, the distance between the graph and the line tends to zero as the input grows in magnitude.

A graph may cross a horizontal or oblique asymptote at a finite input. These two types describe the graph at large input magnitudes. It does not act as a wall.

## Types of Asymptotes

The **direction of the line** distinguishes the three asymptote types.

Asymptotes fall into three types. The type follows from how the graph approaches the line, so each one has its own identifying feature. The three types are named after the direction of the line the graph approaches.

### Vertical Asymptote

A vertical asymptote is a vertical line that the graph approaches when the function value approaches positive or negative infinity.

**Definition**: The line <InlineMath math="x = a" /> is a vertical asymptote if at least one of these one-sided limits is infinite:

- When <InlineMath math="x" /> approaches <InlineMath math="a" /> from the left, <InlineMath math="f(x) \to \pm\infty" />
- When <InlineMath math="x" /> approaches <InlineMath math="a" /> from the right, <InlineMath math="f(x) \to \pm\infty" />

**How to find**: First cancel any common polynomial factors. In the simplified rational function, a vertical asymptote occurs when <InlineMath math="Q(x) = 0" /> while <InlineMath math="P(x) \neq 0" />. An excluded input becomes a hole only if **every vanishing denominator factor** cancels completely. If that factor still remains in the denominator, the input remains a vertical asymptote.

| Original expression | Simplified expression | Behavior at one |
| --- | --- | --- |
| <InlineMath math="\frac{x-1}{x-1}" /> | <InlineMath math="1,\quad x\neq1" /> | Hole |
| <InlineMath math="\frac{x-1}{(x-1)^2}" /> | <InlineMath math="\frac1{x-1},\quad x\neq1" /> | Vertical asymptote |

### Horizontal Asymptote

A horizontal asymptote is a horizontal line that the graph approaches as <InlineMath math="x" /> tends toward positive infinity, negative infinity, or both.

**Definition**: The line <InlineMath math="y = b" /> is a horizontal asymptote in each direction where the corresponding limit holds:

- <InlineMath math="\lim_{x \to \infty} f(x) = b" />
- <InlineMath math="\lim_{x \to -\infty} f(x) = b" />

### Oblique Asymptote

The term **oblique** requires a nonzero slope. With zero slope, the line is a horizontal asymptote.

<BlockMath math="m\neq0" />

An oblique asymptote is a slanted line that the graph approaches as <InlineMath math="x" /> tends toward positive infinity, negative infinity, or both.

**Definition**: The line <InlineMath math="y = mx + c" /> is an oblique asymptote in a direction where the difference tends to zero:

<MathContainer>

<BlockMath math="\lim_{x \to \infty} [f(x) - (mx + c)] = 0" />

<BlockMath math="\lim_{x \to -\infty} [f(x) - (mx + c)] = 0" />
</MathContainer>

## Asymptotes in Rational Functions

The **polynomial degrees** determine the end behavior of a rational function.

Consider rational functions <InlineMath math="f(x) = \frac{P(x)}{Q(x)}" /> where <InlineMath math="P(x)" /> and <InlineMath math="Q(x)" /> are polynomials. For these functions the asymptotes follow directly from the zeros of the denominator and from the degrees of the two polynomials.

### Finding Vertical Asymptotes

**Cancel common factors first**, keeping the original domain. Then use the numerator and denominator of the reduced expression in the steps below.

**Steps**:

1. Find the value of <InlineMath math="x" /> that makes <InlineMath math="Q(x) = 0" />
2. Check if <InlineMath math="P(x) \neq 0" /> at that value
3. If yes, then there is a vertical asymptote at <InlineMath math="x = a" />

**Example**: Determine the vertical asymptote of <InlineMath math="f(x) = \frac{x + 3}{x - 2}" />

**Solution**:

- Denominator is zero when: <InlineMath math="x - 2 = 0" />, so <InlineMath math="x = 2" />
- When <InlineMath math="x = 2" />, numerator is <InlineMath math="2 + 3 = 5 \neq 0" />
- Therefore, vertical asymptote: <InlineMath math="x = 2" />

The following values show the function's behavior around the vertical asymptote:

| <InlineMath math="x" />    | <InlineMath math="f(x) = \frac{x + 3}{x - 2}" />                       | Description                              |
| -------------------------- | ---------------------------------------------------------------------- | ---------------------------------------- |
| <InlineMath math="1.9" />  | <InlineMath math="\frac{1.9 + 3}{1.9 - 2} = \frac{4.9}{-0.1} = -49" /> | Approaches <InlineMath math="-\infty" /> |
| <InlineMath math="1.99" /> | <InlineMath math="\frac{4.99}{-0.01} = -499" />                        | Getting more negative                    |
| <InlineMath math="2.01" /> | <InlineMath math="\frac{5.01}{0.01} = 501" />                          | Approaches <InlineMath math="+\infty" /> |
| <InlineMath math="2.1" />  | <InlineMath math="\frac{5.1}{0.1} = 51" />                             | Value right of the asymptote                    |

### Finding Horizontal Asymptotes

**Rules for rational functions**:

Let the degree of the numerator be <InlineMath math="m" /> and the degree of the denominator be <InlineMath math="n" />

1. If <InlineMath math="m < n" />: Horizontal asymptote is <InlineMath math="y = 0" />
2. If <InlineMath math="m = n" />: Horizontal asymptote is <InlineMath math="y = \frac{a}{b}" /> (ratio of leading coefficients)
3. If <InlineMath math="m > n" />: No horizontal asymptote (but there might be an oblique asymptote)

**Example**: Determine the horizontal asymptote of:

1. <InlineMath math="f(x) = \frac{2x + 1}{x^2 - 4}" />

   **Solution**:

   The numerator degree is <InlineMath math="= 1" /> and the denominator degree is <InlineMath math="= 2" />. Since <InlineMath math="1 < 2" />, the horizontal asymptote is <InlineMath math="y = 0" />.

2. <InlineMath math="g(x) = \frac{3x^2 - 1}{2x^2 + 5}" />

   **Solution**:

   The numerator degree is <InlineMath math="= 2" /> and the denominator degree is <InlineMath math="= 2" />. Since the degrees are equal, the horizontal asymptote is <InlineMath math="y = \frac{3}{2}" />.

The following values show how the function approaches the horizontal asymptote:

| <InlineMath math="x" />    | <InlineMath math="g(x) = \frac{3x^2 - 1}{2x^2 + 5}" />                              | Approaches                |
| -------------------------- | ----------------------------------------------------------------------------------- | ------------------------- |
| <InlineMath math="10" />   | <InlineMath math="\frac{3(100) - 1}{2(100) + 5} = \frac{299}{205} \approx 1.459" /> | <InlineMath math="1.5" /> |
| <InlineMath math="100" />  | <InlineMath math="\frac{29999}{20005} \approx 1.4996" />                            | <InlineMath math="1.5" /> |
| <InlineMath math="1000" /> | <InlineMath math="\frac{2999999}{2000005} \approx 1.499996" />                      | <InlineMath math="1.5" /> |

### Finding Oblique Asymptotes

Oblique asymptotes appear when <InlineMath math="\text{degree of numerator} = \text{degree of denominator} + 1" />.

**How to find**: Perform polynomial division.

**Example**: Determine the oblique asymptote of <InlineMath math="f(x) = \frac{x^2 + 2x - 1}{x - 1}" />

**Solution**:
Using polynomial division:

Polynomial division uses **two subtractions**. Each row removes the highest-degree term of the previous remainder.

| Quotient term | Product with divisor | Remainder |
| --- | --- | --- |
| <InlineMath math="x" /> | <InlineMath math="x(x-1)=x^2-x" /> | <InlineMath math="(x^2+2x-1)-(x^2-x)=3x-1" /> |
| <InlineMath math="3" /> | <InlineMath math="3(x-1)=3x-3" /> | <InlineMath math="(3x-1)-(3x-3)=2" /> |

<BlockMath math="\begin{aligned} f(x) &amp;= \frac{x^2 + 2x - 1}{x - 1} \\ &amp;= x + 3 + \frac{2}{x - 1} \end{aligned}" />

When <InlineMath math="x \to \pm\infty" />, the term <InlineMath math="\frac{2}{x - 1} \to 0" />

Oblique asymptote: <InlineMath math="y = x + 3" />

## Drawing Graphs with Asymptotes

Draw the asymptotes first. A vertical asymptote marks the input value approached as the magnitude of the function's output grows without bound. A horizontal or oblique asymptote describes the graph's end behavior as the magnitude of the input grows. Then use the following steps:

1. **Determine all asymptotes** (vertical, horizontal, or oblique)
2. **Draw asymptotes with dashed lines**
3. **Find intercepts** with the axes
4. **Determine some additional points**
5. **Draw the curve** that approaches the asymptotes

**Complete Example**: Draw the graph of <InlineMath math="f(x) = \frac{x + 1}{x - 2}" />

**Step 1**: Find asymptotes

- Vertical asymptote: <InlineMath math="x = 2" /> (<InlineMath math="\text{denominator} = 0" />)
- Horizontal asymptote: <InlineMath math="y = 1" /> (same degree, coefficient ratio <InlineMath math="= 1/1" />)

**Step 2**: Intercepts

- <InlineMath math="y" />-axis: <InlineMath math="f(0) = \frac{0 + 1}{0 - 2} = -\frac{1}{2}" />
- <InlineMath math="x" />-axis: <InlineMath math="0 = \frac{x + 1}{x - 2}" />, so <InlineMath math="x = -1" />

**Step 3**: Behavior around asymptotes

- When <InlineMath math="x \to 2^-" />: <InlineMath math="f(x) \to -\infty" />
- When <InlineMath math="x \to 2^+" />: <InlineMath math="f(x) \to +\infty" />
- When <InlineMath math="x \to \pm\infty" />: <InlineMath math="f(x) \to 1" />

**Step 4**: Value table to help with drawing

| <InlineMath math="x" />  | <InlineMath math="f(x) = \frac{x + 1}{x - 2}" />                  | Description                      |
| ------------------------ | ----------------------------------------------------------------- | -------------------------------- |
| <InlineMath math="-3" /> | <InlineMath math="\frac{-3 + 1}{-3 - 2} = \frac{-2}{-5} = 0.4" /> | Point in quadrant II             |
| <InlineMath math="-1" /> | <InlineMath math="\frac{-1 + 1}{-1 - 2} = \frac{0}{-3} = 0" />    | <InlineMath math="x" />-axis intercept |
| <InlineMath math="0" />  | <InlineMath math="\frac{0 + 1}{0 - 2} = \frac{1}{-2} = -0.5" />   | <InlineMath math="y" />-axis intercept |
| <InlineMath math="1" />  | <InlineMath math="\frac{1 + 1}{1 - 2} = \frac{2}{-1} = -2" />     | Approaching vertical asymptote   |
| <InlineMath math="3" />  | <InlineMath math="\frac{3 + 1}{3 - 2} = \frac{4}{1} = 4" />       | Right of asymptote               |
| <InlineMath math="5" />  | <InlineMath math="\frac{5 + 1}{5 - 2} = \frac{6}{3} = 2" />       | Approaching horizontal asymptote |

## Practice Problems

Check **denominator factors and the degree difference** for each function. Every function in these exercises is rational.

1. Determine all asymptotes of <InlineMath math="f(x) = \frac{2x^2 - 3x + 1}{x - 3}" />

2. Determine the asymptotes of <InlineMath math="g(x) = \frac{x^2 - 4}{x^2 - 9}" />

3. The average cost function of a product is <InlineMath math="C(x) = \frac{500 + 3x}{x}" />. Determine the limiting cost per unit as production grows without bound.

4. Draw a sketch of the graph <InlineMath math="h(x) = \frac{x}{x^2 - 1}" /> complete with its asymptotes.

### Worked Solutions

**Problem 1**. The denominator is zero at <InlineMath math="x = 3" />, while the **numerator** there is <InlineMath math="2(3)^2 - 3(3) + 1 = 10" />. Because the numerator does not vanish, <InlineMath math="x = 3" /> is a vertical asymptote.

Polynomial division separates the long-term linear behavior from the remainder:

<BlockMath math="\frac{2x^2 - 3x + 1}{x - 3} = 2x + 3 + \frac{10}{x - 3}" />

As <InlineMath math="x \to \pm\infty" />, the remainder <InlineMath math="\frac{10}{x - 3} \to 0" />. Therefore the oblique asymptote is <InlineMath math="y = 2x + 3" />.

**Problem 2**. Factor both polynomials before classifying their zeros:

<MathContainer>

<BlockMath math="x^2 - 4 = (x - 2)(x + 2)" />

<BlockMath math="x^2 - 9 = (x - 3)(x + 3)" />
</MathContainer>

There is no **common factor** to cancel. The denominator zeros <InlineMath math="x = -3" /> and <InlineMath math="x = 3" /> are therefore vertical asymptotes. The numerator zeros <InlineMath math="x = -2" /> and <InlineMath math="x = 2" /> are <InlineMath math="x" />-intercepts. Since numerator and denominator have the same degree and both leading coefficients are <InlineMath math="1" />, the horizontal asymptote is <InlineMath math="y = 1" />.

**Problem 3**. Separate the average cost into a term that depends on output and a constant term.

<BlockMath math="C(x) = \frac{500 + 3x}{x} = \frac{500}{x} + 3" />

When <InlineMath math="x \to \infty" />, <InlineMath math="\frac{500}{x} \to 0" />. Therefore <InlineMath math="C(x) \to 3" />. The cost approaches <InlineMath math="3" /> per unit but does not equal that value for any **finite positive** <InlineMath math="x" />.

**Problem 4**. Factor the denominator as <InlineMath math="x^2 - 1 = (x - 1)(x + 1)" />. Neither factor cancels with the **numerator**, so the vertical asymptotes are <InlineMath math="x = -1" /> and <InlineMath math="x = 1" />. Because the numerator degree is smaller than the denominator degree, <InlineMath math="h(x) \to 0" /> as <InlineMath math="x \to \pm\infty" />. Hence the horizontal asymptote is <InlineMath math="y = 0" />.

The asymptotes split the domain into three intervals. The sign of <InlineMath math="h(x)" /> is negative on <InlineMath math="x < -1" />, positive on <InlineMath math="-1 < x < 0" />, negative on <InlineMath math="0 < x < 1" />, and positive on <InlineMath math="x > 1" />. These signs, together with the intercept <InlineMath math="(0,0)" />, determine the placement of all three branches.
