## The Same Difference between Consecutive Terms

An arithmetic sequence is a sequence of numbers where the difference between consecutive terms is always constant. This constant is the common difference, written <InlineMath math="b" />. To test whether a list of numbers is arithmetic, subtract each term from the one after it and check that every subtraction returns **the same number**.

## Examples of Arithmetic Sequences

**Each term** in this sequence increases by <InlineMath math="2" />:

<InlineMath math="4, 6, 8, 10, ..." />

In this sequence:

- The difference between the second and first term: <InlineMath math="6 - 4 = 2" />
- The difference between the third and second term: <InlineMath math="8 - 6 = 2" />
- The difference between the fourth and third term: <InlineMath math="10 - 8 = 2" />

Since the difference between consecutive terms is always <InlineMath math="2" />, this sequence is an arithmetic sequence with common difference <InlineMath math="b = 2" />.

Each step of <InlineMath math="4, 6, 8, 10, \ldots" /> climbs by the same height. Plot term <InlineMath math="U_n" /> above position <InlineMath math="n" />: every riser of the staircase is exactly <InlineMath math="2" />, the common difference, and every tread is one position long.

## Common Difference in Arithmetic Sequences

The common difference (<InlineMath math="b" />) in an arithmetic sequence can be calculated by **subtracting consecutive terms**:

<BlockMath math="\begin{aligned} b &amp;= U_2 - U_1 \\ &amp;= U_3 - U_2 \\ &amp;= U_4 - U_3 \\ &amp;= ... \\ &amp;= U_n - U_{n-1} \end{aligned}" />

Where:

- <InlineMath math="U_n" /> represents term number <InlineMath math="n" />
- <InlineMath math="U_{n-1}" /> represents term number <InlineMath math="n-1" />

## Formula for the nth Term

Two forms describe the same arithmetic sequence. The general formula returns any term from its position, using the **first term** and the common difference. The recursive form builds each term from the term before it.

### General Term of an Arithmetic Sequence

To determine the <InlineMath math="n" />th term of an arithmetic sequence, we can use the formula:

<BlockMath math="U_n = a + (n-1)b" />

Where:

- <InlineMath math="U_n" /> = term number <InlineMath math="n" />
- <InlineMath math="a" /> = **first term**
- <InlineMath math="n" /> = term number
- <InlineMath math="b" /> = common difference

### Deriving the Formula

If we write the first few terms of an arithmetic sequence:

There are **three moves** from the first term to the fourth, not four. Each move adds the same common difference.

| Term number | Number of additions | Term value |
| --- | --- | --- |
| 1 | 0 | <InlineMath math="U_1 = a" /> |
| 2 | 1 | <InlineMath math="U_2 = a + 1b" /> |
| 3 | 2 | <InlineMath math="U_3 = a + 2b" /> |
| 4 | 3 | <InlineMath math="U_4 = a + 3b" /> |
| 5 | 4 | <InlineMath math="U_5 = a + 4b" /> |

The pattern gives the <InlineMath math="n" />th term:

<BlockMath math="U_n = a + (n-1)b" />

### Recursive Form

The same arithmetic sequence can be defined from its first term and the rule that produces the **next term**:

<MathContainer>
  <BlockMath math="U_1=a" />
  <BlockMath math="U_{n+1}=U_n+b" />
</MathContainer>

The explicit formula gives any term directly, while the recursive form builds the sequence one term at a time.

## Applications of Arithmetic Sequences

Each application below gives a starting value and a **constant change** per step. In the theater example, the seat count per row grows by four seats, and the general formula returns the seat count for any row number.

### Performing Arts Theater

The number of seats in this performing arts theater grows with each row:

- Row <InlineMath math="1" /> has <InlineMath math="20" /> seats.
- Row <InlineMath math="2" /> has <InlineMath math="24" /> seats.
- Row <InlineMath math="3" /> has <InlineMath math="28" /> seats.
- Row <InlineMath math="4" /> has <InlineMath math="32" /> seats.
- Row <InlineMath math="5" /> has <InlineMath math="36" /> seats.

To determine the number of seats in a specific row, we need to find the pattern in this data.

**Step 1**: Finding the common difference between rows

- <InlineMath math="\text{Row }2 - \text{row }1" />: <InlineMath math="24 - 20 = 4" />
- <InlineMath math="\text{Row }3 - \text{row }2" />: <InlineMath math="28 - 24 = 4" />
- <InlineMath math="\text{Row }4 - \text{row }3" />: <InlineMath math="32 - 28 = 4" />
- <InlineMath math="\text{Row }5 - \text{row }4" />: <InlineMath math="36 - 32 = 4" />

Consecutive rows differ by <InlineMath math="4" /> seats. Therefore, the seat counts form an arithmetic sequence with:

- First term <InlineMath math="a = 20" />
- Common difference <InlineMath math="b = 4" />

**Step 2**: Using the formula to find the number of seats in row <InlineMath math="15" />

<MathContainer>
  <BlockMath math="U_{15} = a + (15-1)b" />
  <BlockMath math="U_{15} = 20 + (15-1)4" />
  <BlockMath math="U_{15} = 20 + (14)4" />
  <BlockMath math="U_{15} = 20 + 56" />
  <BlockMath math="U_{15} = 76" />
</MathContainer>

There are <InlineMath math="76" /> seats in row <InlineMath math="15" />.

This result gives **the seats in one row**, row <InlineMath math="15" />. Finding the total number of seats in the first fifteen rows requires the corresponding arithmetic series.

## Increasing Decreasing and Constant Sequences

An arithmetic sequence increases when <InlineMath math="b>0" />, decreases when <InlineMath math="b<0" />, and remains constant when <InlineMath math="b=0" />. For example:

<BlockMath math="12,9,6,3,\ldots\qquad b=-3" />

The **sign of the common difference** therefore describes the direction in which the sequence changes.

The sign of <InlineMath math="b" /> decides the direction of the sequence. ## First Exercise

This problem gives **two terms** of an arithmetic sequence at known positions and asks for the general formula. Each position produces one equation, and solving the two equations together gives the first term and the common difference.

Given an arithmetic sequence with the <InlineMath math="3" />rd term equal to <InlineMath math="9" /> and the <InlineMath math="6" />th term equal to <InlineMath math="18" />. Find the formula for the <InlineMath math="n" />th term.

### Solution to First Exercise

To determine the formula for the general term, we need to find the values of the **first term** <InlineMath math="(a)" /> and the common difference <InlineMath math="(b)" />.

<MathContainer>
  <BlockMath math="U_3 = a + 2b = 9" />
  <BlockMath math="U_6 = a + 5b = 18" />
</MathContainer>

We eliminate these equations to find the value of <InlineMath math="b" />:

<MathContainer>
  <BlockMath math="U_6 - U_3 = (a + 5b) - (a + 2b)" />
  <BlockMath math="18 - 9 = 3b" />
  <BlockMath math="9 = 3b" />
  <BlockMath math="b = 3" />
</MathContainer>

After finding <InlineMath math="b" />, we substitute it into the first equation to find <InlineMath math="a" />:

<MathContainer>
  <BlockMath math="a + 2b = 9" />
  <BlockMath math="a + 2(3) = 9" />
  <BlockMath math="a + 6 = 9" />
  <BlockMath math="a = 9 - 6 = 3" />
</MathContainer>

With <InlineMath math="a = 3" /> and <InlineMath math="b = 3" />, we can formulate the <InlineMath math="n" />th term:

<MathContainer>
  <BlockMath math="U_n = a + (n-1)b" />
  <BlockMath math="U_n = 3 + (n-1)3" />
  <BlockMath math="U_n = 3 + 3n - 3" />
  <BlockMath math="U_n = 3n" />
</MathContainer>

The formula for the general term of this sequence is <InlineMath math="U_n = 3n" />

As a check, substituting <InlineMath math="n=3" /> and <InlineMath math="n=6" /> must reproduce the two given terms:

<MathContainer>
  <BlockMath math="U_3=3(3)=9" />
  <BlockMath math="U_6=3(6)=18" />
</MathContainer>

## Second Exercise

Rudi saves money in a bank with a **constant monthly increase**. In the <InlineMath math="5" />th month, he saves <InlineMath math="\text{Rp}70{,}000.00" /> and in the <InlineMath math="9" />th month, Rudi saves <InlineMath math="\text{Rp}90{,}000.00" />.

1. What is the monthly increase in savings amount?

2. How much did Rudi deposit in the first month?

### Solution to Second Exercise

Each term is **the deposit for one month**, not the account balance. There are four months between month five and month nine, so the difference in their deposits contains four equal increases.

**Problem 1**. Write the deposits for months five and nine using the general term to find the monthly increase:

<MathContainer>
  <BlockMath math="U_5 = 70{,}000" />
  <BlockMath math="a + (5-1)b = 70{,}000" />
  <BlockMath math="a + 4b = 70{,}000 \text{ ... (equation 1)}" />
  <BlockMath math="U_9 = 90{,}000" />
  <BlockMath math="a + (9-1)b = 90{,}000" />
  <BlockMath math="a + 8b = 90{,}000 \text{ ... (equation 2)}" />
</MathContainer>

**Eliminating equations 1 and 2**:

<MathContainer>
  <BlockMath math="4b = 20{,}000" />
  <BlockMath math="b = 5{,}000" />
</MathContainer>

Therefore, the monthly increase in Rudi's savings is <InlineMath math="\text{Rp}5{,}000.00" />.

**Problem 2**. To find the first deposit, use <InlineMath math="b = 5{,}000" /> and **substitute** it into equation (1) to find <InlineMath math="a" />:

<MathContainer>
  <BlockMath math="a + 4b = 70{,}000" />
  <BlockMath math="a + 4(5{,}000) = 70{,}000" />
  <BlockMath math="a + 20{,}000 = 70{,}000" />
  <BlockMath math="a = 70{,}000 - 20{,}000" />
  <BlockMath math="a = 50{,}000" />
</MathContainer>

Therefore, Rudi deposited <InlineMath math="\text{Rp}50{,}000.00" /> in the first month.
