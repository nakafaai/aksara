## Pairing Terms to Add the Numbers from One to One Hundred

A well-known anecdote about Carl Friedrich Gauss illustrates a clever way to add many numbers. In the story, a teacher asks the students to add all the numbers from <InlineMath math="1" /> to <InlineMath math="100" />: <InlineMath math="1 + 2 + 3 + \dots + 98 + 99 + 100" />.

Gauss did not add the terms one by one. He paired the beginning of the list with the end. <Highlight>A sum formed from the terms</Highlight> of an _arithmetic sequence_ is called an **arithmetic series**.

For example, <InlineMath math="1, 2, 3, \dots, 100" /> is an arithmetic sequence with the first term <InlineMath math="a=1" /> and a common difference <InlineMath math="b=1" />. The corresponding arithmetic series is <InlineMath math="1 + 2 + 3 + \dots + 100" />.

### Gauss Pairing Method

Gauss paired terms from **opposite ends of the list**:

| Pair | From the beginning | From the end | Sum |
| --- | --- | --- | --- |
| 1 | 1 | 100 | 101 |
| 2 | 2 | 99 | 101 |
| 3 | 3 | 98 | 101 |
| … | … | … | … |
| 50 | 50 | 51 | 101 |

There are <InlineMath math="50" /> pairs, and every pair sums to <InlineMath math="101" />. Therefore, the total is <InlineMath math="50 \times 101 = 5050" />.

A second copy turned upside down fills the rest, with columns 6 down to 1. Each column pair is <InlineMath math="7" /> tall, so the two copies make a <InlineMath math="6 \times 7" /> rectangle and one copy is <InlineMath math="42 / 2 = 21" />.

## Finding the General Formula

We can use Gauss's method to derive a **general formula** for the sum of the first <InlineMath math="n" /> terms of an arithmetic series, usually denoted by <InlineMath math="S_n" />.

Begin with an arithmetic series:

<BlockMath math="\begin{aligned} S_n &amp;= U_1 + U_2 + U_3 \\ &amp;\quad{}+ \dots + U_{n-1} + U_n \end{aligned}" />

If written out with the first term <InlineMath math="(a)" /> and the common difference <InlineMath math="(b)" />:

<BlockMath math="\begin{aligned} S_n &amp;= a + (a+b) + (a+2b) + \dots \\ &amp;\quad{}+ (a+(n-2)b) + (a+(n-1)b) \end{aligned}" />

Write the same series <InlineMath math="S_n" /> in reverse order, from the last term to the first:

<BlockMath math="S_n = U_n + U_{n-1} + \dots + U_2 + U_1" />

Or:

<BlockMath math="\begin{aligned} S_n &amp;= (a+(n-1)b) + (a+(n-2)b) \\ &amp;\quad{}+ \dots + (a+b) + a \end{aligned}" />

Add the two representations of <InlineMath math="S_n" /> term by term:

<MathContainer>
  <BlockMath math="\begin{aligned} S_n &amp;= a + (a+b) \\ &amp;\quad{}+ \dots + (a+(n-2)b) \\ &amp;\quad{}+ (a+(n-1)b) \end{aligned}" />
  <BlockMath math="\begin{aligned} S_n &amp;= (a+(n-1)b) + (a+(n-2)b) \\ &amp;\quad{}+ \dots + (a+b) + a \end{aligned}" />
  <BlockMath math="\begin{aligned} 2S_n &amp;=[2a+(n-1)b] \\ &amp;\quad{}+[2a+(n-1)b] \\ &amp;\quad{}+\dots+[2a+(n-1)b] \\ &amp;\quad{}+[2a+(n-1)b] \end{aligned}" />
</MathContainer>

Each vertical pair has the same sum, <InlineMath math="2a + (n-1)b" />. Since each row contains <InlineMath math="n" /> terms, the addition produces <InlineMath math="n" /> identical pair sums.

So, we get:

<BlockMath math="2S_n = n \times (2a + (n-1)b)" />

By dividing both sides by <InlineMath math="2" />, we obtain the formula for the sum of the first <InlineMath math="n" /> terms of an arithmetic series:

<BlockMath math="S_n = \frac{n}{2} (2a + (n-1)b)" />

The derivation works for both even and odd <InlineMath math="n" />. When <InlineMath math="n" /> is odd, reversing and adding the series counts the middle term correctly because both copies of the series are included.

## Practical Formulas for Arithmetic Series

There are two main formulas commonly used to calculate <InlineMath math="S_n" />:

1.  If the **first term** <InlineMath math="a" /> and the **common difference** <InlineMath math="b" /> are known:

    <BlockMath math="S_n = \frac{n}{2}(2a + (n - 1)b)" />

2.  If the **first term** <InlineMath math="a" /> and the **last term** <InlineMath math="U_n" /> are known:
    Recall the formula for the <InlineMath math="n" />-th term is <InlineMath math="U_n = a + (n-1)b" />. Substituting this into the first formula:

    <MathContainer>
      <BlockMath math="S_n = \frac{n}{2}(a + a + (n - 1)b)" />
      <BlockMath math="S_n = \frac{n}{2}(a + U_n)" />
    </MathContainer>

    The second formula is **the number of terms times the average of the first and last terms**. That average is <InlineMath math="(a+U_n)/2" />, so the formula also works for an odd number of terms.

**Notation**:

- <InlineMath math="S_n" /> = Sum of the first <InlineMath math="n" /> terms
- <InlineMath math="n" /> = Number of terms
- <InlineMath math="a" /> = First term (<InlineMath math="U_1" />)
- <InlineMath math="b" /> = Common difference (difference between terms)
- <InlineMath math="U_n" /> = Term number <InlineMath math="n" />

Pair the numbers from <InlineMath math="1" /> to <InlineMath math="10" /> from both ends: <InlineMath math="1 + 10" />, <InlineMath math="2 + 9" />, and so on. Every pair has the same height <InlineMath math="11" />, and there are <InlineMath math="5" /> pairs, so <InlineMath math="1 + 2 + \cdots + 10 = 5 \cdot 11 = 55" />.

## Calculating Two Arithmetic Series

Both problems below supply the **terms needed** for a sum formula. Substitute the values first, then compare your result with the worked answer. In each problem decide first whether the series is arithmetic, because that choice fixes which formula applies.

### Adding the Integers from One to One Hundred

Recalculate the **sum of the series** <InlineMath math="1 + 2 + 3 + \dots + 98 + 99 + 100" />.

Given:

- First term <InlineMath math="a = 1" />
- Last term <InlineMath math="U_n = U_{100} = 100" />
- Number of terms <InlineMath math="n = 100" />

Since <InlineMath math="a" /> and <InlineMath math="U_n" /> are known, we use the second formula:

<MathContainer>
  <BlockMath math="S_n = \frac{n}{2}(a + U_n)" />
  <BlockMath math="S_{100} = \frac{100}{2}(1 + 100)" />
  <BlockMath math="S_{100} = 50(101)" />
  <BlockMath math="S_{100} = 5050" />
</MathContainer>

This agrees with the earlier pairing calculation.

### Using the First Term and Common Difference

Given the arithmetic series: <InlineMath math="13 + 16 + 19 + 22 + \dots" />. Calculate the sum of the **first** <InlineMath math="30" /> terms <InlineMath math="(S_{30})" />!

Given:

- First term <InlineMath math="a = 13" />
- Common difference <InlineMath math="b = 16 - 13 = 3" />
- Number of terms to sum <InlineMath math="n = 30" />

Since <InlineMath math="a" /> and <InlineMath math="b" /> are known, we use the first formula:

<MathContainer>
  <BlockMath math="S_n = \frac{n}{2}(2a + (n - 1)b)" />
  <BlockMath math="S_{30} = \frac{30}{2}[2(13) + (30 - 1)(3)]" />
  <BlockMath math="S_{30} = 15[26 + (29)(3)]" />
  <BlockMath math="S_{30} = 15(26 + 87)" />
  <BlockMath math="S_{30} = 15(113)" />
  <BlockMath math="S_{30} = 1695" />
</MathContainer>

So, the sum of the first <InlineMath math="30" /> terms of this series is <InlineMath math="1695" />.

## Application to Theater Seating

A theater has <InlineMath math="20" /> seats in the **first** row and <InlineMath math="4" /> more seats in each following row. The number of seats in row <InlineMath math="15" /> and the total in the first fifteen rows are:

<MathContainer>
  <BlockMath math="U_{15}=20+14\cdot4=76" />
  <BlockMath math="S_{15}=\frac{15}{2}(20+76)=720" />
</MathContainer>

The first result describes only row <InlineMath math="15" />. The second result describes all seats across the first fifteen rows, so the sequence term and the series sum answer different questions.

Run the series row by row for the theater. Each bar is the total <InlineMath math="S_n" /> after <InlineMath math="n" /> rows, from <InlineMath math="S_1 = 20" /> up to <InlineMath math="S_{15} = 720" />. The bars grow faster and faster because every new row is 4 seats longer than the last.

## Exercise

Calculate the **finite arithmetic series**:

### Solution

First determine **how many terms** the series contains. The common difference is <InlineMath math="5" />:

<MathContainer>
  <BlockMath math="\begin{aligned}103&amp;=8+5(n-1)\\95&amp;=5(n-1)\\19&amp;=n-1\\n&amp;=20\end{aligned}" />
  <BlockMath math="S_{20}=\frac{20}{2}(8+103)=1110" />
</MathContainer>

The sum is <InlineMath math="1110" />.
