## Set Operations Combine or Pick Out Elements

The **intersection** <InlineMath math="A \cap B" /> is the set of elements in both <InlineMath math="A" /> and <InlineMath math="B" />. The **union** <InlineMath math="A \cup B" /> is the set of elements in <InlineMath math="A" />, in <InlineMath math="B" />, or in both. The **complement** <InlineMath math="A'" /> is the set of elements of the universal set <InlineMath math="\xi" /> that are not in <InlineMath math="A" />. A Venn diagram shows these operations as regions. In the models here, you move a set to see the intersection, count elements with the inclusion-exclusion principle and solve survey problems.

### The Laws of De Morgan

**The complement of a union equals the intersection of the complements**, and the other way round:

<BlockMath math="(A \cup B)' = A' \cap B', \qquad (A \cap B)' = A' \cup B'" />

Check with the example above: <InlineMath math="A' = \{1, 3, 5, 7, 9\}" /> and <InlineMath math="B' = \{1, 2, 4, 5, 7, 8, 10\}" />, so <InlineMath math="A' \cap B' = \{1, 5, 7\}" />, the same as <InlineMath math="(A \cup B)'" />.

### Combined Operations

In a combined operation, **work out the brackets first**. For example, with <InlineMath math="C = \{1, 2, 3\}" />:

<BlockMath math="(A \cup B) \cap C = \{2, 3, 4, 6, 8, 9, 10\} \cap \{1, 2, 3\} = \{2, 3\}" />

## Number of Elements and the Principle of Inclusion and Exclusion

The notation <InlineMath math="n(A)" /> means **the number of elements** in set <InlineMath math="A" />. The number of elements in a union can be found without listing every element. This matters in survey problems, because the data is usually given as counts, not as lists of names. In the first example, <InlineMath math="n(A) = 5" />, <InlineMath math="n(B) = 3" /> and <InlineMath math="n(A \cap B) = 1" />.

### The Rule for the Number of Elements in a Union

When we add <InlineMath math="n(A)" /> and <InlineMath math="n(B)" />, the elements in the intersection are counted twice. So:

<BlockMath math="n(A \cup B) = n(A) + n(B) - n(A \cap B)" />

This model draws <InlineMath math="n(A \cup B)" /> for every value of <InlineMath math="n(A \cap B)" />. Change the sizes of both sets and notice that **the union shrinks as the intersection grows**.

## Three Sets

The same principle extends to **three sets**, but now there are more overlapping regions to account for. Each intersection of two sets is subtracted once, and the middle region is added back because it has been subtracted too many times:

<BlockMath math="n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(A \cap C) - n(B \cap C) + n(A \cap B \cap C)" />

## Common Mistakes about Operations on Sets

| Mistake | Why it's wrong | How to check |
| :--- | :--- | :--- |
| <InlineMath math="n(A \cup B) = n(A) + n(B)" /> always. | Elements of the intersection are counted twice, so subtract <InlineMath math="n(A \cap B)" />. | Check whether the sets overlap. |
| <InlineMath math="(A \cup B)' = A' \cup B'" />. | De Morgan's law turns a union into an intersection. | Test it with a list of elements. |
| Filling the only regions before the intersection. | The only regions depend on the intersection. | Fill from the middle outwards. |
| Forgetting elements outside every set. | The universal set includes elements that are in none of the sets. | All regions must add up to <InlineMath math="n(\xi)" />. |

The first mistake is the most common one in survey questions. **Subtract the intersection once**.

## Practice on Operations on Sets

These questions move from lists of elements to three-set problems. **Check every answer with the total of all regions**.

1. Given <InlineMath math="\xi = \{x : 1 \le x \le 12\}" />, <InlineMath math="P" /> is the set of multiples of <InlineMath math="3" /> and <InlineMath math="Q" /> is the set of even numbers. List <InlineMath math="P \cap Q" /> and <InlineMath math="(P \cup Q)'" />.

2. Given <InlineMath math="n(A) = 25" />, <InlineMath math="n(B) = 30" /> and <InlineMath math="n(A \cup B) = 45" />. Find <InlineMath math="n(A \cap B)" />.

3. In a group of <InlineMath math="40" /> people, <InlineMath math="22" /> drink coffee, <InlineMath math="19" /> drink tea and <InlineMath math="5" /> drink neither. How many drink both?

4. Show that <InlineMath math="(A \cap B)' = A' \cup B'" /> for the sets <InlineMath math="A" /> and <InlineMath math="B" /> in the first example of these notes.

### Solutions

**Solution 1**: <InlineMath math="P = \{3, 6, 9, 12\}" /> and <InlineMath math="Q = \{2, 4, 6, 8, 10, 12\}" />, so <InlineMath math="P \cap Q = \{6, 12\}" />. **The union** is <InlineMath math="\{2, 3, 4, 6, 8, 9, 10, 12\}" />, so <InlineMath math="(P \cup Q)' = \{1, 5, 7, 11\}" />.

**Solution 2**: Rearrange the inclusion-exclusion principle:

<BlockMath math="n(A \cap B) = 25 + 30 - 45 = 10" />

Check: <InlineMath math="25 + 30 - 10 = 45" />.

**Solution 3**: <InlineMath math="40 - 5 = 35" /> people drink at least one of the drinks:

<BlockMath math="n(K \cap T) = 22 + 19 - 35 = 6" />

Check: <InlineMath math="16 + 6 + 13 + 5 = 40" />.

**Solution 4**: <InlineMath math="A \cap B = \{6\}" />, so <InlineMath math="(A \cap B)'" /> holds every element except <InlineMath math="6" />. **The union of the complements** <InlineMath math="A' \cup B' = \{1, 2, 3, 4, 5, 7, 8, 9, 10\}" /> also holds every element except <InlineMath math="6" />, so the two sets are equal.
