## Operasi Set Menggabungkan atau Memilih Unsur

**Persilangan** <InlineMath math="A \cap B" /> ialah set unsur yang berada dalam kedua-dua <InlineMath math="A" /> dan <InlineMath math="B" />. **Kesatuan** <InlineMath math="A \cup B" /> ialah set unsur yang berada dalam <InlineMath math="A" />, dalam <InlineMath math="B" />, atau dalam kedua-duanya. **Pelengkap** <InlineMath math="A'" /> ialah set unsur dalam set semesta <InlineMath math="\xi" /> yang tidak berada dalam <InlineMath math="A" />. Gambar rajah Venn menunjukkan operasi ini sebagai kawasan. Dalam model di sini, kamu menggerakkan set untuk melihat persilangan, mengira unsur dengan prinsip inklusi dan eksklusi, dan menyelesaikan masalah tinjauan.

## Persilangan dan Kesatuan

Ambil <InlineMath math="\xi = \{1, 2, 3, \ldots, 10\}" />, <InlineMath math="A = \{2, 4, 6, 8, 10\}" /> dan <InlineMath math="B = \{3, 6, 9\}" />.

<MathContainer>
<BlockMath math="A \cap B = \{6\}" />
<BlockMath math="A \cup B = \{2, 3, 4, 6, 8, 9, 10\}" />
<BlockMath math="(A \cup B)' = \{1, 5, 7\}" />
</MathContainer>

Model ini melukis dua set sebagai bulatan dalam set semesta. Gerakkan set <InlineMath math="B" /> dan perhatikan bila **persilangan** wujud dan bila ia menjadi set kosong.

Apabila <InlineMath math="h \ge 3" />, lebar persilangan menjadi sifar dan <InlineMath math="A \cap B = \varnothing" />. Dua set seperti ini dipanggil **set terpisah**.

### Hukum de Morgan

**Pelengkap kesatuan sama dengan persilangan pelengkap**, dan sebaliknya:

<BlockMath math="(A \cup B)' = A' \cap B', \qquad (A \cap B)' = A' \cup B'" />

Semak dengan contoh di atas: <InlineMath math="A' = \{1, 3, 5, 7, 9\}" /> dan <InlineMath math="B' = \{1, 2, 4, 5, 7, 8, 10\}" />, jadi <InlineMath math="A' \cap B' = \{1, 5, 7\}" />, sama dengan <InlineMath math="(A \cup B)'" />.

### Operasi Gabungan

Dalam operasi gabungan, **selesaikan kurungan dahulu**. Contohnya, dengan <InlineMath math="C = \{1, 2, 3\}" />:

<BlockMath math="(A \cup B) \cap C = \{2, 3, 4, 6, 8, 9, 10\} \cap \{1, 2, 3\} = \{2, 3\}" />

## Bilangan Unsur dan Prinsip Inklusi dan Eksklusi

Tatatanda <InlineMath math="n(A)" /> bermaksud **bilangan unsur** dalam set <InlineMath math="A" />. Bilangan unsur sesuatu kesatuan boleh dikira tanpa menyenaraikan semua unsurnya. Cara ini penting dalam masalah tinjauan, kerana data biasanya diberi sebagai bilangan, bukan senarai nama. Dalam contoh awal, <InlineMath math="n(A) = 5" />, <InlineMath math="n(B) = 3" /> dan <InlineMath math="n(A \cap B) = 1" />.

### Rumus Bilangan Unsur Kesatuan

Apabila kita menjumlahkan <InlineMath math="n(A)" /> dan <InlineMath math="n(B)" />, unsur dalam persilangan dikira dua kali. Jadi:

<BlockMath math="n(A \cup B) = n(A) + n(B) - n(A \cap B)" />

Model ini melukis <InlineMath math="n(A \cup B)" /> bagi setiap nilai <InlineMath math="n(A \cap B)" />. Ubah saiz kedua-dua set dan perhatikan **kesatuan mengecil apabila persilangan membesar**.

## Tiga Set

Prinsip yang sama diperluas kepada **tiga set**, tetapi kini terdapat lebih banyak kawasan bertindih yang perlu diambil kira. Persilangan dua set ditolak sekali setiap satu, dan kawasan tengah ditambah semula kerana ia telah ditolak terlalu banyak kali:

<BlockMath math="n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(A \cap C) - n(B \cap C) + n(A \cap B \cap C)" />

### Lapan Kawasan Tiga Set

Tiga set yang bertindih menghasilkan lapan kawasan. **Mulakan dengan kawasan tengah** <InlineMath math="A \cap B \cap C" />, kemudian persilangan dua set, kemudian kawasan sahaja. Gerakkan set <InlineMath math="C" /> dalam model ini dan lihat bagaimana kawasan tengah muncul dan hilang.

## Kesilapan Lazim tentang Operasi Set

| Kesilapan | Sebab salah | Cara semak |
| :--- | :--- | :--- |
| <InlineMath math="n(A \cup B) = n(A) + n(B)" /> sentiasa. | Unsur persilangan dikira dua kali, jadi tolak <InlineMath math="n(A \cap B)" />. | Semak sama ada set bertindih. |
| <InlineMath math="(A \cup B)' = A' \cup B'" />. | Hukum de Morgan menukar kesatuan kepada persilangan. | Uji dengan senarai unsur. |
| Mengisi kawasan sahaja sebelum persilangan. | Bilangan kawasan sahaja bergantung pada persilangan. | Isi dari tengah ke luar. |
| Melupakan unsur di luar semua set. | Set semesta termasuk unsur yang tidak berada dalam mana-mana set. | Jumlah semua kawasan mesti sama dengan <InlineMath math="n(\xi)" />. |

Kesilapan pertama paling kerap muncul dalam soalan tinjauan. **Tolak persilangan sekali**.

## Latihan Operasi Set

Soalan ini bergerak dari senarai unsur ke masalah tiga set. **Semak setiap jawapan dengan jumlah semua kawasan**.

1. Diberi <InlineMath math="\xi = \{x : 1 \le x \le 12\}" />, <InlineMath math="P" /> ialah set gandaan <InlineMath math="3" /> dan <InlineMath math="Q" /> ialah set nombor genap. Senaraikan <InlineMath math="P \cap Q" /> dan <InlineMath math="(P \cup Q)'" />.

2. Diberi <InlineMath math="n(A) = 25" />, <InlineMath math="n(B) = 30" /> dan <InlineMath math="n(A \cup B) = 45" />. Cari <InlineMath math="n(A \cap B)" />.

3. Dalam sebuah kumpulan <InlineMath math="40" /> orang, <InlineMath math="22" /> orang minum kopi, <InlineMath math="19" /> orang minum teh dan <InlineMath math="5" /> orang tidak minum kedua-duanya. Berapa orang minum kedua-duanya?

4. Tunjukkan bahawa <InlineMath math="(A \cap B)' = A' \cup B'" /> bagi set <InlineMath math="A" /> dan <InlineMath math="B" /> dalam contoh awal nota ini.

### Penyelesaian

**Penyelesaian 1**: <InlineMath math="P = \{3, 6, 9, 12\}" /> dan <InlineMath math="Q = \{2, 4, 6, 8, 10, 12\}" />, jadi <InlineMath math="P \cap Q = \{6, 12\}" />. **Kesatuan** ialah <InlineMath math="\{2, 3, 4, 6, 8, 9, 10, 12\}" />, jadi <InlineMath math="(P \cup Q)' = \{1, 5, 7, 11\}" />.

**Penyelesaian 2**: Susun semula prinsip inklusi dan eksklusi:

<BlockMath math="n(A \cap B) = 25 + 30 - 45 = 10" />

Semak: <InlineMath math="25 + 30 - 10 = 45" />.

**Penyelesaian 3**: Seramai <InlineMath math="40 - 5 = 35" /> orang minum sekurang-kurangnya satu minuman:

<BlockMath math="n(K \cap T) = 22 + 19 - 35 = 6" />

Semak: <InlineMath math="16 + 6 + 13 + 5 = 40" />.

**Penyelesaian 4**: <InlineMath math="A \cap B = \{6\}" />, jadi <InlineMath math="(A \cap B)'" /> mengandungi semua unsur kecuali <InlineMath math="6" />. **Kesatuan pelengkap** <InlineMath math="A' \cup B' = \{1, 2, 3, 4, 5, 7, 8, 9, 10\}" /> juga mengandungi semua unsur kecuali <InlineMath math="6" />, jadi kedua-dua set sama.
