## From Rectangular Strips to a Definite Integral

The familiar formulas for rectangles and triangles do not apply directly to a region with a curved boundary.

**Definite integrals** handle such regions by <Highlight>accumulating the areas of increasingly narrow strips</Highlight>. A [Riemann sum](/en/subjects/mathematics/integral/riemann-sum) partitions the interval, approximates each strip with a rectangle, and takes the limit of their total area.

Suppose a function <InlineMath math="f(x)" /> bounds a region from <InlineMath math="x = a" /> to <InlineMath math="x = b" />. We divide <InlineMath math="[a, b]" /> into <InlineMath math="n" /> subintervals of width <InlineMath math="\Delta x" />.

For a continuous **nonnegative** function on <InlineMath math="[a,b]" /> with <InlineMath math="a<b" />, the area formula is:

<MathContainer>
<BlockMath math="A = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*) \cdot \Delta x" />
<BlockMath math="A = \int_{a}^{b} f(x) \, dx" />
</MathContainer>

## Determining Area Using Definite Integrals

To find an area, identify the **bounds and strip height** before finding an antiderivative. The example <InlineMath math="f(x)=x" /> on <InlineMath math="[0,2]" /> shows all three decisions.

| Decision | Example | Reason |
| --- | --- | --- |
| Bounds | <InlineMath math="a=0,\ b=2" /> | Given by the interval in the problem. |
| Height | <InlineMath math="x-0=x" /> | The curve lies above the axis on this interval. |
| Antiderivative | <InlineMath math="F(x)=x^2/2" /> | Differentiating returns <InlineMath math="x" />. |

The function <InlineMath math="F" /> is [an antiderivative](/en/subjects/mathematics/integral/definition-of-indefinite-integral) of <InlineMath math="f" />.

<BlockMath math="A=F(2)-F(0)=\frac{2^2}{2}-\frac{0^2}{2}=2" />

If the curve lies below the axis, use the **absolute value** as the height. If it changes sign, split the interval at its zeros so that areas do not cancel.

On <InlineMath math="[1,3]" />, factor the function as <InlineMath math="f(x)=x(x-4)" />. Every point in the interval satisfies <InlineMath math="x>0" /> and <InlineMath math="x-4<0" />, so <InlineMath math="f(x)<0" /> throughout the interval. The endpoint values <InlineMath math="f(1)=-3" /> and <InlineMath math="f(3)=-3" /> agree with this sign analysis.

**Geometric area** is nonnegative. Because the function is negative throughout this interval, its absolute value equals its negative, so:

<MathContainer>
<BlockMath math="A = \int_{1}^{3} |x^2 - 4x| \, dx" />
<BlockMath math="A = \int_{1}^{3} -(x^2 - 4x) \, dx" />
<BlockMath math="A = \int_{1}^{3} (-x^2 + 4x) \, dx" />
</MathContainer>

Now evaluate the definite integral:

<MathContainer>
<BlockMath math="A = \left[-\frac{x^3}{3} + 2x^2\right]_{1}^{3}" />
<BlockMath math="A = \left(-\frac{27}{3} + 18\right) - \left(-\frac{1}{3} + 2\right)" />
<BlockMath math="A = 9 - \frac{5}{3} = \frac{22}{3}" />
</MathContainer>

The area of that region is <InlineMath math="\frac{22}{3}" /> square units.

The expression <InlineMath math="x\sqrt{x^2 + 5}" /> suggests **substitution** because the factor <InlineMath math="x" /> is proportional to the derivative of the expression inside the square root.

Set <InlineMath math="u = x^2 + 5" />. Then <InlineMath math="du = 2x \, dx" />, so <InlineMath math="x \, dx = \frac{1}{2} du" />.

The limits must use the same variable as the integrand: <InlineMath math="x = 0" /> gives <InlineMath math="u = 5" />, while <InlineMath math="x = 2" /> gives <InlineMath math="u = 9" />.

Now our integral becomes:

<MathContainer>
<BlockMath math="A = \int_{0}^{2} x\sqrt{x^2 + 5} \, dx" />
<BlockMath math="A = \int_{5}^{9} \frac{1}{2}\sqrt{u} \, du" />
<BlockMath math="A = \frac{1}{2} \int_{5}^{9} u^{1/2} \, du" />
<BlockMath math="A = \frac{1}{2} \left[\frac{2}{3}u^{3/2}\right]_{5}^{9}" />
<BlockMath math="A = \frac{1}{3}\left[u^{3/2}\right]_{5}^{9}" />
<BlockMath math="A = \frac{1}{3}\left(27 - 5\sqrt{5}\right)" />
</MathContainer>

Here, <InlineMath math="9^{3/2} = (3^2)^{3/2} = 3^3 = 27" /> and <InlineMath math="5^{3/2} = 5 \cdot \sqrt{5}" />.

> When using substitution in definite integrals, don't forget to change the integration limits according to the new substitution variable.

## Exercises

Bounds may be given directly or found from intersections. Check the sign of the function over the interval so that the integral produces **geometric area**.

1. Calculate the area of the region bounded by the curve <InlineMath math="y = x^2 + 1" />, the <InlineMath math="x" />-axis, and the lines <InlineMath math="x = 0" /> and <InlineMath math="x = 2" />!

2. Determine the area of the region under the curve <InlineMath math="y = \frac{1}{x^2 + 1}" /> from <InlineMath math="x = 0" /> to <InlineMath math="x = 1" />!

3. Calculate the area of the region bounded by the curve <InlineMath math="y = 2x - x^2" /> and the <InlineMath math="x" />-axis!

### Worked Solutions

**Problem 1**. Since this function is **always positive**, we can directly set up the integral:

<BlockMath math="A = \int_{0}^{2} (x^2 + 1) \, dx" />

After we integrate and evaluate, we obtain:

<MathContainer>
<BlockMath math="A = \left[\frac{x^3}{3} + x\right]_{0}^{2}" />
<BlockMath math="A = \left(\frac{8}{3} + 2\right) - 0 = \frac{14}{3}" />
</MathContainer>

Therefore, the area of that region is <InlineMath math="\frac{14}{3}" /> square units.

**Problem 2**. The **antiderivative** used in this integral is <InlineMath math="\arctan(x)" /> because its derivative is <InlineMath math="\frac{1}{x^2 + 1}" />.

<MathContainer>
<BlockMath math="A = \int_{0}^{1} \frac{1}{x^2 + 1} \, dx" />
<BlockMath math="A = [\arctan(x)]_{0}^{1}" />
<BlockMath math="A = \arctan(1) - \arctan(0) = \frac{\pi}{4}" />
</MathContainer>

The area of that region is <InlineMath math="\frac{\pi}{4}" /> square units.

**Problem 3**. First, find where the curve intersects the <InlineMath math="x" />-axis:

<BlockMath math="2x - x^2 = 0 \Rightarrow x(2 - x) = 0" />

So the intersection points are at <InlineMath math="x = 0" /> and <InlineMath math="x = 2" />. Since this function is **positive between these two points**, we can directly integrate:

<MathContainer>
<BlockMath math="A = \int_{0}^{2} (2x - x^2) \, dx" />
<BlockMath math="A = \left[x^2 - \frac{x^3}{3}\right]_{0}^{2}" />
<BlockMath math="A = 4 - \frac{8}{3} = \frac{4}{3}" />
</MathContainer>

The area of that region is <InlineMath math="\frac{4}{3}" /> square units.

Problem 3 on the graph: <InlineMath math="y = 2x - x^2" /> starts at 0, rises to 1 at <InlineMath math="x = 1" /> and returns to 0 at <InlineMath math="x = 2" />. The region between the arch and the x-axis has area <InlineMath math="\int_0^2 (2x - x^2)\,dx = \tfrac43" />.
