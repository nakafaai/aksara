## Memperkirakan Luas dengan Persegi Panjang

Bayangkan sebidang tanah dengan salah satu sisi yang melengkung tidak beraturan. Untuk memperkirakan luas tanah tersebut, kita dapat membagi bidang tanah menjadi beberapa bagian berbentuk persegi panjang dengan lebar yang sama. Setelah itu, kita hitung luas setiap bagian dan menjumlahkan seluruh luas bagian.

**Jumlahan Riemann** menerapkan ide ini dengan membagi interval menjadi subinterval, <Highlight>memilih satu titik sampel pada setiap bagian</Highlight>, lalu menjumlahkan kontribusi persegi panjang bertanda. Untuk fungsi yang terintegralkan secara Riemann, hasil jumlahan mendekati integral tentu ketika lebar subinterval terbesar mendekati nol. Jika fungsi tidak negatif, akumulasi bertanda tersebut sama dengan luas di bawah kurva. Pada partisi sama lebar, semakin banyak persegi panjang yang digunakan, semakin sempit setiap persegi panjang. Namun, satu persegi panjang tambahan belum tentu membuat hasil jumlahan lebih dekat ke nilai integral tentu.

## Partisi Interval dan Lebar Subinterval

Empat besaran menentukan Jumlahan Riemann dengan **partisi sama lebar**:

| Simbol | Arti |
| :----- | :--- |
| <InlineMath math="[a,b]" /> | Interval yang dibagi menjadi beberapa subinterval |
| <InlineMath math="n" /> | Jumlah subinterval |
| <InlineMath math="\Delta x=\frac{b-a}{n}" /> | Lebar setiap subinterval |
| <InlineMath math="x_i^*" /> | Titik sampel pada subinterval ke-<InlineMath math="i" />, sehingga tinggi persegi panjangnya <InlineMath math="f(x_i^*)" /> |

Titik sampel dapat dipilih pada ujung kiri, ujung kanan, titik tengah, atau titik lain di dalam subinterval.

## Formula Jumlahan Riemann

Jika kita menggabungkan semua komponen tersebut, kita mendapatkan formula umum untuk Jumlahan Riemann:

<BlockMath math="R_n = \sum_{i=1}^{n} f(x_i^*) \Delta x" />

Notasi sigma menjumlahkan **kontribusi bertanda**: nilai fungsi di titik sampel dikalikan lebar subinterval. Jika nilai fungsi negatif, suku tersebut negatif. Luas geometris persegi panjang tetap tidak negatif.

## Jumlahan Titik Ujung Kiri pada Fungsi Linear

**Soal**: Tentukan Jumlahan Riemann dari fungsi <InlineMath math="f(x) = x" /> pada interval <InlineMath math="[0, 7]" /> dengan membaginya menjadi <InlineMath math="7" /> subinterval sama panjang dan menggunakan **titik ujung kiri** sebagai titik sampel.

<LineEquation
  showZAxis={false}
  title="Visualisasi Jumlahan Riemann"
  description={<>Grafik fungsi <InlineMath math="f(x)=x" /> dengan <InlineMath math="7" /> partisi persegi panjang menggunakan titik ujung kiri.</>}
  data={[
    {
      points: Array.from({ length: 8 }).map((_, i) => ({ x: i, y: i, z: 0 })),
      smooth: false,
      color: "#9333ea",
      showPoints: false,
      labels: [{ text: <InlineMath math="f(x)=x" />, at: 4, offset: [-1.5, 0.8, 0] }],
    },
    ...Array.from({ length: 7 }).map((_, i) => {
        const x_left = i;
        const x_right = i + 1;
        const y_height = x_left; // f(x) = x, jadi tinggi diambil dari x_left
        return {
            points: [
                {x: x_left, y: 0, z: 0},
                {x: x_right, y: 0, z: 0},
                {x: x_right, y: y_height, z: 0},
                {x: x_left, y: y_height, z: 0},
                {x: x_left, y: 0, z: 0},
            ],
            color: "#0284c7",
            smooth: false,
            showPoints: false,
        }
    })
  ]}
  cameraTarget={[3.5, 3.5, 0]}
  cameraPosition={[3.5, 3.5, 10]}
/>

**Langkah 1**: Tentukan lebar dan titik sampel.

Pada interval <InlineMath math="[0,7]" /> dengan <InlineMath math="n=7" />, setiap bagian memiliki lebar:

<BlockMath math="\Delta x=\frac{7-0}{7}=1" />

Karena memakai **ujung kiri**, titik sampelnya adalah <InlineMath math="0,1,2,3,4,5,6" />. Tinggi setiap persegi panjang sama dengan nilai sampel karena <InlineMath math="f(x)=x" />.

| Subinterval | Titik sampel | Tinggi | Kontribusi |
| --- | --- | --- | --- |
| <InlineMath math="[0,1]" /> | <InlineMath math="0" /> | <InlineMath math="f(0)=0" /> | <InlineMath math="0\cdot1=0" /> |
| <InlineMath math="[1,2]" /> | <InlineMath math="1" /> | <InlineMath math="f(1)=1" /> | <InlineMath math="1\cdot1=1" /> |
| <InlineMath math="[2,3]" /> | <InlineMath math="2" /> | <InlineMath math="f(2)=2" /> | <InlineMath math="2\cdot1=2" /> |
| <InlineMath math="[3,4]" /> | <InlineMath math="3" /> | <InlineMath math="f(3)=3" /> | <InlineMath math="3\cdot1=3" /> |
| <InlineMath math="[4,5]" /> | <InlineMath math="4" /> | <InlineMath math="f(4)=4" /> | <InlineMath math="4\cdot1=4" /> |
| <InlineMath math="[5,6]" /> | <InlineMath math="5" /> | <InlineMath math="f(5)=5" /> | <InlineMath math="5\cdot1=5" /> |
| <InlineMath math="[6,7]" /> | <InlineMath math="6" /> | <InlineMath math="f(6)=6" /> | <InlineMath math="6\cdot1=6" /> |

**Langkah 2**: Jumlahkan ketujuh kontribusi.

Kalikan setiap tinggi dengan lebar <InlineMath math="1" />, kemudian jumlahkan. Persegi panjang pertama berkontribusi nol karena tinggi pada <InlineMath math="x=0" /> adalah nol.

<BlockMath math="\begin{aligned}R_7&=\sum_{i=1}^7f(x_i^*)\Delta x\\&=(0+1+2+3+4+5+6)\cdot1\\&=21\end{aligned}" />

Jadi, hampiran luas dari ujung kiri adalah <InlineMath math="21" /> satuan luas.

> Pada <InlineMath math="[0,7]" />, fungsi <InlineMath math="f(x)=x" /> tidak negatif dan monoton naik secara ketat. Karena itu, persegi panjang dengan titik ujung kiri berada di bawah grafik dan menghasilkan taksiran luas yang terlalu kecil, sedangkan titik ujung kanan menghasilkan taksiran yang terlalu besar.

## Latihan

Setiap soal meminta luas yang dihampiri persegi panjang, jadi tetapkan banyak subinterval dan titik sampel pada setiap subinterval sebelum menjumlahkan sukunya. Pilihan titik sampel menentukan tinggi setiap persegi panjang, sehingga dua pilihan berbeda pada interval yang sama memberi hasil hampiran yang berbeda.

1.  Hitung Jumlahan Riemann untuk fungsi <InlineMath math="f(x) = x^2 + 1" /> pada interval <InlineMath math="[0, 4]" /> menggunakan <InlineMath math="4" /> subinterval dengan lebar yang sama dan titik sampel berupa **titik ujung kanan**.

### Pembahasan Terperinci

Kita akan menghitung Jumlahan Riemann untuk <InlineMath math="f(x) = x^2+1" /> pada <InlineMath math="[0,4]" /> dengan <InlineMath math="n=4" />.

<LineEquation
  showZAxis={false}
title="Visualisasi Latihan Jumlahan Riemann"
description={<>Grafik fungsi <InlineMath math="f(x)=x^2+1" /> dengan <InlineMath math="4" /> partisi persegi panjang menggunakan titik ujung kanan.</>}
cameraPosition={[2, 8.5, 21.5]}
cameraTarget={[2, 8.5, 0]}
data={[
    {
    smooth: false,
    points: Array.from({ length: 41 }).map((_, i) => {
        const x = i * 0.1;
        const y = x * x + 1;
        return { x, y, z: 0 };
    }),
    color: "#d97706",
    showPoints: false,
    labels: [{ text: <InlineMath math="f(x)=x^2+1" />, at: 20, offset: [-5.2, 6, 0] }],
    },
    ...Array.from({ length: 4 }).map((_, i) => {
        const x_left = i;
        const x_right = i + 1;
        const y_height = x_right * x_right + 1; // f(x) = x² + 1, ujung kanan
        return {
            points: [
                {x: x_left, y: 0, z: 0},
                {x: x_right, y: 0, z: 0},
                {x: x_right, y: y_height, z: 0},
                {x: x_left, y: y_height, z: 0},
                {x: x_left, y: 0, z: 0},
            ],
            color: "#0891b2",
            smooth: false,
            showPoints: false,
        }
    })
]}
/>

**Langkah 1**: Tentukan komponen utama.
Fungsi yang digunakan adalah <InlineMath math="f(x)=x^2+1" />, intervalnya <InlineMath math="[0,4]" />, dan jumlah partisinya <InlineMath math="n=4" />. Kita memilih **ujung kanan** untuk menentukan tinggi.

**Langkah 2**: Hitung lebar subinterval.

<BlockMath math="\Delta x = \frac{b-a}{n} = \frac{4-0}{4} = 1" />

**Langkah 3**: Tentukan titik sampel ujung kanan.

Subintervalnya adalah:

<BlockMath math="[0,1], [1,2], [2,3], [3,4]" />

Untuk metode ujung kanan, kita mengambil nilai <InlineMath math="x" /> di sisi kanan setiap subinterval:

<BlockMath math="x_1=1, x_2=2, x_3=3, x_4=4" />

**Langkah 4**: Hitung tinggi setiap persegi panjang.

Tinggi setiap persegi panjang ditentukan oleh nilai fungsi <InlineMath math="f(x) = x^2 + 1" /> di titik sampel ujung kanan:

<MathContainer>
<BlockMath math="f(x_1) = f(1) = 1^2 + 1 = 2" />
<BlockMath math="f(x_2) = f(2) = 2^2 + 1 = 5" />
<BlockMath math="f(x_3) = f(3) = 3^2 + 1 = 10" />
<BlockMath math="f(x_4) = f(4) = 4^2 + 1 = 17" />
</MathContainer>

**Langkah 5**: Hitung total Jumlahan Riemann.

Sekarang kita jumlahkan luas semua persegi panjang (<InlineMath math="\text{tinggi} \times \text{lebar}" />):

<MathContainer>
<BlockMath math="R_4 = \sum_{i=1}^{4} f(x_i^*) \Delta x" />
<BlockMath math="= [f(1) + f(2) + f(3) + f(4)] \cdot 1" />
<BlockMath math="= (2 + 5 + 10 + 17) \cdot 1" />
<BlockMath math="= 34" />
</MathContainer>

Jadi, Jumlahan Riemann untuk fungsi tersebut adalah <InlineMath math="34" />.
