## Understanding Tangent Line Equations

Picture a bicycle wheel resting on a level road. At that instant, the road touches the circular rim at exactly one point. The road itself models the **tangent line**, and the radius to the point of contact is perpendicular to it.

This lesson develops the equation of that line in three situations: when the point of tangency is known, when the slope is known, and when the line must pass through a point outside the circle.

The geometry is the same in each situation. A tangent touches the circle once, while the radius to the point of tangency supplies the perpendicular direction or the required distance.

## Tangent at a Known Point

When the point of tangency is known, first verify that the point lies on the circle. Then the radius to that point becomes a normal vector for the tangent.

For the circle <InlineMath math="x^2 + y^2 = r^2" /> and a point of tangency <InlineMath math="M(p, q)" /> on that circle, the **point-tangent form** is:

<BlockMath math="px + qy = r^2" />

Why does this formula work? The radius <InlineMath math="OM" /> has direction vector <InlineMath math="(p,q)" />. Because the tangent is perpendicular to <InlineMath math="OM" />, that same vector is normal to the tangent. Substituting <InlineMath math="M" /> gives <InlineMath math="p^2+q^2=r^2" />, so the line really does pass through the point of tangency.

For the circle <InlineMath math="(x-h)^2 + (y-k)^2 = r^2" /> with point of tangency <InlineMath math="M(p,q)" />, translate the same idea to center <InlineMath math="(h,k)" />:

<BlockMath math="(p-h)(x-h) + (q-k)(y-k) = r^2" />

> This form is efficient because it uses the radius directly as a normal vector. It also works when the tangent is vertical, where a slope calculation would fail.

## Distance Method for a Given Slope

If the slope is known but the intercept is not, use the defining distance condition: the perpendicular distance from the center to a tangent equals the radius.

Suppose the circle is <InlineMath math="(x-h)^2 + (y-k)^2 = r^2" /> and the tangent has slope <InlineMath math="m" />. Write the line as <InlineMath math="y=mx+c" />.

The **point-to-line distance formula** gives the distance from center <InlineMath math="(h,k)" /> to line <InlineMath math="mx-y+c=0" />:

<BlockMath math="d = \frac{|mh - k + c|}{\sqrt{m^2 + 1}}" />

For tangency, this distance must equal the radius:

<MathContainer>
  <BlockMath math="\frac{|mh - k + c|}{\sqrt{m^2 + 1}} = r" />
  <BlockMath math="|mh - k + c| = r\sqrt{m^2 + 1}" />
  <BlockMath math="mh - k + c = \pm r\sqrt{m^2 + 1}" />
</MathContainer>

Solving the absolute-value equation gives two intercepts:

<BlockMath math="c = k - mh \pm r\sqrt{m^2 + 1}" />

Therefore, the two parallel tangents are:

<BlockMath math="y = mx + k - mh \pm r\sqrt{m^2 + 1}" />

## Tangents Through an Outside Point

From a point outside a circle, exactly two tangent lines can be drawn. When both tangents have finite slopes, their slopes can be found from one quadratic equation.

<LineEquation
  title="Tangents Through an Outside Point"
  description="The repeated-intersection condition determines the two possible slopes."
  data={[
    {
      points: Array.from({ length: 361 }, (_, i) => {
        const angle = (i * Math.PI) / 180;
        const radius = 2.8;
        const h = -1, k = 1.5;
        return {
          x: h + radius * Math.cos(angle),
          y: k + radius * Math.sin(angle),
          z: 0,
        };
      }),
      color: "#9333ea",
      showPoints: false,
    },
    {
      points: [
        { x: -1, y: 1.5, z: 0 }
      ],
      color: "#ea580c",
      showPoints: true,
      labels: [{ text: "Center", at: 0, offset: [-0.8, -0.5, 0] }],
    },
    {
      points: [
        { x: 3.5, y: 4, z: 0 }
      ],
      color: "#d97706",
      showPoints: true,
      labels: [{ text: "Outside point", at: 0, offset: [0.5, 0.5, 0] }],
    },
    {
      points: (() => {
        // First tangent point - intersection of tangent line with circle
        const px = 3.5, py = 4, h = -1, k = 1.5, r = 2.8;

        // Calculate gradient of first tangent line
        const a = (h - px)*(h - px) - r*r;
        const b = -2*(h - px)*(k - py);
        const c = (k - py)*(k - py) - r*r;

        const discriminant = b*b - 4*a*c;
        const m1 = (-b + Math.sqrt(discriminant)) / (2*a);

        // Tangent line equation: y = m1*x + c1
        const c1 = py - m1*px;

        // Substitute y = m1*x + c1 into (x-h)^2 + (y-k)^2 = r^2
        // (x-h)^2 + (m1*x + c1 - k)^2 = r^2
        const A = 1 + m1*m1;
        const B = 2*m1*(c1 - k) - 2*h;
        const C = (c1 - k)*(c1 - k) + h*h - r*r;

        const discX = B*B - 4*A*C;

        // Two solutions, choose the one in the correct direction
        const x1 = (-B + Math.sqrt(discX)) / (2*A);
        const x2 = (-B - Math.sqrt(discX)) / (2*A);

        // Choose x that gives the correct tangent point
        // Tangent point should be between center and external point in certain direction
        const xTangent = Math.abs(x1 - h) < Math.abs(x2 - h) ? x1 : x2;
        const yTangent = m1 * xTangent + c1;

        return [{ x: xTangent, y: yTangent, z: 0 }];
      })(),
      color: "#0891b2",
      showPoints: true,
      labels: [{ text: <InlineMath math="S_1" />, at: 0, offset: [-0.5, -0.5, 0] }],
    },
    {
      points: (() => {
        // Second tangent point - intersection of tangent line with circle
        const px = 3.5, py = 4, h = -1, k = 1.5, r = 2.8;

        // Calculate gradient of second tangent line
        const a = (h - px)*(h - px) - r*r;
        const b = -2*(h - px)*(k - py);
        const c = (k - py)*(k - py) - r*r;

        const discriminant = b*b - 4*a*c;
        const m2 = (-b - Math.sqrt(discriminant)) / (2*a);

        // Tangent line equation: y = m2*x + c2
        const c2 = py - m2*px;

        // Substitute y = m2*x + c2 into (x-h)^2 + (y-k)^2 = r^2
        // (x-h)^2 + (m2*x + c2 - k)^2 = r^2
        const A = 1 + m2*m2;
        const B = 2*m2*(c2 - k) - 2*h;
        const C = (c2 - k)*(c2 - k) + h*h - r*r;

        const discX = B*B - 4*A*C;

        // Two solutions, choose the one in the correct direction
        const x1 = (-B + Math.sqrt(discX)) / (2*A);
        const x2 = (-B - Math.sqrt(discX)) / (2*A);

        // Choose x that gives the correct tangent point
        const xTangent = Math.abs(x1 - h) < Math.abs(x2 - h) ? x1 : x2;
        const yTangent = m2 * xTangent + c2;

        return [{ x: xTangent, y: yTangent, z: 0 }];
      })(),
      color: "#0891b2",
      showPoints: true,
      labels: [{ text: <InlineMath math="S_2" />, at: 0, offset: [0.5, 0.5, 0] }],
    },
    {
      points: (() => {
        // First tangent line
        const px = 3.5, py = 4, h = -1, k = 1.5, r = 2.8;
        const a = (h - px)*(h - px) - r*r;
        const b = -2*(h - px)*(k - py);
        const c = (k - py)*(k - py) - r*r;

        const discriminant = b*b - 4*a*c;
        const m1 = (-b + Math.sqrt(discriminant)) / (2*a);

        const c1 = py - m1*px;

        // Determine consistent line length
        const lineLength = 6;

        return [

        const b = -2*(h - px)*(k - py);
        const c = (k - py)*(k - py) - r*r;

        const discriminant = b*b - 4*a*c;
        const m2 = (-b - Math.sqrt(discriminant)) / (2*a);

Let the outside point be <InlineMath math="P(x_0,y_0)" /> and the circle be <InlineMath math="x^2+y^2=r^2" />. A nonvertical line through <InlineMath math="P" /> has slope <InlineMath math="m" />.

Its equation is <InlineMath math="y-y_0=m(x-x_0)" />, or <InlineMath math="y=mx-mx_0+y_0" />.

Substitute this expression into the circle. A tangent meets the circle at one repeated point, so the resulting quadratic in <InlineMath math="x" /> must have discriminant zero:

<MathContainer>
  <BlockMath math="x^2 + (mx - mx_0 + y_0)^2 = r^2" />
  <BlockMath math="(1 + m^2)x^2 + 2m(y_0 - mx_0)x + (y_0 - mx_0)^2 - r^2 = 0" />
</MathContainer>

After simplification, the discriminant condition becomes:

<BlockMath math="(x_0^2 - r^2)m^2 - 2x_0y_0m + (y_0^2 - r^2) = 0" />

Its roots are the slopes of the two nonvertical tangents. If a vertical tangent is possible, handle <InlineMath math="x=x_0" /> separately because it cannot be written as <InlineMath math="y=mx+c" />.

## Worked Example

Determine the two tangent lines to <InlineMath math="x^2+y^2=25" /> that pass through <InlineMath math="A(7,1)" />.

**Step** <InlineMath math="1" />: Check that <InlineMath math="A" /> lies outside the circle.

<BlockMath math="7^2 + 1^2 = 49 + 1 = 50 > 25 \quad \checkmark" />

**Step** <InlineMath math="2" />: Substitute <InlineMath math="x_0=7" />, <InlineMath math="y_0=1" />, and <InlineMath math="r^2=25" /> into the quadratic for <InlineMath math="m" />:

<MathContainer>
  <BlockMath math="(49 - 25)m^2 - 2(7)(1)m + (1 - 25) = 0" />
  <BlockMath math="24m^2 - 14m - 24 = 0" />
  <BlockMath math="12m^2 - 7m - 12 = 0" />
</MathContainer>

**Step** <InlineMath math="3" />: Solve the quadratic.

<BlockMath math="m = \frac{7 \pm \sqrt{49 + 576}}{24} = \frac{7 \pm \sqrt{625}}{24} = \frac{7 \pm 25}{24}" />

So <InlineMath math="m_1 = \frac{32}{24} = \frac{4}{3}" /> and <InlineMath math="m_2 = \frac{-18}{24} = -\frac{3}{4}" />.

**Step** <InlineMath math="4" />: Use each slope in the point-slope equation through <InlineMath math="A" />.

<MathContainer>
  <BlockMath math="y - 1 = \frac{4}{3}(x - 7) \Rightarrow 4x - 3y = 25" />
  <BlockMath math="y - 1 = -\frac{3}{4}(x - 7) \Rightarrow 3x + 4y = 25" />
</MathContainer>

## Practice

1. Determine the tangent line equation for circle <InlineMath math="x^2 + y^2 = 16" /> at point <InlineMath math="(2\sqrt{2}, 2\sqrt{2})" />.

2. Find the tangent line equations for circle <InlineMath math="x^2 + y^2 = 9" /> with slope <InlineMath math="-\frac{1}{2}" />.

3. Determine the tangent line equations for circle <InlineMath math="(x-3)^2 + (y-4)^2 = 25" /> that pass through point <InlineMath math="(11, 10)" />.

4. A circle has equation <InlineMath math="x^2 + y^2 - 6x - 8y = 0" />. Determine the tangent line equations parallel to line <InlineMath math="3x + 4y = 7" />.

### Worked Solutions

1. **Solution**:

   For circle <InlineMath math="x^2 + y^2 = 16" /> at point <InlineMath math="(2\sqrt{2}, 2\sqrt{2})" />, use the formula:

   <BlockMath math="x \cdot x_1 + y \cdot y_1 = r^2" />

   **Step** <InlineMath math="1" />: Substitute tangent point coordinates

   <MathContainer>
     <BlockMath math="x \cdot 2\sqrt{2} + y \cdot 2\sqrt{2} = 16" />
     <BlockMath math="2\sqrt{2}x + 2\sqrt{2}y = 16" />
   </MathContainer>

   **Step** <InlineMath math="2" />: Simplify by dividing both sides by <InlineMath math="2\sqrt{2}" />

   <BlockMath math="x + y = \frac{16}{2\sqrt{2}} = \frac{8}{\sqrt{2}} = \frac{8\sqrt{2}}{2} = 4\sqrt{2}" />

   So the tangent line equation is <InlineMath math="x + y = 4\sqrt{2}" />.

2. **Solution**:

   For gradient <InlineMath math="m = -\frac{1}{2}" /> and <InlineMath math="r = 3" />, use the formula:

   <BlockMath math="y = mx \pm r\sqrt{1 + m^2}" />

   **Step** <InlineMath math="1" />: Calculate value of <InlineMath math="\sqrt{1 + m^2}" />

   <BlockMath math="\sqrt{1 + m^2} = \sqrt{1 + \left(-\frac{1}{2}\right)^2} = \sqrt{1 + \frac{1}{4}} = \sqrt{\frac{5}{4}} = \frac{\sqrt{5}}{2}" />

   **Step** <InlineMath math="2" />: Substitute into formula

   <BlockMath math="y = -\frac{1}{2}x \pm 3 \cdot \frac{\sqrt{5}}{2} = -\frac{1}{2}x \pm \frac{3\sqrt{5}}{2}" />

   So the two tangent line equations are: <InlineMath math="y = -\frac{1}{2}x + \frac{3\sqrt{5}}{2}" /> and <InlineMath math="y = -\frac{1}{2}x - \frac{3\sqrt{5}}{2}" />.

3. **Solution**:

   Circle <InlineMath math="(x-3)^2 + (y-4)^2 = 25" /> has center <InlineMath math="(3,4)" /> and radius <InlineMath math="r = 5" />.

   **Step** <InlineMath math="1" />: Check position of point <InlineMath math="(11,10)" />

   <BlockMath math="(11-3)^2 + (10-4)^2 = 8^2 + 6^2 = 64 + 36 = 100 > 25" />

   Point is outside the circle.

   **Step** <InlineMath math="2" />: Translate the center to the origin. Relative to the center, point <InlineMath math="(11,10)" /> has coordinates <InlineMath math="(8,6)" />.

   **Step** <InlineMath math="3" />: Form the quadratic for the slopes from <InlineMath math="(8,6)" /> to circle <InlineMath math="x^2 + y^2 = 25" />.

   <MathContainer>
     <BlockMath math="(8^2 - 25)m^2 - 2(8)(6)m + (6^2 - 25) = 0" />
     <BlockMath math="39m^2 - 96m + 11 = 0" />
   </MathContainer>

   **Step** <InlineMath math="4" />: Solve it with the quadratic formula.

   <MathContainer>
     <BlockMath math="m = \frac{96 \pm \sqrt{96^2 - 4(39)(11)}}{2(39)} = \frac{96 \pm \sqrt{9216 - 1716}}{78}" />
     <BlockMath math="m = \frac{96 \pm \sqrt{7500}}{78} = \frac{96 \pm 50\sqrt{3}}{78}" />
   </MathContainer>

   **Step** <InlineMath math="5" />: Simplify the slopes and use point-slope form through <InlineMath math="(11,10)" />.

   <MathContainer>
     <BlockMath math="m_1 = \frac{48 + 25\sqrt{3}}{39} \quad \text{and} \quad m_2 = \frac{48 - 25\sqrt{3}}{39}" />
     <BlockMath math="y-10=\frac{48+25\sqrt{3}}{39}(x-11)" />
     <BlockMath math="y-10=\frac{48-25\sqrt{3}}{39}(x-11)" />
   </MathContainer>

   These are the two tangent lines through <InlineMath math="(11,10)" />.

4. **Solution**:

   **Step** <InlineMath math="1" />: Complete the square to write the circle in standard form.

   <MathContainer>
     <BlockMath math="x^2 + y^2 - 6x - 8y = 0" />
     <BlockMath math="(x^2 - 6x + 9) + (y^2 - 8y + 16) = 9 + 16" />
     <BlockMath math="(x-3)^2 + (y-4)^2 = 25" />
   </MathContainer>
