## Memahami Persamaan Garis Singgung

Bayangkan roda sepeda yang diam di atas jalan datar. Pada saat itu, jalan menyentuh lingkaran roda tepat di satu titik. Garis jalan itulah model **garis singgung**, sedangkan jari-jari menuju titik sentuh tegak lurus terhadapnya.

Kita akan menyusun persamaan garis tersebut dalam tiga keadaan: titik sentuh diketahui, gradien diketahui, atau garis harus melalui sebuah titik di luar lingkaran.

Gagasan geometrinya tetap sama pada ketiga keadaan. Garis singgung berpotongan dengan lingkaran di satu titik, sedangkan jari-jari menuju titik itu memberi arah tegak lurus atau jarak yang dibutuhkan.

## Garis Singgung di Titik yang Diketahui

Untuk lingkaran <InlineMath math="x^2+y^2=r^2" /> dan titik singgung <InlineMath math="M(p,q)" /> yang berada pada lingkaran, **bentuk titik-singgung** adalah:

<BlockMath math="px + qy = r^2" />

Mengapa rumus ini bekerja? Jari-jari <InlineMath math="OM" /> memiliki vektor arah <InlineMath math="(p,q)" />. Karena garis singgung tegak lurus terhadap <InlineMath math="OM" />, vektor tersebut menjadi vektor normal garis singgung. Ketika <InlineMath math="M" /> disubstitusikan, diperoleh <InlineMath math="p^2+q^2=r^2" />, sehingga garis itu benar-benar melalui titik sentuh.

Untuk lingkaran <InlineMath math="(x-h)^2+(y-k)^2=r^2" /> dengan titik singgung <InlineMath math="M(p,q)" />, terapkan gagasan yang sama terhadap pusat <InlineMath math="(h,k)" />:

<BlockMath math="(p-h)(x-h) + (q-k)(y-k) = r^2" />

> Bentuk ini efisien karena langsung memakai jari-jari sebagai vektor normal. Bentuk ini juga tetap berlaku untuk garis singgung vertikal, ketika perhitungan gradien tidak dapat digunakan.

Misalkan lingkarannya <InlineMath math="(x-h)^2+(y-k)^2=r^2" /> dan garis singgung memiliki gradien <InlineMath math="m" />. Tuliskan garis sebagai <InlineMath math="y=mx+c" />.

**Rumus jarak titik ke garis** memberi jarak dari pusat <InlineMath math="(h,k)" /> ke garis <InlineMath math="mx-y+c=0" />:

<BlockMath math="d = \frac{|mh - k + c|}{\sqrt{m^2 + 1}}" />

Karena garis menyinggung lingkaran, jarak ini harus sama dengan jari-jari:

<MathContainer>
  <BlockMath math="\frac{|mh - k + c|}{\sqrt{m^2 + 1}} = r" />
  <BlockMath math="|mh - k + c| = r\sqrt{m^2 + 1}" />
  <BlockMath math="mh - k + c = \pm r\sqrt{m^2 + 1}" />
</MathContainer>

Penyelesaian persamaan nilai mutlak menghasilkan dua titik potong sumbu:

<BlockMath math="c = k - mh \pm r\sqrt{m^2 + 1}" />

Jadi, dua garis singgung yang sejajar adalah:

<BlockMath math="y = mx + k - mh \pm r\sqrt{m^2 + 1}" />

## Garis Singgung melalui Titik di Luar Lingkaran

Dari sebuah titik di luar lingkaran dapat ditarik tepat dua garis singgung. Jika keduanya memiliki gradien berhingga, gradien tersebut dapat dicari melalui satu persamaan kuadrat.

        const px = 3.5, py = 4, h = -1, k = 1.5, r = 2.8;

        // Hitung gradien garis singgung pertama
        const a = (h - px)*(h - px) - r*r;
        const b = -2*(h - px)*(k - py);
        const c = (k - py)*(k - py) - r*r;

        const discriminant = b*b - 4*a*c;
        const m1 = (-b + Math.sqrt(discriminant)) / (2*a);

        const c1 = py - m1*px;

        const x2 = (-B - Math.sqrt(discX)) / (2*A);

        const yTangent = m1 * xTangent + c1;

        // Hitung gradien garis singgung kedua
        const a = (h - px)*(h - px) - r*r;

        const c = (k - py)*(k - py) - r*r;

Misalkan titik luarnya <InlineMath math="P(x_0,y_0)" /> dan lingkarannya <InlineMath math="x^2+y^2=r^2" />. Garis tak vertikal yang melalui <InlineMath math="P" /> memiliki gradien <InlineMath math="m" />.

Persamaannya ialah <InlineMath math="y-y_0=m(x-x_0)" />, atau <InlineMath math="y=mx-mx_0+y_0" />.

Substitusikan bentuk tersebut ke persamaan lingkaran. Garis singgung bertemu lingkaran pada satu titik kembar, sehingga persamaan kuadrat dalam <InlineMath math="x" /> harus memiliki diskriminan nol:

<MathContainer>
  <BlockMath math="x^2 + (mx - mx_0 + y_0)^2 = r^2" />
  <BlockMath math="(1 + m^2)x^2 + 2m(y_0 - mx_0)x + (y_0 - mx_0)^2 - r^2 = 0" />
</MathContainer>

Setelah disederhanakan, syarat diskriminan menjadi:

<BlockMath math="(x_0^2 - r^2)m^2 - 2x_0y_0m + (y_0^2 - r^2) = 0" />

Akar-akarnya adalah gradien kedua garis singgung tak vertikal. Jika mungkin ada garis singgung vertikal, periksa <InlineMath math="x=x_0" /> secara terpisah karena garis itu tidak dapat ditulis sebagai <InlineMath math="y=mx+c" />.

## Contoh dengan Pembahasan

Tentukan kedua garis singgung lingkaran <InlineMath math="x^2+y^2=25" /> yang melalui titik <InlineMath math="A(7,1)" />.

**Langkah** <InlineMath math="1" />: Pastikan <InlineMath math="A" /> berada di luar lingkaran.

<BlockMath math="7^2 + 1^2 = 49 + 1 = 50 > 25 \quad \checkmark" />

**Langkah** <InlineMath math="2" />: Substitusikan <InlineMath math="x_0=7" />, <InlineMath math="y_0=1" />, dan <InlineMath math="r^2=25" /> ke persamaan kuadrat untuk <InlineMath math="m" />:

<MathContainer>
  <BlockMath math="(49 - 25)m^2 - 2(7)(1)m + (1 - 25) = 0" />
  <BlockMath math="24m^2 - 14m - 24 = 0" />
  <BlockMath math="12m^2 - 7m - 12 = 0" />
</MathContainer>

**Langkah** <InlineMath math="3" />: Selesaikan persamaan kuadratnya.

<BlockMath math="m = \frac{7 \pm \sqrt{49 + 576}}{24} = \frac{7 \pm \sqrt{625}}{24} = \frac{7 \pm 25}{24}" />

Jadi <InlineMath math="m_1 = \frac{32}{24} = \frac{4}{3}" /> dan <InlineMath math="m_2 = \frac{-18}{24} = -\frac{3}{4}" />.

**Langkah** <InlineMath math="4" />: Gunakan setiap gradien pada persamaan titik-gradien yang melalui <InlineMath math="A" />.

<MathContainer>
  <BlockMath math="y - 1 = \frac{4}{3}(x - 7) \Rightarrow 4x - 3y = 25" />
  <BlockMath math="y - 1 = -\frac{3}{4}(x - 7) \Rightarrow 3x + 4y = 25" />
</MathContainer>

## Latihan

1. Tentukan persamaan garis singgung lingkaran <InlineMath math="x^2 + y^2 = 16" /> di titik <InlineMath math="(2\sqrt{2}, 2\sqrt{2})" />.

2. Carilah kedua persamaan garis singgung lingkaran <InlineMath math="x^2 + y^2 = 9" /> yang bergradien <InlineMath math="-\frac{1}{2}" />.

3. Tentukan kedua persamaan garis singgung lingkaran <InlineMath math="(x-3)^2 + (y-4)^2 = 25" /> yang melalui titik <InlineMath math="(11, 10)" />.

4. Sebuah lingkaran memiliki persamaan <InlineMath math="x^2 + y^2 - 6x - 8y = 0" />. Tentukan kedua persamaan garis singgung yang sejajar dengan garis <InlineMath math="3x + 4y = 7" />.

### Pembahasan Lengkap

1. **Penyelesaian**:

   Untuk lingkaran <InlineMath math="x^2 + y^2 = 16" /> di titik <InlineMath math="(2\sqrt{2}, 2\sqrt{2})" />, gunakan rumus:

   <BlockMath math="x \cdot x_1 + y \cdot y_1 = r^2" />

   **Langkah** <InlineMath math="1" />: Substitusi koordinat titik singgung

   <MathContainer>
     <BlockMath math="x \cdot 2\sqrt{2} + y \cdot 2\sqrt{2} = 16" />
     <BlockMath math="2\sqrt{2}x + 2\sqrt{2}y = 16" />
   </MathContainer>

   **Langkah** <InlineMath math="2" />: Sederhanakan dengan membagi kedua ruas dengan <InlineMath math="2\sqrt{2}" />

   <BlockMath math="x + y = \frac{16}{2\sqrt{2}} = \frac{8}{\sqrt{2}} = \frac{8\sqrt{2}}{2} = 4\sqrt{2}" />

   Jadi persamaan garis singgungnya adalah <InlineMath math="x + y = 4\sqrt{2}" />.

2. **Penyelesaian**:

   Untuk gradien <InlineMath math="m = -\frac{1}{2}" /> dan <InlineMath math="r = 3" />, gunakan rumus:

   <BlockMath math="y = mx \pm r\sqrt{1 + m^2}" />

   **Langkah** <InlineMath math="1" />: Hitung nilai <InlineMath math="\sqrt{1 + m^2}" />

   <BlockMath math="\sqrt{1 + m^2} = \sqrt{1 + \left(-\frac{1}{2}\right)^2} = \sqrt{1 + \frac{1}{4}} = \sqrt{\frac{5}{4}} = \frac{\sqrt{5}}{2}" />

   **Langkah** <InlineMath math="2" />: Substitusi ke rumus

   <BlockMath math="y = -\frac{1}{2}x \pm 3 \cdot \frac{\sqrt{5}}{2} = -\frac{1}{2}x \pm \frac{3\sqrt{5}}{2}" />

   Jadi dua persamaan garis singgung: <InlineMath math="y = -\frac{1}{2}x + \frac{3\sqrt{5}}{2}" /> dan <InlineMath math="y = -\frac{1}{2}x - \frac{3\sqrt{5}}{2}" />.

3. **Penyelesaian**:
