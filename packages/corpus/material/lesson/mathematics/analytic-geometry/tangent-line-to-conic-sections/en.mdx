## Concept of Tangent Lines

A ruler placed against a smooth curve can meet it at just one point without crossing it nearby. The line along the ruler models a **tangent line** at that point.

For the conic sections in this lesson, a tangent line meets the curve at one repeated intersection point. A secant line, by contrast, cuts the curve at two distinct points.

On the parabola <InlineMath math="y = x^2" />, the distinction is visible: a tangent has one repeated point of intersection, while a secant has two different intersections.

For conic sections like parabolas, ellipses, and hyperbolas, there are several ways to determine the equation of their tangent lines depending on the information we have.

## Point on the Curve

When the point of tangency is known, implicit differentiation gives the slope there. Combining that slope with the point-slope equation produces a direct point form.

### Point Form from Implicit Differentiation

For a point <InlineMath math="T(x_1, y_1)" /> on a conic, the resulting point form replaces each squared coordinate by a product with the corresponding tangent-point coordinate. Linear terms are shared symmetrically between the variable point and the tangent point. This compact form comes from the derivative calculation. Before using it, check that <InlineMath math="T" /> lies on the curve.

For example, if we have a parabola <InlineMath math="y^2 = 4px" /> and tangent point <InlineMath math="T(x_1, y_1)" />, then the tangent line equation becomes:

<BlockMath math="yy_1 = 2p(x + x_1)" />

Take an example of parabola <InlineMath math="y^2 = 8x" /> at point <InlineMath math="(2, 4)" />.

From parabola <InlineMath math="y^2 = 8x" />, we know <InlineMath math="4p = 8" /> so <InlineMath math="p = 2" />. The tangent line at point <InlineMath math="(2, 4)" /> is:

<MathContainer>
  <BlockMath math="y \cdot 4 = 2 \cdot 2 \cdot (x + 2)" />
  <BlockMath math="4y = 4(x + 2)" />
  <BlockMath math="y = x + 2" />
</MathContainer>

> The point form is valid only after the stated point has been verified on the conic. It packages the derivative calculation into a reusable algebraic substitution.

## Given Slope

Sometimes we don't know the tangent point, but we know the **slope** or gradient of the tangent line. In cases like this, we substitute the line equation with gradient <InlineMath math="m" /> into the conic section equation.

For example, we want to find the tangents to <InlineMath math="4x^2 - 9y^2 = 36" /> that are perpendicular to <InlineMath math="x + 4y + 10 = 0" />.

First determine the required tangent slope. The line <InlineMath math="x + 4y + 10 = 0" /> has slope <InlineMath math="m_g = -\frac{1}{4}" />, so every perpendicular tangent must have slope <InlineMath math="m_s = 4" />.

A line with slope <InlineMath math="m" /> has the form <InlineMath math="y = mx + c" />. Substitute it into the hyperbola equation:

<MathContainer>
  <BlockMath math="4x^2 - 9(4x + c)^2 = 36" />
  <BlockMath math="4x^2 - 9(16x^2 + 8cx + c^2) = 36" />
  <BlockMath math="-140x^2 - 72cx - 9c^2 - 36 = 0" />
</MathContainer>

For a tangent line, the discriminant must be zero:

<MathContainer>
  <BlockMath math="D = (-72c)^2 - 4(-140)(-9c^2-36) = 0" />
  <BlockMath math="5184c^2 - 5040c^2 - 20160 = 0" />
  <BlockMath math="144c^2 = 20160" />
  <BlockMath math="c = \pm 2\sqrt{35}" />
</MathContainer>

Therefore the two tangent lines are <InlineMath math="y = 4x + 2\sqrt{35}" /> and <InlineMath math="y = 4x - 2\sqrt{35}" />.

## Tangents Through an External Point

Depending on the conic and the point's location, zero, one, or two real tangents can pass through a given point. In the example below, there are two. Drawing tangents from a point outside a circle is a familiar special case.

For example, take parabola <InlineMath math="y^2 = 8x" /> with point <InlineMath math="A(2, 5)" />. From point <InlineMath math="A" />, we can draw two different tangent lines to the parabola.

For an external point, the polar equation gives the **chord of contact**, the line joining the two tangent points. It is not itself either tangent. For <InlineMath math="y^2 = 8x" /> and <InlineMath math="A(2,5)" />, the polar is:

<BlockMath math="yy_1 = 4(x + x_1)" />

Substitute <InlineMath math="x_1 = 2" /> and <InlineMath math="y_1 = 5" />:

<MathContainer>
  <BlockMath math="5y = 4(x + 2)" />
  <BlockMath math="5y = 4x + 8" />
  <BlockMath math="y = \frac{4x + 8}{5}" />
</MathContainer>

Now we substitute into the parabola equation to find the tangent points:

<MathContainer>
  <BlockMath math="\left(\frac{4x + 8}{5}\right)^2 = 8x" />
  <BlockMath math="\frac{16x^2 + 64x + 64}{25} = 8x" />
  <BlockMath math="16x^2 + 64x + 64 = 200x" />
  <BlockMath math="16x^2 - 136x + 64 = 0" />
  <BlockMath math="2x^2 - 17x + 8 = 0" />
</MathContainer>

Using the quadratic formula, we get <InlineMath math="x_1 = \frac{1}{2}" /> and <InlineMath math="x_2 = 8" />. The tangent points are <InlineMath math="(\frac{1}{2}, 2)" /> and <InlineMath math="(8, 8)" />. Joining each one to <InlineMath math="A(2,5)" /> gives the two tangents <InlineMath math="y = 2x + 1" /> and <InlineMath math="y = \frac{1}{2}x + 4" />.

## Formula Summary

The table collects the point-form tangent equations used in this lesson.

| Conic Section | Tangent Line Equation |
|---|---|
| <InlineMath math="y^2 = 4px" /> | <InlineMath math="yy_1 = 2p(x + x_1)" /> |
| <InlineMath math="x^2 = 4py" /> | <InlineMath math="xx_1 = 2p(y + y_1)" /> |
| <InlineMath math="(x - h)^2 = 4p(y - k)" /> | <InlineMath math="(x - h)(x_1 - h) = 2p((y - k) + (y_1 - k))" /> |
| <InlineMath math="(y - k)^2 = 4p(x - h)" /> | <InlineMath math="(y - k)(y_1 - k) = 2p((x - h) + (x_1 - h))" /> |
| <InlineMath math="\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1" /> | <InlineMath math="\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1" /> |
| <InlineMath math="\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1" /> | <InlineMath math="\frac{xx_1}{a^2} - \frac{yy_1}{b^2} = 1" /> |
| <InlineMath math="\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1" /> | <InlineMath math="\frac{yy_1}{a^2} - \frac{xx_1}{b^2} = 1" /> |
| <InlineMath math="\frac{(x-h)^2}{a^2} + \frac{(y-k)^2}{b^2} = 1" /> | <InlineMath math="\frac{(x-h)(x_1-h)}{a^2} + \frac{(y-k)(y_1-k)}{b^2} = 1" /> |
| <InlineMath math="\frac{(x-h)^2}{a^2} - \frac{(y-k)^2}{b^2} = 1" /> | <InlineMath math="\frac{(x-h)(x_1-h)}{a^2} - \frac{(y-k)(y_1-k)}{b^2} = 1" /> |
| <InlineMath math="\frac{(y-k)^2}{a^2} - \frac{(x-h)^2}{b^2} = 1" /> | <InlineMath math="\frac{(y-k)(y_1-k)}{a^2} - \frac{(x-h)(x_1-h)}{b^2} = 1" /> |

> These formulas are the derivative-based point forms for common standard conics. Always verify first that the stated tangent point lies on the conic.

## Exercises

1. Find the tangent line equation of parabola <InlineMath math="y^2 = 12x" /> at point <InlineMath math="(3, 6)" />.

2. Find the equations of the tangents to <InlineMath math="4x^2 - 9y^2 = 36" /> that are perpendicular to <InlineMath math="x + 4y + 10 = 0" />.

3. Find the equations of the tangents to <InlineMath math="\frac{x^2}{9} + \frac{y^2}{4} = 1" /> that pass through <InlineMath math="A(1, 3)" />.

4. Find the equations of the tangents to <InlineMath math="y^2 = 8x" /> that pass through <InlineMath math="A(2, 5)" />.

### Worked Solutions

1. **Solution**:

   Given: parabola <InlineMath math="y^2 = 12x" /> with tangent point <InlineMath math="(3, 6)" />.

   From equation <InlineMath math="y^2 = 12x" />, we get <InlineMath math="4p = 12" /> so <InlineMath math="p = 3" />.

   Use the parabola tangent line formula:

   <MathContainer>
     <BlockMath math="yy_1 = 2p(x + x_1)" />
     <BlockMath math="y \cdot 6 = 2 \cdot 3 \cdot (x + 3)" />
     <BlockMath math="6y = 6(x + 3)" />
     <BlockMath math="6y = 6x + 18" />
     <BlockMath math="y = x + 3" />
   </MathContainer>

   So the tangent line equation is <InlineMath math="y = x + 3" />.

2. **Solution**:

   Given: hyperbola <InlineMath math="4x^2 - 9y^2 = 36" /> or <InlineMath math="\frac{x^2}{9} - \frac{y^2}{4} = 1" />.

   Line <InlineMath math="x + 4y + 10 = 0" /> has gradient <InlineMath math="m = -\frac{1}{4}" />.

   Since the tangent line is perpendicular to that line, then the tangent line gradient is:

   <BlockMath math="m_s = -\frac{1}{m} = -\frac{1}{-\frac{1}{4}} = 4" />

   Hyperbola tangent line formula with gradient <InlineMath math="m" />:

   <BlockMath math="y = mx \pm \sqrt{a^2m^2 - b^2}" />

   With <InlineMath math="a^2 = 9" />, <InlineMath math="b^2 = 4" />, and <InlineMath math="m = 4" />:

   <MathContainer>
     <BlockMath math="y = 4x \pm \sqrt{9 \cdot 16 - 4}" />
     <BlockMath math="y = 4x \pm \sqrt{144 - 4}" />
     <BlockMath math="y = 4x \pm \sqrt{140}" />
     <BlockMath math="y = 4x \pm 2\sqrt{35}" />
   </MathContainer>

   So the tangent line equations are <InlineMath math="y = 4x + 2\sqrt{35}" /> or <InlineMath math="y = 4x - 2\sqrt{35}" />.

3. **Solution**:

   Given: ellipse <InlineMath math="\frac{x^2}{9} + \frac{y^2}{4} = 1" /> and point <InlineMath math="A(1, 3)" />.

   First check whether point <InlineMath math="A(1, 3)" /> is on the ellipse:

   <BlockMath math="\frac{1^2}{9} + \frac{3^2}{4} = \frac{1}{9} + \frac{9}{4} = \frac{4 + 81}{36} = \frac{85}{36} > 1" />

   Since <InlineMath math="\frac{85}{36} > 1" />, point <InlineMath math="A" /> is outside the ellipse.

   Write a line through <InlineMath math="A(1,3)" /> with slope <InlineMath math="m" />:

   <BlockMath math="y-3=m(x-1)" />

   Substituting this line into the ellipse and requiring a zero discriminant gives:

   <MathContainer>
     <BlockMath math="4x^2 + 9(mx+3-m)^2 = 36" />
     <BlockMath math="8m^2 + 6m - 5 = 0" />
     <BlockMath math="(4m+5)(2m-1)=0" />
     <BlockMath math="m=-\frac{5}{4} \quad \text{or} \quad m=\frac{1}{2}" />
   </MathContainer>

   Insert each slope into the point-slope equation:

   <MathContainer>
     <BlockMath math="y-3=-\frac{5}{4}(x-1) \quad \Longrightarrow \quad 5x+4y-17=0" />
     <BlockMath math="y-3=\frac{1}{2}(x-1) \quad \Longrightarrow \quad x-2y+5=0" />
   </MathContainer>

   Thus the two tangent lines are <InlineMath math="5x+4y-17=0" /> and <InlineMath math="x-2y+5=0" />.

4. **Solution**:

   Given: parabola <InlineMath math="y^2 = 8x" /> and point <InlineMath math="A(2, 5)" />.

   First check whether point <InlineMath math="A(2, 5)" /> is on the parabola:

   <BlockMath math="5^2 = 25 \neq 8 \cdot 2 = 16" />

   Point <InlineMath math="A" /> is outside the parabola.

   Use the parabola polar equation with <InlineMath math="p = 2" />:

   <BlockMath math="yy_1 = 4(x + x_1)" />

   Substitute <InlineMath math="x_1 = 2" /> and <InlineMath math="y_1 = 5" />:

   <MathContainer>
     <BlockMath math="5y = 4(x + 2)" />
     <BlockMath math="5y = 4x + 8" />
     <BlockMath math="y = \frac{4x + 8}{5}" />
   </MathContainer>

   Substitute into the parabola equation:

   <MathContainer>
     <BlockMath math="\left(\frac{4x + 8}{5}\right)^2 = 8x" />
     <BlockMath math="\frac{(4x + 8)^2}{25} = 8x" />
     <BlockMath math="(4x + 8)^2 = 200x" />
     <BlockMath math="16x^2 + 64x + 64 = 200x" />
     <BlockMath math="16x^2 - 136x + 64 = 0" />
     <BlockMath math="2x^2 - 17x + 8 = 0" />
   </MathContainer>

   Use the quadratic formula:

   <BlockMath math="x = \frac{17 \pm \sqrt{289 - 64}}{4} = \frac{17 \pm \sqrt{225}}{4} = \frac{17 \pm 15}{4}" />

   So <InlineMath math="x_1 = \frac{1}{2}" /> and <InlineMath math="x_2 = 8" />.

   The tangent points are at <InlineMath math="(\frac{1}{2}, 2)" /> and <InlineMath math="(8, 8)" />.

   Tangent line equation through <InlineMath math="(\frac{1}{2}, 2)" />:

   <BlockMath math="y - 2 = \frac{2 - 5}{\frac{1}{2} - 2}(x - \frac{1}{2}) = \frac{-3}{-\frac{3}{2}}(x - \frac{1}{2}) = 2(x - \frac{1}{2})" />

   So <InlineMath math="y = 2x + 1" />.

   Tangent line equation through <InlineMath math="(8, 8)" />:

   <BlockMath math="y - 8 = \frac{8 - 5}{8 - 2}(x - 8) = \frac{3}{6}(x - 8) = \frac{1}{2}(x - 8)" />

   So <InlineMath math="y = \frac{1}{2}x + 4" />.

   The tangent line equations are <InlineMath math="y = 2x + 1" /> and <InlineMath math="y = \frac{1}{2}x + 4" />.
