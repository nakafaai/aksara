## Properties of Function Composition

Function composition applies functions in sequence. The examples below show how changing the order can change the result, while changing only the grouping does not:

<MathContainer>
  <BlockMath math="f(x) = 2x + 1" />
  <BlockMath math="g(x) = x^2 + 4" />
  <BlockMath math="h(x) = \frac{1}{x+1}" />
</MathContainer>

Their domains are:

<BlockMath math="D_f=D_g=\mathbb{R}\qquad D_h=\mathbb{R}\setminus\{-1\}" />

### Not Commutative Property

In a composition, each function receives the output of the function to its right. Reversing the order therefore usually produces a different composite function.

In general, <InlineMath math="(f \circ g)(x)" /> is **not equal to** <InlineMath math="(g \circ f)(x)" />.

**Example:**

Compare <InlineMath math="(g \circ f)(x)" /> and <InlineMath math="(f \circ g)(x)" />.

1.  **Calculating <InlineMath math="(g \circ f)(x)" />:**

    <MathContainer>
      <BlockMath math="(g \circ f)(x) = g(f(x)) = g(2x+1)" />
      <BlockMath math="g(2x+1) = (2x+1)^2 + 4 = (4x^2 + 4x + 1) + 4 = 4x^2 + 4x + 5" />
    </MathContainer>

2.  **Calculating <InlineMath math="(f \circ g)(x)" />:**

    <MathContainer>
      <BlockMath math="(f \circ g)(x) = f(g(x)) = f(x^2+4)" />
      <BlockMath math="f(x^2+4) = 2(x^2+4) + 1 = (2x^2 + 8) + 1 = 2x^2 + 9" />
    </MathContainer>

The two polynomial expressions have different coefficients, so they are not the same function. A single input also gives a direct counterexample:

<BlockMath math="(g\circ f)(0)=5\neq9=(f\circ g)(0)" />

The counterexample proves that <InlineMath math="g\circ f\neq f\circ g" /> as functions. Other pairs must be checked in the same way. Composition is not commutative in general.

### Associative Property

If three functions have compatible domains and codomains, changing only the grouping does not change the result. The order of the **functions** must remain the same, and both sides are compared on inputs for which the compositions are defined.

Mathematically, for functions <InlineMath math="f" />, <InlineMath math="g" />, and <InlineMath math="h" />, the following holds:

<BlockMath math="((f \circ g) \circ h)(x) = (f \circ (g \circ h))(x)" />

We may first form <InlineMath math="f\circ g" /> and then compose that function with <InlineMath math="h" />, or first form <InlineMath math="g\circ h" /> and then compose <InlineMath math="f" /> with the result. On any input for which both sides are defined, both expressions apply <InlineMath math="h" />, then <InlineMath math="g" />, then <InlineMath math="f" />.

**Example:**

Check if <InlineMath math="((f \circ g) \circ h)(x) = (f \circ (g \circ h))(x)" />.

1.  **Calculating <InlineMath math="((f \circ g) \circ h)(x)" />:**

    We already know <InlineMath math="(f \circ g)(x) = 2x^2 + 9" />.

    <MathContainer>
      <BlockMath math="((f \circ g) \circ h)(x) = (f \circ g)(h(x)) = (f \circ g)(\frac{1}{x+1})" />
      <BlockMath math="(f \circ g)(\frac{1}{x+1}) = 2\left(\frac{1}{x+1}\right)^2 + 9 = \frac{2}{(x+1)^2} + 9" />
    </MathContainer>

2.  **Calculating <InlineMath math="(f \circ (g \circ h))(x)" />:**

    First, find <InlineMath math="(g \circ h)(x)" />:

    <MathContainer>
      <BlockMath math="(g \circ h)(x) = g(h(x)) = g(\frac{1}{x+1})" />
      <BlockMath math="g(\frac{1}{x+1}) = \left(\frac{1}{x+1}\right)^2 + 4 = \frac{1}{(x+1)^2} + 4" />
    </MathContainer>

    Now, compose <InlineMath math="f" /> with this result:

    <MathContainer>
      <BlockMath math="(f \circ (g \circ h))(x) = f((g \circ h)(x)) = f\left(\frac{1}{(x+1)^2} + 4\right)" />
      <BlockMath math="f\left(\frac{1}{(x+1)^2} + 4\right) = 2\left(\frac{1}{(x+1)^2} + 4\right) + 1 = \frac{2}{(x+1)^2} + 8 + 1 = \frac{2}{(x+1)^2} + 9" />
    </MathContainer>

Since both results are the same (<InlineMath math="\frac{2}{(x+1)^2} + 9" />) for <InlineMath math="x\neq-1" />, the associative property holds on their common domain: <InlineMath math="((f \circ g) \circ h)(x) = (f \circ (g \circ h))(x)" />.

This associative property also applies to other combinations of function order, such as <InlineMath math="((h \circ f) \circ g)(x) = (h \circ (f \circ g))(x)" /> and <InlineMath math="((g \circ f) \circ h)(x) = (g \circ (f \circ h))(x)" />.

### Identity Element

An **identity function** maps every element of a set to itself. For <InlineMath math="f:A\to B" />, let <InlineMath math="I_A" /> be the identity on <InlineMath math="A" /> and <InlineMath math="I_B" /> the identity on <InlineMath math="B" />.

Composing with the identity for the matching set leaves <InlineMath math="f" /> unchanged:

<MathContainer>
  <BlockMath math="(f\circ I_A)(x)=f(I_A(x))=f(x)" />
  <BlockMath math="(I_B\circ f)(x)=I_B(f(x))=f(x)" />
</MathContainer>

**Example:**

With <InlineMath math="f:\mathbb{R}\to\mathbb{R}" /> and <InlineMath math="f(x) = 2x + 1" />:

- <InlineMath math="(f\circ I_{\mathbb{R}})(x)=f(I_{\mathbb{R}}(x))=2x+1" />
- <InlineMath math="(I_{\mathbb{R}}\circ f)(x)=I_{\mathbb{R}}(f(x))=2x+1" />

Both result in the function <InlineMath math="f(x)" /> again.
