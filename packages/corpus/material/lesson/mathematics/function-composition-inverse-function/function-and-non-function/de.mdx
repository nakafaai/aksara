## Beziehungen zwischen Mengen

In der Mathematik ist eine **Relation** von einer Menge <InlineMath math="A" /> zu einer Menge <InlineMath math="B" /> eine beliebige Teilmenge des kartesischen Produkts <InlineMath math="A\times B" />. Ein geordnetes Paar <InlineMath math="(a,b)" /> in der Relation besagt, dass <InlineMath math="a" /> zu <InlineMath math="b" /> in Beziehung steht. Eine Relation darf ein Element aus <InlineMath math="A" /> ohne Zuordnung lassen oder ihm mehrere Elemente aus <InlineMath math="B" /> zuordnen.

Für die Kleiner als Relation zwischen <InlineMath math="A = \{1, 2, 3\}" /> und <InlineMath math="B = \{1, 2, 3, 4\}" /> gehört <InlineMath math="(a,b)" /> genau dann zur Relation, wenn <InlineMath math="a < b" /> gilt:

- Für <InlineMath math="a=1" /> erhalten wir <InlineMath math="1 < 2" />, <InlineMath math="1 < 3" />, <InlineMath math="1 < 4" />. Paare: <InlineMath math="(1, 2), (1, 3), (1, 4)" />.
- Für <InlineMath math="a=2" /> erhalten wir <InlineMath math="2 < 3" />, <InlineMath math="2 < 4" />. Paare: <InlineMath math="(2, 3), (2, 4)" />.
- Für <InlineMath math="a=3" /> erhalten wir <InlineMath math="3 < 4" />. Paar: <InlineMath math="(3, 4)" />.

Die Relation ist <InlineMath math="\{(1, 2), (1, 3), (1, 4), (2, 3), (2, 4), (3, 4)\}" />.

## Funktionen als besondere Relationen

Eine **Funktion** (oder Abbildung) <InlineMath math="f" /> von einer Menge <InlineMath math="A" /> auf eine Menge <InlineMath math="B" />, geschrieben <InlineMath math="f: A \to B" />, ist eine spezielle Beziehung, die zwei Bedingungen erfüllt:

1.  **Jede** Eingabe <InlineMath math="x \in A" /> besitzt mindestens eine Ausgabe <InlineMath math="y \in B" />.

    <BlockMath math="\forall x \in A, \exists y \in B \text{ mit } (x, y) \in f" />

2.  Keine Eingabe <InlineMath math="x \in A" /> besitzt zwei verschiedene Ausgaben in <InlineMath math="B" />.

    <BlockMath math="\text{Wenn} (x, y_1) \in f \text{und} (x, y_2) \in f, \text{dann} y_1 = y_2" />

Zusammen verlangen beide Bedingungen, dass jede Eingabe der Definitionsmenge genau eine Ausgabe besitzt.

## Andere Darstellungen prüfen

- Bei geordneten Paaren wird die erste Koordinate geprüft. Tritt dieselbe erste Koordinate mit zwei verschiedenen zweiten Koordinaten auf, ist die Relation keine Funktion.
- In einer Tabelle muss jede Eingabezeile genau eine Ausgabe besitzen.
- Im Graphen von <InlineMath math="y" /> als Funktion von <InlineMath math="x" /> darf jede senkrechte Gerade den Graphen höchstens einmal schneiden. Dies ist der Senkrechtentest.

Der Kreis <InlineMath math="x^2+y^2=4" /> ist zum Beispiel auf dem gesamten Kreis kein Graph von <InlineMath math="y" /> als Funktion von <InlineMath math="x" />. Für <InlineMath math="x=0" /> enthält die Relation sowohl <InlineMath math="y=2" /> als auch <InlineMath math="y=-2" />.

## Relationen als Funktionen einordnen

1. Ist <InlineMath math="R=\{(-1,3),(0,3),(2,5)\}" /> auf den dargestellten Eingaben eine Funktion?
2. Ist <InlineMath math="S=\{(-1,3),(0,3),(-1,5)\}" /> auf den dargestellten Eingaben eine Funktion?
3. Definiert <InlineMath math="y^2=x" /> die Variable <InlineMath math="y" /> als Funktion jedes <InlineMath math="x\geq0" />?

### Jede Eingabe prüfen

1. Ja. Jede erste Koordinate besitzt genau eine zweite Koordinate. Zwei Eingaben dürfen dieselbe Ausgabe <InlineMath math="3" /> besitzen.
2. Nein. Die Eingabe <InlineMath math="-1" /> besitzt zwei verschiedene Ausgaben.
3. Nein. Für jedes <InlineMath math="x>0" /> enthält die Relation <InlineMath math="y=\sqrt{x}" /> und <InlineMath math="y=-\sqrt{x}" />. Die Einschränkung auf <InlineMath math="y=\sqrt{x}" /> würde eine Funktion definieren.
