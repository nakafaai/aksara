## Relations Between Sets

In mathematics, a **relation** from a set <InlineMath math="A" /> to a set <InlineMath math="B" /> is any subset of the Cartesian product <InlineMath math="A\times B" />. An ordered pair <InlineMath math="(a,b)" /> in the relation states that <InlineMath math="a" /> is related to <InlineMath math="b" />. A relation may leave an element of <InlineMath math="A" /> unpaired or pair it with several elements of <InlineMath math="B" />.

For the "less than" relation between <InlineMath math="A = \{1, 2, 3\}" /> and <InlineMath math="B = \{1, 2, 3, 4\}" />, include <InlineMath math="(a,b)" /> whenever <InlineMath math="a < b" />:

- For <InlineMath math="a=1" />, we get <InlineMath math="1 < 2" />, <InlineMath math="1 < 3" />, <InlineMath math="1 < 4" />. Pairs: <InlineMath math="(1, 2), (1, 3), (1, 4)" />.
- For <InlineMath math="a=2" />, we get <InlineMath math="2 < 3" />, <InlineMath math="2 < 4" />. Pairs: <InlineMath math="(2, 3), (2, 4)" />.
- For <InlineMath math="a=3" />, we get <InlineMath math="3 < 4" />. Pair: <InlineMath math="(3, 4)" />.

The relation is <InlineMath math="\{(1, 2), (1, 3), (1, 4), (2, 3), (2, 4), (3, 4)\}" />.

## Functions as Special Relations

A **function** (or mapping) <InlineMath math="f" /> from a set <InlineMath math="A" /> to a set <InlineMath math="B" />, written <InlineMath math="f: A \to B" />, is a special relation that satisfies two conditions:

1.  **Every** input <InlineMath math="x \in A" /> is paired with at least one output <InlineMath math="y \in B" />.

    <BlockMath math="\forall x \in A, \exists y \in B \text{ such that} (x, y) \in f" />

2.  No input <InlineMath math="x \in A" /> is paired with two different outputs in <InlineMath math="B" />.

    <BlockMath math="\text{If } (x, y_1) \in f \text{ and} (x, y_2) \in f, \text{ then} y_1 = y_2" />

Together, these conditions require each input in the domain to have exactly one output.

## Checking Other Representations

- In ordered pairs, inspect the first coordinate. Repeating a first coordinate with a different second coordinate means the relation is not a function.
- In a table, every input row must have exactly one output.
- On a graph of <InlineMath math="y" /> as a function of <InlineMath math="x" />, every vertical line may intersect the graph at most once. This is the vertical line test.

For example, the circle <InlineMath math="x^2+y^2=4" /> is not the graph of <InlineMath math="y" /> as a function of <InlineMath math="x" /> on the whole circle. At <InlineMath math="x=0" /> it contains both <InlineMath math="y=2" /> and <InlineMath math="y=-2" />.

## Classifying Relations as Functions

1. Is <InlineMath math="R=\{(-1,3),(0,3),(2,5)\}" /> a function on the displayed inputs?
2. Is <InlineMath math="S=\{(-1,3),(0,3),(-1,5)\}" /> a function on the displayed inputs?
3. Does <InlineMath math="y^2=x" /> define <InlineMath math="y" /> as a function of every <InlineMath math="x\geq0" />?

### Checking Each Input

1. Yes. Each first coordinate has exactly one second coordinate. Two inputs may share the output <InlineMath math="3" />.
2. No. The input <InlineMath math="-1" /> has two different outputs.
3. No. For every <InlineMath math="x>0" />, the relation contains <InlineMath math="y=\sqrt{x}" /> and <InlineMath math="y=-\sqrt{x}" />. Restricting it to <InlineMath math="y=\sqrt{x}" /> would define one function.
