## Domain

**Domain** ialah set input yang ditetapkan bagi suatu fungsi. Petuanya mesti tertakrif bagi setiap unsur set itu. Apabila domain tidak dinyatakan, biasanya kita cari domain nyata yang paling besar: penyebut mesti bukan sifar dan punca kuasa genap memerlukan nilai di bawah tanda punca yang tidak negatif.

Domain juga boleh **sengaja dihadkan**. Contohnya, petua <InlineMath math="x^2" /> tertakrif untuk semua nombor nyata, tetapi suatu fungsi boleh ditetapkan hanya untuk <InlineMath math="x\ge0" />.

### Contoh Mencari Domain

Fungsi ini membahagi dengan inputnya, dan pembahagian hanya tertakrif apabila penyebutnya bukan sifar:

<BlockMath math="f(x) = \frac{1}{x}" />

Petua ini membahagi <InlineMath math="1" /> dengan input. Pada input <InlineMath math="0" />, penyebutnya menjadi sifar:

<BlockMath math="\frac10" />

Pembahagian dengan sifar tidak tertakrif, jadi <InlineMath math="0" /> dikecualikan manakala setiap nombor nyata yang lain dibenarkan.

Jadi, domain bagi fungsi <InlineMath math="f(x) = \frac{1}{x}" /> ialah **semua nombor nyata** kecuali <InlineMath math="0" />.

Contoh lain:

<BlockMath math="g(x) = \sqrt{x}" />

Petua ini mengambil punca kuasa dua inputnya. Jika kita uji <InlineMath math="-4" />, kita dapat:

<BlockMath math="\sqrt{-4}" />

Dalam nombor nyata, punca kuasa dua memerlukan nilai di bawah tanda punca yang tidak negatif. Oleh itu, hanya <InlineMath math="0" /> dan input positif yang dibenarkan.

Jadi, domain bagi fungsi <InlineMath math="g(x) = \sqrt{x}" /> ialah semua nombor nyata yang lebih besar daripada atau sama dengan <InlineMath math="0" /> (<InlineMath math="x \ge 0" />).

Domain menentukan titik yang ada pada graf. Dengan <InlineMath math="f(x) = x^2" /> dan domain <InlineMath math="\{0, 1, 2, 3\}" />, graf itu hanyalah empat titik <InlineMath math="(0, 0)" />, <InlineMath math="(1, 1)" />, <InlineMath math="(2, 4)" /> dan <InlineMath math="(3, 9)" /> pada parabola yang dilukis samar. Kalau domain itu ditukar, set titik itu turut berubah.

## Kodomain

**Kodomain** ialah set sasaran yang diisytiharkan sebagai sebahagian daripada takrif fungsi. Setiap output mesti berada dalam set ini, tetapi fungsi itu tidak semestinya mencapai setiap unsurnya.

Contohnya, takrifkan fungsi <InlineMath math="f(x) = 2x" />.

Kita tetapkan **Domain** (input) sebagai set nombor asli:

<BlockMath math="\{1, 2, 3, ...\}" />

Kemudian, kita tetapkan **kodomain** sebagai set integer:

<BlockMath math="\{..., -2, -1, 0, 1, 2, ...\}" />

Dengan memilih integer sebagai kodomain, kita mengisytiharkan set yang mesti mengandungi setiap nilai <InlineMath math="f(x)=2x" />. Untuk input nombor asli, fungsi ini sebenarnya hanya menghasilkan nombor genap positif. Nilai-nilai yang dicapai itu membentuk julat:

<BlockMath math="\{2, 4, 6, ...\}" />

Kodomain yang dipilih itu sah kerana setiap hasil sebenar dalam julat ialah integer.

Jadi kodomain menerangkan ruang sasaran yang dibenarkan. Kodomain bukan senarai nilai yang semestinya dihasilkan oleh fungsi.

## Julat

**Julat** ialah set output yang benar-benar terhasil apabila setiap unsur domain digunakan. Julat ialah subset bagi kodomain.

**Contoh**:

Untuk contoh ini, domain dan kodomain bagi <InlineMath math="f(x) = x^2" /> ialah set integer.

<BlockMath math="\{..., -2, -1, 0, 1, 2, ...\}" />

Apabila kita masukkan nilai daripada domain:

| Input | Output kuasa dua |
| --- | --- |
| <InlineMath math="-2" /> | <InlineMath math="(-2)^2=4" /> |
| <InlineMath math="-1" /> | <InlineMath math="(-1)^2=1" /> |
| <InlineMath math="0" /> | <InlineMath math="0^2=0" /> |
| <InlineMath math="1" /> | <InlineMath math="1^2=1" /> |
| <InlineMath math="2" /> | <InlineMath math="2^2=4" /> |

Nilai yang _sebenarnya_ keluar sebagai output ialah <InlineMath math="0, 1, 4, 9, 16" />, dan seterusnya (nombor kuasa dua yang tidak negatif).

Jadi, **Julat** fungsi ini (dengan domain ini) ialah set:

<BlockMath math="\{0, 1, 4, 9, 16, ...\}" />

Perhatikan bahawa julat ini (<InlineMath math="\{0, 1, 4, 9, ...\}" />) ialah sebahagian (subset) daripada kodomain yang kita takrifkan (integer):

<BlockMath math="\{..., -1, 0, 1, 2, ...\}" />

Bukan semua unsur kodomain termasuk dalam julat.

Di sini <InlineMath math="f(x) = x^2" /> memetakan domain <InlineMath math="\{-2, -1, 0, 1, 2\}" /> ke dalam kodomain <InlineMath math="\{0, 1, 2, 3, 4\}" />. Setiap input ada tepat satu anak panah, tetapi hanya <InlineMath math="0" />, <InlineMath math="1" /> dan <InlineMath math="4" /> yang menerima anak panah. Nilai-nilai itu membentuk julat, manakala <InlineMath math="2" /> dan <InlineMath math="3" /> kekal dalam kodomain tanpa dicapai.

## Peranan Berbeza Domain Kodomain dan Julat

Domain menghalang input yang tidak sah, seperti pembahagian dengan sifar, daripada masuk ke dalam fungsi. Kodomain mengisytiharkan ruang sasaran, manakala julat mengenal pasti nilai yang benar-benar dicapai oleh fungsi.

Untuk melihat perbezaannya, hadkan contoh kuasa dua kepada <InlineMath math="D=\{-2,-1,0,1,2\}" /> dan pilih <InlineMath math="K=\{0,1,2,3,4\}" />. **Setiap input ada satu anak panah**, tetapi sesetengah unsur kodomain tidak menerima sebarang anak panah.

## Hubungan Matematik

Secara matematik, fungsi <InlineMath math="f" /> memetakan setiap unsur daripada set Domain (<InlineMath math="D" />) kepada satu unsur dalam set Kodomain (<InlineMath math="K" />). Ini selalunya ditulis sebagai:

<BlockMath math="f: D \to K" />

Julat (<InlineMath math="R" />) ialah set semua hasil sebenar <InlineMath math="f(x)" /> bagi setiap <InlineMath math="x" /> dalam Domain. Dengan kata lain:

<BlockMath math="R = \{ f(x) \mid x \in D \}" />

Julat <Highlight>sentiasa subset bagi kodomain</Highlight>:

<BlockMath math="R \subseteq K" />

Setiap nilai yang benar-benar dicapai oleh fungsi mesti berada dalam kodomain. Sebaliknya tidak semestinya benar: suatu nilai dalam kodomain mungkin tidak pernah muncul sebagai output.

## Semak Kefahaman Kamu

Katakan <InlineMath math="h:\mathbb{R}\setminus\{2\}\to\mathbb{R}" /> ditakrifkan oleh <InlineMath math="h(x)=\frac1{x-2}" />. Jawab tiga soalan di bawah untuk fungsi ini. Mulakan dengan input yang dilarang oleh penyebut, kemudian fikirkan nilai **output** mana yang boleh dicapai oleh pecahan itu.

1. Mengapa <InlineMath math="2" /> dikecualikan daripada domain?
2. Bolehkah <InlineMath math="0" /> berada dalam julat?
3. Nyatakan julat bagi <InlineMath math="h" />.

### Jalan Kerja

1. Pada <InlineMath math="x=2" />, penyebutnya sifar:

   <BlockMath math="2-2=0" />

   Ungkapan itu tidak tertakrif, jadi <InlineMath math="2" /> tidak boleh berada dalam domain.
2. Tidak. Pecahan dengan **pengangka** <InlineMath math="1" /> tidak boleh sama dengan <InlineMath math="0" />.
3. Setiap nilai nyata yang bukan sifar dapat dicapai. Bagi sebarang <InlineMath math="y\neq0" />, jika kita pilih <InlineMath math="x=2+\frac1y" />, kita dapat <InlineMath math="h(x)=y" />. Jadi:

   <BlockMath math="R_h=\mathbb{R}\setminus\{0\}" />
