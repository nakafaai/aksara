## What Makes a Relation a Function

A function assigns **exactly one output** to every input in its domain. If <InlineMath math="f" /> maps a set <InlineMath math="A" /> to a set <InlineMath math="B" />, we write:

<BlockMath math="f:A\to B" />

For each <InlineMath math="x\in A" />, there must be one value <InlineMath math="y\in B" /> with <InlineMath math="y=f(x)" />. Two different inputs may share an output. What is forbidden is <Highlight>one input receiving two different outputs</Highlight>.

For example, the rule <InlineMath math="f(x)=x+2" /> assigns one value to every real input:

| Input <InlineMath math="x" /> | Output <InlineMath math="f(x)" /> |
| ----------------------------- | -------------------------------- |
| <InlineMath math="3" /> | <InlineMath math="5" /> |
| <InlineMath math="-1" /> | <InlineMath math="1" /> |
| <InlineMath math="0" /> | <InlineMath math="2" /> |

The same information can be written as ordered pairs:

<BlockMath math="\{(3,5),(-1,1),(0,2)\}" />

Each first coordinate appears with only one second coordinate, so these pairs describe a function on the displayed inputs.

Each input of <InlineMath math="f(x) = x + 2" /> gets exactly one output, so the pairs <InlineMath math="(3, 5)" />, <InlineMath math="(-1, 1)" /> and <InlineMath math="(0, 2)" /> all lie on one line, one point above each input.

## Reading Function Notation

In the equation <InlineMath math="f(x)=y" />:

- <InlineMath math="f" /> names the function.
- <InlineMath math="x" /> is an input from the domain.
- <InlineMath math="f(x)" /> is the output produced by applying the rule to <InlineMath math="x" />.
- <InlineMath math="y" /> is another name for that output.

The notation <InlineMath math="f(3)" /> **does not mean multiplication** by <InlineMath math="3" />. It means “evaluate <InlineMath math="f" /> at the input <InlineMath math="3" />.” For <InlineMath math="f(x)=x+2" />:

<MathContainer>
  <BlockMath math="f(3)=3+2=5" />
  <BlockMath math="f(-1)=-1+2=1" />
  <BlockMath math="f(0)=0+2=2" />
</MathContainer>

## Function or Not a Function

Compare these two relations:

<MathContainer>
  <BlockMath math="R=\{(1,4),(2,4),(3,7)\}" />
  <BlockMath math="S=\{(1,4),(1,6),(3,7)\}" />
</MathContainer>

Relation <InlineMath math="R" /> is a function. Inputs <InlineMath math="1" /> and <InlineMath math="2" /> share **the same output**, <InlineMath math="4" />, which is allowed. Relation <InlineMath math="S" /> is not a function because input <InlineMath math="1" /> has **two different outputs**, <InlineMath math="4" /> and <InlineMath math="6" />.

Plot <InlineMath math="S" />: the input 1 has two points above it, <InlineMath math="(1, 4)" /> and <InlineMath math="(1, 6)" />, so the vertical line <InlineMath math="x = 1" /> meets the graph twice. That is exactly why <InlineMath math="S" /> is not a function, while in <InlineMath math="R" /> every input has one point.

## Check Your Understanding

These questions check one definition at a time, so answer each one by naming the input, the rule, and the **single output** that the rule produces.

1. Let <InlineMath math="g(x)=3x-2" />. Find <InlineMath math="g(0)" />, <InlineMath math="g(2)" />, and <InlineMath math="g(-3)" />.
2. Does <InlineMath math="T=\{(-2,5),(0,1),(4,5)\}" /> define a function on the displayed inputs? Explain.
3. Does <InlineMath math="U=\{(-2,5),(0,1),(-2,7)\}" /> define a function on the displayed inputs? Explain.

### Worked Solutions

1. Substitute each input into the same rule:

   <MathContainer>
     <BlockMath math="g(0)=3(0)-2=-2" />
     <BlockMath math="g(2)=3(2)-2=4" />
     <BlockMath math="g(-3)=3(-3)-2=-11" />
   </MathContainer>

2. Yes. Every first coordinate in <InlineMath math="T" /> has exactly one second coordinate. Reusing the output <InlineMath math="5" /> does not violate the definition.
3. No. The input <InlineMath math="-2" /> is paired with **two different outputs**, <InlineMath math="5" /> and <InlineMath math="7" />.
