## Reversing an Input and Output Pair

You often translate words or sentences from English to Indonesian, for example, when watching movies or reading news. This translation process is similar to how a function works: there is an input (English word) and an output (Indonesian word).

Real language translation can be ambiguous. Here we use a deliberately small dictionary in which each selected word has exactly one paired translation.

Here, the "Translation Machine" acts like a function that transforms "Mathematics" (input) into "Matematika" (output).

The reverse mapping sends "Matematika" back to "Mathematics". This mapping is an **inverse function**.

## Definition of Inverse Function

An inverse function **exchanges the input and output**. If function <InlineMath math="f" /> maps element <InlineMath math="x" /> from domain <InlineMath math="A" /> to element <InlineMath math="y" /> in codomain <InlineMath math="B" />, then its inverse function, denoted as <InlineMath math="f^{-1}" /> (read "f inverse"), maps element <InlineMath math="y" /> from <InlineMath math="B" /> back to element <InlineMath math="x" /> in <InlineMath math="A" />.

Mathematically:

<BlockMath math="y = f(x) \iff x = f^{-1}(y)" />

In other words, if <InlineMath math="f" /> changes <InlineMath math="x" /> to <InlineMath math="y" />, then <InlineMath math="f^{-1}" /> changes <InlineMath math="y" /> back to <InlineMath math="x" />. The inverse function "undoes" the effect of the original function.

The notation <InlineMath math="f^{-1}(x)" /> denotes the inverse function. The multiplicative inverse or reciprocal is written <InlineMath math="\frac{1}{f(x)}" />.

To distinguish the two notations, take <InlineMath math="f(x)=2x+3" />. The inverse finds the original input, while the reciprocal divides one by the function value.

| Input | Inverse function | Reciprocal |
| --- | --- | --- |
| <InlineMath math="3" /> | <InlineMath math="f^{-1}(3)=0" /> | <InlineMath math="1/f(3)=1/9" /> |
| <InlineMath math="5" /> | <InlineMath math="f^{-1}(5)=1" /> | <InlineMath math="1/f(5)=1/13" /> |

## Condition for a Function to Have an Inverse

For a function <InlineMath math="f:A\to B" /> <Highlight>to have a two-sided inverse</Highlight> <InlineMath math="f^{-1}:B\to A" />, the function <InlineMath math="f" /> must be **bijective**. A bijective function is both **injective** (one-to-one) and **surjective** (onto).

- **Injective (One-to-one)**: Every distinct element in the domain maps to a distinct element in the codomain. No two different inputs produce the same output.
- **Surjective (Onto)**: Every element in the codomain is the result of mapping from at least one element in the domain. All possible outputs occur.

The specified domain and codomain matter. If <InlineMath math="f" /> is injective but does not reach all of <InlineMath math="B" />, we can replace its codomain by its actual range. Writing that range as <InlineMath math="\operatorname{Im}(f)" />, the resulting function <InlineMath math="f:A\to \operatorname{Im}(f)" /> is bijective and therefore has an inverse <InlineMath math="f^{-1}:\operatorname{Im}(f)\to A" />. If <InlineMath math="f" /> is not injective, reversing its pairs sends one output to more than one input, so the reversed relation is not a function unless the original domain is restricted.

For example, <InlineMath math="q(x)=x^2" /> is not injective on <InlineMath math="\mathbb{R}" /> because <InlineMath math="q(2)=q(-2)=4" />. Restricting its domain and codomain gives the bijection

<BlockMath math="q:[0,\infty)\to[0,\infty),\qquad q(x)=x^2" />

This function has the inverse <InlineMath math="q^{-1}(x)=\sqrt{x}" />.

## Determining the Formula for an Inverse Function

To find the formula for the inverse function <InlineMath math="f^{-1}(x)" /> from a function <InlineMath math="f(x)" />, you can follow these steps:

1.  Replace <InlineMath math="f(x)" /> with <InlineMath math="y" />.
2.  Swap the positions of the variables <InlineMath math="x" /> and <InlineMath math="y" /> in the equation.
3.  Solve the equation for <InlineMath math="y" /> in terms of <InlineMath math="x" />.
4.  Replace <InlineMath math="y" /> with <InlineMath math="f^{-1}(x)" /> to get the inverse function formula.

**Example**:

Let <InlineMath math="f:\mathbb{R}\to\mathbb{R}" /> be defined by <InlineMath math="f(x) = 2x + 3" />. Find its inverse.

**Step 1**. Replace <InlineMath math="f(x)" /> with <InlineMath math="y" />:

<BlockMath math="y = 2x + 3" />

**Step 2**. Swap <InlineMath math="x" /> and <InlineMath math="y" />:

<BlockMath math="x = 2y + 3" />

**Step 3**. Solve for <InlineMath math="y" />:

<MathContainer>
  <BlockMath math="x - 3 = 2y" />
  <BlockMath math="\frac{x - 3}{2} = y" />
</MathContainer>

**Step 4**. Replace <InlineMath math="y" /> with <InlineMath math="f^{-1}(x)" />:

<BlockMath math="f^{-1}(x) = \frac{x - 3}{2}" />

So, the inverse function of <InlineMath math="f(x) = 2x + 3" /> is <InlineMath math="f^{-1}(x) = \frac{x - 3}{2}" />.

## Check Your Understanding

Let <InlineMath math="r:\mathbb{R}\to\mathbb{R}" /> be defined by <InlineMath math="r(x)=3x-5" />. Work through the three steps below for this function. Check **both compositions** at the end, because a correct inverse undoes the original in both orders.

1. Find <InlineMath math="r^{-1}(x)" />.
2. Verify both compositions <InlineMath math="r^{-1}(r(x))" /> and <InlineMath math="r(r^{-1}(x))" />.
3. State the domain and range of both functions.

### Solution

**Problem 1**. Starting with <InlineMath math="y=3x-5" />, **swap the variables** and solve for <InlineMath math="y" />:

<MathContainer>
  <BlockMath math="x=3y-5" />
  <BlockMath math="x+5=3y" />
  <BlockMath math="r^{-1}(x)=\frac{x+5}{3}" />
</MathContainer>

**Problem 2**. Now verify both directions:

<MathContainer>
  <BlockMath math="r^{-1}(r(x))=\frac{(3x-5)+5}{3}=x" />
  <BlockMath math="r(r^{-1}(x))=3\left(\frac{x+5}{3}\right)-5=x" />
</MathContainer>

**Problem 3**. Both <InlineMath math="r" /> and <InlineMath math="r^{-1}" /> have domain <InlineMath math="\mathbb{R}" /> and range <InlineMath math="\mathbb{R}" />. The two identities confirm that the functions undo each other on their complete domains.

For <InlineMath math="r(x) = 3x - 5" /> the inverse is <InlineMath math="r^{-1}(x) = \frac{x + 5}{3}" />. Both lines cross the mirror <InlineMath math="y = x" /> at the same point <InlineMath math="\left(\tfrac52, \tfrac52\right)" />, the one input that <InlineMath math="r" /> leaves unchanged, because <InlineMath math="3 \cdot \tfrac52 - 5 = \tfrac52" />.
