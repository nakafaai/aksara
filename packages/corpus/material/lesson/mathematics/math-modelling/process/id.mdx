## Pemodelan Matematika Mengubah Masalah Menjadi Persamaan

**Pemodelan matematika** adalah proses memakai matematika untuk mewakili dan menyelesaikan masalah seperti tarif taksi, rancangan taman, dan pertumbuhan bakteri. Model adalah persamaan atau fungsi yang menghubungkan variabel dalam masalah itu. Prosesnya berulang: setelah model diuji dengan data, model **diperbaiki** jika prediksinya kurang tepat. Bentuk yang umum adalah **linear** untuk laju perubahan tetap, **kuadrat** untuk masalah optimasi, dan **eksponensial** untuk pertumbuhan dengan persentase tetap. Dalam model di sini, kamu mencocokkan garis dengan data tarif taksi, mencari luas terbesar sebuah taman, dan menyetel model eksponensial dengan data bakteri.

### Contoh Menyusun dan Memakai Model Linear

Dari data, tarif naik <InlineMath math="\text{RM}\,2{,}40" /> untuk setiap <InlineMath math="2\text{ km}" />. Susun **model tarif** dan prediksi tarif untuk perjalanan <InlineMath math="15\text{ km}" />.

<MathContainer>
<BlockMath math="m = \frac{7{,}8 - 5{,}4}{4 - 2} = 1{,}2" />
<BlockMath math="5{,}4 = 1{,}2(2) + c \quad\Rightarrow\quad c = 3" />
<BlockMath math="y = 1{,}2(15) + 3 = 21" />
</MathContainer>

Model <InlineMath math="y = 1{,}2x + 3" /> berarti tarif dasar <InlineMath math="\text{RM}\,3" /> dan <InlineMath math="\text{RM}\,1{,}20" /> per kilometer. Uji dengan titik terakhir: <InlineMath math="1{,}2(10) + 3 = 15" />, sama dengan datanya.

### Asumsi Model Tarif

Model ini menganggap **tidak ada biaya tambahan** untuk menunggu, tol, atau perjalanan malam. Jika perusahaan menarik biaya jam sibuk, model perlu diperbaiki dengan variabel tambahan.

### Contoh Luas Terbesar

Tentukan **lebar yang memberi luas terbesar** dan luas itu.

<MathContainer>
<BlockMath math="A = 40x - 2x^2 = -2(x - 10)^2 + 200" />
<BlockMath math="x = 10 \quad\Rightarrow\quad A_{\max} = 200\text{ m}^2" />
</MathContainer>

Panjangnya <InlineMath math="40 - 2(10) = 20\text{ m}" />. Cek dengan model: pada <InlineMath math="w = 10" />, luasnya terbaca <InlineMath math="200" />, dan pada <InlineMath math="w = 9" /> atau <InlineMath math="w = 11" />, luasnya <InlineMath math="198" />, sedikit lebih kecil.

### Asumsi Model Taman

Model ini menganggap **tembok cukup panjang** dan seluruh <InlineMath math="40\text{ m}" /> pagar terpakai. Jika tembok hanya <InlineMath math="15\text{ m}" />, panjang taman tidak boleh lebih dari <InlineMath math="15\text{ m}" /> dan penyelesaiannya berubah. Dalam keadaan itu, <InlineMath math="40 - 2x \le 15" /> memberi <InlineMath math="x \ge 12{,}5" />, jadi lebar terbaik adalah <InlineMath math="12{,}5\text{ m}" /> dengan luas <InlineMath math="12{,}5 \times 15 = 187{,}5\text{ m}^2" />.

### Contoh Menguji Model Eksponensial

<BlockMath math="N = 200(1{,}3)^t, \qquad N(5) = 200(1{,}3)^5 = 742{,}6" />

Data sebenarnya pada jam kelima adalah <InlineMath math="743" />, jadi model ini memadai. Cek dengan model: pada <InlineMath math="b = 1{,}3" />, kurvanya melewati semua titik dan prediksi jam keenam adalah <InlineMath math="965" />. ### Asumsi Model Bakteri

Model ini menganggap **makanan dan ruang tidak terbatas**. Dalam jangka panjang asumsi ini gagal dan model perlu diperbaiki, karena pertumbuhan bakteri akhirnya melambat. Model yang lebih baik untuk waktu lama adalah model yang pertumbuhannya mendatar saat makanan mulai habis.

## Kesalahan Umum tentang Pemodelan Matematika

| Kesalahan | Mengapa salah | Cara mengecek |
| :--- | :--- | :--- |
| Tidak menyatakan asumsi. | Asumsi menentukan kapan model bisa dipercaya. | Daftarkan setiap asumsi sebelum menyusun model. |
| Memilih model linear untuk pertumbuhan persentase tetap. | Pertumbuhan persentase tetap memberi rasio tetap, bukan selisih tetap. | Hitung selisih dan rasio antardata berturut-turut. |
| Memakai model jauh di luar rentang data. | Prediksi di luar rentang bisa melanggar asumsi. | Bandingkan masukan dengan rentang data asal. |
| Berhenti setelah mendapat persamaan. | Model harus diuji dengan data sebelum dipakai. | Substitusikan nilai data ke dalam model. |

Kesalahan kedua paling sering muncul dalam soal pemilihan model. **Selisih tetap berarti linear, rasio tetap berarti eksponensial**.

## Latihan Pemodelan Matematika

Soal-soal ini bergerak dari model linear ke model eksponensial. **Sebutkan satu asumsi** untuk setiap model.

1. Sebuah tangki berisi <InlineMath math="500\text{ L}" /> air dan bocor <InlineMath math="12\text{ L}" /> per jam. Susun model volumenya dan tentukan kapan tangki kosong.

2. Seutas kawat <InlineMath math="60\text{ cm}" /> ditekuk menjadi persegi panjang. Tentukan ukuran yang memberi luas terbesar.

3. Jumlah penduduk sebuah kota adalah <InlineMath math="10{.}000" />, <InlineMath math="10{.}500" />, <InlineMath math="11{.}025" /> selama tiga tahun berturut-turut. Tentukan apakah model linear atau eksponensial yang lebih cocok, lalu susun modelnya.

4. Jelaskan mengapa model pada soal ketiga mungkin perlu diperbaiki setelah <InlineMath math="30" /> tahun.

### Pembahasan

**Pembahasan 1**: Volume berkurang dengan laju tetap, jadi gunakan model linear <InlineMath math="V = 500 - 12t" />:

<BlockMath math="0 = 500 - 12t \quad\Rightarrow\quad t = \frac{500}{12} = 41{,}7 \text{ jam}" />

**Asumsi**: laju bocor tetap meskipun permukaan air turun.

**Pembahasan 2**: Jika lebarnya <InlineMath math="x" />, panjangnya <InlineMath math="30 - x" />:

<BlockMath math="A = x(30 - x) = -(x - 15)^2 + 225" />

Luas terbesarnya <InlineMath math="225\text{ cm}^2" /> saat <InlineMath math="x = 15\text{ cm}" />, yaitu persegi. **Asumsi**: kawat tidak tumpang tindih di sudut.

**Pembahasan 3**: Selisihnya <InlineMath math="500" /> dan <InlineMath math="525" />, tidak tetap, tetapi rasionya <InlineMath math="\dfrac{10{.}500}{10{.}000} = 1{,}05" /> dan <InlineMath math="\dfrac{11{.}025}{10{.}500} = 1{,}05" />, tetap. Jadi model eksponensial lebih cocok:

<BlockMath math="P = 10{.}000(1{,}05)^t" />

**Asumsi**: laju pertumbuhan tetap <InlineMath math="5\%" /> per tahun.

**Pembahasan 4**: Model memprediksi <InlineMath math="10{.}000(1{,}05)^{30} = 43{.}219" /> orang. Dalam jangka panjang, **lahan, rumah, dan pekerjaan terbatas**, sehingga laju pertumbuhan biasanya turun. Model perlu diperbaiki dengan data baru.
