## Behavior Near a Target Point

A **limit** describes how nearby output values behave as the input approaches a chosen point. The function value at that point does not decide the limit, so a two-sided limit can exist even when the function is undefined or takes a different value there.

> A limit depends only on output values strictly near the target input, never on the value assigned at the target point itself.

At a jump, compare the two one-sided limits. Near a vertical asymptote, an infinite limit describes unbounded growth. Continuity, [derivatives](/en/subjects/mathematics/derivative-function/concept-of-derivative-function), and [definite integrals](/en/subjects/mathematics/integral/definite-integral) all build on limits. We start with a value table, then connect it to one-sided limits and the epsilon-delta definition.

## One Sided and Formal Limits

The standard limit notation reads:

<BlockMath math="\lim_{x \to c} f(x) = L" />

Read this as the limit of <InlineMath math="f(x)" /> as <InlineMath math="x" /> approaches <InlineMath math="c" /> equals <InlineMath math="L" />. **Approaching** does not mean substituting the function value at that point.

When <InlineMath math="c" /> is an interior point and the function is defined on both sides near <InlineMath math="c" />, the two-sided limit exists exactly when:

- The **left limit** and **right limit** both exist
- The left limit is **equal to** the right limit
- Their shared value is <InlineMath math="L" />

Write the left limit as <InlineMath math="x" /> approaches <InlineMath math="c" /> from values smaller than <InlineMath math="c" />:

<BlockMath math="\lim_{x\to c^-}f(x)=L" />

Write the right limit as <InlineMath math="x" /> approaches <InlineMath math="c" /> from values larger than <InlineMath math="c" />:

<BlockMath math="\lim_{x\to c^+}f(x)=L" />

When both one-sided limits share the same finite value <InlineMath math="L" />, the two-sided limit equals <InlineMath math="L" />. If they differ, the two-sided limit does not exist. At a domain endpoint, only the one-sided limit from inside the domain applies.

The precise epsilon-delta definition gives mathematical meaning to "approaches":

<BlockMath math="\begin{aligned} &amp;\forall \varepsilon>0\;\exists\delta>0: \\ &amp;0&lt;|x-c|&lt;\delta\; \\ &amp;\Longrightarrow\;|f(x)-L|&lt;\varepsilon \end{aligned}" />

For every output tolerance <InlineMath math="\varepsilon > 0" />, however small, you can choose an input tolerance <InlineMath math="\delta > 0" /> that traps <InlineMath math="f(x)" /> within <InlineMath math="\varepsilon" /> of <InlineMath math="L" /> whenever <InlineMath math="x" /> lies within <InlineMath math="\delta" /> of <InlineMath math="c" /> without equaling <InlineMath math="c" />. The strict condition <InlineMath math="0 < |x - c|" /> is why <InlineMath math="f(c)" /> **never determines the limit by itself**.

For <InlineMath math="f(x)=x+2" />, <InlineMath math="c=3" />, and <InlineMath math="L=5" />, the output distance matches the input distance:

<BlockMath math="|f(x)-5|=|(x+2)-5|=|x-3|" />

Choosing <InlineMath math="\delta = \varepsilon" /> guarantees that an output error below <InlineMath math="0.01" /> holds whenever the input stays inside:

<BlockMath math="0 < |x - 3| < 0.01" />

## Application of Limits

Limits measure how a quantity behaves near a point. Because a **limit value** can differ from the function value at that point, the next two examples contrast direct substitution with factoring out a removable hole.

### Direct Substitution

Evaluate the linear limit below:

<BlockMath math="\lim_{x \to 4} (2x - 1)" />

Because <InlineMath math="f(x) = 2x - 1" /> is **continuous** at <InlineMath math="x = 4" />, direct substitution gives the answer immediately:

<BlockMath math="\begin{aligned} \lim_{x \to 4} (2x - 1) &amp;= 2(4) - 1 \\ &amp;= 8 - 1 \\ &amp;= 7 \end{aligned}" />

### Factoring Holes

Evaluate the rational limit below:

<BlockMath math="\lim_{x \to 2} \frac{x^2 - 4}{x - 2}" />

Substituting <InlineMath math="x = 2" /> directly yields the **indeterminate form** <InlineMath math="\frac{0}{0}" />, so factor the numerator first:

<MathContainer>
  <BlockMath math="x^2 - 4 = (x + 2)(x - 2)" />
  <BlockMath math="\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x + 2)(x - 2)}{x - 2}" />
</MathContainer>

Because a limit inspects nearby inputs with <InlineMath math="x \neq 2" />, cancel <InlineMath math="(x - 2)" /> before evaluating:

<BlockMath math="\lim_{x\to2}\frac{x^2-4}{x-2}= \lim_{x \to 2} (x + 2) = 2 + 2 = 4" />

The graph matches the line <InlineMath math="y = x + 2" /> everywhere except for a missing point at <InlineMath math="(2, 4)" />.

## Core Limit Combination Rules

Assume both **finite limits** exist at <InlineMath math="x \to c" /> with constant coefficients <InlineMath math="a" /> and <InlineMath math="b" />:

<MathContainer>
  <BlockMath math="L = \lim_{x \to c} f(x)" />
  <BlockMath math="M = \lim_{x \to c} g(x)" />
</MathContainer>

Then combinations of <InlineMath math="f" /> and <InlineMath math="g" /> follow three algebraic rules:

| Operation | Limit | Extra condition |
| --- | --- | --- |
| Linear combination | <InlineMath math="aL+bM" /> | None |
| Product | <InlineMath math="LM" /> | None |
| Quotient | <InlineMath math="\frac{L}{M}" /> | <InlineMath math="M\ne0" /> |

## Checking Basic Limit Values

The four problems below cover **direct substitution**, factoring, a fundamental trigonometric limit, and a piecewise jump. Solve each one on paper first, then compare your steps with the solutions that follow.

1. Evaluate the polynomial limit:

   <BlockMath math="\lim_{x \to 3} (x^2 + 2x - 1)" />

2. Evaluate the rational limit:

   <BlockMath math="\lim_{x \to 1} \frac{x^2 - 1}{x - 1}" />

3. Evaluate the trigonometric limit using the fundamental sine limit theorem:

   <BlockMath math="\lim_{x \to 0} \frac{\sin x}{x}" />

4. Find the two-sided limit at <InlineMath math="x = 2" /> for the piecewise function:

   <BlockMath math="f(x) = \begin{cases} x + 1, & x < 2 \\ 3x - 2, & x \geq 2 \end{cases}" />

Compare your work against the step-by-step solutions below.

**Problem 1**. Because polynomials are **continuous everywhere**, substitute <InlineMath math="x = 3" /> directly:

<BlockMath math="\begin{aligned} &amp;\lim_{x \to 3} (x^2 + 2x - 1) \\ &amp;= 3^2 + 2(3) - 1 \\ &amp;= 9 + 6 - 1 \\ &amp;= 14 \end{aligned}" />

**Problem 2**. **Direct substitution** yields <InlineMath math="\frac{0}{0}" />, so factor the numerator first:

<MathContainer>
  <BlockMath math="x^2 - 1 = (x + 1)(x - 1)" />
  <BlockMath math="\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = \lim_{x \to 1} \frac{(x + 1)(x - 1)}{x - 1}" />
</MathContainer>

Cancel <InlineMath math="(x - 1)" /> for nearby inputs <InlineMath math="x \neq 1" /> and evaluate:

<BlockMath math="\lim_{x\to1}\frac{x^2-1}{x-1}= \lim_{x \to 1} (x + 1) = 1 + 1 = 2" />

**Problem 3**. Direct substitution produces <InlineMath math="\frac{0}{0}" />, so apply the **fundamental trigonometric limit** with <InlineMath math="x" /> measured in radians (degrees give a different value):

<BlockMath math="\lim_{x \to 0} \frac{\sin x}{x} = 1" />

**Problem 4**. For a piecewise rule, evaluate the left and right limits separately.

Approaching <InlineMath math="2" /> from the left (<InlineMath math="x < 2" />) uses the upper branch:

<BlockMath math="\begin{aligned} \lim_{x \to 2^-} f(x) &amp;= \lim_{x \to 2^-} (x + 1) \\ &amp;= 2 + 1 \\ &amp;= 3 \end{aligned}" />

Approaching <InlineMath math="2" /> from the right (<InlineMath math="x > 2" />) uses the lower branch:

<BlockMath math="\begin{aligned} \lim_{x \to 2^+} f(x) &amp;= \lim_{x \to 2^+} (3x - 2) \\ &amp;= 3(2) - 2 \\ &amp;= 6 - 2 \\ &amp;= 4 \end{aligned}" />

Because the left limit <InlineMath math="3" /> differs from the right limit <InlineMath math="4" />, the two-sided limit at <InlineMath math="x = 2" /> **does not exist**.
