## Following Function Values near a Chosen Input

A **limit** describes how nearby output values behave as the input approaches a chosen point. The function value at that point does not determine the limit. A two-sided limit can exist even if the function value is undefined or different. At a jump, compare the two one-sided limits. Near a vertical asymptote, an infinite limit describes the unbounded behavior.

Continuity, [derivatives](/en/subjects/mathematics/derivative-function/concept-of-derivative-function), and [definite integrals](/en/subjects/mathematics/integral/definite-integral) are all defined using limits. We will first read the pattern from a value table, then connect it to one-sided limits and the precise epsilon-delta definition.

## Approach Through Value Tables

The table below records how <InlineMath math="f(x) = x + 2" /> changes as <InlineMath math="x" /> approaches <InlineMath math="3" /> from both sides.

| Approach direction | Input | Output |
| --- | --- | --- |
| From the left | <InlineMath math="2.9" /> | <InlineMath math="4.9" /> |
| From the left | <InlineMath math="2.99" /> | <InlineMath math="4.99" /> |
| From the left | <InlineMath math="2.999" /> | <InlineMath math="4.999" /> |
| From the right | <InlineMath math="3.001" /> | <InlineMath math="5.001" /> |
| From the right | <InlineMath math="3.01" /> | <InlineMath math="5.01" /> |
| From the right | <InlineMath math="3.1" /> | <InlineMath math="5.1" /> |

As <InlineMath math="x" /> approaches <InlineMath math="3" /> from either side, the table values of <InlineMath math="f(x)" /> approach <InlineMath math="5" />. <Highlight>That approaching value is the limit</Highlight>.

## Notation One Sided Limits and Formal Meaning

The standard notation is:

<BlockMath math="\lim_{x \to c} f(x) = L" />

Read this as the limit of <InlineMath math="f(x)" /> as <InlineMath math="x" /> approaches <InlineMath math="c" /> equals <InlineMath math="L" />. **Approaching** does not mean substituting the function value at that point.

When <InlineMath math="c" /> is an interior point and the function is defined on both sides near <InlineMath math="c" />, the two-sided limit exists exactly when:
- **Left limit** and **right limit** must exist
- Left limit must be **equal to** the right limit
- The limit value is <InlineMath math="L" />

More formally, left and right limits can be written as:

For the left limit, <InlineMath math="x" /> approaches <InlineMath math="c" /> from the left:

<BlockMath math="\lim_{x\to c^-}f(x)=L" />

For the right limit, <InlineMath math="x" /> approaches <InlineMath math="c" /> from the right:

<BlockMath math="\lim_{x\to c^+}f(x)=L" />

If both limits are equal, then <InlineMath math="\lim_{x \to c} f(x) = L" />. If they are different, then the two-sided limit does not exist. At an endpoint of a domain, only the one-sided limit from within the domain is relevant.

The precise epsilon-delta definition gives mathematical meaning to "approaches":

<BlockMath math="\begin{aligned} &amp;\forall \varepsilon>0\;\exists\delta>0: \\ &amp;0&lt;|x-c|&lt;\delta\; \\ &amp;\Longrightarrow\;|f(x)-L|&lt;\varepsilon \end{aligned}" />

In words, for every requested output tolerance <InlineMath math="\varepsilon>0" />, however small, we can choose an input tolerance <InlineMath math="\delta>0" /> that keeps <InlineMath math="f(x)" /> within <InlineMath math="\varepsilon" /> of <InlineMath math="L" /> whenever <InlineMath math="x" /> is within <InlineMath math="\delta" /> of <InlineMath math="c" /> but not equal to it. The condition <InlineMath math="0<|x-c|" /> is why the value <InlineMath math="f(c)" /> **does not determine the limit by itself**.

### Choosing an Input Tolerance

For <InlineMath math="f(x)=x+2" />, <InlineMath math="c=3" />, and <InlineMath math="L=5" />, the output distance equals the input distance:

<BlockMath math="|f(x)-5|=|(x+2)-5|=|x-3|" />

Choose **the same input and output tolerance**, so <InlineMath math="\delta=\varepsilon" />. For example, an output error below <InlineMath math="0.01" /> follows whenever <InlineMath math="0<|x-3|<0.01" />. This calculation works for every positive tolerance.

## Application of Limits

Limits answer questions about how a quantity behaves near a point. A **limit value** can differ from the function value at that point, and the two examples show one case where substitution is enough and one where the expression must be simplified first.

### Evaluating a Limit by Direct Substitution

Find <InlineMath math="\lim_{x \to 4} (2x - 1)" />.

**Solution**:

Since the function <InlineMath math="f(x) = 2x - 1" /> is continuous at <InlineMath math="x = 4" />, we can directly substitute:

<BlockMath math="\begin{aligned} \lim_{x \to 4} (2x - 1) &amp;= 2(4) - 1 \\ &amp;= 8 - 1 \\ &amp;= 7 \end{aligned}" />

### Simplifying an Indeterminate Form Before Taking the Limit

Find <InlineMath math="\lim_{x \to 2} \frac{x^2 - 4}{x - 2}" />.

**Solution**:

If we substitute <InlineMath math="x = 2" /> directly, we get the indeterminate form <InlineMath math="\frac{0}{0}" />. We need to simplify first by factoring:

<MathContainer>
<BlockMath math="x^2 - 4 = (x + 2)(x - 2)" />
<BlockMath math="\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x + 2)(x - 2)}{x - 2}" />
</MathContainer>

Since a limit concerns nearby values with <InlineMath math="x \neq 2" />, we may cancel <InlineMath math="(x - 2)" /> before evaluating the simplified expression:

<BlockMath math="\lim_{x\to2}\frac{x^2-4}{x-2}= \lim_{x \to 2} (x + 2) = 2 + 2 = 4" />

## Basic Properties of Limits

The following rules require both limits <InlineMath math="L=\lim_{x\to c}f(x)" /> and <InlineMath math="M=\lim_{x\to c}g(x)" /> to **exist and be finite**, with constant coefficients <InlineMath math="a,b" />.

| Operation | Limit | Extra condition |
| --- | --- | --- |
| Linear combination | <InlineMath math="aL+bM" /> | None |
| Product | <InlineMath math="LM" /> | None |
| Quotient | <InlineMath math="\frac{L}{M}" /> | <InlineMath math="M\ne0" /> |

## Exercises

The four problems below cover **direct substitution**, a case that needs factoring, a basic trigonometric limit, and a piecewise function. Solve each one on paper first, then compare your steps with the solutions.

1. Find <InlineMath math="\lim_{x \to 3} (x^2 + 2x - 1)" />

2. Find <InlineMath math="\lim_{x \to 1} \frac{x^2 - 1}{x - 1}" />

3. Find <InlineMath math="\lim_{x \to 0} \frac{\sin x}{x}" /> (use trigonometric limit theorem)

4. The function <InlineMath math="f" /> is defined by:

   <BlockMath math="f(x) = \begin{cases} x + 1, & x < 2 \\ 3x - 2, & x \geq 2 \end{cases}" />

   Find <InlineMath math="\lim_{x \to 2} f(x)" />.

### Substitution in a Polynomial

Since polynomial functions are **continuous at all points**, we can substitute directly:

<BlockMath math="\begin{aligned} &amp;\lim_{x \to 3} (x^2 + 2x - 1) \\ &amp;= 3^2 + 2(3) - 1 \\ &amp;= 9 + 6 - 1 \\ &amp;= 14 \end{aligned}" />

### Factoring Before Taking the Limit

**Direct substitution** yields the form <InlineMath math="\frac{0}{0}" />. We factor first:

<MathContainer>
<BlockMath math="x^2 - 1 = (x + 1)(x - 1)" />
<BlockMath math="\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = \lim_{x \to 1} \frac{(x + 1)(x - 1)}{x - 1}" />
</MathContainer>

Since the limit uses nearby values with <InlineMath math="x \neq 1" />, we may cancel <InlineMath math="(x - 1)" /> before evaluating the simplified expression:

<BlockMath math="\lim_{x\to1}\frac{x^2-1}{x-1}= \lim_{x \to 1} (x + 1) = 1 + 1 = 2" />

### A Sine Limit in Radians

This **fundamental trigonometric limit** is used to derive the derivatives of sine and cosine. Direct substitution gives the indeterminate form <InlineMath math="\frac{0}{0}" />, so we use the trigonometric limit theorem:

<BlockMath math="\lim_{x \to 0} \frac{\sin x}{x} = 1" />

**Note**: Measure <InlineMath math="x" /> in radians. Degrees give a different result.

### Different Left and Right Limits

For piecewise functions (defined with different rules), we must check left and right limits separately:

**Left limit** (when <InlineMath math="x" /> approaches <InlineMath math="2" /> from the left, so <InlineMath math="x < 2" />):

<BlockMath math="\begin{aligned} \lim_{x \to 2^-} f(x) &amp;= \lim_{x \to 2^-} (x + 1) \\ &amp;= 2 + 1 \\ &amp;= 3 \end{aligned}" />

**Right limit** (when <InlineMath math="x" /> approaches <InlineMath math="2" /> from the right, so nearby inputs satisfy <InlineMath math="x > 2" />):

<BlockMath math="\begin{aligned} \lim_{x \to 2^+} f(x) &amp;= \lim_{x \to 2^+} (3x - 2) \\ &amp;= 3(2) - 2 \\ &amp;= 6 - 2 \\ &amp;= 4 \end{aligned}" />

Since <InlineMath math="\lim_{x \to 2^-} f(x) = 3 \neq 4 = \lim_{x \to 2^+} f(x)" />, then <InlineMath math="\lim_{x \to 2} f(x)" /> **does not exist**.
