## Modalklasse bei gruppierten Daten

Wenn Daten in Intervalle eingeteilt werden, enthält die Tabelle nicht mehr jeden ursprünglichen Beobachtungswert. Die **Modalklasse** lässt sich trotzdem bestimmen, ein exakter Modalwert dagegen nicht unbedingt.

Die **Modalklasse** ist das Klassenintervall mit der **höchsten Häufigkeit**. Es enthält also <Highlight>mehr Beobachtungen als jedes andere Intervall</Highlight>.

**Durchgerechnetes Beispiel:**

Die folgende Tabelle zeigt die verkauften Schuhgrößen in Geschäft A:

| Schuhgröße (Klassenintervall) | Häufigkeit (<InlineMath math="f_i" />) |
| :----------- | :------------------------------------ |
| <InlineMath math="37\text{-}39" /> | <InlineMath math="2" /> |
| <InlineMath math="40\text{-}42" /> | <InlineMath math="11" /> |
| <InlineMath math="43\text{-}45" /> | <InlineMath math="16" /> (höchste Häufigkeit) |
| <InlineMath math="46\text{-}48" /> | <InlineMath math="1" /> |
| **Gesamt** | <InlineMath math="30" /> |

Die höchste Häufigkeit beträgt <InlineMath math="16" />. Damit ist <InlineMath math="43\text{-}45" /> die Modalklasse.

Dieses Intervall enthält die **meisten Verkäufe als gesamte Klasse**. Der häufigste Einzelwert muss jedoch nicht in dieser Klasse liegen. Die <InlineMath math="16" /> Verkäufe könnten sich etwa auf drei Größen verteilen, während die <InlineMath math="11" /> Verkäufe einer anderen Klasse alle dieselbe Größe betreffen. Diese Einzelheiten fehlen in der gruppierten Tabelle.

## Median für gruppierte Daten

Der Median teilt geordnete Daten in zwei gleich große Hälften. Eine gruppierte Tabelle enthält Klassenintervalle und Häufigkeiten anstelle der einzelnen Beobachtungswerte. Deshalb bestimmen wir zuerst die Medianklasse und **schätzen dann die Position des Medians** innerhalb dieser Klasse.
### Medianklasse und Medianposition bestimmen

Berechne die **kumulierte Häufigkeit**, indem du die Häufigkeiten von der ersten bis zur betrachteten Klasse addierst. Suche die erste Klasse, deren kumulierte Häufigkeit <InlineMath math="n/2" /> erreicht. Innerhalb dieser Klasse schätzt du den Median durch Interpolation:

<BlockMath math="\operatorname{Me}=L+\frac{n/2-F}{f_{\mathrm{Me}}}\,c" />

| Symbol | Bedeutung |
| --- | --- |
| <InlineMath math="\operatorname{Me}" /> | Geschätzter Median |
| <InlineMath math="L" /> | Untere stetige Grenze der Medianklasse |
| <InlineMath math="n" /> | Gesamthäufigkeit |
| <InlineMath math="F" /> | Kumulierte Häufigkeit vor der Medianklasse |
| <InlineMath math="f_{\mathrm{Me}}" /> | Häufigkeit der Medianklasse |
| <InlineMath math="c" /> | Klassenbreite |

Bei aufeinanderfolgenden ganzzahligen Größen liegen die stetigen Klassengrenzen eine halbe Einheit außerhalb der angegebenen Grenzen. Die Klasse <InlineMath math="43\text{-}45" /> verwendet daher <InlineMath math="42{,}5" /> und <InlineMath math="45{,}5" /> als stetige Grenzen. Die **Interpolation setzt eine gleichmäßige Verteilung** dazwischen voraus. Da die Einzelwerte fehlen, ist das Ergebnis eine Schätzung.

**Durchgerechnetes Beispiel:**

Wir verwenden wieder die Schuhgrößen aus Geschäft A.

| Schuhgröße | Häufigkeit (<InlineMath math="f_i" />) | Kumulierte Häufigkeit (<InlineMath math="F_k" />) |
| :-------- | :------------------------------------ | :------------------ |
| <InlineMath math="37\text{-}39" /> | <InlineMath math="2" /> | <InlineMath math="2" /> |
| <InlineMath math="40\text{-}42" /> | <InlineMath math="11" /> | <InlineMath math="2 + 11 = 13" /> |
| <InlineMath math="43\text{-}45" /> | <InlineMath math="16" /> (<InlineMath math="f_{\mathrm{Me}}" />) | <InlineMath math="13 + 16 = 29" /> |
| <InlineMath math="46\text{-}48" /> | <InlineMath math="1" /> | <InlineMath math="29 + 1 = 30" /> |
| Gesamt | <InlineMath math="n = 30" /> |                                                  |

Die Medianposition ist <InlineMath math="n/2=30/2=15" />. Nach der zweiten Klasse beträgt die kumulierte Häufigkeit <InlineMath math="13" />, nach der dritten <InlineMath math="29" />. Die **Medianklasse** ist daher <InlineMath math="43\text{-}45" />. Aus der Tabelle erhalten wir:

| Größe | Wert |
| --- | --- |
| <InlineMath math="L" /> | <InlineMath math="43-0{,}5=42{,}5" /> |
| <InlineMath math="n/2" /> | <InlineMath math="30/2=15" /> |
| <InlineMath math="F" /> | <InlineMath math="13" /> |
| <InlineMath math="f_{\mathrm{Me}}" /> | <InlineMath math="16" /> |

Die Klassenbreite ist die Differenz der beiden stetigen Grenzen:

<BlockMath math="\begin{aligned} c &amp;= (45 + 0{,}5) - (43 - 0{,}5) \\ &amp;= 45{,}5 - 42{,}5 \\ &amp;= 3 \end{aligned}" />

**Einsetzen in die Medianformel:**

<MathContainer>
  <BlockMath math="\operatorname{Me} = 42{,}5 + \left( \frac{15 - 13}{16} \right) \times 3" />
  <BlockMath math="\operatorname{Me} = 42{,}5 + \left( \frac{2}{16} \right) \times 3" />
  <BlockMath math="\operatorname{Me} = 42{,}5 + \left( \frac{1}{8} \right) \times 3" />
  <BlockMath math="\operatorname{Me} = 42{,}5 + \frac{3}{8}" />
  <BlockMath math="\operatorname{Me} = 42{,}5 + 0{,}375" />
  <BlockMath math="\operatorname{Me} = 42{,}875" />
</MathContainer>

Der geschätzte Median der Schuhgrößen beträgt <InlineMath math="42{,}875" />. Dieser Wert liegt zwischen den stetigen Klassengrenzen <InlineMath math="42{,}5" /> und <InlineMath math="45{,}5" />, die für die Interpolation verwendet werden.

Das Ergebnis ist eine **Schätzung**, die aus den gruppierten Intervallen stammt. Durch die Gruppierung gehen die genauen Werte innerhalb der Intervalle verloren. Für den [Mittelwert gruppierter Daten](/de/faecher/mathematik/grundlagen-der-statistik/mittelwert-gruppierter-daten) gilt dieselbe Einschränkung.
