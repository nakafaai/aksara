## Modal Class for Grouped Data

When data are grouped into intervals, the table no longer contains each original observation. We can still identify the **modal class**, but the table may not identify one exact mode.

The **modal class** is the class interval with the **highest frequency**, so it contains <Highlight>more observations than any other interval</Highlight>.

**Worked example:**

Store A's shoe size data:

| Shoe Size (Class Interval) | Frequency (<InlineMath math="f_i" />) |
| :------------------------- | :------------------------------------ |
| <InlineMath math="37\text{-}39" /> | <InlineMath math="2" />               |
| <InlineMath math="40\text{-}42" /> | <InlineMath math="11" />              |
| <InlineMath math="43\text{-}45" /> | <InlineMath math="16" /> (Highest Frequency) |
| <InlineMath math="46\text{-}48" /> | <InlineMath math="1" />               |
| **Total**                  | <InlineMath math="30" />              |

The highest frequency is <InlineMath math="16" />, so the modal class is <InlineMath math="43\text{-}45" />.

That interval contains the **most sales as a class**. The most frequent individual size need not belong to it. For example, the <InlineMath math="16" /> sales could be spread across three sizes, while the <InlineMath math="11" /> sales in another class could all have one size. The grouped table does not supply that detail.

## Median for Grouped Data

The median splits ordered data into two equal halves. A grouped table lists intervals together with their frequencies. We therefore locate the median class and **estimate the median's position** within that class.
### Locating the Median Class and Position

Calculate the **cumulative frequency** by adding the class frequencies from the first through the current class. Find the first class whose cumulative frequency reaches <InlineMath math="n/2" />. Within that class, estimate the median by interpolation:

<BlockMath math="\operatorname{Me}=L+\frac{n/2-F}{f_{\mathrm{Me}}}\,c" />

| Symbol | Meaning |
| --- | --- |
| <InlineMath math="\operatorname{Me}" /> | Estimated median |
| <InlineMath math="L" /> | Lower boundary of the median class |
| <InlineMath math="n" /> | Total frequency |
| <InlineMath math="F" /> | Cumulative frequency before the median class |
| <InlineMath math="f_{\mathrm{Me}}" /> | Frequency of the median class |
| <InlineMath math="c" /> | Class width |

For sizes recorded as consecutive integers, class boundaries lie half a unit beyond the class limits. The class <InlineMath math="43\text{-}45" /> therefore uses boundaries <InlineMath math="42.5" /> and <InlineMath math="45.5" />. **Interpolation assumes a uniform spread** between these boundaries. Because the original values are unknown, the result is an estimate.

**Worked example:**

Use Store A's shoe size data from the table below.

| Shoe Size | Frequency (<InlineMath math="f_i" />) | Cumulative Frequency (<InlineMath math="F_k" />) |
| :-------- | :------------------------------------ | :----------------------------------------------- |
| <InlineMath math="37\text{-}39" /> | <InlineMath math="2" /> | <InlineMath math="2" /> |
| <InlineMath math="40\text{-}42" /> | <InlineMath math="11" /> | <InlineMath math="2 + 11 = 13" /> |
| <InlineMath math="43\text{-}45" /> | <InlineMath math="16" /> (<InlineMath math="f_{\mathrm{Me}}" />) | <InlineMath math="13 + 16 = 29" /> |
| <InlineMath math="46\text{-}48" /> | <InlineMath math="1" /> | <InlineMath math="29 + 1 = 30" /> |
| Total     | <InlineMath math="n = 30" />          |                                                  |

The median position is <InlineMath math="n/2=30/2=15" />. The cumulative frequency is <InlineMath math="13" /> after the second class and <InlineMath math="29" /> after the third. The **median class** is therefore <InlineMath math="43\text{-}45" />. The table gives:

| Quantity | Value |
| --- | --- |
| <InlineMath math="L" /> | <InlineMath math="43-0.5=42.5" /> |
| <InlineMath math="n/2" /> | <InlineMath math="30/2=15" /> |
| <InlineMath math="F" /> | <InlineMath math="13" /> |
| <InlineMath math="f_{\mathrm{Me}}" /> | <InlineMath math="16" /> |

The class width is the difference between its two boundaries:

<BlockMath math="\begin{aligned} c &amp;= (45 + 0.5) - (43 - 0.5) \\ &amp;= 45.5 - 42.5 \\ &amp;= 3 \end{aligned}" />

**Substitute into the median formula:**

<MathContainer>
  <BlockMath math="\operatorname{Me} = 42.5 + \left( \frac{15 - 13}{16} \right) \times 3" />
  <BlockMath math="\operatorname{Me} = 42.5 + \left( \frac{2}{16} \right) \times 3" />
  <BlockMath math="\operatorname{Me} = 42.5 + \left( \frac{1}{8} \right) \times 3" />
  <BlockMath math="\operatorname{Me} = 42.5 + \frac{3}{8}" />
  <BlockMath math="\operatorname{Me} = 42.5 + 0.375" />
  <BlockMath math="\operatorname{Me} = 42.875" />
</MathContainer>

The estimated median shoe size is <InlineMath math="42.875" />. This value lies between the class boundaries <InlineMath math="42.5" /> and <InlineMath math="45.5" /> used for interpolation.

This result is an **estimate**. The exact values inside each interval are unavailable, so the original middle observation cannot be recovered. The [mean for grouped data](/en/subjects/mathematics/statistics-foundations/mean-group-data) has the same limitation.
