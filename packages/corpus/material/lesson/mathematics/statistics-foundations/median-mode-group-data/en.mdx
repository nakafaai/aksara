## Modal Class for Grouped Data

When data are grouped into intervals, the table no longer contains each original observation. We can still identify the **modal class**, but the table may not identify one exact mode.

The **modal class** is the class interval with the **highest frequency**, so it contains more observations than any other interval.

**Worked example:**

Store A's shoe size data:

| Shoe Size (Class Interval) | Frequency (<InlineMath math="f_i" />) |
| :------------------------- | :------------------------------------ |
| <InlineMath math="37\text{-}39" /> | <InlineMath math="2" />               |
| <InlineMath math="40\text{-}42" /> | <InlineMath math="11" />              |
| <InlineMath math="43\text{-}45" /> | <InlineMath math="16" /> (Highest Frequency) |
| <InlineMath math="46\text{-}48" /> | <InlineMath math="1" />               |
| **Total**                  | <InlineMath math="30" />              |

The highest frequency is <InlineMath math="16" />, so the modal class is <InlineMath math="43\text{-}45" />.

This tells us that the most frequently sold shoe sizes lie in that interval. Because the data are grouped, the table does not identify which individual size occurs most often.

## Median for Grouped Data

The median splits ordered data into two equal halves. A grouped table provides intervals and frequencies instead of individual observations. We therefore locate the median class and estimate the median's position within that class.

### How to Find the Median for Grouped Data

1.  **Calculate the median position:**

    Locate the middle of the data with <InlineMath math="n/2" />, where <InlineMath math="n" /> is the total frequency.

2.  **Create the cumulative frequency:**

    Add a cumulative-frequency column (<InlineMath math="F_k" />). Each entry is the sum of all frequencies from the first class through the current class.

3.  **Determine the median class:**

    The median class is the first class whose cumulative frequency is **equal to or greater than** <InlineMath math="n/2" />.

4.  **Use the median formula:**

    Once the median class is known, estimate the median with:

    <BlockMath math="\operatorname{Me} = L + \left( \frac{\frac{n}{2} - F}{f_{\mathrm{Me}}} \right) \times c" />

    where:

    - <InlineMath math="\operatorname{Me}" /> = estimated median of the grouped data
    - <InlineMath math="L" /> = **lower boundary of the median class**. For adjacent
      integer-valued classes, calculate it with:

      <BlockMath math="L = \text{Lower Limit of Median Class} - 0.5" />

    - <InlineMath math="n" /> = total frequency
    - <InlineMath math="F" /> = cumulative frequency **before** the median class
    - <InlineMath math="f_{\mathrm{Me}}" /> = frequency of the median class
    - <InlineMath math="c" /> = class width, calculated with:

      <BlockMath math="c = \text{Upper Class Boundary} - \text{Lower Class Boundary}" />

      Here, the <InlineMath math="0.5" /> correction applies because the shoe sizes are recorded as consecutive integers.

    The interpolation also assumes that observations are distributed uniformly within the median class. The result is therefore an estimate from the grouped intervals. The grouped table does not contain the original individual values.

**Worked example:**

Use Store A's shoe size data from the table below.

| Shoe Size | Frequency (<InlineMath math="f_i" />) | Cumulative Frequency (<InlineMath math="F_k" />) |
| :-------- | :------------------------------------ | :----------------------------------------------- |
| <InlineMath math="37 - 39" /> | <InlineMath math="2" /> | <InlineMath math="2" /> |
| <InlineMath math="40 - 42" /> | <InlineMath math="11" /> | <InlineMath math="2 + 11 = 13" /> |
| <InlineMath math="43 - 45" /> | <InlineMath math="16" /> (<InlineMath math="f_{\mathrm{Me}}" />) | <InlineMath math="13 + 16 = 29" /> |
| <InlineMath math="46 - 48" /> | <InlineMath math="1" /> | <InlineMath math="29 + 1 = 30" /> |
| Total     | <InlineMath math="n = 30" />          |                                                  |

1.  **Median position:** <InlineMath math="n/2 = 30/2 = 15" />. We need the observation at position <InlineMath math="15" />.
2.  **Cumulative frequency:** The table already includes it.
3.  **Median class:** The cumulative frequency reaches <InlineMath math="13" /> after the second class and <InlineMath math="29" /> after the third. Position <InlineMath math="15" /> therefore lies in <InlineMath math="43\text{-}45" />.
4.  **Formula components:**

    - Median class: <InlineMath math="43\text{-}45" />
    - Lower boundary: <InlineMath math="L = 43 - 0.5 = 42.5" />
    - <InlineMath math="n/2 = 30/2 = 15" />
    - Cumulative frequency before the median class: <InlineMath math="F = 13" />
    - Median-class frequency: <InlineMath math="f_{\mathrm{Me}} = 16" />
    - Class width: <InlineMath math="c = \text{Upper Boundary} - \text{Lower Boundary}" />

      <BlockMath math="c = (45 + 0.5) - (43 - 0.5) = 45.5 - 42.5 = 3" />

5.  **Substitute into the median formula:**

    <MathContainer>
      <BlockMath math="\operatorname{Me} = 42.5 + \left( \frac{15 - 13}{16} \right) \times 3" />
      <BlockMath math="\operatorname{Me} = 42.5 + \left( \frac{2}{16} \right) \times 3" />
      <BlockMath math="\operatorname{Me} = 42.5 + \left( \frac{1}{8} \right) \times 3" />
      <BlockMath math="\operatorname{Me} = 42.5 + \frac{3}{8}" />
      <BlockMath math="\operatorname{Me} = 42.5 + 0.375" />
      <BlockMath math="\operatorname{Me} = 42.875" />
    </MathContainer>

**The estimated median shoe size is <InlineMath math="42.875" />.** It falls inside the median class <InlineMath math="43\text{-}45" /> once the continuous class boundaries are used.

This result is an **estimate**. The exact values inside each interval are unavailable, so the original middle observation cannot be recovered. The [mean for grouped data](/en/subjects/mathematics/statistics-foundations/mean-group-data) has the same limitation.
