## Estimating Quartile Positions within Class Intervals

For [ungrouped data](/en/subjects/mathematics/statistics-foundations/quartile-data-single), we can sort every observation and identify its position directly. A grouped frequency table provides only the intervals, such as <InlineMath math="70\text{-}79" /> and <InlineMath math="80\text{-}89" />, and the number of observations in each interval. It does not contain the individual values.

As with the [median for grouped data](/en/subjects/mathematics/statistics-foundations/median-mode-group-data), we therefore estimate <InlineMath math="Q_1" />, <InlineMath math="Q_2" />, and <InlineMath math="Q_3" /> by **interpolation**. The calculation places each quartile within the class interval that contains its target position.

We determine the position of the quartile using this formula:

- The position of <InlineMath math="Q_1" /> is the <InlineMath math="\frac{1}{4}n" />-th data point
- The position of <InlineMath math="Q_2" /> is the <InlineMath math="\frac{2}{4}n" />-th data point (or <InlineMath math="\frac{1}{2}n" />-th)
- The position of <InlineMath math="Q_3" /> is the <InlineMath math="\frac{3}{4}n" />-th data point

Where <InlineMath math="n" /> is the total number of data points.

Add the frequencies class by class to get the cumulative frequencies <InlineMath math="2, 13, 23, 28, 30" />. The last bar is always the total <InlineMath math="30" />, and the class where a bar first passes a target position is the class to interpolate in.

## Steps to Find the Value of Quartiles for Grouped Data

Consider the grouped shoe-sales data from Store A. The frequency table below gives each class interval and how many pairs fall in it, and the quartiles are estimated by **interpolating** inside the class that contains the position you want. Work through the steps with the table open, because every value you substitute comes from it.
### Create a Cumulative Frequency Table

First, we need a frequency table with a cumulative frequency column (<InlineMath math="F_k" />). Cumulative frequency is the sum of frequencies from the first class up to that class. This is important to know which class the quartile falls into.

For example, here is the shoe sales table:

| :-------: | :---------------------------------: | :----------------------------------------------: | :----------------------------------------: | :----------------------------------------: | :-----------------------------------: |
| <InlineMath math="37\text{-}39" /> | <InlineMath math="2" />  | <InlineMath math="2" />  | <InlineMath math="36.5" /> | <InlineMath math="39.5" /> | <InlineMath math="3" /> |
| <InlineMath math="40\text{-}42" /> | <InlineMath math="11" /> | <InlineMath math="13" /> | <InlineMath math="39.5" /> | <InlineMath math="42.5" /> | <InlineMath math="3" /> |
| <InlineMath math="43\text{-}45" /> | <InlineMath math="10" /> | <InlineMath math="23" /> | <InlineMath math="42.5" /> | <InlineMath math="45.5" /> | <InlineMath math="3" /> |
| <InlineMath math="46\text{-}48" /> | <InlineMath math="5" />  | <InlineMath math="28" /> | <InlineMath math="45.5" /> | <InlineMath math="48.5" /> | <InlineMath math="3" /> |
| <InlineMath math="49\text{-}51" /> | <InlineMath math="2" />  | <InlineMath math="30" /> | <InlineMath math="48.5" /> | <InlineMath math="51.5" /> | <InlineMath math="3" /> |
| **Total** | <InlineMath math="30" /> |                                                  |                                            |                                            |                                       |

The lower boundary is the lower class limit minus <InlineMath math="0.5" />.

The upper boundary is the upper class limit plus <InlineMath math="0.5" />.

The class width is the upper boundary minus the lower boundary.

### Determine the Quartile Class Position

First, locate each quartile position.

Total data (<InlineMath math="n" />) is <InlineMath math="30" />.

- **Position of <InlineMath math="Q_1" />**: the <InlineMath math="\frac{1}{4} \times 30 = 7.5" />-th data point.

  In the <InlineMath math="F_k" /> column, the first class ends at position <InlineMath math="2" /> and the second ends at position <InlineMath math="13" />. Positions <InlineMath math="3" /> through <InlineMath math="13" /> belong to the second class, so position <InlineMath math="7.5" /> lies in <InlineMath math="40\text{-}42" />.

- **Position of <InlineMath math="Q_2" /> (Median)**: the <InlineMath math="\frac{1}{2} \times 30 = 15" />-th data point.

  Look at <InlineMath math="F_k" />. The <InlineMath math="15" />th data point is in the <InlineMath math="43\text{-}45" /> class (because the previous <InlineMath math="F_k" /> was <InlineMath math="13" />, and this class's <InlineMath math="F_k" /> is <InlineMath math="23" />).

- **Position of <InlineMath math="Q_3" />**: the <InlineMath math="\frac{3}{4} \times 30 = 22.5" />-th data point.

  Look at <InlineMath math="F_k" />. The <InlineMath math="22.5" />th data point is also in the <InlineMath math="43\text{-}45" /> class (because the previous <InlineMath math="F_k" /> was <InlineMath math="13" />, and this class's <InlineMath math="F_k" /> is <InlineMath math="23" />).

### Estimate the Quartile Value by Interpolation

Once the quartile class is known, estimate the value within that interval with:

<BlockMath math="Q_i = T_b + \left( \frac{\frac{i}{4}n - F_{\text{cum}}}{f_i} \right) p" />

The quantities in this formula are:

- <InlineMath math="Q_i" /> = Value of the i-th Quartile (what we're looking for)
- <InlineMath math="T_b" /> = Lower boundary of the i-th quartile class
- <InlineMath math="n" /> = Total frequency
- <InlineMath math="F_{\text{cum}}" /> = cumulative frequency **before** the <InlineMath math="i" />-th quartile
  class
- <InlineMath math="f_i" /> = Frequency of the i-th quartile class
- <InlineMath math="p" /> = Class width

This interpolation assumes that observations are <Highlight>distributed uniformly within the selected class</Highlight>. It is a model-based estimate and cannot recover the original values that were omitted when the data were grouped.

## Finding the Shoe Sales Quartile

Calculate <InlineMath math="Q_1" /> from the table above.

**Position of <InlineMath math="Q_1" />**: <InlineMath math="7.5" />th data point.
**Class of <InlineMath math="Q_1" />**: <InlineMath math="40\text{-}42" />.
**Values to substitute**

| Quantity | Value |
| --- | --- |
| <InlineMath math="T_b" /> | <InlineMath math="39.5" /> |
| <InlineMath math="n" /> | <InlineMath math="30" /> |
| <InlineMath math="F_{\mathrm{cum}}" /> | <InlineMath math="2" /> |
| <InlineMath math="f_i" /> | <InlineMath math="11" /> |
| <InlineMath math="p" /> | <InlineMath math="3" /> |
Plug into the formula:

<MathContainer>
  <BlockMath math="Q_1 = T_b + \left( \frac{\frac{1}{4}n - F_{\text{cum}}}{f_1} \right) p" />
  <BlockMath math="Q_1 = 39.5 + \left( \frac{7.5 - 2}{11} \right) 3" />
  <BlockMath math="Q_1 = 39.5 + \left( \frac{5.5}{11} \right) 3" />
  <BlockMath math="Q_1 = 39.5 + (0.5) \times 3" />
  <BlockMath math="Q_1 = 39.5 + 1.5" />
  <BlockMath math="Q_1 = 41" />
</MathContainer>

So, the value of <InlineMath math="Q_1" /> is <InlineMath math="41" />. This means about <InlineMath math="25\%" /> of the shoes sold are size <InlineMath math="41" /> or smaller.

You can check the interpolation formula on the cumulative frequency line. At the level <InlineMath math="n/4 = 7.5" /> the line is inside the class <InlineMath math="40\text{-}42" />, above <InlineMath math="Q_1 = 41" />. At <InlineMath math="3n/4 = 22.5" /> it is inside <InlineMath math="43\text{-}45" />, above <InlineMath math="Q_3 = 45.35" />. **Comparison with Single Data**:

Finding quartiles for grouped data uses **interpolation** because the table provides intervals and frequencies without the individual observations. The result is an estimated quartile value.

For ungrouped data, the ordered observations are known, so the declared quartile convention can select one value or interpolate directly between two known values. Grouped interpolation is less precise because the observations inside each class are no longer available.
