## Counting Choices by Slots

The **slot filling rule** counts arrangements by multiplying the number of <Highlight>valid choices for each successive slot</Highlight>. It applies when every complete outcome can be built through a fixed sequence of choices.

A form with several fields follows the same pattern. Each field is a slot and each allowed entry is a choice. Multiplying the valid choices gives the number of complete forms.

## Listing Choices in a Table

The table method lists **every combination**. Rows represent choices from one category and columns represent choices from another.

Suppose a student wants to choose an online learning package. There are three platforms (Platform A, Platform B, Platform C) and four subjects (Mathematics, Physics, Chemistry, Biology).

A table lists all possible combinations:

| Platform | Mathematics | Physics | Chemistry | Biology |
|----------|-------------|---------|-----------|---------|
| Platform A | A-Math | A-Phys | A-Chem | A-Bio |
| Platform B | B-Math | B-Phys | B-Chem | B-Bio |
| Platform C | C-Math | C-Phys | C-Chem | C-Bio |

<MathContainer>
<BlockMath math="\begin{aligned} \text{Total combinations} &amp;= 3 \times 4 \\ &amp;= 12 \text{ ways} \end{aligned}" />
</MathContainer>
## Tree Diagram Method

In a **tree diagram**, each branch records one choice. A complete path from the starting point to an endpoint represents one complete outcome.

For the same package selection, the first branches choose a platform and the next branches choose a subject.

<Mermaid title="Two levels of package choices" description="Each of three platform choices branches into four subject choices." chart={`flowchart LR
  S["Start"]
  S --> A["Platform A"]
  A --> A0["Mathematics"]
  A --> A1["Physics"]
  A --> A2["Chemistry"]
  A --> A3["Biology"]
  S --> B["Platform B"]
  B --> B0["Mathematics"]
  B --> B1["Physics"]
  B --> B2["Chemistry"]
  B --> B3["Biology"]
  S --> C["Platform C"]
  C --> C0["Mathematics"]
  C --> C1["Physics"]
  C --> C2["Chemistry"]
  C --> C3["Biology"]

Each platform opens four subject branches. Thus **each complete path** chooses exactly one platform and one subject. For example, Start → Platform A → Physics means Platform A for Physics.

<BlockMath math="3 \times 4 = 12" />

## Multiplication Rule Method

The **multiplication rule** gives the same count without listing every outcome. If there are <InlineMath math="n" /> slots and slot <InlineMath math="i" /> has <InlineMath math="k_i" /> valid choices, then the number of complete outcomes is:

<MathContainer>
<BlockMath math="\begin{aligned} &amp;\text{Total ways} \\ &amp;= k_1 \times k_2 \times k_3 \times \cdots \times k_n \end{aligned}" />
</MathContainer>

The first slot has a fixed number of choices. For each later slot, the number must be the same **for every valid earlier selection**, although the available choices may differ. If branch counts differ, count the branch groups separately and add them.

### Counting Access Codes

A school wants to create access codes for digital learning systems. The code has **three ordered slots**:
- First slot: <InlineMath math="3 \text{ letters}" /> (<InlineMath math="A, B, C" />)
- Second slot: <InlineMath math="5 \text{ numbers}" /> (<InlineMath math="1, 2, 3, 4, 5" />)
- Third slot: <InlineMath math="2 \text{ symbols}" /> (<InlineMath math="@, \#" />)

Multiply the choices for the three slots:

<MathContainer>
<BlockMath math="k_1 = 3 \text{ (letter choices)}" />
<BlockMath math="k_2 = 5 \text{ (number choices)}" />
<BlockMath math="k_3 = 2 \text{ (symbol choices)}" />
<BlockMath math="\begin{aligned} &amp;\text{Total different codes} \\ &amp;= 3 \times 5 \times 2 \\ &amp;= 30 \text{ codes} \end{aligned}" />
</MathContainer>
## Cases with Restrictions

Restrictions can change the number of choices from one slot to the next. Decide for each slot whether an **earlier choice** removes an option, because that is what decides whether the factors stay equal. The examples below work through both cases.
### Repetition Not Allowed

If the same object **cannot be used repeatedly**, then each filled slot will reduce the choices for the next slot.

**Example**: Creating a <InlineMath math="3 \text{-digit}" /> number from digits <InlineMath math="2, 3, 4, 5, 6" /> without repetition.

The first slot has <InlineMath math="5" /> choices. Once <InlineMath math="1" /> digit has been used, <InlineMath math="4" /> choices remain for the second slot. After <InlineMath math="2" /> digits have been used, the third slot has <InlineMath math="3" /> choices.

<BlockMath math="\begin{aligned} \text{Total numbers} &amp;= 5 \times 4 \times 3 \\ &amp;= 60 \text{ numbers} \end{aligned}" />

### Repetition Allowed

If the same object **can be used repeatedly**, then the choices in each slot remain the same.

For the same case with repetition allowed:

<MathContainer>
<BlockMath math="\text{Each slot} = 5 \text{ choices}" />
<BlockMath math="\begin{aligned} \text{Total numbers} &amp;= 5 \times 5 \times 5 \\ &amp;= 125 \text{ numbers} \end{aligned}" />
</MathContainer>

## Exercises

Each problem fills several places in order. Count the choices for one place at a time, multiply them, and watch for the problem that **forbids repetition**.

1. An electronics store sells smartphones with <InlineMath math="4" /> different brands, each available in <InlineMath math="3" /> memory capacities and <InlineMath math="5" /> color choices. How many different smartphone combinations are there?

2. A password contains <InlineMath math="1" /> letter followed by <InlineMath math="2" /> digits. Choose the letter from A, B, C, D and the digits from <InlineMath math="\{1, 2, 3, 4, 5\}" /> without repetition. How many passwords are possible?

3. From city <InlineMath math="P" /> to city <InlineMath math="R" /> through city <InlineMath math="Q" />, there are <InlineMath math="3" /> roads from <InlineMath math="P" /> to <InlineMath math="Q" /> and <InlineMath math="4" /> roads from <InlineMath math="Q" /> to <InlineMath math="R" />. How many different routes can be chosen for the journey from <InlineMath math="P" /> to <InlineMath math="R" />?

4. A license plate contains <InlineMath math="2" /> letters followed by <InlineMath math="3" /> digits. If all <InlineMath math="26" /> letters and the <InlineMath math="10" /> digits <InlineMath math="0\text{-}9" /> are available and repetition is allowed, how many plates are possible?
### Answer Key

**Problem 1**. Each brand can be paired with every capacity and color, so **multiply the choice counts** across the three categories.

Given: <InlineMath math="4 \text{ brands}" />, <InlineMath math="3 \text{ memory capacities}" />, <InlineMath math="5 \text{ color choices}" />

The number of smartphone combinations is:

<BlockMath math="4\times3\times5=60" />

**Problem 2**

Given: <InlineMath math="1 \text{ letter}" /> from <InlineMath math="\{A, B, C, D\}" />, <InlineMath math="2 \text{ digits}" /> from <InlineMath math="\{1, 2, 3, 4, 5\}" /> without repetition

There are <InlineMath math="4" /> choices for the letter and <InlineMath math="5" /> for the first digit. **Repetition is forbidden**, so only <InlineMath math="4" /> choices remain for the second digit.

<BlockMath math="\begin{aligned} &amp;\text{Total passwords} \\ &amp;= 4 \times 5 \times 4 \\ &amp;= 80 \text{ passwords} \end{aligned}" />

**Problem 3**. Each road on the first leg can be followed by any road on the second leg. Use the **multiplication principle** to count complete routes.

Given: <InlineMath math="3 \text{ roads}" /> from <InlineMath math="P" /> to <InlineMath math="Q" />, <InlineMath math="4 \text{ roads}" /> from <InlineMath math="Q" /> to <InlineMath math="R" />

<MathContainer>
<BlockMath math="\begin{aligned} &amp;\text{Total routes} \\ &amp;= 3 \times 4 \\ &amp;= 12 \text{ different routes} \end{aligned}" />
</MathContainer>

**Problem 4**

Given: <InlineMath math="2 \text{ letters}" /> from <InlineMath math="26 \text{ letters}" />, <InlineMath math="3 \text{ digits}" /> from <InlineMath math="10 \text{ digits}" />, **repetition allowed**

<BlockMath math="\begin{aligned} &amp;\text{First letter choices} = 26 \end{aligned}" />
The second letter has <InlineMath math="26" /> choices.
<BlockMath math="\text{Choices for each digit} = 10" />
The total number of license plates is:

<BlockMath math="\begin{aligned}26\times26\times10\times10\times10 &amp;=676\times1000\\ &amp;=676000\text{  license plates}\end{aligned}" />
