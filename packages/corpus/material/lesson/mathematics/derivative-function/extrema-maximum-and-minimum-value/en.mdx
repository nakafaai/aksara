## Understanding Extreme Points

In everyday life, we often look for the "best" value, like the biggest profit, the smallest cost, or the shortest distance. In mathematics, these optimal values are known as **extreme values**, which consist of **maximum values** and **minimum values**. The points where these values occur are called **extreme points**.

An interior local extremum of a differentiable function is a **stationary point**, where <InlineMath math="f'(x)=0" />. More generally, local extrema may also occur where the derivative is undefined or at an endpoint of the domain. A stationary point is therefore a candidate, not a guarantee, for a local extremum. This lesson focuses on differentiable stationary points and classifies them with the First and Second Derivative Tests.

## First Derivative Test

This method focuses on the change in the function's behavior, i.e., whether it's increasing or decreasing, around a stationary point. By observing the sign of <InlineMath math="f'(x)" />, we can identify the type of stationary point.

-   **Maximum Turning Point:** Occurs if the function changes from **increasing to decreasing**. This means the sign of <InlineMath math="f'(x)" /> changes from **positive (+) to negative (-)**. Think of it as the peak of a hill.

-   **Minimum Turning Point:** Occurs if the function changes from **decreasing to increasing**. The sign of <InlineMath math="f'(x)" /> changes from **negative (-) to positive (+)**. This is like the bottom of a valley.

-   **No Local Extremum:** If the sign of <InlineMath math="f'(x)" /> does not change, the stationary point is neither a local maximum nor a local minimum. It may be a horizontal inflection point, but that requires a separate check that the concavity changes.

Apply the test to an example. Determine the stationary values of the function <InlineMath math="f(x) = x(x-3)^2" />.

**Solution:**

**Step** <InlineMath math="1" />: Find the first derivative

First, expand the function: <InlineMath math="f(x) = x(x^2 - 6x + 9) = x^3 - 6x^2 + 9x" />.

Its derivative is:

<BlockMath math="f'(x) = 3x^2 - 12x + 9" />

**Step** <InlineMath math="2" />: Find the stationary points

Set <InlineMath math="f'(x) = 0" />.

<MathContainer>
    <BlockMath math="3x^2 - 12x + 9 = 0" />
    <BlockMath math="x^2 - 4x + 3 = 0" />
    <BlockMath math="(x-1)(x-3) = 0" />
</MathContainer>

The stationary points occur at <InlineMath math="x = 1" /> and <InlineMath math="x = 3" />.

**Step** <InlineMath math="3" />: Test the sign around the stationary points

-   **Around <InlineMath math="x = 1" />:** For <InlineMath math="x < 1" /> (e.g., <InlineMath math="x=0" />), <InlineMath math="f'(0) = 9" /> (positive). For <InlineMath math="x > 1" /> (e.g., <InlineMath math="x=2" />), <InlineMath math="f'(2) = -3" /> (negative). Since the sign changes from (+) to (-), <InlineMath math="x=1" /> is a maximum turning point.

-   **Around <InlineMath math="x = 3" />:** For <InlineMath math="x < 3" /> (e.g., <InlineMath math="x=2" />), <InlineMath math="f'(2) = -3" /> (negative). For <InlineMath math="x > 3" /> (e.g., <InlineMath math="x=4" />), <InlineMath math="f'(4) = 9" /> (positive). Since the sign changes from (-) to (+), <InlineMath math="x=3" /> is a minimum turning point.

**Step** <InlineMath math="4" />: Determine the stationary values

To get the turning point values (<InlineMath math="y" />-values), substitute the stationary point <InlineMath math="x" />-coordinates (<InlineMath math="x = 1" /> and <InlineMath math="x = 3" />) back into the *original* function <InlineMath math="f(x)" />.

-   Local maximum value: <InlineMath math="f(1) = 1(1-3)^2 = 4" />.

-   Local minimum value: <InlineMath math="f(3) = 3(3-3)^2 = 0" />.

So, the local maximum value is <InlineMath math="4" /> at <InlineMath math="(1,4)" />, and the local minimum value is <InlineMath math="0" /> at <InlineMath math="(3,0)" />.

## Second Derivative Test

This method is often faster because it doesn't require testing intervals. It uses the second derivative, <InlineMath math="f''(x)" />, to determine the concavity of the curve at a stationary point.

Suppose <InlineMath math="f'(c) = 0" /> and <InlineMath math="f''" /> is continuous on an interval containing <InlineMath math="c" />.

-   If <InlineMath math="f''(c) < 0" />, then <InlineMath math="f(c)" /> is a **local maximum value**. The curve is concave down at that point, like an upside-down bowl.

-   If <InlineMath math="f''(c) > 0" />, then <InlineMath math="f(c)" /> is a **local minimum value**. The curve is concave up at that point, like an open bowl.

-   If <InlineMath math="f''(c) = 0" />, the test is **inconclusive**. Use the First Derivative Test or another argument; the point could be a maximum, a minimum, an inflection point, or none of these.

Determine the extreme values of <InlineMath math="f(x) = \frac{1}{3}x^3 - x^2 - 3x + 2" /> using the second derivative test.

**Solution:**

**Step** <InlineMath math="1" />: Find the first and second derivatives

<MathContainer>
    <BlockMath math="f'(x) = x^2 - 2x - 3" />
    <BlockMath math="f''(x) = 2x - 2" />
</MathContainer>

**Step** <InlineMath math="2" />: Find the stationary points

<MathContainer>
    <BlockMath math="x^2 - 2x - 3 = 0" />
    <BlockMath math="(x-3)(x+1) = 0" />
</MathContainer>

The stationary points occur at <InlineMath math="x = 3" /> and <InlineMath math="x = -1" />.

**Step** <InlineMath math="3" />: Test the stationary points with the second derivative

-   For <InlineMath math="x = 3" />: <InlineMath math="f''(3) = 2(3) - 2 = 4" />. Since <InlineMath math="4 > 0" />, this gives a **local minimum**.

-   For <InlineMath math="x = -1" />: <InlineMath math="f''(-1) = 2(-1) - 2 = -4" />. Since <InlineMath math="-4 < 0" />, this gives a **local maximum**.

**Step** <InlineMath math="4" />: Calculate the extreme values

Substitute <InlineMath math="x=3" /> and <InlineMath math="x=-1" /> into the original function to get their extreme values.

-   Local minimum value: <InlineMath math="f(3) = \frac{1}{3}(3)^3 - (3)^2 - 3(3) + 2 = 9 - 9 - 9 + 2 = -7" />.

-   Local maximum value: <InlineMath math="f(-1) = \frac{1}{3}(-1)^3 - (-1)^2 - 3(-1) + 2 = -\frac{1}{3} - 1 + 3 + 2 = \frac{11}{3}" />.

If we look at the visualization below, the curve is concave down at the point <InlineMath math="x=-1" /> and concave up at the point <InlineMath math="x=3" />.

## Exercises

1. Determine the stationary point for the function <InlineMath math="y = x^2 + 2x - 3" />.

### Worked Solution

1.  **Solution:**

    **Step** <InlineMath math="1" />: Find the first derivative

    <BlockMath math="f'(x) = 2x + 2" />

    **Step** <InlineMath math="2" />: Find the stationary point

    Set <InlineMath math="f'(x) = 0" />.

    <BlockMath math="2x + 2 = 0 \implies x = -1" />

    **Step** <InlineMath math="3" />: Find the <InlineMath math="y" />-value

    Substitute <InlineMath math="x = -1" /> into the original function.

    <BlockMath math="y = (-1)^2 + 2(-1) - 3 = 1 - 2 - 3 = -4" />

    So, the stationary point is <InlineMath math="(-1, -4)" />. With the Second Derivative Test (<InlineMath math="f''(x)=2 > 0" />), this point is a minimum.
