## Where a Function Can Have an Extremum

A function has a **local maximum** at <InlineMath math="c" /> when <InlineMath math="f(c)" /> is the largest value nearby, and a **local minimum** when it is the smallest value nearby. <Highlight>For a differentiable function, every local extremum inside the domain sits at a stationary point</Highlight>, where <InlineMath math="f'(c)=0" />. Find those points first, then test each one, because not every stationary point is an extremum.

For <InlineMath math="f(x)=x^2-4x" />, the derivative <InlineMath math="f'(x)=2x-4" /> is zero at <InlineMath math="x=2" />. The graph falls before <InlineMath math="x=2" /> and rises after it, so <InlineMath math="f(2)=-4" /> is a local minimum.

Three kinds of points can hold an extremum:

- a [stationary point](/en/subjects/mathematics/derivative-function/increasing-decreasing-and-stationary-function), where <InlineMath math="f'(x)=0" />
- a point where <InlineMath math="f'(x)" /> does not exist, such as the corner of <InlineMath math="|x|" /> at <InlineMath math="x=0" />
- an endpoint, when the function is only looked at on a closed interval

In everyday problems these are the best values, such as the largest profit, the smallest cost, or the shortest distance. The derivative finds them without drawing the whole graph.

## First Derivative Test

The first derivative test reads the **sign of <InlineMath math="f'(x)" /> on both sides** of a stationary point, which tells you whether the function rises or falls there.

-   **Maximum turning point**: the function changes from increasing to decreasing, so <InlineMath math="f'(x)" /> changes from positive to negative, as at a hilltop.
-   **Minimum turning point**: the function changes from decreasing to increasing, so <InlineMath math="f'(x)" /> changes from negative to positive, as at the bottom of a valley.
-   **No local extremum**: the sign of <InlineMath math="f'(x)" /> does not change. The point may be a horizontal inflection point, which needs its own check that the concavity changes.

## Example with the First Derivative Test

Determine the stationary values of <InlineMath math="f(x) = x(x-3)^2" /> with the first derivative test.

**Step 1**: Expand the function and differentiate it.

<MathContainer>
    <BlockMath math="f(x) = x(x^2 - 6x + 9) = x^3 - 6x^2 + 9x" />
    <BlockMath math="f'(x) = 3x^2 - 12x + 9" />
</MathContainer>

**Step 2**: Set <InlineMath math="f'(x) = 0" />.

<MathContainer>
    <BlockMath math="3x^2 - 12x + 9 = 0" />
    <BlockMath math="x^2 - 4x + 3 = 0" />
    <BlockMath math="(x-1)(x-3) = 0" />
</MathContainer>

The stationary points are <InlineMath math="x = 1" /> and <InlineMath math="x = 3" />.

**Step 3**: Test the sign of <InlineMath math="f'" /> on each side.

| Interval | Test value | Sign of <InlineMath math="f'" /> | Behavior |
| --- | --- | --- | --- |
| <InlineMath math="x < 1" /> | <InlineMath math="f'(0) = 9" /> | positive | increasing |
| <InlineMath math="1 < x < 3" /> | <InlineMath math="f'(2) = -3" /> | negative | decreasing |
| <InlineMath math="x > 3" /> | <InlineMath math="f'(4) = 9" /> | positive | increasing |

The sign changes from positive to negative at <InlineMath math="x=1" />, **a maximum**, and from negative to positive at <InlineMath math="x=3" />, **a minimum**.

**Step 4**: Substitute into the *original* function.

<MathContainer>
    <BlockMath math="f(1) = 1(1-3)^2 = 4" />
    <BlockMath math="f(3) = 3(3-3)^2 = 0" />
</MathContainer>

The local maximum value is <InlineMath math="4" /> at <InlineMath math="(1,4)" />, and the local minimum value is <InlineMath math="0" /> at <InlineMath math="(3,0)" />. Check with nearby points: <InlineMath math="f(0.9) = 3.969" /> and <InlineMath math="f(1.1) = 3.971" /> are both below <InlineMath math="4" />, while <InlineMath math="f(2.9)=0.029" /> and <InlineMath math="f(3.1)=0.031" /> are both above <InlineMath math="0" />.

## Second Derivative Test

The second derivative test decides the type at the stationary point itself, without testing neighboring intervals. It uses **the concavity given by <InlineMath math="f''(c)" />**. Suppose <InlineMath math="f'(c) = 0" /> and <InlineMath math="f''" /> is continuous near <InlineMath math="c" />.

-   If <InlineMath math="f''(c) < 0" />, the curve is concave down like an upside-down bowl, and <InlineMath math="f(c)" /> is a local maximum.
-   If <InlineMath math="f''(c) > 0" />, the curve is concave up like an open bowl, and <InlineMath math="f(c)" /> is a local minimum.
-   If <InlineMath math="f''(c) = 0" />, the test gives no answer. The point could be a maximum, a minimum, or neither.

The second derivative usually comes quickly from the [derivative rules for algebraic functions](/en/subjects/mathematics/derivative-function/derivative-of-algebraic-function), so this test is often faster than a sign table.

## Example with the Second Derivative Test

Determine the extreme values of <InlineMath math="f(x) = \frac{1}{3}x^3 - x^2 - 3x + 2" /> with the second derivative test.

**Step 1**: Find both derivatives.

<MathContainer>
    <BlockMath math="f'(x) = x^2 - 2x - 3" />
    <BlockMath math="f''(x) = 2x - 2" />
</MathContainer>

**Step 2**: Solve <InlineMath math="f'(x) = 0" />.

<MathContainer>
    <BlockMath math="x^2 - 2x - 3 = 0" />
    <BlockMath math="(x-3)(x+1) = 0" />
</MathContainer>

The stationary points are <InlineMath math="x = 3" /> and <InlineMath math="x = -1" />.

**Step 3**: Evaluate <InlineMath math="f''" /> at each one.

-   <InlineMath math="f''(3) = 4 > 0" />, so <InlineMath math="x=3" /> gives a **local minimum**.
-   <InlineMath math="f''(-1) = -4 < 0" />, so <InlineMath math="x=-1" /> gives a **local maximum**.

**Step 4**: Substitute into the original function.

<MathContainer>
    <BlockMath math="f(3) = 9 - 9 - 9 + 2 = -7" />
    <BlockMath math="f(-1) = -\frac{1}{3} - 1 + 3 + 2 = \frac{11}{3}" />
</MathContainer>

Check the maximum with a nearby point: <InlineMath math="f(-2) = -\frac{8}{3} - 4 + 6 + 2 = \frac{4}{3}" />, which is less than <InlineMath math="\frac{11}{3}" />. The curve is concave down at <InlineMath math="x=-1" /> and concave up at <InlineMath math="x=3" />.

## When the Second Derivative Test Gives No Answer

When <InlineMath math="f'(c)=0" /> and <InlineMath math="f''(c)=0" />, **go back to the first derivative test**. Two functions show why the second test cannot decide on its own.

For <InlineMath math="f(x)=x^3" />, both <InlineMath math="f'(0)=0" /> and <InlineMath math="f''(0)=0" />. The derivative <InlineMath math="f'(x)=3x^2" /> is positive on both sides of <InlineMath math="0" />, so the sign never changes and <InlineMath math="x=0" /> is not an extremum. It is a horizontal inflection point.

For <InlineMath math="f(x)=x^4" />, again <InlineMath math="f'(0)=0" /> and <InlineMath math="f''(0)=0" />. This time <InlineMath math="f'(x)=4x^3" /> is negative for <InlineMath math="x<0" /> and positive for <InlineMath math="x>0" />, so <InlineMath math="f(0)=0" /> is a local minimum. Check: <InlineMath math="x^4 \ge 0" /> for every <InlineMath math="x" />.

## Largest and Smallest Values on a Closed Interval

On a closed interval <InlineMath math="[a,b]" />, a continuous function always reaches a largest and a smallest value. They can sit at a stationary point or at an endpoint, so **compare the function values at all candidates**.

**Problem**: Find the largest and smallest values of <InlineMath math="f(x)=x^3-3x" /> on <InlineMath math="[-2,3]" />.

The derivative <InlineMath math="f'(x)=3x^2-3" /> is zero at <InlineMath math="x=-1" /> and <InlineMath math="x=1" />, both inside the interval. Evaluate <InlineMath math="f" /> at these two points and at both endpoints:

| <InlineMath math="x" /> | <InlineMath math="-2" /> | <InlineMath math="-1" /> | <InlineMath math="1" /> | <InlineMath math="3" /> |
| --- | --- | --- | --- | --- |
| <InlineMath math="f(x)" /> | <InlineMath math="-2" /> | <InlineMath math="2" /> | <InlineMath math="-2" /> | <InlineMath math="18" /> |

The largest value is <InlineMath math="18" /> at the endpoint <InlineMath math="x=3" />, even though the local maximum at <InlineMath math="x=-1" /> is only <InlineMath math="2" />. The smallest value is <InlineMath math="-2" />, reached twice, at <InlineMath math="x=-2" /> and <InlineMath math="x=1" />. Word problems about the best size or the lowest cost use exactly this comparison, as the [applications of the derivative](/en/subjects/mathematics/derivative-function/application-of-derivative) show.

## Common Mistakes

Most wrong answers come from **skipping a check**, not from the derivative itself.

| Mistake | Why it is wrong | Fix |
| --- | --- | --- |
| Calling every stationary point an extremum | <InlineMath math="f(x)=x^3" /> has <InlineMath math="f'(0)=0" /> but no extremum | Test each stationary point |
| Reporting the <InlineMath math="x" />-value as the extreme value | The value is <InlineMath math="f(c)" />, not <InlineMath math="c" /> | Substitute <InlineMath math="c" /> into the original function |
| Substituting into <InlineMath math="f'" /> instead of <InlineMath math="f" /> | <InlineMath math="f'(c)=0" /> at every stationary point | Use <InlineMath math="f" /> for values, <InlineMath math="f''" /> for the type |
| Treating <InlineMath math="f''(c)=0" /> as an inflection point | <InlineMath math="x^4" /> has a minimum there | Go back to the first derivative test |
| Forgetting the endpoints on a closed interval | The largest value can sit at an endpoint | Compare stationary points and endpoints |

## Exercises

To classify a stationary point, use the **first or second derivative test**. A horizontal tangent alone does not tell you whether the function reaches a maximum or a minimum.

1. Determine the stationary point of <InlineMath math="y = x^2 + 2x - 3" /> and its type.
2. Find and classify the stationary points of <InlineMath math="f(x) = 2x^3 - 3x^2 - 12x + 1" />.
3. Find the largest and smallest values of <InlineMath math="f(x) = x^2 - 6x + 5" /> on <InlineMath math="[0, 4]" />.

### Worked Solution

1. The derivative is <InlineMath math="f'(x) = 2x + 2" />, which is zero at <InlineMath math="x = -1" />. Substitute into the original function:

    <BlockMath math="y = (-1)^2 + 2(-1) - 3 = -4" />

    The stationary point is <InlineMath math="(-1, -4)" />, and <InlineMath math="f''(x)=2 > 0" /> makes it a **minimum**. Check: <InlineMath math="y=(x+1)^2-4" />, so <InlineMath math="y" /> is never below <InlineMath math="-4" />.

2. The derivative is <InlineMath math="f'(x) = 6x^2 - 6x - 12 = 6(x-2)(x+1)" />, so the stationary points are <InlineMath math="x=2" /> and <InlineMath math="x=-1" />. With <InlineMath math="f''(x) = 12x - 6" />:

    <MathContainer>
        <BlockMath math="f''(-1) = -18 < 0, \qquad f(-1) = -2 - 3 + 12 + 1 = 8" />
        <BlockMath math="f''(2) = 18 > 0, \qquad f(2) = 16 - 12 - 24 + 1 = -19" />
    </MathContainer>

    The local maximum is <InlineMath math="8" /> at <InlineMath math="x=-1" />, and the local minimum is <InlineMath math="-19" /> at <InlineMath math="x=2" />. Check: <InlineMath math="f(0)=1" /> lies between them, as it must for a point between the two turning points.

3. The derivative <InlineMath math="f'(x) = 2x - 6" /> is zero at <InlineMath math="x=3" />, inside <InlineMath math="[0,4]" />. Compare the candidates:

    <BlockMath math="f(0) = 5, \qquad f(3) = -4, \qquad f(4) = -3" />

    The largest value is <InlineMath math="5" /> at <InlineMath math="x=0" />, and the smallest value is <InlineMath math="-4" /> at <InlineMath math="x=3" />. Check: <InlineMath math="f(x)=(x-3)^2-4" />, whose vertex is <InlineMath math="(3,-4)" />.
