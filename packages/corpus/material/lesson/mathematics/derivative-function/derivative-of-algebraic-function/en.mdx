## Applying the Derivative Rules

The [derivative rules](/en/subjects/mathematics/derivative-function/properties-of-derivative-function) apply to many algebraic forms. For a polynomial, rational function, or expression containing a radical, first <Highlight>identify the structure</Highlight> and then <Highlight>choose the matching rule</Highlight>. The examples below make that decision explicit.

## Using the Properties of Derivatives

Each example uses a different algebraic form and explains why its method works. Before differentiating, rewrite a quotient or a root as a power, because <Highlight>the power rule then applies directly</Highlight> to every term.

### Differentiating a Polynomial

Find the first derivative of <InlineMath math="y = 4x^2 + x + 2" />.

**Solution**:

We can differentiate each term one by one using the power rule and the constant rule.

<BlockMath math="\begin{aligned}y'&=4(2x)+1+0\\&=8x+1\end{aligned}" />

The derivative of the linear term <InlineMath math="x" /> is <InlineMath math="1" />, and the derivative of the constant <InlineMath math="2" /> is <InlineMath math="0" />. The result <InlineMath math="8x+1" /> holds for every real number, including <InlineMath math="x=0" />.

The derivative <InlineMath math="y' = 8x + 1" /> gives the slope at every point of <InlineMath math="y = 4x^2 + x + 2" />. At <InlineMath math="x = 0" /> it is <InlineMath math="1" />, so the tangent there is <InlineMath math="y = x + 2" />. Turn the scene and compare the steepness of the curve with the tangent line.

### Differentiating a Radical Expression

For <InlineMath math="x>0" />, find the first derivative of <InlineMath math="y = x\sqrt{x^3}" />.

**Solution**:

There are two ways to solve this.

**Method 1: Using the Product Rule**

First, we convert the radical form to an exponent: <InlineMath math="y = x \cdot x^{3/2}" />.

Let <InlineMath math="u(x) = x" /> and <InlineMath math="v(x) = x^{3/2}" />. Then, <InlineMath math="u'(x)=1" /> and <InlineMath math="v'(x) = \frac{3}{2}x^{1/2}" />.

<MathContainer>
  <BlockMath math="y' = u'(x)v(x) + u(x)v'(x)" />
  <BlockMath math="y' = (1)(x^{3/2}) + (x)(\frac{3}{2}x^{1/2})" />
  <BlockMath math="y' = x^{3/2} + \frac{3}{2}x^{3/2}" />
  <BlockMath math="y' = \frac{5}{2}x^{3/2}" />
</MathContainer>

**Method 2: Simplifying First**

We can simplify the function before differentiating it.

<MathContainer>
  <BlockMath math="y = x \cdot x^{3/2} = x^{1 + 3/2} = x^{5/2}" />
  <BlockMath math="y' = \frac{5}{2}x^{5/2 - 1} = \frac{5}{2}x^{3/2}" />
</MathContainer>

> Both methods produce <InlineMath math="y'=\frac{5}{2}x^{3/2}" />. Simplifying first takes fewer steps. The product rule differentiates the two factors separately, so it provides an independent check of the same derivative. As a real-valued function, the original expression has domain <InlineMath math="x \ge 0" />. The differentiation above is carried out on its interior, <InlineMath math="x>0" />.

### Differentiating a Rational Function

On its domain <InlineMath math="x\ne0" />, find the first derivative of <InlineMath math="y = 2\left(\frac{x^2+2}{x}\right)" />.

**Solution**:

We use the quotient rule. Let <InlineMath math="u(x) = x^2+2" /> and <InlineMath math="v(x) = x" />. Then <InlineMath math="u'(x) = 2x" /> and <InlineMath math="v'(x) = 1" />.

<MathContainer>
  <BlockMath math="y' = 2 \cdot \left(\frac{u'(x)v(x) - u(x)v'(x)}{[v(x)]^2}\right)" />
  <BlockMath math="y' = 2 \cdot \left(\frac{(2x)(x) - (x^2+2)(1)}{x^2}\right)" />
  <BlockMath math="y' = 2 \cdot \left(\frac{2x^2 - x^2 - 2}{x^2}\right)" />
  <BlockMath math="y' = 2 \cdot \left(\frac{x^2 - 2}{x^2}\right)" />
  <BlockMath math="\begin{aligned} y' &amp;= 2 \cdot \left(\frac{x^2}{x^2} - \frac{2}{x^2}\right) \\ &amp;= 2 \cdot \left(1 - \frac{2}{x^2}\right) \\ &amp;= 2 - \frac{4}{x^2} \end{aligned}" />
</MathContainer>

The restriction <InlineMath math="x\ne0" /> remains part of the derivative's domain.

## Exercises

Each problem asks for the derivative of an algebraic expression. Simplify the expression where possible, then apply the **power rule**.

1.  For <InlineMath math="x>0" />, find the first derivative of <InlineMath math="y = \frac{\sqrt{x} + x^2}{2x}" />.

### Answer Key

1.  Rewrite the function as a **sum of powers**. The **power rule** can then be applied to each term.

    **Step 1**: Split the Fraction

    Split the two terms in the numerator over the common denominator:

    <BlockMath math="y = \frac{\sqrt{x}}{2x} + \frac{x^2}{2x}" />

    **Step 2**: Simplify Each Term

    Convert the square root to the exponent <InlineMath math="x^{1/2}" /> and use exponent properties to simplify each term.

    <MathContainer>
      <BlockMath math="y = \frac{x^{1/2}}{2x^1} + \frac{x^2}{2x^1}" />
      <BlockMath math="y = \frac{1}{2}x^{1/2 - 1} + \frac{1}{2}x^{2-1}" />
      <BlockMath math="y = \frac{1}{2}x^{-1/2} + \frac{1}{2}x" />
    </MathContainer>

    **Step 3**: Apply the **Power Rule**

    Once the function is simplified, we can directly differentiate it term by term.

    <MathContainer>
      <BlockMath math="y' = \frac{1}{2}\left(-\frac{1}{2}x^{-1/2 - 1}\right) + \frac{1}{2}(1)" />
      <BlockMath math="y' = -\frac{1}{4}x^{-3/2} + \frac{1}{2}" />
    </MathContainer>

    So, the first derivative is <InlineMath math="\frac{1}{2} - \frac{1}{4}x^{-3/2}" />.
