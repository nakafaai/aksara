## Why Trigonometric Derivatives Use Radians

Trigonometric functions use the same [sum, product, quotient, and chain rules](/en/subjects/mathematics/derivative-function/properties-of-derivative-function) as algebraic functions. What changes is the set of basic derivatives we start from.

The formulas below assume that angles are measured in **radians**. If an angle is measured in degrees, the chain rule introduces the additional factor <InlineMath math="\pi/180" />.

## Basic Trigonometric Derivatives

The sine and cosine formulas <Highlight>follow from [the limit definition of the derivative](/en/subjects/mathematics/derivative-function/concept-of-derivative-function)</Highlight>. The remaining four can then be derived from trigonometric identities together with the product or quotient rule.

The table pairs each function with its derivative and the condition under which the function is defined. All angles use **radians**. Restrictions on a denominator still apply after differentiation.

| Function | Derivative | Condition |
| --- | --- | --- |
| <InlineMath math="\sin x" /> | <InlineMath math="\cos x" /> | All real numbers |
| <InlineMath math="\cos x" /> | <InlineMath math="-\sin x" /> | All real numbers |
| <InlineMath math="\tan x" /> | <InlineMath math="\sec^2 x" /> | <InlineMath math="\cos x\ne0" /> |
| <InlineMath math="\cot x" /> | <InlineMath math="-\csc^2 x" /> | <InlineMath math="\sin x\ne0" /> |
| <InlineMath math="\sec x" /> | <InlineMath math="\sec x\tan x" /> | <InlineMath math="\cos x\ne0" /> |
| <InlineMath math="\csc x" /> | <InlineMath math="-\csc x\cot x" /> | <InlineMath math="\sin x\ne0" /> |

## Applying the Rules to Trigonometric Functions

The examples below combine these formulas with familiar derivative rules. Identify the outer rule first, then **differentiate the angle** and multiply, because the derivative of <InlineMath math="\sin u" /> is <InlineMath math="\cos u" /> multiplied by the derivative of <InlineMath math="u" />.

### Combination of Algebra and Trigonometry

Find the derivative of <InlineMath math="y = 2 \sin x + 5x" />.

**Solution**:

We can differentiate this function term by term using the sum rule.

<MathContainer>
    <BlockMath math="y' = \frac{d}{dx}(2 \sin x) + \frac{d}{dx}(5x)" />
    <BlockMath math="y' = 2(\cos x) + 5(1)" />
    <BlockMath math="y' = 2 \cos x + 5" />
</MathContainer>

### Using the Product Rule

Find the derivative of <InlineMath math="y = 2 \sin x \tan x" />.

**Solution**:

Use the product rule <InlineMath math="y' = u'v + uv'" />.

Let <InlineMath math="u = 2 \sin x" /> and <InlineMath math="v = \tan x" />.

Then <InlineMath math="u' = 2 \cos x" /> and <InlineMath math="v' = \sec^2 x" />.

<MathContainer>
    <BlockMath math="\begin{aligned} y' &amp;= (2 \cos x)(\tan x) \\ &amp;\quad{}+ (2 \sin x)(\sec^2 x) \end{aligned}" />
    <BlockMath math="\begin{aligned} y' &amp;= (2 \cos x)\left(\frac{\sin x}{\cos x}\right) \\ &amp;\quad{}+ (2 \sin x)(\sec^2 x) \end{aligned}" />
    <BlockMath math="y' = 2 \sin x + 2 \sin x \sec^2 x" />
</MathContainer>

### Using the Quotient Rule

On its domain <InlineMath math="\sin x \ne 0" />, find the derivative of <InlineMath math="y = \frac{1 + \cos x}{\sin x}" />.

**Solution**:

Use the quotient rule <InlineMath math="y' = \frac{u'v - uv'}{v^2}" />.

Let <InlineMath math="u = 1 + \cos x" /> and <InlineMath math="v = \sin x" />.

Then <InlineMath math="u' = -\sin x" /> and <InlineMath math="v' = \cos x" />.

Compute the numerator first:

<MathContainer>
  <BlockMath math="\begin{aligned} N &amp;=(-\sin x)(\sin x) \\ &amp;\quad{}-(1+\cos x)(\cos x) \end{aligned}" />

  <BlockMath math="y'=\frac{N}{(\sin x)^2}" />
  <BlockMath math="y' = \frac{-\sin^2 x - (\cos x + \cos^2 x)}{\sin^2 x}" />
  <BlockMath math="y' = \frac{-(\sin^2 x + \cos^2 x) - \cos x}{\sin^2 x}" />
</MathContainer>
    Use the Pythagorean identity:

<BlockMath math="y' = \frac{-1 - \cos x}{1 - \cos^2 x}" />
    Factor the expression:

<MathContainer>
  <BlockMath math="y' = \frac{-(1 + \cos x)}{(1 - \cos x)(1 + \cos x)}" />
  <BlockMath math="y' = \frac{-1}{1 - \cos x} = \frac{1}{\cos x - 1}" />
</MathContainer>

The simplified formula is valid only on the original domain, so values with <InlineMath math="\sin x=0" /> remain excluded even if the final expression appears defined there.

## Exercises

Each problem asks for the first derivative of a trigonometric expression, and **the second one is a product**. Choose the rule that matches the structure.

1. Find the first derivative of <InlineMath math="f(x) = 4x^3 - 5 \cos x" />.
2. Find the first derivative of <InlineMath math="f(x) = \sin x \cos x" />.

### Answer Key

1.  **Solution**:

    Use the subtraction rule to differentiate each term separately.

    **Step 1**: Differentiate the first term

    The derivative of <InlineMath math="4x^3" /> using the power rule is <InlineMath math="3 \cdot 4x^{3-1} = 12x^2" />.

    **Step 2**: Differentiate the second term

    The derivative of <InlineMath math="-5 \cos x" /> is <InlineMath math="-5(-\sin x) = 5 \sin x" />.

    **Step 3**: Combine the results

    <BlockMath math="f'(x) = 12x^2 + 5 \sin x" />

    So, the derivative of the function is <InlineMath math="12x^2 + 5 \sin x" />.

2.  **Solution**:

    Use the product rule, <InlineMath math="f'(x) = u'v + uv'" />.

    **Step 1**: Determine <InlineMath math="u" />, <InlineMath math="v" />, <InlineMath math="u'" />, and <InlineMath math="v'" />

    Let <InlineMath math="u = \sin x" /> and <InlineMath math="v = \cos x" />.

    Then, <InlineMath math="u' = \cos x" /> and <InlineMath math="v' = -\sin x" />.

    **Step 2**: Apply the Product Rule

    <MathContainer>
        <BlockMath math="\begin{aligned} f'(x) &amp;= (\cos x)(\cos x) \\ &amp;\quad{}+ (\sin x)(-\sin x) \end{aligned}" />
        <BlockMath math="f'(x) = \cos^2 x - \sin^2 x" />
    </MathContainer>

    **Step 3**: Use a Trigonometric Identity (Optional)

    The result can also be simplified using the double angle identity, <InlineMath math="\cos(2x) = \cos^2 x - \sin^2 x" />.

    <BlockMath math="f'(x) = \cos(2x)" />

    So, the derivative of the function is <InlineMath math="\cos(2x)" />.

Exercise 2 as a chart: the derivative <InlineMath math="\cos 2x" /> of <InlineMath math="\sin x \cos x = \tfrac12 \sin 2x" /> is positive up to <InlineMath math="x = \tfrac{\pi}{4}" /> and negative after it, so <InlineMath math="\sin x \cos x" /> reaches its largest value <InlineMath math="\tfrac12" /> at <InlineMath math="\tfrac{\pi}{4}" />.
