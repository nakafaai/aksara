## Tanda Gradien dan Kemonotonan

Saat grafik dibaca dari kiri ke kanan, kurvanya dapat naik, turun, atau mendatar sesaat. Perilaku ini disebut **kemonotonan fungsi**. Tanda turunan pertama menentukan perilaku fungsi pada setiap interval.

Tanda gradien menunjukkan arah lokal kurva:

-   Gradien positif berarti fungsi **naik**.

-   Gradien negatif berarti fungsi **turun**.

-   Gradien nol menandai **titik stasioner**, tetapi titik itu belum tentu maksimum atau minimum.

Secara geometris, <InlineMath math="f'(x)" /> adalah gradien [garis singgung](/id/materi/matematika/turunan-fungsi/persamaan-garis-singgung-pada-kurva). Tandanya menunjukkan arah lokal kurva.

## Sifat Tanda Turunan

Karena gradien lokal menunjukkan arah gerak grafik, tanda **turunan pertama** mengelompokkan setiap bagian mulus kurva ke dalam perilaku naik, turun, atau mendatar. Pelajari dulu syarat tanda pada suatu interval, lalu amati bagaimana kurva fungsi dan pita turunannya saling berpasangan dalam ruang tiga dimensi.

### Syarat pada Interval

Misalkan fungsi <InlineMath math="y = f(x)" /> kontinu dan dapat diturunkan pada suatu interval. Tanda turunan pertamanya mengelompokkan arah gerak kurva pada interval itu:

-   Jika <InlineMath math="f'(x) > 0" /> untuk semua <InlineMath math="x" /> dalam interval itu, maka <InlineMath math="f(x)" /> adalah **fungsi naik**.

-   Jika <InlineMath math="f'(x) < 0" /> untuk semua <InlineMath math="x" /> dalam interval itu, maka <InlineMath math="f(x)" /> adalah **fungsi turun**.

-   Jika <InlineMath math="f'(x) = 0" /> pada titik tertentu, maka <InlineMath math="f(x)" /> memiliki **titik stasioner** di sana.

Titik stasioner membagi domain menjadi beberapa interval yang dapat diuji. Titik ini menjadi calon tempat perubahan kemonotonan, tetapi fungsi hanya beralih dari naik ke turun atau sebaliknya <Highlight>jika tanda turunannya berubah</Highlight>.

> Turunan bernilai nol hanya menandai calon titik balik. Arah kurva baru berbalik ketika tanda turunan pertama berubah melewati titik itu.

Saat menganalisis fungsi lain, periksa juga **batas domain dan titik yang tidak dapat diturunkan**. Misalnya, domain <InlineMath math="1/x" /> terpisah di <InlineMath math="x = 0" /> meskipun fungsi itu tidak mempunyai titik stasioner. Uji tanda harus dilakukan pada setiap interval domain yang terpisah.

## Analisis Tanda Fungsi Kubik

Tentukan interval ketika fungsi kubik <InlineMath math="x^3 - 3x" /> naik dan turun dengan mengikuti langkah analisis tanda berikut.

**Langkah 1**: Cari turunan pertama dengan menurunkan <InlineMath math="f(x) = x^3 - 3x" />.

<BlockMath math="f'(x) = 3x^2 - 3" />

**Langkah 2**: Temukan titik stasioner dengan menyelesaikan <InlineMath math="f'(x) = 0" />.

<MathContainer>
    <BlockMath math="3x^2 - 3 = 0" />
    <BlockMath math="x^2 - 1 = 0" />
    <BlockMath math="(x-1)(x+1) = 0" />
</MathContainer>

Dari sini, kita dapatkan **titik stasioner** pada <InlineMath math="x = 1" /> dan <InlineMath math="x = -1" />.

**Langkah 3**: Letakkan titik stasioner pada garis bilangan untuk membaginya menjadi tiga interval, lalu ambil satu titik uji dari setiap interval untuk mengetahui tanda <InlineMath math="f'(x)" />.

| Interval | Titik uji | Nilai turunan | Perilaku |
| --- | --- | --- | --- |
| <InlineMath math="x<-1" /> | <InlineMath math="x=-2" /> | <InlineMath math="f'(-2)=3(-2)^2-3=9" /> | Naik |
| <InlineMath math="-1<x<1" /> | <InlineMath math="x=0" /> | <InlineMath math="f'(0)=3(0)^2-3=-3" /> | Turun |
| <InlineMath math="x>1" /> | <InlineMath math="x=2" /> | <InlineMath math="f'(2)=3(2)^2-3=9" /> | Naik |

**Langkah 4**: Simpulkan interval dari tabel tanda:

-   Fungsi naik pada interval <InlineMath math="x < -1" /> atau <InlineMath math="x > 1" />.

-   Fungsi turun pada interval terbuka <InlineMath math="(-1, 1)" />.

## Soal Interval Naik dan Turun

Setiap soal meminta selang naik dan turun suatu fungsi. Tentukan **titik stasionernya** lebih dulu, karena titik itu memisahkan selangnya.

1.  Tentukan interval fungsi naik dan interval fungsi turun pada kurva <InlineMath math="x^3 - 3x^2 - 15" />.

2.  Jika fungsi kubik <InlineMath math="ax^3 + x^2 + 5" /> naik di seluruh interval <InlineMath math="0 < x < 2" />, tentukan semua nilai <InlineMath math="a" /> yang mungkin.

3.  Tentukan interval ketika <InlineMath math="f(x) = \sin 2x \cos 2x" /> naik dan turun.

**Soal 1**. Turunan pertama dari <InlineMath math="x^3 - 3x^2 - 15" /> adalah <InlineMath math="f'(x) = 3x^2 - 6x" />.

**Titik stasioner** didapat saat <InlineMath math="f'(x) = 0" />.

<BlockMath math="3x^2 - 6x = 0 \implies 3x(x - 2) = 0" />

Titik stasionernya adalah <InlineMath math="x = 0" /> dan <InlineMath math="x = 2" />.

Dengan menguji interval pada garis bilangan:

-   Untuk <InlineMath math="x < 0" />, <InlineMath math="f'(x)" /> positif (naik).

-   Untuk <InlineMath math="0 < x < 2" />, <InlineMath math="f'(x)" /> negatif (turun).

-   Untuk <InlineMath math="x > 2" />, <InlineMath math="f'(x)" /> positif (naik).

Jadi, fungsi naik pada <InlineMath math="x < 0" /> atau <InlineMath math="x > 2" />, dan turun pada interval <InlineMath math="0 < x < 2" />.

**Soal 2**. Agar fungsi ini naik di seluruh interval, cukup mensyaratkan <InlineMath math="f'(x) \ge 0" /> pada setiap titik dalam interval itu.

<BlockMath math="f'(x) = 3ax^2 + 2x = x(3ax + 2)" />

Pada interval <InlineMath math="0 < x < 2" />, faktor <InlineMath math="x" /> selalu positif. Jadi, agar <InlineMath math="f'(x) \ge 0" />, faktor kedua yaitu <InlineMath math="3ax + 2" /> juga harus non-negatif.

<BlockMath math="3ax + 2 \ge 0" />

Ketidaksamaan ini harus berlaku untuk setiap <InlineMath math="x" /> pada <InlineMath math="0 < x < 2" />. Karena <InlineMath math="h(x) = 3ax + 2" /> linear, nilai batas terkecilnya didekati pada salah satu ujung interval.

-   Jika <InlineMath math="a \ge 0" />, maka <InlineMath math="3ax \ge 0" />, sehingga <InlineMath math="3ax + 2" /> positif di seluruh interval.

-   Jika <InlineMath math="a < 0" />, maka <InlineMath math="h(x)" /> menurun. Karena <InlineMath math="x = 2" /> tidak termasuk interval, <InlineMath math="h" /> tidak memiliki nilai minimum di sana. Namun, infimumnya adalah nilai batas saat <InlineMath math="x \to 2^-" />. Nilai batas itu harus non-negatif.

Evaluasi syarat batas pada <InlineMath math="x = 2" />:

<MathContainer>
    <BlockMath math="3a(2) + 2 \ge 0" />
    <BlockMath math="6a \ge -2" />
    <BlockMath math="a \ge -1/3" />
</MathContainer>

Dengan menggabungkan kedua kasus, fungsi naik di seluruh interval tepat ketika <InlineMath math="a \ge -1/3" />.

Pada batas <InlineMath math="a = -1/3" />, turunannya menjadi <InlineMath math="f'(x) = x(2 - x)" /> yang tetap positif untuk setiap <InlineMath math="0 < x < 2" />. Jadi, fungsi tetap **naik di seluruh interval terbuka**. Jika <InlineMath math="a < -1/3" />, turunan negatif untuk nilai <InlineMath math="x" /> yang cukup dekat dengan <InlineMath math="2" />, sehingga fungsi tidak terus naik.

**Soal 3**. Gunakan identitas trigonometri sudut ganda <InlineMath math="\sin(2A) = 2\sin(A)\cos(A)" /> untuk menulis ulang fungsinya:

<BlockMath math="f(x) = \sin 2x \cos 2x = \frac{1}{2} \sin(4x)" />

Turunan pertamanya adalah:

<BlockMath math="f'(x) = \frac{1}{2} \cdot \cos(4x) \cdot 4 = 2\cos(4x)" />

-   **Fungsi naik** saat <InlineMath math="f'(x) > 0" />, yaitu <InlineMath math="2\cos(4x) > 0" /> atau <InlineMath math="\cos(4x) > 0" />. Ini terjadi di kuadran <InlineMath math="\mathrm{I}" /> dan <InlineMath math="\mathrm{IV}" />.

    <MathContainer>
        <BlockMath math="-\frac{\pi}{2} + 2k\pi < 4x < \frac{\pi}{2} + 2k\pi" />
        <BlockMath math="-\frac{\pi}{8} + \frac{k\pi}{2} < x < \frac{\pi}{8} + \frac{k\pi}{2}" />
    </MathContainer>

    Interval ini berlaku untuk setiap <InlineMath math="k" /> bilangan bulat.

-   **Fungsi turun** saat <InlineMath math="f'(x) < 0" />, yaitu <InlineMath math="\cos(4x) < 0" />. Ini terjadi di kuadran <InlineMath math="\mathrm{II}" /> dan <InlineMath math="\mathrm{III}" />.

    <MathContainer>
        <BlockMath math="\frac{\pi}{2} + 2k\pi < 4x < \frac{3\pi}{2} + 2k\pi" />
        <BlockMath math="\frac{\pi}{8} + \frac{k\pi}{2} < x < \frac{3\pi}{8} + \frac{k\pi}{2}" />
    </MathContainer>

    Interval ini berlaku untuk setiap <InlineMath math="k" /> bilangan bulat.
