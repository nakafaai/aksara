## Behavior of a Function and Its Derivative

As we read a graph from left to right, its curve may rise, fall, or briefly become flat. This behavior is called the function's **monotonicity**, and its first derivative tells us how to classify it.

The sign of the slope tells us the curve's local direction:

-   A positive slope means the function is **increasing**.

-   A negative slope means the function is **decreasing**.

-   A zero slope marks a **stationary point**, although that point need not be a maximum or minimum.

Geometrically, <InlineMath math="f'(x)" /> is the slope of [the tangent line](/en/subjects/mathematics/derivative-function/equation-of-a-tangent-line-to-a-curve). Its sign therefore describes the curve's local direction.

## Properties of Monotonicity

The relationship between the first derivative and the behavior of a function can be summarized by the following properties:

Suppose the function <InlineMath math="y = f(x)" /> is continuous and differentiable over an interval.

-   If <InlineMath math="f'(x) > 0" /> for all <InlineMath math="x" /> in that interval, then <InlineMath math="f(x)" /> is an **increasing function**.

-   If <InlineMath math="f'(x) < 0" /> for all <InlineMath math="x" /> in that interval, then <InlineMath math="f(x)" /> is a **decreasing function**.

-   If <InlineMath math="f'(x) = 0" /> at a specific point, then <InlineMath math="f(x)" /> has a **stationary point** there.

Stationary points divide the domain into intervals that we can test. They are candidates for a change in monotonicity, but <Highlight>the derivative must change sign</Highlight> for the function to switch from increasing to decreasing or vice versa.

For other functions, also check **domain boundaries and points without a derivative**. For example, the domain of <InlineMath math="1/x" /> is separated at <InlineMath math="x=0" /> even though the function has no stationary point. Test derivative signs on each separate domain interval.

## Analyzing Function Intervals

The following example shows the complete sign-analysis process.

Determine the intervals for which the function <InlineMath math="f(x) = x^3 - 3x" /> is increasing and decreasing.

**Solution**:

**Step 1**: Find the first derivative

First, we differentiate the function <InlineMath math="f(x)" />.

<BlockMath math="f'(x) = 3x^2 - 3" />

**Step 2**: Find the stationary points

Stationary points occur when <InlineMath math="f'(x) = 0" />.

<MathContainer>
    <BlockMath math="3x^2 - 3 = 0" />
    <BlockMath math="x^2 - 1 = 0" />
    <BlockMath math="(x-1)(x+1) = 0" />
</MathContainer>

From this, we get the stationary points at <InlineMath math="x = 1" /> and <InlineMath math="x = -1" />.

**Step 3**: Create a number line and test intervals

We place the stationary points on a number line. These points divide the line into three intervals. We take a test point from each interval to find the sign of <InlineMath math="f'(x)" /> (positive or negative).

| Interval | Test point | Derivative value | Behavior |
| --- | --- | --- | --- |
| <InlineMath math="x<-1" /> | <InlineMath math="x=-2" /> | <InlineMath math="f'(-2)=3(-2)^2-3=9" /> | Increasing |
| <InlineMath math="-1<x<1" /> | <InlineMath math="x=0" /> | <InlineMath math="f'(0)=3(0)^2-3=-3" /> | Decreasing |
| <InlineMath math="x>1" /> | <InlineMath math="x=2" /> | <InlineMath math="f'(2)=3(2)^2-3=9" /> | Increasing |

**Step 4**: Conclude the intervals

Based on the tests, we can conclude:

-   The function is increasing on the intervals <InlineMath math="x < -1" /> or <InlineMath math="x > 1" />.

-   The function is decreasing on the interval <InlineMath math="-1 < x < 1" />.

## Exercises

Each problem asks where a function increases or decreases. Find the **stationary points** first, because they separate the intervals.

1.  Determine the intervals where the function is increasing and decreasing for the curve <InlineMath math="f(x) = x^3 - 3x^2 - 15" />.

2.  If <InlineMath math="f(x) = ax^3 + x^2 + 5" /> is increasing throughout <InlineMath math="0 < x < 2" />, determine the possible values of <InlineMath math="a" />.

3.  Determine the intervals where <InlineMath math="f(x) = \sin 2x \cos 2x" /> is increasing and decreasing.

### Worked Solutions

**Problem 1**. The first derivative of <InlineMath math="f(x) = x^3 - 3x^2 - 15" /> is <InlineMath math="f'(x) = 3x^2 - 6x" />.

**Stationary points** are found when <InlineMath math="f'(x) = 0" />.

<BlockMath math="3x^2 - 6x = 0 \implies 3x(x - 2) = 0" />

The stationary points are at <InlineMath math="x=0" /> and <InlineMath math="x=2" />.

By testing the intervals on a number line:

-   For <InlineMath math="x<0" />, <InlineMath math="f'(x)" /> is positive (increasing).

-   For <InlineMath math="0<x<2" />, <InlineMath math="f'(x)" /> is negative (decreasing).

-   For <InlineMath math="x>2" />, <InlineMath math="f'(x)" /> is positive (increasing).

So, the function is increasing on <InlineMath math="x < 0" /> or <InlineMath math="x > 2" />, and decreasing on the interval <InlineMath math="0 < x < 2" />.

**Problem 2**. For this function to increase throughout the interval, it is enough to require <InlineMath math="f'(x) \ge 0" /> at every point in the interval.

<BlockMath math="f'(x) = 3ax^2 + 2x = x(3ax + 2)" />

In the interval <InlineMath math="0 < x < 2" />, the factor <InlineMath math="x" /> is always positive. Therefore, for <InlineMath math="f'(x) \ge 0" />, the second factor, <InlineMath math="(3ax + 2)" />, must also be non-negative.

<BlockMath math="3ax + 2 \ge 0" />

This inequality must hold for every <InlineMath math="x" /> in <InlineMath math="0 < x < 2" />. Since <InlineMath math="h(x) = 3ax + 2" /> is linear, its smallest limiting value occurs toward one end of the interval.

-   If <InlineMath math="a \ge 0" />, then <InlineMath math="3ax \ge 0" />, so <InlineMath math="3ax+2" /> is positive throughout the interval.

-   If <InlineMath math="a < 0" />, then <InlineMath math="h(x)" /> decreases. Because <InlineMath math="x=2" /> is excluded, <InlineMath math="h" /> has no minimum there. Its infimum is the boundary value approached as <InlineMath math="x \to 2^-" />. Requiring that boundary value to be non-negative gives the exact condition.

Evaluate the limiting boundary condition at <InlineMath math="x=2" />:

<MathContainer>
    <BlockMath math="3a(2) + 2 \ge 0" />
    <BlockMath math="6a \ge -2" />
    <BlockMath math="a \ge -1/3" />
</MathContainer>

Combining both cases, the function increases throughout the given interval precisely when <InlineMath math="a \ge -1/3" />.

At the boundary <InlineMath math="a=-1/3" />, the derivative becomes <InlineMath math="f'(x)=x(2-x)>0" /> for every <InlineMath math="0<x<2" />. The function is therefore **increasing throughout the open interval**. If <InlineMath math="a<-1/3" />, the derivative is negative sufficiently close to <InlineMath math="x=2" />, so the function cannot keep increasing.

**Problem 3**. Use the double angle trigonometric identity: <InlineMath math="\sin(2A) = 2\sin(A)\cos(A)" />.

So, <InlineMath math="f(x) = \sin 2x \cos 2x = \frac{1}{2} \sin(4x)" />.

Its first derivative is:

<BlockMath math="f'(x) = \frac{1}{2} \cdot \cos(4x) \cdot 4 = 2\cos(4x)" />

-   **The function is increasing** when <InlineMath math="f'(x) > 0" />, which is <InlineMath math="2\cos(4x) > 0" /> or <InlineMath math="\cos(4x) > 0" />. This occurs in quadrants <InlineMath math="\mathrm{I}" /> and <InlineMath math="\mathrm{IV}" />.

    <MathContainer>
        <BlockMath math="-\frac{\pi}{2} + 2k\pi < 4x < \frac{\pi}{2} + 2k\pi" />
        <BlockMath math="-\frac{\pi}{8} + \frac{k\pi}{2} < x < \frac{\pi}{8} + \frac{k\pi}{2}" />
    </MathContainer>

    This interval is valid for any integer <InlineMath math="k" />.

-   **The function is decreasing** when <InlineMath math="f'(x) < 0" />, which is <InlineMath math="\cos(4x) < 0" />. This occurs in quadrants <InlineMath math="\mathrm{II}" /> and <InlineMath math="\mathrm{III}" />.

    <MathContainer>
        <BlockMath math="\frac{\pi}{2} + 2k\pi < 4x < \frac{3\pi}{2} + 2k\pi" />
        <BlockMath math="\frac{\pi}{8} + \frac{k\pi}{2} < x < \frac{3\pi}{8} + \frac{k\pi}{2}" />
    </MathContainer>

    This interval is valid for any integer <InlineMath math="k" />.
