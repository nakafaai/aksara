## Sentences You Can Check

A statement is a sentence you can check, and the check comes out **either true or false, never both**. Whether it's true or false is called its **truth value**. You can't check a question or a command that way, so neither one is a statement.

From statements you'll build claims with all and some, flip them with not, and join two of them with and or or. You'll test those rules in tables, in a circuit of switches and on a hidden gate.

| Sentence | Statement? | Truth value |
| :--- | :--- | :--- |
| <InlineMath math="91" /> is a prime number. | Yes | False, because <InlineMath math="91 = 7 \times 13" /> |
| Every square has four equal sides. | Yes | True |
| Is <InlineMath math="0" /> an even number? | No, it's a question | None |
| Write down the first five prime numbers. | No, it's a command | None |
| <InlineMath math="x + 4 = 9" /> | No, it depends on <InlineMath math="x" /> | Not yet |

The first row shows that **a false sentence is still a statement**. You can check it, and the check says false. The last row is different. With <InlineMath math="x = 5" /> the sentence is true, and with <InlineMath math="x = 1" /> it's false, because <InlineMath math="1 + 4 = 5" />. Until you know <InlineMath math="x" />, you can't give it a truth value. A sentence like that is called an open sentence, not a statement.

## The Words All and Some

A claim with all is true only when **every member it talks about passes**. A claim with some is already true when **at least one member passes**. Words such as all and some are called quantifiers. Test three claims on the ten numbers <InlineMath math="1, 4, 6, 9, 12, 16, 20, 25, 30, 36" /> and see which number decides each truth value.

| Claim | Numbers tested | Truth value | What decides it |
| :--- | :--- | :--- | :--- |
| All square numbers here are even. | <InlineMath math="1, 4, 9, 16, 25, 36" /> | False | <InlineMath math="1" />, <InlineMath math="9" /> and <InlineMath math="25" /> are odd |
| Some square numbers here are even. | <InlineMath math="1, 4, 9, 16, 25, 36" /> | True | <InlineMath math="4" /> is even |
| All multiples of <InlineMath math="4" /> here are even. | <InlineMath math="4, 12, 16, 20, 36" /> | True | All five are even |

The first claim falls at the very first square: <InlineMath math="1 = 1^2" /> is odd, and <InlineMath math="9" /> and <InlineMath math="25" /> bring it down too. The second claim is true as soon as you reach <InlineMath math="4 = 2^2" />, because one example is enough. The third claim takes more work. You have to check all five multiples of <InlineMath math="4" />, and every one is even. So **a true all claim needs a full check**, while a false one needs just one failing case.

## Saying Not Flips the Truth

Put not into a statement and its truth value flips: true becomes false, and false becomes true. The new statement is called the **negation**. The negation of <InlineMath math="p" /> is written <InlineMath math="\sim p" /> and read not <InlineMath math="p" />.

| <InlineMath math="p" /> | <InlineMath math="\sim p" /> |
| :--- | :--- |
| True | False |
| False | True |

Take <InlineMath math="p" />: <InlineMath math="91" /> is a prime number. That's false, so its negation, <InlineMath math="91" /> is not a prime number, is true. Check: <InlineMath math="91 = 7 \times 13" />, so <InlineMath math="91" /> has a factor other than <InlineMath math="1" /> and itself.

Be careful with all. In the list above, the claim all square numbers here are even is false. People often write its negation as no square number here is even. That sentence is false too, because <InlineMath math="4" /> is even. A negation always has the opposite truth value, so that sentence can't be the negation. The right negation is **not all square numbers here are even**, and the number <InlineMath math="1" /> shows it's true.

## Joining Two Statements

The words and and or join two statements into one **compound statement**, and its truth value depends on the truth values of the two parts. ### When And Is True

The statement <InlineMath math="p" /> and <InlineMath math="q" /> is true **only when both parts are true**. In the row circuit, the lamp lights only when switches P and Q are both closed.

| <InlineMath math="p" /> | <InlineMath math="q" /> | <InlineMath math="p" /> and <InlineMath math="q" /> |
| :--- | :--- | :--- |
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

Take <InlineMath math="p" />: <InlineMath math="12" /> is a multiple of <InlineMath math="4" />, and <InlineMath math="q" />: <InlineMath math="12" /> is a square number. The statement <InlineMath math="p" /> is true because <InlineMath math="12 = 4 \times 3" />. The statement <InlineMath math="q" /> is false because <InlineMath math="3^2 = 9" /> and <InlineMath math="4^2 = 16" />, so no whole number squares to <InlineMath math="12" />. That makes <InlineMath math="12" /> is a multiple of <InlineMath math="4" /> and <InlineMath math="12" /> is a square number false. Check it in the circuit: close P, leave Q open, and the lamp stays dark.

### Or Includes Both

The statement <InlineMath math="p" /> or <InlineMath math="q" /> is true when **at least one part is true**, and that includes both parts being true. It's false only when both parts are false.

| <InlineMath math="p" /> | <InlineMath math="q" /> | <InlineMath math="p" /> or <InlineMath math="q" /> |
| :--- | :--- | :--- |
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |

With the same <InlineMath math="p" /> and <InlineMath math="q" />, the sentence <InlineMath math="12" /> is a multiple of <InlineMath math="4" /> or <InlineMath math="12" /> is a square number is true, because its first part is true. The sentence <InlineMath math="16" /> is even or <InlineMath math="16" /> is a square number is true as well, and here both parts are true.

In everyday talk, or often means pick just one, and that habit is why people get the first row wrong. Or in logic **doesn't rule out both being true**. Check it in the side by side circuit: close P and Q together, and the lamp stays lit.

### The Hidden Gate

Now turn the question around: you only see the table, and you have to work out the joining word. The trainer below hides a gate P with inputs <InlineMath math="A" /> and <InlineMath math="B" />. A gate is a small circuit that outputs <InlineMath math="1" /> for true and <InlineMath math="0" /> for false. **An AND gate works like and**, and an OR gate works like or.

The output of P goes into a NAND gate together with a third input <InlineMath math="C" />. While <InlineMath math="C = 1" />, the NAND gate just flips its input, exactly like not.
