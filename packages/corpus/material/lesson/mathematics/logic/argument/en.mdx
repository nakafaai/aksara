## Logical Reasoning Tests Whether Statements Are True

A **statement** is a sentence that is either true or false, but not both. The sentence <InlineMath math="7" /> is a prime number is a true statement. Questions and commands are not statements. From statements, we build compound statements, implications and arguments. A **deductive argument** moves from general premises to a specific conclusion, while an **inductive argument** moves from specific cases to a general conclusion. In the models here, you test an implication with a counterexample, see a premise as a set diagram and build a general conclusion from a pattern.

## Compound Statements and Negation

The **negation** of a statement <InlineMath math="p" /> is written <InlineMath math="\sim p" /> and has the opposite truth value. Two statements can be joined with **and** or **or**.

| <InlineMath math="p" /> | <InlineMath math="q" /> | <InlineMath math="p \text{ and } q" /> | <InlineMath math="p \text{ or } q" /> |
| :--- | :--- | :--- | :--- |
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

A statement with **and** is true only when both parts are true. A statement with **or** is false only when both parts are false. This chart compares the number of true rows in the truth table of each kind of statement.

## Implications and Their Converses

An **implication** has the form if <InlineMath math="p" />, then <InlineMath math="q" />. The part <InlineMath math="p" /> is the antecedent and <InlineMath math="q" /> is the consequent. An implication is false only when <InlineMath math="p" /> is true but <InlineMath math="q" /> is false.

| Form | Statement | Example |
| :--- | :--- | :--- |
| Implication | If <InlineMath math="p" />, then <InlineMath math="q" /> | If <InlineMath math="x > 2" />, then <InlineMath math="x^2 > 4" /> |
| Converse | If <InlineMath math="q" />, then <InlineMath math="p" /> | If <InlineMath math="x^2 > 4" />, then <InlineMath math="x > 2" /> |
| Inverse | If <InlineMath math="\sim p" />, then <InlineMath math="\sim q" /> | If <InlineMath math="x \le 2" />, then <InlineMath math="x^2 \le 4" /> |
| Contrapositive | If <InlineMath math="\sim q" />, then <InlineMath math="\sim p" /> | If <InlineMath math="x^2 \le 4" />, then <InlineMath math="x \le 2" /> |

**The contrapositive always has the same truth value as the implication**, while the converse and inverse may differ. This model tests an implication and its converse. Move <InlineMath math="x" /> and find a value that makes the converse false.

### Example Deciding a Truth Value

Decide whether **the converse** of if <InlineMath math="x > 2" />, then <InlineMath math="x^2 > 4" /> is true or false.

The converse is if <InlineMath math="x^2 > 4" />, then <InlineMath math="x > 2" />. Take <InlineMath math="x = -3" />:

<BlockMath math="(-3)^2 = 9 > 4 \quad\text{but}\quad -3 < 2" />

One counterexample is enough, so the converse is false. Check with the model: at <InlineMath math="x = -3" />, the point is above the line <InlineMath math="y = 4" /> but to the left of <InlineMath math="x = 2" />. The original implication is true, because every <InlineMath math="x > 2" /> gives <InlineMath math="x^2 > 4" />.

### Biconditional Statements

If an implication and its converse are both true, they can be written as one **if and only if** statement. For example, <InlineMath math="x^3 = 8" /> if and only if <InlineMath math="x = 2" />, because each direction is true.

## Deductive Arguments

A deductive argument has premises and a conclusion. If the premises are true and the form is valid, **the conclusion must be true**. Three valid forms:

| Form | Premise 1 | Premise 2 | Conclusion |
| :--- | :--- | :--- | :--- |
| Form one | All <InlineMath math="A" /> are <InlineMath math="B" /> | <InlineMath math="C" /> is <InlineMath math="A" /> | <InlineMath math="C" /> is <InlineMath math="B" /> |
| Form two | If <InlineMath math="p" />, then <InlineMath math="q" /> | <InlineMath math="p" /> is true | <InlineMath math="q" /> is true |
| Form three | If <InlineMath math="p" />, then <InlineMath math="q" /> | <InlineMath math="\sim q" /> is true | <InlineMath math="\sim p" /> is true |

### Example Completing a Deductive Argument

Complete **the conclusion**. Premise 1: If a quadrilateral is a square, then all its sides are equal. Premise 2: The sides of quadrilateral <InlineMath math="PQRS" /> are not all equal.

This is form three with <InlineMath math="\sim q" /> true, so the conclusion is: <InlineMath math="PQRS" /> is not a square. Check: if <InlineMath math="PQRS" /> were a square, all its sides would be equal, which contradicts premise 2.

### Example Testing an Inductive Conclusion

Use the rule to **predict** the number of diagonals of an octagon, then check with the model.

<BlockMath math="\frac{8(8 - 3)}{2} = \frac{40}{2} = 20" />

Check with the model: at <InlineMath math="n = 8" />, it reads <InlineMath math="20" />. A direct count also gives <InlineMath math="20" />: each of the <InlineMath math="8" /> vertices has <InlineMath math="5" /> diagonals, and <InlineMath math="8 \times 5 \div 2 = 20" />.

## Common Mistakes about Logical Reasoning

| Mistake | Why it's wrong | How to check |
| :--- | :--- | :--- |
| The converse is always true when the implication is true. | The converse can be false, as the example <InlineMath math="x = -3" /> shows. | Look for one counterexample. |
| A statement with or needs both parts true. | A statement with or is true if at least one part is true. | Check the truth table. |
| An inductive conclusion is certainly true. | An inductive conclusion is only probable and must be tested. | Test the rule on a new case. |
| The negation of all <InlineMath math="A" /> are <InlineMath math="B" /> is no <InlineMath math="A" /> are <InlineMath math="B" />. | The negation is not all <InlineMath math="A" /> are <InlineMath math="B" />. | One element outside <InlineMath math="B" /> is enough. |

The first mistake is the most common one in implication questions. **One counterexample proves a statement false**.

## Practice on Logical Reasoning

These questions move from statements to deductive and inductive arguments. **Name the argument form** in every deductive answer.

1. Decide the truth value of the statement <InlineMath math="5 > 3" /> and <InlineMath math="2^3 = 6" />.

2. Write the contrapositive of if <InlineMath math="n" /> is a multiple of <InlineMath math="4" />, then <InlineMath math="n" /> is even, and state its truth value.

3. Complete the argument. Premise 1: All multiples of <InlineMath math="6" /> are multiples of <InlineMath math="3" />. Premise 2: <InlineMath math="42" /> is a multiple of <InlineMath math="6" />.

4. The sequence <InlineMath math="5, 8, 11, 14, \ldots" /> follows the pattern <InlineMath math="3n + 2" /> for <InlineMath math="n = 1, 2, 3, \ldots" />. Use the inductive conclusion to find term <InlineMath math="20" />.

### Solutions

**Solution 1**: <InlineMath math="5 > 3" /> is true, but <InlineMath math="2^3 = 8" />, not <InlineMath math="6" />, so the second part is false. A statement with **and** needs both parts true, so the statement is **false**.

**Solution 2**: The contrapositive is if <InlineMath math="n" /> is not even, then <InlineMath math="n" /> is not a multiple of <InlineMath math="4" />. The original implication is true, and **the contrapositive has the same truth value**, so it's also true.

**Solution 3**: This is form one, so the conclusion is <InlineMath math="42" /> is a multiple of <InlineMath math="3" />. Check: <InlineMath math="42 = 3 \times 14" />.

**Solution 4**: Substitute <InlineMath math="n = 20" /> into the pattern:

<BlockMath math="3(20) + 2 = 62" />

Check the pattern on a known term: <InlineMath math="3(4) + 2 = 14" />, the same as the fourth term.
