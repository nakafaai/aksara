## The Expected Number of Successes Is np

If <InlineMath math="X" /> counts the successes in <InlineMath math="n" /> independent trials, each with success probability <InlineMath math="p" />, then <InlineMath math="X" /> has a binomial distribution, written <InlineMath math="X \sim B(n, p)" />, and its expected value is:

<BlockMath math="E(X) = np" />

A player makes each free throw with probability <InlineMath math="p = 0.8" /> and shoots <InlineMath math="n = 10" /> times. The expected value is <InlineMath math="E(X) = 10 \cdot 0.8 = 8" />. This means that **the average number of baskets over many sets of ten shots approaches <InlineMath math="8" />**. In a single set, the result can be <InlineMath math="6" />, <InlineMath math="9" />, or <InlineMath math="10" />.

How far does one set usually stray from <InlineMath math="8" />? The measure is the standard deviation, the square root of the variance <InlineMath math="np(1 - p) = 10 \cdot 0.8 \cdot 0.2 = 1.6" />, which is <InlineMath math="\sqrt{1.6} \approx 1.26" /> baskets. An expected value can also be a fraction, even though <InlineMath math="X" /> itself only takes whole numbers.

## Conditions for a Binomial Experiment

A variable <InlineMath math="X" /> is binomial when **four conditions hold together**. Each trial has only two outcomes, success or failure. The number of trials <InlineMath math="n" /> is fixed before the trials begin. The result of one trial does not affect another, as with [independent events](/en/subjects/mathematics/combinatorics/probability-of-independent-events). The success probability <InlineMath math="p" /> is the same in every trial.

When all four conditions hold, the probability of exactly <InlineMath math="k" /> successes comes from the [binomial distribution formula](/en/subjects/mathematics/data-analysis-probability/binomial-distribution-function):

<BlockMath math="P(X = k) = \binom{n}{k} p^k (1 - p)^{n - k}, \qquad k = 0, 1, \ldots, n" />

Rolling a die until a six appears is not a binomial experiment, because the number of rolls is not fixed. Answering questions whose chances of a correct answer differ is not binomial either, because <InlineMath math="p" /> is not the same in every trial.

## Computing the Expected Value from a Probability Table

The expected value of a discrete variable is the sum of each value times its probability, just as for any other [probability distribution](/en/subjects/mathematics/probability/probability-distribution):

<BlockMath math="E(X) = \sum_{k=0}^{n} k \cdot P(X = k)" />

For three tosses of a fair coin, <InlineMath math="n = 3" /> and <InlineMath math="p = \frac{1}{2}" />. The probability of each value comes from <InlineMath math="\binom{3}{k}\left(\frac{1}{2}\right)^3" />, and then each value is **multiplied by its probability**:

| Number of heads <InlineMath math="k" /> | <InlineMath math="P(X = k)" /> | <InlineMath math="k \cdot P(X = k)" /> |
| --- | --- | --- |
| <InlineMath math="0" /> | <InlineMath math="\frac{1}{8}" /> | <InlineMath math="0" /> |
| <InlineMath math="1" /> | <InlineMath math="\frac{3}{8}" /> | <InlineMath math="\frac{3}{8}" /> |
| <InlineMath math="2" /> | <InlineMath math="\frac{3}{8}" /> | <InlineMath math="\frac{6}{8}" /> |
| <InlineMath math="3" /> | <InlineMath math="\frac{1}{8}" /> | <InlineMath math="\frac{3}{8}" /> |

The sum of the last column is the expected value:

<BlockMath math="E(X) = 0 + \frac{3}{8} + \frac{6}{8} + \frac{3}{8} = \frac{12}{8} = 1.5" />

Check with the short formula: <InlineMath math="np = 3 \cdot \frac{1}{2} = 1.5" />. Both methods agree, but for a large <InlineMath math="n" /> such a table gets too long, so the formula <InlineMath math="np" /> does the work.

## Why the Formula Is np

The formula comes from **splitting <InlineMath math="X" /> into one indicator for each trial**. The indicator <InlineMath math="I_k" /> equals <InlineMath math="1" /> if trial <InlineMath math="k" /> is a success and <InlineMath math="0" /> if it fails. The expected value of one indicator is:

<BlockMath math="E(I_k) = 1 \cdot p + 0 \cdot (1 - p) = p" />

The number of successes is the sum of all indicators, because each success contributes exactly one. The expected value of a sum is the sum of the expected values:

<MathContainer>
  <BlockMath math="X = I_1 + I_2 + \cdots + I_n" />
  <BlockMath math="E(X) = E(I_1) + E(I_2) + \cdots + E(I_n) = \underbrace{p + p + \cdots + p}_{n \text{ times}} = np" />
</MathContainer>

Check with three coin tosses: three indicators each have expected value <InlineMath math="\frac{1}{2}" />, and their sum is <InlineMath math="1.5" />, the same as the sum of <InlineMath math="k \cdot P(X = k)" />. The step that adds expected values does not use independence. Independence is needed for the binomial probability formula, while the rule <InlineMath math="np" /> stays true as long as every trial has success probability <InlineMath math="p" />. For a continuous variable, a sum like this becomes an integral, as in the [expected value of a normal distribution](/en/subjects/mathematics/data-analysis-probability/expected-value-of-normal-distribution).

## Example with Seven Dice Rolls

A fair die is rolled <InlineMath math="7" /> times, and <InlineMath math="X" /> counts how many times a <InlineMath math="5" /> appears. Each roll has two outcomes, the number of rolls is fixed, the rolls are independent, and the success probability is always <InlineMath math="p = \frac{1}{6}" />, so <InlineMath math="X \sim B\left(7, \frac{1}{6}\right)" />:

<BlockMath math="E(X) = np = 7 \cdot \frac{1}{6} = \frac{7}{6} \approx 1.17" />

The value <InlineMath math="1.17" /> cannot occur in one set of seven rolls, because the number of fives is always a whole number from <InlineMath math="0" /> to <InlineMath math="7" />. If you repeat the seven rolls hundreds of times, **the average number of fives per set approaches <InlineMath math="1.17" />**.

The expected value also differs from the most likely result. The binomial formula gives <InlineMath math="P(X = 0) \approx 0.279" />, <InlineMath math="P(X = 1) \approx 0.391" />, and <InlineMath math="P(X = 2) \approx 0.234" />. The most likely result is one five, while the expected value lies between <InlineMath math="1" /> and <InlineMath math="2" />. Check with the definition of expected value: <InlineMath math="1(0.3907) + 2(0.2344) + 3(0.0781) + 4(0.0156) + 5(0.0019) + 6(0.0001) \approx 1.166" />, which matches <InlineMath math="\frac{7}{6} \approx 1.167" /> up to rounding.

## Example with Guessing on a Multiple Choice Test

A student guesses all <InlineMath math="20" /> questions on a multiple choice test, each with <InlineMath math="5" /> options. The number of correct answers <InlineMath math="X" /> has the distribution <InlineMath math="B\left(20, \frac{1}{5}\right)" />, so <InlineMath math="E(X) = 20 \cdot \frac{1}{5} = 4" />.

Suppose a correct answer earns <InlineMath math="4" /> points and a wrong answer loses <InlineMath math="1" /> point. The score is <InlineMath math="S = 4X - (20 - X) = 5X - 20" />, and **linearity of expected value** gives:

<BlockMath math="E(S) = 5 \cdot E(X) - 20 = 5 \cdot 4 - 20 = 0" />

Check per question: one guess has an expected value of <InlineMath math="4 \cdot \frac{1}{5} - 1 \cdot \frac{4}{5} = 0" /> points, so twenty guesses also have an expected value of <InlineMath math="0" />. Under this rule, guessing adds nothing to the score in the long run.

## Common Mistakes

| Mistake | Why it fails | How to check |
| --- | --- | --- |
| Thinking <InlineMath math="E(X)" /> must happen | <InlineMath math="E(X)" /> is an average over many repetitions | With the die, <InlineMath math="\frac{7}{6}" /> cannot occur in one set |
| Rounding <InlineMath math="np" /> and calling it the expected value | Rounding changes the value | Write <InlineMath math="\frac{7}{6}" /> or <InlineMath math="1.17" />, not <InlineMath math="1" /> |
| Treating the expected value as the most likely result | The most likely result can differ from <InlineMath math="np" /> | With the die, the most likely result is <InlineMath math="1" />, the expected value <InlineMath math="1.17" /> |
| Using <InlineMath math="p" /> when failures are counted | The number of failures has expected value <InlineMath math="n(1 - p)" /> | Expected successes and failures must add up to <InlineMath math="n" /> |
| Using <InlineMath math="np" /> when each trial has its own probability | Indicator <InlineMath math="k" /> has expected value <InlineMath math="p_k" /> | Add <InlineMath math="p_1 + p_2 + \cdots + p_n" /> |

Before you use <InlineMath math="np" />, **say what counts as a success** and what its probability is. That step prevents the last two mistakes.

## Exercises

The first two problems use the formula directly, the third reverses it, and the fourth combines the expected value with a scoring rule. **Find <InlineMath math="n" /> and <InlineMath math="p" /> first**, then check your answer before you read the solution.

1. A fair coin is tossed <InlineMath math="40" /> times. Find the expected number of heads.

2. A student guesses <InlineMath math="30" /> questions with <InlineMath math="4" /> options each. Find the expected number of correct answers and of wrong answers.

3. A machine is expected to produce <InlineMath math="6" /> defective items out of <InlineMath math="150" />, and each item is defective with the same probability. Find that probability, then the expected number of defective items out of <InlineMath math="400" />.

4. A test has <InlineMath math="25" /> questions with <InlineMath math="5" /> options each. A correct answer earns <InlineMath math="4" /> points and a wrong answer loses <InlineMath math="0.5" /> points. Find the expected score if every question is guessed.

### Worked Solutions

**Problem 1**. Each toss shows heads with probability <InlineMath math="\frac{1}{2}" />, so <InlineMath math="n = 40" /> and <InlineMath math="p = \frac{1}{2}" />:

<BlockMath math="E(X) = 40 \cdot \frac{1}{2} = 20" />

Check: heads and tails are equally likely, so **their expected counts are equal**, each half of <InlineMath math="40" />.

**Problem 2**. The probability of guessing correctly is <InlineMath math="\frac{1}{4}" />, and of guessing wrong <InlineMath math="\frac{3}{4}" />:

<MathContainer>
  <BlockMath math="E(\text{correct}) = 30 \cdot \frac{1}{4} = 7.5" />
  <BlockMath math="E(\text{wrong}) = 30 \cdot \frac{3}{4} = 22.5" />
</MathContainer>

Check: <InlineMath math="7.5 + 22.5 = 30" />, so **the expected correct and wrong answers add up to the number of questions**.

**Problem 3**. From <InlineMath math="np = 6" /> and <InlineMath math="n = 150" />, the defect probability is <InlineMath math="p = \frac{6}{150} = 0.04" />. For <InlineMath math="400" /> items:

<BlockMath math="E(X) = 400 \cdot 0.04 = 16" />

Check: <InlineMath math="\frac{16}{400} = \frac{6}{150} = 0.04" />, so **the expected share of defects stays the same**.

**Problem 4**. The number of correct answers is <InlineMath math="X \sim B\left(25, \frac{1}{5}\right)" />, so <InlineMath math="E(X) = 5" />. The score is <InlineMath math="S = 4X - 0.5(25 - X) = 4.5X - 12.5" />:

<BlockMath math="E(S) = 4.5 \cdot 5 - 12.5 = 22.5 - 12.5 = 10" />

Check per question: one guess has an expected value of <InlineMath math="4 \cdot 0.2 - 0.5 \cdot 0.8 = 0.4" /> points, and <InlineMath math="25 \cdot 0.4 = 10" />. With a small penalty, **guessing raises the score in the long run**.
