## Definition einer Kreissehne

Eine Sehne ist eine Strecke, die zwei Punkte auf einem Kreis verbindet. Im Gegensatz zu einem Durchmesser muss sie nicht durch den Kreismittelpunkt verlaufen. Ihre beiden Endpunkte liegen jedoch immer auf dem Kreis.

## Sehnenlänge

### Formel für die Sehnenlänge

Um die Länge einer Sehne zu berechnen, können wir die Formel verwenden:

<BlockMath math="AB = 2r \sin\left(\frac{\theta}{2}\right)" />

Dabei gilt:

- <InlineMath math="r" /> = Radius des Kreises
- <InlineMath math="\theta" /> = der kleinere Mittelpunktswinkel über der Sehne; der Rechnermodus muss zur Winkeleinheit passen

### Abstand einer Sehne vom Mittelpunkt

Der Abstand einer Sehne vom Mittelpunkt des Kreises kann mit der Formel berechnet werden:

<BlockMath math="d = r \cos\left(\frac{\theta}{2}\right)" />

Oder wenn die Sehnenlänge <InlineMath math="l" /> bekannt ist:

<BlockMath math="d = \sqrt{r^2 - \left(\frac{l}{2}\right)^2}" />

      points: (() => {
        // Schnittpunkt P berechnen
        const A = {
          x: 5 * Math.cos(Math.PI / 3),
          y: 5 * Math.sin(Math.PI / 3),
        };
        const B = {
          x: 5 * Math.cos((4 * Math.PI) / 3),
          y: 5 * Math.sin((4 * Math.PI) / 3),
        };
        const C = {
          x: 5 * Math.cos((5 * Math.PI) / 6),
          y: 5 * Math.sin((5 * Math.PI) / 6),
        };
        const D = {
          x: 5 * Math.cos((11 * Math.PI) / 6),
          y: 5 * Math.sin((11 * Math.PI) / 6),
        };

        // Gerade AB in Parameterform
        // Gerade CD in Parameterform
        // Schnittpunkt bestimmen
        const denominator =
          (A.x - B.x) * (C.y - D.y) - (A.y - B.y) * (C.x - D.x);
        const t =
          ((A.x - C.x) * (C.y - D.y) - (A.y - C.y) * (C.x - D.x)) / denominator;

        const P = {
          x: A.x + t * (B.x - A.x),
          y: A.y + t * (B.y - A.y),
        };

        return [{ x: P.x, y: P.y, z: 0 }];
      })(),
      color: "#db2777",
      showPoints: true,

## Übungsaufgaben

1. Ein Kreis hat einen Radius von <InlineMath math="10 \text{ cm}" />. Der kleinere Mittelpunktswinkel über einer Sehne beträgt <InlineMath math="60^\circ" />. Bestimmen Sie:

   - Die Länge der Sehne
   - Der Abstand der Sehne vom Mittelpunkt des Kreises

2. Zwei Sehnen <InlineMath math="AB" /> und <InlineMath math="CD" /> schneiden sich im Punkt <InlineMath math="P" /> innerhalb eines Kreises. Wenn <InlineMath math="PA = 4 \text{ cm}" />, <InlineMath math="PB = 6 \text{ cm}" /> und <InlineMath math="PC = 3 \text{ cm}" />, ermitteln Sie die Länge von <InlineMath math="PD" />.

3. In einem Kreis mit Radius <InlineMath math="13 \text{ cm}" /> gibt es eine Sehne der Länge <InlineMath math="24 \text{ cm}" />. Berechnen Sie den Abstand dieser Sehne vom Mittelpunkt des Kreises.

4. Zwei parallele Sehnen in einem Kreis sind <InlineMath math="3 \text{ cm}" /> bzw. <InlineMath math="4 \text{ cm}" /> vom Mittelpunkt entfernt. Wenn der Radius des Kreises <InlineMath math="5 \text{ cm}" /> beträgt, bestimmen Sie die Längen beider Sehnen.

5. Beweisen Sie, dass die längste Sehne in einem Kreis der Durchmesser ist.

### Ausführliche Lösungen

1. **Sehnenlänge und Abstand vom Kreismittelpunkt berechnen**

   Gegeben: <InlineMath math="r = 10 \text{ cm}" />, <InlineMath math="\theta = 60^\circ = \frac{\pi}{3}" /> rad

   <MathContainer>
     <BlockMath math="l = 2r \sin\left(\frac{\theta}{2}\right) = 2 \times 10 \times \sin\left(\frac{\pi/3}{2}\right)" />
     <BlockMath math="l = 20 \times \sin(30^\circ) = 20 \times 0{,}5 = 10 \text{ cm}" />
     <BlockMath math="d = r \cos\left(\frac{\theta}{2}\right) = 10 \times \cos(30^\circ)" />
     <BlockMath math="d = 10 \times \frac{\sqrt{3}}{2} = 5\sqrt{3} \text{ cm}" />
   </MathContainer>

2. **Sehnensatz**

   Gegeben: <InlineMath math="PA = 4 \text{ cm}" />, <InlineMath math="PB = 6 \text{ cm}" />, <InlineMath math="PC = 3 \text{ cm}" />

   <MathContainer>
     <BlockMath math="PA \times PB = PC \times PD" />
     <BlockMath math="4 \times 6 = 3 \times PD" />
     <BlockMath math="24 = 3 \times PD" />
     <BlockMath math="PD = 8 \text{ cm}" />
   </MathContainer>

3. **Abstand der Sehne vom Kreismittelpunkt berechnen**

   Gegeben: <InlineMath math="r = 13 \text{ cm}" />, <InlineMath math="l = 24 \text{ cm}" />

   <MathContainer>
     <BlockMath math="d = \sqrt{r^2 - \left(\frac{l}{2}\right)^2}" />
     <BlockMath math="d = \sqrt{13^2 - 12^2}" />
     <BlockMath math="d = \sqrt{169 - 144}" />
     <BlockMath math="d = \sqrt{25} = 5 \text{ cm}" />
   </MathContainer>

4. **Parallele Sehnen**

   Gegeben: <InlineMath math="r = 5 \text{ cm}" />, <InlineMath math="d_1 = 3 \text{ cm}" />, <InlineMath math="d_2 = 4 \text{ cm}" />

   Für die erste Sehne:

   <MathContainer>
     <BlockMath math="l_1 = 2\sqrt{r^2 - d_1^2} = 2\sqrt{25 - 9} = 2\sqrt{16} = 8 \text{ cm}" />
   </MathContainer>

   Für die zweite Sehne:

   <MathContainer>
     <BlockMath math="l_2 = 2\sqrt{r^2 - d_2^2} = 2\sqrt{25 - 16} = 2\sqrt{9} = 6 \text{ cm}" />
   </MathContainer>

5. **Beweis, dass der Durchmesser die längste Sehne ist**

   Für jede Sehne sei <InlineMath math="\theta" /> der kleinere Mittelpunktswinkel, sodass <InlineMath math="0^\circ\leq\theta\leq180^\circ" /> gilt:

   <MathContainer>
     <BlockMath math="l = 2r \sin\left(\frac{\theta}{2}\right)" />
   </MathContainer>

   Der Maximalwert von <InlineMath math="\sin\left(\frac{\theta}{2}\right) = 1" /> wird erreicht, wenn <InlineMath math="\frac{\theta}{2} = 90^\circ" />, also <InlineMath math="\theta = 180^\circ" />.

   Bei <InlineMath math="\theta = 180^\circ" /> verläuft die Sehne durch den Mittelpunkt des Kreises (Durchmesser) mit der Länge:

   <MathContainer>
     <BlockMath math="l_{\max} = 2r \times 1 = 2r" />
   </MathContainer>

   Daher ist der Durchmesser die längste Sehne.
