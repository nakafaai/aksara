## Teorema Perpotongan Tali Busur

Jika dua tali busur berpotongan di dalam lingkaran, maka hasil kali segmen-segmen dari satu tali busur sama dengan hasil kali segmen-segmen dari tali busur lainnya.

      ],
    },
    {
      points: (() => {
        const angle1 = (5 * Math.PI) / 6;
        const angle2 = (11 * Math.PI) / 6;
        return [
          { x: 5 * Math.cos(angle1), y: 5 * Math.sin(angle1), z: 0 },
          { x: 5 * Math.cos(angle2), y: 5 * Math.sin(angle2), z: 0 },
        ];
      })(),
      color: "#0d9488",
      showPoints: true,
      labels: [
        { text: <InlineMath math="C" />, at: 0, offset: [-0.3, 0.3, 0] },
        { text: <InlineMath math="D" />, at: 1, offset: [0.3, -0.3, 0] },
      ],
    },
    {
      points: (() => {
        // Calculate intersection point P
        const A = {
          x: 5 * Math.cos(Math.PI / 3),
          y: 5 * Math.sin(Math.PI / 3),
        };
        const B = {
          x: 5 * Math.cos((4 * Math.PI) / 3),
          y: 5 * Math.sin((4 * Math.PI) / 3),
        };
        const C = {
          x: 5 * Math.cos((5 * Math.PI) / 6),
          y: 5 * Math.sin((5 * Math.PI) / 6),
        };
        const D = {
          x: 5 * Math.cos((11 * Math.PI) / 6),
          y: 5 * Math.sin((11 * Math.PI) / 6),
        };

        // Line AB: parametric form
        // Line CD: parametric form
        // Solve for intersection
        const denominator =
          (A.x - B.x) * (C.y - D.y) - (A.y - B.y) * (C.x - D.x);
        const t =
          ((A.x - C.x) * (C.y - D.y) - (A.y - C.y) * (C.x - D.x)) / denominator;

        const P = {
          x: A.x + t * (B.x - A.x),
          y: A.y + t * (B.y - A.y),
        };

        return [{ x: P.x, y: P.y, z: 0 }];
      })(),
      color: "#db2777",
      showPoints: true,
      labels: [{ text: <InlineMath math="P" />, at: 0, offset: [0.3, 0, 0] }],
    },

]}
cameraPosition={[0, 0, 15]}

/>

## Latihan Soal

1. Sebuah lingkaran memiliki jari-jari <InlineMath math="10 \text{ cm}" />. Jika sudut pusat yang menghadap tali busur adalah <InlineMath math="60^\circ" />, tentukan:

   - Panjang tali busur
   - Jarak tali busur dari pusat lingkaran

2. Dua tali busur <InlineMath math="AB" /> dan <InlineMath math="CD" /> berpotongan di titik <InlineMath math="P" /> di dalam lingkaran. Jika <InlineMath math="PA = 4 \text{ cm}" />, <InlineMath math="PB = 6 \text{ cm}" />, dan <InlineMath math="PC = 3 \text{ cm}" />, tentukan panjang <InlineMath math="PD" />.

3. Dalam lingkaran berjari-jari <InlineMath math="13 \text{ cm}" />, terdapat tali busur sepanjang <InlineMath math="24 \text{ cm}" />. Hitunglah jarak tali busur tersebut dari pusat lingkaran.

4. Dua tali busur sejajar dalam lingkaran masing-masing berjarak <InlineMath math="3 \text{ cm}" /> dan <InlineMath math="4 \text{ cm}" /> dari pusat lingkaran. Jika jari-jari lingkaran <InlineMath math="5 \text{ cm}" />, tentukan panjang kedua tali busur tersebut.

5. Buktikan bahwa tali busur terpanjang dalam lingkaran adalah diameter.

### Pembahasan

1. **Menghitung panjang tali busur dan jaraknya dari pusat**

   Diketahui: <InlineMath math="r = 10 \text{ cm}" />, <InlineMath math="\theta = 60^\circ = \frac{\pi}{3}" /> rad

   <MathContainer>
     <BlockMath math="l = 2r \sin\left(\frac{\theta}{2}\right) = 2 \times 10 \times \sin\left(\frac{\pi/3}{2}\right)" />
     <BlockMath math="l = 20 \times \sin(30^\circ) = 20 \times 0{,}5 = 10 \text{ cm}" />
     <BlockMath math="d = r \cos\left(\frac{\theta}{2}\right) = 10 \times \cos(30^\circ)" />
     <BlockMath math="d = 10 \times \frac{\sqrt{3}}{2} = 5\sqrt{3} \text{ cm}" />
   </MathContainer>

2. **Teorema perpotongan tali busur**

   Diketahui: <InlineMath math="PA = 4 \text{ cm}" />, <InlineMath math="PB = 6 \text{ cm}" />, <InlineMath math="PC = 3 \text{ cm}" />

   <MathContainer>
     <BlockMath math="PA \times PB = PC \times PD" />
     <BlockMath math="4 \times 6 = 3 \times PD" />
     <BlockMath math="24 = 3 \times PD" />
     <BlockMath math="PD = 8 \text{ cm}" />
   </MathContainer>

3. **Menghitung jarak tali busur dari pusat**

   Diketahui: <InlineMath math="r = 13 \text{ cm}" />, <InlineMath math="l = 24 \text{ cm}" />

   <MathContainer>
     <BlockMath math="d = \sqrt{r^2 - \left(\frac{l}{2}\right)^2}" />
     <BlockMath math="d = \sqrt{13^2 - 12^2}" />
     <BlockMath math="d = \sqrt{169 - 144}" />
     <BlockMath math="d = \sqrt{25} = 5 \text{ cm}" />
   </MathContainer>

4. **Tali busur sejajar**

   Diketahui: <InlineMath math="r = 5 \text{ cm}" />, <InlineMath math="d_1 = 3 \text{ cm}" />, <InlineMath math="d_2 = 4 \text{ cm}" />

   Untuk tali busur pertama:

   <MathContainer>
     <BlockMath math="l_1 = 2\sqrt{r^2 - d_1^2} = 2\sqrt{25 - 9} = 2\sqrt{16} = 8 \text{ cm}" />
   </MathContainer>

   Untuk tali busur kedua:

   <MathContainer>
     <BlockMath math="l_2 = 2\sqrt{r^2 - d_2^2} = 2\sqrt{25 - 16} = 2\sqrt{9} = 6 \text{ cm}" />
   </MathContainer>

5. **Bukti diameter adalah tali busur terpanjang**

   Untuk sebarang tali busur, ambil <InlineMath math="\theta" /> sebagai sudut pusat yang lebih kecil, sehingga <InlineMath math="0^\circ\leq\theta\leq180^\circ" />:

   <MathContainer>
     <BlockMath math="l = 2r \sin\left(\frac{\theta}{2}\right)" />
   </MathContainer>

   Nilai maksimum <InlineMath math="\sin\left(\frac{\theta}{2}\right) = 1" /> tercapai ketika <InlineMath math="\frac{\theta}{2} = 90^\circ" />, yaitu <InlineMath math="\theta = 180^\circ" />.

   Saat <InlineMath math="\theta = 180^\circ" />, tali busur melewati pusat lingkaran (diameter) dengan panjang:

   <MathContainer>
     <BlockMath math="l_{\max} = 2r \times 1 = 2r" />
   </MathContainer>

   Terbukti bahwa diameter adalah tali busur terpanjang.
