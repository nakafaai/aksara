## Common Tangent Formulas

A common tangent is a line that **touches two circles at once**. A common external tangent touches both circles from the same side, while a common internal tangent passes between the two circles. If the centers are a distance <InlineMath math="d" /> apart and the radii are <InlineMath math="r_1" /> and <InlineMath math="r_2" />, the length of the tangent segment is:

<MathContainer>
  <BlockMath math="l_{\text{ext}} = \sqrt{d^2 - (r_2 - r_1)^2}" />
  <BlockMath math="l_{\text{int}} = \sqrt{d^2 - (r_1 + r_2)^2}" />
</MathContainer>

The external tangent uses the **difference of the radii**, and the internal tangent uses the **sum of the radii**. The external formula holds while <InlineMath math="d > r_2 - r_1" />, and the internal formula needs <InlineMath math="d \ge r_1 + r_2" />. The external tangent diagram shows two circles whose centers are <InlineMath math="8" /> apart, with radii <InlineMath math="2" /> and <InlineMath math="3" />. Look at the right triangle <InlineMath math="AHB" />, which is where the first formula comes from.

## Length of a Common External Tangent

The external tangent formula rests on one fact: a [tangent line to a circle](/en/subjects/mathematics/circle/circle-and-tangent-line) is always **perpendicular to the radius** at the point of tangency. So the two radii to the points of tangency are parallel, and the shape between them is a right trapezoid.

In the external tangent diagram, draw the helper segment <InlineMath math="AH" /> from center <InlineMath math="A" /> parallel to the tangent. Segment <InlineMath math="AH" /> is as long as the tangent segment, so <InlineMath math="AH = l" />. Segment <InlineMath math="BH" /> is what remains of the larger radius after you take away the smaller one, so <InlineMath math="BH = r_2 - r_1" />. The angle at <InlineMath math="H" /> is a right angle, and the Pythagorean theorem gives:

<BlockMath math="l^2 + (r_2 - r_1)^2 = d^2 \quad\Longrightarrow\quad l = \sqrt{d^2 - (r_2 - r_1)^2}" />

Call the larger radius <InlineMath math="r_2" /> so the difference is positive. The square of the difference is the same either way, but consistent names make the work easier to check. The external tangent segment has a positive length as long as <InlineMath math="d > r_2 - r_1" />, which means the smaller circle is not inside the larger one.

In the internal tangent diagram, extend the radius from center <InlineMath math="B" /> past the point of tangency to the helper point <InlineMath math="H" />, with <InlineMath math="AH" /> parallel to the tangent. Segment <InlineMath math="BH" /> is the radius <InlineMath math="r_2" /> from <InlineMath math="B" /> to the point of tangency plus the extension of length <InlineMath math="r_1" />, so <InlineMath math="BH = r_1 + r_2" />. Triangle <InlineMath math="AHB" /> has a right angle at <InlineMath math="H" />:

<MathContainer>
  <BlockMath math="l^2 + (r_1 + r_2)^2 = d^2" />
  <BlockMath math="l = \sqrt{d^2 - (r_1 + r_2)^2}" />
</MathContainer>

In that diagram, <InlineMath math="d = 8" /> and both radii are <InlineMath math="2" />, so <InlineMath math="l = \sqrt{64 - 16} = \sqrt{48} = 4\sqrt{3}" />. An internal tangent exists only when <InlineMath math="d \ge r_1 + r_2" />. When <InlineMath math="d = r_1 + r_2" />, the circles touch externally, the two points of tangency coincide, and the segment has length zero.

        const T2y = O2.y + r2 * Math.sin(theta - Math.PI / 2 + alpha + Math.PI);

        const dx = T2x - T1x;
        const dy = T2y - T1y;
        const len = Math.sqrt(dx * dx + dy * dy);
        const ux = dx / len;
        const uy = dy / len;

        const points = [
          { x: T1x - 2 * ux, y: T1y - 2 * uy, z: 0 },
          { x: T2x + 2 * ux, y: T2y + 2 * uy, z: 0 },
        ];
        const extension = {
          x: (points[1].x - points[0].x) * 0.1,
          y: (points[1].y - points[0].y) * 0.1,
        };
        return [
          { x: points[0].x - extension.x, y: points[0].y - extension.y, z: 0 },
          ...points,
          { x: points[1].x + extension.x, y: points[1].y + extension.y, z: 0 },
        ];
      })()).map(({ x, y }) => ({ x, y })), appearance: "reference" },
    ],
  }}
/>

The centers are <InlineMath math="d = 4" /> apart and the radii are equal, so the external tangent equals <InlineMath math="d" /> right away:

<MathContainer>
  <BlockMath math="l_{\text{ext}} = d = 4" />
  <BlockMath math="l_{\text{int}} = \sqrt{4^2 - (1.5 + 1.5)^2} = \sqrt{16 - 9} = \sqrt{7} \approx 2.65" />
</MathContainer>

Here the gap between the two lengths is much larger, because the squared sum of the radii, <InlineMath math="9" />, is already more than half of <InlineMath math="d^2 = 16" />.

## How Many Common Tangents Two Circles Have

The number of common tangents depends on **the distance between the centers compared with the radii**. The same comparison decides the [position of two circles](/en/subjects/mathematics/analytic-geometry/position-of-two-circles), so the number of common tangents also tells you how the circles sit.

| Condition on the center distance | Common tangents | Position of the circles |
| --- | ---: | --- |
| <InlineMath math="d > r_1 + r_2" /> | <InlineMath math="4" /> | separate |
| <InlineMath math="d = r_1 + r_2" /> | <InlineMath math="3" /> | touching externally |
| <InlineMath math="\lvert r_1 - r_2 \rvert < d < r_1 + r_2" /> | <InlineMath math="2" /> | intersecting at two points |
| <InlineMath math="d = \lvert r_1 - r_2 \rvert" /> | <InlineMath math="1" /> | touching internally |
| <InlineMath math="d < \lvert r_1 - r_2 \rvert" /> | <InlineMath math="0" /> | one circle inside the other |

This classification holds for two circles that do not coincide. As the circles move closer, the two internal tangents disappear first, because an internal tangent needs a gap between the circles.

## Common Mistakes

Before you substitute any numbers, decide **which kind of tangent** the problem asks for.

| Mistake | Why it fails | How to check |
| --- | --- | --- |
| Using the sum of the radii for an external tangent | Leg <InlineMath math="BH" /> of the helper triangle for an external tangent is the difference of the radii | The external tangent must be longer than the internal one |
| Writing <InlineMath math="l = d - (r_2 - r_1)" /> | The formula comes from the Pythagorean theorem, so the square of the radius difference is subtracted from <InlineMath math="d^2" /> | Check that <InlineMath math="l^2 + (r_2 - r_1)^2 = d^2" /> |
| Using a diameter as the radius | The formula uses the distance from a center to its point of tangency | Reread whether the problem gives radii or diameters |
| Computing an internal tangent for intersecting circles | An internal tangent exists only when <InlineMath math="d \ge r_1 + r_2" /> | Compare <InlineMath math="d" /> with <InlineMath math="r_1 + r_2" /> first |

The last mistake shows up in the numbers. If <InlineMath math="d < r_1 + r_2" />, the number under the square root is negative, which tells you the internal tangent does not exist.

## Practice on Common Tangents

For each problem, choose **the difference or the sum of the radii** to match the kind of tangent before you set up an equation. Problems 3 and 4 also need the table of common tangents.

1. The first circle has center <InlineMath math="(0, 0)" /> and radius <InlineMath math="4" />, and the second has center <InlineMath math="(10, 0)" /> and radius <InlineMath math="2" />. Find the lengths of their common external and internal tangents.

2. Two circles each have radius <InlineMath math="3 \text{ cm}" />. Their common internal tangent is <InlineMath math="8 \text{ cm}" /> long. Find the distance between their centers.

3. Circle <InlineMath math="A" /> has center <InlineMath math="(-5, 0)" /> and radius <InlineMath math="r" />, and circle <InlineMath math="B" /> has center <InlineMath math="(7, 0)" /> and radius <InlineMath math="2r" />. Their common external tangent is <InlineMath math="4\sqrt{8}" /> long. Find <InlineMath math="r" /> and the number of common tangents of the two circles.

4. One circle is <InlineMath math="x^2 + y^2 = 4" />, and another has center <InlineMath math="(5, 0)" /> and radius <InlineMath math="3" />. How many common tangents do they have, and how long is their common external tangent?

### Answers

**Problem 1**. The centers are <InlineMath math="d = 10" /> apart. The external tangent uses the **difference** <InlineMath math="4 - 2 = 2" />, and the internal tangent uses the **sum** <InlineMath math="4 + 2 = 6" />:

<MathContainer>
  <BlockMath math="l_{\text{ext}} = \sqrt{10^2 - 2^2} = \sqrt{96} = 4\sqrt{6}" />
  <BlockMath math="l_{\text{int}} = \sqrt{10^2 - 6^2} = \sqrt{64} = 8" />
</MathContainer>

The order is what you expect, because <InlineMath math="4\sqrt{6} \approx 9.80" /> is longer than <InlineMath math="8" />.

**Problem 2**. The given length belongs to an internal tangent, so the formula uses the **sum of the radii**, <InlineMath math="3 + 3 = 6" />, and you solve for <InlineMath math="d" />:

<MathContainer>
  <BlockMath math="8 = \sqrt{d^2 - 6^2}" />
  <BlockMath math="64 = d^2 - 36" />
  <BlockMath math="d^2 = 100 \quad\Longrightarrow\quad d = 10 \text{ cm}" />
</MathContainer>

A distance is positive, so the value <InlineMath math="-10" /> is rejected. Check: <InlineMath math="\sqrt{100 - 36} = \sqrt{64} = 8" />.

**Problem 3**. The centers are <InlineMath math="d = 7 - (-5) = 12" /> apart, and the difference of the radii is <InlineMath math="2r - r = r" />. Square both sides to remove the square root:

<MathContainer>
  <BlockMath math="4\sqrt{8} = \sqrt{12^2 - r^2}" />
  <BlockMath math="128 = 144 - r^2" />
  <BlockMath math="r^2 = 16 \quad\Longrightarrow\quad r = 4" />
</MathContainer>

A radius is positive, so <InlineMath math="r = -4" /> is rejected. The radii are <InlineMath math="4" /> and <InlineMath math="8" />. Their sum is <InlineMath math="12" />, equal to the distance between the centers, so the circles **touch externally** and have <InlineMath math="3" /> common tangents.

**Problem 4**. The circle <InlineMath math="x^2 + y^2 = 4" /> has center <InlineMath math="(0, 0)" /> and radius <InlineMath math="2" />. The centers are <InlineMath math="d = 5" /> apart, which equals <InlineMath math="2 + 3" />, so the circles touch externally and have <InlineMath math="3" /> common tangents. The external tangent length is:

<BlockMath math="l_{\text{ext}} = \sqrt{5^2 - (3 - 2)^2} = \sqrt{24} = 2\sqrt{6}" />

The remaining internal tangent passes through the point where the circles touch, so its segment has length zero. The formula agrees: <InlineMath math="\sqrt{25 - 25} = 0" />.
