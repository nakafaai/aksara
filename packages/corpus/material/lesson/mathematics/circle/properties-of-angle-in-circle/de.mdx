## Winkelsätze anwenden

### Winkelmaße bestimmen

In einem Kreis mit Mittelpunkt <InlineMath math="O" /> beträgt der Mittelpunktswinkel <InlineMath math="\angle AOB = 100^\circ" />. Gesucht ist der Umfangswinkel <InlineMath math="\angle ACB" /> über demselben Bogen.

**Lösung:**

Wir nutzen den Zusammenhang zwischen Mittelpunktswinkel und Umfangswinkel:

<MathContainer>
  <BlockMath math="\angle ACB = \frac{1}{2} \times \angle AOB" />
  <BlockMath math="\angle ACB = \frac{1}{2} \times 100^\circ" />
  <BlockMath math="\angle ACB = 50^\circ" />
</MathContainer>

### Gegenüberliegende Winkel bestimmen

Im Sehnenviereck <InlineMath math="ABCD" /> ist <InlineMath math="\angle A = 75^\circ" /> gegeben. Bestimme <InlineMath math="\angle C" />.

**Lösung:**

Wir nutzen die Winkelsumme im Sehnenviereck:

<MathContainer>
  <BlockMath math="\angle A + \angle C = 180^\circ" />
  <BlockMath math="75^\circ + \angle C = 180^\circ" />
  <BlockMath math="\angle C = 180^\circ - 75^\circ" />
  <BlockMath math="\angle C = 105^\circ" />
</MathContainer>

### Satz des Thales anwenden

Der Punkt <InlineMath math="C" /> liegt auf einem Kreis mit dem Durchmesser <InlineMath math="AB" />. Bestimme <InlineMath math="\angle ACB" />.

**Lösung:**

Da <InlineMath math="AB" /> ein Durchmesser ist und <InlineMath math="C" /> auf dem Kreis liegt, gilt nach dem Satz des Thales:

<BlockMath math="\angle ACB = 90^\circ" />

   Wir nutzen den Zusammenhang zwischen Mittelpunktswinkel und Umfangswinkel:

   <MathContainer>
     <BlockMath math="\text{Umfangswinkel} = \frac{1}{2} \times \text{Mittelpunktswinkel}" />
     <BlockMath math="\angle ACB = \frac{1}{2} \times \angle AOB" />
     <BlockMath math="\angle ACB = \frac{1}{2} \times 140^\circ" />
     <BlockMath math="\angle ACB = 70^\circ" />
   </MathContainer>

   Da Umfangswinkel über demselben Bogen gleich groß sind:

   <BlockMath math="\angle ADB = \angle ACB = 70^\circ" />

2. **Winkel im Sehnenviereck bestimmen**

   **Lösung:**

   In einem Sehnenviereck gilt <InlineMath math="\text{Summe der entgegengesetzten Winkel} = 180^\circ" />

   Für Winkel <InlineMath math="R" /> (entgegengesetzt zu <InlineMath math="P" />):

   <MathContainer>
     <BlockMath math="\angle P + \angle R = 180^\circ" />
     <BlockMath math="85^\circ + \angle R = 180^\circ" />
     <BlockMath math="\angle R = 180^\circ - 85^\circ" />
     <BlockMath math="\angle R = 95^\circ" />
   </MathContainer>

   Für Winkel <InlineMath math="S" /> (entgegengesetzt zu <InlineMath math="Q" />):

   <MathContainer>
     <BlockMath math="\angle Q + \angle S = 180^\circ" />
     <BlockMath math="110^\circ + \angle S = 180^\circ" />
     <BlockMath math="\angle S = 180^\circ - 110^\circ" />
     <BlockMath math="\angle S = 70^\circ" />
   </MathContainer>

3. **Winkel im gleichschenkligen Dreieck mit Durchmesser bestimmen**

   <LineEquation
     title="Visualisierung"
     description={
       <>
         <InlineMath math="AB" /> ist ein Durchmesser,{" "}
         <InlineMath math="BC = AC" /> (gleichschenkliges Dreieck).
       </>
     }
     data={[
       {
         points: Array.from({ length: 361 }, (_, i) => {
           const angle = (i * Math.PI) / 180;
           return {
             x: 4 * Math.cos(angle),
             y: 4 * Math.sin(angle),
             z: 0,
           };
         }),
         color: "#9333ea",
         showPoints: false,
       },
       {
         points: [
           { x: -4, y: 0, z: 0 },
           { x: 4, y: 0, z: 0 },
         ],
         color: "#ea580c",
         showPoints: true,
         labels: [
           { text: <InlineMath math="A" />, at: 0, offset: [-0.5, 0, 0] },
           { text: <InlineMath math="B" />, at: 1, offset: [0.5, 0, 0] },
         ],
       },
       {
         points: [
           { x: -4, y: 0, z: 0 },
           { x: 0, y: 4, z: 0 },
         ],
         color: "#0891b2",
         showPoints: true,
         labels: [{ text: <InlineMath math="C" />, at: 1, offset: [0, 0.5, 0] }],
       },
       {
         points: [
           { x: 4, y: 0, z: 0 },
           { x: 0, y: 4, z: 0 },
         ],
         color: "#0891b2",
         showPoints: false,
       },
       {
         points: [{ x: 0, y: 0, z: 0 }],
         color: "#d97706",
         showPoints: true,
         labels: [{ text: <InlineMath math="O" />, at: 0, offset: [0, -0.5, 0] }],
       },
       {
         points: (() => {
           const C = { x: 0, y: 4 };
           const A = { x: -4, y: 0 };
           const B = { x: 4, y: 0 };

           // Winkel ACB am Punkt C berechnen (should be 90°)
           const angleCA = Math.atan2(A.y - C.y, A.x - C.x);
           const angleCB = Math.atan2(B.y - C.y, B.x - C.x);

           return Array.from({ length: 16 }, (_, i) => {
             const t = i / 15;
             const angle = angleCA + t * (angleCB - angleCA);
             return {
               x: C.x + 0.8 * Math.cos(angle),
               y: C.y + 0.8 * Math.sin(angle),
               z: 0,
             };
           });
         })(),
         color: "#db2777",
         showPoints: false,
         labels: [{ text: <InlineMath math="90^\circ" />, at: 7, offset: [-0.3, -0.5, 0] }],
       },
     ]}
     cameraPosition={[0, 0, 12]}
     showZAxis={false}
   />

   **Lösung:**

   Da <InlineMath math="AB" /> ein Durchmesser ist, gilt nach dem Satz von Thales:

   <BlockMath math="\angle ACB = 90^\circ" />

   Da <InlineMath math="BC = AC" /> gilt, ist das Dreieck <InlineMath math="ABC" /> ein
   rechtes gleichschenkliges Dreieck.

   In einem rechtwinkligen gleichschenkligen Dreieck sind beide Grundwinkel gleich:

   <MathContainer>
     <BlockMath math="\angle BAC + \angle ABC + \angle ACB = 180^\circ" />
     <BlockMath math="\angle BAC + \angle ABC + 90^\circ = 180^\circ" />
     <BlockMath math="\angle BAC + \angle ABC = 90^\circ" />
   </MathContainer>

   Da <InlineMath math="\angle BAC = \angle ABC" /> (Basiswinkel des gleichschenkligen Dreiecks):

   <MathContainer>
     <BlockMath math="2 \times \angle BAC = 90^\circ" />
     <BlockMath math="\angle BAC = 45^\circ" />
   </MathContainer>

4. **Mittelpunktswinkel aus dem Umfangswinkel bestimmen**

   **Lösung:**

   Wir nutzen den Zusammenhang zwischen Mittelpunktswinkel und Umfangswinkel:

   <MathContainer>
     <BlockMath math="\text{Mittelpunktswinkel} = 2 \times \text{Umfangswinkel}" />
     <BlockMath math="\angle AOB = 2 \times \angle APB" />
     <BlockMath math="\angle AOB = 2 \times 35^\circ" />
     <BlockMath math="\angle AOB = 70^\circ" />
   </MathContainer>

5. **Innenwinkel aus dem Außenwinkel bestimmen**

   **Lösung:**

   In einem Sehnenviereck ist ein Außenwinkel genauso groß wie der gegenüberliegende Innenwinkel.

   Wenn der Außenwinkel bei <InlineMath math="K" /> <InlineMath math="65^\circ" /> beträgt, dann:

   <BlockMath math="\angle M = 65^\circ" />

   Das gilt, weil die Eckpunkte <InlineMath math="K" /> und <InlineMath math="M" /> im Sehnenviereck <InlineMath math="KLMN" /> einander gegenüberliegen.
