## Winkel im Sehnenviereck

Ein Sehnenviereck hat vier Eckpunkte auf einer Kreislinie. Zwei **gegenüberliegende Winkel** überspannen Bögen, die zusammen den ganzen Kreis bilden. Jeder Umfangswinkel ist halb so groß wie sein Bogen, also gilt:

<BlockMath math="\alpha+\gamma=\frac{1}{2}\times360^\circ=180^\circ" />

<LineEquation
  title="Viereck mit gegenüberliegenden Winkeln"
  description="Zwei gegenüberliegende Winkel überspannen Bögen, die den Kreis vervollständigen."
  data={(() => {
    const point = (degrees) => ({ x: 4 * Math.cos(degrees * Math.PI / 180), y: 4 * Math.sin(degrees * Math.PI / 180), z: 0 });
    const A = point(0), B = point(80), C = point(200), D = point(280);
    const E = { x: A.x + 0.4 * (A.x - B.x), y: A.y + 0.4 * (A.y - B.y), z: 0 };
    const arc = (vertex, start, end) => {
      const a = Math.atan2(start.y - vertex.y, start.x - vertex.x);
      let delta = Math.atan2(end.y - vertex.y, end.x - vertex.x) - a;
      if (delta > Math.PI) delta -= 2 * Math.PI;
      if (delta < -Math.PI) delta += 2 * Math.PI;
      return Array.from({ length: 31 }, (_, i) => ({ x: vertex.x + 0.65 * Math.cos(a + delta * i / 30), y: vertex.y + 0.65 * Math.sin(a + delta * i / 30), z: 0 }));
    };
    return [
      { kind: "circle-outline", radius: 4, color: "#9333ea", showPoints: false },
      { points: [A, B, C, D, A], smooth: false, color: "#ea580c", showPoints: true, labels: [{ text: "A", at: 0, offset: [0.35, 0.2, 0] }, { text: "B", at: 1, offset: [0, 0.4, 0] }, { text: "C", at: 2, offset: [-0.4, 0, 0] }, { text: "D", at: 3, offset: [0, -0.4, 0] }] },
      { points: arc(A, D, B), smooth: false, color: "#0891b2", showPoints: false, labels: [{ text: <InlineMath math="\alpha" />, at: 15, offset: [0, -0.35, 0] }] },
      { points: arc(C, B, D), smooth: false, color: "#db2777", showPoints: false, labels: [{ text: <InlineMath math="\gamma" />, at: 15, offset: [0.3, 0.3, 0] }] },
    ];
  })()}
  cameraPosition={[0, 0, 12]}
/>

Im Bild beträgt Winkel <InlineMath math="A" /> <InlineMath math="100^\circ" /> und Winkel <InlineMath math="C" /> <InlineMath math="80^\circ" />. Die Winkel müssen also keine rechten Winkel sein.

<BlockMath math="100^\circ+80^\circ=180^\circ" />

## Außenwinkel und gegenüberliegender Innenwinkel

Verlängere die Seite <InlineMath math="BA" /> bis <InlineMath math="E" />. Der Außenwinkel <InlineMath math="DAE" /> bildet mit dem Innenwinkel bei <InlineMath math="A" /> einen **gestreckten Winkel**. Auch der Innenwinkel bei <InlineMath math="C" /> ergänzt den Winkel bei <InlineMath math="A" /> auf <InlineMath math="180^\circ" />.

<BlockMath math="\varepsilon=180^\circ-\alpha=\gamma" />

## Winkelsätze anwenden

Jedes Beispiel wendet einen Kreissatz auf eine beschriftete Situation an. Bestimme zuerst, welche **Winkel und welchen Bogen** der Satz verbindet. Schreibe die Gleichung auf, bevor du Zahlen einsetzt, weil sie zeigt, welche Größe gesucht ist.

### Winkelmaße bestimmen

In einem Kreis mit Mittelpunkt <InlineMath math="O" /> beträgt der Mittelpunktswinkel <InlineMath math="\angle AOB = 100^\circ" />. Gesucht ist der Umfangswinkel <InlineMath math="\angle ACB" /> über demselben Bogen.

**Lösung**:

Beide Winkel gehören zu **demselben Bogen**. Der Umfangswinkel ist halb so groß wie der Mittelpunktswinkel:

<MathContainer>
  <BlockMath math="\angle ACB = \frac{1}{2} \times \angle AOB" />
  <BlockMath math="\angle ACB = \frac{1}{2} \times 100^\circ" />
  <BlockMath math="\angle ACB = 50^\circ" />
</MathContainer>

### Gegenüberliegende Winkel bestimmen

Im Sehnenviereck <InlineMath math="ABCD" /> ist <InlineMath math="\angle A = 75^\circ" /> gegeben. Bestimme <InlineMath math="\angle C" />.

**Lösung**:

Die **gegenüberliegenden Winkel** im Sehnenviereck ergänzen sich zu einem gestreckten Winkel:

<MathContainer>
  <BlockMath math="\angle A + \angle C = 180^\circ" />
  <BlockMath math="75^\circ + \angle C = 180^\circ" />
  <BlockMath math="\angle C = 180^\circ - 75^\circ" />
  <BlockMath math="\angle C = 105^\circ" />
</MathContainer>

### Satz des Thales anwenden

Der Punkt <InlineMath math="C" /> liegt auf einem Kreis mit dem Durchmesser <InlineMath math="AB" />. Bestimme <InlineMath math="\angle ACB" />.

**Lösung**:

Da <InlineMath math="AB" /> ein Durchmesser ist und <InlineMath math="C" /> auf dem Kreis liegt, gilt nach dem **Satz des Thales**:

<BlockMath math="\angle ACB = 90^\circ" />

## Übungsaufgaben

Bestimme vor dem Rechnen den **überspannten Bogen** oder das Paar gegenüberliegender Winkel. Bei Durchmesseraufgaben muss der dritte Eckpunkt von beiden Durchmesserenden verschieden sein, damit ein Dreieck entsteht.

1. In einem Kreis mit Mittelpunkt <InlineMath math="O" /> gehört zum Mittelpunktswinkel <InlineMath math="\angle AOB = 140^\circ" /> der kleine Bogen <InlineMath math="AB" />. Die Punkte <InlineMath math="C" /> und <InlineMath math="D" /> liegen auf dem großen Bogen <InlineMath math="AB" />. Bestimme die Winkelmaße <InlineMath math="\angle ACB" /> und <InlineMath math="\angle ADB" />.

2. Im Sehnenviereck <InlineMath math="PQRS" /> gilt:

   <MathContainer>
     <BlockMath math="\angle P = 85^\circ" />
     <BlockMath math="\angle Q = 110^\circ" />
   </MathContainer>

   Bestimme <InlineMath math="\angle R" /> und <InlineMath math="\angle S" />.

3. Die Punkte <InlineMath math="A" />, <InlineMath math="B" /> und <InlineMath math="C" /> liegen auf einem Kreis. Dabei ist <InlineMath math="AB" /> ein Durchmesser und es gilt <InlineMath math="BC = AC" />. Bestimme <InlineMath math="\angle BAC" />.

4. Der Umfangswinkel beträgt <InlineMath math="\angle APB = 35^\circ" />. Bestimme den Mittelpunktswinkel <InlineMath math="\angle AOB" /> über demselben Bogen.

5. Im Sehnenviereck <InlineMath math="KLMN" /> beträgt der Außenwinkel bei <InlineMath math="K" /> <InlineMath math="65^\circ" />. Bestimme den Innenwinkel bei <InlineMath math="M" />.
