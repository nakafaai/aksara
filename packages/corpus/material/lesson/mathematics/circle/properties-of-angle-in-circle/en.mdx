## Applications of Angle Properties in Circles

### Determining Angle Measures

In a circle with center <InlineMath math="O" />, the central angle is <InlineMath math="\angle AOB = 100^\circ" />. Find the measure of inscribed angle <InlineMath math="\angle ACB" />!

**Solution:**

Using the property of central and inscribed angles:

<MathContainer>
  <BlockMath math="\angle ACB = \frac{1}{2} \times \angle AOB" />
  <BlockMath math="\angle ACB = \frac{1}{2} \times 100^\circ" />
  <BlockMath math="\angle ACB = 50^\circ" />
</MathContainer>

### Finding Opposite Angles

In cyclic quadrilateral <InlineMath math="ABCD" />, given <InlineMath math="\angle A = 75^\circ" />. Find the measure of <InlineMath math="\angle C" />!

**Solution:**

Using the property of cyclic quadrilaterals:

<MathContainer>
  <BlockMath math="\angle A + \angle C = 180^\circ" />
  <BlockMath math="75^\circ + \angle C = 180^\circ" />
  <BlockMath math="\angle C = 180^\circ - 75^\circ" />
  <BlockMath math="\angle C = 105^\circ" />
</MathContainer>

### Using the Theorem of Thales

Point <InlineMath math="C" /> lies on a circle with <InlineMath math="AB" /> as the diameter. Find the measure of <InlineMath math="\angle ACB" />!

**Solution:**

Since <InlineMath math="AB" /> is a diameter and <InlineMath math="C" /> lies on the circle, by Thales' theorem:

<BlockMath math="\angle ACB = 90^\circ" />

   For angle <InlineMath math="R" /> (opposite to <InlineMath math="P" />):

   <MathContainer>
     <BlockMath math="\angle P + \angle R = 180^\circ" />
     <BlockMath math="85^\circ + \angle R = 180^\circ" />
     <BlockMath math="\angle R = 180^\circ - 85^\circ" />
     <BlockMath math="\angle R = 95^\circ" />
   </MathContainer>

   For angle <InlineMath math="S" /> (opposite to <InlineMath math="Q" />):

   <MathContainer>
     <BlockMath math="\angle Q + \angle S = 180^\circ" />
     <BlockMath math="110^\circ + \angle S = 180^\circ" />
     <BlockMath math="\angle S = 180^\circ - 110^\circ" />
     <BlockMath math="\angle S = 70^\circ" />
   </MathContainer>

3. **Finding angle in an isosceles triangle with diameter**

   <LineEquation

           const angleCA = Math.atan2(A.y - C.y, A.x - C.x);
           const angleCB = Math.atan2(B.y - C.y, B.x - C.x);

           return Array.from({ length: 16 }, (_, i) => {
             const t = i / 15;
             const angle = angleCA + t * (angleCB - angleCA);

   **Solution:**

   Since <InlineMath math="AB" /> is a diameter, by Thales' Theorem:

   <BlockMath math="\angle ACB = 90^\circ" />

   Since <InlineMath math="BC = AC" />, triangle <InlineMath math="ABC" /> is a
   right isosceles triangle.

   In a right isosceles triangle, both base angles are equal:

   <MathContainer>
     <BlockMath math="\angle BAC + \angle ABC + \angle ACB = 180^\circ" />
     <BlockMath math="\angle BAC + \angle ABC + 90^\circ = 180^\circ" />
     <BlockMath math="\angle BAC + \angle ABC = 90^\circ" />
   </MathContainer>

   Since <InlineMath math="\angle BAC = \angle ABC" /> (base angles of isosceles triangle):

   <MathContainer>
     <BlockMath math="2 \times \angle BAC = 90^\circ" />
     <BlockMath math="\angle BAC = 45^\circ" />
   </MathContainer>

   **Solution:**

   Using the relationship between central and inscribed angles:

   <MathContainer>
     <BlockMath math="\text{Central angle} = 2 \times \text{Inscribed angle}" />
     <BlockMath math="\angle AOB = 2 \times \angle APB" />

5. **Finding interior angle from exterior angle in cyclic quadrilateral**

   **Solution:**

   In a cyclic quadrilateral, an exterior angle at a vertex equals the interior angle at the opposite vertex.

   If the exterior angle at <InlineMath math="K" /> is <InlineMath math="65^\circ" />, then:

   <BlockMath math="\angle M = 65^\circ" />

   This is because vertices <InlineMath math="K" /> and <InlineMath math="M" /> are opposite in cyclic quadrilateral <InlineMath math="KLMN" />.
