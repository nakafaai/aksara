## Finding Angle Measures with the Circle Theorems

Each example applies one circle theorem to a labelled situation. Identify the **angles and arc** connected by the theorem before calculating. Write the relation down before substituting numbers, because the relation shows which quantity is the unknown one.

### Determining Angle Measures

In a circle with center <InlineMath math="O" />, the central angle is <InlineMath math="\angle AOB = 100^\circ" />. Find the inscribed angle <InlineMath math="\angle ACB" /> intercepting the same minor arc!

**Solution**:

The inscribed angle intercepts the **same arc**, so it is half the central angle:

<MathContainer>
  <BlockMath math="\angle ACB = \frac{1}{2} \times \angle AOB" />
  <BlockMath math="\angle ACB = \frac{1}{2} \times 100^\circ" />
  <BlockMath math="\angle ACB = 50^\circ" />
</MathContainer>

### Finding Opposite Angles

In cyclic quadrilateral <InlineMath math="ABCD" />, given <InlineMath math="\angle A = 75^\circ" />. Find the measure of <InlineMath math="\angle C" />!

**Solution**:

The **opposite angles** in a cyclic quadrilateral add to a straight angle:

<MathContainer>
  <BlockMath math="\angle A + \angle C = 180^\circ" />
  <BlockMath math="75^\circ + \angle C = 180^\circ" />
  <BlockMath math="\angle C = 180^\circ - 75^\circ" />
  <BlockMath math="\angle C = 105^\circ" />
</MathContainer>

### Using the Theorem of Thales

Point <InlineMath math="C" /> lies on a circle with <InlineMath math="AB" /> as the diameter. Find the measure of <InlineMath math="\angle ACB" />!

**Solution**:

Since <InlineMath math="AB" /> is a diameter and <InlineMath math="C" /> lies on the circle, by **Thales' theorem**:

<BlockMath math="\angle ACB = 90^\circ" />
