## Using Known Points or Roots to Determine a Quadratic

Constructing a quadratic function means determining <InlineMath math="f(x) = ax^2 + bx + c" /> from the given information. Known points lead to <Highlight>a system for the coefficients</Highlight>, known roots lead to <Highlight>factored form</Highlight>, and a known vertex leads to vertex form.

## Forms of Quadratic Functions

1. **Standard Form**: <InlineMath math="f(x) = ax^2 + bx + c" />
2. **Factored Form**: <InlineMath math="f(x) = a(x - p)(x - q)" /> when the real roots <InlineMath math="p" /> and <InlineMath math="q" /> exist
3. **Vertex Form**: <InlineMath math="f(x) = a(x - h)^2 + k" /> where <InlineMath math="(h, k)" /> is the vertex point

These three forms are interrelated and can be converted from one form to another.

<BlockMath math="x^2-2x-3=(x-3)(x+1)=(x-1)^2-4" />

## Methods of Constructing Quadratic Functions

Choose the form that uses the <Highlight>known information directly</Highlight>. Three points give equations for the coefficients. A vertex needs another point away from the symmetry axis, while two roots still need an additional point to determine the leading multiplier.

### Three Points

Three points with **distinct** <InlineMath math="x" />-coordinates determine exactly one polynomial of degree at most <InlineMath math="2" />. It is a quadratic function only when the resulting coefficient satisfies <InlineMath math="a\neq0" />.

If we have three points <InlineMath math="(x_1, y_1)" />, <InlineMath math="(x_2, y_2)" />, and <InlineMath math="(x_3, y_3)" />, we can substitute these values into the standard equation to get three linear equations with three variables <InlineMath math="a" />, <InlineMath math="b" />, and <InlineMath math="c" />.

<MathContainer>
  <BlockMath math="y_1 = ax_1^2 + bx_1 + c" />
  <BlockMath math="y_2 = ax_2^2 + bx_2 + c" />
  <BlockMath math="y_3 = ax_3^2 + bx_3 + c" />
</MathContainer>

**Example**:

Find the quadratic function that passes through points <InlineMath math="K(-1, 0)" />, <InlineMath math="L(0, -3)" />, and <InlineMath math="M(1, -4)" />.

Substitute the coordinate values into the standard equation.

<MathContainer>
  <BlockMath math="K(-1, 0): 0 = a(-1)^2 + b(-1) + c" />
  <BlockMath math="L(0, -3): -3 = a(0)^2 + b(0) + c" />
  <BlockMath math="M(1, -4): -4 = a(1)^2 + b(1) + c" />
</MathContainer>

Simplify these equations.

<MathContainer>
  <BlockMath math="0 = a - b + c" />
  <BlockMath math="-3 = c" />
  <BlockMath math="-4 = a + b + c" />
</MathContainer>

Substitute <InlineMath math="c = -3" /> into the first and third equations.

<MathContainer>
  <BlockMath math="0 = a - b - 3" />
  <BlockMath math="-4 = a + b - 3" />
</MathContainer>

Simplify and add the two equations to find the value of <InlineMath math="a" />.

<MathContainer>
  <BlockMath math="a - b = 3" />
  <BlockMath math="a + b = -1" />
  <BlockMath math="2a = 2" />
  <BlockMath math="a = 1" />
</MathContainer>

Substitute the value of <InlineMath math="a" /> into the equation <InlineMath math="a - b = 3" /> to find the value of <InlineMath math="b" />.

<MathContainer>
  <BlockMath math="1 - b = 3" />
  <BlockMath math="b = -2" />
</MathContainer>

The resulting quadratic function is:

<BlockMath math="f(x) = x^2 - 2x - 3" />

### Vertex Point

If we know the coordinates of the vertex <InlineMath math="(h, k)" /> and another point <InlineMath math="(p, q)" /> on the graph, we can use the vertex form <InlineMath math="f(x) = a(x - h)^2 + k" /> to find the value of <InlineMath math="a" />.

The additional point must satisfy <InlineMath math="p\ne h" /> so the <Highlight>leading multiplier can be determined</Highlight>. If <InlineMath math="q=k" />, the result is <InlineMath math="a=0" /> and the function is not quadratic:

<BlockMath math="q=a(p-h)^2+k\quad\Rightarrow\quad a=\frac{q-k}{(p-h)^2}" />

**Example**:

Find the quadratic function that has a vertex at <InlineMath math="(2, 0)" /> and passes through the point <InlineMath math="(4, 4)" />.

Use the vertex form <InlineMath math="f(x) = a(x - h)^2 + k" /> with <InlineMath math="h = 2" /> and <InlineMath math="k = 0" />.

<BlockMath math="f(x) = a(x - 2)^2 + 0 = a(x - 2)^2" />

Substitute the point <InlineMath math="(4, 4)" /> to find the value of <InlineMath math="a" />.

<MathContainer>
  <BlockMath math="4 = a(4 - 2)^2" />
  <BlockMath math="4 = 4a" />
  <BlockMath math="a = 1" />
</MathContainer>

The resulting quadratic function is:

<BlockMath math="f(x) = (x - 2)^2 = x^2 - 4x + 4" />

### Roots and One Additional Point

If we know the roots (<InlineMath math="x" />-intercepts) <InlineMath math="p" /> and <InlineMath math="q" /> of the quadratic function, and an additional point <InlineMath math="(r, s)" /> on the curve with <InlineMath math="r\neq p" />, <InlineMath math="r\neq q" />, and <InlineMath math="s\neq0" />, we can use the **factored form** <InlineMath math="f(x) = a(x - p)(x - q)" /> to determine <InlineMath math="a" />.

**Example**:

Find the quadratic function that has roots at <InlineMath math="x = -2" /> and <InlineMath math="x = 3" />, and passes through the point <InlineMath math="(1, -6)" />.

Use the factored form <InlineMath math="f(x) = a(x - p)(x - q)" /> with <InlineMath math="p = -2" /> and <InlineMath math="q = 3" />.

<BlockMath math="\begin{aligned} f(x) &amp;= a(x - (-2))(x - 3) \\ &amp;= a(x + 2)(x - 3) \end{aligned}" />

Substitute the point <InlineMath math="(1, -6)" /> to find the value of <InlineMath math="a" />.

<MathContainer>
  <BlockMath math="-6 = a(1 + 2)(1 - 3)" />
  <BlockMath math="-6 = a(3)(-2)" />
  <BlockMath math="-6 = -6a" />
  <BlockMath math="a = 1" />
</MathContainer>

The resulting quadratic function is:

<BlockMath math="\begin{aligned} f(x) &amp;= (x + 2)(x - 3) \\ &amp;= x^2 - x - 6 \end{aligned}" />

### Choosing a Function from Two Conditions

The axis of symmetry and the discriminant usually allow several quadratic functions. Another piece of information is needed to select one unique function.

**Example**:

Find a quadratic function with axis of symmetry <InlineMath math="x = 1" /> and discriminant <InlineMath math="D = 16" />.

From the axis of symmetry <InlineMath math="x = 1" />, we know that <InlineMath math="-\frac{b}{2a} = 1" />, so <InlineMath math="b = -2a" />.

From the discriminant <InlineMath math="D = 16" />, we know that <InlineMath math="b^2 - 4ac = 16" />.

Substitute <InlineMath math="b = -2a" /> into the discriminant equation.

<MathContainer>
  <BlockMath math="(-2a)^2 - 4ac = 16" />
  <BlockMath math="4a^2 - 4ac = 16" />
  <BlockMath math="4a(a - c) = 16" />
  <BlockMath math="a(a - c) = 4" />
</MathContainer>

There are many values of <InlineMath math="a" /> and <InlineMath math="c" /> that satisfy this equation, so the data do not determine a unique function. To obtain one example, choose <InlineMath math="a = 1" />.

<MathContainer>
  <BlockMath math="1(1 - c) = 4" />
  <BlockMath math="1 - c = 4" />
  <BlockMath math="c = -3" />
</MathContainer>

With <InlineMath math="a = 1" />, <InlineMath math="b = -2" />, and <InlineMath math="c = -3" />, the resulting quadratic function is:

<BlockMath math="f(x) = x^2 - 2x - 3" />

Another leading coefficient gives a <Highlight>different function with the same conditions</Highlight>:

<BlockMath math="a=2,\quad b=-4,\quad c=0\quad\Rightarrow\quad f(x)=2x^2-4x,\quad -\frac b{2a}=1,\quad D=16" />

### Symmetric Coordinates

Symmetric points can also determine a quadratic function.

Equal outputs at opposite inputs force the <Highlight>linear coefficient to be zero</Highlight>. Substituting the two points proves this:

<BlockMath math="f(4)-f(-4)=(16a+4b+c)-(16a-4b+c)=8b=1-1=0" />

**Example**:

Determine the quadratic function that passes through the points <InlineMath math="(0, 0)" />, <InlineMath math="(4, 1)" />, and <InlineMath math="(-4, 1)" />.

Since the points <InlineMath math="(4, 1)" /> and <InlineMath math="(-4, 1)" /> have the same <InlineMath math="y" />-value and are at the same distance from the <InlineMath math="y" />-axis, the curve is symmetric about the <InlineMath math="y" />-axis. This means the axis of symmetry is <InlineMath math="x = 0" />, and the vertex is at <InlineMath math="(0, 0)" />.

Use the vertex form <InlineMath math="f(x) = a(x - h)^2 + k" /> with <InlineMath math="h = 0" /> and <InlineMath math="k = 0" />.

<BlockMath math="f(x) = ax^2" />

Substitute the point <InlineMath math="(4, 1)" /> to find the value of <InlineMath math="a" />.

<MathContainer>
  <BlockMath math="1 = a(4)^2" />
  <BlockMath math="1 = 16a" />
  <BlockMath math="a = \frac{1}{16}" />
</MathContainer>

The resulting quadratic function is:

<BlockMath math="f(x) = \frac{1}{16}x^2" />

## Transformations Between Quadratic Function Forms

Changing form uses <Highlight>algebraic identities</Highlight>, so every input keeps the same function value. Vertex form is always available, while a product of real linear factors requires real roots.

### Standard Form to Vertex Form

Factor out the leading coefficient, then <Highlight>add and subtract the same square</Highlight> inside the brackets. The function value is unchanged:

<MathContainer>
<BlockMath math="\begin{aligned} f(x)&amp;=a\left(x^2+\frac ba x\right)+c\\&amp;=a\left[\left(x+\frac b{2a}\right)^2-\frac{b^2}{4a^2}\right]+c\\&amp;=a\left(x+\frac b{2a}\right)^2+c-\frac{b^2}{4a}\end{aligned}" />

<BlockMath math="h=-\frac b{2a},\qquad k=c-\frac{b^2}{4a}" />
</MathContainer>

### Standard Form to Factored Form

To convert <InlineMath math="f(x) = ax^2 + bx + c" /> to factored form over the real numbers, first verify that the **discriminant is nonnegative**:

1. Determine the roots of the equation <InlineMath math="ax^2 + bx + c = 0" /> using the formula:

   <BlockMath math="x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}" />

2. If <InlineMath math="D\ge0" /> and the real roots are <InlineMath math="p" /> and <InlineMath math="q" />, then:

   <BlockMath math="f(x) = a(x - p)(x - q)" />

If <InlineMath math="D<0" />, the function has no real roots and cannot be written as a product of real linear factors.

### Factored Form to Standard Form

To convert <InlineMath math="f(x) = a(x - p)(x - q)" /> to standard form <InlineMath math="f(x) = ax^2 + bx + c" />:

<MathContainer>
  <BlockMath math="f(x) = a(x - p)(x - q)" />
  <BlockMath math="f(x) = a(x^2 - qx - px + pq)" />
  <BlockMath math="f(x) = a(x^2 - (p+q)x + pq)" />
  <BlockMath math="f(x) = ax^2 - a(p+q)x + apq" />
</MathContainer>

By **comparing coefficients** with the standard form, we get:

- <InlineMath math="b = -a(p+q)" />
- <InlineMath math="c = apq" />

## Exercises and Solutions

Choose the <Highlight>form that matches the conditions</Highlight>, then determine the missing coefficients. Finally substitute every given point back into the function. This checks that all conditions hold together, rather than only some of them.

### First Exercise

Find the quadratic function that passes through the points <InlineMath math="(-2, 4)" />, <InlineMath math="(1, -5)" />, and <InlineMath math="(3, 7)" />.

**Answer**:

Substitute the points into the standard equation:

<MathContainer>
  <BlockMath math="\begin{aligned} 4 &amp;= a(-2)^2 + b(-2) + c \\ &amp;= 4a - 2b + c \end{aligned}" />
  <BlockMath math="-5 = a(1)^2 + b(1) + c = a + b + c" />
  <BlockMath math="7 = a(3)^2 + b(3) + c = 9a + 3b + c" />
</MathContainer>

From the second equation, <InlineMath math="c = -5 - a - b" />.
Substitute into the first equation, then solve:

<MathContainer>
  <BlockMath math="4 = 4a - 2b + (-5 - a - b)" />
  <BlockMath math="9 = 3a - 3b" />
  <BlockMath math="3 = a - b" />
  <BlockMath math="a = 3 + b" />
</MathContainer>

Substitute into the third equation:

<MathContainer>
  <BlockMath math="\begin{aligned} 7 &amp;= 9(3 + b) + 3b \\ &amp;\quad{}+ (-5 - (3 + b) - b) \end{aligned}" />
  <BlockMath math="7 = 19 + 10b" />
  <BlockMath math="b = -\frac{12}{10} = -\frac{6}{5}" />
</MathContainer>

Then:

<MathContainer>
  <BlockMath math="a = 3 + (-\frac{6}{5}) = \frac{9}{5}" />
  <BlockMath math="c = -5 - \frac{9}{5} - (-\frac{6}{5}) = -\frac{28}{5}" />
</MathContainer>

The quadratic function is:

<BlockMath math="f(x) = \frac{9}{5}x^2 - \frac{6}{5}x - \frac{28}{5}" />

Check **all three points** in the resulting function:

<BlockMath math="\begin{aligned}f(-2)&amp;=\frac{36+12-28}{5}=4\\f(1)&amp;=\frac{9-6-28}{5}=-5\\f(3)&amp;=\frac{81-18-28}{5}=7\end{aligned}" />

### Second Exercise

Determine the quadratic function that has a vertex at <InlineMath math="(-1, 4)" /> and passes through the point <InlineMath math="(2, -5)" />.

**Answer**:

Use the **vertex form** with <InlineMath math="h = -1" /> and <InlineMath math="k = 4" />:

<BlockMath math="\begin{aligned} f(x) &amp;= a(x - (-1))^2 + 4 \\ &amp;= a(x + 1)^2 + 4 \end{aligned}" />

Substitute the point <InlineMath math="(2, -5)" />:

<MathContainer>
  <BlockMath math="-5 = a(2 + 1)^2 + 4" />
  <BlockMath math="-5 = 9a + 4" />
  <BlockMath math="-9 = 9a" />
  <BlockMath math="a = -1" />
</MathContainer>

The quadratic function is:

<BlockMath math="\begin{aligned} f(x) &amp;= -(x + 1)^2 + 4 \\ &amp;= -x^2 - 2x + 3 \end{aligned}" />

### Third Exercise

Determine the quadratic function that has roots at <InlineMath math="x = -3" /> and <InlineMath math="x = 2" />, and has a maximum value of <InlineMath math="4" />.

**Answer**:

Use the factored form with <InlineMath math="p = -3" /> and <InlineMath math="q = 2" />:

<BlockMath math="\begin{aligned} f(x) &amp;= a(x - (-3))(x - 2) \\ &amp;= a(x + 3)(x - 2) \end{aligned}" />

Since the function has a **maximum value**, <InlineMath math="a < 0" />.

The vertex is at <InlineMath math="x = \frac{p + q}{2} = \frac{-3 + 2}{2} = -\frac{1}{2}" />.

Substitute <InlineMath math="x = -\frac{1}{2}" /> into the factored form and use the fact that the maximum value is <InlineMath math="4" />:

<MathContainer>
  <BlockMath math="\begin{aligned} f(-\frac{1}{2}) &amp;= a(-\frac{1}{2} + 3)(-\frac{1}{2} - 2) \\ &amp;= -a\frac{25}{4} \\ &amp;= 4 \end{aligned}" />
  <BlockMath math="a = -\frac{16}{25}" />
</MathContainer>

The quadratic function is:

<BlockMath math="\begin{aligned} f(x) &amp;= -\frac{16}{25}(x + 3)(x - 2) \\ &amp;= -\frac{16}{25}x^2 - \frac{16}{25}x + \frac{96}{25} \end{aligned}" />
