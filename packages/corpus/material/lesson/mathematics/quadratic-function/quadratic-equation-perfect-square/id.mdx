## Mengubah Persamaan ke Bentuk Kuadrat Sempurna

Melengkapi kuadrat sempurna menyelesaikan persamaan kuadrat dengan mengubah bentuk <InlineMath math="ax^2 + bx + c = 0" /> menjadi <InlineMath math="(x + p)^2 = q" />. Metode ini tetap dapat digunakan ketika persamaan sulit difaktorkan dengan bilangan bulat.

Bentuk kuadrat sempurna mengikuti pola <InlineMath math="x^2 + 2px + p^2 = (x + p)^2" />. <Highlight>Setelah ruas kiri menjadi kuadrat</Highlight>, akar persamaan dapat ditentukan dengan menarik akar kedua ruas. Jika suku tengahnya <InlineMath math="2px" />, tambahkan suku <InlineMath math="p^2" /> untuk melengkapi kuadrat.

## Persamaan yang Sulit Difaktorkan

Pasangan rasional tidak diperlukan karena kita dapat <Highlight>menambahkan nilai yang sama ke kedua ruas</Highlight>:

<BlockMath math="\begin{aligned}x^2+4x+2&amp;=0\\x^2+4x+4&amp;=2\\(x+2)^2&amp;=2\\x&amp;=-2\pm\sqrt2\end{aligned}" />

Nilai <InlineMath math="\sqrt2" /> irasional, sehingga kedua akar juga irasional. Itulah sebabnya pasangan faktor rasional tidak ada.

## Langkah Melengkapi Kuadrat Sempurna

Mulailah dengan <InlineMath math="a\ne0" />. Setelah seluruh persamaan dibagi dengan <InlineMath math="a" />, tulis <InlineMath math="m=b/a" /> dan <InlineMath math="k=c/a" />. Suku pelengkap memakai <Highlight>koefisien setelah pembagian</Highlight>, yaitu <InlineMath math="m" />, bukan koefisien awal <InlineMath math="b" />.

<BlockMath math="\begin{aligned}x^2+mx+k&amp;=0\\x^2+mx&amp;=-k\\x^2+mx+\frac{m^2}{4}&amp;=-k+\frac{m^2}{4}\\\left(x+\frac m2\right)^2&amp;=\frac{m^2}{4}-k\end{aligned}" />

Dua persegi panjang masing-masing memiliki luas <InlineMath math="px" />. Ketika keduanya diletakkan di sisi persegi berluas <InlineMath math="x^2" />, tersisa sudut seluas <InlineMath math="p^2" />. Menambah sudut itu melengkapi persegi bersisi <InlineMath math="x+p" />.

## Menyelesaikan Persamaan Kuadrat dengan Melengkapkan Kuadrat

Setiap persamaan di bawah diselesaikan dengan mengubah ruas kiri menjadi **kuadrat sempurna**. Persamaan pertama berkoefisien utama satu, dan contoh berikutnya membagi dengan koefisien lebih dulu.

### Persamaan dengan Koefisien Utama Satu

Selesaikan persamaan: <InlineMath math="x^2 + 5x + 6 = 0" />

**Langkah 1**: Koefisien <InlineMath math="a = 1" />, jadi kita langsung ke langkah berikutnya.

**Langkah 2**: Pindahkan konstanta ke ruas kanan.

<BlockMath math="x^2 + 5x = -6" />

**Langkah 3**: Tambahkan **kuadrat dari setengah koefisien** <InlineMath math="x" /> ke **kedua ruas**.

<MathContainer>
  <BlockMath math="\text{Setengah koefisien } x = \frac{5}{2}" />
  <BlockMath math="\left(\frac{5}{2}\right)^2 = \frac{25}{4}" />
  <BlockMath math="x^2 + 5x + \frac{25}{4} = -6 + \frac{25}{4}" />
</MathContainer>

**Langkah 4**: Faktorkan ruas kiri menjadi bentuk kuadrat sempurna.

<BlockMath math="\left(x + \frac{5}{2}\right)^2 = -6 + \frac{25}{4}" />

**Langkah 5**: Sederhanakan ruas kanan.

<MathContainer>
  <BlockMath math="-6 + \frac{25}{4} = \frac{-24 + 25}{4} = \frac{1}{4}" />
  <BlockMath math="\left(x + \frac{5}{2}\right)^2 = \frac{1}{4}" />
</MathContainer>

**Langkah 6**: Ambil akar kuadrat dari **kedua ruas**.

<BlockMath math="x + \frac{5}{2} = \pm\frac{1}{2}" />

**Langkah 7**: Selesaikan untuk mendapatkan nilai <InlineMath math="x" />.

<MathContainer>
  <BlockMath math="x + \frac{5}{2} = \frac{1}{2} \quad \text{atau} \quad x + \frac{5}{2} = -\frac{1}{2}" />
  <BlockMath math="\begin{aligned} &amp;x = \frac{1}{2} - \frac{5}{2} = -2 \\ &amp;\text{atau} \\ &amp;x = -\frac{1}{2} - \frac{5}{2} = -3 \end{aligned}" />
</MathContainer>

Jadi, akar-akar persamaan adalah <InlineMath math="x = -2" /> dan <InlineMath math="x = -3" />.

### Persamaan dengan Koefisien Utama Bukan Satu

Selesaikan persamaan: <InlineMath math="2x^2 + 6x + 3 = 0" />

**Langkah 1**: Bagi semua suku dengan koefisien <InlineMath math="a = 2" />

<BlockMath math="x^2 + 3x + \frac{3}{2} = 0" />

**Langkah 2**: Pindahkan konstanta ke ruas kanan

<BlockMath math="x^2 + 3x = -\frac{3}{2}" />

**Langkah 3**: Tambahkan **kuadrat dari setengah koefisien** <InlineMath math="x" /> ke **kedua ruas**

<MathContainer>
  <BlockMath math="\text{Setengah koefisien } x = \frac{3}{2}" />
  <BlockMath math="\left(\frac{3}{2}\right)^2 = \frac{9}{4}" />
  <BlockMath math="x^2 + 3x + \frac{9}{4} = -\frac{3}{2} + \frac{9}{4}" />
</MathContainer>

**Langkah 4**: Faktorkan ruas kiri menjadi bentuk kuadrat sempurna

<BlockMath math="\left(x + \frac{3}{2}\right)^2 = -\frac{3}{2} + \frac{9}{4}" />

**Langkah 5**: Sederhanakan ruas kanan

<MathContainer>
  <BlockMath math="-\frac{3}{2} + \frac{9}{4} = \frac{-6 + 9}{4} = \frac{3}{4}" />
  <BlockMath math="\left(x + \frac{3}{2}\right)^2 = \frac{3}{4}" />
</MathContainer>

**Langkah 6**: Ambil akar kuadrat dari **kedua ruas**

<BlockMath math="x + \frac{3}{2} = \pm\frac{\sqrt{3}}{2}" />

**Langkah 7**: Selesaikan untuk mendapatkan nilai <InlineMath math="x" />

<MathContainer>
  <BlockMath math="\begin{aligned} &amp;x + \frac{3}{2} = \frac{\sqrt{3}}{2} \\ &amp;\text{atau} \\ &amp;x + \frac{3}{2} = -\frac{\sqrt{3}}{2} \end{aligned}" />
  <BlockMath math="\begin{aligned} &amp;x = \frac{\sqrt{3}}{2} - \frac{3}{2} \\ &amp;= -\frac{3}{2} + \frac{\sqrt{3}}{2} \\ &amp;\text{atau} \\ x &amp;= -\frac{\sqrt{3}}{2} - \frac{3}{2} \\ &amp;= -\frac{3}{2} - \frac{\sqrt{3}}{2} \end{aligned}" />
</MathContainer>

Jadi, akar-akar persamaan adalah <InlineMath math="x = -\frac{3}{2} + \frac{\sqrt{3}}{2}" /> dan <InlineMath math="x = -\frac{3}{2} - \frac{\sqrt{3}}{2}" />.

## Pemeriksaan Kesalahan Umum

Periksa <Highlight>normalisasi koefisien, penambahan pada kedua ruas, dan bentuk akhir</Highlight> melalui tiga contoh berikut.

1. Untuk persamaan dengan koefisien <InlineMath math="x^2" /> bukan <InlineMath math="1" />: Selalu bagi seluruh persamaan dengan koefisien <InlineMath math="a" /> terlebih dahulu. Contoh: <InlineMath math="3x^2 + 6x + 2 = 0" /> menjadi <InlineMath math="x^2 + 2x + \frac{2}{3} = 0" />

2. **Konstanta yang ditambahkan**: Selalu tambahkan kuadrat dari setengah koefisien <InlineMath math="x" /> ke kedua ruas. Contoh: Untuk <InlineMath math="x^2 + 8x = 5" />, tambahkan <InlineMath math="\left(\frac{8}{2}\right)^2 = 16" /> ke kedua ruas.

3. **Bentuk akhir**: Persamaan akan berubah menjadi bentuk <InlineMath math="\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}" />. Contoh: <InlineMath math="x^2 + 6x + 8 = 0" /> menjadi <InlineMath math="\left(x + 3\right)^2 = 1" />

## Kasus Khusus dan Variasi

Kuadrat bilangan real selalu tidak negatif. Gunakan fakta itu untuk membaca ruas kanan sebelum menarik akar.

Setelah persamaan menjadi <InlineMath math="(x+p)^2=q" />, <Highlight>tanda ruas kanan</Highlight> menentukan solusi real. Nilai <InlineMath math="q>0" /> memberi dua akar, <InlineMath math="q=0" /> satu akar kembar, dan <InlineMath math="q<0" /> tidak memberi akar real.

### Ketika Diskriminan Negatif

Jika <InlineMath math="b^2 - 4ac < 0" />, maka persamaan **tidak memiliki akar real**.

**Contoh konkret**: <InlineMath math="x^2 + 2x + 2 = 0" />

Dengan melengkapi kuadrat sempurna:

Tambahkan <InlineMath math="1" /> pada kedua ruas:

<MathContainer>
  <BlockMath math="x^2 + 2x + 1 = -2 + 1" />
  <BlockMath math="(x + 1)^2 = -1" />
</MathContainer>

Karena tidak ada bilangan real yang kuadratnya <InlineMath math="-1" />, maka persamaan ini tidak memiliki akar real.

Dalam bilangan kompleks, gunakan <InlineMath math="i^2=-1" /> untuk memperoleh:

<BlockMath math="(x+1)^2=-1\quad\Rightarrow\quad x+1=\pm i\quad\Rightarrow\quad x=-1\pm i" />

### Pada Persamaan Kuadrat Tidak Lengkap

Untuk persamaan bentuk <InlineMath math="ax^2 + c = 0" />, kita dapat **langsung mengisolasi kuadrat**.

**Contoh konkret**: <InlineMath math="3x^2 - 12 = 0" />

<MathContainer>
  <BlockMath math="3x^2 = 12" />
  <BlockMath math="x^2 = 4" />
  <BlockMath math="x = \pm 2" />
</MathContainer>

Jadi, akar-akar persamaan adalah <InlineMath math="x = 2" /> dan <InlineMath math="x = -2" />.

## Latihan Soal

Pada setiap langkah, lakukan <Highlight>operasi yang sama pada kedua ruas</Highlight>. Setelah koefisien utama menjadi satu, hitung kuadrat dari setengah koefisien linear yang baru, lalu ambil kedua tanda akar.

Selesaikan persamaan-persamaan kuadrat berikut dengan metode melengkapi kuadrat sempurna:

1. <InlineMath math="x^2 + 5x + 6 = 0" />
2. <InlineMath math="2x^2 + 6x + 3 = 0" />
3. <InlineMath math="6x^2 + 2x + \frac{1}{6} = 0" />
4. <InlineMath math="x^2 - 12x - 15 = 0" />
5. <InlineMath math="\frac{3}{2}x^2 - 8x - 6 = 0" />

### Kunci Jawaban

**Soal 1**

<InlineMath math="x^2 + 5x + 6 = 0" />

**Langkah 1**: Pindahkan konstanta ke ruas kanan:

<BlockMath math="x^2 + 5x = -6" />

**Langkah 2**: Tambahkan **kuadrat dari setengah koefisien** <InlineMath math="x" /> ke kedua ruas:

<MathContainer>
  <BlockMath math="\text{Setengah koefisien } x = \frac{5}{2}" />
  <BlockMath math="\left(\frac{5}{2}\right)^2 = \frac{25}{4}" />
  <BlockMath math="x^2 + 5x + \frac{25}{4} = -6 + \frac{25}{4}" />
</MathContainer>

**Langkah 3**: Faktorkan ruas kiri menjadi **bentuk kuadrat sempurna**:

<BlockMath math="\left(x + \frac{5}{2}\right)^2 = -6 + \frac{25}{4}" />

**Langkah 4**: Sederhanakan ruas kanan:

<MathContainer>
  <BlockMath math="-6 + \frac{25}{4} = \frac{-24 + 25}{4} = \frac{1}{4}" />
  <BlockMath math="\left(x + \frac{5}{2}\right)^2 = \frac{1}{4}" />
</MathContainer>

**Langkah 5**: Ambil akar kuadrat dari kedua ruas:

<BlockMath math="x + \frac{5}{2} = \pm\frac{1}{2}" />

**Langkah 6**: Selesaikan untuk mendapatkan nilai <InlineMath math="x" />:

<MathContainer>
  <BlockMath math="x + \frac{5}{2} = \frac{1}{2} \quad \text{atau} \quad x + \frac{5}{2} = -\frac{1}{2}" />
  <BlockMath math="\begin{aligned} &amp;x = \frac{1}{2} - \frac{5}{2} = -2 \\ &amp;\text{atau} \\ &amp;x = -\frac{1}{2} - \frac{5}{2} = -3 \end{aligned}" />
</MathContainer>

Jadi, akar-akar persamaan adalah <InlineMath math="x = -2" /> dan <InlineMath math="x = -3" />.

**Soal 2**

<InlineMath math="2x^2 + 6x + 3 = 0" />

**Langkah 1**: Bagi semua suku dengan koefisien <InlineMath math="a = 2" />:

<BlockMath math="x^2 + 3x + \frac{3}{2} = 0" />

**Langkah 2**: Pindahkan konstanta ke ruas kanan:

<BlockMath math="x^2 + 3x = -\frac{3}{2}" />

**Langkah 3**: Tambahkan **kuadrat dari setengah koefisien** <InlineMath math="x" /> ke kedua ruas:

<MathContainer>
  <BlockMath math="\text{Setengah koefisien } x = \frac{3}{2}" />
  <BlockMath math="\left(\frac{3}{2}\right)^2 = \frac{9}{4}" />
  <BlockMath math="x^2 + 3x + \frac{9}{4} = -\frac{3}{2} + \frac{9}{4}" />
</MathContainer>

**Langkah 4**: Faktorkan ruas kiri menjadi **bentuk kuadrat sempurna**:

<BlockMath math="\left(x + \frac{3}{2}\right)^2 = -\frac{3}{2} + \frac{9}{4}" />

**Langkah 5**: Sederhanakan ruas kanan:

<MathContainer>
  <BlockMath math="-\frac{3}{2} + \frac{9}{4} = \frac{-6 + 9}{4} = \frac{3}{4}" />
  <BlockMath math="\left(x + \frac{3}{2}\right)^2 = \frac{3}{4}" />
</MathContainer>

**Langkah 6**: Ambil akar kuadrat dari kedua ruas:

<BlockMath math="x + \frac{3}{2} = \pm\frac{\sqrt{3}}{2}" />

**Langkah 7**: Selesaikan untuk mendapatkan nilai <InlineMath math="x" />:

<MathContainer>
  <BlockMath math="\begin{aligned} &amp;x = -\frac{3}{2} + \frac{\sqrt{3}}{2} \\ &amp;\text{atau} \\ &amp;x = -\frac{3}{2} - \frac{\sqrt{3}}{2} \end{aligned}" />
</MathContainer>

Jadi, akar-akar persamaan adalah <InlineMath math="x = -\frac{3}{2} + \frac{\sqrt{3}}{2}" /> dan <InlineMath math="x = -\frac{3}{2} - \frac{\sqrt{3}}{2}" />.

**Soal 3**

<InlineMath math="6x^2 + 2x + \frac{1}{6} = 0" />

**Langkah 1**: Bagi semua suku dengan koefisien <InlineMath math="a = 6" />:

<BlockMath math="x^2 + \frac{1}{3}x + \frac{1}{36} = 0" />

**Langkah 2**: Pindahkan konstanta ke ruas kanan:

<BlockMath math="x^2 + \frac{1}{3}x = -\frac{1}{36}" />

**Langkah 3**: Tambahkan **kuadrat dari setengah koefisien** <InlineMath math="x" /> ke kedua ruas:

<MathContainer>
  <BlockMath math="\text{Setengah koefisien } x = \frac{1}{6}" />
  <BlockMath math="\left(\frac{1}{6}\right)^2 = \frac{1}{36}" />
  <BlockMath math="x^2 + \frac{1}{3}x + \frac{1}{36} = -\frac{1}{36} + \frac{1}{36}" />
</MathContainer>

**Langkah 4**: Faktorkan ruas kiri menjadi **bentuk kuadrat sempurna**:

<BlockMath math="\left(x + \frac{1}{6}\right)^2 = -\frac{1}{36} + \frac{1}{36}" />

**Langkah 5**: Sederhanakan ruas kanan:

<BlockMath math="\left(x + \frac{1}{6}\right)^2 = 0" />

**Langkah 6**: Ambil akar kuadrat dari kedua ruas:

<BlockMath math="x + \frac{1}{6} = 0" />

**Langkah 7**: Selesaikan untuk mendapatkan nilai <InlineMath math="x" />:

<BlockMath math="x = -\frac{1}{6}" />

Jadi, persamaan ini memiliki satu akar (akar ganda), yaitu <InlineMath math="x = -\frac{1}{6}" />.

**Soal 4**

<InlineMath math="x^2 - 12x - 15 = 0" />

**Langkah 1**: Pindahkan konstanta ke ruas kanan:

<BlockMath math="x^2 - 12x = 15" />

**Langkah 2**: Tambahkan **kuadrat dari setengah koefisien** <InlineMath math="x" /> ke kedua ruas:

Setengah koefisien <InlineMath math="x" /> adalah <InlineMath math="-6" />.

<MathContainer>
  <BlockMath math="(-6)^2 = 36" />
  <BlockMath math="x^2 - 12x + 36 = 15 + 36" />
</MathContainer>

**Langkah 3**: Faktorkan ruas kiri menjadi **bentuk kuadrat sempurna**:

<BlockMath math="(x - 6)^2 = 51" />

**Langkah 4**: Ambil akar kuadrat dari kedua ruas:

<BlockMath math="x - 6 = \pm\sqrt{51}" />

**Langkah 5**: Selesaikan untuk mendapatkan nilai <InlineMath math="x" />:

<BlockMath math="x = 6 \pm \sqrt{51}" />

Jadi, akar-akar persamaan adalah <InlineMath math="x = 6 + \sqrt{51}" /> dan <InlineMath math="x = 6 - \sqrt{51}" />.

**Soal 5**

<InlineMath math="\frac{3}{2}x^2 - 8x - 6 = 0" />

**Langkah 1**: Bagi semua suku dengan koefisien <InlineMath math="a = \frac{3}{2}" />:

<MathContainer>
  <BlockMath math="x^2 - \frac{16}{3}x - 4 = 0" />
</MathContainer>

**Langkah 2**: Pindahkan konstanta ke ruas kanan:

<BlockMath math="x^2 - \frac{16}{3}x = 4" />

**Langkah 3**: Tambahkan **kuadrat dari setengah koefisien** <InlineMath math="x" /> ke kedua ruas:

Setengah koefisien <InlineMath math="x" /> adalah <InlineMath math="-\frac83" />.

<MathContainer>
  <BlockMath math="\left(-\frac{8}{3}\right)^2 = \frac{64}{9}" />
  <BlockMath math="x^2 - \frac{16}{3}x + \frac{64}{9} = 4 + \frac{64}{9}" />
</MathContainer>

**Langkah 4**: Faktorkan ruas kiri menjadi **bentuk kuadrat sempurna**:

<BlockMath math="\left(x - \frac{8}{3}\right)^2 = 4 + \frac{64}{9}" />

**Langkah 5**: Sederhanakan ruas kanan:

<MathContainer>
  <BlockMath math="4 + \frac{64}{9} = \frac{36 + 64}{9} = \frac{100}{9}" />
  <BlockMath math="\left(x - \frac{8}{3}\right)^2 = \frac{100}{9}" />
</MathContainer>

**Langkah 6**: Ambil akar kuadrat dari kedua ruas:

<BlockMath math="x - \frac{8}{3} = \pm\frac{10}{3}" />

**Langkah 7**: Selesaikan untuk mendapatkan nilai <InlineMath math="x" />:

<MathContainer>
  <BlockMath math="\begin{aligned} &amp;x = \frac{8}{3} + \frac{10}{3} = \frac{18}{3} = 6 \\ &amp;\text{atau} \\ &amp;x = \frac{8}{3} - \frac{10}{3} = -\frac{2}{3} \end{aligned}" />
</MathContainer>

Jadi, akar-akar persamaan adalah <InlineMath math="x = 6" /> dan <InlineMath math="x = -\frac{2}{3}" />.
