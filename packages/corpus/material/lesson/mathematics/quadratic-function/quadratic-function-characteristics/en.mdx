## Shape of Quadratic Function Graphs

The graph of a quadratic function is a parabola. The leading coefficient <InlineMath math="a" /> controls its opening direction and how narrow or wide it appears.

## Influence of the Leading Coefficient on Graph Shape

### When the Leading Coefficient Is Positive

If <InlineMath math="a > 0" />, the graph of the quadratic function will open upward. This means the graph has a minimum point.

Examples of functions with <InlineMath math="a > 0" />:

- <InlineMath math="f(x) = x^2" />, the simplest example with <InlineMath math="a = 1" />
- <InlineMath math="f(x) = 2x^2 + 1" />, an example with <InlineMath math="a = 2" />

The sign of <InlineMath math="a" /> controls the opening direction. Its magnitude controls the width: compared with <InlineMath math="y=x^2" />, the graph is narrower when <InlineMath math="|a|>1" /> and wider when <InlineMath math="0<|a|<1" />.

### When the Leading Coefficient Is Negative

If <InlineMath math="a < 0" />, the graph of the quadratic function will open downward. This means the graph has a maximum point.

Examples of functions with <InlineMath math="a < 0" />:

- <InlineMath math="f(x) = -x^2" /> with <InlineMath math="a = -1" />
- <InlineMath math="f(x) = -3x^2 - 12x - 15" /> with <InlineMath math="a = -3" />

### Why the Leading Coefficient Cannot Be Zero

When <InlineMath math="a = 0" />, the function form becomes <InlineMath math="f(x) = bx + c" />. This is no longer a quadratic function, but a linear function. A quadratic function must have <InlineMath math="a \neq 0" /> so that the highest power of the variable <InlineMath math="x" /> is <InlineMath math="2" />.

## Important Characteristics of Quadratic Functions

### Vertex

The vertex is the highest point (if <InlineMath math="a < 0" />) or the lowest point (if <InlineMath math="a > 0" />) on the graph. The coordinates of the vertex are expressed as <InlineMath math="(-\frac{b}{2a}, f(-\frac{b}{2a}))" />.

### Axis of Symmetry

The axis of symmetry is a vertical line that divides the parabola into two symmetrical parts. The equation of the axis of symmetry is <InlineMath math="x = -\frac{b}{2a}" />.

### Vertical-Axis Intercept

The <InlineMath math="y" />-intercept is obtained when <InlineMath math="x = 0" />. Its value is <InlineMath math="f(0) = c" />.

### Horizontal-Axis Intercepts

The intercepts on the <InlineMath math="x" />-axis are obtained when <InlineMath math="f(x) = 0" />, that is, when <InlineMath math="ax^2 + bx + c = 0" />. The solutions can be found using the formula:

<BlockMath math="x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}" />

## Steps to Graph a Quadratic Function

1. Determine whether the parabola opens upward (<InlineMath math="a > 0" />) or downward (<InlineMath math="a < 0" />).
2. Calculate the coordinates of the vertex <InlineMath math="(-\frac{b}{2a}, f(-\frac{b}{2a}))" />.
3. Calculate the <InlineMath math="y" />-intercept: <InlineMath math="(0, c)" />.
4. Calculate the intercepts on the <InlineMath math="x" />-axis, if any.
5. Choose several other <InlineMath math="x" /> values and calculate their corresponding <InlineMath math="y" /> values.
6. Plot all points in the coordinate system.
7. Connect the points with a parabolic curve.

## Drawing Quadratic Function Graphs

### Upward-Opening Parabola Example

Let's graph the function <InlineMath math="f(x) = x^2 - 2x - 3" />:

1. Coefficient <InlineMath math="a = 1 > 0" />, so the parabola opens upward.
2. Vertex:

   <MathContainer>
     <BlockMath math="x = -\frac{b}{2a} = -\frac{-2}{2 \cdot 1} = 1" />
     <BlockMath math="f(1) = 1^2 - 2 \cdot 1 - 3 = 1 - 2 - 3 = -4" />
   </MathContainer>

   So the vertex is at <InlineMath math="(1, -4)" />.

3. <InlineMath math="y" />-intercept:

   <BlockMath math="f(0) = 0^2 - 2 \cdot 0 - 3 = -3" />

   So the <InlineMath math="y" />-intercept is at <InlineMath math="(0, -3)" />.

4. Intercepts on the <InlineMath math="x" />-axis: <InlineMath math="f(x) = 0" /> or <InlineMath math="x^2 - 2x - 3 = 0" />

   Using the quadratic formula:

   <MathContainer>
     <BlockMath math="x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} = \frac{2 \pm \sqrt{4 + 12}}{2} = \frac{2 \pm \sqrt{16}}{2} = \frac{2 \pm 4}{2}" />
     <BlockMath math="x = \frac{2 + 4}{2} = 3 \text{ or} x = \frac{2 - 4}{2} = -1" />
   </MathContainer>

   So the intercepts on the <InlineMath math="x" />-axis are <InlineMath math="(-1, 0)" /> and <InlineMath math="(3, 0)" />.

5. Let's calculate some additional points:

   <MathContainer>
     <BlockMath math="f(-2) = (-2)^2 - 2 \cdot (-2) - 3 = 4 + 4 - 3 = 5" />
     <BlockMath math="f(2) = 2^2 - 2 \cdot 2 - 3 = 4 - 4 - 3 = -3" />
   </MathContainer>

Let's graph the function <InlineMath math="f(x) = -x^2" />:

1. Coefficient <InlineMath math="a = -1 < 0" />, so the parabola opens downward.
2. Vertex:

   <MathContainer>
     <BlockMath math="x = -\frac{b}{2a} = -\frac{0}{2 \cdot (-1)} = 0" />
     <BlockMath math="f(0) = -(0)^2 = 0" />
   </MathContainer>

   So the vertex is at <InlineMath math="(0, 0)" />.

3. <InlineMath math="y" />-intercept:

   <BlockMath math="f(0) = 0" />

   So the <InlineMath math="y" />-intercept is at <InlineMath math="(0, 0)" />.

4. Intercepts on the <InlineMath math="x" />-axis: <InlineMath math="f(x) = 0" /> or <InlineMath math="-x^2 = 0" />

   <MathContainer>
     <BlockMath math="x^2 = 0" />
     <BlockMath math="x = 0" />
   </MathContainer>

   So the <InlineMath math="x" />-intercept is at <InlineMath math="(0, 0)" />.

## Reading the Shape at a Glance

Write the vertex as <InlineMath math="(x_v,y_v)" />, where <InlineMath math="y_v=f(x_v)" />.

| Condition                    | Opening  | Vertex value | Range                                  |
| ---------------------------- | -------- | ------------ | -------------------------------------- |
| <InlineMath math="a > 0" />  | Upward   | Minimum      | <InlineMath math="[y_v,\infty)" />    |
| <InlineMath math="a < 0" />  | Downward | Maximum      | <InlineMath math="(-\infty,y_v]" />   |

## Practice Problem

Analyze the graph of <InlineMath math="g(x)=-2(x+1)^2+8" />. Find its opening direction, vertex, symmetry axis, intercepts, and range.

### Worked Solution

The function is already in vertex form <InlineMath math="a(x-h)^2+k" />. Here <InlineMath math="a=-2" />, <InlineMath math="h=-1" />, and <InlineMath math="k=8" />.

- Because <InlineMath math="a<0" />, the parabola opens downward.
- The vertex is <InlineMath math="(-1,8)" />, so its maximum value is <InlineMath math="8" />.
- The symmetry axis is <InlineMath math="x=-1" />.

For the <InlineMath math="y" />-axis intercept, set <InlineMath math="x=0" />:

<BlockMath math="g(0)=-2(0+1)^2+8=6" />

Thus, the graph crosses the <InlineMath math="y" />-axis at <InlineMath math="(0,6)" />. For the <InlineMath math="x" />-axis intercepts, solve <InlineMath math="g(x)=0" />:

<MathContainer>
  <BlockMath math="-2(x+1)^2+8=0" />
  <BlockMath math="(x+1)^2=4" />
  <BlockMath math="x+1=\pm2" />
  <BlockMath math="x=-3\quad\text{or}\quad x=1" />
</MathContainer>

The intercepts are <InlineMath math="(-3,0)" /> and <InlineMath math="(1,0)" />. Since the parabola opens downward from the maximum <InlineMath math="8" />, its range is <InlineMath math="(-\infty,8]" />.
