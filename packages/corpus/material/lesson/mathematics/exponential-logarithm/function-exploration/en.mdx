## An Idealized Transmission Tree

Suppose one initial case leads to exactly <InlineMath math="3" /> new cases, and every new case leads to exactly <InlineMath math="3" /> more cases in the next phase. Assume no contacts overlap, nobody recovers during the model, and the factor never changes.

Under these assumptions, each phase has three times as many new cases as the previous phase. The model is only for studying exponential functions because real outbreaks include overlapping contacts, recovery, and changing transmission rates.

## New Cases in Each Phase

The number below counts **new cases in that phase**. Add all phases to get the cumulative total:

- **Phase** <InlineMath math="1" />: <InlineMath math="3=3^1" /> new cases
- **Phase** <InlineMath math="2" />: <InlineMath math="9=3^2" /> new cases
- **Phase** <InlineMath math="3" />: <InlineMath math="27=3^3" /> new cases
- **Phase** <InlineMath math="4" />: <InlineMath math="81=3^4" /> new cases
- **Phase** <InlineMath math="5" />: <InlineMath math="243=3^5" /> new cases

If <InlineMath math="N(x)" /> is the number of new cases in phase <InlineMath math="x" />, then:

<BlockMath math="N(x)=3^x" />

The cumulative number of new cases through phase <InlineMath math="x" /> is a geometric sum:

<BlockMath math="S(x)=3+3^2+\cdots+3^x=\frac{3^{x+1}-3}{2}" />

Keeping these two quantities separate prevents a common modeling error: <InlineMath math="N(x)" /> describes one phase, while <InlineMath math="S(x)" /> adds all completed phases.

## Worked Questions

1. How many new cases does the model produce in phase <InlineMath math="20" />?

   <BlockMath math="N(20)=3^{20}=3{,}486{,}784{,}401" />

2. How many new cases have accumulated from phase <InlineMath math="1" /> through phase <InlineMath math="20" />?

   <BlockMath math="S(20)=\frac{3^{21}-3}{2}=5{,}230{,}176{,}600" />

3. Which part of the “multiply by three each phase” rule makes the exponential curve fit?

   The exponential model multiplies the previous phase by <InlineMath math="3" />. A linear model would add the same amount each phase. Multiplication by a constant factor and addition of a constant amount are different processes.

At phase <InlineMath math="20" />, the model gives <InlineMath math="3{,}486{,}784{,}401" /> new cases and <InlineMath math="5{,}230{,}176{,}600" /> cumulative cases. The model assumes that every case produces three new cases, no person is infected from two sources, and no one recovers. These values are outputs of the simplified model and cannot forecast real case counts.

## Properties of Exponential Functions

For <InlineMath math="f(x)=a^x" /> with <InlineMath math="a>0" /> and <InlineMath math="a\neq1" />:

1. The domain is <InlineMath math="\mathbb{R}" /> and the range is <InlineMath math="(0,\infty)" />.
2. The graph passes through <InlineMath math="(0,1)" /> because <InlineMath math="a^0=1" />.
3. If <InlineMath math="a>1" />, the function is increasing.
4. If <InlineMath math="0<a<1" />, the function is decreasing.
5. For <InlineMath math="a>1" />, a larger value of <InlineMath math="a" /> gives more growth per interval. For <InlineMath math="0<a<1" />, a smaller value of <InlineMath math="a" /> gives more decay per interval.

## Where Exponential Models Appear

Exponential functions can model compound interest, radioactive decay, repeated doubling, and short phases of population or transmission change. Before using one, identify whether the process really applies a roughly constant **factor** over equal intervals. If the rate, resources, or interactions change, the model must also change.
