## Seven Exponent Properties

| Situation | Property | Conditions used here |
| --------- | -------- | -------------------- |
| Multiply equal bases | <InlineMath math="a^m a^n=a^{m+n}" /> | <InlineMath math="a\neq0" />, <InlineMath math="m,n\in\mathbb{Z}" /> |
| Divide equal bases | <InlineMath math="\frac{a^m}{a^n}=a^{m-n}" /> | <InlineMath math="a\neq0" />, <InlineMath math="m,n\in\mathbb{Z}" /> |
| Raise a power to a power | <InlineMath math="(a^m)^n=a^{mn}" /> | <InlineMath math="a\neq0" />, <InlineMath math="m,n\in\mathbb{Z}" /> |
| Raise a product to a power | <InlineMath math="(ab)^m=a^m b^m" /> | <InlineMath math="a,b\neq0" />, <InlineMath math="m\in\mathbb{Z}" /> |
| Raise a quotient to a power | <InlineMath math="\left(\frac ab\right)^m=\frac{a^m}{b^m}" /> | <InlineMath math="a,b\neq0" />, <InlineMath math="m\in\mathbb{Z}" /> |
| Multiply rational powers with equal denominators | <InlineMath math="a^{m/n}a^{p/n}=a^{(m+p)/n}" /> | <InlineMath math="a>0" />, <InlineMath math="m,n,p\in\mathbb{Z}" />, <InlineMath math="n\neq0" /> |
| Multiply general rational powers | <InlineMath math="a^{m/n}a^{p/q}=a^{(mq+pn)/(nq)}" /> | <InlineMath math="a>0" />, <InlineMath math="m,n,p,q\in\mathbb{Z}" />, <InlineMath math="n,q\neq0" /> |

The **base stays the same** when powers with equal bases are multiplied or divided. Only the exponents are combined. By contrast, a power outside parentheses acts on the entire expression inside the parentheses.

Multiplying powers of the same base adds the exponents. On the exponent line, <InlineMath math="2^3" /> is a step of length <InlineMath math="3" /> and <InlineMath math="2^2" /> a step of length <InlineMath math="2" />. Put them end to end and you land on exponent <InlineMath math="5" />: <InlineMath math="2^3 \cdot 2^2 = 2^5 = 32" />.

## Conditions for Exponent Rules

- A zero base works for some positive exponents, but not for negative exponents because <InlineMath math="0^{-1}" /> would require division by zero. The integer rules therefore use <InlineMath math="a\neq0" /> as one consistent condition.
- A quotient also requires a nonzero denominator.
- For rational exponents, using <InlineMath math="a>0" /> keeps every root and power real and unambiguous. Some individual negative-base examples are real, but one unrestricted rule would not cover all rational exponents.

Check the **conditions on the base and exponent** before applying a property.

Zero and negative exponents continue the same pattern. Each step to the left halves the value, so <InlineMath math="2^0 = 1" />, <InlineMath math="2^{-1} = \frac12" /> and <InlineMath math="2^{-3} = \frac18" />. The values get smaller but stay positive, because each one is <InlineMath math="1" /> divided by a positive power of <InlineMath math="2" />: <InlineMath math="2^{-n} = \frac{1}{2^n}" />.

## The Operation Determines the Exponent Rule

The table links each operation in the expression to the **first step in simplifying** it. Find the operation, then follow the matching row.

| Pattern in the expression | First move |
| ------------------------- | ---------- |
| Same base multiplied | Add the exponents |
| Same base divided | Subtract the denominator exponent |
| Power outside a power | Multiply the exponents |
| Product or quotient inside parentheses | Distribute the outer exponent |
| Rational exponents with different denominators | Rewrite them with a common denominator |

## Simplifying Products Quotients and Powers

The examples below combine several rules in one expression. Apply **one rule per step** and keep the base unchanged. Write the intermediate line each time, because that line shows which rule you used.

### Combining Products and Quotients

Each problem below combines multiplication and division of powers with the same base. **Add the exponents** of factors in the numerator, then **subtract the exponents** of factors in the denominator, and keep the base unchanged.

1. Simplify <InlineMath math="\frac{2^5\cdot2^3}{2^2}" />.

    <BlockMath math="2^5\cdot2^2=2^{5+2}=2^7=128" />

4. Simplify <InlineMath math="2^3\cdot2^7" />.

    <BlockMath math="2^3\cdot2^7=2^{3+7}=2^{10}=1024" />

5. Simplify <InlineMath math="\frac{2^8}{2^6}" />.

    <BlockMath math="\frac{2^8}{2^6}=2^{8-6}=2^2=4" />

6. Simplify <InlineMath math="\frac{2^{10}}{2^3}" />.

7. Simplify <InlineMath math="\frac{2^6}{2^4}" />.

### Powers of Powers

Each expression below raises a power to another power. **Multiply the two exponents** and keep the base unchanged, then check your result against the numeric value in the answer.

8. Simplify <InlineMath math="(2^3)^3" />.

    <BlockMath math="(2^3)^3=2^{3\cdot3}=2^9=512" />

    <BlockMath math="(2^4)^2=2^{4\cdot2}=2^8=256" />

### Rational Exponents

For equal bases, add the fractional exponents. Use a **common denominator** so the numerators count equal-sized parts. In the second example, one half is three sixths and one third is two sixths.

11. Simplify <InlineMath math="2^{1/3}2^{2/3}" />.

    <MathContainer>
