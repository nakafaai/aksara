## The Standard Exponential Function

An exponential function places its variable in the exponent:

<BlockMath math="f(x)=a^x" />

For a real-valued exponential function on all real inputs, the base must satisfy:

<BlockMath math="a>0\qquad\text{and}\qquad a\neq1" />

The restriction <InlineMath math="a>0" /> keeps <InlineMath math="a^x" /> real for every real <InlineMath math="x" />. Excluding <InlineMath math="a=1" /> separates genuine growth or decay from a constant function.

A scaled exponential function has the form:

<BlockMath math="g(x)=k\,a^x" />

where <InlineMath math="k\neq0" /> is a vertical scale factor. The base controls growth or decay, while <InlineMath math="k" /> controls the initial value and the side of the <InlineMath math="x" />-axis on which the graph lies.

## Domain, Range, and Intercept

For the standard function <InlineMath math="f(x)=a^x" />:

1. The domain is <InlineMath math="\mathbb{R}" />.
2. The range is <InlineMath math="(0,\infty)" />.
3. The graph crosses the <InlineMath math="y" />-axis at <InlineMath math="(0,1)" /> because <InlineMath math="a^0=1" />.
4. The graph never crosses the <InlineMath math="x" />-axis because <InlineMath math="a^x>0" />.
5. If <InlineMath math="a>1" />, the function is strictly increasing.
6. If <InlineMath math="0<a<1" />, the function is strictly decreasing.

For <InlineMath math="g(x)=k\,a^x" />, the <InlineMath math="y" />-intercept is <InlineMath math="(0,k)" />. If <InlineMath math="k>0" />, its range is <InlineMath math="(0,\infty)" />. If <InlineMath math="k<0" />, the graph is reflected across the <InlineMath math="x" />-axis and its range is <InlineMath math="(-\infty,0)" />.

## Why Two Bases Are Excluded

### Base One

If <InlineMath math="a=1" />, then:

<BlockMath math="g(x)=k\cdot1^x=k" />

The output never changes, so this is a constant function rather than an exponential growth or decay function.

### Base Zero

The expression <InlineMath math="0^x" /> does not define a real-valued function on all real inputs:

<MathContainer>
  <BlockMath math="0^x=0\qquad\text{for }x>0" />
  <BlockMath math="0^x\text{ is undefined for }x<0" />
</MathContainer>

At <InlineMath math="x=0" />, the expression <InlineMath math="0^0" /> is not assigned a value in this function definition. Therefore, base zero cannot satisfy the required domain <InlineMath math="\mathbb{R}" />.

## Reading Examples

1. <InlineMath math="f(x)=4^x" /> has <InlineMath math="a=4>1" />, so it is increasing. Its first values include <InlineMath math="f(0)=1" />, <InlineMath math="f(1)=4" />, and <InlineMath math="f(2)=16" />.

2. <InlineMath math="f(x)=3^{x+1}" /> can be rewritten as <InlineMath math="f(x)=3\cdot3^x" />. The factor <InlineMath math="3" /> changes the <InlineMath math="y" />-intercept from <InlineMath math="1" /> to <InlineMath math="3" />.

3. <InlineMath math="f(x)=5^{2x-1}" /> is increasing because the exponent <InlineMath math="2x-1" /> increases with <InlineMath math="x" />. For example, <InlineMath math="f(0)=5^{-1}=\frac15" /> and <InlineMath math="f(1)=5" />.

4. <InlineMath math="f(x)=0.5^x" /> has <InlineMath math="0<a<1" />, so it is decreasing. Its first values include <InlineMath math="f(0)=1" />, <InlineMath math="f(1)=0.5" />, and <InlineMath math="f(2)=0.25" />.

## Common Models

1. **Repeated doubling**: <InlineMath math="P(t)=P_0\,2^{t/d}" />, where <InlineMath math="d" /> is the doubling time.
2. **Compound growth**: <InlineMath math="A(t)=P(1+r)^t" />, where <InlineMath math="r" /> is the rate per compounding interval.
3. **Half-life**: <InlineMath math="A(t)=A_0\left(\frac12\right)^{t/h}" />, where <InlineMath math="h" /> is the half-life.
4. **Early transmission**: <InlineMath math="C(n)=C_0R^n" />, where <InlineMath math="R" /> is an assumed average factor per cycle.

Each formula is meaningful only after its variables, units, interval, and assumptions have been stated. The same exponential shape can describe different contexts, but the symbols do not acquire real-world meaning by themselves.
