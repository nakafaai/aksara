## Shifting a Graph Left or Right

A horizontal shift slides the whole graph of a function left or right without changing its shape. A shift by <InlineMath math="h" /> changes the equation of the graph and every one of its points like this:

<BlockMath math="y = f(x) \longrightarrow y = f(x - h), \qquad (x_0, y_0) \longrightarrow (x_0 + h, y_0)" />

So **every <InlineMath math="x" />-coordinate increases by <InlineMath math="h" />** while **the height stays the same**. For <InlineMath math="h > 0" /> the graph moves right, and for <InlineMath math="h < 0" /> it moves left. The interactive function machine computes the output of <InlineMath math="f" /> for the number you type, so you can check at which input the new graph reaches the same output.

For example, <InlineMath math="y = f(x - 3)" /> is the graph of <InlineMath math="f" /> shifted <InlineMath math="3 \text{ units}" /> right, while <InlineMath math="y = f(x + 3)" /> is shifted <InlineMath math="3 \text{ units}" /> left because <InlineMath math="x + 3 = x - (-3)" />. The shift goes right even though the parentheses contain a minus sign, because the new function **produces the output <InlineMath math="f(x_0)" /> at the input <InlineMath math="x_0 + 3" />**, which is <InlineMath math="3 \text{ units}" /> further right. The domain moves by <InlineMath math="h" />, while the range stays the same, because no point changes its height.

## Why a Minus Sign Moves the Graph Right

The function <InlineMath math="g(x) = f(x - 3)" /> works in two steps: **subtract <InlineMath math="3" /> from the input first**, then apply the rule <InlineMath math="f" />. In this example the machine runs the rule <InlineMath math="f(x) = 2x + 1" />. The number you type is the number that enters the machine, and the card shows it as <InlineMath math="x" />.

The function <InlineMath math="f" /> already produces <InlineMath math="1" />, <InlineMath math="5" />, and <InlineMath math="11" /> at the inputs <InlineMath math="0" />, <InlineMath math="2" />, and <InlineMath math="5" />. The function <InlineMath math="g" /> produces the same outputs **at inputs that are <InlineMath math="3" /> larger**, namely <InlineMath math="3" />, <InlineMath math="5" />, and <InlineMath math="8" />. The same relationship holds for any function and any shift <InlineMath math="h" />:

<BlockMath math="g(x_0 + h) = f\big((x_0 + h) - h\big) = f(x_0)" />

This equation says that every point <InlineMath math="(x_0, f(x_0))" /> on the graph of <InlineMath math="f" /> has a partner <InlineMath math="(x_0 + h, f(x_0))" /> on the graph of <InlineMath math="g" />, at the same height and with its <InlineMath math="x" />-coordinate increased by <InlineMath math="h" />.

For a straight line, the shape alone cannot tell you the direction of the shift. Because <InlineMath math="2(x - 3) + 1 = (2x + 1) - 6" />, the line <InlineMath math="g" /> is also the line <InlineMath math="f" /> moved down <InlineMath math="6 \text{ units}" />. The horizontal direction shows up in **pairs of points with equal outputs**, such as <InlineMath math="(2, 5)" /> and <InlineMath math="(5, 5)" />. A parabola has a single vertex, so for a parabola you can read the direction straight from where the vertex moves.

## Shifting a Parabola and Its Vertex

The function <InlineMath math="f(x) = x^2 - 2x - 3" /> can be rewritten as <InlineMath math="f(x) = (x - 1)^2 - 4" /> by [completing the square](/en/subjects/mathematics/quadratic-function/quadratic-equation-perfect-square). From this form you read the vertex <InlineMath math="(1, -4)" /> directly. Factoring as <InlineMath math="(x + 1)(x - 3)" /> gives the zeros <InlineMath math="-1" /> and <InlineMath math="3" />, the values of <InlineMath math="x" /> that make <InlineMath math="f(x) = 0" />.

Now shift the graph of <InlineMath math="f" /> by <InlineMath math="2 \text{ units}" /> to the left. A left shift means <InlineMath math="h = -2" />, so <InlineMath math="g(x) = f(x - (-2)) = f(x + 2)" />. **Replace every <InlineMath math="x" /> in the rule for <InlineMath math="f" /> with <InlineMath math="x + 2" />**, including the <InlineMath math="x" /> in the term <InlineMath math="-2x" />:

<BlockMath math="\begin{aligned} g(x) &amp;= (x + 2)^2 - 2(x + 2) - 3 \\ &amp;= x^2 + 4x + 4 - 2x - 4 - 3 \\ &amp;= x^2 + 2x - 3 \end{aligned}" />

Check the result against points you already know. The form <InlineMath math="x^2 + 2x - 3 = (x + 1)^2 - 4" /> gives the vertex <InlineMath math="(-1, -4)" />, exactly <InlineMath math="2 \text{ units}" /> left of <InlineMath math="(1, -4)" />. Factoring as <InlineMath math="(x + 3)(x - 1)" /> gives the zeros <InlineMath math="-3" /> and <InlineMath math="1" />, so **each old zero has decreased by <InlineMath math="2" />**.

## Where the Domain and Intercepts Go

The graph of the [square root function](/en/subjects/mathematics/function-modeling/square-root-function) <InlineMath math="f(x) = \sqrt{x}" /> starts at <InlineMath math="(0, 0)" /> because <InlineMath math="\sqrt{x}" /> is defined only for <InlineMath math="x \geq 0" />. Shift this graph <InlineMath math="4 \text{ units}" /> to the left, so <InlineMath math="g(x) = f(x + 4) = \sqrt{x + 4}" />. The new domain comes from the condition on the number under the root:

<BlockMath math="x + 4 \geq 0 \iff x \geq -4" />

The domain of <InlineMath math="g" /> is <InlineMath math="[-4, \infty)" />, which is the old domain <InlineMath math="[0, \infty)" /> **moved <InlineMath math="4 \text{ units}" /> left with the graph**. The range stays <InlineMath math="[0, \infty)" /> because no height changes. The starting point <InlineMath math="(0, 0)" /> moves to <InlineMath math="(-4, 0)" />, and the point <InlineMath math="(4, 2)" /> moves to <InlineMath math="(0, 2)" />. Check the second point: <InlineMath math="g(0) = \sqrt{0 + 4} = 2" />.

The <InlineMath math="y" />-intercept has to be recalculated. The old point <InlineMath math="(0, f(0))" /> moves to <InlineMath math="(h, f(0))" />, so it no longer lies on the <InlineMath math="y" />-axis when <InlineMath math="h \neq 0" />. **The new intercept always comes from the input zero**: it is <InlineMath math="(0, g(0))" /> with <InlineMath math="g(0) = f(-h)" />.

Take <InlineMath math="f(x) = 2^x" /> shifted <InlineMath math="2 \text{ units}" /> to the right, which is <InlineMath math="g(x) = 2^{x - 2}" />. The point <InlineMath math="(0, 1)" /> on <InlineMath math="f" /> moves to <InlineMath math="(2, 1)" />, and the new intercept comes from the input zero:

<BlockMath math="g(0) = 2^{0 - 2} = 2^{-2} = \frac{1}{4}" />

The graph of <InlineMath math="g" /> crosses the <InlineMath math="y" />-axis at <InlineMath math="\left(0, \tfrac{1}{4}\right)" />, as the general rule <InlineMath math="g(0) = f(-h)" /> predicts: with <InlineMath math="h = 2" />, it gives <InlineMath math="f(-2) = 2^{-2} = \tfrac{1}{4}" />. The horizontal asymptote <InlineMath math="y = 0" />, the horizontal line the curve gets closer and closer to, stays where it is, because a horizontal line does not change when it is shifted left or right. Both curves approach the <InlineMath math="x" />-axis as <InlineMath math="x" /> decreases.

## Inside Versus Outside the Parentheses

A constant inside the parentheses acts on the input before <InlineMath math="f" /> is evaluated, while a constant outside acts on the output after <InlineMath math="f" /> is evaluated. That placement is what separates a horizontal shift from a [vertical shift](/en/subjects/mathematics/function-transformation/vertical-translation).

| Feature | Constant inside the parentheses | Constant outside the parentheses |
| --- | --- | --- |
| Form of the rule | <InlineMath math="y = f(x - h)" /> | <InlineMath math="y = f(x) + k" /> |
| Part that changes | The input, before <InlineMath math="f" /> acts | The output, after <InlineMath math="f" /> acts |
| How a point moves | <InlineMath math="(x_0, y_0) \to (x_0 + h, y_0)" /> | <InlineMath math="(x_0, y_0) \to (x_0, y_0 + k)" /> |
| Example with the number <InlineMath math="3" /> | <InlineMath math="f(x - 3)" /> right, <InlineMath math="f(x + 3)" /> left | <InlineMath math="f(x) + 3" /> up, <InlineMath math="f(x) - 3" /> down |
| Domain | Moves by <InlineMath math="h" /> | Stays the same |
| Range | Stays the same | Moves by <InlineMath math="k" /> |
| Horizontal asymptote | Stays the same | Moves by <InlineMath math="k" /> |

Inside the parentheses, the shift runs opposite to the written sign because the input has to make up for the subtraction. For <InlineMath math="x - 3" /> to equal <InlineMath math="x_0" />, the value of <InlineMath math="x" /> must be <InlineMath math="x_0 + 3" />. A constant outside the parentheses needs no such compensation, so **the sign of <InlineMath math="k" /> gives the direction of the shift directly**.

Multiplying the input, as in <InlineMath math="f(2x)" />, is a [horizontal dilation](/en/subjects/mathematics/function-transformation/horizontal-dilation) that changes the width of the graph, while adding to or subtracting from the input only shifts it. When a factor and a shift appear together, as in [combined function transformations](/en/subjects/mathematics/function-transformation/combined-transformation-function), factor out the multiplier first: <InlineMath math="f(2x - 6) = f(2(x - 3))" />. For <InlineMath math="f(x) = x^2" />, the vertex of <InlineMath math="y = (2x - 6)^2" /> lies at <InlineMath math="x = 3" />, not at <InlineMath math="x = 6" />.

## Mistakes When Shifting a Graph Sideways

You can catch a mistake with a horizontal shift by **testing one point** whose output you already know, such as the vertex or the starting point of the graph.

| Mistake | Why it fails | How to catch it |
| --- | --- | --- |
| Reading <InlineMath math="f(x - 3)" /> as a shift to the left | The input must be <InlineMath math="3" /> larger to produce an old output | For <InlineMath math="f(x) = x^2" />, the graph of <InlineMath math="y = (x - 3)^2" /> has its vertex at <InlineMath math="(3, 0)" />, right of <InlineMath math="(0, 0)" /> |
| Replacing only the first <InlineMath math="x" />, as in <InlineMath math="(x + 2)^2 - 2x - 3" /> | Every <InlineMath math="x" /> in the rule stands for the same input | The old vertex at <InlineMath math="x = 1" /> requires <InlineMath math="g(-1) = -4" />, but this rule gives <InlineMath math="0" /> |
| Writing <InlineMath math="f(x) - 3" /> for a shift to the right | A constant outside the parentheses changes the output, so the graph moves down | Test one point: <InlineMath math="(x_0, y_0)" /> must move to <InlineMath math="(x_0 + 3, y_0)" />, but <InlineMath math="f(x) - 3" /> moves it to <InlineMath math="(x_0, y_0 - 3)" /> |
| Judging the direction from the shape of a line | The line <InlineMath math="2(x - 3) + 1" /> is also <InlineMath math="(2x + 1) - 6" /> | Compare two points with the same output |
| Assuming the domain stays the same | The domain follows the shifted <InlineMath math="x" />-coordinates | Solve the condition of the new function again, such as <InlineMath math="x + 4 \geq 0" /> |

## Exercises

In each problem, first find <InlineMath math="h" />, the change in the <InlineMath math="x" />-coordinate of every point, then replace every <InlineMath math="x" /> in the rule for <InlineMath math="f" /> with <InlineMath math="x - h" />. Work each one out yourself, then **check one point** before you compare your answer with the worked solutions.

1. Find the equation of the graph of <InlineMath math="f(x) = x^2 + 2x + 1" /> after a shift of <InlineMath math="3 \text{ units}" /> to the right.

2. The graph of <InlineMath math="f(x) = \sqrt{x - 2}" /> is shifted <InlineMath math="5 \text{ units}" /> to the left. Find the equation of the new graph and its domain.

3. The graph of <InlineMath math="f(x) = 3^x" /> is shifted horizontally so that the point <InlineMath math="(0, 1)" /> moves to <InlineMath math="(-2, 1)" />. Find the equation of the new graph and its <InlineMath math="y" />-intercept.

4. The vertex of the graph of <InlineMath math="f(x) = x^2 - 4x + 3" /> is moved horizontally to <InlineMath math="(-3, -1)" />. Find the equation of the new graph in the form <InlineMath math="ax^2 + bx + c" /> together with its zeros.

### Worked Solutions

**Problem 1**. A shift of <InlineMath math="3 \text{ units}" /> to the right means <InlineMath math="h = 3" />, so the new graph is <InlineMath math="g(x) = f(x - 3)" />. Replace every <InlineMath math="x" /> with <InlineMath math="x - 3" />:

<BlockMath math="\begin{aligned} g(x) &amp;= (x - 3)^2 + 2(x - 3) + 1 \\ &amp;= x^2 - 6x + 9 + 2x - 6 + 1 \\ &amp;= x^2 - 4x + 4 \end{aligned}" />

Check with the vertex. Since <InlineMath math="f(x) = (x + 1)^2" />, the old vertex is <InlineMath math="(-1, 0)" />. The result <InlineMath math="g(x) = (x - 2)^2" /> has its vertex at <InlineMath math="(2, 0)" />, **exactly <InlineMath math="3 \text{ units}" /> right of the old vertex**. So the equation of the new graph is <InlineMath math="y = x^2 - 4x + 4" />.

**Problem 2**. A shift of <InlineMath math="5 \text{ units}" /> to the left means <InlineMath math="h = -5" />, so <InlineMath math="g(x) = f(x + 5)" />. Replace the <InlineMath math="x" /> under the root with <InlineMath math="x + 5" />, then find the domain from **the condition on the number under the root**:

<MathContainer>
<BlockMath math="g(x) = \sqrt{(x + 5) - 2} = \sqrt{x + 3}" />
<BlockMath math="x + 3 \geq 0 \iff x \geq -3" />
</MathContainer>

Check with the starting point. The graph of <InlineMath math="f" /> starts at <InlineMath math="(2, 0)" />, and <InlineMath math="g(-3) = \sqrt{0} = 0" />, so the starting point moves to <InlineMath math="(-3, 0)" />, exactly <InlineMath math="5 \text{ units}" /> to the left. The point <InlineMath math="(6, 2)" /> also moves to <InlineMath math="(1, 2)" />, because <InlineMath math="g(1) = \sqrt{4} = 2" />. So the new graph is <InlineMath math="y = \sqrt{x + 3}" /> with the domain <InlineMath math="[-3, \infty)" />.

**Problem 3**. The point <InlineMath math="(0, 1)" /> moves to <InlineMath math="(-2, 1)" />, so the <InlineMath math="x" />-coordinate changes by <InlineMath math="h = -2 - 0 = -2" />. The height stays <InlineMath math="1" />, so this move is indeed a horizontal shift. Substitute <InlineMath math="h = -2" /> into <InlineMath math="g(x) = f(x - h)" />, then compute **the intercept from the input zero**:

<MathContainer>
<BlockMath math="g(x) = 3^{x - (-2)} = 3^{x + 2}" />
<BlockMath math="g(0) = 3^{0 + 2} = 9" />
</MathContainer>

Check the point given in the problem: <InlineMath math="g(-2) = 3^0 = 1" />, so the new graph does pass through <InlineMath math="(-2, 1)" />. The equation of the new graph is <InlineMath math="y = 3^{x + 2}" />, and its <InlineMath math="y" />-intercept is <InlineMath math="(0, 9)" />.

**Problem 4**. The form <InlineMath math="f(x) = (x - 2)^2 - 1" /> gives the vertex <InlineMath math="(2, -1)" />. The vertex moves to <InlineMath math="(-3, -1)" />, so <InlineMath math="h = -3 - 2 = -5" />, a shift of <InlineMath math="5 \text{ units}" /> to the left. Substitute into the vertex form, because that form contains only one <InlineMath math="x" /> to replace:

<BlockMath math="\begin{aligned} g(x) &amp;= f(x + 5) = \big((x + 5) - 2\big)^2 - 1 \\ &amp;= (x + 3)^2 - 1 \\ &amp;= x^2 + 6x + 8 \end{aligned}" />

Factoring as <InlineMath math="x^2 + 6x + 8 = (x + 2)(x + 4)" /> gives the zeros <InlineMath math="-2" /> and <InlineMath math="-4" />. Check against the old zeros. The function <InlineMath math="f" /> is zero at <InlineMath math="1" /> and <InlineMath math="3" />, and **subtracting <InlineMath math="5" /> from each old zero** gives <InlineMath math="-4" /> and <InlineMath math="-2" />. So the equation of the new graph is <InlineMath math="y = x^2 + 6x + 8" /> with the zeros <InlineMath math="-4" /> and <InlineMath math="-2" />.
