## Sliding a Graph Left or Right

A **horizontal shift** by <InlineMath math="h" /> turns <InlineMath math="y = f(x)" /> into <InlineMath math="y = f(x - h)" />. Every point <InlineMath math="(x_0, y_0)" /> moves to <InlineMath math="(x_0 + h, y_0)" />, so **the height stays the same** and the whole graph slides sideways. For <InlineMath math="h > 0" /> the graph moves right, and for <InlineMath math="h < 0" /> it moves left. The first graph follows a parabola and its copy shifted three units to the right, so you can track the vertex as it travels.

<BlockMath math="(x_0, y_0) \longmapsto (x_0 + h,\ y_0)" />

The minus sign inside the bracket looks as if it should move the graph left, but it moves the graph right. The new function <InlineMath math="g(x) = f(x - 3)" /> reaches the output <InlineMath math="f(x_0)" /> only when its input is <InlineMath math="x_0 + 3" />, which is three units further right. The domain moves with the graph, while **the range stays the same**.

The graph shows the whole curve moving together. Its shape and its height at each position stay the same, and only its horizontal position changes. That is the meaning of a horizontal shift.

## Why a Minus Sign Moves the Graph Right

Read <InlineMath math="g(x) = f(x - 3)" /> as two steps. First the machine subtracts <InlineMath math="3" /> from the input, and then it applies the rule of <InlineMath math="f" />. The function machine runs <InlineMath math="f(x) = 2x + 1" />. Type a number, and the card shows what the rule returns.

Now let the machine receive <InlineMath math="x - 3" /> instead of <InlineMath math="x" />. For the input <InlineMath math="8" /> of <InlineMath math="g" />, the number entering the machine is <InlineMath math="8 - 3 = 5" />, and the rule returns <InlineMath math="f(5) = 11" />. So <InlineMath math="g(8) = 11" />. The table lists three more pairs.

| Input of <InlineMath math="g" /> | Number entering the machine | Output <InlineMath math="g(x)" /> |
| --- | --- | --- |
| <InlineMath math="3" /> | <InlineMath math="3 - 3 = 0" /> | <InlineMath math="f(0) = 1" /> |
| <InlineMath math="5" /> | <InlineMath math="5 - 3 = 2" /> | <InlineMath math="f(2) = 5" /> |
| <InlineMath math="8" /> | <InlineMath math="8 - 3 = 5" /> | <InlineMath math="f(5) = 11" /> |

Every output of <InlineMath math="f" /> appears again at an input that is **three larger**. For any shift <InlineMath math="h" />, the same reasoning gives

<BlockMath math="g(x_0 + h) = f\big((x_0 + h) - h\big) = f(x_0)" />

Each point <InlineMath math="(x_0, f(x_0))" /> on <InlineMath math="f" /> has a partner <InlineMath math="(x_0 + h, f(x_0))" /> on <InlineMath math="g" />.

## Shifting a Parabola and Its Vertex

Let <InlineMath math="f(x) = x^2 - 2x - 3" />. **Completing the square** gives <InlineMath math="f(x) = (x - 1)^2 - 4" />, so the vertex is <InlineMath math="(1, -4)" /> and the zeros are <InlineMath math="-1" /> and <InlineMath math="3" />. Shift the graph <InlineMath math="2" /> units to the left, which means <InlineMath math="h = -2" />. Replace every <InlineMath math="x" /> with <InlineMath math="x + 2" />:

<BlockMath math="\begin{aligned} g(x) &= f(x + 2) \\ &= (x + 2)^2 - 2(x + 2) - 3 \\ &= x^2 + 4x + 4 - 2x - 4 - 3 \\ &= x^2 + 2x - 3 \end{aligned}" />

Check the result with the points you already know. The new function factors as <InlineMath math="x^2 + 2x - 3 = (x + 3)(x - 1)" />, so its zeros are <InlineMath math="-3" /> and <InlineMath math="1" />. Each old zero moved two units to the left: <InlineMath math="-1 - 2 = -3" /> and <InlineMath math="3 - 2 = 1" />. The vertex moved the same way, from <InlineMath math="(1, -4)" /> to <InlineMath math="(-1, -4)" />, which agrees with the completed square <InlineMath math="(x + 1)^2 - 4" />.

## The Domain and Intercepts Move With the Graph

The square root function <InlineMath math="f(x) = \sqrt{x}" /> needs <InlineMath math="x \ge 0" />, so its domain is <InlineMath math="[0, \infty)" />. Shift it four units to the left to get <InlineMath math="g(x) = \sqrt{x + 4}" />. The condition <InlineMath math="x + 4 \ge 0" /> gives <InlineMath math="x \ge -4" />, so **the new domain starts at** <InlineMath math="-4" />. The range stays <InlineMath math="[0, \infty)" />, because every value from zero upward is still reached.

The starting point <InlineMath math="(0, 0)" /> moves to <InlineMath math="(-4, 0)" />. The point <InlineMath math="(4, 2)" /> moves to <InlineMath math="(0, 2)" />, because <InlineMath math="g(0) = \sqrt{4} = 2" />.

## Common Mistakes With the Sign Inside the Bracket

Most errors come from treating **the input and the output** as if they were the same. The table lists five mistakes, why each one fails, and how to catch it.

| Mistake | Why it fails | How to catch it |
| --- | --- | --- |
| Reading <InlineMath math="x - 3" /> as a shift of three units to the left | The graph moves right, as the machine showed for <InlineMath math="g(8) = 11" /> | Check that the vertex of <InlineMath math="x^2" /> lands on <InlineMath math="(3, 0)" /> |
| Replacing only one <InlineMath math="x" /> | Every <InlineMath math="x" /> in the rule becomes <InlineMath math="x - 3" /> | Write <InlineMath math="2(x - 3) + 1" /> and not <InlineMath math="2x - 3 + 1" />, which equals <InlineMath math="2x - 2" /> |
| Writing <InlineMath math="f(x) - 3" /> for a horizontal shift | Subtracting outside the bracket moves the graph down | Ask whether the change happens to the input or to the output |
| Judging the direction with a straight line | A shifted line can equal a vertical shift of the original line | Compare a curve or one pair of corresponding points |
| Keeping the domain fixed | The domain moves by the same amount as the input shift | Solve the new input condition, such as <InlineMath math="x + 4 \ge 0" /> |

## Exercises

Before you write an equation, **find the shift** <InlineMath math="h" /> **and its direction**. Then replace every <InlineMath math="x" /> in the rule with <InlineMath math="x - h" />, and check one corresponding point before you finish.

1. Shift <InlineMath math="f(x) = x^2 + 2x + 1" /> three units to the right. Write the new equation and find its vertex.
2. Shift <InlineMath math="g(x) = \sqrt{x - 1}" /> five units to the left. Write the new equation, its domain, and the image of the point <InlineMath math="(1, 0)" />.
3. The graph of <InlineMath math="h(x) = 3^x" /> passes through <InlineMath math="(0, 1)" />. Shift it so that this point moves to <InlineMath math="(-2, 1)" />. Write the new equation and its y-intercept.
4. The vertex of <InlineMath math="f(x) = x^2 - 4x + 3" /> is <InlineMath math="(2, -1)" />. Shift the graph so that the vertex moves to <InlineMath math="(-3, -1)" />. Write the new equation and find both zeros.

### Worked Solutions

**Problem 1**. **The shift is** <InlineMath math="h = 3" />, so replace <InlineMath math="x" /> with <InlineMath math="x - 3" />: <InlineMath math="(x - 3)^2 + 2(x - 3) + 1 = x^2 - 6x + 9 + 2x - 6 + 1 = x^2 - 4x + 4" />. The rule factors as <InlineMath math="(x - 2)^2" />, so the vertex is <InlineMath math="(2, 0)" />. The old vertex <InlineMath math="(-1, 0)" /> moved three units to the right, which agrees.

**Problem 2**. The shift is <InlineMath math="h = -5" />, so replace <InlineMath math="x" /> with <InlineMath math="x + 5" />: <InlineMath math="g(x + 5) = \sqrt{x + 5 - 1} = \sqrt{x + 4}" />. The condition <InlineMath math="x + 4 \ge 0" /> gives the domain <InlineMath math="[-4, \infty)" />. The point <InlineMath math="(1, 0)" /> moves to <InlineMath math="(-4, 0)" />, and indeed <InlineMath math="\sqrt{-4 + 4} = 0" />.

**Problem 3**. The point <InlineMath math="(0, 1)" /> must move to <InlineMath math="(-2, 1)" />, so <InlineMath math="h = -2" />, and the new rule is <InlineMath math="H(x) = 3^{x + 2}" />. Its y-intercept is <InlineMath math="H(0) = 3^2 = 9" />, so the intercept is <InlineMath math="(0, 9)" />. The check <InlineMath math="H(-2) = 3^0 = 1" /> confirms that the moved point lies on the new graph.

**Problem 4**. The vertex moves from <InlineMath math="(2, -1)" /> to <InlineMath math="(-3, -1)" />, so the shift is five units to the left, <InlineMath math="h = -5" />. Then <InlineMath math="g(x) = (x + 5)^2 - 4(x + 5) + 3 = x^2 + 6x + 8" />. The zeros of <InlineMath math="g" /> are the zeros of <InlineMath math="f" />, which are <InlineMath math="1" /> and <InlineMath math="3" />, each moved five units to the left. Check <InlineMath math="g(-4) = 16 - 24 + 8 = 0" /> and <InlineMath math="g(-2) = 4 - 12 + 8 = 0" />.
