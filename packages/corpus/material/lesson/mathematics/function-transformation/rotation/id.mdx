## Pengertian Rotasi Fungsi

Rotasi adalah transformasi geometri yang memutar suatu objek terhadap titik pusat tertentu dengan sudut rotasi yang ditentukan. Dalam konteks fungsi, rotasi mengubah posisi grafik fungsi dengan cara memutar setiap titik pada grafik tersebut.

Sebuah roda memperlihatkan geometrinya: setiap titik bergerak pada lingkaran yang berpusat di poros. Grafik berotasi dengan cara yang sama, titik demi titik, sambil mempertahankan jarak setiap titik dari pusat rotasi.

## Rumus Rotasi Terhadap Titik Pusat

Untuk rotasi terhadap titik pusat <InlineMath math="(a, b)" /> dengan sudut <InlineMath math="\theta" />, rumus transformasinya adalah:

<MathContainer>
<BlockMath math="x' = (x - a) \cos \theta - (y - b) \sin \theta + a" />
<BlockMath math="y' = (x - a) \sin \theta + (y - b) \cos \theta + b" />
</MathContainer>

Dimana:
- <InlineMath math="(x, y)" /> adalah koordinat titik asal
- <InlineMath math="(x', y')" /> adalah koordinat titik hasil rotasi
- <InlineMath math="(a, b)" /> adalah titik pusat rotasi
- <InlineMath math="\theta" /> adalah sudut rotasi (positif untuk arah berlawanan jarum jam)

## Rotasi Khusus Terhadap Titik Asal

Ketika rotasi dilakukan terhadap titik asal <InlineMath math="(0, 0)" />, rumus menjadi lebih sederhana:

1. Rotasi <InlineMath math="90^\circ" />

    <BlockMath math="(x, y) \rightarrow (-y, x)" />

2. Rotasi <InlineMath math="180^\circ" />

    <BlockMath math="(x, y) \rightarrow (-x, -y)" />

3. Rotasi <InlineMath math="270^\circ" />

    <BlockMath math="(x, y) \rightarrow (y, -x)" />

## Sifat Rotasi Fungsi

Rotasi memiliki beberapa sifat penting:

- **Mempertahankan Bentuk**: Rotasi tidak mengubah bentuk dasar grafik, hanya mengubah orientasinya
- **Mempertahankan Jarak**: Jarak antara dua titik pada grafik tetap sama setelah rotasi
- **Komposisi Rotasi**: Rotasi berturut-turut dapat digabungkan dengan menjumlahkan sudut rotasinya

## Penerapan Rotasi pada Berbagai Fungsi

### Rotasi Fungsi Linear

Untuk fungsi linear <InlineMath math="y = mx + c" />, rotasi akan mengubah kemiringan dan posisi garis.

    {
      points: Array.from({ length: 11 }, (_, i) => {
        const x = (i - 5);
        const y = 2 * x + 1;

## Langkah Menentukan Hasil Rotasi

Untuk menentukan hasil rotasi suatu fungsi, ikuti langkah berikut:

- Tentukan titik pusat rotasi dan sudut rotasi yang diinginkan
- Pilih beberapa titik pada grafik fungsi asli sebagai sampel
- Terapkan rumus rotasi pada setiap titik sampel
- Hubungkan titik-titik hasil rotasi untuk menelusuri kurva baru, yang belum tentu tetap merupakan fungsi terhadap x
- Verifikasi hasil dengan memeriksa beberapa titik tambahan

## Latihan

1. Tentukan hasil rotasi titik <InlineMath math="(3, 4)" /> terhadap titik asal dengan sudut <InlineMath math="90^\circ" /> berlawanan arah jarum jam.

2. Fungsi <InlineMath math="f(x) = x^2 - 2x + 1" /> dirotasi <InlineMath math="180^\circ" /> terhadap titik asal. Tentukan koordinat titik puncak hasil rotasi jika titik puncak asli berada di <InlineMath math="(1, 0)" />.

3. Garis <InlineMath math="y = 3x - 2" /> dirotasi <InlineMath math="270^\circ" /> terhadap titik asal. Tentukan persamaan garis hasil rotasi.

4. Titik <InlineMath math="(2, 5)" /> dirotasi <InlineMath math="60^\circ" /> terhadap titik <InlineMath math="(1, 1)" />. Tentukan koordinat hasil rotasi.

5. Fungsi <InlineMath math="y = \sqrt{x}" /> untuk <InlineMath math="x \geq 0" /> dirotasi <InlineMath math="90^\circ" /> berlawanan arah jarum jam terhadap titik asal. Jelaskan bentuk grafik hasil rotasi.
