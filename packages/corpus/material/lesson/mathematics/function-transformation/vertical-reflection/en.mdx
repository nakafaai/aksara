## Flipping a Graph across the Horizontal Axis

Vertical reflection flips a function graph across the <InlineMath math="x" />-axis. Like a reflection on calm water, each point <Highlight>keeps its horizontal position</Highlight> and appears at <Highlight>the same distance on the opposite side</Highlight>.

If we have a function <InlineMath math="f(x)" />, then vertical reflection produces a new function <InlineMath math="g(x) = -f(x)" /> which is the reflection of the original function across the <InlineMath math="x" />-axis.

### Rules of Vertical Reflection

For any function <InlineMath math="f(x)" />, vertical reflection is defined as:

<BlockMath math="g(x) = -f(x)" />

This transformation changes every point <InlineMath math="(x, y)" /> on the original graph to <InlineMath math="(x, -y)" /> on the reflected graph.

Points on the **mirror axis stay fixed**. For other points, the coordinate perpendicular to the mirror axis changes sign. Reflecting twice returns every point to its original position.

<BlockMath math="-g(x)=-(-f(x))=f(x)" />

## Which Values the Vertical Flip Moves

Vertical reflection flips a graph across the <InlineMath math="x" />-axis, so the <InlineMath math="x" />-axis acts as the mirror line. Each point on the original graph keeps its distance to the mirror line, but moves to the other side of it.

Take a point <InlineMath math="(a, b)" /> on the graph of <InlineMath math="f(x)" />. The matching point on the graph of <InlineMath math="-f(x)" /> is <InlineMath math="(a, -b)" />. The <InlineMath math="x" /> coordinate stays at <InlineMath math="a" />, and only the sign of the <InlineMath math="y" /> value flips.

| Part of the function | Before the reflection | After the reflection |
| --- | --- | --- |
| Point <InlineMath math="(a, b)" /> | On the graph of <InlineMath math="f(x)" /> | Moves to <InlineMath math="(a, -b)" /> |
| Domain | The original interval | The same interval as before |
| Range <InlineMath math="[c, d]" /> | The original interval | Becomes <InlineMath math="[-d, -c]" /> |
| <InlineMath math="x" />-intercept | At <InlineMath math="x = x_0" /> | Stays at <InlineMath math="x = x_0" /> |
| Maximum and minimum points | Highest and lowest points | Swap their roles |

<Highlight>The range flips to the opposite side</Highlight> because it lists the output values, and those values change sign. The domain keeps its values because the allowed inputs do not change. A [horizontal reflection](/en/subjects/mathematics/function-transformation/horizontal-reflection) flips the horizontal coordinates instead.

## Reflecting an Exponential Graph across the Horizontal Axis

For the exponential function <InlineMath math="f(x) = 2^x" />, every positive output moves to the corresponding negative output.

For exponential functions:
- The **horizontal asymptote** remains at <InlineMath math="y = 0" /> for both functions (since the <InlineMath math="x" />-axis reflects onto itself)
- The <InlineMath math="y" />-intercept changes from <InlineMath math="(0, 1)" /> to <InlineMath math="(0, -1)" />
- The function that was originally increasing becomes decreasing

## Exercises

The three problems below use the mirror rule you have just learned. Each one multiplies the whole output by <InlineMath math="-1" />, so every **height** appears on the opposite side of the <InlineMath math="x" />-axis. Try them without the answer key first, then compare your steps with the worked answers.

1. Given the function <InlineMath math="f(x) = x^2 + 4x + 3" />. Determine the equation of the function resulting from vertical reflection.

2. The graph of the function <InlineMath math="g(x) = 3^x + 2" /> is reflected across the <InlineMath math="x" />-axis. Determine the equation of the resulting function, then determine the range of that function.

3. Function <InlineMath math="h(x) = \sqrt{x + 1}" /> undergoes vertical reflection. Determine the <InlineMath math="y" />-intercept of the resulting reflected function.

### The Exponential Range

<BlockMath math="3^x>0\;\Rightarrow\;3^x+2>2\;\Rightarrow\;-(3^x+2)&lt;-2" />

Multiplying by negative one **reverses the inequality**. Two is only a boundary, because an exponential is always positive.

Equation of the resulting reflected function:

- Vertical reflection: <InlineMath math="G(x) = -(3^x + 2) = -3^x - 2" />
- Range after reflection: Since the original range of <InlineMath math="g(x) = 3^x + 2" /> is <InlineMath math="(2, \infty)" />, the range after reflection is <InlineMath math="(-\infty, -2)" />

### The Square Root Intercept

A vertical intercept uses **zero input**. Calculate the function value, then reverse its sign.

The original function <InlineMath math="h(x) = \sqrt{x + 1}" /> has a <InlineMath math="y" />-intercept at <InlineMath math="(0, 1)" /> because <InlineMath math="h(0) = \sqrt{0 + 1} = 1" />.
After vertical reflection: <InlineMath math="H(x) = -\sqrt{x + 1}" />, the <InlineMath math="y" />-intercept becomes <InlineMath math="(0, -1)" />.
