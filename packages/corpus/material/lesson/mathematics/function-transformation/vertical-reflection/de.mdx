## Grundidee der vertikalen Spiegelung

Bei einer vertikalen Spiegelung wird ein Funktionsgraph an der <InlineMath math="x" />-Achse gespiegelt. Das ähnelt dem Spiegelbild eines Gegenstands auf einer ruhigen Wasseroberfläche: Die Form bleibt erhalten, aber oben und unten tauschen ihre Plätze.

Für eine Funktion <InlineMath math="f(x)" /> entsteht die neue Funktion <InlineMath math="g(x) = -f(x)" />. Das Minuszeichen vor der Funktion bewirkt die Spiegelung an der <InlineMath math="x" />-Achse.

### Spiegelungsregel

Für jede Funktion <InlineMath math="f(x)" /> gilt:

<BlockMath math="g(x) = -f(x)" />

Jeder Punkt <InlineMath math="(x, y)" /> des ursprünglichen Graphen wird also zum Punkt <InlineMath math="(x, -y)" />. Die horizontale Position bleibt gleich, nur die Höhe wechselt das Vorzeichen.

Betrachten wir zuerst die quadratische Funktion <InlineMath math="f(x) = x^2" />.

Am Graphen lässt sich direkt ablesen:
- Die ursprüngliche Funktion <InlineMath math="f(x) = x^2" /> öffnet sich nach oben mit dem Scheitelpunkt bei <InlineMath math="(0, 0)" />
- Die reflektierte Funktion <InlineMath math="g(x) = -x^2" /> öffnet sich nach unten, wobei der Scheitelpunkt immer noch bei <InlineMath math="(0, 0)" /> liegt
- Die beiden Graphen sind Spiegelbilder voneinander an der <InlineMath math="x" />-Achse

## Spiegelung einer linearen Funktion

Dieselbe Spiegelungsregel gilt für die lineare Funktion <InlineMath math="f(x) = 2x + 3" />.

      }),
      smooth: false,
      color: "#7c3aed",
      labels: [{ text: <InlineMath math="f(x)=2x+3" />, offset: [1, 0.5, 0] }],
      showPoints: false,
    },
    {
      points: Array.from({ length: 21 }, (_, i) => {
        const x = (i - 10) * 0.5;
        return { x, y: -(2 * x + 3), z: 0 };
      }),

      color: "#d97706",

/>

Der Vergleich zeigt:
- Die ursprüngliche Funktion <InlineMath math="f(x) = 2x + 3" /> hat eine positive Steigung und schneidet die <InlineMath math="y" />-Achse bei <InlineMath math="(0, 3)" />
- Die reflektierte Funktion <InlineMath math="g(x) = -2x - 3" /> hat eine negative Steigung und schneidet die <InlineMath math="y" />-Achse bei <InlineMath math="(0, -3)" />
- Beide Geraden schneiden sich auf der <InlineMath math="x" />-Achse

## Eigenschaften der vertikalen Spiegelung

### Horizontale Achse als Spiegellinie

Die <InlineMath math="x" />-Achse ist die Spiegellinie. Ein Punkt und sein Spiegelpunkt liegen gleich weit von der <InlineMath math="x" />-Achse entfernt.

### Wirkung auf Koordinatenpunkte

Liegt <InlineMath math="(a, b)" /> auf dem Graphen von <InlineMath math="f(x)" />, dann liegt auf dem Graphen von <InlineMath math="-f(x)" /> der Punkt <InlineMath math="(a, -b)" />.

### Definitionsbereich und Wertebereich

- **Definitionsbereich**: Bleibt unverändert
- **Wertebereich**: Alle Vorzeichen der Funktionswerte kehren sich um

Hat die ursprüngliche Funktion den Wertebereich <InlineMath math="[c, d]" />, so besitzt die vertikal gespiegelte Funktion den Wertebereich <InlineMath math="[-d, -c]" />.

## Einen Exponentialgraphen an der horizontalen Achse spiegeln

Bei der Exponentialfunktion <InlineMath math="f(x) = 2^x" /> liegt der gespiegelte Graph vollständig unterhalb der horizontalen Achse.

<LineEquation
  title={<>Spiegelung der Exponentialfunktion <InlineMath math="f(x) = 2^x" /></>}
  description={<>Der gespiegelte Graph fällt und nähert sich derselben horizontalen Asymptote <InlineMath math="y = 0" /> von unten.</>}
  showZAxis={false}
  cameraPosition={[8, 6, 8]}
  data={[
    {
      points: Array.from({ length: 31 }, (_, i) => {
        const x = (i - 15) * 0.3;
        return { x, y: Math.pow(2, x), z: 0 };
      }),
      color: "#4f46e5",
      labels: [{ text: <InlineMath math="f(x)=2^x" />, offset: [0.5, 1, 0] }],
      showPoints: false,
    },
    {
      points: Array.from({ length: 31 }, (_, i) => {
        const x = (i - 15) * 0.3;
        return { x, y: -Math.pow(2, x), z: 0 };
      }),
      color: "#059669",
      labels: [{ text: <InlineMath math="g(x)=-2^x" />, offset: [0.5, -1, 0] }],
      showPoints: false,
    },
  ]}
/>

Für Exponentialfunktionen:
- Die horizontale Asymptote bleibt für beide Funktionen bei <InlineMath math="y = 0" /> (da die <InlineMath math="x" />-Achse sich selbst spiegelt)
- Der <InlineMath math="y" />-Achsenabschnitt ändert sich von <InlineMath math="(0, 1)" /> auf <InlineMath math="(0, -1)" />
- Die ursprünglich steigende Funktion wird abnehmend

## Spiegelung einer trigonometrischen Funktion

Bei der <InlineMath math="\sin" />-Funktion vertauscht die Spiegelung Hochpunkte und Tiefpunkte.

<LineEquation
  title={<>Spiegelung der Sinusfunktion <InlineMath math="f(x) = \sin(x)" /></>}
  description={<>Die gespiegelte <InlineMath math="\sin" />-Welle verläuft mit entgegengesetztem Vorzeichen.</>}
  showZAxis={false}
  cameraPosition={[0, 0, 12]}
  data={[
    {
      points: Array.from({ length: 61 }, (_, i) => {
        const x = (i - 30) * 0.2;
        return { x, y: Math.sin(x), z: 0 };
      }),
      color: "#0891b2",
      labels: [{ text: <InlineMath math="f(x)=\sin(x)" />, offset: [1, 1.5, 0] }],
      showPoints: false,
    },
    {
      points: Array.from({ length: 61 }, (_, i) => {
        const x = (i - 30) * 0.2;
        return { x, y: -Math.sin(x), z: 0 };
      }),
      color: "#e11d48",
      labels: [{ text: <InlineMath math="g(x)=-\sin(x)" />, offset: [1, -1.5, 0] }],
      showPoints: false,
    },
  ]}
/>

Der Graph zeigt:
- Die Amplitude bleibt gleich, aber die Wellenrichtung ist umgekehrt
- Periode und Frequenz ändern sich nicht
- Maximale Punkte werden zu minimalen Punkten und umgekehrt
