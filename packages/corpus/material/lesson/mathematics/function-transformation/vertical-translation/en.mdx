## Lifting or Lowering the Whole Graph

A **vertical shift** by <InlineMath math="k" /> turns <InlineMath math="y = f(x)" /> into <InlineMath math="y = f(x) + k" />. Every point <InlineMath math="(x_0, y_0)" /> moves to <InlineMath math="(x_0, y_0 + k)" />, so **every x-coordinate stays the same**. The graph moves up when <InlineMath math="k > 0" /> and down when <InlineMath math="k < 0" />. The domain does not change, while the range, a horizontal asymptote, and the y-intercept all move by <InlineMath math="k" />. The first graph lifts the parabola <InlineMath math="x^2 - 4x + 3" /> by five units, and its vertex and its zeros respond in different ways.

<BlockMath math="(x_0, y_0) \longmapsto (x_0,\ y_0 + k)" />

Adding <InlineMath math="k" /> changes every height by the same amount, including the heights of points on the x-axis. That is why zeros do not simply move by <InlineMath math="k" />. A zero of <InlineMath math="f" /> solves <InlineMath math="f(x) = 0" />, but a zero of <InlineMath math="f(x) + k" /> solves <InlineMath math="f(x) = -k" />, which is a different equation.

The zeros satisfy <InlineMath math="x^2 - 4 + k = 0" />, or <InlineMath math="x^2 = 4 - k" />. The number of solutions depends on <InlineMath math="k" />. For <InlineMath math="k = 0" /> there are two zeros, <InlineMath math="\pm 2" />. For <InlineMath math="k = 3" /> they are <InlineMath math="\pm 1" />, and for <InlineMath math="k = 4" /> the only zero is <InlineMath math="0" />, where the parabola touches the x-axis. For <InlineMath math="k = 5" /> the equation <InlineMath math="x^2 = -1" /> has no real solution.

Every height drops by three, so the asymptote moves to <InlineMath math="y = -3" />. The graph still approaches that line, but it never reaches it, and the range becomes <InlineMath math="(-3, \infty)" />. The y-intercept moves from <InlineMath math="(0, 1)" /> to <InlineMath math="(0, -2)" />, because <InlineMath math="g(0) = 1 - 3 = -2" />.

The graph of <InlineMath math="g" /> crosses the x-axis where <InlineMath math="2^x = 3" />, so <InlineMath math="x = \log_2 3 \approx 1.585" />. Check it with <InlineMath math="g(\log_2 3) = 3 - 3 = 0" />.

## Mistakes When Adding a Constant

The table lists **five mistakes**, why each one fails, and how to catch it.

| Mistake | Why it fails | How to catch it |
| --- | --- | --- |
| Adding <InlineMath math="k" /> inside the bracket | <InlineMath math="f(x + k)" /> is a horizontal shift, which moves the graph sideways | A vertical shift changes only the second coordinate of each point |
| Changing the domain | Adding a constant to the output never makes an input allowed or forbidden | Compare the domain of <InlineMath math="f(x) + k" /> with the domain of <InlineMath math="f" /> |
| Moving the zeros by <InlineMath math="k" /> | The new zeros solve <InlineMath math="f(x) = -k" />, a different equation | Substitute an old zero into the new rule, which gives <InlineMath math="k" />, not zero |
| Keeping the asymptote at <InlineMath math="y = 0" /> | The asymptote moves with the graph by the same amount | Read the height that the new function approaches |
| Reading a negative <InlineMath math="k" /> as an upward shift | A negative constant lowers every point | Read the sign of <InlineMath math="k" /> as the direction of the move |

## Exercises

Start each problem by **finding the constant** <InlineMath math="k" /> and its sign. Then add it to the output of the rule, and check one point before you finish.

1. Shift <InlineMath math="f(x) = x^2 + 4x + 3" /> five units up. Write the new equation and find its vertex.
2. Shift <InlineMath math="g(x) = 3x + 2" /> seven units down. Write the new equation, its y-intercept, and its zero.
3. The graph of <InlineMath math="h(x) = \sqrt{x}" /> passes through <InlineMath math="(4, 2)" />. Shift it so that this point moves to <InlineMath math="(4, 5)" />. Find <InlineMath math="k" />, write the new equation, and state its range.
4. Let <InlineMath math="f(x) = x^2 - 4" />. For which values of <InlineMath math="k" /> does <InlineMath math="f(x) + k" /> have exactly one zero? Explain your answer and check it.

### Worked Solutions

**Problem 1**. **The shift is** <InlineMath math="k = 5" />, so the new rule is <InlineMath math="x^2 + 4x + 3 + 5 = x^2 + 4x + 8" />. The vertex of <InlineMath math="f" /> is at <InlineMath math="x = -\frac{4}{2} = -2" />, where <InlineMath math="f(-2) = 4 - 8 + 3 = -1" />. Adding five to the height moves the vertex to <InlineMath math="(-2, 4)" />. Check: <InlineMath math="g(-2) = 4 - 8 + 8 = 4" />.

**Problem 2**. The shift is <InlineMath math="k = -7" />, so the new rule is <InlineMath math="3x + 2 - 7 = 3x - 5" />. The y-intercept is <InlineMath math="(0, -5)" />. The zero solves <InlineMath math="3x - 5 = 0" />, so <InlineMath math="x = \frac{5}{3}" />. Check: <InlineMath math="3 \cdot \frac{5}{3} - 5 = 0" />.

**Problem 3**. The height of <InlineMath math="(4, 2)" /> must become <InlineMath math="5" />, so **<InlineMath math="k = 3" />**. The new equation is <InlineMath math="H(x) = \sqrt{x} + 3" />. The square root is never negative, so its smallest value is <InlineMath math="3" />, and the range is <InlineMath math="[3, \infty)" />. The domain stays <InlineMath math="[0, \infty)" />.

**Problem 4**. The zeros of <InlineMath math="f(x) + k" /> solve <InlineMath math="x^2 - 4 + k = 0" />, which means <InlineMath math="x^2 = 4 - k" />. This equation has exactly one solution only when the right side is zero, so **<InlineMath math="k = 4" />**, where the only zero is <InlineMath math="x = 0" />. For <InlineMath math="k > 4" /> the right side is negative and there are no zeros, while for <InlineMath math="k < 4" /> there are two. Check: <InlineMath math="f(x) + 4 = x^2" /> has the single zero <InlineMath math="0" />.
