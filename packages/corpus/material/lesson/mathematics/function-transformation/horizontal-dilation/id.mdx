## Mengalikan Masukan dengan Sebuah Bilangan

**Dilatasi horizontal** mengubah fungsi <InlineMath math="y = f(x)" /> menjadi <InlineMath math="y = f(bx)" /> dengan <InlineMath math="b > 0" />. Bilangan <InlineMath math="b" /> disebut pengali masukan karena bilangan ini mengalikan <InlineMath math="x" /> sebelum aturan <InlineMath math="f" /> bekerja. Akibatnya, setiap titik grafik <InlineMath math="f" /> pindah mendatar:

<BlockMath math="(x_0, y_0) \longmapsto \left(\frac{x_0}{b},\ y_0\right)" />

Tinggi titik tidak berubah, hanya jaraknya ke sumbu <InlineMath math="y" /> yang dibagi <InlineMath math="b" />. Jika <InlineMath math="b > 1" />, grafik **memampat ke arah sumbu <InlineMath math="y" />** sehingga lebarnya tinggal <InlineMath math="\frac{1}{b}" /> kali lebar semula. Jika <InlineMath math="0 < b < 1" />, grafik meregang menjauhi sumbu <InlineMath math="y" /> dengan faktor <InlineMath math="\frac{1}{b}" />. Di tampilan tiga dimensi lapisan grafik, kamu bisa memutar susunan grafik <InlineMath math="f(bx)" /> dan melihat lebarnya mengecil ketika <InlineMath math="b" /> membesar.

Titik di sumbu <InlineMath math="y" /> tidak bergerak karena <InlineMath math="\frac{0}{b} = 0" />, dan pengali negatif menambahkan pencerminan terhadap sumbu <InlineMath math="y" />. Jika soal menyebut faktor skala <InlineMath math="s" />, setiap koordinat <InlineMath math="x" /> dikalikan <InlineMath math="s" />, jadi persamaannya <InlineMath math="y = f\left(\frac{x}{s}\right)" /> dengan <InlineMath math="b = \frac{1}{s}" />.

Terapkan aturan itu pada parabola <InlineMath math="f(x) = x^2" /> dengan <InlineMath math="b = 2" /> dan <InlineMath math="b = \frac{1}{2}" />.

## Mengapa Pengali Besar Membuat Grafik Sempit

Ambil satu titik <InlineMath math="(x_0, y_0)" /> pada grafik <InlineMath math="f" />, jadi <InlineMath math="f(x_0) = y_0" />. Fungsi baru <InlineMath math="g(x) = f(bx)" /> mengalikan masukannya dengan <InlineMath math="b" /> lebih dulu. Agar <InlineMath math="g" /> menghasilkan keluaran yang sama, hasil kali <InlineMath math="bx" /> harus sama dengan <InlineMath math="x_0" />, sehingga <InlineMath math="x = \frac{x_0}{b}" />.

<BlockMath math="g\left(\frac{x_0}{b}\right) = f\left(b \cdot \frac{x_0}{b}\right) = f(x_0) = y_0" />

Untuk <InlineMath math="b = 2" />, keluaran yang dicapai <InlineMath math="f" /> di <InlineMath math="x = 6" /> sudah dicapai <InlineMath math="g" /> di <InlineMath math="x = 3" />. **Setiap keluaran muncul pada separuh jarak dari sumbu <InlineMath math="y" />**, sehingga lebar grafik <InlineMath math="g" /> tinggal separuh lebar grafik <InlineMath math="f" />.

Sekarang terapkan <InlineMath math="b = 2" /> pada <InlineMath math="f(x) = x^2 - 4x" />. Fungsi ini memiliki pembuat nol <InlineMath math="x = 0" /> dan <InlineMath math="x = 4" />, serta titik puncak <InlineMath math="(2, -4)" />. Ganti setiap <InlineMath math="x" /> dengan <InlineMath math="2x" />:

<BlockMath math="\begin{aligned} g(x) &= f(2x) \\ &= (2x)^2 - 4(2x) \\ &= 4x^2 - 8x \end{aligned}" />

Pemfaktoran <InlineMath math="4x^2 - 8x = 4x(x - 2)" /> memberi pembuat nol <InlineMath math="x = 0" /> dan <InlineMath math="x = 2" />, yaitu pembuat nol <InlineMath math="f" /> yang dibagi <InlineMath math="2" />. Titik puncak <InlineMath math="g" /> ada di <InlineMath math="x = \frac{8}{2 \cdot 4} = 1" /> dengan <InlineMath math="g(1) = 4 - 8 = -4" />. Jadi titik puncak <InlineMath math="(2, -4)" /> pindah ke <InlineMath math="(1, -4)" />: **tingginya tetap**, sedangkan **jaraknya ke sumbu <InlineMath math="y" /> menjadi separuh**.

## Lebar Grafik yang Berbanding Terbalik dengan Pengali

Apa yang terjadi pada lebar grafik <InlineMath math="f(bx)" /> jika <InlineMath math="b" /> menjadi dua kali? Kamu bisa membandingkan beberapa nilai <InlineMath math="b" /> sekaligus di tampilan tiga dimensi lapisan grafik, yang menyusun grafik <InlineMath math="g(x) = f(bx)" /> dari <InlineMath math="f(x) = 4(x - 1)^2" /> untuk <InlineMath math="b = \frac{1}{2}" />, <InlineMath math="1" />, <InlineMath math="2" />, dan <InlineMath math="4" />. Lapisan untuk setiap nilai <InlineMath math="b" /> diletakkan pada kedalaman <InlineMath math="z = b" />, jadi **bergerak sepanjang sumbu <InlineMath math="z" /> sama dengan memperbesar <InlineMath math="b" />**.

Grafik <InlineMath math="f" /> digambar dari titik potong sumbu <InlineMath math="y" /> di <InlineMath math="(0, 4)" />, turun ke titik puncak <InlineMath math="(1, 0)" />, lalu naik lagi ke <InlineMath math="(2, 4)" />. Pada lapisan <InlineMath math="b" />, ketiga titik itu menjadi <InlineMath math="(0, 4)" />, <InlineMath math="\left(\frac{1}{b}, 0\right)" />, dan <InlineMath math="\left(\frac{2}{b}, 4\right)" />. Tiga jejak menghubungkan titik yang bersesuaian di semua lapisan.

Seret tampilan sampai kamu melihat susunan lapisan dari atas, dengan sumbu <InlineMath math="y" /> mengarah lurus ke matamu. Jejak ujung kanan membentuk kurva <InlineMath math="x = \frac{2}{b}" />: **jika <InlineMath math="b" /> menjadi dua kali, lebar lapisan menjadi separuh**. Hasil kali <InlineMath math="b" /> dan lebar selalu <InlineMath math="2" />, jadi lebar grafik berbanding terbalik dengan pengali masukan.

Titik <InlineMath math="(0, 4)" /> meninggalkan jejak lurus di <InlineMath math="x = 0" />, karena titik di sumbu <InlineMath math="y" /> tidak ikut berpindah. Pada setiap lapisan, titik puncak berada di <InlineMath math="x = \frac{1}{b}" />, tepat di tengah antara jejak lurus itu dan ujung kanan <InlineMath math="x = \frac{2}{b}" />, sebab <InlineMath math="\frac{1}{b}" /> adalah separuh dari <InlineMath math="\frac{2}{b}" />.

Setiap lapisan tetap membentang dari ketinggian <InlineMath math="0" /> sampai <InlineMath math="4" />. Jejak titik puncak berada di bidang <InlineMath math="y = 0" />, sedangkan jejak ujung kanan dan jejak lurus tetap di ketinggian <InlineMath math="4" />. Jadi **dilatasi horizontal tidak mengubah tinggi mana pun**, dan range bagian grafik yang digambar tetap <InlineMath math="[0, 4]" />.

Pada setiap lapisan, koordinat <InlineMath math="x" /> titik puncak dan ujung kanan sama dengan <InlineMath math="1" /> dan <InlineMath math="2" /> yang dibagi <InlineMath math="b" />.

| <InlineMath math="b" /> | Titik puncak | Ujung kanan | Lebar |
| --- | --- | --- | --- |
| <InlineMath math="\frac{1}{2}" /> | <InlineMath math="(2, 0)" /> | <InlineMath math="(4, 4)" /> | <InlineMath math="4" /> |
| <InlineMath math="1" /> | <InlineMath math="(1, 0)" /> | <InlineMath math="(2, 4)" /> | <InlineMath math="2" /> |
| <InlineMath math="2" /> | <InlineMath math="\left(\frac{1}{2}, 0\right)" /> | <InlineMath math="(1, 4)" /> | <InlineMath math="1" /> |
| <InlineMath math="4" /> | <InlineMath math="\left(\frac{1}{4}, 0\right)" /> | <InlineMath math="\left(\frac{1}{2}, 4\right)" /> | <InlineMath math="\frac{1}{2}" /> |

Pada [dilatasi vertikal](/id/materi/matematika/transformasi-fungsi/dilatasi-vertikal), tinggi titik sebanding dengan faktornya, sehingga jejak titik pada lapisan serupa berupa garis lurus. Pada dilatasi horizontal, koordinat <InlineMath math="x" /> dibagi <InlineMath math="b" />, dan pembagian itulah yang membuat jejaknya melengkung.

## Faktor Skala Horizontal dan Pengali Masukan

Soal dilatasi tidak selalu menyebut pengali masukan. Ada soal yang menyebut **faktor skala** <InlineMath math="s" />: setiap koordinat <InlineMath math="x" /> dikalikan <InlineMath math="s" />, sedangkan koordinat <InlineMath math="y" /> tetap. Titik <InlineMath math="(x_0, y_0)" /> pada grafik <InlineMath math="f" /> pindah ke <InlineMath math="(s x_0, y_0)" />.

Untuk menemukan persamaannya, nyatakan koordinat lama dengan koordinat baru. Dari <InlineMath math="x = s x_0" /> diperoleh <InlineMath math="x_0 = \frac{x}{s}" />, lalu substitusikan ke <InlineMath math="y = f(x_0)" />:

<BlockMath math="y = f\left(\frac{x}{s}\right)" />

Persamaan ini sama dengan <InlineMath math="y = f(bx)" /> untuk <InlineMath math="b = \frac{1}{s}" />. Jadi **mengalikan koordinat dengan <InlineMath math="s" /> sama dengan membagi masukan dengan <InlineMath math="s" />**. Faktor skala <InlineMath math="3" /> menghasilkan grafik yang lebarnya tiga kali lebar semula, dengan persamaan <InlineMath math="y = f\left(\frac{x}{3}\right)" />.

Contohnya, setiap koordinat <InlineMath math="x" /> pada grafik <InlineMath math="y = \sqrt{x}" /> dikalikan <InlineMath math="3" />. Ganti <InlineMath math="x" /> dengan <InlineMath math="\frac{x}{3}" />:

<BlockMath math="g(x) = \sqrt{\frac{x}{3}}" />

Periksa dengan titik <InlineMath math="(4, 2)" /> pada <InlineMath math="y = \sqrt{x}" />. Titik itu pindah ke <InlineMath math="(12, 2)" />, dan memang <InlineMath math="g(12) = \sqrt{\frac{12}{3}} = \sqrt{4} = 2" />. Domain tetap <InlineMath math="[0, \infty)" /> karena <InlineMath math="\frac{x}{3} \ge 0" /> tepat ketika <InlineMath math="x \ge 0" />.

Di tampilan tiga dimensi lapisan grafik, grafik <InlineMath math="y = \sqrt{\frac{x}{s}}" /> untuk <InlineMath math="s = 1" />, <InlineMath math="2" />, dan <InlineMath math="3" /> diletakkan pada kedalaman <InlineMath math="z = s" />. Titik setinggi <InlineMath math="2" /> pada lapisan <InlineMath math="s" /> berada di <InlineMath math="x = 4s" />, jadi pada lapisan <InlineMath math="s = 3" /> kamu menemukan titik <InlineMath math="(12, 2)" /> yang baru saja kamu periksa.

Kedua jejak lurus karena koordinat <InlineMath math="x" /> setiap titik dikalikan <InlineMath math="s" />: **lebar grafik sebanding dengan faktor skala**. Bandingkan dengan jejak <InlineMath math="x = \frac{2}{b}" /> pada lapisan grafik <InlineMath math="f(bx)" /> yang melengkung, karena di sana koordinat <InlineMath math="x" /> dibagi pengali masukan <InlineMath math="b = \frac{1}{s}" />.

[Dilatasi](/id/materi/matematika/transformasi-geometri/dilatasi) terhadap titik asal mengalikan kedua koordinat dengan faktor yang sama, sehingga besar setiap sudut tetap dan bangun hasilnya sebangun dengan bangun semula. Dilatasi horizontal hanya mengalikan koordinat <InlineMath math="x" />, jadi **sudut pada grafik bisa berubah**. Kedua kaki grafik <InlineMath math="y = |x|" /> saling tegak lurus, sedangkan kaki grafik <InlineMath math="y = |2x| = 2|x|" /> memiliki kemiringan <InlineMath math="2" /> dan <InlineMath math="-2" />, sehingga sudut di titik puncaknya menyempit menjadi sekitar <InlineMath math="53^\circ" />.

## Bagian Grafik yang Berpindah dan yang Tetap

Untuk <InlineMath math="b > 0" />, **setiap bagian yang ditentukan oleh nilai <InlineMath math="x" /> dibagi <InlineMath math="b" />**, sedangkan setiap bagian yang ditentukan oleh tinggi tetap sama.

| Bagian grafik | Pada <InlineMath math="f(bx)" /> | Alasan |
| --- | --- | --- |
| Titik <InlineMath math="(x_0, y_0)" /> | <InlineMath math="\left(\frac{x_0}{b}, y_0\right)" /> | tinggi tetap, <InlineMath math="x" /> dibagi <InlineMath math="b" /> |
| Pembuat nol <InlineMath math="x_0" /> | <InlineMath math="\frac{x_0}{b}" /> | pembuat nol adalah nilai <InlineMath math="x" /> |
| Domain <InlineMath math="[c, d]" /> | <InlineMath math="\left[\frac{c}{b}, \frac{d}{b}\right]" /> | domain berisi nilai <InlineMath math="x" /> |
| Asimtot vertikal <InlineMath math="x = x_1" /> | <InlineMath math="x = \frac{x_1}{b}" /> | garis tegak ditentukan oleh nilai <InlineMath math="x" /> |
| Range | tetap | range berisi tinggi |
| Titik potong sumbu <InlineMath math="y" /> | tetap <InlineMath math="(0, f(0))" /> | <InlineMath math="\frac{0}{b} = 0" /> |
| Asimtot horizontal <InlineMath math="y = y_1" /> | tetap | garis mendatar ditentukan oleh tinggi |

## Pengali Negatif Menambahkan Pencerminan

Aturan <InlineMath math="(x_0, y_0) \longmapsto \left(\frac{x_0}{b}, y_0\right)" /> tetap berlaku ketika <InlineMath math="b < 0" />. Membagi dengan bilangan negatif membalik tanda koordinat <InlineMath math="x" />, jadi grafik meregang atau memampat dengan faktor <InlineMath math="\frac{1}{|b|}" /> lalu **dicerminkan terhadap sumbu <InlineMath math="y" />**. Untuk <InlineMath math="b = -1" />, yang tersisa hanya pencerminan <InlineMath math="y = f(-x)" />, yaitu [refleksi horizontal](/id/materi/matematika/transformasi-fungsi/refleksi-horizontal).

Pada fungsi genap, pencerminan itu tidak terlihat. Untuk <InlineMath math="f(x) = x^2 + 1" /> dan <InlineMath math="b = -2" />, berlaku <InlineMath math="f(-2x) = 4x^2 + 1 = f(2x)" />, jadi grafiknya sama dengan hasil pemampatan saja. Titik <InlineMath math="(2, 5)" /> tetap pindah ke sisi kiri, ke <InlineMath math="(-1, 5)" />, dan titik <InlineMath math="(-1, 2)" /> pindah ke sisi kanan, ke <InlineMath math="\left(\frac{1}{2}, 2\right)" />.

Satu-satunya nilai yang tidak boleh dipakai adalah <InlineMath math="b = 0" />. Untuk <InlineMath math="b = 0" />, setiap masukan berubah menjadi <InlineMath math="0" />, jadi <InlineMath math="f(0 \cdot x) = f(0)" /> untuk setiap <InlineMath math="x" />, dan grafiknya hanya berupa garis mendatar <InlineMath math="y = f(0)" /> jika <InlineMath math="f(0)" /> terdefinisi. Aturan <InlineMath math="\frac{x_0}{b}" /> juga tidak bisa dipakai karena pembagian dengan nol tidak terdefinisi.

Pencerminan pada <InlineMath math="b < 0" /> juga menukar urutan batas domain. Jika domain <InlineMath math="f" /> adalah <InlineMath math="[c, d]" /> dan <InlineMath math="b < 0" />, batas kiri domain baru berasal dari batas kanan domain lama:

<BlockMath math="[c, d] \longmapsto \left[\frac{d}{b},\ \frac{c}{b}\right]" />

## Kesalahan Membaca Faktor Pengali

Untuk menemukan kesalahan seperti di tabel ini, ambil satu titik yang sudah kamu ketahui, **hitung bayangannya pada grafik <InlineMath math="f(bx)" />**, lalu cocokkan bayangan itu dengan jawabanmu.

| Kesalahan | Mengapa keliru | Cara memeriksa |
| --- | --- | --- |
| Membaca <InlineMath math="f(2x)" /> sebagai grafik dua kali lebih lebar | Masukan dikali <InlineMath math="2" />, jadi setiap keluaran muncul pada separuh jarak | Pembuat nol <InlineMath math="x_0" /> harus menjadi <InlineMath math="\frac{x_0}{2}" /> |
| Membagi tinggi titik menjadi <InlineMath math="\left(x_0, \frac{y_0}{b}\right)" /> | Pengali di dalam <InlineMath math="f" /> hanya mengubah masukan | Substitusikan <InlineMath math="x = \frac{x_0}{b}" /> dan pastikan hasilnya <InlineMath math="y_0" /> |
| Menulis <InlineMath math="f(3x)" /> untuk faktor skala <InlineMath math="3" /> | Faktor skala <InlineMath math="s" /> berarti <InlineMath math="b = \frac{1}{s}" /> | Titik <InlineMath math="(x_0, y_0)" /> harus menjadi <InlineMath math="(3x_0, y_0)" /> |
| Membaca <InlineMath math="f(2x - 6)" /> sebagai geser <InlineMath math="6" /> satuan | <InlineMath math="2x - 6 = 2(x - 3)" />, jadi pergeserannya <InlineMath math="3" /> satuan | Faktorkan pengali dari dalam kurung lebih dulu |
| Lupa menukar batas domain saat <InlineMath math="b < 0" /> | Pembagian dengan bilangan negatif membalik urutan | Batas kiri domain baru harus lebih kecil dari batas kanannya |

Persamaan <InlineMath math="f(2x - 6) = f(2(x - 3))" /> berarti grafik dimampatkan dengan faktor <InlineMath math="\frac{1}{2}" /> lalu digeser <InlineMath math="3" /> satuan ke kanan, sehingga titik <InlineMath math="(x_0, y_0)" /> berakhir di <InlineMath math="\left(\frac{x_0}{2} + 3, y_0\right)" />. Jika urutannya dibalik, yaitu digeser <InlineMath math="3" /> satuan ke kanan dulu lalu dimampatkan, persamaannya menjadi <InlineMath math="f(2x - 3)" /> dan titik yang sama berakhir di <InlineMath math="\left(\frac{x_0 + 3}{2}, y_0\right)" />. Pada [kombinasi transformasi fungsi](/id/materi/matematika/transformasi-fungsi/kombinasi-transformasi-fungsi), kamu menentukan urutan langkah dari bentuk persamaan, seperti saat memfaktorkan <InlineMath math="f(2x - 6)" /> tadi.

## Latihan

Mulailah setiap soal dengan **menentukan nilai <InlineMath math="b" />**, karena pengali itulah yang membagi koordinat <InlineMath math="x" />. Soal 1 cukup mengganti <InlineMath math="x" /> dengan <InlineMath math="3x" />, sedangkan pada soal 4 kamu harus menemukan <InlineMath math="b" /> dari satu titik pada grafik.

1. Diberikan <InlineMath math="f(x) = x^2 - 2x - 3" />. Tentukan persamaan <InlineMath math="f(3x)" /> beserta pembuat nolnya.
2. Setiap titik <InlineMath math="(x, y)" /> pada grafik <InlineMath math="y = \sqrt{x}" /> dipindahkan ke <InlineMath math="(4x, y)" />. Tentukan persamaan grafik barunya, lalu periksa dengan satu titik.
3. Fungsi <InlineMath math="f" /> memiliki domain <InlineMath math="[-2, 8]" />. Tentukan domain <InlineMath math="g(x) = f\left(-\frac{x}{2}\right)" />.
4. Grafik <InlineMath math="g(x) = 2^{bx}" /> melalui titik <InlineMath math="(6, 8)" />. Tentukan <InlineMath math="b" />, lalu jelaskan dilatasi yang mengubah <InlineMath math="y = 2^x" /> menjadi grafik <InlineMath math="g" />.

### Pembahasan

**Soal 1**. Pengali masukannya <InlineMath math="b = 3" />, jadi ganti setiap <InlineMath math="x" /> pada <InlineMath math="f" /> dengan <InlineMath math="3x" />:

<BlockMath math="\begin{aligned} f(3x) &= (3x)^2 - 2(3x) - 3 \\ &= 9x^2 - 6x - 3 \\ &= 3(3x + 1)(x - 1) \end{aligned}" />

Dari bentuk faktor, pembuat nolnya <InlineMath math="x = -\frac{1}{3}" /> dan <InlineMath math="x = 1" />. Aturan dilatasi memberi pemeriksaan kedua: <InlineMath math="f(x) = (x + 1)(x - 3)" /> punya pembuat nol <InlineMath math="-1" /> dan <InlineMath math="3" />, dan **keduanya dibagi <InlineMath math="3" />** menjadi tepat <InlineMath math="-\frac{1}{3}" /> dan <InlineMath math="1" />.

<LineEquation
  showZAxis={false}
  title={<>Parabola <InlineMath math="f(x) = x^2 - 2x - 3" /> dan <InlineMath math="F(x) = f(3x)" /></>}

  cameraPosition={[1, 0.5, 12]}
  cameraTarget={[1, 0.5, 0]}
  data={(() => {
    // f(x) = x^2 - 2x - 3 stays inside the frame y <= 12 for -3 <= x <= 5.
    // F(x) = f(3x) reaches the height f(t) at x = t / 3, so F reuses the inputs t of f.
    // Sample 480 is t = -1 and sample 1440 is t = 3, the zeros of f.
    const f = (x) => x * x - 2 * x - 3;

    const t = Array.from({ length: 1921 }, (_, i) => -3 + i / 240);

        showPoints: true,
        pointIndices: [480, 1440],
        labels: [{ text: <InlineMath math="f" />, at: 1680, offset: [0.3, 0, 0], anchorX: "left" }],
      },
      {
        points: t.map((s) => s / 3).map((x) => ({ x, y: F(x), z: 0 })),
        smooth: false,
        color: "#0d9488",
        showPoints: true,
        pointIndices: [480, 1440],
        labels: [{ text: <InlineMath math="F" />, at: 1560, offset: [0.25, 0, 0], anchorX: "left" }],
      },
      {
        points: [
          { x: 1, y: f(1), z: 0 },
          { x: 1 / 3, y: F(1 / 3), z: 0 },

        color: "#d97706",
        showPoints: false,
        cone: { position: "end", size: 0.25 },
      },
    ];
  })()}

**Soal 2**. Setiap koordinat <InlineMath math="x" /> dikalikan <InlineMath math="4" />, jadi **faktor skalanya <InlineMath math="s = 4" />** dan <InlineMath math="b = \frac{1}{4}" />. Ganti <InlineMath math="x" /> dengan <InlineMath math="\frac{x}{4}" />:

<BlockMath math="y = \sqrt{\frac{x}{4}} = \frac{\sqrt{x}}{2}" />

Bentuk kedua berlaku karena <InlineMath math="\sqrt{\frac{x}{4}} = \frac{\sqrt{x}}{\sqrt{4}}" /> untuk <InlineMath math="x \ge 0" />. Periksa dengan <InlineMath math="(1, 1)" /> pada <InlineMath math="y = \sqrt{x}" />: titik itu pindah ke <InlineMath math="(4, 1)" />, dan <InlineMath math="\frac{\sqrt{4}}{2} = 1" />. Bentuk <InlineMath math="\frac{\sqrt{x}}{2}" /> juga bisa dibaca sebagai dilatasi vertikal dengan faktor <InlineMath math="\frac{1}{2}" />: titik <InlineMath math="(4, 2)" /> turun tegak ke <InlineMath math="(4, 1)" />. Jadi untuk fungsi akar kedua dilatasi itu menghasilkan grafik yang sama.

<LineEquation
  showZAxis={false}
  title={<>Kurva <InlineMath math="y = \sqrt{x}" /> dan <InlineMath math="y = \sqrt{\tfrac{x}{4}}" /></>}
  description={<>Panah mendatar membawa <InlineMath math="(1, 1)" /> ke <InlineMath math="(4, 1)" />, dan panah tegak membawa <InlineMath math="(4, 2)" /> ke titik yang sama.</>}
  cameraPosition={[2.5, 1.2, 6.4]}
  cameraTarget={[2.5, 1.2, 0]}
  data={(() => {
    // y = sqrt(x) is sampled by its heights r: the point of height r sits at x = r^2, which keeps
    // the samples dense where the curve leaves the y-axis vertically. The frame x <= 9 stops it at r = 3.
    // Moving every point (x, y) to (4x, y) gives y = sqrt(x / 4); its point of height r sits at
    // x = 4 r^2, and it reaches the frame side x = 9 at r = 3/2.
    const g = (x) => Math.sqrt(x);
    const G = (x) => g(x / 4);
    const r = Array.from({ length: 1201 }, (_, i) => i / 400);
    return [
      {
        points: r.map((y) => y * y).map((x) => ({ x, y: g(x), z: 0 })),
        smooth: false,
        color: "#ea580c",
        showPoints: false,
        labels: [{ text: <InlineMath math="\sqrt{x}" />, at: 880, offset: [-0.2, 0.3, 0], anchorX: "right" }],
      },
      {
        points: r.slice(0, 601).map((y) => 4 * y * y).map((x) => ({ x, y: G(x), z: 0 })),
        smooth: false,
        color: "#0d9488",
        showPoints: false,
        labels: [{ text: <InlineMath math="\sqrt{\tfrac{x}{4}}" />, at: 460, offset: [0, -0.45, 0], anchorX: "right" }],
      },
      {
        points: [
          { x: 1, y: g(1), z: 0 },
          { x: 4, y: G(4), z: 0 },
        ],
        smooth: false,
        color: "#d97706",
        showPoints: false,
        cone: { position: "end", size: 0.2 },
      },
      {
        points: [
          { x: 4, y: g(4), z: 0 },
          { x: 4, y: G(4), z: 0 },
        ],
        smooth: false,
        color: "#d97706",
        showPoints: false,
        cone: { position: "end", size: 0.2 },
      },
    ];
  })()}
/>

**Soal 3**. Pengalinya <InlineMath math="b = -\frac{1}{2}" />, jadi urutan batas domain akan berbalik. Nilai <InlineMath math="g(x)" /> terdefinisi ketika masukan <InlineMath math="-\frac{x}{2}" /> berada di domain <InlineMath math="f" />. Kalikan pertidaksamaan dengan <InlineMath math="-2" /> dan **balik arah tandanya**:

<BlockMath math="\begin{aligned} -2 &\le -\frac{x}{2} \le 8 \\ 4 &\ge x \ge -16 \end{aligned}" />

Rumus <InlineMath math="\left[\frac{d}{b}, \frac{c}{b}\right] = \left[\frac{8}{-1/2}, \frac{-2}{-1/2}\right] = [-16, 4]" /> memberi selang yang sama. Periksa kedua batas: <InlineMath math="x = -16" /> memberi masukan <InlineMath math="8" />, dan <InlineMath math="x = 4" /> memberi masukan <InlineMath math="-2" />. Keduanya tepat batas domain <InlineMath math="f" />, jadi domain <InlineMath math="g" /> adalah <InlineMath math="[-16, 4]" />.

**Soal 4**. Substitusikan titik <InlineMath math="(6, 8)" /> ke <InlineMath math="g(x) = 2^{bx}" />:

<BlockMath math="\begin{aligned} 2^{6b} &= 8 = 2^3 \\ 6b &= 3 \\ b &= \tfrac{1}{2} \end{aligned}" />

Fungsi <InlineMath math="2^t" /> selalu naik, jadi <InlineMath math="2^{6b} = 2^3" /> hanya berlaku jika <InlineMath math="6b = 3" />. Karena <InlineMath math="0 < b < 1" />, grafik <InlineMath math="y = 2^x" /> diregangkan menjauhi sumbu <InlineMath math="y" /> dengan faktor <InlineMath math="\frac{1}{b} = 2" />: **setiap jarak ke sumbu <InlineMath math="y" /> menjadi dua kali lipat**. Periksa: titik <InlineMath math="(3, 8)" /> pada <InlineMath math="y = 2^x" /> pindah ke <InlineMath math="\left(\frac{3}{1/2}, 8\right) = (6, 8)" />, tepat titik yang diberikan. Titik potong <InlineMath math="(0, 1)" /> dan asimtot <InlineMath math="y = 0" /> tetap di tempatnya.

<LineEquation
  showZAxis={false}
  title={<>Kurva <InlineMath math="y = 2^x" /> dan <InlineMath math="g(x) = 2^{x/2}" /></>}
  description={<>Panah membawa <InlineMath math="(3, 8)" /> ke <InlineMath math="(6, 8)" />, jadi jaraknya ke sumbu <InlineMath math="y" /> menjadi dua kali lipat, sedangkan <InlineMath math="(0, 1)" /> tetap.</>}
  cameraPosition={[1.5, 4.2, 11]}
  cameraTarget={[1.5, 4.2, 0]}
  data={(() => {
    // f(x) = 2^x stays inside the frame x >= -10, y <= 16 up to x = 4, and g(x) = f(x / 2) up to x = 8.
    // g reaches the height f(t) at x = 2t, so it reuses the inputs t of f from -5 to 4.
    const f = (x) => 2 ** x;
    const g = (x) => f(x / 2);
    const t = Array.from({ length: 897 }, (_, i) => -10 + i / 64);
    return [
      {
        points: t.map((x) => ({ x, y: f(x), z: 0 })),
        smooth: false,
        color: "#ea580c",
        showPoints: false,
        labels: [{ text: <InlineMath math="2^x" />, at: 832, offset: [-0.3, 0, 0], anchorX: "right" }],
      },
      {
        points: t.filter((s) => s >= -5).map((s) => 2 * s).map((x) => ({ x, y: g(x), z: 0 })),
        smooth: false,
        color: "#0d9488",
        showPoints: false,
        labels: [{ text: <InlineMath math="g" />, at: 448, offset: [0.3, -0.3, 0], anchorX: "left" }],
      },
      {
        points: [
          { x: 3, y: f(3), z: 0 },
          { x: 6, y: g(6), z: 0 },
        ],
        smooth: false,
        color: "#d97706",
        showPoints: false,
        cone: { position: "end", size: 0.3 },
      },
      {
        points: [{ x: 0, y: f(0), z: 0 }],
        smooth: false,
        color: "#64748b",
        showPoints: true,
      },
    ];
  })()}
/>
