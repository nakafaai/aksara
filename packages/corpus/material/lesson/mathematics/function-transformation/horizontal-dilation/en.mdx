## Changing the Width of a Function Graph

Horizontal dilation changes how wide a function graph looks along the <InlineMath math="x" />-axis without changing any of its heights. Stretching the graph makes it wider, and compressing it makes the graph narrower, while every point keeps its original <InlineMath math="y" /> value.

If you have a function <InlineMath math="f(x)" />, then horizontal dilation produces a new function <InlineMath math="g(x) = f(kx)" />. Here <InlineMath math="k \ne 0" /> is the number that multiplies the input, and the horizontal scale of the new graph is <InlineMath math="s = \frac{1}{|k|}" />.

### How the Input Factor Changes the Width

For any function <InlineMath math="f(x)" /> and a nonzero factor <InlineMath math="k" /> that multiplies the input, horizontal dilation is defined as:

<MathContainer>
  <BlockMath math="g(x) = f(kx)" />
  <BlockMath math="s = \frac{1}{|k|}" />
</MathContainer>

The factor <InlineMath math="k" /> decides what happens to the width:
- If <InlineMath math="k > 1" />, the graph is compressed to <InlineMath math="\frac{1}{k}" /> of its original width
- If <InlineMath math="0 < k < 1" />, the graph is stretched to <InlineMath math="\frac{1}{k}" /> times its original width
- If <InlineMath math="k = 1" />, the graph does not change
- If <InlineMath math="k < 0" />, the graph is also reflected across the <InlineMath math="y" />-axis

The value <InlineMath math="k = 0" /> is excluded: <InlineMath math="f(0x) = f(0)" /> would be constant wherever it is defined. The graph would collapse to one horizontal line.

The reciprocal matters here. A larger factor that multiplies the input makes the graph <Highlight>narrower, not wider</Highlight>, because the horizontal scale is <InlineMath math="\frac{1}{|k|}" />.

## What Changes and What Stays

Once you know whether the graph stretches or compresses, you still need to know which values move. Horizontal dilation divides every horizontal coordinate by the factor <InlineMath math="k" /> that multiplies the input, so positions along the <InlineMath math="x" />-axis change while heights stay the same.

Take a point <InlineMath math="(a, b)" /> on the graph of <InlineMath math="f(x)" />. The matching point on the graph of <InlineMath math="f(kx)" /> is <InlineMath math="(\frac{a}{k}, b)" />. The <InlineMath math="y" /> value stays at <InlineMath math="b" /> because horizontal dilation never changes a height.

| Part of the function | Before the dilation | After the dilation by <InlineMath math="k > 0" /> |
| --- | --- | --- |
| Point <InlineMath math="(a, b)" /> | On the graph of <InlineMath math="f(x)" /> | Moves to <InlineMath math="(\frac{a}{k}, b)" /> |
| Domain <InlineMath math="[c, d]" /> | The original interval | Becomes <InlineMath math="[\frac{c}{k}, \frac{d}{k}]" /> |
| Range | The original output values | The same output values as before |
| <InlineMath math="x" />-intercept | At <InlineMath math="x = x_0" /> | Moves to <InlineMath math="x = \frac{x_0}{k}" /> |
| <InlineMath math="y" />-intercept | At <InlineMath math="x = 0" /> | Stays at <InlineMath math="x = 0" /> |

The domain shrinks or grows together with the graph, because it lists the allowed values of <InlineMath math="x" />. The range keeps its original values, because the height of the graph at each point never changes. A [horizontal translation](/en/subjects/mathematics/function-transformation/horizontal-translation) moves those coordinates instead of dividing them.

## Exercises

The three problems below use the width rule you have just learned. Each one multiplies the input by a stated factor, so watch whether that factor is greater than one, between zero and one, or negative. Try them without the answer key first, then compare your steps with the worked answers.

2. The graph of the function <InlineMath math="g(x) = \sqrt{x}" /> undergoes horizontal dilation with input factor <InlineMath math="\frac{1}{2}" />. Determine the equation of the resulting function, then determine the domain of that function.
