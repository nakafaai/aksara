## Basic Concepts of Horizontal Dilation

Horizontal dilation changes a function graph's width without changing its heights. Picture a photograph pulled outward from its left and right edges or pressed inward toward its center.

If we have a function <InlineMath math="f(x)" />, then horizontal dilation produces a new function <InlineMath math="g(x) = f(kx)" />. Here, <InlineMath math="k \ne 0" /> is the input multiplier. The actual horizontal scale magnitude is <InlineMath math="s = \frac{1}{|k|}" />.

### Rules of Horizontal Dilation

For any function <InlineMath math="f(x)" /> and nonzero input multiplier <InlineMath math="k" />, horizontal dilation is defined as:

<MathContainer>
  <BlockMath math="g(x) = f(kx)" />
  <BlockMath math="s = \frac{1}{|k|}" />
</MathContainer>

The input multiplier <InlineMath math="k" /> determines the transformation:
- If <InlineMath math="k > 1" />, the graph is compressed to <InlineMath math="\frac{1}{k}" /> of its original width
- If <InlineMath math="0 < k < 1" />, the graph is stretched to <InlineMath math="\frac{1}{k}" /> times its original width
- If <InlineMath math="k = 1" />, the graph does not change
- If <InlineMath math="k < 0" />, the graph is also reflected across the <InlineMath math="y" />-axis

The value <InlineMath math="k = 0" /> is excluded: <InlineMath math="f(0x) = f(0)" /> would be constant wherever it is defined. The graph would collapse to one horizontal line.

The reciprocal matters: a larger input multiplier makes the graph narrower, while the horizontal scale itself is <InlineMath math="\frac{1}{|k|}" />.

## Important Properties of Horizontal Dilation

### Effect on Coordinate Points

If point <InlineMath math="(a, b)" /> is on the graph of <InlineMath math="f(x)" />, then the corresponding point on the graph of <InlineMath math="f(kx)" /> is <InlineMath math="(\frac{a}{k}, b)" />.

### Domain and Range

- **Domain**: Its horizontal coordinates are divided by the input multiplier <InlineMath math="k" />
- **Range**: Does not change after horizontal dilation

If the domain of the original function is <InlineMath math="[c, d]" />, then the domain after horizontal dilation with input multiplier <InlineMath math="k > 0" /> becomes <InlineMath math="[\frac{c}{k}, \frac{d}{k}]" />.

### Axis Intercepts

- **<InlineMath math="x" />-intercept**: Its coordinate is divided by the input multiplier
- **<InlineMath math="y" />-intercept**: Does not change
