## Mencerminkan Grafik terhadap Sumbu Vertikal

Refleksi horizontal mencerminkan grafik fungsi terhadap sumbu <InlineMath math="y" />. Seperti pada cermin vertikal, setiap titik tetap berada pada <Highlight>ketinggian yang sama</Highlight> dan berpindah <Highlight>sejauh jarak yang sama ke sisi berlawanan</Highlight>.

Jika kita memiliki fungsi <InlineMath math="f(x)" />, maka refleksi horizontal menghasilkan fungsi baru <InlineMath math="g(x) = f(-x)" /> yang merupakan bayangan dari fungsi asli terhadap sumbu <InlineMath math="y" />.

### Aturan Refleksi Horizontal

Untuk setiap fungsi <InlineMath math="f(x)" />, refleksi horizontal didefinisikan sebagai:

<BlockMath math="g(x) = f(-x)" />

Transformasi ini mengubah setiap titik <InlineMath math="(x, y)" /> pada grafik asli menjadi <InlineMath math="(-x, y)" /> pada grafik hasil refleksi.

Titik pada **garis cermin tetap di tempatnya**. Untuk titik di luar garis cermin, koordinat yang tegak lurus garis cermin berubah tanda. Jika dicerminkan dua kali, titik kembali ke posisi semula.

<BlockMath math="g(-x)=f(-(-x))=f(x)" />

## Nilai Mana yang Berubah pada Refleksi Horizontal

Refleksi horizontal membalik grafik terhadap sumbu <InlineMath math="y" />, jadi sumbu <InlineMath math="y" /> berperan sebagai garis cermin. Setiap titik pada grafik asli mempertahankan jaraknya ke garis cermin, tetapi berpindah ke sisi yang berlawanan.

Ambil titik <InlineMath math="(a, b)" /> pada grafik <InlineMath math="f(x)" />. Titik yang bersesuaian pada grafik <InlineMath math="f(-x)" /> adalah <InlineMath math="(-a, b)" />. Nilai <InlineMath math="y" /> tetap <InlineMath math="b" />, dan hanya tanda koordinat <InlineMath math="x" /> yang berbalik.

| Bagian fungsi | Sebelum refleksi | Setelah refleksi |
| --- | --- | --- |
| Titik <InlineMath math="(a, b)" /> | Pada grafik <InlineMath math="f(x)" /> | Berpindah ke <InlineMath math="(-a, b)" /> |
| Domain <InlineMath math="[c, d]" /> | Selang asli | Menjadi <InlineMath math="[-d, -c]" /> |
| Range | Nilai keluaran asli | Tetap sama seperti semula |
| Titik potong sumbu <InlineMath math="y" /> | Di <InlineMath math="x = 0" /> | Tetap di <InlineMath math="x = 0" /> |

<Highlight>Domain berbalik ke sisi yang berlawanan</Highlight> karena domain memuat batas nilai <InlineMath math="x" />, dan nilai itu berubah tanda. Range tetap karena tinggi grafik di setiap titik tidak berubah. [Refleksi vertikal](/id/materi/matematika/transformasi-fungsi/refleksi-vertikal) membalik tinggi grafik dan membiarkan koordinat <InlineMath math="x" /> tetap.

## Mengubah Pertumbuhan Eksponensial menjadi Peluruhan

Pada fungsi eksponensial <InlineMath math="f(x) = 2^x" />, refleksi mengubah pertumbuhan dari kiri ke kanan menjadi peluruhan dari kiri ke kanan.

<LineEquation

  data={[
    {

      }),
      color: "#4f46e5",
      labels: [{ text: <InlineMath math="f(x)=2^x" />, offset: [3, 1, 0], at: 480 }],
      showPoints: false,
    },
    {
      smooth: false,
      points: Array.from({ length: 115 }, (_, pointIndex) => {

        return { x, y: Math.pow(2, -x), z: 0 };
      }),
      color: "#059669",

  ]}

Pada fungsi eksponensial:
- **Asimtot horizontal** tetap di <InlineMath math="y = 0" /> untuk kedua fungsi
- Titik potong dengan sumbu <InlineMath math="y" /> tetap sama di <InlineMath math="(0, 1)" />
- Fungsi yang semula naik menjadi turun setelah refleksi

## Refleksi Horizontal pada Fungsi Akar

Fungsi akar kuadrat menunjukkan bahwa refleksi juga memindahkan domain yang terbatas.

<LineEquation
  title={<>Refleksi Horizontal Fungsi Akar <InlineMath math="f(x) = \sqrt{x}" /></>}
  description="Kurva akar kuadrat direfleksikan menghasilkan kurva yang membuka ke arah berlawanan."
  cameraPosition={[0, 3, 16]}
  cameraTarget={[0, 3, 0]}
  data={[
    {
      smooth: false,
      points: (() => {
        const parameters = Array.from({ length: 121 }, (_, i) => i / 40);
        parameters.push(1.5811388300841898);
        return parameters
          .sort((a, b) => a - b)
          .map((t) => {
            const x = t * t;
            return { x, y: t, z: 0 };
          });
      })(),
      color: "#0891b2",
      labels: [{ at: 64, text: <InlineMath math="f(x)=\sqrt{x}" />, offset: [1, 1.5, 0] }],
      showPoints: false,
    },
    {
      smooth: false,
      points: (() => {
        const parameters = Array.from({ length: 121 }, (_, i) => i / 40);
        parameters.push(1.5811388300841898);
        return parameters
          .sort((a, b) => a - b)
          .map((t) => {
            const x = -t * t;
            return { x, y: t, z: 0 };
          });
      })(),
      color: "#e11d48",
      labels: [{ text: <InlineMath math="g(x)=\sqrt{-x}" />, offset: [-1, 1.5, 0], at: 64 }],
      showPoints: false,
    },
  ]}
  showZAxis={false}
/>

Grafik tersebut menegaskan:
- Domain fungsi asli <InlineMath math="f(x) = \sqrt{x}" /> adalah <InlineMath math="[0, \infty)" />
- Domain fungsi hasil refleksi <InlineMath math="g(x) = \sqrt{-x}" /> adalah <InlineMath math="(-\infty, 0]" />
- Kedua kurva bertemu di **titik asal** <InlineMath math="(0, 0)" />

## Latihan

Tiga soal berikut memakai aturan cermin yang baru saja kamu pelajari. Setiap soal mengganti masukan <InlineMath math="x" /> menjadi <InlineMath math="-x" />, jadi semua hasilnya muncul di sisi yang berlawanan dari sumbu <InlineMath math="y" />. Kerjakan dulu tanpa melihat kunci, lalu bandingkan langkahmu dengan pembahasan di bawah.

1. Diberikan fungsi <InlineMath math="f(x) = x^2 + 3x + 2" />. Tentukan persamaan fungsi hasil refleksi horizontal.

2. Grafik fungsi <InlineMath math="g(x) = 3^x + 1" /> direfleksikan terhadap sumbu <InlineMath math="y" />. Tentukan persamaan fungsi hasilnya, lalu tentukan domain fungsi tersebut.

3. Fungsi <InlineMath math="h(x) = |x + 2|" /> mengalami refleksi horizontal. Tentukan **titik puncak** dari fungsi hasil refleksi.

### Domain Eksponensial

Tanda negatif pada masukan **tidak membatasi bilangan real**, sehingga eksponensial tetap terdefinisi untuk semua masukan real.

Persamaan fungsi hasil refleksi:

- Refleksi horizontal: <InlineMath math="G(x) = g(-x) = 3^{-x} + 1" />
- Domain setelah refleksi: Tetap <InlineMath math="(-\infty, \infty)" /> karena fungsi eksponensial terdefinisi untuk semua bilangan real

### Titik Puncak Nilai Mutlak

<BlockMath math="-x+2=0\;\Rightarrow\;x=2,\qquad H(2)=0" />

Nilai mutlak mencapai minimum ketika **isi nilai mutlak nol**. Selesaikan persamaan itu untuk memperoleh koordinat mendatar titik puncak.

Fungsi asli <InlineMath math="h(x) = |x + 2|" /> memiliki titik puncak di <InlineMath math="(-2, 0)" />.
Setelah refleksi horizontal: <InlineMath math="H(x) = |-x + 2| = |-(x - 2)| = |x - 2|" />, titik puncak menjadi <InlineMath math="(2, 0)" />.
