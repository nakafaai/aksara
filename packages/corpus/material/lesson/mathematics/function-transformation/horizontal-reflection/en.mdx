## Mirroring a Graph Across the y-Axis

A **horizontal reflection** across the y-axis turns <InlineMath math="y = f(x)" /> into <InlineMath math="y = f(-x)" />. Every point <InlineMath math="(x_0, y_0)" /> moves to <InlineMath math="(-x_0, y_0)" />, so **the height stays the same** and the graph swaps its left and right sides. Points that lie on the y-axis do not move at all. The first graph shows the parabola <InlineMath math="x^2 + 3x + 2" /> beside its mirror image, which is the graph of <InlineMath math="x^2 - 3x + 2" />, so you can compare the zeros on both sides.

<BlockMath math="(x_0, y_0) \longmapsto (-x_0,\ y_0)" />

The formula confirms the picture. The new function <InlineMath math="g(x) = f(-x)" /> returns <InlineMath math="f(x_0)" /> when its input is <InlineMath math="-x_0" />, because <InlineMath math="g(-x_0) = f(-(-x_0)) = f(x_0)" />. Each point of <InlineMath math="f" /> therefore has a partner at the same height on the opposite side of the y-axis.

Put the graph of <InlineMath math="y = \sqrt{x}" /> in the plane <InlineMath math="z = 0" />, and turn the plane around the y-axis. A point <InlineMath math="(x, y, 0)" /> travels along a half circle and comes to rest at <InlineMath math="(-x, y, 0)" />. Use the controls to turn the scene and follow the three paths drawn on it.

Each path keeps the same height the whole time, because the turn is around the vertical axis. That is why the mirror image of <InlineMath math="y = \sqrt{x}" /> is the graph of <InlineMath math="y = \sqrt{-x}" />. Points on the y-axis stay where they are, because a half turn about that axis leaves them fixed.

## Replacing Every Input With Its Negative

Let <InlineMath math="f(x) = x^2 + 3x + 2 = (x + 1)(x + 2)" />. To reflect the graph, **replace every** <InlineMath math="x" /> with <InlineMath math="-x" />. Keep the brackets, because <InlineMath math="(-x)^2" /> is not the same as <InlineMath math="-x^2" />:

<BlockMath math="\begin{aligned} g(x) &= f(-x) \\ &= (-x)^2 + 3(-x) + 2 \\ &= x^2 - 3x + 2 \\ &= (x - 1)(x - 2) \end{aligned}" />

Check the zeros. The zeros of <InlineMath math="f" /> are <InlineMath math="-1" /> and <InlineMath math="-2" />, and the zeros of <InlineMath math="g" /> are <InlineMath math="1" /> and <InlineMath math="2" />, so each zero changes its sign. The vertex of <InlineMath math="f" /> is at <InlineMath math="x = -\tfrac{3}{2}" />, and that of <InlineMath math="g" /> is at <InlineMath math="x = \tfrac{3}{2}" />, with the same height <InlineMath math="-\tfrac{1}{4}" />. Finally, the value <InlineMath math="g(1) = 1 - 3 + 2 = 0" /> equals <InlineMath math="f(-1) = 0" />, which is the point you expect.

## Growth That Becomes Decay

The mirror graph decreases, so **growth becomes decay**. The horizontal asymptote <InlineMath math="y = 1" /> stays where it is, because a horizontal reflection never changes a height. The y-intercept <InlineMath math="(0, 2)" /> also stays, because the input <InlineMath math="0" /> is fixed by the reflection.

## Even and Odd Functions Under the Mirror

Some functions are unchanged by the mirror. A function is **even** when <InlineMath math="f(-x) = f(x)" />, as with <InlineMath math="x^2" /> and <InlineMath math="|x|" />. Its graph is symmetric about the y-axis, so each mirror image lies on the original graph. A function is **odd** when <InlineMath math="f(-x) = -f(x)" />, as with <InlineMath math="x^3 - x" />. For an odd function, the mirror image is the graph of <InlineMath math="-f(x)" />, so a horizontal reflection gives the same result as a vertical reflection.

<BlockMath math="f(-x) = (-x)^3 - (-x) = -x^3 + x = -(x^3 - x) = -f(x)" />

## Domains That Change Sides

Let <InlineMath math="f(x) = \sqrt{x - 2}" />. Its domain is <InlineMath math="x \ge 2" />, so the graph starts at <InlineMath math="(2, 0)" />. After the reflection, <InlineMath math="g(x) = f(-x) = \sqrt{-x - 2}" />. The condition <InlineMath math="-x - 2 \ge 0" /> gives <InlineMath math="x \le -2" />, so **the new domain is** <InlineMath math="(-\infty, -2]" />, and the range stays <InlineMath math="[0, \infty)" />. The point <InlineMath math="(6, 2)" /> on <InlineMath math="f" /> moves to <InlineMath math="(-6, 2)" />, because <InlineMath math="g(-6) = \sqrt{6 - 2} = 2" />.

The absolute value function gives a second check. For <InlineMath math="f(x) = |x + 2|" />, the vertex is <InlineMath math="(-2, 0)" />. Its mirror function is <InlineMath math="f(-x) = |-x + 2| = |x - 2|" />, whose vertex is <InlineMath math="(2, 0)" />. The point <InlineMath math="(-4, 2)" /> on <InlineMath math="f" /> moves to <InlineMath math="(4, 2)" />.

The graph takes one point, <InlineMath math="P(1, 6)" />, and sends it to both places. The point <InlineMath math="(-1, 6)" /> lies on the horizontal reflection, and the point <InlineMath math="(1, -6)" /> lies on the vertical one.

The table lists five mistakes, why each one fails, and how to catch it.

| Mistake | Why it fails | How to catch it |
| --- | --- | --- |
| Writing <InlineMath math="-f(x)" /> for a reflection across the y-axis | <InlineMath math="-f(x)" /> flips the heights, so the points move up and down instead of sideways | Check whether the x-coordinate or the height changes |
| Dropping the brackets in <InlineMath math="(-x)^2" /> | <InlineMath math="-x^2" /> means <InlineMath math="-(x^2)" />, which is a reflection across the x-axis | Substitute with brackets, so that <InlineMath math="(-x)^2 = x^2" /> |

| Forgetting to reverse the domain | The domain interval flips to its mirror image | Solve the new condition on the new input |
| Expecting an even function to change | An even function equals its own mirror image | Check whether <InlineMath math="f(-x)" /> simplifies to <InlineMath math="f(x)" /> |

## Exercises

Start each problem by **writing the full substitution** of <InlineMath math="-x" /> for <InlineMath math="x" />. Then simplify, and check one point before you finish.

1. Let <InlineMath math="f(x) = x^2 - 6x + 5" />. Find the equation of its mirror image across the y-axis and the zeros of that mirror image.
2. Let <InlineMath math="g(x) = \sqrt{x - 2}" />. Find the equation of its mirror image, its domain, and check the point <InlineMath math="(6, 2)" />.
3. Let <InlineMath math="h(x) = |x + 2|" />. Find the equation of its mirror image and its vertex.
4. Does the graph of <InlineMath math="y = x^3 - x" /> change under a horizontal reflection? Explain with <InlineMath math="f(-x)" />, and check the point <InlineMath math="(2, 6)" />.

### Worked Solutions

**Problem 1**. **The substitution** gives <InlineMath math="f(-x) = (-x)^2 - 6(-x) + 5 = x^2 + 6x + 5" />. Factoring gives <InlineMath math="(x + 1)(x + 5)" />, so the zeros are <InlineMath math="-1" /> and <InlineMath math="-5" />. These are the zeros of <InlineMath math="f" />, which are <InlineMath math="1" /> and <InlineMath math="5" />, with their signs changed. Check: <InlineMath math="f(1) = 1 - 6 + 5 = 0" />, so the mirror function at <InlineMath math="-1" /> is zero.

**Problem 2**. **The new function** is <InlineMath math="g(-x) = \sqrt{-x - 2}" />. Its domain comes from <InlineMath math="-x - 2 \ge 0" />, which gives <InlineMath math="x \le -2" />, so the domain is <InlineMath math="(-\infty, -2]" />. The point <InlineMath math="(6, 2)" /> on the original graph has <InlineMath math="g(6) = \sqrt{4} = 2" />, so the mirror point is <InlineMath math="(-6, 2)" />. Check: <InlineMath math="\sqrt{-(-6) - 2} = \sqrt{4} = 2" />.

**Problem 3**. **Replace** <InlineMath math="x" /> with <InlineMath math="-x" />: <InlineMath math="|-x + 2| = |x - 2|" />. The vertex of this function is where the expression inside the bars is zero, so <InlineMath math="x = 2" />, and the vertex is <InlineMath math="(2, 0)" />, the mirror image of <InlineMath math="(-2, 0)" />.

**Problem 4**. **The substitution** gives <InlineMath math="f(-x) = (-x)^3 - (-x) = -x^3 + x = -f(x)" />. The graph therefore changes, because the mirror image is the graph of <InlineMath math="-f(x)" />, which is a different curve. Check: <InlineMath math="f(2) = 8 - 2 = 6" />, so the mirror point is <InlineMath math="(-2, 6)" />, and indeed <InlineMath math="-f(-2) = -(-6) = 6" />.
