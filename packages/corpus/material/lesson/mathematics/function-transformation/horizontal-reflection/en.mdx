## Flipping a Graph across the Vertical Axis

Horizontal reflection flips a function graph across the <InlineMath math="y" />-axis. As with a vertical mirror, each point appears at <Highlight>the same height</Highlight> and <Highlight>the same distance on the opposite side</Highlight>.

If we have a function <InlineMath math="f(x)" />, then horizontal reflection produces a new function <InlineMath math="g(x) = f(-x)" /> which is the reflection of the original function across the <InlineMath math="y" />-axis.

### Rules of Horizontal Reflection

For any function <InlineMath math="f(x)" />, horizontal reflection is defined as:

<BlockMath math="g(x) = f(-x)" />

This transformation changes every point <InlineMath math="(x, y)" /> on the original graph to <InlineMath math="(-x, y)" /> on the reflected graph.

Points on the **mirror axis stay fixed**. For other points, the coordinate perpendicular to the mirror axis changes sign. Reflecting twice returns every point to its original position.

<BlockMath math="g(-x)=f(-(-x))=f(x)" />

- Both lines intersect the <InlineMath math="y" />-axis at the same point <InlineMath math="(0, 3)" />

## Which Values the Horizontal Flip Moves

Horizontal reflection flips a graph across the <InlineMath math="y" />-axis, so the <InlineMath math="y" />-axis acts as the mirror line. Each point on the original graph keeps its distance to the mirror line, but moves to the other side of it.

Take a point <InlineMath math="(a, b)" /> on the graph of <InlineMath math="f(x)" />. The matching point on the graph of <InlineMath math="f(-x)" /> is <InlineMath math="(-a, b)" />. The <InlineMath math="y" /> value stays at <InlineMath math="b" />, and only the sign of the <InlineMath math="x" /> coordinate flips.

| Part of the function | Before the reflection | After the reflection |
| --- | --- | --- |
| Point <InlineMath math="(a, b)" /> | On the graph of <InlineMath math="f(x)" /> | Moves to <InlineMath math="(-a, b)" /> |
| Domain <InlineMath math="[c, d]" /> | The original interval | Becomes <InlineMath math="[-d, -c]" /> |
| Range | The original output values | The same output values as before |
| <InlineMath math="y" />-intercept | At <InlineMath math="x = 0" /> | Stays at <InlineMath math="x = 0" /> |

<Highlight>The domain flips to the opposite side</Highlight> because it lists the allowed values of <InlineMath math="x" />, and those values change sign. The range keeps its values because the height of the graph at each point stays the same. A [vertical reflection](/en/subjects/mathematics/function-transformation/vertical-reflection) flips those heights instead.

## Turning Exponential Growth into Decay

For the exponential function <InlineMath math="f(x) = 2^x" />, reflection turns growth from left to right into decay from left to right.

<LineEquation
  title={<>Horizontal Reflection of Exponential Function <InlineMath math="f(x) = 2^x" /></>}
  description={<>The reflected graph decreases but keeps the same horizontal asymptote and <InlineMath math="y" />-intercept.</>}
  cameraPosition={[0, 3, 16]}
  cameraTarget={[0, 3, 0]}
  data={[
    {
      smooth: false,
      points: Array.from({ length: 961 }, (_, pointIndex) => {
        const x = -3 + (pointIndex / 960) * 6;
        return { x, y: Math.pow(2, x), z: 0 };
      }),
      color: "#4f46e5",
      labels: [{ text: <InlineMath math="f(x)=2^x" />, offset: [3, 1, 0], at: 480 }],
      showPoints: false,
    },
    {
      smooth: false,
      points: Array.from({ length: 115 }, (_, pointIndex) => {
        const x = -3 + (pointIndex / 114) * 6;
        return { x, y: Math.pow(2, -x), z: 0 };
      }),
      color: "#059669",
      labels: [{ text: <InlineMath math="g(x)=2^{-x}" />, offset: [-3, 1, 0], at: 57 }],
      showPoints: false,
    },
  ]}
  showZAxis={false}
/>

For exponential functions:
- The **horizontal asymptote** remains at <InlineMath math="y = 0" /> for both functions
- The <InlineMath math="y" />-intercept remains the same at <InlineMath math="(0, 1)" />
- The function that was originally increasing becomes decreasing after reflection

## Horizontal Reflection on Square Root Functions

The square root function shows how reflection also moves a **restricted domain**.

<LineEquation
  title={<>Horizontal Reflection of Square Root Function <InlineMath math="f(x) = \sqrt{x}" /></>}
  description="The reflected square root curve produces a curve that opens in the opposite direction."
  cameraPosition={[0, 3, 16]}
  cameraTarget={[0, 3, 0]}
  data={[
    {
      smooth: false,
      points: (() => {
        const parameters = Array.from({ length: 121 }, (_, i) => i / 40);
        parameters.push(1.5811388300841898);
        return parameters
          .sort((a, b) => a - b)
          .map((t) => {
            const x = t * t;
            return { x, y: t, z: 0 };
          });
      })(),
      color: "#0891b2",
      labels: [{ at: 64, text: <InlineMath math="f(x)=\sqrt{x}" />, offset: [1, 1.5, 0] }],
      showPoints: false,
    },
    {
      smooth: false,
      points: (() => {
        const parameters = Array.from({ length: 121 }, (_, i) => i / 40);
        parameters.push(1.5811388300841898);
        return parameters
          .sort((a, b) => a - b)
          .map((t) => {
            const x = -t * t;
            return { x, y: t, z: 0 };
          });
      })(),
      color: "#e11d48",
      labels: [{ text: <InlineMath math="g(x)=\sqrt{-x}" />, offset: [-1, 1.5, 0], at: 64 }],
      showPoints: false,
    },
  ]}
  showZAxis={false}
/>

The graph confirms:
- The domain of the original function <InlineMath math="f(x) = \sqrt{x}" /> is <InlineMath math="[0, \infty)" />
- The domain of the reflected function <InlineMath math="g(x) = \sqrt{-x}" /> is <InlineMath math="(-\infty, 0]" />
- Both curves meet at the origin <InlineMath math="(0, 0)" />

## Exercises

The three problems below use the mirror rule you have just learned. Each one replaces the input <InlineMath math="x" /> with <InlineMath math="-x" />, so every result appears on the opposite side of the <InlineMath math="y" />-axis. Try them without the answer key first, then compare your steps with the worked answers.

1. Given the function <InlineMath math="f(x) = x^2 + 3x + 2" />. Determine the equation of the function resulting from horizontal reflection.

2. The graph of the function <InlineMath math="g(x) = 3^x + 1" /> is reflected across the <InlineMath math="y" />-axis. Determine the equation of the resulting function, then determine the domain of that function.

3. Function <InlineMath math="h(x) = |x + 2|" /> undergoes horizontal reflection. Determine the **vertex** of the resulting reflected function.
