## Scaling the Heights of a Function Graph

Vertical dilation multiplies **every output value** by the same factor. Horizontal coordinates remain unchanged, while the distance from the <InlineMath math="x" />-axis is multiplied by the absolute value of that factor.

If you have a function <InlineMath math="f(x)" />, then vertical dilation produces a new function <InlineMath math="g(x) = k \cdot f(x)" />. Here <InlineMath math="k \ne 0" /> is the factor that multiplies each output value.

### How the Output Factor Changes the Height

For any function <InlineMath math="f(x)" /> and a nonzero factor <InlineMath math="k" />, vertical dilation is defined as:

<BlockMath math="g(x) = k \cdot f(x)" />

The factor <InlineMath math="k" /> decides what happens to the height:
- If <InlineMath math="k > 1" />, the graph is stretched vertically (enlarged)
- If <InlineMath math="0 < k < 1" />, the graph is compressed vertically (reduced)
- If <InlineMath math="k = 1" />, the graph does not change
- If <InlineMath math="k < 0" />, the graph undergoes reflection as well as dilation

The value <InlineMath math="k = 0" /> is excluded because it sends every output to <InlineMath math="0" />. The resulting graph lies on the <InlineMath math="x" />-axis only at inputs in the original domain.

The absolute factor changes the **distance from the horizontal axis**. A positive factor above one moves points farther from that axis. A factor between zero and one moves points closer to it.

## Which Values the Vertical Scale Moves

Once you know whether the graph grows taller or shorter, you still need to know which values move. Vertical dilation multiplies every output value by the factor <InlineMath math="k" />, so heights change while positions along the <InlineMath math="x" />-axis stay the same.

Take a point <InlineMath math="(a, b)" /> on the graph of <InlineMath math="f(x)" />. The matching point on the graph of <InlineMath math="k \cdot f(x)" /> is <InlineMath math="(a, k \cdot b)" />. The <InlineMath math="x" /> coordinate stays at <InlineMath math="a" /> because vertical dilation never moves a point sideways.

| Part of the function | Before the dilation | After the dilation by <InlineMath math="k > 0" /> |
| --- | --- | --- |
| Point <InlineMath math="(a, b)" /> | On the graph of <InlineMath math="f(x)" /> | Moves to <InlineMath math="(a, k \cdot b)" /> |
| Domain | The original interval | The same interval as before |
| Range <InlineMath math="[c, d]" /> | The original interval | Becomes <InlineMath math="[k \cdot c, k \cdot d]" /> |
| <InlineMath math="x" />-intercept | At <InlineMath math="x = x_0" /> | Stays at <InlineMath math="x = x_0" /> |
| <InlineMath math="y" />-intercept | At <InlineMath math="y = y_0" /> | Moves to <InlineMath math="y = k \cdot y_0" /> |

The range grows or shrinks together with the graph, because it lists the output values. The domain keeps its own values because the allowed inputs do not change. A [horizontal dilation](/en/subjects/mathematics/function-transformation/horizontal-dilation) divides the horizontal coordinates, so the heights stay unchanged.

With a **negative factor**, the range endpoints reverse order. The range <InlineMath math="[c,d]" /> becomes <InlineMath math="[kd,kc]" />. For example, scaling <InlineMath math="[1,4]" /> by <InlineMath math="k=-2" /> gives <InlineMath math="[-8,-2]" />.

When the scale factor is negative:
- The graph undergoes reflection across the <InlineMath math="x" />-axis
- Simultaneously undergoes dilation according to the absolute value of the scale factor
- A parabola that opens **upward** becomes one that opens downward

## Exercises

The three problems below use the **height** rule you have just learned. Each one multiplies the output by a stated factor, so watch whether that factor is greater than one, between zero and one, or negative. Try them without the answer key first, then compare your steps with the worked answers.

1. Given the function <InlineMath math="f(x) = x^2 - 4x + 3" />. Determine the equation of the function resulting from vertical dilation with scale factor <InlineMath math="3" />.

2. The graph of the function <InlineMath math="g(x) = \sqrt{x}" /> undergoes vertical dilation with factor <InlineMath math="\frac{1}{2}" />. Determine the equation of the resulting function, then determine the range of that function.

3. Function <InlineMath math="h(x) = |x - 1| + 2" /> undergoes vertical dilation with factor <InlineMath math="-1" />. Determine the vertex of the resulting dilated function.

Every worked answer starts by multiplying the whole output expression by the factor, because that is where the height rule lives. The equation is then simplified and the new graph is checked to confirm whether it grew taller or shorter.
