## Vertical Dilation

Vertical dilation changes a function graph's height without changing its horizontal coordinates. Picture a photograph pulled outward from its top and bottom edges or pressed toward the <InlineMath math="x" />-axis.

If we have a function <InlineMath math="f(x)" />, then vertical dilation produces a new function <InlineMath math="g(x) = k \cdot f(x)" /> where <InlineMath math="k \ne 0" /> is the scale factor that determines how much the vertical size changes.

### Rules of Vertical Dilation

For any function <InlineMath math="f(x)" /> and nonzero scale factor <InlineMath math="k" />, vertical dilation is defined as:

<BlockMath math="g(x) = k \cdot f(x)" />

Where <InlineMath math="k" /> is the scale factor that affects the transformation:
- If <InlineMath math="k > 1" />, the graph is stretched vertically (enlarged)
- If <InlineMath math="0 < k < 1" />, the graph is compressed vertically (reduced)
- If <InlineMath math="k = 1" />, the graph does not change
- If <InlineMath math="k < 0" />, the graph undergoes reflection as well as dilation

The value <InlineMath math="k = 0" /> is excluded because it sends every output to <InlineMath math="0" />. The whole graph then collapses onto the <InlineMath math="x" />-axis.

## Properties of Vertical Dilation

### Effect on Coordinate Points

If point <InlineMath math="(a, b)" /> is on the graph of <InlineMath math="f(x)" />, then the corresponding point on the graph of <InlineMath math="k \cdot f(x)" /> is <InlineMath math="(a, k \cdot b)" />.

### Domain and Range

- **Domain**: Does not change after vertical dilation
- **Range**: Changes according to the scale factor <InlineMath math="k" />

If the range of the original function is <InlineMath math="[c, d]" />, then the range after vertical dilation with factor <InlineMath math="k > 0" /> becomes <InlineMath math="[k \cdot c, k \cdot d]" />.

### Axis Intercepts

- **<InlineMath math="x" />-intercept**: Does not change
- **<InlineMath math="y" />-intercept**: Changes according to the scale factor

## Scaling the Values of an Exponential Function

For the exponential function <InlineMath math="f(x) = 2^x" />, the scale factor multiplies every function value.

For exponential functions:
- The horizontal asymptote remains at <InlineMath math="y = 0" /> for both functions
- The <InlineMath math="y" />-intercept changes from <InlineMath math="(0, 1)" /> to <InlineMath math="(0, 2)" />
- Every function value doubles, while the exponential base and relative growth rate stay the same

- The graph undergoes reflection across the <InlineMath math="x" />-axis
