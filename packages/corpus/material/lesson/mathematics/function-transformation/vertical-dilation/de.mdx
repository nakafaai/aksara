## Grundidee der vertikalen Skalierung

Eine vertikale Skalierung verändert die Höhe eines Funktionsgraphen. Man kann sich den Graphen wie ein Gummiband vorstellen, das nach oben und unten auseinandergezogen oder zur <InlineMath math="x" />-Achse hin zusammengedrückt wird. Seine Breite bleibt dabei unverändert.

Aus einer Funktion <InlineMath math="f(x)" /> entsteht die neue Funktion <InlineMath math="g(x) = k \cdot f(x)" />. Der Skalierungsfaktor <InlineMath math="k \ne 0" /> multipliziert jeden Funktionswert und verändert dadurch die vertikalen Abstände.

### Skalierungsregel

Für jede Funktion <InlineMath math="f(x)" /> und jeden von null verschiedenen Skalierungsfaktor <InlineMath math="k" /> gilt:

<BlockMath math="g(x) = k \cdot f(x)" />

Der Faktor <InlineMath math="k" /> bestimmt die Wirkung:
- Bei <InlineMath math="k > 1" /> wird der Graph vertikal gestreckt
- Bei <InlineMath math="0 < k < 1" /> wird der Graph vertikal gestaucht
- Bei <InlineMath math="k = 1" /> bleibt der Graph unverändert
- Bei <InlineMath math="k < 0" /> kommt zur Streckung oder Stauchung eine Spiegelung hinzu

Der Wert <InlineMath math="k = 0" /> ist ausgeschlossen, weil dann alle Funktionswerte zu <InlineMath math="0" /> zusammenfallen. Das wäre keine Skalierung des Graphen.

- Alle Graphen haben den gleichen Scheitelpunkt bei <InlineMath math="(0, 0)" />

## Wichtige Eigenschaften

### Wirkung auf Koordinatenpunkte

Liegt <InlineMath math="(a, b)" /> auf dem Graphen von <InlineMath math="f(x)" />, dann liegt auf dem Graphen von <InlineMath math="k \cdot f(x)" /> der Punkt <InlineMath math="(a, k \cdot b)" />.

### Definitionsbereich und Wertebereich

- **Definitionsbereich**: Bleibt unverändert
- **Wertebereich**: Wird entsprechend dem Skalierungsfaktor <InlineMath math="k" /> vertikal skaliert

Ist der ursprüngliche Wertebereich <InlineMath math="[c, d]" />, dann wird er bei einer vertikalen Skalierung mit <InlineMath math="k > 0" /> zu <InlineMath math="[k \cdot c, k \cdot d]" />.

### Achsenabschnitte

- **<InlineMath math="x" />-Achsenabschnitt**: Bleibt unverändert
- **<InlineMath math="y" />-Achsenabschnitt**: Wird mit dem Skalierungsfaktor multipliziert

## Weitere Beispiele

### Exponentialfunktion

Bei der Exponentialfunktion <InlineMath math="f(x) = 2^x" /> verdoppelt der vertikale Faktor alle Funktionswerte.

<LineEquation
  title={<>Vertikale Skalierung der Exponentialfunktion <InlineMath math="f(x) = 2^x" /></>}
  description="Der Skalierungsfaktor verändert die Höhe des Exponentialgraphen."
  showZAxis={false}
  cameraPosition={[8, 6, 8]}
  data={[
    {
      points: Array.from({ length: 31 }, (_, i) => {
        const x = (i - 15) * 0.3;
        return { x, y: Math.pow(2, x), z: 0 };
      }),
      color: "#4f46e5",
      labels: [{ text: <InlineMath math="f(x)=2^x" />, offset: [2, 1, 0] }],
      showPoints: false,
    },
    {
      points: Array.from({ length: 31 }, (_, i) => {
        const x = (i - 15) * 0.3;
        return { x, y: 2 * Math.pow(2, x), z: 0 };
      }),
      color: "#059669",
      labels: [{ text: <InlineMath math="g(x)=2 \cdot 2^x" />, offset: [1, 2, 0] }],
      showPoints: false,
    },
  ]}
/>

Für Exponentialfunktionen:
- Die horizontale Asymptote bleibt für beide Funktionen bei <InlineMath math="y = 0" />
- Der <InlineMath math="y" />-Achsenabschnitt ändert sich von <InlineMath math="(0, 1)" /> auf <InlineMath math="(0, 2)" />
- Jeder Funktionswert verdoppelt sich, während Basis und relative Wachstumsrate gleich bleiben

## Negativer Skalierungsfaktor

Ein negatives Vorzeichen vor der Funktion spiegelt den Graphen zusätzlich an der <InlineMath math="x" />-Achse.

  title={<>Vertikale Skalierung mit negativem Faktor bei <InlineMath math="f(x) = x^2" /></>}

  cameraPosition={[10, 6, 10]}

      color: "#0891b2",

      showPoints: false,
    },
    {
      points: Array.from({ length: 41 }, (_, i) => {
        const x = (i - 20) * 0.25;
        return { x, y: -2 * x * x, z: 0 };
      }),
      color: "#db2777",
      labels: [{ text: <InlineMath math="g(x)=-2x^2" />, offset: [1, -2, 0] }],
      showPoints: false,

Für einen negativen Skalierungsfaktor gilt:
- Der Graph erfährt eine Spiegelung an der <InlineMath math="x" />-Achse
- Gleichzeitig wird der Graph entsprechend dem Betrag des Skalierungsfaktors gestreckt oder gestaucht
- Eine Parabel, die sich nach oben öffnet, wird zu einer, die sich nach unten öffnet
