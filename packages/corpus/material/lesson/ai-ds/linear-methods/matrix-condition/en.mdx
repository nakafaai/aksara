## Induced matrix norms

A vector norm measures vector size. The corresponding induced matrix norm measures the largest factor by which a matrix can stretch a vector:

<BlockMath math="\|A\|=\sup_{x\ne0}\frac{\|Ax\|}{\|x\|}=\max_{\|x\|=1}\|Ax\|" />

This definition immediately gives two essential bounds for dimensionally compatible matrices and vectors:

<MathContainer>
<BlockMath math="\|Ax\|\le\|A\|\|x\|" />
<BlockMath math="\|AB\|\le\|A\|\|B\|" />
</MathContainer>

The vector norm determines the induced matrix norm.

| Vector norm | Induced matrix norm |
| --- | --- |
| <InlineMath math="\displaystyle\|x\|_1=\sum_{i=1}^{n}\lvert x_i\rvert" /> | <InlineMath math="\displaystyle\|A\|_1=\max_j\sum_i\lvert a_{ij}\rvert" />, the largest absolute column sum |
| <InlineMath math="\displaystyle\|x\|_\infty=\max_i\lvert x_i\rvert" /> | <InlineMath math="\displaystyle\|A\|_\infty=\max_i\sum_j\lvert a_{ij}\rvert" />, the largest absolute row sum |
| <InlineMath math="\displaystyle\|x\|_2=\sqrt{x^{\mathsf T}x}" /> | <InlineMath math="\displaystyle\|A\|_2=\sigma_{\max}(A)" />, the largest singular value |

## Spectral radius and spectral norm

For a square matrix, the spectral radius is

<BlockMath math="\rho(A)=\max_{\lambda\in\operatorname{spec}(A)}|\lambda|" />

Every induced matrix norm bounds the spectral radius:

<BlockMath math="\rho(A)\le\|A\|" />

The spectral norm satisfies

<BlockMath math="\|A\|_2=\sigma_{\max}(A)=\sqrt{\lambda_{\max}(A^{\mathsf T}A)}" />

If <InlineMath math="A" /> is real symmetric, its singular values are the absolute values of its eigenvalues, so

<BlockMath math="\|A\|_2=\max_i|\lambda_i(A)|=\rho(A)" />

For a general nonnormal matrix, the spectral radius and spectral norm need not be equal.

## Condition number of a linear solve

For an invertible square matrix and an induced norm, define

<BlockMath math="\kappa(A)=\|A\|\|A^{-1}\|" />

The condition number is at least one. A singular matrix has infinite condition number. In the Euclidean norm,

<BlockMath math="\kappa_2(A)=\frac{\sigma_{\max}(A)}{\sigma_{\min}(A)}" />

For an invertible symmetric matrix, this becomes

<BlockMath math="\kappa_2(A)=\frac{\max_i|\lambda_i(A)|}{\min_i|\lambda_i(A)|}" />

The smallest magnitude rather than the algebraically smallest eigenvalue, belongs in the denominator.

| Size of <InlineMath math="\kappa(A)" /> | Interpretation |
| --- | --- |
| Near <InlineMath math="1" /> | Relative perturbations are not strongly amplified in the worst case. |
| Large | Some input directions can produce much larger relative changes in the solution. |
| Infinite | The matrix is singular, so the inverse problem is not uniquely solvable. |

## A two-dimensional example

Consider

<BlockMath math="A=\begin{pmatrix}1&0\\0&\varepsilon\end{pmatrix},\qquad 0<\varepsilon\ll1" />

Its singular values are <InlineMath math="1" /> and <InlineMath math="\varepsilon" />, hence

<BlockMath math="\kappa_2(A)=\frac{1}{\varepsilon}" />

For <InlineMath math="b=(b_1,b_2)^{\mathsf T}" />, the solution is

<BlockMath math="x=A^{-1}b=\begin{pmatrix}b_1\\b_2/\varepsilon\end{pmatrix}" />

A small change in <InlineMath math="b_2" /> is amplified by <InlineMath math="1/\varepsilon" /> in the second solution component. The matrix is close to singular because it nearly collapses one direction.

## Perturbation bound

Let <InlineMath math="Ax=b" /> and

<BlockMath math="(A+\delta A)(x+\delta x)=b+\delta b" />

use the same induced norm. If

<BlockMath math="\kappa(A)\frac{\|\delta A\|}{\|A\|}<1" />

then the relative solution change is bounded by

<BlockMath math="\frac{\|\delta x\|}{\|x\|}\le\frac{\kappa(A)}{1-\kappa(A)\|\delta A\|/\|A\|}\left(\frac{\|\delta b\|}{\|b\|}+\frac{\|\delta A\|}{\|A\|}\right)" />

This is a worst-case bound rather than a prediction that every perturbation attains the maximum amplification.

## Conditioning is not algorithmic stability

These concepts answer different questions:

- **conditioning** describes the sensitivity of the mathematical problem to input changes
- **stability** describes how much additional error a numerical algorithm introduces

A stable algorithm cannot remove sensitivity already present in an ill-conditioned problem. Conversely, a well-conditioned problem can still be solved poorly by an unstable implementation. A small residual <InlineMath math="\|b-A\hat{x}\|" /> alone also does not guarantee a small forward error <InlineMath math="\|x-\hat{x}\|" /> when <InlineMath math="\kappa(A)" /> is large.

In numerical work, estimate the reciprocal condition number from a trusted factorization instead of explicitly forming <InlineMath math="A^{-1}" /> merely to evaluate <InlineMath math="\kappa(A)" />.
