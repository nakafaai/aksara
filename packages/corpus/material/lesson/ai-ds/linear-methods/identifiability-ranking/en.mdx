## Identifiability in a Linear Model

A parameter is identifiable when the available data determine it uniquely. Let <InlineMath math="A \in \mathbb{R}^{m \times n}" />, <InlineMath math="b \in \mathbb{R}^m" />, and <InlineMath math="m \geq n" />. The linear least-squares problem is

<BlockMath math="\min_{x \in \mathbb{R}^n} \|Ax-b\|_2^2" />

The corresponding normal equations are

<BlockMath math="A^T A x = A^T b" />

The parameter vector <InlineMath math="x" /> is uniquely identifiable exactly when <InlineMath math="A" /> has full column rank:

<MathContainer>
<BlockMath math="\operatorname{rank}(A)=n" />
<BlockMath math="\ker(A)=\{0\}" />
</MathContainer>

These statements are equivalent. If <InlineMath math="z \in \ker(A)" /> is nonzero, then

<BlockMath math="A(x+z)=Ax" />

This equality shows that the data cannot distinguish <InlineMath math="x" /> from <InlineMath math="x+z" />. If <InlineMath math="\ker(A)=\{0\}" />, then <InlineMath math="A^TA" /> is positive definite and the least-squares problem has one minimizer.

## Solution Uniqueness and Numerical Stability

Full column rank guarantees a unique exact solution, but not a numerically reliable one. A very small nonzero singular value can make the estimate highly sensitive to small changes in the data.

| Question | Diagnostic | Meaning |
| --- | --- | --- |
| Is the parameter structurally identifiable? | <InlineMath math="\operatorname{rank}(A)=n" /> | No two parameter vectors produce the same prediction. |
| Is the estimate numerically well determined? | <InlineMath math="\sigma_n" /> is not tiny relative to <InlineMath math="\sigma_1" /> | Small perturbations do not cause large parameter changes. |
| How sensitive is the problem? | <InlineMath math="\kappa_2(A)=\sigma_1/\sigma_n" /> | A large condition number signals strong sensitivity. |

Structural identifiability is an exact algebraic property. Practical identifiability also depends on scale, noise, and the numerical tolerance used.

## Factorizations for Determining Rank

Two common factorizations can determine rank without relying on determinant calculations that are sensitive to numerical error:

| Method | Strength | Typical use |
| --- | --- | --- |
| <InlineMath math="\mathrm{QR}" /> factorization with column pivoting | Usually cheaper than a full <InlineMath math="\mathrm{SVD}" /> | Fast least-squares solving and practical rank detection |
| Singular value decomposition | Separates the independent directions and the scale of each direction | Detects small singular values that indicate a matrix is nearly rank deficient |

Plain <InlineMath math="\mathrm{LU}" /> factorization is primarily a square-system tool. For a rectangular design matrix, rank is usually determined with pivoted <InlineMath math="\mathrm{QR}" /> or <InlineMath math="\mathrm{SVD}" />.

## Singular Value Decomposition

Let <InlineMath math="q=\min(m,n)" />. Every matrix <InlineMath math="A \in \mathbb{R}^{m \times n}" /> has a singular value decomposition

<BlockMath math="A=U\Sigma V^T" />

In this decomposition, <InlineMath math="U \in \mathbb{R}^{m \times m}" /> and <InlineMath math="V \in \mathbb{R}^{n \times n}" /> are orthogonal. The matrix <InlineMath math="\Sigma \in \mathbb{R}^{m \times n}" /> has nonnegative diagonal entries satisfying

<BlockMath math="\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_q \geq 0" />

The exact rank is the number of positive singular values:

<BlockMath math="\operatorname{rank}(A)=\#\{i:\sigma_i>0\}" />

For <InlineMath math="m \geq n" />, full column rank is therefore equivalent to <InlineMath math="\sigma_n>0" />. Parameter directions that the data cannot identify are spanned by the right singular vectors associated with zero singular values, which form a basis for <InlineMath math="\ker(A)" />.

## Exact Rank and Numerical Rank

If the exact rank is <InlineMath math="r" /> with <InlineMath math="0<r<q" />, then

<BlockMath math="\sigma_r>0=\sigma_{r+1}=\cdots=\sigma_q" />

Floating-point data rarely contain exact zeros. A numerical rank instead counts singular values above a scale-aware threshold <InlineMath math="\tau" />:

<MathContainer>
<BlockMath math="\tau=c\,\max(m,n)\,\varepsilon_{\mathrm{mach}}\,\sigma_1" />
<BlockMath math="\operatorname{rank}_{\tau}(A)=\#\{i:\sigma_i>\tau\}" />
</MathContainer>

The factor <InlineMath math="c" /> reflects the application and noise model, so there is no universal decimal cutoff. If <InlineMath math="A" /> is rank deficient, the least-squares minimum still exists, but the minimizing parameter vector is not unique. The Moore-Penrose pseudoinverse selects the minimum-norm solution:

<BlockMath math="x^{\dagger}=V\Sigma^{\dagger}U^T b" />

## Estimating Matrix Rank with SVD or Rank Revealing QR

The identity

<BlockMath math="A^TA=V\Sigma^2V^T" />

This identity shows why squared singular values are eigenvalues of <InlineMath math="A^TA" />. For numerical computation, explicitly forming <InlineMath math="A^TA" /> squares the condition number:

<BlockMath math="\kappa_2(A^TA)=\kappa_2(A)^2" />

Numerical software therefore usually uses <InlineMath math="\mathrm{SVD}" /> or rank-revealing <InlineMath math="\mathrm{QR}" /> to estimate matrix rank. Both algorithms work directly on <InlineMath math="A" />, so they do not square the condition number as forming <InlineMath math="A^TA" /> does.
