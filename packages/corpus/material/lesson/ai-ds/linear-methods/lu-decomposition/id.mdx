## Faktorisasi

Dekomposisi LU menyimpan eliminasi Gauss dalam dua matriks segitiga. Dengan pivoting parsial, matriks persegi nonsingular <InlineMath math="A \in \mathbb{R}^{n\times n}" /> difaktorkan sebagai

<BlockMath math="PA=LU" />

dengan:

- <InlineMath math="P" /> adalah matriks permutasi yang mencatat pertukaran baris
- <InlineMath math="L" /> adalah matriks segitiga bawah dengan diagonal satu
- <InlineMath math="U" /> adalah matriks segitiga atas

Pada langkah eliminasi <InlineMath math="k" />, pivoting parsial memilih entri bermagnitudo terbesar pada kolom <InlineMath math="k" /> yang berada pada atau di bawah diagonal. Langkah ini mencegah pembagian dengan pivot nol dan biasanya membatasi pertumbuhan galat numerik.

Untuk matriks permutasi, berlaku <InlineMath math="P^{-1}=P^{\mathsf T}" />. Kesamaan <InlineMath math="P^{-1}=P" /> hanya berlaku pada permutasi khusus, misalnya satu pertukaran baris, dan tidak benar untuk setiap permutasi gabungan.

## Cara eliminasi membentuk faktor

Setelah memilih pivot pada kolom <InlineMath math="k" />, hilangkan setiap entri di bawahnya dengan pengali

<BlockMath math="\ell_{ik}=\frac{u_{ik}}{u_{kk}},\qquad i=k+1,\ldots,n" />

dan pembaruan baris

<BlockMath math="u_{ij}\leftarrow u_{ij}-\ell_{ik}u_{kj},\qquad j=k,\ldots,n" />

Pengali disimpan di bawah diagonal <InlineMath math="L" />. Jika dua baris ditukar setelah beberapa langkah eliminasi, kolom <InlineMath math="L" /> yang sudah terisi juga harus ditukar. Jika tidak, kesamaan <InlineMath math="PA=LU" /> tidak lagi terpenuhi.

## Contoh terurai lengkap

Perhatikan

<MathContainer>
<BlockMath math="A=\begin{pmatrix}0&2&1\\1&1&0\\2&1&1\end{pmatrix}" />
<BlockMath math="b=\begin{pmatrix}7\\3\\7\end{pmatrix}" />
</MathContainer>

### Pivot pertama

Pada kolom pertama, magnitudo terbesar adalah <InlineMath math="2" /> di baris ketiga. Tukar baris pertama dan ketiga. Pengali eliminasi pertama adalah <InlineMath math="\ell_{31}=1/2" />; entri lain di bawah pivot sudah bernilai nol.

### Pivot kedua

Entri tersisa dengan magnitudo terbesar pada kolom kedua adalah <InlineMath math="2" />, sehingga pertukaran kedua tidak diperlukan. Pengali untuk baris terakhir adalah <InlineMath math="\ell_{32}=1/4" />.

Faktor yang dihasilkan adalah

<MathContainer>
<BlockMath math="P=\begin{pmatrix}0&0&1\\1&0&0\\0&1&0\end{pmatrix}" />
<BlockMath math="L=\begin{pmatrix}1&0&0\\0&1&0\\\frac12&\frac14&1\end{pmatrix}" />
<BlockMath math="U=\begin{pmatrix}2&1&1\\0&2&1\\0&0&-\frac34\end{pmatrix}" />
</MathContainer>

Perkalian kedua faktor memverifikasi dekomposisi:

<BlockMath math="LU=\begin{pmatrix}2&1&1\\0&2&1\\1&1&0\end{pmatrix}=PA" />

## Menyelesaikan sistem linear

Dari <InlineMath math="PA=LU" />, persamaan <InlineMath math="Ax=b" /> berubah menjadi

<BlockMath math="LUx=Pb" />

Selesaikan melalui dua tahap sistem segitiga.

### Substitusi maju

Pertama, selesaikan <InlineMath math="Ly=Pb" />. Pada contoh ini,

<MathContainer>
<BlockMath math="Pb=\begin{pmatrix}7\\7\\3\end{pmatrix}" />
<BlockMath math="y=\begin{pmatrix}7\\7\\-\frac94\end{pmatrix}" />
</MathContainer>

Untuk matriks segitiga bawah umum,

<BlockMath math="y_i=\frac{1}{\ell_{ii}}\left(c_i-\sum_{j=1}^{i-1}\ell_{ij}y_j\right),\qquad c=Pb" />

Entri diagonal <InlineMath math="L" /> pada dekomposisi ini semuanya satu.

### Substitusi mundur

Kemudian selesaikan <InlineMath math="Ux=y" /> dari baris terakhir ke atas:

<BlockMath math="x_i=\frac{1}{u_{ii}}\left(y_i-\sum_{j=i+1}^{n}u_{ij}x_j\right)" />

Untuk contoh tersebut,

<BlockMath math="x=\begin{pmatrix}1\\2\\3\end{pmatrix}" />

dan substitusi langsung mengonfirmasi <InlineMath math="Ax=b" />.

## Biaya dan penggunaan ulang

Faktorisasi LU padat membutuhkan sekitar

<BlockMath math="\frac{2}{3}n^3+O(n^2)" />

operasi titik mengambang ketika perkalian dan pengurangan dihitung secara terpisah. Setelah faktor tersedia, setiap ruas kanan baru hanya membutuhkan <InlineMath math="O(n^2)" /> kerja untuk dua substitusi. Inilah alasan LU bermanfaat ketika banyak sistem menggunakan matriks yang sama.

Determinan juga dapat diperoleh dari faktor:

<BlockMath math="\det(A)=\det(P)\prod_{i=1}^{n}u_{ii}" />

## Implementasi NumPy yang aman

<CodeBlock data={[{
  language: "python",
  filename: "plu_solve.py",
  code: `import numpy as np


def plu_factor(matrix, tolerance=1e-12):
    """Return P, L, U such that P @ matrix == L @ U."""
    A = np.asarray(matrix, dtype=float)
    if A.ndim != 2 or A.shape[0] != A.shape[1]:
        raise ValueError("PLU factorization requires a square matrix")

    n = A.shape[0]
    U = A.copy()
    L = np.eye(n)
    P = np.eye(n)

    for k in range(n - 1):
        pivot = k + np.argmax(np.abs(U[k:, k]))
        if abs(U[pivot, k]) <= tolerance:
            raise np.linalg.LinAlgError("matrix is singular to working precision")

        if pivot != k:
            U[[k, pivot]] = U[[pivot, k]]
            P[[k, pivot]] = P[[pivot, k]]
            L[[k, pivot], :k] = L[[pivot, k], :k]

        for i in range(k + 1, n):
            L[i, k] = U[i, k] / U[k, k]
            U[i, k:] -= L[i, k] * U[k, k:]

    if abs(U[-1, -1]) <= tolerance:
        raise np.linalg.LinAlgError("matrix is singular to working precision")

    return P, L, U


def forward_substitution(L, right_hand_side):
    b = np.asarray(right_hand_side, dtype=float)
    y = np.empty_like(b)
    for i in range(len(b)):
        y[i] = (b[i] - L[i, :i] @ y[:i]) / L[i, i]
    return y


def backward_substitution(U, right_hand_side, tolerance=1e-12):
    y = np.asarray(right_hand_side, dtype=float)
    x = np.empty_like(y)
    for i in range(len(y) - 1, -1, -1):
        if abs(U[i, i]) <= tolerance:
            raise np.linalg.LinAlgError("singular triangular system")
        x[i] = (y[i] - U[i, i + 1:] @ x[i + 1:]) / U[i, i]
    return x


def plu_solve(matrix, right_hand_side):
    P, L, U = plu_factor(matrix)
    y = forward_substitution(L, P @ right_hand_side)
    x = backward_substitution(U, y)
    return x, P, L, U


A = np.array([[0, 2, 1], [1, 1, 0], [2, 1, 1]], dtype=float)
b = np.array([7, 3, 7], dtype=float)
x, P, L, U = plu_solve(A, b)

assert np.allclose(P @ A, L @ U)
assert np.allclose(A @ x, b)
assert np.allclose(x, np.array([1, 2, 3], dtype=float))`
}]} />

Pemeriksaan tersebut menjadi bagian dari contoh karena urutan faktor dan pencatatan pertukaran baris merupakan sumber kesalahan implementasi yang umum.

## Batas penggunaan metode

Implementasi ini sengaja hanya menerima matriks persegi nonsingular. Pivot numerik nol dilaporkan sebagai galat dan bukan dilewati secara diam-diam. Untuk masalah kuadrat terkecil persegi panjang atau matriks rank-deficient, gunakan faktorisasi QR yang mengungkap peringkat atau SVD. Masalah-masalah tersebut memiliki kontrak keluaran yang berbeda dan tidak seharusnya disembunyikan di dalam penyelesai PLU persegi.
