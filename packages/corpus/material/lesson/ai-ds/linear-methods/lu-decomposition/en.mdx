## The factorization

LU decomposition stores Gaussian elimination as two triangular matrices. With partial pivoting, a nonsingular square matrix <InlineMath math="A \in \mathbb{R}^{n\times n}" /> is factored as

<BlockMath math="PA=LU" />

where:

- <InlineMath math="P" /> is a permutation matrix that records row swaps
- <InlineMath math="L" /> is unit lower triangular
- <InlineMath math="U" /> is upper triangular

At elimination step <InlineMath math="k" />, partial pivoting selects the largest-magnitude entry in column <InlineMath math="k" /> at or below the diagonal. This avoids dividing by a zero pivot and usually limits numerical error growth.

For a permutation matrix, <InlineMath math="P^{-1}=P^{\mathsf T}" />. The equality <InlineMath math="P^{-1}=P" /> holds only for special permutations, such as a single row swap, and is not true for every accumulated permutation.

## How elimination builds the factors

After selecting the pivot in column <InlineMath math="k" />, eliminate each entry below it with the multiplier

<BlockMath math="\ell_{ik}=\frac{u_{ik}}{u_{kk}},\qquad i=k+1,\ldots,n" />

and the row update

<BlockMath math="u_{ij}\leftarrow u_{ij}-\ell_{ik}u_{kj},\qquad j=k,\ldots,n" />

The multipliers are stored below the diagonal of <InlineMath math="L" />. If two rows are swapped after earlier elimination steps, the already-filled columns of <InlineMath math="L" /> must be swapped as well. Otherwise <InlineMath math="PA=LU" /> will no longer hold.

## Complete worked example

Consider

<MathContainer>
<BlockMath math="A=\begin{pmatrix}0&2&1\\1&1&0\\2&1&1\end{pmatrix}" />
<BlockMath math="b=\begin{pmatrix}7\\3\\7\end{pmatrix}" />
</MathContainer>

### First pivot

In the first column, the largest magnitude is <InlineMath math="2" /> in row three. Swap rows one and three. The first elimination multiplier is <InlineMath math="\ell_{31}=1/2" />; the other entry below the pivot is already zero.

### Second pivot

The largest remaining entry in column two is <InlineMath math="2" />, so no second swap is needed. The multiplier for the final row is <InlineMath math="\ell_{32}=1/4" />.

The resulting factors are

<MathContainer>
<BlockMath math="P=\begin{pmatrix}0&0&1\\1&0&0\\0&1&0\end{pmatrix}" />
<BlockMath math="L=\begin{pmatrix}1&0&0\\0&1&0\\\frac12&\frac14&1\end{pmatrix}" />
<BlockMath math="U=\begin{pmatrix}2&1&1\\0&2&1\\0&0&-\frac34\end{pmatrix}" />
</MathContainer>

Multiplying the factors verifies the decomposition:

<BlockMath math="LU=\begin{pmatrix}2&1&1\\0&2&1\\1&1&0\end{pmatrix}=PA" />

## Solving a linear system

From <InlineMath math="PA=LU" />, the equation <InlineMath math="Ax=b" /> becomes

<BlockMath math="LUx=Pb" />

Solve it in two triangular stages.

### Forward substitution

First solve <InlineMath math="Ly=Pb" />. Here,

<MathContainer>
<BlockMath math="Pb=\begin{pmatrix}7\\7\\3\end{pmatrix}" />
<BlockMath math="y=\begin{pmatrix}7\\7\\-\frac94\end{pmatrix}" />
</MathContainer>

For a general lower triangular matrix,

<BlockMath math="y_i=\frac{1}{\ell_{ii}}\left(c_i-\sum_{j=1}^{i-1}\ell_{ij}y_j\right),\qquad c=Pb" />

The diagonal entries of this <InlineMath math="L" /> are all one.

### Backward substitution

Then solve <InlineMath math="Ux=y" /> from the last row upward:

<BlockMath math="x_i=\frac{1}{u_{ii}}\left(y_i-\sum_{j=i+1}^{n}u_{ij}x_j\right)" />

For the example,

<BlockMath math="x=\begin{pmatrix}1\\2\\3\end{pmatrix}" />

and direct substitution confirms <InlineMath math="Ax=b" />.

## Cost and reuse

Dense LU factorization requires approximately

<BlockMath math="\frac{2}{3}n^3+O(n^2)" />

floating-point operations when multiplications and subtractions are counted separately. Once the factors are available, each new right-hand side requires only <InlineMath math="O(n^2)" /> work for the two substitutions. This is why LU is valuable when many systems share the same matrix.

The determinant also follows from the factors:

<BlockMath math="\det(A)=\det(P)\prod_{i=1}^{n}u_{ii}" />

## Guarded NumPy implementation

<CodeBlock data={[{
  language: "python",
  filename: "plu_solve.py",
  code: `import numpy as np


def plu_factor(matrix, tolerance=1e-12):
    """Return P, L, U such that P @ matrix == L @ U."""
    A = np.asarray(matrix, dtype=float)
    if A.ndim != 2 or A.shape[0] != A.shape[1]:
        raise ValueError("PLU factorization requires a square matrix")

    n = A.shape[0]
    U = A.copy()
    L = np.eye(n)
    P = np.eye(n)

    for k in range(n - 1):
        pivot = k + np.argmax(np.abs(U[k:, k]))
        if abs(U[pivot, k]) <= tolerance:
            raise np.linalg.LinAlgError("matrix is singular to working precision")

        if pivot != k:
            U[[k, pivot]] = U[[pivot, k]]
            P[[k, pivot]] = P[[pivot, k]]
            L[[k, pivot], :k] = L[[pivot, k], :k]

        for i in range(k + 1, n):
            L[i, k] = U[i, k] / U[k, k]
            U[i, k:] -= L[i, k] * U[k, k:]

    if abs(U[-1, -1]) <= tolerance:
        raise np.linalg.LinAlgError("matrix is singular to working precision")

    return P, L, U


def forward_substitution(L, right_hand_side):
    b = np.asarray(right_hand_side, dtype=float)
    y = np.empty_like(b)
    for i in range(len(b)):
        y[i] = (b[i] - L[i, :i] @ y[:i]) / L[i, i]
    return y


def backward_substitution(U, right_hand_side, tolerance=1e-12):
    y = np.asarray(right_hand_side, dtype=float)
    x = np.empty_like(y)
    for i in range(len(y) - 1, -1, -1):
        if abs(U[i, i]) <= tolerance:
            raise np.linalg.LinAlgError("singular triangular system")
        x[i] = (y[i] - U[i, i + 1:] @ x[i + 1:]) / U[i, i]
    return x


def plu_solve(matrix, right_hand_side):
    P, L, U = plu_factor(matrix)
    y = forward_substitution(L, P @ right_hand_side)
    x = backward_substitution(U, y)
    return x, P, L, U


A = np.array([[0, 2, 1], [1, 1, 0], [2, 1, 1]], dtype=float)
b = np.array([7, 3, 7], dtype=float)
x, P, L, U = plu_solve(A, b)

assert np.allclose(P @ A, L @ U)
assert np.allclose(A @ x, b)
assert np.allclose(x, np.array([1, 2, 3], dtype=float))`
}]} />

The checks are part of the example because factor order and row-swap bookkeeping are common implementation errors.

## Scope of the method

This implementation deliberately accepts only nonsingular square matrices. A zero numerical pivot is reported rather than silently skipped. For rectangular least-squares problems or rank-deficient matrices, use a rank-revealing QR factorization or an SVD. Those problems have different output contracts and should not be hidden inside a square PLU solver.
