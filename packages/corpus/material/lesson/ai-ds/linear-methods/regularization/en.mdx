## Why Least Squares Can Be Unstable

For <InlineMath math="A\in\mathbb{R}^{m\times n}" /> and <InlineMath math="b\in\mathbb{R}^m" />, ordinary least squares solves

<BlockMath math="\min_x\|Ax-b\|_2^2" />

A minimizer always exists, even when the equations <InlineMath math="Ax=b" /> are inconsistent. The difficulty is different: if <InlineMath math="A" /> is rank deficient, the minimizer may not be unique; if <InlineMath math="A" /> is nearly rank deficient, small perturbations in <InlineMath math="b" /> can cause large changes in the fitted parameters.

The singular value decomposition explains the amplification. For <InlineMath math="A=U\Sigma V^T" />, the least-squares solution contains factors <InlineMath math="1/\sigma_i" />. A data component along a very small singular value <InlineMath math="\sigma_i" /> is therefore magnified.

## Tikhonov Problem

Tikhonov regularization balances data fit against a chosen notion of plausible parameters:

<BlockMath math="\min_x\left(\|Ax-b\|_2^2+\alpha^2\|L(x-x_0)\|_2^2\right),\qquad \alpha>0" />

Here <InlineMath math="x_0" /> is a reference estimate, <InlineMath math="L" /> defines what should remain small or smooth, and <InlineMath math="\alpha" /> controls the tradeoff.

- <InlineMath math="L=I" /> penalizes distance from <InlineMath math="x_0" />.
- A first-difference matrix penalizes rapid changes between neighboring parameters.
- A second-difference matrix penalizes curvature and favors smoother profiles.

The penalty does not create new information in the observations. It makes the chosen prior structure explicit and produces a stable optimization problem.

## Augmented Least-Squares Form

The objective is exactly the least-squares problem

<BlockMath math="\min_x\left\|\begin{pmatrix}A\\\alpha L\end{pmatrix}x-\begin{pmatrix}b\\\alpha Lx_0\end{pmatrix}\right\|_2^2" />

Differentiating gives the normal equation

<BlockMath math="(A^TA+\alpha^2L^TL)x=A^Tb+\alpha^2L^TLx_0" />

The solution is unique precisely when

<BlockMath math="\operatorname{null}(A)\cap\operatorname{null}(L)=\{0\}" />

For standard ridge regularization with <InlineMath math="L=I" />, this condition holds for every <InlineMath math="\alpha>0" /> because <InlineMath math="A^TA+\alpha^2I" /> is positive definite.

## Spectral Filtering

For <InlineMath math="L=I" /> and <InlineMath math="x_0=0" />, write <InlineMath math="A=U\Sigma V^T" />. Then

<MathContainer>
<BlockMath math="x_\alpha=\sum_i\frac{\sigma_i}{\sigma_i^2+\alpha^2}(u_i^Tb)v_i" />
<BlockMath math="\phi_i(\alpha)=\frac{\sigma_i^2}{\sigma_i^2+\alpha^2}" />
</MathContainer>

The factor <InlineMath math="\phi_i" /> is close to <InlineMath math="1" /> when <InlineMath math="\sigma_i\gg\alpha" /> and close to <InlineMath math="0" /> when <InlineMath math="\sigma_i\ll\alpha" />. Regularization therefore preserves well-determined directions while damping directions that would amplify noise.

## Worked Sensitivity Example

Consider

<MathContainer>
<BlockMath math="A=\begin{pmatrix}1&0\\0&0.1\end{pmatrix},\qquad b=\begin{pmatrix}1\\0.2\end{pmatrix}" />
<BlockMath math="x_{\mathrm{LS}}=A^{-1}b=\begin{pmatrix}1\\2\end{pmatrix}" />
</MathContainer>

The second singular value is only <InlineMath math="0.1" />. Changing the second observation by <InlineMath math="0.01" /> changes the unregularized second parameter by <InlineMath math="0.1" />.

With <InlineMath math="L=I" />, <InlineMath math="x_0=0" />, and <InlineMath math="\alpha=0.2" />,

<MathContainer>
<BlockMath math="(A^TA+0.2^2I)x=A^Tb" />
<BlockMath math="x_{0.2}=\begin{pmatrix}1/1.04\\0.02/0.05\end{pmatrix}=\begin{pmatrix}25/26\\0.4\end{pmatrix}" />
</MathContainer>

The same <InlineMath math="0.01" /> perturbation now changes the second parameter by only <InlineMath math="0.02" />. This stability is purchased with bias: the estimate <InlineMath math="0.4" /> is farther from the unregularized value <InlineMath math="2" />.

## Choosing the Regularization Parameter

There is no universally best <InlineMath math="\alpha" />. It depends on the noise level, parameter scaling, penalty, and purpose of the model.

| Method | Appropriate evidence | Decision |
| --- | --- | --- |
| Validation or cross-validation | Predictive modeling with held-out observations | Choose the value with the best out-of-sample performance |
| Discrepancy principle | A credible estimate of the observation-noise norm | Match the residual norm to the expected noise level |
| Generalized cross-validation | Linear inverse problems without a separate validation set | Minimize a predictive score computed from the fitted system |
| L-curve | Exploratory inverse-problem analysis | Inspect the corner of the residual-norm versus penalty-norm curve |

Small <InlineMath math="\alpha" /> emphasizes data fit and can leave noise amplification. Large <InlineMath math="\alpha" /> emphasizes the penalty and can oversmooth or over-shrink the solution. Parameter columns and penalty rows must also use meaningful scales; otherwise the numerical value of <InlineMath math="\alpha" /> is hard to interpret.

## General Weights and Constraints

A diagonal matrix <InlineMath math="L=\operatorname{diag}(\omega_1,\ldots,\omega_n)" /> gives parameter-specific penalties:

<BlockMath math="\|L(x-x_0)\|_2^2=\sum_{i=1}^n\omega_i^2(x_i-x_{0i})^2" />

Larger <InlineMath math="\omega_i" /> means stronger shrinkage toward <InlineMath math="x_{0i}" />. Choose weights from the units and a defensible prior structure. Difficulty in estimating a coefficient is not enough to determine its weight.

An equality such as <InlineMath math="x_i=c" /> should be modeled as an explicit equality constraint when it must hold exactly. Bounds such as <InlineMath math="l_i\le x_i\le u_i" /> require constrained least squares. An extremely large penalty can approximate an equality, but it is not a replacement for an exact constraint and can worsen numerical scaling.

## Solving the Problem Reliably

The normal equation is useful for analysis, but explicitly forming <InlineMath math="A^TA" /> squares the condition number. In numerical code, solve the augmented least-squares system with QR or SVD whenever stability matters. Report <InlineMath math="\alpha" />, <InlineMath math="L" />, parameter scaling, residual norm, and penalty norm. These details let another reader understand how regularization shaped the estimate.
