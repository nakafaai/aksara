## Menghitung dengan Operator Python

Operator aritmatika memberi tahu Python jenis perhitungan yang harus dilakukan. Misalnya, `+` menjumlahkan nilai, `*` mengalikannya, dan `` memangkatkan satu nilai dengan nilai lain.

Python memiliki tujuh operator aritmatika utama. Saat satu ekspresi memuat beberapa operator, <Highlight>operator precedence menentukan operasi yang dikerjakan lebih dahulu</Highlight>.

## Urutan Prioritas Operator

Ketika satu ekspresi memuat beberapa operator aritmatika sekaligus, Python memerlukan urutan tetap untuk menentukan perhitungan mana yang dikerjakan lebih dulu. Urutan itu berasal dari tiga tingkat prioritas. Operator pada tingkat yang lebih tinggi selalu selesai sebelum operator pada tingkat yang lebih rendah, sehingga tingkat setiap operator menentukan urutan perhitungannya.

### Prioritas Tertinggi

Operator Perpangkatan `**`**

Operator `**` digunakan untuk perpangkatan dan memiliki prioritas tertinggi di antara tujuh operator aritmatika biner yang dibahas di sini. Berbeda dari operator lainnya, operator ini memiliki asosiativitas kanan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "exponentiation.py",
      code: `>>> 2**3
8

>>> 2**-1
0.5

>>> 2**0.5
1.4142135623730951`
    }
  ]}
/>

Gunakan `**` untuk menghitung kuadrat, kubik, akar, dan pangkat negatif. Misalnya, akar kuadrat dapat ditulis dengan pangkat `0.5`.

### Prioritas Menengah

Kelompok operator dengan prioritas menengah terdiri dari empat operator yang sering kamu gunakan dalam perhitungan sehari-hari.

**Operator Perkalian**

Operator `*` digunakan untuk mengalikan dua angka.

**Operator Pembagian**

Operator `/` melakukan pembagian dan selalu menghasilkan bilangan float, bahkan ketika kedua operand adalah integer.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "division_examples.py",
      code: `>>> 7.0 / 2.0
3.5

>>> 7.0 / 2
3.5

>>> 7 / 2.0
3.5

>>> 7 / 2
3.5

>>> 4 / 2
2.0`
    }
  ]}
/>

Perhatikan bahwa meskipun `4 / 2` menghasilkan angka bulat secara matematis, Python tetap mengembalikan <InlineMath math="2.0" /> sebagai float.

**Operator Floor Division**

Operator `//` melakukan floor division. Hasil bagi dibulatkan ke bilangan bulat terbesar yang lebih kecil atau sama dengan hasil pembagian.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "integer_division.py",
      code: `>>> 4 // 2
2

>>> 7 // 2
3

>>> -7 // 2
-4

>>> 7.0 // 2
3.0`
    }
  ]}
/>

Floor division membulatkan hasil ke arah negatif tak hingga. Untuk `-7 // 2`, Python memperoleh `-3.5` lalu membulatkannya menjadi `-4`. Jika salah satu operand berupa float, Python tetap melakukan floor division, tetapi mengembalikan float.

**Operator Modulo `%`**

Operator `%` mengembalikan sisa pembagian. Operator ini mengikuti rumus matematika <InlineMath math="a \% b = a - (a // b) \times b" />.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "modulo_examples.py",
      code: `>>> 5 % 4
1

>>> -5 % 4
3

>>> 5 % -4
-3

>>> -5 % -4
-1`
    }
  ]}
/>

Untuk bilangan negatif, ingatlah bahwa Python tetap mempertahankan identitas di atas. Itulah sebabnya `5 % 4` menghasilkan `1`, sedangkan `-5 % 4` menghasilkan `3`. Modulo berguna untuk memeriksa apakah satu bilangan habis dibagi bilangan lain dan, pada bilangan bulat tak negatif, mengambil digit terakhir.

### Prioritas Terendah

Penjumlahan dan pengurangan dikerjakan paling akhir, setelah seluruh perpangkatan, perkalian, pembagian, pembagian bulat, dan sisa bagi di dalam ekspresi yang sama sudah menghasilkan nilai. Pada `2 + 3 * 4`, Python mengalikan lebih dulu lalu menjumlahkan, sehingga hasilnya `14`. Agar penjumlahan dikerjakan lebih dulu, bungkus bagian itu dengan tanda kurung dan tulis `(2 + 3) * 4`.

## Aturan Prioritas dan Asosiativitas

Python tidak membaca ekspresi dari kiri ke kanan. Prioritas menentukan operator mana yang dijalankan lebih dulu, sedangkan asosiativitas menentukan bagaimana Python mengelompokkan operator yang tingkatnya sama. Kedua aturan ini bekerja pada operator yang kamu tulis, sehingga `2 ** 3 ** 2` dan `8 - 3 - 2` masing-masing hanya punya satu cara pembacaan.

### Urutan Evaluasi Ekspresi

Python mengevaluasi ekspresi berdasarkan tiga aturan utama.

1. **Urutan prioritas** menentukan operator mana yang dikerjakan terlebih dahulu
2. **Asosiativitas kiri** berlaku untuk operator dengan prioritas yang sama, kecuali perpangkatan
3. **Tanda kurung** dapat mengubah urutan evaluasi

14

>>> (2 + 4) * 3
18

>>> 2 * 2**3
16

>>> 6 / 2 * 4

### Aturan Asosiativitas

Asosiativitas menentukan urutan evaluasi ketika ada beberapa operator dengan prioritas yang sama dalam satu ekspresi.

**Asosiativitas Kiri**

Evaluasi dimulai dari kiri ke kanan. Sebagian besar operator menggunakan aturan ini.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "left_associative.py",
      code: `>>> 6 / 2 * 4
12

>>> 10 - 3 - 2
5`
    }
  ]}
/>

Perkalian dan pembagian memiliki prioritas yang sama, sehingga Python membaca ekspresi ini dari kiri ke kanan: `6 / 2 * 4 = (6 / 2) * 4 = 12`.

**Asosiativitas Kanan**

Evaluasi dimulai dari kanan ke kiri. Hanya operator perpangkatan `**` yang menggunakan aturan ini.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "right_associative.py",
      code: `>>> 2 ** 3 ** 2
512

>>> 3 ** 2 ** 2
81`
    }
  ]}
/>

Python mengelompokkan perpangkatan berulang dari kanan ke kiri: `2 ** 3 ** 2 = 2 ** (3 ** 2) = 2 ** 9 = 512`.

## Python Shell sebagai Kalkulator

Kamu bisa memakai Python shell sebagai kalkulator. Ketik ekspresi matematika dan Python langsung menghitung hasilnya.

Operator `/` selalu menghasilkan float, termasuk ketika hasilnya berupa bilangan bulat. Operator `//` menghasilkan integer jika kedua operand berupa integer dan menghasilkan float jika salah satunya berupa float. Hasil modulo yang tidak nol memiliki tanda yang sama dengan pembagi dan memenuhi persamaan di atas.

|-----------|----------|--------|---------------|
| **Tertinggi** | `**` | Perpangkatan | Kanan |
| **Menengah** | `*` | Perkalian | Kiri |
| **Menengah** | `/` | Pembagian | Kiri |
| **Menengah** | `//` | Floor division | Kiri |
| **Menengah** | `%` | Modulo | Kiri |

Prioritas operator menentukan cara Python mengelompokkan ekspresi aritmatika. Gunakan tanda kurung jika urutan yang dimaksud berbeda dari pengelompokan standar.
