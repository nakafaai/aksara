## Menggunakan Operator untuk Aritmetik

Operator aritmetik memberitahu Python pengiraan mana yang perlu dilakukan. Contohnya, `+` menambah nilai, `*` mendarab nilai, dan `**` menaikkan satu nilai kepada suatu kuasa.

Python menyediakan tujuh operator aritmetik utama. Keutamaannya menentukan <Highlight>cara sesuatu ungkapan dikumpulkan</Highlight> apabila tanda kurung tidak menentukan kumpulan itu.

Pada setiap titik, `x == 3 * (x // 3) + x % 3` sentiasa benar.

## Susunan Keutamaan Operator

Apabila satu ungkapan mencampurkan beberapa operator aritmetik, Python memerlukan susunan yang tetap untuk memutuskan pengiraan mana yang berlaku dahulu. Tujuh operator binari ini terbahagi kepada **tiga aras keutamaan**. Keutamaan menentukan cara operasi dikumpulkan. Tanda kurung boleh mengubah kumpulan itu.

### Keutamaan Tertinggi

**Operator Eksponen**

Operator `**` digunakan untuk eksponen (kuasa) dan mempunyai keutamaan tertinggi antara tujuh operator aritmetik binari yang dibincangkan di sini. Tidak seperti yang lain, ia mengikut **kesekutuan kanan** (right-associative).

<CodeBlock
  data={[
    {
      language: "python",
      filename: "exponentiation.py",
      code: `>>> 2**3
8

>>> 2**-1
0.5

>>> 2**0.5
1.4142135623730951`
    }
  ]}
/>

Gunakan `**` untuk mengira kuasa dua, kuasa tiga, punca dan kuasa negatif. Contohnya, punca kuasa dua boleh ditulis dengan eksponen `0.5`.

### Keutamaan Pertengahan

Kumpulan operator dengan keutamaan pertengahan terdiri daripada empat operator yang kerap kamu gunakan dalam pengiraan harian.

**Operator Darab**

Operator `*` digunakan untuk mendarab dua nombor.

**Operator Bahagi**

Operator `/` melakukan pembahagian dan menghasilkan **hasil float** bagi operan `int` atau `float`, walaupun kedua-duanya integer.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "division_examples.py",
      code: `>>> 7.0 / 2.0
3.5

>>> 7.0 / 2
3.5

>>> 7 / 2.0
3.5

>>> 7 / 2
3.5

>>> 4 / 2
2.0`
    }
  ]}
/>

Walaupun `4 / 2` ialah nombor bulat dari segi matematik, Python memulangkan <InlineMath math="2.0" /> sebagai float.

**Operator Pembahagian Lantai**

Operator `//` melakukan pembahagian lantai (floor division). Ia membundarkan hasil bahagi ke bawah kepada integer terbesar yang kurang daripada atau sama dengan hasil yang tepat.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "integer_division.py",
      code: `>>> 4 // 2
2

>>> 7 // 2
3

>>> -7 // 2
-4

>>> 7.0 // 2
3.0`
    }
  ]}
/>

Pembahagian lantai membundar ke arah negatif infiniti. Bagi `-7 // 2`, Python mendapat `-3.5` dan membundarkannya ke bawah menjadi `-4`. Jika salah satu operan ialah float, Python tetap menggunakan operasi lantai tetapi memulangkan float.

**Operator Modulo `%`**

Operator `%` memulangkan baki pembahagian. Bagi operan integer dan pembahagi yang bukan sifar, ia mematuhi identiti tepat <InlineMath math="a \% b = a - (a // b) \times b" />.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "modulo_examples.py",
      code: `>>> 5 % 4
1

>>> -5 % 4
3

>>> 5 % -4
-3

>>> -5 % -4
-1`
    }
  ]}
/>

Bagi integer negatif, Python tetap memenuhi identiti di atas. Sebab itulah `5 % 4` menghasilkan `1`, manakala `-5 % 4` menghasilkan `3`. Modulo berguna untuk menyemak kebolehbahagian dan, bagi integer bukan negatif, untuk mencari digit terakhir.

### Keutamaan Terendah

**Tambah dan tolak** mempunyai keutamaan yang lebih rendah daripada lima operator yang lain. Tanda kurung masih boleh mengubah kumpulan operasi. Dalam `2 + 3 * 4`, Python mendarab dahulu dan menambah kemudian, jadi hasilnya `14`. Jika kamu mahu operasi tambah berlaku lebih awal, balut operasi itu dengan tanda kurung dan tulis `(2 + 3) * 4`.

Keutamaan menentukan bentuk pepohon ungkapan bagi `2 + 3 * 4 ** 2`. Operator dengan keutamaan lebih tinggi duduk lebih dalam, jadi Python bekerja dari bawah ke atas: <InlineMath math="4^2=16" />, kemudian <InlineMath math="3\cdot16=48" />, kemudian <InlineMath math="2+48=50" />.

## Peraturan Keutamaan dan Kesekutuan

**Keutamaan dan kesekutuan** menentukan cara operasi dikumpulkan, manakala Python menilai operan dari kiri ke kanan. Keutamaan mengumpulkan operator daripada aras yang berbeza, dan kesekutuan mengumpulkan operator yang berada pada aras yang sama. Kedua-dua peraturan ini bertindak pada operator yang benar-benar kamu tulis, jadi `2 ** 3 ** 2` dan `8 - 3 - 2` masing-masing hanya ada satu bacaan.

### Susunan Penilaian Ungkapan

Tiga peraturan menentukan **cara operasi dikumpulkan** dalam sesuatu ungkapan.

1. **Susunan keutamaan** menentukan operator mana yang terikat lebih kuat
2. **Kesekutuan kiri** digunakan untuk operator yang sama keutamaannya, kecuali eksponen
3. **Tanda kurung** boleh mengubah susunan penilaian

>>> (2 + 4) * 3

16

>>> 6 / 2 * 4

0.75`
    }

### Peraturan Kesekutuan

Kesekutuan menentukan **pengumpulan pada keutamaan yang sama** dalam sesuatu ungkapan.

**Kesekutuan Kiri**

Kebanyakan operator aritmetik binari pada aras keutamaan yang sama dikumpulkan dari kiri ke kanan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "left_associative.py",
      code: `>>> 6 / 2 * 4
12.0

>>> 10 - 3 - 2
5`
    }
  ]}
/>

Darab dan bahagi mempunyai keutamaan yang sama, jadi Python membaca ungkapan ini dari kiri ke kanan: `6 / 2 * 4 = (6 / 2) * 4 = 12`.

**Kesekutuan Kanan**

Antara tujuh operator ini, eksponen `**` dikumpulkan dari kanan ke kiri.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "right_associative.py",
      code: `>>> 2 ** 3 ** 2
512

>>> 3 ** 2 ** 2
81`
    }
  ]}
/>

Python mengumpulkan eksponen berulang dari kanan ke kiri: `2 ** 3 ** 2 = 2 ** (3 ** 2) = 2 ** 9 = 512`.

Kesekutuan menentukan arah condong pepohon apabila operatornya sama. `2 ** 3 ** 2` condong ke kanan, jadi <InlineMath math="3^2=9" /> dikira dahulu dan hasilnya <InlineMath math="2^9=512" />. `100 / 10 / 5` condong ke kiri, jadi <InlineMath math="100/10=10.0" /> dikira dahulu dan hasilnya `2.0`.

## Shell Python sebagai Kalkulator

Bagi operan `int` atau `float`, operator `/` menghasilkan **float**, walaupun hasilnya nombor bulat. Operator `//` menghasilkan integer apabila kedua-dua operan ialah integer, dan float apabila salah satu operan ialah float. Hasil modulo yang bukan sifar mempunyai tanda yang sama dengan pembahagi. Identiti di atas tepat bagi integer, manakala operasi titik apungan boleh membawa ralat pembundaran.

## Jadual Ringkasan Operator Aritmetik

| Keutamaan | Operator | Fungsi | Kesekutuan |
|------------|----------|----------|---------------|
| **Tertinggi** | `**` | Eksponen | Kanan |
| **Pertengahan** | `*` | Darab | Kiri |
| **Pertengahan** | `/` | Bahagi | Kiri |
| **Pertengahan** | `//` | Pembahagian lantai | Kiri |
| **Pertengahan** | `%` | Modulo | Kiri |
| **Terendah** | `+` | Tambah | Kiri |
| **Terendah** | `-` | Tolak | Kiri |

**Keutamaan operator** menentukan cara Python mengumpulkan ungkapan aritmetik. Gunakan tanda kurung untuk mengatasi kumpulan yang biasa apabila susunan yang kamu mahukan berbeza.
