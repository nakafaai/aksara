## Variabel dalam Python

Dalam Python, variabel adalah nama yang menunjuk ke sebuah objek. Reassignment dapat membuat nama itu menunjuk ke objek lain. Nama lain yang masih merujuk ke objek lama tidak ikut berubah.

Ketika Python mengeksekusi `x = 2`, Python mengevaluasi ekspresi <InlineMath math="2" /> lalu mengikat nama `x` pada objek integer yang dihasilkan. Alokasi, penggunaan ulang objek, dan lokasi memori fisiknya adalah detail implementasi yang tidak boleh diasumsikan oleh program.

## Cara Kerja Variabel dan Memori

Built-in `id()` mengembalikan bilangan bulat yang mengidentifikasi sebuah objek secara unik selama masa hidup objek tersebut. CPython biasanya memakai alamat memori objek sebagai dasar nilai itu, tetapi Python tidak menjamin cara yang sama pada setiap implementasi.

Beberapa implementasi Python memakai kembali objek immutable tertentu. Kode yang benar tidak boleh bergantung pada optimasi tersebut.

## Karakteristik Variabel Python

Saat kamu memberi nilai pada sebuah nama, ingat dua hal. Python langsung mengikat nama itu pada sebuah objek tanpa deklarasi terpisah. Setelah itu, kamu dapat mengikat nama yang sama pada objek bertipe berbeda.

### Tidak Ada Deklarasi Variabel

Python mengikat nama ketika assignment dijalankan, tanpa deklarasi variabel terpisah. Objek memiliki tipe, dan `type(value)` menampilkan tipe objek yang sedang ditunjuk oleh sebuah nama.

tinggi = 175.5          # Float
aktif = True            # Boolean

# Python menentukan tipe data secara otomatis
print(type(nama))       # Output: <class 'str'>
print(type(umur))       # Output: <class 'int'>
print(type(tinggi))     # Output: <class 'float'>
print(type(aktif))      # Output: <class 'bool'>`
    }
  ]}
/>

Python memakai dynamic typing: setiap objek memiliki tipe, sedangkan nama yang sama dapat diikat ulang pada objek dari tipe berbeda saat program berjalan.

## Aturan Nama Variabel

Nama variabel harus memenuhi aturan berikut agar dapat diterima oleh Python.

### Komponen Nama Variabel

Identifier dimulai dengan underscore atau huruf Unicode. Karakter berikutnya boleh berupa huruf, underscore, atau digit seperti <InlineMath math="0,1,2,\dots,9" />. Python menerima banyak identifier non-ASCII, tetapi nama `snake_case` ASCII yang deskriptif biasanya lebih mudah diketik, dicari, dan dipakai lintas tools.

## Kata Kunci yang Tidak Boleh Digunakan

Kelompok pertama meliputi `and`, `as`, `assert`, `async`, `await`, `break`, `class`, `continue`, `def`, `del`, `elif`, `else`. Kelompok kedua mencakup `except`, `finally`, `for`, `from`, `global`, `if`, `import`, `in`, `is`, `lambda`, `nonlocal`, `not`. Kelompok ketiga terdiri dari `or`, `pass`, `raise`, `return`, `try`, `while`, `with`, `yield`, `False`, `True`, `None`.

## Contoh Penggunaan Variabel dalam Program

Program berikut menggunakan variabel untuk menghitung luas dan keliling persegi panjang.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "rectangle_calculator.py",
      code: `# Program menghitung luas dan keliling persegi panjang
print("=== Kalkulator Persegi Panjang ===")

# Input dari pengguna
panjang = float(input("Masukkan panjang (cm): "))
lebar = float(input("Masukkan lebar (cm): "))

# Perhitungan
luas = panjang * lebar
keliling = 2 * (panjang + lebar)

# Menampilkan hasil
print(f"\\nHasil Perhitungan:")
print(f"Panjang: {panjang} cm")
print(f"Lebar: {lebar} cm")
print(f"Luas: {luas} cm²")
print(f"Keliling: {keliling} cm")

# Validasi input
if panjang <= 0 or lebar <= 0:
    print("\\nPeringatan: Panjang dan lebar harus lebih besar dari 0!")
else:
    print("\\nPerhitungan valid.")`
    }
  ]}
/>

Dalam program ini, `panjang` dan `lebar` menamai dua input, sedangkan `luas` dan `keliling` menamai hasil perhitungan. Kondisi terakhir menolak ukuran yang tidak positif sebelum nilai luas dan keliling dinyatakan valid.

Nama variabel yang konsisten membuat kode Python lebih mudah dibaca. Saat mempelajari perubahan objek dan argumen fungsi, bedakan equality, identity, dan reassignment karena ketiganya menjawab pertanyaan yang berbeda.
