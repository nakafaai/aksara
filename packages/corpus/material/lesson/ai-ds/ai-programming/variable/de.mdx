## Variablennamen an Objekte binden

In Python ist eine Variable ein Name, der an ein Objekt gebunden ist. <Highlight>Der Name ist keine typisierte Speicherbox</Highlight>: Eine Zuweisung kann ihn an ein anderes Objekt binden, während weitere Namen weiterhin auf das ursprüngliche Objekt verweisen können.

Wenn Python `x = 2` ausführt, wertet es den Ausdruck <InlineMath math="2" /> aus und bindet den Namen `x` an das entstehende Integer-Objekt. Allokation, Wiederverwendung und physischer Speicherort des Objekts sind Implementierungsdetails, auf die sich ein Programm nicht verlassen darf.

## Wie Variablen und Speicher funktionieren

Das Built-in `id()` liefert eine ganze Zahl, die ein Objekt während seiner Lebensdauer **eindeutig identifiziert**. CPython leitet sie häufig aus einer Speicheradresse ab, doch Python garantiert diese Deutung nicht für jede Implementierung.

## Eigenschaften von Variablen in Python

Wenn du einem Namen einen Wert zuweist, merke dir zwei Dinge. Python bindet den Namen **ohne separate Deklaration** an ein Objekt. Später kannst du denselben Namen an ein Objekt eines anderen Typs binden.

### Keine Variablendeklaration

Anders als Sprachen mit separater Variablendeklaration bindet Python einen Namen, sobald eine Zuweisung ausgeführt wird. **Objekte besitzen Typen**, und `type(value)` meldet den Typ des Objekts, das gerade an einen Namen gebunden ist.

print(type(aktif))      # Ausgabe: <class 'bool'>`

Python ist dynamisch typisiert: Jedes Objekt besitzt einen Typ, während derselbe Name im Programmverlauf an **Objekte verschiedener Typen** neu gebunden werden kann.

## Variablenbenennungsregeln

Python hat feste Syntaxregeln für Identifier. Ein Name darf Buchstaben, Ziffern und Unterstriche enthalten, aber **nicht mit einer Ziffer beginnen** und nicht mit einem reservierten Schlüsselwort übereinstimmen.

### Variablennamenskomponenten

Ein Identifier beginnt mit einem **Unterstrich oder einem Unicode-Buchstaben**. Danach dürfen Identifier-Buchstaben, Unterstriche und Ziffern wie <InlineMath math="0,1,2,\dots,9" /> folgen. Python akzeptiert viele Nicht-ASCII-Identifier, doch aussagekräftige ASCII-Namen in `snake_case` lassen sich meist leichter tippen, suchen und werkzeugübergreifend teilen.

_total = 100                # Beginnend mit Unterstrich

camelCase = "valid"         # CamelCase-Stil
snake_case = "valid"        # snake_case-Stil

### Großschreibung und Kleinschreibung

Python unterscheidet bei Variablennamen zwischen **Groß- und Kleinbuchstaben**. Das bedeutet, dass `nama`, `Nama` und `NAMA` drei verschiedene Variablen sind.

## Für Python reservierte Schlüsselwörter

Python reserviert bestimmte Wörter für seine Syntax. Deshalb können sie **nicht als Variablennamen** verwendet werden. Eine Zuweisung an eines dieser Wörter löst einen `SyntaxError` aus, noch bevor das Programm startet.

### Liste der Schlüsselwörter in Python

Diese **reservierten Schlüsselwörter** können keine Identifier sein. Die Tabelle gruppiert sie nach ihrer Rolle in der Syntax.

| Rolle | Schlüsselwörter |
| --- | --- |
| Logik und Werte | `and`, `or`, `not`, `True`, `False`, `None` |
| Verzweigung und Iteration | `if`, `elif`, `else`, `for`, `while`, `break`, `continue`, `pass` |
| Definitionen und Gültigkeit | `def`, `class`, `lambda`, `return`, `yield`, `global`, `nonlocal` |
| Importe und Aliase | `import`, `from`, `as` |
| Fehler und Kontext | `try`, `except`, `finally`, `raise`, `assert`, `with` |
| Weitere Operationen | `async`, `await`, `del`, `in`, `is` |

Soft Keywords wie `match`, `case`, `type` und `_` sind nur in bestimmten Syntaxkontexten speziell. `keyword.iskeyword("match")` ergibt `False`, `keyword.issoftkeyword("match")` dagegen `True`.

## Bewährte Vorgehensweisen für Variablennamen

Python-Bezeichner müssen die oben beschriebenen Syntaxregeln erfüllen. Innerhalb dieser Regeln sollten die Namen angeben, **wofür ein Wert steht**. Ein Name wie `gesamtpreis` sagt der nächsten Leserin mehr als `gp`, und dieselbe Gewohnheit hält ein längeres Programm auch Monate später lesbar.

### Bedeutungsvolle Namen

Wähle Variablennamen, die den gebundenen Wert oder **seine Rolle im Programm** erklären. Aussagekräftige Namen helfen dir und allen späteren Lesenden, den Code schneller zu verstehen.

## Beispiel für Variablen in einem Programm

Das folgende Programm verwendet Variablen, um **Fläche und Umfang eines Rechtecks** zu berechnen.

<CodeBlock

perimeter = 2 * (length + width)

# Ergebnisse anzeigen

Nichtnumerischen Text lehnt `float()` ab.

Namensbindung, Identifier-Regeln und einheitliche Konventionen machen Python-Code leichter lesbar. Wer Gleichheit, Identität und Neuzuweisung unterscheidet, kann später auch Mutability, Funktionsargumente und Objektmodelle besser einordnen.
