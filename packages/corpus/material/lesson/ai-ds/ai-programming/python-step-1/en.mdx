## Running Your First Python Code

<Highlight>Python uses indentation to mark code blocks</Highlight> and short keywords for common operations. In the first examples, you can identify assignments, function calls, and conditions before learning every part of the syntax.

The same language is used in web development, data analysis, machine learning, and artificial intelligence. The first example is a small program that prints text.

When you need to check syntax or find a function in the standard library, open the [official Python documentation](https://docs.python.org). Choose the same Python version that you are running so the examples and feature list match your program.

## Three Ways to Run Python Programs

Python code can be run in three common ways. The interactive prompt is best for trying one expression at a time, a saved script file is best for a program you run again, and a notebook is best for **mixing code with written notes**.

### Interactive Mode

Interactive mode runs Python statements directly in the terminal. Use it to check a short expression or **inspect a value without creating a file**.

Here's how to use interactive mode. First open a terminal or command prompt, then type `python` or `python3` and press Enter. You'll see the `>>>` prompt indicating Python is ready to receive commands. Next, write Python code and press Enter to execute it.

<CodeBlock
  data={[{
    language: "bash",
    filename: "terminal",
    code: `$ python3
>>> print("Hello World!")
Hello World!
>>> 2 + 3
5
>>> name = "Alice"
>>> print(f"Hello, {name}!")
Hello, Alice!
>>>`
  }]}
/>

### Script Mode

Script mode is a way to **run saved Python files**. This is suitable for more complex programs or programs you want to save for repeated use.

To run a script, create a file with the `.py` extension in a text editor, write the Python code, and save the file. Then open a terminal, go to the folder that contains the file, and run `python3 filename.py`.

<CodeBlock

print(f"You are {age} years old.")

### Jupyter Lab and Notebooks

Jupyter is an interactive environment often used for data science and teaching. A notebook combines **executable code**, its output, and written explanation in one document.

Each cell can run independently, and its output appears directly below it. Because code, results, explanatory text, images, and graphs stay in one document, a notebook can record each step of an experiment or data analysis.

Cells share state in the same kernel. After restarting the kernel, run the cells from top to bottom: a cell using `math` or a function depends on the cell that defined that name.

Install JupyterLab in a dedicated Python environment so its packages do not interfere with unrelated projects:

These commands use macOS/Linux paths. On Windows, use `py -m venv .venv`, then `.venv\Scripts\python -m pip install jupyterlab` and `.venv\Scripts\jupyter lab`.

<CodeBlock

python3 -m venv .venv
.venv/bin/python -m pip install jupyterlab`
  }]}
/>

Second, run Jupyter Lab:

## Basic Python Syntax

A first Python program reads its statements from top to bottom. A variable stores a value, a **data type decides which operations** that value supports, and input, output, and arithmetic turn those values into a working program.

### Variables and Data Types

Python has several basic data types. A **variable name refers to a value**. Assigning another value makes the name point to that new value.

<CodeBlock

### Simple Calculator

This program reads **two numbers and an operator**, then prints the result. It combines input, type conversion, and branching in one file.

<CodeBlock
  data={[{
    language: "python",
    filename: "calculator.py",
    code: `# Simple calculator
print("=== SIMPLE CALCULATOR ===")

# Input from user
number1 = float(input("Enter first number: "))
operator = input("Enter operator (+, -, *, /): ")
number2 = float(input("Enter second number: "))

# Calculation process
if operator == "+":
    result = number1 + number2
elif operator == "-":
    result = number1 - number2
elif operator == "*":
    result = number1 * number2
elif operator == "/":
    if number2 != 0:
        result = number1 / number2
    else:
        print("Error: Cannot divide by zero!")
        result = None
else:
    print("Invalid operator!")
    result = None

# Output result
if result is not None:
    print(f"Result: {number1} {operator} {number2} = {result}")`
  }]}
/>

### Temperature Conversion

This program converts a **Celsius temperature into Fahrenheit and Kelvin**, and it rejects a value below absolute zero.

The freezing and boiling statements approximate pure water at one atmosphere. Try `26.85`: the conversion produces `80.3 °F` and `300.0 K`.

<CodeBlock
  data={[{
    language: "python",
    filename: "temperature_converter.py",
    code: `import math

# Temperature converter from Celsius to Fahrenheit and Kelvin
print("=== TEMPERATURE CONVERTER ===")

# Input temperature in Celsius
celsius = float(input("Enter temperature in Celsius: "))

if not math.isfinite(celsius) or celsius < -273.15:
    raise ValueError("Temperature must be finite and at or above absolute zero")

# Convert to Fahrenheit and Kelvin
fahrenheit = (celsius * 9/5) + 32
kelvin = celsius + 273.15

# Output conversion results
print(f"\\nConversion results from {celsius}°C:")
print(f"Fahrenheit: {fahrenheit:.1f}°F")
print(f"Kelvin: {kelvin:.1f}K")

# Bonus: Additional information
if celsius < 0:
    print("This temperature is below water freezing point!")
elif celsius == 0:
    print("This temperature is water freezing point!")
elif celsius == 100:
    print("This temperature is water boiling point!")
elif celsius > 100:
    print("This temperature is above water boiling point!")`
  }]}
/>
