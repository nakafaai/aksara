## Menjalankan Kod Python Pertama Kamu

<Highlight>Python menggunakan lekukan (indentation) untuk menandakan blok kod</Highlight> dan kata kunci yang pendek untuk operasi yang biasa. Dalam contoh-contoh awal, kamu sudah boleh mengenal pasti umpukan, panggilan fungsi dan syarat sebelum mempelajari setiap bahagian sintaks.

Bahasa yang sama digunakan dalam pembangunan web, analisis data, pembelajaran mesin dan kecerdasan buatan. Contoh pertama ialah atur cara kecil yang mencetak teks.

Apabila kamu perlu menyemak sintaks atau mencari fungsi dalam pustaka standard, buka [dokumentasi rasmi Python](https://docs.python.org). Pilih versi Python yang sama dengan yang kamu jalankan supaya contoh dan senarai ciri di situ sepadan dengan atur cara kamu.

## Atur Cara Hello World

Atur cara pertama yang biasa ditulis **memaparkan teks "Hello World!"**. Apabila kamu menjalankannya, kamu dapat memastikan Python boleh melaksanakan fail, dan kamu juga mendapat satu atur cara kecil yang lengkap untuk diteliti.

<CodeBlock
  data={[{
    language: "python",
    filename: "hello.py",
    code: `print("Hello World!")`
  }]}
/>

Fungsi terbina dalam `print()` menulis nilai di dalam kurungannya ke output.

## Tiga Cara Menjalankan Atur Cara Python

Kod Python boleh dijalankan dengan tiga cara yang biasa. Gesaan interaktif paling sesuai untuk mencuba satu ungkapan pada satu masa, fail skrip yang disimpan paling sesuai untuk atur cara yang kamu jalankan berulang kali, dan buku nota paling sesuai untuk **menggabungkan kod dengan nota bertulis**.

### Mod Interaktif

Mod interaktif menjalankan pernyataan Python terus dalam terminal. Guna mod ini untuk menyemak ungkapan pendek atau **melihat sesuatu nilai tanpa membuat fail**.

Begini cara menggunakan mod interaktif. Mula-mula, buka terminal atau Command Prompt, kemudian taip `python` atau `python3` dan tekan Enter. Kamu akan nampak gesaan `>>>` yang menunjukkan Python sudah sedia menerima arahan. Seterusnya, tulis kod Python dan tekan Enter untuk melaksanakannya.

<CodeBlock
  data={[{
    language: "bash",
    filename: "terminal",
    code: `$ python3
>>> print("Hello World!")
Hello World!
>>> 2 + 3
5
>>> name = "Alice"
>>> print(f"Hello, {name}!")
Hello, Alice!
>>>`
  }]}
/>

### Mod Skrip

Mod skrip ialah cara untuk **menjalankan fail Python yang disimpan**. Mod ini sesuai untuk atur cara yang lebih kompleks atau atur cara yang kamu mahu simpan untuk digunakan berulang kali.

Untuk menjalankan skrip, buat fail dengan sambungan `.py` dalam penyunting teks, tulis kod Python dan simpan fail itu. Kemudian buka terminal, pergi ke folder yang mengandungi fail itu dan jalankan `python3 filename.py`.

### Jupyter Lab dan Buku Nota

Jupyter ialah persekitaran interaktif yang sering digunakan untuk sains data dan pengajaran. Buku nota (notebook) menggabungkan **kod yang boleh dilaksanakan**, outputnya dan penerangan bertulis dalam satu dokumen.

Setiap sel boleh dijalankan secara berasingan, dan outputnya muncul terus di bawah sel itu. Oleh sebab kod, hasil, teks penerangan, imej dan graf berada dalam satu dokumen, buku nota boleh merekodkan setiap langkah dalam sesuatu eksperimen atau analisis data.

Sel-sel berkongsi keadaan dalam kernel yang sama. Selepas kernel dimulakan semula, jalankan sel dari atas ke bawah: sel yang menggunakan `math` atau sesuatu fungsi bergantung pada sel yang mentakrifkan nama itu.

Pasang JupyterLab dalam persekitaran Python yang khusus untuknya supaya pakej-pakejnya tidak mengganggu projek lain yang tidak berkaitan:

Arahan di bawah menggunakan laluan macOS/Linux. Pada Windows, guna `py -m venv .venv`, kemudian `.venv\Scripts\python -m pip install jupyterlab` dan `.venv\Scripts\jupyter lab`.

<CodeBlock
  data={[{

python3 -m venv .venv
.venv/bin/python -m pip install jupyterlab`

Kedua, jalankan Jupyter Lab:

<CodeBlock

## Sintaks Asas Python

Atur cara Python yang pertama membaca pernyataannya dari atas ke bawah. Pemboleh ubah menyimpan nilai, **jenis data menentukan operasi** yang disokong oleh nilai itu, dan input, output serta aritmetik menukar nilai-nilai itu menjadi atur cara yang berfungsi.

Python mempunyai beberapa jenis data asas. **Nama pemboleh ubah merujuk kepada sesuatu nilai**. Apabila kamu mengumpukkan nilai lain, nama itu akan menunjuk kepada nilai baharu tersebut.

<CodeBlock

## Latihan Amali

Selesaikan latihan ini untuk berlatih **pemboleh ubah, input, output dan operasi asas**. Tulis setiap jawapan sendiri sebelum menyemaknya, kerana latihan ini melatih langkah-langkah yang kamu ambil. Penyelesaiannya mengikut susunan yang sama dengan soalan.

### Kalkulator Mudah

Atur cara ini membaca **dua nombor dan satu operator**, kemudian mencetak hasilnya. Atur cara ini menggabungkan input, penukaran jenis dan pencabangan dalam satu fail.

<CodeBlock
  data={[{
    language: "python",
    filename: "calculator.py",
    code: `# Kalkulator mudah
print("=== KALKULATOR MUDAH ===")

# Input daripada pengguna
number1 = float(input("Masukkan nombor pertama: "))
operator = input("Masukkan operator (+, -, *, /): ")
number2 = float(input("Masukkan nombor kedua: "))

# Proses pengiraan
if operator == "+":
    result = number1 + number2
elif operator == "-":
    result = number1 - number2
elif operator == "*":
    result = number1 * number2
elif operator == "/":
    if number2 != 0:
        result = number1 / number2
    else:
        print("Ralat: Tidak boleh bahagi dengan sifar!")
        result = None
else:
    print("Operator tidak sah!")
    result = None

# Paparkan hasil
if result is not None:
    print(f"Hasil: {number1} {operator} {number2} = {result}")`
  }]}
/>

### Penukaran Suhu

Atur cara ini menukar **suhu Celsius kepada Fahrenheit dan Kelvin**, dan menolak nilai di bawah sifar mutlak.

Mesej tentang takat beku dan takat didih ialah anggaran bagi air tulen pada tekanan satu atmosfera. Cuba `26.85`: penukarannya menghasilkan `80.3 °F` dan `300.0 K`.

<CodeBlock
  data={[{
    language: "python",
    filename: "temperature_converter.py",
    code: `import math

# Penukar suhu daripada Celsius kepada Fahrenheit dan Kelvin
print("=== PENUKAR SUHU ===")

# Input suhu dalam Celsius
celsius = float(input("Masukkan suhu dalam Celsius: "))

if not math.isfinite(celsius) or celsius < -273.15:
    raise ValueError("Suhu mesti terhingga dan tidak kurang daripada sifar mutlak")

# Tukar kepada Fahrenheit dan Kelvin
fahrenheit = (celsius * 9/5) + 32
kelvin = celsius + 273.15

# Paparkan hasil penukaran
print(f"\\nHasil penukaran daripada {celsius}°C:")
print(f"Fahrenheit: {fahrenheit:.1f}°F")
print(f"Kelvin: {kelvin:.1f}K")

# Bonus: Maklumat tambahan
if celsius < 0:
    print("Suhu ini di bawah takat beku air!")
elif celsius == 0:
    print("Suhu ini ialah takat beku air!")
elif celsius == 100:
    print("Suhu ini ialah takat didih air!")
elif celsius > 100:
    print("Suhu ini melebihi takat didih air!")`
  }]}
/>

### Semak Kerja Kamu

**Atur cara latihan kamu betul** apabila:

- Kalkulator meminta dua nombor dan satu operator, kemudian memaparkan hasil operasi yang dipilih.
- Penukar suhu memaparkan nilai Fahrenheit dan Kelvin daripada input Celsius.
- Profil pelajar memaparkan data yang dimasukkan, tahun masuk, anggaran tahun tamat pengajian dan mesej yang bergantung pada semester.

Tetapkan `number1 = 2` dan bayangkan kamu mencuba banyak nilai `number2` dalam kalkulator di atas. Setiap operator memberi grafnya sendiri: `+` dan `-` ialah garis yang condong ke arah bertentangan, `*` ialah garis yang lebih curam, dan `/` memberi titik-titik magenta.
