## Pengenalan Python

Python memakai indentasi untuk menandai blok kode dan keyword pendek untuk operasi umum. Pada contoh pertama, kamu sudah dapat mengenali assignment, function call, dan condition sebelum mempelajari setiap bagian sintaks.

Bahasa yang sama dipakai untuk pengembangan web, analisis data, pembelajaran mesin, dan kecerdasan buatan. Pelajaran ini dimulai dari program kecil yang mencetak teks.

Untuk mempelajari bahasa dan standard library Python lebih lanjut, buka [Python](https://docs.python.org). Dokumentasi resmi Python menjadi referensi utama untuk versi yang kamu pakai.

## Program Hello World

Program pertama yang umum dibuat menampilkan teks "Hello World!". Menjalankannya memastikan Python dapat mengeksekusi sebuah file sekaligus memberi kamu satu program kecil yang lengkap untuk dipelajari.

  }]}
/>

## Tiga Cara Menjalankan Program Python

Pelajaran ini memakai tiga cara umum untuk menjalankan kode Python. Masing-masing mendukung bagian yang berbeda dalam alur belajar.

### Mode Interaktif

Mode interaktif menjalankan kode Python yang ditulis langsung di terminal. Mode ini cocok untuk menguji potongan kode sederhana atau melakukan eksperimen singkat.

Cara menggunakan mode interaktif seperti ini. Pertama buka terminal atau command prompt, kemudian ketik `python` atau `python3` dan tekan Enter. Kamu akan melihat prompt `>>>` yang menandakan Python siap menerima perintah. Selanjutnya tulis kode Python dan tekan Enter untuk menjalankannya.

<CodeBlock
  data={[{
    language: "bash",
    filename: "terminal",
    code: `$ python3
Python 3.8.5 (default, Sep  4 2020, 02:22:02)
[Clang 10.0.0 ] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>> print("Hello World!")
Hello World!
>>> 2 + 3
5
>>> name = "Alice"
>>> print(f"Hello, {name}!")
Hello, Alice!
>>>`
  }]}
/>

### Mode Script

Mode script menjalankan file Python yang sudah disimpan. Mode ini cocok untuk program yang lebih panjang atau yang ingin kamu gunakan kembali.

Untuk menjalankan script, buat file berekstensi `.py` dengan editor teks, tulis kode Python di dalamnya, lalu simpan. Setelah itu, buka terminal, masuk ke folder tempat file disimpan, dan jalankan `python nama_file.py`.

### Jupyter Lab dan Notebooks

Jupyter adalah lingkungan interaktif yang sering digunakan untuk sains data dan pembelajaran. Sebuah notebook menggabungkan kode yang dapat dijalankan, hasilnya, dan penjelasan tertulis dalam satu dokumen.

Setiap sel dapat dijalankan secara terpisah, lalu output sel muncul tepat di bawah kode. Kode, output, penjelasan, gambar, dan grafik tetap berada dalam satu dokumen. Susunan ini dapat merekam setiap langkah eksperimen atau analisis data.

Instal JupyterLab di environment Python khusus agar paketnya tidak mengganggu proyek lain:

<CodeBlock
  data={[{

Kedua, jalankan Jupyter Lab:

print(f"Tahun depan kamu akan berumur {next_year} tahun.")

## Latihan Praktis

Kerjakan latihan berikut untuk mempraktikkan variabel, input, output, dan operasi dasar:

### Kalkulator Sederhana

<CodeBlock
  data={[{
    language: "python",
    filename: "calculator.py",
    code: `# Kalkulator sederhana
print("=== KALKULATOR SEDERHANA ===")

# Input dari pengguna
angka1 = float(input("Masukkan angka pertama: "))
operator = input("Masukkan operator (+, -, *, /): ")
angka2 = float(input("Masukkan angka kedua: "))

# Proses kalkulasi
if operator == "+":
    hasil = angka1 + angka2
elif operator == "-":
    hasil = angka1 - angka2
elif operator == "*":
    hasil = angka1 * angka2
elif operator == "/":
    if angka2 != 0:
        hasil = angka1 / angka2
    else:
        print("Error: Tidak bisa membagi dengan nol!")
        hasil = None
else:
    print("Operator tidak valid!")
    hasil = None

# Output hasil
if hasil is not None:
    print(f"Hasil: {angka1} {operator} {angka2} = {hasil}")`
  }]}
/>

### Konversi Suhu

<CodeBlock
  data={[{
    language: "python",
    filename: "temperature_converter.py",
    code: `# Konverter suhu Celsius ke Fahrenheit dan Kelvin
print("=== KONVERTER SUHU ===")

# Input suhu dalam Celsius
celsius = float(input("Masukkan suhu dalam Celsius: "))

if celsius < -273.15:
    raise ValueError("Suhu tidak boleh lebih rendah dari nol mutlak")

# Konversi ke Fahrenheit dan Kelvin
fahrenheit = (celsius * 9/5) + 32
kelvin = celsius + 273.15

# Output hasil konversi
print(f"\\nHasil konversi dari {celsius}°C:")
print(f"Fahrenheit: {fahrenheit:.1f}°F")
print(f"Kelvin: {kelvin:.1f}K")

# Bonus: Informasi tambahan
if celsius < 0:
    print("Suhu ini di bawah titik beku air!")
elif celsius == 0:
    print("Suhu ini adalah titik beku air!")
elif celsius == 100:
    print("Suhu ini adalah titik didih air!")
elif celsius > 100:
    print("Suhu ini di atas titik didih air!")`
  }]}
/>

### Profil Mahasiswa

<CodeBlock
  data={[{
    language: "python",

    code: `# Program untuk mengumpulkan dan menampilkan informasi personal
print("=== PROFIL MAHASISWA ===")

print("PROFIL MAHASISWA")

print(f"Nama        : {nama}")
print(f"NIM         : {nim}")
print(f"Jurusan     : {jurusan}")
print(f"Semester    : {semester}")
print(f"Hobi        : {hobi}")
print(f"Tahun Masuk : {tahun_masuk}")
print(f"Perkiraan Lulus: {perkiraan_lulus}")
print("="*40)

# Pesan motivasi
if semester <= 2:
    print("Semangat di awal perkuliahan!")
elif semester <= 6:
