## Einführung in Python

Python ist eine beliebte Programmiersprache, bei der gut lesbarer Code im Mittelpunkt steht. Die klare Syntax macht Python zu einer guten ersten Sprache für Menschen, die mit dem Programmieren beginnen.

Viele Python-Anweisungen ähneln kurzen englischen Arbeitsaufträgen. Deshalb lässt sich oft schon erkennen, was ein Programm tut, bevor jedes Detail der Syntax bekannt ist. Python wird unter anderem in der Webentwicklung, Datenanalyse, im maschinellen Lernen und in der künstlichen Intelligenz eingesetzt.

Einzelheiten zur Sprache und ihrer Standardbibliothek stehen in der [offiziellen Python-Dokumentation](https://docs.python.org). Sie ist die maßgebliche Referenz für die jeweils verwendete Python-Version.

## Hello World Programm

Ein verbreitetes erstes Programm gibt den Text „Hello World!“ aus. Wenn es läuft, kann Python eine Datei ausführen, und du hast zugleich ein kleines, vollständiges Programm zum Untersuchen.

<CodeBlock
  data={[{
    language: "python",
    filename: "hello.py",
    code: `print("Hello World!")`
  }]}
/>

`print()` ist eine eingebaute Python-Funktion. Sie gibt den Text oder Wert in den Klammern auf dem Bildschirm aus.

## Drei Möglichkeiten, Python-Programme auszuführen

Diese Lektion nutzt drei verbreitete Wege, Python-Code auszuführen. Jeder davon unterstützt einen anderen Teil des Lernablaufs.

### Interaktiver Modus

Im interaktiven Modus kannst du Python-Code direkt im Terminal schreiben und ausführen. Das eignet sich gut, um kurze Ausdrücke zu prüfen oder etwas schnell auszuprobieren.

Öffne ein Terminal, gib `python` oder `python3` ein und drücke die Eingabetaste. Die Eingabeaufforderung `>>>` zeigt, dass Python bereit ist. Gib danach eine Python-Anweisung ein und bestätige erneut mit der Eingabetaste.

<CodeBlock
  data={[{
    language: "bash",
    filename: "terminal",
    code: `$ python3
Python 3.8.5 (default, Sep  4 2020, 02:22:02)
[Clang 10.0.0 ] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>> print("Hello World!")
Hello World!
>>> 2 + 3
5
>>> name = "Alice"
>>> print(f"Hello, {name}!")
Hello, Alice!
>>>`
  }]}
/>

### Skriptmodus

Im Skriptmodus wird eine gespeicherte Python-Datei ausgeführt. Das eignet sich für längere Programme und für Code, den du später erneut verwenden möchtest.

Erstelle dazu mit einem Texteditor eine Datei mit der Endung `.py`, schreibe den Python-Code hinein und speichere die Datei. Öffne anschließend ein Terminal, wechsle in den Ordner der Datei und führe `python dateiname.py` aus.

### Jupyter Lab und Notebooks

Jupyter ist eine interaktive Umgebung, die häufig für Data Science und Unterricht verwendet wird. Ein Notebook verbindet ausführbaren Code, dessen Ausgabe und schriftliche Erklärungen in einem Dokument.

Jede Zelle lässt sich einzeln ausführen, und ihre Ausgabe erscheint direkt darunter. Außerdem können Notebooks Erklärungen, Bilder und Diagramme enthalten. Das macht sie nützlich für Experimente und Datenanalysen.

Installiere JupyterLab in einer eigenen Python-Umgebung, damit seine Pakete nicht mit anderen Projekten in Konflikt geraten:

<CodeBlock
  data={[{

Python kennt mehrere grundlegende Datentypen. Ein Variablenname verweist auf einen Wert. Eine neue Zuweisung ändert diese Bindung, statt jeden Wert in einen veränderbaren Behälter zu verwandeln.

## Praktische Übungen

Probieren wir einige einfache Übungen aus, um das Gelernte in die Praxis umzusetzen:

### Einfacher Rechner

<CodeBlock
  data={[{
    language: "python",
    filename: "calculator.py",
    code: `# Einfacher Rechner
print("=== EINFACHER RECHNER ===")

# Eingabe vom Benutzer
number1 = float(input("Gib die erste Zahl ein: "))
operator = input("Gib den Operator (+, -, *, /) ein: ")
number2 = float(input("Gib die zweite Zahl ein: "))

# Berechnungsprozess
if operator == "+":
    result = number1 + number2
elif operator == "-":
    result = number1 - number2
elif operator == "*":
    result = number1 * number2
elif operator == "/":
    if number2 != 0:
        result = number1 / number2
    else:
        print("Fehler: Division durch Null nicht möglich!")
        result = None
else:
    print("Ungültiger Operator!")
    result = None

# Ausgabeergebnis
if result is not None:
    print(f"Ergebnis: {number1} {operator} {number2} = {result}")`
  }]}
/>

### Temperaturumrechnung

<CodeBlock
  data={[{
    language: "python",
    filename: "temperature_converter.py",
    code: `# Temperaturkonverter von Celsius in Fahrenheit und Kelvin
print("=== TEMPERATURKONVERTER ===")

# Eingabetemperatur in Celsius
celsius = float(input("Temperatur in Celsius eingeben: "))

if celsius < -273.15:
    raise ValueError("Die Temperatur darf nicht unter dem absoluten Nullpunkt liegen")

# In Fahrenheit und Kelvin umrechnen
fahrenheit = (celsius * 9/5) + 32
kelvin = celsius + 273.15

# Konvertierungsergebnisse ausgeben
print(f"\\nKonvertierungsergebnisse von {celsius}°C:")
print(f"Fahrenheit: {fahrenheit:.1f}°F")
print(f"Kelvin: {kelvin:.1f}K")

# Bonus: Zusätzliche Informationen
if celsius < 0:
    print("Diese Temperatur liegt unter dem Gefrierpunkt des Wassers!")
elif celsius == 0:
    print("Diese Temperatur ist der Gefrierpunkt von Wasser!")
elif celsius == 100:
    print("Diese Temperatur ist der Siedepunkt von Wasser!")
elif celsius > 100:
    print("Diese Temperatur liegt über dem Siedepunkt von Wasser!")`
  }]}
/>

<CodeBlock

print("=== SCHÜLERPROFIL ===")
