## Kod Boleh Guna Semula dengan Input dan Hasil

Fungsi <Highlight>memberi nama kepada satu operasi yang boleh digunakan semula</Highlight>. Parameternya menerangkan **input yang diterimanya**, badannya melakukan kerja, dan pernyataan `return` boleh memberi hasil kepada pemanggil.

## Struktur dan Sintaks Fungsi

Setiap fungsi Python mengikut **struktur asas** yang sama:

<CodeBlock

    statement_1
    statement_2

    }

Komponen fungsi terdiri daripada:

1. Kata kunci `def` untuk memulakan definisi fungsi
2. Nama fungsi yang mengikut peraturan penamaan pemboleh ubah Python
3. Kurungan yang mengandungi senarai parameter (boleh kosong)
4. Titik bertindih untuk menamatkan baris definisi
5. Blok kod yang diinden
6. Pernyataan `return` pilihan untuk memulangkan nilai

## Apa yang Berlaku Semasa Fungsi Dipanggil

Apabila kamu memanggil fungsi, Python menilai ungkapan yang boleh dipanggil itu, **mengikat argumen yang diberi kepada parameter**, lalu melaksanakan badan fungsi dalam bingkai setempat yang baharu.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "function_example.py",
      code: `# Definisi fungsi
def greet(name):
    message = f"Hello, {name}!"
    return message

# Panggilan fungsi
result = greet("Alice")
print(result)  # Output: Hello, Alice!

# Panggilan terus di dalam print
print(greet("Bob"))  # Output: Hello, Bob!`
    }
  ]}
/>

Proses yang berlaku semasa fungsi dipanggil:

1. Python menilai nama atau ungkapan itu dan menyemak sama ada hasilnya boleh dipanggil
2. Pengikatan argumen memadankan nilai yang diberi dengan tandatangan fungsi
3. Python melaksanakan badan fungsi dalam skop setempat yang baharu
4. `return` menamatkan panggilan dengan satu nilai. Jika fungsi sampai ke penghujungnya, ia memulangkan `None`

## Parameter dan Argumen

Parameter ialah pemboleh ubah yang ditulis dalam definisi fungsi, manakala argumen ialah **nilai sebenar yang kamu hantar** semasa memanggil fungsi itu. Python menawarkan beberapa jenis parameter, dan jenis yang digunakan oleh sesuatu definisi memberitahu kamu sama ada pemanggil mesti memberi nilai itu mengikut kedudukan, mengikut nama, atau tidak perlu memberinya langsung.

### Parameter Kedudukan dan Kata Kunci

<CodeBlock
  data={[

Peraturan parameter:

1. **Argumen kedudukan mengikut susunan parameter**
2. Argumen kata kunci boleh diberi dalam apa-apa susunan
3. Argumen kedudukan biasa diletakkan sebelum argumen kata kunci
4. Parameter yang ada nilai lalai tidak wajib diberi

## Skop Pemboleh Ubah dalam Fungsi

Pemboleh ubah dalam Python ada skop yang menentukan **di mana pemboleh ubah itu boleh dicapai**. Kamu perlu faham skop pemboleh ubah supaya dapat mengelakkan ralat dalam atur cara.

### Pemboleh Ubah Setempat dan Sejagat

<CodeBlock
  data={[
    {
      language: "python",
      filename: "scope_variables.py",
      code: `# Pemboleh ubah sejagat
counter = 0

def add_counter():
    # Pemboleh ubah setempat dengan nama yang sama
    counter = 10
    print(f"Pembilang setempat: {counter}")

def add_global_counter():
    global counter
    counter += 1
    print(f"Pembilang sejagat: {counter}")

# Demonstrasi penggunaan
print(f"Pembilang awal: {counter}")       # Output: Pembilang awal: 0
add_counter()                        # Output: Pembilang setempat: 10
print(f"Pembilang selepas fungsi: {counter}")  # Output: Pembilang selepas fungsi: 0
add_global_counter()                 # Output: Pembilang sejagat: 1
print(f"Pembilang akhir: {counter}")      # Output: Pembilang akhir: 1`
    }
  ]}
/>

Carian nama mengikut **susunan LEGB**:

1. **Local** - di dalam fungsi semasa
2. **Enclosing** - di dalam fungsi yang melingkunginya (untuk fungsi bersarang)
3. **Global** - pada peringkat modul
4. **Built-in** - nama terbina dalam Python

## Dokumentasi Fungsi dengan Docstring

Docstring ialah literal rentetan yang diletakkan sebagai **pernyataan pertama** dalam definisi fungsi. Ia menerangkan apa yang dilakukan oleh fungsi itu dan cara menggunakannya.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "docstring_example.py",
      code: `def calculate_factorial(n):
    """
    Kira faktorial bagi integer bukan negatif.

    Parameters:
        n (int): Integer bukan negatif

    Returns:
        int: Nilai faktorial bagi n

    Raises:
        ValueError: Jika n negatif
        TypeError: Jika n bukan integer

    Example:
        >>> calculate_factorial(5)
        120
        >>> calculate_factorial(0)
        1
    """
    if not isinstance(n, int):
        raise TypeError("Input mesti integer")
    if n < 0:
        raise ValueError("Input mesti positif atau sifar")

    if n <= 1:
        return 1
    return n * calculate_factorial(n - 1)

# Capai docstring
print(calculate_factorial.__doc__)

# Gunakan fungsi
print(calculate_factorial(5))  # Output: 120
print(calculate_factorial(0))  # Output: 1`
    }
  ]}
/>

Amalan yang baik semasa menulis docstring:

1. Baris pertama mengandungi ringkasan pendek tentang fungsi
2. Jika penerangan terperinci diperlukan, pisahkan dengan baris kosong
3. Terangkan parameter, nilai pulangan, dan pengecualian yang mungkin berlaku
4. Beri contoh penggunaan jika membantu

## Fungsi Bersarang dan Closure

Python membenarkan definisi fungsi di dalam fungsi lain. Apabila fungsi dalaman yang dipulangkan masih menyimpan **pemboleh ubah bebas daripada skop yang melingkunginya**, fungsi itu bersama persekitaran yang disimpannya membentuk closure.

<CodeBlock
  data={[

    return multiplier

print(multiply_five(4))   # Output: 20

        'subtract': subtract,

    }

calc = simple_calculator()
print(calc['add'](5, 3))  # Output: 8
print(calc['subtract'](10, 4)) # Output: 6

    }

## Pengendalian Ralat dalam Fungsi

Fungsi patut menyatakan **input yang diterimanya** dan gagal secara eksplisit apabila kontrak itu dilanggar. Tangkap pengecualian hanya di tempat kod boleh pulih, boleh menambah konteks yang berguna, atau boleh memaparkan kegagalan itu kepada pengguna.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "error_handling.py",
      code: `def divide(numerator, denominator):
    """Bahagi dua nombor nyata dengan kontrak input yang eksplisit."""
    if not isinstance(numerator, (int, float)):
        raise TypeError("Pengangka mesti nombor nyata")
    if not isinstance(denominator, (int, float)):
        raise TypeError("Penyebut mesti nombor nyata")
    if denominator == 0:
        raise ValueError("Penyebut tidak boleh sifar")
    return numerator / denominator

def convert_to_int(value):
    """Tukar nilai yang disokong, atau biarkan ralat penukaran Python berlaku."""
    return int(value)

# Panggilan yang berjaya ditulis terus tanpa try
print(f"Hasil bahagi: {divide(10, 2)}")
# Output: Hasil bahagi: 5.0
print(convert_to_int("123"))
# Output: 123

# Tangkap di sempadan paparan, iaitu tempat pemulihan boleh dilakukan
for value in ("abc", [1, 2]):
    try:
        print(convert_to_int(value))
    except (TypeError, ValueError) as error:
        print(f"Tidak dapat menukar {value!r}: {error}")`
    }
  ]}
