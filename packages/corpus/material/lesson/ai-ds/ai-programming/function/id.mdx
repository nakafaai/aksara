## Fungsi

Fungsi memberi nama pada sekumpulan instruksi agar logika yang sama dapat dijalankan tanpa menyalin kode. Parameter menyatakan input yang diterima, function body berisi kode yang dijalankan, dan statement `return` mengirimkan hasil kepada pemanggil.

## Struktur dan Sintaks Fungsi

Setiap fungsi Python mengikuti struktur dasar yang sama:

Komponen fungsi terdiri dari:

1. Kata kunci `def` untuk memulai definisi fungsi
2. Nama fungsi yang mengikuti aturan penamaan variabel Python
3. Tanda kurung yang berisi daftar parameter (bisa kosong)
4. Titik dua untuk mengakhiri baris definisi
5. Blok kode yang diindentasi
6. Statement `return` bersifat opsional dan mengembalikan nilai kepada pemanggil

## Cara Kerja Pemanggilan Fungsi

Saat fungsi dipanggil, Python memastikan nama atau ekspresi tersebut merujuk ke objek callable. Python kemudian memasangkan setiap argumen dengan parameter dan menjalankan function body di local scope baru.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "contoh_fungsi.py",
      code: `# Definisi fungsi
def sapa(nama):
    pesan = f"Halo, {nama}!"
    return pesan

# Pemanggilan fungsi
hasil = sapa("Alice")
print(hasil)  # Output: Halo, Alice!

# Pemanggilan langsung dalam print
print(sapa("Bob"))  # Output: Halo, Bob!`
    }
  ]}
/>

Proses yang terjadi saat pemanggilan fungsi:

1. Python mengevaluasi nama atau ekspresi dan memeriksa bahwa hasilnya callable
2. Argument binding memasangkan setiap argumen dengan parameter pada definisi fungsi
3. Python menjalankan function body di local scope baru
4. `return` mengakhiri pemanggilan dengan nilai. Mencapai akhir fungsi mengembalikan `None`

## Parameter dan Argumen

Parameter adalah variabel yang didefinisikan dalam fungsi, sedangkan argumen adalah nilai aktual yang dikirimkan saat memanggil fungsi. Python menyediakan beberapa jenis parameter untuk fleksibilitas yang lebih besar.

1. Argumen posisi diberikan sesuai urutan parameter

3. Argumen posisi ditulis sebelum keyword argument
4. Parameter dengan default value tidak wajib diberi argumen

Aturan pencarian variabel mengikuti urutan LEGB:

1. **Local** - di dalam fungsi saat ini
2. **Enclosing** - di fungsi luar tempat fungsi saat ini dibuat, khusus untuk fungsi bersarang
3. **Global** - di level modul
4. **Built-in** - nama yang disediakan Python

## Dokumentasi Fungsi dengan Docstring

Docstring adalah string literal yang ditempatkan sebagai statement pertama dalam definisi fungsi. Isinya menjelaskan tujuan fungsi dan cara menggunakannya.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "docstring_example.py",
      code: `def hitung_faktorial(n):
    """
    Menghitung faktorial dari bilangan bulat positif.

    Parameter:
        n (int): Bilangan bulat nonnegatif

    Returns:
        int: Nilai faktorial dari n

    Raises:
        ValueError: Jika n negatif
        TypeError: Jika n bukan bilangan bulat

    Contoh:
        >>> hitung_faktorial(5)
        120
        >>> hitung_faktorial(0)
        1
    """
    if not isinstance(n, int):
        raise TypeError("Input harus berupa bilangan bulat")
    if n < 0:
        raise ValueError("Input harus bilangan positif atau nol")

    if n <= 1:
        return 1
    return n * hitung_faktorial(n - 1)

# Mengakses docstring
print(hitung_faktorial.__doc__)

# Menggunakan fungsi
print(hitung_faktorial(5))  # Output: 120
print(hitung_faktorial(0))  # Output: 1`
    }
  ]}
/>

Konvensi penulisan docstring yang baik:

1. Baris pertama berisi ringkasan singkat fungsi
2. Jika perlu penjelasan tambahan, pisahkan dengan baris kosong
3. Jelaskan parameter, return value, dan exception yang mungkin terjadi
4. Berikan contoh penggunaan jika membantu

## Error Handling dalam Fungsi

Tentukan jenis dan nilai input yang diterima fungsi, lalu hasilkan error yang jelas ketika kontrak input dilanggar. Tangkap exception hanya ketika kode dapat memulihkan keadaan, menambahkan keterangan yang berguna, atau menjelaskan kegagalan kepada pengguna.
