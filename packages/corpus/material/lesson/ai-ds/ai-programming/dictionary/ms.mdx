## Definisi Kamus dan Cara Membinanya

Kamus (dictionary) ialah pemetaan yang boleh diubah (mutable) daripada **kunci unik kepada nilai**. Kamu mencari setiap item melalui kunci yang bermakna, contohnya nama, pengecam atau tarikh.

### Pelbagai Cara Membina Kamus

Python menyediakan beberapa cara untuk membina kamus, termasuk **kamus kosong** dan kamus yang sudah berisi data.

b = dict()
print("Kamus kosong a:", a)
print("Kamus kosong b:", b)
# Output: Kamus kosong a: {}
# Output: Kamus kosong b: {}

# Membina kamus yang berisi data
phone = {'ann': 110, 'bob': 991, 'cat': 112, 'dan': 999}
print("Kamus phone:", phone)
# Output: Kamus phone: {'ann': 110, 'bob': 991, 'cat': 112, 'dan': 999}

# Membina kamus bersarang
person = {1: {'name': 'ann', 'age': 23}, 2: {'name': 'bob', 'age': 21}}
print("Kamus bersarang:", person)
# Output: Kamus bersarang: {1: {'name': 'ann', 'age': 23}, 2: {'name': 'bob', 'age': 21}}

### Sintaks Kamus

Paparan kamus (dictionary display) menggunakan tanda kurung kerinting. Koma memisahkan setiap entri, dan **titik bertindih** memisahkan setiap kunci daripada nilainya. Paparan kosong `{}` membina kamus kosong.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "dictionary_syntax.py",
      code: `# Sintaks asas kamus
phone = {'ann': 110, 'bob': 991, 'cat': 112, 'don': 999}
print(phone)
# Output: {'ann': 110, 'bob': 991, 'cat': 112, 'don': 999}`
    }
  ]}
/>

**Kunci mesti boleh dicincang (hashable)**. Rentetan dan nombor ialah pilihan yang biasa. Tuple hanya layak apabila setiap unsurnya juga boleh dicincang. Tuple yang mengandungi senarai tidak layak. Senarai itu sendiri tidak boleh dicincang. Nilai pula boleh jadi apa-apa objek Python, termasuk kamus lain.

## Kamus sebagai Bekas

Kamus ialah bekas (container) kerana ia memegang sekumpulan objek lain. Ciri utamanya ialah **memetakan setiap kunci kepada satu nilai** sambil mengekalkan susunan kunci itu mula-mula dimasukkan.

## Ciri-ciri Kamus

Kamus boleh diubah, **kuncinya unik dan boleh dicincang**, dan susunan lelarannya mengikut susunan kunci dimasukkan. Tiga sifat ini menerangkan kebanyakan tingkah laku yang kamu akan lihat nanti: kenapa kamu boleh menambah atau membuang entri selepas kamus dibina, kenapa umpukan kepada kunci yang sudah ada menulis ganti nilainya dan bukan menduplikasikannya, dan kenapa lelaran ke atas kamus memberi susunan yang stabil dan boleh dijangka.

### Susunan Kemasukan dan Kunci Unik

Spesifikasi bahasa Python menjamin susunan kemasukan kamus mulai Python `3.7`. Apabila kamu mengumpukkan nilai baharu kepada kunci yang sudah ada, entri itu dikemas kini **tanpa mengalihkan kunci itu**. Kalau kamu memadam kunci itu lalu memasukkannya semula, kunci itu akan berada di hujung.

Kunci dalam kamus sentiasa unik. Dalam `d = {'a': 1, 'b': 2, 'a': 3}`, kunci `'a'` muncul dua kali dan umpukan yang terakhir menang, jadi `d` hanya memegang dua pasangan, dengan `d['a']` sama dengan `3`.

## Mengakses Kamus

Untuk mendapatkan nilai daripada kamus, **berikan kuncinya**. Kunci yang bermakna seperti nama atau tarikh mengambil tempat indeks nombor yang berturutan, jadi kamu tidak perlu mengingati kedudukan setiap nilai.

### Pengindeksan dengan Kunci

<CodeBlock
  data={[
    {
      language: "python",
      filename: "dictionary_indexing.py",
      code: `# Mengakses nilai dengan kunci
phone = {'ann': 110, 'bob': 991, 'cat': 112, 'dan': 999}

# Mendapatkan nilai
print(phone['cat'])
# Output: 112

# Menggunakan pemboleh ubah sebagai kunci
name = 'bob'
print(phone[name])
# Output: 991

phone['bob'] = 999  # Tukar nilai bagi kunci yang sudah ada
phone['eve'] = 111  # Tambah kunci baharu
print(phone)
# Output: {'ann': 110, 'bob': 999, 'cat': 112, 'dan': 999, 'eve': 111}`
    }
  ]}
/>

Akses dengan kurungan siku mendapatkan nilai yang sudah ada. Umpukan dengan kurungan siku pula **mengemas kini kunci yang sudah ada** atau menambah pasangan kunci-nilai baharu di hujung susunan kemasukan.

Untuk `phone = {'ann': 110, 'bob': 991, 'cat': 112, 'dan': 999}`, `phone['ann']` dan `phone.get('ann', 0)` kedua-duanya memberi `110`. Kunci `'eve'` pula tiada: `phone['eve']` menimbulkan `KeyError`, manakala `phone.get('eve', 0)` memulangkan nilai sandaran `0`.

## Lelaran Kamus

Pilih bentuk lelaran yang sepadan dengan apa yang kamu perlukan: **kunci sahaja, nilai sahaja**, atau kedua-dua bahagian setiap entri. Melelar kamus secara terus memberi kunci, memanggil `.values()` memberi nilai, dan memanggil `.items()` memberi pasangan kunci-nilai.

### Melelar Kunci Kamus

<CodeBlock
  data={[
    {
      language: "python",
      filename: "dictionary_simple_loop.py",
      code: `# Melelar kunci kamus
phone = {'ann': 110, 'bob': 999, 'cat': 112, 'dan': 999}

for key in phone:
    print(key, phone[key])
# Output:
# ann 110
# bob 999
# cat 112
# dan 999`
    }
  ]}
/>

Apabila kamu melelar kamus secara terus, Python mengambil **kunci mengikut susunan kemasukannya**.

### Melelar Entri Kamus

<CodeBlock
  data={[
    {
      language: "python",

      code: `# Melelar pasangan kunci-nilai dengan items()

Pandangan `items()` menghasilkan **setiap kunci dan nilai bersama-sama**, jadi pembongkaran tuple (tuple unpacking) boleh menamakan kedua-duanya dalam satu gelung.

## Tiga Jenis Pandangan Kamus

Kamus menyediakan **pandangan dinamik** (dynamic view) bagi kunci, nilai dan pasangan kunci-nilainya. Pandangan bukan salinan: ia membaca isi semasa kamus setiap kali kamu melelarnya, jadi perubahan yang dibuat selepas pandangan itu dibina terus kelihatan dalam gelung yang berikutnya.

### Membina Pandangan Kamus

<CodeBlock
  data={[
    {
      language: "python",
      filename: "dictionary_methods.py",
      code: `# Menggunakan kaedah kamus
phone = {'ann': 110, 'bob': 991, 'cat': 112, 'dan': 999}

# Mendapatkan semua kunci
keys = phone.keys()
print("Kunci:", list(keys))
# Output: Kunci: ['ann', 'bob', 'cat', 'dan']

# Mendapatkan semua nilai
values = phone.values()
print("Nilai:", list(values))
# Output: Nilai: [110, 991, 112, 999]

# Mendapatkan pasangan kunci-nilai
items = phone.items()
print("Item:", list(items))
# Output: Item: [('ann', 110), ('bob', 991), ('cat', 112), ('dan', 999)]

snapshot = list(keys)
phone['eve'] = 111
print(list(keys))  # Output: ['ann', 'bob', 'cat', 'dan', 'eve']
print(snapshot)    # Output: ['ann', 'bob', 'cat', 'dan']`
    }
  ]}
/>

Pandangan ini menyokong lelaran, tetapi tidak menyokong pengindeksan mengikut kedudukan atau umpukan item. Memanggil `list()` membina **salinan pegun (snapshot) bagi entri semasa**. Kunci yang dimasukkan kemudian akan muncul dalam pandangan, tetapi tidak dalam salinan pegun itu. Kalau sesuatu nilai boleh diubah, salinan pegun itu masih memegang rujukan kepada objek yang sama.

## Kaedah Get

Guna `get()` apabila kunci yang tiada memang dijangka dan kamu mahukan **nilai sandaran**. Guna akses kurungan siku apabila kunci yang tiada patut dianggap sebagai ralat.

### Ralat daripada Akses Kurungan Siku kepada Kunci yang Tiada

<CodeBlock
  data={[
    {
      language: "python",
      filename: "dictionary_indexing_problem.py",
      code: `# Masalah apabila mengakses kunci yang tidak wujud
phone = {'ann': 110, 'bob': 991, 'cat': 112, 'dan': 999}

except KeyError as e:
    print("KeyError:", e)
# Output: KeyError: 'pat'`
    }
  ]}
/>

Mengindeks kamus dengan **kunci yang tidak wujud** akan menimbulkan `KeyError`.

### Penyelesaian dengan Kaedah Get

<CodeBlock
  data={[
    {
      language: "python",
      filename: "dictionary_get_method.py",
      code: `# Menggunakan kaedah get() untuk akses yang selamat
phone = {'ann': 110, 'bob': 991, 'cat': 112, 'dan': 999}

# get() memulangkan None jika kunci tidak wujud
result = phone.get('pat')
print("Hasil get('pat'):", result)
# Output: Hasil get('pat'): None

# get() dengan nilai lalai
result = phone.get('pat', -1)
print("Hasil get('pat', -1):", result)
# Output: Hasil get('pat', -1): -1

# get() untuk kunci yang wujud
result = phone.get('ann')
print("Hasil get('ann'):", result)
# Output: Hasil get('ann'): 110`
    }
  ]}
/>

`get()` memulangkan nilai yang disimpan apabila kunci itu wujud. Kalau tidak, ia memulangkan **nilai lalai yang kamu berikan**, atau `None` jika tiada nilai lalai diberikan. Apabila perbezaan itu penting, pilih nilai lalai yang tidak mungkin tertukar dengan nilai sah yang tersimpan.

Kira huruf dalam `"banana"` dengan `counts[ch] = counts.get(ch, 0) + 1`. Apabila sesuatu huruf muncul buat kali pertama, `get` memulangkan nilai lalai `0`, jadi tiada `KeyError`. Hasilnya ada dalam gambar: `{"b": 1, "a": 3, "n": 2}`, dengan kunci mengikut susunan ia mula-mula muncul. Jumlah tinggi semua bar ialah `6`, sama dengan `len("banana")`.
