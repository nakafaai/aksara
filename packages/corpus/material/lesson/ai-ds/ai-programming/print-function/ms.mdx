## Menulis Nilai ke Strim Output

Fungsi terbina dalam `print()` <Highlight>menulis perwakilan teks bagi nilai ke satu strim</Highlight>. Secara lalai, strim itu ialah `sys.stdout`, dan terminal biasanya memaparkannya pada skrin. Namun, output juga boleh dihalakan ke fail atau destinasi lain.

Fungsi print tergolong dalam kategori fungsi terbina dalam, sama seperti `len()`, `abs()` dan `round()`. Maksudnya, kamu tidak perlu mengimport modul tambahan untuk menggunakannya.

## Sintaks Asas Fungsi Print

Sintaks lengkap fungsi print mempunyai beberapa **parameter output** untuk mengawal cara output dipaparkan.

Tatatanda `*objects` bermaksud `print()` menerima sifar atau lebih objek sebagai argumen kedudukan. Fungsi ini menulis pemisah yang ditetapkan oleh `sep` di antara objek yang bersebelahan.

## Parameter Sep

Parameter `sep` menentukan aksara atau rentetan yang memisahkan beberapa objek dalam satu panggilan print. Nilai lalai `sep` ialah **satu ruang kosong**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "separator_param.py",
      code: `# Contoh penggunaan parameter sep
x = 8

# Pemisah lalai (ruang)
print("Selesaikan", 2, "x =", x, "untuk x")

# Pemisah tersuai dengan rentetan kosong
print("Selesaikan", 2, "x =", x, "untuk x", sep="")

# Pemisah tersuai dengan sengkang
print("Selesaikan", 2, "x =", x, "untuk x", sep="-")

# Pemisah tersuai dengan koma dan ruang
print("Ahmad", "Budi", "Citra", sep=", ")

# Pemisah dengan beberapa aksara
print("Python", "Java", "JavaScript", sep=" | ")

# Pemisah dengan aksara khas
print("Data", "Science", "Machine", "Learning", sep="\\t")  # tab
print("Baris", "Pertama", "Baris", "Kedua", sep="\\n")     # baris baharu`
    }
  ]}
/>

Nilai `sep` menentukan aksara tepat yang ditulis di antara objek yang bersebelahan, contohnya ruang, koma, tab atau pemisah baris.

`print(1, 2, 3, sep=s)` menulis tiga aksara digit dan menyelitkan `s` sebanyak dua kali di antaranya. Panjang baris output, tanpa baris baharu di hujungnya, ialah <InlineMath math="3+2k" />, dengan keadaan <InlineMath math="k" /> ialah `len(s)`.

## Parameter End

Parameter `end` menetapkan aksara atau rentetan yang ditulis selepas objek yang dicetak. <Highlight>Nilai lalainya ialah pemisah baris</Highlight> (`\n`), jadi panggilan `print` yang seterusnya bermula pada baris baharu.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "end_parameter.py",
      code: `# Contoh penggunaan parameter end

# end lalai (baris baharu)

print("Baris kedua")

print()  # Cetak baris kosong sebagai pemisah

# end tersuai dengan rentetan kosong
print("Perkataan pertama", end="")
print("Perkataan kedua")

print()  # Cetak baris kosong sebagai pemisah

# end tersuai dengan ruang
print("Nombor:", end=" ")
print(42)

print()  # Cetak baris kosong sebagai pemisah

# end tersuai dengan aksara khas
print("Memuatkan", end="")
for i in range(5):
    print(".", end="")
print(" Selesai!")

print()  # Cetak baris kosong sebagai pemisah

# Gabungan sep dan end
print("A", "B", "C", sep="-", end=" | ")
print("D", "E", "F", sep="-", end="\\n")`
    }
  ]}
/>

Apabila kamu mengubah `end`, beberapa panggilan boleh bersambung pada satu baris. Berikan `flush=True` apabila output mesti muncul serta-merta, kerana ini terus menulis sebarang teks yang masih berada dalam penimbal.

## Memaparkan Pelbagai Jenis Data

`print()` menerima objek pelbagai jenis dan mendapatkan **perwakilan rentetan yang mudah dibaca oleh manusia** bagi setiap objek sebelum menulisnya. Kelas tersuai boleh mengawal perwakilan itu dengan `__str__()`.

## Teknik Pemformatan Output

Panggilan `print()` biasa sudah cukup untuk melihat sepintas lalu, tetapi output berformat memerlukan satu alat lagi. F-string membina **satu nilai teks** daripada ungkapan yang diletakkan terus di sebelah perkataan di sekelilingnya, dan argumen `end` mengawal apa yang ditulis oleh `print()` selepas nilai itu. Kedua-duanya memastikan output mudah dibaca tanpa langkah penyambungan yang berasingan.

### Mencetak dengan F String

F-string menilai **ungkapan di dalam kurungan kerinting** dan menggunakan spesifikasi format pilihan. Dengan cara ini, nilai dan teks di sekelilingnya kekal dalam satu ungkapan yang mudah dibaca.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "fstring_formatting.py",
      code: `# Contoh pemformatan dengan f-string
name = "Sari"
age = 23
score = 87.5

# Pemformatan asas f-string
print(f"Nama: {name}")
print(f"Umur: {age} tahun")
print(f"Markah: {score}")

# F-string dengan operasi matematik
x = 10
y = 3
print(f"{x} + {y} = {x + y}")
print(f"{x} / {y} = {x / y:.2f}")

# F-string dengan panggilan kaedah
text = "python programming"
print(f"Asal: {text}")
print(f"Huruf awal besar: {text.title()}")
print(f"Panjang: {len(text)} aksara")

# F-string dengan syarat
score = 85
status = "Lulus" if score >= 70 else "Gagal"
print(f"Markah: {score}, Status: {status}")

# F-string dengan pemformatan nombor
pi = 3.14159265359
print(f"Pi dengan 2 tempat perpuluhan: {pi:.2f}")
print(f"Pi dengan 4 tempat perpuluhan: {pi:.4f}")
completion = 0.875
print(f"Kadar siap: {completion:.1%}")  # 87.5%`
    }
  ]}
/>

F-string menggabungkan teks dengan pemboleh ubah atau hasil pengiraan dalam satu ungkapan.

### Mencetak Tanpa Baris Baharu

Apabila kamu mahu memaparkan output pada satu baris sedikit demi sedikit, ubah parameter `end` untuk **mengelakkan baris baharu automatik**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "print_no_newline.py",
      code: `# Contoh print tanpa baris baharu
import time

# Simulasi proses memuatkan dengan titik
print("Memproses", end="")
for i in range(5):
    time.sleep(0.5)  # Tunggu setengah saat
    print(".", end="", flush=True)
print(" Selesai!")

# Membina bar kemajuan yang ringkas
print("\\nKemajuan: [", end="")
for i in range(10):
    time.sleep(0.2)
    print("#", end="", flush=True)
print("] 100%")

# Cetak kiraan dalam satu baris
print("\\nKira detik: ", end="")
for i in range(5, 0, -1):
    print(i, end=" ", flush=True)
    time.sleep(1)
print("Mula!")

# Memaparkan data dalam format jadual
print("\\nJadual Data:")
print("Nama", "Umur", "Bandar", sep="\\t")
print("-" * 30)
print("Ahmad", 25, "Jakarta", sep="\\t")
print("Budi", 30, "Bandung", sep="\\t")
print("Citra", 28, "Surabaya", sep="\\t")`
    }
  ]}
/>

Argumen `end` mengekalkan setiap kemas kini pada baris semasa, manakala `flush=True` meminta Python menulis output dalam penimbal dengan segera. Untuk paparan kemajuan yang sebenar, ambil kira juga keupayaan terminal, dan jangan anggap tab atau lebar aksara dipaparkan sama di semua tempat.
