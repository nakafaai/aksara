## Broadcasting dalam NumPy

[Broadcasting](https://numpy.org/doc/stable/user/basics.broadcasting.html) (penyiaran) ialah peraturan NumPy untuk menggabungkan tatasusunan yang mempunyai **bentuk berbeza tetapi serasi**. Dimensi bersaiz satu dianggap seolah-olah saiznya sama dengan dimensi sepadan pada tatasusunan yang satu lagi, tanpa menyalin data ke dalam tatasusunan yang lebih besar.

Pemvektoran (vectorization) membolehkan satu ungkapan bertindak ke atas seluruh tatasusunan. NumPy menjalankan gelung di sebaliknya dalam kod terkompil yang dioptimumkan, dan cara ini selalunya lebih pantas daripada gelung Python yang ditulis secara jelas.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "vectorization_example.py",
      code: `import numpy as np

# Cipta dua tatasusunan
a = np.array([0, 1, 2])
b = np.array([2, 2, 2])

# Operasi pemvektoran (unsur demi unsur)
result = a + b
print(result)
# Output: [2 3 4]`
    }
  ]}
/>

Dalam contoh di atas, NumPy menambah unsur pada kedudukan yang sepadan. Kita huraikan operasi itu sekali sahaja, dan NumPy uruskan kedudukan setiap unsur untuk kita.

### Peraturan Broadcasting

Dua tatasusunan boleh digabungkan tanpa gelung eksplisit apabila NumPy dapat <Highlight>menyejajarkan dimensinya</Highlight> dengan sendiri. Untuk menentukan sama ada dua bentuk itu serasi, NumPy membandingkan dimensinya dari kanan ke kiri dan berhenti pada pasangan pertama yang tidak dapat disejajarkan.

Tiga peraturan meliputi semua kes. Jadual di bawah menyatakan syarat yang disemak oleh setiap peraturan dan hasil yang NumPy keluarkan untuk syarat itu.

| Peraturan | Syarat pada bentuk | Apa yang NumPy lakukan |
| --- | --- | --- |
| Peraturan <InlineMath math="1" /> | Kedua-dua bentuk mempunyai bilangan dimensi yang berbeza | NumPy menambah dimensi bersaiz <InlineMath math="1" /> di sebelah kiri bentuk yang lebih pendek |
| Peraturan <InlineMath math="2" /> | Sesuatu pasangan yang sejajar mempunyai saiz yang sama, atau salah satunya bersaiz <InlineMath math="1" /> | Saiz yang sama memang sudah sepadan. Dimensi bersaiz satu digunakan semula secara konsep tanpa membina salinan berulang |
| Peraturan <InlineMath math="3" /> | Sesuatu pasangan yang sejajar mempunyai saiz berbeza dan tiada satu pun yang bersaiz <InlineMath math="1" /> | NumPy menimbulkan `ValueError` |

### Tatasusunan dengan Skalar

Broadcasting juga berlaku antara **tatasusunan dengan satu nombor**. NumPy meregangkan skalar itu ke setiap unsur, jadi kamu tidak perlukan gelung eksplisit.

Apabila tatasusunan mempunyai **bentuk yang serasi tetapi berbeza**, NumPy boleh melaraskannya secara automatik melalui broadcasting. Dengan cara ini, satu operasi dikenakan pada setiap baris atau lajur tanpa perlu menyalin nilai secara manual.

## Operasi Aritmetik Tatasusunan

Operator aritmetik NumPy berfungsi **unsur demi unsur**, kecuali jika sesuatu operasi memang mempunyai semantik yang berbeza, contohnya pendaraban matriks.

Apabila tatasusunan digabungkan dengan skalar, broadcasting mengenakan skalar itu pada setiap unsur. Kamu tidak perlu menulis gelung pengindeksan secara manual.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "arithmetic_scalar.py",
      code: `import numpy as np

a = np.array([0, 1, 2, 3, 4])

# Penambahan dengan skalar
print("Penambahan:")
print(f"a + 1 = {a + 1}")
# Output: [1 2 3 4 5]

# Pendaraban dengan skalar
print("Pendaraban:")
a *= 2
print(f"a *= 2: {a}")
# Output: [0 2 4 6 8]

# Kuasa
print("Kuasa:")
print(f"2**a = {2**a}")
# Output: [  1   4  16  64 256]`
    }
  ]}
/>

### Operasi antara Tatasusunan

<CodeBlock
  data={[
    {
      language: "python",
      filename: "arithmetic_arrays.py",
      code: `import numpy as np

a = np.array([0, 1, 2, 3, 4])
b = np.array([4, 3, 2, 1, 0])

# Penolakan unsur demi unsur
print("Penolakan:")
print(f"a - b = {a - b}")
# Output: [-4 -2  0  2  4]

# Pendaraban unsur demi unsur
print("Pendaraban unsur demi unsur:")
print(f"a * b = {a * b}")
# Output: [0 3 4 3 0]

# Pendaraban matriks (hasil darab skalar)
print("Pendaraban matriks:")
print(f"a @ b = {a @ b}")
# Output: 10`
    }
  ]}
/>

Operator `*` mendarab **entri pada kedudukan yang sama**. Untuk dua tatasusunan satu dimensi di atas, `@` memulangkan hasil darab skalar (dot product) kedua-duanya: `0 + 3 + 4 + 3 + 0` sama dengan `10`. Untuk dua matriks, `@` mengikut peraturan baris darab lajur. Jangan anggap `np.dot()` setara dengan `@` untuk semua bentuk tatasusunan. Peraturan kedua-duanya berbeza dalam dimensi yang lebih tinggi.

### Perbandingan dan Logik

Operasi perbandingan NumPy menghasilkan **tatasusunan boolean**. Gunakan tatasusunan itu untuk menapis data atau menggabungkan beberapa syarat.

Letakkan setiap perbandingan dalam tanda kurung kerana keutamaan operator ini berbeza daripada operator perbandingan. Operator skalar Python `not`, `and` dan `or` tidak menjalankan logik tatasusunan unsur demi unsur.

## Fungsi Statistik dan Penurunan

Fungsi penurunan (reduction) menggabungkan **banyak unsur menjadi lebih sedikit nilai**. Tanpa `axis`, penurunan menggabungkan semua unsur menjadi satu nilai. Dengan `axis`, ia menggabungkan nilai sepanjang paksi itu dan membiarkan paksi lain di tempatnya. Untuk jadual markah peperiksaan, cara ini boleh menghasilkan purata bagi setiap subjek atau setiap murid.

NumPy menyediakan fungsi statistik untuk ringkasan seperti jumlah, min dan sisihan piawai. Setiap fungsi boleh memproses seluruh tatasusunan atau paksi yang dipilih.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "basic_statistics.py",
      code: `import numpy as np

# Cipta tatasusunan 2D sebagai contoh

                 [2, -1, -2, 4],
                 [1, 7, 0, 4]])

print("Tatasusunan data:")

print(f"Nilai minimum: {np.min(data)}")
print(f"Nilai maksimum: {np.max(data)}")
print(f"Sisihan piawai: {np.std(data):.2f}")
# Output:
# Jumlah keseluruhan: 18
# Min: 1.50

# Nilai maksimum: 7
# Sisihan piawai: 2.50`
    }
  ]}

### Operasi dengan Paksi

Untuk tatasusunan dua dimensi, `axis=0` memampatkan dimensi baris dan menghasilkan **satu nilai bagi setiap lajur**. `axis=1` pula memampatkan dimensi lajur dan menghasilkan satu nilai bagi setiap baris.

Paksi yang dipilih menentukan dimensi mana yang diturunkan oleh fungsi statistik. Untuk data jualan bulanan bagi beberapa produk, satu paksi boleh menghasilkan jumlah bagi setiap produk, dan paksi yang satu lagi menghasilkan jumlah bagi setiap bulan.

## Manipulasi Bentuk Tatasusunan

Operasi bentuk menyusun semula cara unsur yang sama diindeks. Reshape memastikan **bilangan unsur tidak berubah** sambil meletakkan unsur itu ke dalam dimensi yang berbeza.

Tatasusunan NumPy yang baharu biasanya bersifat C-contiguous, iaitu indeks terakhir berubah paling pantas dalam memori. Pandangan (view) yang dicipta melalui penghirisan atau transpos boleh mempunyai langkah (stride) yang berbeza, jadi tatasusunan tidak selalu disimpan dalam satu susun atur baris-major yang ringkas. Peraturan `order` dan stride penting apabila kamu membentuk semula atau meratakan tatasusunan.

print("Tatasusunan 2D:")
print(a)
print(f"Bentuk: {a.shape}")

### Flatten dan Ravel

Kedua-dua `flatten()` dan `ravel()` memulangkan tatasusunan satu dimensi. `flatten()` **sentiasa mencipta salinan**, manakala `ravel()` memulangkan pandangan apabila boleh, dan memulangkan salinan apabila susun atur memori memerlukannya.

<CodeBlock
  data={[

      language: "python",
      filename: "flatten_ravel.py",

# Cipta tatasusunan pepenjuru
a = np.diag([1, 2, 3])
print("Tatasusunan pepenjuru:")
print(a)

# Flatten - mencipta salinan yang bebas
b_flatten = a.flatten()
print(f"Hasil flatten: {b_flatten}")

# Mengubah nilai hasil flatten tidak menjejaskan tatasusunan asal
b_flatten[0] = 9
print(f"Selepas mengubah flatten: {b_flatten}")
print("Tatasusunan asal kekal sama:")
print(a)

print()

# Ravel - cuba mencipta pandangan dan tidak sentiasa menyalin data
b_ravel = a.ravel()
print(f"Hasil ravel: {b_ravel}")

# Mengubah nilai hasil ravel menjejaskan tatasusunan asal
b_ravel[0] = 9
print(f"Selepas mengubah ravel: {b_ravel}")
print("Tatasusunan asal berubah:")
print(a)`

### Reshape dan Resize

`reshape()` mengubah bentuk selagi bilangan unsur kekal sama, dan memulangkan pandangan apabila boleh. Kaedah `ndarray.resize()` yang digunakan di bawah **mengubah tatasusunan asal secara langsung (in place)**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "reshape_resize.py",
      code: `import numpy as np

# Cipta tatasusunan pepenjuru dan ratakan
a = np.diag([1, 2, 3])
a_flat = a.flatten()
print(f"Tatasusunan rata: {a_flat}")

# Reshape - ubah bentuk dengan bilangan unsur yang sama
b = a_flat.reshape(3, 3)
print("Hasil reshape kepada (3,3):")
print(b)

# Mengubah nilai dalam hasil reshape

## Pemiawaian Data dengan Skor Z

Pemiawaian skor-z memusatkan setiap ciri pada min <InlineMath math="0" /> dan menskalakannya kepada sisihan piawai <InlineMath math="1" />. Pemiawaian ini hanya ditakrifkan untuk ciri yang mempunyai **sisihan piawai bukan sifar**, dan ia meletakkan ciri-ciri pada skala berangka yang setanding.

Formula skor-z ialah <InlineMath math="Z = \frac{X - \mu}{\sigma}" />, dengan:
- <InlineMath math="X" /> ialah matriks ciri bersaiz <InlineMath math="n \times k" />
- <InlineMath math="n" /> ialah bilangan cerapan (baris)
- <InlineMath math="k" /> ialah bilangan ciri (lajur)
- <InlineMath math="\mu" /> ialah vektor min bagi setiap lajur
- <InlineMath math="\sigma" /> ialah vektor sisihan piawai bagi setiap lajur

<CodeBlock
  data={[
    {
      language: "python",
      filename: "z_score.py",
      code: `import numpy as np

# Cipta data sampel (5 cerapan, 3 ciri)
rng = np.random.default_rng(42)
X = rng.standard_normal((5, 3)) * 10 + 50  # Sampel daripada taburan normal dengan min 50 dan sisihan piawai 10

print("Data asal:")
print(X)
print(f"Bentuk data: {X.shape}")

# Kira min dan sisihan piawai bagi setiap lajur
mu = np.mean(X, axis=0)  # Min setiap lajur
sigma = np.std(X, axis=0)  # Sisihan piawai setiap lajur

print(f"Min setiap ciri: {mu}")
print(f"Sisihan piawai setiap ciri: {sigma}")

# Jalankan pemiawaian skor-z
Z = (X - mu) / sigma

print("Data selepas pemiawaian skor-z:")
print(Z)

# Sahkan hasil pemiawaian
print("Pengesahan pemiawaian:")
print(f"Min baharu: {np.mean(Z, axis=0)}")  # Sepatutnya hampir dengan 0
print(f"Sisihan piawai baharu: {np.std(Z, axis=0)}")  # Sepatutnya hampir dengan 1
# Output sisihan piawai baharu: [1. 1. 1.]`
    }
  ]}
/>

Pemiawaian menghalang unit semata-mata daripada mewujudkan perbezaan skala yang besar. Ia tidak menjamin kepentingan atau pengaruh yang sama: model dan data masih menentukan perkara itu. Contohnya, tinggi dalam sentimeter dan berat dalam kilogram menjadi setanding dari segi nombor selepas pemiawaian.

Ambil `data = np.array([1, 3, 5, 7, 9])`. Minnya ialah `5` dan sisihan piawainya, `np.std(data)`, sama dengan `np.sqrt(8)`. Garis kelabu dalam gambar menunjukkan dua perkara serentak: menolak min mengalihkan pusat ke `0`, dan membahagi dengan sisihan piawai menarik titik-titik itu lebih rapat. Hasilnya, nilai `5` jatuh tepat pada `0`, dan nilai paling luar menjadi lebih kurang `-1.41` dan `1.41`.
