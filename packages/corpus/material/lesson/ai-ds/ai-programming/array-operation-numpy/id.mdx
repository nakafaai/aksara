## Broadcasting dalam NumPy

Broadcasting adalah aturan NumPy untuk menggabungkan array dengan shape berbeda yang masih kompatibel. Dimensi berukuran satu diperlakukan seolah-olah ukurannya sama dengan ukuran dimensi yang bersesuaian pada array lain, tanpa menyalin data ke array yang lebih besar. [NumPy](https://numpy.org/doc/stable/user/basics.broadcasting.html)

Vektorisasi memungkinkan satu ekspresi bekerja pada seluruh array. NumPy menjalankan loop di baliknya dalam kode terkompilasi yang telah dioptimalkan, sehingga sering lebih cepat daripada loop Python eksplisit.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "vectorization_example.py",

# Membuat dua array
a = np.array([0, 1, 2])
b = np.array([2, 2, 2])

# Operasi vektorisasi (elemen per elemen)
hasil = a + b
print(hasil)
# Output: [2 3 4]`
    }
  ]}
/>

Pada contoh di atas, NumPy menjumlahkan elemen-elemen pada posisi yang bersesuaian. Kita cukup menyatakan operasinya sekali tanpa mengindeks setiap elemen dalam loop Python.

### Aturan Broadcasting

Untuk menentukan apakah dua shape kompatibel, NumPy membandingkan dimensinya dari kanan ke kiri.

Terdapat tiga aturan utama dalam broadcasting:

1. **Aturan** <InlineMath math="1" />: Jika jumlah dimensinya berbeda, tambahkan dimensi berukuran <InlineMath math="1" /> di sebelah kiri shape yang memiliki lebih sedikit dimensi
2. **Aturan** <InlineMath math="2" />: Dua dimensi yang sejajar kompatibel jika ukurannya sama atau salah satunya berukuran <InlineMath math="1" />. NumPy memperlakukan dimensi berukuran satu seolah-olah ukurannya sama dengan dimensi pasangannya
3. **Aturan** <InlineMath math="3" />: Jika ada pasangan dimensi yang tidak kompatibel, NumPy menghasilkan `ValueError`

Jika dua array memiliki bentuk berbeda yang masih kompatibel, NumPy dapat menyesuaikannya secara otomatis melalui broadcasting. Dengan cara ini, satu operasi dapat diterapkan ke setiap baris atau kolom tanpa menyalin nilai secara manual.

## Operasi Aritmetika Array

Operator aritmetika NumPy bekerja elemen per elemen, kecuali operasi yang memang memiliki semantik lain, seperti perkalian matriks.

Ketika array digabungkan dengan skalar, broadcasting menerapkan skalar itu pada setiap elemen. Kita tidak perlu menulis indexing loop secara manual.

<CodeBlock

### Perbandingan dan Logika

Operasi perbandingan NumPy menghasilkan array boolean. Gunakan array tersebut untuk menyaring data atau menggabungkan beberapa kondisi.

<CodeBlock
  data={[
    {
      language: "python",

      code: `import numpy as np

b = np.array([0, 0, 2, 4, 4])

# Operasi perbandingan
print("Perbandingan lebih besar:")
print(f"a > 2: {a > 2}")
# Output: [False False False  True  True]

print("Perbandingan sama dengan:")
print(f"a == b: {a == b}")
# Output: [ True False  True False  True]

# Output: [ True False  True  True  True]`
    }
  ]}
/>

Untuk logika boolean elemen per elemen, gunakan `~` untuk NOT, `&` untuk AND, dan `|` untuk OR, atau fungsi `np.logical_*` yang sesuai. Beri tanda kurung pada setiap perbandingan karena prioritas operatornya berbeda. Operator skalar Python `not`, `and`, dan `or` tidak menjalankan logika array secara elemen per elemen.

## Fungsi Statistik dan Reduksi

Fungsi reduksi menggabungkan banyak elemen menjadi lebih sedikit nilai. Tanpa axis, seluruh array dapat direduksi menjadi satu nilai. Dengan axis, hanya dimensi tersebut yang direduksi. Pada tabel nilai ujian, hasilnya dapat berupa rata-rata per mata pelajaran atau per siswa.

NumPy menyediakan fungsi statistik untuk menghitung ringkasan seperti jumlah, rata-rata, dan simpangan baku. Setiap fungsi dapat diterapkan pada seluruh array atau sumbu tertentu.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "basic_statistics.py",
      code: `import numpy as np

# Membuat array 2D untuk contoh

                 [2, -1, -2, 4],
                 [1, 7, 0, 4]])

print(data)

# Statistik pada seluruh array
print(f"Jumlah total: {np.sum(data)}")
print(f"Rata-rata: {np.mean(data):.2f}")
print(f"Nilai minimum: {np.min(data)}")
print(f"Nilai maksimum: {np.max(data)}")
print(f"Standar deviasi: {np.std(data):.2f}")
# Output:
# Jumlah total: 18
# Rata-rata: 1.50

# Nilai maksimum: 7
# Standar deviasi: 2.50`

### Operasi dengan Sumbu

Pada array dua dimensi, `axis=0` mereduksi dimensi baris dan menghasilkan satu nilai per kolom. `axis=1` mereduksi dimensi kolom dan menghasilkan satu nilai per baris.

Sumbu yang dipilih menentukan dimensi yang direduksi oleh fungsi statistik. Pada data penjualan bulanan untuk beberapa produk, satu sumbu dapat menghasilkan total per produk dan sumbu lainnya menghasilkan total per bulan.

<CodeBlock

## Manipulasi Bentuk Array

Operasi shape mengubah cara elemen-elemen yang sama diindeks. Reshape mempertahankan jumlah elemen, tetapi menempatkannya ke dalam susunan dimensi yang berbeda.

Array NumPy yang baru dibuat biasanya tersimpan berurutan dengan tata letak `C-contiguous`. Dalam tata letak ini, indeks terakhir berubah paling cepat saat data dibaca dari memori. Hasil slicing atau transpose dapat merujuk ke data yang sama dengan jarak antarelemen memori yang berbeda. Karena itu, perhatikan argumen `order` dan atribut `strides` saat memakai `reshape()` atau `flatten()`.

### Flatten dan Ravel

`flatten()` dan `ravel()` sama-sama menghasilkan array satu dimensi. `flatten()` selalu membuat salinan, sedangkan `ravel()` mengembalikan view jika memungkinkan dan salinan jika tata letak memorinya mengharuskan demikian.

print(a)

# Flatten - membuat salinan independen

print(f"Hasil flatten: {b_flatten}")

# Mengubah nilai flatten tidak memengaruhi array asli
b_flatten[0] = 9
print(f"Setelah mengubah flatten: {b_flatten}")

b_ravel = a.ravel()
print(f"Hasil ravel: {b_ravel}")

# Mengubah nilai ravel memengaruhi array asli

print(f"Setelah mengubah ravel: {b_ravel}")
print("Array asli berubah:")

`reshape()` mengubah shape selama jumlah elemennya tetap sama dan mengembalikan `view` jika memungkinkan. Method `ndarray.resize()` yang digunakan di bawah mengubah array asli secara langsung.

## Standardisasi Data dengan Z Score

Standardisasi z-score memusatkan setiap fitur pada rata-rata <InlineMath math="0" /> dan menskalakannya ke standar deviasi <InlineMath math="1" />. Operasi ini hanya terdefinisi untuk fitur dengan standar deviasi tak nol. Setelah standardisasi, fitur yang semula memakai skala berbeda dapat dibandingkan pada skala yang sama.

Formula Z-Transform adalah <InlineMath math="Z = \frac{X - \mu}{\sigma}" />, dengan:
- <InlineMath math="X" /> adalah matriks fitur berukuran <InlineMath math="n \times k" />
- <InlineMath math="n" /> adalah jumlah observasi (baris)
- <InlineMath math="k" /> adalah jumlah fitur (kolom)
- <InlineMath math="\mu" /> adalah vektor rata-rata untuk setiap kolom
- <InlineMath math="\sigma" /> adalah vektor standar deviasi untuk setiap kolom

<CodeBlock
  data={[
    {
      language: "python",
      filename: "z_transform.py",
      code: `import numpy as np

# Membuat data contoh (5 observasi, 3 fitur)
np.random.seed(42)
X = np.random.randn(5, 3) * 10 + 50  # Data dengan mean~50, std~10

print("Data asli:")
print(X)
print(f"Bentuk data: {X.shape}")

# Menghitung rata-rata dan standar deviasi setiap kolom
mu = np.mean(X, axis=0)  # Rata-rata setiap kolom
sigma = np.std(X, axis=0)  # Standar deviasi setiap kolom

print(f"Rata-rata setiap fitur: {mu}")
print(f"Standar deviasi setiap fitur: {sigma}")

# Melakukan Z-Transform
Z = (X - mu) / sigma

print("Data setelah Z-Transform:")
print(Z)

# Verifikasi hasil standardisasi
print("Verifikasi standardisasi:")
print(f"Rata-rata baru: {np.mean(Z, axis=0)}")  # Harus mendekati 0
print(f"Standar deviasi baru: {np.std(Z, axis=0)}")  # Harus mendekati 1
# Output rata-rata baru: [ 1.24344979e-15  8.88178420e-17 -1.77635684e-16] (mendekati 0)
# Output standar deviasi baru: [1. 1. 1.]`
    }
  ]}
/>

Standardisasi mencegah perbedaan satuan saja menciptakan selisih skala yang besar. Namun, standardisasi tidak menjamin setiap fitur sama penting atau sama berpengaruh karena hal itu tetap ditentukan oleh model dan datanya. Misalnya, tinggi dalam sentimeter dan berat dalam kilogram menjadi sebanding secara numerik setelah distandardisasi.
