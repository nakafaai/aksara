## Konsep Modul dalam Python

Python <Highlight>menyimpan banyak kod yang boleh diguna semula dalam modul</Highlight>. Satu modul boleh mengandungi fungsi, pemalar, kelas dan nama lain tanpa meletakkan semuanya dalam ruang nama global.

Pernyataan `import` memuatkan modul apabila diperlukan dan mengikat satu nama. Melalui nama itulah kod kamu boleh mencapai ahli awam modul tersebut. Pustaka standard sudah menyediakan operasi matematik yang diuji dengan teliti. Apabila kamu menggunakannya semula, kamu mengelakkan kesilapan yang timbul daripada menulis semula rumus sendiri.

## Modul math untuk Fungsi Matematik

Modul `math` menyediakan **fungsi dan pemalar bernilai nyata**. Modul ini menerima nombor nyata yang serasi seperti `int` dan `float`, tetapi tidak menerima nilai kompleks untuk operasi seperti `sqrt()`. Gunakan `cmath` apabila domain atau hasilnya mungkin kompleks.

## Cara Mengimport Modul math

Python menawarkan beberapa cara untuk mengimport modul, dan pilihan kamu menentukan **rupa setiap panggilan selepas itu**. Kamu boleh mengimport seluruh modul, mengimport nama tertentu sahaja daripadanya, atau menamakan semula modul itu semasa mengimport.

### Import Asas dengan Ruang Nama

Pernyataan `import math` mengimport modul itu di bawah **ruang nama `math`**. Selepas itu, fungsi dan pemalar dicapai dengan nama seperti `math.sqrt` dan `math.pi`.

# Jika dicuba tanpa awalan, ralat akan berlaku
# sqrt(9)  # NameError: name 'sqrt' is not defined`
    }
  ]}

### Import dengan Alias

Alias mengikat modul itu kepada **nama tempatan yang lain**. Gunakan alias hanya apabila ia mengikut konvensyen yang sudah mantap atau menyelesaikan konflik nama yang sebenar. Nama `math` sendiri sudah pendek dan jelas.

# Import ini mengikat m, bukan math
# math.sqrt(9)  # NameError: name 'math' is not defined`
    }
  ]}

Bentuk ini mengimport setiap nama awam daripada `math` ke dalam ruang nama semasa. Cara ini mungkin memudahkan dalam sesi interaktif yang sekali guna, tetapi kod aplikasi patut mengelakkannya.

<CodeBlock

`from math import *` meletakkan setiap nama awam daripada `math` dalam ruang nama semasa. Jika salah satu nama itu sudah digunakan, nilai daripada `math` menggantikannya tanpa sebarang ralat. Kod kamu juga tidak lagi menunjukkan modul mana yang membekalkan setiap nama, dan perubahan pada `math` pada masa hadapan boleh menambah nama baharu ke dalam modul yang mengimportnya. Import yang eksplisit pula <Highlight>menyenaraikan setiap kebergantungan pada baris import</Highlight>.

## Fungsi Terbina Dalam Berbanding Fungsi Modul

Python menyediakan fungsi berangka terbina dalam seperti `abs()` dan `round()` **tanpa perlu import**. Fungsi ini boleh digunakan pada pelbagai jenis melalui protokol berangka Python. Setiap jenis boleh mentakrifkan operasi yang disokongnya.

### Fungsi Nilai Mutlak

Untuk nombor nyata, `abs()` memulangkan magnitud yang bukan negatif. Untuk nombor kompleks pula, `abs()` memulangkan **jarak dari asalan**.

<CodeBlock

    }

Hasil bagi `4 + 3j` ialah <InlineMath math="5.0" /> kerana <InlineMath math="|4+3i|=\sqrt{4^2+3^2}=\sqrt{25}=5" />. Python menulis unit khayalan sebagai `j`, manakala rumus matematik lazimnya menggunakan <InlineMath math="i" />.

### Fungsi Pembundaran

Untuk jenis berangka terbina dalam Python, `round()` membundarkan kepada nilai yang terdekat, dan kes yang betul-betul di tengah diselesaikan dengan **membundarkan kepada nombor genap**. Tanpa `ndigits`, `round()` memulangkan integer bagi float. Berikan `ndigits` sebagai argumen kedua untuk memilih nilai tempat yang digunakan dalam pembundaran.

## Fungsi dan Pemalar dalam Modul math

Setiap fungsi `math` **mempunyai domain**. Contohnya, `sqrt(x)` memerlukan input nyata yang bukan negatif, dan logaritma memerlukan input nyata yang positif. Nilai di luar domain akan menimbulkan `ValueError`, bukannya memulangkan nombor.

### Fungsi Punca Kuasa Dua dan Logaritma

Contoh ini memanggil fungsi punca kuasa dua dan logaritma, kemudian menunjukkan cara Python melaporkan **input di luar domain yang dibenarkan**.

## Memilih Cara Import yang Sesuai

Pilih gaya import yang menunjukkan **nama modul pada setiap panggilan** apabila konteks itu penting, dan bawa masuk hanya nama yang benar-benar digunakan oleh atur cara. Satu fungsi yang digunakan sekali sahaja mudah dibaca sebagai `from math import sqrt`, manakala beberapa panggilan lebih jelas dengan `import math`.

### Panduan Memilih Cara Import

Pilih gaya import berdasarkan bilangan nama yang kamu perlukan dan **sejauh mana tempat panggilan itu kekal mudah dibaca**. Senarai di bawah menyusun pilihan daripada yang paling eksplisit hingga yang paling kurang eksplisit.

1. **Utamakan `import math`** apabila atur cara menggunakan beberapa ahli modul. Panggilan seperti `math.sqrt()` mengekalkan nama modul di sebelah fungsi.
2. **Gunakan `import math as m` dengan tujuan yang jelas** hanya apabila alias itu ialah konvensyen tempatan yang didokumenkan.
3. **Gunakan `from math import sqrt, pi`** apabila sekumpulan kecil nama yang tidak mengelirukan menjadikan kod setempat lebih baik.
4. **Elakkan `from math import *`** kerana nama-namanya tiada awalan modul dan boleh menggantikan nama yang sudah digunakan oleh atur cara.

### Mengira Jarak dan Luas

Untuk titik `(0, 0)` dan `(3, 4)`, **jarak Euclidean** ialah punca kuasa dua bagi hasil tambah kuasa dua beza koordinat. Untuk sisi `3`, `4` dan `5`, rumus Heron memberikan hasil yang sama dengan rumus luas segi tiga bersudut tegak.

<BlockMath math="\begin{aligned}d&=\sqrt{(3-0)^2+(4-0)^2}=5\\s&=\frac{3+4+5}{2}=6\\A&=\sqrt{6(6-3)(6-4)(6-5)}=\sqrt{36}=6\end{aligned}" />

<CodeBlock
  data={[
    {
      language: "python",
      filename: "practical_example.py",
      code: `import math

def calculate_euclidean_distance(x1, y1, x2, y2):
    """Kira jarak Euclidean antara dua titik"""
    return math.hypot(x2 - x1, y2 - y1)

def calculate_triangle_area(a, b, c):
    """Kira luas segi tiga menggunakan rumus Heron"""
    if not all(math.isfinite(side) for side in (a, b, c)):
        raise ValueError("Panjang sisi mesti terhingga")
    if min(a, b, c) <= 0:
        raise ValueError("Panjang sisi mesti positif")

    if a + b <= c or a + c <= b or b + c <= a:
        raise ValueError("Panjang sisi mesti membentuk segi tiga")

    # Kira separuh perimeter
    s = (a + b + c) / 2

    # Rumus Heron
    area = math.sqrt(s * (s - a) * (s - b) * (s - c))
    return area

# Contoh penggunaan
point1 = (0, 0)
point2 = (3, 4)
distance = calculate_euclidean_distance(*point1, *point2)
print(f"Jarak antara {point1} dengan {point2}: {distance}")

# Kira luas segi tiga dengan sisi 3, 4, 5
area = calculate_triangle_area(3, 4, 5)
print(f"Luas segi tiga dengan sisi 3, 4, 5: {area}")`
    }
  ]}
/>

Kod berangka yang jelas menyatakan tiga keputusan secara terang: ruang nama mana yang memiliki sesuatu operasi, **domain input mana** yang diterima oleh operasi itu, dan cara input luar biasa dikendalikan. Keputusan ini lebih penting daripada memendekkan nama fungsi beberapa aksara.
