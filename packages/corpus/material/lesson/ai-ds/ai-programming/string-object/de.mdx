## Stringobjekte definieren

In Python ist ein String eine unveränderliche Folge von Unicode-Zeichen. Ihre Reihenfolge ist wichtig: Jedes Zeichen hat eine Position, die etwa beim Indizieren und Slicen verwendet wird.

Strings haben drei Merkmale:

1. **Geordnete Zeichenfolge:** Jedes Zeichen hat eine feste Position.
2. **Als Literal geschrieben:** Einfache oder doppelte Anführungszeichen begrenzen den Text im Quellcode.
3. **Typ `str`:** Python speichert den entstandenen Wert als String.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "string_definition.py",
      code: `# Beispielzeichenfolge mit einfachen Anführungszeichen
>>> 'hello'
'hello'

# Beispielzeichenfolge mit doppelten Anführungszeichen
>>> "hello"
'hello'

# String mit print() ausgeben
>>> print("hello")
hello

# Zeichenfolge in einer Variablen speichern
>>> text = 'hello'
>>> text
'hello'`
    }
  ]}
/>

Die interaktive Eingabe zeigt die Repräsentation eines Strings. Python kann dafür einfache oder doppelte Anführungszeichen wählen, damit sie gut lesbar bleibt. `print()` gibt dagegen den Stringwert selbst ohne die Begrenzungszeichen des Literals aus.

## Leere Strings und die Funktion Str

Python kann leere Strings erzeugen und Werte anderer Datentypen in Strings umwandeln.

### Leere Strings

Ein leerer String enthält kein Zeichen und hat die Länge null. Du schreibst ihn als ein Paar Anführungszeichen ohne Inhalt.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "empty_string.py",
      code: `# Leeren String erstellen
>>> empty_text = ""
>>> empty_text
''`
    }
  ]}
/>

### Die Funktion Str

Die Funktion `str()` liefert eine gut lesbare Stringdarstellung eines Werts. Verwende sie, wenn ein Text eine Zahl oder einen anderen Wert enthalten soll, der noch kein String ist.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "str_function.py",
      code: `# Zahl in Zeichenfolge umwandeln

  ]}

## Mehrzeilige Zeichenfolgen

Python unterscheidet zwischen Quellcode, der über mehrere Zeilen verteilt ist, und tatsächlichen Zeilenumbrüchen in einem String.

### Zeilenfortsetzungszeichen

Ein Backslash am Ende einer physischen Quellcodezeile setzt die Anweisung ausdrücklich fort. Im Beispiel enthält die fortgesetzte Anweisung zwei benachbarte Literale, die Python ohne Zeilenumbruch im Wert verbindet.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "line_continuation.py",
      code: `# Anweisung mit einem Backslash fortsetzen
>>> text = 'xxx' \\
...     'yyy'

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Zeilenfortsetzung mit Klammern

Innerhalb von Klammern setzt Python eine Anweisung über den Zeilenumbruch hinweg fort, ohne dass ein Backslash nötig ist. Kommentare oder Leerzeichen am Zeilenende unterbrechen diese Fortsetzung nicht. Beim Verschieben einer Zeile muss außerdem kein Fortsetzungszeichen mitverschoben werden.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "parentheses_continuation.py",
      code: `# Anweisung innerhalb von Klammern fortsetzen
>>> text = (
...     'xxx'
...     'yyy'
... )

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Dreifache Anführungszeichen

Literale mit drei Anführungszeichen können tatsächliche Zeilenumbrüche speichern. Diese erscheinen als `\n`-Zeichen im Stringwert.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "triple_quotes.py",
      code: `# String mit drei Anführungszeichen und echten Zeilenumbrüchen
>>> text = '''xxx
... yyy
... zzz'''

>>> text
'xxx\\nyyy\\nzzz'

>>> print(text)
xxx
yyy
zzz`
    }
  ]}
/>

Drei doppelte Anführungszeichen funktionieren genauso. Wähle die Begrenzung, mit der sich der enthaltene Text am klarsten und mit möglichst wenigen Escape-Zeichen schreiben lässt.

## Verknüpfung von Stringliteralen

Python kann Stringliterale bereits beim Lesen des Quellcodes oder Stringwerte während der Programmausführung verbinden.

### Angrenzende Literalverkettung

Python verbindet benachbarte Stringliterale beim Lesen des Quellcodes. Diese Kurzform funktioniert nur für Text, der direkt als Literal im Code steht.

<CodeBlock
  data={[

  ]}

## Verknüpfung von Stringvariablen

Variablen enthalten Werte und keine Literaltoken. Deshalb brauchen sie beim Verknüpfen einen Operator.

### Operatoren verwenden

Verwende `+`, um Stringwerte zu verketten, und `*` mit einer ganzen Zahl, um einen String zu wiederholen. Variablennamen ohne Operator nebeneinander zu schreiben, ist ungültige Syntax.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "variable_concatenation.py",
      code: `# String-Variablen definieren
>>> text1 = 'hello'
>>> text2 = 'world!'
>>> text3 = '+o+'
>>> a = 3

# Kombination mit +-Operator
>>> text1 + ' world!'
'hello world!'

>>> 'hello ' + text2
'hello world!'

>>> text1 + ' ' + text2
'hello world!'

# Wiederholen mit *-Operator
>>> a * text3
'+o++o++o+'

>>> text3 * a
'+o++o++o+'`
    }
  ]}
/>
