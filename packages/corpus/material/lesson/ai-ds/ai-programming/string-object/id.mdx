## Karakter Unicode dan Tanda Kutip dalam String

Dalam Python, string adalah <Highlight>sequence karakter Unicode yang bersifat immutable</Highlight>. Indexing dan slicing memakai posisi setiap karakter, sehingga perubahan urutan menghasilkan string yang berbeda.

String memiliki tiga karakteristik utama yang perlu kamu pahami:

1. **Urutan karakter**: Setiap karakter memiliki posisi tetap.
2. **Ditulis sebagai literal**: Tanda kutip tunggal atau ganda membatasi teks dalam kode sumber.
3. **Bertipe `str`**: Python menyimpan nilai yang dihasilkan sebagai string.

Python menghitung posisi berdasarkan **code point Unicode**, bukan selalu satu simbol yang terlihat. Misalnya, `len("é")` bernilai `1`, tetapi `len("e\u0301")` bernilai `2`: bentuk kedua memakai huruf `e` dan tanda aksen terpisah.

>>> "hello"

## String Kosong dan Fungsi Str

Python mendukung string kosong dan **konversi tipe data lain menjadi string**. String kosong tidak memuat karakter dan **panjangnya nol**, sedangkan `str()` membangun representasi teks dari nilai apa pun.

### String Kosong

String kosong tidak memuat karakter dan **panjangnya nol**. Kamu dapat menulisnya dengan sepasang tanda kutip tanpa isi.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "empty_string.py",
      code: `# Membuat string kosong
>>> teks_kosong = ""
>>> teks_kosong
''`
    }
  ]}
/>

### Fungsi Str

Fungsi `str()` menghasilkan **representasi string yang mudah dibaca** dari suatu nilai. Gunakan fungsi ini ketika teks perlu memuat angka atau nilai non-string lain.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "str_function.py",
      code: `# Mengubah angka menjadi string
>>> str(5)
'5'

# Mengubah float menjadi string
>>> xstr = str(3.4)
>>> print(xstr)
3.4`
    }
  ]}
/>

## String Multibaris

Python membedakan pemecahan kode sumber ke beberapa baris dari **penyimpanan karakter baris baru** di dalam string. Baris kode bisa dilipat tanpa menambah baris baru pada nilainya, sedangkan string dengan tiga tanda kutip menyimpan setiap baris baru.

### Karakter Lanjutan Baris

Backslash di akhir baris fisik kode sumber **melanjutkan statement secara eksplisit**. Pada contoh ini, statement yang dilanjutkan memuat dua literal berdekatan yang digabung Python tanpa menambahkan karakter baris baru ke nilai string.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "line_continuation.py",
      code: `# Melanjutkan statement dengan backslash
>>> text = 'xxx' \\
...     'yyy'

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Lanjutan Baris dengan Tanda Kurung

Di dalam tanda kurung, Python tetap membaca baris berikutnya sebagai bagian dari statement yang sama, jadi kita **tidak perlu menulis backslash**. Komentar atau spasi di akhir baris tidak memutus kelanjutan ini. Saat baris dipindahkan, tidak ada tanda kelanjutan yang perlu ikut dipindahkan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "parentheses_continuation.py",
      code: `# Melanjutkan statement di dalam tanda kurung
>>> text = (
...     'xxx'
...     'yyy'
... )

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Triple Quotes

Literal dengan tiga tanda kutip dapat menyimpan **baris baru yang sebenarnya**. Baris baru tersebut menjadi karakter `\n` di dalam nilai string.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "triple_quotes.py",
      code: `# String tiga kutip dengan baris baru sebenarnya
>>> text = '''xxx
... yyy
... zzz'''

>>> text
'xxx\\nyyy\\nzzz'

>>> print(text)
xxx
yyy
zzz`
    }
  ]}
/>

Tiga kutip ganda bekerja dengan cara yang sama. Pilih pembatas yang membuat teks paling mudah dibaca dan tidak perlu banyak escape.

Ikuti alur ini untuk melihat ke mana baris baru di dalam kutip tiga pergi.

## Penggabungan String Literal

Python dapat menggabungkan literal string saat membaca kode sumber atau menggabungkan nilai string ketika program berjalan. **Literal yang bersebelahan** digabung tanpa operator, sedangkan nilai di dalam variabel memerlukan operator.

### Penggabungan Literal Berdekatan

Python menggabungkan **literal string yang bersebelahan** saat membaca kode sumber. Cara singkat ini hanya berlaku untuk teks yang ditulis langsung sebagai literal.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "literal_concatenation.py",
      code: `# String literal berdekatan otomatis digabung
>>> 'hello ' 'world'
'hello world'

# Menggabungkan beberapa string sekaligus
>>> "hel" 'lo' " world" '!'
'hello world!'`
    }
  ]}
/>

### Operator Plus

Operator `+` menggabungkan **dua nilai string** saat program berjalan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "plus_operator.py",
      code: `# Menggunakan operator + untuk penggabungan
>>> 'hello ' + 'world'
'hello world'`
    }
  ]}
/>

### Operator Perkalian

Operator `*` **mengulang string** sebanyak bilangan bulat yang diberikan.

<CodeBlock
  data={[
    {
      language: "python",

      code: `# Mengulang string dengan operator *

  ]}

## Penggabungan String Variabel

Variabel menyimpan nilai. Gunakan operator seperti `+` untuk **menggabungkan nilai tersebut**. Literal yang bersebelahan sudah digabung saat kode sumber dibaca, sehingga `"a" "b"` berhasil sedangkan `nama lain` tidak.

### Menggunakan Operator

Gunakan `+` untuk menggabungkan nilai string dan `*` bersama bilangan bulat untuk mengulangnya. Meletakkan nama variabel bersebelahan tanpa operator merupakan **sintaks yang tidak valid**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "variable_concatenation.py",
      code: `# Mendefinisikan variabel string
>>> text1 = 'hello'
>>> text2 = 'world!'
>>> text3 = '+o+'
>>> a = 3

# Menggabungkan dengan operator +
>>> text1 + ' world!'
'hello world!'

>>> 'hello ' + text2
'hello world!'

>>> text1 + ' ' + text2
'hello world!'

# Mengulang dengan operator *
>>> a * text3
'+o++o++o+'

>>> text3 * a
'+o++o++o+'`
    }
  ]}
/>
