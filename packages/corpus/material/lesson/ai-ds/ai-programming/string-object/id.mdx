## Mendefinisikan Objek String

Dalam Python, string adalah urutan karakter Unicode yang tidak dapat diubah. Urutannya penting: setiap karakter memiliki posisi, dan operasi seperti pengindeksan serta pengirisan memakai urutan tersebut.

String memiliki tiga karakteristik utama yang perlu kamu pahami:

1. **Urutan karakter:** Setiap karakter memiliki posisi tetap.
2. **Ditulis sebagai literal:** Tanda kutip tunggal atau ganda membatasi teks dalam kode sumber.
3. **Bertipe `str`:** Python menyimpan nilai yang dihasilkan sebagai string.

hello

# Menyimpan string dalam variabel

>>> text
'hello'`

Prompt interaktif menampilkan representasi string, sehingga Python dapat memilih kutip tunggal atau ganda agar representasinya mudah dibaca. `print()` menulis nilai string itu sendiri tanpa tanda kutip pembatas literal.

## String Kosong dan Fungsi str()

Python memungkinkan kamu membuat string kosong dan mengubah tipe data lain menjadi string.

### String Kosong

String kosong tidak memuat karakter dan panjangnya nol. Kamu dapat menulisnya dengan sepasang tanda kutip tanpa isi.

<CodeBlock

  ]}
/>

### Fungsi str()

Fungsi `str()` meminta bentuk string yang mudah dibaca dari suatu nilai. Gunakan fungsi ini ketika teks perlu memuat angka atau nilai non-string lainnya.

<CodeBlock
  data={[
    {

## String Multi-baris

Python membedakan pemecahan kode sumber ke beberapa baris dari penyimpanan karakter baris baru di dalam string.

### Karakter Lanjutan Baris

Backslash di akhir baris fisik kode sumber melanjutkan pernyataan secara eksplisit. Pada contoh ini, pernyataan yang dilanjutkan memuat dua literal berdekatan yang digabung Python tanpa menambahkan baris baru ke nilainya.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "line_continuation.py",
      code: `# Melanjutkan pernyataan dengan backslash
>>> text = 'xxx' \\
...     'yyy'

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Lanjutan Baris dengan Tanda Kurung

Di dalam tanda kurung, Python melanjutkan pernyataan secara implisit. Cara ini biasanya lebih mudah dibaca dan lebih aman disunting daripada backslash eksplisit.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "parentheses_continuation.py",
      code: `# Melanjutkan pernyataan di dalam tanda kurung
>>> text = (
...     'xxx'
...     'yyy'
... )

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Triple Quotes

Literal dengan tiga tanda kutip dapat menyimpan baris baru yang sebenarnya. Baris baru tersebut menjadi karakter `\n` di dalam nilai string.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "triple_quotes.py",
      code: `# String tiga kutip dengan baris baru sebenarnya
>>> text = '''xxx
... yyy
... zzz'''

>>> text
'xxx\\nyyy\\nzzz'

>>> print(text)
xxx
yyy
zzz`
    }
  ]}
/>

Tiga kutip ganda bekerja dengan cara yang sama. Pilih pembatas yang membuat teks paling mudah dibaca dan tidak perlu banyak escape.

## Penggabungan String Variabel

Variabel menyimpan nilai, bukan token literal, sehingga penggabungannya memerlukan operator.

### Menggunakan Operator

Gunakan `+` untuk menggabungkan nilai string dan `*` bersama bilangan bulat untuk mengulangnya. Meletakkan nama variabel bersebelahan tanpa operator merupakan sintaks yang tidak valid.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "variable_concatenation.py",
      code: `# Mendefinisikan variabel string
>>> text1 = 'hello'
>>> text2 = 'world!'
>>> text3 = '+o+'
>>> a = 3

# Menggabungkan dengan operator +
>>> text1 + ' world!'
'hello world!'

>>> 'hello ' + text2
'hello world!'

>>> text1 + ' ' + text2
'hello world!'

# Mengulang dengan operator *
>>> a * text3
'+o++o++o+'

>>> text3 * a
'+o++o++o+'`
    }
  ]}
/>
