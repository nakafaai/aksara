## Aksara Unicode dalam Jujukan Tersusun

Dalam Python, rentetan (string) ialah <Highlight>jujukan aksara Unicode yang tidak boleh diubah (immutable)</Highlight>. Susunannya penting: setiap aksara ada kedudukan, dan operasi seperti pengindeksan dan penghirisan menggunakan susunan itu.

Rentetan ada tiga ciri utama yang perlu kamu fahami:

1. **Jujukan tersusun**: Setiap aksara ada kedudukan yang tetap.
2. **Ditulis sebagai literal**: Tanda petikan tunggal atau berganda membatasi teks dalam kod sumber.
3. **Jenis `str`**: Python menyimpan nilai yang terhasil sebagai rentetan.

Python mengira kedudukan berdasarkan **titik kod Unicode** (code point), dan satu titik kod tidak semestinya sepadan dengan satu simbol yang kelihatan. Contohnya, `len("é")` ialah `1`, tetapi `len("e\u0301")` ialah `2`: bentuk kedua mengandungi `e` dan satu tanda aksen gabungan yang berasingan.

Gesaan interaktif menunjukkan perwakilan rentetan itu, jadi Python mungkin memilih petikan tunggal atau berganda supaya perwakilan itu mudah dibaca. `print()` pula menulis nilai rentetan itu sendiri, tanpa tanda pembatas literal.

Rentetan ialah jujukan tersusun aksara Unicode, dan setiap aksara ada kod integer yang dibaca oleh `ord()`. Huruf besar `P` ada kod <InlineMath math="80" />, manakala huruf kecil terletak antara <InlineMath math="97" /> dan <InlineMath math="122" />.

## Rentetan Kosong dan Fungsi Str

Python menyokong rentetan kosong dan **penukaran daripada jenis data lain** kepada rentetan. Rentetan kosong tidak mengandungi sebarang aksara dan **panjangnya sifar**, manakala `str()` membina perwakilan teks bagi apa-apa nilai.

### Rentetan Kosong

Rentetan kosong tidak mengandungi sebarang aksara dan **panjangnya sifar**. Kamu boleh menulisnya dengan sepasang tanda petikan yang tidak berisi apa-apa.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "empty_string.py",
      code: `# Membina rentetan kosong
>>> empty_text = ""
>>> empty_text
''`
    }
  ]}
/>

### Fungsi Str

Fungsi `str()` memulangkan **perwakilan rentetan yang mudah dibaca** bagi sesuatu nilai. Gunakan fungsi ini apabila teks perlu mengandungi nombor atau nilai lain yang bukan rentetan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "str_function.py",
      code: `# Menukar nombor kepada rentetan
>>> str(5)
'5'

# Menukar float kepada rentetan
>>> xstr = str(3.4)
>>> print(xstr)
3.4`
    }
  ]}
/>

`str()` menukar apa-apa nilai kepada teksnya, dan `len()` mengira aksara dalam teks itu. Tanda tolak dan titik perpuluhan juga dikira, dan rentetan kosong `''` ialah satu-satunya rentetan yang panjangnya <InlineMath math="0" />.

## Rentetan Berbilang Baris

Python membezakan antara memecahkan kod sumber kepada beberapa baris dengan menyimpan **aksara baris baharu yang sebenar** di dalam rentetan. Satu baris boleh bersambung ke baris seterusnya dalam kod sumber tanpa menambah baris baharu pada nilainya, manakala rentetan berpetikan tiga menyimpan setiap pemisah baris.

### Aksara Sambungan Baris

Garis condong ke belakang (backslash) di hujung baris fizikal kod sumber **menyambung pernyataan secara eksplisit**. Dalam contoh ini, pernyataan yang bersambung itu mengandungi dua literal bersebelahan, dan Python mencantumkannya tanpa menambah baris baharu pada nilainya.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "line_continuation.py",
      code: `# Sambung pernyataan sumber dengan garis condong ke belakang
>>> text = 'xxx' \\
...     'yyy'

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Sambungan Baris dengan Kurungan

Di dalam kurungan, Python menyambung pernyataan merentas pemisah baris **tanpa garis condong ke belakang**. Komen atau ruang di hujung baris tidak memutuskan sambungan ini, dan jika kamu memindahkan satu baris, kamu tidak perlu memindahkan aksara sambungan bersamanya.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "parentheses_continuation.py",
      code: `# Sambung pernyataan di dalam kurungan
>>> text = (
...     'xxx'
...     'yyy'
... )

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Tanda Petikan Tiga

Literal berpetikan tiga boleh menyimpan **pemisah baris yang sebenar**. Pemisah baris itu menjadi aksara `\n` dalam nilai rentetan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "triple_quotes.py",
      code: `# Rentetan berpetikan tiga dengan pemisah baris sebenar
>>> text = '''xxx
... yyy
... zzz'''

>>> text
'xxx\\nyyy\\nzzz'

>>> print(text)
xxx
yyy
zzz`
    }
  ]}
/>

Petikan berganda tiga juga berkelakuan sama. Pilih pembatas yang menjadikan teks paling mudah dibaca dan paling sedikit memerlukan jujukan lepas.

## Penggabungan Literal Rentetan

Python boleh menggabungkan literal rentetan semasa membaca kod sumber, atau menggabungkan nilai rentetan semasa atur cara berjalan. **Literal bersebelahan bercantum** **tanpa operator** di antaranya, manakala nilai yang disimpan dalam pemboleh ubah perlukan operator.

### Penggabungan Literal Bersebelahan

Python **mencantumkan literal rentetan yang bersebelahan** semasa ia membaca kod sumber. Jalan pintas ini hanya berfungsi untuk teks yang ditulis terus sebagai literal.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "literal_concatenation.py",
      code: `# Literal rentetan yang bersebelahan digabungkan secara automatik
>>> 'hello ' 'world'
'hello world'

# Menggabungkan beberapa rentetan sekali gus
>>> "hel" 'lo' " world" '!'
'hello world!'`
    }
  ]}
/>

### Operator Tambah

Operator `+` menggabungkan **dua nilai rentetan** semasa atur cara berjalan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "plus_operator.py",
      code: `# Menggunakan operator + untuk penggabungan
>>> 'hello ' + 'world'

    }
  ]}
/>

### Operator Darab

Operator `*` **mengulang rentetan** sebanyak bilangan kali yang diberi oleh satu integer.

<CodeBlock

## Penggabungan Pemboleh Ubah Rentetan

Pemboleh ubah menyimpan nilai. Gunakan operator seperti `+` apabila kamu **menggabungkan nilai-nilai itu**. Literal bersebelahan dicantumkan semasa kod sumber dibaca, sebab itulah `"a" "b"` berfungsi tetapi `name other` tidak.

### Menggunakan Operator

Gunakan `+` untuk menggabungkan nilai rentetan dan `*` bersama integer untuk mengulang satu rentetan. Meletakkan nama pemboleh ubah bersebelahan begitu sahaja ialah **sintaks yang tidak sah**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "variable_concatenation.py",
      code: `# Mentakrifkan pemboleh ubah rentetan
>>> text1 = 'hello'
>>> text2 = 'world!'
>>> text3 = '+o+'
>>> a = 3

# Menggabungkan dengan operator +
>>> text1 + ' world!'
'hello world!'

>>> 'hello ' + text2
'hello world!'

>>> text1 + ' ' + text2
'hello world!'

# Mengulang dengan operator *
>>> a * text3
'+o++o++o+'

>>> text3 * a
'+o++o++o+'`
    }
  ]}
/>
