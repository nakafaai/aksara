## Defining String Objects

In Python, a string is an immutable sequence of Unicode characters. Its order matters: every character has a position, and operations such as indexing and slicing use that order.

Strings have three main characteristics you need to understand:

1. **Ordered sequence:** Each character has a fixed position.
2. **Written as a literal:** Single or double quotes delimit the text in source code.
3. **Type `str`:** Python stores the resulting value as a string.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "string_definition.py",
      code: `# Example string with single quotes
>>> 'hello'
'hello'

# Example string with double quotes
>>> "hello"
'hello'

# Displaying string with print
>>> print("hello")
hello

# Storing string in a variable
>>> text = 'hello'
>>> text
'hello'`
    }
  ]}
/>

The interactive prompt shows the string's representation, so Python may choose single or double quotes to keep that representation readable. `print()` writes the string value itself, without the literal delimiters.

## Empty Strings and str() Function

Python allows you to create empty strings and convert other data types to strings.

### Empty Strings

An empty string contains no characters and has length zero. You can write one with a pair of quotes containing nothing.

### str() Function

The `str()` function asks a value for its readable string form. Use it when text must include a number or another non-string value.

## Multi-line Strings

Python distinguishes between splitting source code across lines and storing actual newline characters inside a string.

### Line Continuation Character

A backslash at the end of a physical source line explicitly continues the statement. In this example, the continued statement contains two adjacent literals, which Python concatenates without adding a newline to the value.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "line_continuation.py",
      code: `# Continue the source statement with a backslash
>>> text = 'xxx' \\
...     'yyy'

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Line Continuation with Parentheses

Inside parentheses, Python continues the statement implicitly. This is usually easier to read and safer to edit than an explicit backslash.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "parentheses_continuation.py",
      code: `# Continue the statement inside parentheses
>>> text = (
...     'xxx'
...     'yyy'
... )

>>> text
'xxxyyy'

>>> print(text)
xxxyyy`
    }
  ]}
/>

### Triple Quotes

Triple-quoted literals can store actual line breaks. Those line breaks become `\n` characters in the string value.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "triple_quotes.py",
      code: `# Triple-quoted string with real line breaks
>>> text = '''xxx
... yyy
... zzz'''

>>> text
'xxx\\nyyy\\nzzz'

>>> print(text)
xxx
yyy
zzz`
    }
  ]}
/>

Triple double quotes behave the same way. Choose the delimiter that makes the text easiest to read and escape.

## String Literal Concatenation

Python can combine string literals while parsing the source or combine string values while the program runs.

### Adjacent Literal Concatenation

Adjacent string literals are concatenated while Python parses the source. This syntax works only with literals, not variables.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "literal_concatenation.py",

'hello world'

# Combining multiple strings at once
>>> "hel" 'lo' " world" '!'
'hello world!'`

  ]}
/>

## String Variable Concatenation

Variables hold values rather than literal tokens, so they need an operator when you combine them.

### Using Operators

Use `+` to concatenate string values and `*` with an integer to repeat one. Simply placing variable names next to each other is invalid syntax.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "variable_concatenation.py",
      code: `# Defining string variables
>>> text1 = 'hello'
>>> text2 = 'world!'
>>> text3 = '+o+'
>>> a = 3

# Combining with + operator
>>> text1 + ' world!'
'hello world!'

>>> 'hello ' + text2
'hello world!'

>>> text1 + ' ' + text2
'hello world!'

# Repeating with * operator
>>> a * text3
'+o++o++o+'

>>> text3 * a
'+o++o++o+'`
    }
  ]}
/>
