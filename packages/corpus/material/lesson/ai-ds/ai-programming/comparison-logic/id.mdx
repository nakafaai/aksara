## Urutan Prioritas Operator

Prioritas operator <Highlight>menentukan cara Python mengelompokkan ekspresi ketika tanda kurung tidak menyatakannya secara langsung</Highlight>. Aturan ini menjelaskan pengelompokan ekspresi. Python mengevaluasi operand dari kiri ke kanan. Prioritas menentukan bagaimana operasi atas operand itu dikelompokkan.

<Mermaid
  title="Prioritas Operator yang Dibahas"
  description="Diagram merangkum prioritas operator yang dibahas, bukan waktu evaluasi setiap operand."
  chart={`
    flowchart LR
        A["tanda kurung, pemanggilan, indexing"] --> B["** pangkat"]
        B --> C["unary +, -, ~"]
        C --> D["*, /, //, %"]
        D --> E["+, -"]
        E --> F["operator pembanding"]
        F --> G["not"]
        G --> H["and"]
        H --> I["or"]
  `}
/>

Pada perpangkatan, operator unary di kanan diperlakukan khusus: `2 ** -1` berarti `2 ** (-1)` dan bernilai `0.5`. Sebaliknya, `-2 ** 2` berarti `-(2 ** 2)` dan bernilai `-4`.

Operator dengan prioritas lebih tinggi mengikat operand lebih kuat. Sebagian besar operator biner pada level yang sama mengelompok dari kiri ke kanan, tetapi perpangkatan mengelompok dari kanan ke kiri dan perbandingan membentuk rantai. Gunakan tanda kurung jika pengelompokan yang dimaksud mungkin tidak langsung terbaca.

## Operator Perbandingan

Operator perbandingan digunakan untuk membandingkan dua nilai dan menghasilkan nilai boolean (`True` atau `False`). Operator perbandingan yang tersedia dalam Python:

- `==` sama dengan
- `!=` tidak sama dengan
- `<` kurang dari
- `<=` kurang dari atau sama dengan
- `>` lebih dari
- `>=` lebih dari atau sama dengan

Perbandingan nilai bawaan seperti angka dan string menghasilkan **nilai boolean**. Objek buatan sendiri dapat mendefinisikan hasil perbandingan lain. Kesetaraan dapat membandingkan objek dari tipe berbeda, tetapi perbandingan urutan seperti `<` membutuhkan tipe yang mendefinisikan urutan kompatibel dan dapat menghasilkan `TypeError` jika tidak. Operator perbandingan berbagi satu level prioritas dan dapat dirangkai.

## Operator Boolean

Operator boolean menggabungkan beberapa kondisi atau mengubah nilai boolean. Python menyediakan tiga operator boolean utama:

<Mermaid
  title="Operator Boolean Menggabungkan Keputusan"
  description="Lihat bagaimana and, or, dan not menggabungkan nilai benar-salah dalam keputusan program."
  chart={`
    flowchart LR
        A[Input A] --> AND{and}
        B[Input B] --> AND
        AND --> C["A false: A"]
        AND --> D["A true: B"]

        E[Input A] --> OR{or}
        F[Input B] --> OR
        OR --> G["A true: A"]
        OR --> H["A false: B"]

        I[Input] --> NOT{not}
        NOT --> J["Boolean kebalikan"]
  `}
/>

1. **Operator `and`** mengembalikan nilai pertama jika bernilai false, atau nilai kedua jika nilai pertama bernilai true.

2. **Operator `or`** mengembalikan nilai pertama jika bernilai true, atau nilai kedua jika nilai pertama bernilai false.

3. **Operator `not`** berbeda dari operator `and` dan `or` karena selalu menghasilkan nilai boolean baru.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "boolean_operators.py",
      code: `# Contoh operator boolean
>>> 4.0 and 5.0  # 4.0 truthy, lalu mengembalikan 5.0 tanpa perlu menguji kebenaran 5.0
5.0

>>> 0 and 5  # mengevaluasi 0 sebagai false, mengembalikan 0 (short-circuit)
0

>>> 4.0 or 5.0  # mengevaluasi 4.0 sebagai true, mengembalikan 4.0 (short-circuit)
4.0

>>> 0 or 5  # 0 falsy, lalu mengembalikan 5 tanpa perlu menguji kebenaran 5
5

>>> not 4.0  # mengevaluasi 4.0 sebagai true, mengembalikan False
False

>>> not 0  # mengevaluasi 0 sebagai false, mengembalikan True
True`
    }
  ]}
/>

Operator `and` dan `or` menggunakan <Highlight>evaluasi short-circuit</Highlight>, yang berarti evaluasi berhenti ketika hasil sudah dapat ditentukan tanpa mengevaluasi semua operand. Keduanya mengembalikan argumen terakhir yang dievaluasi, sedangkan operator `not` selalu membuat nilai boolean baru.

## Nilai dalam Konteks Boolean

Semua objek Python bisa menjalani **pengujian kebenaran**, termasuk objek yang bukan nilai `True` dan `False`. Python kemudian menentukan sendiri nilai mana yang dianggap salah. Dengan aturan tersebut, list kosong, bilangan nol, dan string kosong semuanya bersikap seperti `False` di dalam `if`, sedangkan wadah yang tidak kosong bersikap seperti `True`.

### Nilai Falsy dan Truthy

<Mermaid
  title="Nilai yang Dibaca Python sebagai Kondisi"
  description="Kelompokkan nilai yang dianggap False dan True oleh Python sebelum dipakai dalam kondisi."
  chart={`
    flowchart TD
        A[Nilai Python] --> B{Evaluasi Boolean}
        B -->|Falsy| C[False]
        B -->|Falsy| D[None]
        B -->|Falsy| E["Nol dan container kosong"]
        B -->|Truthy| F["Contoh nilai bawaan truthy"]
        F --> G["Angka bukan nol"]
        F --> H["Container berisi"]
  `}
/>

Nilai bawaan berikut memiliki **aturan truthiness** yang dapat kamu uji dengan `bool()`.

| Kelompok | Contoh falsy | Contoh truthy |
| --- | --- | --- |
| Boolean | `False` | `True` |
| Nilai kosong | `None` | Tidak berlaku |
| Bilangan | `0`, `0.0`, `0j` | `-1`, `0.5`, `2j` |
| String | `""` | `"0"` |
| Container | `[]`, `{}`, `()`, `set()` | `[0]`, `{"a": 0}` |

String `"0"` dan list `[0]` tetap truthy karena tidak kosong. Nilai elemen di dalam container tidak menentukan truthiness container bawaan.

Objek buatan sendiri dapat mengatur pengujian kebenaran melalui `__bool__()` atau `__len__()`. Jika keduanya tidak didefinisikan, objek tersebut dianggap benar.

## Membandingkan Nilai Float

Banyak pecahan desimal tidak dapat direpresentasikan secara persis sebagai bilangan biner dengan jumlah digit terbatas. Karena hasil antara dibulatkan, dua perhitungan yang setara secara matematis dapat menghasilkan nilai `float` yang **sangat dekat tetapi tidak sama**.

### Masalah Presisi Float

Pecahan desimal dapat memerlukan **pembulatan dalam biner**. Diagram berikut membedakan nilai yang dapat disimpan tepat dari nilai yang perlu dibulatkan.

### Solusi dengan Fungsi Isclose

Python menyediakan fungsi `math.isclose(a, b, rel_tol=1e-09, abs_tol=0.0)` untuk menguji kesetaraan aproksimasi. Fungsi ini menggunakan **toleransi relatif dan absolut** melalui `rel_tol` dan `abs_tol` untuk menentukan apakah dua nilai cukup dekat.


Untuk contoh `math.isclose(100, 95, rel_tol=0.05)`, selisih absolut adalah 5. Toleransi relatif memakai nilai absolut yang lebih besar, yaitu 100.

<BlockMath math="\begin{aligned} |100-95| &= 5 \\ 0{,}05\max(|100|,|95|) &= 5 \\ 5 &\leq \max(5,0) \end{aligned}" />

Karena selisih tidak melebihi toleransi, hasilnya `True`. Pada `abs_tol=5`, batas absolut 5 juga cukup untuk menerima selisih tersebut.


> Gunakan kesetaraan persis hanya jika nilai `float` memang harus identik. Untuk hasil pengukuran atau perhitungan, tentukan toleransi yang sesuai dengan jenis perhitungan lalu gunakan `math.isclose()`. Saat nilai yang dibandingkan mendekati nol, tentukan `abs_tol` karena toleransi relatif juga mengecil.
