## Grundkonzept von Zahlen als Objekten

Jede Zahl in Python ist ein Objekt mit einem numerischen Typ. Dieser Typ bestimmt neben den Rechenoperatoren auch die verfügbaren Attribute und Methoden.

Zum Beispiel erzeugt <InlineMath math="5" /> einen `int` und <InlineMath math="3.14" /> einen `float`. Numerische Objekte sind unveränderlich. Ihre Methoden liefern deshalb Informationen oder neue Werte, statt die ursprüngliche Zahl zu verändern.

## Zugriff auf Attribute und Methoden

Ein Attribut liest du mit `object.attribute`. Eine Methode rufst du mit `object.method()` auf, einschließlich der Klammern, die den Aufruf ausführen.

Betrachten wir ein praktisches Beispiel mit komplexen Zahlen:

## Methoden für komplexe Zahlen

### Die conjugate()-Methode

Für <InlineMath math="z=a+bi" /> gibt `conjugate()` den Wert <InlineMath math="\overline{z}=a-bi" /> zurück. Der Realteil bleibt gleich, während sich das Vorzeichen des Imaginärteils ändert.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "conjugate_method.py",
      code: `# Beispielverwendung der conjugate()-Methode
z1 = 3 + 4j
z2 = -2 - 5j
z3 = 7 + 0j

print(f"Konjugat von {z1} ist {z1.conjugate()}")
print(f"Konjugat von {z2} ist {z2.conjugate()}")
print(f"Konjugat von {z3} ist {z3.conjugate()}")

# Ausgabe:
# Konjugat von (3+4j) ist (3-4j)
# Konjugat von (-2-5j) ist (-2+5j)
# Konjugat von (7+0j) ist (7-0j)`
    }
  ]}
/>

### Praktische Verwendung von Konjugat

Die Identität <InlineMath math="z\overline{z}=|z|^2" /> verbindet eine komplexe Zahl mit ihrem Betrag. Das Beispiel zeigt diesen Zusammenhang ausdrücklich. In gewöhnlichem Python-Code berechnet `abs(z)` den Betrag direkt.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "conjugate_practical.py",
      code: `import math

# Berechnen des komplexen Zahlenmoduls mithilfe der Konjugation
z = 3 + 4j
modulus_squared = z * z.conjugate()
modulus = math.sqrt(modulus_squared.real)

print(f"Komplexe Zahl: {z}")
print(f"Konjugierte Zahl: {z.conjugate()}")
print(f"z × z*: {modulus_squared}")
print(f"Modulus |z|: {modulus}")
print(f"Eingebautes abs(z): {abs(z)}")

# Ausgabe:
# Komplexe Zahl: (3+4j)
# Konjugierte Zahl: (3-4j)
# z × z*: (25+0j)
# Modulus |z|: 5.0
# Eingebautes abs(z): 5.0`
    }
  ]}

## Attribute und Methoden für andere Zahlen

Auch Ganzzahlen und Gleitkommazahlen stellen Methoden bereit, die zu ihrer jeweiligen Darstellung passen.

### Ganzzahlige Zahlen

<CodeBlock
  data={[
    {
      language: "python",
      filename: "integer_methods.py",
      code: `# Einige Methoden für ganze Zahlen
n = 42

# bit_length()-Methode - berechnet die benötigte Anzahl von Bits
print(f"Anzahl der Bits für {n}: {n.bit_length()}")

# to_bytes()-Methode - wandelt den Wert in Bytes um
byte_representation = n.to_bytes(2, byteorder='big')
print(f"Byte-Darstellung von {n}: {byte_representation}")

# Ausgabe:
# Anzahl der Bits für 42: 6
# Byte-Darstellung von 42: b'\\x00*'`
    }
  ]}
/>

`bit_length()` zählt die Bits für den Absolutwert der Ganzzahl, ohne Vorzeichen und führende Nullen. `to_bytes()` benötigt zusätzlich eine Ausgabelänge und Byte-Reihenfolge. Deshalb beginnt das Zwei-Byte-Ergebnis oben mit einem Nullbyte.

### Float-Zahlen

<CodeBlock
  data={[
    {
      language: "python",
      filename: "float_methods.py",
      code: `# Einige Methoden für Gleitkommazahlen
f = 3.14159

# is_integer()-Methode - prüft, ob eine Gleitkommazahl ganzzahlig ist
print(f"{f} ist eine ganze Zahl: {f.is_integer()}")
print(f"{4.0} ist eine ganze Zahl: {(4.0).is_integer()}")

# as_integer_ratio()-Methode - gibt das Verhältnis als Bruch zurück
ratio = f.as_integer_ratio()
print(f"Verhältnis von {f}: {ratio}")

# Ausgabe:
# 3.14159 ist eine ganze Zahl: False
# 4.0 ist eine ganze Zahl: True
# Verhältnis von 3.14159: (3537115888337719, 1125899906842624)`
    }
  ]}
/>

`is_integer()` prüft, ob ein endlicher Float keinen Nachkommaanteil besitzt. `as_integer_ratio()` gibt den exakten Bruch des gespeicherten binären Floats zurück. Dieser kann vom erwarteten Dezimalbruch abweichen.

### Mathematische Berechnungen

<CodeBlock
  data={[
    {
      language: "python",
      filename: "math_calculations.py",
      code: `def complex_operations(z1, z2):
    """Verschiedene Operationen mit komplexen Zahlen ausführen"""
    print(f"Zahl 1: {z1}")
    print(f"Zahl 2: {z2}")
    print(f"Realteil von z1: {z1.real}")
    print(f"Imaginärer Teil von z1: {z1.imag}")
    print(f"Konjugat von z1: {z1.conjugate()}")

    # Mathematische Operationen
    addition = z1 + z2
    multiplication = z1 * z2.conjugate()

    print(f"z1 + z2 = {addition}")
    print(f"z1 × z2* = {multiplication}")

# Anwendungsbeispiel
z1 = 2 + 3j
z2 = 1 - 2j
complex_operations(z1, z2)`
    }
  ]}
/>

Das wichtige Muster lautet: Erkenne den numerischen Typ, wähle die Operation dieses Typs und unterscheide, ob sie eine Komponente, eine Darstellung oder einen neuen Wert liefert. Diese Unterscheidung wird wichtiger, sobald numerischer Code über einen einzelnen Ausdruck hinauswächst.
