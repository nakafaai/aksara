## Bilangan sebagai Objek

Setiap bilangan Python adalah objek dengan tipe numerik. Tipe tersebut menentukan atribut dan method yang tersedia selain operator aritmetika.

Sebagai contoh, <InlineMath math="5" /> membuat `int` dan <InlineMath math="3.14" /> membuat `float`. Objek numerik tidak dapat diubah, sehingga metodenya mengembalikan informasi atau nilai baru tanpa mengubah bilangan asal.

## Mengakses Atribut dan Method

Baca atribut dengan `object.attribute`. Panggil method dengan `object.method()`. Tanda kurung pada bentuk kedua membuat Python menjalankan method tersebut.

Lihat contoh praktis dengan bilangan kompleks:

<CodeBlock
  data={[
    {
      language: "python",

      code: `# Membuat bilangan kompleks
c = 2 + 3j

# Mengakses atribut real (bagian riil)
print(c.real)  # Output: 2.0

# Mengakses atribut imag (bagian imajiner)
print(c.imag)  # Output: 3.0

# Memanggil method conjugate() untuk mendapatkan konjugat
print(c.conjugate())  # Output: (2-3j)`
    }

## Method Bilangan Kompleks

### Method Conjugate

Untuk <InlineMath math="z=a+bi" />, `conjugate()` mengembalikan <InlineMath math="\overline{z}=a-bi" />. Bagian riilnya tetap, sedangkan tanda bagian imajinernya berubah.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "conjugate_method.py",
      code: `# Contoh penggunaan method conjugate()
z1 = 3 + 4j
z2 = -2 - 5j
z3 = 7 + 0j

print(f"Konjugat dari {z1} adalah {z1.conjugate()}")
print(f"Konjugat dari {z2} adalah {z2.conjugate()}")
print(f"Konjugat dari {z3} adalah {z3.conjugate()}")

# Output:
# Konjugat dari (3+4j) adalah (3-4j)
# Konjugat dari (-2-5j) adalah (-2+5j)
# Konjugat dari (7+0j) adalah (7-0j)`
    }
  ]}
/>

### Penggunaan Praktis Konjugat

Identitas <InlineMath math="z\overline{z}=|z|^2" /> menghubungkan bilangan kompleks dengan modulusnya. Contoh berikut memperlihatkan hubungan itu secara eksplisit. Dalam kode Python biasa, `abs(z)` merupakan cara langsung untuk menghitung modulus.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "conjugate_practical.py",
      code: `import math

# Menghitung modulus bilangan kompleks menggunakan konjugat
z = 3 + 4j
modulus_squared = z * z.conjugate()
modulus = math.sqrt(modulus_squared.real)

print(f"Bilangan kompleks: {z}")
print(f"Konjugatnya: {z.conjugate()}")
print(f"z × z*: {modulus_squared}")
print(f"Modulus |z|: {modulus}")
print(f"abs(z) bawaan: {abs(z)}")

# Output:
# Bilangan kompleks: (3+4j)
# Konjugatnya: (3-4j)
# z × z*: (25+0j)
# Modulus |z|: 5.0
# abs(z) bawaan: 5.0`
    }
  ]}
/>

## Atribut dan Method pada Bilangan Lain

Objek `int` dan `float` juga memiliki method yang sesuai dengan representasinya.

### Bilangan Integer

<CodeBlock
  data={[
    {
      language: "python",
      filename: "integer_methods.py",
      code: `# Beberapa method pada bilangan integer
n = 42

# Method bit_length() menghitung jumlah bit yang diperlukan
print(f"Jumlah bit untuk {n}: {n.bit_length()}")

# Method to_bytes() mengonversi nilai ke bytes
byte_representation = n.to_bytes(2, byteorder='big')
print(f"Representasi byte dari {n}: {byte_representation}")

# Output:
# Jumlah bit untuk 42: 6
# Representasi byte dari 42: b'\\x00*'`
    }
  ]}
/>

`bit_length()` menghitung jumlah bit untuk nilai absolut bilangan bulat, tanpa tanda dan nol di depan. `to_bytes()` juga memerlukan panjang output serta urutan byte, sehingga hasil dua byte di atas diawali byte nol.

### Bilangan Float

<CodeBlock
  data={[
    {
      language: "python",
      filename: "float_methods.py",
      code: `# Beberapa method pada bilangan float
f = 3.14159

# Method is_integer() memeriksa apakah float adalah bilangan bulat
print(f"{f} adalah bilangan bulat: {f.is_integer()}")
print(f"{4.0} adalah bilangan bulat: {(4.0).is_integer()}")

# Method as_integer_ratio() mengembalikan rasio sebagai pecahan
ratio = f.as_integer_ratio()
print(f"Rasio dari {f}: {ratio}")

# Output:
# 3.14159 adalah bilangan bulat: False
# 4.0 adalah bilangan bulat: True
# Rasio dari 3.14159: (3537115888337719, 1125899906842624)`
    }
  ]}
/>

`is_integer()` memeriksa apakah float terbatas tidak memiliki bagian pecahan. `as_integer_ratio()` mengembalikan pecahan persis dari float biner yang tersimpan, yang dapat berbeda dari pecahan desimal yang dibayangkan pembaca.

<CodeBlock
  data={[

    """Fungsi untuk memvalidasi input bilangan kompleks"""
    if not isinstance(z, complex):
        return False, "Input bukan bilangan kompleks"

    if z.real < 0:
        return False, "Bagian riil tidak boleh negatif"

    if z.imag == 0:
        return False, "Bagian imajiner tidak boleh nol"

    return True, "Input valid"

    is_valid, message = validate_complex_input(num)
    print(f"{num}: {message}")`
