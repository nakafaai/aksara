## Bilangan sebagai Objek

Setiap bilangan Python adalah objek, dan objek itu membawa tipe numeriknya sendiri. Tipe inilah yang menentukan atribut dan method apa saja yang bisa kamu panggil dengan notasi titik, di atas operator aritmetika yang sudah dimiliki setiap bilangan.

Menulis <InlineMath math="5" /> membuat `int`, sedangkan menulis <InlineMath math="3.14" /> membuat `float`. Objek numerik bersifat <Highlight>tidak dapat diubah</Highlight>, jadi sebuah method tidak pernah mengubah bilangan yang kamu panggil. Pemanggilan seperti `conjugate()` membangun nilai baru lalu mengembalikannya, sementara bilangan aslinya tetap menyimpan nilai yang sama.

Pelajaran [bilangan](/id/materi/ai-ds/pemrograman-ai/numbers) menjelaskan bagaimana Python memilih tipe untuk setiap literal yang kamu tulis. Pelajaran [immutable, mutable, dan identity](/id/materi/ai-ds/pemrograman-ai/immutable-mutable-dan-identity) menjelaskan apa yang berubah dari sifat tersebut ketika kamu menyimpan hasilnya ke dalam variabel.

## Mengakses Atribut dan Method

Atribut menamai nilai yang sudah tersimpan di dalam objek, sedangkan method menamai tindakan yang bisa dilakukan objek itu. Kamu membaca atribut dengan `object.attribute` dan memanggil method dengan `object.method()`. Tanda kurung pada bentuk kedua itulah yang memberitahu Python untuk menjalankan method tersebut.

Bilangan kompleks memperlihatkan perbedaannya dengan jelas. Ekspresi `c.real` adalah data yang sudah disimpan Python di dalam `c`, sehingga membacanya tidak menambah pekerjaan. Pemanggilan `c.conjugate()` adalah pekerjaan yang Python lakukan saat itu juga, dan hasilnya adalah bilangan kompleks kedua yang membiarkan `c` tetap tidak berubah.

## Mengenali Tipe Numerik

Python memilih tipe numerik dari literal yang kamu tulis, dan tipe itu menentukan atribut serta method yang dibawa nilainya. Bertanya lebih dulu kepada Python tentang class-nya membuat kamu tidak perlu menebak apakah sebuah operasi tersedia pada nilai tersebut.

Fungsi `type()` mengembalikan <Highlight>class dari nilai</Highlight>, yaitu nama yang dipakai Python untuk tipe numerik itu. Ketiga literal di bawah ini terlihat mirip ketika kamu masukkan ke sebuah fungsi, tetapi `type()` melaporkan class yang berbeda untuk masing-masing.

### Menggunakan Fungsi Tipe

<CodeBlock

    {

      code: `# Melihat tipe data bilangan

    }

| Literal | Class yang dilaporkan `type()` | Alasan Python memilih class itu |

| `3.14` | `float` | Literal memuat titik desimal |

## Membaca Bagian Bilangan Kompleks

Bilangan kompleks menyimpan dua komponennya secara terpisah, dan Python menyediakan keduanya sebagai atribut sehingga kamu tidak perlu membongkarnya sendiri. Atribut `real` menyimpan komponen riil, atribut `imag` menyimpan koefisien satuan imajiner, dan keduanya kembali sebagai <Highlight>float meskipun kamu menulis bilangan bulat</Highlight>.

Setiap atribut mengembalikan satu komponen dari bilangan tersebut. Membandingkan bilangan riil murni, bilangan imajiner murni, dan bilangan campuran memperlihatkan komponen mana yang menjadi milik atribut mana.

### Atribut real

Atribut `real` mengembalikan komponen riil dari bilangan tersebut. Membacanya tidak pernah mengubah bilangan itu, sehingga kamu bisa memeriksa nilai yang sama sebanyak yang kamu butuhkan.

print(f"Bagian riil dari {z3} adalah {z3.real}")

Atribut `imag` mengembalikan koefisien <InlineMath math="i" />, dan Python menulis satuan itu sebagai `j` di dalam literal bilangan kompleks. Tanda milik koefisien tersebut, sehingga suku yang dikurangi kembali sebagai bilangan negatif.

## Method pada Bilangan Kompleks

Bilangan kompleks juga membawa methodnya sendiri, dan method di bawah ini mencakup operasi yang paling sering kamu pakai. Setiap method mengembalikan bilangan kompleks baru, sehingga kamu bisa terus memanggil method pada hasilnya tanpa mengubah nilai tempat kamu memulai.

### Method Conjugate

Untuk <InlineMath math="z=a+bi" />, `conjugate()` mengembalikan <InlineMath math="\overline{z}=a-bi" />. Bagian riilnya tetap dan <Highlight>hanya bagian imajinernya yang berubah tanda</Highlight>, sehingga konjugat menjadi bayangan cermin bilangan itu terhadap sumbu riil.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "conjugate_method.py",
      code: `# Contoh penggunaan method conjugate()
z1 = 3 + 4j
z2 = -2 - 5j
z3 = 7 + 0j

print(f"Konjugat dari {z1} adalah {z1.conjugate()}")
print(f"Konjugat dari {z2} adalah {z2.conjugate()}")
print(f"Konjugat dari {z3} adalah {z3.conjugate()}")

# Output:
# Konjugat dari (3+4j) adalah (3-4j)
# Konjugat dari (-2-5j) adalah (-2+5j)
# Konjugat dari (7+0j) adalah (7-0j)`
    }
  ]}
/>

Hasil kedua memperlihatkan aturan itu pada koefisien negatif. Bagian imajiner `z2` adalah <InlineMath math="-5" />, sehingga konjugatnya membawa <InlineMath math="+5" />, sementara bagian riilnya tetap <InlineMath math="-2" />. Bilangan riil seperti `z3` adalah konjugat bagi dirinya sendiri, karena bagian imajinernya sudah bernilai nol.

### Memakai Konjugat untuk Mencari Modulus

Identitas <InlineMath math="z\overline{z}=|z|^2" /> menghubungkan bilangan kompleks dengan modulusnya, dan contoh di bawah ini menjalankan identitas tersebut dalam kode. Pada kode Python sehari-hari kamu cukup memanggil `abs(z)` untuk modulus, jadi bacalah contoh ini sebagai alasan mengapa fungsi bawaan itu bekerja.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "conjugate_practical.py",
      code: `import math

# Menghitung modulus bilangan kompleks memakai konjugat

modulus_squared = z * z.conjugate()
modulus = math.sqrt(modulus_squared.real)

print(f"Bilangan kompleks: {z}")
print(f"Konjugatnya: {z.conjugate()}")
print(f"z × z*: {modulus_squared}")
print(f"Modulus |z|: {modulus}")
print(f"abs(z) bawaan: {abs(z)}")

# Output:
# Bilangan kompleks: (3+4j)
# Konjugatnya: (3-4j)
# z × z*: (25+0j)
# Modulus |z|: 5.0
# abs(z) bawaan: 5.0`
    }
  ]}
/>

Mengalikan <InlineMath math="z" /> dengan konjugatnya menghapus bagian imajiner dan menyisakan bilangan riil <InlineMath math="25" />. Akar kuadrat dari bilangan riil itu menghasilkan <InlineMath math="5.0" />, dan `abs(z)` bawaan melaporkan nilai yang sama dalam satu pemanggilan.

## Method pada Bilangan Bulat dan Float

Bilangan bulat dan float menyediakan method yang sesuai dengan representasinya masing-masing, dan method itu tidak bisa saling ditukar dengan method bilangan kompleks. `bit_length()` menghitung bit pada nilai absolut bilangan bulat, `to_bytes()` menuliskan bit itu ke dalam urutan byte, `is_integer()` memeriksa apakah sebuah float punya bagian pecahan, dan `as_integer_ratio()` melaporkan pecahan yang benar-benar disimpan float.

| Method | Tipe pemiliknya | Pertanyaan yang dijawab |
| --- | --- | --- |
| `bit_length()` | `int` | Berapa bit yang dibutuhkan nilai absolutnya |
| `to_bytes()` | `int` | Byte apa yang mewakili nilai ini pada lebar dan urutan pilihan |
| `is_integer()` | `float` | Apakah float ini tidak punya bagian pecahan |
| `as_integer_ratio()` | `float` | Pecahan tepat apa yang sama dengan nilai tersimpan |

### Method Bilangan Bulat

  data={[
    {
      language: "python",

`bit_length()` menghitung bit yang dibutuhkan nilai absolut bilangan bulat, dan perhitungan itu mengabaikan tanda serta angka nol di depan. `to_bytes()` juga membutuhkan panjang keluaran dan urutan byte, sehingga hasil dua byte di atas dibuka dengan satu byte nol untuk memenuhi lebar yang kamu minta.

## Memeriksa dan Menghitung dengan Objek Numerik

Atribut dan method juga mendukung pemeriksaan serta konversi, dan kedua langkah itu memang berjalan berurutan. Kamu memeriksa masukannya lebih dulu lalu menghitung, sehingga nilai yang tidak valid tidak pernah sampai ke perhitungan berikutnya.

### Memeriksa Masukan Sebelum Menghitung

Atribut bisa membawa aturan pemeriksaan yang eksplisit. Fungsi di bawah ini menuntut objek `complex` terlebih dahulu, lalu menerapkan dua contoh aturan domain pada komponennya dan melaporkan pesan untuk setiap kasus yang ditolak.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "data_validation.py",
      code: `def validate_complex_input(z):
    """Fungsi untuk memeriksa masukan bilangan kompleks"""
    if not isinstance(z, complex):
        return False, "Masukan bukan bilangan kompleks"

    if z.real < 0:
        return False, "Bagian riil tidak boleh negatif"

    if z.imag == 0:
        return False, "Bagian imajiner tidak boleh nol"

    return True, "Masukan valid"

# Menguji fungsi pemeriksa
test_numbers = [3+4j, -2+5j, 7+0j, 2.5+1.5j]

for num in test_numbers:
    is_valid, message = validate_complex_input(num)
    print(f"{num}: {message}")`

Fungsi itu mengembalikan sepasang nilai, sehingga pemanggilnya menerima keputusan dan alasannya sekaligus. Dari empat bilangan uji, <InlineMath math="3+4j" /> dan <InlineMath math="2.5+1.5j" /> lolos ketiga pemeriksaan, <InlineMath math="-2+5j" /> ditolak karena bagian riilnya negatif, dan <InlineMath math="7+0j" /> ditolak karena bagian imajinernya nol.

### Menghitung dengan Masukan yang Sudah Diperiksa

<CodeBlock
  data={[

Dengan masukan tersebut, `z1 + z2` bernilai <InlineMath math="3+1j" />, karena bagian riil dan bagian imajiner dijumlahkan secara terpisah. Ekspresi `z1 * z2.conjugate()` mengalikan <InlineMath math="2+3j" /> dengan <InlineMath math="1+2j" /> dan mengembalikan <InlineMath math="-4+7j" />.

Pola pada seluruh pelajaran ini tetap sama. Kenali dulu tipe numeriknya, lalu periksa apakah sebuah operasi mengembalikan komponen, representasi, atau nilai baru, karena tipe kembalian itulah yang menentukan cara ekspresi berikutnya memakai hasilnya.
