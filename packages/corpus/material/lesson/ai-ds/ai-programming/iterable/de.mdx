## Grundlegende iterierbare Konzepte

In Python ist ein Iterable ein Objekt, das einer Schleife oder einem anderen Verbraucher nacheinander Elemente liefern kann. Strings, Listen, Tupel, Mengen, Dictionaries, Dateien und Generatoren sind alle iterierbar, obwohl sie ihre Elemente unterschiedlich ordnen und erzeugen.

Ein Iterable muss weder geordnet noch indizierbar, wiederverwendbar oder endlich sein. Entscheidend ist nur, dass `iter()` einen Iterator liefert, über den sich die Elemente nacheinander abrufen lassen, bis er erschöpft ist.

## Mitgliedschaftsoperatoren

Die Operatoren `in` und `not in` fragen, ob ein Container einen bestimmten Wert enthält. Jeder Container-Typ legt fest, wie die Mitgliedschaft geprüft wird.

### Verwendung von In und Not In

Eingebaute Sequenzen durchsuchen ihre Elemente bis zu einem Treffer oder bis zum Ende. Mengen und Dictionaries verwenden ihr eigenes Suchverhalten. Ein Mitgliedschaftstest in einem Dictionary durchsucht seine Schlüssel.

## Die Funktionen Any und All

Die eingebauten Funktionen `any()` und `all()` verbrauchen ein Iterable und prüfen den Wahrheitswert seiner Elemente. Beide stoppen, sobald das Ergebnis feststeht. Generatorausdrücke vermeiden deshalb eine unnötige Zwischenliste.

### Die Funktion Any

`any()` gibt nach dem ersten wahren Element `True` zurück. Nur wenn alle Elemente falsch sind oder das Iterable leer ist, lautet das Ergebnis `False`.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "any_function.py",
      code: `# Beispiel mit any()

# Prüfe, ob Werte über 70 vorhanden sind
print("Hohe Noten vorhanden:", any(grade > 70 for grade in grades))
# Ausgabe: Hohe Noten vorhanden: True

# Beispiel mit direktem booleschen Wert
conditions = [False, False, True, False]
print("Mindestens eine Bedingung ist wahr:", any(conditions))
# Ausgabe: Mindestens eine Bedingung ist wahr: True

# Beispiel mit leerer Liste
empty_list = []
print("any() für eine leere Liste:", any(empty_list))
# Ausgabe: any() für eine leere Liste: False

# Praxisbeispiel
numbers = [0, 0, 5, 0]
if any(numbers):
    print("In der Liste sind Zahlen ungleich Null vorhanden")
# Ausgabe: In der Liste sind Zahlen ungleich Null vorhanden`
    }
  ]}

### Die Funktion All

`all()` gibt nach dem ersten falschen Element `False` zurück. Endet die Iteration ohne ein solches Element, lautet das Ergebnis `True`. Das erklärt auch den leeren Fall: Es gibt kein Element, das die Bedingung verletzt.

<CodeBlock

# Beispiel mit einer falschen Bedingung

## Entpackoperator

In einem Funktionsaufruf erweitert ein vorangestelltes Sternchen (`*`) ein Iterable zu Positionsargumenten. Die Anzahl der entstandenen Argumente muss weiterhin zur aufgerufenen Funktion passen.

### Problem ohne Entpackoperator

Eine Funktion, die getrennte Koordinaten erwartet, erhält eine Liste als einziges Argument, wenn du sie nicht entpackst. Manuelle Indizes funktionieren bei einer festen Form, wiederholen aber die Containerstruktur an jeder Aufrufstelle.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "unpacking_problem.py",
      code: `import math

# Problem: Die math.hypot-Funktion benötigt separate Argumente
coordinates = [3, 4]

# Falscher Weg - führt zu einem Fehler
try:
    result = math.hypot(coordinates)
    print(result)
except TypeError as e:
    print("Error:", e)
# Ausgabe: Error: must be real number rather than list

# Manueller Weg, der für viele Argumente mühsam ist
result = math.hypot(coordinates[0], coordinates[1])
print("Manuelles Ergebnis:", result)
# Ausgabe: Manuelles Ergebnis: 5.0

# Beispiel mit mehr Argumenten
points = [1, 1, 1, 1]
# Der manuelle Weg wird sehr mühsam
result = math.hypot(points[0], points[1], points[2], points[3])
print("Ergebnis mit vier Argumenten:", result)
# Ausgabe: Ergebnis mit vier Argumenten: 2.0`
    }
  ]}
/>

### Lösung mit dem Entpackoperator

Ein `*` vor dem Iterable im Aufruf übergibt jedes erzeugte Element als eigenes Positionsargument.

### Praktische Anwendungen des Entpackens

Dieselbe Syntax funktioniert in Funktionsaufrufen und Collection-Darstellungen. Verwende sie, wenn die Schnittstelle einzelne erweiterte Elemente erwartet. Nimmt die Funktion ein Iterable an, übergibst du dieses direkt.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "unpacking_practical.py",

# Ausgabe: Früchte: Apfel Orange Mango
