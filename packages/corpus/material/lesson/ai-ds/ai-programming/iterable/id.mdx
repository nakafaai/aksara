## Objek yang Dapat Diiterasi

Dalam Python, iterable adalah objek yang menghasilkan **item satu per satu** saat diiterasi atau digunakan oleh operasi lain. String, list, tuple, set, dictionary, file, dan generator semuanya iterable meskipun cara menyusun serta menghasilkan itemnya berbeda.

Iterable tidak harus berurutan, memiliki indeks, dapat dipakai ulang, atau berhingga. Syarat utamanya hanya satu. Pemanggilan `iter()` harus menghasilkan iterator yang mengeluarkan item satu per satu. Iterator yang berhingga akan berhenti ketika habis.

### Berbagai Jenis Iterable

Beberapa tipe bawaan Python dapat **menghasilkan item satu per satu** ketika diulang.

## Operator Keanggotaan

Operator `in` dan `not in` memeriksa apakah suatu objek **memuat nilai tertentu**. Cara pemeriksaannya bergantung pada tipe objek tersebut: list menelusuri elemennya, dictionary mencari pada daftar kunci, dan string mencari potongan teks.

### Penggunaan Operator in dan not in

List dan tuple membandingkan elemen sampai menemukan kecocokan atau mencapai akhir. String mencari substring, sedangkan `set` dan `dict` memakai mekanisme pencarian sendiri. Pada dictionary, `in` memeriksa **kunci, bukan nilai**.

## Fungsi any dan all

Built-in `any()` dan `all()` menerima iterable lalu menguji truthiness setiap item, yaitu apakah Python menganggap item tersebut benar atau salah dalam konteks Boolean. Kedua fungsi <Highlight>berhenti segera setelah return value dapat ditentukan</Highlight>, sehingga ekspresi generator dapat menghindari pembuatan list perantara yang tidak diperlukan.

### Fungsi Any

`any()` mengembalikan `True` setelah menemukan **item pertama yang dianggap benar**. Return value menjadi `False` jika semua item dianggap salah atau iterable tersebut kosong.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "any_function.py",

print("Ada nilai tinggi:", any(grade > 70 for grade in grades))
# Output: Ada nilai tinggi: True

# Contoh dengan boolean langsung
conditions = [False, False, True, False]
print("Ada kondisi yang benar:", any(conditions))
# Output: Ada kondisi yang benar: True

# Contoh dengan list kosong
empty_list = []
print("Any pada list kosong:", any(empty_list))
# Output: Any pada list kosong: False

# Contoh praktis
numbers = [0, 0, 5, 0]
if any(numbers):
    print("Ada angka selain nol dalam list")
# Output: Ada angka selain nol dalam list`
    }
  ]}
/>

### Fungsi All

`all()` mengembalikan `False` setelah menemukan **item pertama yang dianggap salah**. Jika iterasi selesai tanpa item tersebut, return value menjadi `True`. Pada iterable kosong, tidak ada item yang melanggar kondisi sehingga `all()` juga mengembalikan `True`.

## Positional Unpacking

Dalam pemanggilan fungsi, asterisk di depan iterable (`*`) mengembangkannya menjadi **argumen posisi**. Jumlah argumen yang dihasilkan tetap harus sesuai dengan yang diterima fungsi.

### Pemanggilan Tanpa Unpacking

Jika `coordinates` diberikan langsung kepada fungsi, **seluruh list diterima sebagai satu argumen**. Padahal, `math.hypot()` mengharapkan setiap koordinat sebagai argumen tersendiri. Mengakses setiap indeks secara manual dapat bekerja untuk jumlah koordinat yang tetap, tetapi pemanggil harus mengulang cara data tersebut disusun.

# Masalah: fungsi math.hypot membutuhkan argumen terpisah

try:
    result = math.hypot(coordinates)
    print(result)
except TypeError as e:
    print("Error:", e)

result = math.hypot(coordinates[0], coordinates[1])

# Output: Hasil manual: 5.0

# Contoh dengan lebih banyak argumen
points = [1, 1, 1, 1]
# Cara manual menjadi sangat merepotkan

### Pemakaian Unpacking

Sintaks unpacking yang sama dapat dipakai saat memanggil fungsi atau membuat list baru. Gunakan asterisk jika fungsi mengharapkan **beberapa argumen terpisah**. Berikan iterable secara langsung jika fungsi memang menerima satu iterable.

# Output: Buah-buahan: apel jeruk mangga

list1 = [1, 2, 3]
list2 = [4, 5, 6]
