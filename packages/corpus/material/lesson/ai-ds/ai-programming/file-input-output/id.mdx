## Membaca File

Python membaca dan menulis file melalui objek file. Dalam text mode, objek ini mendekode byte yang tersimpan menjadi string dengan encoding yang dipilih. Dalam binary mode, byte diteruskan tanpa perubahan.

### Membaca Seluruh Isi File

Cara paling sederhana untuk membaca file adalah mengambil seluruh isinya sekaligus ke dalam memori.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "read_entire_file.py",
      code: `# Membaca seluruh file teks UTF-8 sekaligus
with open('file.txt', 'r', encoding='utf-8') as f:
    txt = f.read()

print(txt)
# Output: [isi lengkap file akan ditampilkan]`
    }
  ]}
/>

`open()` membuat objek file, `read()` mengambil teksnya, dan blok `with` menutup file secara otomatis ketika blok berakhir, termasuk ketika operasi terhenti oleh exception.

### Membaca File Baris per Baris

Untuk file yang besar, membaca baris per baris lebih efisien karena tidak memuat seluruh file ke memori sekaligus.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "read_line_by_line.py",
      code: `# Membaca file teks UTF-8 baris per baris
with open('file.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line, end='')

# Catatan: setiap baris mempertahankan karakter newline
# Parameter end='' mencegah penambahan newline tambahan`
    }
  ]}
/>

Setiap baris mempertahankan newline di akhirnya jika karakter itu memang ada. Baris terakhir mungkin tidak memiliki newline. Pengaturan `end=''` mencegah `print()` menambahkan newline kedua.

### Posisi File dan Pembacaan

File yang baru dibuka berawal pada posisi stream pertamanya. Pembacaan memajukan posisi tersebut. Dalam text mode, `tell()` dapat menghasilkan cookie posisi yang opaque, bukan indeks karakter sederhana. Simpan dan gunakan kembali posisi itu daripada menghitung offset byte sendiri.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "file_position.py",
      code: `# Demonstrasi posisi file
with open('sample.txt', 'r', encoding='utf-8') as f:
    first_read = f.read(5)  # Membaca paling banyak 5 karakter
    saved_position = f.tell()
    print("Bacaan pertama:", first_read)

    second_read = f.read(3)  # Melanjutkan dari posisi saat ini
    print("Bacaan kedua:", second_read)

    f.seek(saved_position)  # Kembali ke posisi text stream yang disimpan
    repeated = f.read(3)
    print("Bacaan ulang:", repeated)`
    }
  ]}
/>

Dalam text mode, `read()` dan `readline()` mengembalikan string serta menghasilkan `''` ketika tidak ada teks tersisa. Dalam binary mode, keduanya mengembalikan `bytes` dan memakai `b''` pada akhir file. Iterasi berhenti otomatis ketika mencapai akhir.

## Penanganan File yang Aman

Python menyediakan statement `with` untuk penanganan file yang lebih aman dan otomatis.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "safe_file_handling.py",
      code: `# Menggunakan with statement untuk penanganan file aman
with open('file.txt', 'r', encoding='utf-8') as f:
    content = f.read()
    print(content)
# File otomatis tertutup setelah keluar dari blok with

# Menulis dengan with statement
with open('output.txt', 'w', encoding='utf-8') as f:
    f.write("Hello World!")
    f.write("\\nBaris kedua")
# File otomatis tertutup dan disimpan

# Membaca dan menulis bersamaan
with open('input.txt', 'r', encoding='utf-8') as input_file, open('output.txt', 'w', encoding='utf-8') as output_file:
    data = input_file.read()
    output_file.write(data.upper())
# Kedua file otomatis tertutup`
    }
  ]}
/>

Statement `with` memastikan file selalu tertutup dengan benar, bahkan jika terjadi error dalam program. Ini mencegah masalah seperti file yang terbuka terus dan menghabiskan sumber daya sistem.
