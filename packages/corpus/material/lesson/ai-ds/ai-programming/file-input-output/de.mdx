## Dateien lesen

Python liest und schreibt Dateien über Dateiobjekte. Im Textmodus dekodiert das Objekt die gespeicherten Bytes mit einer gewählten Zeichenkodierung zu Strings. Im Binärmodus stellt es die Bytes unverändert bereit.

### Gesamten Dateiinhalt lesen

Der einfachste Weg, eine Datei zu lesen, besteht darin, ihren gesamten Inhalt auf einmal in den Speicher zu übernehmen.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "read_entire_file.py",
      code: `# Die gesamte UTF-8-Textdatei auf einmal lesen
with open('file.txt', 'r', encoding='utf-8') as f:
    txt = f.read()

print(txt)
# Ausgabe: [Der vollständige Dateiinhalt wird angezeigt]`
    }
  ]}
/>

`open()` erzeugt das Dateiobjekt, `read()` liest seinen Text und der `with`-Block schließt die Datei automatisch. Das gilt auch dann, wenn eine Exception den Vorgang unterbricht.

### Datei Zeile für Zeile lesen

Bei großen Dateien ist das zeilenweise Lesen effizienter, da nicht die gesamte Datei auf einmal in den Speicher geladen wird.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "read_line_by_line.py",
      code: `# Eine UTF-8-Textdatei Zeile für Zeile lesen
with open('file.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line, end='')

# Hinweis: Jede Zeile behält ihr Zeilenumbruchzeichen
# Der Parameter end='' verhindert das Hinzufügen zusätzlicher Zeilenumbrüche`
    }
  ]}
/>

Jede Zeile behält ihren abschließenden Zeilenumbruch, sofern einer vorhanden ist. Die letzte Zeile kann ohne Zeilenumbruch enden. Mit `end=''` fügt `print()` keinen zweiten hinzu.

### Druckausgabe in eine Datei umleiten

Mit dem Parameter `file` kannst du die Ausgabe von `print()` direkt in eine Datei umleiten.

Python bietet verschiedene Modi zum Öffnen von Dateien entsprechend den Anforderungen der auszuführenden Vorgänge.

### Dateiöffnungssyntax

<CodeBlock
  data={[
    {
      language: "python",
      filename: "file_opening_syntax.py",
      code: `# Eine vorhandene Textdatei lesen
with open('data.txt', 'r', encoding='utf-8') as f:
    first_line = f.readline()

# Eine Datei erstellen oder ihren bisherigen Inhalt leeren
with open('output.txt', 'w', encoding='utf-8') as f:

# Eine Datei erstellen oder an ihren Inhalt anhängen
with open('log.txt', 'a', encoding='utf-8') as f:
    f.write('nächstes Ereignis\\n')

# Eine vorhandene Datei lesen und schreiben, ohne sie beim Öffnen zu leeren

    original = f.read()`
    }
  ]}
/>

Der Modus bestimmt, ob die Datei bereits existieren muss, ob ihr alter Inhalt beim Öffnen gelöscht wird und welche Operationen erlaubt sind. `r` und `r+` benötigen eine vorhandene Datei. `w` erstellt oder leert sie, während `a` sie erstellt oder Daten anhängt. Das Suffix `b` wählt den Binärmodus, in dem keine `encoding`-Angabe verwendet wird.

## Methoden zum Lesen von Dateien

Python bietet verschiedene Methoden, um Dateien je nach Bedarf auf unterschiedliche Weise zu lesen.

### read()-Methode mit Parametern

<CodeBlock

### Dateiposition und -lesung

Eine neu geöffnete Datei beginnt an ihrer ersten Streamposition. Durch das Lesen bewegt sich diese Position weiter. Im Textmodus kann `tell()` ein undurchsichtiges Positions-Cookie statt eines einfachen Zeichenindex liefern. Speichere und verwende solche Positionen erneut, anstatt Byte-Offsets selbst zu berechnen.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "file_position.py",
      code: `# Dateiposition demonstrieren
with open('sample.txt', 'r', encoding='utf-8') as f:
    first_read = f.read(5)  # Höchstens 5 Zeichen lesen
    saved_position = f.tell()
    print("Erste Ausgabe:", first_read)

    second_read = f.read(3)  # Von der aktuellen Position weiterlesen
    print("Zweite Ausgabe:", second_read)

    f.seek(saved_position)  # Zur gespeicherten Textstream-Position zurückkehren
    repeated = f.read(3)
    print("Wiederholte Ausgabe:", repeated)`
    }
  ]}
/>

Im Textmodus geben `read()` und `readline()` Strings zurück. Ist kein Text mehr vorhanden, liefern sie `''`. Im Binärmodus geben sie `bytes` zurück und verwenden am Dateiende `b''`. Eine Iteration endet dort automatisch.

## Sicherer Umgang mit Dateien

Python bietet die `with`-Anweisung für eine sicherere und automatische Dateiverarbeitung.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "safe_file_handling.py",
      code: `# Verwendung der with-Anweisung zur sicheren Dateiverarbeitung
with open('file.txt', 'r', encoding='utf-8') as f:
    content = f.read()
    print(content)
# Datei wird nach Beenden mit Block automatisch geschlossen

# Mit einer with-Anweisung schreiben
with open('output.txt', 'w', encoding='utf-8') as f:
    f.write("Hello World!")
    f.write("\\nZweite Zeile")
# Datei automatisch geschlossen und gespeichert

# Gleichzeitiges Lesen und Schreiben
with open('input.txt', 'r', encoding='utf-8') as input_file, open('output.txt', 'w', encoding='utf-8') as output_file:
    data = input_file.read()
    output_file.write(data.upper())
# Beide Dateien wurden automatisch geschlossen`
    }
  ]}
/>

Die `with`-Anweisung stellt sicher, dass Dateien immer ordnungsgemäß geschlossen werden, auch wenn im Programm ein Fehler auftritt. Dadurch wird verhindert, dass Dateien geöffnet bleiben und Systemressourcen verbrauchen.
