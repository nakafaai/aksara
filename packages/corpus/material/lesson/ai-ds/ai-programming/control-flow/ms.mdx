## Pernyataan Kawalan Gelung

Python menyediakan beberapa pernyataan yang mengubah aliran sesuatu gelung. Pernyataan ini boleh <Highlight>menghentikan gelung, melompat ke lelaran seterusnya, atau menentukan apa yang berlaku selepas gelung selesai seperti biasa</Highlight>.

### Break Continue Pass dan Else

Pernyataan `break` <Highlight>terus keluar dari gelung terdekat yang melingkunginya</Highlight> apabila sesuatu syarat dipenuhi. Selepas itu, pelaksanaan diteruskan dengan pernyataan pertama selepas gelung tersebut.

<CodeBlock
  data={[

        break

# Output: 75 boleh dibahagi dengan 15 dan 25`
    }
  ]}
/>

Pernyataan `continue` melangkau baki kod dalam lelaran semasa, lalu terus ke lelaran seterusnya. Ini berbeza daripada `break`, yang menghentikan seluruh gelung.

<CodeBlock

## Fungsi Enumerate

Guna `enumerate()` apabila lelaran memerlukan **pembilang dan setiap nilai sekali gus**. Ia memulangkan pelelar yang menghasilkan tuple `(index, value)`.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "enumerate_basic.py",
      code: `# Menggunakan enumerate untuk mendapatkan indeks dan nilai
fruits = ['apple', 'banana', 'mango', 'melon']

for i, fruit in enumerate(fruits):
    print(i, ':', fruit)
# Output:
# 0 : apple
# 1 : banana
# 2 : mango
# 3 : melon`
    }
  ]}
/>

Secara lalai, `enumerate()` mula mengira dari <InlineMath math="0" />, tetapi kamu boleh menetapkan nilai permulaannya melalui parameter kedua.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "enumerate_custom_start.py",
      code: `# Menetapkan indeks permulaan sendiri untuk enumerate

for i, fruit in enumerate(fruits, 5):
    print(i, ':', fruit)
# Output:
# 5 : apple
# 6 : banana
# 7 : mango
# 8 : melon`
    }
  ]}
/>

Dalam `for i, fruit in enumerate(fruits)`, pembongkaran tuple (tuple unpacking) mengikat indeks kepada `i` dan nilai yang sepadan kepada `fruit` pada setiap lelaran.

## Gelung While

Gelung `while` melaksanakan sesuatu blok **selagi syaratnya bernilai benar (truthy)**. Gelung `for` mengambil nilai daripada objek boleh lelar sehingga habis, manakala gelung `while` berulang berdasarkan syarat yang biasanya dikemas kini oleh badan gelung.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "while_loop_example.py",
      code: `# Contoh gelung while dengan pengiraan matematik
z = 1
while abs(z) < 100:
    z = z**2 + 1
print(z)
# Output: 677`
    }
  ]}
/>

Gelung `while` sesuai untuk ulangan yang dipandu oleh syarat, tetapi badan gelung akhirnya mesti mengubah syarat itu atau keluar secara jelas. Kalau tidak, gelung itu boleh berjalan tanpa henti.

## Fungsi Zip

Fungsi `zip()` **memasangkan item pada kedudukan yang sama** dalam beberapa objek boleh lelar. Lelaran berhenti apabila objek boleh lelar yang paling pendek kehabisan item, jadi bilangan pasangan sama dengan panjang input yang paling pendek.

### Penggunaan Asas Zip

<CodeBlock
  data={[
    {
      language: "python",
      filename: "zip_basic.py",
      code: `# Menggabungkan dua senarai dengan zip
p = [1, 2, 3, 4]
q = ['a', 'b', 'c', 'd']

for pair in zip(p, q):
    print(pair)
# Output:
# (1, 'a')
# (2, 'b')
# (3, 'c')
# (4, 'd')`
    }
  ]}
/>

Fungsi `zip()` memulangkan **pelelar tuple**. Setiap tuple mengandungi unsur yang sepadan daripada setiap input. Secara lalai, lelaran berhenti apabila objek boleh lelar yang paling pendek tamat, jadi unsur yang berbaki dalam input yang lebih panjang ditinggalkan. Guna `zip(..., strict=True)` untuk menimbulkan ralat apabila panjang input berbeza.

### Menukar Hasil Zip

Kamu boleh membaca pasangan daripada pelelar `zip()` secara terus dalam gelung. Tukarkannya kepada **senarai atau tuple** apabila kamu perlu menyimpan pasangan itu untuk digunakan semula.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "zip_conversion.py",
      code: `# Menukar hasil zip kepada senarai atau tuple

q = ['a', 'b', 'c', 'd']

# Output: [(1, 'a'), (2, 'b'), (3, 'c'), (4, 'd')]

# Output: ((1, 'a'), (2, 'b'), (3, 'c'), (4, 'd'))`
    }
  ]}
/>

## Range dan Gelung For

Fungsi `range()` menghasilkan **jujukan integer** untuk lelaran. Gunakannya apabila gelung memerlukan kedudukan bernombor atau bilangan ulangan yang tetap. Oleh sebab `range` menghasilkan setiap nilai hanya apabila diminta dan tidak menyimpan seluruh jujukan, penggunaan memorinya kekal kecil walaupun gelung berjalan berjuta-juta kali.

### Sintaks Range

<CodeBlock
  data={[
    {
      language: "python",
      filename: "range_syntax.py",
      code: `# Pelbagai cara menggunakan range
# range(stop) - dari 0 hingga stop-1
for i in range(4):
    print(i)
# Output:
# 0
# 1
# 2
# 3

print()

# range(start, stop) - dari start hingga stop-1
for i in range(2, 6):
    print(i)
# Output:
# 2
# 3
# 4
# 5

print()

# range(start, stop, step) - dengan langkah tertentu
for i in range(8, 4, -1):
    print(i)
# Output:
# 8
# 7
# 6
# 5`
    }
  ]}
/>

Range mengikut **formula aritmetik**, iaitu unsur ke-i ialah `start + i * step` untuk semua `i` dari <InlineMath math="0" /> hingga `n-1`.

### Kecekapan Range berbanding Senarai

`range` menyimpan **start, stop dan step sahaja**. Ia mengira setiap integer apabila diminta, jadi penggunaan memorinya tidak bertambah walaupun bilangan integer yang diwakilinya bertambah.

## Pernyataan Bersyarat

Pernyataan bersyarat membolehkan program **memilih satu cabang** berdasarkan syarat yang dinilai. Inden (indentation) ialah sebahagian daripada sintaks Python. Gunakan empat ruang bagi setiap aras dan jangan sekali-kali mencampurkan tab dengan ruang dalam satu blok.

### Sintaks If Elif dan Else

<CodeBlock
  data={[
    {
      language: "python",
      filename: "conditional_syntax.py",

if age <= 5:
    print("masuk percuma")
elif age <= 14:
    print("15.00 EUR")
elif age <= 65:
    print("30.00 EUR")
else:
    print("20.00 EUR")
# Output: 30.00 EUR`
    }
  ]}
/>

Syarat tidak perlu diapit tanda kurung, tetapi titik bertindih selepas setiap pengepala cabang mesti ada. Setiap pernyataan dalam satu blok mesti menggunakan **aras inden yang konsisten**.

### Pernyataan If Bersarang

<CodeBlock
  data={[

Guna **keputusan bersarang** apabila cabang yang dipilih menentukan syarat mana yang perlu disemak seterusnya. Dengan menyemak koordinat sifar dahulu, titik yang terletak pada paksi tidak akan dimasukkan ke dalam mana-mana sukuan.

## Sintaks Gelung For

Gelung `for` melawati **unsur sesuatu objek boleh lelar** seperti senarai, tuple, rentetan atau range.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "for_loop_syntax.py",
      code: `# Contoh lelaran senarai
fruit_list = ['apple', 'banana', 'mango']
for fruit in fruit_list:
    print(fruit)
# Output:
# apple
# banana
# mango

# Contoh lelaran rentetan
text = 'hi'
for char in text:
    print(char)
# Output:
# h
# i`
    }
  ]}
/>

Objek boleh lelar membekalkan nilai satu demi satu, tetapi ia tidak semestinya tersusun, boleh diindeks, boleh digunakan semula atau terhingga. Gelung `for` meminta nilai yang berturutan daripada pelelarnya. Dalam pengepala `for`, `in` menghubungkan sasaran lelaran dengan objek boleh lelar. Dalam ungkapan seperti `3 in [1, 3]`, `in` menguji keahlian.
