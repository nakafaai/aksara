## Datentypsystem von NumPy

Der Datentyp legt die **Darstellung im Speicher** und die möglichen NumPy-Operationen für einen Wert fest. Ein NumPy-Boolean belegt ein Byte, während eine komplexe Zahl Real- und Imaginärteil getrennt speichert.

Alle Elemente eines gewöhnlichen NumPy-Arrays verwenden [denselben Datentyp](https://numpy.org/doc/stable/user/basics.types.html). Dadurch können die von NumPy in C ausgeführten Schleifen die Elemente verarbeiten, ohne den Typ jedes Werts einzeln zu prüfen.

### Grundlegende Datentypen

NumPy akzeptiert die eingebauten Skalar-Typen von Python und bietet Typen mit **fester Bitbreite**, wenn die Darstellung genau festgelegt werden muss:

1. **Boolean** (`bool` oder `np.bool_`) für `True` und `False`, mit einem Byte pro Element
2. **Integer** (`np.int8` bis `np.int64`) für vorzeichenbehaftete Ganzzahlen mit eindeutiger Bitbreite
3. **Float** (`np.float16`, `np.float32` oder `np.float64`) für Gleitkommazahlen mit unterschiedlicher Genauigkeit
4. **Complex** (`np.complex64` oder `np.complex128`) für Werte mit Real- und Imaginärteil

### Spezifische numerische Datentypen

NumPy bietet eine detaillierte Präzisionskontrolle mit **verschiedenen Größen numerischer Datentypen**:

| Kategorie | Datentyp | Beschreibung | Wertebereich |
|----------|-----------|-------------|-------------|
| **Ganzzahl mit Vorzeichen** | `int8` | <InlineMath math="8" />-Bit-Ganzzahl mit Vorzeichen | <InlineMath math="-128 \text{ bis } 127" /> |
| | `int16` | <InlineMath math="16" />-Bit-Ganzzahl mit Vorzeichen | <InlineMath math="-32768 \text{ bis } 32767" /> |
| | `int32` | <InlineMath math="32" />-Bit-Ganzzahl mit Vorzeichen | <InlineMath math="-2147483648 \text{ bis } 2147483647" /> |
| | `int64` | <InlineMath math="64" />-Bit-Ganzzahl mit Vorzeichen | <InlineMath math="-2^{63} \text{ bis } 2^{63}-1" /> |
| **Ganzzahl ohne Vorzeichen** | `uint8` | <InlineMath math="8" />-Bit-Ganzzahl ohne Vorzeichen | <InlineMath math="0 \text{ bis } 255" /> |
| | `uint16` | <InlineMath math="16" />-Bit-Ganzzahl ohne Vorzeichen | <InlineMath math="0 \text{ bis } 65535" /> |
| | `uint32` | <InlineMath math="32" />-Bit-Ganzzahl ohne Vorzeichen | <InlineMath math="0 \text{ bis } 4294967295" /> |
| | `uint64` | <InlineMath math="64" />-Bit-Ganzzahl ohne Vorzeichen | <InlineMath math="0 \text{ bis } 2^{64}-1" /> |
| **Gleitkommazahl** | `float16` | Gleitkommazahl mit halber Genauigkeit | <InlineMath math="5 \text{ Exponentenbits}" />, <InlineMath math="10 \text{ Bruchbits}" /> |
| | `float32` | Gleitkommazahl mit einfacher Genauigkeit | <InlineMath math="8 \text{ Exponentenbits}" />, <InlineMath math="23 \text{ Bruchbits}" /> |
| | `float64` | Gleitkommazahl mit doppelter Genauigkeit | <InlineMath math="11 \text{ Exponentenbits}" />, <InlineMath math="52 \text{ Bruchbits}" /> |
| **Komplex** | `complex64` | Komplexe Zahl | Zwei <InlineMath math="32" />-Bit-Gleitkommazahlen |
| | `complex128` | Komplexe Zahl | Zwei <InlineMath math="64" />-Bit-Gleitkommazahlen |

## Attribute von NumPy Arrays

Attribute beschreiben die **Array-Struktur**, ohne jeden Wert auszulesen: Form, Elementzahl, dtype und die von den Elementen belegten Bytes. `nbytes` misst den Elementspeicher, nicht den gesamten Speicher des Python-Prozesses oder die Metadaten des Array-Objekts.

### Attribute eines Arrays

Ein Array beschreibt seinen eigenen Aufbau über Attribute. Die Tabelle nennt die **häufig gelesenen Attribute** und den Wert, den jedes für ein <InlineMath math="2 \times 3" />-Array liefert.

| Attribut | Funktion | Beispielergebnis |
|-----------|----------|----------------|
| `ndarray.shape` | Anzahl der Elemente in jeder Achse | `(2, 3)` für <InlineMath math="2 \times 3" />-Array |
| `ndarray.ndim` | Anzahl der Achsen/Abmessungen | `2` für zweidimensionales Array |
| `ndarray.size` | Gesamtzahl der Elemente | `6` für <InlineMath math="2 \times 3" />-Array |
| `ndarray.dtype` | Elementdatentyp | `int64`, `float64` usw. |
| `ndarray.nbytes` | Von den Array-Elementen belegte Bytes | `48` für sechs `int64`-Werte |

### Datentypkonsistenz

Alle Elemente eines gewöhnlichen NumPy-Arrays haben denselben Datentyp. Das `numpy.dtype`-Objekt beschreibt, wie diese Werte im Speicher liegen und gelesen werden. Haben Eingaben unterschiedliche Typen, <Highlight>ermittelt NumPy mit festen Promotionsregeln</Highlight> einen passenden gemeinsamen dtype. Genauigkeit und Typkategorie bestimmen das Ergebnis. Die Häufigkeit eines Eingabetyps spielt dabei keine Rolle.

## Konvertierung und Bearbeitung von Datentypen

Konvertiere, wenn der **benötigte Typ abweicht**, etwa wegen einer Funktionsanforderung oder zur Speicherersparnis. Dabei können Genauigkeit oder Nachkommastellen verloren gehen. Auch ganzzahlig gespeicherte Werte garantieren nicht, dass jede spätere Operation wieder Ganzzahlen liefert.

### Methoden zur Konvertierung von Datentypen

Mit einer Datentypkonvertierung wählst du eine andere Darstellung für die weitere Analyse. `astype()` gibt ein konvertiertes Array zurück und verändert das ursprüngliche Array nicht direkt. Beim Umwandeln einer Gleitkommazahl in eine Ganzzahl schneidet NumPy den **Nachkommaanteil in Richtung null** ab.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "dtype_conversion.py",
      code: `import numpy as np

# Ursprüngliches Float-Array
original = np.array([1.1, 2.7, 3.9])
print("Original array:", original)  # Ausgabe: Original array: [1.1 2.7 3.9]
print("Original dtype:", original.dtype)  # Ausgabe: Original dtype: float64

# Mit astype in eine Ganzzahl konvertieren
converted = original.astype(np.int64)
print("Converted to int:", converted)  # Ausgabe: Converted to int: [1 2 3]
print("Converted dtype:", converted.dtype)  # Ausgabe: Converted dtype: int64

# In einen bestimmten Datentyp konvertieren
float32_array = original.astype(np.float32)
print("Float32 dtype:", float32_array.dtype)  # Ausgabe: Float32 dtype: float32

# Strings in Ganzzahlen konvertieren
string_array = np.array(['1', '2', '3'])
int_from_string = string_array.astype(np.int64)
print("Aus einem String:", int_from_string)  # Ausgabe: Aus einem String: [1 2 3]
print("Datentyp nach Konvertierung zu int:", int_from_string.dtype)  # Ausgabe: Datentyp nach Konvertierung zu int: int64`
    }

### Speicheroptimierung mit Datentypen

Der schmalste Datentyp, der alle **benötigten Werte und die erforderliche Genauigkeit** abdeckt, kann den Speicherbedarf deutlich senken. Prüfe vor dem Verkleinern eines dtype dessen Wertebereich, damit keine Werte überlaufen oder wichtige Genauigkeit verloren geht.

<CodeBlock

print("Int64 element memory:", large_array_int64.nbytes, "bytes")  # Ausgabe: Int64 element memory: 8000000 bytes

# Array mit kleinerem Datentyp (int32)
large_array_int32 = np.arange(1000000, dtype=np.int32)

memory_saved = large_array_int64.nbytes - large_array_int32.nbytes

### Datenvalidierung und Debugging

Bevor du ein Array an ein Modell übergibst, prüfst du **Form, dtype, fehlende Werte** und den Speicherbedarf, den dieses Modell tatsächlich erwartet.

<CodeBlock

def validate_feature_matrix(arr):
    """Eine numerische Merkmalsmatrix vor dem Modellieren prüfen."""
    print("=== ML-Array-Validierung ===")

    # Dimensionen prüfen
    if arr.ndim != 2:
        print(f"WARNUNG: Array ist nicht 2D (aktuell: {arr.ndim}D)")
    else:
        print(f"✓ 2D-Array mit Form: {arr.shape}")

    # Prüfen, ob die Matrix numerische Werte enthält
    if not np.issubdtype(arr.dtype, np.number):
        print(f"WARNUNG: Der Datentyp muss möglicherweise konvertiert werden: {arr.dtype}")
        return

    print(f"✓ Numerischer Datentyp: {arr.dtype}")

    # Fehlende Werte prüfen (NaN)
    if np.isnan(arr).any():
        nan_count = np.isnan(arr).sum()
        print(f"WARNUNG: Anzahl der NaN-Werte: {nan_count}")
    else:
        print("✓ Keine NaN-Werte")
