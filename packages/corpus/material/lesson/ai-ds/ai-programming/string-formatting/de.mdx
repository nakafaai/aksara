## Formatfelder und Breite

Stringformatierung bestimmt, wie Werte als Text erscheinen. Damit kannst du Tabellenspalten ausrichten, eine Zahlendarstellung wählen, die Genauigkeit steuern und verständliche Meldungen zusammensetzen. Python stellt dafür die Methode `str.format()` und F-Strings bereit.

Ein einfaches Ersetzungsfeld hat die Form `{field_name:format_spec}`. Eine Breite innerhalb der Formatspezifikation legt eine Mindestbreite und keine Höchstbreite fest. Braucht der formatierte Wert mehr Platz, gibt Python ihn vollständig aus, statt ihn abzuschneiden.

### Formattypen für Zahlensysteme

| Formattyp | Symbol | Beispieleingabe | Ausgabe | Verwendung |
|-------------|---------|--------------|--------|-------|
| Dezimal | `d` | `45` | `45` | Dezimale Ganzzahl |
| Binär | `b` | `45` | `101101` | Bitdarstellung |
| Oktal | `o` | `45` | `55` | Darstellung zur Basis acht |
| Hexadezimal | `x/X` | `45` | `2d/2D` | Basis sechzehn mit Klein- oder Großbuchstaben |

### Füllzeichen und erweiterte Formatierung

Das Füllzeichen belegt den ungenutzten Raum im Feld. Standardmäßig ist es ein Leerzeichen und steht unmittelbar vor dem Ausrichtungssymbol. In `str.format()` und F-Strings können die literalen Zeichen `{` und `}` nicht als Füllzeichen dienen.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "alignment_fill.py",
      code: `# Grundlegende Ausrichtung

print('|{0:>15}|'.format('xxx'))    # Ausgabe: |            xxx|
print('|{0:^15}|'.format('xxx'))    # Ausgabe: |      xxx      |

# Benutzerdefinierte Füllzeichen
print('|{0:-<15}|'.format('xxx'))   # Ausgabe: |xxx------------|
print('|{0:*>15}|'.format('xxx'))   # Ausgabe: |************xxx|
print('|{0:^^15}|'.format('xxx'))   # Ausgabe: |^^^^^^xxx^^^^^^|

# Decimal formatting
x = 123.98
print('x = {0:12f}'.format(x))      # Ausgabe: x =   123.980000
print('x = {0:12e}'.format(x))      # Ausgabe: x = 1.239800e+02`
    }

### Vergleich der Referenzmethoden

| Methode | Syntax | Vorteile | Einschränkungen |
|--------|---------|-----------|-------------|
| Nummeriert | `{0}, {1}` | Explizite Kontrolle, kann wiederholt werden | Jeder verwendete Index muss vorhanden sein |
| Schlüsselwort | `{name}, {age}` | Jeder Name kennzeichnet seinen Wert und kann wiederholt werden | Namen müssen übereinstimmen |
| Automatisch | `{}, {}` | Einfache Syntax | Nicht mit nummerierten Feldern kombinierbar |

## Präzision und Vorzeichen

### Präzision für Dezimalzahlen

Die Bedeutung der Präzision hängt vom Darstellungstyp ab. Bei `f` und `e` bestimmt sie die Stellen nach dem Dezimalpunkt, bei `g` die Anzahl signifikanter Ziffern.

| Formattyp | Präzisionsverhalten | Beispiel |
|-------------|-----|---------|
| `f/F` | Dezimalstellen | `{:.2f}` → `123.99` |
| `e/E` | Dezimalstellen in der Exponentialfunktion | `{:.2e}` → `1.24e+02` |
| `g/G` | Signifikante Ziffern | `{:.3g}` → `124` |

In der Leerzeichenzeile ist das Symbol ein Leerzeichen innerhalb des Formatbezeichners, wie in `{: d}`. Da dieses Zeichen unsichtbar ist, wird es in der Tabelle als literales Leerzeichen bezeichnet.

| Symbol | Verhalten | Beispiel |
|--------|----------|---------|
| `+` | Vorzeichen immer anzeigen | `+100`, `-200` |
| `-` | Nur negatives Vorzeichen (Standard) | `100`, `-200` |
| literales Leerzeichen | Lässt ein Leerzeichen vor einer positiven Zahl | `' 100'`, `'-200'` |

## Formatierte Strings und dynamische Vorlagen

### Formatierte Strings und Version von Python

F-Strings gibt es seit Python 3.6. Sie werten Ausdrücke direkt im Ersetzungsfeld aus. Dadurch ist eine lokale Formatierung oft leichter lesbar als eine getrennte Argumentliste für `format()`.

### Dynamische Formatvorlagen

Verschachtelte Ersetzungsfelder können Breite, Füllzeichen oder Ausrichtung aus einem anderen Wert übernehmen. Verwende diese Form, wenn diese Formatwerte erst zur Laufzeit feststehen.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "fstrings_dynamic.py",
      code: `# F-Strings mit einfacher Syntax
name, age = 'Alice', 25
print(f'{name} ist {age} Jahre alt')                  # Ausgabe: Alice ist 25 Jahre alt
print(f'Nächstes Jahr ist {name} {age + 1} Jahre alt') # Ausgabe: Nächstes Jahr ist Alice 26 Jahre alt

# Dynamische Formatvorlagen
value, width, fill, align = 'data', 12, '-', '^'
template = '|{val:{f}{a}{w}}|'
result = template.format(val=value, w=width, f=fill, a=align)
print(result)                                 # Ausgabe: |----data----|

# Vergleich: gleiche Ausgabe mit unterschiedlichen Methoden
x = 123.456
print('Alter Stil: %8.2f' % x)               # Ausgabe: Alter Stil:   123.46
print('Format-Methode: {0:8.2f}'.format(x))  # Ausgabe: Format-Methode:   123.46
print(f'F-string: {x:8.2f}')                 # Ausgabe: F-string:   123.46

# Komplexer F-String mit Formatangabe
import math
radius = 5.7
print(f'Fläche: {math.pi * radius**2:.2f} cm²') # Ausgabe: Fläche: 102.07 cm²`
    }
  ]}

### Vollständiges Formatspezifikationsmuster

<Mermaid
  title="Reihenfolge innerhalb eines Formatbezeichners"

  chart={`

        A["Formatspezifikation"] --> B["Reihenfolge der Komponenten"]

        B --> C[": (Beginn)"]
        C --> D["fill (Füllzeichen)"]
        D --> E["align (Ausrichtung: < > ^)"]
        E --> F["sign (Vorzeichen: + - Leerzeichen)"]
        F --> G["width (Mindestbreite)"]
        G --> H[".prec (Dezimalgenauigkeit)"]
        H --> I["type (Typ: d b o x f e g)"]

        K --> L["ein vollständiges Ersetzungsfeld"]
  `}
/>

Für die hier behandelte Teilmenge liest du `{value:*^+10.2f}` als Feldname `value`, Füllzeichen `*`, mittige Ausrichtung `^`, ausdrückliches Vorzeichen `+`, Mindestbreite `10`, Präzision `2` und Festkommatyp `f`. Die vollständige Formatierungs-Minisprache von Python unterstützt außerdem Optionen wie Zifferngruppierung und alternative Darstellungen.
