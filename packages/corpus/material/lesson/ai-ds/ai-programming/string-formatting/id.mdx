## Konsep Dasar dan Kontrol Lebar

Pemformatan string mengubah nilai menjadi keluaran teks yang terencana. Kamu dapat meratakan kolom tabel, memilih notasi angka, mengatur presisi, dan menyusun pesan yang mudah dibaca. Python menyediakan metode `str.format()` dan f-string untuk pekerjaan ini.

Replacement field dasar berbentuk `{field_name:format_spec}`. Nilai lebar di dalam spesifikasi format menetapkan lebar minimum dan bukan maksimum. Jika nilai yang diformat memerlukan ruang lebih besar, Python tetap menampilkan nilai lengkap tanpa memotongnya.

### Tipe Format untuk Sistem Bilangan

| Tipe format | Simbol | Contoh input | Output | Kegunaan |
|-------------|---------|--------------|--------|----------|
| Desimal | `d` | `45` | `45` | Bilangan bulat desimal |
| Biner | `b` | `45` | `101101` | Representasi bit |
| Oktal | `o` | `45` | `55` | Representasi basis delapan |
| Heksadesimal | `x/X` | `45` | `2d/2D` | Basis enam belas dengan huruf kecil atau besar |

### Karakter Pengisi dan Format Lanjutan

Karakter pengisi menempati ruang yang tidak terpakai di dalam bidang. Nilai bawaannya adalah spasi dan penulisannya tepat sebelum simbol perataan. Pada `str.format()` dan f-string, karakter literal `{` atau `}` tidak dapat dipakai sebagai pengisi.

print('|{0:^15}|'.format('xxx'))    # Output: |      xxx      |

print('|{0:^^15}|'.format('xxx'))   # Output: |^^^^^^xxx^^^^^^|

print('x = {0:12f}'.format(x))      # Output: x =   123.980000

### Perbandingan Metode Referensi

| Metode | Sintaks | Kelebihan | Batasan |
|--------|---------|-----------|---------|
| Numbered | `{0}, {1}` | Kontrol eksplisit, bisa diulang | Setiap indeks yang dirujuk harus tersedia |
| Keyword | `{name}, {age}` | Mudah dibaca, fleksibel | Nama harus cocok |
| Automatic | `{}, {}` | Sintaks sederhana | Tidak bisa dicampur dengan numbered |

## Kontrol Presisi dan Spesifikasi Tanda

### Presisi untuk Angka Desimal

Arti presisi bergantung pada tipe penyajian. Untuk `f` dan `e`, presisi menentukan jumlah digit setelah tanda desimal. Untuk `g`, presisi menentukan jumlah digit signifikan.

| Tipe format | Perilaku presisi | Contoh |
|-------------|-------------------|--------|
| `f/F` | Tempat desimal | `{:.2f}` → `123.99` |
| `e/E` | Tempat desimal dalam eksponensial | `{:.2e}` → `1.24e+02` |
| `g/G` | Digit signifikan | `{:.3g}` → `124` |

Pada baris spasi, simbolnya memang satu karakter kosong di dalam format specifier, seperti pada `{: d}`. Karena karakter itu tidak terlihat, tabel menamainya sebagai spasi literal.

| Simbol | Perilaku | Contoh |
|--------|----------|--------|
| `+` | Selalu tampilkan tanda | `+100`, `-200` |
| `-` | Hanya tanda negatif (default) | `100`, `-200` |
| spasi literal | Menyisakan satu spasi sebelum angka positif | `' 100'`, `'-200'` |

## F-Strings dan Template Dinamis

### F-Strings dan Versi Python

F-string tersedia sejak Python 3.6. Ekspresi dievaluasi langsung di dalam replacement field, sehingga pemformatan lokal sering lebih mudah dibaca daripada daftar argumen `format()` yang terpisah.

### Template Format Dinamis

Replacement field bertingkat dapat memasok bagian spesifikasi format, seperti lebar, pengisi, atau perataan. Cara ini berguna ketika pilihan tersebut baru diketahui saat program berjalan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "fstrings_dynamic.py",
      code: `# F-strings - sintaks sederhana
name, age = 'Alice', 25
print(f'{name} is {age} years old')           # Output: Alice is 25 years old
print(f'Next year: {name} will be {age + 1}') # Output: Next year: Alice will be 26

# Dynamic format templates
value, width, fill, align = 'data', 12, '-', '^'
template = '|{val:{f}{a}{w}}|'
result = template.format(val=value, w=width, f=fill, a=align)
print(result)                                 # Output: |----data----|

# Comparison - same output, different methods
x = 123.456
print('Old style: %8.2f' % x)                # Output: Old style:   123.46
print('Format method: {0:8.2f}'.format(x))   # Output: Format method:   123.46
print(f'F-string: {x:8.2f}')                 # Output: F-string:   123.46

# Complex f-string with format spec
import math
radius = 5.7
print(f'Area: {math.pi * radius**2:.2f} cm²') # Output: Area: 102.07 cm²`
    }
  ]}
