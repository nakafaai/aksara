## Mengakses Elemen dengan Indeks

Indexing mengambil **satu elemen berdasarkan posisinya** dari string atau list. Misalnya, jika `huruf = ["a", "b", "c"]`, maka `huruf[1]` menghasilkan `"b"`.

Python memulai nomor indeks dari <InlineMath math="0" />. Elemen pertama memiliki indeks <InlineMath math="0" />, elemen kedua memiliki indeks <InlineMath math="1" />, dan seterusnya. Python juga mendukung **indeks negatif** yang menghitung mundur dari akhir.

### Indeks Positif dan Negatif

Dalam string atau list, setiap karakter atau elemen memiliki dua jenis indeks. Indeks positif dimulai dari <InlineMath math="0" /> di awal, sedangkan indeks negatif dimulai dari <InlineMath math="-1" /> di akhir.

Tabel ini menempatkan **dua indeks pada elemen yang sama**. Indeks `1` dan `-4` sama-sama memilih `e`. Contoh kode memakai `repr()` agar tanda kutip dan string kosong terlihat pada keluaran.

| Karakter | `H` | `e` | `l` | `l` | `o` |
| --- | --- | --- | --- | --- | --- |
| Indeks dari awal | `0` | `1` | `2` | `3` | `4` |
| Indeks dari akhir | `-5` | `-4` | `-3` | `-2` | `-1` |

<CodeBlock
  data={[
    {
      language: "python",
      filename: "indexing_dasar.py",
      code: `# Contoh indexing pada string
s = "Hello"

# Mengakses karakter dengan indeks positif
print(repr(s[0]))    # Output: 'H'
print(repr(s[4]))    # Output: 'o'

# Mengakses karakter dengan indeks negatif
print(repr(s[-1]))   # Output: 'o'
print(repr(s[-5]))   # Output: 'H'

# Mencoba mengakses indeks yang tidak ada
try:
    print(repr(s[5]))

/>

Indeks di luar rentang yang valid menghasilkan `IndexError`. Python memeriksa batas string dan list sebelum mengambil elemennya.

## Mengambil Beberapa Elemen

Slicing memilih **sebagian elemen** dari string atau list melalui batas awal, batas akhir, dan step. Indeks akhir tidak disertakan. Panjang hasil bergantung pada batas yang sudah disesuaikan dengan panjang data dan pada step.

### Slicing dengan Dua Batas

Sintaks `[i:j]` memakai `i` sebagai indeks awal dan `j` sebagai indeks akhir. Elemen pada indeks `i` masuk ke hasil, sedangkan elemen pada **indeks `j` tidak**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "slicing_dasar.py",
      code: `# Contoh slicing pada string
s = "Hello"

# Mengambil indeks 1 sampai sebelum indeks 3
print(repr(s[1:3]))    # Output: 'el'

# Mengambil indeks 3 sampai akhir
print(repr(s[3:]))     # Output: 'lo'

# Mengambil awal string sampai sebelum indeks 3
print(repr(s[:3]))     # Output: 'Hel'

# Menggunakan indeks negatif
print(repr(s[-4:-2]))  # Output: 'el'
print(repr(s[-2:-4]))  # Output: ''`
    }
  ]}
/>

Jika indeks awal lebih besar daripada indeks akhir dan `step` bernilai positif, slicing menghasilkan string atau list kosong. `Step` negatif memilih elemen ke arah sebaliknya.

### Mengatur Jarak Antar Elemen

Parameter ketiga dalam `[start:stop:step]` menentukan **jarak antarelemen yang dipilih**. Nilai `step` sebesar `2`, misalnya, mengambil satu elemen lalu melewati satu elemen berikutnya.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "slicing_stride.py",
      code: `# Contoh slicing dengan step tertentu
s = "Hello World!"

# Mengambil setiap karakter kedua
print(repr(s[::2]))      # Output: 'HloWrd'

# Mengambil setiap karakter kedua dari indeks 1
print(repr(s[1::2]))     # Output: 'el ol!'

# Membalik string dengan step negatif
print(repr(s[::-1]))     # Output: '!dlroW olleH'

# Memilih mundur dari indeks tertentu
print(repr(s[-1:4:-1]))  # Output: '!dlroW '`
    }
  ]}
/>

`Step` negatif membalik arah pemilihan. Bentuk `s[::-1]` mengosongkan kedua batas dan memilih semua elemen dari akhir ke awal. `step` tidak boleh nol karena Python tidak dapat maju ke indeks berikutnya.

## Aturan Slicing

Indeks awal, indeks akhir, dan `step` menentukan elemen yang masuk ke hasil. Aturan utamanya: indeks awal ikut diambil, **indeks akhir tidak**, dan `step` negatif membalik arah pembacaan dari kanan ke kiri.

### Menghitung Panjang Hasil

Misalkan <InlineMath math="n" /> adalah panjang `s`. Untuk kasus <InlineMath math="0 \le i \le j \le n" /> dengan `step` positif bawaan, panjang `s[i:j]` adalah <InlineMath math="j-i" />. Bentuk lain dapat mengosongkan batas, memakai indeks negatif, melewati rentang, atau menentukan `step` berbeda. **Python menyesuaikan batas tersebut** terhadap panjang data. Jumlah elemen hasil slicing dapat dihitung dengan `len(range(*slice(i, j, step).indices(len(s))))`.

## Indeks yang Dipilih

Fungsi `range()` dapat menunjukkan **indeks mana saja yang dipilih** oleh slicing. Perbandingan ini menjelaskan indeks hasil slicing pada contoh ini.

    result_manual += s[index]

result_slicing = s[1:8:2]

## Bentuk Singkat Slicing

Batas yang dikosongkan mengikuti **arah step**. Untuk step positif, awal bawaan adalah awal data dan akhir bawaan melewati elemen terakhir. Untuk step negatif, awal bawaan adalah elemen terakhir dan akhir bawaan melewati elemen pertama.

### Mengambil dari Awal atau Sampai Akhir

Dengan **step positif bawaan**, `s[:3]` mengambil bagian awal dan `s[3:]` mengambil bagian akhir. Pada `s[::-1]`, kedua batas mengikuti arah negatif sehingga urutannya terbalik.

  ]}

Gunakan indexing untuk mengambil satu elemen pada posisi yang diketahui. Gunakan slicing untuk mengambil beberapa elemen yang berurutan atau berjarak tetap. Bentuk `[::-1]` membalik urutan elemen. Untuk ekstensi file, jangan mengandalkan jumlah karakter tetap karena panjang ekstensi dapat berbeda. `Path.suffix` membaca ekstensi sesuai struktur path.

<Highlight>Batas slicing disesuaikan dengan panjang data</Highlight>, sehingga `s[10:]` pada string yang lebih pendek menghasilkan `""`. Akses langsung seperti `s[10]` tetap menghasilkan `IndexError`. Gunakan slicing hanya jika hasil kosong memang dapat diterima.

Indeks negatif menghitung posisi dari akhir data. Gunakan `s[-1]` untuk elemen terakhir atau `s[-3:]` untuk tiga elemen terakhir. Bentuk ini dapat dipakai saat memproses file, parsing teks, atau mengolah dataset yang elemennya perlu dihitung dari akhir.
