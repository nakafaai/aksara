## Sammlungen in Python

Sammlungen speichern mehrere Werte in einem Objekt. Einige bewahren die Position jedes Elements, andere ordnen Schlüsseln Werte zu und wieder andere enthalten nur eindeutige Elemente. Wähle die Sammlung danach aus, wie das Programm auf die Daten zugreifen und sie verändern soll.

Einige Sammlungen können Objekte verschiedener Typen enthalten. Für jeden Sammlungstyp gelten jedoch eigene Regeln. Schlüssel eines Dictionaries und Elemente eines Sets müssen zum Beispiel unverändert hashbar bleiben, solange sie in der Sammlung liegen. Der Sammlungstyp bestimmt außerdem, ob sich sein Inhalt nach der Erstellung ändern lässt.


Python stellt fünf häufig verwendete eingebaute Sammlungen bereit:

- **String**: unveränderliche Textsequenz
- **Liste**: veränderliche, indexierbare Sequenz
- **Tupel**: unveränderliche Sequenz
- **Dictionary**: Zuordnung von Schlüsseln zu Werten
- **Set**: Sammlung eindeutiger Elemente ohne Indizes

## Listen in Python

Eine Liste bewahrt die Reihenfolge ihrer Elemente und ihr Inhalt lässt sich verändern. Eine Liste darf Werte verschiedener Typen enthalten, eine einheitliche Elementform ist jedoch meist leichter zu verarbeiten.

Anders als ein niedrigstufiges Array fester Größe kann eine Python-Liste wachsen und schrumpfen. Sie speichert Verweise auf Python-Objekte. Eine Änderung an einem verschachtelten Objekt kann deshalb über jeden Verweis auf dieses Objekt sichtbar sein.


### Eigenschaften von Listen

| Eigenschaft | Erklärung | Beispiel |
|---------------|-------------|---------|
| Geordnet | Elemente haben eine feste Reihenfolge | `[1, 2, 3]` ist nicht dasselbe wie `[3, 2, 1]` |
| Heterogen | Kann verschiedene Datentypen enthalten | `[1, 'text', 3.14, True]` |
| Veränderlich | Inhalte können nach der Erstellung geändert werden | Kann Elemente hinzufügen, entfernen oder ändern |

### Listen schreiben

Ein Listenliteral verwendet eckige Klammern und trennt die Elemente durch Kommas. Eine Liste kann Werte unterschiedlicher Typen oder weitere Listen enthalten.

## Listenindizierung

Die Indizierung greift über seine Position auf ein einzelnes Listenelement zu. Python zählt ab <InlineMath math="0" />, daher hat das erste Element den Index <InlineMath math="0" />.


Für Listenindizes gelten diese Regeln:

- **Positive Indizes** beginnen bei <InlineMath math="0" /> für das erste Element
- **Negative Indizes** beginnen bei <InlineMath math="-1" /> für das letzte Element
- **Ein Index außerhalb des gültigen Bereichs** löst `IndexError` aus

<CodeBlock
  data={[
    {
      language: "python",
      filename: "list_indexing.py",
      code: `# Beispiel für die Indizierung verschachtelter Listen
nested = [1, [2.5, False, 'red'], 3.5, 'blue']

print('nested =', nested)                    # Ausgabe: nested = [1, [2.5, False, 'red'], 3.5, 'blue']

# Indizierung der Hauptelemente
print('nested[0] =', nested[0])              # Ausgabe: nested[0] = 1
print('nested[-1] =', nested[-1])            # Ausgabe: nested[-1] = blue
print('nested[1] =', nested[1])              # Ausgabe: nested[1] = [2.5, False, 'red']

# Indizierung von Elementen in verschachtelten Listen
print('nested[1][2] =', nested[1][2])        # Ausgabe: nested[1][2] = red

# Zeichen in Strings indizieren (doppelte Indizierung)
print('nested[1][2][1] =', nested[1][2][1])  # Ausgabe: nested[1][2][1] = e`
    }
  ]}

## Slicing mit Schrittweite

Mit Slicing wird ein Teil einer Liste ausgewählt. Die Schrittweite legt den Abstand zwischen den ausgewählten Elementen fest.


Die vollständige Syntax lautet `list[start:stop:step]`:

- `start` ist der erste enthaltene Index
- `stop` ist der erste nicht mehr enthaltene Index
- `step` ist der Abstand zwischen den ausgewählten Indizes

<CodeBlock
  data={[
    {
      language: "python",
      filename: "list_slicing.py",
      code: `# Liste mit Slicing-Beispielen
x = [0, 1, 2, 3, 4, 5]
print('x =', x)                              # Ausgabe: x = [0, 1, 2, 3, 4, 5]

# Grundlegendes Slicing
print('x[1:4] =', x[1:4])                    # Ausgabe: x[1:4] = [1, 2, 3]

# Slicing vom negativen Index bis zum Ende
print('x[-3:] =', x[-3:])                    # Ausgabe: x[-3:] = [3, 4, 5]

# Slicing mit Schrittweite
print('x[1:4:2] =', x[1:4:2])                # Ausgabe: x[1:4:2] = [1, 3]

# Liste mit negativer Schrittweite umkehren
print('x[::-1] =', x[::-1])                  # Ausgabe: x[::-1] = [5, 4, 3, 2, 1, 0]`
    }
  ]}
/>

Beim Slicing wählt man einen zusammenhängenden oder regelmäßig übersprungenen Teil einer Liste aus. Für `x = [0, 1, 2, 3, 4, 5]` liefert `x[1:4]` die Elemente an den Indizes <InlineMath math="1" />, <InlineMath math="2" /> und <InlineMath math="3" />. Der Endindex <InlineMath math="4" /> gehört nicht mehr zum Ergebnis. Der Ausdruck `x[1:4:2]` verwendet die Schrittweite <InlineMath math="2" /> und wählt deshalb die Indizes <InlineMath math="1" /> und <InlineMath math="3" /> aus.

Listen und Strings unterstützen beide Indizierung und Slicing.

| Operation | Zeichenfolge | Liste |
|---------|--------|------|

## Häufige Listenformen

Eine Liste kann leer sein, gemischte Typen enthalten oder weitere Listen enthalten:

1. **Leere Listen**

   Sowohl `[]` als auch `list()` erzeugen eine leere Liste, die später gefüllt werden kann.

2. **Heterogene Listen**

   Eine Liste kann zum Beispiel einen Namen, ein Alter und einen booleschen Wert enthalten. Gemischte Typen sind sinnvoll, wenn jede Position eine klar festgelegte Bedeutung hat.

3. **Verschachtelte Listen**

   Eine verschachtelte Liste enthält weitere Listen als Elemente. Innere Listen gleicher Länge können die Zeilen einer Matrix oder Tabelle darstellen.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "special_lists.py",
      code: `# Leere Listen - zwei Erstellungsmethoden
a = []                                       # Ausgabe: []
b = list()                                   # Ausgabe: []

# Heterogene Liste - verschiedene Datentypen
mixed = [False, 2, 3.5, 'blue']             # Ausgabe: [False, 2, 3.5, 'blue']

# Verschachtelte Liste - Liste innerhalb der Liste
nested = [1, [2.5, False, 'red'], 3.5, 'blue']  # Ausgabe: [1, [2.5, False, 'red'], 3.5, 'blue']

print('Empty list 1:', a)
print('Empty list 2:', b)
print('Mixed types:', mixed)
print('Nested structure:', nested)`
    }

/>

Verschachtelte Listen können Zeilen, Bäume oder kleine tabellenartige Strukturen darstellen. Sie bilden nicht automatisch eine rechteckige Matrix. Mehrere Elemente können außerdem auf dieselbe innere Liste verweisen. Eine verkettete Indizierung wie `nested[1][2]` wählt auf jeder Ebene ein Element aus.

## Weitere Sammlungen

Neben Listen stellt Python Tupel, Dictionaries und Sets mit jeweils eigenen Regeln bereit.

### Tupel

Ein Tupel ähnelt einer Liste, aber seine Positionen können nach der Erstellung nicht ersetzt werden. Mehrere Werte lassen sich in einem Tupel zusammenfassen und später wieder auf einzelne Variablen verteilen.

Ein Tupel kann seine eigenen Elemente nicht ersetzen. Ein Element darf jedoch auf ein veränderliches Objekt verweisen, dessen Inhalt sich weiterhin ändern lässt.

| Aspekt | Tupel | Liste |
|-------|-------|------|
| **Veränderlichkeit** | Unveränderlich | Veränderlich |
| **Syntax** | `()` oder ohne Klammern | `[]` |
| **Nutzung** | Daten mit festen Positionen, etwa Koordinaten | Daten, die ergänzt oder geändert werden |

t1 = (0, 1, 2)                               # Ausgabe: t1 = (0, 1, 2)
t2 = 3, 4, 5                                 # Ausgabe: t2 = (3, 4, 5)
print('t1 =', t1)

### Dictionary

Ein Dictionary speichert Schlüssel-Wert-Paare. Jeder Schlüssel muss eindeutig sein und unverändert hashbar bleiben, solange er im Dictionary liegt. Werte dürfen mehrfach vorkommen und auf veränderliche Objekte verweisen. Ein Dictionary-Literal verwendet `{}` mit einem Doppelpunkt zwischen Schlüssel und Wert.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "dictionary_examples.py",
      code: `# Wörterbuch erstellen

print('kontakte =', kontakte)
# Ausgabe: kontakte = {'Alice': 'alice@example.com', 'Bob': 'bob@example.com'}

# Zugriff auf Werte per Schlüssel

print('Nach dem Hinzufügen von David:', kontakte)
# Ausgabe: Nach dem Hinzufügen von David: {'Alice': 'alice@example.com', 'Bob': 'bob@example.com', 'David': 'david@example.com'}`
    }
  ]}

### Mengen in Python

Ein Set speichert eindeutige, hashbare Elemente und unterstützt mathematische Mengenoperationen. Es bietet keine Elementindizes und garantiert keine Iterationsreihenfolge. Nichtleere Set-Literale verwenden `{}`. Ein leeres Set entsteht mit `set()`, weil `{}` ein leeres Dictionary erzeugt.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "set_examples.py",
      code: `# Set erstellen
zahlen = {1, 2, 3, 4, 5}
print('zahlen =', sorted(zahlen))            # Ausgabe: zahlen = [1, 2, 3, 4, 5]

# Elemente zum Set hinzufügen
zahlen.add(6)
print('Nach dem Hinzufügen von 6:', sorted(zahlen))
# Ausgabe: Nach dem Hinzufügen von 6: [1, 2, 3, 4, 5, 6]

# Set-Operationen
gerade = {2, 4, 6, 8}
ungerade = {1, 3, 5, 7}

# Union (Kombination)
print('gerade | ungerade =', sorted(gerade | ungerade))
# Ausgabe: gerade | ungerade = [1, 2, 3, 4, 5, 6, 7, 8]

# Überschneidung
print('gerade & ungerade =', gerade & ungerade) # Ausgabe: gerade & ungerade = set()`
    }
  ]}

### Vergleich der Sammlungstypen

| Sammlung | Syntax | Geordnet | Veränderlich | Duplikate | Hauptverwendung |
|-----------|---------|---------|---------|------------|------------|
| **Liste** | `[1, 2, 3]` | Ja | Ja | Ja | Daten, die geändert werden müssen |
| **Tupel** | `(1, 2, 3)` | Ja | Nein | Ja | Feste Daten, Koordinaten |
| **Wörterbuch** | `{'a': 1}` | Ja* | Ja | Nein (Schlüssel) | Schlüsselwertzuordnung |
| **Set** | `{1, 2, 3}` | Nein | Ja | Nein | Eindeutige Elemente, Mengenoperationen |

> Seit Python `3.7` folgt die Iteration eines Dictionaries garantiert der Einfügereihenfolge der Schlüssel. Das Aktualisieren eines Schlüssels ändert seine Position nicht. Wird ein Schlüssel gelöscht und erneut eingefügt, steht er anschließend am Ende.
