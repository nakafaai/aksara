## Container dalam Python

Container menyimpan beberapa nilai dalam satu objek. Ada container yang mempertahankan posisi setiap elemen, ada yang menghubungkan kunci dengan nilai, dan ada yang hanya menyimpan anggota unik. Pilih jenis container berdasarkan cara program akan membaca dan mengubah data.

Beberapa container dapat memuat objek dari tipe yang berbeda. Namun, setiap jenis memiliki aturan sendiri. Kunci pada `dict` dan anggota `set`, misalnya, harus memiliki nilai hash yang tetap selama digunakan. Jenis container juga menentukan apakah isinya mutable atau immutable.


Pelajaran ini membandingkan lima container bawaan:

- **String** menyimpan urutan karakter dan bersifat immutable
- **List** menyimpan urutan elemen dan bersifat mutable
- **Tuple** menyimpan urutan elemen dan bersifat immutable
- **Dictionary** menyimpan pasangan kunci dan nilai
- **Set** menyimpan anggota unik tanpa indeks

## List dalam Python

Tipe `list` menyimpan elemen secara berurutan dan bersifat mutable, sehingga isinya dapat diubah setelah dibuat. Satu `list` boleh memuat nilai dari tipe yang berbeda, meskipun bentuk elemen yang konsisten biasanya lebih mudah diproses.

Berbeda dari array tingkat rendah yang ukurannya tetap, `list` Python dapat bertambah dan berkurang. Setiap elemennya menyimpan referensi ke objek Python. Jika objek bersarang diubah, perubahan itu dapat diakses melalui setiap referensi yang menunjuk objek yang sama.


### Sifat List

| Karakteristik | Penjelasan | Contoh |
|---------------|------------|---------|
| Terurut | Setiap elemen memiliki posisi | `[1, 2, 3]` berbeda dengan `[3, 2, 1]` |
| Dapat memuat tipe campuran | Elemen tidak harus bertipe sama | `[1, 'teks', 3.14, True]` |
| Mutable | Isi dapat diubah setelah dibuat | Elemen dapat ditambah, dihapus, atau diganti |

## Indexing pada List

Indexing mengambil satu elemen dari `list` berdasarkan posisinya. Indeks Python dimulai dari <InlineMath math="0" />, sehingga elemen pertama berada pada indeks <InlineMath math="0" />.


Indexing dalam Python mengikuti aturan berikut:

- **Indeks positif** dimulai dari <InlineMath math="0" /> untuk elemen pertama
- **Indeks negatif** dimulai dari <InlineMath math="-1" /> untuk elemen terakhir
- **Indeks di luar rentang** menghasilkan `IndexError`

<CodeBlock

## Slicing dengan Step

Slicing mengambil sebagian elemen dari `list`. Nilai `step` menentukan jarak antarelemen yang dipilih.


Sintaks lengkap slicing adalah `list[start:stop:step]`, dengan:

- `start` sebagai indeks awal yang ikut diambil
- `stop` sebagai indeks akhir yang tidak ikut diambil
- `step` sebagai jarak antarindeks

<CodeBlock
  data={[
    {
      language: "python",
      filename: "list_slicing.py",
      code: `# List untuk contoh slicing
x = [0, 1, 2, 3, 4, 5]
print('x =', x)                              # Hasil: x = [0, 1, 2, 3, 4, 5]

# Slicing dasar
print('x[1:4] =', x[1:4])                    # Hasil: x[1:4] = [1, 2, 3]

# Slicing dari indeks negatif sampai akhir
print('x[-3:] =', x[-3:])                    # Hasil: x[-3:] = [3, 4, 5]

# Slicing dengan step
print('x[1:4:2] =', x[1:4:2])                # Hasil: x[1:4:2] = [1, 3]

# Membalik list dengan step negatif
print('x[::-1] =', x[::-1])                  # Hasil: x[::-1] = [5, 4, 3, 2, 1, 0]`
    }
  ]}
/>

Slicing dapat memilih elemen berurutan atau elemen dengan jarak tetap. Untuk `x = [0, 1, 2, 3, 4, 5]`, `x[1:4]` mengambil elemen pada indeks <InlineMath math="1" />, <InlineMath math="2" />, dan <InlineMath math="3" />. Indeks akhir <InlineMath math="4" /> tidak ikut diambil. Bentuk `x[1:4:2]` memakai `step` <InlineMath math="2" />, sehingga Python mengambil indeks <InlineMath math="1" /> dan <InlineMath math="3" />.

## Bentuk List yang Umum

Sebuah `list` dapat kosong, memuat tipe campuran, atau bersarang:

1. **List kosong**

   `[]` dan `list()` sama-sama membuat `list` kosong yang dapat diisi kemudian.

2. **List dengan tipe campuran**

   Satu `list` dapat berisi nama, umur, dan nilai `bool`. Gunakan bentuk campuran hanya jika setiap posisi memang memiliki arti yang jelas.

3. **List bersarang**

   `list` bersarang memuat `list` lain sebagai elemen. Jika setiap bagian dalam memiliki panjang yang sama, susunan ini dapat mewakili baris pada tabel atau matriks.

Beberapa elemen juga dapat merujuk ke `list` bagian dalam yang sama. Indexing bertingkat seperti `nested[1][2]` memilih satu elemen pada setiap tingkat.

## Container Lain

Selain `list`, Python menyediakan `tuple`, `dict`, dan `set` dengan aturan yang berbeda.

### Tuple Python

Tipe `tuple` menyerupai `list`, tetapi urutan posisinya bersifat immutable. Beberapa nilai dapat dikemas ke dalam satu `tuple`, lalu di-unpack ke beberapa variabel.

Posisi dalam `tuple` tidak dapat diubah. Namun, sebuah posisi dapat merujuk ke objek seperti `list` yang isinya masih dapat berubah.

| Aspek | Tuple | List |
|-------|-------|------|
| **Perubahan isi** | Posisi tidak dapat diubah | Posisi dan isi dapat diubah |
| **Sintaks** | `()` atau tanpa kurung | `[]` |
| **Kegunaan** | Data dengan posisi tetap, seperti koordinat | Data yang perlu ditambah atau diubah |

### Dictionary Python

Tipe `dict` menyimpan pasangan kunci dan nilai. Setiap kunci harus unik dan memiliki nilai hash yang tetap selama digunakan. Nilai dalam pasangan boleh berulang dan dapat merujuk ke objek mutable. Literal `dict` memakai `{}` dengan titik dua di antara kunci dan nilai.

### Set Python

Tipe `set` menyimpan anggota unik yang memiliki nilai hash tetap dan mendukung operasi himpunan matematika. `set` tidak menyediakan indeks dan tidak menjamin urutan iterasi. Literal `set` yang tidak kosong memakai `{}`, sedangkan himpunan kosong harus dibuat dengan `set()` karena `{}` menghasilkan `dict` kosong.

<CodeBlock
  data={[
    {
      language: "python",

### Perbandingan Container

| Container | Sintaks | Terurut | Mutable | Duplikasi | Kegunaan Utama |
|-----------|---------|---------|---------|-----------|----------------|
| **List** | `[1, 2, 3]` | Ya | Ya | Ya | Data yang perlu diubah |
| **Tuple** | `(1, 2, 3)` | Ya | Tidak pada tiap posisi | Ya | Data dengan posisi tetap |
| **Dictionary** | `{'a': 1}` | Ya | Ya | Kunci harus unik | Pasangan kunci dan nilai |
| **Set** | `{1, 2, 3}` | Tidak | Ya | Tidak | Anggota unik dan operasi himpunan |

> Sejak Python `3.7`, iterasi `dict` mengikuti urutan penyisipan kunci. Memperbarui kunci tidak mengubah posisinya. Jika kunci dihapus lalu dimasukkan kembali, posisinya berpindah ke akhir.
