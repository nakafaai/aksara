## Cara Python Menyusun Data dan Tingkah Laku

Python menyokong beberapa cara untuk menyusun atur cara. Kod prosedural mengikut satu urutan langkah. Kod fungsian mengubah data menggunakan fungsi. Kod berorientasikan objek mengumpulkan data dan tingkah laku yang berkaitan. Satu atur cara boleh menggabungkan ketiga-tiga gaya ini.

Semasa atur cara berjalan, <Highlight>setiap nilai Python ialah objek</Highlight>. Nombor, fungsi, kelas dan modul masing-masing mempunyai jenis, identiti yang membezakan objek itu daripada objek lain, dan nilai yang disimpan.

Jenis sesuatu objek menentukan atribut dan kaedah (method) yang tersedia padanya. Oleh sebab peraturan ini terpakai pada setiap objek, fungsi boleh disimpan dalam senarai, kelas boleh dihantar kepada fungsi lain, dan nombor boleh mempunyai kaedah. Model objek Python boleh digunakan dalam struktur atur cara prosedural, fungsian dan berorientasikan objek.

## Membandingkan Cara Menyusun Atur Cara

Model objek yang sama menyokong beberapa cara untuk menyusun atur cara. Gaya prosedural menyusun langkah demi langkah dan menghantar data antara langkah itu, gaya fungsian membina pengiraan daripada gabungan fungsi, dan gaya berorientasikan objek **menyimpan data bersama operasi** yang menggunakannya. Apabila kamu tahu gaya yang diikuti oleh sesuatu fail, aliran fail itu lebih mudah dibaca.

### Gaya Prosedural

Dalam gaya prosedural, atur cara disusun berdasarkan **operasi dan aliran data yang jelas**. Struktur data dan fungsi yang menerimanya boleh kekal berasingan, walaupun dalam bahasa yang turut menyokong kelas.

struct ParkSystem {
    int max;
    int occ;
};

int occupy(struct ParkSystem* ps) {
    if (ps->max <= ps->occ) {
        return -1;
    }
    ps->occ++;
    return 0;
}

void leave(struct ParkSystem* ps) {
    if (ps->occ > 0) {
        ps->occ--;
    }
}

int main() {
    struct ParkSystem ps = {100, 0};
    occupy(&ps);
    printf("%d %d", ps.max, ps.occ);
    return 0;
}`

Dalam gaya berorientasikan objek, kelas boleh **mengumpulkan keadaan dan tingkah laku yang berkaitan** di sebalik satu antara muka. Atribut mewakili keadaan objek, manakala kaedah mentakrifkan operasi yang menggunakan atau mengemas kini keadaan itu.

## Sistem Tempat Letak Kereta sebagai Contoh

Dalam contoh ini, sistem tempat letak kereta ialah objek yang mempunyai keadaan dan tingkah laku. Keadaannya merekodkan **kapasiti maksimum dan bilangan ruang yang sudah diisi**. Kaedahnya membenarkan kereta masuk atau merekodkan kereta yang keluar.

<CodeBlock
  data={[{
    language: "python",
    filename: "parking_system_detailed.py",
    code: `class ParkingSystem:
    def __init__(self, capacity):
        """Mulakan sistem tempat letak kereta dengan kapasiti tertentu"""
        if type(capacity) is not int or capacity <= 0:
            raise ValueError("Kapasiti mesti integer positif")
        self.capacity = capacity
        self.vehicles = []  # Senarai kenderaan yang sedang diletakkan

    def park_vehicle(self, vehicle_plate):
        """Kaedah untuk meletakkan kenderaan"""
        if vehicle_plate in self.vehicles:
            return f"Kenderaan {vehicle_plate} sudah diletakkan"
        if len(self.vehicles) >= self.capacity:
            return f"Tempat letak kereta penuh! Tidak boleh meletakkan {vehicle_plate}"

        self.vehicles.append(vehicle_plate)
        return f"Kenderaan {vehicle_plate} berjaya diletakkan"

    def exit_vehicle(self, vehicle_plate):
        """Kaedah untuk keluar dari tempat letak kereta"""
        if vehicle_plate in self.vehicles:
            self.vehicles.remove(vehicle_plate)
            return f"Kenderaan {vehicle_plate} sudah keluar"
        else:
            return f"Kenderaan {vehicle_plate} tidak dijumpai"

    def get_status(self):
        """Kaedah untuk melihat status tempat letak kereta"""
        occupied = len(self.vehicles)
        available = self.capacity - occupied
        return {
            'capacity': self.capacity,
            'occupied': occupied,
            'available': available,
            'vehicles': tuple(self.vehicles)
        }

    def is_full(self):
        """Kaedah untuk menyemak sama ada tempat letak kereta penuh"""
        return len(self.vehicles) >= self.capacity

# Contoh penggunaan

print(parking.park_vehicle("B 1234 CD"))
print(parking.park_vehicle("B 5678 EF"))
print(parking.get_status())
print(parking.is_full())`

Yang berbeza ialah set atribut dan kaedah yang disediakan oleh kelas itu, kerana <Highlight>jenis yang menentukan alat yang tersedia</Highlight>, bukan model objek itu sendiri.

## Fungsi Juga Objek

Kamu boleh **menghantar fungsi sebagai argumen**, menyimpannya dalam bekas, dan mengumpukkannya kepada pemboleh ubah sama seperti nilai lain.

## Kelas dan Tika sebagai Objek

Kelas mentakrifkan cara tikanya dibina dan cara Python mencari tingkah laku yang dikongsi oleh tika-tika itu. Kelas itu sendiri juga objek, dan **setiap tika membawa keadaan tikanya sendiri**.

## Kaedah Khas

Kaedah khas bermula dan berakhir dengan **dua garis bawah**. Python memanggilnya melalui sintaks dan fungsi terbina dalam seperti `+`, `abs()`, `repr()` dan ujian kebenaran. Tulis kaedah khas hanya apabila maknanya memang semula jadi bagi domain itu.

<CodeBlock
  data={[{
    language: "python",
    filename: "magic_methods.py",

    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        """Perwakilan yang mudah dibaca oleh manusia."""
        return f"({self.x}, {self.y})"

    def __repr__(self):
        """Perwakilan yang tidak samar untuk nyahpepijat."""
        return f"Vector2D(x={self.x!r}, y={self.y!r})"

        """Pulangkan magnitud vektor."""
        return hypot(self.x, self.y)

        if not isinstance(other, Vector2D):

        if not isinstance(other, Vector2D):

        """Pulangkan False untuk vektor sifar dan True untuk setiap vektor lain."""
        return bool(self.x or self.y)

## Latihan Pengaturcaraan Berorientasikan Objek

Contoh berikut menggabungkan beberapa kelas untuk memodelkan **buku, ahli dan pinjaman perpustakaan**.

| Peringkat | Buku pertama | Pinjaman Alice |
| --- | --- | --- |
| Sebelum meminjam | Tersedia, tiada peminjam | Kosong |
| Selepas `borrow_book()` | Dipinjam oleh Alice | Berisi buku pertama |
| Selepas `return_book()` | Tersedia semula | Kosong |

Tajuk buku, nama pengarang dan pengecam dalam contoh ini ialah data sampel. Senarai buku dan senarai ahli kekal sebagai atribut awam. Contoh ini mengajar hubungan antara objek, bukan storan untuk ramai pengguna.
