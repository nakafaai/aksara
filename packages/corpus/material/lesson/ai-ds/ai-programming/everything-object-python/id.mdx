## Cara Python Mengatur Data dan Perilaku

Python mendukung beberapa cara menyusun program. Procedural programming mengatur program sebagai urutan langkah. Functional programming mengolah data dengan fungsi. Object-oriented programming menyatukan data dan operasi yang berkaitan. Ketiganya dapat dipakai bersama.

Saat program berjalan, setiap nilai di Python merupakan objek. Bilangan, fungsi, class, dan modul memiliki tipe, identitas yang membedakannya dari objek lain, serta nilai yang disimpan.

Tipe sebuah objek menentukan atribut dan method yang tersedia. Karena aturan ini berlaku untuk semua objek, fungsi dapat disimpan dalam list, class dapat diberikan kepada fungsi lain, dan bilangan dapat memiliki method. Model objek Python dapat digunakan dalam program procedural, functional, maupun object-oriented.

## Membandingkan Cara Menyusun Program

### Procedural Programming

Dalam procedural programming, program disusun sebagai rangkaian operasi dengan aliran data yang jelas. Struktur data dan fungsi yang mengolahnya dapat ditulis secara terpisah, termasuk dalam bahasa yang mendukung class.

<CodeBlock

// Contoh pendekatan procedural dalam bahasa C
struct ParkSystem {
    int max;
    int occ;
};

int occupy(struct ParkSystem* ps) {
    if (ps->max <= ps->occ) {
        return -1;
    }
    ps->occ++;
    return 0;
}

void leave(struct ParkSystem* ps) {
    if (ps->occ > 0) {
        ps->occ--;
    }
}

int main() {
    struct ParkSystem ps = {100, 0};
    occupy(&ps);
    printf("%d %d", ps.max, ps.occ);
    return 0;
}`

Di sini, `struct` C menyimpan state parkir. Setiap fungsi menerima pointer ke data tersebut. Fungsi procedural dapat membaca input dan membiarkannya tetap sama.

### Object Oriented Programming

Dalam object-oriented programming, class mengelompokkan data dan operasi yang saling berkaitan. Atribut menyimpan state objek, sedangkan method membaca atau memperbarui state tersebut.

<CodeBlock
  data={[{
    language: "python",
    filename: "oop_parking.py",
    code: `# Contoh pendekatan object-oriented dalam Python
class ParkSystem:
    def __init__(self, max_capacity):
        self.max = max_capacity
        self.occ = 0

    def occupy(self):
        if self.max <= self.occ:
            return -1
        self.occ += 1
        return 0

    def leave(self):
        if self.occ > 0:
            self.occ -= 1

# Penggunaan
ps = ParkSystem(100)
ps.occupy()
print(f"Max: {ps.max}, Occupied: {ps.occ}")`
  }]}

Versi Python menyimpan aturan dan operasi parkir dalam satu class. Method `occupy` memeriksa kapasitas saat dipanggil. Namun, kode dari luar masih dapat mengubah atribut `max` dan `occ` secara langsung. Jadi, contoh singkat ini belum sepenuhnya melindungi state objek.

## Sistem Parkir sebagai Contoh

Pada contoh ini, state objek menyimpan kapasitas maksimum dan jumlah tempat yang terisi. Method `occupy` mencatat mobil yang masuk, sedangkan `leave` mencatat mobil yang keluar.

    def __init__(self, capacity):
        """Inisialisasi sistem parkir dengan kapasitas tertentu"""
        if capacity <= 0:
            raise ValueError("Kapasitas harus positif")
        self.capacity = capacity
        self.vehicles = []  # List kendaraan yang parkir

    def park_vehicle(self, vehicle_plate):
        """Method untuk memarkir kendaraan"""
        if vehicle_plate in self.vehicles:
            return f"Kendaraan {vehicle_plate} sudah terparkir"
        if len(self.vehicles) >= self.capacity:
            return f"Parkir penuh! Tidak bisa parkir {vehicle_plate}"

        self.vehicles.append(vehicle_plate)
        return f"Kendaraan {vehicle_plate} berhasil parkir"

    def exit_vehicle(self, vehicle_plate):
        """Method untuk mengeluarkan kendaraan"""
        if vehicle_plate in self.vehicles:
            self.vehicles.remove(vehicle_plate)
            return f"Kendaraan {vehicle_plate} keluar parkir"
        else:
            return f"Kendaraan {vehicle_plate} tidak ditemukan"

        """Method untuk melihat status parkir"""
        occupied = len(self.vehicles)
        available = self.capacity - occupied
        return {
            'capacity': self.capacity,
            'occupied': occupied,
            'available': available,
            'vehicles': tuple(self.vehicles)
        }

        """Method untuk memeriksa apakah parkir penuh"""
        return len(self.vehicles) >= self.capacity

## Special Methods

Nama special method dimulai dan diakhiri dengan double underscore, seperti `__len__`. Python memanggil method ini melalui sintaks atau built-in function seperti `+`, `abs()`, `repr()`, dan `bool()`. Tambahkan special method hanya jika operasi tersebut memang masuk akal untuk objek yang dibuat.

<CodeBlock
  data={[{
    language: "python",
    filename: "magic_methods.py",
    code: `from math import hypot

class Vector2D:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        """Representasi yang mudah dibaca manusia."""
        return f"({self.x}, {self.y})"

    def __repr__(self):
        """Representasi eksplisit untuk debugging."""
        return f"Vector2D(x={self.x!r}, y={self.y!r})"

    def __abs__(self):
        """Mengembalikan panjang vektor."""
        return hypot(self.x, self.y)

    def __eq__(self, other):
        """Membandingkan koordinat dengan Vector2D lain."""
        if not isinstance(other, Vector2D):
            return NotImplemented
        return self.x == other.x and self.y == other.y

    def __add__(self, other):
        """Mengembalikan vektor baru berisi jumlah per koordinat."""
        if not isinstance(other, Vector2D):
            return NotImplemented
        return Vector2D(self.x + other.x, self.y + other.y)

    def __bool__(self):
        """Mengembalikan False untuk vektor nol dan True untuk vektor lainnya."""
        return bool(self.x or self.y)

pertama = Vector2D(3, 4)
kedua = Vector2D(1, -2)

print(pertama)                         # (3, 4) melalui __str__
print(repr(pertama))                   # Vector2D(x=3, y=4)
print(abs(pertama))                    # 5.0 melalui __abs__
print(pertama == Vector2D(3, 4))       # True melalui __eq__

gabungan = pertama + kedua             # __add__ menghasilkan vektor baru
print(gabungan)                        # (4, 2)
print(pertama)                         # (3, 4), tidak berubah

nol = Vector2D(0, 0)
print(bool(pertama))                   # True
print(bool(nol))                       # False`

    def __init__(self, name):
        self.name = name
        self.books = []
        self.members = []

    def add_book(self, book):
        """Menambah buku ke perpustakaan"""
        self.books.append(book)
        return f"Buku '{book.title}' berhasil ditambahkan"

    def register_member(self, member):
        """Mendaftarkan anggota baru"""
        self.members.append(member)
        return f"Anggota {member.name} berhasil didaftarkan"

    def borrow_book(self, member_id, isbn):
        """Meminjam buku"""
        # Cari anggota
        member = None
        for m in self.members:
            if m.member_id == member_id:
                member = m
                break

        if not member:
            return "Anggota tidak ditemukan"

        # Cari buku
        book = None
        for b in self.books:
            if b.isbn == isbn and not b.is_borrowed:
                book = b
                break

        if not book:
            return "Buku tidak tersedia"

        # Proses peminjaman
        book.is_borrowed = True
        book.borrower = member
        member.borrowed_books.append(book)

        return f"{member.name} berhasil meminjam '{book.title}'"

    def return_book(self, member_id, isbn):
        """Mengembalikan buku"""
        member = None
        for m in self.members:
            if m.member_id == member_id:
                member = m
                break

        if not member:
            return "Anggota tidak ditemukan"

        book = None
        for b in member.borrowed_books:
            if b.isbn == isbn:
                book = b
                break

        if not book:
            return "Buku tidak ditemukan dalam daftar pinjaman"

        # Proses pengembalian
        book.is_borrowed = False
        book.borrower = None
        member.borrowed_books.remove(book)

        return f"{member.name} berhasil mengembalikan '{book.title}'"

        """Mendapatkan daftar buku yang tersedia"""
        available = [book for book in self.books if not book.is_borrowed]
        return available

        """Mendapatkan daftar buku yang dipinjam anggota"""

            if member.member_id == member_id:

        return []

Karena semua nilai mengikuti model objek yang sama, fungsi dan class dapat disimpan dalam variabel, dimasukkan ke list, atau diberikan sebagai argumen seperti nilai lain. Gunakan object-oriented programming ketika data dan operasi terkait perlu dikelola bersama. Gunakan procedural programming atau functional programming ketika urutan langkah atau aliran datanya lebih mudah dijelaskan secara langsung.
