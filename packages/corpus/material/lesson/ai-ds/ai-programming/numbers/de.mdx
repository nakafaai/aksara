## Wie Python Zahlen darstellt

Python hat drei eingebaute Zahlentypen: `int` für ganze Zahlen, `float` für näherungsweise Berechnungen mit reellen Zahlen und `complex` für komplexe Zahlen. <Highlight>Der Typ bestimmt, wie Python einen Wert darstellt</Highlight> und mit ihm rechnet.

Die interaktive Shell wertet ein Zahlenliteral aus und zeigt seinen Wert an. Vergleiche die folgenden Literale.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "basic_numbers.py",
      code: `>>> 4
4

>>> 4.
4.0

>>> 0.30
0.3

>>> 0.0000999
9.99e-05

>>> 2. + 1j
(2+1j)`
    }
  ]}
/>

Python liest jedes Literal anhand seiner Schreibweise. <InlineMath math="4" /> erzeugt eine Ganzzahl. Der Dezimalpunkt in <InlineMath math="4." /> macht den Ausdruck dagegen zu einem Gleitkommaliteral, das als <InlineMath math="4.0" /> angezeigt wird.

## Arten von Zahlendaten

Die **drei wichtigsten eingebauten Zahlentypen** in Python sind `int`, `float` und `complex`. Ein `int` speichert eine ganze Zahl beliebiger Größe, ein `float` eine Näherung einer reellen Zahl, und ein `complex` einen Real- und einen Imaginärteil.

### Ganzzahl

Eine Ganzzahl ist **positiv, negativ oder null** und besitzt keine Nachkommastellen. Python-Ganzzahlen können so weit wachsen, wie es der verfügbare Speicher erlaubt. Eine feste 32-Bit- oder 64-Bit-Grenze gibt es dabei nicht.

**Gültige Ganzzahlbeispiele**

<MathContainer>
<BlockMath math="-2, -1, 0, 1, 2" />
<BlockMath math="+1, +2, +3" />
</MathContainer>

**Besonderheiten von Ganzzahlen in Python**

Zwischen Ziffern dürfen Unterstriche stehen, damit lange Literale leichter lesbar sind. <InlineMath math="123\_456\_789" /> hat denselben Wert wie <InlineMath math="123456789" />. Die Unterstriche verändern nur die Schreibweise im Quellcode.

### Float

Ein `float` speichert eine **binäre Gleitkommanäherung**. Float-Literale können einen Dezimalpunkt oder einen Exponenten enthalten. Sie eignen sich für Messwerte und numerische Berechnungen, doch viele Dezimalbrüche lassen sich binär nicht exakt darstellen.

**Allgemeine Float-Beispiele**

<MathContainer>
<BlockMath math="-1.2, 3.85, +7.01" />
<BlockMath math="-.21, .01, 2., +5." />
</MathContainer>

**Wissenschaftliche Notation für sehr kleine oder große Zahlen**

Die Exponentschreibweise mit `e` oder `E` erleichtert sehr kleine oder sehr große Float-Literale. Zum Beispiel:

<MathContainer>
<BlockMath math="-3.2e5 = -3.2 \times 10^5" />
<BlockMath math="2e-2 = 2 \times 10^{-2}" />
<BlockMath math="+2.e4 = +2.0 \times 10^4" />
</MathContainer>

Die Notation <InlineMath math="e" /> oder <InlineMath math="E" /> in Python ist dieselbe wie die wissenschaftliche Notation, die du aus der Mathematik kennst. Die Zahl <InlineMath math="1E1" /> entspricht <InlineMath math="1 \times 10^1 = 10.0" /> und <InlineMath math="3.1E-7" /> entspricht <InlineMath math="3.1 \times 10^{-7}" />.

### Komplex

Komplexe Zahlen besitzen einen **Real- und einen Imaginärteil**. In einem Python-Literal kennzeichnet das Suffix <InlineMath math="j" /> den Koeffizienten der imaginären Einheit. Komplexe Arithmetik wird unter anderem in der Signalverarbeitung, Elektrotechnik und wissenschaftlichen Datenverarbeitung eingesetzt.

**Beispiele für komplexe Zahlen**

<MathContainer>
<BlockMath math="2 + 3j" />
<BlockMath math="4.5 - 2.1j" />
</MathContainer>

Eine komplexe Zahl lässt sich in einer Koordinatenebene darstellen. Ihr Realteil bestimmt die waagerechte und ihr Imaginärteil die senkrechte Koordinate.

## Die Typfunktion zum Überprüfen von Datentypen

Die Funktion `type()` zeigt die **genaue Klasse** eines Objekts an. Das ist beim Erkunden von Werten in der Python-Shell oder bei der Fehlersuche hilfreich.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "check_types.py",
      code: `>>> type(5)
<class 'int'>

>>> type(.1)
<class 'float'>

>>> type(2j)
<class 'complex'>`
    }
  ]}
/>

Für eine strikte Typgleichheit kannst du `type(value)` mit einer Klasse vergleichen. In Anwendungscode ist `isinstance(value, SomeType)` häufig flexibler, weil es auch Unterklassen erkennt.

## Konstruktoren zum Erstellen von Zahlenobjekten

Python bietet Konstruktoren, die Zahlenobjekte aus anderen Typen erzeugen. Damit lässt sich zum Beispiel eine **Texteingabe in eine Zahl umwandeln**, bevor du rechnest, weil Python Text nicht automatisch in eine Rechnung übernimmt.

### Konstruktor Float

Der Konstruktor `float()` wandelt eine andere Zahl oder **gültigen Zahlentext** in einen Gleitkommawert um.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "float_constructor.py",
      code: `>>> float(2)
2.0

>>> float()
0.0`
    }
  ]}
/>

`float(2)` wandelt die Ganzzahl <InlineMath math="2" /> in den Gleitkommawert <InlineMath math="2.0" /> um. `float()` ohne Argument gibt den Standardwert <InlineMath math="0.0" /> zurück.

### Konstruktor int

Der Konstruktor `int()` wandelt einen endlichen Float in eine Ganzzahl um und schneidet dabei **in Richtung null** ab.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "int_constructor.py",
      code: `>>> int(2.1)
2

>>> int(2.9)
2

>>> int(-2.9)
-2`
    }
  ]}
/>

`int()` rundet nicht auf die nächste Ganzzahl. Beide positiven Beispiele ergeben <InlineMath math="2" />. `int(-2.9)` ergibt <InlineMath math="-2" />, weil die Abschneidung in Richtung null erfolgt.

### Konstruktor für komplexe Zahlen

Der Konstruktor `complex()` erzeugt komplexe Zahlen aus **einer oder zwei reellen Zahlen**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "complex_constructor.py",
      code: `>>> complex(2.)
(2+0j)

>>> complex(0., 2.)
2j`
    }
  ]}
/>

`complex(2.)` erzeugt eine komplexe Zahl mit Realteil <InlineMath math="2" /> und Imaginärteil <InlineMath math="0" />. Unterdessen erzeugt `complex(0., 2.)` eine rein imaginäre Zahl <InlineMath math="2j" />.

Vergleich die violette Treppe mit der grauen Linie <InlineMath math="y=x" />. Bei positiven Zahlen wirft `int()` den Nachkommateil weg, also liegt das Ergebnis unter der Linie, zum Beispiel wird `int(2.9)` zu `2`. Bei negativen Zahlen liegt das Ergebnis über der Linie, denn `int(-2.9)` wird zu `-2`, nicht zu `-3`. `int()` schneidet also immer Richtung null ab, und die Stufe um null ist breiter als die anderen.
