## Tipe Numerik dari Cara Penulisan Bilangan

Python memiliki tiga tipe numerik bawaan: `int` untuk bilangan bulat, `float` untuk aproksimasi bilangan real, dan `complex` untuk bilangan kompleks. <Highlight>Tipe tersebut menentukan cara Python merepresentasikan nilai</Highlight> dan menjalankan operasi aritmetika.

Python shell mengevaluasi literal numerik dan menampilkan nilai literal. Bandingkan literal berikut.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "basic_numbers.py",
      code: `>>> 4
4

>>> 4.
4.0

>>> 0.30
0.3

>>> 0.0000999
9.99e-05

>>> 2. + 1j
(2+1j)`
    }
  ]}
/>

Python menentukan tipe setiap literal dari cara penulisannya. <InlineMath math="4" /> menghasilkan `int`, sedangkan titik desimal pada <InlineMath math="4." /> menjadikannya `float` yang ditampilkan sebagai <InlineMath math="4.0" />.

## Jenis Tipe Data Angka

**Tiga tipe numerik bawaan** utama Python adalah `int`, `float`, dan `complex`. Tipe `int` menyimpan bilangan bulat dengan ukuran tak terbatas, `float` menyimpan hampiran bilangan riil, dan `complex` menyimpan bagian riil serta bagian imajiner.

### Bilangan Bulat

Tipe `int` menyimpan **bilangan bulat** positif, negatif, atau nol. Nilai `int` dapat terus membesar selama memori masih tersedia, sehingga tidak dibatasi pada rentang 32 bit atau 64 bit.

**Contoh bilangan bulat yang valid**

<MathContainer>
<BlockMath math="-2, -1, 0, 1, 2" />
<BlockMath math="+1, +2, +3" />
</MathContainer>

**Penulisan bilangan bulat panjang**

Python mengizinkan underscore di antara digit agar literal panjang lebih mudah dibaca. Misalnya, <InlineMath math="123\_456\_789" /> bernilai sama dengan <InlineMath math="123456789" />. Underscore hanya memengaruhi penulisan kode. Nilai literalnya tetap sama.

### Tipe Float

Tipe `float` menyimpan **pendekatan biner** terhadap bilangan real. Literal `float` dapat memuat titik desimal atau eksponen. Tipe ini cocok untuk pengukuran dan komputasi numerik, tetapi banyak pecahan desimal tidak dapat disimpan secara persis dalam biner.

**Contoh literal `float`**

<MathContainer>
<BlockMath math="-1.2, 3.85, +7.01" />
<BlockMath math="-.21, .01, 2., +5." />
</MathContainer>

**Notasi ilmiah untuk angka sangat kecil atau besar**

Notasi eksponen `e` atau `E` memudahkan penulisan literal `float` yang sangat kecil atau sangat besar. Misalnya:

<MathContainer>
<BlockMath math="-3.2e5 = -3.2 \times 10^5" />
<BlockMath math="2e-2 = 2 \times 10^{-2}" />
<BlockMath math="+2.e4 = +2.0 \times 10^4" />
</MathContainer>

Notasi <InlineMath math="e" /> atau <InlineMath math="E" /> dalam Python sama seperti notasi ilmiah yang kamu pelajari di matematika. Angka <InlineMath math="1E1" /> sama dengan <InlineMath math="1 \times 10^1 = 10.0" />, dan <InlineMath math="3.1E-7" /> sama dengan <InlineMath math="3.1 \times 10^{-7}" />.

### Bilangan Kompleks

Bilangan kompleks memiliki **bagian real dan imajiner**. Dalam literal Python, sufiks <InlineMath math="j" /> menandai koefisien unit imajiner. Aritmetika kompleks umum digunakan dalam pemrosesan sinyal, teknik listrik, dan komputasi ilmiah.

**Contoh bilangan kompleks**

<MathContainer>
<BlockMath math="2 + 3j" />
<BlockMath math="4.5 - 2.1j" />
</MathContainer>

Bilangan kompleks dapat digambar pada bidang koordinat. Bagian real menentukan koordinat horizontal, sedangkan bagian imajiner menentukan koordinat vertikal.

## Memeriksa Tipe dengan Fungsi Type

Fungsi `type()` menunjukkan **class sebenarnya** dari sebuah objek. Fungsi ini berguna ketika mencoba nilai di Python shell atau melacak data yang tidak sesuai dugaan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "check_types.py",
      code: `>>> type(5)
<class 'int'>

>>> type(.1)
<class 'float'>

>>> type(2j)
<class 'complex'>`
    }
  ]}
/>

Untuk memeriksa class sebenarnya, bandingkan `type(value)` dengan class yang diharapkan. Dalam kode aplikasi, `isinstance(value, SomeType)` biasanya lebih sesuai karena juga mengenali subclass.

## Constructor untuk Membuat Bilangan

Python menyediakan constructor untuk membuat bilangan dari tipe lain. Misalnya, **input teks** yang dibaca dari pengguna harus diubah menjadi bilangan sebelum dipakai dalam perhitungan, dan Python tidak mengubahnya secara otomatis.

### Constructor Float

Constructor `float()` mengubah nilai numerik lain atau **teks yang valid** menjadi nilai `float`.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "float_constructor.py",
      code: `>>> float(2)
2.0

>>> float()
0.0`
    }
  ]}
/>

Ketika kamu memanggil `float(2)`, Python mengubah bilangan bulat <InlineMath math="2" /> menjadi <InlineMath math="2.0" />. Jika `float()` dipanggil tanpa argumen, default value yang dihasilkan adalah <InlineMath math="0.0" />.

### Constructor Int

Constructor `int()` mengubah `float` berhingga menjadi bilangan bulat dengan memotong bagian pecahannya **ke arah nol**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "int_constructor.py",
      code: `>>> int(2.1)
2

>>> int(2.9)
2

>>> int(-2.9)
-2`
    }
  ]}
/>

`int()` tidak membulatkan ke bilangan bulat terdekat. Kedua contoh positif menghasilkan <InlineMath math="2" />, sedangkan `int(-2.9)` menghasilkan <InlineMath math="-2" /> karena pemotongan bergerak ke arah nol.

### Constructor Complex

Constructor `complex()` membuat bilangan kompleks dari **satu atau dua bilangan real**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "complex_constructor.py",
      code: `>>> complex(2.)
(2+0j)

>>> complex(0., 2.)
2j`
    }
  ]}
/>

`complex(2.)` membuat bilangan kompleks dengan bagian real <InlineMath math="2" /> dan bagian imajiner <InlineMath math="0" />. Sedangkan `complex(0., 2.)` membuat bilangan imajiner murni <InlineMath math="2j" />.

Bandingkan tangga ungu dengan garis abu-abu <InlineMath math="y=x" />. Untuk bilangan positif, `int()` membuang bagian desimal sehingga hasilnya berada di bawah garis, misalnya `int(2.9)` menjadi `2`. Untuk bilangan negatif, hasilnya berada di atas garis, karena `int(-2.9)` menjadi `-2`, bukan `-3`. Jadi `int()` selalu memotong ke arah nol, dan anak tangga di sekitar nol lebih lebar dari yang lain.
