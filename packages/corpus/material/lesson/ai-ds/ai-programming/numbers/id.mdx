## Pengenalan Tipe Data Angka

Python menyediakan tipe numerik bawaan untuk bilangan bulat, perhitungan bilangan real secara aproksimatif, dan bilangan kompleks. Pemilihan tipe penting karena setiap tipe merepresentasikan nilai dan menjalankan aritmetika dengan cara yang berbeda.

Python sangat fleksibel dalam menangani angka. Ketika kamu mengetik angka di Python shell, Python langsung mengenali dan menampilkannya kembali. Mari kita lihat bagaimana Python bekerja dengan angka.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "basic_numbers.py",
      code: `>>> 4
4

>>> 4.
4.0

>>> 0.30
0.3

>>> 0.0000999
9.99e-05

>>> 2. + 1j
(2+1j)`
    }
  ]}
/>

Python membaca setiap literal berdasarkan notasinya. <InlineMath math="4" /> menghasilkan integer, sedangkan titik desimal pada <InlineMath math="4." /> menjadikannya literal floating-point yang ditampilkan sebagai <InlineMath math="4.0" />.

## Jenis Tipe Data Angka

Tiga tipe numerik bawaan utama Python adalah `int`, `float`, dan `complex`.

### Integer

Integer adalah bilangan bulat positif, negatif, atau nol. Integer Python memiliki presisi arbitrer, sehingga ukurannya dibatasi oleh memori yang tersedia, bukan oleh rentang tetap 32-bit atau 64-bit.

**Contoh integer yang valid**

<MathContainer>
<BlockMath math="-2, -1, 0, 1, 2" />
<BlockMath math="+1, +2, +3" />
</MathContainer>

**Fitur khusus integer di Python**

Python mengizinkan underscore di antara digit agar literal panjang lebih mudah dibaca. Misalnya, <InlineMath math="123\_456\_789" /> bernilai sama dengan <InlineMath math="123456789" />. Underscore hanya memengaruhi notasi dalam kode sumber.

### Float

`float` menyimpan aproksimasi floating-point biner. Literal float dapat memuat titik desimal atau eksponen. Tipe ini cocok untuk pengukuran dan komputasi numerik, tetapi banyak pecahan desimal tidak dapat direpresentasikan secara persis dalam biner.

**Contoh float yang umum**

<MathContainer>
<BlockMath math="-1.2, 3.85, +7.01" />
<BlockMath math="-.21, .01, 2., +5." />
</MathContainer>

**Notasi ilmiah untuk angka sangat kecil atau besar**

Notasi eksponen `e` atau `E` memudahkan penulisan literal float yang sangat kecil atau sangat besar. Misalnya:

<MathContainer>
<BlockMath math="-3.2e5 = -3.2 \times 10^5" />
<BlockMath math="2e-2 = 2 \times 10^{-2}" />
<BlockMath math="+2.e4 = +2.0 \times 10^4" />
</MathContainer>

Notasi <InlineMath math="e" /> atau <InlineMath math="E" /> dalam Python sama seperti notasi ilmiah yang kamu pelajari di matematika. Angka <InlineMath math="1E1" /> sama dengan <InlineMath math="1 \times 10^1 = 10.0" />, dan <InlineMath math="3.1E-7" /> sama dengan <InlineMath math="3.1 \times 10^{-7}" />.

### Complex

Bilangan kompleks memiliki bagian real dan imajiner. Dalam literal Python, sufiks <InlineMath math="j" /> menandai koefisien unit imajiner. Aritmetika kompleks umum digunakan dalam pemrosesan sinyal, teknik listrik, dan komputasi ilmiah.

**Contoh bilangan kompleks**

<MathContainer>
<BlockMath math="2 + 3j" />
<BlockMath math="4.5 - 2.1j" />
</MathContainer>

Bayangkan bilangan kompleks seperti koordinat pada peta. Bagian real adalah posisi horizontal, dan bagian imajiner adalah posisi vertikal.

## Fungsi type untuk Memeriksa Tipe Data

Fungsi `type()` melaporkan class persis dari sebuah objek. Fungsi ini berguna ketika mengeksplorasi nilai di Python shell atau melacak data yang tidak sesuai dugaan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "check_types.py",
      code: `>>> type(5)
<class 'int'>

>>> type(.1)
<class 'float'>

>>> type(2j)
<class 'complex'>`
    }
  ]}
/>

Untuk pemeriksaan identitas tipe yang ketat, kamu dapat membandingkan `type(value)` dengan sebuah class. Dalam kode aplikasi, `isinstance(value, SomeType)` sering lebih fleksibel karena juga mengenali subclass.

## Constructor untuk Membuat Objek Angka

Python menyediakan constructor untuk mengubah atau membuat objek angka dari tipe lain. Ini sangat berguna ketika kamu perlu mengonversi data dari satu format ke format lain.

### Constructor float

Constructor `float()` mengubah angka lain menjadi bilangan desimal.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "float_constructor.py",
      code: `>>> float(2)
2.0

>>> float()
0.0`
    }
  ]}
/>

Ketika kamu memanggil `float(2)`, Python mengubah integer <InlineMath math="2" /> menjadi float <InlineMath math="2.0" />. Jika kamu memanggil `float()` tanpa argumen, Python memberikan nilai default <InlineMath math="0.0" />.

### Constructor int

Constructor `int()` mengubah float berhingga menjadi integer dengan memotong nilainya ke arah nol.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "int_constructor.py",
      code: `>>> int(2.1)
2

>>> int(2.9)
2

>>> int(-2.9)
-2`
    }
  ]}
/>

`int()` tidak membulatkan ke integer terdekat. Kedua contoh positif menghasilkan <InlineMath math="2" />, sedangkan `int(-2.9)` menghasilkan <InlineMath math="-2" /> karena pemotongan bergerak ke arah nol.

### Constructor complex

Constructor `complex()` membuat bilangan kompleks dari bilangan real.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "complex_constructor.py",
      code: `>>> complex(2.)
(2+0j)

>>> complex(0., 2.)
2j`
    }
  ]}
/>

`complex(2.)` membuat bilangan kompleks dengan bagian real <InlineMath math="2" /> dan bagian imajiner <InlineMath math="0" />. Sedangkan `complex(0., 2.)` membuat bilangan imajiner murni <InlineMath math="2j" />.
