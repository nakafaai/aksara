## Numeric Types Begin with Literal Notation

Python has three built-in numeric types: `int` for integers, `float` for approximate real-number calculations, and `complex` for complex numbers. <Highlight>The type determines how Python represents a value</Highlight> and performs arithmetic with it.

The interactive shell evaluates a numeric literal and displays its value. Compare the literals below.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "basic_numbers.py",
      code: `>>> 4
4

>>> 4.
4.0

>>> 0.30
0.3

>>> 0.0000999
9.99e-05

>>> 2. + 1j
(2+1j)`
    }
  ]}
/>

Python parses each literal from its notation. <InlineMath math="4" /> creates an integer, while the decimal point in <InlineMath math="4." /> makes it a floating-point literal whose displayed value is <InlineMath math="4.0" />.

In scientific notation, the number after `e` shifts the decimal point. `3.2e5` means <InlineMath math="3.2\cdot10^5=320000" />, and `2e-2` means <InlineMath math="2\cdot10^{-2}=0.02" />. The base-ten logarithm shows that shift as a number close to the exponent.

## Types of Number Data

Python's **three core built-in numeric types** are `int`, `float`, and `complex`. An `int` stores a whole number of unlimited size, a `float` stores an approximation of a real number, and a `complex` stores a real and an imaginary part.

### Integer

An integer is a **whole number**: positive, negative, or zero. Python integers can grow as large as the available memory allows. They do not have a fixed 32-bit or 64-bit limit.

**Valid integer examples**

<MathContainer>
<BlockMath math="-2, -1, 0, 1, 2" />
<BlockMath math="+1, +2, +3" />
</MathContainer>

**Special features of integers in Python**

Python allows underscores between digits to make long literals easier to scan. For example, <InlineMath math="123\_456\_789" /> has the same value as <InlineMath math="123456789" />. The underscores affect only the source notation.

### Float

A `float` stores a **binary floating-point approximation**. Float literals can contain a decimal point or an exponent. They are useful for measurements and numerical calculations, but many decimal fractions cannot be represented exactly in binary.

**Common float examples**

<MathContainer>
<BlockMath math="-1.2, 3.85, +7.01" />
<BlockMath math="-.21, .01, 2., +5." />
</MathContainer>

**Scientific notation for very small or large numbers**

The exponent notation `e` or `E` is convenient for very small or very large float literals. For example:

<MathContainer>
<BlockMath math="-3.2e5 = -3.2 \times 10^5" />
<BlockMath math="2e-2 = 2 \times 10^{-2}" />
<BlockMath math="+2.e4 = +2.0 \times 10^4" />
</MathContainer>

The notation <InlineMath math="e" /> or <InlineMath math="E" /> in Python is the same as the scientific notation you learned in mathematics. The number <InlineMath math="1E1" /> equals <InlineMath math="1 \times 10^1 = 10.0" />, and <InlineMath math="3.1E-7" /> equals <InlineMath math="3.1 \times 10^{-7}" />.

### Complex

Complex numbers have **real and imaginary parts**. In a Python literal, the suffix <InlineMath math="j" /> marks the coefficient of the imaginary unit. Complex arithmetic is common in signal processing, electrical engineering, and scientific computing.

**Complex number examples**

<MathContainer>
<BlockMath math="2 + 3j" />
<BlockMath math="4.5 - 2.1j" />
</MathContainer>

A complex number can be plotted on a coordinate plane. Its real part sets the horizontal coordinate, and its imaginary part sets the vertical coordinate.

The three number types live in different places. An `int` sits only on whole-number points, a `float` can sit between them, and a `complex` such as `1+2j` leaves the number line because it has an imaginary part.

## The type Function for Checking Data Types

The `type()` function reports the **exact class** of an object. It is useful when exploring values in the Python shell or diagnosing unexpected data.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "check_types.py",
      code: `>>> type(5)
<class 'int'>

>>> type(.1)
<class 'float'>

>>> type(2j)
<class 'complex'>`
    }
  ]}
/>

For a strict equality check you can compare `type(value)` with a class. In ordinary application code, `isinstance(value, SomeType)` is often more flexible because it also recognizes subclasses.

## Constructors for Creating Number Objects

Python provides constructors that create numeric objects from other types. Use them, for example, to convert **text input into a number** before calculating with it.

### Constructor float

The `float()` constructor converts another number or **valid numeric text** into a floating-point value.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "float_constructor.py",
      code: `>>> float(2)
2.0

>>> float()
0.0`
    }
  ]}
/>

When you call `float(2)`, Python converts the integer <InlineMath math="2" /> to float <InlineMath math="2.0" />. If you call `float()` without arguments, Python gives the default value <InlineMath math="0.0" />.

### Constructor int

The `int()` constructor converts a finite float to an integer by **truncating toward zero**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "int_constructor.py",
      code: `>>> int(2.1)
2

>>> int(2.9)
2

>>> int(-2.9)
-2`
    }
  ]}
/>

`int()` does not round to the nearest integer. Both positive examples become <InlineMath math="2" />, while `int(-2.9)` becomes <InlineMath math="-2" /> because truncation moves toward zero.

### Constructor complex

The `complex()` constructor creates complex numbers from **one or two real numbers**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "complex_constructor.py",
      code: `>>> complex(2.)
(2+0j)

>>> complex(0., 2.)
2j`
    }
  ]}
/>

`complex(2.)` creates a complex number with real part <InlineMath math="2" /> and imaginary part <InlineMath math="0" />. Meanwhile, `complex(0., 2.)` creates a pure imaginary number <InlineMath math="2j" />.

Compare the violet staircase with the gray line <InlineMath math="y=x" />. For positive numbers, `int()` drops the decimal part, so the result sits below the line, for example `int(2.9)` becomes `2`. For negative numbers, the result sits above the line, because `int(-2.9)` becomes `-2`, not `-3`. So `int()` always cuts toward zero, and the step around zero is wider than the others.
