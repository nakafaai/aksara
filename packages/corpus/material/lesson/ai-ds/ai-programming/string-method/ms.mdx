## Rentetan Tidak Boleh Diubah

<Highlight>Rentetan Python tidak boleh diubah (immutable)</Highlight>: nilai yang disimpan dalam objek rentetan tidak boleh disunting di tempatnya. Sesuatu operasi boleh mencipta rentetan lain, dan pemboleh ubah boleh diikat semula kepada objek baharu itu, tetapi objek rentetan yang asal kekal tidak berubah.

Oleh itu, kalau kamu mengumpukkan nilai kepada sesuatu kedudukan aksara, Python akan menimbulkan `TypeError`. Senarai pula berbeza kerana unsur-unsurnya boleh diganti di tempatnya.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "immutable_string.py",
      code: `# Demonstrasi sifat rentetan yang tidak boleh diubah
s = "hello"
print(f"Rentetan awal: {s}")

# Cuba menukar aksara secara terus
try:
    s[1] = "a"  # Baris ini akan menyebabkan ralat
except TypeError as e:
    print(f"Ralat: {e}")

# Cara yang betul: cipta rentetan baharu
s_new = s[:1] + "a" + s[2:]
print(f"Rentetan baharu: {s_new}")

# Rentetan asal kekal tidak berubah
print(f"Rentetan asal masih: {s}")`
    }
  ]}
/>

Penghirisan (slicing) dan penyambungan (concatenation) ialah dua cara untuk membina rentetan baharu daripada rentetan yang sedia ada. Operator `+` tidak menambah apa-apa pada objek asal.

## Mengukur Panjang Rentetan

Bagi rentetan Python, `len()` mengira **titik kod Unicode** (code point). Huruf Latin biasa, ruang atau tanda baca biasanya menyumbang satu, tetapi satu grafem yang kelihatan boleh mengandungi beberapa titik kod, seperti yang berlaku pada sesetengah emoji dan tanda gabungan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "string_length.py",
      code: `# Mengukur panjang pelbagai jenis rentetan
strings = [
    "hello",
    "Hello World!",
    "Python programming",
    "",  # rentetan kosong
    "   ",  # rentetan yang mengandungi ruang
    "123456"
]

for s in strings:
    print(f"'{s}' mempunyai panjang: {len(s)}")

# Panjang rentetan dengan aksara khas
special = "Hello\\nWorld\\t!"
print(f"Rentetan dengan jujukan lepas: {len(special)} aksara")
print(f"Paparan rentetan: {repr(special)}")

raw_newline = r"\\n"
print(f"Ejaan mentah {raw_newline!r}: {len(raw_newline)} titik kod")`
    }
  ]}
/>

Dalam literal rentetan biasa, ejaan sumber `\n` dan `\t` masing-masing menjadi satu titik kod baris baharu atau tab. Dalam rentetan mentah seperti `r"\n"`, garis condong ke belakang dan `n` kekal sebagai dua titik kod yang berasingan.

## Kaedah Transformasi Rentetan

Kaedah-kaedah ini memulangkan rentetan baharu dan **membiarkan rentetan asal tidak berubah**. Ini berlaku kerana rentetan tidak boleh diubah, jadi setiap transformasi menghasilkan nilai kedua dan bukannya menyunting nilai pertama.

### Menukar Huruf Besar dan Kecil

Python menyediakan beberapa kaedah untuk menukar huruf besar dan kecil. Setiap kaedah memulangkan rentetan baharu dan menggunakan **peraturan huruf besar-kecil Unicode**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "case_transformation.py",
      code: `# Contoh transformasi huruf besar-kecil pada rentetan

print(f"Huruf besar: {upper_text}")

# Tukar semua huruf kepada huruf kecil
lower_text = text.lower()
print(f"Huruf kecil: {lower_text}")

# Gaya tajuk: huruf pertama setiap perkataan menjadi huruf besar
title_text = text.title()
print(f"Gaya tajuk: {title_text}")

# Contoh dengan rentetan bercampur
mixed = "hELLo WoRLd PyThOn"
print(f"Asal: {mixed}")
print(f"Gaya tajuk: {mixed.title()}")

# Gaya tajuk pada rentetan yang ada nombor dan simbol
complex_text = "python3.9 is-awesome!"
print(f"Gaya tajuk rentetan kompleks: {complex_text.title()}")`
    }
  ]}
/>

Kaedah `title()` mengikut peraturan huruf besar-kecil yang mekanikal. Kaedah ini mudah digunakan untuk label paparan, tetapi bukan alat pemformat yang boleh dipercayai untuk nama orang atau tajuk editorial. Untuk nilai-nilai seperti itu, kekalkan ejaan yang sahih atau gunakan peraturan khusus bagi domainnya.

### Membuang Aksara di Awal dan Akhir

Tanpa argumen, `strip()`, `lstrip()` dan `rstrip()` membuang ruang putih di sekeliling rentetan. Argumen `chars` memberi Python **set aksara individu**. Python membuang mana-mana aksara itu berulang kali dari hujung yang berkenaan.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "strip_methods.py",

print(f"Strip kiri: '{left_stripped}'")

# Buang ruang di sebelah kanan sahaja
right_stripped = text.rstrip()
print(f"Strip kanan: '{right_stripped}'")

print(f"Strip tersuai: '{custom_stripped}'")

Setiap kaedah transformasi memulangkan rentetan baharu, dan bilangan huruf besar menunjukkan apa yang dilakukannya. ## Kaedah Carian dan Pengesahan

Satu kumpulan kaedah mencari kedudukan teks, dan satu kumpulan lagi menjawab soalan ya atau tidak tentang teks itu. Kaedah carian **memulangkan kedudukan**, manakala kaedah pengesahan memulangkan `True` atau `False`.

### Mencari Kedudukan Subrentetan

Kaedah `index()` dan `find()` digunakan untuk mencari kedudukan subrentetan dalam rentetan. Bezanya terletak pada cara kedua-duanya mengendalikan keadaan apabila **subrentetan tidak dijumpai**.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "substring_search.py",
      code: `# Carian subrentetan dengan pelbagai kaedah
text = "Python is a powerful programming language"

# Menggunakan index() - ralat jika tidak dijumpai
try:
    pos = text.index("powerful")
    print(f"'powerful' dijumpai pada kedudukan: {pos}")

    # Cari subrentetan yang tiada
    pos_not_found = text.index("Java")
except ValueError as e:
    print(f"Ralat dengan index(): {e}")

# Menggunakan find() - memulangkan -1 jika tidak dijumpai
pos_find = text.find("powerful")
print(f"find('powerful'): {pos_find}")

pos_not_found = text.find("Java")
print(f"find('Java'): {pos_not_found}")

print(f"Mengandungi 'Python': {'Python' in text}")

# Cari dengan parameter mula dan tamat

print(f"'{substring}' selepas kedudukan 20: {start_pos}")

    }
  ]}

Pilih kaedah mengikut kontrak kegagalannya: `find()` memulangkan `-1`, manakala `index()` menimbulkan `ValueError`. Jika kamu hanya perlu jawapan ya atau tidak, operator `in` lebih jelas daripada kedua-dua kaedah kedudukan itu.

## Kaedah Replace dan Split

Kedua-dua kaedah ini mengubah cara sesuatu rentetan dibahagikan kepada beberapa bahagian. `replace` **menukar satu subrentetan dengan subrentetan lain**, dan `split` memecahkan rentetan menjadi senarai pada sesuatu pemisah.

### Menggantikan Subrentetan

Kaedah `replace()` digunakan untuk menggantikan **semua kemunculan sesuatu subrentetan** dengan rentetan baharu.

<CodeBlock
  data={[
    {
      language: "python",
      filename: "replace_method.py",
      code: `# Contoh penggunaan kaedah replace
text = "Python is great. Python is powerful. Python is easy."

Kaedah `replace()` peka huruf besar-kecil dan menggantikan semua kemunculan, kecuali jika dihadkan oleh parameter ketiga.

### Memisahkan Rentetan

Kaedah `split()` memecahkan rentetan menjadi senarai di sekeliling pembatas yang ditetapkan. Tanpa pembatas, kaedah ini menganggap **ruang putih berturut-turut sebagai satu pemisah** dan mengabaikan medan kosong di awal atau di akhir.

<CodeBlock
  data={[
    {

      filename: "split_method.py",
      code: `# Pelbagai cara menggunakan split

sentence = "Python is a great language"
words = sentence.split()

Tanpa argumen, `split()` memotong rentetan pada setiap ruang dan memulangkan senarai perkataan. `'the quick brown fox'.split()` memberi empat perkataan, dan jumlah nilai `len()` perkataan itu ialah <InlineMath math="16" />, iaitu <InlineMath math="19" /> aksara tolak tiga ruang.

## Merantaikan Kaedah Rentetan

Kaedah transformasi yang **memulangkan rentetan** boleh dirantaikan. Kaedah seperti `split()` memulangkan senarai, jadi operasi seterusnya mesti sesuai dengan jenis hasil itu. Pastikan rantaian cukup pendek supaya setiap langkah tetap jelas. Guna pemboleh ubah perantaraan apabila satu langkah perlu disahkan atau diterangkan sebelum transformasi seterusnya.

Selepas `.strip()` yang pertama, masih ada ruang di antara `+++` dan `Python`. Oleh itu, `.strip("+- ")` membuang **tanda tambah, tanda tolak dan ruang** dari kedua-dua hujung sebelum huruf ditukar.
