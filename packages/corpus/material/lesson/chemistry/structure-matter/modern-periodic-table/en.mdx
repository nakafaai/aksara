## Atomic Number Sets the Order

Each box in the modern periodic table represents one element. The elements are arranged by increasing **atomic number**, written as <InlineMath math="Z" />. The atomic number is the number of protons in an atom's nucleus.

Because the number of protons identifies an element, increasing <InlineMath math="Z" /> produces a repeating pattern of chemical properties.

## Periods and Groups

A **period** is a horizontal row. Periods are read from left to right and numbered <InlineMath math="1" /> to <InlineMath math="7" />. In the simple shell model, elements in the same period have the same number of main occupied shells.

A **group** is a vertical column. Groups are read from top to bottom and numbered <InlineMath math="1" /> to <InlineMath math="18" />. In the main groups, the number of valence electrons is often the same, so chemical properties tend to be similar.

Elements in one group can have different properties while sharing a similar outer-electron pattern. In chemistry, that outer feature is mainly the valence electrons.

## Colors Mark Element Regions

The periodic table also divides elements into regions.

| Region | Typical location and behavior |
| :----- | :---------------------------- |
| Metals | Many are on the left and in the middle of the table. Many metals conduct electricity and tend to lose electrons when forming ions. |
| Nonmetals | Many are in the upper-right part of the table. Many nonmetals tend to gain or share electrons when bonding. |
| Metalloids | They sit at the boundary between metals and nonmetals. Their properties are in between, for example silicon can be used as a semiconductor. |
| Noble gases | They are in group <InlineMath math="18" />. These elements are very unreactive because their outer electron arrangement is stable. |

The metalloid boundary is not drawn exactly the same in every book because some elements sit in an overlapping property region. The important idea is the position: the transition area between metals and nonmetals.

## Why Two Rows Sit Below

If the lanthanides and actinides were drawn in the middle of the main table, the periodic table would become very wide. They are placed below to keep the drawing readable. They still occupy positions within the periodic system.

Lanthanides are still part of period <InlineMath math="6" />, while actinides are still part of period <InlineMath math="7" />.
